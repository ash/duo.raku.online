## Uzdevums

Parādiet abas `try` puses. `try` bloks noķer kļūdas savā kodā. Vispirms ielieciet aprēķinu `try` blokā. Aprēķinam jāizdodas, piemēram, `6 * 7`. Izdrukājiet tā rezultātu. Tad ielieciet kodu ar `die 'broken'` otrā `try` blokā. Izdrukājiet, vai šis bloks deva definētu rezultātu. Izdrukājiet arī noķertā izņēmuma paziņojumu.

## Piemērs

Programma izdrukā:

```
42
False
broken
```
