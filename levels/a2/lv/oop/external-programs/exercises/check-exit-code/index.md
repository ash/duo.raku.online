## Uzdevums

Palaidiet komandu, kas neizdodas ar nolūku. Piemēram, izmantojiet `sh -c 'exit 4'`. Paturiet `Proc`, ko tā atgriež. Izdrukājiet komandas izejas kodu. Izejas kods ir skaitlis. Komanda to atgriež, kad beidz darbu. Tad izdrukājiet `success`, ja komanda izdevās. Izdrukājiet `failure`, ja tā neizdevās.

## Piemērs

Programma izdrukā:

```
4
failure
```
