Kura funkcija sūta savu komandu caur sistēmas **čaulu**? Šī funkcija ļauj jums lietot caurules un novirzīšanu.

{:.quiz}
0 | `run`
1 | `shell`
0 | `exec`
0 | `system`

{% include quiz.html %}

<div class="extended-explanation">

`shell` dod čaulai vienu virkni. Čaula saprot tādas iespējas kā caurules. `run` palaiž programmu tieši. Tas ņem atsevišķus argumentus un nelieto čaulu. Tas ir drošāk. Tāpēc `run` ir labāka noklusējuma izvēle.

</div>
