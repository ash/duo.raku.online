## Uzdevums

Atveriet failu ar nosaukumu `out.txt` rakstīšanai. Atstājiet turi atvērtu. Ciklā ierakstiet tajā skaitļus `1`, `2` un `3`. Katram skaitlim jābūt savā rindā. Tad aizveriet turi. Nolasiet failu un izdrukājiet tā saturu.

## Piemērs

Programma izdrukā:

```
1
2
3
```
