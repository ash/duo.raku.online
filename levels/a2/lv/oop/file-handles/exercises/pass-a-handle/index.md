## Uzdevums

Faila turis ir parasta vērtība. Tāpēc jūs varat to padot funkcijai, tāpat kā jebkuru citu argumentu. Uzrakstiet apakšprogrammu `log-line`. Tā ņem turi un paziņojumu. Tā ieraksta paziņojumu turī, savā rindā.

Atveriet `log.txt` rakstīšanai. Izsauciet `log-line` trīs reizes. Ar to ierakstiet `started`, `working` un `done`. Tad aizveriet turi. Nolasiet failu un izdrukājiet tā saturu.

## Piemērs

Programma izdrukā:

```
started
working
done
```
