## Uzdevums

Izveidojiet divas tukšas klases, `Cat` un `Dog`. Pēc tam uzrakstiet ciklu pāri četrām vērtībām: `Cat`, `Dog`, `Cat.new` un `Dog.new`. Katrai vērtībai izdrukājiet, vai tā ir definēta. Apskatiet rezultātu. Abi tipa objekti ir nedefinēti. Abas instances ir definētas. Klasei šeit nav nozīmes.

## Piemērs

Programma izdrukā:

```
False
False
True
True
```
