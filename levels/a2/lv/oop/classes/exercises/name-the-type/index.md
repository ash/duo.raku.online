## Uzdevums

Izveidojiet divas tukšas klases, `Cat` un `Dog`. Pēc tam izveidojiet `Cat` instanci ar nosaukumu `$felix`. Izdrukājiet `$felix` tipu ar `WHAT`. Pēc tam izdrukājiet vēl divas rindas. Izmantojiet tajās operatoru `===`. Pirmā rinda parāda, vai tips ir tas pats, kas `Cat`. Otrā rinda parāda, vai tas ir tas pats, kas `Dog`.

## Piemērs

Programma izdrukā:

```
(Cat)
True
False
```
