## Uzdevums

Uzrakstiet bloku ar `die 'timeout'` iekšā. Pievienojiet blokam fāzeri `CATCH`. Tas noķer izņēmumu un izdrukā tā paziņojumu. Paziņojuma priekšā ielieciet `Error: `.

## Piemērs

Programma izdrukā:

```
Error: timeout
```
