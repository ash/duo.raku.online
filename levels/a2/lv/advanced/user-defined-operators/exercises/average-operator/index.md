## Uzdevums

Definējiet infiksa operatoru `avg`. Tas atgriež savu divu operandu vidējo vērtību. Tad lietojiet to. Izdrukājiet `4` un `10` vidējo vērtību.

## Piemērs

Programma izdrukā:

```
7
```
