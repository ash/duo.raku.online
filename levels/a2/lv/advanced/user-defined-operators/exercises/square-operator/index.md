## Uzdevums

Operatora simbols var būt jebkura rakstzīme. Tā var būt arī Unikoda rakstzīme. Definējiet **postfiksa** operatoru `²`. Tas atgriež sava operanda kvadrātu. Tātad `5²` nozīmē `5 ** 2`. Tad izdrukājiet `5²`.

## Piemērs

Programma izdrukā:

```
25
```
