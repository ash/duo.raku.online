## Uzdevums

Šeit ir skaitļu saraksts. Daži no tiem atkārtojas:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Izdrukājiet, cik tajā ir _atšķirīgu_ vērtību. Atšķirīgās vērtības visas atšķiras viena no otras. Izmantojiet kopu.

## Piemērs

Programma izdrukā:

```
7
```
