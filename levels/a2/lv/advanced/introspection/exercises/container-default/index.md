## Uzdevums

Konteineram var būt noklusējuma vērtība. Jūs to iestatāt ar iezīmi `is default`. Pirms jūs piešķirat vērtību, mainīgais atgriež šo noklusējuma vērtību. Arī `.VAR.default` to parāda.

Deklarējiet skalāru `$count`. Tā noklusējuma vērtībai jābūt `0`. Nepiešķiriet tam neko. Izdrukājiet mainīgo. Pēc tam izdrukājiet tā konteinera noklusējuma vērtību. Abām rindām jārāda `0`.

## Piemērs

Programma izdrukā:

```
0
0
```
