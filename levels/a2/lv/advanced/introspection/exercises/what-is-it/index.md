## Uzdevums

`WHAT` dara vairāk nekā apraksta tipu. Tas atgriež pašu tipa objektu. Tipa objektus var salīdzināt ar operatoru `===`.

Deklarējiet divus mainīgos. `$a` glabā veselo skaitli `42`. `$b` glabā virkni `'x'`. Katram mainīgajam aplūkojiet tā `WHAT`. Vai tas ir tips `Int`? Izdrukājiet atbildi.

## Piemērs

Programma izdrukā:

```
True
False
```
