## Uzdevums

`do` darbojas arī pirms vadības plūsmas teikumiem. Tas padara tos par izteiksmēm ar vērtību. Ar `do if 7 > 5 { 'big' } else { 'small' }` izvēlieties apzīmējumu. Piešķiriet apzīmējumu mainīgajam `$label` un izdrukājiet to.

## Piemērs

Programma izdrukā:

```
big
```
