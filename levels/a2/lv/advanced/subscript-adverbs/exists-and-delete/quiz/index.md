Ko šī programma izdrukā?

```raku
my %h = a => 1, b => 2;
say %h<z>:exists;
```

{:.quiz}
0 | True
1 | False
0 | Nil
0 | (Any)

{% include quiz.html %}

<div class="extended-explanation">

Apstākļvārds `:exists` jautā, vai atslēga ir tur. Tas atgriež `True` vai `False`. Jauktenī nav atslēgas `z`. Tāpēc atbilde ir `False`.
