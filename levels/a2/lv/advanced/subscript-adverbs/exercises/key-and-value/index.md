## Uzdevums

Šeit ir jauktenis: `x => 10, y => 20`. Izdrukājiet atslēgu `x` kopā ar tās vērtību. Šim nolūkam izmantojiet indeksa apstākļvārdu.

## Piemērs

Programma izdrukā:

```
(x 10)
```
