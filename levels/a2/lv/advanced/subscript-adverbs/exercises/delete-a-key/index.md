## Uzdevums

Šeit ir jauktenis: `a => 1, b => 2, c => 3`. Izdzēsiet ierakstu `b` ar indeksa apstākļvārdu. Pēc tam izdrukājiet, cik ierakstu jauktenī ir palicis. Tas parāda, ka viena ieraksta vairs nav.

## Piemērs

Programma izdrukā:

```
2
```
