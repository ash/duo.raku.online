## Uzdevums

Deklarējiet skalāru mainīgo `$discount`. Tā noklusējuma vērtībai jābūt `0`. Izdrukājiet mainīgo, pirms jūs tam kaut ko piešķirat. Programmai jāizdrukā `0`. Tā nedrīkst izdrukāt nevienu brīdinājumu.

Tad piešķiriet mainīgajam `15`. Izdrukājiet to vēlreiz.

## Piemērs

Programma izdrukā divas rindas:

```
0
15
```
