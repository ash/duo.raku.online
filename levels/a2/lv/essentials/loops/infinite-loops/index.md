Jūs varat rakstīt `loop` arī tikai ar ķermeni:

```raku
loop {
    say 'Eternity';
}
```

Šī cilpa pati nekad neapstājas. Jums jāaptur programma, piemēram, ar `Ctrl+C`. Kursa otrā daļa rāda labākus veidus, kā kontrolēt cilpas.
