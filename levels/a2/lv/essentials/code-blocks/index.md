title: Koda bloki
---

{% include menu.html %}

Koda bloks ir jūsu programmas daļa. Tas atrodas starp cirtainajām iekavām: `{` un `}`. Blokā ir vairāki paziņojumi. Tie strādā kopā kā viens liels paziņojums. Nākamās sadaļas rāda daudzus veidus, kā izmantot blokus.

```raku
{
    say 'Hello, World!';
}
```

Šai programmai koda bloks īsti nav vajadzīgs. Bet citos gadījumos koda bloki ir ļoti noderīgi. Mēs tos apskatīsim pavisam drīz.

Bet vispirms apskatīsim _apjoma_ ideju. Apjoms parāda, kur jūs varat izmantot mainīgo.
