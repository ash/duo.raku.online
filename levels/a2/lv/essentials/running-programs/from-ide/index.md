Šī sadaļa ir ļoti īsa. Tā rāda, kā palaist programmu, neizejot no IDE. Mēs aplūkojam divus visvairāk ieteiktos [IDE](../../editors-and-ides).

## Visual Studio Code redaktors

Atveriet termināli no izvēlnes: `Terminal` → `New Terminal`. Zem jūsu programmas teksta atveras jauns panelis. Palaidiet programmu tur, tāpat kā no komandrindas:

```console
$ raku hello.raku
```

## Comma IDE

Lai palaistu programmu, izmantojiet izvēlnes vienumu `Run`. Pirms pirmās palaišanas iestatiet IDE. Sekojiet [instrukcijām](https://commaide.com/docs/running) Comma vietnē.
