{% include menu.html %}

Dažreiz programmai dažādās situācijās jādara dažādas lietas. Tam jūs varat izmantot `if` un līdzīgus vārdus.

Visām tām vajag nosacījumu. Nosacījums var būt [Būla](/lv/essentials/booleans) vērtība, `True` vai `False`. Tas var būt Būla izteiksme. Šāda izteiksme dod `True` vai `False`. Vai arī tas var būt jebkura cita izteiksme. Raku jāspēj [pārvērst](/lv/essentials/coercion) tās vērtību par `True` vai `False`.
