## Uzdevums

Uzrakstiet programmu. Tā izveido dažus skalāros mainīgos. Tā dod tiem šo tipu vērtības: `Int`, `Rat`, `Num`, `Bool` un `Str`. Programma izdrukā katru vērtību un tās tipu.

## Piemērs

Jūsu izvade var būt citāda. Bet šī testa palaišana parāda ideju:

```console
$ raku types.raku
151 (Int)
4.2 (Rat)
1e10 (Num)
True (Bool)
xyz (Str)
```
