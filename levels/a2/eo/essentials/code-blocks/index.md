title: Kodoblokoj
---

{% include menu.html %}

Kodobloko estas parto de via programo. Ĝi estas ene de paro de kurbaj krampoj: `{` kaj `}`. Bloko havas plurajn deklarojn. Ili laboras kune, kiel unu granda deklaro. La sekvaj sekcioj montras multajn manierojn uzi blokojn.

```raku
{
    say 'Saluton, Mondo!';
}
```

Ĉi tiu programo ne vere bezonas la kodoblokon. Sed kodoblokoj estas tre utilaj en aliaj kazoj. Ni rigardos ilin tre baldaŭ.

Sed unue, ni rigardu la ideon de _amplekso_. La amplekso montras, kie vi povas uzi variablon.
