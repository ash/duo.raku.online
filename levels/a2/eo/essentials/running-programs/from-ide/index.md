Ĉi tiu sekcio estas tre mallonga. Ĝi montras, kiel ruli programon sen forlasi la IDE. Ni rigardas la du plej rekomenditajn [IDE-ojn](../../editors-and-ides).

## Visual Studio Code Editor

Malfermu terminalon el la menuo: `Terminal` → `New Terminal`. Nova panelo malfermiĝas sub via programteksto. Rulu la programon tie, kiel de la komandlinio:

```console
$ raku hello.raku
```

## Comma IDE

Por ruli programon, uzu la eron `Run` en la menuo. Antaŭ la unua rulado, agordu la IDE. Sekvu [la instrukciojn](https://commaide.com/docs/running) en la retejo de Comma.
