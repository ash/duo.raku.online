REPL estas mallongigo de _Read–eval–print loop_. Ĝi estas enkonstruita ŝelreĝimo. Vi tajpas instrukciojn. Post ĉiu, vi vidas la rezulton sur la ekrano. Vi vidas la staton de la variabloj. Vi ankaŭ vidas la eligon de via programo.

Tajpu ĉi tion por starti la ŝelon de Rakudo:

```console
$ raku
Welcome to 𝐑𝐚𝐤𝐮𝐝𝐨™ v2020.10.
Implementing the 𝐑𝐚𝐤𝐮™ programming language v6.d.
Built on MoarVM version 2020.10.

You may want to `zef install Readline` or `zef install Linenoise` or use rlwrap for a line editor

To exit type 'exit' or '^D'
> 
```

La eligo dependas de via versio de la kompililo. En la supra eligo, la ŝelo proponas instali kelkajn modulojn. Kun ili, la ŝelo estas pli agrabla por uzi. Tial vi vidas ĉi tiun mesaĝon.

Fine, vi vidas la promptan signon `>`. Ĉi tie vi tajpas vian programon aŭ partojn de ĝi. La ŝelo kompilas vian kodon linion post linio. Ĝi faras tion, kiam vi premas Enter.

    > say 'Hello, World';
    Hello, World
    >
