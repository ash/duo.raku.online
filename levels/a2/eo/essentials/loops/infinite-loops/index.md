{% include menu.html %}

Vi ankaŭ povas uzi `loop` nur kun korpo:

```raku
loop {
    say 'Eterneco';
}
```

Ĉi tiu buklo ruliĝas senfine. Ĝi haltas nur, kiam vi haltigas la programon, ekzemple, per `Ctrl+C`. En la dua parto de la kurso, vi lernos pli bonajn manierojn por regi buklojn.
