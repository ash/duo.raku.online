Vi ankaŭ povas skribi `loop` nur kun korpo:

```raku
loop {
    say 'Eterneco';
}
```

Ĉi tiu buklo neniam haltas per si mem. Vi devas haltigi la programon, ekzemple, per `Ctrl+C`. La dua parto de la kurso montras pli bonajn manierojn regi buklojn.
