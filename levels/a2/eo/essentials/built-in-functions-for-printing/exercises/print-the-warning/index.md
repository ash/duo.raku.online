## Problemo

Skribu programon. Ĝi demandas vian aĝon. Se la nombro estas negativa, la programo presas unu aŭ du avertojn. La averto devas iri al `STDERR`.

## Ekzemplo

Jen du ekzemploj:

```console
$ raku print-the-warning.raku
Kiom estas via aĝo? 20
Via aĝo estas 20

$ raku print-the-warning.raku
Kiom estas via aĝo? -1
Vi enmetis negativan numeron!
```
