## Kodo

Rulu la programon kaj vidu kion ĝi presas:

```console

```

## Komentoj

Unu regulo de ĉi tiu tasko estas uzi variablojn. `42` estas nur unu valoro. Do skalara variablo estas bona loko por teni ĝin.
