Estas facile presi la valoron de π.

## Kodo

```raku
say π;
```

🦋 Vi povas trovi la plenan kodon en la dosiero [pi.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/numbers/pi.raku).

## Eligo

Rulu la programon kaj vidu kion ĝi presas:

```console
$ raku exercises/numbers/pi.raku
3.141592653589793
```

## Komentoj

Raku havas enkonstruitan konstanton `π`. Do la programo estas tre simpla. Sed estas aliaj manieroj fari la samon:

```raku
    π.say;
```

Aŭ:

```raku
    pi.say;
```

Aŭ:

```raku
    say pi;
```
