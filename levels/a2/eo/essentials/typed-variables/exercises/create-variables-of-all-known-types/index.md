## Problemo

Skribu programon. Ĝi kreas kelkajn skalarajn variablojn. Ĝi donas al ili valorojn de ĉi tiuj tipoj: `Int`, `Rat`, `Num`, `Bool` kaj `Str`. La programo presas ĉiun valoron kaj ĝian tipon.

## Ekzemplo

Via eligo povas esti malsama. Sed ĉi tiu testa rulado montras la ideon:

```console
$ raku types.raku
151 (Int)
4.2 (Rat)
1e10 (Num)
True (Bool)
xyz (Str)
```
