## Problemo

Dosiertenilo estas normala valoro. Do vi povas transdoni ĝin al funkcio, kiel ĉiun alian argumenton. Skribu subrutinon `log-line`. Ĝi prenas tenilon kaj mesaĝon. Ĝi skribas la mesaĝon al la tenilo, en aparta linio.

Malfermu `log.txt` por skribado. Voku `log-line` tri fojojn. Skribu per ĝi `started`, `working` kaj `done`. Poste fermu la tenilon. Legu la dosieron kaj presu ĝian enhavon.

## Ekzemplo

La programo presas:

```
started
working
done
```
