## Problemo

Kiam bloko `try` malsukcesas, ĝia valoro estas nedifinita. Uzu tion kun la difinita-aŭ operatoro `//`. Per `//`, vi povas doni rezervan valoron por ĉi tiu kazo. Rulu blokon `try` kun `die 'no'` interne. Se la bloko malsukcesas, uzu anstataŭe la ĉenon `default`. Presu la rezulton.

## Ekzemplo

La programo presas:

```
default
```
