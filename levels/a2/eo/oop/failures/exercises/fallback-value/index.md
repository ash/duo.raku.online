## Problemo

Skribu subrutinon `get`. Ĝi redonas sian argumenton. Sed se la argumento estas `0`, ĝi vokas `fail`. La mesaĝo estas `bad`.

Presu la rezulton de `get(5)`. Poste presu la rezulton de `get(0)`. Uzu la difinita-aŭ operatoron `//` kun la rezerva valoro `default`. La operatoro `//` donas ĉi tiun valoron, kiam la rezulto estas nedifinita.

## Ekzemplo

La programo presas:

```
5
default
```
