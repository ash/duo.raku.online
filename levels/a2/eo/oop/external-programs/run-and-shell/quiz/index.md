Kiu funkcio sendas sian komandon tra la sistema **ŝelo**? Ĉi tiu funkcio permesas al vi uzi duktojn kaj redirektadon.

{:.quiz}
0 | `run`
1 | `shell`
0 | `exec`
0 | `system`

{% include quiz.html %}

<div class="extended-explanation">

`shell` donas unu solan ĉenon al la ŝelo. La ŝelo komprenas ecojn kiel duktojn. `run` lanĉas programon rekte. Ĝi prenas apartajn argumentojn kaj uzas neniun ŝelon. Tio estas pli sekura. Do `run` estas la pli bona defaŭlta elekto.

</div>
