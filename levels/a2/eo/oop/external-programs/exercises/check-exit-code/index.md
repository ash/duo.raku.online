## Problemo

Rulu komandon, kiu intence malsukcesas. Ekzemple, uzu `sh -c 'exit 4'`. Tenu la `Proc`, kiun ĝi redonas. Presu la elirkodon de la komando. La elirkodo estas nombro. Komando redonas ĝin, kiam ĝi finiĝas. Poste presu `success`, se la komando funkciis. Presu `failure`, se ĝi ne funkciis.

## Ekzemplo

La programo presas:

```
4
failure
```
