## Problemo

Faru du malplenajn klasojn, `Cat` kaj `Dog`. Poste skribu buklon tra kvar valoroj: `Cat`, `Dog`, `Cat.new` kaj `Dog.new`. Por ĉiu valoro, presu, ĉu ĝi estas difinita. Rigardu la rezulton. La du tipobjektoj estas nedifinitaj. La du ekzempleroj estas difinitaj. La klaso ne gravas ĉi tie.

## Ekzemplo

La programo presas:

```
False
False
True
True
```
