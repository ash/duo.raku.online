## Problemo

Faru du malplenajn klasojn, `Cat` kaj `Dog`. Poste faru ekzempleron de `Cat` kun la nomo `$felix`. Presu la tipon de `$felix` per `WHAT`. Poste presu du pliajn liniojn. Uzu la operatoron `===` en ili. La unua linio montras, ĉu la tipo estas la sama kiel `Cat`. La dua linio montras, ĉu ĝi estas la sama kiel `Dog`.

## Ekzemplo

La programo presas:

```
(Cat)
True
False
```
