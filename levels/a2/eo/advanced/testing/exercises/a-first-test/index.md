## Problemo

Uzu la modulon `Test`. Skribu unu teston `ok`. Ĝi kontrolas, ke la ĉeno `Raku` havas kvar signojn. Ĝia priskribo estas `Raku has four letters`. Ĉe la fino, voku `done-testing`.

## Ekzemplo

La programo presas:

```
ok 1 - Raku has four letters
1..1
```
