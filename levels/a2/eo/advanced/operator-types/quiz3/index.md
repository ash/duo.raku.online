La operatoro `x` ripetas ĉenon. Do `'ab' x 3` donas `'ababab'`. La `x` staras inter siaj du operandoj. Kio estas ĝia kategorio?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Nur la pozicio gravas. La operatoro povas esti simbolo aŭ vorto. `x` staras *inter* du operandoj. Do ĝi estas **infiksa** operatoro, same kiel `+` aŭ `~`. Sed ĝia nomo estas litero.

</div>
