Jen unu maniero solvi la taskon.

## Kodo

```raku
my %h = a => 1;
say %h<a>;
```

🦋 Vi povas trovi la fontkodon en la dosiero [subscript-a-hash.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operator-types/subscript-a-hash.raku).

## Eligo

```
1
```

## Komentoj

1. La subskribo `< >` estas post-ĉirkaŭfiksa operatoro. Ĝi venas post termino, ĉi tie la hako. Kaj ĝi staras ĉirkaŭ la ŝlosilo.

1. `%h<a>` redonas la valoron por la ŝlosilo `a`. Ĉi tiu valoro estas `1`.
