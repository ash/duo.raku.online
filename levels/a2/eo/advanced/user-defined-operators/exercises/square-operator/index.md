## Problemo

La simbolo de operatoro povas esti ajna signo. Ĝi ankaŭ povas esti Unikoda signo. Difinu **postfiksan** operatoron `²`. Ĝi redonas la kvadraton de sia operando. Do `5²` signifas `5 ** 2`. Poste presu `5²`.

## Ekzemplo

La programo presas:

```
25
```
