Kion presas ĉi tiu programo?

```raku
say 'programming'.substr: 0, 3;
```

{:.quiz}
1 | pro
0 | program
0 | ing
0 | (0 3)

{% include quiz.html %}

<div class="extended-explanation">

La dupunkto prenas la *tutan* reston de la deklaro. Ĉio fariĝas la listo de argumentoj. Do `substr: 0, 3` estas la sama kiel `substr(0, 3)`. Ambaŭ argumentoj iras al `substr`. Ĝi komencas ĉe indekso `0` kaj prenas `3` signojn. La rezulto estas `pro`.

</div>
