Kion presas ĉi tiu programo?

```raku
enum Colour <red green blue>;
say green + blue;
```

{:.quiz}
1 | 3
0 | greenblue
0 | (green blue)
0 | eraron

{% include quiz.html %}

<div class="extended-explanation">

Ĉiu konstanto havas nombron. La nombroj komenciĝas de nulo kaj sekvas la ordon de la listo. Do `red` estas `0`, `green` estas `1`, kaj `blue` estas `2`. En aritmetiko, la konstantoj funkcias kiel ĉi tiuj nombroj. Do `green + blue` estas `1 + 2`. Tio estas `3`.

</div>
