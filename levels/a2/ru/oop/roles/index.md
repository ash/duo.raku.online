_Роль_ — это набор методов. Иногда в ней есть и данные. Несколько классов могут делить одну роль. Наследование говорит, что класс _является_ видом другого класса. Роль устроена иначе. Она описывает то, что класс _умеет делать_.

Вы создаёте роль ключевым словом `role`. Она очень похожа на класс. Чтобы дать роль классу, используйте трейт `does`:

```raku
role Greet {
    method hello {
        'Hello from ' ~ self.name;
    }
}

class Person does Greet {
    has $.name;
}
```

Теперь у класса `Person` есть метод `hello` из роли. Он работает так же, как метод в самом классе:

```raku
say Person.new(name => 'Anna').hello; # Hello from Anna
```

Класс может выполнять роль. Тогда Raku знает, что у класса есть эта роль:

```raku
say Person.new(name => 'Anna') ~~ Greet; # True
```

Посмотрите на метод `hello` в роли. Он использует `self.name`. Но у самой роли нет атрибута `name`. Это не проблема. Метод работает как часть класса, который включает роль. Включить роль значит взять её в класс. А у этого класса есть атрибут `name`. Следующая тема показывает больше. У класса может быть больше одной роли сразу.
