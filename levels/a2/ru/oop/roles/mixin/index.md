Роль не обязательно встраивать в класс. Роль можно дать и объекту, который уже есть. Для этого используйте оператор `but`. Он подмешивает роль в один-единственный объект. Это происходит, пока программа работает. Потом `but` возвращает новый объект с этой ролью:

```raku
role Loud {
    method greet {
        callsame().uc;
    }
}

class Greeter {
    method greet {
        'Hello';
    }
}

my $quiet = Greeter.new;
my $loud  = Greeter.new but Loud;

say $quiet.greet; # Hello
say $loud.greet;  # HELLO
```

Роль получил только `$loud`. Класс `Greeter` и все другие объекты `Greeter` не меняются. Поэтому `$quiet` всё так же здоровается обычным образом. Иногда у роли и у класса есть методы с одним именем. Тогда побеждает версия из роли. А `callsame` вызывает другой метод, который роль переопределяет. Здесь это исходный `greet` из `Greeter`. Потом все буквы его результата становятся большими.

Объект может получить роль таким способом. Тогда считается, что он выполняет эту роль:

```raku
say $quiet ~~ Loud; # False
say $loud  ~~ Loud; # True
```

`but` не меняет исходный объект. Он даёт вам новый объект. Может быть, вы хотите изменить сам объект. Тогда используйте вместо него оператор `does`:

```raku
my $speaker = Greeter.new;
$speaker does Loud;
say $speaker.greet; # HELLO
```

Роли можно подмешивать в отдельные объекты. Так вы решаете для каждого объекта, какое ещё поведение он получит. Вам не нужен отдельный класс для каждого сочетания.
