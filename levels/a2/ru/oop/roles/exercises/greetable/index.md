## Задача

Создайте роль `Sized` с методом `describe`. Метод возвращает строку `size is <размер>`. Для размера он использует `self.size`.

Потом создайте класс `Box`. Он выполняет роль `Sized`, и у него есть атрибут `size`. Создайте коробку с размером `10`. Вызовите у неё `describe` и напечатайте результат. На второй строке напечатайте результат `~~ Sized` для коробки. Он показывает, считается ли, что коробка выполняет роль.

## Пример

Программа печатает:

```
size is 10
True
```
