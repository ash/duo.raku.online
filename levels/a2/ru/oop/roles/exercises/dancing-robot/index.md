## Задача

Создайте класс `Robot` с методом `speak`. Этот метод возвращает `beep`. Потом создайте роль `Dancing`. Она добавляет метод `dance`. Этот метод возвращает `spinning around`.

Создайте двух роботов. Дайте роль `Dancing` только одному из них. Вызовите `speak` у обоих роботов и напечатайте результаты. Потом вызовите `dance` у робота, который умеет танцевать. Напечатайте и этот результат.

## Пример

Программа печатает:

```
beep
beep
spinning around
```
