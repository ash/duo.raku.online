## Задача

Создайте две роли:

* У `Named` есть метод `label`. Метод возвращает `I am <имя>`.
* У `Aged` есть метод `status`. Метод возвращает `<возраст> years`.

Потом создайте класс `Pet`. Он выполняет обе роли. У него есть атрибуты `name` и `age`. Создайте питомца с именем `Rex` и возрастом `3`. Напечатайте его `label` и его `status`.

## Пример

Программа печатает:

```
I am Rex
3 years
```
