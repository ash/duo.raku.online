Какая функция передаёт свою команду через системную **оболочку**? С этой функцией можно использовать конвейеры и перенаправление.

{:.quiz}
0 | `run`
1 | `shell`
0 | `exec`
0 | `system`

{% include quiz.html %}

<div class="extended-explanation">

`shell` даёт одну строку оболочке. Оболочка понимает такие возможности, как конвейеры. `run` запускает программу напрямую. Он принимает отдельные аргументы и не использует оболочку. Так безопаснее. Поэтому `run` — лучший выбор по умолчанию.

</div>
