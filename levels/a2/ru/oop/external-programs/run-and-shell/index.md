Есть два способа запустить внешнюю программу. Первый способ — функция `run`. Она не использует оболочку. Оболочка — это программа, которая читает команды и выполняет их. `run` принимает команду и её аргументы как **отдельные** значения. Аргументы — это значения, которые вы даёте команде. Потом `run` запускает программу напрямую:

```raku
run 'echo', 'hello';
```

Этот код запускает программу `echo` с одним аргументом, `hello`. Программа печатает `hello`. Аргументы приходят в программу по отдельности. Поэтому никакая оболочка не может неправильно понять пробелы или специальные символы. Вот почему `run` — безопасный выбор по умолчанию.

Функция `shell` работает по-другому. Она даёт **одну строку** оболочке системы. Оболочка читает эту строку и выполняет её. Поэтому можно использовать возможности оболочки, например перенаправление и конвейеры. Перенаправление отправляет вывод в другое место, например в файл. Конвейер передаёт вывод одной команды следующей:

```raku
shell 'echo hello | tr a-z A-Z';
```

Здесь оболочка запускает `echo`. Конвейер передаёт его вывод в `tr`. Потом оболочка печатает `HELLO`. Это просто, но есть риск. Оболочка сама читает строку и находит в ней части. Может быть, строка пришла из ввода, которому вы не доверяете. Тогда команда `shell` опасна. Используйте `run`, если вам правда не нужны возможности оболочки.

Обе функции возвращают объект `Proc`. Он говорит, как закончилась программа. Обычно запущенная программа использует тот же вывод, что и ваша программа. Поэтому вы видите её вывод на экране. Этот вывод можно и перехватить. Для этого его нужно запросить. Следующая тема показывает, как это сделать.
