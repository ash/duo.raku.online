Что выведет эта программа?

```raku
my $proc = run 'sh', '-c', 'exit 2', :out;
$proc.out.slurp(:close);
say $proc.exitcode;
```

{:.quiz}
0 | 0
1 | 2
0 | True
0 | ошибка

{% include quiz.html %}

<div class="extended-explanation">

`.exitcode` — это целое число, которое вернула программа. Здесь оболочка получила команду `exit 2`. Поэтому число равно `2`. Программа не бросает исключение. Значит, она не останавливается с ошибкой. Программа хранит неудачный `Proc` в `$proc`. Потом она смотрит на него через `.exitcode`. Посмотреть на результат — это уже обработка. Исключение бывает только в одном случае. Это когда вы выбрасываете неудачный `Proc` без проверки.

</div>
