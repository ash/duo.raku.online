Каждый вызов `run` или `shell` возвращает объект `Proc`. Это небольшая запись о программе. Она говорит, какая программа работала и как она закончилась. В прошлых темах мы читали вывод через его дескриптор `.out`. Но в `Proc` есть не только это.

Самая полезная часть — **код возврата**. Это небольшое целое число. Программа возвращает его тому, кто её запустил. Этим числом программа говорит, сработала ли она. `0` значит успех. Любое другое число значит неудачу. Программа сама выбирает этот код неудачи. `.exitcode` даёт вам это число:

```raku
my $proc = run 'sh', '-c', 'exit 3';
say $proc.exitcode; # 3
```

Часто вы задаёте только вопрос «да или нет». Всё сработало? Для этого `Proc` истинен, когда код возврата равен `0`. Иначе он ложен. Поэтому `Proc` можно проверять напрямую:

```raku
my $proc = run 'ls', '/', :out;
$proc.out.slurp(:close);
say $proc ?? 'ok' !! 'failed'; # ok
```

Ещё `Proc` помнит команду, которую он запустил. Вы найдёте её в `.command`:

```raku
my $proc = run 'echo', 'hi', :out;
$proc.out.slurp(:close);
say $proc.command; # (echo hi)
```

Будьте осторожны с одной вещью. Иногда команда даёт сбой. Что, если вы просто **проигнорируете** `Proc`, который она возвращает? Тогда Raku бросает исключение. Исключение — это ошибка, которая останавливает программу. Raku не даёт сбою остаться незамеченным:

```raku
run 'sh', '-c', 'exit 1';
# умирает: The spawned command 'sh' exited unsuccessfully (exit code: 1, signal: 0)
```

Код возврата, который не равен `0`, обычно говорит о проблеме. Поэтому неудачный `Proc` бросает исключение, если вы его выбрасываете. Это происходит, когда `Proc` выходит из области видимости. Тогда никакой код больше не может до него добраться. Дело не в проверке кода возврата. Дело в том, что вы *выбрасываете* результат. Просто положите `Proc` в переменную. Этого хватает, чтобы не было исключения. Вам даже не нужно потом смотреть на эту переменную.

```raku
my $proc = run 'sh', '-c', 'exit 1'; # ошибки нет, хотя команда и не удалась
# …и $proc больше нигде не используется
```

Итак, вы *ждёте*, что команда может дать сбой? Тогда сохраните её `Proc`. Когда захотите узнать, что случилось, посмотрите на `.exitcode`. Или проверьте `Proc` как булево значение.
