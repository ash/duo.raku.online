## Задача

Используйте `run` с `:out`. Запустите `echo` с тремя словами `hello world raku`. Перехватите его вывод в переменную. Не нужно просто печатать вывод. Вместо этого посчитайте в нём слова. Потом напечатайте это число.

## Пример

Программа печатает:

```
3
```
