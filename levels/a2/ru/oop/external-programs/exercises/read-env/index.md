## Задача

Создайте файл `notes.txt`. Запишите в него несколько строк. Поместите имя файла в переменную окружения `NOTES`. Потом с помощью `shell` запустите `wc -l`. Оболочка берёт имя файла из `$NOTES`. Так дочерняя программа считает строки и печатает их число. Дочерняя программа — это программа, которую запускает ваша программа. В конце удалите файл кодом на Raku. Используйте для этого `unlink`, а не оболочку.

## Пример

Программа печатает:

```
3
```

После этого файла `notes.txt` больше нет.
