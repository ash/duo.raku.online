Вот один способ решить задачу.

## Код

```raku
my $file = 'notes.txt';
spurt $file, "one\ntwo\nthree\n";

%*ENV<NOTES> = $file;

my $proc = shell 'wc -l < "$NOTES"', :out;
say $proc.out.slurp(:close).trim;

unlink $file;
```

🦋 Исходный код можно найти в файле [read-env.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/external-programs/read-env.raku).

## Вывод

```
3
```

## Комментарии

1. `spurt` создаёт `notes.txt` с тремя строками. Потом мы записываем в `%*ENV<NOTES>` имя файла. Так что теперь имя файла есть в окружении. Каждая дочерняя программа получает это окружение.

1. Команда `shell` получает это окружение. Она заменяет `$NOTES` на `notes.txt`. Потом она отправляет файл в `wc -l`. `wc -l` считает строки файла. Здесь важно перенаправление `< "$NOTES"`. Из-за него в выводе только число `3`. Мы перехватываем это число через `:out` и обрезаем его.

1. В конце мы убираем за собой в Raku с помощью `unlink`. Оболочка для этого не нужна. Удалить файл — это простая операция файловой системы. Поэтому незачем запускать для этого ещё один процесс. Процесс — это работающая программа.
