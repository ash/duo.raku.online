Вот один способ решить задачу.

## Код

```raku
my $proc = run 'sh', '-c', 'exit 4';

say $proc.exitcode;
say $proc ?? 'success' !! 'failure';
```

🦋 Исходный код можно найти в файле [check-exit-code.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/external-programs/check-exit-code.raku).

## Вывод

```
4
failure
```

## Комментарии

1. `run` возвращает `Proc`. Мы сохраняем его в `$proc` и потом читаем. Здесь это важно. Команда может дать сбой. Если никто не сохраняет её `Proc`, Raku бросает исключение. Исключение — это ошибка, которая останавливает программу. Но здесь мы смотрим на результат. Это считается обработкой сбоя.

1. `.exitcode` даёт число, которое вернула команда. Здесь это `4`. Ещё можно проверить `Proc` как булево значение. Булево значение — это истина или ложь. Так вы отвечаете на более простой вопрос: сработала ли команда? `Proc` истинен, только когда код возврата равен `0`. Здесь он ложен. Поэтому программа печатает `failure`.
