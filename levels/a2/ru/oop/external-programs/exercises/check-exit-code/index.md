## Задача

Запустите команду, которая специально даёт сбой. Например, возьмите `sh -c 'exit 4'`. Сохраните `Proc`, который она возвращает. Напечатайте код возврата команды. Код возврата — это число. Команда возвращает его, когда заканчивает работу. Потом напечатайте `success`, если команда сработала. Напечатайте `failure`, если нет.

## Пример

Программа печатает:

```
4
failure
```
