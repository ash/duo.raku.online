Вот один способ решить задачу.

## Код

```raku
run 'echo', 'home:', '$HOME';
```

🦋 Исходный код можно найти в файле [run-a-command.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/external-programs/run-a-command.raku).

## Вывод

```
home: $HOME
```

## Комментарии

1. `run` запускает `echo` напрямую. Он передаёт каждую строку как отдельный аргумент. Здесь нет `:out`. Поэтому вывод программы идёт прямо на экран.

1. Аргумент приходит к `echo` точно таким, каким вы его написали. Поэтому `$HOME` печатается как есть. Он не заменяется вашим домашним каталогом. Это потому, что здесь нет оболочки. Оболочка бы его заменила. Вот почему `run` — безопасный выбор по умолчанию. С `shell` та же команда может работать совсем по-другому.

1. Вы правда хотите напечатать домашний каталог? Тогда пусть переменную заменит оболочка. `shell 'echo home: $HOME'` печатает что-то вроде `home: /home/anna`. Ещё оставьте одинарные кавычки в коде на Raku. С двойными кавычками, `"$HOME"`, есть проблема. Сам Raku пытается вставить в строку свою переменную `$HOME`. Это происходит ещё до того, как запускается `echo`.
