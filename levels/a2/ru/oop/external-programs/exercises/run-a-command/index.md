## Задача

С помощью `run` запустите `echo`. Дайте ему два отдельных аргумента: `home:` и `$HOME`. Аргументы — это значения, которые вы даёте программе. Пусть вывод идёт на экран. Заметьте, что программа печатает `$HOME` как есть. Она **не** печатает домашний каталог. Это потому, что `run` не использует оболочку. Только оболочка заменяет переменные вроде `$HOME` их значениями.

## Пример

Программа печатает:

```
home: $HOME
```
