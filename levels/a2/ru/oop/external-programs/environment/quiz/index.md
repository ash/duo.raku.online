В какой переменной хранятся переменные окружения программы?

{:.quiz}
0 | `@*ARGS`
1 | `%*ENV`
0 | `$*ENV`
0 | `%ENV`

{% include quiz.html %}

<div class="extended-explanation">

`%*ENV` — это динамический хеш с переменными окружения. Вы читаете переменную по её имени, например `%*ENV<HOME>`. `@*ARGS` — это другое. В нём хранятся аргументы командной строки. Это значения после имени программы в команде.

</div>
