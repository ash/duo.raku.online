Что выведет эта программа?

```raku
my $r = try {
    die 'Boom!';
    say 'inside';
};

say 'outside';
```

{:.quiz}
1 | outside
0 | inside
0 | сначала inside, потом outside
0 | Boom!
0 | ошибка

{% include quiz.html %}

<div class="extended-explanation">

Здесь происходят две вещи. Во-первых, `die` сразу останавливает остаток блока `try`. Поэтому программа так и не доходит до строки `say 'inside'`. Изнутри блока ничего не печатается. Во-вторых, `try` перехватывает исключение, то есть ошибку от `die`. Поэтому сама программа не останавливается. Она идёт дальше после блока. `say 'outside'` выполняется как обычно. Поэтому программа печатает только одну строку: `outside`. Ещё можно посмотреть на `$r` и `$!`. `$r` не определён. Сообщение `Boom!` ждёт в `$!`.

</div>
