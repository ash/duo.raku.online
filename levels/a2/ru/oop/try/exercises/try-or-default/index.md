## Задача

Когда блок `try` даёт сбой, его значение не определено. Используйте это вместе с оператором «определённое или» `//`. С `//` можно дать запасное значение для этого случая. Выполните блок `try` с `die 'no'` внутри. Если блок даст сбой, возьмите вместо него строку `default`. Напечатайте результат.

## Пример

Программа печатает:

```
default
```
