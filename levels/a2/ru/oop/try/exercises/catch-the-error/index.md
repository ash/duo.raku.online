## Задача

Покажите обе стороны `try`. Блок `try` перехватывает ошибки в своём коде. Сначала положите в блок `try` вычисление. Вычисление должно работать без ошибки, например `6 * 7`. Напечатайте его результат. Потом положите код с `die 'broken'` во второй блок `try`. Напечатайте, дал ли этот блок определённый результат. Ещё напечатайте сообщение перехваченного исключения.

## Пример

Программа печатает:

```
42
False
broken
```
