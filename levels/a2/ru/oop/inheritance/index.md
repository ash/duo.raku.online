_Наследование_ позволяет построить один класс на основе другого класса. Для этого напишите `is` после имени нового класса. Потом напишите имя другого класса. Новый класс наследует от другого класса. Он получает все его атрибуты и методы. Этот другой класс — _родительский_ класс, или _базовый_ класс.

```raku
class Animal {
    has $.name;
    method speak {
        'some sound';
    }
}

class Dog is Animal {
}
```

`Dog is Animal` значит, что `Dog` — это вид `Animal`. Мы ничего не пишем в `Dog`. Но у `Dog` уже есть атрибут `name` из `Animal`. Ещё у него есть метод `speak` из `Animal`:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.name;  # Rex
say $rex.speak; # some sound
```

Объект `Dog` — это ещё и `Animal`:

```raku
say Dog.new ~~ Animal; # True
```

С помощью `~~` можно сделать умное сопоставление объекта с типом. Результат истинный, когда у объекта этот тип. Он истинный и тогда, когда объект наследует от этого типа. Следующая тема — о дочернем классе. Дочерний класс наследует от родительского класса. Он может заменить метод родителя своей версией.
