## Задача

Создайте базовый класс `Shape` с двумя методами. Метод `name` возвращает `'shape'`. Метод `describe` возвращает строку `I am a <имя>`. Для имени он вызывает свой метод `name`.

Потом создайте класс `Square`. Он наследует от `Shape`. Он переопределяет `name`. Его собственная версия `name` возвращает `'square'`.

Напечатайте описание объекта `Square`.

## Пример

Программа печатает:

```
I am a square
```
