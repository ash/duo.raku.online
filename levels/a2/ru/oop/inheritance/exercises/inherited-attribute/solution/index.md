Вот один способ решить задачу.

## Код

```raku
class Vehicle {
    has $.wheels;
}

class Bike is Vehicle {
    has $.wheels = 2;
}

class Car is Vehicle {
    has $.wheels = 4;
}

say Bike.new.wheels;
say Car.new.wheels;
```

🦋 Исходный код можно найти в файле [inherited-attribute.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/inheritance/inherited-attribute.raku).

## Вывод

```
2
4
```

## Комментарии

1. И `Bike`, и `Car` наследуют от `Vehicle` атрибут `wheels`. Ещё они наследуют его аксессор. Они не создают новый атрибут. Они только дают унаследованному атрибуту значение по умолчанию. Для `Bike` это `2`. Для `Car` это `4`.

1. У каждого класса внутри есть своё значение по умолчанию. Поэтому объекты можно создать просто через `Bike.new` и `Car.new`. Потом унаследованный аксессор возвращает нужное число колёс.

1. Вы всё равно можете сами передать значение, например `Car.new(wheels => 3)`. Тогда это значение заменяет значение по умолчанию. Но у велосипедов и машин обычно привычное число колёс. Поэтому значения по умолчанию делают обычный случай простым. А иногда всё равно можно сделать исключение.
