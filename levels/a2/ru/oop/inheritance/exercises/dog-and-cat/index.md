## Задача

Создайте базовый класс `Employee`. Это родительский класс для других классов. У него есть атрибут `name` и два метода. Метод `role` возвращает `'staff'`. Метод `badge` возвращает строку `<имя> - <роль>`. Для роли он вызывает свой метод `role`.

Потом создайте два дочерних класса, `Manager` и `Intern`. Они наследуют от `Employee`. Каждый из них переопределяет `role`. Это значит, что у него своя версия этого метода. В `Manager` метод `role` возвращает `'manager'`. В `Intern` он возвращает `'intern'`.

Напечатайте бейдж менеджера с именем `Anna`. Потом напечатайте бейдж стажёра с именем `Bob`.

## Пример

Программа печатает:

```
Anna - manager
Bob - intern
```
