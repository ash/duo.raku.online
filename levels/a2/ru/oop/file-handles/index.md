Читать или записывать весь файл сразу легко. Но иногда вы хотите пройти по файлу строка за строкой. Или вы хотите много раз писать в файл. Всё это время файл должен быть открыт. Для этого вы используете _файловый дескриптор_. Файловый дескриптор — это объект для открытого файла. Через него вы читаете из файла или пишете в него.

Вот самый простой способ читать файл строка за строкой. Вам даже не нужно самим создавать дескриптор. Вызовите метод `lines` у объекта пути. Он даёт вам строки по одной. Они готовы для цикла `for`:

```raku
spurt 'words.txt', "one\ntwo\nthree\n";

for 'words.txt'.IO.lines -> $line {
    say $line.uc;
}
```

Каждая `$line` — это одна строка. В её конце нет перевода строки. Программа печатает:

```
ONE
TWO
THREE
```

Через дескриптор можно и писать в файл. Сначала откройте файл с помощью `open` и флага `:w`. Этот флаг значит «запись». Потом используйте методы `say` или `print` у дескриптора. В конце закройте его с помощью `close`:

```raku
my $fh = open 'out.txt', :w;
$fh.say('first line');
$fh.say('second line');
$fh.close;
```

В конце закройте дескриптор. Тогда все ваши данные действительно попадают на диск. Некоторые файлы слишком большие для памяти. Вы не можете прочитать их целиком сразу. Такие файлы вы обычно читаете строка за строкой, как выше.
