## Задача

Запишите три слова в файл с именем `words.txt`. Это слова `apple`, `banana` и `cherry`. Каждое слово стоит на своей строке. Затем прочитайте файл строка за строкой. Напечатайте каждую строку с её номером впереди. Номера начинаются с `1`. Используйте такую форму: `<номер>: <строка>`.

## Пример

Программа печатает:

```
1: apple
2: banana
3: cherry
```
