## Задача

Файловый дескриптор — это обычное значение. Поэтому его можно передать в функцию, как любой другой аргумент. Напишите подпрограмму `log-line`. Она принимает дескриптор и сообщение. Она пишет сообщение в дескриптор, на отдельной строке.

Откройте `log.txt` на запись. Вызовите `log-line` три раза. Запишите с её помощью `started`, `working` и `done`. Затем закройте дескриптор. Прочитайте файл и напечатайте его содержимое.

## Пример

Программа печатает:

```
started
working
done
```
