Вот один способ решить задачу.

## Код

```raku
sub log-line($fh, $message) {
    $fh.say($message);
}

my $fh = open 'log.txt', :w;
log-line($fh, 'started');
log-line($fh, 'working');
log-line($fh, 'done');
$fh.close;

print slurp 'log.txt';
```

🦋 Исходный код можно найти в файле [pass-a-handle.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/file-handles/pass-a-handle.raku).

## Вывод

```
started
working
done
```

## Комментарии

1. `open` возвращает дескриптор. Этот дескриптор — просто значение в `$fh`. Поэтому вы можете передать его в `log-line` как аргумент. Так же вы передаёте строку или число. Внутри подпрограммы `$fh.say` пишет через этот же открытый дескриптор.

1. Дескриптор остаётся открытым во время всех трёх вызовов. Поэтому каждый `log-line` добавляет строку в конец того же файла. Потом `close` записывает всё на диск. `slurp` читает три строки обратно.

1. Поэтому дескрипторы легко сочетать с функциями. Функция может принять дескриптор. Она может писать в него или читать из него. Ей всё равно, для какого файла этот дескриптор. Файл выбирает код, который вызывает функцию. Он делает это, когда открывает файл.
