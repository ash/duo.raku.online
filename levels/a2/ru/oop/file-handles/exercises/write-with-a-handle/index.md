## Задача

Откройте файл с именем `out.txt` на запись. Держите дескриптор открытым. Запишите в него в цикле числа `1`, `2` и `3`. Каждое число должно стоять на своей строке. Затем закройте дескриптор. Прочитайте файл и напечатайте его содержимое.

## Пример

Программа печатает:

```
1
2
3
```
