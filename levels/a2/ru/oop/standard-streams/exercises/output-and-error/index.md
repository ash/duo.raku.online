## Задача

Программа в цикле складывает список чисел `3, 5, 7`. На каждом проходе отправляйте текущую сумму в стандартный поток ошибок. Такая сумма называется накопленной. Это сообщение о ходе работы. После цикла отправьте итоговый результат в стандартный вывод. Используйте дескрипторы потоков напрямую.

Почему это важно? Результат можно сохранить или отправить в другую программу. Сообщения о ходе работы остаются в стандартном потоке ошибок. Там они не мешают.

## Пример

Запустите программу. Вы видите на экране оба потока. Сначала идут накопленные суммы, потом итоговый результат:

```
running total: 3
running total: 8
running total: 15
15
```

Но теперь мы отбрасываем стандартный поток ошибок. Остаётся только настоящий результат:

```
$ raku output-and-error.raku 2>/dev/null
15
```
