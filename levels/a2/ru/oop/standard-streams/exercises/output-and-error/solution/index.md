Вот один способ решить задачу.

## Код

```raku
my @data = 3, 5, 7;

my $sum = 0;
for @data -> $n {
    $sum += $n;
    $*ERR.say("running total: $sum");
}

$*OUT.say($sum);
```

🦋 Исходный код можно найти в файле [output-and-error.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/standard-streams/output-and-error.raku).

## Вывод

Вы видите на экране оба потока. Сначала идут накопленные суммы, потом итоговый результат:

```
running total: 3
running total: 8
running total: 15
15
```

Здесь мы отбрасываем стандартный поток ошибок. Остаётся только настоящий вывод:

```
$ raku output-and-error.raku 2>/dev/null
15
```

## Комментарии

1. `$*OUT` — это дескриптор стандартного вывода. `$*ERR` — это дескриптор стандартного потока ошибок. У каждого из них есть свой метод `say`.

1. Каждый проход цикла прибавляет следующее число. Потом он пишет накопленную сумму в `$*ERR`. В `$*OUT` уходит только итоговая сумма. На экране ход работы и результат выглядят одинаково. Но они идут по разным потокам. `2>/dev/null` убирает стандартный поток ошибок. Поэтому остаётся только итоговое `15`.
