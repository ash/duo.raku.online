## Задача

Программа работает со значением. Это значение отрицательное. Если значение меньше нуля, отправьте предупреждение в стандартный поток ошибок. Для этого используйте `note`. Потом отправьте настоящий результат в стандартный вывод с помощью `say`. Результат — это абсолютное значение числа. Это число без знака минус. Возьмите значение `-3`.

## Пример

Вы видите на экране обе строки:

```
Warning: the value is negative
3
```

Здесь мы отбрасываем стандартный поток ошибок. Остаётся только результат:

```
$ raku note-a-warning.raku 2>/dev/null
3
```
