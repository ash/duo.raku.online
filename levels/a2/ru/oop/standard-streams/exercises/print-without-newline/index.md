## Задача

Используйте `$*OUT`, дескриптор стандартного вывода. Напечатайте буквы `a` и `b` с помощью `print`. `print` не добавляет перевод строки. Затем напечатайте букву `c` с помощью `say`. Все три буквы должны быть на одной строке.

## Пример

Программа печатает:

```
abc
```
