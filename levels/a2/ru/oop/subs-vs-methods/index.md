Теперь вы знаете два способа собрать вместе какие-то действия. Один из них — _подпрограмма_. Другой — _метод_. Выглядят они похоже. Но используете вы их по-разному.

Подпрограмма существует сама по себе. Она ни к чему не относится. Вы вызываете её по имени. Вы передаёте ей всё, что ей нужно, как аргументы:

```raku
sub area-of($radius) {
    π * $radius * $radius;
}

say area-of(2); # 12.566370614359172
```

Метод принадлежит классу. Он как функция внутри класса. Вы вызываете метод у объекта, через точку. Объект — это значение этого класса. Метод может использовать данные своего объекта. Для этого у него есть `self` и аксессоры атрибутов. Поэтому эти данные ему не нужно передавать:

```raku
class Circle {
    has $.radius;

    method area {
        π * $.radius * $.radius;
    }
}

say Circle.new(radius => 2).area; # 12.566370614359172
```

Оба варианта дают одно и то же число. Разница в том, откуда берутся данные. Подпрограмма получает радиус как аргумент. Метод читает радиус из своего объекта. Это тот объект, у которого вы его вызываете.

Вот простое правило. Код существует сам по себе и работает только со своими аргументами? Тогда используйте подпрограмму. Код относится к объекту и работает с его данными? Тогда используйте метод. Код относится к классу, но не к одному объекту? Тогда используйте методы класса.
