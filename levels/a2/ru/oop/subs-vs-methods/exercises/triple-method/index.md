## Задача

Теперь решите ту же задачу с помощью **метода**. Создайте класс `Number`. У него есть атрибут `n` и метод `triple`. Метод возвращает `n`, умноженное на три. Создайте `Number`, где `n` равно `7`. Вызовите у него `triple` и напечатайте результат.

## Пример

Программа печатает:

```
21
```
