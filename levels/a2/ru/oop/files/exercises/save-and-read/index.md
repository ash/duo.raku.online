## Задача

Сохраните число в файл и снова загрузите его. Файл называется `number.txt`. Запишите в него число `42`, а потом перевод строки. Затем прочитайте файл. Превратите его содержимое в целое число. Умножьте это число на два и напечатайте результат.

## Пример

Программа печатает:

```
84
```
