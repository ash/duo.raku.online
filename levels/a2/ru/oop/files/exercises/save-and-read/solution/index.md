Вот один способ решить задачу.

## Код

```raku
spurt 'number.txt', "42\n";

my $n = slurp('number.txt').trim.Int;
say $n * 2;
```

🦋 Исходный код можно найти в файле [save-and-read.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/files/save-and-read.raku).

## Вывод

```
84
```

## Комментарии

1. `spurt` создаёт файл и записывает в него строку. `slurp` читает весь файл обратно в строку. Вместе они делают оба дела. Они сохраняют данные и снова загружают их.

1. `slurp` возвращает текст: `"42\n"`. Поэтому мы убираем перевод строки в конце через `trim`. Потом мы вызываем `.Int`, чтобы превратить текст в число. Теперь с ним можно делать вычисления. Результат `42 * 2` — это `84`.

1. Но программа работает и без `.trim.Int`.
