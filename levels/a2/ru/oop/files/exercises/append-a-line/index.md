## Задача

Сделайте небольшой файл журнала. Несколько раз добавьте строки в его конец. Сначала запишите строку `start` в файл с именем `log.txt`. Затем в цикле **допишите** ещё три строки. Это значит, что вы добавляете их в конец файла. Это строки `entry 1`, `entry 2` и `entry 3`. Не удаляйте то, что уже есть в файле. В конце прочитайте весь файл и напечатайте его.

## Пример

Программа печатает:

```
start
entry 1
entry 2
entry 3
```
