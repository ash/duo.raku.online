Обычно `spurt` заменяет всё старое содержимое файла. Но иногда вы хотите добавить что-то в конец файла. Для этого передайте именованный аргумент `:append`:

```raku
spurt 'log.txt', "line1\n";
spurt 'log.txt', "line2\n", :append;

print slurp 'log.txt';
```

Второй `spurt` сохраняет старое содержимое. Он добавляет новую строку после него. Поэтому в конце в файле есть обе строки:

```
line1
line2
```

Без `:append` второй вызов перезаписывает файл. Тогда в файле есть только `line2`. Добавление в конец файла называется дописыванием. Оно полезно, например, для файлов журнала. Файл журнала хранит историю работы программы. Каждый запуск программы что-то добавляет в эту историю. Так история растёт. Программа не начинает заново с пустым файлом.
