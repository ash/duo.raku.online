Вот самый простой способ работать с файлом. Вы читаете или записываете весь файл сразу.

Процедура `spurt` записывает строку в файл. Она создаёт файл. Или, если файл уже есть, она заменяет старое содержимое:

```raku
spurt 'greeting.txt', "Hello, file!\n";
```

Процедура `slurp` читает весь файл. Она даёт вам содержимое в виде строки:

```raku
my $text = slurp 'greeting.txt';
print $text; # Hello, file!
```

С помощью `spurt` и `slurp` вы сохраняете данные и снова загружаете их. Нужно всего два коротких вызова. Здесь мы используем `print`, а не `say`. Причина в том, что текст уже заканчивается переводом строки.

Эти процедуры работают со всем файлом сразу. Они хороши для маленьких файлов. Маленький файл легко помещается в памяти. Для большого файла вы используете [файловый дескриптор](/ru/oop/file-handles). Он нужен и для работы с файлом строка за строкой. Вы узнаете о нём в конце этого раздела. Следующая тема показывает, как добавлять данные в файл. Старое содержимое файла при этом остаётся.
