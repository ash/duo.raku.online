## Задача

Создайте класс `Label` с одним атрибутом, `text`. Этот атрибут можно менять (`is rw`). Создайте метку с текстом `draft`. Потом **добавьте** ` (revised)` в конец её текста. Сделайте это через аксессор. Не создавайте объект заново. Напечатайте результат.

## Пример

Программа печатает:

```
draft (revised)
```
