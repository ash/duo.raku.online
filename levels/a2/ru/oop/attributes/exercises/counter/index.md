## Задача

Создайте класс `Counter` с одним атрибутом, `count`. Этот атрибут можно менять (`is rw`). Его значение по умолчанию — `0`.

Создайте счётчик. Сначала напечатайте его `count`. Это показывает, что он начинается со значения по умолчанию. Потом в цикле пять раз прибавьте к нему 1. Напечатайте последнее значение.

## Пример

Программа печатает:

```
0
5
```
