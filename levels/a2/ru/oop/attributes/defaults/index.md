У атрибута может быть _значение по умолчанию_. Иногда вы создаёте объект без значения для атрибута. Тогда Raku берёт значение по умолчанию. Напишите его после атрибута, через `=`:

```raku
class Dog {
    has Str $.name;
    has Rat $.weight = 4.0;
}
```

Заметьте ещё одну вещь. Атрибуту можно дать тип, как переменной. Тогда значение должно быть этого типа.

Здесь `new` не получает `weight`. Поэтому атрибут получает значение по умолчанию:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.weight; # 4
```

Но вы всё равно можете дать своё значение. Оно заменяет значение по умолчанию:

```raku
my $lighty = Dog.new(name => 'Lighty', weight => 3.2);
say $lighty.weight; # 3.2
```

Иногда у атрибута нет значения по умолчанию. Вы также не передаёте для него значение в `new`. Тогда атрибут просто не определён. Это как новая скалярная переменная.
