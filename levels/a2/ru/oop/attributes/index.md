Пустой класс не очень полезен. Объекту нужны свои данные. Для этого вы даёте классу _атрибуты_. Атрибут — это часть данных внутри объекта. Чтобы создать атрибут, напишите внутри класса ключевое слово `has`:

```raku
class Dog {
    has $.name;
    has $.age;
}
```

Каждый объект получает свою копию этих атрибутов. Вы даёте им значения, когда создаёте объект. Передайте значения в `new` как именованные аргументы:

```raku
class Dog {
    has $.name;
    has $.age;
}

my $rex = Dog.new(name => 'Rex', age => 3);
```

Посмотрите на `$.` в `has $.name`. Эта запись делает две вещи. Во-первых, она создаёт атрибут. Во-вторых, она создаёт метод с тем же именем. Этот метод возвращает значение атрибута. Такой метод называется _аксессором_:

```raku
say $rex.name; # Rex
say $rex.age;  # 3
```

Разные объекты хранят свои значения. Они не делят их между собой:

```raku
my $rex  = Dog.new(name => 'Rex',  age => 3);
my $fido = Dog.new(name => 'Fido', age => 5);

say $rex.name;  # Rex
say $fido.name; # Fido
```

Следующие темы показывают две вещи. Сначала вы делаете атрибуты, которые можно менять. Потом вы даёте атрибутам значения по умолчанию. Есть ещё способ сделать _приватные_ атрибуты. Код снаружи объекта их не видит. Мы вернёмся к ним после методов.
