По умолчанию аксессор из `has $.name` работает _только на чтение_. Конструктор даёт атрибуту значение. Конструктор — это метод, который создаёт объект, здесь это `new`. После этого код снаружи объекта может читать значение. Но он не может его изменить. Попробуйте присвоить ему новое значение. Это даёт ошибку:

```raku
class Dog {
    has $.name;
}

my $rex = Dog.new(name => 'Rex');
$rex.name = 'Max';
```

Программа останавливается с такой ошибкой:

```
Cannot modify an immutable Str (Rex)
```

Хотите менять значение через аксессор? Тогда пометьте атрибут трейтом `is rw`:

```raku
class Dog {
    has $.name is rw;
}

my $rex = Dog.new(name => 'Rex');
$rex.name = 'Max';
say $rex.name; # Max
```

Теперь аксессор возвращает контейнер, в который можно записывать. Поэтому присваивание работает. Атрибут `name` у объекта теперь равен `Max`.
