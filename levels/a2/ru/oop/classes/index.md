До сих пор вы пользовались только типами, которые уже есть в Raku. Это числа, строки, массивы и так далее. В _объектно-ориентированном программировании_ вы можете создавать свои типы. Такой тип называется _классом_. Значение такого типа называется _объектом_.

Чтобы создать класс, напишите ключевое слово `class`. После него напишите имя и блок:

```raku
class Dog {
}
```

Этот класс `Dog` пока пустой. Но это уже новый тип. Объект класса ещё называют _экземпляром_. `new` — это метод. Чтобы создать экземпляр, вызовите его у имени класса:

```raku
class Dog {
}

my $rex = Dog.new;
say $rex; # Dog.new
```

Теперь в переменной `$rex` лежит объект `Dog`. Каждый вызов `new` создаёт новый, отдельный объект:

```raku
my $rex = Dog.new;
my $fido = Dog.new;
```

`$rex` и `$fido` — две разные собаки. Класс ещё пустой, но собаки разные. В следующих разделах вы дадите классу свои данные. Эти данные называются _атрибутами_. Ещё класс получит своё поведение, то есть действия. Эти действия называются _методами_. Первая тема подробнее рассказывает о классе и его экземплярах. Она показывает, чем они отличаются.
