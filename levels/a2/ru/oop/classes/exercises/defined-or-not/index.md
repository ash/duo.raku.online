## Задача

Создайте два пустых класса, `Cat` и `Dog`. Потом напишите цикл по четырём значениям: `Cat`, `Dog`, `Cat.new` и `Dog.new`. Для каждого значения напечатайте, определено ли оно. Посмотрите на результат. Два объекта типа не определены. Два экземпляра определены. Класс здесь не важен.

## Пример

Программа печатает:

```
False
False
True
True
```
