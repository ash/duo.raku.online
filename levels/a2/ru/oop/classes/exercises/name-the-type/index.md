## Задача

Создайте два пустых класса, `Cat` и `Dog`. Потом создайте экземпляр `Cat` с именем `$felix`. Напечатайте тип `$felix` с помощью `WHAT`. Потом напечатайте ещё две строки. Используйте в них оператор `===`. Первая строка показывает, совпадает ли тип с `Cat`. Вторая строка показывает, совпадает ли он с `Dog`.

## Пример

Программа печатает:

```
(Cat)
True
False
```
