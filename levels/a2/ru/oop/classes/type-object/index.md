Вы можете написать имя класса, например `Dog`. Это имя означает _объект типа_ этого класса. Объект типа обозначает сам тип. Это не один из объектов этого типа. С _экземпляром_ всё иначе. Вы создаёте его с помощью `new`. Это настоящий объект.

Raku видит разницу между ними. Метод `defined` возвращает `False` для объекта типа. Для экземпляра он возвращает `True`:

```raku
class Dog {
}

say Dog.defined;     # False
say Dog.new.defined; # True
```

У объекта типа нет настоящих данных. Он только описывает тип. Поэтому Raku называет его _неопределённым_. Экземпляр — это настоящий объект. Поэтому он _определён_.

`WHAT` показывает для обоих один и тот же тип. Вы видели `WHAT` в [разделе о контейнерах](/ru/advanced/containers):

```raku
class Dog {
}

say Dog.WHAT;     # (Dog)
say Dog.new.WHAT; # (Dog)
```

Raku показывает тип в круглых скобках, например `(Dog)`. Значит, у `Dog` и `Dog.new` один и тот же тип, `Dog`. Но это разные вещи. `Dog` — это сам тип. `Dog.new` — это объект этого типа.
