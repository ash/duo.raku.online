## Задача

Напишите подпрограмму `lookup`. Если её аргумент равен `'a'`, она возвращает `100`. Иначе она вызывает `fail` с сообщением `no such key`.

Вызовите `lookup('z')`. Если результат определён, напечатайте его. Если нет, напечатайте `not found`. Потом напечатайте вторую строку с причиной сбоя. Возьмите причину из самого `Failure`. Строка выглядит так: `reason: <сообщение>`.

## Пример

Программа печатает:

```
not found
reason: no such key
```
