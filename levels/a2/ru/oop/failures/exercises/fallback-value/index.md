## Задача

Напишите подпрограмму `get`. Она возвращает свой аргумент. Но если аргумент равен `0`, она вызывает `fail`. Сообщение — `bad`.

Напечатайте результат `get(5)`. Потом напечатайте результат `get(0)`. Используйте оператор «определённое или» `//` с запасным значением `default`. Оператор `//` даёт это значение, когда результат не определён.

## Пример

Программа печатает:

```
5
default
```
