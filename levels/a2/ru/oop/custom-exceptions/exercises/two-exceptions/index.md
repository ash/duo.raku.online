## Задача

Создайте два собственных класса исключений: `TooSmall` и `TooBig`. Это классы для ваших собственных ошибок. Каждый класс наследует от `Exception`. Метод `message` класса `TooSmall` возвращает `too small`. Метод `message` класса `TooBig` возвращает `too big`.

Напишите цикл по двум типам. Для каждого типа бросьте исключение этого типа. У каждого исключения свой блок. Добавьте фазер `CATCH` с ветвью `when` для каждого типа. Для `TooSmall` он печатает `small`. Для `TooBig` он печатает `big`. Так вы видите, что работают обе ветви.

## Пример

Программа печатает:

```
small
big
```
