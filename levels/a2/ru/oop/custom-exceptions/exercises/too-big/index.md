## Задача

Создайте собственный класс исключения `TooBig`. Это класс для ваших собственных ошибок. Он наследует от `Exception`. У него есть два атрибута: `value` и `limit`. Его метод `message` должен возвращать `Value <value> exceeds the limit of <limit>`.

Потом напишите цикл по значениям `30`, `99` и `60`. Предел равен `50`. Бросайте `TooBig`, только когда значение больше предела. Добавьте фазер `CATCH` с ветвью `when TooBig`. Он печатает сообщение **и** вторую строку. Для этой строки он прямо читает атрибут `limit` исключения. Вторая строка — это `Try a value up to <limit>.`. Если значение не больше предела, просто напечатайте, что всё в порядке.

Вы видите, что исключение получают только плохие числа. Остальные числа проходят без проблем. В обоих случаях цикл идёт дальше.

## Пример

Программа печатает:

```
Value 30 is within the limit
Value 99 exceeds the limit of 50
Try a value up to 50.
Value 60 exceeds the limit of 50
Try a value up to 50.
```
