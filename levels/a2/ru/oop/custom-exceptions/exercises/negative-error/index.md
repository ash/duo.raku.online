## Задача

Создайте собственный класс исключения `Negative`. Это класс для ваших собственных ошибок. Он наследует от `Exception`. У него есть атрибут `n`. Его метод `message` возвращает `<n> is negative`.

Напишите подпрограмму `check($n)`. Если её аргумент меньше нуля, она бросает `Negative`. Этот `Negative` хранит `n`. Иначе подпрограмма возвращает аргумент. Потом вызовите `check(-5)` внутри блока. Добавьте фазер `CATCH` с ветвью `when Negative`. Он печатает сообщение исключения.

В конце, после блока, бросьте ещё один `Negative`. Его `n` равно `-10`. Там его не перехватывает никакой `CATCH`. Это показывает, что тогда происходит. Исключение завершает программу.

## Пример

Программа печатает:

```
-5 is negative
-10 is negative
  in block <unit> at negative-error.raku line 24
```
