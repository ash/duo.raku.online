В Raku есть встроенные исключения. Их имена начинаются с `X::`. Вы можете создавать и свои исключения. Мы называем их собственными исключениями. Собственное исключение — это класс. Он наследует от встроенного класса `Exception`. Поэтому он — один из видов `Exception`. Ещё у него есть метод `message`:

```raku
class TooBig is Exception {
    has $.value;

    method message {
        "Value $.value is too big";
    }
}
```

`TooBig` — обычный класс. У него могут быть атрибуты, например `value`. Но он `is Exception`. Поэтому его можно бросить, как ошибку из `die`. Чтобы бросить его, создайте объект этого класса. Потом вызовите у этого объекта `.throw`:

```raku
my $value = 20 * 30;

TooBig.new(value => $value).throw if $value > 50;

CATCH {
    when TooBig {
        say .message;
    }
}
```

Программа печатает:

```
Value 600 is too big
```

Внутри `CATCH` срабатывает `when TooBig`. Это потому, что брошенный объект имеет тип `TooBig`. Собственное исключение хранит любые данные, которые вы ему даёте. Здесь эти данные — `value`. Код, который обрабатывает исключение, — это обработчик. Обработчик может использовать эти данные. Он может составить точное сообщение. Или он может отреагировать особым образом. Это гораздо полезнее, чем простая строка для `die`.

Здесь собрано всё из этой части курса. Собственное исключение — это _класс_. У него есть атрибуты и метод. Ещё оно работает с инструментами Raku для исключений. Его можно бросить и перехватить. Поэтому оно может точно сказать, что пошло не так.
