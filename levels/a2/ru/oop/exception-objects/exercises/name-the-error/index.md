## Задача

Напишите подпрограмму `risky`. Она делает `die 'sub failed'`. Потом вызовите `risky` внутри блока с фазером `CATCH`. Сначала `CATCH` печатает имя типа исключения с помощью `.^name`. Потом он печатает его сообщение с помощью `.message`. Это показывает ещё одну вещь о `CATCH`. Он обрабатывает и исключения из кода, который блок *вызывает*. `die` не обязан стоять в самом блоке.

## Пример

Программа печатает:

```
X::AdHoc
sub failed
```
