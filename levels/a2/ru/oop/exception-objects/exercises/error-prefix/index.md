## Задача

Напишите блок с `die 'timeout'` внутри. Добавьте в блок фазер `CATCH`. Он перехватывает исключение и печатает его сообщение. Поставьте перед сообщением `Error: `.

## Пример

Программа печатает:

```
Error: timeout
```
