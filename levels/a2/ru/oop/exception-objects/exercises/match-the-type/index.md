## Задача

У каждой встроенной ошибки есть свой тип исключения. Эти типы можно сопоставлять. Напишите блок, который вычисляет `1 / 0`. Потом блок пытается использовать результат. Из-за этого бросается `X::Numeric::DivideByZero`. Добавьте в блок фазер `CATCH`. В нём используйте `when X::Numeric::DivideByZero`. Эта ветвь совпадает именно с этим типом. Потом напечатайте `cannot divide by zero`.

## Пример

Программа печатает:

```
cannot divide by zero
```
