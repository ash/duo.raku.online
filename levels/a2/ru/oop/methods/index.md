Атрибуты дают объекту данные. С _методами_ объект может ещё и что-то делать. Метод — это подпрограмма внутри класса. Вы вызываете метод у объекта. Чтобы создать метод, напишите ключевое слово `method`:

```raku
class Dog {
    has $.name;

    method bark {
        return $.name ~ ' says Woof!';
    }
}
```

Чтобы вызвать метод у объекта, используйте точку. С аксессором всё точно так же:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.bark; # Rex says Woof!
```

Внутри метода `self` — это объект. Это тот объект, у которого вы вызвали метод. Атрибуты вы получаете через их аксессоры. Вы пишете их так: `$.name`, `$.age` и так далее. Их можно использовать и внутри строки в двойных кавычках:

```raku
class Dog {
    has $.name;

    method greet {
        "Hello, my name is $.name";
    }
}

say Dog.new(name => 'Rex').greet; # Hello, my name is Rex
```

Следующие темы рассказывают о трёх вещах. Первая — приватные атрибуты. Для них нужны методы, и теперь методы у вас есть. Вторая — методы с параметрами. Третья — методы, которые вызывают другие методы.
