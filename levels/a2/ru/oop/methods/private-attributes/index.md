В [разделе об атрибутах](/ru/oop/attributes) у каждого атрибута в имени было `$.`. `$.` создаёт публичный аксессор. Им может пользоваться любой код снаружи объекта. Но вместо этого можно написать `$!`. Тогда атрибут _приватный_. У него нет аксессора. Код снаружи объекта его не видит. Его могут использовать только методы класса. Там вы пишете его как `$!name`.

```raku
class Safe {
    has $!code = 4321;

    method unlocks($attempt) {
        return $attempt == $!code;
    }
}

my $safe = Safe.new;
say $safe.unlocks(4321); # True
say $safe.unlocks(1111); # False
```

Секретный `$!code` лежит внутри объекта. Но снаружи его никто не видит. Аксессора `.code` нет. Использовать код можно только через метод `unlocks`. Класс даёт вам этот метод специально. Прочитать `$safe.code` или `$safe!code` просто не получится.

Приватные атрибуты хороши для деталей внутри объекта. Остальная программа не должна трогать их напрямую.
