У метода могут быть параметры, как у подпрограммы. Напишите их в круглых скобках после имени метода:

```raku
class Account {
    has $.balance is rw = 0;

    method deposit($amount) {
        $.balance += $amount;
    }
}
```

У метода `deposit` один параметр, `$amount`. Метод прибавляет эту сумму к балансу объекта:

```raku
my $a = Account.new;
$a.deposit(100);
$a.deposit(50);
say $a.balance; # 150
```

Каждый вызов работает с одним объектом. Это тот объект, у которого вы вызываете метод. Поэтому один метод может менять разные объекты. Один объект не меняет другие. У методов могут быть позиционные и именованные параметры. Ещё у них могут быть значения по умолчанию. Всё остальное из сигнатур подпрограмм тоже здесь работает.
