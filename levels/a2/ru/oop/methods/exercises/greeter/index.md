## Задача

Создайте класс `Word` с атрибутом `text`. Дайте ему метод `reversed`. Этот метод возвращает текст слова задом наперёд. Подсказка: метод `flip` переворачивает строку.

Создайте слово с текстом `Raku`. Напечатайте этот текст задом наперёд.

## Пример

Программа печатает:

```
ukaR
```
