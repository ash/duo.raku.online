## Задача

Создайте класс `Celsius` с атрибутом `degrees`. Добавьте метод `to-fahrenheit`. Он переводит температуру в градусы Фаренгейта. Используйте такую формулу: `degrees × 9 / 5 + 32`.

Создайте объект `Celsius` для `100` градусов. Напечатайте его значение по Фаренгейту.

## Пример

Программа печатает:

```
212
```
