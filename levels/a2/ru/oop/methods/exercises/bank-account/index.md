## Задача

Создайте класс `Robot`. У него есть атрибут `position`, который можно менять. Его значение по умолчанию — `0`. Ещё у класса есть метод `move`. Этот метод сдвигает позицию вперёд на несколько шагов. По умолчанию число шагов равно `1`. Поэтому `move` без аргумента сдвигает робота на один шаг.

Создайте робота. Сдвиньте его на `5` шагов. Потом вызовите `move` без аргумента. Потом сдвиньте его ещё на `2` шага. Напечатайте его последнюю позицию.

## Пример

Программа печатает:

```
8
```
