## Задача

Создайте класс `Rectangle` с двумя атрибутами, `width` и `height`. Добавьте метод `area`. Он возвращает площадь прямоугольника. Добавьте второй метод, `describe`. Он возвращает строку `area is <площадь>`. Для этого он должен **вызвать собственный метод `area`** через `self`.

Создайте прямоугольник. Его ширина `3`, а высота `4`. Напечатайте его описание.

## Пример

Программа печатает:

```
area is 12
```
