## Задача

Создайте каталог `cache` с помощью `mkdir`. Положите в него два файла. Затем удалите всё. Сначала удалите оба файла. Теперь каталог пуст, так что удалите и его. В конце напечатайте, существует ли ещё каталог.

## Пример

Программа печатает:

```
False
```
