Вы вызываете _метаметод_ через `.^`, а не через `.`. Обычный `.method` выполняет метод объекта. С `.^method` всё иначе. Он вызывает метод **метаобъекта** этого объекта. Метаобъект — это объект, который описывает тип. Поэтому такой вызов спрашивает о типе. Он не действует как тип.

Вы уже знаете `.^name`. Он возвращает имя типа:

```raku
say 42.^name; # Int
```

Другие метаметоды показывают, как устроен тип. `.^attributes` перечисляет его атрибуты. `.^find_method` говорит, есть ли метод:

```raku
class Animal {
    has $.name;
    method speak { 'generic' }
}

say Animal.^attributes.elems;          # 1
say so Animal.^find_method('speak');   # True
say so Animal.^find_method('fly');     # False
```

`.^mro` возвращает _порядок разрешения методов_. Это цепочка типов. Raku ищет метод в каждом из них, в этом порядке. Это линия наследования класса:

```raku
class A {}
class B is A {}

say B.^mro.map(*.^name); # (B A Any Mu)
```

`B` наследует от `A`. А в конце концов каждый тип наследует от `Any` и `Mu`. Вы вызываете метод у `B`. Тогда Raku ищет его ровно по этому пути. Эти метаметоды превращают ваши типы в данные. Эти данные показывают, как устроены типы. О них можно спрашивать, пока программа работает.
