## Задача

Создайте класс `Dog`. У него есть только атрибут `name` и нет методов. Потом с помощью MOP добавьте ему метод `speak`. Сделайте это, пока программа работает. Новый метод использует `name` самого объекта. Он возвращает `<имя> says woof`. Создайте собаку с именем `Rex` и вызовите новый метод.

## Пример

Программа печатает:

```
Rex says woof
```
