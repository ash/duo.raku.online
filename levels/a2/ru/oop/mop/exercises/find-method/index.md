## Задача

Создайте класс `Animal` с методом `speak`. Потом создайте класс `Dog`. Он наследует от `Animal`. У него нет своих методов. Вызовите у `Dog` метаметод. Проверьте, есть ли у `Dog` метод `speak`. Напечатайте только `True` или `False`. Это кое-что показывает про `find_method`. Он смотрит по всей цепочке наследования. Он смотрит не только на методы самого класса.

## Пример

Программа печатает:

```
True
```
