Вот один способ решить задачу.

## Код

```raku
class A {
}

class B is A {
}

class C is A {
}

class D is B is C {
}

say D.^mro.map(*.^name);
```

🦋 Исходный код можно найти в файле [diamond-mro.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/mop/diamond-mro.raku).

## Вывод

```
(D B C A Any Mu)
```

## Комментарии

1. `D` наследует сразу от двух родителей. В `class D is B is C` у каждого родителя есть своё `is`. Это называется множественным наследованием. Классы `A`, `B`, `C` и `D` образуют *ромб*. От `D` вверх к `A` ведут два пути. `A` — родитель и для `B`, и для `C`.

1. `.^mro` превращает ромб в одну прямую линию. Raku ищет в этом порядке. Первым идёт `D`. Потом идут его родители, `B` и `C`. Они идут в том порядке, как стоят в коде. Потом идёт `A`, общий родитель. В конце идут `Any` и `Mu`.

1. И `B`, и `C` ведут к `A`. Но тип `A` стоит в списке только **один раз**. И он идёт после них обоих. В этом цель порядка разрешения методов. Raku посещает каждый тип ровно один раз. Родитель никогда не идёт раньше своего потомка. Поэтому Raku всегда сначала находит метод в `B`. Он находит его раньше того метода в `A`, который он переопределяет.
