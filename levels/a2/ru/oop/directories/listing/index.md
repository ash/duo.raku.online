Процедура `dir` возвращает записи каталога. Запись — это файл или каталог внутри него. Каждая запись — это объект пути. Порядок записей может меняться. Поэтому результат часто сортируют. Тогда вывод всегда идёт в одном и том же порядке.

```raku
mkdir 'box';
spurt 'box/a.txt', '';
spurt 'box/b.txt', '';

for dir('box').sort -> $entry {
    say $entry.basename;
}
```

Эта программа печатает имена файлов в каталоге `box`. Имена идут по порядку:

```
a.txt
b.txt
```

Каждая запись — это полный объект пути. Метод `basename` даёт только имя в конце. Часть с каталогом он не даёт. Вы можете задать объекту пути все те же вопросы, что и раньше: `.f`, `.d`, `.e`. Так что, например, можно взять из каталога только файлы.
