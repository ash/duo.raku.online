Иногда нужно работать с самой файловой системой. В файловой системе хранятся все файлы и каталоги на диске. Например, вы проверяете, что существует, или создаёте каталоги. Каталог — это папка. В нём могут быть файлы и другие каталоги. Для этой работы Raku использует _объекты пути_. Путь показывает, где лежит файл или каталог. Метод `.IO` превращает любую строку в объект пути. Потом объект пути отвечает на вопросы об этом пути.

Два вопроса задают чаще всего. Существует ли путь? И что это такое?

```raku
spurt 'greeting.txt', 'hi';

say 'greeting.txt'.IO.e; # True  — существует ли?
say 'greeting.txt'.IO.f; # True  — это файл?
say 'greeting.txt'.IO.d; # False — это каталог?
```

`.e` проверяет, существует ли путь. `.f` проверяет, обычный ли это файл. `.d` проверяет, каталог ли это.

`mkdir` создаёт новый каталог:

```raku
mkdir 'reports';
say 'reports'.IO.d; # True
```

Следующая тема показывает, как получить список всего, что есть в каталоге.
