## Задача

Пока ничего не создавайте. Сначала напечатайте, существует ли файл `test.txt`. Затем создайте этот файл. Снова напечатайте, существует ли он теперь. Один и тот же путь должен дать сначала `False`, а потом `True`.

## Пример

Программа печатает:

```
False
True
```
