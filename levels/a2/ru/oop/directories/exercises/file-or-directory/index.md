## Задача

Создайте файл с именем `a.txt`. Затем задайте *одному и тому же* пути два вопроса. Это обычный файл (`.f`)? Это каталог (`.d`)? Напечатайте оба ответа. Вы видите, что для одного пути две проверки дают противоположные результаты.

## Пример

Программа печатает:

```
True
False
```
