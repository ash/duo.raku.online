## Задача

Создайте базовый класс `Animal`. Потом создайте класс `Dog`, который наследует от него. Напечатайте имя класса `Dog`. Потом посмотрите на цепочку наследования `Dog`. В этой цепочке есть сам класс и все его родители. На следующей строке напечатайте, сколько в ней типов. Используйте `.^mro` и посчитайте её элементы. На третьей строке напечатайте, есть ли в этой цепочке класс `Cat`.

## Пример

Программа печатает:

```
Dog
4
False
```
