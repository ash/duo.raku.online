Один класс может наследовать от другого класса. Тогда можно запросить всю цепочку типов. Класс построен на этих типах. Метаметод `.^mro` возвращает эту цепочку. Название значит _method resolution order_, то есть порядок разрешения методов. В этом порядке Raku ищет метод.

```raku
class Animal {
}

class Dog is Animal {
}

say Dog.^mro; # ((Dog) (Animal) (Any) (Mu))
```

Читайте список слева. Сначала `Dog` — это сам `Dog`. Потом это `Animal`, его родитель. Потом это `Any` и `Mu`. Каждый объект Raku наследует от этих двух типов. Они на самом верху. Когда вы вызываете метод у `Dog`, Raku ищет в этом списке. Он идёт слева направо. Он берёт первый подходящий метод. Это объясняет переопределение. Потомок стоит в цепочке раньше. Поэтому его метод побеждает метод родителя.

Иногда у класса нет родителя с `is`. Тогда цепочка короче. В ней только сам класс, а потом `Any` и `Mu`.
