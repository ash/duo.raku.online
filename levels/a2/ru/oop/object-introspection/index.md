В [разделе о контейнерах](/ru/advanced/containers) вы использовали `.^name`. С его помощью вы спрашивали у значения его тип. Те же метавызовы `.^` работают и с классами и объектами. С ними можно увидеть их имена и их атрибуты. Ещё можно увидеть их место в дереве классов.

Метаметод — это метод, который вы вызываете через `.^`. Метаметод `.^name` возвращает имя класса:

```raku
class Dog {
    has Str $.name;
    method bark { 'Woof' }
}

say Dog.^name; # Dog
```

Метаметод `.^attributes` перечисляет атрибуты класса. Для каждого атрибута вы видите его тип. Ещё вы видите его внутреннее приватное имя. Это форма с `$!`. Вы видели её в [приватных атрибутах](/ru/oop/methods/private-attributes):

```raku
say Dog.^attributes; # (Str $!name)
```

Интроспекция значит, что вы спрашиваете объект о нём самом. Она полезна для инструментов, которые работают с любыми объектами. Например, инструмент может напечатать каждый атрибут объекта. Ему не нужно заранее знать класс объекта. Следующая тема — о цепочке наследования класса. Это линия его родительских классов.
