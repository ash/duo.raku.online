Большинство методов вы вызываете у объекта. Объект — это экземпляр класса. Но метод можно вызвать и у самого класса. Это значит, что вы вызываете его у объекта типа. Такой метод часто называют _методом класса_. Он полезен для значений и действий всего класса. Они не принадлежат только одному объекту.

Вы пишете метод класса так же, как любой другой метод:

```raku
class Road {
    method speed-limit { 120 }
}
```

Но вы вызываете его у имени класса. Вы не вызываете его у экземпляра:

```raku
say Road.speed-limit; # 120
```

Вы уже знаете один метод класса. Но вы не называли его так. Это `new`. Вы вызываете `new` у класса, и он создаёт новый объект.

Метод класса не может использовать атрибуты экземпляра. За ним не стоит никакой объект. Поэтому он может работать только с общей информацией. Эта информация одинакова для всех объектов класса. Иногда для работы нужны данные одного объекта. Тогда используйте обычный метод и вызывайте его у экземпляра. Иногда для работы такие данные не нужны. Тогда метод класса — хороший выбор.

Методам класса не нужен экземпляр. Но иногда у вас есть объект. Тогда вы всё равно можете использовать в них его данные:

```raku
class Road {
    has $.name;
    method speed-limit { 120 }

    method info {
        "The maximum speed on $.name is " ~ self.speed-limit
    }
}

my $R404 = Road.new(name => 'Road 404');
say $R404.info;
```

Эта программа печатает тот результат, который вы ждёте:

```
The maximum speed on Road 404 is 120
```

Здесь нужен экземпляр класса. Без него вызов вроде `say Road.info` даёт ошибку.
