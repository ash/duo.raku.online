## Задача

Напишите цикл по трём элементам: `ok`, `bad` и `ok`. Для каждого элемента выполните блок. Блок печатает `processed <элемент>`. Но для элемента `bad` он делает `die 'boom'`. Поставьте внутрь блока фазер `CATCH`. Он перехватывает ошибку. Для элемента с ошибкой он печатает `skipped (<элемент>): <сообщение>`. Потом цикл переходит к следующему элементу. Он не останавливается.

## Пример

Программа печатает:

```
processed ok
skipped (bad): boom
processed ok
```
