## Задача

Покажите, как `CATCH` помогает программе восстановиться после ошибки. Программа не останавливается. Она продолжает работу с безопасным значением по умолчанию.

Перед блоком создайте переменную `$timeout`. Дайте ей значение по умолчанию `30`. Внутри блока сделайте `die 'config missing'`. На следующей строке попробуйте присвоить `$timeout` значение `60`. Программа никогда не доходит до этой строки. Добавьте фазер `CATCH` с блоком `default`. Он печатает `warning: <сообщение>; keeping default`. После блока напечатайте `timeout is <timeout> seconds`.

## Пример

Программа печатает:

```
warning: config missing; keeping default
timeout is 30 seconds
```
