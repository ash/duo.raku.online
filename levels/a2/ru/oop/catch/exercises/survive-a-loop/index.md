## Задача

Напишите цикл по числам `1`, `2` и `3`. Для каждого числа печатайте `ok: <n>`. Но для числа `2` сделайте `die "bad: 2"`. Добавьте внутрь тела цикла фазер `CATCH`. Он перехватывает ошибку и печатает `caught: <сообщение>`. Тогда один плохой проход не останавливает весь цикл.

## Пример

Программа печатает:

```
ok: 1
caught: bad: 2
ok: 3
```
