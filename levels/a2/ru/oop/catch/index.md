Блоком `try` легко пользоваться. Но для `try` весь блок — одно целое. Блок либо работает, либо даёт сбой. Фазер `CATCH` даёт вам больше контроля. Исключение — это ошибка, которая останавливает программу. С `CATCH` вы обрабатываете исключение _внутри_ его блока. Это блок, где случилась ошибка. Там вы решаете, что делать.

`CATCH` — это фазер. Фазер — это особый блок. Raku сам запускает его в определённый момент. Вы уже встречали фазеры в [разделе о порядке выполнения](/ru/advanced/phasers). `CATCH` можно поставить где угодно внутри блока. Он работает, только если код в этом блоке бросает исключение. Исключение вы получаете в переменной темы `$_`:

```raku
{
    die 'Boom!';

    CATCH {
        default {
            say 'Caught: ' ~ .message;
        }
    }
}

say 'after';
```

Программа печатает:

```
Caught: Boom!
after
```

Блок `default` внутри `CATCH` обрабатывает любое исключение. После него исключение считается обработанным. Поэтому программа не останавливается. Она идёт дальше после блока с `CATCH`. Вот почему программа печатает `after`.

Без `CATCH` вызов `die` останавливает программу. Программа не доходит до `after`.
