Блок сам по себе — это оператор, а не выражение. Поэтому обычно его нельзя присвоить переменной. Префикс `do` делает блок выражением. Его значение — это значение **последнего** оператора в блоке:

```raku
my $x = do {
    my $a = 3;
    $a + 4;
};

say $x; # 7
```

Внутри блока можно создавать переменные. Можно выполнить несколько операторов и вычислить результат. `do` возвращает значение блока. Это удобно, когда для значения мало одного выражения.

`do` работает и перед управляющими конструкциями. Эти конструкции выбирают или повторяют код. С `do` они тоже возвращают значение:

```raku
my $sign = do given 5 {
    when * > 0 { 'positive' }
    when * < 0 { 'negative' }
    default    { 'zero' }
};

say $sign; # positive
```

Здесь `do given` делает всю конструкцию `given`/`when` выражением. Его значение — `positive`. То же работает с `do if` и `do for`. Короче говоря, с `do` блок может стоять там, где Raku нужно значение. Это работает и для управляющих конструкций.
