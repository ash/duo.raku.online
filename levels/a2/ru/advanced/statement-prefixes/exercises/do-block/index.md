## Задача

`do` работает и перед управляющими конструкциями. Он делает их выражениями со значением. Выберите метку с помощью `do if 7 > 5 { 'big' } else { 'small' }`. Присвойте метку переменной `$label` и напечатайте её.

## Пример

Программа выводит:

```
big
```
