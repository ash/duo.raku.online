## Задача

Префикс `eager` делает противоположное `lazy`. Он заставляет Raku создать весь список сразу. Тогда список больше не ленивый. Покажите разницу с помощью `.is-lazy`.

Сначала напечатайте, ленивый ли бесконечный диапазон `1 .. Inf`. Потом напечатайте, ленивый ли `eager 1..3`. В конце напечатайте, ленивый ли `lazy 1..3`. Результаты должны быть такими: `True`, `False`, `True`.

## Пример

Программа выводит:

```
True
False
True
```
