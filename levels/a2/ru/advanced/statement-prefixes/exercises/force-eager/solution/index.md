Вот один способ решить задачу.

## Код

```raku
say (1 .. Inf).is-lazy;
say (eager 1..3).is-lazy;
say (lazy 1..3).is-lazy;
```

🦋 Исходный код можно найти в файле [force-eager.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/statement-prefixes/force-eager.raku).

## Вывод

```
True
False
True
```

## Комментарии

1. Raku не может вычислить диапазон до `Inf` весь сразу. Поэтому диапазон ленивый, и `.is-lazy` даёт `True`.

1. Префикс `eager` заставляет Raku создать список сразу. Поэтому результат больше не ленивый, и `.is-lazy` даёт `False`. Это точная противоположность пометке списка как `lazy`.

1. Не используйте `eager` с диапазоном без конца. `eager 1 .. Inf` пытается вычислить каждый элемент сразу. Поэтому программа просто зависает. Она никогда не заканчивается. Она берёт всё больше и больше памяти. Так продолжается, пока программу не остановят. Используйте `eager` только со списками, у которых точно есть конец.

1. Это работает и в обратную сторону. `lazy 1..3` помечает короткий диапазон как ленивый. У этого диапазона есть конец, но он всё равно ленивый. Поэтому `.is-lazy` даёт `True`. Префикс делает ленивым любой список, даже самый маленький. Списку не нужно быть бесконечным, чтобы быть ленивым.
