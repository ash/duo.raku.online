Некоторые списки Raku вычисляет, только когда ему нужны их элементы. Такие списки — _ленивые_. С префиксами `lazy` и `eager` вы можете управлять этим сами.

Префикс `eager` заставляет Raku создать список **весь сразу**, прямо сейчас:

```raku
my @squares = eager (1..3).map(* ** 2);
say @squares; # [1 4 9]
```

`map` создаёт значения и без `eager`. Но `eager` следит, чтобы Raku вычислил их все сразу. Он не ждёт, пока они вам понадобятся.

Префикс `lazy` делает обратное. Он помечает список как ленивый. Тогда Raku создаёт каждый элемент, только когда код его просит. Поэтому список может, в теории, не иметь конца:

```raku
my $numbers = lazy (1 .. Inf);
say $numbers.is-lazy; # True
```

Метод `.is-lazy` показывает, что список ленивый. Поэтому он не пытается сначала вычислить все свои элементы. А у этих элементов нет конца.

Но в этом примере Raku и так делает список ленивым. Диапазон без конца, например `1 .. Inf`, уже ленивый. Поэтому `say (1 .. Inf).is-lazy` печатает `True` и без префикса. Здесь `lazy` ничего не меняет. Он только ясно показывает, чего вы хотите. Префикс по-настоящему полезен в другом случае. Иногда Raku вычисляет список нетерпеливо, весь сразу. С префиксом такой список можно сделать ленивым.

Чаще всего Raku сам делает хороший выбор. Диапазоны и последовательности ленивые. Обычное присваивание массиву — нетерпеливое. Используйте эти префиксы, когда хотите другой выбор. Используйте `eager`, чтобы медленное вычисление произошло сейчас. Используйте `lazy`, чтобы отложить очень большое или бесконечное вычисление.
