Целое число можно записать и в других системах счисления. Это не обязательно система с основанием 10. Система с основанием 10 — это десятичная система. Raku знает три другие самые частые системы. Для них не нужно ничего дополнительного. У каждой системы свой префикс:

```raku
say 0xFF;   # 255  — hexadecimal (base 16)
say 0b1010; # 10   — binary (base 2)
say 0o17;   # 15   — octal (base 8)
```

В коде можно использовать любую систему счисления. Значение всегда одно и то же целое число. Отличается только способ записи.

Для любой другой системы используйте форму `:основание<число>`. Её называют формой с основанием:

```raku
say :16<FF>;   # 255
say :2<1010>;  # 10
```

Можно пойти и в обратную сторону. Возьмите число и запишите его в другой системе счисления. Для этого вызовите метод `base`. Он даёт строку цифр:

```raku
say 255.base(16); # FF
say 10.base(2);   # 1010
```
