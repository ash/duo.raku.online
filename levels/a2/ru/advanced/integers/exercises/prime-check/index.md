## Задача

Число простое или нет? Часто этого не видно на глаз. Метод `is-prime` отвечает на этот вопрос. Используйте его для двух чисел, `97` и `91`. На первый взгляд оба кажутся простыми. Напечатайте результат для каждого числа на отдельной строке.

Будьте осторожны с `91`. Оно равно `7 × 13`.

## Пример

Программа печатает:

```
True
False
```
