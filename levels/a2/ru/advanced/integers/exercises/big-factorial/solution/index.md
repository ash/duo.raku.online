Вот один способ решить задачу.

## Код

```raku
say (2 ** 1000).chars;
```

🦋 Исходный код можно найти в файле [big-factorial.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/integers/big-factorial.raku).

## Вывод

```
302
```

## Комментарии

1. У целых чисел в Raku нет предела размера. Поэтому Raku находит точное значение `2 ** 1000`. Он не округляет число. Число не переполняется.

1. Обычно `chars` — это метод для строк. Его можно вызвать и на целом числе. Тогда он сначала превращает число в текст в десятичной системе. После этого он считает символы. У этого числа нет знака минус и нет десятичной точки. Поэтому количество символов равно количеству цифр: `302`.
