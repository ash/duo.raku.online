## Задача

Число можно прочитать в какой-то системе счисления. Его можно и записать обратно в этой системе. Эти два шага противоположны. Возьмите шестнадцатеричное число `1A`. Шестнадцатеричное — значит, с основанием 16. Сохраните его десятичное значение в переменной. Десятичное — значит, с основанием 10. Потом напечатайте две строки. Первая строка — это десятичное значение. Дальше превратите значение обратно в шестнадцатеричную строку. Напечатайте её во второй строке.

## Пример

Программа печатает:

```
26
1A
```
