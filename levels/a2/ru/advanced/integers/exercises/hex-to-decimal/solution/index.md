Вот один способ решить задачу.

## Код

```raku
my $n = :16<1A>;

say $n;
say $n.base(16);
```

🦋 Исходный код можно найти в файле [hex-to-decimal.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/integers/hex-to-decimal.raku).

## Вывод

```
26
1A
```

## Комментарии

1. Форма с основанием `:16<1A>` читает `1A` как число с основанием 16. Его значение — `1 × 16 + 10 = 26`. Теперь переменная `$n` хранит это значение как обычное целое число.

1. `$n.base(16)` превращает целое число обратно в строку с основанием 16. Результат — снова `1A`. Значит, чтение в системе счисления и печать в ней — противоположные действия.
