У целых чисел много полезных методов и функций. Вот несколько из них. Вы будете часто ими пользоваться.

Метод `is-prime` говорит, простое ли число:

```raku
say 17.is-prime; # True
say 18.is-prime; # False
```

Операторы `gcd` и `lcm` работают с двумя числами. `gcd` даёт наибольший общий делитель. Это самое большое число, на которое делятся оба числа. `lcm` даёт наименьшее общее кратное. Это самое маленькое число, которое делится на оба числа:

```raku
say 12 gcd 18; # 6
say 4 lcm 6;   # 12
```

Метод `abs` даёт абсолютное значение. Это число без знака минус. Метод `sign` даёт `-1`, `0` или `1`. Для отрицательного числа это `-1`. Для нуля это `0`. Для положительного числа это `1`:

```raku
say (-5).abs;  # 5
say (-5).sign; # -1
say 0.sign;    # 0
```
