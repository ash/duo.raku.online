Вы используете целые числа с самого начала курса. Целые числа — это числа без дробной части. Этот раздел показывает несколько их особенностей. Сначала эти особенности можно не заметить.

Самая важная особенность — это _произвольная точность_. У целого числа в Raku нет фиксированного количества байтов. Поэтому оно никогда не переполняется. При переполнении число становится слишком большим. Тогда оно тихо становится неправильным. Если памяти достаточно, целое число может быть таким большим, как вам нужно:

```raku
say 2 ** 100;
# 1267650600228229401496703205376
```

Это значение точное. Оно не округлено. То же самое верно и для умножения больших чисел. Например, Raku находит точный факториал числа 50:

```raku
my $factorial = 1;
$factorial = $factorial * $_ for 1..50;
say $factorial;
# 30414093201713378043612608166064768844377641568960512000000000000
```

Длинные числа в коде трудно читать. Поэтому цифры можно разделить на группы подчёркиваниями. Компилятор пропускает подчёркивания:

```raku
say 1_000_000; # 1000000
```
