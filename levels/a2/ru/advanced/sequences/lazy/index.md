Последовательности не нужно вычислять все свои значения сразу. Последовательности в Raku _ленивые_. Raku создаёт каждое значение, только когда оно вам действительно нужно. Поэтому можно описать последовательность вообще без конца.

Для бесконечной последовательности используйте `Inf` как конечную точку. Raku выполняет `=` раньше, чем `...`. Мы говорим, что `...` связывает слабее, чем `=`. Поэтому напишите последовательность в скобках:

```raku
my $naturals = (1 ... Inf);
```

Посмотрите на `my $naturals = 1 ... Inf` без скобок. Здесь переменная получает только `1`. После этого Raku строит последовательность отдельно. Никто не использует эту бесконечную последовательность. Но Raku пытается её вычислить. Поэтому программа зависает и никогда не заканчивается.

Пока что Raku ничего не вычисляет. Последовательность даёт вам значения, только когда вы их просите. Метод `head` берёт первые несколько значений:

```raku
say (1 ... Inf).head(5); # (1 2 3 4 5)
```

Последовательность бесконечная. Но Raku создаёт только первые пять чисел. Без ленивости программа пытается построить всю бесконечную последовательность. Такая программа никогда не заканчивается.

У конечной последовательности есть конец. Для такой последовательности метод `tail` берёт значения с конца:

```raku
say (1 ... 100).tail(3); # (98 99 100)
```

Ленивость позволяет делать две вещи отдельно. Сначала вы даёте _описание_ последовательности. Позже вы решаете, сколько из неё взять.
