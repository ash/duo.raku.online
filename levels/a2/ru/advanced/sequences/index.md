_Последовательность_ — это ряд значений в определённом порядке. Raku создаёт значения одно за другим. Raku строит последовательности с помощью оператора `...`. Вы даёте ему несколько значений. Оператор находит в них закономерность. Потом он создаёт остальные значения, до конечной точки. Конечная точка — это значение, на котором последовательность заканчивается.

В самом простом случае последовательность считает от одного значения до другого:

```raku
say 1 ... 5; # (1 2 3 4 5)
```

В начале можно дать два значения. Тогда Raku находит шаг между ними. Он продолжает с тем же шагом. Так вы создаёте арифметическую последовательность:

```raku
say 1, 3 ... 11; # (1 3 5 7 9 11)
```

Здесь значения `1, 3` в начале дают шаг два. Поэтому Raku считает с шагом два. Он останавливается, когда доходит до `11`.

Оператор `...` даёт значение типа `Seq`:

```raku
say (1 ... 5).WHAT; # (Seq)
```

Следующие темы показывают другие закономерности, которые знает оператор `...`. Ещё они показывают, что последовательность может быть ленивой. Она может даже быть бесконечной и не иметь конца.
