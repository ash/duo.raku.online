Вот один способ решить задачу.

## Код

```raku
say (1, 2, 4 ... Inf).head(8);
```

🦋 Исходный код можно найти в файле [powers-of-two.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/sequences/powers-of-two.raku).

## Вывод

```
(1 2 4 8 16 32 64 128)
```

## Комментарии

1. Три значения в начале — это `1, 2, 4`. Они растут за счёт умножения. Поэтому `...` видит геометрическую последовательность. Конечная точка — `Inf`. Поэтому последовательность никогда не останавливается сама.

1. `head(8)` берёт только первые восемь значений. Последовательность ленивая. Поэтому Raku никогда не создаёт остальные значения. Только поэтому бесконечную последовательность можно безопасно записать.
