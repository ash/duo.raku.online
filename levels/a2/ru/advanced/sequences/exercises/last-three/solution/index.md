Вот один способ решить задачу.

## Код

```raku
say (5, 10 ... 50).tail(3);
```

🦋 Исходный код можно найти в файле [last-three.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/sequences/last-three.raku).

## Вывод

```
(40 45 50)
```

## Комментарии

1. Начальные значения здесь — `5, 10`. Они дают шаг пять. Последовательность идёт до своей конечной точки, `50`.

1. `tail(3)` возвращает последние три значения последовательности: `40, 45, 50`. Последовательность конечная, поэтому у неё есть конец. `head` работает так же. Он возвращает первые несколько значений.
