## Задача

Создайте пакет `Temperature`. В нём две вещи. Первая — переменная `our` `$freezing` со значением `0`. Вторая — подпрограмма `our` `fahrenheit`. Она переводит значение по Цельсию в градусы Фаренгейта. Для этого умножьте на 9/5 и прибавьте 32. Снаружи пакета выведите точку замерзания. Потом выведите `100` градусов Цельсия в градусах Фаренгейта.

## Пример

Программа выводит:

```
0
212
```
