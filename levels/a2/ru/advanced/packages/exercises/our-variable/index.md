## Задача

Только `our` делает имя видимым снаружи пакета. `my` оставляет имя приватным. Создайте пакет `Config`. В нём есть переменная `our` `$port` со значением `8080`. **Ещё** в нём есть переменная `my` `$secret` со значением `42`. Снаружи пакета выведите `$Config::port`. Потом выведите, определена ли `$Config::secret`. Она не должна быть определена. Переменная `my` — не часть пространства имён.

## Пример

Программа выводит:

```
8080
False
```
