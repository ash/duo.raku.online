## Задача

Положите модуль `Inner` внутрь модуля `Outer`. В `Inner` создайте переменную `our` `$base` со значением `10`. Ещё создайте `our sub doubled`. Она умножает `$base` на два и возвращает результат. Снаружи обоих модулей используйте полное вложенное имя переменной. В этом имени есть имена обоих модулей. Подпрограмму тоже вызовите по полному вложенному имени. Выведите оба результата.

## Пример

Программа выводит:

```
10
20
```
