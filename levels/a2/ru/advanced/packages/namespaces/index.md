Слово `our` делает что-то видимым в его пространстве имён. Переменная с `my` — лексическая. Она приватная для своего блока. Переменная с `our` — это ещё и переменная пакета. До неё можно добраться снаружи через путь `::`:

```raku
module Counter {
    our $count = 0;  # package variable
    my  $secret = 42; # lexical, not visible outside
}

say $Counter::count; # 0
```

`$Counter::count` работает. У переменной `count` есть `our`. А `$Counter::secret` не работает. Переменная `secret` — лексическая.

Пространства имён могут быть **вложенными**. Это значит, что одно пространство имён лежит внутри другого. Пакет внутри пакета даёт более длинный путь `::`:

```raku
module Outer {
    module Inner {
        our $val = 42;
    }
}

say $Outer::Inner::val; # 42
```

Полное имя `$Outer::Inner::val` похоже на путь. Этот путь идёт от внешнего пространства имён во внутреннее. Потом он идёт к переменной. Стандартная библиотека использует именно эту схему. Имена вроде `IO::Socket::INET` — это вложенные пространства имён. Ваши модули тоже могут так работать. Они держат все свои части под одним именем верхнего уровня.
