Ключевое слово `package` создаёт пространство имён. Внутри него можно создавать вещи с `our`. Они становятся частью пространства имён. До них можно добраться снаружи. Используйте имя пакета и разделитель `::`:

```raku
package Maths {
    our $pi = 3.14;
    our sub double($x) { $x * 2 }
}

say $Maths::pi;         # 3.14
say Maths::double(5);   # 10
```

Переменную вы получаете как `$Maths::pi`. Сначала идёт сигил, потом имя пакета, потом имя переменной. Подпрограмму вы вызываете как `Maths::double(...)`.

И `package`, и `module` создают пространство имён. Но ещё они делают разные вещи. `module` — обычный выбор для кода, который вы используете снова. Простой `package` — это только пространство имён, и больше ничего. `class` тоже создаёт пространство имён. О классах вы узнаете в [следующей части](/ru/oop). Ещё класс добавляет инструменты для объектов.

```raku
module Greet {
    our sub hello { 'hi' }
}

say Greet::hello; # hi
```

Итак, `module` даёт вам пространство имён. `package` сам по себе даёт такое же пространство имён. Выбирайте между ними по тому, что вы хотите сделать. Используйте `module` для библиотек. Используйте `package` для простого пространства имён. Позже, с объектами, используйте `class` для типов.
