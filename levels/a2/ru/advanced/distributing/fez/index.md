В прошлой теме вы видели `fez`. С помощью `fez` вы загружаете дистрибутив в экосистему Raku. Вы не обязаны использовать `fez`. Есть и другие способы публикации. Но большинство людей использует `fez`. И он умеет не только загружать. Он также может создать для вас новый дистрибутив. Ещё он помогает с вашей учётной записью автора. Установите `fez` с помощью `zef`:

```
zef install fez
```

## Создание нового дистрибутива

Вы можете сами сделать `META6.json` и каталоги `lib/` и `t/`. Но `fez` может сделать их за вас:

```
fez init My::Greeting
```

`fez init` создаёт основу нового дистрибутива. Это директория проекта. В ней уже есть `META6.json` и стандартная структура. Поэтому вы можете сразу начать писать. Код лежит в `lib/`, а тесты лежат в `t/`. Вам не нужно самим готовить `META6.json`.

## Регистрация и вход

Чтобы публиковать, нужна учётная запись в экосистеме. Вы создаёте её только один раз, командой `fez register`. Она спрашивает имя пользователя, email и пароль. Потом вы входите командой `fez login`. Она сохраняет ваш ключ. С этим ключом следующие команды знают, кто вы:

```
fez register
fez login
```

Ваше имя пользователя важно. В `META6.json` дистрибутива должно быть поле `auth`. Его значение — `zef:<username>`. Так экосистема знает, что загрузка точно ваша.

## Загрузка

У вас есть учётная запись, и дистрибутив готов. Теперь `fez upload` упаковывает текущую директорию и отправляет её:

```
fez upload
```

После этого любой может установить его по имени командой `zef install My::Greeting`. Вы можете загрузить каждую версию только один раз. Поэтому перед обновлением увеличьте `version` в `META6.json`.

## Ещё полезные команды

Вы также будете использовать эти команды `fez`:

* `fez review` — искать возможные проблемы в дистрибутиве до загрузки;
* `fez list` — показать дистрибутивы, которые вы уже опубликовали;
* `fez refresh` — снова сделать `META6.json` по файлам, которые сейчас лежат на диске.

> Всем этим командам нужны установленный `fez` и сеть. Всем командам после `init` нужна ещё учётная запись в экосистеме.
