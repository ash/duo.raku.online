## Задача

Напишите файл `META6.json`. У дистрибутива имя `Greet::Simple` и версия `0.0.1`. Он предоставляет модуль `Greet::Simple` из файла `lib/Greet/Simple.rakumod`. В примере из теории `depends` пустой. Здесь всё иначе. Этот дистрибутив **зависит от** другого дистрибутива, `JSON::Fast`. Запишите его в массив `depends`.

> Результат этого упражнения — файл. Это не вывод программы.
