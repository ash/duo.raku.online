Вот один способ решить задачу.

## Структура

```
Greet-Simple/
├── META6.json
├── README.md
├── lib/
│   └── Greet/
│       └── Simple.rakumod
└── t/
    └── 01-basic.rakutest
```

## Комментарии

1. `META6.json` лежит в корне. Исходный код модуля лежит в `lib/`. Его путь из каталогов совпадает с частями имени. В имени `::` разделяет эти части.

1. Тесты лежат в `t/`. Используйте эту структуру. Тогда `zef test .` и `zef install .` работают в корневой директории.
