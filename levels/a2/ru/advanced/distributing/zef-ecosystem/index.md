`zef` устанавливает модули Raku. Вы уже устанавливали с ним модули по их именам. Он также работает с дистрибутивом в локальной директории. Перейдите в директорию дистрибутива. Оттуда вы можете сразу протестировать и установить его:

```
zef test .
zef install .
```

`zef test .` запускает файлы из `t/`. `zef install .` устанавливает дистрибутив в ваш Raku. Тогда другие программы могут загрузить его через `use`. Вы также можете установить модуль по имени, например `zef install Cro`. Эта команда делает то же самое. Но сначала она скачивает дистрибутив из экосистемы.

Может быть, вы хотите **опубликовать** свой дистрибутив. Тогда другие люди смогут установить его по имени. Для этого вы загружаете его в экосистему. Обычно для этого используют `fez`:

```
fez upload
```

Эта команда упаковывает текущий дистрибутив и отправляет его в экосистему Raku. После этого `zef install Maths::Simple` работает у всех.

> Этим командам нужны установленный `zef`/`fez` и сеть. Для загрузки нужна ещё учётная запись в экосистеме.

Итак, общий модуль проходит три шага. Сначала вы даёте ему стандартную структуру и `META6.json`. Потом вы тестируете его с помощью `zef test`. Затем вы публикуете его с помощью `fez upload`. После этого это просто ещё одно имя. Любой может установить его с помощью `zef install`.
