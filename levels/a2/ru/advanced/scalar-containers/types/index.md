Давайте посмотрим на программу. Она использует одну и ту же переменную для разных видов данных. Мы используем `dd`, чтобы видеть данные на каждом шаге. Этот пример только показывает, как всё работает. Это не лучший способ писать программы.

```raku
my $value;
dd $value;

$value = 42;
dd $value;

$value = 'forty-two';
dd $value;
```

Каждый вызов `dd` показывает текущее значение `$value`:

```
$value = Any
$value = 42
$value = "forty-two"
```

Сначала переменная пустая. `dd` показывает её значение как `Any`. Это неопределённое базовое значение. С него начинает каждый контейнер без типа. После присваиваний `dd` показывает целое число. Потом она показывает строку.

Обратите внимание: здесь `dd` не печатает тип перед именем. Контейнер без типа не привязан к типу. Поэтому `dd` показывает только значение. [Контейнер с объявленным типом](/ru/advanced/scalar-containers/type-constraints) работает иначе. Вы увидите это в следующей теме.
