Скалярный контейнер — это на самом деле объект типа `Scalar`. Обычно вы этот контейнер совсем не видите. Вам не нужно о нём думать. Можно представить, что вы работаете прямо со значениями в нём.

Почему это работает? Скалярный контейнер передаёт вызовы методов значению внутри себя. Например, возьмём присваивание `my $lang = 'Raku'`. После него можно вызвать метод `.chars` для переменной:

```raku
my $lang = 'Raku';
say $lang.chars; # 4
```

Программа печатает `4`. Это число символов в строке `'Raku'`. Теперь вызовите `.chars` для самого строкового значения, а не для переменной. Результат точно такой же:

```raku
say 'Raku'.chars; # 4
```

Значит, контейнер тихо передаёт вызов `.chars` своей строке. Потом он отдаёт вам результат.
