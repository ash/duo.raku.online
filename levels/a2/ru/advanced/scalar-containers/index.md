---
title: Скалярные контейнеры
---

{% include menu.html %}

Скалярные контейнеры хранят одиночные, или скалярные, значения. Об этом говорит название. У таких контейнеров сигил `$`.

Вот очень простой пример со скаляром:

```raku
my $lang = 'Raku';
```

Переменная `$lang` — это скалярный контейнер.

По умолчанию скалярный контейнер не ограничивает тип данных. Поэтому в нём можно хранить значение любого типа. Вот самый простой пример. Сначала переменная хранит целое число. Потом та же переменная хранит строку:

```raku
my $value = 42;
$value = 'forty-two';
```

Автор не советует писать такой код.

Внутри Raku это значит вот что. По умолчанию новый контейнер может хранить значения типа `Any`. `Any` — это базовый тип для большинства других типов. Например, `Int` и `Str` происходят от `Any`.
