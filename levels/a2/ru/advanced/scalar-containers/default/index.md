---
title: Значения по умолчанию
---

{% include menu.html %}

Иногда вы создаёте скалярную переменную. Но вы пока не присваиваете ей значение. Контейнер всё равно хранит значение. Это его значение по умолчанию. Значение по умолчанию зависит от типа переменной.

Эта программа использует Raku не лучшим образом. Но она показывает идею:

```raku
my $int;
say $int + 5;
```

В выводе есть `5`. Может быть, вы этого ждали. Может быть, вы думали, что значение по умолчанию у `$int` — это `0`. Но программа также печатает предупреждение:

```
Use of uninitialized value $int of type Any in numeric context
  in block <unit> at t.raku line 2
5
```

Убрать это сомнение можно двумя способами. Можно прямо присвоить значение:

```raku
my $int = 0;
say $int + 5; # 5
```

Или можно задать значение по умолчанию с помощью трейта `is default`:

```raku
my $int is default(0);
say $int + 5; # 5
```

Значение по умолчанию не обязательно ноль. Это может быть любое значение, которое вы считаете хорошим. Например:

```raku
my $int is default(1);
say $int + 5; # 6
```
