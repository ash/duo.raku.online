Вот один способ решить задачу.

## Код

```raku
my $discount is default(0);
say $discount;

$discount = 15;
say $discount;
```

🦋 Исходный код можно найти в файле [default-discount.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/scalar-containers/default-discount.raku).

Конечно, есть решение проще. Дайте переменной значение `0`, когда создаёте её:

```raku
my $discount = 0;
say $discount;

$discount = 15;
say $discount;
```

## Вывод

```
0
15
```

## Комментарии

1. Трейт `is default(0)` даёт контейнеру запасное значение. Контейнер использует его, пока вы ничего не присвоили. Если прочитать переменную, вы получите `0`. Без объявленного значения по умолчанию вы получаете предупреждение о _неинициализированном значении_. Здесь такого предупреждения нет.

1. После присваивания в контейнере лежит `15`. Значение по умолчанию больше не важно.
