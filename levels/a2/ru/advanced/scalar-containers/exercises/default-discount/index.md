## Задача

Объявите скалярную переменную `$discount`. Её значение по умолчанию должно быть `0`. Напечатайте переменную до того, как присвоите ей что-нибудь. Программа должна напечатать `0`. Она не должна печатать никаких предупреждений.

Затем присвойте переменной `15`. Выведите её снова.

## Пример

Программа выводит две строки:

```
0
15
```
