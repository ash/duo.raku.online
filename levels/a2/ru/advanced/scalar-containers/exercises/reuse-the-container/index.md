## Задача

Объявите рядом две скалярные переменные. Первая — `$untyped`. У неё нет типа. Вторая — `$typed`. У неё тип `Int`. Выведите обе с помощью `dd`, пока они ещё пустые. Потом присвойте каждой из них `42`. Снова выведите обе. Внимательно посмотрите на вывод. `dd` описывает два контейнера по-разному.

## Пример

Программа выводит вот это в стандартный поток ошибок:

```
$untyped = Any
Int $typed = Int
$untyped = 42
Int $typed = 42
```
