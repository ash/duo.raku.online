Вот один способ решить задачу.

## Код

```raku
my $untyped;
my Int $typed;

dd $untyped;
dd $typed;

$untyped = 42;
$typed = 42;

dd $untyped;
dd $typed;
```

🦋 Исходный код можно найти в файле [reuse-the-container.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/scalar-containers/reuse-the-container.raku).

## Вывод

```
$untyped = Any
Int $typed = Int
$untyped = 42
Int $typed = 42
```

## Комментарии

1. `dd` показывает два контейнера по-разному. Для контейнера без типа она печатает только `$untyped`. Для контейнера с типом она добавляет впереди объявленный тип: `Int $typed`. Именно это и меняет объявленный тип.

1. Пустые значения тоже разные. Контейнер без типа начинает с `Any`. Это базовое неопределённое значение. Контейнер с типом начинает с неопределённого значения *своего* типа. Здесь это `Int`.

1. Потом обе переменные получают `42`. Теперь значения выглядят одинаково. Но у `$typed` всё ещё есть тип. Она не принимает значение, если это не целое число. `$untyped` принимает любое значение.
