Вот один способ решить задачу.

## Код

```raku
my Int $cars;

$cars = 250.7.Int;
say $cars;
say $cars.WHAT;
```

🦋 Исходный код можно найти в файле [integers-only.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/scalar-containers/integers-only.raku).

## Вывод

```
250
(Int)
```

## Комментарии

1. Ограничение типа `Int` в `my Int $cars` — это правило для контейнера. Контейнер не принимает значения, если это не целые числа. Присвоить `250.7` напрямую нельзя. Это значение типа `Rat`. Raku выдаёт ошибку при компиляции, ещё до запуска программы.

1. Программа вызывает `.Int` для рационального значения `250.7`. Это превращает его в целое число `250`. Метод просто отбрасывает всё, что стоит после точки. Новое значение подходит для контейнера. Заметьте, что это не то же самое, что округление.

1. Псевдометод `.WHAT` показывает тип сохранённого значения. Это `Int`.
