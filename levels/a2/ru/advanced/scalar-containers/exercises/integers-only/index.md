## Задача

Объявите контейнер `$cars`. Он может хранить только целые числа.

У вас есть значение из компьютерной модели дорожного движения: `250.7`. Положите его в `$cars`. Сначала преобразуйте его в целое число. Без этого присваивание не работает. Потом напечатайте значение и его тип.

## Пример

Программа выводит:

```
250
(Int)
```
