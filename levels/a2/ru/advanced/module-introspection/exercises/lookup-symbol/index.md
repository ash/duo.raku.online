## Задача

Вы можете перечислить имена пакета. А ещё можно получить одно имя по-другому. Используйте имя как ключ в stash пакета. Stash — это его таблица имён. С ключом программа может выбрать имя во время работы. Вот модуль `Circle.rakumod`:

```raku
unit module Circle;

our $pi = 3.14;
```

Напишите отдельную программу. Она загружает модуль. Потом она выводит значение `$pi`. Она должна найти `$pi` в stash с помощью `Circle::{'$pi'}`. Не используйте полное имя `$Circle::pi`.

## Пример

Запустите программу с модулем в пути поиска. Она выводит:

```console
$ raku -I. lookup.raku
3.14
```
