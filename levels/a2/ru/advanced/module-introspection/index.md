Имя модуля также создаёт _пакет_. Пакет — это пространство имён. В нём хранятся имена из модуля. Раньше, в [разделе о контейнерах](/ru/advanced/containers), вы видели `WHO`. Он возвращает `Stash` пакета. `Stash` — это таблица символов, то есть имён, в пакете. Интроспекция модулей использует это. С её помощью программа смотрит внутрь модуля.

Примеры ниже используют модуль `Greeting` из прошлых тем. В нём есть подпрограмма, которую он экспортирует. Ещё в нём есть общая переменная `our`:

```raku
unit module Greeting;

our $version = '1.0';

sub hello($name) is export {
    return "Hello, $name!";
}
```

Чтобы получить пакет модуля, напишите `::` после его имени. Потом добавьте `.keys`. Он показывает имена в пакете:

```raku
use Greeting;

say Greeting::.keys.sort; # ($version EXPORT)
```

У модуля `Greeting` из прошлых тем есть переменная `our` — `$version`. Поэтому в его пакете есть это имя. У имени есть сигил. Рядом с ним вы видите `EXPORT`. Это может удивить. `EXPORT` — тоже пакет. Raku создаёт его автоматически. Модуль помечает некоторые вещи как `is export`. `EXPORT` хранит их все, например подпрограмму `hello`. Поэтому экспортированное имя лежит _не_ прямо в пакете. Оно лежит в `EXPORT`. Это пакет поменьше внутри пакета модуля. Порядок ключей может быть разным. Поэтому пример их сортирует. Тогда результат всегда одинаковый.

Ещё вы можете найти имя в пакете. Используйте имя как ключ. Вы получите то же значение, что и с полным именем `$Greeting::version`:

```raku
use Greeting;

say Greeting::{'$version'}; # 1.0
```

## Список экспортов модуля

На самом деле экспортированные имена лежат в пакете `EXPORT` из примера выше. Поэтому их можно перечислить. Просто посмотрите на один уровень глубже. Экспорты без тега попадают в группу `DEFAULT`. О тегах можно прочитать в разделе [Теги экспорта](/ru/advanced/modules-basics/export-tags). `.keys` группы `DEFAULT` — это экспортированные подпрограммы:

```raku
use Greeting;

say Greeting::EXPORT::DEFAULT::.keys.sort; # (&hello)
```

Каждый ключ — это экспортированное имя с сигилом. Здесь только один ключ: подпрограмма `&hello`. Сигил `&` показывает, что это подпрограмма. Так вы можете узнать, что модуль даёт своим пользователям. Вам не нужно читать его исходный код. Просто спросите его пакет `EXPORT::DEFAULT`, что в нём есть.

Так смотреть внутрь пакета полезно. Вы можете узнать, что есть в модуле. Ещё можно добраться до его имён, пока программа работает. Тогда не нужно писать каждое имя в коде.
