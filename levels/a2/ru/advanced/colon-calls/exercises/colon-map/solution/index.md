Вот один способ решить задачу.

## Код

```raku
say (1..10).map(* * 2).grep: * > 10;
```

🦋 Исходный код можно найти в файле [colon-map.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/colon-calls/colon-map.raku).

## Вывод

```
(12 14 16 18 20)
```

## Комментарии

1. Только `grep` может использовать форму с двоеточием. Это последний вызов в цепочке. Двоеточие делает `* > 10` его аргументом. Это точно как `grep(* > 10)`. Нам всё ещё нужно вывести результат. Поэтому теперь мы используем `say` как функцию, а не как метод.

1. Вызов `map` должен оставить свои скобки. Если написать `.map: * * 2`, будет проблема. Двоеточие забирает и `.grep(* > 10)`. Он становится частью аргументов `map`. Тогда цепочка ломается.
