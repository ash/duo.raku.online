## Задача

Вот выражение. Оно удваивает числа от `1` до `10`. Потом оно оставляет только числа больше `10`:

```raku
(1..10).map(* * 2).grep(* > 10).say;
```

Измените код. Вызов метода `grep` должен использовать форму с двоеточием, а не скобки. Остальную цепочку не меняйте. Помните: форма с двоеточием берёт весь остаток выражения. Поэтому только последний вызов в цепочке может её использовать.

## Пример

Программа выводит:

```
(12 14 16 18 20)
```
