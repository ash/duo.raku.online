## Задача

Форма с двоеточием должна быть *последним* вызовом в цепочке. Но вызовы перед ней могут быть обычными, со скобками. Начните со слов `a`, `b`, `c`. Поставьте их в обратном порядке с помощью `.reverse`. Потом соедините результат через дефис. Для соединения используйте форму с **двоеточием**. Выведите результат.

## Пример

Программа выводит:

```
c-b-a
```
