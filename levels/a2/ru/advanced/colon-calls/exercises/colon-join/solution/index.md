Вот один способ решить задачу.

## Код

```raku
say <a b c>.reverse.join: '-';
```

🦋 Исходный код можно найти в файле [colon-join.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/colon-calls/colon-join.raku).

## Вывод

```
c-b-a
```

## Комментарии

1. `.reverse` стоит в середине цепочки. Поэтому у него обычная форма. `join` — последний вызов. Поэтому он может использовать двоеточие. Двоеточие передаёт ему `'-'`, так же как `join('-')`.

1. После `.reverse` список такой: `c, b, a`. Потом `join` ставит дефисы между словами. Результат — `c-b-a`. Форма с двоеточием работает и с обычными значениями, не только с блоками.
