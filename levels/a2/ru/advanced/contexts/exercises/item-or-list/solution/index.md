Вот один способ решить задачу.

## Код

```raku
my @a = 1, 2, 3;
my $count = 0;

my $x = $(@a);
$count++ for @($x);
say $count;
```

🦋 Исходный код можно найти в файле [item-or-list.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/contexts/item-or-list.raku).

## Вывод

```
3
```

## Комментарии

1. `my $x = $(@a)` задаёт контекст элемента. Поэтому весь массив попадает в один скаляр `$x`. Массив не распадается на элементы.

1. Потом `@($x)` задаёт контекст списка. Теперь `$x` снова становится тремя элементами. Поэтому цикл `for` выполняется три раза. В конце счётчик равен `3`. Два контекстуализатора делают противоположные вещи. `$( )` упаковывает список в один элемент. `@( )` снова распаковывает его.
