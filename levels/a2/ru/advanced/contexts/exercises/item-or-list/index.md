## Задача

Возьмите массив `1, 2, 3`. Положите его в скаляр `$x` с помощью контекстуализатора **элемента**. Контекстуализатор задаёт контекст. Теперь `$x` хранит весь массив как одно значение. Потом запустите цикл `for` по `$x` с контекстуализатором **списка**. Посчитайте, сколько раз выполняется цикл. В контексте списка массив снова становится тремя элементами. Поэтому цикл выполняется три раза. Выведите счётчик.

## Пример

Программа выводит:

```
3
```
