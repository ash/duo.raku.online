Что выведет эта программа?

```raku
my @a = 1, 2, 3;
my $n = 0;
$n++ for $(@a);
say $n;
```

{:.quiz}
0 | 3
1 | 1
0 | 0
0 | 6

{% include quiz.html %}

<div class="extended-explanation">

Контекстуализатор `$( … )` задаёт контекст элемента. Поэтому массив — это одно значение, а не список элементов. Цикл `for` видит один элемент. Поэтому он выполняет своё тело только один раз. В конце `$n` равно `1`. Без `$( )` цикл выполняется три раза.

</div>
