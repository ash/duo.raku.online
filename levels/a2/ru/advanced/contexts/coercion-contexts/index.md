Три контекста встречаются очень часто. В первом значение работает как число. Во втором оно работает как строка. В третьем оно работает как `True` или `False`. У каждого из этих контекстов есть префиксный оператор. Оператор стоит перед значением. Он прямо задаёт контекст:

* `+` — числовой контекст: значение работает как число
* `~` — строковый контекст: значение работает как строка
* `?` — логический контекст: значение работает как `True` или `False`

Используйте их с массивом. `+` даёт длину массива. `~` даёт его элементы с пробелами между ними. `?` говорит, есть ли в массиве элементы:

```raku
my @a = 1, 2, 3;

say +@a; # 3
say ~@a; # 1 2 3
say ?@a; # True
```

Пустой массив равен `0` в числовом контексте. В логическом контексте он равен `False`:

```raku
my @empty;
say +@empty; # 0
say ?@empty; # False
```

Вам не всегда нужно писать эти операторы. Часто Raku сам задаёт нужный контекст. Арифметика ставит значения в числовой контекст. Соединение строк ставит их в строковый контекст. А `if`, `while`, `and` и `or` ставят своё условие в логический контекст:

```raku
my @a = 1, 2, 3;

say 10 + @a;              # 13, here @a is its length: 3
say 'items: ' ~ @a;       # items: 1 2 3
if @a { say 'not empty' } # not empty
```

Поэтому `if @array { … }` работает так, как вы ждёте. Массив с элементами — истинный. С префиксными операторами вы сами просите те же преобразования.

Ещё можно поставить `if` после инструкции. Тогда код короткий и понятный:

```raku
say "{+@a} items are there" if @a; # 3 items are there
```
