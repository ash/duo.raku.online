Имена нативных типов пишутся строчными буквами: `int`, `num` и `str`. Переменную с ними объявляют так же, как с `Int` или `Str`:

```raku
my int $i = 42;
my num $n = 3.14e0;
say $i; # 42
say $n; # 3.14
```

Нативное значение прямо соответствует машинному регистру или слову. Это маленькие места для данных внутри компьютера. У обычного значения Raku есть объект-обёртка вокруг него. У нативного значения обёртки нет. Поэтому нативные типы быстрее и занимают меньше памяти. Это важно в больших массивах. Это важно и в коротких циклах, которые много считают.

Одну вещь нужно знать сразу. Нативная переменная никогда не бывает неопределённой. Обычная переменная `Int` сначала не определена. `say` показывает её как `(Int)`. Но нативный `int` начинается с **нуля**:

```raku
say (my Int $a); # (Int)
say (my int $b); # 0
```

То же верно для нативных массивов. Чтобы объявить такой массив, напишите нативный тип перед переменной с `@`:

```raku
my int @numbers = 10, 20, 30;
say @numbers.sum; # 60
```

Такой массив хранит свои элементы как простые машинные целые числа. Это не полноценные объекты `Int`. Поэтому массив занимает меньше памяти. Нативное значение можно спросить о его типе. Тогда Raku автоматически кладёт его в соответствующий полный тип. Мы говорим, что значение _упаковано_. Вот почему `(my int $b).WHAT` показывает `(Int)`.
