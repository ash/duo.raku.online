## Задача

Нативная переменная никогда не бывает неопределённой. Это правило верно для всех нативных типов, не только для `int`. Объявите нативный `num` и нативный `str`. Не давайте им значений. Напечатайте число. Потом напечатайте строку в квадратных скобках. Так вы увидите, что она пустая.

## Пример

Программа выводит:

```
0
[]
```
