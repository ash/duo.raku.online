Вот один способ решить задачу.

## Код

```raku
my num $n;
my str $s;

say $n;
say "[$s]";
```

🦋 Исходный код можно найти в файле [native-default.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/native-default.raku).

## Вывод

```
0
[]
```

## Комментарии

1. Нативный `num` не может быть неопределённым. Поэтому он начинается с `0`, как нативный `int`. Он не начинается с `(Num)`.

1. Нативный `str` начинается как пустая строка. Поэтому между скобками ничего нет. Нативный тип никогда не хранит неопределённое значение.

1. Здесь типы очень важны. Попробуйте их убрать. Напишите вместо этого `my $n; my $s;`. Теперь переменные — обычные контейнеры. Сначала они *неопределённые*: в них `Any`. Тогда `say $n` печатает `(Any)`. Строка интерполирует `$s`, но значение `$s` не определено. Поэтому Raku показывает предупреждение: *«Use of uninitialized value … in string context»*. Только нативные типы `num` и `str` дают начальные значения. Это `0` и пустая строка.
