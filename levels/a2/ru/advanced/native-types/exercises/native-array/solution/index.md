Вот один способ решить задачу.

## Код

```raku
my uint8 @bytes = 100, 200, 255;
say @bytes.sum;
```

🦋 Исходный код можно найти в файле [native-array.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/native-array.raku).

## Вывод

```
555
```

## Комментарии

1. Напишите нативный тип фиксированного размера `uint8` перед массивом с `@`. Тогда Raku хранит каждый элемент в одном байте. Этот байт беззнаковый: у него нет знака минус. Такой массив занимает мало памяти. Это хорошо для двоичных данных.

1. У каждого *элемента* есть предел — `0..255`. За этим пределом значения идут по кругу. Но этот предел не для суммы элементов. `.sum` кладёт итог в обычный `Int`. Поэтому `100 + 200 + 255` даёт полное значение `555`.
