## Задача

Нативные типы с фиксированным размером хороши для массивов байтов. Такие массивы занимают мало памяти. Создайте массив `uint8` со значениями `100`, `200` и `255`. Каждое значение помещается в один байт. Напечатайте сумму элементов.

Элементы остаются в диапазоне `0..255`. Но их сумма может быть больше. `.sum` возвращает обычный `Int`.

## Пример

Программа выводит:

```
555
```
