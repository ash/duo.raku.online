Вот один способ решить задачу.

## Код

```raku
my uint8 $u = 250;
$u += 10;
say $u;

my uint8 $v = 0;
$v--;
say $v;
```

🦋 Исходный код можно найти в файле [wrap-around.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/wrap-around.raku).

## Вывод

```
4
255
```

## Комментарии

1. `uint8` идёт от `0` до `255`. Это 256 разных значений. На деле вся арифметика с ним идёт по модулю 256. Результат — это остаток от деления на 256.

1. Обычно `250 + 10` — это `260`. Но `260` не помещается. Поэтому значение идёт по кругу. Оно начинает снова снизу и попадает в `260 - 256 = 4`. Переполнение — это не только один шаг за верхнюю границу. Любой результат вне диапазона возвращается в диапазон.

1. В другую сторону тоже бывает переполнение. В беззнаковом типе декремент `0` не может дать `-1`. Поэтому значение по кругу переходит к самому большому значению, `255`.
