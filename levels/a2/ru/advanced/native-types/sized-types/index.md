В Raku есть простой `int`. Ещё в нём есть целые числа с фиксированным количеством битов. Это `int8`, `int16`, `int32` и `int64`. У каждого из них есть беззнаковая пара: `uint8`, `uint16`, `uint32` и `uint64`. Беззнаковые значения никогда не бывают отрицательными. Число в имени говорит, сколько битов занимает значение.

Фиксированный размер значит фиксированный диапазон значений. `int8` хранит значения от `-128` до `127`. `uint8` хранит значения от `0` до `255`. Место для хранения не может расти. Поэтому когда значение выходит за верхнюю границу, оно идёт по кругу. Оно возвращается снизу. Это _переполнение_:

```raku
my int8 $i = 127;
$i++;
say $i; # -128
```

Прибавьте единицу к самому большому `int8`. Вы не получите `128`, потому что `128` не помещается. Значение по кругу переходит к самому маленькому значению, `-128`. Беззнаковые типы тоже идут по кругу:

```raku
my uint8 $u = 255;
$u++;
say $u; # 0
```

Обычный `Int` — полная противоположность. Он просто растёт, сколько нужно. Он никогда не переполняется. Нативные типы фиксированного размера — это сделка. Вы соглашаетесь на фиксированный диапазон. Взамен хранение получается маленьким, быстрым и без сюрпризов. В этой сделке и есть весь смысл нативных типов фиксированного размера.

Вы знаете диапазон своих данных? Вам нужно быстрое и маленькое хранение? Тогда используйте нативный тип фиксированного размера. Например, храните байты двоичных данных в массиве `uint8`. В обычной арифметике числа могут расти без предела. Там используйте `Int`.
