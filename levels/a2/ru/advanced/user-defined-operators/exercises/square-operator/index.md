## Задача

Символом оператора может быть любой символ. Это может быть и символ Юникода. Определите **постфиксный** оператор `²`. Он возвращает квадрат своего операнда. Значит, `5²` означает `5 ** 2`. Потом напечатайте `5²`.

## Пример

Программа выводит:

```
25
```
