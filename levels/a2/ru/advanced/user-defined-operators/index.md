В Raku операторы — это просто подпрограммы с особыми именами. Поэтому вы можете делать свои операторы. Для этого вы используете названия категорий со страницы [Типы операторов Raku](/ru/advanced/operator-types). Это `prefix`, `infix`, `postfix` и так далее.

Чтобы объявить оператор, напишите `sub`. Имя состоит из трёх частей. Сначала идёт категория. Потом идёт двоеточие. Потом идёт символ оператора в угловых скобках. Вот новый инфиксный оператор. Его имя — `plus`:

```raku
sub infix:<plus>($a, $b) {
    $a + $b
}

say 3 plus 4; # 7
```

После этого вы пишете `plus` между двумя его операндами. Он работает точно как встроенный инфиксный оператор.

Постфиксный оператор стоит после своего операнда. Факториал — типичный пример. Вот он в виде постфиксного оператора `!`. Он использует [метаоператор редукции](/ru/advanced/metaoperators/reduction), который вы уже знаете:

```raku
sub postfix:<!>(Int $n) {
    [*] 1..$n
}

say 5!; # 120
```

Можно использовать не только буквы и знаки препинания ASCII. Символом оператора может быть любой символ. Этот префиксный оператор использует знак параграфа `§`. Он удваивает число:

```raku
sub prefix:<§>($x) {
    $x * 2
}

say §5; # 10
```

Свои операторы — сильный инструмент. Поэтому используйте их осторожно. Хороший оператор делает код похожим на язык самой задачи. Странный оператор только запутает следующего читателя.
