## Задача

`WHAT` не только описывает тип. Он возвращает сам объект типа. Объекты типов можно сравнивать оператором `===`.

Объявите две переменные. `$a` хранит целое число `42`. `$b` хранит строку `'x'`. Для каждой переменной посмотрите на её `WHAT`. Это тип `Int`? Напечатайте ответ.

## Пример

Программа печатает:

```
True
False
```
