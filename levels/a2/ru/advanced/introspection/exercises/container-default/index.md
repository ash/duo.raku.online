## Задача

У контейнера может быть значение по умолчанию. Вы задаёте его трейтом `is default`. Пока вы не присвоили значение, переменная возвращает это значение по умолчанию. `.VAR.default` тоже показывает его.

Объявите скаляр `$count`. Его значение по умолчанию должно быть `0`. Ничего ему не присваивайте. Напечатайте переменную. Потом напечатайте значение по умолчанию её контейнера. Обе строки должны показать `0`.

## Пример

Программа печатает:

```
0
0
```
