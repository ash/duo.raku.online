## Задача

Вот переменная с типом:

```raku
my Str $lang = 'Raku';
```

Напечатайте о ней три вещи. Каждую напечатайте на отдельной строке:

1. тип её значения;
2. тип её контейнера;
3. её имя вместе с сигилом.

## Пример

Программа печатает:

```
Str
Scalar
$lang
```
