`WHAT` — это псевдо-метод. Он даёт вам тип значения. Вы используете его почти как `.^name`:

```raku
my $var = 42;

say $var.^name;
say $var.WHAT;
```

Оба печатают тип, но выглядят немного по-разному. `.^name` даёт только имя. `WHAT` даёт сам тип как объект типа. Он показывает его в круглых скобках:

```
Int
(Int)
```

Возьмите переменную без ограничения типа. Сначала её тип — `Any`. Потом вы присваиваете значение. Теперь `^name` и `WHAT` оба показывают тип этого значения:

```raku
my $var;
say $var.^name; # Any
say $var.WHAT;  # (Any)

$var = 'Hello';
say $var.^name; # Str
say $var.WHAT;  # (Str)
```

С ограничением типа Raku сразу знает тип. Это так даже до того, как вы присвоите значение:

```raku
my Str $var;
say $var.^name; # Str
say $var.WHAT;  # (Str)

$var = 'Hello';
say $var.^name; # Str
say $var.WHAT;  # (Str)
```

## Сравнение объектов типов

`WHAT` возвращает сам объект типа. Поэтому можно сравнить два объекта типов. Для этого используйте оператор `===`. Это оператор _тождества значений_. Он проверяет, одно ли значение с обеих сторон. У каждого типа только один объект типа. Поэтому `===` легко проверяет, одинаковый ли тип у двух значений:

```raku
my $a = 42;
my $b = 100;

say $a.WHAT === $b.WHAT; # True  — both are Int
say $a.WHAT === Int;     # True
say $a.WHAT === Str;     # False
```

`==` сравнивает числа. А `===` сравнивает тождество. Поэтому он работает прямо с объектами типов. Он работает и с другими значениями.
