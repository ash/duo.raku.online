Вы можете писать свои модули. Но сообщество Raku тоже публикует много модулей. Есть модули для многих задач, от веб-фреймворков до форматов данных. Вы можете установить их и использовать в своих программах.

## Установка с помощью `zef`

Вы устанавливаете модули с помощью `zef`. `zef` — это стандартный менеджер модулей. Он идёт вместе с Rakudo. Чтобы установить модуль, передайте `zef` имя модуля:

```console
$ zef install JSON::Fast
```

`zef` скачивает модуль. Ещё он скачивает всё, что нужно модулю. Дальше он запускает тесты модуля. Потом он устанавливает модуль. После этого модуль сам попадает в путь поиска. Поэтому программа может загрузить его просто через `use`. Вам не нужна опция `-I`:

```raku
use JSON::Fast;
```

Вы также можете искать в экосистеме. Экосистема — это все модули, которые публикуют люди. И вы можете обновлять или удалять модули:

```console
$ zef search Test
$ zef uninstall JSON::Fast
```

## Откуда берутся модули

Опубликованные модули находятся в _экосистеме_ Raku. Вы можете посмотреть её на сайте [raku.land](https://raku.land). На сайте есть список доступных дистрибутивов. В дистрибутиве есть один или несколько модулей. Ещё сайт показывает их документацию.

## `META6.json`

У дистрибутива для других людей есть файл с описанием. Файл называется `META6.json`. В нём есть имя и версия дистрибутива. Там есть список модулей дистрибутива. Ещё там есть список других дистрибутивов, которые ему нужны. `zef` читает этот файл. Поэтому он знает, что устанавливать. Ещё он знает, как части связаны между собой. Может быть, вы захотите опубликовать свой модуль. Тогда добавьте к нему правильный `META6.json`. С этим файлом все остальные смогут установить ваш модуль.
