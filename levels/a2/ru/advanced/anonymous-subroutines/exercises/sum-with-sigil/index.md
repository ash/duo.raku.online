## Задача

У остроконечного блока может быть больше одного параметра. С сигилом `&` его можно вызвать по имени. Напишите остроконечный блок с двумя параметрами. Он складывает два своих аргумента. Сохраните его в переменной `&add`. У этой переменной сигил `&`. Потом вызовите его как `add(2, 3)`, без сигила. Выведите результат.

## Пример

Программа выводит:

```
5
```
