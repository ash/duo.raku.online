Вот один способ решить задачу.

## Код

```raku
my $factor = 3;
my $scale = -> $x { $x * $factor };

say $scale(7);
```

🦋 Исходный код можно найти в файле [triple-it.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/anonymous-subroutines/triple-it.raku).

## Вывод

```
21
```

## Комментарии

1. У остроконечного блока только один параметр, `$x`. Но он использует ещё и `$factor`. Эта переменная пришла из кода вокруг блока. Блок, который держит такие переменные, — это замыкание.

1. `$factor` равен `3`, поэтому `$scale(7)` даёт `21`. Теперь измените `$factor`. Тогда тот же блок использует новое значение:

```raku
$factor = 5;
say $scale(7); # 35
```

Замыкание хранит саму *переменную*. Оно не хранит старое значение переменной. Поэтому следующий вызов видит новый `$factor`. Он возвращает `35`.
