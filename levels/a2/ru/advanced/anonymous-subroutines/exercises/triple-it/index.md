## Задача

Анонимная подпрограмма — это замыкание. Она помнит переменные из того места, где вы её пишете. Создайте переменную `$factor` со значением `3`. Потом напишите остроконечный блок. Он умножает свой аргумент на `$factor`. Не пишите в блоке число `3`. Сохраните блок в `$scale`. Вызовите `$scale(7)` и выведите результат.

## Пример

Программа выводит:

```
21
```
