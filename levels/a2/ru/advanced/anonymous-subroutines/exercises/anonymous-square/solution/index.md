Вот один способ решить задачу.

## Код

```raku
say (1, 2, 3).map(sub ($x) { $x * $x });
```

🦋 Исходный код можно найти в файле [anonymous-square.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/anonymous-subroutines/anonymous-square.raku).

## Вывод

```
(1 4 9)
```

## Комментарии

1. У подпрограммы `sub ($x) { $x * $x }` нет имени. Программа никогда не хранит её в переменной. Она сразу передаёт её в `map` как аргумент.

1. `map` использует её для каждого элемента `1, 2, 3`. Она умножает каждое число само на себя. Результат — `(1 4 9)`. Чаще всего анонимную подпрограмму пишут именно для этого. Её передают сразу, как здесь.
