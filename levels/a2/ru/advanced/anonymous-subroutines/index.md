Подпрограмме не нужно имя. Подпрограмма без имени — _анонимная_. Вы пишете её как обычную подпрограмму, только без имени. Обычно вы храните её в переменной. Тогда её можно вызвать позже.

```raku
my $double = sub ($x) {
    $x * 2
};

say $double(5); # 10
```

Переменная `$double` хранит подпрограмму. `$double(5)` вызывает подпрограмму с аргументом `5`.

## Остроконечные блоки

В Raku можно записать то же самое короче. Это _остроконечный блок_ (pointy block). Перед параметрами у него стоит стрелка `->`. Слово `sub` не нужно. Скобки вокруг параметров тоже не нужны:

```raku
my $double = -> $x {
    $x * 2
};

say $double(5); # 10
```

Так обычно пишут небольшую анонимную подпрограмму.

## Сигил `&`

Может быть, для вызова вам нужно имя, а не переменная с `$`. Тогда создайте переменную с сигилом `&`. Теперь её можно вызвать без сигила. Это работает так же, как обычная подпрограмма:

```raku
my &triple = -> $x {
    $x * 3
};

say triple(4); # 12
```

## Передаём её другой функции

Анонимную подпрограмму не обязательно хранить в переменной. Это просто значение. Поэтому её можно сразу передать функции. Некоторым функциям нужно такое значение, например `map`, `grep` или `sort`:

```raku
say (1, 2, 3).map(-> $x { $x * 2 }); # (2 4 6)
```

Здесь остроконечный блок — это анонимная подпрограмма. `map` вызывает его один раз для каждого элемента. На самом деле вы делаете это постоянно. Вы часто передаёте в `map` и `grep` блок `{ ... }` или `-> $x { ... }`. Каждый из них — небольшая анонимная подпрограмма. Вы пишете её прямо там, где она нужна. Вы не даёте ей имя заранее.
