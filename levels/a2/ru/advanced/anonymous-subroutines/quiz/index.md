Что напечатает эта программа?

```raku
(-> $a, $b { $a * $b })(3, 4).say
```

{:.quiz}
1 | 12
0 | 7
0 | 34
0 | an error

{% include quiz.html %}

<div class="extended-explanation">

У остроконечного блока может быть несколько параметров. `-> $a, $b` принимает два. Здесь программа не хранит блок в переменной. Блок стоит в скобках. Программа сразу вызывает его с `(3, 4)`. Поэтому `$a` получает `3`, а `$b` получает `4`. Блок умножает их. Результат — `12`. Потом `.say` в конце печатает его.

</div>
