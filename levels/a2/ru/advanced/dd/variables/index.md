---
title: Вывод переменных
---

{% include menu.html %}

Чтобы увидеть значение переменной, вызовите `dd`. Это похоже на `say`:

```raku
my $var = 42;
dd $var;
```

`dd` показывает значение. Ещё она показывает имя переменной:

```console
$var = 42
```

У переменной может быть объявленный тип. Тогда `dd` показывает и тип. Сравните вывод этой программы и прошлой:

```raku
my Int $var = 42;
dd $var;
```

```console
Int $var = 42
```

В этом главное отличие от `say`. Вызовите `dd` один раз для скаляра. Она показывает вам имя переменной. Ещё она показывает тип данных, если Raku его знает. Поэтому можно поставить в программу несколько вызовов `dd`. Вы всё равно знаете, какой вывод от какой переменной.

Можно выводить и большие структуры данных, например массивы или хэши. Тогда `dd` печатает значение в форме, похожей на код:

```raku
my @arr = 10, 20, [1, 2, 3], 30;
dd @arr;
```

```console
[10, 20, [1, 2, 3], 30]
```

Обратите внимание: внутренний массив хорошо видно. Но имя переменной `dd` здесь не печатает. С хэшами это работает так же. `dd` печатает ключи хэша в отсортированном порядке:

```raku
my %hash =
    gamma => 'g',
    alpha => 'a',
    beta  => 'b';
dd %hash;
```

```console
{:alpha("a"), :beta("b"), :gamma("g")}
```
