## Задача

Объявите переменную с типом `Int`: `my Int $n = 42;`. Выведите её с помощью `dd`. Посмотрите на вывод. У переменной без типа вывод другой.

## Пример

Программа печатает вот это в стандартный поток ошибок:

```
Int $n = 42
```
