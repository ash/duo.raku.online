## Задача

Вот вложенная структура данных. В ней одни данные лежат внутри других:

```raku
my @data = 'Raku', [1, 2, 3], (key => 'value');
```

Сделайте с ней два действия:

1. Выведите `@data` с помощью `dd` в форме для программистов.
2. Напечатайте ту же форму в виде строки. Поставьте перед ней текст `Structure: `.

## Пример

Программа печатает две строки. Они очень похожи:

```
["Raku", [1, 2, 3], :key("value")]
Structure: ["Raku", [1, 2, 3], :key("value")]
```
