---
title: Сигнатура функции
---

{% include menu.html %}

Иногда вы вызываете `dd` без аргументов внутри подпрограммы. Тогда `dd` печатает сигнатуру подпрограммы. Это её имя и её параметры, если они есть. Посмотрите на этот пример с двумя подпрограммами:

```raku
sub f1 {
    dd
}

f1();

sub f2($x) {
    dd
}

f2(42);
```

Программа печатает сигнатуры. Никаких значений она не печатает:

```console
sub f1()
sub f2($x)
```

Это очень полезно с мультифункциями. Это несколько функций с одним и тем же именем. Здесь `dd` говорит вам, какой вариант программа вызывает на самом деле:

```raku
multi sub g {
    dd
}

multi sub g($x) {
    dd
}

g();
g(42);
```

Каждый раз вывод называет вариант, который подходит:

```console
sub g()
sub g($x)
```
