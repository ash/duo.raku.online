## Задача

В программе может быть больше одного фейзера `END`. Тогда они выполняются в **обратном** порядке. Последний в коде выполняется первым. Это называют «последним пришёл — первым ушёл».

Напишите два фейзера `END`. Первый выводит `first END`. Второй выводит `second END`. После них напишите простой `say 'body'`. В каком порядке будет вывод? Сначала угадайте его. Потом получите этот вывод своей программой.

## Пример

Программа выводит:

```
body
second END
first END
```
