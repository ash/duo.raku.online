## Задача

Фейзер `END` выполняется после основного кода. Поэтому он видит *последние* значения ваших переменных. Это делает его отличным местом для итога.

Создайте счётчик `$count` со значением `0`. Напишите фейзер `END`, который выводит `processed $count items`. Поставьте фейзер перед основным кодом. Затем в основном теле прибавьте 1 к счётчику три раза. Используйте для этого цикл. Итог должен показать последнее значение счётчика. Он не должен показывать старое значение из строки с фейзером.

## Пример

Программа выводит:

```
processed 3 items
```
