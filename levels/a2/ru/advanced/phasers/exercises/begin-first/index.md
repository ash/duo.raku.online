## Задача

Фейзер `BEGIN` — это не только блок, который выполняется рано. Это также *выражение*. Raku вычисляет его значение один раз, когда компилирует программу. Потом значение остаётся в программе и не меняется.

Создайте переменную `$compiled`. Задайте её первое значение с помощью `BEGIN { 2 + 3 }`. Потом выведите переменную. Raku вычисляет `2 + 3` во время компиляции. Но сохранённое значение всё равно можно использовать, когда программа работает.

## Пример

Программа выводит:

```
5
```
