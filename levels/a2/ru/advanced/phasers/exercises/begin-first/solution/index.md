Вот один способ решить задачу.

## Код

```raku
my $compiled = BEGIN { 2 + 3 };

say $compiled;
```

🦋 Найдите программу в файле [begin-first.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/phasers/begin-first.raku).

## Вывод

```
5
```

## Комментарии

1. `BEGIN { 2 + 3 }` выполняется во время компиляции. Он даёт `5`. Здесь блок `BEGIN` — это выражение. Поэтому он возвращает своё значение. Программа кладёт это значение в `$compiled`.

1. Вычисление происходит только один раз, во время компиляции. Когда программа работает, в `$compiled` просто лежит постоянное значение `5`. Поэтому `BEGIN` можно использовать, чтобы вычислять значения заранее. Он нужен не только для раннего вывода.
