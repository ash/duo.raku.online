## Задача

Напишите тестовый файл. Используйте `plan`, а не `done-testing`. С помощью `plan` скажите в начале, что в файле ровно две проверки. Сделайте эти две проверки:

1. С помощью `is-deeply` проверьте, что список `3, 1, 2` после сортировки даёт `[1, 2, 3]`.
1. С помощью `is` проверьте, что `10 % 3` равно `1`.

Напишите своё короткое описание для каждой проверки.

## Пример

Пусть описания будут `sorted` и `remainder`. Тогда программа печатает:

```
1..2
ok 1 - sorted
ok 2 - remainder
```
