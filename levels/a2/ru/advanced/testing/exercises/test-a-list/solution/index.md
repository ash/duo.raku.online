Вот один способ решить задачу.

## Код

```raku
use Test;

plan 2;

my @sorted = (3, 1, 2).sort;
is-deeply @sorted, [1, 2, 3], 'sorted';

is 10 % 3, 1, 'remainder';
```

🦋 Исходный код можно найти в файле [test-a-list.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/testing/test-a-list.raku).

## Вывод

```
1..2
ok 1 - sorted
ok 2 - remainder
```

## Комментарии

1. `plan 2` указывает количество до запуска тестов. Поэтому строка `1..2` идёт первой. Файл может запустить другое число проверок. Тогда весь набор тестов не проходит. `done-testing` не может защитить вас так.

1. `is-deeply` проверяет, что два списка точно равны, и их типы тоже. Сортировка `3, 1, 2` даёт `1, 2, 3`. Это совпадает.

1. `is` проверяет, что два значения равны. Если они не равны, он показывает оба значения. Здесь `10 % 3` равно `1`. Это ожидаемое значение. Поэтому второй тест тоже проходит.
