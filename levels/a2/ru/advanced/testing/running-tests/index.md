Один тестовый файл — это просто программа на Raku. Поэтому его можно запустить как любую программу:

```
raku t/01-basic.rakutest
```

Он печатает на экран результат в формате TAP. Но у вас может быть больше одного-двух файлов. Тогда вам нужно _средство запуска тестов_. Оно запускает все тесты в директории. Потом оно даёт короткую сводку результатов. В Raku средство запуска тестов — это `prove6`:

```
prove6 t/
```

Эта команда запускает каждый тестовый файл в `t/`. Она показывает, сколько файлов и тестов прошло. В конце она даёт один результат для всего: успех или неудача. Это читать намного легче, чем сырой TAP из каждого файла.

У дистрибутива может быть `META6.json`. Тогда инструмент для модулей запускает его тесты за вас:

```
zef test .
```

`zef test` находит директорию `t/`. Он запускает все тесты и показывает результат. То же самое происходит само, перед тем как кто-то устанавливает дистрибутив. Поэтому у тестов две задачи. Вы запускаете их с помощью `prove6`, пока работаете над кодом. А экосистема запускает их, перед тем как кто-то установит дистрибутив. Так она проверяет дистрибутив.

> У тестовых файлов расширение `.rakutest` или `.t`. Обычно их имена начинаются с числа, например `t/01-basic.rakutest`.
