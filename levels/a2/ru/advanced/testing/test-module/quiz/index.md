Одна функция в модуле `Test` проходит, когда условие истинно. Условие равно `True` или `False`. Какая это функция?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` принимает условие. Эта проверка проходит, когда условие истинно. `is` сравнивает значение, которое вы получаете, со значением, которое вы ждёте. `plan` говорит, сколько тестов ждать. `done-testing` завершает файл и печатает план.

</div>
