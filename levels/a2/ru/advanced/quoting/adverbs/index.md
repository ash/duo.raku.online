Работу конструкции цитирования можно изменить. Для этого есть _наречия_. У конструкции цитирования есть несколько возможностей. Например, она может интерполировать скаляры. Она может выполнять код в фигурных скобках. Она может обрабатывать обратные слэши. У каждой возможности есть своё наречие. Наречие включает или выключает эту одну возможность. Поэтому можно начать с `q` или `Q`. Потом вы добавляете обратно ровно те возможности, которые вам нужны.

Вот несколько частых наречий:

* `:s` / `:scalar` — вставить значения скалярных переменных (`$x`) в строку
* `:c` / `:closure` — выполнить код в `{ … }` и вставить результат в строку
* `:b` / `:backslash` — обработать управляющие последовательности с обратным слэшем, например `\n`

Добавьте одно наречие к `q`. Тогда у `q` появляется одна возможность. Например, пусть он выполняет код, но больше ничего:

```raku
say q/result: {3 * 4}/;   # result: {3 * 4}  — plain q leaves the block untouched
say q:c/result: {3 * 4}/; # result: 12        — :c runs the block
```

С простым `q` Raku печатает `{ 3 * 4 }` как есть. Только `:c` выполняет блок. Тогда Raku вставляет результат в строку. А `$переменная` всё равно остаётся как есть. Посмотрите на разделители здесь: `/…/`. Разделители — это символы вокруг текста. В качестве разделителей можно использовать и `{…}`. Ошибки не будет, потому что компилятор правильно считает скобки. Но тогда внутренний `{ 3 * 4 }` — просто часть текста. Это не код. Поэтому `:c` его не выполняет, и он остаётся как есть. В тексте есть блок `{ … }`? Тогда не используйте `{…}` как разделители. Используйте другие разделители. Тогда код в фигурных скобках выполнится. Ещё к `Q` можно добавить интерполяцию скаляров. Без неё `Q` оставляет весь текст как есть:

```raku
my $name = 'Anna';
say Q:s{Hi, $name}; # Hi, Anna
```

Наречия могут и **выключать** возможности. Для этого напишите `!`. Здесь мы используем `qq`, но `$` остаётся обычным символом:

```raku
my $price = 5;
say qq:!s{costs $price dollars}; # costs $price dollars
```

`qq` — то же самое, что `Q` со всеми включёнными наречиями интерполяции. `q` — то же самое, что `Q` с меньшим числом включённых наречий. С наречиями вы сами выбираете каждую возможность между этими двумя концами.
