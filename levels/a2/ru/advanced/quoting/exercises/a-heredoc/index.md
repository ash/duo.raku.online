## Задача

Напишите письмо, которое подтверждает заказ. Используйте heredoc, который *интерполирует*. Соберите письмо из нескольких переменных. Это имя покупателя `$name`, товар `$item`, цена `$price` и количество `$count`. Это цена за один товар. Heredoc вставляет значения переменных. Он *также* находит итоговую сумму. Для этого внутри текста есть блок `{ … }` (`$count * $price`).

Сделайте отступ у тела heredoc'а. Оно должно стоять ровно с кодом вокруг него. Поставьте закрывающий терминатор с тем же отступом, что и текст. Тогда в выводе не будет отступов. Напечатайте результат.

## Пример

Возьмите `$name = 'Anna'`, `$item = 'Raku Book'`, `$price = 25` и `$count = 3`. Тогда программа печатает вот это. В начале строк нет пробелов:

```
Dear Anna,
You ordered 3 copies of "Raku Book".
That comes to 75 dollars.
Thank you!
```
