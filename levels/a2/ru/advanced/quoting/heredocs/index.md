_Heredoc_ — это форма цитирования для текста в несколько строк. У неё нет разделителей вокруг текста. Вместо них вы даёте слово-терминатор с `:to`. Терминатор отмечает конец. Текст начинается на следующей строке. Он идёт до строки, где есть только это слово:

```raku
my $text = q:to/END/;
Hello,
World!
END

print $text;
```

Это выводит:

```
Hello,
World!
```

Терминатор отмечает конец текста. Здесь это `END`, но можно взять любое слово. Посмотрите на `print`. Текст сохраняет перевод строки перед терминатором. Поэтому текст уже заканчивается переводом строки. `say` добавляет второй. Тогда в конце получается пустая строка. Этот heredoc начинается с `q:to`. Поэтому текст не интерполируется. Чтобы интерполировать переменные, используйте `qq:to`:

```raku
my $name = 'Anna';

my $greeting = qq:to/EOF/;
Dear $name,
Welcome!
EOF

print $greeting;
```

Вот полезная деталь. Посмотрите на **отступ закрывающего терминатора**. Raku убирает его из каждой строки текста. Поэтому у heredoc'а можно сделать такой же отступ, как у кода вокруг него. Этот отступ не попадает в строку:

```raku
sub greeting {
    return q:to/END/;
        Hello,
        World!
        END
}

print greeting;
```

Это печатает те же `Hello,` и `World!`, что и первый пример. Здесь у закрывающего `END` впереди восемь пробелов. Поэтому Raku убирает восемь пробелов из каждой строки. Функция возвращает просто `Hello,\nWorld!`. В начале пробелов нет.

Закрывающий терминатор решает, сколько пробелов убирает Raku. Поэтому в каждой строке текста нужно хотя бы столько же пробелов. Может быть, в какой-то строке пробелов меньше. Тогда Raku не может убрать их все. Он предупреждает: *Asked to remove 8 spaces, but the shortest indent is 4 spaces*. Избегайте этого предупреждения. Делайте у терминатора отступ не больше, чем у каждой строки текста. Heredoc'и — естественный выбор для шаблонов и сообщений. На самом деле они хороши для любого текста в несколько строк.
