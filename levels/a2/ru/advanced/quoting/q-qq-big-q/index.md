Есть три базовых оператора цитирования. Они меняют текст внутри себя в разной степени:

* `q` — как одинарные кавычки: почти весь текст остаётся как есть
* `qq` — как двойные кавычки: Raku интерполирует переменные и управляющие последовательности
* `Q` — самая буквальная форма: Raku **ничего** не меняет

Каждый из них берёт текст между двумя разделителями. Разделители — это символы вокруг текста. Вы уже знаете `'…'`. Это короткая форма `q`. А `"…"` — короткая форма `qq`:

```raku
my $name = 'Anna';

say q{Hello $name};  # Hello $name
say qq{Hello $name}; # Hello Anna
```

`q` не меняет `$name`. `qq` интерполирует его. Управляющие последовательности с обратным слэшем, например `\n`, работают так же. Только `qq` и `"…"` превращают `\n` в настоящий перевод строки. И `q`, и `Q` оставляют его двумя символами: `\` и `n`:

```raku
say qq{line\nbreak}; # line<newline>break
say q{line\nbreak};  # line\nbreak
say Q{line\nbreak};  # line\nbreak
```

Так в чём разница между `q` и `Q`? `q` похож на одинарные кавычки. Он всё же обрабатывает *небольшой* набор управляющих последовательностей. Двойной обратный слэш `\\` превращается в один обратный слэш. Ещё можно экранировать закрывающий разделитель обратным слэшем. Но простая форма `Q` не меняет **совсем ничего**:

```raku
say q{a\\b}; # a\b   — q collapses the escaped backslash
say Q{a\\b}; # a\\b  — Q keeps both characters
```

Можно использовать любые разделители: `q{…}`, `q[…]`, `q/…/`, `q!…!`. Это удобно, когда в самом тексте есть кавычки. Эти три оператора — основа. Следующая тема показывает [_наречия_](/ru/advanced/quoting/adverbs). С ними вы точно выбираете, какие возможности включены.
