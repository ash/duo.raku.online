## Задача

Вложенная подпрограмма — это *замыкание*. Она видит переменные подпрограммы вокруг неё. Напишите подпрограмму `greet($name)`. Внутри неё определите помощника `message`. Помощник не принимает **никаких** аргументов. Он возвращает `"Hello, $name!"`. Он берёт `$name` прямо из `greet` вокруг него. Внутри `greet` выведите результат `message`. Потом вызовите `greet('Anna')`.

## Пример

Программа выводит:

```
Hello, Anna!
```
