## Задача

Напишите подпрограмму `stats`. Внутри неё определите **вложенную** вспомогательную подпрограмму `double`. Она возвращает свой аргумент, умноженный на два. Внутри `stats` используйте эту подпрограмму. Выведите значение `double(3) + double(5)`.

Затем вызовите `stats`.

## Пример

Программа выводит:

```
16
```
