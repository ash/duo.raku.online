Подпрограмму можно определить _внутри_ другой подпрограммы. Это вложенная подпрограмма. Она — обычная подпрограмма. Но видеть и использовать её можно только внутри внешней подпрограммы.

```raku
sub outer {
    sub inner {
        say 'I am the inner subroutine';
    }

    inner;
}

outer;
```

Программа выводит:

```
I am the inner subroutine
```

Здесь мы создаём `inner` внутри `outer`. Потом `outer` вызывает её. Это работает. Имя `inner` известно во всём теле `outer`.

Но вне `outer` имени `inner` не существует. Эта программа не компилируется:

```raku
sub outer {
    sub inner { 42 }
}

inner; # error: Undeclared routine: inner
```

Иногда вспомогательная подпрограмма нужна только одной подпрограмме. Тогда вложенность полезна. Поместите её внутрь этой подпрограммы. Так видно, что она закрыта для других. Кроме того, никакой другой код не может вызвать её по ошибке.
