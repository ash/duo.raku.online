Иногда программа должна выбрать один из нескольких вариантов. Цепочка проверок `if` и `elsif` может стать длинной. Ещё в ней повторяется одно и то же. В таком случае `given`/`when` часто понятнее. Это похоже на оператор `switch` в других языках.

Блок `given` берёт значение. Он делает это значение _топиком_. Топик — это специальная переменная `$_`. Потом Raku сравнивает каждый блок `when` с топиком. Выполняется первый `when`, который совпадает:

```raku
my $n = 2;

given $n {
    when 1 { say 'one' }
    when 2 { say 'two' }
    when 3 { say 'three' }
}
```

Эта программа печатает:

```
two
```

В некоторых других языках есть оператор `switch`. После совпадения он может перейти к следующему случаю. Raku так не делает. Когда `when` совпадает, выполняется его блок. Потом блок `given` заканчивается. Raku не проверяет остальные блоки `when`.

## Блок `default`

Блок `default` выполняется, когда не совпал ни один блок `when`. Он работает как часть `else` в операторе `if`:

```raku
my $n = 5;

given $n {
    when 1 { say 'one' }
    when 2 { say 'two' }
    default { say 'many' }
}
```

`$n` не равно `1` и не равно `2`. Поэтому программа печатает:

```
many
```
