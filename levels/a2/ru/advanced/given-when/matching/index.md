Блок `when` не только проверяет, равны ли два значения. Он делает _умное сопоставление_ (smart match). Он сравнивает топик со значением, которое вы даёте. Поэтому можно сопоставлять с диапазонами, типами и условиями. Можно не ограничиваться отдельными значениями.

## Диапазоны

Диапазон совпадает, когда топик лежит внутри него. Поэтому `given`/`when` хорошо подходит, чтобы делить числа на группы:

```raku
my $score = 75;

given $score {
    when 90..100 { say 'A' }
    when 80..89  { say 'B' }
    when 70..79  { say 'C' }
    default      { say 'F' }
}
```

Значение `75` входит в диапазон `70..79`. Поэтому программа печатает:

```
C
```

## Типы

Тип совпадает, когда у топика этот тип. Поэтому можно выбирать действие по виду значения:

```raku
my $value = 'Raku';

given $value {
    when Int { say 'an integer' }
    when Str { say 'a string' }
}
```

В `$value` лежит строка. Поэтому программа печатает:

```
a string
```

## Условия

Можно также написать сравнение напрямую. Внутри `when` топик — это `$_`. Поэтому условие вроде `$_ < 0` совпадает, когда оно истинно:

```raku
my $n = -7;

given $n {
    when $_ < 0 { say 'negative' }
    when 0      { say 'zero' }
    default     { say 'positive' }
}
```

Здесь совпадает первый `when`. Программа печатает:

```
negative
```
