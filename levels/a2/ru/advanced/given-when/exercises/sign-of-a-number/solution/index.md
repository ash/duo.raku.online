Вот один способ решить задачу.

## Код

```raku
my $n = 12;

given $n {
    when 0      { say 'zero' }
    when $_ %% 2 { say 'even' }
    default     { say 'odd' }
}
```

🦋 Исходный код можно найти в файле [sign-of-a-number.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/given-when/sign-of-a-number.raku).

## Вывод

```
even
```

## Комментарии

1. `when 0` совпадает только с одним значением, с нулём. Он идёт первым. Ноль тоже чётный, но мы хотим показать его отдельно.

1. `when $_ %% 2` — это условие. Здесь `$_` — это топик из `given`. Оператор `%%` проверяет, делится ли он на два без остатка. Значение `12` не равно нулю. Но оно делится на два. Поэтому программа печатает `even`.

1. `default` нужен для всех остальных чисел. Они не ноль и не чётные. Значит, это нечётные числа.
