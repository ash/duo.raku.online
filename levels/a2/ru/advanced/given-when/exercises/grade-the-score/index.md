## Задача

Используйте `given`/`when`. Возраст — это число в коде. Напечатайте этап жизни для этого возраста. Используйте эти группы:

* `child` для 0–12,
* `teenager` для 13–19,
* `adult` для 20–64,
* `senior` для 65 и старше.

Возраст меньше нуля не имеет смысла. Поэтому для любого числа меньше нуля печатайте `invalid`. Проверьте этот случай первым, до диапазонов.

## Пример

Если возраст `30`, программа печатает:

```
adult
```
