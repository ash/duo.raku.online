Вот один способ решить задачу.

## Код

```raku
my $age = 30;

given $age {
    when $_ < 0 { say 'invalid' }
    when 0..12  { say 'child' }
    when 13..19 { say 'teenager' }
    when 20..64 { say 'adult' }
    default     { say 'senior' }
}
```

🦋 Исходный код можно найти в файле [grade-the-score.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/given-when/grade-the-score.raku).

## Вывод

```
adult
```

## Комментарии

1. В этом решении два вида `when`. Первый — это *условие*, `$_ < 0`. Здесь `$_` — это топик из `given`. Это условие ловит возрасты, которые не имеют смысла. Остальные блоки `when` — это *диапазоны*. Они делят правильные возрасты на этапы.

1. Порядок важен. Проверка отрицательного возраста идёт первой. Поэтому она выполняется раньше всех диапазонов. Значение `30` входит в `20..64`. Поэтому программа печатает `adult`.

1. Блок `default` нужен для любого возраста от 65 и старше. Ни один диапазон в списке не включает эти возрасты.

Есть и другой способ. Пусть `default` ловит *неправильный* ввод. Перечислите все известные этапы. Запишите `senior` как условие `$_ >= 65`. Всё остальное неправильно, например отрицательный возраст:

```raku
given $age {
    when 0..12    { say 'child' }
    when 13..19   { say 'teenager' }
    when 20..64   { say 'adult' }
    when $_ >= 65 { say 'senior' }
    default       { say 'invalid' }
}
```

Здесь `default` правда значит «ничего из перечисленного выше». Какой вариант лучше? Выбирать вам. Неправильный случай бывает редко? Тогда поставьте проверку первой. Вы ясно перечисляете все правильные этапы? Тогда сделайте неправильный случай блоком `default`.
