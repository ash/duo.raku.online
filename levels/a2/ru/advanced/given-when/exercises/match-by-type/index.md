## Задача

`when` может совпадать с *типом*, а не только со значением. В переменной лежит число `3.14`. С помощью `given`/`when` скажите, какого вида это значение. Для `Int` напечатайте `integer`. Для `Rat` напечатайте `rational`. Для `Str` напечатайте `string`.

## Пример

Программа печатает:

```
rational
```
