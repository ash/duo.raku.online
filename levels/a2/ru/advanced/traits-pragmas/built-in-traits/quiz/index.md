Подпрограмма хочет **изменить переменную вызывающей стороны** через параметр. Какой типаж позволяет это сделать?

{:.quiz}
1 | `is rw`
0 | `is copy`
0 | `is default`
0 | ни один — параметры по умолчанию доступны для записи

{% include quiz.html %}

<div class="extended-explanation">

Обычно параметр доступен только для чтения. Поэтому обычному параметру нельзя присвоить новое значение. `is rw` связывает параметр с самой переменной вызывающей стороны. Поэтому изменение внутри подпрограммы видно снаружи. `is copy` работает по-другому. Он даёт вам *копию*, которую можно менять. Переменная вызывающей стороны остаётся прежней.

</div>
