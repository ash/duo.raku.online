Вы добавляете _типаж_ с помощью ключевого слова `is`, сразу после объявления. Типаж выполняется во время компиляции. Он меняет постоянное свойство той вещи, у которой есть этот типаж. В Raku много типажей. Некоторые из них вы уже использовали.

Обычно параметры подпрограммы доступны **только для чтения**. Внутри подпрограммы им нельзя присвоить новые значения. Типаж `is copy` даёт вам личную копию аргумента. Эту копию можно менять. Изменение остаётся внутри подпрограммы. Переменная вызывающей стороны остаётся прежней:

```raku
sub greet($name is copy) {
    $name = "dear $name";
    say "Hello, $name!";
}

my $who = 'Anna';
greet($who); # Hello, dear Anna!
say $who;    # Anna — the caller's own variable is untouched
```

Типаж `is rw` идёт дальше. Он связывает параметр с переменной вызывающей стороны. Вы меняете параметр внутри подпрограммы. Тогда изменение видно и снаружи:

```raku
sub bump($n is rw) {
    $n++;
}

my $x = 10;
bump($x);
say $x; # 11
```

Без одного из этих типажей `$n++` даёт ошибку. Это потому, что параметр доступен только для чтения.

Другой распространённый типаж задаёт значение по умолчанию:

```raku
my $port is default(8080);
say $port; # 8080
```

Здесь `is default` даёт переменной значение по умолчанию. У переменной это значение, когда в ней нет ничего другого. Есть много встроенных типажей: `is rw`, `is copy`, `is default` и другие. Каждый из них добавляет объявлению одно особое поведение. Это происходит во время компиляции. Следующая тема показывает, что список типажей не закрыт. [Вы можете делать свои типажи](/ru/advanced/traits-pragmas/writing-a-trait).
