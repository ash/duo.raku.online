В Raku прагма `strict` включена по умолчанию. Вы не объявляете переменную, но присваиваете ей значение. Например, `$x = 42`. Что происходит?

{:.quiz}
1 | Это ошибка времени компиляции
0 | Он молча создаёт `$x`
0 | Он выводит предупреждение, но работает
0 | Он устанавливает `$x` в `Nil`

{% include quiz.html %}

<div class="extended-explanation">

`strict` включена по умолчанию. С ней вы должны сначала объявить каждую переменную с помощью `my`. Поэтому `$x = 42` без `my` не компилируется. Ошибка такая: *Variable '$x' is not declared*. С `no strict` прагма выключена. Тогда присваивание работает.

</div>
