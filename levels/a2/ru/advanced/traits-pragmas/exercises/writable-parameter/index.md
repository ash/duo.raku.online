## Задача

Обычно параметры подпрограммы доступны только для чтения. Поэтому подпрограмма не может изменить переменную вызывающей стороны. Типаж `is rw` убирает это ограничение.

Напишите подпрограмму `double`. У неё один параметр с типажом `is rw`. Подпрограмма удваивает сам параметр: `$n *= 2`. Вызовите `double` с переменной, в которой лежит `21`. Потом выведите переменную. Теперь она равна `42`.

## Пример

Программа выводит:

```
42
```
