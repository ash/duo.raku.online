## Задача

Ваш собственный типаж может не только быть или не быть. Он может также принимать аргумент. Напишите типаж `is role(...)`. Он принимает строку. Эта строка — роль подпрограммы. Типаж сохраняет роль в хеше. Ключ — это имя подпрограммы.

Добавьте `is role('admin')` к подпрограмме `login`. Потом выведите сохранённую роль для `login`.

## Пример

Программа выводит:

```
admin
```
