Вот один способ решить задачу.

## Код

```raku
no strict;

$a = 10;
$b = 20;
say $a + $b;
```

🦋 Исходный код можно найти в файле [no-strict.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/traits-pragmas/no-strict.raku).

## Вывод

```
30
```

## Комментарии

1. `no strict` выключает одно правило. Правило говорит, что все переменные нужно объявлять. Поэтому можно присвоить значения `$a` и `$b` без `my`. С обычной `strict` эти строки дают ошибки во время компиляции.

1. После присваивания переменные работают как обычно. Поэтому `$a + $b` равно `30`. Это изменение правила лексическое. Оно действует только до конца текущей области видимости. Это область видимости с `no strict`.

1. Это только демонстрация. Мы не советуем так делать на практике. `strict` включена по умолчанию по важной причине. Она находит опечатки в именах переменных во время компиляции. В настоящем коде оставляйте её включённой. Объявляйте переменные с помощью `my`.
