В разделе «Основы» вы использовали `MAIN`, [чтобы получать аргументы командной строки](/ru/essentials/the-main-function/reading-command-line-arguments). Raku делает для вас с `MAIN` больше. Он не только передаёт значения.

## Сообщение об использовании

Иногда аргументы командной строки не подходят к сигнатуре `MAIN`. Сигнатура — это список её параметров. Тогда Raku не выполняет тело. Вместо этого он выводит _сообщение об использовании_ (usage message). Raku сам создаёт это сообщение. Сообщение показывает, как запускать программу.

Посмотрите на эту программу:

```raku
sub MAIN($name) {
    say "Hello, $name!";
}
```

Запустите её правильно. Тогда она здоровается с человеком:

```console
$ raku hello.raku Anna
Hello, Anna!
```

Теперь запустите её без аргумента. Сигнатура не подходит. Поэтому Raku выводит сообщение об использовании. Он не здоровается:

```console
$ raku hello.raku
Usage:
  hello.raku <name>
```

Raku строит сообщение из имён параметров. Поэтому давайте параметрам хорошие имена. Тогда текст справки полезен, и лишней работы нет.

## Именованные аргументы

У `MAIN` могут быть позиционные параметры. Ещё у него могут быть именованные параметры. В командной строке именованный параметр становится опцией вида `--option=value`. Ему можно дать значение по умолчанию. Тогда опция не обязательна:

```raku
sub MAIN(:$name = 'World') {
    say "Hello, $name!";
}
```

```console
$ raku hello.raku
Hello, World!

$ raku hello.raku --name=Raku
Hello, Raku!
```
