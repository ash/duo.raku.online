Что выведет эта программа?

```raku
my $*n = 1;
sub show { say $*n }

sub run {
    my $*n = 2;
    show();
}

run();
```

{:.quiz}
0 | 1
1 | 2
0 | Nothing
0 | An error

{% include quiz.html %}

<div class="extended-explanation">

`show` находится на верхнем уровне. Она стоит прямо рядом с `my $*n = 1`. Но место здесь не важно. Raku ищет динамическую переменную по *стеку вызовов*. Он не смотрит, где находится код. Здесь `run` вызывает `show`. А `run` снова объявляет `$*n` как `2`. Поэтому действует это значение, и программа выводит `2`.

</div>
