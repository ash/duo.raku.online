---
title: Динамические переменные
---

{% include menu.html %}

У _динамической_ переменной есть твигил `*`. Обычная, лексическая переменная видна только в своём блоке. Вы объявляете её в этом блоке. Динамическая переменная другая. Raku ищет её **по стеку вызовов**. Он смотрит на код, который вызвал текущий код. Потом он идёт ещё на шаг назад, и так далее. Неважно, где написан текущий код.

```raku
my $*greeting = 'Hello';

sub greet {
    say $*greeting;
}

greet(); # Hello
```

Подпрограмма `greet` не объявляет `$*greeting`. Она не получает её как аргумент. Но она всё равно её видит. Переменная динамическая. А там, где программа вызывает `greet`, эта переменная видна.

Этот пример работает и с простой глобальной скалярной переменной `$greeting`. Следующий пример показывает, что особенного в динамических переменных.

Raku ищет переменную по стеку вызовов. Поэтому более близкое объявление **перекрывает** более далёкое. Это значит, что Raku использует более близкое. Это действует, пока работает его блок:

```raku
my $*level = 'outer';

sub show {
    say $*level;
}

show(); # outer

{
    my $*level = 'inner';
    show(); # inner
}
```

Та же `show` в первый раз печатает `outer`. Во второй раз она печатает `inner`. В этот раз программа вызывает `show` изнутри блока. Этот блок снова объявляет `$*level`. Это _динамическая область видимости_. Встроенные переменные Raku `$*OUT`, `$*IN` и `$*ERR` работают так же. Например, можно снова объявить `$*OUT` в блоке. Тогда вывод на время идёт в новое место. Каждая подпрограмма, которую вы вызываете в блоке, видит новое значение. Динамические переменные отлично подходят для информации, которая нужна вызванному коду. Вам не нужно передавать эту информацию как аргумент.
