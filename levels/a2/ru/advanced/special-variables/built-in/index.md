В Raku есть набор готовых переменных для вас. Большинство из них _динамические_, с твигилом `*`. Вы уже знаете [динамические переменные](/ru/advanced/special-variables/dynamic-variables). Поэтому эти переменные можно читать где угодно. Можно даже дать им новое значение для одной области видимости. Вот переменные, которые вам нужны чаще всего.

## Стандартные потоки

Ввод и вывод идут через три динамические переменные. `$*OUT` — это стандартный вывод. `$*ERR` — это стандартный поток ошибок, вывод для сообщений об ошибках. `$*IN` — это стандартный ввод. `say` и `print` пишут в `$*OUT`. Вы хотите отправить текст в стандартный поток ошибок? Тогда вызовите метод у `$*ERR`:

```raku
$*OUT.say('normal output'); # goes to standard output
$*ERR.say('a diagnostic');  # goes to standard error
```

Эти переменные динамические. Поэтому внутри блока можно направить `$*OUT` в новое место. Тогда код, который вы вызываете в блоке, печатает туда. Вы совсем не меняете этот код.

## Программа и её процесс

Некоторые переменные рассказывают о программе, которая сейчас работает:

```raku
say $*PROGRAM-NAME; # the path of the script being run
say $*PID;          # the process id of this program
say $*CWD;          # the current working directory
```

Их значения разные при каждом запуске программы. Поэтому мы не показываем здесь вывод.

## Командная строка и окружение

Raku кладёт аргументы и окружение в два контейнера. Они готовы для вас:

* `@*ARGS` — список аргументов командной строки; подпрограмма `MAIN` получает те же аргументы
* `%*ENV` — переменные окружения в хэше

```raku
say @*ARGS.elems; # how many arguments were passed
say %*ENV<HOME>;  # the value of the HOME environment variable
```

Эти встроенные переменные экономят вам работу. Вам не нужно самим собирать эту информацию. Они динамические, поэтому Raku ищет их по стеку вызовов. Поэтому любую встроенную переменную с `$*` можно перекрыть для области видимости. Это работает так же, как с вашей собственной переменной с `$*`.

Всё это динамические переменные. Но в Raku есть и встроенные переменные с твигилом `?`. Это `$?FILE` и `$?LINE`. Компилятор задаёт их значения до запуска программы. Вы уже видели их на странице о [твигилах](/ru/advanced/special-variables/twigils).
