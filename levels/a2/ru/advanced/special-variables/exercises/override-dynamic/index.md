## Задача

Покажите, как динамическая переменная проходит через подпрограмму в середине. Эта подпрограмма ничего не знает о переменной.

Напишите подпрограмму `log-it($msg)`. Она выводит сообщение. Перед сообщением она выводит динамическую переменную `$*prefix`. Напишите вторую подпрограмму, `task`. Она только вызывает `log-it('working')`. Сама она никогда не использует `$*prefix`. Потом вызовите `task` два раза. Каждый раз вызывайте её изнутри блока. Каждый блок даёт `$*prefix` другое значение: сначала `INFO`, потом `DEBUG`.

## Пример

Программа выводит:

```
INFO: working
DEBUG: working
```
