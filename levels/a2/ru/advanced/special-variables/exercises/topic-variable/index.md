## Задача

`$_` — это переменная *темы* (topic variable). Цикл `for` по очереди кладёт в неё каждый элемент. Некоторые вызовы методов начинаются с точки, например `.chars`. Перед точкой ничего нет. Такой вызов работает с `$_`. Поэтому `.chars` значит `$_.chars`.

Пройдите в цикле по трём строкам: `'apple'`, `'fig'` и `'cherry'`. Для каждой из них выведите такую строку: `<слово> has <n> letters`. Для слова используйте переменную темы `$_`. Для его длины используйте вызов `.chars`. Он начинается с точки. Посмотрите, как `$_` по очереди становится каждой строкой.

## Пример

Программа выводит:

```
apple has 5 letters
fig has 3 letters
cherry has 6 letters
```
