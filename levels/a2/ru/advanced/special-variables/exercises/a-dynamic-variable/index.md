## Задача

У динамической переменной есть твигил `*`. Raku ищет её по стеку вызовов, а не по лексической области видимости. Поэтому подпрограмма может видеть разные значения. Значение зависит от того, кто вызывает подпрограмму. Тогда блок может запустить код, который он вызывает, от имени кого-то другого.

1. Объявите динамическую переменную `$*user` со значением `'guest'`.
2. Напишите подпрограмму `whoami`. Она выводит `running as ` и потом текущее значение `$*user`, например `running as guest`. У неё нет параметров. Она должна читать `$*user` напрямую.
3. Вызовите `whoami` один раз на верхнем уровне. Она показывает `guest`.
4. Потом создайте блок. В нём снова объявите `$*user` как `'admin'`. Вызовите там *ту же самую* `whoami`. Теперь она показывает `admin`.

## Пример

Программа выводит:

```
running as guest
running as admin
```
