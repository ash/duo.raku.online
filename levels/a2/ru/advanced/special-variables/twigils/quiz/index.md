Raku находит **динамическую** переменную по стеку вызовов. Какой твигил показывает, что переменная динамическая?

{:.quiz}
1 | `*`
0 | `?`
0 | `!`
0 | `.`

{% include quiz.html %}

<div class="extended-explanation">

Твигил `*` показывает динамическую переменную, как в `$*OUT` или `$*greeting`. Твигил `?` — для значений времени компиляции. `!` — для приватного атрибута. А `.` — для аксессора атрибута.

</div>
