title: Твигилы
---

{% include menu.html %}

_Твигил_ — это символ. Он стоит между сигилом и именем переменной. Он не меняет имя. Он меняет то, как работает переменная. Ещё он меняет то, как Raku её находит. Вот частые твигилы:

* `*` — **динамическая** переменная, например `$*OUT`; Raku находит её по стеку вызовов
* `?` — значение **времени компиляции**; его задаёт компилятор, например `$?FILE` и `$?LINE`
* `!` — **приватный** атрибут объекта, например `$!balance`
* `.` — атрибут, который вы используете через его метод-аксессор, например `$.name`

Вы уже знаете некоторые из них, но без названия «твигил». `$*OUT` и `$*IN` — динамические. А `$!` и `$.` вы видели в [части об объектах](/ru/oop).

Компилятор даёт значения переменным с `?`. Он делает это, когда компилирует вашу программу:

```raku
say $?LINE; # the line number of this statement
say $?FILE; # the path of this source file
```

Каждый твигил показывает свой вид переменной. Вы видите это сразу. Когда вы читаете `$*foo`, вы знаете, что она динамическая. А `$?foo` — это константа времени компиляции. Следующая тема подробно смотрит на [динамические переменные](/ru/advanced/special-variables/dynamic-variables). Они работают совсем не так, как лексические переменные, которые вы знаете.
