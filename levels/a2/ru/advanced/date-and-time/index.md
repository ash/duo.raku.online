В Raku есть типы для дат и времени. Они — часть языка. Дата в календаре имеет тип `Date`. Чтобы создать дату, укажите год, месяц и день:

```raku
my $d = Date.new(2026, 6, 27);
say $d; # 2026-06-27
```

У даты есть части. Вы можете прочитать каждую из них:

```raku
my $d = Date.new(2026, 6, 27);
say $d.year;  # 2026
say $d.month; # 6
say $d.day;   # 27
```

Метод `day-of-week` даёт день недели для даты. У дней есть номера. Понедельник — это `1`, а воскресенье — `7`:

```raku
say Date.new(2026, 6, 27).day-of-week; # 6
```

27 июня 2026 года — суббота. Поэтому результат — `6`.

В високосном году 366 дней. Метод `is-leap-year` проверяет, попадает ли дата в високосный год:

```raku
say Date.new(2024, 1, 1).is-leap-year; # True
say Date.new(2026, 1, 1).is-leap-year; # False
```

Чтобы получить сегодняшнюю дату, вызовите `Date.today`. Мы не показываем здесь результат. Он зависит от дня, когда вы запускаете программу.
