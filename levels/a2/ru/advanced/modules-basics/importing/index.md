Есть несколько способов подключить модуль к программе. Для этого в Raku есть три инструкции: `use`, `need` и `require`. Между ними два отличия. Первое — _когда_ они загружают модуль. Второе — _что_ они дают программе.

## `use`

Вы уже знаете `use`. Он загружает модуль во время компиляции, до запуска программы. Ещё он импортирует экспортированные имена модуля. Поэтому их можно вызывать напрямую:

```raku
use Greeting;
say hello('Anna'); # Hello, Anna!
```

## `need`

`need` тоже загружает модуль во время компиляции. Но он _не_ импортирует экспортированные имена. Переменные `our` модуля всё равно вам доступны. Для этого используйте имя модуля:

```raku
need Greeting;
say $Greeting::version; # 1.0
```

После `need Greeting` простой вызов `hello(...)` не работает. Ничего не импортировано. Доступны только полные имена, с именем модуля внутри. Например, `$Greeting::version`.

## `require`

`require` загружает модуль _во время выполнения_, а не во время компиляции. В некоторых случаях это полезно. Бывает, что вы не знаете, нужен ли модуль. Вы узнаёте это только во время работы программы. Например, имя модуля может ввести пользователь.

Модуль загружается во время выполнения. Поэтому ничего не импортируется автоматически. После имени модуля напишите нужные имена. Возьмите их в угловые скобки. Тогда Raku их импортирует. Поэтому их можно вызывать напрямую:

```raku
require Greeting <&hello>;
say hello('Anna'); # Hello, Anna!
```

Обычно `use` — правильный выбор. `need` и `require` нужны для более редких случаев.
