Чтобы использовать модуль, загрузите его инструкцией `use`. После этого можно использовать имена, которые модуль экспортирует. Это как будто вы написали их сами.

Возьмём файл `Greeting.rakumod` из прошлой темы. Программа использует его так:

```raku
use Greeting;

say hello('Anna');
```

У `hello` есть пометка `is export`. Поэтому инструкция `use` делает её доступной. Программа вызывает её напрямую:

```
Hello, Anna!
```

Raku должен найти модуль. Поэтому модуль должен быть в пути поиска модулей. Это список мест, где Raku ищет модули. Может быть, файл модуля лежит в том же каталоге, что и ваша программа. Тогда скажите Raku искать там с помощью опции `-I.`. Точка означает «текущий каталог»:

```console
$ raku -I. program.raku
Hello, Anna!
```

Raku находит установленные модули автоматически. О них вы узнаете позже, в разделе [Установка модулей из сети](/ru/advanced/installing-modules). Поэтому опция `-I` нужна только для модулей рядом с вашей программой.
