## Задача

Создайте модуль с именем `Shouter` в файле `Shouter.rakumod`. Он экспортирует подпрограмму `shout`. Подпрограмма возвращает свой аргумент в верхнем регистре, большими буквами.

Затем напишите отдельную программу. Она использует модуль и печатает `shout('hi')`.

## Пример

Запустите программу с модулем в пути поиска. Она печатает:

```console
$ raku -I. shout.raku
HI
```
