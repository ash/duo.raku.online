## Задача

Вот модуль в файле `Temperature.rakumod`:

```raku
unit module Temperature;

sub c-to-f($c) is export {
    $c * 9/5 + 32
}
```

Напишите отдельную программу. Она использует этот модуль. Программа получает температуру по Цельсию как аргумент командной строки. С помощью модуля она переводит температуру в градусы Фаренгейта. Потом она печатает результат.

## Пример

```console
$ raku -I. temperature.raku 100
212
```
