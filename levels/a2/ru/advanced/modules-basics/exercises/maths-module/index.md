## Задача

Создайте модуль с именем `Maths` в файле `Maths.rakumod`. Он экспортирует подпрограмму `square`. Подпрограмма возвращает квадрат своего аргумента.

Затем напишите отдельную программу. Она использует модуль и печатает `square(6)`.

## Пример

Запустите программу с модулем в пути поиска. Она печатает:

```console
$ raku -I. maths.raku
36
```
