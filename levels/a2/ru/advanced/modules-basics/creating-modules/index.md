Со временем программы становятся больше. Тогда их полезно делить на части. Эти части можно использовать снова. Такая часть кода называется _модулем_. Она лежит в своём файле. Другие программы могут загрузить её и использовать.

У файла модуля расширение `.rakumod`. Он начинается с `unit module` и имени модуля. Обычно подпрограммы в модуле приватные. Только сам модуль может их использовать. Хотите поделиться подпрограммой с другим кодом? Пометьте её трейтом `is export`.

Вот модуль в файле `Greeting.rakumod`:

```raku
unit module Greeting;

sub hello($name) is export {
    return "Hello, $name!";
}
```

У подпрограммы `hello` есть `is export`. Поэтому её видит каждая программа, которая использует модуль. Подпрограмма без `is export` остаётся приватной. Только сам модуль может её использовать.

Модуль также может делиться данными. Для этого он использует переменные `our`. Другой код может получить их через имя модуля. Давайте добавим номер версии в `Greeting`. Нам нужна всего одна новая строка в файле:

```raku
our $version = '1.0';
```

Теперь в `Greeting.rakumod` есть эта строка. Поэтому значение доступно как `$Greeting::version`. Это работает везде, где программа загружает модуль.

Следующие темы показывают, [как программа загружает такой модуль](/ru/advanced/modules-basics/using-modules). Ещё они показывают, что программа из него получает.
