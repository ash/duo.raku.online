Посмотрите на выражение `@a[0]`. Какая категория у обращения по индексу `[0]`?

{:.quiz}
0 | postfix
1 | postcircumfix
0 | circumfix
0 | infix

{% include quiz.html %}

<div class="extended-explanation">

У обращения по индексу есть скобки вокруг содержимого. Оно *также* идёт после терма, здесь это `@a`. Поэтому это постциркумфиксный оператор. У обычного постфикса, как `++`, нет никаких скобок. Циркумфикс стоит вокруг чего-то. Но он не идёт после терма. Пример — `[1, 2, 3]`. Он создаёт массив.

</div>
