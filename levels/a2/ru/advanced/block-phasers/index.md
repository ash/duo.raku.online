Вы уже знаете фазеры для всей программы. В Raku есть и фазеры для одного блока или одного цикла. Они связаны с жизнью этого блока или цикла.

## Вход в блок и выход из него

Фазер `ENTER` выполняется каждый раз, когда программа входит в блок. Фазер `LEAVE` выполняется каждый раз, когда программа выходит из блока. Их место в блоке не важно:

```raku
say 'before block';
{
    LEAVE say 'leaving';
    ENTER say 'entering';
    say 'inside';
}
say 'after block';
```

Посмотрите на вывод. `ENTER` выполняется первым, а `LEAVE` — последним. Тело блока стоит между ними:

```
before block
entering
inside
leaving
after block
```

`LEAVE` очень полезен. Он выполняется, даже когда блок заканчивается раньше времени. Поэтому в нём можно спокойно освободить ресурс, например открытый файл.

Фазер может содержать целый блок `{ }`, а не только одно выражение. Ещё можно задать несколько фазеров. В блоке может быть больше одного `LEAVE`. Тогда они выполняются в обратном порядке. Последний выполняется первым. Это работает как стек. Что пришло последним, уходит первым:

```raku
say 'open A';
{
    LEAVE {
        say 'close A';
    }
    say 'open B';
    LEAVE {
        say 'close B';
    }
    say 'work';
}
say 'done';
```

Программа открывает ресурс `A` первым. Она закрывает его последним:

```
open A
open B
work
close B
close A
done
```

Этот порядок — «последним пришёл, первым ушёл». Он как раз подходит для очистки. Что вы настроили последним, вы убираете первым. Фазер `END` для всей программы работает так же. Несколько блоков `END` тоже выполняются в обратном порядке.

## Фазеры для циклов

У циклов есть ещё три фазера. Они отмечают этапы цикла. `FIRST` выполняется один раз, перед первым шагом. `LAST` выполняется один раз, после последнего шага. `NEXT` выполняется в конце каждого шага:

```raku
for 1..3 {
    FIRST say '-- first';
    LAST  say '-- last';
    NEXT  say "-- next (was $_)";
    say "body $_";
}
```

Цикл печатает:

```
-- first
body 1
-- next (was 1)
body 2
-- next (was 2)
body 3
-- next (was 3)
-- last
```

Здесь всё как с другими фазерами. `FIRST`, `NEXT` и `LAST` можно писать в любом месте цикла. Каждый выполняется в своё время.
