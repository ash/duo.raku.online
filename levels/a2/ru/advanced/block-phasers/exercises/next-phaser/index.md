## Задача

Фазер `NEXT` выполняется в *конце* каждого шага цикла. Это хорошее время, чтобы показать прогресс.

Храните растущую сумму в `$sum`. Сначала она равна `0`. Сделайте цикл по `1..3`. На каждом шаге сначала прибавляйте текущее число к `$sum`. С помощью фазера `NEXT` печатайте `sum so far: $sum` после каждого шага.

Будьте внимательны с порядком. Фазер `NEXT` выполняется после тела. Поэтому сумма, которую он показывает, *уже включает* текущее число.

## Пример

Программа выводит:

```
sum so far: 1
sum so far: 3
sum so far: 6
```
