## Задача

Самое лучшее в `LEAVE` — вот что. Он выполняется *при любом* выходе программы из блока. Он выполняется даже после раннего `return`.

Напишите подпрограмму `work`. Её тело начинается с фазера `LEAVE`. Фазер печатает `Cleanup`. Потом, всё ещё в подпрограмме, напечатайте `Working`. После этого сразу сделайте `return`. Поставьте строку `say 'never reached'` после `return`. Вызовите подпрограмму. Ранний `return` пропускает последнюю строку. Но программа всё равно печатает `Cleanup`.

## Пример

Программа выводит:

```
Working
Cleanup
```
