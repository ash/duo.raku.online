## Задача

`FIRST` выполняется только один раз. Фазер `ENTER` работает иначе. Он выполняется *каждый раз*, когда программа входит в блок. Цикл входит в своё тело заново на каждом шаге.

Сделайте цикл по `1..2`. Внутри цикла поставьте фазер `ENTER`. Он печатает `--entering`. Ещё поставьте туда обычное выражение. Оно печатает `body` и текущее число. Вы увидите `--entering` один раз на каждом шаге.

## Пример

Программа выводит:

```
--entering
body 1
--entering
body 2
```
