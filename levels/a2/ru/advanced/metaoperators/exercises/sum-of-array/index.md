## Задача

Напишите программу. Она печатает среднее значение массива чисел. Среднее значение также называют средним арифметическим. Сложите значения с помощью метаоператора свёртки.

Числа записаны прямо в программе. Например:

```raku
my @data = 10, 20, 30, 40;
```

## Пример

Программа печатает среднее значение элементов `@data`:

```
25
```
