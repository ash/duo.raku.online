## Задача

URL разрезан на части. Части лежат в массиве. Снова соедините части в одну строку. Используйте для этого метаоператор свёртки. Напечатайте URL. На следующей строке напечатайте его длину в символах.

## Пример

Вот входной массив:

```raku
my @parts = <http :// example .com>;
```

Программа печатает:

```
http://example.com
18
```
