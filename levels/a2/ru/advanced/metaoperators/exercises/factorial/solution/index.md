Вот один способ решить задачу.

## Код

```raku
say [\*] 1..6;
```

🦋 Исходный код можно найти в файле [factorial.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/metaoperators/factorial.raku).

## Вывод

```
(1 2 6 24 120 720)
```

## Комментарии

1. Внутри скобок стоит обратная косая черта. Она делает `[*]` *треугольной* свёрткой. Такая свёртка не превращает список в одно значение. Она сохраняет каждый шаг произведения: `1`, затем `1*2`, затем `1*2*3` и так далее.

1. Каждое произведение `1*2*...*k` — это ровно _k!_. Поэтому результат — список факториалов чисел от `1` до `6`. Простая свёртка `[*] 1..6` даёт только последний из них, `720`.
