В Raku есть и другие метаоператоры, не только свёртка и zip. Здесь вы узнаете три из них.

## Перекрёстный — `X`

Перекрёстный метаоператор `X` берёт два списка и делает пары. Здесь **каждый** элемент одного списка идёт в пару с **каждым** элементом другого. Это называют декартовым произведением:

```raku
say <a b> X <1 2>; # ((a 1) (a 2) (b 1) (b 2))
```

Как и zip, `X` тоже может взять оператор. Тогда оператор работает с каждой парой. `X~` соединяет каждую пару в строку. `X*` перемножает два числа:

```raku
say <a b> X~ <1 2>;         # (a1 a2 b1 b2)
say (1, 2, 3) X* (10, 100); # (10 100 20 200 30 300)
```

Zip проходит по двум спискам одновременно. Перекрёстный оператор соединяет их всеми возможными способами.

## Гипероператор — `»…«`

Гипероператор применяет оператор к **каждому элементу** списка. Оператор стоит между стрелками `»…«`. Если нужны только символы ASCII, пишите `>>…<<`. С двумя списками он работает элемент за элементом, как zip. Иногда с одной стороны стоит только одно значение. Тогда он применяет это значение к каждому элементу списка:

```raku
say (1, 2, 3) »+» (10, 20, 30); # (11 22 33)
say (1, 2, 3) »*» 2;            # (2 4 6)
```

Две стрелки могут смотреть в разные стороны. Направление важно для списков разной длины. Если стрелка смотрит **на** список, Raku может повторить этот список. Тогда он такой же длины, как другой список. Вот четыре сочетания в ASCII, с `<<` и `>>`:

* `>>op<<` — Raku не повторяет ни один список. Списки должны быть одной длины. Иначе вы получите ошибку.
* `>>op>>` — Raku повторяет **правый** список. Тогда он такой же длины, как левый.
* `<<op<<` — Raku повторяет **левый** список. Тогда он такой же длины, как правый.
* `<<op>>` — Raku повторяет **более короткий** список. Тогда он такой же длины, как более длинный.

```raku
say (1, 2, 3, 4) <<+>> (10, 20); # (11 22 13 24)  — 10, 20 повторяется как 10, 20, 10, 20
```

Есть также форма только с одним операндом. Она вызывает метод у каждого элемента. `>>.uc` делает все буквы каждой строки заглавными:

```raku
say <raku perl>>>.uc; # (RAKU PERL)
```

Гипероперация также сообщает Raku ещё кое-что. Raku *может* выполнять работу параллельно. Тогда несколько частей работы идут одновременно. Позже вы узнаете похожий метод `.hyper`. Он есть в [разделе о конкурентном программировании](/ru/paradigms/hyper-race).

## Отрицающий — `!`

Поставьте `!` перед оператором сравнения. Тогда вы получите обратный результат. Вы уже знаете `!=`, или «не равно». Это просто тот же метаоператор с `==`. Другие операторы тоже дают `True` или `False`, например `eq` и `%%`. С ними метаоператор работает так же:

```raku
say 3 != 4;      # True
say 'a' !eq 'b'; # True  — не равны как строки
say 5 !%% 2;     # True  — 5 не делится на 2
```

Так что `$a !op $b` — это просто более аккуратный способ записать `!($a op $b)`.

Raku делает это специально. Некоторые языки специально маленькие и простые, например эсперанто. Эсперанто хочет иметь один правильный способ для каждой мысли. Raku другой. Он с радостью даёт вам несколько способов. Поэтому в Raku есть отрицающий `!eq`. В нём также есть особый оператор `ne`. Они означают ровно одно и то же:

```raku
say 'a' ne 'b'; # True — та же проверка, что и 'a' !eq 'b'
```
