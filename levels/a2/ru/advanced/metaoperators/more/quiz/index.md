Что напечатает эта программа?

```raku
say (1, 2, 3) »+» 10;
```

{:.quiz}
1 | (11 12 13)
0 | (11 2 3)
0 | 16
0 | 6

{% include quiz.html %}

<div class="extended-explanation">

Гипероператор `»+»` применяет `+` к каждому элементу. Справа стоит только одно значение, `10`. Raku использует это значение для всего списка. Поэтому каждый элемент становится больше на `10`: `(11 12 13)`. Свёртка `[+]` работает по-другому. Она превращает список в одну сумму, `6`.

</div>
