Метаоператор zip `Z` берёт два списка или больше. Он соединяет их элементы по позициям:

```raku
say (1, 2, 3) Z (4, 5, 6); # ((1 4) (2 5) (3 6))
```

Результат — список групп. В первой группе — первый элемент каждого списка. Во второй группе — второй элемент каждого списка, и так далее.

Есть и более умный способ. Можно использовать `Z` вместе с оператором. Тогда оператор работает с каждой парой. Например, `Z+` складывает элементы на одинаковых позициях:

```raku
say (1, 2, 3) Z+ (10, 20, 30); # (11 22 33)
```

Здесь метаоператор zip работает с оператором `+`. Он вычисляет `1 + 10`, `2 + 20` и `3 + 30`. Так же `Z*` перемножает элементы на одинаковых позициях:

```raku
say (1, 2, 3) Z* (10, 20, 30); # (10 40 90)
```

А `Z~` соединяет строки на одинаковых позициях:

```raku
say <a b c> Z~ <1 2 3>; # (a1 b2 c3)
```
