В тексте Pod вы отмечаете слова _кодами форматирования_. Каждый код — это одна буква. После буквы вы ставите угловые скобки вокруг текста:

* `B<…>` — жирный
* `I<…>` — курсив
* `C<…>` — код (все буквы одной ширины)
* `L<…>` — ссылка

```raku
=begin pod

This is B<important>, and C<say> is a built-in.

=end pod
```

В форматированном тексте `important` стоит жирным шрифтом. `say` стоит шрифтом для кода. Вы можете поставить один код внутрь другого кода. Так вы их соединяете. Поэтому `B<C<say>>` — это жирный код.

Иногда вам нужен целый блок кода. Короткого кусочка внутри строки мало. Тогда используйте блок кода: `=begin code … =end code`. У него есть строка в начале и строка в конце. Он сохраняет текст точно таким, какой он есть:

```raku
=begin pod

Here is how to call it:

=begin code
say greet('world');
=end code

=end pod
```

Строки в блоке кода выглядят точно так, как вы их пишете. Raku не читает их как Pod. Итак, в Pod есть коды внутри строк и есть блоки кода. С ними вы можете описать API. API — это то, как другие программы используют ваш код. Вы пишете форматированный текст и примеры. Примеры выглядят как код, который можно запустить. Всё это остаётся рядом с кодом, который оно описывает.
