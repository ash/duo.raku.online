## Задача

Напишите блок Pod. В нём есть заголовок `=head1` `Greeting` и абзац `Hello, world!`. Сделайте слово `world` жирным с помощью `B<…>`. Потом превратите блок в текст с помощью `raku --doc`.

> Запустите файл с `raku --doc`. Тогда вы увидите форматированный текст.

## Пример

С `raku --doc` он печатает вот что:

```
Greeting

Hello, world!
```
