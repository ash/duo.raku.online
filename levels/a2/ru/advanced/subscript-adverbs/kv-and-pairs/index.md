Другие наречия меняют **то, что** возвращает обращение по индексу. Обычно обращение по индексу возвращает значение. Эти наречия возвращают больше:

* `:v` — значение; это вариант по умолчанию
* `:k` — ключ или индекс
* `:kv` — ключ и значение
* `:p` — пару (`Pair`) из ключа и значения

Для массива «ключом» является индекс:

```raku
my @a = 10, 20, 30;

say @a[1]:kv; # (1 20)
say @a[1]:p;  # 1 => 20
```

`@a[1]:kv` возвращает индекс и значение вместе в виде списка. `@a[1]:p` возвращает их в виде пары.

Это работает и с хешами. Это очень удобно со срезом. В срезе сразу несколько ключей:

```raku
my %h = a => 1, b => 2, c => 3;

say %h<a c>:kv; # (a 1 c 3)
```

Здесь в срезе два ключа. Результат — ключ, его значение, следующий ключ, его значение. `map`, `for` и похожие инструменты часто используют эти наречия. С ними можно работать с ключами и значениями вместе. Отдельные обращения не нужны.
