Наречие `:exists` превращает обращение по индексу в вопрос. Есть ли значение по этому ключу или индексу? Ответ — `True` или `False`. Наречие не получает само значение:

```raku
my %h = apple => 1, pear => 2;

say %h<apple>:exists; # True
say %h<plum>:exists;  # False
```

Это правильный способ проверить ключ. Можно также просто прочитать `%h<plum>`. Но тогда вы получите неопределённое значение. Или, с некоторыми данными, вы не увидите разницы. Ключа просто «нет»? Или он «есть, но не определён»?

Наречие `:delete` удаляет запись. Оно возвращает значение этой записи:

```raku
my %h = apple => 1, pear => 2;

say %h<apple>:delete; # 1
say %h.keys;          # (pear)
say %h;               # {pear => 2}
```

Записи `apple` больше нет. Вы получаете обратно её значение `1`. Это значение можно использовать.

Оба наречия работают и с массивами. Там вы используете индекс:

```raku
my @a = 10, 20, 30;

say @a[1]:exists; # True
say @a[5]:exists; # False

say @a[1]:delete; # 20
say @a[1]:exists; # False
```

Вы удаляете элемент из середины. Как тогда выглядит массив? Вот ответ:

```raku
say @a; # [10 (Any) 30]
```

Итак, вы используете одну запись, и она всегда работает одинаково. С ней можно спросить о контейнере. Можно также изменить контейнер на месте. Отдельные методы для этого не нужны.
