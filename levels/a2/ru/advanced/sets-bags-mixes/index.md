В Raku есть массивы и хеши. Ещё в нём есть несколько особых контейнеров для групп значений. Самый простой из них — `Set`. Его значения _уникальны_, то есть каждое значение отличается от других. У значений в множестве нет порядка. Значение либо есть в множестве, либо его нет. Если значение встречается дважды, множество пропускает второе.

Чтобы создать множество, используйте подпрограмму `set`. Повторяющиеся значения становятся одним значением:

```raku
my $s = set(1, 2, 3, 2, 1);
say $s.elems; # 3
```

Мы даём множеству пять чисел. Но в нём только три элемента. Это потому, что `1` и `2` встречаются больше одного раза.

Обычно вы задаёте множеству один главный вопрос. Есть ли значение в множестве? На него отвечает оператор `∈`. Вы читаете `∈` как «является элементом». Он возвращает булево значение, `True` или `False`:

```raku
say 2 ∈ set(1, 2, 3); # True
say 9 ∈ set(1, 2, 3); # False
```

Может быть, вы хотите использовать только простые символы ASCII. Тогда пишите тот же оператор как `(elem)`:

```raku
say 2 (elem) set(1, 2, 3); # True
```

Следующие темы показывают, как комбинировать множества. Ещё они показывают мультимножества (bags) и смеси (mixes). Мультимножества и смеси — близкие родственники множеств.
