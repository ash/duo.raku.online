Что напечатает эта программа?

```raku
say (set(1, 2) ∪ set(2, 3)).elems;
```

{:.quiz}
1 | 3
0 | 4
0 | 2
0 | 1

{% include quiz.html %}

<div class="extended-explanation">

Объединение берёт каждое значение из обоих множеств. Но множество хранит каждое значение только один раз. Значение `2` есть в обоих множествах. Поэтому объединение — это `{1, 2, 3}`. В нём три разных элемента.

</div>
