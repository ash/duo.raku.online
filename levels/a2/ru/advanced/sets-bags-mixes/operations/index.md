Множества можно комбинировать обычными операциями из теории множеств. Теория множеств — это часть математики. У каждого оператора есть символ в Unicode. Ещё его можно записать в ASCII. Используйте тот вариант, который вам больше нравится.

_Объединение_ — это `∪`, или `(|)` в ASCII. Оно берёт все значения из обоих множеств:

```raku
say (set(1, 2, 3) ∪ set(3, 4, 5)).elems; # 5
```

Значение `3` есть в обоих множествах. Поэтому в объединении пять разных элементов: `1, 2, 3, 4, 5`.

_Пересечение_ — это `∩`, или `(&)` в ASCII. Оно оставляет только значения, которые есть в обоих множествах:

```raku
my $common = set(1, 2, 3) ∩ set(2, 3, 4);
say $common;       # Set(2 3) — обратите внимание, что множества неупорядочены
say $common.elems; # 2
say 2 ∈ $common;   # True
```

Здесь в пересечении `2` и `3`. Эти значения есть в обоих множествах. У множества нет порядка. Поэтому при выводе два элемента могут идти в любом порядке.

Эти операции тоже дают множество. Поэтому ему можно задать те же вопросы. Сколько в нём элементов? Есть ли в нём нужное значение?
