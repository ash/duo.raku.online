Множество помнит только, _есть ли_ в нём значение. Иногда вы хотите знать ещё, _сколько раз_ оно там есть. Для этого есть `Bag`. Он хранит счётчик для каждого значения.

Чтобы создать мультимножество, используйте подпрограмму `bag`. Мультимножество не соединяет повторы в одно значение. Оно их считает:

```raku
my $b = bag(<a b a c a>);
say $b<a>; # 3
say $b<b>; # 1
```

Спросите мультимножество о значении с помощью индекса `< >`. Так вы узнаёте, сколько раз это значение попало в мультимножество. Метод `total` складывает все счётчики:

```raku
say bag(<a b a c a>).total; # 5
```

`Mix` похож на мультимножество. Но в смеси счётчики называются _весами_. Вес не обязательно целое число. Он может быть и дробью. Вы можете сами задать веса. Соедините каждое значение с его весом в пару. Потом превратите список в смесь с помощью `.Mix`:

```raku
my $m = (flour => 2.5, sugar => 0.75).Mix;
say $m<flour>; # 2.5
say $m.total;  # 3.25
```

Вы получаете вес с помощью `< >`. Вы складываете веса с помощью `total`. Оба способа работают так же, как для мультимножества. Только числа не обязаны быть целыми. Здесь `total` складывает веса `2.5` и `0.75`. Результат — `3.25`. Значит, `total` даёт сумму весов. Он не считает значения. Мультимножества и смеси полезны, когда нужно считать количества. Например, мультимножество может посчитать слова в тексте. Оно показывает, как часто встречается каждое слово. А смесь может дать веса вариантам.
