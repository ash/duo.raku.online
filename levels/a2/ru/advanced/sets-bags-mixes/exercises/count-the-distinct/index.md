## Задача

Вот список чисел. Некоторые из них повторяются:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Напечатайте, сколько в нём _уникальных_ значений. Уникальные значения все отличаются друг от друга. Используйте множество.

## Пример

Программа печатает:

```
7
```
