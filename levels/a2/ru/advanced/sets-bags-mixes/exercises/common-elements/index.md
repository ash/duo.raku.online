## Задача

Вот два множества с названиями фруктов:

```raku
my $a = set(<apple banana cherry>);
my $b = set(<banana cherry date>);
```

Найдите их пересечение. Пересечение содержит значения, которые есть в обоих множествах. Сохраните его в переменной. Потом напечатайте две строки. Первая строка — число общих значений. Вторая строка показывает, есть ли среди них `apple`. Его там быть не должно.

## Пример

Программа печатает:

```
2
False
```
