## Задача

Мультимножество отлично подходит для подсчёта слов. Возьмите предложение `the cat sat on the mat`. Разбейте его на слова. Создайте из слов мультимножество. Потом напечатайте две строки. Первая строка показывает, сколько раз встречается слово `the`. Вторая строка показывает общее число слов.

## Пример

Программа печатает:

```
2
6
```
