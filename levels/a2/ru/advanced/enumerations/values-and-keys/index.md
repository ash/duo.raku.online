У каждой константы перечисления есть имя и число. Метод `.value` даёт число. Метод `.key` даёт имя в виде строки:

```raku
enum Colour <red green blue>;

say green.value; # 1
say green.key;   # green
```

Raku нумерует константы с нуля. Но это можно изменить. Запишите константы как пары. Тогда вы сами выбираете значения:

```raku
enum Day (Mon => 1, Tue => 2, Wed => 3, Thu => 4, Fri => 5);

say Tue.value; # 2
say Fri.value; # 5
```

Здесь рабочая неделя начинается с единицы, а не с нуля.

Тип перечисления может также показать все свои константы. Метод `.enums` возвращает отображение. Отображение похоже на хеш. В этом отображении у каждого имени есть своё значение:

```raku
enum Colour <red green blue>;

say Colour.enums;       # Map.new((blue => 2, green => 1, red => 0))
say Colour.enums.elems; # 3
```

С `.value`, `.key` и `.enums` можно свободно двигаться. Можно перейти от константы к её числу. Можно перейти от числа обратно к данным. А ещё можно пройти по всему набору. Поэтому перечисления полезны, например, для меню, состояний и таблиц соответствий.
