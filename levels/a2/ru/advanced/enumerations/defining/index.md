Чтобы объявить перечисление, напишите ключевое слово `enum`. Потом напишите имя и список имён констант:

```raku
enum Colour <red green blue>;
```

Это создаёт новый тип, `Colour`. Ещё это создаёт три константы: `red`, `green` и `blue`. Вы можете использовать константу просто по её имени:

```raku
say red;   # red
say green; # green
```

За каждым именем стоит число. Raku сам даёт эти числа. Он начинает с нуля и идёт по порядку вашего списка. Поэтому `red` — это `0`, `green` — `1`, а `blue` — `2`. У значений есть порядок. Поэтому константы можно сравнивать:

```raku
say red < blue; # True
```

Перечисление может быть типом переменной. Тогда переменная принимает только эти константы:

```raku
my Colour $c = green;
say $c; # green
```

У константы и чего-то другого может быть одно имя. Тогда напишите перед константой имя перечисления и `::`. Это работает всегда:

```raku
say Colour::red; # red
```

Перечисление собирает связанные константы вместе. Оно даёт им имя и тип. Код с ними гораздо понятнее, чем код с одними числами. Следующая тема — о [числах за именами](/ru/advanced/enumerations/values-and-keys).
