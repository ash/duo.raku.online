Вот один способ решить задачу.

## Код

```raku
my $sum = 0;
my @result = gather for 1..100 {
    $sum += $_;
    last if $sum > 10;
    take $_;
}

say @result;
```

🦋 Исходный код можно найти в файле [gather-big.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/gather-take/gather-big.raku).

## Вывод

```
[1 2 3 4]
```

## Комментарии

1. Цикл получает диапазон из ста чисел. Ему нужно гораздо меньше. Но это нормально. Цикл останавливается сам. Когда `$sum` становится больше `10`, `last` выходит из цикла. Программа никогда не смотрит на остальные числа.

1. Порядок в блоке важен. Сначала мы прибавляем число к `$sum`. Потом мы проверяем предел. После этого мы берём число. Одно число делает сумму больше `10`. Здесь это число `5`. Код его не берёт. После `4` сумма равна ровно `10`. Поэтому список — это `1, 2, 3, 4`.

1. С `for` пара `gather`/`take` может остановиться раньше. `grep` так не умеет. `grep` всегда смотрит весь список. Здесь мы сами решаем, когда остановиться.
