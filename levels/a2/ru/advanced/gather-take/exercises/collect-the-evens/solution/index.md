Вот один способ решить задачу.

## Код

```raku
my @result = gather for 1..4 -> $n {
    take $n for 1..$n;
};

say @result;
```

🦋 Исходный код можно найти в файле [collect-the-evens.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/gather-take/collect-the-evens.raku).

## Вывод

```
[1 2 2 3 3 3 4 4 4 4]
```

## Комментарии

1. Не нужно ставить ровно один `take` на каждом шаге. Посмотрите здесь на внутренний `take $n for 1..$n`. Он выполняет `take` разное число раз на каждом шаге. Эта свобода делает `gather`/`take` сильнее простого `map`.

1. У внешнего цикла есть переменная с именем, `-> $n`. Это сделано специально. Представьте, что мы используем `$_` во внутреннем цикле. Тогда внутренний `for` кладёт в `$_` свой счётчик. И мы берём счётчик, а не текущее число.

1. `gather` просто собирает по порядку каждое значение, которое берёт код. Поэтому в `@result` есть одно число `1`, два числа `2`, три числа `3` и четыре числа `4`.
