## Задача

Постройте список с помощью `gather` и `take`. Каждое число от `1` до `4` есть в списке несколько раз. Сколько раз — это само число: `1` один раз, `2` два раза, `3` три раза и `4` четыре раза. Напечатайте список.

## Пример

Программа печатает:

```
[1 2 2 3 3 3 4 4 4 4]
```
