Вот один способ решить задачу.

## Код

```raku
my @squares = gather for 1..6 {
    take $_ ** 2 if $_ %% 2;
};

say @squares;
```

🦋 Исходный код можно найти в файле [squares.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/gather-take/squares.raku).

## Вывод

```
[4 16 36]
```

## Комментарии

1. Проверка `if $_ %% 2` решает, *берёт ли* код значение. `$_ ** 2` решает, *что* он берёт. Проверку проходят только чётные числа `2`, `4`, `6`.

1. Их квадраты — это `4`, `16`, `36`. Только эти значения попадают в `take`. Поэтому `gather` собирает именно эти значения. Здесь один `take` и выбирает значения, и меняет их. Простой `map` не может сказать это так же ясно.
