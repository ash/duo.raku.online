Можно положить один массив внутрь другого. Raku _не_ соединяет их элементы сам. Посмотрите на эту программу:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;
my @c = @a, @b;

say @c.elems; # 2
say @c;       # [[1 2 3] [4 5]]
```

В массиве `@c` всего два элемента: массивы `@a` и `@b`. Raku хранит каждый контейнер как один элемент. Его элементы не попадают во внешний массив. То же самое с массивом среди других значений:

```raku
my @a = 1, 2, 3;
my @d = 0, @a, 99;
say @d; # [0 [1 2 3] 99]
```

Вам нужна одна плоская последовательность? Тогда попросите её с помощью функции `flat`:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat(@a, @b);       # (1 2 3 4 5)
say flat(@a, @b).elems; # 5
```

## Упаковка в элемент (Itemisation)

Иногда нужно обратное. Вы хотите сохранить контейнер целым, даже внутри `flat`. Конструкция `$(...)` _упаковывает_ свой аргумент. Это значит, что она помечает результат как один-единственный элемент. Сравните прошлый пример с этим:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat($(@a), @b); # ([1 2 3] 4 5)
```

Здесь `$(@a)` сохраняет `@a` как один элемент. Но `@b` всё равно становится плоским. Он отдаёт свои два значения. Это снова идея сигила `$`. Знак `$` значит «считать это одной вещью».
