---
title: Привязка с помощью `:=`
---

{% include menu.html %}

До сих пор каждая новая переменная создавала новый контейнер. Присваивание через `=` клало значение _в_ этот контейнер. Привязка работает иначе. Вы пишете её так: `:=`. Привязка не создаёт новый контейнер. Она даёт имя _уже существующему_ контейнеру.

После привязки у двух имён один общий контейнер. Измените значение через одно имя. Другое имя тоже видит это изменение:

```raku
my $x = 10;
my $y := $x;

$x = 20;
say $y; # 20
```

Здесь `$y := $x` не копирует значение `10`. Привязка делает `$y` вторым именем для контейнера `$x`. Это тот же самый контейнер. Потом `$x` получает значение `20`. Тогда в `$y` тоже `20`.

Сравните это с обычным присваиванием. Оно копирует значение в другой контейнер:

```raku
my $x = 10;
my $y = $x; # обычная копия

$x = 20;
say $y; # 10
```

Привязка работает и с массивами. Здесь `@alias` становится вторым именем для `@data`:

```raku
my @data = 1, 2, 3;
my @alias := @data;

@alias[0] = 99;
say @data; # [99 2 3]
```

Ещё одна деталь. Имя можно привязать прямо к литералу. Это значение, которое вы пишете прямо в коде. Тогда за именем нет контейнера. Поэтому имя доступно только для чтения. Ему нельзя ничего присвоить:

```raku
my $pi := 3.14;
$pi = 3;
```
