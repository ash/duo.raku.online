## Задача

Вот массив:

```raku
my @original = 10, 20, 30;
```

Создайте второе имя, `@alias`, для _того же самого_ массива. Не копируйте массив. На этот раз добавьте новый элемент в `@original` с помощью `push`. Потом напечатайте `@alias`. Это показывает, что псевдоним видит не только новые значения. Он видит и изменения в структуре массива.

## Пример

Программа печатает:

```
[10 20 30 40]
```
