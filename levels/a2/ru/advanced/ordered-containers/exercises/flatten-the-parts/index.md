## Задача

Вот два массива:

```raku
my @first = 1, 2;
my @second = 3, 4, 5;
```

Соедините их в один _плоский_ массив. Это не должен быть вложенный массив, с массивами внутри. Напечатайте массив. Потом напечатайте число его элементов.

## Пример

Программа печатает:

```
[1 2 3 4 5]
5
```
