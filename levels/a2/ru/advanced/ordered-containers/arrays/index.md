Массив — это упорядоченный контейнер. Каждый элемент массива — тоже скалярный контейнер.

```raku
my @array = 100, 200, 300;
my @letters = 'a', 'b', 'c';
```

Сигил `@` показывает, что переменная работает как объект `Positional`. Поэтому каждый элемент можно получить по индексу:

```raku
say @array[1];   # 200
say @letters[2]; # c
```

Каждый элемент — это скалярный контейнер. Поэтому ему можно присвоить новое значение. Это работает так же, как с обычной скалярной переменной:

```raku
my @array = 100, 200, 300;
@array[0] = 10;
say @array; # [10 200 300]
```

Можно присвоить и значение другого типа. Например:

```raku
my @array = 100, 200, 300;
@array[0] = 'ten';
say @array; # [ten 200 300]
```

Поэтому массивы _изменяемые_. Это значит, что их можно менять. Каждое место в массиве — это контейнер. Он может получить новое значение. [Списки](/ru/advanced/ordered-containers/lists) работают иначе. Вы увидите это в следующей теме.
