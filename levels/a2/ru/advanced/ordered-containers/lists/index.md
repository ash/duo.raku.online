title: Списки
---

Список — это тоже упорядоченный набор значений. Но он не похож на массив. Список _неизменяем_. Его элементы нельзя менять. Добавлять и удалять элементы тоже нельзя. Чтобы записать список, поставьте запятые между значениями. Часто вокруг них стоят круглые скобки:

```raku
my $colours = ('red', 'green', 'blue');
```

Элементы списка можно читать по индексу. Ещё можно узнать, сколько там элементов. Всё так же, как с массивом:

```raku
my $colours = ('red', 'green', 'blue');
say $colours[0];    # red
say $colours.elems; # 3
```

Теперь попробуйте изменить элемент. Здесь вы видите разницу. С массивом это работает. Каждый элемент массива — это контейнер:

```raku
my @array = 1, 2, 3;
@array[0] = 10;
say @array; # [10 2 3]
```

Со списком вы получаете ошибку. Элементы списка — это просто значения. Они не контейнеры:

```raku
my $list = (1, 2, 3);
$list[0] = 10;
```

Вторая программа останавливается. Она печатает такое сообщение:

```
Cannot modify an immutable List ((1 2 3))
  in block <unit> at t.raku line 2
```

Итак, вам нужно менять данные? Тогда используйте массив, с сигилом `@`. Вам нужно только хранить значения в постоянном порядке? Тогда используйте список.
