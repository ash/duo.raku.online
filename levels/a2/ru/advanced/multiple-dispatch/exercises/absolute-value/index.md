## Задача

Напишите две мульти-подпрограммы с именем `abs-value`. Они принимают целое число и возвращают его абсолютное значение. Абсолютное значение — это число без знака минус. Используйте конструкцию `where` для отрицательных чисел. Не используйте `if` в подпрограммах. Встроенную функцию `abs` тоже не используйте.

Напечатайте результат для `-7` и для `4`.

## Пример

Программа печатает:

```
7
4
```
