## Задача

Оператор `**` сильнее, чем `+`. Поэтому Raku читает `2 ** 3 + 1` как `(2 ** 3) + 1`. Это `9`. Добавьте скобки и измените этот порядок. Сложение должно выполняться *первым*. Выведите результат.

## Пример

Программа выводит:

```
16
```
