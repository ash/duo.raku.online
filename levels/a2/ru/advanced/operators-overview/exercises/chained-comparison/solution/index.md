Вот один способ решить задачу.

## Код

```raku
say 0 <= 73 <= 100;
```

🦋 Исходный код можно найти в файле [chained-comparison.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operators-overview/chained-comparison.raku).

## Вывод

```
True
```

## Комментарии

1. Операторы сравнения можно соединять в цепочку. Поэтому `0 <= 73 <= 100` значит «0 не больше 73, а 73 не больше 100». Оператор `<=` разрешает и границы. Поэтому результат ровно `0` или `100` тоже допустимый.

1. Обе части истинны. Поэтому всё выражение равно `True`. Посмотрите на среднее значение, `73`. Вы пишете его только один раз. Но Raku сравнивает его с обоими соседними значениями.

1. Без цепочки нужно писать оба сравнения. Вы соединяете их с помощью `&&`. И вы пишете среднее значение два раза: `0 <= 73 && 73 <= 100`. Форма с цепочкой говорит то же самое короче.
