В выражении может быть несколько операторов. Тогда Raku должен выбрать порядок. Какой оператор идёт первым? Это решают два правила: _приоритет_ и _ассоциативность_.

## Приоритет

Приоритет решает, какой оператор сильнее. Более сильный оператор берёт свои операнды первым. У умножения приоритет выше, чем у сложения. Поэтому умножение выполняется первым:

```raku
say 2 + 3 * 4; # 14
```

Raku читает выражение как `2 + (3 * 4)`. Результат — `14`, а не `20`. Вы всегда можете добавить скобки. Они задают другой порядок:

```raku
say (2 + 3) * 4; # 20
```

## Ассоциативность

У некоторых операторов _одинаковый_ приоритет. Тогда порядок решает ассоциативность. Вычитание левоассоциативно. Поэтому Raku группирует его слева:

```raku
say 8 - 3 - 2; # 3
```

Это `(8 - 3) - 2`. Результат — `3`. Но возведение в степень, оператор `**`, правоассоциативно:

```raku
say 2 ** 3 ** 2; # 512
```

Здесь Raku группирует выражение как `2 ** (3 ** 2)`. Это `2 ** 9`, и результат — `512`.

## Цепочки сравнений

Операторы сравнения можно _соединять в цепочку_. Тогда они идут один за другим. Такой код легко читать. Он работает как в математике:

```raku
say 1 < 2 < 3; # True
say 1 < 5 < 3; # False
```

Raku сравнивает среднее значение с обоими соседними значениями. `1 < 2 < 3` истинно. Это потому, что `1 < 2` истинно, и `2 < 3` тоже истинно.
