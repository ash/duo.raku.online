## Задача

`index` говорит, *где* находится символ. Потом можно разрезать строку в этом месте с помощью `substr`. Используйте их вместе.

Возьмите адрес электронной почты `user@example.com`. Найдите позицию знака `@`. Потом напечатайте всё, что идёт после него. Это доменная часть.

## Пример

Программа выводит:

```
example.com
```
