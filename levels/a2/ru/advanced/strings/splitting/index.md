Строку можно разделить на части несколькими способами. Части можно и снова соединить.

Метод `words` разделяет строку на список слов. Слова разделяют пробельные символы, например пробел:

```raku
say 'Hello big World'.words; # (Hello big World)
```

Метод `split` разрезает строку по разделителю. Разделитель выбираете вы:

```raku
say 'a,b,c'.split(','); # (a b c)
```

Вот важный особый случай. Можно разделять по **пустой строке** `''`. Тогда вы получаете отдельные символы строки. Но вы получаете и ещё две пустые строки. Они стоят в самом начале и в самом конце. Поэтому в результате на два элемента больше, чем вы ждёте:

```raku
say 'abc'.split('').elems;        # 5 — the three letters, plus an empty string at each end
say 'abc'.split('', :skip-empty); # (a b c) — the :skip-empty adverb drops the empties
```

Хотите разделить строку на символы? Вызовите метод `comb` без аргументов. Он делает это сразу. Лишних пустых строк нет:

```raku
say 'Raku'.comb; # (R a k u)
```

Метод `join` делает обратное. Он соединяет список значений в одну строку. Он ставит разделитель между значениями:

```raku
say <a b c>.join('-'); # a-b-c
```

Ещё два метода работают с частями строки. Метод `substr` даёт вам кусок строки. Вы даёте ему начальную позицию. Если хотите, можно дать ему и длину:

```raku
say 'Hello World'.substr(0, 5); # Hello
say 'Hello World'.substr(6);    # World
```

А `trim` убирает пробельные символы на обоих концах строки:

```raku
say '  hi  '.trim; # hi
```
