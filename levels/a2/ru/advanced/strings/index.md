В части «Основы» вы узнали, [как создавать строки](/ru/essentials/strings). Вы научились соединять строки и интерполировать. Ещё вы научились находить длину строки. У строк есть и много методов. Этот раздел показывает самые полезные из них. Поиск с помощью [регулярных выражений](/ru/regexes) — отдельная, большая тема. У неё есть своя часть дальше в курсе.

Три метода меняют регистр строки. Регистр — это заглавные или строчные буквы:

```raku
say 'raku'.uc; # RAKU  — upper case
say 'RAKU'.lc; # raku  — lower case
say 'raku'.tc; # Raku  — title case (first letter capitalised)
```

Метод `flip` записывает символы строки задом наперёд:

```raku
say 'Raku'.flip; # ukaR
```

А оператор `x` повторяет строку несколько раз. Вы указываете, сколько раз:

```raku
say 'ab' x 3; # ababab
```

Следующие темы показывают, как искать в строках. Ещё они показывают, как разделять строки на части. И они показывают, как снова соединять части.
