Возьмём простые скаляры, например числа и строки. Здесь все три формы выглядят одинаково. Формы различаются у значений из нескольких частей. Ещё они различаются у неопределённых значений. Вот `Pair`, показанный тремя способами:

```raku
say (foo => 1).gist; # foo => 1
say (foo => 1).Str;  # foo	1
say (foo => 1).raku; # :foo(1)
```

Вот простое правило:

* [`.gist`](../gist) — для вывода, который *читают* люди (`say`, `note`).
* [`.Str`](../str) — для вывода в виде *простого текста* (`print`, `put`, значения внутри строк, оператор `~`).
* [`.raku`](../raku-method) — для формы, *похожей на код*, когда вы отлаживаете программу (`dd`).

Вы можете писать свои классы. В классе можно самому определить каждый из этих методов. Тогда ваши объекты тоже печатаются красиво. Мы вернёмся к этому в следующей части. Там мы [создаём классы](/ru/oop/classes).
