title: Преобразование значений в текст

Иногда программа показывает значение. Его можно вывести через `say`, напечатать или вставить в строку. Во всех этих случаях значение должно стать текстом. В Raku для этого нет одного-единственного способа. Вместо этого у каждого значения есть несколько стандартных методов. Каждый метод делает строку для своей цели:

* `.gist` — форма, которую читают люди. `say` печатает эту форму.
* `.Str` — простая строковая форма. Raku использует её, когда ему нужна строка.
* `.raku` — форма, похожая на код. Она полезна, когда вы отлаживаете программу.

Все три — обычные методы. Они есть у каждого значения в Raku. Поэтому они работают одинаково для любого значения. Это может быть число, строка или массив. Это может быть и ваш собственный объект. Следующие страницы показывают каждый метод по очереди. Потом они помогают выбрать нужный. [Следующий раздел — о `dd`](/ru/advanced/dd). Это инструмент в Rakudo. Он построен на `.raku`.
