---
title: Метод `.raku`
---

{% include menu.html %}

Третий метод — `.raku`. Он возвращает строку с формой значения, **похожей на код**. В лучшем случае эту строку можно вставить в программу. Тогда вы снова получите то же значение. Этот метод есть у каждого значения в Raku.

```raku
say 42.raku;        # 42
say 'Raku'.raku;    # "Raku"
say (1, 2, 3).raku; # (1, 2, 3)
```

Посмотрите на строку `'Raku'`. Она возвращается с кавычками. Поэтому число и строка выглядят по-разному. Такие детали нужны, когда вы отлаживаете программу.

Метод работает и для данных из многих частей. Это касается и вложенных данных, где одна структура лежит внутри другой:

```raku
my @data = 1, [2, 3], 4;
say @data.raku; # [1, [2, 3], 4]
```

`.raku` возвращает обычную строку. Поэтому его можно использовать везде, где нужна строка. Например, его можно вставить в строку в двойных кавычках:

```raku
my @data = 10, 20, 30;
say "The data is { @data.raku }";
# The data is [10, 20, 30]
```

Используйте `.raku`, когда вам нужна эта форма в виде строки. Тогда её можно добавить в свои сообщения. Совсем скоро вы познакомитесь с `dd`. Это инструмент в Rakudo. Он печатает такую же форму за вас, за один шаг.
