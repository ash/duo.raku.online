---
title: Метод `.Str`
---

{% include menu.html %}

Метод `.Str` возвращает **простую строковую** форму значения. Raku вызывает его, когда ему нужно значение в виде строки. Это называют *строковым контекстом*. `print` и `put` вызывают его. Оператор `~` тоже вызывает его. Этот оператор соединяет строки. Это работает и для значений внутри строк в двойных кавычках.

```raku
say 42.Str;    # 42
my @a = 'alpha', 'beta', 'gamma';
say @a.Str;    # alpha beta gamma
```

Обратите внимание: массив возвращается **без скобок**. Между его элементами просто стоят пробелы. Здесь видно отличие от [`.gist`](../gist). Метод `.gist` оставляет скобки. Сравните два метода рядом:

```raku
my @data = 1, 2, 3;
say @data.gist; # [1 2 3]
say @data.Str;  # 1 2 3
```

Значение внутри строки в двойных кавычках использует `.Str`. Поэтому массив внутри строки выводится в простом виде:

```raku
my @data = 10, 20, 30;
say "data: @data[]"; # data: 10 20 30
```
