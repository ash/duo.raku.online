---
title: Метод `.gist`
---

{% include menu.html %}

Метод `.gist` возвращает **удобную для человека** форму значения. Это форма, которую вы хотите *читать*. `say` печатает именно эту форму. `note` тоже печатает её. Они вызывают `.gist` для каждого аргумента.

```raku
say 42.gist;     # 42
say 'Raku'.gist; # Raku
```

Для простых значений gist — это просто само значение. У некоторых данных несколько частей. Для таких данных `.gist` добавляет немного оформления. Тогда структуру всё так же легко читать:

```raku
my @a = 'alpha', 'beta', 'gamma';
say @a.gist; # [alpha beta gamma]
```

Типовой объект — это значение. Оно обозначает сам тип. Его gist — это имя типа в скобках. Поэтому его легко заметить в выводе:

```raku
say Int.gist; # (Int)
```
