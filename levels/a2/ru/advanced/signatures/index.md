В разделе "Основы" вы [писали подпрограммы](/ru/essentials/functions). У них были позиционные и именованные параметры. У параметров были значения по умолчанию. Список параметров — это _сигнатура_. Этот раздел показывает ещё две вещи, которые умеет сигнатура. Она может сделать параметр необязательным. И она может собрать любое количество дополнительных аргументов.

## Необязательные параметры

Параметр со знаком вопроса после него — _необязательный_. При вызове его можно пропустить. Тогда параметр не определён. Поэтому можно дать другое значение взамен. Для этого используйте оператор defined-or `//`:

```raku
sub greet($name, $greeting?) {
    my $g = $greeting // 'Hello';
    say "$g, $name!";
}

greet('Anna');           # Hello, Anna!
greet('Anna', 'Hi');     # Hi, Anna!
```

Здесь мы вызываем `greet` с одним аргументом. Тогда `$greeting` не определён. Поэтому `//` даёт вместо него `'Hello'`.

## Поглощающие параметры

Параметр с символом `*` — _поглощающий_ (slurpy). Он берёт все аргументы, которые остались. Поглощающий массив вы пишете как `*@`. Он собирает любое количество позиционных аргументов в массив:

```raku
sub count-them(*@items) {
    say @items.elems;
}

count-them(1, 2, 3, 4); # 4
count-them('a', 'b');   # 2
```

Можно использовать обычные параметры вместе с поглощающим. Сначала свои значения получают фиксированные параметры. Всё остальное попадает в поглощающий массив:

```raku
sub titles($name, *@titles) {
    say "$name has {@titles.elems} title(s)";
}

titles('Anna', 'Dr', 'Prof'); # Anna has 2 title(s)
```

Поглощающий хеш работает так же. Вы пишете его как `*%`. Он собирает все дополнительные именованные аргументы в хеш:

```raku
sub register($name, *%options) {
    say "$name: {%options.elems} option(s)";
    say "role is %options<role>";
}

register('Anna', role => 'admin', active => True);
```

Два именованных аргумента становятся ключами `%options`. Поэтому программа выводит:

```
Anna: 2 option(s)
role is admin
```
