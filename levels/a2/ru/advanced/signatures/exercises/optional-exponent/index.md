## Задача

Напишите подпрограмму `power`. У неё есть обязательный параметр `$base` и **необязательный** параметр `$exp`. Если вызов передаёт показатель степени, возведите основание в эту степень. Если показателя степени нет, возведите основание в квадрат. Для этого используйте оператор defined-or `//`, чтобы дать `2`.

Вызовите её два раза. Сначала передайте только основание. Потом передайте основание и показатель степени.

## Пример

Программа выводит:

```
25
125
```
