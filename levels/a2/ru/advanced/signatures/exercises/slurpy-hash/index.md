## Задача

Напишите подпрограмму `describe`. Её первый параметр — имя. Это имя позиционное и обязательное. После него поглощающий хеш `*%opts` собирает любое количество именованных аргументов. Подпрограмма возвращает строку такого вида: `name: key=value, key=value, ...`. Строка перечисляет все опции. Ключи идут в алфавитном порядке.

Вызовите её так: `describe('Anna', colour => 'red', size => 5)`. Выведите результат.

## Пример

Программа выводит:

```
Anna: colour=red, size=5
```
