Вот один способ решить задачу.

## Код

```raku
say (2, 4 ... *).head(4);
```

🦋 Исходный код можно найти в файле [open-range.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/whatever/open-range.raku).

## Вывод

```
(2 4 6 8)
```

## Комментарии

1. Первые значения, `2, 4`, задают шаг. Каждое число на два больше предыдущего. Одна звёздочка в конце значит, что последовательность никогда не заканчивается.

1. `head(4)` берёт только первые четыре значения: `2, 4, 6, 8`. Последовательность ленивая. Поэтому Raku никогда не вычисляет бесконечный остаток. Здесь одна звёздочка значит «что угодно, без верхней границы».
