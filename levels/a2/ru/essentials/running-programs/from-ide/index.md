Эта глава очень короткая. Она показывает, как запустить программу, не выходя из IDE. Мы посмотрим на две самые рекомендуемые [IDE](../../editors-and-ides).

## Visual Studio Code Editor

Откройте терминал через меню: `Terminal` → `New Terminal` (`Терминал` → `Новый терминал`). Под текстом вашей программы открывается новая панель. Запустите там программу, как из командной строки:

```console
$ raku hello.raku
```

## Comma IDE

Чтобы запустить программу, используйте пункт `Run` в меню. Перед первым запуском настройте IDE. Следуйте [инструкциям](https://commaide.com/docs/running) на сайте Comma.
