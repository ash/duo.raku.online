---
title: Локальные переменные
---

{% include menu.html %}

Теперь вы создаёте переменную в глобальной области видимости. Ещё вы создаёте её локально, внутри блока. Что тогда происходит?

```raku
my $x = 1;

{
    my $x = 42;
    say $x;
}

say $x;
```

Теперь в программе две переменные. У них одно и то же имя. Но это разные переменные. В глобальной области видимости `$x` — это всегда глобальная переменная. Внутри блока `$x` — это локальная переменная. Это не глобальная `$x`. Программа выводит два разных значения:

```console
$ raku t.raku
42
1
```
