Блок кода — это часть вашей программы. Он находится внутри пары фигурных скобок: `{` и `}`. В блоке есть несколько инструкций. Они работают вместе, как одна большая инструкция. Следующие главы показывают много способов использовать блоки.

```raku
{
    say 'Hello, World!';
}
```

Этой программе блок кода на самом деле не нужен. Но блоки кода очень полезны в других случаях. Мы увидим их очень скоро.

Но сначала давайте узнаем, что такое _область видимости_. Она показывает, где можно использовать переменную.
