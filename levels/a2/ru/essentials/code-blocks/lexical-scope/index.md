---
title: Лексическая область видимости
---

{% include menu.html %}

Блок кода создаёт лексическую область видимости. Что это значит? Вы создаёте переменную в блоке. Она видна внутри этого блока. Потом программа выходит из блока. После этого переменная не видна. Посмотрите на пример:

```raku
{
    my $x = 42;
    say $x;
}

say $x;
```

Переменная `$x` создаётся в блоке кода. Первый `say $x` стоит внутри блока. Там переменная видна. Поэтому `say` выводит её значение. Второй `say $x` не работает. Вне блока имени `$x` нет. После конца блока программа его не знает. Программа не компилируется. Вы получаете ошибку:

```
===SORRY!=== Error while compiling /Users/ash/raku-course/t.raku
Variable '$x' is not declared
at /Users/ash/raku-course/t.raku:6
------> say ⏏$x;
```
