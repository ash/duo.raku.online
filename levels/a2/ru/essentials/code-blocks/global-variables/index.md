title: Глобальные переменные
---

{% include menu.html %}

Теперь мы создаём переменную перед блоком кода:

```raku
my $x = 1;

{
    $x = 42;
    say $x;
}

say $x;
```

Здесь `$x` — глобальная переменная. Она находится в глобальной области видимости. Вся программа может её использовать. Программа выводит `42` два раза.
