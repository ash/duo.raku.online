**Raku++** — это второй компилятор Raku. Файл его программы называется `rakupp`. Первая версия вышла в июле 2026 года. Rakudo работает на виртуальной машине MoarVM. Raku++ устроен по-другому. Автор написал его на **C++**. Ему не нужна своя виртуальная машина.

Он одновременно и **интерпретатор**, и **компилятор**. Он может выполнить программу напрямую. Ещё он может превратить программу в машинный код. Так она работает быстрее. Ему не нужно сначала запускать большую среду выполнения. Поэтому `rakupp` запускается всего за несколько миллисекунд. Это удобно для коротких скриптов. Это удобно и для повседневной работы в командной строке. Автор называет его самым быстрым компилятором Raku.

По умолчанию Raku++ поддерживает Raku 6.d. Он также поддерживает 6.e. Программа просит 6.e с помощью `use v6.e.PREVIEW`. Версия 5.4.1 вышла в октябре 2026 года. Она проходит все 1425 тестовых файлов Roast. Roast — это официальный набор тестов Raku.

Raku++ также работает в веб-браузере. Для этого его компилируют в WebAssembly. Песочница на [raku.online](https://raku.online) работает на нём. Там вы можете попробовать Raku, ничего не устанавливая.

## Режимы интерпретатора и компилятора

Запустите программу напрямую, как с Rakudo:

```console
$ rakupp hello.raku
```

Или попросите Raku++ сделать файл программы в машинном коде. Он работает сам по себе. И он ещё быстрее:

```console
$ rakupp --exe hello.raku -o hello
$ ./hello
```

Для обычной учёбы вам нужен только простой режим интерпретатора. Режимы компиляции нужны для большей скорости.
