---
title: Ввод с использованием `prompt`
---

{% include menu.html %}

`prompt` — это противоположность `say`. Он ждёт пользователя. Пользователь что-то вводит и нажимает Enter. Потом `prompt` передаёт этот ввод в программу в виде строки. Вы можете взять результат `prompt` и передать его в `say`. Тогда программа повторяет то, что вводит пользователь. Давайте напишем такую программу:

```raku
say prompt;
```

Запустите эту программу. Возможно, вы не поймёте, что происходит. Программа только ждёт ввода. Поэтому хорошо сначала напечатать сообщение. Тогда программой проще пользоваться. Для этого не нужен отдельный `say`. Вы можете передать сообщение в `prompt`:

```raku
prompt 'What language are you going to learn? '
```

Эта глава скоро закончится. Но сначала давайте соберём все части вместе. Новая программа спрашивает, чего хочет пользователь. Потом она печатает фразу с текстом от пользователя.

```raku
say 'You are going to learn ', prompt 'What language are you going to learn? ';
```

Если вы введёте `Raku`, программа напечатает такую фразу:

```
You are going to learn Raku
```

Хорошо, теперь мы можем говорить с программой. И мы можем заставить программу говорить с нами!

Заметьте: функция `say` должна знать строки, прежде чем их напечатать. Поэтому Raku сначала выполняет `prompt`. Так диалог идёт в правильном порядке:

```console
$ raku t.raku
What language are you going to learn? Raku
You are going to learn Raku
```
