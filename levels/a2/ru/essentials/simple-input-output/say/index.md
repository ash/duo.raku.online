---
title: Вывод с использованием `say`
---

{% include menu.html %}

Функция `say` печатает значения в стандартный поток вывода, `STDOUT`. Её также называют подпрограммой, или просто программой. Вы запускаете программу в терминале? Тогда вы видите вывод там. Вы используете онлайн-сервис? Тогда вывод попадает в особую часть веб-страницы.

Вот пример использования `say`:

```raku
say 42;
```

Эта строка может быть частью большой программы. Она также может быть целой программой. Конечно, она выводит `42`.

Теперь давайте попробуем строку:

```raku
say 'Hello, World!';
```

Хорошо! Теперь `Hello, World!` на экране.

Подпрограмма `say` может принимать больше одного аргумента. Поэтому мы можем напечатать несколько значений сразу:

```raku
say 42, 'Hello, World!';
```

Но посмотрите на вывод. Все его части идут одной строкой: `42Hello, World!`. Поэтому лучше добавить между ними пробел. Вы уже можете решить эту проблему. Например, вот так:

```raku
say 42, ' ', 'Hello, World!';
```

Подпрограмма `say` печатает все аргументы. Потом она добавляет в вывод символ новой строки.
