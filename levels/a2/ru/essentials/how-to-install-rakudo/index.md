Вам нужен компилятор, чтобы запустить программу на Raku. Сначала его нужно установить. В этом курсе мы используем Rakudo. Есть также [Raku++](/ru/essentials/the-rakupp-compiler) и [mutsu](/ru/essentials/the-mutsu-interpreter). Их устанавливают отдельно. Прочитайте страницы [Как установить Raku++](/ru/essentials/how-to-install-rakupp) и [Как установить mutsu](/ru/essentials/how-to-install-mutsu). Зайдите на [сайт Rakudo](https://rakudo.org). Там вы можете скачать нужную версию для вашей операционной системы.

## Исходники

Скачайте установщик для вашей системы на странице [rakudo.org/downloads](https://rakudo.org/downloads). Есть версии для всех главных операционных систем: Windows, Mac OS и Linux. Есть также исходный код. Вы можете сами его скомпилировать.

## Docker-образы

Rakudo можно получить и в виде docker-образа. С ним вы можете запускать программы. Ещё вы можете проверять небольшие скрипты в оболочке REPL. Все инструкции есть на [github.com/Raku/docker](https://github.com/Raku/docker).

## Номера версий

Номер версии Rakudo состоит из двух частей. Это год и месяц выпуска. Так вы легко видите, насколько новый ваш компилятор. Выполните эту команду, чтобы увидеть номер версии:

```console
$ raku -v
Welcome to 𝐑𝐚𝐤𝐮𝐝𝐨™ v2026.06.
Implementing the 𝐑𝐚𝐤𝐮™ programming language v6.d.
Built on MoarVM version 2026.06.
```

Здесь вы видите три номера версий. Первый — это версия самого Rakudo: `v2026.06`. Дальше идёт версия языка Raku: `v6.d`. Пока каждое обновление языка получает следующую букву. Эта буква — младшая, или малая, часть версии. Например, следующей будет `v6.e`, и так далее. В конце вы видите название виртуальной машины. Этот компилятор использует MoarVM версии `2026.06`.
