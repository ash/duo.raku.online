## Задача

Напишите программу. Она берёт два целых числа из командной строки. Потом она выводит их сумму. Используйте функцию `MAIN`. У её параметров должны быть типы.

## Пример

Вот пример:

```console
$ raku print-the-sum.raku 500 700
1200
```
