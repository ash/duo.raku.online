---
title: Несколько функций `MAIN`
---

{% include menu.html %}

Как любая другая функция в Raku, `MAIN` может иметь варианты `multi`. Так программа может по-разному реагировать на разные входные данные. Во входных данных может быть разное число параметров. Или у параметров могут быть разные типы.

```raku
multi sub MAIN($a) {
    say 2 * $a;
}

multi sub MAIN($a, $b) {
    say $a + $b;
}
```

С одним аргументом эта программа удваивает его. С двумя аргументами она складывает их:

```console
$ raku t.raku 21
42

$ raku t.raku 21 33
54
```
