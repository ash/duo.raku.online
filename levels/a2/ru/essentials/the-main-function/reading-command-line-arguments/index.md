---
title: Чтение аргументов командной строки
---

{% include menu.html %}

Функция `MAIN` полезна по двум причинам. Во-первых, она ясно показывает, где начинается программа. Во-вторых, у неё есть аргументы. Они получают значения из командной строки.

Есть два способа читать аргументы командной строки. Один способ — это массив [`@*ARGS`](/ru/essentials/positionals/args-array). Мы уже использовали его. Теперь давайте посмотрим на второй способ.

Посмотрите на эту программу. Она складывает два числа.

```raku
sub MAIN($a, $b) {
    say $a + $b;
}
```

Запустите программу так. Она выводит сумму двух своих аргументов:

```console
$ raku t.raku 123 45
168
```

Как любая другая функция, `MAIN` может иметь значения по умолчанию для аргументов. Они могут быть у некоторых аргументов. Они могут быть даже у всех аргументов. Например:

```raku
sub MAIN($a, $b = 100) {
    say $a + $b;
}
```

Иногда второго аргумента нет. Тогда программа использует значение по умолчанию:

```console
$ raku t.raku 15
115
```
