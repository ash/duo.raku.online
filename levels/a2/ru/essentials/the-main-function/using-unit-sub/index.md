---
title: Использование `unit sub`
---

{% include menu.html %}

С `unit sub` остальная часть файла становится телом функции! Это очень удобно с `MAIN`. Без `unit sub` фигурные скобки стоят вокруг почти всего файла. С `unit sub` эти скобки не нужны. Кроме того, строкам не нужны лишние пробелы в начале.

Вот пример программы с `unit sub`.

```raku
unit sub MAIN($a, $b);

my $sum = $a + $b;
say "Сумма $a и $b равна $sum.";
```

В этом файле `MAIN` — единственная функция. В вашей программе тоже так? Тогда попробуйте использовать `unit sub MAIN`, как в примере выше.
