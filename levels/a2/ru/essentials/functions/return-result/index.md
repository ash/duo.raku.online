title: Возврат результата
---

{% include menu.html %}

Часто функция что-то делает и ещё возвращает результат. Например, в функциональном программировании у функций не должно быть побочных эффектов. Вывод на консоль — один из таких побочных эффектов. Но Raku разрешает так делать. Давайте посмотрим, как функция возвращает значение. Мы также посмотрим, как вызывающий код получает это значение.

```raku
sub add($x, $y) {
    return $x + $y;
}

my $sum = add(10, 20);
say $sum; # 30
```

Здесь функция `add` принимает два числа. Она возвращает их сумму. В коде функции есть слово `return`. Вызывающий код может использовать это значение как любое другое. В программе выше мы присваиваем его переменной.

## Последнее значение

Результат может быть последним значением в теле функции. Тогда в Raku вам не нужно писать `return`. Поэтому мы можем сделать нашу функцию `add` проще:

```raku
sub add($x, $y) {
    $x + $y
}
```

Обратите внимание: в конце строки нет точки с запятой. Это последняя строка в блоке кода. Поэтому точка с запятой там не нужна.

Такие маленькие и простые функции часто пишут в одну строку. Тогда код короче:

```raku
sub add($x, $y) { $x + $y }
```

## Нечего возвращать

Иногда из функции нужно выйти до конца её тела. Если функция не возвращает результат, напишите `return` без значения.

```raku
sub test($x) {
    return if $x <= 10;
    say "$x is above the limit";
}
```
