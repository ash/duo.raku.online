Теперь мы передадим данные в функцию. Функция может принимать параметры. Напишите их в скобках сразу после имени функции.

```raku
sub greet($name) {
    say "Hello, $name!";
}
```

Теперь вы можете использовать функцию. Вы можете передавать ей разные аргументы:

```raku
greet('Алла');
greet('Карл');
```

Мы вызываем одну и ту же функцию два раза. Теперь результаты разные:

```console
$ raku t.raku
Hello, Алла!
Hello, Карл!
```

%%tipblock

## Параметр или аргумент

Люди часто используют эти два слова одинаково. Оба слова — об «одном и том же». Но они смотрят на это с разных сторон.

* Параметр — это то, что функция ожидает получить.
* Аргумент — это то, что вы передаёте функции.

В примере выше `$name` — это параметр функции. `'Алла'` и `'Карл'` — это её аргументы.

%%/tipblock

## Больше параметров

Функция может принимать больше одного параметра. Тогда ставьте между ними запятые:

```raku
sub add($x, $y) {
    say $x + $y;
}

add(10, 20); # 30
```

## Без параметров

У функции может совсем не быть параметров. Тогда вы можете написать пустые скобки. Или вы можете совсем не писать скобки. Мы так сделали в [начале этого раздела](../).

```raku
sub greet() {
    say 'Hello, World!';
}

greet();
```
