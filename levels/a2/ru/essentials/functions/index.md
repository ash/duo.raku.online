Этот раздел — последний в первой части курса. После него вы можете написать почти _любую_ программу на Raku. Этот раздел — о _функциях_. У функций есть и другие названия: _подпрограммы_ или просто _рутины_.

Функция — это часть кода со своим именем. Вы можете использовать её много раз. Чтобы использовать функцию, вы её _вызываете_. Вы можете вызвать её из разных мест программы.

## Создание функции

Чтобы создать функцию, напишите ключевое слово `sub`. После него напишите имя функции. Тело функции напишите в фигурных скобках.

```raku
sub greet {
    say 'Hello, World!';
}
```

## Использование функции

Чтобы использовать функцию, просто напишите её имя. Напишите его там, где вы хотите вызвать функцию. В Raku вы можете создать функцию до этого места. Вы можете создать её и после этого места.

```raku
say 'This is what the first program usually prints:';
greet;    

sub greet {
    say 'Hello, World!';
}
```

Программа выводит оба сообщения:

```console
$ raku t.raku
This is what the first program usually prints:
Hello, World!
```
