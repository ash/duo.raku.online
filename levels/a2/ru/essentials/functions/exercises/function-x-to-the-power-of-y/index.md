## Задача

Напишите функцию с двумя аргументами, `$x` и `$y`. Она возвращает `$x` в степени `$y`. Потом напишите программу. Она печатает значения `5³`, `2¹⁰` и `(−4)⁵`.

## Пример

Для этих значений программа печатает вот что:

```
$ raku function-x-to-the-power-of-y.raku
125
1024
-1024
```
