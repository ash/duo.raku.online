## Проблема

Напишите функцию. Она вычисляет математическую константу _e_. Результат не точный, но близкий. Используйте эту формулу:

<img src="e-formula.png" style="height: 4.5em; width: auto">

Функция должна работать двумя способами:

1. Аргумент задаёт число элементов в формуле: `e-approx(10)`.
2. Без аргумента в сумме 100 элементов: `e-approx()`.

Выведите результаты для обоих случаев.

## Пример

```console
$ raku the-value-of-e.raku
2.7182818
2.718281828459045
```
