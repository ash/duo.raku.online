Позиционные и именованные параметры могут иметь значения по умолчанию. Параметр со значением по умолчанию не обязателен. Вы можете пропустить его, когда вызываете функцию. Тогда параметр получает своё значение по умолчанию.

## Позиционные параметры

Вот пример. У функции есть позиционный параметр со значением по умолчанию:

```raku
sub greet($name = 'World') {
    say "Hello, $name!";
}

greet('Merinda');
greet();
```

Первый вызов передаёт имя как единственный аргумент. Поэтому он печатает `Hello, Merinda!`. Второй вызов использует значение по умолчанию. Он печатает `Hello, World!`.

Иногда у функции больше одного параметра. Тогда значения по умолчанию должны быть в конце списка:

```raku
sub f($a, $b, $c = 42, $d = 50) { . . . } # правильно
# sub f($a = 10, $b = 20, $c, $d) { . . . } # НЕПРАВИЛЬНО
```

## Именованные параметры

Именованные параметры получают значения по умолчанию так же:

```raku
sub greet(:$name = 'World') {
    say "Hello, $name!";
}

greet(name => 'Merinda'); # Hello, Merinda!
greet(); # Hello, World!
```

Порядок именованных параметров не важен. Поэтому значение по умолчанию может быть у любого из них. Оно может быть даже у первого в списке:

```raku
sub greet(:$greeting = 'Hello', :$name) {
    say "$greeting, $name!";
}

greet(name => 'Alla'); # Hello, Alla!
```
