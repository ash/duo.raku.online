title: Позиционные параметры
---

{% include menu.html %}

Порядок параметров функции важен. Например, возьмём функцию. Она находит разницу между двумя числами:

```raku
sub diff($a, $b) { $a - $b }
```

Конечно, `diff(10, 20)` и `diff(20, 10)` дают разные результаты.

В функции выше параметры идут списком через запятую. Такие параметры называют _позиционными_. В вызове порядок аргументов важен. От него зависит значение каждого параметра.
