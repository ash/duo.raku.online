_Именованные_ параметры не похожи на [позиционные параметры](../positional-parameters). В вызове вы пишете их имена.

Эта функция принимает два параметра. Их имена — `$from` и `$to`.

```raku
sub distance(:$from, :$to) { $from - $to }
```

Чтобы вызвать функцию, напишите имя каждого аргумента:

```raku
say distance(from => 30, to => 10); # 20
```

Не передавайте аргументы как позиционные. Это ошибка. Например, вызов `distance(30, 10)` даёт ошибку:

    Слишком много позиционных аргументов; ожидалось 0 аргументов, но получено 2
        в подпрограмме distance на строке 1 в t.raku
        в блоке <unit> на строке 2 в t.raku

А вот хорошая новость. Вы можете писать именованные аргументы в любом порядке. Эти два вызова делают точно одно и то же:

```raku
say distance(from => 30, to => 10); # 20

say distance(to => 10, from => 30); # 20
```

## Передача переменных

Иногда вы хотите передать значение из переменной. У переменной то же имя, что и у параметра. Тогда помогает особый синтаксис. С ним вы пишете меньше:

```raku
my $from = 30;
my $to = 10;
say distance(:$from, :$to); # 20
```

Этот вызов делает то же, что и более длинный:

```raku
say distance(from => $from, to => $to); # 20
```

И снова порядок не важен:

```raku
say distance(:$to, :$from); # 20
```

Иногда у переменной и параметра разные имена. Тогда передайте пару одним из этих способов:

```raku
my $a = 20;
my $b = 10;

say distance(from => $a, to => $b);

# или:

say distance(:from($a), :to($b));
```
