Вы можете также написать `loop` только с телом:

```raku
loop {
    say 'Вечность';
}
```

Этот цикл никогда не останавливается сам. Вам нужно остановить программу, например, с помощью `Ctrl+C`. Во второй части курса есть лучшие способы управлять циклами.
