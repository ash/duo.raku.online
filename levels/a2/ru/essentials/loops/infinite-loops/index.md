Вы можете также использовать `loop` только с телом:

```raku
loop {
    say 'Вечность';
}
```

Этот цикл работает вечно. Он останавливается, только когда вы останавливаете программу, например, с помощью `Ctrl+C`. Во второй части курса вы узнаете лучшие способы управлять циклами.
