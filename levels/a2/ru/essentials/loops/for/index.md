Цикл `for` очень полезен. Он проходит по многим элементам, по одному за раз. Например, возьмём диапазон:

```raku
for 1..5 -> $n {
    say $n;
}
```

`$n` каждый раз получает следующее значение из диапазона. Вам не нужно писать `my` перед `$n`. Блок выполняется один раз для каждого значения из диапазона. Поэтому программа печатает числа, по одному на каждой строке:

```console
$ raku t.raku 
1
2
3
4
5
```

Программа проходит по всем значениям [диапазона](/ru/essentials/ranges) `1..5`. Эти значения — `1`, `2`, `3`, `4` и `5`.

## Больше одного значения за раз

В Raku цикл может каждый раз брать два элемента или больше. Эта программа печатает по два числа за раз:

```raku
for 1..6 -> $n, $m {
    say "$n and $m";
}
```

Вот что печатает программа:

```console
$ raku t.raku
1 and 2
3 and 4
5 and 6
```
