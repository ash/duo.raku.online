Цикл `for` — это мощный инструмент. Он проходит по многим элементам, один за другим. Например, возьмём диапазон:

```raku
for 1..5 -> $n {
    say $n;
}
```

В этой программе переменная `$n` каждый раз получает следующее значение из диапазона. Вам не нужно объявлять переменную с помощью `my`. Блок кода выполняется один раз для каждого элемента диапазона. Поэтому программа печатает числа, по одному на каждой строке:

```console
$ raku t.raku 
1
2
3
4
5
```

Программа проходит по всем значениям [диапазона](/ru/essentials/ranges) `1..5`. Это `1`, `2`, `3`, `4` и `5`.

## Больше одного значения за раз

В Raku цикл может брать больше одного элемента за раз. Эта программа каждый раз печатает два числа:

```raku
for 1..6 -> $n, $m {
    say "$n and $m";
}
```

Вот вывод программы:

```console
$ raku t.raku
1 and 2
3 and 4
5 and 6
```
