---
title: Постфиксная форма `for`
---

{% include menu.html %}

Вы уже знаете другие модификаторы операторов: [`if` и `else`](/ru/essentials/conditional-checks/modifiers) и [`while` и `until`](/ru/essentials/loops/modifiers). Это хорошая новость. В Raku похожие вещи работают похожим образом.

После короткого тела цикла может стоять `for`:

```raku
.say for 1..7;
```

С `for` в конце диапазоны выглядят очень естественно.

Эта программа делает то же самое, что и обычный цикл:

```raku
for 1..7 -> $n {
    say $n;
}
```

Или она делает то же, что этот цикл с `$_`:

```raku
for 1..7 {
    .say;
}
```

Здесь `.say` — это короткий способ записать `$_.say`.
