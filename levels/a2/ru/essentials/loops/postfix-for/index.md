---
title: Постфиксная форма `for`
---

{% include menu.html %}

Вы уже знаете другие модификаторы операторов: [`if` и `else`](/ru/essentials/conditional-checks/modifiers) и [`while` и `until`](/ru/essentials/loops/modifiers). Это хорошая новость, потому что дизайн Raku очень последовательный.

Когда тело цикла короткое, можно написать `for` после него:

```raku
.say for 1..7;
```

С такой формой `for` диапазоны выглядят очень естественно.

Эта программа делает то же самое, что и более привычный цикл:

```raku
for 1..7 -> $n {
    say $n;
}
```

Или, с переменной цикла по умолчанию, она делает то же, что и этот код:

```raku
for 1..7 {
    .say;
}
```

Здесь `.say` — это короткий способ записать `$_.say`.
