Оператор `loop` в Raku похож на классические циклы в языке C и в близких к нему языках. Он принимает три выражения. Первое задаёт начальное значение. Второе — это проверка. Третье меняет переменную цикла. Тело цикла выполняется снова и снова, пока проверка даёт `True`.

```raku
loop (my $c = 0; $c < 5; $c++) {
    say "Текущее значение счетчика: $c.";
}
```

Здесь `++` — это оператор после переменной. Он прибавляет 1 к переменной. Больше операторов вы узнаете во второй части курса.

Программа выполняет тело цикла пять раз.

```console
$ raku t.raku
Текущее значение счетчика: 0.
Текущее значение счетчика: 1.
Текущее значение счетчика: 2.
Текущее значение счетчика: 3.
Текущее значение счетчика: 4.
```

Можно пропустить некоторые или даже все выражения в заголовке `loop`. Например, вот та же программа:

```raku
my $c = 0;
loop (; $c < 5;) {
    say "Текущее значение счетчика: $c.";
    $c++;
}
```

## * * *

В Raku `loop` используют не очень часто. Его можно увидеть, например, в программах, которые инструмент перевёл с C на Raku. В Raku есть более простые циклы, например `for`. Цикл `for` мы рассмотрим очень скоро.
