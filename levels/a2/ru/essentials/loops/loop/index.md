В Raku есть оператор `loop`. Он работает как циклы в C и похожих языках. У него три выражения. Первое даёт переменной цикла начальное значение. Второе — это проверка. Третье меняет переменную цикла. Цикл работает, пока проверка даёт `True`.

```raku
loop (my $c = 0; $c < 5; $c++) {
    say "Текущее значение счетчика: $c.";
}
```

Здесь `++` — это оператор. Вы пишете его после переменной. Он прибавляет 1 к переменной. Во второй части курса есть ещё операторы.

Тело цикла выполняется пять раз.

```console
$ raku t.raku
Текущее значение счетчика: 0.
Текущее значение счетчика: 1.
Текущее значение счетчика: 2.
Текущее значение счетчика: 3.
Текущее значение счетчика: 4.
```

Вы можете пропустить некоторые из трёх выражений в `loop`. Можно даже пропустить их все. Например, вот та же программа:

```raku
my $c = 0;
loop (; $c < 5;) {
    say "Текущее значение счетчика: $c.";
    $c++;
}
```

## * * *

В Raku `loop` используют не очень часто. Иногда инструмент переводит код с C на Raku. В таком коде вы можете увидеть `loop`. В Raku есть более простые циклы, например `for`. Цикл `for` мы рассмотрим очень скоро.
