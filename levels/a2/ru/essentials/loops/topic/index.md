`$_` — это специальная переменная. Она называется _переменной topic_.

Посмотрите на этот цикл по диапазону:

```raku
for 1..5 -> $n {
    say $n;
}
```

Вам не нужно писать `$n`. Без неё Raku использует переменную `$_`. Raku создаёт эту переменную за вас. Поэтому эта программа делает то же самое:

```raku
for 1..5 {
    say $_;
}
```

Вы [уже знаете](/ru/essentials/hello-world/), что `say` может быть и методом:

```raku
for 1..5 {
    $_.say;
}
```

При вызове метода на `$_` имя `$_` не нужно. Поэтому цикл может быть ещё короче:

```raku
for 1..5 {
    .say;
}
```
