`$_` — это специальная переменная. Она называется _переменной topic_.

Посмотрите на этот цикл по диапазону:

```raku
for 1..5 -> $n {
    say $n;
}
```

Переменную `$n` можно не писать. Тогда Raku вместо неё использует переменную `$_`. Программа делает то же самое, что и эта:

```raku
for 1..5 {
    say $_;
}
```

Вы [уже знаете](/ru/essentials/hello-world/), что `say` можно использовать как метод:

```raku
for 1..5 {
    $_.say;
}
```

Когда вы вызываете метод на `$_`, писать саму переменную не нужно. Поэтому цикл может быть ещё короче:

```raku
for 1..5 {
    .say;
}
```
