Этой программе нужен цикл, который останавливается, когда пользователь вводит особое слово.

## Код

Задачу можно решить несколькими похожими способами: с `while`, `until` или `repeat`. Вот один из них.

```raku
my $word;
repeat {
    $word = prompt 'Ваше слово: ';
    say $word;
} while $word ne 'достаточно';

say 'OK, готово.';
```

🦋 Найдите программу в файле [echo-until-enough.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/loops/echo-until-enough.raku).

## Вывод

Запустите программу и введите несколько разных слов. Потом остановите цикл.

```console
$ raku exercises/loops/echo-until-enough.raku
Ваше слово: это
это
Ваше слово: есть
есть
Ваше слово: мое
мое
Ваше слово: слово
слово
Ваше слово: достаточно
достаточно
OK, готово.
```

## Комментарий

Обратите внимание: вы объявляете переменную `$word` _до_ цикла. Проверка `while` находится вне тела цикла. Если вы определите переменную внутри цикла, проверка её не увидит.
