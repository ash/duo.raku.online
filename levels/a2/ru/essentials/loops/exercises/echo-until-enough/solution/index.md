Этой программе нужен цикл. Цикл останавливается, когда пользователь вводит особое слово.

## Код

Вы можете решить задачу с помощью `while`, `until` или `repeat`. Эти способы очень похожи. Вот один из них.

```raku
my $word;
repeat {
    $word = prompt 'Ваше слово: ';
    say $word;
} while $word ne 'достаточно';

say 'OK, готово.';
```

🦋 Найдите программу в файле [echo-until-enough.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/loops/echo-until-enough.raku).

## Вывод

Запустите программу. Введите несколько разных слов. Потом остановите цикл.

```console
$ raku exercises/loops/echo-until-enough.raku
Ваше слово: это
это
Ваше слово: есть
есть
Ваше слово: мое
мое
Ваше слово: слово
слово
Ваше слово: достаточно
достаточно
OK, готово.
```

## Комментарий

Обратите внимание: вы создаёте переменную `$word` _до_ цикла. Проверка `while` стоит не внутри тела цикла. Поэтому проверка не может увидеть переменную из тела цикла.
