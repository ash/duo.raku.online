## Задача

Напишите программу, которая делит целые числа с помощью вычитания. Числа уже есть в самой программе:

```raku
my $a = 175;
my $b = 25;
```

Допишите программу. Она должна выводить целую часть от `$a / $b`. Используйте только цикл и вычитание.

## Пример

```console
$ raku division-via-subtraction.raku
7
```
