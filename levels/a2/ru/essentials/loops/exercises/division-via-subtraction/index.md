## Задача

Напишите программу, которая делит одно целое число на другое. Она должна использовать вычитание. Числа уже есть в коде:

```raku
my $a = 175;
my $b = 25;
```

Допишите программу. Она должна печатать целую часть от `$a / $b`. Используйте только цикл и вычитание.

## Пример

```console
$ raku division-via-subtraction.raku
7
```
