title: Присвоение значения

{% include menu.html %}

Оператор `=` записывает новое значение в скалярный контейнер.

```raku
my $name;
$name = 'Anna';
```

Теперь вы можете использовать переменную. Например, вы можете её напечатать:

```raku
say $name;
```

## Сразу две переменные или больше

Можно присвоить значения нескольким переменным сразу. Например, здесь одна инструкция присваивает значения двум скалярам:

```raku
my ($a, $b);
($a, $b) = 10, 20;
```

Слева нужно обязательно писать скобки. Их нельзя убрать. Справа их тоже можно добавить. Тогда обе стороны выглядят одинаково:

```raku
($a, $b) = (10, 20);
```
