---
title: Оператор присвоено-или
---

{% include menu.html %}

Иногда у переменной ещё нет значения. Тогда вместо него можно взять другое значение. Для этого есть оператор `//`. Он называется оператором _присвоено-или_.

```raku
my $a = 'alpha';
say $a // 'gamma';

my $b;
say $b // 'delta';
```

Эта программа выведет:

```
alpha
delta
```

В первой строке `$a` получает значение. Поэтому выражение `$a // 'gamma'` использует текущее значение `$a`. С переменной `$b` всё по-другому. У неё нет значения. Поэтому `$b // 'delta'` даёт значение справа. Программа печатает `delta`.

## //=

Вместе `//` и `=` дают оператор `//=`. Он присваивает значение, только когда переменная не определена.

```raku
my $x;
$x //= 42;
say $x; # 42
```
