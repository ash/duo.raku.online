## Проблема

Напишите программу. Сначала она создаёт две переменные. В каждую она кладёт целое число. Потом она меняет значения местами. Каждая переменная получает значение другой. В конце программа печатает значения. Постарайтесь сделать программу как можно проще. Не используйте временные, то есть лишние, переменные.
