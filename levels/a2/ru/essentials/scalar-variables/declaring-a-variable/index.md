---
title: Объявление переменной
---

{% include menu.html %}

Переменную нужно объявить до того, как её использовать. В Raku для этого есть особые слова. Они называются _объявителями_. Чтобы объявить переменную, используйте `my`, вот так:

```raku
my $name;
```

Теперь у вас есть новая переменная. У неё ещё нет значения. Но компилятор уже знает её имя. Потом программа снова использует это имя. Тогда компилятор знает, какая это переменная.

## Больше, чем одна переменная

Один `my` может объявить две переменные или больше:

```raku
my ($x, $y);
```
