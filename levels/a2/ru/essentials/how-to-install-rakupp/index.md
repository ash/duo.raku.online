Raku++ можно скачать с его сайта, [raku.online](https://raku.online). Он также есть на GitHub: [github.com/ash/rakupp](https://github.com/ash/rakupp). Когда вы его устанавливаете, вы получаете один файл программы: `rakupp`. Больше ничего настраивать не нужно. У Raku++ нет отдельной виртуальной машины для установки.

## Установщик

В macOS, Linux и системах BSD нужна только одна команда. Она скачивает сборку для вашего компьютера. Она проверяет сборку. Потом она добавляет `rakupp` в ваш `PATH`. Ей не нужны права администратора:

```console
$ curl -fsSL https://raku.online/install.sh | sh
```

В Windows вместо этого используйте окно PowerShell. Другой способ — программа установки, `rakupp-setup-windows-x64.exe`. Её можно скачать со страницы релизов репозитория. Вот команда для PowerShell:

```console
> irm https://raku.online/install-windows.ps1 | iex
```

Установщик спрашивает, нужно ли вам ещё имя `raku` для Raku++. После этого откройте новый терминал. Тогда новый `PATH` начнёт работать. Позже `rakupp upgrade` обновит его до самого нового выпуска.

## Другие способы установки

* В macOS, через Homebrew: `brew tap ash/rakupp && brew install rakupp`.
* С Docker вам не нужно ничего устанавливать. Команда `docker run --rm -it ghcr.io/ash/rakupp` запускает интерактивную оболочку REPL.
* Есть готовые архивы для каждой платформы. Они лежат на странице релизов репозитория.
* Raku++ написан на C++. Поэтому вы можете сами собрать его из исходного кода. В репозитории написано, какие инструменты вам нужны.

## Номера версий

Какая у вас версия? Используйте опцию `--version`:

```console
$ rakupp --version
Raku++ 5.4.1 (2026-10-13) arm64-darwin
```

Эта строка показывает три вещи. Первая — выпуск самого Raku++: `5.4.1`. Вторая — дата сборки. Третья — платформа для этого файла программы. Версия языка Raku — это другое. Вы можете спросить её у самого языка:

```console
$ rakupp -e 'say $*RAKU.version'
v6.d
```

Сравните это с сообщением о версии Rakudo. Оно есть на [странице установки Rakudo](/ru/essentials/how-to-install-rakudo). Вы увидите, как два компилятора показывают свои версии.
