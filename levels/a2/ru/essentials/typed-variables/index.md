В Raku скалярная переменная, или скалярный контейнер, хранит один объект. Этот объект может быть разных типов. Например, одна и та же переменная может сначала содержать число. Потом она может содержать строку:

```raku
my $var = 42;
$var = 'Hello';
```

Вот ещё один пример. В одном выражении есть разные типы данных:

```raku
my $a = '100';
my $b = 200;
say $a + $b; # 300
```

Наверное, так писать код не очень хорошо. Но это полностью правильная программа на Raku.

Но Raku также позволяет указать, что может хранить переменная. Темы ниже расскажут об этом больше.
