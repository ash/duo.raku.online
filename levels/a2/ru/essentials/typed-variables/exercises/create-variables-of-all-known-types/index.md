## Задача

Напишите программу. Она создаёт несколько скалярных переменных. Она даёт им значения таких типов: `Int`, `Rat`, `Num`, `Bool` и `Str`. Программа выводит каждое значение и его тип.

## Пример

Ваш вывод может быть другим. Но этот тестовый запуск показывает идею:

```console
$ raku types.raku
151 (Int)
4.2 (Rat)
1e10 (Num)
True (Bool)
xyz (Str)
```
