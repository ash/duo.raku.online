## Код

Вот полная программа. Она решает задачу. Она выводит значение, которое вы вводите, и его тип.

```raku
my $n = prompt 'Введите число: ';
say $n;
say $n.WHAT;
```

🦋 Исходный код можно найти в файле [prompt-numbers.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/typed-variables/prompt-numbers.raku).

## Тестовые запуски

Запустите программу несколько раз. Вводите числа разных типов.

### Целые числа

Сначала давайте попробуем целые числа. Попробуйте положительные и отрицательные.

```console
$ raku exercises/what/prompt-numbers.raku
Введите число: 10
10
(IntStr)
```

Тип результата — `IntStr`. Этот тип встроен в Raku. У него есть свойства `Int` и свойства `Str`.

### Рациональные числа

Теперь давайте попробуем рациональное число. Помните: в Raku число с десятичной точкой — это `Rat`. Это не число с плавающей запятой.

```console
$ raku exercises/what/prompt-numbers.raku
Введите число: 3.14
3.14
(RatStr)
```

На этот раз данные в `$n` имеют тип `RatStr`. Это комбинированный тип. Он одновременно `Rat` и `Str`.

### Числа с плавающей запятой

Наконец, попробуйте число в научной нотации, с буквой `e`. Теперь вы, наверное, можете угадать вывод.

```console
$ raku exercises/what/prompt-numbers.raku
Введите число: 5e-14
5e-14
(NumStr)
```

Да, новое значение имеет тип `NumStr`.
