title: Приведение типов для типизированных переменных
---

{% include menu.html %}

Ограничения типов — это правила для типов переменных. Эти правила довольно строгие. Например, возьмём переменную типа `Int`. Ей нельзя присвоить значение типа `Num`. Это так, даже если значение — целое число:

```raku
my Int $x = 42;
# $x = 42e1; # Ошибка
```

Чтобы преобразовать значение, используйте [один из методов](/ru/essentials/coercion/#topics-in-this-section).

```raku
my Int $x = 42;
$x = 42e1.Int;
$x = Int(42e1);
```
