---
title: Ограничения типов
---

{% include menu.html %}

В Raku есть так называемая постепенная типизация. Это значит, что типы можно использовать только там, где вы хотите. Обычно вам не нужно указывать тип переменной. Но иногда вы можете захотеть ограничить тип переменной. Тогда укажите тип вот так:

```raku
my Int $var = 42;
```

Теперь можно присвоить `$var` другое целое значение. Но строку в неё положить нельзя. Даже число с плавающей запятой туда положить нельзя. Если вы попробуете, вы получите исключение:

```raku
my Int $var = 42;
$var = '314E-2';
```

Программа выдаёт такую ошибку:

    Ошибка проверки типа при присвоении $var; ожидался Int, но получен Str ("314E-2")
      в блоке <unit> на строке 2 в t.raku
