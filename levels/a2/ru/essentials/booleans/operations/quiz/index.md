Ниже есть несколько программ. Что выводит каждая программа? Выберите правильный ответ.

## 1

Вот программа:

```raku
my $value = True && False;
say $value;
```

Что она выведет?

{:.quiz}
0 | True
1 | False

## 2 

Что выведет вторая программа?

```raku
my $value = True && False || True;
say $value;
```

{:.quiz}
1 | True
0 | False

## 3

Что выводит эта программа?

```raku
my $value = True || False && True;
say $value;
```

{:.quiz}
1 | True
0 | False

{% include quiz.html %}

## Комментарии

Во второй и третьей программах есть выражения с тремя булевыми значениями. Результат зависит от порядка операций. У оператора `&&` приоритет выше, чем у `||`. Поэтому Raku сначала выполняет `&&`.
