Вы можете делать все обычные операции с булевыми значениями. Это логическое И, ИЛИ и исключающее ИЛИ. Исключающее ИЛИ также называют XOR:

```raku
say False && True; # И
say False || True; # ИЛИ
say False ^^ True; # исключающее ИЛИ
```

Программа выводит вот это:

```
False
True
True
```

## Инверсия

Инверсия даёт противоположное булево значение. Для инверсии используйте префиксный оператор `!`. Префиксный оператор стоит перед значением:

```raku
say !False; # True
```

Скалярная переменная может хранить булево значение:

```raku
my $did = True;
my $didn't = !$did;
```
