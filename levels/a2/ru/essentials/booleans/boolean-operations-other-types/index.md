Следующая глава рассказывает о [переводе данных из одного типа в другой](/ru/essentials/coercion). Но сначала посмотрите на одну важную особенность Raku. Вы можете применять логические операции к строкам или целым числам. Тогда Raku не превращает значения в булевы. Результат — тоже не булево значение. Посмотрите на эти примеры:

```raku
say 'Hello' && 'World'; # World
say 'Alpha' || 'Beta';  # Alpha
say 0 ^^ 42;            # 42
```

Вот правила 📖 [из документации](https://docs.raku.org/language/operators#Tight_AND_precedence):

* `&&` возвращает первое значение, которое для Raku равно False. Если такого значения нет, он возвращает последнее значение.
* `||` возвращает первое значение, которое для Raku равно True. Если такого значения нет, он возвращает последнее значение.
* `^^` возвращает значение True, если такое значение только одно. Если все значения равны False, он возвращает последнее значение. Если значений True больше одного, он возвращает `Nil`.

Здесь мы видим новое значение — `Nil`. Это «нулевое» значение.
