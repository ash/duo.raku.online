## Проблема

Есть _N_ человек и _K_ яблок. Люди делят яблоки поровну. Напишите программу, которая отвечает на эти вопросы:

* Сколько яблок получает каждый человек?
* Сколько яблок остаётся в корзине?

Запишите числа _N_ и _K_ прямо в коде. Сохраните их в переменных, например:

```raku
my $N = 3;
my $K = 11;

# Ваш код …
```

Каждое яблоко остаётся целым. Яблоки нельзя резать на части.

## Пример

С числами выше программа должна вывести вот это:

```console
$ raku apple-sharing.raku
Each person gets 3 apple(s).
There are 2 apple(s) remaining.
```

Пока не думайте о правильной форме существительных. Вывод также может выглядеть странно, если яблок не остаётся. Пока это нормально.
