Вот как вы можете выполнить эту задачу.

## Код

```raku
my $n = prompt 'Enter a positive integer number: ';

say ($n % 100) div 10;
```

🦋 Вы можете найти исходный код в файле [tens.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/numbers/tens.raku).

## Вывод

Запустите программу. Проверьте её на нескольких разных случаях:

* Круглое число из трёх цифр, например, 120;
* Число, которое делится на 100 без остатка, например, 400;
* Число больше 10, но меньше 100;
* Число меньше 10.

Для числа 234 программа выводит вот это:

```console
$ raku exercises/numbers/tens.raku
Enter a positive integer number: 234
3
```

## Комментарии

Это решение снова использует два оператора вместе: остаток от деления `%` и целочисленное деление `div`.

Посмотрите на пробел перед открывающей скобкой. Он должен там быть. Без него вы получите синтаксическую ошибку. Мы вернёмся к [этой особенности](/ru/essentials/more-on-functions/mind-the-space) Raku в главе про функции. Пока набирайте код так, как вы видите его выше. Или добавьте ещё одну пару скобок. Поставьте их вокруг аргумента функции. Тогда пробел не нужен:

```raku
    say(($n % 100) div 10);
```
