## Проблема

Напишите программу. Она просит пользователя ввести целое положительное число. Потом она выводит цифру, которая показывает количество _десятков_ в этом числе.

## Пример

Например, пользователь вводит 234. Количество десятков в нём равно 3. Поэтому программа выводит 3:

```console
$ raku tens.raku
Enter a positive integer number: 234
3
```
