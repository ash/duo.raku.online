## Проблема

Школа готовится к учебному году после коронавируса. Она собирается заказать новые парты. Одна парта — для двух учеников. Вы знаете число учеников в классе. Сколько парт школа должна купить для класса? Выведите самое маленькое возможное число.

Запишите число учеников прямо в коде. Храните его в переменной.

## Пример

Вот первая строчка программы:

```raku
my $students = 23;
# Ваш код …
```

Запустите программу. Вы должны увидеть вот это:

```console
$ raku class-desks.raku
12 desks must be bought.
```
