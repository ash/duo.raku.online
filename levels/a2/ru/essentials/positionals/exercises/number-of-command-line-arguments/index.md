## Задача

Напишите программу. Она считает аргументы из командной строки. Она выводит их количество полным предложением. Грамматика должна быть правильной. Если аргумент ровно один, используйте слово `argument`. Во всех остальных случаях используйте `arguments`.

## Пример

Вот что должна делать программа:

```console
$ raku number-of-command-line-arguments.raku make them count us now
You passed 5 arguments.

$ raku number-of-command-line-arguments.raku solo
You passed 1 argument.
```
