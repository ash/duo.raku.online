## Задача

Напишите программу. Она читает аргументы из командной строки. Их может быть сколько угодно. Программа выводит каждый аргумент на отдельной строке. У строк есть номера.

## Пример

Программа должна работать так:

```console
$ raku count-and-print-arguments.raku words to display
1. words
2. to
3. display
```
