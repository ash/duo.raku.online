title: Вложенные массивы
---

Массив может содержать любые другие данные. Он может содержать даже другие массивы. Это вложенные массивы. Используйте квадратные скобки, чтобы показать, где начинается и кончается каждый вложенный массив:

```raku
my @table = 
    [1, 2, 3, 4],
    [10, 20, 30, 40],
    [100, 200, 300, 400];
```

Можно также добавить ещё одну пару скобок. Они стоят вокруг внешнего массива, массива верхнего уровня. В следующем примере та же структура данных, что и раньше.

```raku
my @table = [
    [1, 2, 3, 4],
    [10, 20, 30, 40],
    [100, 200, 300, 400]
];
```

Чтобы получить внутренний элемент, добавьте ещё индексы. Добавьте столько, сколько нужно. С каждой парой квадратных скобок вы спускаетесь на один уровень глубже:

```raku
say @table[0][3]; # Выводит 4
say @table[2][1]; # Выводит 200 
```
