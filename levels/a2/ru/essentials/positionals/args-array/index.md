---
title: Массив `@*ARGS`
---

{% include menu.html %}

Теперь вы знаете о массивах. Поэтому давайте познакомимся со встроенным массивом `@*ARGS`. Посмотрите на `*` в его имени. Это второй сигил, или _твигил_. Другие твигилы мы увидим позже. Но пока давайте посмотрим, чем полезен этот особый массив. Он хранит аргументы программы. Программа получает их из командной строки.

Посмотрите на этот запуск программы:

```console
$ raku run.raku alpha beta
```

Программа `run.raku` получает два параметра: `alpha` и `beta`. Вы можете прочитать их из `@*ARGS`.

```raku
say @*ARGS.elems;
say @*ARGS[0];
say @*ARGS[1];
```

Эта программа выводит количество своих аргументов. Потом она выводит сами аргументы:

```console
$ raku run.raku alpha beta
2
alpha
beta
```

Программу можно запустить и как исполняемый файл. Для этого не нужно менять программу:

```console
$ ./run.raku alpha beta
```

В этом случае программе [нужен шебанг](/ru/essentials/running-programs/from-command-line). Но самое важное вот что. Индексы `@*ARGS` всё равно начинаются с `0`:

```raku
#!/usr/bin/env raku

say @*ARGS.elems;
say @*ARGS[0];
say @*ARGS[1];
```
