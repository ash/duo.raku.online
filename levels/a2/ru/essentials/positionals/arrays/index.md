Массивы — это агрегированные типы данных. Это значит, что массив может хранить больше одного значения. Этим массивы отличаются от [скалярных элементов](/ru/essentials/scalar-variables). Элементы массива можно индексировать, или _субскриптировать_. Другими словами, у каждого элемента есть позиция. Поэтому такие данные мы называем позиционными.

У переменных-массивов другой сигил: `@`. Правила для имени такие же, как [для скаляров](/ru/essentials/scalar-variables/identifiers/).

```raku
my @cities;
```

Теперь у нас есть массив. Его имя — `@cities`. Вы можете положить в него несколько значений:

```raku
@cities = 'Paris', 'Rome', 'Berlin';
```

Вы можете также создать массив вместе со значениями:

```raku
my @cities = 'Paris', 'Rome', 'Berlin';
```

## Индексация

Чтобы получить один элемент массива, используйте пару скобок. Поставьте их после имени переменной:

```raku
say @cities[1];
```

Обратите внимание: сигил не меняется. Это всегда `@`. Raku считает элементы с нуля. Поэтому в нашем примере `@cities[1]` — это `'Rome'`.

Массивы изменяемы. Это значит, что их можно менять. Чтобы изменить элемент, просто присвойте ему новое значение:

```raku
@cities[0] = 'Rome';
@cities[1] = 'Paris';
```

После этого оператор `say @cities[1]` выводит новое значение, `'Paris'`.

## Размер

Что такое длина массива? Это количество его элементов. Чтобы её получить, используйте метод `elems`:

```raku
say @cities.elems; # 3
```

Иногда вы используете массив там, где Raku нужно число. Тогда вы получаете размер массива:

```raku
say +@cities; # 3
```

Здесь [префиксный оператор `+`](/ru/essentials/coercion/prefixes) ждёт от своего аргумента число. Поэтому результат `+@cities` — это `3`.
