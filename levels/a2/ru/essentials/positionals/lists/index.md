Списки похожи на массивы, но они неизменяемы. Нельзя изменить размер списка. Его элементы тоже нельзя изменить. Чтобы создать список, используйте круглые скобки:

```raku
my $odd = (1, 3, 5, 7, 9);
```

## Индексация списков

Чтобы получить один элемент списка, используйте квадратные скобки. Поставьте в них индекс:

```raku
say $odd[3]; # 7
```

Но дать элементу новое значение нельзя:

```raku
$odd[3] = 8; # Не ОК
```

Если вы попробуете, вы получите исключение:

    Невозможно изменить неизменяемый список ((1 3 5 7 9))
      в блоке <unit> на строке t.raku 4

## Присвоение списка массиву

Список можно сохранить в переменной с сигилом `@`. Что тогда произойдёт?

```raku
my @data = (40, 42, 44);
```

Тогда переменная `@data` содержит массив. Его элементы можно менять.

%%tipblock
## Переменная или список

Список неизменяем. Но его переменную всё равно можно использовать снова. В неё можно положить новый список.

```raku
my $elements = (1, 2);
say $elements[0]; # 1

$elements = (3, 4);
say $elements[0]; # 3
```

%%/tipblock
