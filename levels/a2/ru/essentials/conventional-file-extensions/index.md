Расширение файла — это последняя часть имени файла. Вот [рекомендуемые](https://github.com/Raku/problem-solving/blob/master/solutions/language/Path-to-Raku.md#extensions) расширения для файлов Raku:

* `.raku` для файлов с программами
* `.rakumod` для модулей
* `.rakutest` и `.t` для тестов
* `.rakudoc` для документов в формате POD6
