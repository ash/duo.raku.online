---
title: Исключение концов интервала
---

{% include menu.html %}

Вы можете не включать в интервал один его конец или оба конца. Для этого добавьте символ `^` к оператору интервала. Так вы получаете ещё три оператора. Комментарии показывают числа, которые даёт каждый интервал.

```raku
1 ..^ 5;  # 1, 2, 3, 4
1 ^.. 5;  #    2, 3, 4, 5
1 ^..^ 5; #    2, 3, 4
```

Случаи выше простые. В таких случаях можно не ставить пробелы вокруг оператора интервала:

```raku
my $r1 = 1..5;
my $r2 = 1..^5;
```

Некоторые интервалы начинаются с 0, например, `0..^5`. Есть короткий способ записать такой интервал: `^5`.
