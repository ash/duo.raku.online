В Raku интервал создаёт список элементов. Элементы идут по порядку, один за другим.

В самом простом случае интервал — это список целых чисел. Каждое число на 1 больше предыдущего. Чтобы создать интервал, используйте оператор `..` с двумя значениями. Первое значение — самое маленькое значение интервала. Второе значение — самое большое:

```raku
1 .. 5
```

Пробелы вокруг оператора не нужны. Поэтому тот же интервал можно записать и так:

```raku
1..5
```

Интервал создаёт список. Но сам интервал — это один объект. Поэтому его можно хранить в скалярной переменной:

```raku
my $r = 1 .. 5;
```

## Не только числа

Вы также можете создавать интервалы из других типов данных. Это работает, если Raku знает, как получить следующее значение. Например:

```raku
my $letters = 'a' .. 'z';
```

В Raku у интервалов есть свой тип данных. У переменной `$r` тип `Range`.
