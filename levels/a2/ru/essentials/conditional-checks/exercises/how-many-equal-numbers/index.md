## Проблема

Напишите программу. Пользователь вводит три целых числа. Программа говорит, сколько из них равны. Числа могут быть положительными или отрицательными. Программа должна работать с обоими видами.

## Пример

Вот как может работать программа:

```console
$ raku how-many-equal-numbers.raku
Number 1: 3
Number 2: -4
Number 3: 3
2
```

Если все три числа разные, программа должна вывести `0`.
