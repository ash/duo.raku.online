Используйте эти операторы, чтобы сравнить два числа. Вы знаете другие языки программирования? Тогда они все вам хорошо понятны.

`==` | Равно
`!=` | Не равно
`<` | Меньше
`<=` | Меньше или равно
`>` | Больше
`>=` | Больше или равно

## Приблизительно равно

В Raku есть стандартные операторы. И ещё Raku добавляет один оператор: `=~=`. Этот оператор проверяет, что два числа почти равны. Результат равен `True`, если числа близки. Raku сравнивает разницу с размером самих чисел. Так получается относительная разница. Она не должна быть больше встроенного значения `$*TOLERANCE`. Это значение равно `1e-15`.

## Символы Юникода

У некоторых из этих операторов есть ещё форма в Юникоде:

`!=` | `≠`
`<=` | `≤` 
`>=` | `≥`
`=~=` | `≅`

## Примеры

Вот несколько примеров сравнения чисел:

```raku
say 10 == 10; # True
say 10 != 10; # False

say 15 < 10;  # False
say 10 <= 10; # True
say 16 > 10;  # True
say 10 >= 14; # False

say 1.000000000000000000000001 =~= 1.000000000000000000000002; # True
say 2e17 + 1 =~= 2e17 + 100; # True
```

Обратите внимание: `1.000000000000000000000001` — это число типа `Rat`. Выражение сравнивает его с очень близким числом `1.000000000000000000000002`. С числами `Rat` вы здесь не теряете точность. Raku хранит все цифры. В последнем примере есть `2e17`. Этот пример работает с числами `Num`. Их точность ограничена. Они не могут хранить все цифры.
