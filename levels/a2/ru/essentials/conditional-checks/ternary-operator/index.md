---
title: Тернарный оператор
---

{% include menu.html %}

У тернарного оператора в Raku две части: `??` ... `!!`. Сначала идёт булева проверка. Её результат равен `True` или `False`. После проверки идут два выражения. Raku выполняет только одно из них. Результат проверки выбирает, какое именно.

```raku
my $shines = 'Sun';
my $day-time = $shines eq 'Sun' ?? 'day' !! 'night';
say $day-time;
```

С текущим значением `$shines` программа выводит `day`. Поменяйте значение на `Moon`. Тогда результат равен `night`.

Тернарные выражения можно соединять в цепочку. Но не делайте её слишком сложной.

```raku
my $hours = 20;
my $day-time =
    $hours <= 6 ?? 'Night' !!
    $hours <= 12 ?? 'Morning' !! 
    $hours <= 18 ?? 'Afternoon' !! 'Evening';
say $day-time;
```

Здесь программа выводит часть дня. Эта часть зависит от значения в `$hours`.
