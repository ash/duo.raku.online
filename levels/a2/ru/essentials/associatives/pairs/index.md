Пара — это структура данных. Она хранит имя и значение. Вместе они составляют один целый объект. Этот объект можно хранить в скалярной переменной. Вот как создать пару:

```raku
my $pair = name => 'Anna';
```

У переменной `$pair` тип `Pair`:

```raku
say $pair.WHAT; # (Pair)
```

Имя и значение можно получить по отдельности. Метод `key` даёт имя. Метод `value` даёт значение:

```raku
say $pair.key; # name
say $pair.value; # Anna
```

У пар есть важная особенность. Они неизменяемые. Это значит, что вы не можете дать паре новое значение. Вы также не можете дать ей новое имя. Конечно, той же переменной можно присвоить совсем новую пару:

```raku
my $pair = name => 'Anna';
$pair = name => 'John';
say $pair.value; # John
```

## Индексация

Есть ещё один способ прочитать значение пары. Вы можете индексировать пару. Напишите имя её ключа в угловых скобках. Вот как:

```raku
say $pair<name>;
```

Обратите внимание: ключу без пробелов не нужны кавычки. Если в ключе есть пробелы, правила немного строже:

```raku
my $pair = 'employee name' => 'Julie Madelon';
say $pair{'employee name'};
```

Обратите внимание: на этот раз в коде фигурные скобки.
