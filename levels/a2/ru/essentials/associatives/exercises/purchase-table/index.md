## Задача

Вы уже делали упражнение «[Таблица покупок](/ru/essentials/strings/exercises/purchase-table)». Возьмите из него ту же таблицу:

    Товар    Цена    Кол-во  Итого
    Стулья   $20.57  4       $82.28
    Столы    $50.18  1       $50.18

Выберите структуру данных для этих значений. Потом напишите программу. Она должна выводить эти данные.

## Пример

Запустите программу. Она должна вывести таблицу выше.

```console
$ raku purchase-table.raku
```
