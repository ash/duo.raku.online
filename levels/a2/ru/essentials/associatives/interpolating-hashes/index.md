Вы можете интерполировать элементы хеша в строках с двойными кавычками. Пишите их так же, как в коде программы: `%data<FR>`. Вы можете интерполировать и весь хеш. Для этого добавьте пустые угловые или пустые фигурные скобки: `%data{}`. Эта программа показывает, как это работает:

```raku
my %data = FR => 'Paris', IT => 'Rome';

say "%data<FR>";
say "%data<>";

# Или:
# say "%data{}";
```

Программа выводит нужные нам данные:

```console
$ raku t.raku
Paris
FR	Paris
IT	Rome
```

Обратите внимание: весь хеш может занять больше одной строки.
