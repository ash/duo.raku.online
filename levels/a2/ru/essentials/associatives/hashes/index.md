_Хэш_ — это ещё один ассоциативный тип данных в Raku. Это агрегированный тип данных. Он хранит много элементов. У каждого элемента есть имя и значение. Переменные-хэши используют новый сигил: `%`.

```raku
my %capitals;
```

Теперь вы можете использовать хэш. Вы можете присвоить ему начальные значения.

```raku
%capitals = France => 'Paris', Italy => 'Rome';
```

Вы можете сделать оба действия сразу. С другими типами данных это тоже работает:

```raku
my %capitals = France => 'Paris', Italy => 'Rome';
```

## Как получить элементы

Чтобы получить элемент, вы индексируете хэш. Вы делаете это так же, как с [парами](../pairs). Напишите строку в угловых или фигурных скобках:

```raku
say %capitals<France>;
say %capitals{'Italy'};
```

Хэши изменяемы. Это значит, что их можно менять. Вы можете менять значения. Вы также можете добавлять новые:

```raku
%capitals<Germany> = 'Berlin';
```

## Ключи и значения

В Raku есть два встроенных метода для хэшей: `keys` и `values`. Метод `keys` возвращает список ключей. Метод `values` возвращает список значений:

```raku
say %capitals.keys;
say %capitals.values;
```

Программа может вывести, например, вот это:

    (Germany Italy France)
    (Berlin Rome Paris)

Обратите внимание: у элементов хэша нет порядка. Но оба метода используют один и тот же порядок.
