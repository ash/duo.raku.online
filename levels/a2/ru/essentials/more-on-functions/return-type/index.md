Вы также можете задать тип для результата функции. В коде это можно записать несколькими способами.

```raku
sub add(Int $x, Int $y) returns Int { $x + $y }

my Int sub add(Int $x, Int $y) { $x + $y }

sub add(Int $x, Int $y) of Int { $x + $y }

sub add(Int $x, Int $y --> Int) { $x + $y }
```

Выберите тот, который вам больше нравится. Посмотрите на четвёртый пример. Там тип результата стоит внутри скобок. Параметры функции тоже стоят там.
