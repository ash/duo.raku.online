Функции в Raku в основном легко использовать. Обычно с ними нет проблем. Но будьте осторожны с одной вещью.

## TL;DR

Не ставьте пробел между именем функции и скобками. В скобках находятся аргументы. Но после `for` и `if` обязательно ставьте пробел.

## Длинная история

Вот простая функция:

```raku
sub f($x, $y) {
    return $x + $y;
}
```

Сначала посмотрите на имя функции. Открывающая скобка стоит сразу после него, без пробела. В этих скобках находятся параметры. В других языках некоторые стили кода требуют там пробел. Raku тоже это принимает. Но это не лучший способ писать код:

```raku
sub f ($x, $y) {
    return $x + $y;
}
```

В вызове функции важно, что пробела нет. Иногда вы вызываете функцию без скобок. Тогда после имени функции нужно поставить пробел:

```raku
f 5, 6;
```

Но если есть скобки, перед ними не должно быть пробела. Этот вызов правильный:

```raku
f(5, 6);
```

А этот вызов неправильный:

```raku
f (5, 6);
```

Этот код вызывает исключение:

    Too few positionals passed; expected 2 arguments but got 1
      sub f at t.raku line 1
      in block <unit> at t.raku line 5

Посмотрите на вызов с пробелом: `f (5, 6)`. Raku думает, что вы передаёте функции один аргумент. Этот аргумент — `(5, 6)`. Вы можете легко проверить тип этого аргумента. Измените функцию. Она должна принимать только один аргумент:

```raku
sub f($param) {
    say $param.WHAT;
}

f (5, 6); # (List)
```

Значит, вызов `f (5, 6)` передаёт функции [список](/ru/essentials/positionals/lists). Весь список — это один аргумент.

## Когда нужен пробел

Иногда пробел нужен. Так бывает, когда вы ставите скобки после ключевого слова. Например, ключевым словом может быть `if`, `for` или `loop`. Этот код неправильный:

```raku
if(True != False) {
    say 'OK';
}
```

Сообщение об ошибке говорит, что не так:

    ===SORRY!===
    The word 'if' is interpreted as a 'if()' function call.  Please use
    whitespace instead of parentheses.
    at /Users/ash/raku-course/t.raku:1
    ------> if⏏(True != False) {
    Unexpected block in infix position (two terms in a row)
    at /Users/ash/raku-course/t.raku:1
    ------> if(True != False)⏏ {

С `if` скобки совсем не нужны. Без них этой проблемы не может быть. Но иногда скобки нужны, например, с `loop`. Тогда обязательно ставьте пробел:

```raku
loop(my $c = 0; $c != 10; $c++) { say $c }
```

В этом коде происходит то же самое. Компилятор думает, что `loop(...)` — это вызов функции. Добавьте пробел, чтобы исправить проблему. Или, лучше, напишите этот код с `for`.

## Заключение

Итак, вот главное. Не ставьте пробел между именем функции и её скобками. Тогда таких проблем не будет. Также старайтесь не ставить скобки в других местах, если можно. Например, с `if` и `for` они не нужны.
