Интерполяция кода — это следующий уровень интерполяции. Можно вставить код прямо в строку в двойных кавычках. Код может быть простым. А может быть и сложным!

Напишите код в фигурных скобках, `{` и `}`:

```raku
my $a = 10;
my $b = 20;
say "The sum of $a and $b is {$a + $b}.";
```

Программа выводит:

```console
$ raku t.raku 
The sum of 10 and 20 is 30.
```

## И снова переменные

Вот один случай, где нужен этот способ. Иногда сразу после переменной идёт текст. Raku может по ошибке прочитать этот текст как часть имени. Чтобы этого не было, поставьте переменную в фигурные скобки:

```raku
my $how-many = 5;
my $what = 'suit';
say "There are $how-many {$what}s."; # There are 5 suits.
```

Без фигурных скобок Raku пытается интерполировать переменную `$whats`. Но такой переменной нет.
