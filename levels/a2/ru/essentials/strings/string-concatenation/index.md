Две строки можно соединить. Тогда получится новая, более длинная строка. Мы называем это конкатенацией строк. В Raku строки соединяют с помощью оператора. Угадаете, как он называется? Это оператор конкатенации! Этот оператор — тильда: `~`. Чтобы соединить две строки, поставьте между ними `~`:

```raku
say 'Hello, ' ~ 'World!';
```

Иногда строки хранятся в переменных. Тогда мы можем «конкатенировать переменные». Ну, на самом деле мы конкатенируем строки в этих переменных:

```raku
my $greeting = 'Hello, ';
my $who = 'World!';

say $greeting ~ $who;
```

Можно также записать результат в новую переменную:

```raku
my $greeting = 'Hello, ';
my $who = 'World!';
my $message = $greeting ~ $who;

say $message;
```

## Конкатенация и присвоение за один шаг

Иногда нужно добавить строку в конец переменной. Тогда используйте такую форму:

```raku
# Instead of 
$str = $str ~ $another-str;

# use:
$str ~= $another-str;
```
