Строки в Raku — это строки Юникода. Из-за этого некоторые простые вещи немного сложнее. Или, по крайней мере, о них нужно больше думать. Например, возьмём длину строки. Это количество символов? Или это количество байтов? А иногда один и тот же символ состоит из разных частей в разных строках. Тогда это всё ещё один символ?

## Длина в символах

_Метод_ `chars` даёт длину строки в символах:

```raku
my $str = '你好世界';
say $str.chars;
```

О методах мы поговорим позже. Но мы уже можем их использовать. В Raku можно вызвать метод почти для любого объекта. Строки и скалярные переменные — тоже объекты. Чтобы вызвать метод, поставьте точку. Здесь переменная хранит строку. Мы вызываем метод для этой переменной: `$str.chars`.

В этом китайском приветствии четыре символа: 你好世界. И `$str.chars` даёт ровно `4`.

## Длина в байтах

Это только для справки. Вот как узнать длину строки в байтах. Для этого нужно знать кодировку строки:

```raku
my $str = '你好世界';
say $str.encode('UTF-8').bytes;
```

В этот раз программа печатает `12`. Посмотрите на вторую строку. В ней два вызова методов, один за другим.

## Длина в кодовых позициях

Чтобы закончить тему, вот ещё один полезный метод для длины строки: `codes`. Он даёт количество кодовых позиций в строке. Кодовая позиция — это номер символа в Юникоде. Перед подсчётом Raku нормализует строку. Он приводит строку к стандартному виду. Часто `codes` и `chars` дают одинаковый результат. Но в некоторых редких случаях эти два метода дают разные результаты. Например, можно собрать «невозможный» символ. Во всём пространстве Юникода для него нет ни одной кодовой позиции.

```raku
say 'x̨'.chars;
say 'x̨'.codes;
```

У символа `x̨` нет своей кодовой позиции. Его можно собрать только из двух частей. Первая часть — строчная буква `x`. Вторая часть — комбинирующий символ `0x0328`. Он добавляет к букве значок. Значит, это один символ, но у него две кодовые позиции. Вот почему программа печатает это:

```
1
2
```
