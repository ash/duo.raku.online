Теперь давайте поговорим о строках. В наших программах уже были строки. Их также называют строковыми литералами. Строковый литерал — это текст в кавычках:

```raku
say 'I am a string literal';
```

Конечно, скалярная переменная тоже может хранить строку:

```raku
my $message = 'This is my message';
```

Теперь давайте узнаем ещё несколько основных вещей о строках.
