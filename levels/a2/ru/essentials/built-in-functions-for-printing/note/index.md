title: '`note`'
---

{% include menu.html %}

Рутина `note` выводит свои аргументы в поток стандартных ошибок. Во всём остальном `note` похожа на [`say`](../say).

1. Вызывает метод `gist` для своих аргументов.
1. Добавляет символ новой строки.
1. Преобразует результат в UTF-8.
1. Отправляет его в поток `STDERR`.

```raku
my $x = 42;
note "Текущее значение \$x равно $x";
```

Эта программа не отправляет сообщение в `STDOUT`. Проверьте это:

```
$ raku t.raku > /dev/null
Текущее значение $x равно 42
```

Вы можете вызвать `note` без аргументов. Тогда она выводит сообщение по умолчанию, `Noted`.
