Процедура `put` работает как [`print`](../print). Но по умолчанию она добавляет в конце символ новой строки:

1. Преобразует свои аргументы в строку. Для этого она вызывает на них метод `Str`.
1. Добавляет символ новой строки.
1. Отправляет строку в поток `STDOUT`.

Несколько примеров:

```raku
42.put;
put 'Alpha', 'Beta';

my @array = 3, 4, 5;
put @array;

my %hash = a => 'b', c => 'd';
%hash.put;
```

Вот вывод программы:

```console
$ raku t.raku
42
AlphaBeta
3 4 5
a	b
c	d
```

%%tipblock
## Новая строка в `put`

Какие символы `put` добавляет после вывода? Она берёт их из метода `nl-out` выходного потока. Значение по умолчанию — `\n`.
%%/tipblock
