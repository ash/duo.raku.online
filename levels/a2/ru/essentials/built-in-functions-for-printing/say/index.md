title: '`say`'
---

{% include menu.html %}

Встроенная операция `say` делает четыре вещи:

1. Вызывает метод `gist` для своих аргументов.
1. Добавляет символ новой строки.
1. Преобразует результат в UTF-8.
1. Отправляет его в поток `STDOUT`.

Для пользователя всё просто. `say` выводит значение переменной в терминал. Затем она добавляет новую строку.

Первый шаг нужно немного объяснить. У каждого встроенного типа данных есть метод `gist`. Целые числа и строки — примеры таких типов. Для этих простых типов `gist` возвращает элемент в удобном для чтения виде.

```raku
say 42; # 42
say 'Raku'; # Raku
```

Некоторые данные сложнее, например массивы или хэши. Для таких данных `gist` добавляет немного форматирования.

```raku
my @data = 'alpha', 'beta', 'gamma';
say @data; # [alpha beta gamma]

my %data = alpha => 1, beta => 2, gamma => 3;
say %data; # {alpha => 1, beta => 2, gamma => 3}
```

Вы можете вызвать `say` как функцию. Вы также можете вызвать её как метод:

```raku
say 42;
say(42);
42.say;
```

Вы можете передать в `say` больше одного аргумента. `say` соединяет части вывода. Между ними нет пробелов.

```raku
say(100, 500); # 100500
```
