title: Приведение типов с помощью методов приведения типов
---

{% include menu.html %}

Вы можете преобразовать значение в другой тип. Другое слово для этого — _привести_. Для этого вызовите метод. Его имя — это имя типа данных. Например, преобразуйте строку в целое число:

```raku
my $howmany = '42';
my $n = $howmany.Int;
say $n;
```

Часто вам не нужно преобразовывать значения самим. Raku делает это за вас. Этот код работает правильно и так, как вы ждёте:

```raku
my $a = '10';
my $b = '20';
my $c = $a + $b;
say "The result is $c."; # The result is 30.
```

Две переменные, `$a` и `$b`, содержат строки. Но выражение складывает их с помощью `+`. Поэтому здесь Raku преобразует обе строки в целые числа. Тогда `$c` тоже получает целое число. В последней строке Raku интерполирует эту переменную в строку. Для этого Raku превращает число в символы цифр.
