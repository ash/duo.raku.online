Есть похожий способ. Можно создать новый объект нужного типа. Для этого вызовите конструктор типа. Конструктор создаёт новые объекты. Его имя совпадает с именем типа. Например:

```raku
my $n = Int('1.23E4');
say $n;      # 12300
say $n.WHAT; # (Int)
```

Здесь в строке записано число с плавающей запятой. Raku преобразует его в целое число.
