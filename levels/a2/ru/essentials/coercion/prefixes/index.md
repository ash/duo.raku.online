---
title: Приведение типов с помощью префиксных операторов
---

{% include menu.html %}

Тип объекта можно изменить и с помощью префиксных операторов. Каждый такой оператор — это всего один символ. Вы ставите его прямо перед значением или переменной.

`~` | Преобразует в строку
`+` | Преобразует в число
`?` | Преобразует в логическое значение

Вот пример. Он делает логическое значение из целого числа:

```raku
say ?42; # True
```

Преобразование в строку работает так же:

```raku
my $n = -30;
my $s = ~$n;
say $s.chars; # 3, так как "-30" содержит 3 символа
```

Обратите внимание на преобразование в число. Тип результата может быть разным. Он зависит от числа. Сравните эти преобразования из строк:

```raku
say (+'100').WHAT;   # (Int)
say (+'3.14').WHAT;  # (Rat)
say (+'27E-1').WHAT; # (Num)
```

Чтобы получить логическое значение, можно также использовать `so`. Его можно использовать как префиксный оператор. Или его можно использовать как метод:

```raku
my $value = 42;
say so $value; # True
say $value.so; # True
```
