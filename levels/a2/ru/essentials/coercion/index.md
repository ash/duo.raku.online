Мы уже знаем несколько типов данных в Raku. Во-первых, есть разные виды [чисел](/ru/essentials/numbers). Это целые числа, рациональные числа и числа с плавающей запятой. Потом есть [строки](/ru/essentials/strings). И ещё есть [логический](/ru/essentials/booleans) тип. У каждого типа данных есть имя в системе типов Raku.

`Str` | Строка символов
`Int` | Целое число
`Rat` | Рациональное число
`Num` | Число с плавающей запятой
`Bool` | Логический тип

Raku знает и другие типы данных. Мы увидим их позже в курсе.
