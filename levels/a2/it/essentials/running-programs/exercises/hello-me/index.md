## Problema

Scrivi un programma ed eseguilo. Il programma stampa un saluto con il tuo nome. Salva il programma in un file. Eseguilo dalla riga di comando. Se vuoi, [esegui il programma](/it/essentials/running-programs) online o direttamente da un IDE.

## Esempio

Qui vedi come eseguire il programma. Vedi anche il suo output:

```console
$ raku hello-me.raku
Hello, Andrew!
```

## Soluzione

Prova a risolvere questo compito da solo. Salva il codice in un file. Poi dai il file all'interprete della riga di comando. Oppure eseguilo in un altro modo delle pagine precedenti. Vuoi vedere un esempio? Oppure il tuo programma non funziona per qualche motivo? Allora guarda la soluzione che funziona. Il link è qui sotto.
