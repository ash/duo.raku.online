Questa sezione è molto breve. Mostra come eseguire un programma senza uscire dall'IDE. Vediamo i due [IDE](../../editors-and-ides) più consigliati.

## Visual Studio Code Editor

Apri un terminale dal menu: `Terminal` → `New Terminal`. Sotto il testo del tuo programma si apre un nuovo pannello. Esegui lì il programma, come dalla riga di comando:

```console
$ raku hello.raku
```

## Comma IDE

Per eseguire un programma, usa la voce `Run` nel menu. Prima del primo avvio, configura l'IDE. Segui [le istruzioni](https://commaide.com/docs/running) sul sito di Comma.
