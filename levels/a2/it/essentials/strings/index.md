Ora parliamo di stringhe. I nostri programmi avevano già delle stringhe. Queste stringhe si chiamano anche stringhe letterali. Una stringa letterale è del testo tra virgolette:

```raku
say 'Io sono una stringa letterale';
```

Certo, anche una variabile scalare può contenere una stringa:

```raku
my $messaggio = 'Questo è il mio messaggio';
```

Ora impariamo altre cose di base sulle stringhe.
