title: Blocchi di codice

{% include menu.html %}

Un blocco di codice è una parte del tuo programma. Sta dentro una coppia di parentesi graffe: `{` e `}`. Un blocco contiene diverse istruzioni. Lavorano insieme, come una grande istruzione. Le prossime sezioni mostrano molti modi di usare i blocchi.

```raku
{
    say 'Hello, World!';
}
```

A questo programma il blocco di codice non serve davvero. Ma i blocchi di codice sono molto utili in altri casi. Li vediamo molto presto.

Ma prima, guardiamo l'idea di _ambito_. L'ambito dice dove puoi usare una variabile.
