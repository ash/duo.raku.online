Ecco un modo per risolvere il compito.

## Codice

```raku
my $answer = 42;
say $answer;
```

🦋 Puoi trovare il codice sorgente nel file [answer.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/scalar-variables/answer.raku).

## Output

Esegui il programma e guarda cosa stampa:

```console
$ raku exercises/scalar-variables/answer.raku 
42
```

## Commenti

Una regola di questo compito è usare variabili. `42` è un solo valore. Quindi una variabile scalare è un buon posto per conservarlo.
