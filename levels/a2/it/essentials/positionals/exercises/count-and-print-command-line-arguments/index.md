## Compito

Scrivi un programma. Legge gli argomenti dalla riga di comando. Possono essere quanti vuoi. Il programma stampa ogni argomento su una riga diversa. Le righe hanno un numero.

## Esempio

Il programma deve funzionare così:

```console
$ raku count-and-print-arguments.raku parole da visualizzare
1. parole
2. da
3. visualizzare
```
