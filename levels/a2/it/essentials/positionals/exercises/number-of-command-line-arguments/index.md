## Compito

Scrivi un programma. Conta gli argomenti dalla riga di comando. Stampa il numero in una frase completa. La grammatica deve essere corretta. Per un argomento solo, usa la parola `argument`. In tutti gli altri casi, usa `arguments`.

## Esempio

Ecco cosa deve fare il programma:

```console
$ raku number-of-command-line-arguments.raku make them count us now
You passed 5 arguments.

$ raku number-of-command-line-arguments.raku solo
You passed 1 argument.
```
