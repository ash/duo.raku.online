## Problema

Questo hash contiene i dati di un dipendente:

```raku
my %employee =
    full-name => 'Eliza Vents',
    department => 'Sales',
    salary => 3000;
```

Aumenta lo stipendio del 5&thinsp;%. Stampa il nuovo stipendio e il nome del dipendente. Dopo la modifica, l'hash `%employee` deve avere i valori corretti.

## Esempio

Il programma deve stampare questo:

```console
$ raku salary-raise.raku
Nuovo stipendio di Eliza Vents: 3150
```
