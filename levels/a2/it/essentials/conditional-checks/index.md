title: Controlli condizionali
---

{% include menu.html %}

A volte un programma deve fare cose diverse in situazioni diverse. Per questo puoi usare `if` e parole simili.

Tutti hanno bisogno di una condizione. La condizione può essere un valore [booleano](/it/essentials/booleans), `True` o `False`. Può essere un'espressione booleana. Questa espressione dà `True` o `False`. Oppure può essere qualsiasi altra espressione. Raku deve poter [cambiare](/it/essentials/coercion) il suo valore in `True` o `False`.
