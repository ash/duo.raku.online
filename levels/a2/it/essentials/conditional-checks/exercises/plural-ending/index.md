## Compito

Scrivi un programma. Chiede all'utente un numero intero più grande di zero. Poi stampa `N file copiati`. Qui `N` è il numero dell'utente. La parola `file` deve essere nella forma giusta, singolare o plurale.

## Esempio

Questo è quello che il programma deve fare:

```console
$ raku plural-endings.raku
Quanti file copiare? 15
15 file copiati.
```
