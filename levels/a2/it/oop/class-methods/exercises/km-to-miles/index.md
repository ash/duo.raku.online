## Problema

Crea una classe `Converter` con un metodo di classe `km-to-miles`. Prende un numero di chilometri. Restituisce la distanza in miglia. Per avere le miglia, moltiplica per `0.621`.

Chiama il metodo sulla classe per `10` chilometri. Stampa il risultato.

## Esempio

Il programma stampa:

```
6.21
```
