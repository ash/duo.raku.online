## Problema

Un metodo di classe può avere parametri, come ogni altro metodo. Crea una classe `Geometry` con un metodo di classe `circle-area`. Prende un raggio. Restituisce l'area di un cerchio. Usa `π` o `pi`. Arrotonda l'area a un numero intero. La formula appartiene a tutta la classe. Qui non c'è un singolo oggetto cerchio. Chiama il metodo sulla classe con un raggio di `10`. Stampa il risultato.

## Esempio

Il programma stampa:

```
314
```
