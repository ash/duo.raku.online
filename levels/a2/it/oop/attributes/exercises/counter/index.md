## Problema

Crea una classe `Counter` con un attributo, `count`. Puoi cambiare questo attributo (`is rw`). Il suo valore predefinito è `0`.

Crea un contatore. Prima stampa il suo `count`. Questo mostra che parte dal valore predefinito. Poi aggiungi 1 al contatore cinque volte in un ciclo. Stampa l'ultimo valore.

## Esempio

Il programma stampa:

```
0
5
```
