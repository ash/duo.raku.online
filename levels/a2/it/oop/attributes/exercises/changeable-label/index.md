## Problema

Crea una classe `Label` con un attributo, `text`. Puoi cambiare questo attributo (`is rw`). Crea un'etichetta con il testo `draft`. Poi **aggiungi** ` (revised)` alla fine del suo testo. Fallo attraverso l'accessore. Non creare di nuovo l'oggetto. Stampa il risultato.

## Esempio

Il programma stampa:

```
draft (revised)
```
