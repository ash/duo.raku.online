## Problema

Scrivi un blocco con dentro `die 'timeout'`. Aggiungi un phaser `CATCH` al blocco. Il phaser intercetta l'eccezione e stampa il suo messaggio. Metti `Error: ` prima del messaggio.

## Esempio

Il programma stampa:

```
Error: timeout
```
