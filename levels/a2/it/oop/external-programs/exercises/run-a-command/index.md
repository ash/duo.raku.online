## Problema

Usa `run` per avviare `echo`. Dagli due argomenti separati: `home:` e `$HOME`. Gli argomenti sono valori che dai a un programma. Lascia andare l'output sullo schermo. Nota che il programma stampa `$HOME` così com'è. **Non** stampa la directory home. Questo perché `run` non usa una shell. Solo una shell sostituisce variabili come `$HOME` con i loro valori.

## Esempio

Il programma stampa:

```
home: $HOME
```
