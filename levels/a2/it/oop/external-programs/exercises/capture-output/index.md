## Problema

Usa `run` con `:out`. Avvia `echo` con le tre parole `hello world raku`. Cattura il suo output in una variabile. Non stampare solo l'output. Invece conta le parole che contiene. Poi stampa questo numero.

## Esempio

Il programma stampa:

```
3
```
