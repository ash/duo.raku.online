## Problema

Crea due classi vuote, `Cat` e `Dog`. Poi crea un'istanza di `Cat` con il nome `$felix`. Stampa il tipo di `$felix` con `WHAT`. Poi stampa altre due righe. Usa in queste righe l'operatore `===`. La prima riga mostra se il tipo è lo stesso di `Cat`. La seconda riga mostra se è lo stesso di `Dog`.

## Esempio

Il programma stampa:

```
(Cat)
True
False
```
