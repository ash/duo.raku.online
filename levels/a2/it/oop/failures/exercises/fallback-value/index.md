## Problema

Scrivi una subroutine `get`. Restituisce il suo argomento. Ma se l'argomento è `0`, chiama `fail`. Il messaggio è `bad`.

Stampa il risultato di `get(5)`. Poi stampa il risultato di `get(0)`. Usa l'operatore defined-or `//` con il valore di ripiego `default`. L'operatore `//` dà questo valore quando il risultato non è definito.

## Esempio

Il programma stampa:

```
5
default
```
