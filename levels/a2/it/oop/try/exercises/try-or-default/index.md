## Problema

Quando un blocco `try` fallisce, il suo valore non è definito. Usa questo fatto con l'operatore defined-or `//`. Con `//` puoi dare un valore di ripiego per questo caso. Esegui un blocco `try` con dentro `die 'no'`. Se il blocco fallisce, usa invece la stringa `default`. Stampa il risultato.

## Esempio

Il programma stampa:

```
default
```
