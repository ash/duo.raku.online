## Problema

Mostra le due facce di `try`. Un blocco `try` intercetta gli errori nel suo codice. Prima metti un calcolo in un blocco `try`. Il calcolo deve funzionare, per esempio `6 * 7`. Stampa il suo risultato. Poi metti del codice con `die 'broken'` in un secondo blocco `try`. Stampa se questo blocco ha dato un risultato definito. Stampa anche il messaggio dell'eccezione intercettata.

## Esempio

Il programma stampa:

```
42
False
broken
```
