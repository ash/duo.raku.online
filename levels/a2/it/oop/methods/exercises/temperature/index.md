## Problema

Crea una classe `Celsius` con un attributo `degrees`. Aggiungi un metodo `to-fahrenheit`. Cambia la temperatura in Fahrenheit. Usa questa formula: `gradi × 9 / 5 + 32`.

Crea un oggetto `Celsius` per `100` gradi. Stampa il suo valore in Fahrenheit.

## Esempio

Il programma stampa:

```
212
```
