## Problema

Apri per scrivere un file con il nome `out.txt`. Tieni aperto l'handle. Scrivici i numeri `1`, `2` e `3` in un ciclo. Ogni numero deve stare su una riga a parte. Poi chiudi l'handle. Leggi il file e stampa il suo contenuto.

## Esempio

Il programma stampa:

```
1
2
3
```
