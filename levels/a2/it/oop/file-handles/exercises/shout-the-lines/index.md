## Problema

Scrivi tre parole in un file con il nome `words.txt`. Le parole sono `apple`, `banana` e `cherry`. Ogni parola sta su una riga a parte. Poi leggi il file riga per riga. Stampa ogni riga con il suo numero davanti. I numeri partono da `1`. Usa questa forma: `<numero>: <riga>`.

## Esempio

Il programma stampa:

```
1: apple
2: banana
3: cherry
```
