## Problema

Crea un piccolo file di log. Aggiungi più volte delle righe alla sua fine. Prima scrivi la riga `start` in un file con il nome `log.txt`. Poi **aggiungi in coda** altre tre righe in un ciclo. Questo vuol dire che le aggiungi alla fine del file. Le righe sono `entry 1`, `entry 2` e `entry 3`. Non cancellare quello che c'è già nel file. Alla fine leggi tutto il file e stampalo.

## Esempio

Il programma stampa:

```
start
entry 1
entry 2
entry 3
```
