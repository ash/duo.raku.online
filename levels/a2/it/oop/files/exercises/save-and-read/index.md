## Problema

Salva un numero in un file e caricalo di nuovo. Il file è `number.txt`. Scrivici il numero `42` e poi un ritorno a capo. Poi leggi il file. Trasforma il suo contenuto in un intero, un numero senza virgola. Moltiplica l'intero per due e stampa il risultato.

## Esempio

Il programma stampa:

```
84
```
