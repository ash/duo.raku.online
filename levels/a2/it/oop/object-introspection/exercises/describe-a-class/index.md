## Problema

Crea una classe base `Animal`. Poi crea una classe `Dog` che eredita da essa. Stampa il nome della classe `Dog`. Poi guarda la catena di ereditarietà di `Dog`. Questa catena contiene la classe e tutti i suoi genitori. Sulla riga successiva, stampa il numero di tipi che contiene. Usa `.^mro` e conta i suoi elementi. Su una terza riga, stampa se questa catena contiene una classe `Cat`.

## Esempio

Il programma stampa:

```
Dog
4
False
```
