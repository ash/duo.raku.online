## Problema

Scrivi un file `META6.json`. La distribuzione si chiama `Greet::Simple` e ha la versione `0.0.1`. Fornisce il modulo `Greet::Simple` dal file `lib/Greet/Simple.rakumod`. Nell'esempio della teoria, `depends` è vuoto. Qui invece è diverso. Questa distribuzione **dipende da** un'altra distribuzione, `JSON::Fast`. Mettila nell'array `depends`.

> Il risultato di questo esercizio è un file. Non è l'output di un programma.

## Esempio

Nella soluzione puoi vedere un file corretto. Ha solo le parti che servono.
