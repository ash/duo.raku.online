## Problema

Dichiarate una variabile scalare `$discount`. Il suo valore predefinito deve essere `0`. Stampate la variabile prima di assegnarle qualcosa. Il programma deve stampare `0`. Non deve stampare nessun avvertimento.

Poi assegnate `15` alla variabile. Stampatela di nuovo.

## Esempio

Il programma stampa due righe:

```
0
15
```
