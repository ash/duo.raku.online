## Problema

Una variabile nativa non è mai indefinita. Questa regola vale per tutti i tipi nativi, non solo per `int`. Dichiara un `num` nativo e una `str` nativa. Non dare loro valori. Stampa il numero. Poi stampa la stringa tra parentesi quadre. Così puoi vedere che è vuota.

## Esempio

Il programma stampa:

```
0
[]
```
