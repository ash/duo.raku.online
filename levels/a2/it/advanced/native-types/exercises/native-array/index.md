## Problema

I tipi nativi di dimensione fissa vanno bene per gli array di byte. Questi array usano poca memoria. Crea un array `uint8` con i valori `100`, `200` e `255`. Ogni valore sta in un byte. Stampa la somma degli elementi.

Gli elementi restano nell'intervallo `0..255`. Ma la loro somma può essere più grande. `.sum` restituisce un normale `Int`.

## Esempio

Il programma stampa:

```
555
```
