## Problema

Ecco due array:

```raku
my @first = 1, 2;
my @second = 3, 4, 5;
```

Uniscili in un solo array _piatto_. Non deve essere un array annidato, con array dentro. Stampa l'array. Poi stampa il numero dei suoi elementi.

## Esempio

Il programma stampa:

```
[1 2 3 4 5]
5
```
