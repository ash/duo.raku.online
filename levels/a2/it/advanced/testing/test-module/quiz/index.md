Una funzione del modulo `Test` ha successo quando una condizione è vera. La condizione è `True` o `False`. Qual è questa funzione?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` riceve una condizione. Ha successo quando la condizione è vera. `is` confronta il valore che ottieni con il valore che ti aspetti. `plan` dice quanti test aspettarsi. `done-testing` chiude il file e stampa il piano.

</div>
