## Problema

Ecco un hash: `a => 1, b => 2, c => 3`. Elimina l'elemento `b` con un avverbio di accesso tramite indice. Poi stampa quanti elementi restano nell'hash. Questo mostra che un elemento non c'è più.

## Esempio

Il programma stampa:

```
2
```
