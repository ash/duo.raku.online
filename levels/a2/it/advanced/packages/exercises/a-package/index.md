## Problema

Crea un package `Temperature`. Dentro ci sono due cose. La prima è una variabile `our` `$freezing` con il valore `0`. La seconda è una subroutine `our` `fahrenheit`. Trasforma un valore in Celsius in Fahrenheit. Per farlo, moltiplica per 9/5 e aggiungi 32. Dall'esterno del package, stampa il punto di congelamento. Poi stampa `100` gradi Celsius in Fahrenheit.

## Esempio

Il programma stampa:

```
0
212
```
