## Problema

`do` funziona anche prima delle istruzioni di controllo del flusso. Le rende espressioni con un valore. Usate `do if 7 > 5 { 'big' } else { 'small' }` per scegliere un'etichetta. Assegnate l'etichetta a `$label` e stampatela.

## Esempio

Il programma stampa:

```
big
```
