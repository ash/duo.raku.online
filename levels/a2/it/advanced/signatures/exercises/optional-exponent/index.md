## Problema

Scrivi una subroutine `power`. Ha un parametro obbligatorio `$base` e un parametro **opzionale** `$exp`. Se il chiamante dà l'esponente, eleva la base all'esponente. Se l'esponente non c'è, eleva la base al quadrato. Per farlo, usa l'operatore defined-or `//` per dare `2`.

Chiamala due volte. Prima dai solo una base. Poi dai una base e un esponente.

## Esempio

Il programma stampa:

```
25
125
```
