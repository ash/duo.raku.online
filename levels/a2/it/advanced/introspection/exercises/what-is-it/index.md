## Problema

`WHAT` fa più che descrivere un tipo. Restituisce l'oggetto tipo stesso. Puoi confrontare gli oggetti tipo con l'operatore `===`.

Dichiara due variabili. `$a` contiene l'intero `42`. `$b` contiene la stringa `'x'`. Per ogni variabile, guarda il suo `WHAT`. È il tipo `Int`? Stampa la risposta.

## Esempio

Il programma stampa:

```
True
False
```
