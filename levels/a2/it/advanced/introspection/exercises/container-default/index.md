## Problema

Un contenitore può avere un valore predefinito. Lo imposti con il trait `is default`. Finché non assegni un valore, la variabile restituisce questo valore predefinito. Anche `.VAR.default` lo mostra.

Dichiara uno scalare `$count`. Il suo valore predefinito deve essere `0`. Non assegnargli niente. Stampa la variabile. Poi stampa il valore predefinito del suo contenitore. Tutte e due le righe devono mostrare `0`.

## Esempio

Il programma stampa:

```
0
0
```
