## Problema

Crea un hash con la coppia `a => 1`. Poi leggi il valore della chiave `a`. Per farlo, usa l'operatore di indicizzazione postcircumfisso `< >`. Stampa il valore.

## Esempio

Il programma stampa:

```
1
```
