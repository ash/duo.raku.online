Un _modulo_ è un file con codice che puoi usare di nuovo. Può avere subroutine, variabili e altro. Altri programmi possono caricare il modulo e condividerlo. Questa sezione mostra le cose principali in tre passi. Primo, **scrivi** un modulo. Indichi cosa dà agli altri programmi. Secondo, un programma **carica** il modulo con `use`. Terzo, l'**importazione** porta i nomi del modulo nel tuo scope.
