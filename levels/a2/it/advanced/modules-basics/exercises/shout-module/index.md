## Problema

Crea un modulo con il nome `Shouter` nel file `Shouter.rakumod`. Il modulo esporta una subroutine `shout`. La subroutine restituisce il suo argomento in maiuscolo, cioè tutto in lettere maiuscole.

Poi scrivi un programma separato. Il programma usa il modulo e stampa `shout('hi')`.

## Esempio

Esegui il programma con il modulo nel percorso di ricerca. Ecco cosa stampa:

```console
$ raku -I. shout.raku
HI
```
