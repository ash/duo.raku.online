## Problema

Crea un modulo con il nome `Maths` nel file `Maths.rakumod`. Il modulo esporta una subroutine `square`. La subroutine restituisce il quadrato del suo argomento.

Poi scrivi un programma separato. Il programma usa il modulo e stampa `square(6)`.

## Esempio

Esegui il programma con il modulo nel percorso di ricerca. Ecco cosa stampa:

```console
$ raku -I. maths.raku
36
```
