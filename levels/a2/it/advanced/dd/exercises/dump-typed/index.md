## Problema

Dichiara una variabile di tipo `Int`: `my Int $n = 42;`. Fai il dump con `dd`. Guarda l'output. Una variabile senza tipo dà un output diverso.

## Esempio

Il programma stampa questo sul flusso di errore standard:

```
Int $n = 42
```
