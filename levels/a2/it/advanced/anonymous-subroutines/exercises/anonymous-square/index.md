## Problema

Non devi per forza tenere prima una subroutine anonima in una variabile. Puoi darla direttamente a un'altra routine. Usa la forma `sub`, non un blocco a freccia. Scrivi una subroutine anonima “quadrato”. Moltiplica un numero per se stesso. Passala direttamente a `map` sulla lista `1, 2, 3`. Stampa il risultato.

## Esempio

Il programma stampa:

```
(1 4 9)
```
