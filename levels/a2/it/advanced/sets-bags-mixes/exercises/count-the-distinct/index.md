## Problema

Ecco una lista di numeri. Alcuni si ripetono:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Stampa quanti valori _distinti_ ha. I valori distinti sono tutti diversi tra loro. Usa un set.

## Esempio

Il programma stampa:

```
7
```
