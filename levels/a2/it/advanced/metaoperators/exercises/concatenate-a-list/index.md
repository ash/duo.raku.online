## Problema

Un URL è diviso in pezzi. I pezzi sono in un array. Unisci di nuovo i pezzi in una stringa. Usa un meta-operatore di riduzione per questo. Stampa l'URL. Sulla riga dopo, stampa la sua lunghezza in caratteri.

## Esempio

Ecco l'array di input:

```raku
my @parts = <http :// example .com>;
```

Il programma stampa:

```
http://example.com
18
```
