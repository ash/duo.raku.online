## Problema

Scrivi un programma. Il programma stampa la media di un array di numeri. La media si chiama anche media aritmetica. Usa un meta-operatore di riduzione per sommare i valori.

I numeri sono scritti nel programma stesso. Per esempio:

```raku
my @data = 10, 20, 30, 40;
```

## Esempio

Il programma stampa la media degli elementi di `@data`:

```
25
```
