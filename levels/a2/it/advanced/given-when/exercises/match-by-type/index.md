## Problema

Un `when` può confrontare un *tipo*, non solo un valore. Una variabile contiene il numero `3.14`. Usa `given`/`when` per dire di che tipo è il valore. Stampa `integer` per un `Int`. Stampa `rational` per un `Rat`. Stampa `string` per uno `Str`.

## Esempio

Il programma stampa:

```
rational
```
