## Problema

Usa `given`/`when`. L'età è un numero nel codice. Stampa la fase della vita per questa età. Usa questi gruppi:

* `child` per 0–12,
* `teenager` per 13–19,
* `adult` per 20–64,
* `senior` per 65 o più.

Un'età sotto zero non ha senso. Così per ogni numero sotto zero stampa `invalid`. Controlla questo caso per primo, prima degli intervalli.

## Esempio

Se l'età è `30`, il programma stampa:

```
adult
```
