## Problema

Crea un acronimo da una frase. Un acronimo è fatto delle prime lettere delle parole. Prendi la prima lettera di ogni parola. Unisci le lettere. Stampa il risultato in maiuscolo.

Usa questa frase:

```raku
my $phrase = 'hyper text markup language';
```

## Esempio

Il programma stampa:

```
HTML
```
