## Problema

L'operatore `**` è più forte di `+`. Così Raku legge `2 ** 3 + 1` come `(2 ** 3) + 1`. Questo fa `9`. Aggiungi le parentesi e cambia questo ordine. L'addizione deve avvenire *per prima*. Stampa il risultato.

## Esempio

Il programma stampa:

```
16
```
