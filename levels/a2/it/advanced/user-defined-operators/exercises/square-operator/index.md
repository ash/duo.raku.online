## Problema

Il simbolo di un operatore può essere qualsiasi carattere. Può anche essere un carattere Unicode. Definisci un operatore **postfisso** `²`. Restituisce il quadrato del suo operando. Così `5²` vuol dire `5 ** 2`. Poi stampa `5²`.

## Esempio

Il programma stampa:

```
25
```
