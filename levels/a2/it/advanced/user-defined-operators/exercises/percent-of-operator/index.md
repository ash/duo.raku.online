## Problema

Definisci un operatore infisso `percent-of`. L'espressione `$p percent-of $whole` deve restituire il `$p` per cento di `$whole`. Per esempio, `20 percent-of 150` fa `30`.

Usa l'operatore per stampare `20 percent-of 150`.

## Esempio

Il programma stampa:

```
30
```
