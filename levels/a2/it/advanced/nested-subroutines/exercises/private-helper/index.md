## Problema

Scrivi una subroutine `stats`. Dentro, definisci una subroutine helper **annidata** `double`. Restituisce il suo argomento moltiplicato per due. Dentro `stats`, usa l'helper. Stampa il valore di `double(3) + double(5)`.

Poi chiama `stats`.

## Esempio

Il programma stampa:

```
16
```
