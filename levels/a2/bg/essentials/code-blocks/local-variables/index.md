---
title: Локални променливи
---

{% include menu.html %}

Сега създавате променлива в глобалния обхват. Създавате я и локално, вътре в блока. Какво става тогава?

```raku
my $x = 1;

{
    my $x = 42;
    say $x;
}

say $x;
```

Сега в програмата има две променливи. Те имат едно и също име. Но това са различни променливи. В глобалния обхват всяко `$x` е глобалната променлива. Вътре в блока `$x` е локална променлива. Тя не е глобалната `$x`. Програмата отпечатва две различни стойности:

```console
$ raku t.raku
42
1
```
