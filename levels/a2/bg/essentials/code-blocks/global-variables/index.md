title: Глобални променливи
---

{% include menu.html %}

Сега създаваме променлива преди блока с код:

```raku
my $x = 1;

{
    $x = 42;
    say $x;
}

say $x;
```

Тук `$x` е глобална променлива. Тя е в глобалния обхват. Цялата програма може да я използва. Програмата отпечатва `42` два пъти.
