---
title: Множество функции `MAIN`
---

{% include menu.html %}

Като всяка друга функция в Raku, `MAIN` може да има `multi` варианти. Така програмата може да реагира различно на различни входни данни. Входните данни могат да имат различен брой параметри. Или параметрите могат да имат различни типове.

```raku
multi sub MAIN($a) {
    say 2 * $a;
}

multi sub MAIN($a, $b) {
    say $a + $b;
}
```

При един аргумент тази програма го удвоява. При два аргумента тя ги събира:

```console
$ raku t.raku 21
42

$ raku t.raku 21 33
54
```
