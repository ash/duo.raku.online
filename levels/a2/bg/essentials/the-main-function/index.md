---
title: Функцията `MAIN`
---

{% include menu.html %}

Програмата на Raku няма нужда от специален код в началото. Затова можете веднага да започнете с полезен код. Този код не е в нито един [код блок](/bg/essentials/code-blocks). Например, той не е във [функция](/bg/essentials/functions). Тази част от програмата наричаме _основна линия_.

Програмата може да има функция със специалното име `MAIN`. В този случай Raku първо компилира всичко. След това изпълнява основния код. После изпълнява функцията `MAIN`.

```raku
say '1. Основен код';

sub MAIN {
    say '3. MAIN извикана';
}

say '2. Също основен код';
```

Първо тази програма изпълнява `say` на най-високо ниво. След това извиква `MAIN`:

```console
$ raku t.raku
1. Основен код
2. Също основен код
3. MAIN извикана
```

Разбира се, програмата може да има и само функцията `MAIN`. Тогава тя няма друг основен код.
