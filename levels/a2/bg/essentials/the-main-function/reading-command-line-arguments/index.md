---
title: Четене на аргументите на командния ред
---

{% include menu.html %}

Функцията `MAIN` е полезна по две причини. Първо, тя ясно показва къде започва програмата. Второ, тя има аргументи. Те получават стойностите си от командния ред.

Има два начина да четем аргументи от командния ред. Единият начин е масивът [`@*ARGS`](/bg/essentials/positionals/args-array). Вече го използвахме. Сега нека разгледаме втория начин.

Вижте тази програма. Тя събира две числа.

```raku
sub MAIN($a, $b) {
    say $a + $b;
}
```

Стартирайте програмата така. Тя отпечатва сумата на двата си аргумента:

```console
$ raku t.raku 123 45
168
```

Като всяка друга функция, `MAIN` може да има стойности по подразбиране за аргументите си. Някои аргументи могат да ги имат. Дори всички аргументи могат да ги имат. Например:

```raku
sub MAIN($a, $b = 100) {
    say $a + $b;
}
```

Понякога няма втори аргумент. Тогава програмата използва стойността по подразбиране:

```console
$ raku t.raku 15
115
```
