---
title: Преобразуване на типове за типизирани променливи
---

{% include menu.html %}

Ограниченията на типовете са правила за типовете на променливите. Тези правила са доста строги. Например, вземете променлива с тип `Int`. Не можете да ѝ присвоите стойност от тип `Num`. Това е така, дори ако стойността е цяло число:

```raku
my Int $x = 42;
# $x = 42e1; # Грешка
```

За да преобразувате стойността, използвайте [един от методите](/bg/essentials/coercion/#topics-in-this-section).

```raku
my Int $x = 42;
$x = 42e1.Int;
$x = Int(42e1);
```
