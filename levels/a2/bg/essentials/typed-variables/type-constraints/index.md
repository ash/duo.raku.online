---
title: Ограничения на типове
---

{% include menu.html %}

Raku има така наречената постепенна типова система. Това означава, че можете да използвате типове само там, където ги искате. Обикновено не е нужно да задавате типа на променлива. Но понякога може да искате да ограничите типа на променлива. Тогава задайте типа така:

```raku
my Int $var = 42;
```

Сега можете да присвоите друго цяло число на `$var`. Но не можете да сложите низ в нея. Не можете да сложите в нея дори число с плаваща запетая. Ако опитате, получавате изключение:

```raku
my Int $var = 42;
$var = '314E-2';
```

Програмата дава тази грешка:

    Type check failed in assignment to $var; expected Int but got Str ("314E-2")
      in block <unit> at t.raku line 2
