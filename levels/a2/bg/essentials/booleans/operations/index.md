title: Булеви операции

С булеви стойности можете да правите всички обичайни операции. Това са булево И, ИЛИ и изключващо ИЛИ. Изключващото ИЛИ се нарича също XOR:

```raku
say False && True; # И
say False || True; # ИЛИ
say False ^^ True; # XOR
```

Програмата отпечатва това:

    False
    True
    True

## Отрицание

Отрицанието дава обратната булева стойност. За отрицание използвайте префиксния оператор `!`. Префиксният оператор стои преди стойността:

```raku
say !False; # True
```

Скаларната променлива може да пази булева стойност:

```raku
my $did = True;
my $didn't = !$did;
```
