По-долу има няколко програми. Какво отпечатва всяка програма? Изберете правилния отговор.

## 1

Ето програмата:

```raku
my $value = True && False;
say $value;
```

Какво отпечатва?

{:.quiz}
0 | True
1 | False

## 2 

Какво отпечатва втората програма?

```raku
my $value = True && False || True;
say $value;
```

{:.quiz}
1 | True
0 | False

## 3

Какво отпечатва тази програма?

```raku
my $value = True || False && True;
say $value;
```

{:.quiz}
1 | True
0 | False

{% include quiz.html %}

## Коментари

Втората и третата програма имат изрази с три булеви стойности. Резултатът зависи от реда на операциите. Операторът `&&` има по-висок приоритет от `||`. Затова Raku прави `&&` първо.
