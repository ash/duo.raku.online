Рутината `put` работи като [`print`](../print). Но по подразбиране тя добавя нов ред накрая:

1. Преобразува аргументите си в низ. За целта тя извиква метода `Str` върху тях.
1. Добавя символ за нов ред.
1. Изпраща низа към потока `STDOUT`.

Няколко примера:

```raku
42.put;
put 'Alpha', 'Beta';

my @array = 3, 4, 5;
put @array;

my %hash = a => 'b', c => 'd';
%hash.put;
```

Ето изхода на програмата:

```console
$ raku t.raku
42
AlphaBeta
3 4 5
a	b
c	d
```

%%tipblock
## Нов ред на `put`

Какви символи добавя `put` след изхода? Тя ги взема от метода `nl-out` на изходния поток. Стойността по подразбиране е `\n`.
%%/tipblock
