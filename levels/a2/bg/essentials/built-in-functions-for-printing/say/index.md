Вградената рутина `say` прави четири неща:

1. Извиква метода `gist` върху своите аргументи.
1. Добавя нов ред.
1. Преобразува резултата в UTF-8.
1. Изпраща го към потока `STDOUT`.

За потребителя това е просто. `say` отпечатва стойността на променлива в терминала. След това тя добавя нов ред.

Първата стъпка има нужда от малко обяснение. Всеки вграден тип данни има метод `gist`. Целите числа и низовете са примери за такива типове. За тези прости типове `gist` връща елемента като лесна за четене стойност.

```raku
say 42; # 42
say 'Raku'; # Raku
```

Някои данни са по-сложни, например масиви или хешове. За такива данни `gist` добавя малко форматиране.

```raku
my @data = 'alpha', 'beta', 'gamma';
say @data; # [alpha beta gamma]

my %data = alpha => 1, beta => 2, gamma => 3;
say %data; # {alpha => 1, beta => 2, gamma => 3}
```

Можете да извикате `say` като функция. Можете също да я извикате като метод:

```raku
say 42;
say(42);
42.say;
```

Можете да подадете повече от един аргумент на `say`. Тя съединява частите на изхода. Между тях няма интервали.

```raku
say(100, 500); # 100500
```
