title: '`note`'
---

{% include menu.html %}

Рутината `note` отпечатва своите аргументи на стандартния поток за грешки. Във всичко друго `note` е като [`say`](../say).

1. Извиква метода `gist` на своите аргументи.
1. Добавя символ за нов ред.
1. Преобразува резултата в UTF-8.
1. Изпраща го на потока `STDERR`.

```raku
my $x = 42;
note "Текущата стойност на \$x е $x";
```

Тази програма не изпраща съобщението към `STDOUT`. Проверете това:

```
$ raku t.raku > /dev/null
Текущата стойност на $x е 42
```

Можете да извикате `note` без аргументи. Тогава тя отпечатва съобщението по подразбиране, `Noted`.
