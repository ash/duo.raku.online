Тази секция е много кратка. Тя показва как да стартирате програма, без да излизате от IDE. Разглеждаме двете най-препоръчвани [IDE-та](../../editors-and-ides).

## Visual Studio Code Editor

Отворете терминал от менюто: `Terminal` → `New Terminal`. Под текста на програмата се отваря нов панел. Стартирайте програмата там, както от командния ред:

```console
$ raku hello.raku
```

## Comma IDE

За да стартирате програма, използвайте `Run` в менюто. Преди първото стартиране настройте IDE. Следвайте [инструкциите](https://commaide.com/docs/running) на сайта на Comma.
