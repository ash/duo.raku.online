Можете да съедините два низа. Тогава получавате нов, по-дълъг низ. Това наричаме конкатенация на низове. В Raku конкатенирате низове с оператор. Можете ли да познаете името му? Това е операторът за конкатенация! Този оператор е тилда: `~`. За да конкатенирате два низа, сложете `~` между тях:

```raku
say 'Hello, ' ~ 'World!';
```

Понякога низовете са в променливи. Тогава можем да „конкатенираме променливите“. Е, всъщност конкатенираме низовете в тези променливи:

```raku
my $greeting = 'Hello, ';
my $who = 'World!';

say $greeting ~ $who;
```

Можете също да сложите резултата в нова променлива:

```raku
my $greeting = 'Hello, ';
my $who = 'World!';
my $message = $greeting ~ $who;

say $message;
```

## Конкатенация и присвояване в една стъпка

Понякога искате да добавите низ в края на променлива. Тогава използвайте тази форма:

```raku
# Вместо 
$str = $str ~ $another-str;

# използвайте:
$str ~= $another-str;
```
