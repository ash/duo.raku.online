title: Тематична променлива
---

{% include menu.html %}

`$_` е специална променлива. Тя се казва _променлива за тема_.

Вижте този цикъл върху диапазон:

```raku
for 1..5 -> $n {
    say $n;
}
```

Не е нужно да пишете `$n`. Без нея Raku използва променливата `$_`. Raku създава тази променлива за вас. Така тази програма прави същото:

```raku
for 1..5 {
    say $_;
}
```

[Вече знаете](/bg/essentials/hello-world/), че `say` може да бъде и метод:

```raku
for 1..5 {
    $_.say;
}
```

При извикване на метод върху `$_` не ви трябва името `$_`. Така цикълът може да е още по-кратък:

```raku
for 1..5 {
    .say;
}
```
