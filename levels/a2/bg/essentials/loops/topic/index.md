title: Тематична променлива
---

{% include menu.html %}

`$_` е специална променлива. Тя се казва _променлива за тема_.

Вижте този цикъл върху диапазон:

```raku
for 1..5 -> $n {
    say $n;
}
```

Можете да пропуснете променливата `$n`. Тогава Raku използва вместо нея променливата `$_`. Програмата прави същото като тази:

```raku
for 1..5 {
    say $_;
}
```

[Вече знаете](/bg/essentials/hello-world/), че можете да използвате `say` като метод:

```raku
for 1..5 {
    $_.say;
}
```

Когато извиквате метод върху `$_`, не е нужно да пишете променливата. Така цикълът може да бъде още по-кратък:

```raku
for 1..5 {
    .say;
}
```
