title: Тристатъментен цикъл `loop`

Операторът `loop` в Raku прилича на класическите цикли в езика C и подобни езици. Той приема три израза. Първият задава началната стойност. Вторият е тестът. Третият променя променливата на цикъла. Тялото на цикъла се изпълнява отново и отново, докато тестът е `True`.

```raku
loop (my $c = 0; $c < 5; $c++) {
    say "Текущата стойност на брояча е $c.";
}
```

Тук `++` е оператор след променлива. Той добавя 1 към променливата. Ще научите още оператори във втората част на курса.

Програмата изпълнява тялото на цикъла пет пъти.

```console
$ raku t.raku
Текущата стойност на брояча е 0.
Текущата стойност на брояча е 1.
Текущата стойност на брояча е 2.
Текущата стойност на брояча е 3.
Текущата стойност на брояча е 4.
```

Можете да пропуснете някои или дори всички изрази в заглавието на `loop`. Например, ето същата програма:

```raku
my $c = 0;
loop (; $c < 5;) {
    say "Текущата стойност на брояча е $c.";
    $c++;
}
```

## * * *

В Raku хората не използват `loop` много често. Можете да го видите, например, в програми, които някой инструмент е превел от C към Raku. Raku има по-лесни цикли, като `for`. Ще разгледаме `for` много скоро.
