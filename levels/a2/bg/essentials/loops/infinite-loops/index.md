Можете да напишете `loop` и само с тяло:

```raku
loop {
    say 'Вечност';
}
```

Този цикъл никога не спира сам. Трябва да спрете програмата, например с `Ctrl+C`. Втората част на курса показва по-добри начини да контролирате циклите.
