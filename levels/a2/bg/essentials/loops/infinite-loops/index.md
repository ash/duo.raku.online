Можете да използвате `loop` и само с тяло:

```raku
loop {
    say 'Вечност';
}
```

Този цикъл работи вечно. Той спира само когато спрете програмата, например с `Ctrl+C`. Във втората част на курса ще научите по-добри начини да контролирате циклите.
