---
title: Постфиксна форма на `for`
---

{% include menu.html %}

Вече познавате други модификатори на изрази: [`if` и `else`](/bg/essentials/conditional-checks/modifiers) и [`while` и `until`](/bg/essentials/loops/modifiers). Това е добра новина. В Raku подобните неща работят по подобен начин.

Кратко тяло на цикъл може да има `for` след себе си:

```raku
.say for 1..7;
```

Диапазоните изглеждат много естествено с `for` в края.

Тази програма прави същото като обикновен цикъл:

```raku
for 1..7 -> $n {
    say $n;
}
```

Или прави същото като този цикъл с `$_`:

```raku
for 1..7 {
    .say;
}
```

Тук `.say` е кратък начин да напишете `$_.say`.
