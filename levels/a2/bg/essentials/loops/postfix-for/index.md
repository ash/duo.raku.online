---
title: Постфиксна форма на `for`
---

{% include menu.html %}

Вече познавате други модификатори на изрази: [`if` и `else`](/bg/essentials/conditional-checks/modifiers) и [`while` и `until`](/bg/essentials/loops/modifiers). Това е добра новина, защото Raku има много последователен дизайн.

Когато тялото на цикъла е кратко, можете да напишете `for` след него:

```raku
.say for 1..7;
```

Диапазоните изглеждат много естествено с тази форма на `for`.

Тази програма прави същото като един по-обикновен цикъл:

```raku
for 1..7 -> $n {
    say $n;
}
```

Или, със стандартната променлива на цикъла, тя прави същото като това:

```raku
for 1..7 {
    .say;
}
```

Тук `.say` е кратък начин да напишете `$_.say`.
