Цикълът `for` е много полезен. Той минава през много елементи, един по един. Например, вземете един диапазон:

```raku
for 1..5 -> $n {
    say $n;
}
```

`$n` получава следващата стойност от диапазона всеки път. Не е нужно да пишете `my` преди `$n`. Блокът се изпълнява веднъж за всяка стойност в диапазона. Така програмата отпечатва числата, по едно на всеки ред:

```console
$ raku t.raku 
1
2
3
4
5
```

Програмата минава през всички стойности на [диапазона](/bg/essentials/ranges) `1..5`. Тези стойности са `1`, `2`, `3`, `4` и `5`.

## Повече от една стойност наведнъж

В Raku един цикъл може да взема два или повече елемента всеки път. Тази програма отпечатва по две числа наведнъж:

```raku
for 1..6 -> $n, $m {
    say "$n and $m";
}
```

Ето какво отпечатва програмата:

```console
$ raku t.raku
1 and 2
3 and 4
5 and 6
```
