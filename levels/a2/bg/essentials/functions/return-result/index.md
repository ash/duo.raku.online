Често функцията прави нещо и освен това връща резултат. Във функционалното програмиране, например, функциите не трябва да имат странични ефекти. Печатането на конзолата е един такъв страничен ефект. Но Raku ви позволява да го правите. Нека видим как функцията връща стойност. Ще видим и как извикващият код получава тази стойност.

```raku
sub add($x, $y) {
    return $x + $y;
}

my $sum = add(10, 20);
say $sum; # 30
```

Тук функцията `add` приема две числа. Тя връща тяхната сума. Функцията има думата `return` в своя код. Извикващият код може да използва тази стойност като всяка друга стойност. В програмата по-горе я присвояваме на променлива.

## Последната стойност

Резултатът може да е последната стойност в тялото на функцията. Тогава в Raku не е нужно да пишете `return`. Така можем да направим нашата функция `add` по-проста:

```raku
sub add($x, $y) {
    $x + $y
}
```

Обърнете внимание, че редът няма точка и запетая в края. Редът е последният в блока код. Затова там не е нужна точка и запетая.

Малки и прости функции като тази често се пишат на един ред. Тогава кодът е по-кратък:

```raku
sub add($x, $y) { $x + $y }
```

## Няма данни за връщане

Понякога функцията трябва да излезе преди края на своето тяло. Ако функцията не връща резултат, използвайте `return` без стойност.

```raku
sub test($x) {
    return if $x <= 10;
    say "$x е над лимита";
}
```
