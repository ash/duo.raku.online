Сега предаваме някакви данни на функция. Функцията може да приема параметри. Напишете ги в скоби веднага след името на функцията.

```raku
sub greet($name) {
    say "Здравей, $name!";
}
```

Сега можете да използвате функцията. Можете да ѝ предавате различни аргументи:

```raku
greet('Алла');
greet('Карл');
```

Извикваме една и съща функция два пъти. Сега резултатите са различни:

```console
$ raku t.raku
Здравей, Алла!
Здравей, Карл!
```

%%tipblock

## Параметър или аргумент

Хората често използват тези две думи по един и същ начин. И двете думи са за ‘едно и също нещо’. Но те го гледат от различни страни.

* Параметър е това, което функцията очаква да получи.
* Аргумент е това, което предавате на функцията.

В горния пример `$name` е параметърът на функцията. `'Алла'` и `'Карл'` са нейните аргументи.

%%/tipblock

## Повече параметри

Функцията може да приема повече от един параметър. Тогава сложете запетаи между тях:

```raku
sub add($x, $y) {
    say $x + $y;
}

add(10, 20); # 30
```

## Без параметри

Функцията може и да няма никакви параметри. Тогава можете да напишете празни скоби. Или можете да пропуснете скобите. Така направихме в [началото на тази секция](../).

```raku
sub greet() {
    say 'Здравей, свят!';
}

greet();
```

## Подпис

Списъкът с параметри на функцията е нейният _подпис_.
