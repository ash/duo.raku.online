---
title: Позиционни параметри
---

{% include menu.html %}

Редът на параметрите на функцията е важен. Например, вземете една функция. Тя намира разликата между две числа:

```raku
sub diff($a, $b) { $a - $b }
```

Разбира се, `diff(10, 20)` и `diff(20, 10)` дават различни резултати.

Във функцията по-горе параметрите са списък със запетаи. Такива параметри се наричат _позиционни_. При извикване редът на аргументите е важен. Той определя значението на всеки параметър.
