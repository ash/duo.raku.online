Позиционните и именуваните параметри могат да имат стойности по подразбиране. Параметър със стойност по подразбиране не е задължителен. Можете да го пропуснете, когато извиквате функцията. Тогава параметърът получава своята стойност по подразбиране.

## Позиционни параметри

Ето един пример. Функцията има позиционен параметър със стойност по подразбиране:

```raku
sub greet($name = 'World') {
    say "Hello, $name!";
}

greet('Merinda');
greet();
```

Първото извикване предава име като единствен аргумент. Затова то отпечатва `Hello, Merinda!`. Второто извикване използва стойността по подразбиране. То отпечатва `Hello, World!`.

Понякога функцията има повече от един параметър. Тогава стойностите по подразбиране трябва да са в края на списъка:

```raku
sub f($a, $b, $c = 42, $d = 50) { . . . } # правилно
# sub f($a = 10, $b = 20, $c, $d) { . . . } # ГРЕШНО
```

## Именувани параметри

Именуваните параметри получават стойности по подразбиране по същия начин:

```raku
sub greet(:$name = 'World') {
    say "Hello, $name!";
}

greet(name => 'Merinda'); # Hello, Merinda!
greet(); # Hello, World!
```

Редът на именуваните параметри няма значение. Затова всеки от тях може да има стойност по подразбиране. Дори първият в списъка може да има такава:

```raku
sub greet(:$greeting = 'Hello', :$name) {
    say "$greeting, $name!";
}

greet(name => 'Alla'); # Hello, Alla!
```
