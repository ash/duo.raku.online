Ето отново функцията от предишния тест:

```raku
sub f(:$a, :$b) {
    $a - $b
}
```

Програмата има и три променливи:

```raku
my $a = 1;
my $b = 2;
my $c = 3;
```

Предавате две от трите променливи на функцията. Кои извиквания са правилни? Отбележете ги всичките.

{:.quiz}
1 | f(a => $a, b => $b)
1 | f(a => $c, b => $c)
0 | f($a, $b) | Тук са предадени позиционни аргументи вместо именувани.
1 | f(:$a, :$b)
0 | f($:a, $:b) | Невалиден синтаксис в Raku.
0 | f(:$b, :$c) | Няма именуван параметър `c`.
0 | f(:$a, c => $c) | Няма именуван параметър `c`.
1 | f(:$a, b => $c)
1 | f(:$a, :b($c)) | Същото като горното.
1 | f(:a($a), :b($c)) | Също е правилно, макар и малко излишно.
