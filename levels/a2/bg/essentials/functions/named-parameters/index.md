_Именуваните_ параметри не са като [позиционните параметри](../positional-parameters). При извикване пишете техните имена.

Тази функция приема два параметъра. Техните имена са `$from` и `$to`.

```raku
sub distance(:$from, :$to) { $from - $to }
```

За да извикате функцията, напишете името на всеки аргумент:

```raku
say distance(from => 30, to => 10); # 20
```

Не предавайте аргументите като позиционни. Това е грешка. Например извикването `distance(30, 10)` дава грешка:

    Прекалено много позиционни аргументи; очаквани 0 аргумента, но получени 2
        в sub distance на ред 1 в t.raku
        в блок <unit> на ред 2 в t.raku

Ето и добрата част. Можете да пишете именуваните аргументи в произволен ред. Тези две извиквания правят точно едно и също:

```raku
say distance(from => 30, to => 10); # 20

say distance(to => 10, from => 30); # 20
```

## Предаване на променливи

Понякога искате да предадете стойност от променлива. Променливата има същото име като параметъра. Тогава помага специален синтаксис. С него пишете по-малко:

```raku
my $from = 30;
my $to = 10;
say distance(:$from, :$to); # 20
```

Това извикване прави същото като едно по-дълго:

```raku
say distance(from => $from, to => $to); # 20
```

Отново, редът няма значение:

```raku
say distance(:$to, :$from); # 20
```

Понякога променливата и параметърът имат различни имена. Тогава предайте двойка по един от тези начини:

```raku
my $a = 20;
my $b = 10;

say distance(from => $a, to => $b);

# или:

say distance(:from($a), :to($b));
```
