Raku има _многократно разпределение_ според подписа на функцията. С него няколко функции могат да имат едно и също име. Но те приемат различни типове входни данни. Напишете декларатора `multi` пред всеки вариант на функцията.

```raku
multi sub add(Int $x, Int $y) { $x + $y }
multi sub add(Str $x, Str $y) { $x ~ $y }
```

Можете да пропуснете `sub` след `multi`.

Тук една и съща функция има два варианта. Компилаторът гледа аргументите във всяко извикване. После избира правилния вариант. Това е многократно разпределение. Сравнете тези две извиквания:

```raku
say add(10, 20); # 30
say add('10', '20'); # 1020
```

Първото извикване изпълнява варианта с целочислени параметри. Второто извикване изпълнява втория вариант. Този вариант очаква два низа.

## Литерални параметри

Ето един интересен случай. Един вариант може да има литерална стойност като параметър. Литералът е стойност в кода, например `42`. Вижте тези два варианта:

```raku
multi sub f(42) {say 'Това е отговорът'}
multi sub f($x) {say "$x не е отговорът"}
```

Raku изпълнява първия вариант само когато аргументът е точно 42. Във всички други случаи Raku изпълнява втория вариант. Редът на двете дефиниции няма значение.

```raku
f(10); # 10 не е отговорът
f(42); # Това е отговорът
```
