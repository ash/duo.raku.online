Функциите в Raku са предимно лесни за използване. Обикновено те не създават проблеми. Но внимавайте с едно нещо.

## TL;DR

Не пишете интервал между името на функцията и скобите. В скобите са аргументите. Но слагайте интервал след `for` и `if`.

## Дълга история

Ето една проста функция:

```raku
sub f($x, $y) {
    return $x + $y;
}
```

Първо, вижте името на функцията. Отварящата скоба идва веднага след него, без интервал. Параметрите са в тези скоби. Някои стилове на кодиране в други езици искат интервал там. Raku също го приема. Но това не е добър начин да пишете код:

```raku
sub f ($x, $y) {
    return $x + $y;
}
```

При извикване на функция липсата на интервал е важна. Понякога извиквате функция без скоби. Тогава трябва да сложите интервал след името на функцията:

```raku
f 5, 6;
```

Но със скоби не трябва да има интервал преди тях. Това извикване е правилно:

```raku
f(5, 6);
```

А това извикване е грешно:

```raku
f (5, 6);
```

Този код предизвиква изключение:

    Too few positionals passed; expected 2 arguments but got 1
      sub f at t.raku line 1
      in block <unit> at t.raku line 5

Вижте извикването с интервал: `f (5, 6)`. Raku мисли, че предавате един аргумент на функцията. Този аргумент е `(5, 6)`. Можете лесно да проверите типа на този аргумент. Променете функцията. Тя трябва да приема само един аргумент:

```raku
sub f($param) {
    say $param.WHAT;
}

f (5, 6); # (List)
```

Значи извикването `f (5, 6)` предава [списък](/bg/essentials/positionals/lists) на функцията. Целият списък е един аргумент.

## Кога ви трябва интервал

Понякога ви трябва интервал. Това става, когато използвате скоби след ключова дума. Например, ключовата дума може да е `if`, `for` или `loop`. Този код е грешен:

```raku
if(True != False) {
    say 'OK';
}
```

Съобщението за грешка ви казва какво не е наред:

    ===SORRY!===
    The word 'if' is interpreted as a 'if()' function call.  Please use
    whitespace instead of parentheses.
    at /Users/ash/raku-course/t.raku:1
    ------> if⏏(True != False) {
    Unexpected block in infix position (two terms in a row)
    at /Users/ash/raku-course/t.raku:1
    ------> if(True != False)⏏ {

С `if` изобщо не ви трябват скоби. Без тях този проблем не може да се случи. Но понякога ви трябват скоби, например с `loop`. Тогава трябва да сложите интервал:

```raku
loop(my $c = 0; $c != 10; $c++) { say $c }
```

Същото се случва и в този код. Компилаторът мисли, че `loop(...)` е извикване на функция. Добавете интервал, за да оправите проблема. Или, още по-добре, напишете този код с `for`.

## Заключение

И така, ето главното. Не слагайте интервал между името на функцията и нейните скоби. Така избягвате такива проблеми. Също така, опитайте да не използвате скоби на други места, когато можете. Например, с `if` и `for` те не ви трябват.
