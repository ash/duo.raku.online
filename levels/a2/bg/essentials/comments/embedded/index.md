---

{% include menu.html %}

Вградените коментари се казват още inline коментари. Те изглеждат като многострочните коментари. Има само една разлика. Поставяте ги между други части на програмата. Например:

```raku
my $name;
$name = #`[Очаква се потребителски вход тук] prompt 'Как се казваш? ';
say $name;
```

Добрият синтактичен оцветител показва кода в цветове. Това много помага да виждате коментарите.
