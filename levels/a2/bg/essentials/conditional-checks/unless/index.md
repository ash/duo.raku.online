---
title: Използване на `unless`
---

{% include menu.html %}

[Операторът `!`](/bg/essentials/booleans/operations#negation) лесно превръща всяко булево условие в обратното. Но понякога този `!` прави израза по-сложен. Тогава той се чете по-трудно. В такива случаи `unless` може да помогне.

Условието на `unless` трябва да е `False`. Тогава Raku изпълнява блока.

```raku
my $broken = False;

# ...Нещо може да направи $broken True тук...
    
unless $broken {
    say "Не се притеснявай!";
    say "Бъди щастлив!";
}
```

Ето две версии на една и съща програма. Сравнете ги:

С `if` и `!`:

```raku
if !$broken { . . . }
```

С `unless`:

```raku
unless $broken { . . . }
```

Значи имате избор. Във всяка ситуация изберете това, което ви харесва повече.

Не можете да сложите блок `else` или `elsif` след `unless`. За това трябва да използвате `if`.
