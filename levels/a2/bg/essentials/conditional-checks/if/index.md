---
title: Блокове `if`
---

{% include menu.html %}

`if` е условна проверка. Тя тества условие. Ако условието е `True`, `if` изпълнява блок от код.

```raku
if 10 > 4 {
    say 'Математиката работи!';
}
```

Не е нужно да слагате условието в кръгли скоби. Но можете, ако искате.

Разбира се, можете да използвате променливи в тестовете:

```raku
my $flag = False;
if $flag {
    # . . . направете нещо
}
```

Понякога две или повече проверки използват една и съща променлива. Тогава можете да напишете сравненията като верига:

```raku
my $x = 42;
if 40 < $x < 45 {
    say "Даден е правилният отговор $x.";
}
```

Понякога условието е `False`. Тогава Raku не изпълнява блока от код. Програмата просто продължава.

```raku
say 'Начало';
if False {
    say 'Това никога не се отпечатва.';
}
say 'Край';
```

Тази програма отпечатва само `Начало` и `Край`.
