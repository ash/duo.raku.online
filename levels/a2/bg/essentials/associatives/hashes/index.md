_Хеш_ е още един асоциативен тип данни в Raku. Това е агрегатен тип данни. Той съдържа много елементи. Всеки елемент има име и стойност. Хеш променливите използват нов сигил: `%`.

```raku
my %capitals;
```

Сега можете да използвате хеша. Можете да му присвоите някои начални стойности.

```raku
%capitals = France => 'Paris', Italy => 'Rome';
```

Можете също да направите двете неща наведнъж. Това работи и с другите типове данни:

```raku
my %capitals = France => 'Paris', Italy => 'Rome';
```

## Вземане на елементите

За да вземете елемент, индексирате хеша. Правите това по същия начин като при [двойките](../pairs). Сложете низ в ъглови скоби или в къдрави скоби:

```raku
say %capitals<France>;
say %capitals{'Italy'};
```

Хешовете са изменяеми. Това означава, че можете да ги променяте. Можете да променяте стойностите. Можете също да добавяте нови:

```raku
%capitals<Germany> = 'Berlin';
```

## Ключове и стойности

Raku има два вградени метода за хешове, `keys` и `values`. Методът `keys` връща списък с ключовете. Методът `values` връща списък със стойностите:

```raku
say %capitals.keys;
say %capitals.values;
```

Програмата може да отпечата например това:

    (Germany Italy France)
    (Berlin Rome Paris)

Забележете, че елементите на хеша нямат определен ред. Но двата метода използват един и същ ред.
