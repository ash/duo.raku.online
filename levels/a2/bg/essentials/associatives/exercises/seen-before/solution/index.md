Това е класическа задача за хеш. Хешът помни кои елементи вече са се появили. Преди цикъла програмата създава хеша `%seen`. В цикъла потребителят въвежда дума, `$word`. Програмата използва тази дума като ключ на хеша.

## Код

Ето решението:

```raku
my %seen;
loop {
    my $word = prompt 'Дума: ';
    if %seen{$word} {
        say %seen{$word} == 1 ?? 'Виждано!' !! say "Виждано %seen{$word} пъти!";
    }
    %seen{$word}++;
}
```

🦋 Намерете програмата във файла [seen-before.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/associatives/seen-before.raku).

## Коментар

Кодът `%seen{$word}++` добавя 1 към стойността. Ако стойността още не съществува, кодът също я създава. Създаването на стойност по този начин се нарича _автовивификация_. Забележете, че това не се случва, когато само _четете_ стойността. Например, това не се случва в условието `if %seen{$word}`.
