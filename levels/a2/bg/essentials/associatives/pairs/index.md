Двойката е структура от данни. Тя пази име и стойност. Заедно те образуват един цял обект. Можете да пазите този обект в скаларна променлива. Ето как създавате двойка:

```raku
my $pair = name => 'Anna';
```

Променливата `$pair` има типа `Pair`:

```raku
say $pair.WHAT; # (Pair)
```

Можете да вземете името и стойността поотделно. Методът `key` дава името. Методът `value` дава стойността:

```raku
say $pair.key; # name
say $pair.value; # Anna
```

Двойките имат една важна черта. Те са неизменяеми. Това означава, че не можете да дадете нова стойност на двойка. Не можете да ѝ дадете и ново име. Разбира се, можете да присвоите съвсем нова двойка на същата променлива:

```raku
my $pair = name => 'Anna';
$pair = name => 'John';
say $pair.value; # John
```

## Индексиране

Има още един начин да прочетете стойността на двойка. Можете да индексирате двойката. Сложете името на ключа ѝ в ъглови скоби. Ето как:

```raku
say $pair<name>;
```

Забележете, че ключ без интервали няма нужда от кавички. Ако ключът има интервали, правилата са малко по-строги:

```raku
my $pair = 'employee name' => 'Julie Madelon';
say $pair{'employee name'};
```

Забележете, че този път кодът използва къдрави скоби.
