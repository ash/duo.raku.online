title: Операторът "defined-or"
---

Понякога променливата още няма стойност. Тогава можете да използвате друга стойност вместо нея. За това има оператор `//`. Той се нарича оператор _defined-or_.

```raku
my $a = 'alpha';
say $a // 'gamma';

my $b;
say $b // 'delta';
```

Тази програма отпечатва:

```
alpha
delta
```

Първият ред дава стойност на `$a`. Затова изразът `$a // 'gamma'` използва текущата стойност на `$a`. С променливата `$b` е различно. Тя няма стойност. Затова `$b // 'delta'` дава стойността отдясно. Програмата отпечатва `delta`.

## //=

Заедно `//` и `=` правят оператора `//=`. Той присвоява стойност само когато променливата не е дефинирана.

```raku
my $x;
$x //= 42;
say $x; # 42
```
