Сега знаете два начина да съберете действия заедно. Единият е _подпрограма_. Другият е _метод_. Те изглеждат подобни. Но ги използвате по различен начин.

Подпрограмата стои сама. Тя не принадлежи на нищо. Извиквате я по име. Подавате ѝ като аргументи всичко, което ѝ трябва:

```raku
sub area-of($radius) {
    π * $radius * $radius;
}

say area-of(2); # 12.566370614359172
```

Методът принадлежи на клас. Той е като функция вътре в класа. Извиквате метода върху обект, с точка. Обектът е стойност от този клас. Методът може да използва данните на своя обект. За това той има `self` и аксесорите на атрибутите. Затова не му подавате тези данни:

```raku
class Circle {
    has $.radius;

    method area {
        π * $.radius * $.radius;
    }
}

say Circle.new(radius => 2).area; # 12.566370614359172
```

И двете дават едно и също число. Разликата е откъде идват данните. Подпрограмата получава радиуса като аргумент. Методът чете радиуса от своя обект. Това е обектът, върху който го извиквате.

Ето едно просто правило. Стои ли кодът сам и работи ли само с аргументите си? Тогава използвайте подпрограма. Принадлежи ли кодът на обект и работи ли с неговите данни? Тогава използвайте метод. Принадлежи ли кодът на клас, но не на един обект? Тогава използвайте методи на класа.
