По подразбиране аксесорът от `has $.name` е _само за четене_. Конструкторът дава стойност на атрибута. Конструкторът е методът, който създава обекта, тук `new`. След това кодът извън обекта може да чете стойността. Но не може да я променя. Опитайте да ѝ присвоите нова стойност. Това дава грешка:

```raku
class Dog {
    has $.name;
}

my $rex = Dog.new(name => 'Rex');
$rex.name = 'Max';
```

Програмата спира с тази грешка:

```
Cannot modify an immutable Str (Rex)
```

Искате ли да променяте стойността през аксесора? Тогава отбележете атрибута с трейта `is rw`:

```raku
class Dog {
    has $.name is rw;
}

my $rex = Dog.new(name => 'Rex');
$rex.name = 'Max';
say $rex.name; # Max
```

Сега аксесорът връща контейнер, в който можете да записвате. Затова присвояването работи. Сега `name` на обекта е `Max`.
