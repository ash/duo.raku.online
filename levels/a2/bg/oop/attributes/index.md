Празният клас не е много полезен. Обектът има нужда от свои данни. Затова давате на класа _атрибути_. Атрибутът е една част от данните в обекта. За да създадете атрибут, напишете ключовата дума `has` вътре в класа:

```raku
class Dog {
    has $.name;
    has $.age;
}
```

Всеки обект получава свое копие на тези атрибути. Давате им стойности, когато създавате обекта. Подайте стойностите на `new` като именувани аргументи:

```raku
class Dog {
    has $.name;
    has $.age;
}

my $rex = Dog.new(name => 'Rex', age => 3);
```

Вижте `$.` в `has $.name`. Това `$.` върши две неща. Първо, създава атрибут. Второ, създава метод със същото име. Този метод връща стойността на атрибута. Такъв метод се нарича _аксесор_:

```raku
say $rex.name; # Rex
say $rex.age;  # 3
```

Различните обекти пазят свои стойности. Те не ги споделят:

```raku
my $rex  = Dog.new(name => 'Rex',  age => 3);
my $fido = Dog.new(name => 'Fido', age => 5);

say $rex.name;  # Rex
say $fido.name; # Fido
```

Следващите теми показват две неща. Първо, правите атрибути, които можете да променяте. После давате на атрибутите стойности по подразбиране. Има и начин да направите _частни_ атрибути. Кодът извън обекта не ги вижда. Връщаме се към тях след методите.
