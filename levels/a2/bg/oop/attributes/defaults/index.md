Атрибутът може да има _стойност по подразбиране_. Понякога създавате обект без стойност за атрибута. Тогава Raku използва стойността по подразбиране. Напишете стойността по подразбиране след атрибута, с `=`:

```raku
class Dog {
    has Str $.name;
    has Rat $.weight = 4.0;
}
```

Забележете още едно нещо. Можете да дадете на атрибута тип, както на променлива. Тогава стойността трябва да е от този тип.

Тук `new` не получава `weight`. Затова атрибутът получава стойността по подразбиране:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.weight; # 4
```

Но пак можете да дадете своя стойност. Тя заменя стойността по подразбиране:

```raku
my $lighty = Dog.new(name => 'Lighty', weight => 3.2);
say $lighty.weight; # 3.2
```

Понякога атрибутът няма стойност по подразбиране. Вие също не подавате стойност за него на `new`. Тогава атрибутът просто е недефиниран. Той е като нова скаларна променлива.
