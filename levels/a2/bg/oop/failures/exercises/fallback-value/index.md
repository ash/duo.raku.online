## Задача

Напишете подпрограма `get`. Тя връща аргумента си. Но ако аргументът е `0`, тя извиква `fail`. Съобщението е `bad`.

Отпечатайте резултата от `get(5)`. После отпечатайте резултата от `get(0)`. Използвайте оператора „определено или“ `//` с резервната стойност `default`. Операторът `//` дава тази стойност, когато резултатът е недефиниран.

## Пример

Програмата отпечатва:

```
5
default
```
