Блокът `try` е лесен за използване. Но за `try` целият блок е едно цяло. Блокът или работи, или се проваля. Фазерът `CATCH` ви дава повече контрол. Изключението е грешка, която спира програмата. С `CATCH` обработвате изключението _вътре_ в неговия блок. Това е блокът с грешката. Там вие решавате какво да правите.

`CATCH` е фазер. Фазерът е специален блок. Raku го изпълнява сам в определен момент. Вече видяхте фазери в [раздела за управлението на потока](/bg/advanced/phasers). Можете да сложите `CATCH` където и да е вътре в блок. Той се изпълнява само ако код в този блок хвърли изключение. Получавате изключението в тематичната променлива `$_`:

```raku
{
    die 'Boom!';

    CATCH {
        default {
            say 'Caught: ' ~ .message;
        }
    }
}

say 'after';
```

Програмата отпечатва:

```
Caught: Boom!
after
```

Блокът `default` вътре в `CATCH` обработва всяко изключение. След като той се изпълни, изключението се смята за обработено. Затова програмата не спира. Тя продължава след блока с `CATCH`. Ето защо програмата отпечатва `after`.

Без `CATCH` `die` спира програмата. Програмата никога не стига до `after`.
