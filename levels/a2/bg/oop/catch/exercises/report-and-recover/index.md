## Задача

Покажете как `CATCH` помага на програмата да се възстанови след грешка. Програмата не спира. Тя продължава с безопасна стойност по подразбиране.

Преди блок създайте променлива `$timeout`. Дайте ѝ стойност по подразбиране `30`. Вътре в блока направете `die 'config missing'`. На следващия ред опитайте да зададете на `$timeout` стойност `60`. Програмата никога не стига до този ред. Добавете фазер `CATCH` с блок `default`. Той отпечатва `warning: <съобщение>; keeping default`. След блока отпечатайте `timeout is <timeout> seconds`.

## Пример

Програмата отпечатва:

```
warning: config missing; keeping default
timeout is 30 seconds
```
