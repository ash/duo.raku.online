Ето един начин да решите задачата.

## Код

```raku
sub log-line($fh, $message) {
    $fh.say($message);
}

my $fh = open 'log.txt', :w;
log-line($fh, 'started');
log-line($fh, 'working');
log-line($fh, 'done');
$fh.close;

print slurp 'log.txt';
```

🦋 Намерете програмата във файла [pass-a-handle.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/file-handles/pass-a-handle.raku).

## Изход

```
started
working
done
```

## Коментари

1. `open` връща манипулатор. Този манипулатор е просто стойност в `$fh`. Затова можете да го подадете на `log-line` като аргумент. Същото правите с низ или число. Вътре в подпрограмата `$fh.say` пише чрез същия отворен манипулатор.

1. Манипулаторът остава отворен през трите извиквания. Затова всяко `log-line` добавя ред в края на същия файл. След това `close` записва всичко на диска. `slurp` прочита трите реда обратно.

1. Така манипулаторите лесно се съчетават с функции. Функцията може да приеме манипулатор. Тя може да пише в него или да чете от него. За нея няма значение за кой файл е манипулаторът. Кодът, който извиква функцията, избира файла. Той прави това, когато отваря файла.
