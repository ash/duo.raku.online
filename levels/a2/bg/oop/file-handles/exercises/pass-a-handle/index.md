## Задача

Манипулаторът на файл е обикновена стойност. Затова можете да го подадете на функция като всеки друг аргумент. Напишете подпрограма `log-line`. Тя приема манипулатор и съобщение. Тя записва съобщението в манипулатора на отделен ред.

Отворете `log.txt` за писане. Извикайте `log-line` три пъти. Запишете с нея `started`, `working` и `done`. След това затворете манипулатора. Прочетете файла и отпечатайте съдържанието му.

## Пример

Програмата отпечатва:

```
started
working
done
```
