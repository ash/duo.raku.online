## Задача

Отворете файл с името `out.txt` за писане. Дръжте манипулатора отворен. Запишете в него числата `1`, `2` и `3` с цикъл. Всяко число трябва да е на отделен ред. След това затворете манипулатора. Прочетете файла и отпечатайте съдържанието му.

## Пример

Програмата отпечатва:

```
1
2
3
```
