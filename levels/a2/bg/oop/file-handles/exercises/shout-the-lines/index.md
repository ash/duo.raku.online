## Задача

Запишете три думи във файл с името `words.txt`. Думите са `apple`, `banana` и `cherry`. Всяка дума е на отделен ред. След това прочетете файла ред по ред. Отпечатайте всеки ред с номера му пред него. Номерата започват от `1`. Използвайте този вид: `<номер>: <ред>`.

## Пример

Програмата отпечатва:

```
1: apple
2: banana
3: cherry
```
