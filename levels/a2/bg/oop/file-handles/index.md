Лесно е да прочетете или запишете цял файл наведнъж. Но понякога искате да минете през файла ред по ред. Или искате да пишете във файл много пъти. Тогава файлът трябва да остане отворен през цялото време. За това използвате _манипулатор на файл_. Манипулаторът на файл е обект за отворен файл. Чрез него четете от файла или пишете в него.

Ето най-лесния начин да четете файл ред по ред. Дори не е нужно сами да правите манипулатор. Извикайте метода `lines` върху обект-път. Той ви дава редовете един по един. Те са готови за цикъл `for`:

```raku
spurt 'words.txt', "one\ntwo\nthree\n";

for 'words.txt'.IO.lines -> $line {
    say $line.uc;
}
```

Всеки `$line` е един ред. В края му няма нов ред. Програмата отпечатва:

```
ONE
TWO
THREE
```

Можете и да пишете във файл чрез манипулатор. Първо отворете файла с `open` и флага `:w`. Този флаг означава „write“, тоест писане. След това използвайте методите `say` или `print` на манипулатора. Накрая го затворете с `close`:

```raku
my $fh = open 'out.txt', :w;
$fh.say('first line');
$fh.say('second line');
$fh.close;
```

Накрая затворете манипулатора. Тогава всичките ви данни наистина отиват на диска. Някои файлове са твърде големи за паметта. Не можете да ги прочетете целите наведнъж. Такива файлове обикновено четете ред по ред, както по-горе.
