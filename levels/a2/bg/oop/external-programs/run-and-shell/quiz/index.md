Коя функция изпраща командата си през системната **обвивка**? Тази функция ви позволява да използвате канали и пренасочване.

{:.quiz}
0 | `run`
1 | `shell`
0 | `exec`
0 | `system`

{% include quiz.html %}

<div class="extended-explanation">

`shell` дава един-единствен низ на обвивката. Обвивката разбира възможности като каналите. `run` стартира програма направо. `run` приема отделни аргументи и не използва обвивка. Това е по-безопасно. Затова `run` е по-добрият избор по подразбиране.

</div>
