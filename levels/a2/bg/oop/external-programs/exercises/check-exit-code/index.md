## Задача

Изпълнете команда, която се проваля нарочно. Например използвайте `sh -c 'exit 4'`. Запазете `Proc`, който тя връща. Отпечатайте кода на изход на командата. Кодът на изход е число. Командата го връща, когато приключи. После отпечатайте `success`, ако командата е успяла. Отпечатайте `failure`, ако не е успяла.

## Пример

Програмата отпечатва:

```
4
failure
```
