Ето един начин да решите задачата.

## Код

```raku
my $proc = run 'sh', '-c', 'exit 4';

say $proc.exitcode;
say $proc ?? 'success' !! 'failure';
```

🦋 Намерете програмата във файла [check-exit-code.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/external-programs/check-exit-code.raku).

## Изход

```
4
failure
```

## Коментари

1. `run` връща `Proc`. Запазваме го в `$proc` и после го четем. Това е важно тук. Командата може да се провали. Ако никой не запази нейния `Proc`, Raku хвърля изключение. Изключението е грешка, която спира програмата. Но тук ние гледаме резултата. Това се брои за обработка на провала.

1. `.exitcode` дава числото, което командата е върнала. Тук то е `4`. Можете също да проверите `Proc` като булева стойност. Булевата стойност е истина или лъжа. Това отговаря на по-прост въпрос: успя ли командата? `Proc` е истина само когато кодът на изход е `0`. Тук той е лъжа. Затова програмата отпечатва `failure`.
