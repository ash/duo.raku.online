Ето един начин да решите задачата.

## Код

```raku
run 'echo', 'home:', '$HOME';
```

🦋 Намерете програмата във файла [run-a-command.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/external-programs/run-a-command.raku).

## Изход

```
home: $HOME
```

## Коментари

1. `run` стартира `echo` направо. `run` подава всеки низ като отделен аргумент. Тук няма `:out`. Затова изходът на програмата отива право на екрана.

1. Аргументът стига до `echo` точно както сте го написали. Затова `$HOME` се отпечатва точно така, както е написан. Той не се заменя с вашата домашна директория. Това е така, защото няма обвивка. Обвивката би го заменила. Ето защо `run` е безопасният избор по подразбиране. С `shell` същата команда може да работи съвсем различно.

1. Наистина ли искате да отпечатате домашната директория? Тогава оставете обвивката да замени променливата. `shell 'echo home: $HOME'` отпечатва нещо като `home: /home/anna`. Запазете и единичните кавички в кода на Raku. С двойни кавички, `"$HOME"`, има проблем. Самият Raku се опитва да вмъкне своя променлива `$HOME` в низа. Това става, преди `echo` дори да започне работа.
