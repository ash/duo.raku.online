## Задача

Използвайте `run`, за да стартирате `echo`. Дайте на `echo` два отделни аргумента: `home:` и `$HOME`. Аргументите са стойности, които давате на програмата. Оставете изхода да отиде на екрана. Забележете, че програмата отпечатва `$HOME` точно така, както е написано. Тя **не** отпечатва домашната директория. Това е така, защото `run` не използва обвивка. Само обвивката заменя променливи като `$HOME` със стойностите им.

## Пример

Програмата отпечатва:

```
home: $HOME
```
