Коя променлива съдържа променливите на средата на програмата?

{:.quiz}
0 | `@*ARGS`
1 | `%*ENV`
0 | `$*ENV`
0 | `%ENV`

{% include quiz.html %}

<div class="extended-explanation">

`%*ENV` е динамичният хеш с променливите на средата. Четете променлива по името ѝ, например `%*ENV<HOME>`. `@*ARGS` е нещо друго. Той съдържа аргументите от командния ред. Това са стойностите след името на програмата в командата.

</div>
