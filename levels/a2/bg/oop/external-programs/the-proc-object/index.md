Всяко извикване на `run` или `shell` връща обект `Proc`. Това е малък запис за програмата. Той ви казва коя програма е работила и как е приключила. В предишните теми използвахме манипулатора му `.out`, за да четем изхода. Но `Proc` съдържа повече от това.

Най-полезната част е **кодът на изход**. Това е малко цяло число. Програмата го връща на онзи, който я е стартирал. С това число програмата казва дали е успяла. `0` означава успех. Всяко друго число означава провал. Самата програма избира този код за провал. `.exitcode` ви дава числото:

```raku
my $proc = run 'sh', '-c', 'exit 3';
say $proc.exitcode; # 3
```

Често питате само въпрос с отговор „да“ или „не“. Проработи ли? За това `Proc` е истина, когато кодът на изход е `0`. Иначе той е лъжа. Затова можете да проверите `Proc` направо:

```raku
my $proc = run 'ls', '/', :out;
$proc.out.slurp(:close);
say $proc ?? 'ok' !! 'failed'; # ok
```

`Proc` помни и командата, която е стартирал. Намирате я в `.command`:

```raku
my $proc = run 'echo', 'hi', :out;
$proc.out.slurp(:close);
say $proc.command; # (echo hi)
```

Внимавайте с едно нещо. Понякога командата се проваля. Какво става, ако просто **пренебрегнете** `Proc`, който тя връща? Тогава Raku повдига изключение. Изключението е грешка, която спира програмата. Raku не оставя провала скрит:

```raku
run 'sh', '-c', 'exit 1';
# умира: The spawned command 'sh' exited unsuccessfully (exit code: 1, signal: 0)
```

Код на изход, различен от `0`, обикновено означава проблем. Затова провалил се `Proc` хвърля изключение, ако го изхвърлите. Това става, когато `Proc` излезе от обхват. Тогава никакъв код не може да стигне до него. Въпросът не е в проверката на кода на изход. Въпросът е в *изхвърлянето* на резултата. Просто сложете `Proc` в променлива. Това е достатъчно, за да избегнете изключението. Дори не е нужно да гледате променливата отново.

```raku
my $proc = run 'sh', '-c', 'exit 1'; # няма грешка, макар да се провали
# …и $proc никога повече не се използва
```

И така, *очаквате* ли, че командата може да се провали? Тогава запазете нейния `Proc`. Когато искате да разберете какво е станало, погледнете `.exitcode`. Или проверете `Proc` като булева стойност.
