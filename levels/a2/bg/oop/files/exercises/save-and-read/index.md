## Задача

Запазете число във файл и го заредете отново. Файлът е `number.txt`. Запишете в него числото `42`, а после нов ред. След това прочетете файла. Превърнете съдържанието му в цяло число, тоест число без дробна част. Умножете числото по две и отпечатайте резултата.

## Пример

Програмата отпечатва:

```
84
```
