## Задача

Направете малък журнален файл. Добавете редове в края му няколко пъти. Първо запишете реда `start` във файл с името `log.txt`. След това с цикъл **добавете** още три реда. Това значи, че ги добавяте в края на файла. Редовете са `entry 1`, `entry 2` и `entry 3`. Не изтривайте това, което вече е във файла. Накрая прочетете целия файл и го отпечатайте.

## Пример

Програмата отпечатва:

```
start
entry 1
entry 2
entry 3
```
