Ето най-лесния начин да работите с файл. Прочитате или записвате целия файл наведнъж.

Процедурата `spurt` записва низ във файл. Тя създава файла. Или, ако файлът вече е там, заменя старото съдържание:

```raku
spurt 'greeting.txt', "Hello, file!\n";
```

Процедурата `slurp` прочита целия файл. Тя ви дава съдържанието като низ:

```raku
my $text = slurp 'greeting.txt';
print $text; # Hello, file!
```

Със `spurt` и `slurp` запазвате данни и ги зареждате отново. Трябват ви само две кратки извиквания. Тук използваме `print`, а не `say`. Причината е, че текстът вече завършва с нов ред.

Тези процедури работят с целия файл наведнъж. Те са добри за малки файлове. Малкият файл лесно се побира в паметта. За голям файл използвате [манипулатор на файл](/bg/oop/file-handles). Използвате го и за да работите с файл ред по ред. Ще научите за него в края на този раздел. Следващата тема показва как да добавяте към файл. Старото съдържание на файла остава там.
