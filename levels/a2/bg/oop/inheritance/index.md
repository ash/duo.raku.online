_Наследяването_ позволява един клас да се изгради върху друг клас. За да направите това, напишете `is` след името на новия клас. После напишете името на другия клас. Новият клас наследява другия клас. Той получава всичките му атрибути и методи. Другият клас е _родителският_ клас, или _базовият_ клас.

```raku
class Animal {
    has $.name;
    method speak {
        'some sound';
    }
}

class Dog is Animal {
}
```

`Dog is Animal` означава, че `Dog` е вид `Animal`. Не пишем нищо ново в `Dog`. Но `Dog` вече има атрибута `name` от `Animal`. Той има и метода `speak` от `Animal`:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.name;  # Rex
say $rex.speak; # some sound
```

Обектът `Dog` е също и `Animal`:

```raku
say Dog.new ~~ Animal; # True
```

Можете да съпоставите обект с тип чрез интелигентното съпоставяне `~~`. Резултатът е истина, когато обектът има този тип. Той е истина и когато обектът наследява този тип. Следващата тема е за дъщерния клас. Дъщерният клас наследява родителски клас. Той може да замени метод на родителя си със своя версия.
