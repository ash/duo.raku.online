## Задача

Една програма работи със стойност. Стойността е отрицателна. Ако стойността е под нулата, изпратете предупреждение в стандартната грешка. Използвайте `note` за това. След това изпратете истинския резултат в стандартния изход със `say`. Резултатът е абсолютната стойност на числото. Това е числото без знака минус. Използвайте стойността `-3`.

## Пример

На екрана виждате и двата реда:

```
Warning: the value is negative
3
```

Тук изхвърляме стандартната грешка. Остава само резултатът:

```
$ raku note-a-warning.raku 2>/dev/null
3
```
