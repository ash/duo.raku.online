Ето един начин да решите задачата.

## Код

```raku
my @data = 3, 5, 7;

my $sum = 0;
for @data -> $n {
    $sum += $n;
    $*ERR.say("running total: $sum");
}

$*OUT.say($sum);
```

🦋 Намерете програмата във файла [output-and-error.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/standard-streams/output-and-error.raku).

## Изход

На екрана виждате и двата потока. Първо идват междинните суми, после крайният резултат:

```
running total: 3
running total: 8
running total: 15
15
```

Тук изхвърляме стандартната грешка. Остава само истинският изход:

```
$ raku output-and-error.raku 2>/dev/null
15
```

## Коментари

1. `$*OUT` е манипулаторът за стандартния изход. `$*ERR` е манипулаторът за стандартната грешка. Всеки от тях има свой метод `say`.

1. Всяка обиколка на цикъла добавя следващото число. След това записва междинната сума в `$*ERR`. Само крайната сума отива в `$*OUT`. На екрана напредъкът и резултатът изглеждат еднакво. Но те минават през различни потоци. `2>/dev/null` изпраща стандартната грешка настрани. Затова остава само крайното `15`.
