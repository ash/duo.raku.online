Повечето методи извиквате върху обект. Обектът е екземпляр на клас. Но можете да извикате метод и върху самия клас. Това значи, че го извиквате върху обекта на типа. Такъв метод често се нарича _метод на класа_. Той е полезен за стойности и действия на целия клас. Те не принадлежат само на един обект.

Пишете метод на класа като всеки друг метод:

```raku
class Road {
    method speed-limit { 120 }
}
```

Но го извиквате върху името на класа. Не го извиквате върху екземпляр:

```raku
say Road.speed-limit; # 120
```

Вие вече знаете един метод на класа. Но не сте го наричали така. Това е `new`. Извиквате `new` върху класа и той създава нов обект.

Методът на класа не може да използва атрибутите на екземпляр. Зад него няма обект. Затова той може да работи само с обща информация. Тази информация е една и съща за всеки обект от класа. Понякога работата има нужда от данните на един обект. Тогава използвайте обикновен метод и го извикайте върху екземпляр. Понякога работата няма нужда от такива данни. Тогава методът на класа е добър избор.

Методите на класа нямат нужда от екземпляр. Но понякога имате обект. Тогава пак можете да използвате данните му в тях:

```raku
class Road {
    has $.name;
    method speed-limit { 120 }

    method info {
        "The maximum speed on $.name is " ~ self.speed-limit
    }
}

my $R404 = Road.new(name => 'Road 404');
say $R404.info;
```

Тази програма отпечатва резултата, който очаквате:

```
The maximum speed on Road 404 is 120
```

Тук ви трябва екземпляр на класа. Без него извикване като `say Road.info` дава грешка.
