Извиквате _метаметод_ с `.^`, а не с `.`. Обикновеното `.method` изпълнява метод на обекта. `.^method` е нещо различно. То извиква метод на **метаобекта** на обекта. Метаобектът е обект, който описва тип. Затова извикването пита за типа. То не действа като типа.

Вече знаете `.^name`. Той връща името на типа:

```raku
say 42.^name; # Int
```

Други метаметоди показват как е изграден типът. `.^attributes` изброява атрибутите му. `.^find_method` ви казва дали даден метод съществува:

```raku
class Animal {
    has $.name;
    method speak { 'generic' }
}

say Animal.^attributes.elems;          # 1
say so Animal.^find_method('speak');   # True
say so Animal.^find_method('fly');     # False
```

`.^mro` връща _реда на разрешаване на методите_. Това е верига от типове. Raku търси метод във всеки от тях, в този ред. Това е линията на наследяване на класа:

```raku
class A {}
class B is A {}

say B.^mro.map(*.^name); # (B A Any Mu)
```

`B` наследява `A`. В крайна сметка всеки тип наследява `Any` и `Mu`. Извиквате метод върху `B`. Тогава Raku го търси точно по този път. Тези метаметоди превръщат вашите типове в данни. Тези данни показват как са изградени типовете. Можете да питате за тях, докато програмата работи.
