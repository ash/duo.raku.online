## Задача

Създайте клас `Animal` с метод `speak`. После създайте клас `Dog`. Той наследява `Animal`. Той няма свои методи. Използвайте метаметод върху `Dog`. Проверете дали `Dog` има метод `speak`. Отпечатайте само `True` или `False`. Това показва нещо за `find_method`. Той търси по цялата верига на наследяване. Той не гледа само методите на самия клас.

## Пример

Програмата отпечатва:

```
True
```
