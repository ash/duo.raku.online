Ето един начин да решите задачата.

## Код

```raku
class A {
}

class B is A {
}

class C is A {
}

class D is B is C {
}

say D.^mro.map(*.^name);
```

🦋 Намерете програмата във файла [diamond-mro.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/mop/diamond-mro.raku).

## Изход

```
(D B C A Any Mu)
```

## Коментари

1. `D` наследява от двама родители едновременно. `class D is B is C` има по едно `is` за всеки родител. Това се нарича множествено наследяване. Класовете `A`, `B`, `C` и `D` образуват *ромб*. Има два пътя от `D` нагоре до `A`. `A` е родител и на `B`, и на `C`.

1. `.^mro` превръща ромба в една права линия. Raku търси в този ред. `D` е първи. После идват родителите му, `B` и `C`. Те са в същия ред като в кода. После идва `A`, общият родител. Накрая идват `Any` и `Mu`.

1. И `B`, и `C` водят до `A`. Но типът `A` е в списъка само **веднъж**. И идва след двата. Това е целта на реда на разрешаване на методите. Raku посещава всеки тип точно веднъж. Родителят никога не идва преди дъщерния си клас. Затова Raku винаги намира първо метода в `B`. Намира го преди метода в `A`, който той предефинира.
