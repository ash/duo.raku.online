Ето един начин да решите задачата.

## Код

```raku
class A {
}

class B is A {
}

class C is B {
}

say C.^mro.map(*.^name);
```

🦋 Намерете програмата във файла [the-mro.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/mop/the-mro.raku).

## Изход

```
(C B A Any Mu)
```

## Коментари

1. `.^mro` връща верига от типове. Raku претърсва тази верига, за да намери метод.

1. Веригата следва линията на наследяване, стъпка по стъпка. Първо идва `C`. После идва родителят му, `B`. После идва `A`, родителят на `B`. Накрая идват `Any` и `Mu`. Всеки тип завършва с тях. При повече нива от класове списъкът е просто по-дълъг.
