## Задача

Създайте базов клас `Animal`. После създайте клас `Dog`, който го наследява. Отпечатайте името на класа `Dog`. После погледнете веригата на наследяване на `Dog`. В тази верига са класът и всички негови родители. На следващия ред отпечатайте броя на типовете в нея. Използвайте `.^mro` и пребройте нейните елементи. На трети ред отпечатайте дали в тази верига има клас `Cat`.

## Пример

Програмата отпечатва:

```
Dog
4
False
```
