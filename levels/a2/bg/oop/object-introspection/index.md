В [раздела за контейнерите](/bg/advanced/containers) използвахте `.^name`. С него питахте стойността за нейния тип. Същите метаизвиквания с `.^` работят и с класове и обекти. С тях можете да видите имената и атрибутите им. Можете да видите и мястото им в дървото на класовете.

Метаметодът е метод, който извиквате с `.^`. Метаметодът `.^name` връща името на класа:

```raku
class Dog {
    has Str $.name;
    method bark { 'Woof' }
}

say Dog.^name; # Dog
```

Метаметодът `.^attributes` изброява атрибутите на класа. За всеки атрибут виждате типа му. Виждате и вътрешното му частно име. Това е формата `$!`. Видяхте я при [частните атрибути](/bg/oop/methods/private-attributes):

```raku
say Dog.^attributes; # (Str $!name)
```

Интроспекция значи, че питате обекта за самия него. Тя е полезна за инструменти, които работят с всякакви обекти. Например такъв инструмент може да отпечата всеки атрибут на обекта. Той не трябва първо да знае класа на обекта. Следващата тема е за веригата на наследяване на класа. Това е линията на родителските му класове.
