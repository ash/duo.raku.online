Един клас може да наследява друг клас. Тогава можете да поискате цялата верига от типове. Класът е изграден върху тези типове. Метаметодът `.^mro` връща тази верига. Името означава _method resolution order_. Raku търси метод в този ред.

```raku
class Animal {
}

class Dog is Animal {
}

say Dog.^mro; # ((Dog) (Animal) (Any) (Mu))
```

Четете списъка отляво. Първо `Dog` е сам себе си. После е `Animal`, неговият родител. После е `Any` и `Mu`. Всеки обект в Raku наследява тези два типа. Те са най-отгоре. Когато извикате метод върху `Dog`, Raku претърсва този списък. Той върви отляво надясно. Използва първия метод, който съвпада. Това обяснява предефинирането. Дъщерният клас идва по-рано във веригата. Затова неговият метод печели пред метода на родителя.

Понякога класът няма родител с `is`. Тогава веригата е по-къса. В нея са само самият клас и после `Any` и `Mu`.
