## Задача

Създайте роля `Sized` с метод `describe`. Методът връща низа `size is <size>`. За размера той използва `self.size`.

После създайте клас `Box`. Той изпълнява ролята `Sized` и има атрибут `size`. Създайте кутия с размер `10`. Извикайте `describe` върху нея и отпечатайте резултата. На втори ред отпечатайте резултата от `~~ Sized` за кутията. Той показва дали кутията изпълнява ролята.

## Пример

Програмата отпечатва:

```
size is 10
True
```
