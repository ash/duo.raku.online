## Задача

Създайте клас `Robot` с метод `speak`. Този метод връща `beep`. После създайте роля `Dancing`. Тя добавя метод `dance`. Този метод връща `spinning around`.

Създайте два робота. Дайте ролята `Dancing` само на единия. Извикайте `speak` върху двата робота и отпечатайте резултатите. После извикайте `dance` върху робота, който може да танцува. Отпечатайте и този резултат.

## Пример

Програмата отпечатва:

```
beep
beep
spinning around
```
