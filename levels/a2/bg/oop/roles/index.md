_Ролята_ е набор от методи. Понякога тя има и данни. Няколко класа могат да споделят една роля. Наследяването казва, че един клас _е_ вид друг клас. Ролята е нещо друго. Тя описва нещо, което класът _може да прави_.

Създавате роля с ключовата дума `role`. Тя прилича много на клас. За да дадете роля на клас, използвайте трейта `does`:

```raku
role Greet {
    method hello {
        'Hello from ' ~ self.name;
    }
}

class Person does Greet {
    has $.name;
}
```

Сега класът `Person` има метода `hello` от ролята. Той работи точно като метод в самия клас:

```raku
say Person.new(name => 'Anna').hello; # Hello from Anna
```

Класът може да изпълнява роля. Тогава Raku знае, че класът има тази роля:

```raku
say Person.new(name => 'Anna') ~~ Greet; # True
```

Вижте метода `hello` в ролята. Той използва `self.name`. Но самата роля няма атрибут `name`. Това не е проблем. Методът се изпълнява като част от класа, който компонира ролята. Да компонирате роля значи да я вземете в класа. А този клас има атрибута `name`. Следващата тема показва още нещо. Класът може да има повече от една роля наведнъж.
