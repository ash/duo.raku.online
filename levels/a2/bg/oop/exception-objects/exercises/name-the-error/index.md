## Задача

Напишете подпрограма `risky`. Тя прави `die 'sub failed'`. После извикайте `risky` вътре в блок с фазер `CATCH`. Първо `CATCH` отпечатва името на типа на изключението, с `.^name`. После той отпечатва съобщението му, с `.message`. Това показва още нещо за `CATCH`. Той обработва и изключения от код, който блокът *извиква*. Не е нужно `die` да е в самия блок.

## Пример

Програмата отпечатва:

```
X::AdHoc
sub failed
```
