## Задача

Всяка вградена грешка има свой тип изключение. Можете да съпоставяте тези типове. Напишете блок, който изчислява `1 / 0`. После блокът се опитва да използва резултата. Това хвърля `X::Numeric::DivideByZero`. Добавете фазер `CATCH` към блока. В него използвайте `when X::Numeric::DivideByZero`. Това съвпада точно с този тип. После отпечатайте `cannot divide by zero`.

## Пример

Програмата отпечатва:

```
cannot divide by zero
```
