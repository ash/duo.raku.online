Процедурата `dir` връща елементите на директория. Елементът е файл или директория вътре в нея. Всеки елемент е обект-път. Редът на елементите не е фиксиран. Затова хората често сортират резултата. Тогава изходът винаги идва в същия ред.

```raku
mkdir 'box';
spurt 'box/a.txt', '';
spurt 'box/b.txt', '';

for dir('box').sort -> $entry {
    say $entry.basename;
}
```

Тази програма отпечатва имената на файловете в директорията `box`. Имената са сортирани:

```
a.txt
b.txt
```

Всеки елемент е пълен обект-път. Методът `basename` дава само името в края. Той не дава частта с директорията. Можете да зададете на обекта-път всички същите въпроси както преди: `.f`, `.d`, `.e`. Така например можете да вземете само файловете от директория.
