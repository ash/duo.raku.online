## Задача

Създайте файл с името `a.txt`. След това задайте на *същия* път два въпроса. Обикновен файл ли е (`.f`)? Директория ли е (`.d`)? Отпечатайте и двата отговора. Ще видите, че двете проверки дават противоположни резултати за един път.

## Пример

Програмата отпечатва:

```
True
False
```
