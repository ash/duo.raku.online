## Задача

Създайте собствен клас изключение `TooBig`. Това е клас за вашите собствени грешки. Той наследява `Exception`. Той има два атрибута, `value` и `limit`. Неговият метод `message` трябва да връща `Value <value> exceeds the limit of <limit>`.

После напишете цикъл по стойностите `30`, `99` и `60`. Границата е `50`. Хвърляйте `TooBig` само когато стойността е по-голяма от границата. Добавете фазер `CATCH` с `when TooBig`. Той отпечатва съобщението **и** втори ред. За този ред той чете направо атрибута `limit` на изключението. Вторият ред е `Try a value up to <limit>.`. За стойност до границата просто отпечатайте, че е наред.

Виждате, че само провалените числа получават изключение. Другите числа минават без проблем. И в двата случая цикълът продължава.

## Пример

Програмата отпечатва:

```
Value 30 is within the limit
Value 99 exceeds the limit of 50
Try a value up to 50.
Value 60 exceeds the limit of 50
Try a value up to 50.
```
