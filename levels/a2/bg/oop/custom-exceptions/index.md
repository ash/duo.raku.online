Raku има вградени изключения. Имената им започват с `X::`. Можете да създавате и свои изключения. Наричаме ги собствени изключения. Собственото изключение е клас. Той наследява вградения клас `Exception`. Така той е вид `Exception`. Той има и метод `message`:

```raku
class TooBig is Exception {
    has $.value;

    method message {
        "Value $.value is too big";
    }
}
```

`TooBig` е нормален клас. Той може да има атрибути, като `value`. Но той е `is Exception`. Затова можете да го хвърлите, като грешка от `die`. За да го хвърлите, създайте обект от класа. После извикайте `.throw` върху този обект:

```raku
my $value = 20 * 30;

TooBig.new(value => $value).throw if $value > 50;

CATCH {
    when TooBig {
        say .message;
    }
}
```

Програмата отпечатва:

```
Value 600 is too big
```

Вътре в `CATCH` клонът `when TooBig` съвпада. Това е така, защото хвърленият обект е от типа `TooBig`. Собственото изключение пази всякакви данни, които му дадете. Тук тези данни са `value`. Кодът, който обработва изключението, е обработчикът. Обработчикът може да използва тези данни. Той може да състави точно съобщение. Или може да реагира по особен начин. Това е много по-полезно от обикновен низ за `die`.

Тук се събира всичко от тази част на курса. Собственото изключение е _клас_. То има атрибути и метод. То работи и с инструментите на Raku за изключения. Можете да го хвърлите и да го прихванете. Така то може да каже точно какво се е объркало.
