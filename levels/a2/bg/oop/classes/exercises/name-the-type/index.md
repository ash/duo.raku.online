## Задача

Създайте два празни класа, `Cat` и `Dog`. После създайте екземпляр на `Cat` с име `$felix`. Отпечатайте типа на `$felix` с `WHAT`. После отпечатайте още два реда. Използвайте в тях оператора `===`. Първият ред показва дали типът е същият като `Cat`. Вторият ред показва дали той е същият като `Dog`.

## Пример

Програмата отпечатва:

```
(Cat)
True
False
```
