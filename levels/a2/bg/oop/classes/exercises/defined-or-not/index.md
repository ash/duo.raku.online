## Задача

Създайте два празни класа, `Cat` и `Dog`. После напишете цикъл по четири стойности: `Cat`, `Dog`, `Cat.new` и `Dog.new`. За всяка стойност отпечатайте дали е дефинирана. Вижте резултата. Двата обекта на типа са недефинирани. Двата екземпляра са дефинирани. Класът тук няма значение.

## Пример

Програмата отпечатва:

```
False
False
True
True
```
