Можете да напишете име на клас, например `Dog`. Това име означава _обекта на типа_ на класа. Обектът на типа представя самия тип. Той не е един от обектите от този тип. А _екземплярът_ е нещо друго. Създавате го с `new`. Той е истински обект.

Raku вижда разликата между тях. Методът `defined` връща `False` за обект на типа. Той връща `True` за екземпляр:

```raku
class Dog {
}

say Dog.defined;     # False
say Dog.new.defined; # True
```

Обектът на типа няма истински данни. Той само описва тип. Затова Raku казва, че той е _недефиниран_. Екземплярът е истински обект. Затова той е _дефиниран_.

`WHAT` показва един и същ тип и за двете. Видяхте `WHAT` в [раздела за контейнерите](/bg/advanced/containers):

```raku
class Dog {
}

say Dog.WHAT;     # (Dog)
say Dog.new.WHAT; # (Dog)
```

Raku показва типа в кръгли скоби, като `(Dog)`. Значи `Dog` и `Dog.new` имат един и същ тип, `Dog`. Но те са различни неща. `Dog` е самият тип. `Dog.new` е обект от този тип.
