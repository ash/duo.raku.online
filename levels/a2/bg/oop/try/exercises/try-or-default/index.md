## Задача

Когато блок `try` се провали, стойността му е недефинирана. Използвайте това с оператора „определено или“ `//`. С `//` можете да дадете резервна стойност за този случай. Изпълнете блок `try` с `die 'no'` вътре. Ако блокът се провали, използвайте вместо това низа `default`. Отпечатайте резултата.

## Пример

Програмата отпечатва:

```
default
```
