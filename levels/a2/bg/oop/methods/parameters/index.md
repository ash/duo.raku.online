Методът може да има параметри, като подпрограма. Напишете ги в кръгли скоби след името на метода:

```raku
class Account {
    has $.balance is rw = 0;

    method deposit($amount) {
        $.balance += $amount;
    }
}
```

Методът `deposit` има един параметър, `$amount`. Той добавя тази сума към баланса на обекта:

```raku
my $a = Account.new;
$a.deposit(100);
$a.deposit(50);
say $a.balance; # 150
```

Всяко извикване работи върху един обект. Това е обектът, върху който извиквате метода. Затова един метод може да променя различни обекти. Един обект не променя другите. Методите могат да имат позиционни и именувани параметри. Те могат да имат и стойности по подразбиране. Всичко друго от сигнатурите на подпрограмите също работи тук.
