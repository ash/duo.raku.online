В [раздела за атрибутите](/bg/oop/attributes) всеки атрибут имаше `$.` в името си. `$.` създава публичен аксесор. Всеки извън обекта може да го използва. Но можете да напишете и `$!` вместо това. Тогава атрибутът е _частен_. Той няма аксесор. Кодът извън обекта не може да го види. Само методите на класа могат да го използват. Там го пишете като `$!name`.

```raku
class Safe {
    has $!code = 4321;

    method unlocks($attempt) {
        return $attempt == $!code;
    }
}

my $safe = Safe.new;
say $safe.unlocks(4321); # True
say $safe.unlocks(1111); # False
```

Тайният `$!code` е вътре в обекта. Но никой отвън не може да го види. Няма аксесор `.code`. Единственият начин да използвате кода е методът `unlocks`. Класът ви дава този метод нарочно. Четенето на `$safe.code` или `$safe!code` просто не работи.

Частните атрибути са добри за подробности вътре в обекта. Останалата част от програмата не бива да ги пипа направо.
