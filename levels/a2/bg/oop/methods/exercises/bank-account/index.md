## Задача

Създайте клас `Robot`. Той има атрибут `position`, който можете да променяте. Стойността му по подразбиране е `0`. Класът има и метод `move`. Този метод мести позицията напред с някакъв брой стъпки. Броят стъпки по подразбиране е `1`. Така `move` без аргумент мести робота с една стъпка.

Създайте робот. Преместете го с `5` стъпки. После извикайте `move` без аргумент. После го преместете с още `2` стъпки. Отпечатайте последната му позиция.

## Пример

Програмата отпечатва:

```
8
```
