Атрибутите дават на обекта неговите данни. С _методите_ обектът може и да прави неща. Методът е подпрограма в клас. Извиквате метода върху обект. За да създадете метод, напишете ключовата дума `method`:

```raku
class Dog {
    has $.name;

    method bark {
        return $.name ~ ' says Woof!';
    }
}
```

За да извикате метод върху обект, използвайте точка. Това е същото като при аксесор:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.bark; # Rex says Woof!
```

Вътре в метода `self` е обектът. Това е обектът, върху който сте извикали метода. Стигате до атрибутите през техните аксесори. Пишете ги като `$.name`, `$.age` и така нататък. Можете да ги използвате и в низ с двойни кавички:

```raku
class Dog {
    has $.name;

    method greet {
        "Hello, my name is $.name";
    }
}

say Dog.new(name => 'Rex').greet; # Hello, my name is Rex
```

Следващите теми разглеждат три неща. Първото са частните атрибути. За тях ви трябват методи, а сега вече имате методи. Второто са методите с параметри. Третото са методите, които извикват други методи.
