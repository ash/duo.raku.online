В Pod текста маркирате думи с _форматиращи кодове_. Всеки код е една буква. След буквата слагате ъглови скоби около текста:

* `B<…>` — удебелен
* `I<…>` — курсив
* `C<…>` — код (всички букви имат еднаква ширина)
* `L<…>` — връзка

```raku
=begin pod

This is B<important>, and C<say> is a built-in.

=end pod
```

Във форматирания текст `important` е удебелено. `say` е с шрифт за код. Можете да сложите един код в друг код. Така ги комбинирате. Затова `B<C<say>>` е удебелен код.

Понякога ви трябва цял блок от код. Кратко парче код вътре в ред не е достатъчно. Тогава използвайте кодов блок: `=begin code … =end code`. Той има ред в началото и ред в края. Той запазва текста точно какъвто е:

```raku
=begin pod

Here is how to call it:

=begin code
say greet('world');
=end code

=end pod
```

Редовете в кодовия блок се показват точно както ги пишете. Raku не ги чете като Pod. Така Pod има кодове вътре в редовете и има кодови блокове. С тях можете да опишете API. API е начинът, по който други програми използват вашия код. Пишете форматиран текст и примери. Примерите изглеждат като код, който можете да изпълните. Всичко това стои до кода, който описва.
