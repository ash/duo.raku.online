## Проблем

Дефинирайте изброим тип `Light` с константите `red`, `amber` и `green`. Пазете ги в този ред. Декларирайте променлива с изброимия тип като неин тип: `my Light $current`. Задайте ѝ стойността `red`. Отпечатайте светлината и числото зад нея. Използвайте формата `red is 0`.

След това **сменете светлината два пъти**. Първо задайте на `$current` стойност `amber`. После ѝ задайте `green`. След всяка смяна я отпечатвайте по същия начин. Така светлината минава `red` → `amber` → `green`.

Може би мислите, че `$current++` минава сам към следващата светлина. Опитайте и вижте какво ще стане.

## Пример

Програмата отпечатва:

```
red is 0
amber is 1
green is 2
```
