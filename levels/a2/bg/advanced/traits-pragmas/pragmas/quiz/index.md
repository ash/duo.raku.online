В Raku прагмата `strict` е включена по подразбиране. Не декларирате променлива, но ѝ присвоявате стойност. Например `$x = 42`. Какво се случва?

{:.quiz}
1 | Грешка по време на компилация
0 | Мълчаливо създава `$x`
0 | Извежда предупреждение, но се изпълнява
0 | Задава `$x` на `Nil`

{% include quiz.html %}

<div class="extended-explanation">

`strict` е включена по подразбиране. С нея трябва първо да декларирате всяка променлива с `my`. Затова `$x = 42` без `my` не се компилира. Грешката е *Variable '$x' is not declared*. С `no strict` прагмата е изключена. Тогава присвояването работи.

</div>
