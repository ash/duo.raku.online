Ето един начин да решите задачата.

## Код

```raku
no strict;

$a = 10;
$b = 20;
say $a + $b;
```

🦋 Можете да намерите изходния код във файла [no-strict.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/traits-pragmas/no-strict.raku).

## Изход

```
30
```

## Коментари

1. `no strict` изключва едно правило. Правилото казва, че трябва да декларирате всички променливи. Затова можете да присвоявате на `$a` и `$b` без `my`. С обичайния `strict` тези редове дават грешки по време на компилация.

1. След присвояването променливите работят както обикновено. Затова `$a + $b` е `30`. Тази промяна на правилото е лексикална. Тя важи само до края на текущия обхват. Това е обхватът с `no strict`.

1. Това е само демонстрация. На практика не я препоръчваме. `strict` е включен по подразбиране с добра причина. Той намира грешки при писане в имената на променливите по време на компилация. В истински код го оставете включен. Декларирайте променливите си с `my`.
