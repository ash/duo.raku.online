## Задача

Вземете думите `pear`, `fig`, `apple`, `kiwi`. Сортирайте ги по **дължина**. Най-кратката дума е първа, а най-дългата е последна. Използвайте формата на извикване с двоеточие. Дайте ключа за сортиране като Whatever израз, а не като блок. Ключът за сортиране казва какво да се сравнява. Отпечатайте резултата.

## Пример

Програмата отпечатва:

```
(fig pear kiwi apple)
```
