Ето един начин да решите задачата.

## Код

```raku
say 0 <= 73 <= 100;
```

🦋 Можете да намерите пълния код във файла [chained-comparison.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operators-overview/chained-comparison.raku).

## Резултат

```
True
```

## Коментари

1. Можете да свързвате операторите за сравнение във верига. Така `0 <= 73 <= 100` означава „0 е най-много 73, и 73 е най-много 100“. Операторът `<=` позволява и краищата. Така резултат от точно `0` или `100` също е валиден.

1. И двете части са верни. Така целият израз е `True`. Вижте средната стойност, `73`. Пишете я само веднъж. Но Raku я сравнява с двете стойности до нея.

1. Без верига трябва да напишете двете сравнения. Свързвате ги с `&&`. И пишете средната стойност два пъти: `0 <= 73 && 73 <= 100`. Верижната форма казва същото по по-кратък начин.
