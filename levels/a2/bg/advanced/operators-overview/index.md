Един израз може да има няколко оператора. Тогава Raku трябва да реши реда. Кой оператор идва първи? Две правила решават това: _приоритет_ и _асоциативност_.

## Приоритет

Приоритетът решава кой оператор е по-силен. По-силният оператор взима операндите си първи. Умножението има по-висок приоритет от събирането. Затова умножението става първо:

```raku
say 2 + 3 * 4; # 14
```

Raku чете израза като `2 + (3 * 4)`. Резултатът е `14`, а не `20`. Винаги можете да добавите скоби. Те дават различен ред:

```raku
say (2 + 3) * 4; # 20
```

## Асоциативност

Някои оператори имат _еднакъв_ приоритет. Тогава асоциативността решава реда. Изваждането е ляво-асоциативно. Затова Raku го групира отляво:

```raku
say 8 - 3 - 2; # 3
```

Това е `(8 - 3) - 2`. Резултатът е `3`. Но степенуването, операторът `**`, е дясно-асоциативно:

```raku
say 2 ** 3 ** 2; # 512
```

Тук Raku групира израза като `2 ** (3 ** 2)`. Това е `2 ** 9`, а резултатът е `512`.

## Верижни сравнения

Можете да свързвате операторите за сравнение във _верига_. Тогава те идват един след друг. Такъв код се чете лесно. Той работи като в математиката:

```raku
say 1 < 2 < 3; # True
say 1 < 5 < 3; # False
```

Raku сравнява средната стойност с двете стойности до нея. `1 < 2 < 3` е вярно. Това е така, защото `1 < 2` е вярно, а `2 < 3` също е вярно.
