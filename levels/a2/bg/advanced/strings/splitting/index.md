Можете да разделите низ на части по няколко начина. Можете и да съедините частите отново.

Методът `words` разделя низ на списък от думи. Празното място, например интервал, разделя думите:

```raku
say 'Hello big World'.words; # (Hello big World)
```

Методът `split` разрязва низ при разделител. Вие избирате разделителя:

```raku
say 'a,b,c'.split(','); # (a b c)
```

Ето един важен специален случай. Можете да разделите низ по **празен низ** `''`. Тогава получавате отделните символи на низа. Но получавате и още два празни низа. Те са в самото начало и в самия край. Затова резултатът има два елемента повече, отколкото очаквате:

```raku
say 'abc'.split('').elems;        # 5 — the three letters, plus an empty string at each end
say 'abc'.split('', :skip-empty); # (a b c) — the :skip-empty adverb drops the empties
```

Искате ли да разделите низ на символи? Извикайте метода `comb` без аргументи. Той прави това директно. Няма излишни празни низове:

```raku
say 'Raku'.comb; # (R a k u)
```

Методът `join` прави обратното. Той съединява списък от стойности в един низ. Слага разделител между стойностите:

```raku
say <a b c>.join('-'); # a-b-c
```

Още два метода работят с части от низ. Методът `substr` ви дава парче от низ. Вие му давате начална позиция. Ако искате, можете да му дадете и дължина:

```raku
say 'Hello World'.substr(0, 5); # Hello
say 'Hello World'.substr(6);    # World
```

А `trim` премахва интервалите в двата края на низ:

```raku
say '  hi  '.trim; # hi
```
