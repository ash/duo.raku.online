Понякога създавате скаларна променлива. Но още не й присвоявате стойност. Контейнерът пак пази стойност. Това е неговата стойност по подразбиране. Тя зависи от типа на променливата.

Тази програма не използва Raku по най-добрия начин. Но тя показва идеята:

```raku
my $int;
say $int + 5;
```

Изходът съдържа `5`. Може би сте очаквали това. Може би сте мислили, че стойността по подразбиране на `$int` е `0`. Но програмата отпечатва и предупреждение:

```
Use of uninitialized value $int of type Any in numeric context
  in block <unit> at t.raku line 2
5
```

Има два начина да махнете това съмнение. Можете да присвоите стойност направо:

```raku
my $int = 0;
say $int + 5; # 5
```

Или можете да зададете стойност по подразбиране с характеристиката `is default`:

```raku
my $int is default(0);
say $int + 5; # 5
```

Стойността по подразбиране не е задължително да е нула. Тя може да е всяка стойност, която смятате за добра. Например:

```raku
my $int is default(1);
say $int + 5; # 6
```
