Нека разгледаме една програма. Тя използва една и съща променлива за различни видове данни. Използваме `dd`, за да видим данните на всяка стъпка. Този пример само показва как работят нещата. Това не е добър начин да пишете програми.

```raku
my $value;
dd $value;

$value = 42;
dd $value;

$value = 'forty-two';
dd $value;
```

Всяко извикване на `dd` показва текущата стойност на `$value`:

```
$value = Any
$value = 42
$value = "forty-two"
```

В началото променливата е празна. `dd` показва нейната стойност като `Any`. Това е неопределената базова стойност. Всеки нетипизиран контейнер започва с нея. След присвояванията `dd` показва цялото число. След това показва низа.

Забележете, че тук `dd` не отпечатва тип преди името. Нетипизираният контейнер няма фиксиран тип. Затова `dd` показва само стойността. [Контейнер с деклариран тип](/bg/advanced/scalar-containers/type-constraints) работи различно. Ще видите това в следващата тема.
