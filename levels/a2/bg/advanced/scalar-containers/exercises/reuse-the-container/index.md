## Задача

Декларирайте две скаларни променливи една до друга. Първата е `$untyped`. Тя няма тип. Втората е `$typed`. Тя има тип `Int`. Изведете и двете с `dd`, докато са още празни. След това присвоете `42` на всяка от тях. Изведете и двете отново. Разгледайте внимателно изхода. `dd` описва двата контейнера по различен начин.

## Пример

Програмата отпечатва това към стандартния поток за грешки:

```
$untyped = Any
Int $typed = Int
$untyped = 42
Int $typed = 42
```
