Ето един начин да решите задачата.

## Код

```raku
my Int $cars;

$cars = 250.7.Int;
say $cars;
say $cars.WHAT;
```

🦋 Можете да намерите изходния код във файла [integers-only.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/scalar-containers/integers-only.raku).

## Изход

```
250
(Int)
```

## Коментари

1. Ограничението на типа `Int` в `my Int $cars` е правило за контейнера. Контейнерът не приема стойности, които не са цели числа. Не можете да присвоите `250.7` директно. Тази стойност е `Rat`. Raku дава грешка по време на компилация, преди програмата да започне.

1. Програмата извиква `.Int` върху рационалната стойност `250.7`. Това я превръща в цялото число `250`. Методът просто маха частта след десетичната точка. Новата стойност е подходяща за контейнера. Забележете, че това не е същото като закръгляне.

1. Псевдо-методът `.WHAT` показва типа на записаната стойност. Той е `Int`.
