В частта „Основи“ научихте за [_мулти-функциите_](/bg/essentials/more-on-functions/multi-functions). Това са няколко подпрограми с едно и също име. Raku гледа типовете на аргументите. После избира правилната подпрограма. Това се нарича _множествено диспечиране_ (multiple dispatch).

Досега Raku избираше по _типа_ на аргументите. С клауза `where` можете да направите повече. Raku може да избира и по _стойността_. Пишете `where` след параметъра. Клаузата съдържа условие. Всеки вариант на функцията се нарича кандидат. Raku избира кандидата само когато условието му е вярно за аргумента:

```raku
multi sub info(Int $n where $n < 0)  { say "$n is negative" }
multi sub info(Int $n where $n == 0) { say "$n is zero" }
multi sub info(Int $n where $n > 0)  { say "$n is positive" }

info(-5);
info(0);
info(7);
```

Всяко извикване отива към кандидата с вярно условие за тази стойност:

```
-5 is negative
0 is zero
7 is positive
```

Вижте типовете. И трите кандидата имат една и съща сигнатура: един `Int`. Без клаузите `where` те се сблъскват. Raku не може да избере между тях. Условията ги правят различни.

## Как да спрем рекурсията

Хората често използват `where` при рекурсия. При рекурсия функцията извиква сама себе си. Тя трябва да спре в някакъв момент. Можете да сложите тази точка на спиране в отделен кандидат. Ето отново факториелът. Сега той има две мулти-подпрограми:

```raku
multi sub fact(Int $n where $n <= 1) { 1 }
multi sub fact(Int $n)               { $n * fact($n - 1) }

say fact(5); # 120
```

Първият кандидат е базовият случай. Тук рекурсията спира. В този случай `$n` е `1` или по-малко. Този кандидат просто връща `1`. Всички други стойности отиват към втория кандидат. Той извиква `fact` отново с по-малко число. Във функцията няма `if`. Диспечерът избира между базовия случай и рекурсивната стъпка. Диспечерът е частта от Raku, която избира кандидат.
