## Проблем

Динамичната променлива има туигила `*`. Raku я търси през стека на извикванията, а не по лексикален обхват. Така една подпрограма може да вижда различни стойности. Стойността зависи от това кой извиква подпрограмата. Тогава един блок може да накара кода, който извиква, да работи като някой друг.

1. Декларирайте динамична променлива `$*user` със стойност `'guest'`.
2. Напишете подпрограма `whoami`. Тя отпечатва `running as ` и след това текущата `$*user`, например `running as guest`. Тя няма параметри. Тя трябва да чете `$*user` директно.
3. Извикайте `whoami` веднъж на най-горното ниво. Тя показва `guest`.
4. След това направете блок. В него декларирайте `$*user` отново като `'admin'`. Извикайте *същата* `whoami` там. Сега тя показва `admin`.

## Пример

Програмата отпечатва:

```
running as guest
running as admin
```
