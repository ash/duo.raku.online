## Проблем

Покажете как динамична променлива минава през подпрограма по средата. Тази подпрограма не знае нищо за променливата.

Напишете подпрограма `log-it($msg)`. Тя отпечатва съобщението. Преди съобщението тя отпечатва динамичната променлива `$*prefix`. Напишете втора подпрограма, `task`. Тя само извиква `log-it('working')`. Тя никога не използва `$*prefix` сама. След това извикайте `task` два пъти. Всеки път я извиквайте отвътре на блок. Всеки блок дава на `$*prefix` различна стойност: първо `INFO`, после `DEBUG`.

## Пример

Програмата отпечатва:

```
INFO: working
DEBUG: working
```
