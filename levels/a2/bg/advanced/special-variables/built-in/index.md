Raku има набор от готови променливи за вас. Повечето от тях са _динамични_, с туигила `*`. Вие вече познавате [динамичните променливи](/bg/advanced/special-variables/dynamic-variables). Затова можете да четете тези променливи навсякъде. Можете дори да им дадете нова стойност за един обхват. Ето променливите, които ви трябват най-често.

## Стандартни потоци

Входът и изходът минават през три динамични променливи. `$*OUT` е стандартният изход. `$*ERR` е стандартната грешка, изход за съобщения за грешки. `$*IN` е стандартният вход. `say` и `print` пишат в `$*OUT`. Искате ли да изпратите текст към стандартната грешка? Тогава извикайте метода върху `$*ERR`:

```raku
$*OUT.say('normal output'); # goes to standard output
$*ERR.say('a diagnostic');  # goes to standard error
```

Тези променливи са динамични. Затова в един блок можете да насочите `$*OUT` към ново място. Тогава кодът, който извиквате в блока, печата там. Вие изобщо не променяте този код.

## Програмата и нейният процес

Някои променливи ви казват нещо за програмата, която работи сега:

```raku
say $*PROGRAM-NAME; # the path of the script being run
say $*PID;          # the process id of this program
say $*CWD;          # the current working directory
```

Стойностите им са различни всеки път, когато пускате програмата. Затова тук не показваме изхода.

## Команден ред и среда

Raku поставя аргументите и средата в два контейнера. Те са готови за вас:

* `@*ARGS` — списъкът с аргументи от командния ред; подпрограмата `MAIN` получава същите аргументи
* `%*ENV` — променливите на средата, в хеш

```raku
say @*ARGS.elems; # how many arguments were passed
say %*ENV<HOME>;  # the value of the HOME environment variable
```

Тези вградени променливи ви спестяват работа. Не трябва сами да взимате тази информация. Те са динамични, затова Raku ги търси през стека на извикванията. Така можете да замените всяка вградена `$*` променлива за даден обхват. Това работи точно като ваша собствена `$*` променлива.

Всички тези променливи са динамични. Но Raku има и вградени променливи с туигила `?`. Това са `$?FILE` и `$?LINE`. Компилаторът задава стойностите им, преди програмата да започне. Вече ги видяхте на страницата за [туигилите](/bg/advanced/special-variables/twigils).
