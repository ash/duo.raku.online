## Задача

Един `when` може да съвпада с *тип*, а не само със стойност. Една променлива пази числото `3.14`. Използвайте `given`/`when`, за да кажете какъв вид стойност е то. Отпечатайте `integer` за `Int`. Отпечатайте `rational` за `Rat`. Отпечатайте `string` за `Str`.

## Пример

Програмата отпечатва:

```
rational
```
