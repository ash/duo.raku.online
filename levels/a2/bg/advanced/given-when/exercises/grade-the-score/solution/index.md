Ето един начин да решите задачата.

## Код

```raku
my $age = 30;

given $age {
    when $_ < 0 { say 'invalid' }
    when 0..12  { say 'child' }
    when 13..19 { say 'teenager' }
    when 20..64 { say 'adult' }
    default     { say 'senior' }
}
```

🦋 Можете да намерите изходния код във файла [grade-the-score.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/given-when/grade-the-score.raku).

## Изход

```
adult
```

## Коментари

1. Това решение има два вида `when`. Първият е *условие*, `$_ < 0`. Тук `$_` е темата от `given`. Това условие хваща възрастите, които нямат смисъл. Другите блокове `when` са *диапазони*. Те слагат правилните възрасти в етапи.

1. Редът е важен. Проверката за отрицателна възраст е първа. Затова тя се изпълнява преди всички диапазони. Стойността `30` е в `20..64`. Затова програмата отпечатва `adult`.

1. Блокът `default` е за всяка възраст от 65 и повече. Нито един от диапазоните в списъка няма тези възрасти.

Има и друг начин. Нека `default` хваща *невалидния* вход. Изброете всеки познат етап. Напишете `senior` като условието `$_ >= 65`. Всичко останало е невалидно, например отрицателна възраст:

```raku
given $age {
    when 0..12    { say 'child' }
    when 13..19   { say 'teenager' }
    when 20..64   { say 'adult' }
    when $_ >= 65 { say 'senior' }
    default       { say 'invalid' }
}
```

Тук `default` наистина значи „нищо от горното“. Кой вариант е по-добър? Вие избирате. Рядък ли е невалидният случай? Тогава сложете проверката първа. Изброявате ли ясно всички валидни етапи? Тогава направете невалидния случай `default`.
