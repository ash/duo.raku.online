Блокът `when` прави повече от проверка дали две стойности са равни. Той прави _умно съвпадение_. Той сравнява темата със стойността, която давате. Затова можете да проверявате за съвпадение с диапазони, типове и условия. Не сте ограничени до единични стойности.

## Диапазони

Диапазонът съвпада, когато темата е в него. Затова с `given`/`when` е лесно да слагате числа в групи:

```raku
my $score = 75;

given $score {
    when 90..100 { say 'A' }
    when 80..89  { say 'B' }
    when 70..79  { say 'C' }
    default      { say 'F' }
}
```

Стойността `75` е в диапазона `70..79`. Затова програмата отпечатва:

```
C
```

## Типове

Типът съвпада, когато темата е от този тип. Така можете да изберете какво да правите според вида на стойността:

```raku
my $value = 'Raku';

given $value {
    when Int { say 'an integer' }
    when Str { say 'a string' }
}
```

`$value` съдържа низ. Затова програмата отпечатва:

```
a string
```

## Условия

Можете също да напишете сравнение директно. Вътре в `when` темата е `$_`. Затова условие като `$_ < 0` съвпада, когато е вярно:

```raku
my $n = -7;

given $n {
    when $_ < 0 { say 'negative' }
    when 0      { say 'zero' }
    default     { say 'positive' }
}
```

Тук първият `when` съвпада. Програмата отпечатва:

```
negative
```
