Понякога програмата трябва да избира между няколко възможности. Верига от проверки `if` и `elsif` може да стане дълга. Тя също повтаря едни и същи неща. В такъв случай конструкцията `given`/`when` често е по-ясна. Тя прилича на оператора `switch` в други езици.

Блокът `given` приема стойност. Той прави тази стойност _тема_. Темата е специалната променлива `$_`. След това Raku сравнява всеки блок `when` с темата. Първият `when`, който съвпадне, се изпълнява:

```raku
my $n = 2;

given $n {
    when 1 { say 'one' }
    when 2 { say 'two' }
    when 3 { say 'three' }
}
```

Тази програма отпечатва:

```
two
```

Някои други езици имат оператор `switch`. След съвпадение той може да продължи към следващия случай. Raku не прави това. Когато един `when` съвпадне, неговият блок се изпълнява. След това блокът `given` свършва. Raku не проверява другите блокове `when`.

## Блокът `default`

Блокът `default` се изпълнява, когато нито един блок `when` не съвпада. Той работи като частта `else` на оператора `if`:

```raku
my $n = 5;

given $n {
    when 1 { say 'one' }
    when 2 { say 'two' }
    default { say 'many' }
}
```

`$n` не е `1` и не е `2`. Затова програмата отпечатва:

```
many
```
