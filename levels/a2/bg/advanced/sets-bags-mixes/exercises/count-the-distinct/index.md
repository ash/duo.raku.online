## Проблем

Ето списък от числа. Някои от тях се повтарят:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Изведете колко _различни_ стойности има в него. Сред различните стойности няма две еднакви. Използвайте множество.

## Пример

Програмата извежда:

```
7
```
