Вече знаете фазерите за цялата програма. Raku има и фазери за един блок или един цикъл. Те са свързани с живота на този блок или цикъл.

## Влизане в блок и излизане от него

Фазерът `ENTER` се изпълнява всеки път, когато програмата влиза в блок. Фазерът `LEAVE` се изпълнява всеки път, когато програмата излиза от блока. Мястото им в блока няма значение:

```raku
say 'before block';
{
    LEAVE say 'leaving';
    ENTER say 'entering';
    say 'inside';
}
say 'after block';
```

Вижте изхода. `ENTER` се изпълнява първи, а `LEAVE` — последен. Тялото на блока е между тях:

```
before block
entering
inside
leaving
after block
```

`LEAVE` е много полезен. Той се изпълнява дори когато блокът свършва рано. Затова там можете спокойно да освободите ресурс, например отворен файл.

Фазерът може да има цял блок `{ }`, а не само един оператор. Можете да имате и няколко фазера. Един блок може да има повече от един `LEAVE`. Тогава те се изпълняват в обратен ред. Последният се изпълнява първи. Това работи като стек. Което влиза последно, излиза първо:

```raku
say 'open A';
{
    LEAVE {
        say 'close A';
    }
    say 'open B';
    LEAVE {
        say 'close B';
    }
    say 'work';
}
say 'done';
```

Програмата първо отваря ресурс `A`. Тя го затваря най-накрая:

```
open A
open B
work
close B
close A
done
```

Този ред е „последен влязъл, първи излязъл“. Той е точно подходящ за почистване. Първо премахвате нещото, което сте настроили последно. Фазерът `END` за цялата програма работи по същия начин. Няколко блока `END` също се изпълняват в обратен ред.

## Фазери за цикли

Циклите имат още три фазера. Те отбелязват стъпките на цикъла. `FIRST` се изпълнява веднъж, преди първата обиколка. `LAST` се изпълнява веднъж, след последната обиколка. `NEXT` се изпълнява в края на всяка обиколка:

```raku
for 1..3 {
    FIRST say '-- first';
    LAST  say '-- last';
    NEXT  say "-- next (was $_)";
    say "body $_";
}
```

Цикълът отпечатва:

```
-- first
body 1
-- next (was 1)
body 2
-- next (was 2)
body 3
-- next (was 3)
-- last
```

Същото е като при другите фазери. Можете да пишете `FIRST`, `NEXT` и `LAST` навсякъде в цикъла. Всеки от тях се изпълнява в своето време.
