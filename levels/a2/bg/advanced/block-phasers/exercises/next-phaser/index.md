## Задача

Фазерът `NEXT` се изпълнява в *края* на всяка обиколка на цикъла. Това е добро време да покажете напредъка.

Пазете растяща сума в `$sum`. Тя започва от `0`. Минете с цикъл през `1..3`. При всяка обиколка първо добавете текущото число към `$sum`. Използвайте фазер `NEXT`, за да отпечатате `sum so far: $sum` след всяка обиколка.

Внимавайте с реда. Фазерът `NEXT` се изпълнява след тялото. Затова сумата, която той показва, *включва* текущото число.

## Пример

Програмата отпечатва:

```
sum so far: 1
sum so far: 3
sum so far: 6
```
