## Задача

Ето един хеш: `a => 1, b => 2, c => 3`. Изтрийте записа `b` с наречие за индексиране. След това отпечатайте колко записа остават в хеша. Това показва, че един запис е изчезнал.

## Пример

Програмата отпечатва:

```
2
```
