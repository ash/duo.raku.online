## Задача

Създайте пакет `Temperature`. В него има две неща. Първото е `our` променлива `$freezing` със стойност `0`. Второто е `our` подпрограма `fahrenheit`. Тя превръща стойност по Целзий във Фаренхайт. За това умножете по 9/5 и добавете 32. Извън пакета отпечатайте точката на замръзване. След това отпечатайте `100` градуса по Целзий във Фаренхайт.

## Пример

Програмата отпечатва:

```
0
212
```
