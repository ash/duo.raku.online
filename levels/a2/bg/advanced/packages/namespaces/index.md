Думата `our` прави нещо видимо в неговото пространство от имена. Променлива с `my` е лексикална. Тя е частна за своя блок. Променлива с `our` е също и пакетна променлива. Можете да стигнете до нея отвън чрез пътя с `::`:

```raku
module Counter {
    our $count = 0;  # package variable
    my  $secret = 42; # lexical, not visible outside
}

say $Counter::count; # 0
```

`$Counter::count` работи. Променливата `count` има `our`. Но `$Counter::secret` не работи. Променливата `secret` е лексикална.

Пространствата от имена могат да бъдат **вложени**. Това значи, че едно пространство от имена е вътре в друго. Пакет вътре в пакет прави по-дълъг път с `::`:

```raku
module Outer {
    module Inner {
        our $val = 42;
    }
}

say $Outer::Inner::val; # 42
```

Пълното име `$Outer::Inner::val` е като път. То води от външното пространство от имена към вътрешното. След това води до променливата. Стандартната библиотека използва точно тази структура. Имена като `IO::Socket::INET` са вложени пространства от имена. Вашите модули също могат да работят така. Те държат всичките си части под едно име от най-високо ниво.
