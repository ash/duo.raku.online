Ето един начин да решите задачата.

## Код

```raku
my num $n;
my str $s;

say $n;
say "[$s]";
```

🦋 Можете да намерите изходния код във файла [native-default.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/native-default.raku).

## Резултат

```
0
[]
```

## Коментари

1. Нативният `num` не може да бъде недефиниран. Затова той започва от `0`, както нативният `int`. Той не започва като `(Num)`.

1. Нативният `str` започва като празен низ. Затова между скобите няма нищо. Нативният тип никога не пази недефинирана стойност.

1. Тук типовете са много важни. Опитайте да ги премахнете. Вместо това напишете `my $n; my $s;`. Сега променливите са обикновени контейнери. В началото те са *недефинирани*: пазят `Any`. Тогава `say $n` отпечатва `(Any)`. Низът интерполира `$s`, но `$s` е недефинирана. Затова Raku показва предупреждение: *"Use of uninitialized value … in string context"*. Само нативните типове `num` и `str` дават началните стойности. Това са `0` и празният низ.
