## Задача

Нативната променлива никога не е недефинирана. Това правило важи за всички нативни типове, не само за `int`. Декларирайте нативен `num` и нативен `str`. Не им давайте стойности. Отпечатайте числото. След това отпечатайте низа в квадратни скоби. Така можете да видите, че той е празен.

## Пример

Програмата отпечатва:

```
0
[]
```
