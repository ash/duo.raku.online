Ето един начин да решите задачата.

## Код

```raku
my uint8 @bytes = 100, 200, 255;
say @bytes.sum;
```

🦋 Можете да намерите изходния код във файла [native-array.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/native-array.raku).

## Резултат

```
555
```

## Коментари

1. Напишете нативния тип с размер `uint8` преди масива с `@`. Тогава Raku пази всеки елемент в един байт. Този байт е беззнаков: той няма знак минус. Такъв масив заема малко памет. Това е добре за двоични данни.

1. Всеки *елемент* има граница, `0..255`. Извън тази граница стойностите се обръщат. Но границата не е за сумата на елементите. `.sum` слага общата сума в обикновен `Int`. Затова `100 + 200 + 255` дава пълните `555`.
