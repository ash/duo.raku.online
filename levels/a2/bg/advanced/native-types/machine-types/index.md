Нативните типове имат имена с малки букви: `int`, `num` и `str`. С тях декларирате променлива точно както с `Int` или `Str`:

```raku
my int $i = 42;
my num $n = 3.14e0;
say $i; # 42
say $n; # 3.14
```

Нативната стойност съответства директно на машинен регистър или дума. Това са малки места за данни в компютъра. Обикновената Raku стойност има обвиващ обект около себе си. Нативната стойност няма обвивка. Затова нативните типове са по-бързи и заемат по-малко памет. Това е важно при големи масиви. Важно е и при кратки цикли, които смятат много.

Едно нещо трябва да знаете веднага. Нативната променлива никога не е недефинирана. Обикновената `Int` променлива започва като недефинирана. `say` я показва като `(Int)`. Но нативният `int` започва от **нула**:

```raku
say (my Int $a); # (Int)
say (my int $b); # 0
```

Същото важи и за нативните масиви. За да декларирате такъв масив, напишете нативния тип преди променливата с `@`:

```raku
my int @numbers = 10, 20, 30;
say @numbers.sum; # 60
```

Такъв масив пази елементите си като прости машинни цели числа. Те не са пълни `Int` обекти. Затова масивът заема по-малко памет. Можете да попитате нативна стойност за нейния тип. Тогава Raku автоматично я слага в съответния пълен тип. Казваме, че стойността е _обвита_. Ето защо `(my int $b).WHAT` показва `(Int)`.
