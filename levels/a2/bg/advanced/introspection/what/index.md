`WHAT` е псевдо-метод. Той ви дава типа на стойност. Използвате го почти като `.^name`:

```raku
my $var = 42;

say $var.^name;
say $var.WHAT;
```

И двата отпечатват типа, но изглеждат малко различно. `.^name` дава само името. `WHAT` дава самия тип като типов обект. Той го показва в кръгли скоби:

```
Int
(Int)
```

Вземете променлива без ограничение на типа. Отначало нейният тип е `Any`. След това присвоявате стойност. Сега и `^name`, и `WHAT` показват типа на тази стойност:

```raku
my $var;
say $var.^name; # Any
say $var.WHAT;  # (Any)

$var = 'Hello';
say $var.^name; # Str
say $var.WHAT;  # (Str)
```

С ограничение на типа Raku знае типа веднага. Това е вярно дори преди да присвоите стойност:

```raku
my Str $var;
say $var.^name; # Str
say $var.WHAT;  # (Str)

$var = 'Hello';
say $var.^name; # Str
say $var.WHAT;  # (Str)
```

## Сравняване на типови обекти

`WHAT` връща самия типов обект. Затова можете да сравните два типови обекта. За това използвайте оператора `===`. Това е операторът за _идентичност на стойности_. Той проверява дали двете страни са една и съща стойност. Всеки тип има само един типов обект. Така `===` лесно проверява дали две стойности имат един и същ тип:

```raku
my $a = 42;
my $b = 100;

say $a.WHAT === $b.WHAT; # True  — both are Int
say $a.WHAT === Int;     # True
say $a.WHAT === Str;     # False
```

`==` сравнява числа. Но `===` сравнява идентичност. Затова той работи направо с типови обекти. Той работи и с други стойности.
