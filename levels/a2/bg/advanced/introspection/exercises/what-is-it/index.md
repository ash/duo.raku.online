## Задача

`WHAT` прави повече от това да опише тип. Той връща самия типов обект. Можете да сравнявате типови обекти с оператора `===`.

Декларирайте две променливи. `$a` пази цялото число `42`. `$b` пази низа `'x'`. За всяка променлива погледнете нейния `WHAT`. Дали е типът `Int`? Отпечатайте отговора.

## Пример

Програмата отпечатва:

```
True
False
```
