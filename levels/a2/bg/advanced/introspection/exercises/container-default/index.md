## Задача

Контейнерът може да има стойност по подразбиране. Задавате я с характеристиката `is default`. Преди да присвоите стойност, променливата връща тази стойност по подразбиране. `.VAR.default` също я показва.

Декларирайте скалар `$count`. Стойността му по подразбиране трябва да е `0`. Не му присвоявайте нищо. Отпечатайте променливата. След това отпечатайте стойността по подразбиране на нейния контейнер. И двата реда трябва да показват `0`.

## Пример

Програмата отпечатва:

```
0
0
```
