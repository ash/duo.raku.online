Raku има още метаоператори, не само редукция и zip. Тук научавате три от тях.

## Cross — `X`

Метаоператорът cross `X` взима два списъка и прави двойки. Тук **всеки** елемент от единия списък прави двойка с **всеки** елемент от другия. Това се нарича декартово произведение:

```raku
say <a b> X <1 2>; # ((a 1) (a 2) (b 1) (b 2))
```

Както zip, `X` също може да взима оператор. Тогава операторът работи върху всяка двойка. `X~` съединява всяка двойка в низ. `X*` умножава двете числа:

```raku
say <a b> X~ <1 2>;         # (a1 a2 b1 b2)
say (1, 2, 3) X* (10, 100); # (10 100 20 200 30 300)
```

Zip минава през два списъка едновременно. Cross ги съчетава по всички възможни начини.

## Хипер — `»…«`

Хипер метаоператорът използва оператор за **всеки елемент** от списък. Операторът стои между стрелките `»…«`. Само с ASCII знаци пишете `>>…<<`. С два списъка той работи елемент по елемент, както zip. Понякога едната страна има само една стойност. Тогава той използва тази стойност с всеки елемент от списъка:

```raku
say (1, 2, 3) »+» (10, 20, 30); # (11 22 33)
say (1, 2, 3) »*» 2;            # (2 4 6)
```

Двете стрелки могат да сочат в различни посоки. Посоката е важна, когато списъците имат различна дължина. Ако стрелката сочи **към** списък, Raku може да повтори този списък. Тогава той става дълъг колкото другия списък. Ето четирите комбинации в ASCII, с `<<` и `>>`:

* `>>op<<` — Raku не повтаря нито един списък. Списъците трябва да са с еднаква дължина. Ако не са, получавате грешка.
* `>>op>>` — Raku повтаря **десния** списък. Тогава той е дълъг колкото левия.
* `<<op<<` — Raku повтаря **левия** списък. Тогава той е дълъг колкото десния.
* `<<op>>` — Raku повтаря **по-късия** списък. Тогава той е дълъг колкото по-дългия.

```raku
say (1, 2, 3, 4) <<+>> (10, 20); # (11 22 13 24)  — 10, 20 repeats to 10, 20, 10, 20
```

Има и форма само с един операнд. Тя извиква метод за всеки елемент. `>>.uc` превръща всеки низ в главни букви:

```raku
say <raku perl>>>.uc; # (RAKU PERL)
```

Хипер операцията казва на Raku и още нещо. Raku *може* да свърши работата паралелно. Тогава няколко части от работата вървят едновременно. По-късно ще научите подобния метод `.hyper`. Той е в [раздела за конкурентно програмиране](/bg/paradigms/hyper-race).

## Отрицание — `!`

Поставете `!` пред оператор за сравнение. Тогава получавате обратния резултат. Вече познавате `!=`, или „не е равно“. Това е просто този метаоператор с `==`. И други оператори дават `True` или `False`, като `eq` и `%%`. Метаоператорът работи с тях по същия начин:

```raku
say 3 != 4;      # True
say 'a' !eq 'b'; # True  — не са равни като низове
say 5 !%% 2;     # True  — 5 не се дели на 2
```

Така `$a !op $b` е просто по-чист начин да запишете `!($a op $b)`.

Raku прави това нарочно. Някои езици са малки и прости нарочно, като есперанто. Есперанто иска за всяко нещо да има един правилен начин. Raku е различен. Той с радост ви дава няколко начина. Затова Raku има отрицателния `!eq`. Той има и специален оператор `ne`. Двата значат точно едно и също:

```raku
say 'a' ne 'b'; # True — същата проверка като 'a' !eq 'b'
```
