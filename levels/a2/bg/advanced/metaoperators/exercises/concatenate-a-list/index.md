## Проблем

URL адресът е разделен на части. Частите са в масив. Съединете частите отново в един низ. Използвайте за това метаоператор за редукция. Отпечатайте URL адреса. На следващия ред отпечатайте дължината му в символи.

## Пример

Ето входния масив:

```raku
my @parts = <http :// example .com>;
```

Програмата отпечатва:

```
http://example.com
18
```
