## Проблем

Създайте хеш с двойката `a => 1`. След това прочетете стойността за ключа `a`. За това използвайте постциркумфиксния оператор за индексиране `< >`. Отпечатайте стойността.

## Пример

Програмата отпечатва:

```
1
```
