Ето един начин да решите задачата.

## Код

```raku
use Test;

plan 2;

my @sorted = (3, 1, 2).sort;
is-deeply @sorted, [1, 2, 3], 'sorted';

is 10 % 3, 1, 'remainder';
```

🦋 Можете да намерите пълния код във файла [test-a-list.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/testing/test-a-list.raku).

## Резултат

```
1..2
ok 1 - sorted
ok 2 - remainder
```

## Коментари

1. `plan 2` дава броя преди всички тестове. Затова редът `1..2` идва пръв. Файлът може да изпълни различен брой проверки. Тогава целият набор от тестове се проваля. `done-testing` не може да ви пази по този начин.

1. `is-deeply` проверява дали двата списъка са точно равни, и типовете им също. Сортирането на `3, 1, 2` дава `1, 2, 3`. Това съвпада.

1. `is` проверява дали две стойности са равни. Ако не са, показва и двете стойности. Тук `10 % 3` е `1`. Това е очакваната стойност. Затова и вторият тест минава.
