## Проблем

Напишете тестов файл. Използвайте `plan`, а не `done-testing`. С `plan` кажете в началото, че файлът има точно две проверки. Направете тези две проверки:

1. С `is-deeply` проверете, че списъкът `3, 1, 2` дава `[1, 2, 3]` след сортиране.
1. С `is` проверете, че `10 % 3` е равно на `1`.

Напишете свое кратко описание за всяка проверка.

## Пример

Нека описанията да са `sorted` и `remainder`. Тогава програмата отпечатва:

```
1..2
ok 1 - sorted
ok 2 - remainder
```
