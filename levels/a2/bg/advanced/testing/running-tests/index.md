---
title: Стартиране на тестове
---

{% include menu.html %}

Един тестов файл е просто програма на Raku. Затова можете да го стартирате като всяка програма:

```
raku t/01-basic.rakutest
```

Той отпечатва своя TAP резултат на екрана. Но може да имате повече от един-два файла. Тогава ви трябва _тестов изпълнител_. Той изпълнява всички тестове в една директория. След това дава кратко обобщение на резултатите. Тестовият изпълнител на Raku е `prove6`:

```
prove6 t/
```

Това изпълнява всеки тестов файл под `t/`. Показва колко файла и теста са минали. Накрая дава един резултат за всичко: успех или неуспех. Това се чете много по-лесно от суровия TAP от всеки файл.

Една дистрибуция може да има `META6.json`. Тогава инструментът за модули изпълнява тестовете ѝ вместо вас:

```
zef test .
```

`zef test` намира директорията `t/`. Той изпълнява всички тестове и показва резултата. Същото става автоматично, преди някой да инсталира дистрибуция. Така тестовете имат две задачи. Вие ги изпълнявате с `prove6`, докато работите по кода си. А екосистемата ги изпълнява, преди някой да инсталира дистрибуция. Така тя проверява дистрибуцията.

> Тестовите файлове имат разширение `.rakutest` или `.t`. Обикновено имената им започват с число, например `t/01-basic.rakutest`.
