Масивът е подреден контейнер. Всеки елемент на масива също е скаларен контейнер.

```raku
my @array = 100, 200, 300;
my @letters = 'a', 'b', 'c';
```

Сигилът `@` показва, че променливата работи като обект от тип `Positional`. Затова можете да вземете всеки елемент по неговия индекс:

```raku
say @array[1];   # 200
say @letters[2]; # c
```

Всеки елемент е скаларен контейнер. Затова можете да му присвоите нова стойност. Това работи точно като при обикновена скаларна променлива:

```raku
my @array = 100, 200, 300;
@array[0] = 10;
say @array; # [10 200 300]
```

Можете да присвоите и стойност от друг тип. Например:

```raku
my @array = 100, 200, 300;
@array[0] = 'ten';
say @array; # [ten 200 300]
```

Затова масивите са _изменяеми_. Това означава, че можете да ги променяте. Всяко място в масива е контейнер. То може да получи нова стойност. [Списъците](/bg/advanced/ordered-containers/lists) са различни. Ще видите това в следващата тема.
