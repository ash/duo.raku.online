Можете да сложите един масив в друг. Raku _не_ обединява сам елементите им. Вижте тази програма:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;
my @c = @a, @b;

say @c.elems; # 2
say @c;       # [[1 2 3] [4 5]]
```

Масивът `@c` има само два елемента: масивите `@a` и `@b`. Raku пази всеки контейнер като един елемент. Неговите елементи не отиват във външния масив. Същото е и с масив сред други стойности:

```raku
my @a = 1, 2, 3;
my @d = 0, @a, 99;
say @d; # [0 [1 2 3] 99]
```

Искате ли една плоска последователност? Тогава я поискайте с рутината `flat`:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat(@a, @b);       # (1 2 3 4 5)
say flat(@a, @b).elems; # 5
```

## Айтемизация (Itemization)

Понякога искате обратното. Искате да запазите контейнер цял, дори вътре във `flat`. Конструкцията `$(...)` _айтемизира_ аргумента си. Това означава, че тя отбелязва резултата като един единствен елемент. Сравнете предишния пример с този:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat($(@a), @b); # ([1 2 3] 4 5)
```

Тук `$(@a)` пази `@a` като един елемент. Но `@b` все пак става плосък. Той дава двете си стойности. Това отново е идеята на сигила `$`. Знакът `$` означава „третирай това като едно нещо“.
