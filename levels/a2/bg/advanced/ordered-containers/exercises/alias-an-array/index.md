## Задача

Ето един масив:

```raku
my @original = 10, 20, 30;
```

Създайте второ име, `@alias`, за _същия_ масив. Не копирайте масива. Този път добавете нов елемент към `@original` с `push`. След това отпечатайте `@alias`. Това показва, че псевдонимът вижда не само нови стойности. Той вижда и промени в структурата на масива.

## Пример

Програмата отпечатва:

```
[10 20 30 40]
```
