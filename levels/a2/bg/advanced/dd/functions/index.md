---
title: Извеждане на сигнатури на функции
---

{% include menu.html %}

Понякога извиквате `dd` без аргументи вътре в подпрограма. Тогава `dd` отпечатва сигнатурата на подпрограмата. Това са нейното име и нейните параметри, ако има такива. Вижте този пример с две подпрограми:

```raku
sub f1 {
    dd
}

f1();

sub f2($x) {
    dd
}

f2(42);
```

Програмата отпечатва сигнатурите. Тя не отпечатва никакви стойности:

```console
sub f1()
sub f2($x)
```

Това е много полезно при мулти-функции. Това са няколко функции с едно и също име. Тук `dd` ви казва кой вариант програмата наистина извиква:

```raku
multi sub g {
    dd
}

multi sub g($x) {
    dd
}

g();
g(42);
```

Всеки път изходът посочва подходящия вариант:

```console
sub g()
sub g($x)
```
