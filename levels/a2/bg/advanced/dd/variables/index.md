---
title: Извеждане на променливи
---

{% include menu.html %}

За да видите стойността на променлива, извикайте `dd`. Това е като `say`:

```raku
my $var = 42;
dd $var;
```

`dd` показва стойността. Тя показва и името на променливата:

```console
$var = 42
```

Променливата може да има деклариран тип. Тогава `dd` показва и типа. Сравнете изхода на тази програма с предишната:

```raku
my Int $var = 42;
dd $var;
```

```console
Int $var = 42
```

Това е главната разлика от `say`. Извикайте `dd` веднъж върху скалар. Тя ви показва името на променливата. Показва и типа на данните, ако Raku го знае. Така можете да сложите няколко извиквания на `dd` в програмата. Пак знаете кой изход от коя променлива е.

Можете да извеждате и по-големи структури от данни, като масиви или хешове. Тогава `dd` отпечатва стойността във форма, подобна на код:

```raku
my @arr = 10, 20, [1, 2, 3], 30;
dd @arr;
```

```console
[10, 20, [1, 2, 3], 30]
```

Забележете, че ясно виждате вътрешния масив. Но тук `dd` не отпечатва името на променливата. С хешовете е същото. `dd` отпечатва ключовете на хеша в сортиран ред:

```raku
my %hash =
    gamma => 'g',
    alpha => 'a',
    beta  => 'b';
dd %hash;
```

```console
{:alpha("a"), :beta("b"), :gamma("g")}
```
