## Проблем

Ето една вложена структура от данни. Тя има данни вътре в други данни:

```raku
my @data = 'Raku', [1, 2, 3], (key => 'value');
```

Направете две неща с нея:

1. Изведете `@data` с `dd`, във форма за програмисти.
2. Отпечатайте същата форма като низ. Сложете текста `Structure: ` пред него.

## Пример

Програмата отпечатва два реда. Те много си приличат:

```
["Raku", [1, 2, 3], :key("value")]
Structure: ["Raku", [1, 2, 3], :key("value")]
```
