## Проблем

Декларирайте променлива от тип `Int`: `my Int $n = 42;`. Изведете я с `dd`. Разгледайте изхода. Променлива без тип дава различен изход.

## Пример

Програмата отпечатва това в стандартния поток за грешки:

```
Int $n = 42
```
