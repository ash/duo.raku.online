title: Потребителски оператори
---

В Raku операторите са просто подпрограми със специални имена. Затова можете да създавате свои оператори. За това използвате имената на категориите от страницата [Видове оператори в Raku](/bg/advanced/operator-types). Това са `prefix`, `infix`, `postfix` и така нататък.

За да декларирате оператор, напишете `sub`. Името на `sub` има три части. Първо идва категорията. После идва двоеточие. После идва символът на оператора в ъглови скоби. Ето един нов инфиксен оператор. Името му е `plus`:

```raku
sub infix:<plus>($a, $b) {
    $a + $b
}

say 3 plus 4; # 7
```

След това използвате `plus` между двата му операнда. Той работи точно като вграден инфиксен оператор.

Постфиксният оператор идва след своя операнд. Факториелът е типичен пример. Ето го като постфиксен оператор `!`. Той използва [метаоператора за редукция](/bg/advanced/metaoperators/reduction), който вече познавате:

```raku
sub postfix:<!>(Int $n) {
    [*] 1..$n
}

say 5!; # 120
```

Можете да използвате не само букви и ASCII пунктуация. Символът на оператора може да бъде всеки знак. Този префиксен оператор използва знака за параграф `§`. Той удвоява число:

```raku
sub prefix:<§>($x) {
    $x * 2
}

say §5; # 10
```

Вашите собствени оператори са силен инструмент. Затова ги използвайте внимателно. Добрият оператор прави кода подобен на езика на неговата област. Странният оператор само обърква следващия читател.
