## Проблем

Символът на оператора може да бъде всеки знак. Той може да бъде и Unicode знак. Дефинирайте **постфиксен** оператор `²`. Той връща квадрата на своя операнд. Така `5²` означава `5 ** 2`. След това отпечатайте `5²`.

## Пример

Програмата отпечатва:

```
25
```
