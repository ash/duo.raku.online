Можете да дефинирате подпрограма _вътре_ в друга подпрограма. Това е вложена подпрограма. Тя е обикновена подпрограма. Но можете да я виждате и използвате само във външната подпрограма.

```raku
sub outer {
    sub inner {
        say 'I am the inner subroutine';
    }

    inner;
}

outer;
```

Програмата отпечатва:

```
I am the inner subroutine
```

Тук създаваме `inner` вътре в `outer`. После `outer` я извиква. Това работи. Името `inner` е известно в цялото тяло на `outer`.

Но извън `outer` името `inner` не съществува. Тази програма не се компилира:

```raku
sub outer {
    sub inner { 42 }
}

inner; # error: Undeclared routine: inner
```

Понякога само една подпрограма има нужда от помощна подпрограма. Тогава влагането е полезно. Сложете помощника вътре в тази подпрограма. Това показва, че помощникът е частен. Освен това друг код не може да го извика по грешка.
