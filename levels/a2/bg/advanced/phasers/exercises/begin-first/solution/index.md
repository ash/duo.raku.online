Ето един начин да решите задачата.

## Код

```raku
my $compiled = BEGIN { 2 + 3 };

say $compiled;
```

🦋 Можете да намерите изходния код във файла [begin-first.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/phasers/begin-first.raku).

## Изход

```
5
```

## Коментари

1. `BEGIN { 2 + 3 }` се изпълнява по време на компилацията. Той дава `5`. Тук блокът `BEGIN` е израз. Затова той връща стойността си. Програмата слага тази стойност в `$compiled`.

1. Пресмятането става само веднъж, по време на компилация. Когато програмата работи, `$compiled` просто пази постоянната стойност `5`. Така можете да използвате `BEGIN`, за да пресмятате стойности рано. Той не е само за ранно отпечатване.
