## Проблем

Напишете подпрограма `describe`. Първият ѝ параметър е име. Това име е позиционно и задължително. След него slurpy хешът `*%opts` събира всякакъв брой именувани аргументи. Подпрограмата връща низ като този: `name: key=value, key=value, ...`. Низът изброява всяка опция. Ключовете са в азбучен ред.

Извикайте я така: `describe('Anna', colour => 'red', size => 5)`. Отпечатайте резултата.

## Пример

Програмата отпечатва:

```
Anna: colour=red, size=5
```
