В частта „Основи“ вие [написахте подпрограми](/bg/essentials/functions). Те имаха позиционни и именувани параметри. Параметрите имаха стойности по подразбиране. Списъкът от параметри е _сигнатурата_. Този раздел показва още две неща, които сигнатурата може да прави. Тя може да направи параметър незадължителен. И може да събира всякакъв брой допълнителни аргументи.

## Незадължителни параметри

Параметър с въпросителен знак след него е _незадължителен_. Извикващият код може да го пропусне. Тогава параметърът е недефиниран. Затова можете да дадете друга стойност вместо него. Използвайте за това оператора defined-or `//`:

```raku
sub greet($name, $greeting?) {
    my $g = $greeting // 'Hello';
    say "$g, $name!";
}

greet('Anna');           # Hello, Anna!
greet('Anna', 'Hi');     # Hi, Anna!
```

Тук извикваме `greet` с един аргумент. Тогава `$greeting` е недефинирана. Затова `//` дава `'Hello'` вместо нея.

## Slurpy параметри

Параметър със `*` е _slurpy_. Той взема всички аргументи, които остават. Пишете slurpy масив с `*@`. Той събира всякакъв брой позиционни аргументи в масив:

```raku
sub count-them(*@items) {
    say @items.elems;
}

count-them(1, 2, 3, 4); # 4
count-them('a', 'b');   # 2
```

Можете да използвате обикновени параметри заедно със slurpy параметър. Първо фиксираните параметри получават стойностите си. Всичко останало отива в slurpy масива:

```raku
sub titles($name, *@titles) {
    say "$name has {@titles.elems} title(s)";
}

titles('Anna', 'Dr', 'Prof'); # Anna has 2 title(s)
```

Slurpy хешът работи по същия начин. Пишете го с `*%`. Той събира всички допълнителни именувани аргументи в хеш:

```raku
sub register($name, *%options) {
    say "$name: {%options.elems} option(s)";
    say "role is %options<role>";
}

register('Anna', role => 'admin', active => True);
```

Двата именувани аргумента стават ключове на `%options`. Затова програмата отпечатва:

```
Anna: 2 option(s)
role is admin
```
