В частта „Основи“ използвахте `MAIN`, за да [получавате аргументи от командния ред](/bg/essentials/the-main-function/reading-command-line-arguments). Raku прави още неща за вас с `MAIN`. Той не само подава стойностите.

## Съобщение за употреба

Понякога аргументите от командния ред не съвпадат със сигнатурата на `MAIN`. Сигнатурата е списъкът с параметри на `MAIN`. Тогава Raku не изпълнява тялото. Вместо това той отпечатва _съобщение за употреба_. Raku сам създава това съобщение. Съобщението показва как да стартирате програмата.

Вижте тази програма:

```raku
sub MAIN($name) {
    say "Hello, $name!";
}
```

Стартирайте я правилно. Тогава тя поздравява човека:

```console
$ raku hello.raku Anna
Hello, Anna!
```

Сега я стартирайте без аргумент. Сигнатурата не съвпада. Затова Raku отпечатва съобщението за употреба. Той не поздравява:

```console
$ raku hello.raku
Usage:
  hello.raku <name>
```

Raku прави съобщението от имената на параметрите. Затова давайте на параметрите добри имена. Тогава текстът за помощ е полезен, а вие не вършите допълнителна работа.

## Именувани аргументи

`MAIN` може да има позиционни параметри. Може да има и именувани параметри. На командния ред именуваният параметър става опция като `--option=value`. Можете да му дадете стойност по подразбиране. Тогава опцията не е задължителна:

```raku
sub MAIN(:$name = 'World') {
    say "Hello, $name!";
}
```

```console
$ raku hello.raku
Hello, World!

$ raku hello.raku --name=Raku
Hello, Raku!
```
