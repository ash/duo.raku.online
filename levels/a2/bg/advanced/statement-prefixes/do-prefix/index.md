Блокът сам по себе си е оператор, а не израз. Затова обикновено не можете да го присвоите на променлива. Префиксът `do` прави блока израз. Стойността му е стойността на **последния** оператор в блока:

```raku
my $x = do {
    my $a = 3;
    $a + 4;
};

say $x; # 7
```

Вътре в блока можете да създавате променливи. Можете да изпълнявате няколко оператора и да изчислите резултат. `do` връща стойността на блока. Това е полезно, когато един израз не стига, за да получите стойност.

`do` работи и пред операторите за управление на потока. Тези оператори избират или повтарят код. С `do` и те връщат стойност:

```raku
my $sign = do given 5 {
    when * > 0 { 'positive' }
    when * < 0 { 'negative' }
    default    { 'zero' }
};

say $sign; # positive
```

Тук `do given` прави цялата конструкция `given`/`when` израз. Стойността на този израз е `positive`. Същото работи с `do if` и `do for`. Накратко, с `do` блокът може да стои там, където Raku иска стойност. Това работи и за управляващите конструкции.
