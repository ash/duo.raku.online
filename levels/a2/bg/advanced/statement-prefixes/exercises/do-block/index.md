## Задача

`do` работи и пред операторите за управление на потока. Той ги прави изрази със стойност. Използвайте `do if 7 > 5 { 'big' } else { 'small' }`, за да изберете етикет. Присвоете етикета на `$label` и го отпечатайте.

## Пример

Програмата отпечатва:

```
big
```
