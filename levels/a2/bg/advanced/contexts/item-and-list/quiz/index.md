Какво отпечатва тази програма?

```raku
my @a = 1, 2, 3;
my $n = 0;
$n++ for $(@a);
say $n;
```

{:.quiz}
0 | 3
1 | 1
0 | 0
0 | 6

{% include quiz.html %}

<div class="extended-explanation">

Контекстуализаторът `$( … )` задава контекст на елемент. Така масивът е една единична стойност, а не списък от елементи. Цикълът `for` вижда един елемент. Затова изпълнява тялото си само веднъж. Накрая `$n` е `1`. Без `$( )` цикълът се изпълнява три пъти.

</div>
