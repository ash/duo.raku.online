Три контекста са много чести. В първия стойността действа като число. Във втория тя действа като низ. В третия тя действа като `True` или `False`. Всеки от тези контексти има префиксен оператор. Операторът стои пред стойността. Той задава контекста направо:

* `+` — числов контекст: стойността действа като число
* `~` — низов контекст: стойността действа като низ
* `?` — булев контекст: стойността действа като `True` или `False`

Използвайте ги с масив. `+` дава дължината на масива. `~` дава елементите му с интервали между тях. `?` ви казва дали масивът има елементи:

```raku
my @a = 1, 2, 3;

say +@a; # 3
say ~@a; # 1 2 3
say ?@a; # True
```

Празен масив е `0` в числов контекст. В булев контекст той е `False`:

```raku
my @empty;
say +@empty; # 0
say ?@empty; # False
```

Не винаги трябва да пишете тези оператори. Често Raku задава правилния контекст вместо вас. Аритметиката поставя стойностите в числов контекст. Съединяването на низове ги поставя в низов контекст. А `if`, `while`, `and` и `or` поставят условието си в булев контекст:

```raku
my @a = 1, 2, 3;

say 10 + @a;              # 13, here @a is its length: 3
say 'items: ' ~ @a;       # items: 1 2 3
if @a { say 'not empty' } # not empty
```

Така `if @array { … }` работи, както очаквате. Масив с елементи е истина. С префиксните оператори вие сами искате същите преобразувания.

Можете да поставите `if` и след израза. Тогава кодът е кратък и ясен:

```raku
say "{+@a} items are there" if @a; # 3 items are there
```
