## Problema

Crea dos clases vacías, `Cat` y `Dog`. Después escribe un bucle sobre cuatro valores: `Cat`, `Dog`, `Cat.new` y `Dog.new`. Para cada valor, imprime si está definido. Mira el resultado. Los dos objetos de tipo no están definidos. Las dos instancias están definidas. Aquí la clase no importa.

## Ejemplo

El programa imprime:

```
False
False
True
True
```
