## Problema

Crea dos clases vacías, `Cat` y `Dog`. Después crea una instancia de `Cat` con el nombre `$felix`. Imprime el tipo de `$felix` con `WHAT`. Después imprime dos líneas más. Usa en ellas el operador `===`. La primera línea muestra si el tipo es el mismo que `Cat`. La segunda línea muestra si es el mismo que `Dog`.

## Ejemplo

El programa imprime:

```
(Cat)
True
False
```
