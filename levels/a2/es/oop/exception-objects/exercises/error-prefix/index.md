## Problema

Escribe un bloque con `die 'timeout'` dentro. Añade un phaser `CATCH` al bloque. Este phaser captura la excepción e imprime su mensaje. Pon `Error: ` delante del mensaje.

## Ejemplo

El programa imprime:

```
Error: timeout
```
