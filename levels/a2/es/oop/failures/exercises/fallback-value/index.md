## Problema

Escribe una subrutina `get`. Devuelve su argumento. Pero si el argumento es `0`, llama a `fail`. El mensaje es `bad`.

Imprime el resultado de `get(5)`. Después imprime el resultado de `get(0)`. Usa el operador defined-or `//` con el valor de reserva `default`. El operador `//` da este valor cuando el resultado no está definido.

## Ejemplo

El programa imprime:

```
5
default
```
