## Problema

Un método de clase puede tener parámetros, como cualquier otro método. Crea una clase `Geometry` con un método de clase `circle-area`. Recibe un radio. Devuelve el área de un círculo. Usa `π` o `pi`. Redondea el área a un número entero. La fórmula pertenece a toda la clase. Aquí no hay ningún objeto círculo. Llama al método sobre la clase con un radio de `10`. Imprime el resultado.

## Ejemplo

El programa imprime:

```
314
```
