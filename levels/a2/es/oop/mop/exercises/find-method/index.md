## Problema

Crea una clase `Animal` con un método `speak`. Después crea una clase `Dog`. Hereda de `Animal`. No tiene métodos propios. Usa un metamétodo sobre `Dog`. Comprueba si `Dog` tiene un método `speak`. Imprime solo `True` o `False`. Esto muestra algo sobre `find_method`. Busca a lo largo de toda la cadena de herencia. No busca solo entre los métodos de la clase misma.

## Ejemplo

El programa imprime:

```
True
```
