## Problema

Crea una clase `Dog`. Solo tiene un atributo `name` y ningún método. Después usa el MOP para añadirle un método `speak`. Hazlo mientras el programa se ejecuta. El método nuevo usa el `name` del propio objeto. Devuelve `<nombre> says woof`. Crea un perro con el nombre `Rex` y llama al método nuevo.

## Ejemplo

El programa imprime:

```
Rex says woof
```
