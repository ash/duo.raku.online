## Problema

Crea una clase `Celsius` con un atributo `degrees`. Añade un método `to-fahrenheit`. Cambia la temperatura a Fahrenheit. Usa esta fórmula: `grados × 9 / 5 + 32`.

Crea un objeto `Celsius` para `100` grados. Imprime su valor en Fahrenheit.

## Ejemplo

El programa imprime:

```
212
```
