## Problema

Cuando un bloque `try` falla, su valor no está definido. Usa esto con el operador defined-or `//`. Con `//`, puedes dar un valor de reserva para este caso. Ejecuta un bloque `try` con `die 'no'` dentro. Si el bloque falla, usa la cadena `default` en su lugar. Imprime el resultado.

## Ejemplo

El programa imprime:

```
default
```
