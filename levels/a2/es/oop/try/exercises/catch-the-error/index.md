## Problema

Muestra las dos caras de `try`. Un bloque `try` captura los errores de su código. Primero, pon un cálculo en un bloque `try`. El cálculo debe funcionar, por ejemplo `6 * 7`. Imprime su resultado. Después pon código con `die 'broken'` en un segundo bloque `try`. Imprime si este bloque dio un resultado definido. Imprime también el mensaje de la excepción capturada.

## Ejemplo

El programa imprime:

```
42
False
broken
```
