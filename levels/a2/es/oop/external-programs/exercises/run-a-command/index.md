## Problema

Usa `run` para iniciar `echo`. Dale dos argumentos separados: `home:` y `$HOME`. Los argumentos son valores que das a un programa. Deja que la salida vaya a la pantalla. Fíjate en que el programa imprime `$HOME` tal cual. **No** imprime la carpeta personal. Esto pasa porque `run` no usa una shell. Solo una shell cambia variables como `$HOME` por sus valores.

## Ejemplo

El programa imprime:

```
home: $HOME
```
