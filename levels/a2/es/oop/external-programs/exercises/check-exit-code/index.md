## Problema

Ejecuta una orden que falle a propósito. Por ejemplo, usa `sh -c 'exit 4'`. Guarda el `Proc` que devuelve. Imprime el código de salida de la orden. El código de salida es un número. Una orden lo devuelve cuando termina. Después imprime `success` si la orden funcionó. Imprime `failure` si no funcionó.

## Ejemplo

El programa imprime:

```
4
failure
```
