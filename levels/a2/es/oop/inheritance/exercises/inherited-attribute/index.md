## Problema

Crea una clase base `Vehicle` con un atributo `wheels`. Después crea dos clases que heredan de ella. La primera es `Bike`. Viene con `2` ruedas. La segunda es `Car`. Viene con `4`.

Crea una `Bike` y un `Car`. Imprime el número de ruedas de cada uno.

## Ejemplo

El programa imprime:

```
2
4
```
