## Problema

Crea una clase base `Shape` con dos métodos. El método `name` devuelve `'shape'`. El método `describe` devuelve la cadena `I am a <nombre>`. Para el nombre, llama a su propio método `name`.

Después crea una clase `Square`. Hereda de `Shape`. Sobrescribe `name`. Su propia versión de `name` devuelve `'square'`.

Imprime la descripción de un `Square`.

## Ejemplo

El programa imprime:

```
I am a square
```
