## Problema

Crea una clase base `Animal`. Después crea una clase `Dog` que hereda de ella. Imprime el nombre de la clase `Dog`. Después mira la cadena de herencia de `Dog`. Esta cadena tiene la clase y todos sus padres. En la línea siguiente, imprime el número de tipos que hay en ella. Usa `.^mro` y cuenta sus elementos. En una tercera línea, imprime si esta cadena tiene una clase `Cat`.

## Ejemplo

El programa imprime:

```
Dog
4
False
```
