## Problema

Crea un archivo con el nombre `a.txt`. Después hazle dos preguntas a la *misma* ruta. ¿Es un archivo regular (`.f`)? ¿Es un directorio (`.d`)? Imprime las dos respuestas. Ves que las dos comprobaciones dan resultados opuestos para una sola ruta.

## Ejemplo

El programa imprime:

```
True
False
```
