## Problema

Escribe tres palabras en un archivo con el nombre `words.txt`. Las palabras son `apple`, `banana` y `cherry`. Cada palabra está en su propia línea. Después lee el archivo línea a línea. Imprime cada línea con su número delante. Los números empiezan por `1`. Usa esta forma: `<número>: <línea>`.

## Ejemplo

El programa imprime:

```
1: apple
2: banana
3: cherry
```
