## Problema

Abre un archivo con el nombre `out.txt` para escribir. Mantén el manejador abierto. Escribe en él los números `1`, `2` y `3` con un bucle. Cada número debe estar en su propia línea. Después cierra el manejador. Lee el archivo e imprime su contenido.

## Ejemplo

El programa imprime:

```
1
2
3
```
