## Problema

Un manejador de archivo es un valor normal. Así que puedes pasarlo a una función, como cualquier otro argumento. Escribe una subrutina `log-line`. Recibe un manejador y un mensaje. Escribe el mensaje en el manejador, en una línea propia.

Abre `log.txt` para escribir. Llama a `log-line` tres veces. Escribe con ella `started`, `working` y `done`. Después cierra el manejador. Lee el archivo e imprime su contenido.

## Ejemplo

El programa imprime:

```
started
working
done
```
