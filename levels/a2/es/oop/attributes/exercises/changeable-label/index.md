## Problema

Crea una clase `Label` con un atributo, `text`. Puedes cambiar este atributo (`is rw`). Crea una etiqueta con el texto `draft`. Después **añade** ` (revised)` al final de su texto. Hazlo a través del accesor. No crees el objeto otra vez. Imprime el resultado.

## Ejemplo

El programa imprime:

```
draft (revised)
```
