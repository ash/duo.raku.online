## Problema

Crea una clase `Robot` con un método `speak`. Este método devuelve `beep`. Después crea un rol `Dancing`. Añade un método `dance`. Este método devuelve `spinning around`.

Crea dos robots. Da el rol `Dancing` solo a uno de ellos. Llama a `speak` sobre los dos robots e imprime los resultados. Después llama a `dance` sobre el robot que sabe bailar. Imprime también este resultado.

## Ejemplo

El programa imprime:

```
beep
beep
spinning around
```
