## Problema

Escribe un programa. Pide al usuario un entero positivo. Luego imprime el último dígito de este número.

## Ejemplo

Aquí hay un ejemplo de cómo funciona el programa:

```console
$ raku the-last-digit.raku
Introduce un número: 123
El último dígito de 123 es 3.
```
