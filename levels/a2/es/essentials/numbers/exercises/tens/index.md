## Problema

Escribe un programa. Pide al usuario un entero positivo. Luego imprime el dígito que muestra el número de _decenas_ en él.

## Ejemplo

Por ejemplo, el usuario ingresa 234. El número de decenas en él es 3. Así que el programa imprime 3:

```console
$ raku tens.raku
Ingrese un número entero positivo: 234
3
```
