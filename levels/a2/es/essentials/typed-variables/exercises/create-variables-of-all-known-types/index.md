## Tarea

Escribe un programa. Crea algunas variables escalares. Les da valores de estos tipos: `Int`, `Rat`, `Num`, `Bool` y `Str`. El programa imprime cada valor y su tipo.

## Ejemplo

Tu salida puede ser diferente. Pero esta ejecución de prueba muestra la idea:

```console
$ raku types.raku
151 (Int)
4.2 (Rat)
1e10 (Num)
True (Bool)
xyz (Str)
```
