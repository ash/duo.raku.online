## Problema

Hiciste antes el ejercicio ‘[Tabla de compras](/es/essentials/strings/exercises/purchase-table)’. Toma la misma tabla de ese ejercicio:

    Artículo  Precio  N      Total
    Sillas    $20.57  4      $82.28
    Mesas     $50.18  1      $50.18

Elige una estructura de datos para estos valores. Después escribe un programa. Debe imprimir los datos.

## Ejemplo

Ejecuta el programa. Debe imprimir la tabla de arriba.

```console
$ raku purchase-table.raku
```
