## Problema

Este hash tiene los datos de un empleado:

```raku
my %employee =
    full-name => 'Eliza Vents',
    department => 'Sales',
    salary => 3000;
```

Aumenta el salario en un 5&thinsp;%. Imprime el nuevo salario y el nombre del empleado. Después del cambio, el hash `%employee` debe tener los valores correctos.

## Ejemplo

El programa debe imprimir esto:

```console
$ raku salary-raise.raku
Nuevo salario de Eliza Vents: 3150
```
