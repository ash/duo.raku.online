## Problema

Escribe un programa que divida un número entero entre otro. Debe usar la resta. Los números ya están en el código:

```raku
my $a = 175;
my $b = 25;
```

Termina el programa. Debe imprimir la parte entera de `$a / $b`. Usa solo un bucle y restas.

## Ejemplo

```console
$ raku division-via-subtraction.raku
7
```
