También puedes usar `loop` solo con un cuerpo:

```raku
loop {
    say 'Eternidad';
}
```

Este bucle se ejecuta para siempre. Solo para cuando detienes el programa, por ejemplo, con `Ctrl+C`. En la segunda parte del curso, vas a aprender mejores formas de controlar los bucles.
