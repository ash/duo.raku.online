También puedes escribir `loop` solo con un cuerpo:

```raku
loop {
    say 'Eternidad';
}
```

Este bucle nunca se detiene solo. Debes detener el programa, por ejemplo, con `Ctrl+C`. La segunda parte del curso muestra mejores formas de controlar los bucles.
