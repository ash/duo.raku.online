Un bloque de código es una parte de tu programa. Está dentro de un par de llaves: `{` y `}`. Un bloque tiene varias declaraciones dentro. Funcionan juntas, como una gran declaración. Las siguientes secciones muestran muchas formas de usar bloques.

```raku
{
    say '¡Hola, Mundo!';
}
```

Este programa no necesita realmente el bloque de código. Pero los bloques de código son muy útiles en otros casos. Los vemos muy pronto.

Pero primero, veamos la idea de _alcance_. El alcance trata de dónde puedes usar una variable.
