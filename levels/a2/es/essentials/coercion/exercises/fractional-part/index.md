## Problema

Hay un número escrito directamente en el programa. Imprime su parte fraccionaria. Aquí está el inicio del programa:

```raku
my $n = 15.8972;
# ... Tu código aquí
```

## Ejemplo

El programa debe imprimir la parte después del punto decimal:

```console
$ raku fractional-part.raku
0.8972
```
