Ahora hablemos de cadenas. Nuestros programas ya tenían cadenas. Estas cadenas también se llaman literales de cadena. Un literal de cadena es un texto entre comillas:

```raku
say 'Soy un literal de cadena';
```

Claro, una variable escalar también puede guardar una cadena:

```raku
my $mensaje = 'Este es mi mensaje';
```

Ahora aprendamos algunas cosas básicas más sobre las cadenas.
