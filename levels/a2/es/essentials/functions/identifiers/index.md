title: Nombres de funciones
---

{% include menu.html %}

El nombre de una función es un identificador. Sigue las mismas reglas que los [nombres de variables](/es/essentials/scalar-variables/identifiers). Debe empezar con una letra o un guion bajo (`_`). Después puede tener letras, dígitos y guiones bajos. También puede tener guiones (`-`) y apóstrofes (`'`). Un apóstrofe es una comilla simple.

Después de un apóstrofe o un guion, debe ir una letra. La gente no usa mucho los apóstrofes en los nombres. Pero sí usa mucho los guiones. Con guiones, un nombre puede decir más.

Aquí tienes algunos ejemplos de nombres de funciones correctos.

    greet

    greet-them

    hello-world

    NumberOfItems

    is-valid

    to_be-or-not_to_be
