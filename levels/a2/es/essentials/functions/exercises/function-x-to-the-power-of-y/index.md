## Problema

Escribe una función con dos argumentos, `$x` y `$y`. La función devuelve `$x` elevado a `$y`. Después escribe un programa. El programa imprime los valores de `5³`, `2¹⁰` y `(−4)⁵`.

## Ejemplo

Para estos valores, el programa imprime esto:

```
$ raku function-x-to-the-power-of-y.raku
125
1024
-1024
```
