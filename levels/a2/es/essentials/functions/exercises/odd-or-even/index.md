## Problema

Escribe una función. Esta función toma un número entero como argumento. Devuelve la cadena `'Impar'` o `'Par'`. Después escribe un programa con esta función. Imprime la respuesta para algunos números. Por ejemplo, usa `10`, `5`, `0` y `3`.

## Ejemplo

Para estos números, el programa imprime esto:

```console
$ raku odd-or-even.raku
Par
Impar
Par
Impar
```
