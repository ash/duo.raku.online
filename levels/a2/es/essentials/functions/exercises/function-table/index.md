## Problema

Escribe un programa. El programa imprime los valores de la función `f(x) = x²`. Toma `x` de −3 a 3, con −3 y 3 incluidos. Cada vez, suma 0.1 a `x`.

## Ejemplo

El programa imprime dos columnas. La primera columna tiene el valor de `x`. La segunda columna tiene el valor de `f(x)`.

```
$ raku function-table.raku
-3	9
-2.9	8.41
-2.8	7.84
. . .
```
