Los programas en Raku son texto plano. Normalmente, los guardas en archivos de texto. Pero hay algunas excepciones. Por ejemplo, puedes ejecutar un programa en línea. O puedes ejecutarlo en la línea de comandos. También puedes preparar código y ejecutarlo con `EVAL`. Hay también algunos otros casos raros.

Raku espera el texto del programa en UTF-8. Así que puedes usar cualquier editor de texto. Pero no debe guardar el formato en el archivo. Puedes usar `vim`, `nano`, `emacs` o `mcedit`. Cualquiera de ellos es una buena opción. Pero quizás también quieras probar algunas aplicaciones nuevas y populares.

## Enlaces externos

Aquí tienes enlaces a algunos IDEs populares. Un IDE es un programa para escribir y ejecutar código.

* [Visual Studio Code](https://code.visualstudio.com/) — para Windows, Mac OS y Linux
* [Comma](https://commaide.com) — el IDE de Raku, hecho solo para programar en Raku. Funciona en Windows, Mac OS y Linux.
