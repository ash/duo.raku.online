Esta sección es muy corta. Muestra cómo ejecutar un programa sin salir del IDE. Vemos los dos [IDEs](../../editors-and-ides) más recomendados.

## Editor de Visual Studio Code

Abre una terminal desde el menú: `Terminal` → `New Terminal`. Se abre un panel nuevo debajo del texto de tu programa. Ejecuta allí el programa, como desde la línea de comandos:

```console
$ raku hello.raku
```

## Comma IDE

Para ejecutar un programa, usa la opción `Run` del menú. Antes de la primera ejecución, configura el IDE. Sigue [las instrucciones](https://commaide.com/docs/running) del sitio web de Comma.
