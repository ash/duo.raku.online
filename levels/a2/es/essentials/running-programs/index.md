En [una de las secciones anteriores](../hello-world), escribimos un programa simple. Pero todavía no lo ejecutamos. Hay muchas formas de ejecutar un programa. Puedes usar una herramienta de línea de comandos en tu ordenador. Puedes usar un shell REPL. Puedes ejecutar el programa directamente desde un [IDE](../editors-and-ides). Puedes usar un servicio en línea, como [glot.io](https://glot.io/new/raku). O puedes usar un contenedor de Docker.

Esta sección tiene cinco temas. Puedes leerlos todos. O puedes leer solo los que necesitas. Después de los temas, hay una tarea.
