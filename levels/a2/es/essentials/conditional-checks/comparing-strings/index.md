Las cadenas tienen sus propios operadores para compararlas:

`eq` | Igual
`ne` | No igual
`gt` | Mayor que
`ge` | Mayor o igual que
`lt` | Menor que
`le` | Menor o igual que

## Ejemplos

Aquí tienes algunos ejemplos. Cada uno compara dos cadenas:

```raku
say 'alpha' lt 'beta'; # True
say 'word' ne 'Word';  # True
say 'xyz' gt 'xvw';    # True
```
