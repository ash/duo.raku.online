## Problema

Escribe un programa. El programa hace dos cosas:

1. Pregunta al usuario su nombre.
2. Imprime el mensaje `¡Hola, Nombre!`. `Nombre` es el nombre que el usuario acaba de escribir.

Usa variables en este programa.

## Ejemplo

Así funciona el programa:

```console
$ raku greet-a-person.raku
¿Cuál es tu nombre? Juan
¡Hola, Juan!
```
