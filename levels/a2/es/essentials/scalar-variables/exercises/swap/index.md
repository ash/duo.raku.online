## Problema

Escribe un programa. Primero, el programa crea dos variables. Pone un número entero en cada una. Luego intercambia los valores. Cada variable recibe el valor de la otra. Al final, el programa imprime los valores. Intenta hacer el programa lo más simple posible. No uses variables temporales, o sea, variables extra.
