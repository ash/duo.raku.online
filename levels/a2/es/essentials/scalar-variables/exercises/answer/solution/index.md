Aquí hay una forma de resolver la tarea.

## Código

```raku
my $answer = 42;
say $answer;
```

🦋 Puedes encontrar el código fuente en el archivo [answer.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/scalar-variables/answer.raku).

## Salida

Ejecuta el programa y observa lo que imprime:

```console
$ raku exercises/scalar-variables/answer.raku 
42
```

## Comentarios

Una regla de esta tarea es usar variables. `42` es solo un valor. Así que una variable escalar es un buen lugar para guardarlo.
