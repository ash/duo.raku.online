Hasta ahora, nuestros programas tenían cadenas de texto escritas directamente en el código. Ahora añadimos un poco de libertad. Los programas pueden usar variables.

Raku tiene algunos tipos de variables. Una variable es un contenedor. Guarda algunos datos, como una caja. Empezamos con los contenedores más simples. Solo guardan un valor. Los llamamos _escalares_, o variables escalares. Cada variable tiene un nombre. Delante del nombre va un carácter especial. Indica el tipo de contenedor. Este carácter es el _sigil_. Para los contenedores escalares, el sigil es el signo de dólar `$`.

Aquí hay dos variables escalares:

```raku
$name

$age
```
