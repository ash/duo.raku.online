## Problema

Escribe un programa. El programa calcula el perímetro de un rectángulo y lo imprime. Pasa las longitudes de dos lados como argumentos de la línea de comandos. Para un cuadrado, pasa solo un valor. Usa la función `MAIN`.

## Ejemplo

El programa tiene que decir claramente qué figura es: un cuadrado o un rectángulo. Aquí tienes una posible salida para los dos casos:

```console
$ raku perimeter.raku 15
El perímetro de un cuadrado es 60.

$ raku perimeter.raku 15 20
El perímetro de un rectángulo es 70.
```
