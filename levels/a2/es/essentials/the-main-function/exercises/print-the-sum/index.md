## Problema

Escribe un programa. El programa toma dos números enteros de la línea de comandos. Luego imprime su suma. Usa la función `MAIN`. Sus parámetros deben tener tipos.

## Ejemplo

Aquí tienes un ejemplo:

```console
$ raku print-the-sum.raku 500 700
1200
```
