## Tarea

Escribe un programa. Lee argumentos desde la línea de comandos. Puede haber cualquier número de ellos. El programa imprime cada argumento en su propia línea. Las líneas tienen números.

## Ejemplo

El programa debe funcionar así:

```console
$ raku count-and-print-arguments.raku palabras para mostrar
1. palabras
2. para
3. mostrar
```
