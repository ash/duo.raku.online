## Problema

Crea un módulo con el nombre `Maths` en el archivo `Maths.rakumod`. El módulo exporta una subrutina `square`. La subrutina devuelve el cuadrado de su argumento.

Luego escribe un programa separado. El programa usa el módulo e imprime `square(6)`.

## Ejemplo

Ejecuta el programa con el módulo en la ruta de búsqueda. El programa imprime:

```console
$ raku -I. maths.raku
36
```
