## Problema

Crea un módulo con el nombre `Shouter` en el archivo `Shouter.rakumod`. El módulo exporta una subrutina `shout`. La subrutina devuelve su argumento en letras mayúsculas.

Luego escribe un programa separado. El programa usa el módulo e imprime `shout('hi')`.

## Ejemplo

Ejecuta el programa con el módulo en la ruta de búsqueda. El programa imprime:

```console
$ raku -I. shout.raku
HI
```
