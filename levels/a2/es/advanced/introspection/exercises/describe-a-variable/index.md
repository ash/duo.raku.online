## Problema

Aquí tienes una variable con un tipo:

```raku
my Str $lang = 'Raku';
```

Imprime tres cosas sobre ella. Imprime cada una en su propia línea:

1. el tipo de su valor;
2. el tipo de su contenedor;
3. su nombre, con el sigil.

## Ejemplo

El programa imprime:

```
Str
Scalar
$lang
```
