## Problema

`WHAT` hace más que describir un tipo. Devuelve el objeto de tipo mismo. Puedes comparar objetos de tipo con el operador `===`.

Declara dos variables. `$a` guarda el entero `42`. `$b` guarda la cadena `'x'`. Para cada variable, mira su `WHAT`. ¿Es el tipo `Int`? Imprime la respuesta.

## Ejemplo

El programa imprime:

```
True
False
```
