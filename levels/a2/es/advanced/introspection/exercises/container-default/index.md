## Problema

Un contenedor puede tener un valor por defecto. Lo pones con el trait `is default`. Antes de asignar un valor, la variable devuelve este valor por defecto. `.VAR.default` también lo muestra.

Declara un escalar `$count`. Su valor por defecto debe ser `0`. No le asignes nada. Imprime la variable. Luego imprime el valor por defecto de su contenedor. Las dos líneas deben mostrar `0`.

## Ejemplo

El programa imprime:

```
0
0
```
