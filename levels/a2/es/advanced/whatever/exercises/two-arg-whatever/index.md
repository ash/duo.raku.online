## Problema

Cada `*` en una expresión Whatever es un argumento distinto. Así que dos estrellas crean una función con dos argumentos. Escribe una función así. Une sus dos argumentos con un guion entre ellos: `* ~ '-' ~ *`. Guárdala en una variable. Después llámala con `'a'` y `'b'`. Imprime el resultado.

## Ejemplo

El programa imprime:

```
a-b
```
