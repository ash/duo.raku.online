## Problema

Una URL está cortada en partes. Las partes están en un array. Vuelve a unir las partes en una sola cadena. Usa un meta-operador de reducción para esto. Imprime la URL. En la línea siguiente, imprime su longitud en caracteres.

## Ejemplo

Este es el array de entrada:

```raku
my @parts = <http :// example .com>;
```

El programa imprime:

```
http://example.com
18
```
