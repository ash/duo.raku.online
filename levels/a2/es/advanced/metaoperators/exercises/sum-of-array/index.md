## Problema

Escribe un programa. Imprime el promedio de un array de números. El promedio también se llama media aritmética. Usa un meta-operador de reducción para sumar los valores.

Los números están escritos en el mismo programa. Por ejemplo:

```raku
my @data = 10, 20, 30, 40;
```

## Ejemplo

El programa imprime el promedio de los elementos de `@data`:

```
25
```
