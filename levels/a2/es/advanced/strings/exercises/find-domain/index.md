## Problema

`index` te dice *dónde* está un carácter. Luego puedes cortar la cadena en ese lugar con `substr`. Úsalos juntos.

Toma la dirección de correo `user@example.com`. Busca la posición del signo `@`. Luego imprime todo lo que hay después. Esta es la parte del dominio.

## Ejemplo

El programa imprime:

```
example.com
```
