## Problema

Crea un acrónimo a partir de una frase. Un acrónimo se forma con las primeras letras de unas palabras. Toma la primera letra de cada palabra. Une las letras. Imprime el resultado en mayúsculas.

Usa esta frase:

```raku
my $phrase = 'hyper text markup language';
```

## Ejemplo

El programa imprime:

```
HTML
```
