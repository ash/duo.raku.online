Una función del módulo `Test` pasa cuando una condición es verdadera. La condición es `True` o `False`. ¿Cuál es esa función?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` toma una condición. Pasa cuando la condición es verdadera. `is` compara el valor que obtienes con el valor que esperas. `plan` dice cuántas pruebas esperar. `done-testing` termina el archivo e imprime el plan.

</div>
