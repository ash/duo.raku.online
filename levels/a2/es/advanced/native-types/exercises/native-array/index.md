## Problema

Los tipos nativos con un tamaño fijo son buenos para arrays de bytes. Estos arrays usan poca memoria. Crea un array `uint8` con los valores `100`, `200` y `255`. Cada valor cabe en un byte. Imprime la suma de los elementos.

Los elementos quedan en el rango `0..255`. Pero su suma puede ser mayor. `.sum` devuelve un `Int` normal.

## Ejemplo

El programa imprime:

```
555
```
