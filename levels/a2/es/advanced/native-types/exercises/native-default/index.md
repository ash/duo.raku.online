## Problema

Una variable nativa nunca es indefinida. Esta regla vale para todos los tipos nativos, no solo para `int`. Declara un `num` nativo y un `str` nativo. No les des valores. Imprime el número. Luego imprime la cadena entre corchetes. Así puedes ver que está vacía.

## Ejemplo

El programa imprime:

```
0
[]
```
