## Problema

Usa `given`/`when`. La edad es un número en el código. Imprime la etapa de la vida para esta edad. Usa estos grupos:

* `child` para 0-12,
* `teenager` para 13-19,
* `adult` para 20-64,
* `senior` para 65 o más.

Una edad menor que cero no tiene sentido. Así que para cualquier número menor que cero, imprime `invalid`. Comprueba este caso primero, antes de los rangos.

## Ejemplo

Si la edad es `30`, el programa imprime:

```
adult
```
