## Problema

Un `when` puede comparar con un *tipo*, no solo con un valor. Una variable guarda el número `3.14`. Usa `given`/`when` para decir de qué tipo es el valor. Imprime `integer` para un `Int`. Imprime `rational` para un `Rat`. Imprime `string` para un `Str`.

## Ejemplo

El programa imprime:

```
rational
```
