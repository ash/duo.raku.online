## Problema

Toma un número entero en el código. Usa `given`/`when` para imprimir si es `zero`, `even` u `odd`. El cero también es un número par. Así que comprueba primero el cero. Muéstralo aparte.

## Ejemplo

Si el número es `12`, el programa imprime:

```
even
```
