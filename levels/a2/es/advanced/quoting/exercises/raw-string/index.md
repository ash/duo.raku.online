## Problema

Toma la forma de entrecomillado más literal. Deja todo el texto tal como está. Con ella, imprime el texto `$x and \n` exactamente como está escrito. La variable no se debe interpolar. La secuencia de escape no se debe procesar.

## Ejemplo

El programa imprime:

```
$x and \n
```
