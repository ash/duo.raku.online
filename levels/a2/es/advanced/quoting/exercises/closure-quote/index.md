## Problema

Empieza desde la forma `q`. No interpola. Activa solo el adverbio de closure. La variable `$x` guarda `10`. Imprime una línea con el cálculo `{$x ** 2}` *y* un `$x` simple. Este `$x` simple no se interpola. Así ves que el adverbio de closure ejecuta código entre llaves. Pero no toca las variables `$` simples.

## Ejemplo

El programa imprime:

```
$x squared is 100
```
