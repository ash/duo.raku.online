## Problema

Escribe una subrutina `power`. Tiene un parámetro obligatorio `$base` y un parámetro **opcional** `$exp`. Si quien llama da el exponente, eleva la base a ese exponente. Si no hay exponente, eleva la base al cuadrado. Para esto, usa el operador defined-or `//` para dar `2`.

Llámala dos veces. Primero, da solo una base. Después, da una base y un exponente.

## Ejemplo

El programa imprime:

```
25
125
```
