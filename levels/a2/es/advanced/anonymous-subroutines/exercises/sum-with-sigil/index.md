## Problema

Un bloque puntiagudo puede tener más de un parámetro. Con el sigilo `&`, puedes llamarlo por su nombre. Escribe un bloque puntiagudo con dos parámetros. Suma sus dos argumentos. Guárdalo en la variable `&add`. Esta variable tiene el sigilo `&`. Después llámalo como `add(2, 3)`, sin el sigilo. Imprime el resultado.

## Ejemplo

El programa imprime:

```
5
```
