## Problema

No tienes que guardar primero una subrutina anónima en una variable. Puedes darla directamente a otra rutina. Usa la forma `sub`, no un bloque puntiagudo. Escribe una subrutina anónima de "cuadrado". Multiplica un número por sí mismo. Dala directamente a `map` sobre la lista `1, 2, 3`. Imprime el resultado.

## Ejemplo

El programa imprime:

```
(1 4 9)
```
