## Problema

El operador `**` es más fuerte que `+`. Así, Raku lee `2 ** 3 + 1` como `(2 ** 3) + 1`. Esto es `9`. Añade paréntesis y cambia este orden. La suma debe ir *primero*. Imprime el resultado.

## Ejemplo

El programa imprime:

```
16
```
