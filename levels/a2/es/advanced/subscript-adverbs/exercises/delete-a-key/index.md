## Problema

Aquí tienes un hash: `a => 1, b => 2, c => 3`. Elimina la entrada `b` con un adverbio de subíndice. Luego imprime cuántas entradas quedan en el hash. Esto muestra que una entrada ya no está.

## Ejemplo

El programa imprime:

```
2
```
