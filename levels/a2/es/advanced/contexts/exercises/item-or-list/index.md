## Problema

Toma el array `1, 2, 3`. Ponlo en un escalar `$x` con el contextualizador de **elemento**. Un contextualizador pone el contexto. Ahora `$x` guarda el array completo como un solo valor. Luego ejecuta un bucle `for` sobre `$x` con el contextualizador de **lista**. Cuenta cuántas veces se ejecuta el bucle. En contexto de lista, el array vuelve a ser tres elementos. Así que el bucle se ejecuta tres veces. Imprime el conteo.

## Ejemplo

El programa imprime:

```
3
```
