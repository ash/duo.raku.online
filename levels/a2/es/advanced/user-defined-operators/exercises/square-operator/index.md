## Problema

El símbolo de un operador puede ser cualquier carácter. También puede ser un carácter Unicode. Define un operador **postfijo** `²`. Devuelve el cuadrado de su operando. Así, `5²` significa `5 ** 2`. Después imprime `5²`.

## Ejemplo

El programa imprime:

```
25
```
