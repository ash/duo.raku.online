## Problema

Declara una variable escalar `$discount`. Su valor por defecto debe ser `0`. Imprime la variable antes de asignarle algo. El programa debe imprimir `0`. No debe imprimir ninguna advertencia.

Luego asigna `15` a la variable. Imprímela otra vez.

## Ejemplo

El programa imprime dos líneas:

```
0
15
```
