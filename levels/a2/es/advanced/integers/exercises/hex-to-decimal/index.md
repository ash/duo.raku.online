## Problema

Puedes leer un número en una base. También puedes escribirlo otra vez en esa base. Estos dos pasos son opuestos. Toma el número hexadecimal `1A`. Hexadecimal significa base 16. Guarda su valor decimal en una variable. Decimal significa base 10. Luego imprime dos líneas. La primera línea es el valor decimal. Después, convierte el valor otra vez en una cadena hexadecimal. Imprímela en la segunda línea.

## Ejemplo

El programa imprime:

```
26
1A
```
