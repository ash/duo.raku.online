## Problema

Crea un paquete `Temperature`. Tiene dos cosas dentro. La primera es una variable `our` llamada `$freezing` con el valor `0`. La segunda es una subrutina `our` llamada `fahrenheit`. Cambia un valor en Celsius a Fahrenheit. Para esto, multiplica por 9/5 y suma 32. Desde fuera del paquete, imprime el punto de congelación. Luego imprime `100` grados Celsius en Fahrenheit.

## Ejemplo

El programa imprime:

```
0
212
```
