## Problema

Pon un módulo `Inner` dentro de un módulo `Outer`. En `Inner`, crea una variable `our` llamada `$base` con el valor `10`. Crea también una `our sub doubled`. Devuelve `$base` por dos. Desde fuera de los dos módulos, usa el nombre anidado completo de la variable. Este nombre tiene dentro los nombres de los dos módulos. Llama también a la subrutina por su nombre anidado completo. Imprime los dos resultados.

## Ejemplo

El programa imprime:

```
10
20
```
