## Problema

Escribe una subrutina `compute`. Dentro de ella, define una función auxiliar anidada `add`. Devuelve la suma de sus dos argumentos. Dentro de `compute`, devuelve `add(2, 3) + add(4, 5)`.

Llama a `compute` e imprime el resultado.

## Ejemplo

El programa imprime:

```
14
```
