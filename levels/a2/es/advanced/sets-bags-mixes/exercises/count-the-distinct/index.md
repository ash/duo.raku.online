## Problema

Aquí tienes una lista de números. Algunos de ellos se repiten:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Imprime cuántos valores _distintos_ tiene. Los valores distintos son todos diferentes entre sí. Usa un set.

## Ejemplo

El programa imprime:

```
7
```
