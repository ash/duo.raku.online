## Problema

Escribe dos multi-subrutinas con el nombre `abs-value`. Toman un entero y devuelven su valor absoluto. El valor absoluto es el número sin su signo menos. Usa una cláusula `where` para los números negativos. No uses `if` en las subrutinas. Tampoco uses la función incorporada `abs`.

Imprime el resultado para `-7` y para `4`.

## Ejemplo

El programa imprime:

```
7
4
```
