## Problema

Tu propio trait puede hacer más que estar o no estar. También puede recibir un argumento. Escribe un trait `is role(...)`. Recibe una cadena. Esta cadena es el rol de una subrutina. El trait guarda el rol en un hash. La clave es el nombre de la subrutina.

Añade `is role('admin')` a una subrutina `login`. Después imprime el rol guardado de `login`.

## Ejemplo

El programa imprime:

```
admin
```
