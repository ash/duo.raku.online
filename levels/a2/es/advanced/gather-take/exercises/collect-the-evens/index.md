## Problema

Usa `gather` y `take` para construir una lista. Cada número del `1` al `4` está varias veces en la lista. El número de veces es el mismo número: `1` una vez, `2` dos veces, `3` tres veces y `4` cuatro veces. Imprime la lista.

## Ejemplo

El programa imprime:

```
[1 2 2 3 3 3 4 4 4 4]
```
