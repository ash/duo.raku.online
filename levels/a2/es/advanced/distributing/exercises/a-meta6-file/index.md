## Problema

Escribe un archivo `META6.json`. La distribución tiene el nombre `Greet::Simple` y la versión `0.0.1`. Ofrece el módulo `Greet::Simple` desde el archivo `lib/Greet/Simple.rakumod`. En el ejemplo de la teoría, `depends` está vacío. Aquí es diferente. Esta distribución **depende de** otra distribución, `JSON::Fast`. Ponla en el array `depends`.

> El resultado de este ejercicio es un archivo. No es la salida de un programa.
