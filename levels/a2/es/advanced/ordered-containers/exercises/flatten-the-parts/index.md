## Problema

Aquí tienes dos arrays:

```raku
my @first = 1, 2;
my @second = 3, 4, 5;
```

Júntalos en un solo array _plano_. No debe ser un array anidado, con arrays dentro. Imprime el array. Luego imprime el número de sus elementos.

## Ejemplo

El programa imprime:

```
[1 2 3 4 5]
5
```
