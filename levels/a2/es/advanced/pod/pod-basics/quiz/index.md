¿Qué directiva Pod hace un **encabezado de nivel superior**?

{:.quiz}
1 | `=head1`
0 | `=title`
0 | `=h1`
0 | `=heading`

{% include quiz.html %}

<div class="extended-explanation">

`=head1` es un encabezado de nivel superior. `=head2`, `=head3` y los demás son niveles más bajos. El número es el nivel del encabezado. Otros lenguajes para dar formato al texto funcionan de forma parecida.

</div>
