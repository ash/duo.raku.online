## Problema

La forma con dos puntos debe ser la *última* llamada de una cadena. Pero las llamadas anteriores pueden ser llamadas normales con paréntesis. Empieza con las palabras `a`, `b`, `c`. Ponlas en orden inverso con `.reverse`. Después une el resultado con un guion. Usa la forma con **dos puntos** para unir. Imprime el resultado.

## Ejemplo

El programa imprime:

```
c-b-a
```
