---
title: Блоки `else`
---

{% include menu.html %}

Після блоку `if` ви можете додати блок `else`. Raku виконує блок `else`, коли умова — `False`.

```raku
my $t = 36.6;
if 35.5 < $t < 37.5 {
    say 'У вас все добре.';
}
else {
    say 'Можливо, зверніться до лікаря?';
}
```

Ви не можете використати блок `else` окремо. Для цього є кращий спосіб: [`unless`](../unless). Ми скоро його розглянемо.
