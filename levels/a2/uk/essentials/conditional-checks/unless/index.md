---
title: Використання `unless`
---

{% include menu.html %}

[Оператор `!`](/uk/essentials/booleans/operations#negation) легко перетворює будь-яку булеву умову на протилежну. Але іноді цей `!` робить вираз складнішим. Тоді його важче читати. У таких випадках `unless` може допомогти.

Умова `unless` має бути `False`. Тоді Raku виконує блок.

```raku
my $broken = False;

# ...Щось може встановити $broken на True тут...
    
unless $broken {
    say "Не хвилюйся!";
    say "Будь щасливий!";
}
```

Ось дві версії однієї програми. Порівняйте їх:

З `if` та `!`:

```raku
if !$broken { . . . }
```

З `unless`:

```raku
unless $broken { . . . }
```

Отже, у вас є вибір. У кожній ситуації вибирайте те, що вам більше подобається.

Ви не можете поставити блок `else` або `elsif` після `unless`. Для цього вам треба використати `if`.
