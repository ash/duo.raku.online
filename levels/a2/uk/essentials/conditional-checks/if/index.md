---
title: Блоки `if`
---

{% include menu.html %}

`if` — це умовна перевірка. Вона перевіряє умову. Якщо умова — `True`, `if` виконує блок коду.

```raku
if 10 > 4 {
    say 'Математика працює!';
}
```

Вам не потрібно брати умову в круглі дужки. Але ви можете, якщо хочете.

Звісно, ви можете використовувати змінні в тестах:

```raku
my $flag = False;
if $flag {
    # . . . зробити щось
}
```

Іноді дві чи більше перевірок використовують ту саму змінну. Тоді можна записати порівняння ланцюжком:

```raku
my $x = 42;
if 40 < $x < 45 {
    say "Правильна відповідь $x дана.";
}
```

Іноді умова — `False`. Тоді Raku не виконує блок коду. Програма просто йде далі.

```raku
say 'Початок';
if False {
    say 'Це ніколи не буде надруковано.';
}
say 'Кінець';
```

Ця програма друкує тільки `Початок` і `Кінець`.
