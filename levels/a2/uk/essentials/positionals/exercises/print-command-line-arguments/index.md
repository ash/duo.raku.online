## Завдання

Напишіть програму. Вона виводить усі аргументи з командного рядка. Виводьте по одному аргументу в кожному рядку.

## Приклад

Програма повинна працювати так:

```console
$ raku print-command-line-arguments.raku words to display
words
to
display
```
