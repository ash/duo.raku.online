Списки схожі на масиви, але вони незмінні. Ви не можете змінити розмір списку. Ви також не можете змінити його елементи. Щоб створити список, використовуйте круглі дужки:

```raku
my $odd = (1, 3, 5, 7, 9);
```

## Індексація списків

Щоб отримати один елемент списку, використовуйте квадратні дужки. Поставте в них індекс:

```raku
say $odd[3]; # 7
```

Але ви не можете дати елементу нове значення:

```raku
$odd[3] = 8; # Не ОК
```

Якщо ви спробуєте, ви отримаєте виняток:

    Неможливо змінити незмінний список ((1 3 5 7 9))
      в блоці <unit> на t.raku рядок 4

## Призначення списку масиву

Ви можете зберегти список у змінній з сигілом `@`. Що тоді відбувається?

```raku
my @data = (40, 42, 44);
```

Тоді змінна `@data` містить масив. Ви можете змінювати його елементи.

%%tipblock
## Змінна чи список

Список незмінний. Але ви все одно можете знову використати його змінну. Ви можете покласти в неї новий список.

```raku
my $elements = (1, 2);
say $elements[0]; # 1

$elements = (3, 4);
say $elements[0]; # 3
```

%%/tipblock
