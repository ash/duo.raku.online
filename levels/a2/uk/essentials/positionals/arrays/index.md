Масиви — це агрегатні типи даних. Це означає, що масив може зберігати більше одного значення. Цим масиви відрізняються від [скалярних елементів](/uk/essentials/scalar-variables). Ви можете індексувати, або _підписувати_, елементи масиву. Іншими словами, кожен елемент має позицію. Тому ми називаємо такі дані позиційними.

Змінні-масиви мають інший сигіл: `@`. Правила для імені такі самі, як [для скалярів](/uk/essentials/scalar-variables/identifiers/).

```raku
my @cities;
```

Тепер у нас є масив. Його назва — `@cities`. Ви можете покласти в нього кілька значень:

```raku
@cities = 'Paris', 'Rome', 'Berlin';
```

Ви також можете створити масив одразу зі значеннями:

```raku
my @cities = 'Paris', 'Rome', 'Berlin';
```

## Індексація

Щоб отримати один елемент масиву, використовуйте пару дужок. Поставте їх після імені змінної:

```raku
say @cities[1];
```

Зверніть увагу, що сигіл не змінюється. Він завжди `@`. Raku рахує елементи з нуля. Тож у нашому прикладі `@cities[1]` — це `'Rome'`.

Масиви є змінними. Це означає, що ви можете їх змінювати. Щоб змінити елемент, просто присвойте йому нове значення:

```raku
@cities[0] = 'Rome';
@cities[1] = 'Paris';
```

Після цього оператор `say @cities[1]` виводить нове значення, `'Paris'`.

## Розмір

Що таке довжина масиву? Це кількість його елементів. Щоб її отримати, використовуйте метод `elems`:

```raku
say @cities.elems; # 3
```

Іноді ви використовуєте масив там, де Raku потрібне число. Тоді ви отримуєте розмір масиву:

```raku
say +@cities; # 3
```

Тут [`+` префіксний оператор](/uk/essentials/coercion/prefixes) потребує числа від свого аргументу. Тож результат `+@cities` — це `3`.
