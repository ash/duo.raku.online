У Raku діапазон створює список елементів. Елементи йдуть по порядку, один за одним.

У найпростішому випадку діапазон — це список цілих чисел. Кожне число на 1 більше за попереднє. Щоб створити діапазон, використовуйте оператор `..` з двома значеннями. Перше значення — найменше значення діапазону. Друге значення — найбільше:

```raku
1 .. 5
```

Пробіли навколо оператора не потрібні. Тому той самий діапазон можна записати й так:

```raku
1..5
```

Діапазон створює список. Але сам діапазон — це один об'єкт. Тому його можна зберігати в скалярній змінній:

```raku
my $r = 1 .. 5;
```

## Не тільки числа

Діапазони можна створювати й з інших типів даних. Це працює, якщо Raku знає, як отримати наступне значення. Наприклад:

```raku
my $letters = 'a' .. 'z';
```

У Raku діапазони мають власний тип даних. Змінна `$r` має тип `Range`.
