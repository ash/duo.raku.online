Ось один спосіб вирішити задачу.

## Код

```raku
my $answer = 42;
say $answer;
```

🦋 Ви можете знайти вихідний код у файлі [answer.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/scalar-variables/answer.raku).

## Вивід

Запустіть програму і подивіться, що вона виведе:

```console
$ raku exercises/scalar-variables/answer.raku 
42
```

## Коментарі

Одне правило цієї задачі — використовувати змінні. `42` — це лише одне значення. Тому його добре зберігати в скалярній змінній.
