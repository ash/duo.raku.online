Іноді змінна ще не має значення. Тоді ви можете використати інше значення. Для цього є оператор `//`. Він називається оператором _defined-or_.

```raku
my $a = 'alpha';
say $a // 'gamma';

my $b;
say $b // 'delta';
```

Ця програма виводить:

```
alpha
delta
```

Перший рядок дає змінній `$a` значення. Тому вираз `$a // 'gamma'` використовує поточне значення `$a`. Зі змінною `$b` усе інакше. Вона не має значення. Тому `$b // 'delta'` дає значення праворуч. Програма виводить `delta`.

## //=

Разом `//` і `=` дають оператор `//=`. Він присвоює значення, лише коли змінна не визначена.

```raku
my $x;
$x //= 42;
say $x; # 42
```
