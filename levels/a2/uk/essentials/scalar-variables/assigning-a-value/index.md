Оператор `=` кладе нове значення в скалярний контейнер.

```raku
my $name;
$name = 'Анна';
```

Тепер ви можете використовувати змінну. Наприклад, ви можете її вивести:

```raku
say $name;
```

## Дві або більше змінних одразу

Ви можете присвоїти значення кільком змінним одразу. Наприклад, тут один вираз присвоює значення двом скалярам:

```raku
my ($a, $b);
($a, $b) = 10, 20;
```

Ви повинні писати дужки з лівого боку. Ви не можете їх пропустити. З правого боку ви теж можете їх додати. Тоді обидва боки виглядають однаково:

```raku
($a, $b) = (10, 20);
```
