Найпростіший коментар — це однорядковий коментар. Він починається з символу `#`. Він іде до кінця рядка.

```raku
my $name; # Ця змінна використовується для зберігання імені користувача
$name = prompt 'Як вас звати? ';
say $name; # Тепер ми бачимо ім'я
```

Shebang — це перший рядок, наприклад `#!/usr/bin/env raku`. Для Raku це теж коментар. Але оболонка може його прочитати і запустити.
