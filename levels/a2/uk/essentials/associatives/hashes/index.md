_Хеш_ — це ще один асоціативний тип даних у Raku. Це агрегатний тип даних. Він зберігає багато елементів. Кожен елемент має ім'я і значення. Змінні-хеші використовують новий сигіл: `%`.

```raku
my %capitals;
```

Тепер ви можете використовувати хеш. Ви можете присвоїти йому кілька початкових значень.

```raku
%capitals = France => 'Paris', Italy => 'Rome';
```

Ви також можете зробити обидві дії одразу. Це працює і з іншими типами даних:

```raku
my %capitals = France => 'Paris', Italy => 'Rome';
```

## Як отримати елементи

Щоб отримати елемент, ви індексуєте хеш. Ви робите це так само, як із [парами](../pairs). Напишіть рядок у кутових або у фігурних дужках:

```raku
say %capitals<France>;
say %capitals{'Italy'};
```

Хеші є змінними. Це означає, що ви можете їх змінювати. Ви можете змінювати значення. Також ви можете додавати нові:

```raku
%capitals<Germany> = 'Berlin';
```

## Ключі та значення

У Raku є два вбудовані методи для хешів: `keys` і `values`. Метод `keys` повертає список ключів. Метод `values` повертає список значень:

```raku
say %capitals.keys;
say %capitals.values;
```

Програма може вивести, наприклад, таке:

    (Germany Italy France)
    (Berlin Rome Paris)

Зверніть увагу, що елементи хешу не мають порядку. Але обидва методи використовують однаковий порядок.
