Пара — це структура даних. Вона зберігає ім'я та значення. Разом вони утворюють один цілий об'єкт. Ви можете зберігати цей об'єкт у скалярній змінній. Ось як створити пару:

```raku
my $pair = name => 'Anna';
```

Змінна `$pair` має тип `Pair`:

```raku
say $pair.WHAT; # (Pair)
```

Ви можете отримати ім'я і значення окремо. Метод `key` дає ім'я. Метод `value` дає значення:

```raku
say $pair.key; # name
say $pair.value; # Anna
```

Пари мають важливу особливість. Вони незмінні. Це означає, що ви не можете дати парі нове значення. Також ви не можете дати їй нове ім'я. Звичайно, ви можете присвоїти зовсім нову пару тій самій змінній:

```raku
my $pair = name => 'Anna';
$pair = name => 'John';
say $pair.value; # John
```

## Індексування

Є ще один спосіб прочитати значення пари. Ви можете індексувати пару. Напишіть ім'я її ключа в кутових дужках. Ось як:

```raku
say $pair<name>;
```

Зверніть увагу: ключу без пробілів не потрібні лапки. Якщо в ключі є пробіли, правила трохи суворіші:

```raku
my $pair = 'employee name' => 'Julie Madelon';
say $pair{'employee name'};
```

Зверніть увагу, що цього разу код використовує фігурні дужки.
