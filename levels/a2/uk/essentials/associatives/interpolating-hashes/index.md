title: Інтерполяція хешів
---

{% include menu.html %}

Ви можете інтерполювати елементи хешу в рядках з подвійними лапками. Пишіть їх так само, як у коді програми: `%data<FR>`. Ви також можете інтерполювати весь хеш. Для цього додайте порожні кутові дужки або порожні фігурні дужки: `%data{}`. Ця програма показує, як це працює:

```raku
my %data = FR => 'Paris', IT => 'Rome';

say "%data<FR>";
say "%data<>";

# Або:
# say "%data{}";
```

Програма виводить потрібні нам дані:

```console
$ raku t.raku
Paris
FR	Paris
IT	Rome
```

Зверніть увагу: весь хеш може зайняти більше одного рядка.
