title: Запуск з командного рядка
---

Збережіть програму в текстовому файлі, наприклад, `hello.raku`. Потім передайте шлях до файлу інструменту командного рядка `raku`. Тут знак долара — це запрошення оболонки:

```console
$ raku hello.raku
```

Якщо в програмі немає помилок, вона одразу запускається. Якщо вона щось виводить, ви бачите результат у терміналі:

```console
$ raku hello.raku 
Hello, World!
```

У системах на базі Unix ви можете додати shebang. Це особливий перший рядок. Ви також можете зробити файл виконуваним:

```raku
#!/usr/bin/env raku

say 'Hello, World!';
```

Ось наступні кроки:

```console
$ chmod a+x hello.raku
$ ./hello.raku
Hello, World!
```
