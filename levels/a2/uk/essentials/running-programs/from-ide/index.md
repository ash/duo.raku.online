Цей розділ дуже короткий. Він показує, як запустити програму, не виходячи з IDE. Ми розглянемо два найбільш рекомендовані [IDE](../../editors-and-ides).

## Редактор Visual Studio Code

Відкрийте термінал з меню: `Terminal` → `New Terminal`. Під текстом вашої програми відкривається нова панель. Запустіть програму там, як з командного рядка:

```console
$ raku hello.raku
```

## Comma IDE

Щоб запустити програму, використайте пункт `Run` у меню. Перед першим запуском налаштуйте IDE. Дотримуйтесь [інструкцій](https://commaide.com/docs/running) на сайті Comma.
