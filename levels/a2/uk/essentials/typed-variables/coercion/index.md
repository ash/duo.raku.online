---
title: Перетворення типів для типізованих змінних
---

{% include menu.html %}

Обмеження типів — це правила для типів змінних. Ці правила досить суворі. Наприклад, візьміть змінну з типом `Int`. Ви не можете присвоїти їй значення `Num`. Це так, навіть якщо значення — ціле число:

```raku
my Int $x = 42;
# $x = 42e1; # Помилка
```

Щоб перетворити значення, використайте [один із методів](/uk/essentials/coercion/#topics-in-this-section).

```raku
my Int $x = 42;
$x = 42e1.Int;
$x = Int(42e1);
```
