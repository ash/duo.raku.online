---
title: Обмеження типу
---

{% include menu.html %}

У Raku так звана поступова система типів. Це означає, що ви можете використовувати типи лише там, де хочете. Зазвичай вам не треба вказувати тип змінної. Але іноді ви можете захотіти обмежити тип змінної. Тоді вкажіть тип ось так:

```raku
my Int $var = 42;
```

Тепер ви можете присвоїти змінній `$var` інше ціле значення. Але ви не можете покласти в неї рядок. Ви не можете покласти в неї навіть число з плаваючою комою. Якщо ви спробуєте, ви отримаєте виняток:

```raku
my Int $var = 42;
$var = '314E-2';
```

Програма видає таку помилку:

    Type check failed in assignment to $var; expected Int but got Str ("314E-2")
      in block <unit> at t.raku line 2
