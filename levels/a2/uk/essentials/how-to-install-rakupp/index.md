Ви можете взяти Raku++ з його сайту, [raku.online](https://raku.online). Він також є на GitHub: [github.com/ash/rakupp](https://github.com/ash/rakupp). Коли ви його встановите, ви отримаєте один файл програми: `rakupp`. Вам не треба більше нічого налаштовувати. У Raku++ немає окремої віртуальної машини для встановлення.

## Встановлювач

У macOS, Linux і системах BSD вам потрібна лише одна команда. Вона завантажує збірку для вашого комп'ютера. Вона перевіряє збірку. Потім вона додає `rakupp` до вашого `PATH`. Їй не потрібні права адміністратора:

```console
$ curl -fsSL https://raku.online/install.sh | sh
```

У Windows натомість використайте вікно PowerShell. Інший спосіб — програма встановлення, `rakupp-setup-windows-x64.exe`. Ви можете завантажити її зі сторінки випусків репозиторію. Ось команда для PowerShell:

```console
> irm https://raku.online/install-windows.ps1 | iex
```

Встановлювач питає, чи хочете ви також назву `raku` для Raku++. Після цього відкрийте новий термінал. Тоді новий `PATH` почне працювати. Пізніше `rakupp upgrade` оновить його до найновішого випуску.

## Інші способи встановлення

* У macOS, з Homebrew: `brew tap ash/rakupp && brew install rakupp`.
* З Docker вам не треба нічого встановлювати. `docker run --rm -it ghcr.io/ash/rakupp` запускає інтерактивну оболонку REPL.
* Є готові архіви для кожної платформи. Вони лежать на сторінці випусків репозиторію.
* Raku++ написано мовою C++. Тож ви можете й самі зібрати його з вихідного коду. Репозиторій каже, які інструменти вам потрібні.

## Номери версій

Яка у вас версія? Використайте опцію `--version`:

```console
$ rakupp --version
Raku++ 5.4.1 (2026-10-13) arm64-darwin
```

Рядок показує три речі. Перша — це випуск самого Raku++: `5.4.1`. Друга — це дата збірки. Третя — це платформа для цього файлу програми. Версія мови Raku — це інша річ. Ви можете запитати про неї саму мову:

```console
$ rakupp -e 'say $*RAKU.version'
v6.d
```

Порівняйте це з повідомленням про версію Rakudo. Воно є на [сторінці встановлення Rakudo](/uk/essentials/how-to-install-rakudo). Ви побачите, як два компілятори показують свої версії.
