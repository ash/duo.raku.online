Тепер ми передаємо функції деякі дані. Функція може приймати параметри. Пишіть їх у дужках одразу після назви функції.

```raku
sub greet($name) {
    say "Hello, $name!";
}
```

Тепер ви можете використовувати функцію. Ви можете передавати їй різні аргументи:

```raku
greet('Алла');
greet('Карл');
```

Ми викликаємо ту саму функцію двічі. Тепер результати різні:

```console
$ raku t.raku
Hello, Алла!
Hello, Карл!
```

%%tipblock

## Параметр чи аргумент

Люди часто вживають ці два слова однаково. Обидва слова — про «одне й те саме». Але вони дивляться на це з різних боків.

* Параметр — це те, що функція очікує отримати.
* Аргумент — це те, що ви передаєте функції.

У прикладі вище `$name` — параметр функції. `'Алла'` і `'Карл'` — її аргументи.

%%/tipblock

## Більше параметрів

Функція може приймати більше ніж один параметр. Тоді ставте між ними коми:

```raku
sub add($x, $y) {
    say $x + $y;
}

add(10, 20); # 30
```

## Без параметрів

Функція може також зовсім не мати параметрів. Тоді ви можете написати порожню пару дужок. Або ви можете не писати дужки. Ми так зробили на [початку цього розділу](../).

```raku
sub greet() {
    say 'Hello, World!';
}

greet();
```
