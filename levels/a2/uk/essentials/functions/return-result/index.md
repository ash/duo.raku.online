title: Повернення результату
---

Часто функція щось робить і ще повертає результат. Наприклад, у функціональному програмуванні функції не повинні мати побічних ефектів. Виведення на консоль — один із таких побічних ефектів. Але Raku дозволяє це робити. Давайте подивимося, як функція повертає значення. Ми також побачимо, як його отримує код, що викликає функцію.

```raku
sub add($x, $y) {
    return $x + $y;
}

my $sum = add(10, 20);
say $sum; # 30
```

Тут функція `add` приймає два числа. Вона повертає їхню суму. У коді функції є слово `return`. Код, що викликає функцію, може використовувати це значення як будь-яке інше. У програмі вище ми присвоюємо його змінній.

## Останнє значення

Результат може бути останнім значенням у тілі функції. Тоді в Raku не треба писати `return`. Тож ми можемо зробити нашу функцію `add` простішою:

```raku
sub add($x, $y) {
    $x + $y
}
```

Зверніть увагу: у кінці рядка немає крапки з комою. Цей рядок — останній у блоці коду. Тому крапка з комою там не потрібна.

Такі маленькі й прості функції часто пишуть в один рядок. Тоді код коротший:

```raku
sub add($x, $y) { $x + $y }
```

## Немає даних для повернення

Іноді з функції треба повернутися до кінця її тіла. Якщо функція не повертає результату, пишіть `return` без значення.

```raku
sub test($x) {
    return if $x <= 10;
    say "$x перевищує ліміт";
}
```
