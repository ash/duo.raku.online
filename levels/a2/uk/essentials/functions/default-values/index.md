---

Позиційні та іменовані параметри можуть мати значення за замовчуванням. Параметр зі значенням за замовчуванням не обов'язковий. Ви можете пропустити його, коли викликаєте функцію. Тоді параметр отримує своє значення за замовчуванням.

## Позиційні параметри

Ось приклад. Функція має позиційний параметр зі значенням за замовчуванням:

```raku
sub greet($name = 'World') {
    say "Hello, $name!";
}

greet('Merinda');
greet();
```

Перший виклик передає ім'я як єдиний аргумент. Тому він виводить `Hello, Merinda!`. Другий виклик використовує значення за замовчуванням. Він виводить `Hello, World!`.

Іноді функція має більше одного параметра. Тоді значення за замовчуванням мають бути в кінці списку:

```raku
sub f($a, $b, $c = 42, $d = 50) { . . . } # правильно
# sub f($a = 10, $b = 20, $c, $d) { . . . } # НЕПРАВИЛЬНО
```

## Іменовані параметри

Іменовані параметри отримують значення за замовчуванням так само:

```raku
sub greet(:$name = 'World') {
    say "Hello, $name!";
}

greet(name => 'Merinda'); # Hello, Merinda!
greet(); # Hello, World!
```

Порядок іменованих параметрів не має значення. Тому будь-який з них може мати значення за замовчуванням. Навіть перший у списку може його мати:

```raku
sub greet(:$greeting = 'Hello', :$name) {
    say "$greeting, $name!";
}

greet(name => 'Alla'); # Hello, Alla!
```
