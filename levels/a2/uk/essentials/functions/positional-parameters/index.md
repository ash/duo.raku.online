---
title: Позиційні параметри
---

{% include menu.html %}

Порядок параметрів функції важливий. Наприклад, візьмемо функцію. Вона знаходить різницю між двома числами:

```raku
sub diff($a, $b) { $a - $b }
```

Звичайно, `diff(10, 20)` і `diff(20, 10)` дають різні результати.

У функції вище параметри йдуть списком через кому. Такі параметри називаються _позиційними_. У виклику порядок аргументів важливий. Він визначає значення кожного параметра.
