_Іменовані_ параметри не такі, як [позиційні параметри](../positional-parameters). У виклику ви пишете їхні імена.

Ця функція приймає два параметри. Їхні імена — `$from` і `$to`.

```raku
sub distance(:$from, :$to) { $from - $to }
```

Щоб викликати функцію, напишіть ім'я кожного аргументу:

```raku
say distance(from => 30, to => 10); # 20
```

Не передавайте аргументи як позиційні. Це помилка. Наприклад, виклик `distance(30, 10)` дає помилку:

    Занадто багато позиційних аргументів; очікувалося 0 аргументів, але отримано 2
        в підпрограмі distance на рядку 1 у файлі t.raku
        в блоці <unit> на рядку 2 у файлі t.raku

Ось хороша новина. Ви можете писати іменовані аргументи в будь-якому порядку. Ці два виклики роблять те саме:

```raku
say distance(from => 30, to => 10); # 20

say distance(to => 10, from => 30); # 20
```

## Передача змінних

Іноді ви хочете передати значення зі змінної. Змінна має те саме ім'я, що й параметр. Тоді допомагає спеціальний синтаксис. З ним ви друкуєте менше:

```raku
my $from = 30;
my $to = 10;
say distance(:$from, :$to); # 20
```

Цей виклик робить те саме, що й довший:

```raku
say distance(from => $from, to => $to); # 20
```

І знову порядок не має значення:

```raku
say distance(:$to, :$from); # 20
```

Іноді змінна і параметр мають різні імена. Тоді передайте пару одним із цих способів:

```raku
my $a = 20;
my $b = 10;

say distance(from => $a, to => $b);

# або:

say distance(:from($a), :to($b));
```
