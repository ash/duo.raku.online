Цим розділом закінчується перша частина курсу. Після нього ви можете написати майже _будь-яку_ програму на Raku. Цей розділ — про _функції_. Функції мають також інші назви: _підпрограми_ або просто _рутини_.

Функція — це частина коду з власним ім'ям. Ви можете використовувати її багато разів. Щоб використати функцію, ви її _викликаєте_. Ви можете викликати її з різних місць програми.

## Створення функції

Щоб створити функцію, напишіть ключове слово `sub`. Після нього напишіть ім'я функції. Тіло функції помістіть у фігурні дужки.

```raku
sub greet {
    say 'Hello, World!';
}
```

## Використання функції

Щоб використати функцію, просто напишіть її ім'я. Пишіть його там, де хочете викликати функцію. У Raku ви можете створити функцію перед цим місцем. Ви також можете створити її після цього місця.

```raku
say 'This is what the first program usually prints:';
greet;    

sub greet {
    say 'Hello, World!';
}
```

Програма виведе обидва повідомлення:

```console
$ raku t.raku
This is what the first program usually prints:
Hello, World!
```

Далі дізнаймося більше про створення і використання функцій.
