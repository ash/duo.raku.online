Розширення файлу — це остання частина імені файлу. Ось [рекомендовані](https://github.com/Raku/problem-solving/blob/master/solutions/language/Path-to-Raku.md#extensions) розширення для файлів Raku:

* `.raku` для програмних файлів
* `.rakumod` для модулів
* `.rakutest` та `.t` для тестів
* `.rakudoc` для документації у форматі POD6
