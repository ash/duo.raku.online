title: Постфіксна форма `for`
---

{% include menu.html %}

Ви вже знаєте інші модифікатори операторів: [`if` та `else`](/uk/essentials/conditional-checks/modifiers) і [`while` та `until`](/uk/essentials/loops/modifiers). Це добра новина, бо Raku має дуже послідовний дизайн.

Коли тіло циклу коротке, ви можете написати `for` після нього:

```raku
.say for 1..7;
```

Діапазони виглядають дуже природно з такою формою `for`.

Ця програма робить те саме, що й більш звичайний цикл:

```raku
for 1..7 -> $n {
    say $n;
}
```

Або зі змінною циклу за замовчуванням вона робить те саме, що й ось цей код:

```raku
for 1..7 {
    .say;
}
```

Тут `.say` — це короткий спосіб написати `$_.say`.
