`$_` — це спеціальна змінна. Вона називається _topic variable_ (змінна теми).

Подивіться на цей цикл по діапазону:

```raku
for 1..5 -> $n {
    say $n;
}
```

Ви можете пропустити змінну `$n`. Тоді Raku використовує замість неї змінну `$_`. Програма робить те саме, що й ця:

```raku
for 1..5 {
    say $_;
}
```

Ви [вже знаєте](/uk/essentials/hello-world/), що `say` можна використовувати як метод:

```raku
for 1..5 {
    $_.say;
}
```

Коли ви викликаєте метод на `$_`, вам не потрібно писати змінну. Тож цикл може бути ще коротшим:

```raku
for 1..5 {
    .say;
}
```
