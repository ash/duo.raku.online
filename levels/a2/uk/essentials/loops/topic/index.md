`$_` — це спеціальна змінна. Вона називається _topic variable_ (змінна теми).

Подивіться на цей цикл по діапазону:

```raku
for 1..5 -> $n {
    say $n;
}
```

Вам не обов'язково писати `$n`. Без `$n` Raku використовує змінну `$_`. Raku створює цю змінну для вас. Тож ця програма робить те саме:

```raku
for 1..5 {
    say $_;
}
```

Ви [вже знаєте](/uk/essentials/hello-world/), що `say` може бути й методом:

```raku
for 1..5 {
    $_.say;
}
```

Метод на `$_` можна викликати без імені `$_`. Тож цикл може бути ще коротшим:

```raku
for 1..5 {
    .say;
}
```
