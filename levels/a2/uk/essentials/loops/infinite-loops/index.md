Ви також можете написати `loop` лише з тілом:

```raku
loop {
    say 'Вічність';
}
```

Цей цикл ніколи не зупиняється сам. Ви повинні зупинити програму, наприклад, за допомогою `Ctrl+C`. Друга частина курсу показує кращі способи керувати циклами.
