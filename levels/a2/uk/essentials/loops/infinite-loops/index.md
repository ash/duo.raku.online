Ви також можете використовувати `loop` лише з тілом:

```raku
loop {
    say 'Вічність';
}
```

Цей цикл працює вічно. Він зупиняється лише тоді, коли ви зупиняєте програму, наприклад, за допомогою `Ctrl+C`. У другій частині курсу ви дізнаєтеся кращі способи керувати циклами.
