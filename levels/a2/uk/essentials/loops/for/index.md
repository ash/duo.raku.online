title: Цикли `for`
---

{% include menu.html %}

Цикл `for` — це потужний інструмент. Він проходить по багатьох елементах, один за одним. Наприклад, візьмімо діапазон:

```raku
for 1..5 -> $n {
    say $n;
}
```

У цій програмі змінна `$n` щоразу отримує наступне значення з діапазону. Вам не потрібно оголошувати змінну за допомогою `my`. Блок коду виконується один раз для кожного елемента діапазону. Тож програма виводить числа, по одному в кожному рядку:

```console
$ raku t.raku 
1
2
3
4
5
```

Програма проходить по всіх значеннях [діапазону](/uk/essentials/ranges) `1..5`. Це `1`, `2`, `3`, `4` і `5`.

## Більше ніж одне значення за раз

У Raku цикл може брати більше ніж один елемент за раз. Ця програма щоразу виводить два числа:

```raku
for 1..6 -> $n, $m {
    say "$n and $m";
}
```

Ось вивід програми:

```console
$ raku t.raku
1 and 2
3 and 4
5 and 6
```
