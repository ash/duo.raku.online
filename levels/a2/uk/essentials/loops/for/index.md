Цикл `for` дуже корисний. Він проходить по багатьох елементах, по одному за раз. Наприклад, візьміть діапазон:

```raku
for 1..5 -> $n {
    say $n;
}
```

`$n` щоразу отримує наступне значення з діапазону. Вам не треба писати `my` перед `$n`. Блок виконується один раз для кожного значення з діапазону. Тож програма виводить числа, по одному в кожному рядку:

```console
$ raku t.raku 
1
2
3
4
5
```

Програма проходить по всіх значеннях [діапазону](/uk/essentials/ranges) `1..5`. Ці значення — `1`, `2`, `3`, `4` і `5`.

## Більше ніж одне значення за раз

У Raku цикл може брати два або більше елементів щоразу. Ця програма виводить по два числа за раз:

```raku
for 1..6 -> $n, $m {
    say "$n and $m";
}
```

Ось що виводить програма:

```console
$ raku t.raku
1 and 2
3 and 4
5 and 6
```
