---
title: Триопераційний цикл `loop`
---

{% include menu.html %}

Оператор `loop` у Raku схожий на класичні цикли в мові C та подібних мовах. Він приймає три вирази. Перший задає початкове значення. Другий — це тест. Третій змінює змінну циклу. Тіло циклу виконується знову і знову, поки тест є `True`.

```raku
loop (my $c = 0; $c < 5; $c++) {
    say "Поточне значення лічильника: $c.";
}
```

Тут `++` — це оператор, який стоїть після змінної. Він додає 1 до змінної. Більше операторів ви вивчите в другій частині курсу.

Програма виконує тіло циклу п'ять разів.

```console
$ raku t.raku
Поточне значення лічильника: 0.
Поточне значення лічильника: 1.
Поточне значення лічильника: 2.
Поточне значення лічильника: 3.
Поточне значення лічильника: 4.
```

Ви можете пропустити деякі або навіть усі вирази в заголовку `loop`. Наприклад, ось та сама програма:

```raku
my $c = 0;
loop (; $c < 5;) {
    say "Поточне значення лічильника: $c.";
    $c++;
}
```

## * * *

У Raku `loop` використовують не дуже часто. Ви можете побачити його, наприклад, у програмах, які інструмент переклав з C на Raku. У Raku є простіші цикли, як-от `for`. Ми дуже скоро розглянемо `for`.
