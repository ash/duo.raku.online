title: Триопераційний цикл `loop`
---

{% include menu.html %}

У Raku є оператор `loop`. Він працює як цикли в C та подібних мовах. Він має три вирази. Перший дає змінній циклу початкове значення. Другий — це тест. Третій змінює змінну циклу. Цикл працює, поки тест є `True`.

```raku
loop (my $c = 0; $c < 5; $c++) {
    say "Поточне значення лічильника: $c.";
}
```

Тут `++` — це оператор. Ви пишете його після змінної. Він додає 1 до змінної. У другій частині курсу є більше операторів.

Тіло циклу виконується п'ять разів.

```console
$ raku t.raku
Поточне значення лічильника: 0.
Поточне значення лічильника: 1.
Поточне значення лічильника: 2.
Поточне значення лічильника: 3.
Поточне значення лічильника: 4.
```

Ви можете пропустити деякі з трьох виразів у `loop`. Ви можете навіть пропустити їх усі. Наприклад, ось та сама програма:

```raku
my $c = 0;
loop (; $c < 5;) {
    say "Поточне значення лічильника: $c.";
    $c++;
}
```

## * * *

У Raku `loop` використовують не дуже часто. Іноді інструмент перекладає код з C на Raku. Ви можете побачити `loop` у такому коді. У Raku є простіші цикли, як-от `for`. Ми дуже скоро розглянемо `for`.
