---
title: Читання аргументів командного рядка
---

{% include menu.html %}

Функція `MAIN` корисна з двох причин. По-перше, вона чітко показує, де починається програма. По-друге, вона має аргументи. Вони отримують значення з командного рядка.

Є два способи читати аргументи командного рядка. Один спосіб — це [масив `@*ARGS`](/uk/essentials/positionals/args-array). Ми вже використовували його. Тепер давайте розглянемо другий спосіб.

Подивіться на цю програму. Вона додає два числа.

```raku
sub MAIN($a, $b) {
    say $a + $b;
}
```

Запустіть програму ось так. Вона виводить суму своїх двох аргументів:

```console
$ raku t.raku 123 45
168
```

Як і будь-яка інша функція, `MAIN` може мати значення за замовчуванням для своїх аргументів. Їх можуть мати деякі аргументи. Їх можуть мати навіть усі аргументи. Наприклад:

```raku
sub MAIN($a, $b = 100) {
    say $a + $b;
}
```

Іноді другого аргументу немає. Тоді програма використовує значення за замовчуванням:

```console
$ raku t.raku 15
115
```
