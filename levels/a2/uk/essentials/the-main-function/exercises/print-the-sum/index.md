## Завдання

Напишіть програму. Вона бере з командного рядка два цілі числа. Потім вона виводить їхню суму. Використайте функцію `MAIN`. Її параметри повинні мати типи.

## Приклад

Ось приклад:

```console
$ raku print-the-sum.raku 500 700
1200
```
