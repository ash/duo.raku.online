---
title: Кілька функцій `MAIN`
---

{% include menu.html %}

Як і будь-яка інша функція в Raku, `MAIN` може мати варіанти `multi`. Тож програма може по-різному реагувати на різні вхідні дані. Вхідні дані можуть мати різну кількість параметрів. Або параметри можуть мати різні типи.

```raku
multi sub MAIN($a) {
    say 2 * $a;
}

multi sub MAIN($a, $b) {
    say $a + $b;
}
```

З одним аргументом ця програма його подвоює. З двома аргументами вона їх додає:

```console
$ raku t.raku 21
42

$ raku t.raku 21 33
54
```
