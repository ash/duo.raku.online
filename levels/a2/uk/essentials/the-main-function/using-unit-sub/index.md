---
title: Використання `unit sub`
---

{% include menu.html %}

З `unit sub` решта файлу стає тілом функції! Це дуже корисно з `MAIN`. Без нього фігурні дужки стоять навколо майже всього файлу. З `unit sub` ці дужки вам не потрібні. Також рядкам не потрібні зайві пробіли на початку.

Ось приклад програми з `unit sub`.

```raku
unit sub MAIN($a, $b);

my $sum = $a + $b;
say "Сума $a та $b дорівнює $sum.";
```

У цьому файлі `MAIN` — єдина функція. У вашій програмі теж так? Тоді спробуйте використати `unit sub MAIN`, як у прикладі вище.
