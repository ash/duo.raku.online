title: Цілі числа
---

Цілі числа — це числа без дробової частини. У Raku для цілих чисел є тип даних `Int`. Ціле число може бути додатним або від'ємним. Ви також можете написати знак `+` перед числом, якщо хочете. Ось кілька простих прикладів:

```raku
42
-42
100
-5
0
```

Так, звичайний `0` теж за замовчуванням є цілим числом.

## Групи цифр

У Raku є гарна можливість для великих чисел. Цифри можна розділити на групи тисяч. Так числа легше читати:

```raku
1_000_000
-3_141_592
```

Можна також написати число на зразок `34_56`. Краще так не робити. Це може заплутати інших людей, які читають ваш код. Але не можна ставити два підкреслення поруч. І число не може починатися або закінчуватися підкресленням.

## Цілі числа будь-якої довжини

Raku чудово працює з дуже великими числами. Вони можуть виходити за межі 32 або 64 біт. Наприклад, програма нижче цілком правильна. Вона множить два великі цілі числа і виводить правильний результат.

```raku
say 1_234_456_789_012_345_678_901 * 987_654_321_098_765_432_100;
```
