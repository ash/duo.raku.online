Ми впевнені, що ви вже знаєте деякі операції з числами в Raku. Ось два слова, які варто запам'ятати. Символ _операції_ називається _оператором_. Операція працює з деякими об'єктами. Вони називаються _операндами_.

## Арифметика

**Оператор** | **Операція**
`+` | Додавання
`-` | Віднімання
`*` | Множення
`/` | Ділення

Raku дуже добре [підтримує Unicode](/uk/essentials/on-unicode). Тому деякі з цих операторів мають ще одну форму з не-ASCII символами:

`×` | Множення
`÷` | Ділення

Використовуйте дужки, щоб змінити порядок операцій:

```raku
say 3 * 4 + 5;   # 17
say 3 * (4 + 5); # 27
```

## Модуль

Оператор модуля — це `%`. У багатьох інших мовах він такий самий.

`%` | Модуль

Він дає залишок від цілочисельного ділення двох чисел. Залишок — це те, що лишається після ділення. Тому `10 % 3` дорівнює `1`. Але зверніть увагу: `-10 % 3` дорівнює `2`. Ось чому. Поділіть перше число на друге. Округліть результат вниз. Помножте його на друге число. Потім відніміть це від першого числа. Це і є результат `%`. Тож `$a % $b` — те саме, що `$a - $b * floor($a / $b)`.

## Кратність

У Raku також є корисний оператор для подільності чисел. Він перевіряє, чи ділиться одне число на інше. Це означає, що залишку немає.

`%%` | Кратність

Це інфіксний оператор. Він стоїть між двома операндами: `10 %% 3`. Перший операнд ділиться на другий? Тоді результат — булеве значення `True`. Якщо ні, результат — `False`.

## Цілі операції

Деякі спеціальні операції дають у результаті цілі числа. Їхні оператори — це слова, а не символи.

`div` | Ціле ділення
`mod` | Цілий модуль

Оператор `div` округлює результат вниз. Тому `10 div 3` дорівнює `3`. А `-10 div 3` дорівнює `-4`.

І `div`, і `mod` потребують цілих операндів. Подивіться на рядки з позначкою `Error` у програмі нижче. Якщо прибрати з них `#`, програма не працює:

```raku
say 10.3 % 3;     # OK
# say 10.3 mod 3; # Error

say 10.3 / 3.3;     # OK
# say 10.3 div 3.3; # Error
```

## Степінь

Є два способи піднести _x_ до степеня _y_. Перший спосіб — оператор `**`:

```raku
say 3 ** 4; # 81
```

Другий спосіб — використати надрядкові цифри. Це маленькі цифри вгорі рядка. Наприклад:

```raku
say 3⁴; # 81
```

Можна також використати дві або більше надрядкових цифр. Тоді степінь може бути більшим за 9. Наприклад:

```raku
say 2¹⁵; # 32768
```

Від'ємний степінь теж працює:

```raku
say 2 ** (-2); ## 0.25
say 2⁻²; # 0.25
```

Зверніть увагу: останні два вирази дають число типу `Rat`.

## Операції з присвоєнням

Іноді потрібно оновити змінну за допомогою операції. Усі операції мають для цього коротку форму. Ось приклад із `+`.

Повна форма

```raku
$a = $a + $b;
```

це те саме, що:

```raku
$a += $b;
```
