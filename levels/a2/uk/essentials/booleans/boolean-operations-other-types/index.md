Наступний розділ — про [зміну даних з одного типу на інший](/uk/essentials/coercion). Але спершу подивіться на одну важливу особливість Raku. Ви можете застосовувати булеві операції до рядків або цілих чисел. Тоді Raku не змінює ці значення на булеві. Результат теж не є булевим значенням. Подивіться на ці приклади:

```raku
say 'Hello' && 'World'; # World
say 'Alpha' || 'Beta';  # Alpha
say 0 ^^ 42;            # 42
```

Ось правила 📖 [з документації](https://docs.raku.org/language/operators#Tight_AND_precedence):

* `&&` повертає перше значення, яке для Raku є False. Якщо такого значення немає, він повертає останнє значення.
* `||` повертає перше значення, яке для Raku є True. Якщо такого значення немає, він повертає останнє значення.
* `^^` повертає значення, яке є True, якщо таке значення лише одне. Якщо всі значення False, він повертає останнє значення. Якщо значень True більше одного, він повертає `Nil`.

Тут ми бачимо нове значення, `Nil`. Це значення «null».
