З булевими значеннями можна робити всі звичайні операції. Це булеве І (AND), АБО (OR) та виключне АБО. Виключне АБО також називають XOR:

```raku
say False && True; # AND
say False || True; # OR
say False ^^ True; # XOR
```

Програма виводить ось що:

    False
    True
    True

## Заперечення

Заперечення дає протилежне булеве значення. Для заперечення використовуйте префіксний оператор `!`. Префіксний оператор стоїть перед значенням:

```raku
say !False; # True
```

Скалярна змінна може зберігати булеве значення:

```raku
my $did = True;
my $didn't = !$did;
```
