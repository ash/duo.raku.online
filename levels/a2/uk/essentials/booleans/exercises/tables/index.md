## Завдання

Напишіть програму. Вона застосовує три булеві операції до всіх пар `True` і `False`. Вона виводить результат кожної операції.

## Приклад

Ось частина виводу.

```console
$ raku tables.raku
True && True is True
True && False is False
. . .
```
