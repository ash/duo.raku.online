Функції в Raku здебільшого легко використовувати. Зазвичай вони не створюють проблем. Але з однією річчю будьте обережні.

## Коротко

Не пишіть пробіл між назвою функції та дужками. У дужках стоять аргументи. Але після `for` та `if` пробіл ставте.

## Детально

Ось проста функція:

```raku
sub f($x, $y) {
    return $x + $y;
}
```

Спочатку подивіться на назву функції. Відкривна дужка йде одразу після неї, без пробілу. Параметри стоять у цих дужках. Деякі стилі коду в інших мовах вимагають там пробіл. Raku теж це приймає. Але це не добрий спосіб писати код:

```raku
sub f ($x, $y) {
    return $x + $y;
}
```

У виклику функції відсутність пробілу важлива. Іноді ви викликаєте функцію без дужок. Тоді ви маєте поставити пробіл після назви функції:

```raku
f 5, 6;
```

Але з дужками пробілу перед ними бути не повинно. Цей виклик правильний:

```raku
f(5, 6);
```

А цей виклик неправильний:

```raku
f (5, 6);
```

Цей код викликає виняток:

    Too few positionals passed; expected 2 arguments but got 1
      sub f at t.raku line 1
      in block <unit> at t.raku line 5

Подивіться на виклик із пробілом: `f (5, 6)`. Raku думає, що ви передаєте функції один аргумент. Цей аргумент — `(5, 6)`. Ви легко можете перевірити тип цього аргументу. Змініть функцію. Вона має приймати лише один аргумент:

```raku
sub f($param) {
    say $param.WHAT;
}

f (5, 6); # (List)
```

Отже, виклик `f (5, 6)` передає функції [список](/uk/essentials/positionals/lists). Увесь список — це один аргумент.

## Коли вам потрібен пробіл

Іноді пробіл потрібен. Це буває, коли ви ставите дужки після ключового слова. Наприклад, ключове слово може бути `if`, `for` або `loop`. Цей код неправильний:

```raku
if(True != False) {
    say 'OK';
}
```

Повідомлення про помилку каже, що не так:

    ===SORRY!===
    The word 'if' is interpreted as a 'if()' function call.  Please use
    whitespace instead of parentheses.
    at /Users/ash/raku-course/t.raku:1
    ------> if⏏(True != False) {
    Unexpected block in infix position (two terms in a row)
    at /Users/ash/raku-course/t.raku:1
    ------> if(True != False)⏏ {

З `if` дужки взагалі не потрібні. Без них ця проблема не може статися. Але іноді дужки потрібні, наприклад, з `loop`. Тоді ви маєте поставити пробіл:

```raku
loop(my $c = 0; $c != 10; $c++) { say $c }
```

У цьому коді відбувається те саме. Компілятор думає, що `loop(...)` — це виклик функції. Додайте пробіл, щоб виправити проблему. Або, краще, напишіть цей код із `for`.

## Висновок

Отже, ось головне. Не ставте пробіл між назвою функції та її дужками. Тоді ви уникнете таких проблем. Також намагайтеся не ставити дужки в інших місцях, коли можна. Наприклад, з `if` і `for` вони не потрібні.
