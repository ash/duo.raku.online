---
title: Локальні змінні
---

{% include menu.html %}

Тепер ви створюєте змінну в глобальній області видимості. Ви також створюєте її локально, всередині блоку. Що тоді станеться?

```raku
my $x = 1;

{
    my $x = 42;
    say $x;
}

say $x;
```

Тепер у програмі є дві змінні. Вони мають однакове ім'я. Але це різні змінні. У глобальній області видимості кожен `$x` — це глобальна змінна. Усередині блоку `$x` — це локальна змінна. Це не глобальна `$x`. Програма виводить два різні значення:

```console
$ raku t.raku
42
1
```
