Блок коду — це частина вашої програми. Він стоїть у парі фігурних дужок: `{` і `}`. У блоці є кілька операторів. Вони працюють разом, як один великий оператор. Наступні розділи покажуть багато способів використати блоки.

```raku
{
    say 'Hello, World!';
}
```

Цій програмі блок коду насправді не потрібен. Але блоки коду дуже корисні в інших випадках. Ми скоро їх розглянемо.

Але спочатку давайте подивимося на ідею _області видимості_. Область видимості показує, де можна використати змінну.
