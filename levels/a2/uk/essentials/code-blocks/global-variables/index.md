title: Глобальні змінні
---

{% include menu.html %}

Тепер створимо змінну перед блоком коду:

```raku
my $x = 1;

{
    $x = 42;
    say $x;
}

say $x;
```

Тут `$x` — глобальна змінна. Вона знаходиться в глобальній області видимості. Її може використовувати вся програма. Програма виводить `42` два рази.
