---
title: Лексична область видимості
---

{% include menu.html %}

Блок коду створює лексичний обсяг. Що це означає? Ви створюєте змінну в блоці. Вона видима всередині цього блоку. Потім програма виходить з блоку. Після цього змінна вже не видима. Подивіться на приклад:

```raku
{
    my $x = 42;
    say $x;
}

say $x;
```

Змінна `$x` створюється в блоці коду. Перший `say $x` стоїть усередині блоку. Там змінна видима. Тому `say` виводить її значення. Другий `say $x` не працює. Поза блоком імені `$x` не існує. Після кінця блоку програма його не знає. Програма не компілюється. Ви отримуєте помилку:

    ===SORRY!=== Error while compiling /Users/ash/raku-course/t.raku
    Variable '$x' is not declared
    at /Users/ash/raku-course/t.raku:6
    ------> say ⏏$x;
