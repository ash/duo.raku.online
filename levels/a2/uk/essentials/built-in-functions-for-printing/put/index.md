Процедура `put` працює як [`print`](../print). Але за замовчуванням вона додає в кінці новий рядок:

1. Перетворює свої аргументи на рядок. Для цього вона викликає на них метод `Str`.
1. Додає символ нового рядка.
1. Відправляє рядок до потоку `STDOUT`.

Кілька прикладів:

```raku
42.put;
put 'Alpha', 'Beta';

my @array = 3, 4, 5;
put @array;

my %hash = a => 'b', c => 'd';
%hash.put;
```

Ось вивід програми:

```console
$ raku t.raku
42
AlphaBeta
3 4 5
a	b
c	d
```

%%tipblock
## Новий рядок у `put`

Які символи `put` додає після виводу? Вона бере їх з методу `nl-out` вихідного потоку. Значення за замовчуванням — `\n`.
%%/tipblock
