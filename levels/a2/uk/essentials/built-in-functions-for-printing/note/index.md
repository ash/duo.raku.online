title: '`note`'
---

{% include menu.html %}

Рутинна функція `note` виводить свої аргументи в стандартний потік помилок. В усьому іншому `note` схожа на [`say`](../say).

1. Викликає метод `gist` на своїх аргументах.
1. Додає символ нового рядка.
1. Конвертує результат в UTF-8.
1. Відправляє його в потік `STDERR`.

```raku
my $x = 42;
note "Current value of \$x is $x";
```

Ця програма не відправляє повідомлення в `STDOUT`. Перевірте це:

```
$ raku t.raku > /dev/null
Current value of $x is 42
```

Ви можете викликати `note` без аргументів. Тоді вона виводить повідомлення за замовчуванням, `Noted`.
