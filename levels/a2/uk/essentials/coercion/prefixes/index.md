---
title: Перетворення типів за допомогою префіксних операторів
---

{% include menu.html %}

Ви також можете змінити тип об'єкта префіксними операторами. Кожен такий оператор — це лише один символ. Ви ставите його прямо перед значенням або змінною.

`~` | Перетворює на рядок
`+` | Перетворює на число
`?` | Перетворює на логічне значення

Ось приклад. Він створює логічне значення з цілого числа:

```raku
say ?42; # True
```

Перетворення на рядок працює так само:

```raku
my $n = -30;
my $s = ~$n;
say $s.chars; # 3, оскільки "-30" має 3 символи
```

Зверніть увагу на одну річ при перетворенні на число. Тип результату може бути різним. Він залежить від числа. Порівняйте ці перетворення з рядків:

```raku
say (+'100').WHAT;   # (Int)
say (+'3.14').WHAT;  # (Rat)
say (+'27E-1').WHAT; # (Num)
```

Щоб перетворити на логічне значення, можна також використати `so`. Ви можете використати його як префіксний оператор. Або ви можете використати його як метод:

```raku
my $value = 42;
say so $value; # True
say $value.so; # True
```
