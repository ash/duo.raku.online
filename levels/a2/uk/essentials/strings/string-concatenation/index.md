Ви можете з'єднати два рядки разом. Тоді ви отримаєте новий, довший рядок. Ми називаємо це конкатенацією рядків. У Raku ви конкатенуєте рядки за допомогою оператора. Вгадаєте, як він називається? Це оператор конкатенації! Цей оператор — тильда: `~`. Щоб конкатенувати два рядки, поставте `~` між ними:

```raku
say 'Hello, ' ~ 'World!';
```

Іноді рядки зберігаються у змінних. Тоді ми можемо ‘конкатенувати змінні’. Ну, насправді ми конкатенуємо рядки в цих змінних:

```raku
my $greeting = 'Hello, ';
my $who = 'World!';

say $greeting ~ $who;
```

Ви також можете покласти результат у нову змінну:

```raku
my $greeting = 'Hello, ';
my $who = 'World!';
my $message = $greeting ~ $who;

say $message;
```

## Конкатенація і присвоєння за один крок

Іноді ви хочете додати рядок у кінець змінної. Тоді використовуйте таку форму:

```raku
# Замість 
$str = $str ~ $another-str;

# використовуйте:
$str ~= $another-str;
```
