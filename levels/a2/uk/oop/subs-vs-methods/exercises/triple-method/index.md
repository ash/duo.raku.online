## Завдання

Тепер розв'яжіть те саме завдання **методом**. Створіть клас `Number`. Він має атрибут `n` і метод `triple`. Метод повертає `n`, помножене на три. Створіть `Number`, у якого `n` дорівнює `7`. Викличте для нього `triple` і виведіть результат.

## Приклад

Програма виводить:

```
21
```
