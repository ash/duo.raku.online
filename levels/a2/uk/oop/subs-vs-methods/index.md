Тепер ви знаєте два способи зібрати кілька дій разом. Один спосіб — _підпрограма_. Другий — _метод_. Вони схожі на вигляд. Але ви використовуєте їх по-різному.

Підпрограма стоїть окремо. Вона нічому не належить. Ви викликаєте її за іменем. Ви передаєте їй усе потрібне як аргументи:

```raku
sub area-of($radius) {
    π * $radius * $radius;
}

say area-of(2); # 12.566370614359172
```

Метод належить класу. Він як функція всередині класу. Ви викликаєте метод для об'єкта, через крапку. Об'єкт — це значення класу. Метод може використовувати дані свого об'єкта. Для цього він має `self` та аксесори атрибутів. Тож ці дані йому не треба передавати:

```raku
class Circle {
    has $.radius;

    method area {
        π * $.radius * $.radius;
    }
}

say Circle.new(radius => 2).area; # 12.566370614359172
```

Обидва дають те саме число. Різниця в тому, звідки беруться дані. Підпрограма отримує радіус як аргумент. Метод читає радіус зі свого об'єкта. Це об'єкт, для якого ви його викликаєте.

Ось просте правило. Код стоїть окремо й працює лише зі своїми аргументами? Тоді використайте підпрограму. Код належить об'єкту й працює з його даними? Тоді використайте метод. Код належить класу, але не одному об'єкту? Тоді використайте методи класу.
