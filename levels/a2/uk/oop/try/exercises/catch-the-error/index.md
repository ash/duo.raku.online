## Завдання

Покажіть обидві сторони `try`. Блок `try` перехоплює помилки у своєму коді. Спочатку покладіть обчислення в блок `try`. Обчислення має спрацювати, наприклад `6 * 7`. Виведіть його результат. Потім покладіть код із `die 'broken'` у другий блок `try`. Виведіть, чи дав цей блок визначений результат. Також виведіть повідомлення перехопленого винятку.

## Приклад

Програма виводить:

```
42
False
broken
```
