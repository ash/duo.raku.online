## Завдання

Коли блок `try` не спрацьовує, його значення невизначене. Використайте це з оператором «визначене або» `//`. Через `//` можна дати запасне значення для цього випадку. Виконайте блок `try` з `die 'no'` усередині. Якщо блок не спрацює, використайте натомість рядок `default`. Виведіть результат.

## Приклад

Програма виводить:

```
default
```
