## Завдання

Напишіть підпрограму `reciprocal`. Вона повертає `1`, поділену на свій аргумент. Але якщо аргумент дорівнює `0`, вона використовує `fail`. Повідомлення — `no reciprocal of zero`.

Виведіть результат `reciprocal(4)`. Потім виведіть результат `reciprocal(0)`. Не перевіряйте тут `.defined` самі. Натомість використайте оператор `//`. Якщо виклик не спрацьовує, `//` дає рядок `undefined`.

## Приклад

Програма виводить:

```
0.25
undefined
```
