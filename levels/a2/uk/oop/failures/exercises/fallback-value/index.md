## Завдання

Напишіть підпрограму `get`. Вона повертає свій аргумент. Але якщо аргумент дорівнює `0`, вона викликає `fail`. Повідомлення — `bad`.

Виведіть результат `get(5)`. Потім виведіть результат `get(0)`. Використайте оператор «визначене або» `//` із запасним значенням `default`. Оператор `//` дає це значення, коли результат невизначений.

## Приклад

Програма виводить:

```
5
default
```
