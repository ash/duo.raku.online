У [розділі про контейнери](/uk/advanced/containers) ви користувалися `.^name`. З ним ви питали значення про його тип. Ті самі метавиклики `.^` працюють і з класами та об'єктами. З ними можна побачити їхні імена та атрибути. Також можна побачити їхнє місце в дереві класів.

Метаметод — це метод, який ви викликаєте через `.^`. Метаметод `.^name` повертає ім'я класу:

```raku
class Dog {
    has Str $.name;
    method bark { 'Woof' }
}

say Dog.^name; # Dog
```

Метаметод `.^attributes` перелічує атрибути класу. Для кожного атрибута ви бачите його тип. Ви також бачите його внутрішнє приватне ім'я. Це форма `$!`. Ви бачили її в темі про [приватні атрибути](/uk/oop/methods/private-attributes):

```raku
say Dog.^attributes; # (Str $!name)
```

Інтроспекція означає, що ви питаєте об'єкт про нього самого. Вона корисна для інструментів, які працюють з будь-якими об'єктами. Наприклад, інструмент може вивести кожен атрибут об'єкта. Йому не треба спершу знати клас цього об'єкта. Наступна тема — про ланцюжок успадкування класу. Це лінія його батьківських класів.
