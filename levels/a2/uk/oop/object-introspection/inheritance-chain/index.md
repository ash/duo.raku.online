Один клас може успадковувати від іншого класу. Тоді можна запитати весь ланцюжок типів. Клас побудований на цих типах. Метаметод `.^mro` повертає цей ланцюжок. Назва означає _method resolution order_, тобто «порядок розв'язання методів». У такому порядку Raku шукає метод.

```raku
class Animal {
}

class Dog is Animal {
}

say Dog.^mro; # ((Dog) (Animal) (Any) (Mu))
```

Читайте список зліва. Спершу `Dog` — це він сам. Потім він — `Animal`, його батько. Потім він — `Any` та `Mu`. Кожен об'єкт Raku успадковує від цих двох типів. Вони на самій вершині. Коли ви викликаєте метод для `Dog`, Raku шукає в цьому списку. Він іде зліва направо. Він бере перший метод, який підходить. Це пояснює перевизначення. Дитина стоїть у ланцюжку раніше. Тож її метод перемагає метод батька.

Іноді клас не має батька з `is`. Тоді ланцюжок коротший. У ньому лише сам клас, а потім `Any` та `Mu`.
