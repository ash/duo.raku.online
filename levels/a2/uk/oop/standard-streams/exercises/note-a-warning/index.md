## Завдання

Програма працює зі значенням. Значення від'ємне. Якщо значення менше за нуль, надішліть попередження у стандартний потік помилок. Використайте для цього `note`. Потім надішліть справжній результат у стандартний вивід через `say`. Результат — це абсолютне значення числа. Це число без знака мінус. Візьміть значення `-3`.

## Приклад

Ви бачите обидва рядки на екрані:

```
Warning: the value is negative
3
```

Тут ми відкидаємо стандартний потік помилок. Лишається тільки результат:

```
$ raku note-a-warning.raku 2>/dev/null
3
```
