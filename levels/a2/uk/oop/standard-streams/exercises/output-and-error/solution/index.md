Ось один спосіб розв'язати задачу.

## Код

```raku
my @data = 3, 5, 7;

my $sum = 0;
for @data -> $n {
    $sum += $n;
    $*ERR.say("running total: $sum");
}

$*OUT.say($sum);
```

🦋 Вихідний код можна знайти у файлі [output-and-error.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/standard-streams/output-and-error.raku).

## Вивід

Ви бачите на екрані обидва потоки. Спочатку йдуть накопичені суми, потім остаточний результат:

```
running total: 3
running total: 8
running total: 15
15
```

Тут ми відкидаємо стандартний потік помилок. Лишається тільки справжній вивід:

```
$ raku output-and-error.raku 2>/dev/null
15
```

## Коментарі

1. `$*OUT` — це дескриптор стандартного виводу. `$*ERR` — це дескриптор стандартного потоку помилок. Кожен із них має власний метод `say`.

1. Кожен прохід циклу додає наступне число. Потім він пише накопичену суму в `$*ERR`. Лише остаточна сума йде в `$*OUT`. На екрані прогрес і результат виглядають однаково. Але вони йдуть різними потоками. `2>/dev/null` прибирає стандартний потік помилок. Тож лишається тільки остаточне `15`.
