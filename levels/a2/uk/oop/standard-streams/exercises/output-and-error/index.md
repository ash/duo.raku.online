## Завдання

Програма в циклі додає числа зі списку `3, 5, 7`. На кожному проході надсилайте суму на цей момент у стандартний потік помилок. Це накопичена сума. Це повідомлення про прогрес. Після циклу надішліть остаточний результат у стандартний вивід. Використовуйте дескриптори потоків напряму.

Чому це важливо? Результат можна зберегти або передати іншій програмі. Повідомлення про прогрес лишаються у стандартному потоці помилок. Там вони не заважають.

## Приклад

Запустіть програму. Ви бачите на екрані обидва потоки. Спочатку йдуть накопичені суми, потім остаточний результат:

```
running total: 3
running total: 8
running total: 15
15
```

А тепер ми відкидаємо стандартний потік помилок. Лишається тільки справжній результат:

```
$ raku output-and-error.raku 2>/dev/null
15
```
