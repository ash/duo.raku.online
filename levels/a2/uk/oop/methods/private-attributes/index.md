У [розділі про атрибути](/uk/oop/attributes) кожен атрибут мав `$.` в імені. `$.` створює публічний аксесор. Будь-хто поза об'єктом може ним користуватися. Але замість цього можна написати `$!`. Тоді атрибут _приватний_. Він не має аксесора. Код поза об'єктом його не бачить. Лише методи класу можуть ним користуватися. Там ви пишете його як `$!name`.

```raku
class Safe {
    has $!code = 4321;

    method unlocks($attempt) {
        return $attempt == $!code;
    }
}

my $safe = Safe.new;
say $safe.unlocks(4321); # True
say $safe.unlocks(1111); # False
```

Таємний `$!code` лежить усередині об'єкта. Але ніхто ззовні його не бачить. Аксесора `.code` немає. Єдиний спосіб використати код — метод `unlocks`. Клас дає вам цей метод навмисно. Прочитати `$safe.code` чи `$safe!code` просто не вийде.

Приватні атрибути добрі для деталей усередині об'єкта. Решта програми не має чіпати їх напряму.
