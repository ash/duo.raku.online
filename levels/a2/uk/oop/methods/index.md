Атрибути дають об'єкту дані. З _методами_ об'єкт може ще й щось робити. Метод — це підпрограма в класі. Ви викликаєте метод для об'єкта. Щоб створити метод, напишіть ключове слово `method`:

```raku
class Dog {
    has $.name;

    method bark {
        return $.name ~ ' says Woof!';
    }
}
```

Щоб викликати метод для об'єкта, поставте крапку. Це так само, як з аксесором:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.bark; # Rex says Woof!
```

Усередині методу `self` — це об'єкт. Це той об'єкт, для якого ви викликали метод. До атрибутів ви дістаєтеся через їхні аксесори. Ви пишете їх як `$.name`, `$.age` тощо. Їх також можна вживати всередині рядка з подвійними лапками:

```raku
class Dog {
    has $.name;

    method greet {
        "Hello, my name is $.name";
    }
}

say Dog.new(name => 'Rex').greet; # Hello, my name is Rex
```

Наступні теми розповідають про три речі. Перша — приватні атрибути. Для них потрібні методи, і тепер у вас є методи. Друга — методи з параметрами. Третя — методи, які викликають інші методи.
