Метод може мати параметри, як підпрограма. Напишіть їх у круглих дужках після імені методу:

```raku
class Account {
    has $.balance is rw = 0;

    method deposit($amount) {
        $.balance += $amount;
    }
}
```

Метод `deposit` має один параметр, `$amount`. Він додає цю суму до балансу об'єкта:

```raku
my $a = Account.new;
$a.deposit(100);
$a.deposit(50);
say $a.balance; # 150
```

Кожен виклик працює з одним об'єктом. Це той об'єкт, для якого ви викликаєте метод. Тож один метод може змінювати різні об'єкти. Один об'єкт не змінює інших. Методи можуть мати позиційні та іменовані параметри. Вони також можуть мати типові значення. Усе інше із сигнатур підпрограм тут теж працює.
