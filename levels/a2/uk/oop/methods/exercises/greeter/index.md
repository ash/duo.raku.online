## Завдання

Створіть клас `Word` з атрибутом `text`. Дайте йому метод `reversed`. Цей метод повертає текст слова задом наперед. Підказка: метод `flip` перевертає рядок.

Створіть слово з текстом `Raku`. Виведіть цей текст задом наперед.

## Приклад

Програма виводить:

```
ukaR
```
