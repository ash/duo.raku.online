Порожній клас не дуже корисний. Об'єктові потрібні власні дані. Для цього ви даєте класу _атрибути_. Атрибут — це частина даних усередині об'єкта. Щоб створити атрибут, напишіть ключове слово `has` усередині класу:

```raku
class Dog {
    has $.name;
    has $.age;
}
```

Кожен об'єкт отримує власну копію цих атрибутів. Ви даєте їм значення, коли створюєте об'єкт. Передайте значення до `new` як іменовані аргументи:

```raku
class Dog {
    has $.name;
    has $.age;
}

my $rex = Dog.new(name => 'Rex', age => 3);
```

Подивіться на `$.` у `has $.name`. Він робить дві речі. По-перше, він створює атрибут. По-друге, він створює метод із тим самим ім'ям. Цей метод повертає значення атрибута. Такий метод називають _аксесором_:

```raku
say $rex.name; # Rex
say $rex.age;  # 3
```

Різні об'єкти зберігають власні значення. Вони не мають спільних значень:

```raku
my $rex  = Dog.new(name => 'Rex',  age => 3);
my $fido = Dog.new(name => 'Fido', age => 5);

say $rex.name;  # Rex
say $fido.name; # Fido
```

Наступні теми показують дві речі. Спочатку ви створюєте атрибути, які можна змінювати. Потім ви даєте атрибутам типові значення. Є також спосіб створити _приватні_ атрибути. Код поза об'єктом їх не бачить. Ми повернемося до них після методів.
