За замовчуванням аксесор із `has $.name` доступний _лише для читання_. Конструктор дає атрибуту значення. Конструктор — це метод, який створює об'єкт, тут це `new`. Після цього код поза об'єктом може читати значення. Але він не може його змінити. Спробуйте присвоїти йому нове значення. Це дає помилку:

```raku
class Dog {
    has $.name;
}

my $rex = Dog.new(name => 'Rex');
$rex.name = 'Max';
```

Програма зупиняється з такою помилкою:

```
Cannot modify an immutable Str (Rex)
```

Хочете змінювати значення через аксесор? Тоді позначте атрибут трейтом `is rw`:

```raku
class Dog {
    has $.name is rw;
}

my $rex = Dog.new(name => 'Rex');
$rex.name = 'Max';
say $rex.name; # Max
```

Тепер аксесор повертає контейнер, у який можна записувати. Тож присвоєння працює. Тепер `name` об'єкта — це `Max`.
