Атрибут може мати _типове значення_. Іноді ви створюєте об'єкт без значення для цього атрибута. Тоді Raku бере типове значення. Запишіть типове значення після атрибута, через `=`:

```raku
class Dog {
    has Str $.name;
    has Rat $.weight = 4.0;
}
```

Зверніть увагу ще на одне. Ви можете дати атрибуту тип, як і змінній. Тоді значення має бути цього типу.

Тут `new` не отримує `weight`. Тому атрибут отримує типове значення:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.weight; # 4
```

Але ви все одно можете дати своє значення. Воно замінює типове:

```raku
my $lighty = Dog.new(name => 'Lighty', weight => 3.2);
say $lighty.weight; # 3.2
```

Іноді атрибут не має типового значення. Ви також не передаєте значення для нього до `new`. Тоді атрибут просто невизначений. Він як нова скалярна змінна.
