## Завдання

Створіть два порожні класи, `Cat` та `Dog`. Потім створіть екземпляр `Cat` з ім'ям `$felix`. Виведіть тип `$felix` за допомогою `WHAT`. Потім виведіть ще два рядки. Використайте в них оператор `===`. Перший рядок показує, чи цей тип такий самий, як `Cat`. Другий рядок показує, чи він такий самий, як `Dog`.

## Приклад

Програма виводить:

```
(Cat)
True
False
```
