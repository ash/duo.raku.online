## Завдання

Створіть два порожні класи, `Cat` та `Dog`. Потім напишіть цикл по чотирьох значеннях: `Cat`, `Dog`, `Cat.new` та `Dog.new`. Для кожного значення виведіть, чи воно визначене. Подивіться на результат. Два об'єкти типу невизначені. Два екземпляри визначені. Клас тут не важливий.

## Приклад

Програма виводить:

```
False
False
True
True
```
