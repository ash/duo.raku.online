Ви можете написати ім'я класу, наприклад `Dog`. Це ім'я означає _об'єкт типу_ цього класу. Об'єкт типу представляє сам тип. Це не один з об'єктів цього типу. З _екземпляром_ усе інакше. Ви створюєте його через `new`. Це справжній об'єкт.

Raku бачить різницю між ними. Метод `defined` повертає `False` для об'єкта типу. Він повертає `True` для екземпляра:

```raku
class Dog {
}

say Dog.defined;     # False
say Dog.new.defined; # True
```

Об'єкт типу не має справжніх даних. Він лише описує тип. Тому Raku каже, що він _невизначений_. Екземпляр — це справжній об'єкт. Тому він _визначений_.

`WHAT` показує для обох той самий тип. Ви бачили `WHAT` у [розділі про контейнери](/uk/advanced/containers):

```raku
class Dog {
}

say Dog.WHAT;     # (Dog)
say Dog.new.WHAT; # (Dog)
```

Raku показує тип у круглих дужках, як `(Dog)`. Тож `Dog` і `Dog.new` мають той самий тип, `Dog`. Але це різні речі. `Dog` — це сам тип. `Dog.new` — це об'єкт цього типу.
