Досі ви використовували лише типи, які вже є в Raku. Це числа, рядки, масиви тощо. З _об'єктно-орієнтованим програмуванням_ ви можете створювати власні типи. Такий тип називають _класом_. Значення такого типу називають _об'єктом_.

Щоб створити клас, напишіть ключове слово `class`. Після нього напишіть ім'я та блок:

```raku
class Dog {
}
```

Цей клас `Dog` поки що порожній. Але це вже новий тип. Об'єкт класу ще називають _екземпляром_. `new` — це метод. Щоб створити екземпляр, викличте його для імені класу:

```raku
class Dog {
}

my $rex = Dog.new;
say $rex; # Dog.new
```

Тепер у змінній `$rex` є об'єкт `Dog`. Кожен виклик `new` створює новий, окремий об'єкт:

```raku
my $rex = Dog.new;
my $fido = Dog.new;
```

`$rex` і `$fido` — два різні пси. Клас ще порожній, але пси різні. У наступних розділах ви даєте класу власні дані. Ці дані називають _атрибутами_. Клас також отримує власну поведінку, тобто дії. Ці дії називають _методами_. Перша тема уважніше розглядає клас і його екземпляри. Вона показує, чим вони різні.
