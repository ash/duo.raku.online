Читати чи записувати весь файл за раз легко. Але іноді ви хочете пройти файл рядок за рядком. Або ви хочете писати у файл багато разів. Увесь цей час файл має бути відкритим. Для цього ви використовуєте _дескриптор файлу_. Дескриптор файлу — це об'єкт для відкритого файлу. Через нього ви читаєте з файлу або пишете в нього.

Ось найпростіший спосіб читати файл рядок за рядком. Вам навіть не треба самим створювати дескриптор. Викличте метод `lines` для об'єкта шляху. Він дає вам рядки один за одним. Вони готові для циклу `for`:

```raku
spurt 'words.txt', "one\ntwo\nthree\n";

for 'words.txt'.IO.lines -> $line {
    say $line.uc;
}
```

Кожен `$line` — це один рядок. У його кінці немає символу нового рядка. Програма виводить:

```
ONE
TWO
THREE
```

Через дескриптор можна також писати у файл. Спочатку відкрийте файл за допомогою `open` із прапорцем `:w`. Цей прапорець означає запис. Потім використовуйте методи `say` або `print` дескриптора. Наприкінці закрийте його через `close`:

```raku
my $fh = open 'out.txt', :w;
$fh.say('first line');
$fh.say('second line');
$fh.close;
```

Наприкінці закрийте дескриптор. Тоді всі ваші дані справді потраплять на диск. Деякі файли завеликі для пам'яті. Їх не можна прочитати цілком за раз. Такі файли зазвичай читають рядок за рядком, як вище.
