## Завдання

Запишіть чотири рядки у файл з ім'ям `data.txt`. Рядки такі: `a`, `b`, `c` і `d`. Кожен із них стоїть на своєму рядку. Потім виведіть кількість рядків у файлі.

## Приклад

Програма виводить:

```
4
```
