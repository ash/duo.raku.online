## Завдання

Відкрийте файл з ім'ям `out.txt` для запису. Тримайте дескриптор відкритим. Запишіть у нього числа `1`, `2` і `3` у циклі. Кожне число має бути на своєму рядку. Потім закрийте дескриптор. Прочитайте файл і виведіть його вміст.

## Приклад

Програма виводить:

```
1
2
3
```
