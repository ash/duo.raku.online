## Завдання

Запишіть три слова у файл з ім'ям `words.txt`. Слова такі: `apple`, `banana` і `cherry`. Кожне слово стоїть на своєму рядку. Потім прочитайте файл рядок за рядком. Виведіть кожен рядок із його номером попереду. Номери починаються з `1`. Використайте таку форму: `<номер>: <рядок>`.

## Приклад

Програма виводить:

```
1: apple
2: banana
3: cherry
```
