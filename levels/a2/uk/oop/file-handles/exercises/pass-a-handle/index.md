## Завдання

Дескриптор файлу — це звичайне значення. Тож його можна передати функції, як будь-який інший аргумент. Напишіть підпрограму `log-line`. Вона приймає дескриптор і повідомлення. Вона записує повідомлення в дескриптор окремим рядком.

Відкрийте `log.txt` для запису. Викличте `log-line` тричі. Запишіть з її допомогою `started`, `working` і `done`. Потім закрийте дескриптор. Прочитайте файл і виведіть його вміст.

## Приклад

Програма виводить:

```
started
working
done
```
