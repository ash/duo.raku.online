Ось один спосіб розв'язати задачу.

## Код

```raku
sub log-line($fh, $message) {
    $fh.say($message);
}

my $fh = open 'log.txt', :w;
log-line($fh, 'started');
log-line($fh, 'working');
log-line($fh, 'done');
$fh.close;

print slurp 'log.txt';
```

🦋 Вихідний код можна знайти у файлі [pass-a-handle.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/file-handles/pass-a-handle.raku).

## Вивід

```
started
working
done
```

## Коментарі

1. `open` повертає дескриптор. Цей дескриптор — просто значення в `$fh`. Тож його можна передати до `log-line` як аргумент. Так само ви робите з рядком чи числом. Усередині підпрограми `$fh.say` пише через цей самий відкритий дескриптор.

1. Дескриптор лишається відкритим під час усіх трьох викликів. Тож кожен `log-line` додає рядок у кінець того самого файлу. Потім `close` записує все на диск. `slurp` читає три рядки назад.

1. Тому дескриптори легко поєднувати з функціями. Функція може приймати дескриптор. Вона може писати в нього або читати з нього. Їй байдуже, для якого файлу цей дескриптор. Код, який викликає функцію, вибирає файл. Він робить це, коли відкриває файл.
