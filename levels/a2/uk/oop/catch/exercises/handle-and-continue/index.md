## Завдання

Напишіть цикл по трьох елементах: `ok`, `bad` та `ok`. Для кожного елемента виконайте блок. Блок виводить `processed <item>`. Але для елемента `bad` він робить `die 'boom'`. Помістіть усередину блоку фазер `CATCH`. Він перехоплює помилку. Для невдалого елемента він виводить `skipped (<item>): <message>`. Потім цикл переходить до наступного елемента. Він не зупиняється.

## Приклад

Програма виводить:

```
processed ok
skipped (bad): boom
processed ok
```
