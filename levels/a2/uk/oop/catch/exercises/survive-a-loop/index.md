## Завдання

Напишіть цикл по числах `1`, `2` та `3`. Для кожного числа виведіть `ok: <n>`. Але для числа `2` зробіть `die "bad: 2"`. Додайте фазер `CATCH` усередину тіла циклу. Він перехоплює помилку й виводить `caught: <message>`. Тоді один поганий прохід не зупиняє весь цикл.

## Приклад

Програма виводить:

```
ok: 1
caught: bad: 2
ok: 3
```
