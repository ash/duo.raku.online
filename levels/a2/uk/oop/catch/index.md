Блоком `try` легко користуватися. Але для `try` весь блок — це одне ціле. Блок або спрацьовує, або не спрацьовує. Фазер `CATCH` дає вам більше контролю. Виняток — це помилка, яка зупиняє програму. З `CATCH` ви обробляєте виняток _усередині_ його блоку. Це блок, де сталася помилка. Там ви вирішуєте, що робити.

`CATCH` — це фазер. Фазер — це особливий блок. Raku сам запускає його в певний момент. Ви бачили фазери в [розділі про порядок виконання](/uk/advanced/phasers). `CATCH` можна поставити будь-де всередині блоку. Він виконується, лише якщо код у цьому блоці кидає виняток. Виняток ви отримуєте в змінній-топіку `$_`:

```raku
{
    die 'Boom!';

    CATCH {
        default {
            say 'Caught: ' ~ .message;
        }
    }
}

say 'after';
```

Програма виводить:

```
Caught: Boom!
after
```

Блок `default` усередині `CATCH` обробляє кожен виняток. Коли він виконався, виняток уже оброблений. Тож програма не зупиняється. Вона працює далі після блоку з `CATCH`. Тому програма виводить `after`.

Без `CATCH` команда `die` зупиняє програму. Програма так і не доходить до `after`.
