Кожен виклик `run` чи `shell` повертає об'єкт `Proc`. Це невеликий запис про програму. Він каже, яка програма працювала і як вона завершилася. У попередніх темах ми читали вивід через його дескриптор `.out`. Але `Proc` містить більше.

Найкорисніша частина — це **код завершення**. Це невелике ціле число. Програма повертає його тому, хто її запустив. Цим числом програма каже, чи вона спрацювала. `0` означає успіх. Будь-яке інше число означає невдачу. Програма сама вибирає цей код невдачі. `.exitcode` дає вам це число:

```raku
my $proc = run 'sh', '-c', 'exit 3';
say $proc.exitcode; # 3
```

Часто ви ставите лише запитання «так чи ні». Чи спрацювало? Для цього `Proc` істинний, коли код завершення дорівнює `0`. Інакше він хибний. Тож `Proc` можна перевіряти напряму:

```raku
my $proc = run 'ls', '/', :out;
$proc.out.slurp(:close);
say $proc ?? 'ok' !! 'failed'; # ok
```

`Proc` також пам'ятає команду, яку він запустив. Ви знайдете її в `.command`:

```raku
my $proc = run 'echo', 'hi', :out;
$proc.out.slurp(:close);
say $proc.command; # (echo hi)
```

Будьте уважні з однією річчю. Іноді команда не спрацьовує. А що, як ви просто **проігноруєте** `Proc`, який вона повертає? Тоді Raku кидає виняток. Виняток — це помилка, яка зупиняє програму. Raku не дає збою сховатися:

```raku
run 'sh', '-c', 'exit 1';
# гине: The spawned command 'sh' exited unsuccessfully (exit code: 1, signal: 0)
```

Код завершення, інший ніж `0`, зазвичай означає проблему. Тож невдалий `Proc` кидає виняток, якщо ви його викинете. Це стається, коли `Proc` виходить за межі області видимості. Тоді жоден код уже не може до нього дістатися. Справа не в перевірці коду завершення. Справа в тому, що ви *викидаєте* результат. Просто покладіть `Proc` у змінну. Цього досить, щоб уникнути винятку. Вам навіть не треба більше дивитися на цю змінну.

```raku
my $proc = run 'sh', '-c', 'exit 1'; # помилки немає, хоч команда й зазнала невдачі
# …і $proc більше ніколи не використовується
```

Тож ви *очікуєте*, що команда може не спрацювати? Тоді збережіть її `Proc`. Коли захочете дізнатися, що сталося, погляньте на `.exitcode`. Або перевірте `Proc` як булеве значення.
