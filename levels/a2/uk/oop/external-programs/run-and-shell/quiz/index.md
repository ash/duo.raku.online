Яка функція передає свою команду через системну **оболонку**? Ця функція дозволяє використовувати канали й перенаправлення.

{:.quiz}
0 | `run`
1 | `shell`
0 | `exec`
0 | `system`

{% include quiz.html %}

<div class="extended-explanation">

`shell` дає оболонці один рядок. Оболонка розуміє такі можливості, як канали. `run` запускає програму напряму. Він бере окремі аргументи й не використовує оболонку. Так безпечніше. Тож `run` — кращий вибір за замовчуванням.

</div>
