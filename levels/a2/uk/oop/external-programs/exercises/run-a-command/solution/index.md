Ось один спосіб розв'язати задачу.

## Код

```raku
run 'echo', 'home:', '$HOME';
```

🦋 Вихідний код можна знайти у файлі [run-a-command.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/external-programs/run-a-command.raku).

## Вивід

```
home: $HOME
```

## Коментарі

1. `run` запускає `echo` напряму. Він передає кожен рядок як окремий аргумент. Тут немає `:out`. Тож вивід програми йде просто на екран.

1. Аргумент приходить до `echo` точно так, як ви його написали. Тож `$HOME` виводиться без змін. Він не замінюється вашим домашнім каталогом. Це тому, що тут немає оболонки. Оболонка замінила б його. Ось чому `run` — безпечний вибір за замовчуванням. Через `shell` та сама команда може працювати зовсім інакше.

1. Ви справді хочете вивести домашній каталог? Тоді хай змінну замінить оболонка. `shell 'echo home: $HOME'` виводить щось на кшталт `home: /home/anna`. Також залиште одинарні лапки в коді Raku. З подвійними лапками, `"$HOME"`, буде проблема. Raku сам намагається вставити в рядок свою змінну `$HOME`. Це стається ще до того, як `echo` запускається.
