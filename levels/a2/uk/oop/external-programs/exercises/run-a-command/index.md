## Завдання

Використайте `run`, щоб запустити `echo`. Дайте йому два окремі аргументи: `home:` і `$HOME`. Аргументи — це значення, які ви даєте програмі. Хай вивід іде на екран. Зверніть увагу: програма виводить `$HOME` без змін. Вона **не** виводить домашній каталог. Це тому, що `run` не використовує оболонку. Лише оболонка замінює такі змінні, як `$HOME`, на їхні значення.

## Приклад

Програма виводить:

```
home: $HOME
```
