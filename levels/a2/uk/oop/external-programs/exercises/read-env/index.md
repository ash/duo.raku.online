## Завдання

Створіть файл `notes.txt`. Запишіть у нього кілька рядків. Покладіть ім'я файлу у змінну середовища `NOTES`. Потім використайте `shell`, щоб запустити `wc -l`. Оболонка бере ім'я файлу з `$NOTES`. Тож дочірня програма рахує рядки й виводить число. Дочірня програма — це програма, яку запускає ваша програма. Наприкінці видаліть файл із Raku. Використайте для цього `unlink`, а не оболонку.

## Приклад

Програма виводить:

```
3
```

Після цього файлу `notes.txt` уже немає.
