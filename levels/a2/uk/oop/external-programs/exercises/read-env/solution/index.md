Ось один спосіб розв'язати задачу.

## Код

```raku
my $file = 'notes.txt';
spurt $file, "one\ntwo\nthree\n";

%*ENV<NOTES> = $file;

my $proc = shell 'wc -l < "$NOTES"', :out;
say $proc.out.slurp(:close).trim;

unlink $file;
```

🦋 Вихідний код можна знайти у файлі [read-env.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/external-programs/read-env.raku).

## Вивід

```
3
```

## Коментарі

1. `spurt` створює `notes.txt` із трьома рядками. Потім ми записуємо ім'я файлу в `%*ENV<NOTES>`. Тож тепер ім'я файлу лежить у середовищі. Кожна дочірня програма отримує це середовище.

1. Команда `shell` отримує це середовище. Вона замінює `$NOTES` на `notes.txt`. Потім вона передає файл у `wc -l`. `wc -l` рахує рядки файлу. Перенаправлення `< "$NOTES"` тут важливе. Через нього вивід — це лише число `3`. Ми перехоплюємо це число через `:out` і обрізаємо його.

1. Наприкінці ми прибираємо за собою в Raku через `unlink`. Оболонка для цього не потрібна. Видалити файл — це проста операція файлової системи. Тож немає причини запускати для цього ще один процес. Процес — це запущена програма.
