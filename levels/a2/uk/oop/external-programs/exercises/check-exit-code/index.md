## Завдання

Запустіть команду, яка навмисно не спрацьовує. Наприклад, використайте `sh -c 'exit 4'`. Збережіть `Proc`, який вона повертає. Виведіть код завершення команди. Код завершення — це число. Команда повертає його, коли закінчує роботу. Потім виведіть `success`, якщо команда спрацювала. Виведіть `failure`, якщо ні.

## Приклад

Програма виводить:

```
4
failure
```
