Ось один спосіб розв'язати задачу.

## Код

```raku
my $proc = run 'sh', '-c', 'exit 4';

say $proc.exitcode;
say $proc ?? 'success' !! 'failure';
```

🦋 Вихідний код можна знайти у файлі [check-exit-code.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/external-programs/check-exit-code.raku).

## Вивід

```
4
failure
```

## Коментарі

1. `run` повертає `Proc`. Ми зберігаємо його в `$proc`, а потім читаємо. Тут це важливо. Команда може не спрацювати. Якщо ніхто не зберігає її `Proc`, Raku кидає виняток. Виняток — це помилка, яка зупиняє програму. Але тут ми дивимося на результат. Це вважається обробкою збою.

1. `.exitcode` дає число, яке повернула команда. Тут це `4`. Можна також перевірити `Proc` як булеве значення. Булеве значення буває істинним або хибним. Це відповідає на простіше запитання: чи спрацювала команда? `Proc` істинний, лише коли код завершення дорівнює `0`. Тут він хибний. Тож програма виводить `failure`.
