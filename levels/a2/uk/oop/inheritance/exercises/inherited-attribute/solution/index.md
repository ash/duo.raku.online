Ось один спосіб розв'язати задачу.

## Код

```raku
class Vehicle {
    has $.wheels;
}

class Bike is Vehicle {
    has $.wheels = 2;
}

class Car is Vehicle {
    has $.wheels = 4;
}

say Bike.new.wheels;
say Car.new.wheels;
```

🦋 Вихідний код можна знайти у файлі [inherited-attribute.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/inheritance/inherited-attribute.raku).

## Вивід

```
2
4
```

## Коментарі

1. І `Bike`, і `Car` успадковують атрибут `wheels` від `Vehicle`. Вони також успадковують його аксесор. Вони не створюють нового атрибута. Вони лише дають успадкованому атрибуту типове значення. Для `Bike` це `2`. Для `Car` це `4`.

1. Кожен клас має своє типове значення всередині. Тож об'єкти можна створити просто через `Bike.new` та `Car.new`. Потім успадкований аксесор повертає правильну кількість коліс.

1. Ви все одно можете передати значення самі, наприклад, `Car.new(wheels => 3)`. Тоді це значення замінює типове. Але велосипеди й автомобілі зазвичай мають звичну кількість коліс. Тож типові значення роблять звичайний випадок простим. А іноді ви все одно можете зробити виняток.
