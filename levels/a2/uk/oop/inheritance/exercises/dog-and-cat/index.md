## Завдання

Створіть базовий клас `Employee`. Це батьківський клас для інших класів. Він має атрибут `name` і два методи. Метод `role` повертає `'staff'`. Метод `badge` повертає рядок `<name> - <role>`. Для ролі він викликає власний метод `role`.

Потім створіть два дочірні класи, `Manager` та `Intern`. Вони успадковують від `Employee`. Кожен із них перевизначає `role`. Це означає, що він має власну версію цього методу. У `Manager` метод `role` повертає `'manager'`. У `Intern` він повертає `'intern'`.

Виведіть бейдж менеджера на ім'я `Anna`. Потім виведіть бейдж стажера на ім'я `Bob`.

## Приклад

Програма виводить:

```
Anna - manager
Bob - intern
```
