_Успадкування_ дозволяє одному класу будуватися на іншому класі. Для цього напишіть `is` після імені нового класу. Потім напишіть ім'я іншого класу. Новий клас успадковує від іншого класу. Він отримує всі його атрибути й методи. Інший клас — це _батьківський_ клас, або _базовий_ клас.

```raku
class Animal {
    has $.name;
    method speak {
        'some sound';
    }
}

class Dog is Animal {
}
```

`Dog is Animal` означає, що `Dog` — це різновид `Animal`. Ми не пишемо в `Dog` нічого нового. Але `Dog` уже має атрибут `name` від `Animal`. Він також має метод `speak` від `Animal`:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.name;  # Rex
say $rex.speak; # some sound
```

Об'єкт `Dog` — це також `Animal`:

```raku
say Dog.new ~~ Animal; # True
```

Через `~~` ви робите розумне зіставлення об'єкта з типом. Результат істинний, коли об'єкт має цей тип. Він також істинний, коли об'єкт успадковує від цього типу. Наступна тема — про дочірній клас. Дочірній клас успадковує від батьківського класу. Він може замінити метод батьківського класу власною версією.
