Більшість методів ви викликаєте для об'єкта. Об'єкт — це екземпляр класу. Але метод можна викликати й для самого класу. Тобто ви викликаєте його для об'єкта типу. Такий метод часто називають _методом класу_. Він корисний для значень і дій усього класу. Вони не належать лише одному об'єкту.

Метод класу ви пишете так само, як будь-який інший метод:

```raku
class Road {
    method speed-limit { 120 }
}
```

Але ви викликаєте його для імені класу. Ви не викликаєте його для екземпляра:

```raku
say Road.speed-limit; # 120
```

Ви вже знаєте один метод класу. Але ви не називали його так. Це `new`. Ви викликаєте `new` для класу, і він створює новий об'єкт.

Метод класу не може використовувати атрибути екземпляра. За ним немає об'єкта. Тож він може працювати лише зі спільною інформацією. Ця інформація однакова для кожного об'єкта класу. Іноді для роботи потрібні дані одного об'єкта. Тоді візьміть звичайний метод і викличте його для екземпляра. Іноді для роботи такі дані не потрібні. Тоді метод класу — добрий вибір.

Методам класу не потрібен екземпляр. Але іноді у вас є об'єкт. Тоді ви все одно можете використати його дані в них:

```raku
class Road {
    has $.name;
    method speed-limit { 120 }

    method info {
        "The maximum speed on $.name is " ~ self.speed-limit
    }
}

my $R404 = Road.new(name => 'Road 404');
say $R404.info;
```

Ця програма виводить результат, який ви чекаєте:

```
The maximum speed on Road 404 is 120
```

Тут вам потрібен екземпляр класу. Без нього виклик на зразок `say Road.info` дає помилку.
