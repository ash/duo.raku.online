## Завдання

Створіть клас `Converter` із методом класу `km-to-miles`. Він приймає кількість кілометрів. Він повертає відстань у милях. Щоб отримати милі, помножте на `0.621`.

Викличте метод для класу зі значенням `10` кілометрів. Виведіть результат.

## Приклад

Програма виводить:

```
6.21
```
