## Завдання

Метод класу може мати параметри, як і будь-який інший метод. Створіть клас `Geometry` із методом класу `circle-area`. Він приймає радіус. Він повертає площу круга. Використайте `π` або `pi`. Заокругліть площу до цілого числа. Формула належить усьому класу. Тут немає окремого об'єкта-круга. Викличте метод для класу з радіусом `10`. Виведіть результат.

## Приклад

Програма виводить:

```
314
```
