## Завдання

Створіть роль `Sized` з методом `describe`. Метод повертає рядок `size is <size>`. Для розміру він використовує `self.size`.

Потім створіть клас `Box`. Він виконує роль `Sized` і має атрибут `size`. Створіть коробку з розміром `10`. Викличте для неї `describe` і виведіть результат. Другим рядком виведіть результат `~~ Sized` для коробки. Він показує, чи коробка виконує цю роль.

## Приклад

Програма виводить:

```
size is 10
True
```
