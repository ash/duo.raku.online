## Завдання

Створіть клас `Robot` з методом `speak`. Цей метод повертає `beep`. Потім створіть роль `Dancing`. Вона додає метод `dance`. Цей метод повертає `spinning around`.

Створіть двох роботів. Дайте роль `Dancing` лише одному з них. Викличте `speak` для обох роботів і виведіть результати. Потім викличте `dance` для робота, який уміє танцювати. Виведіть і цей результат.

## Приклад

Програма виводить:

```
beep
beep
spinning around
```
