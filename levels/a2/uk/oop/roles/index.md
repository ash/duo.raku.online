_Роль_ — це набір методів. Іноді вона має й дані. Кілька класів можуть мати спільну роль. Успадкування каже, що клас _є_ різновидом іншого класу. З роллю все інакше. Вона описує те, що клас _уміє робити_.

Роль створюють ключовим словом `role`. Вона дуже схожа на клас. Щоб дати роль класу, використайте трейт `does`:

```raku
role Greet {
    method hello {
        'Hello from ' ~ self.name;
    }
}

class Person does Greet {
    has $.name;
}
```

Тепер клас `Person` має метод `hello` з ролі. Він працює так само, як метод у самому класі:

```raku
say Person.new(name => 'Anna').hello; # Hello from Anna
```

Клас може виконувати роль. Тоді Raku знає, що клас має цю роль:

```raku
say Person.new(name => 'Anna') ~~ Greet; # True
```

Подивіться на метод `hello` у ролі. Він використовує `self.name`. Але сама роль не має атрибута `name`. Це не проблема. Метод виконується як частина класу, який компонує роль. Компонувати роль означає взяти її в клас. А цей клас має атрибут `name`. Наступна тема показує більше. Клас може мати більш ніж одну роль одночасно.
