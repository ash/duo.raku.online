Роль не обов'язково вбудовувати в клас. Роль можна дати й об'єкту, який уже існує. Для цього використайте оператор `but`. Він підмішує роль лише в один об'єкт. Це стається, поки програма працює. Потім `but` повертає новий об'єкт із цією роллю:

```raku
role Loud {
    method greet {
        callsame().uc;
    }
}

class Greeter {
    method greet {
        'Hello';
    }
}

my $quiet = Greeter.new;
my $loud  = Greeter.new but Loud;

say $quiet.greet; # Hello
say $loud.greet;  # HELLO
```

Роль отримав лише `$loud`. Клас `Greeter` і всі інші об'єкти `Greeter` лишаються такими самими. Тож `$quiet` і далі вітається звичайно. Іноді роль і клас мають методи з однаковим іменем. Тоді перемагає версія з ролі. А `callsame` викликає інший метод, який роль перевизначає. Тут це початковий `greet` із `Greeter`. Потім його результат переводять у великі літери.

Об'єкт може отримати роль у такий спосіб. Тоді вважається, що він виконує цю роль:

```raku
say $quiet ~~ Loud; # False
say $loud  ~~ Loud; # True
```

`but` не змінює початковий об'єкт. Він дає вам новий об'єкт. Можливо, ви хочете змінити сам об'єкт. Тоді використайте замість нього оператор `does`:

```raku
my $speaker = Greeter.new;
$speaker does Loud;
say $speaker.greet; # HELLO
```

Ролі можна підмішувати в окремі об'єкти. Тож ви вирішуєте для кожного об'єкта, яку додаткову поведінку він отримує. Вам не потрібен окремий клас для кожного поєднання.
