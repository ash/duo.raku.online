## Завдання

Кожна вбудована помилка має свій тип винятку. Ці типи можна зіставляти. Напишіть блок, який обчислює `1 / 0`. Потім блок намагається використати результат. Це кидає `X::Numeric::DivideByZero`. Додайте до блоку фазер `CATCH`. У ньому використайте `when X::Numeric::DivideByZero`. Він збігається саме з цим типом. Потім виведіть `cannot divide by zero`.

## Приклад

Програма виводить:

```
cannot divide by zero
```
