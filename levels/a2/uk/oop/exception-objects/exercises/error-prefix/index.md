## Завдання

Напишіть блок із `die 'timeout'` усередині. Додайте до блоку фазер `CATCH`. Він перехоплює виняток і виводить його повідомлення. Поставте `Error: ` перед повідомленням.

## Приклад

Програма виводить:

```
Error: timeout
```
