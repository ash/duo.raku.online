## Завдання

Напишіть підпрограму `risky`. Вона робить `die 'sub failed'`. Потім викличте `risky` усередині блоку з фазером `CATCH`. Спершу `CATCH` виводить ім'я типу винятку через `.^name`. Потім він виводить його повідомлення через `.message`. Це показує ще одну річ про `CATCH`. Він також обробляє винятки з коду, який блок *викликає*. `die` не мусить стояти в самому блоці.

## Приклад

Програма виводить:

```
X::AdHoc
sub failed
```
