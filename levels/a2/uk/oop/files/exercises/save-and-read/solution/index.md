Ось один спосіб розв'язати задачу.

## Код

```raku
spurt 'number.txt', "42\n";

my $n = slurp('number.txt').trim.Int;
say $n * 2;
```

🦋 Вихідний код можна знайти у файлі [save-and-read.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/files/save-and-read.raku).

## Вивід

```
84
```

## Коментарі

1. `spurt` створює файл і записує в нього рядок. `slurp` читає весь файл назад у рядок. Разом вони роблять обидві справи. Вони зберігають дані й знову їх завантажують.

1. `slurp` повертає текст: `"42\n"`. Тож ми використовуємо `trim`, щоб прибрати символ нового рядка в кінці. Потім ми викликаємо `.Int`, щоб перетворити текст на число. Тепер з ним можна рахувати. Результат `42 * 2` дорівнює `84`.

1. Але програма працює й без `.trim.Int`.
