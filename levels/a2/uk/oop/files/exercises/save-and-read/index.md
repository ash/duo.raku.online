## Завдання

Збережіть число у файлі й завантажте його знову. Файл називається `number.txt`. Запишіть у нього число `42`, а потім символ нового рядка. Потім прочитайте файл. Перетворіть його вміст на ціле число. Помножте це число на два й виведіть результат.

## Приклад

Програма виводить:

```
84
```
