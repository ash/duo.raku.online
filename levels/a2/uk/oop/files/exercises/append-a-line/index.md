## Завдання

Створіть невеликий файл журналу. Кілька разів додайте рядки в його кінець. Спочатку запишіть рядок `start` у файл з ім'ям `log.txt`. Потім у циклі **допишіть** ще три рядки. Це означає, що ви додаєте їх у кінець файлу. Рядки такі: `entry 1`, `entry 2` і `entry 3`. Не видаляйте те, що вже є у файлі. Наприкінці прочитайте весь файл і виведіть його.

## Приклад

Програма виводить:

```
start
entry 1
entry 2
entry 3
```
