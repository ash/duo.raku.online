Зазвичай `spurt` замінює весь старий вміст файлу. Але іноді ви хочете додати щось у кінець файлу. Для цього передайте іменований аргумент `:append`:

```raku
spurt 'log.txt', "line1\n";
spurt 'log.txt', "line2\n", :append;

print slurp 'log.txt';
```

Другий `spurt` зберігає старий вміст. Він додає новий рядок після нього. Тож наприкінці файл має обидва рядки:

```
line1
line2
```

Без `:append` другий виклик перезаписує файл. Тоді у файлі лишається тільки `line2`. Додавання в кінець файлу називають дописуванням. Воно корисне, наприклад, для файлів журналу. Файл журналу зберігає запис про роботу програми. Кожен запуск програми доповнює цей запис. Тож запис росте. Програма не починає знову з порожнього файлу.
