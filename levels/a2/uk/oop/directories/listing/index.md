Підпрограма `dir` повертає записи каталогу. Запис — це файл або каталог усередині нього. Кожен запис — це об'єкт шляху. Порядок записів не завжди однаковий. Тому результат часто сортують. Тоді вивід завжди йде в тому самому порядку.

```raku
mkdir 'box';
spurt 'box/a.txt', '';
spurt 'box/b.txt', '';

for dir('box').sort -> $entry {
    say $entry.basename;
}
```

Ця програма виводить імена файлів у каталозі `box`. Імена відсортовані:

```
a.txt
b.txt
```

Кожен запис — це повний об'єкт шляху. Метод `basename` дає лише ім'я в кінці. Він не дає частину з каталогом. Об'єкту шляху можна ставити всі ті самі запитання, що й раніше: `.f`, `.d`, `.e`. Тож, наприклад, можна взяти з каталогу лише файли.
