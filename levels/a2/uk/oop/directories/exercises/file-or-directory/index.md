## Завдання

Створіть файл з ім'ям `a.txt`. Потім поставте *тому самому* шляху два запитання. Чи це звичайний файл (`.f`)? Чи це каталог (`.d`)? Виведіть обидві відповіді. Ви побачите, що дві перевірки дають для одного шляху протилежні результати.

## Приклад

Програма виводить:

```
True
False
```
