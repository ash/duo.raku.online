Іноді треба працювати із самою файловою системою. Файлова система зберігає всі файли й каталоги на диску. Наприклад, ви перевіряєте, що існує, або створюєте каталоги. Каталог — це папка. У ньому можуть бути файли й інші каталоги. Для цієї роботи Raku використовує _об'єкти шляху_. Шлях показує, де лежить файл чи каталог. Метод `.IO` перетворює будь-який рядок на об'єкт шляху. Тоді об'єкт шляху відповідає на запитання про цей шлях.

Найчастіше ставлять два запитання. Чи існує шлях? І що це за річ?

```raku
spurt 'greeting.txt', 'hi';

say 'greeting.txt'.IO.e; # True  — чи існує?
say 'greeting.txt'.IO.f; # True  — чи це файл?
say 'greeting.txt'.IO.d; # False — чи це каталог?
```

`.e` перевіряє, чи існує шлях. `.f` перевіряє, чи це звичайний файл. `.d` перевіряє, чи це каталог.

`mkdir` створює новий каталог:

```raku
mkdir 'reports';
say 'reports'.IO.d; # True
```

Наступна тема показує, як отримати список того, що лежить у каталозі.
