Raku має вбудовані винятки. Їхні імена починаються з `X::`. Ви можете також створити свої винятки. Ми називаємо їх власними винятками. Власний виняток — це клас. Він успадковує від вбудованого класу `Exception`. Тож він — один із видів `Exception`. Також він має метод `message`:

```raku
class TooBig is Exception {
    has $.value;

    method message {
        "Value $.value is too big";
    }
}
```

`TooBig` — звичайний клас. Він може мати атрибути, наприклад `value`. Але він `is Exception`. Тож його можна кинути, як помилку з `die`. Щоб кинути його, створіть об'єкт цього класу. Потім викличте для цього об'єкта `.throw`:

```raku
my $value = 20 * 30;

TooBig.new(value => $value).throw if $value > 50;

CATCH {
    when TooBig {
        say .message;
    }
}
```

Програма виводить:

```
Value 600 is too big
```

Усередині `CATCH` гілка `when TooBig` збігається. Це тому, що кинутий об'єкт має тип `TooBig`. Власний виняток зберігає будь-які дані, які ви йому даєте. Тут ці дані — це `value`. Код, який обробляє виняток, — це обробник. Обробник може використати ці дані. Він може побудувати точне повідомлення. Або він може відреагувати особливим способом. Це набагато корисніше, ніж простий рядок для `die`.

Тут усе з цієї частини курсу сходиться разом. Власний виняток — це _клас_. Він має атрибути й метод. Також він працює з інструментами винятків у Raku. Його можна кинути й перехопити. Тож він може точно сказати, що пішло не так.
