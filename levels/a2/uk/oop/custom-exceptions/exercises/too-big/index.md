## Завдання

Створіть власний клас винятку `TooBig`. Це клас для ваших власних помилок. Він успадковує від `Exception`. Він має два атрибути, `value` та `limit`. Його метод `message` має повертати `Value <value> exceeds the limit of <limit>`.

Потім напишіть цикл по значеннях `30`, `99` та `60`. Межа дорівнює `50`. Кидайте `TooBig`, лише коли значення більше за межу. Додайте фазер `CATCH` із `when TooBig`. Він виводить повідомлення **і** другий рядок. Для цього рядка він читає атрибут `limit` винятку напряму. Другий рядок — це `Try a value up to <limit>.`. Якщо значення не виходить за межу, просто виведіть, що все гаразд.

Ви бачите, що виняток отримують лише погані числа. Інші числа проходять без проблем. В обох випадках цикл іде далі.

## Приклад

Програма виводить:

```
Value 30 is within the limit
Value 99 exceeds the limit of 50
Try a value up to 50.
Value 60 exceeds the limit of 50
Try a value up to 50.
```
