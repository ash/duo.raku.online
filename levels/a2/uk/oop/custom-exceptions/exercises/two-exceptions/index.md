## Завдання

Створіть два власні класи винятків, `TooSmall` та `TooBig`. Це класи для ваших власних помилок. Кожен клас успадковує від `Exception`. Метод `message` класу `TooSmall` повертає `too small`. Метод `message` класу `TooBig` повертає `too big`.

Напишіть цикл по цих двох типах. Для кожного типу киньте виняток цього типу. Кожен виняток має свій блок. Додайте фазер `CATCH` із гілкою `when` для кожного типу. Для `TooSmall` він виводить `small`. Для `TooBig` він виводить `big`. Так ви бачите, що спрацьовують обидві гілки.

## Приклад

Програма виводить:

```
small
big
```
