## Завдання

Створіть ланцюжок із трьох класів. Перший — `A`. Потім `B` успадковує від `A`. Потім `C` успадковує від `B`. Виведіть порядок розв'язання методів для `C`. Виведіть його як список імен типів. У такому порядку Raku шукає метод.

## Приклад

Програма виводить:

```
(C B A Any Mu)
```
