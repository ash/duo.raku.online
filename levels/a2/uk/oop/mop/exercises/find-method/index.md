## Завдання

Створіть клас `Animal` з методом `speak`. Потім створіть клас `Dog`. Він успадковує від `Animal`. Він не має власних методів. Викличте метаметод для `Dog`. Перевірте, чи має `Dog` метод `speak`. Виведіть просто `True` або `False`. Це показує дещо про `find_method`. Він шукає вздовж усього ланцюжка успадкування. Він шукає не лише серед методів самого класу.

## Приклад

Програма виводить:

```
True
```
