_Метаметод_ викликають через `.^`, а не через `.`. Звичайний `.method` виконує метод об'єкта. А `.^method` працює інакше. Він викликає метод **метаоб'єкта** цього об'єкта. Метаоб'єкт — це об'єкт, який описує тип. Тож цей виклик питає про тип. Він не діє як тип.

Ви вже знаєте `.^name`. Він повертає ім'я типу:

```raku
say 42.^name; # Int
```

Інші метаметоди показують, як побудований тип. `.^attributes` перелічує його атрибути. `.^find_method` каже, чи існує метод:

```raku
class Animal {
    has $.name;
    method speak { 'generic' }
}

say Animal.^attributes.elems;          # 1
say so Animal.^find_method('speak');   # True
say so Animal.^find_method('fly');     # False
```

`.^mro` повертає _порядок розв'язання методів_. Це ланцюжок типів. Raku шукає метод у кожному з них, у такому порядку. Це лінія успадкування класу:

```raku
class A {}
class B is A {}

say B.^mro.map(*.^name); # (B A Any Mu)
```

`B` успадковує від `A`. Зрештою, кожен тип успадковує від `Any` та `Mu`. Ви викликаєте метод для `B`. Тоді Raku шукає його саме цим шляхом. Ці метаметоди перетворюють ваші типи на дані. Ці дані показують, як побудовані типи. Про них можна питати, поки програма працює.
