Вираз може мати кілька операторів. Тоді Raku має вирішити порядок. Який оператор іде першим? Це вирішують два правила: _пріоритет_ і _асоціативність_.

## Пріоритет

Пріоритет вирішує, який оператор сильніший. Сильніший оператор бере свої операнди першим. Множення має вищий пріоритет, ніж додавання. Тож множення відбувається першим:

```raku
say 2 + 3 * 4; # 14
```

Raku читає вираз як `2 + (3 * 4)`. Результат — `14`, а не `20`. Ви завжди можете додати дужки. Вони дають інший порядок:

```raku
say (2 + 3) * 4; # 20
```

## Асоціативність

Деякі оператори мають _однаковий_ пріоритет. Тоді порядок вирішує асоціативність. Віднімання лівоасоціативне. Тож Raku групує його зліва:

```raku
say 8 - 3 - 2; # 3
```

Це `(8 - 3) - 2`. Результат — `3`. Але піднесення до степеня, оператор `**`, правоасоціативне:

```raku
say 2 ** 3 ** 2; # 512
```

Тут Raku групує вираз як `2 ** (3 ** 2)`. Це `2 ** 9`, і результат — `512`.

## Ланцюжки порівнянь

Оператори порівняння можна об'єднувати в _ланцюжки_. Тоді вони йдуть один за одним. Такий код легко читати. Він працює як у математиці:

```raku
say 1 < 2 < 3; # True
say 1 < 5 < 3; # False
```

Raku порівнює середнє значення з обома значеннями поруч із ним. `1 < 2 < 3` істинне. Це тому, що `1 < 2` істинне, і `2 < 3` теж істинне.
