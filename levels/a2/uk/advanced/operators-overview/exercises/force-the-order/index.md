## Завдання

Оператор `**` сильніший за `+`. Тож Raku читає `2 ** 3 + 1` як `(2 ** 3) + 1`. Це `9`. Додайте дужки й змініть цей порядок. Додавання має відбутися *першим*. Виведіть результат.

## Приклад

Програма виводить:

```
16
```
