Ось один спосіб розв'язати задачу.

## Код

```raku
say 0 <= 73 <= 100;
```

🦋 Вихідний код можна знайти у файлі [chained-comparison.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operators-overview/chained-comparison.raku).

## Вивід

```
True
```

## Коментарі

1. Оператори порівняння можна об'єднувати в ланцюжки. Тож `0 <= 73 <= 100` означає «0 не більше за 73, і 73 не більше за 100». Оператор `<=` дозволяє й краї. Тож бал рівно `0` або `100` теж дійсний.

1. Обидві частини істинні. Тож увесь вираз дає `True`. Подивіться на середнє значення, `73`. Ви пишете його лише раз. Але Raku порівнює його з обома значеннями поруч.

1. Без ланцюжка треба написати обидва порівняння. Ви з'єднуєте їх через `&&`. І ви пишете середнє значення двічі: `0 <= 73 && 73 <= 100`. Форма з ланцюжком каже те саме коротше.
