У частині «Основи» ви використовували `MAIN`, [щоб отримувати аргументи командного рядка](/uk/essentials/the-main-function/reading-command-line-arguments). Raku робить для вас із `MAIN` більше. Він не лише передає значення всередину.

## Повідомлення про використання

Іноді аргументи командного рядка не відповідають сигнатурі `MAIN`. Сигнатура — це список її параметрів. Тоді Raku не виконує тіло. Натомість він виводить _повідомлення про використання_. Raku сам створює це повідомлення. Повідомлення показує, як запускати програму.

Подивіться на цю програму:

```raku
sub MAIN($name) {
    say "Hello, $name!";
}
```

Запустіть її правильно. Тоді вона вітається з людиною:

```console
$ raku hello.raku Anna
Hello, Anna!
```

Тепер запустіть її без аргументу. Сигнатура не збігається. Тож Raku виводить повідомлення про використання. Він не вітається:

```console
$ raku hello.raku
Usage:
  hello.raku <name>
```

Raku складає повідомлення з імен параметрів. Тож дайте параметрам добрі імена. Тоді текст довідки корисний, і ви не робите зайвої роботи.

## Іменовані аргументи

`MAIN` може мати позиційні параметри. Також `MAIN` може мати іменовані параметри. У командному рядку іменований параметр стає опцією, як-от `--option=value`. Ви можете дати йому типове значення. Тоді опція не обов'язкова:

```raku
sub MAIN(:$name = 'World') {
    say "Hello, $name!";
}
```

```console
$ raku hello.raku
Hello, World!

$ raku hello.raku --name=Raku
Hello, Raku!
```
