Цілі числа мають багато корисних методів і підпрограм. Ось кілька з них. Ви будете часто ними користуватися.

Метод `is-prime` каже вам, чи число просте:

```raku
say 17.is-prime; # True
say 18.is-prime; # False
```

Оператори `gcd` та `lcm` працюють із двома числами. `gcd` дає найбільший спільний дільник. Це найбільше число, на яке діляться обидва числа. `lcm` дає найменше спільне кратне. Це найменше число, яке ділиться на обидва числа:

```raku
say 12 gcd 18; # 6
say 4 lcm 6;   # 12
```

Метод `abs` дає абсолютне значення. Це число без знака мінус. Метод `sign` дає `-1`, `0` або `1`. Для від'ємного числа це `-1`. Для нуля це `0`. Для додатного числа це `1`:

```raku
say (-5).abs;  # 5
say (-5).sign; # -1
say 0.sign;    # 0
```
