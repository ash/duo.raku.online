Ім'я модуля також створює _пакунок_. Пакунок — це простір імен. Він зберігає імена з модуля. Раніше, у [розділі про контейнери](/uk/advanced/containers), ви бачили `WHO`. Він повертає `Stash` пакунка. `Stash` — це таблиця символів, тобто імен, у пакунку. Інтроспекція модулів використовує це. З нею програма заглядає всередину модуля.

Приклади нижче використовують модуль `Greeting` із попередніх тем. У ньому є підпрограма, яку він експортує. Також у ньому є спільна змінна `our`:

```raku
unit module Greeting;

our $version = '1.0';

sub hello($name) is export {
    return "Hello, $name!";
}
```

Щоб отримати пакунок модуля, напишіть `::` після його імені. Потім додайте `.keys`. Він перелічує імена в пакунку:

```raku
use Greeting;

say Greeting::.keys.sort; # ($version EXPORT)
```

Модуль `Greeting` із попередніх тем має змінну `our` під назвою `$version`. Тож це ім'я є в його пакунку. Сигіл теж входить в ім'я. Поруч із ним ви бачите `EXPORT`. Це може вас здивувати. `EXPORT` — це теж пакунок. Raku створює його автоматично. Модуль позначає деякі речі через `is export`. `EXPORT` зберігає їх усі, наприклад, підпрограму `hello`. Тож експортоване ім'я _не_ лежить прямо в пакунку. Воно лежить в `EXPORT`. Це менший пакунок усередині пакунка модуля. Порядок ключів не завжди однаковий. Тому приклад сортує їх. Тоді результат завжди однаковий.

Ви також можете знайти ім'я в пакунку. Використайте ім'я як ключ. Ви отримаєте те саме значення, що й через повне ім'я `$Greeting::version`:

```raku
use Greeting;

say Greeting::{'$version'}; # 1.0
```

## Список експортів модуля

Насправді експортовані імена лежать у пакунку `EXPORT`, який ви бачили вище. Тож ви можете їх перелічити. Просто загляньте на рівень глибше. Експорти без мітки потрапляють до групи `DEFAULT`. Про мітки можна прочитати в темі [Мітки експорту](/uk/advanced/modules-basics/export-tags). `.keys` групи `DEFAULT` — це експортовані підпрограми:

```raku
use Greeting;

say Greeting::EXPORT::DEFAULT::.keys.sort; # (&hello)
```

Кожен ключ — це експортоване ім'я з його сигілом. Тут є лише один ключ: підпрограма `&hello`. Сигіл `&` показує, що це підпрограма. Так ви можете дізнатися, що модуль дає своїм користувачам. Вам не треба читати його вихідний код. Просто спитайте його пакунок `EXPORT::DEFAULT`, що він містить.

Так заглядати всередину пакунка корисно. Ви можете дізнатися, що є в модулі. Також ви можете дістатися до його імен під час роботи програми. Тоді вам не треба писати кожне ім'я в коді.
