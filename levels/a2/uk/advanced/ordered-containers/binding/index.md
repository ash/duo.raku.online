Досі кожна нова змінна створювала новий контейнер. Присвоєння через `=` клало значення _всередину_ цього контейнера. Зв'язування працює інакше. Ви пишете його як `:=`. Зв'язування не створює новий контейнер. Воно дає ім'я _наявному_ контейнеру.

Після зв'язування два імені мають один спільний контейнер. Змініть значення через одне ім'я. Інше ім'я теж бачить цю зміну:

```raku
my $x = 10;
my $y := $x;

$x = 20;
say $y; # 20
```

Тут `$y := $x` не копіює значення `10`. Воно робить `$y` другим іменем для контейнера `$x`. Це той самий контейнер. Пізніше `$x` отримує значення `20`. Тоді `$y` теж дорівнює `20`.

Порівняйте це зі звичайним присвоєнням. Воно копіює значення в інший контейнер:

```raku
my $x = 10;
my $y = $x; # звичайна копія

$x = 20;
say $y; # 10
```

Зв'язування працює і з масивами. Тут `@alias` стає другим іменем для `@data`:

```raku
my @data = 1, 2, 3;
my @alias := @data;

@alias[0] = 99;
say @data; # [99 2 3]
```

Ще одна деталь. Ви можете зв'язати ім'я прямо з літеральним значенням. Це значення, яке ви пишете в коді. Тоді за іменем немає контейнера. Тому ім'я можна лише читати. Ви не можете нічого йому присвоїти:

```raku
my $pi := 3.14;
$pi = 3;
```
