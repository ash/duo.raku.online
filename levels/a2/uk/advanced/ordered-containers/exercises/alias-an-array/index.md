## Завдання

Ось масив:

```raku
my @original = 10, 20, 30;
```

Створіть друге ім'я, `@alias`, для _того самого_ масиву. Не копіюйте масив. Цього разу додайте новий елемент до `@original` через `push`. Потім виведіть `@alias`. Це показує, що псевдонім бачить не лише нові значення. Він також бачить зміни в структурі масиву.

## Приклад

Програма виводить:

```
[10 20 30 40]
```
