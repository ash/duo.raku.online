Масив — це впорядкований контейнер. Кожен елемент масиву — теж скалярний контейнер.

```raku
my @array = 100, 200, 300;
my @letters = 'a', 'b', 'c';
```

Сигіл `@` показує, що змінна працює як об'єкт `Positional`. Тому кожен елемент можна отримати за його індексом:

```raku
say @array[1];   # 200
say @letters[2]; # c
```

Кожен елемент — це скалярний контейнер. Тому йому можна присвоїти нове значення. Це працює так само, як зі звичайною скалярною змінною:

```raku
my @array = 100, 200, 300;
@array[0] = 10;
say @array; # [10 200 300]
```

Можна також присвоїти значення іншого типу. Наприклад:

```raku
my @array = 100, 200, 300;
@array[0] = 'ten';
say @array; # [ten 200 300]
```

Ось чому масиви _змінювані_. Це означає, що їх можна змінювати. Кожне місце в масиві — це контейнер. Він може отримати нове значення. [Списки](/uk/advanced/ordered-containers/lists) інші. Ви побачите це в наступній темі.
