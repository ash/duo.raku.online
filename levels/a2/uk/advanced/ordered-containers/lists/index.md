Список — це теж упорядкований набір значень. Але він не такий, як масив. Список _незмінний_. Ви не можете змінювати його елементи. Також ви не можете додавати чи вилучати елементи. Щоб записати список, поставте коми між значеннями. Часто навколо них стоять дужки:

```raku
my $colours = ('red', 'green', 'blue');
```

Ви можете читати елементи списку за їхнім індексом. Також можна спитати, скільки там елементів. Це так само, як з масивом:

```raku
my $colours = ('red', 'green', 'blue');
say $colours[0];    # red
say $colours.elems; # 3
```

Тепер спробуйте змінити елемент. Тут ви бачите різницю. З масивом це працює. Кожен елемент масиву — це контейнер:

```raku
my @array = 1, 2, 3;
@array[0] = 10;
say @array; # [10 2 3]
```

Зі списком ви отримуєте помилку. Елементи списку — це просто значення. Вони не контейнери:

```raku
my $list = (1, 2, 3);
$list[0] = 10;
```

Друга програма зупиняється. Вона виводить таке повідомлення:

```
Cannot modify an immutable List ((1 2 3))
  in block <unit> at t.raku line 2
```

Отже, вам треба змінювати дані? Тоді використовуйте масив із сигілом `@`. Вам треба лише зберігати кілька значень у сталому порядку? Тоді використовуйте список.
