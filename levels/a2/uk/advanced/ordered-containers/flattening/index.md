Ви можете покласти один масив усередину іншого. Raku _не_ об'єднує їхні елементи сам. Подивіться на цю програму:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;
my @c = @a, @b;

say @c.elems; # 2
say @c;       # [[1 2 3] [4 5]]
```

Масив `@c` має лише два елементи: масиви `@a` і `@b`. Raku зберігає кожен контейнер як один елемент. Його елементи не потрапляють у зовнішній масив. Те саме буває з масивом серед інших значень:

```raku
my @a = 1, 2, 3;
my @d = 0, @a, 99;
say @d; # [0 [1 2 3] 99]
```

Вам потрібна одна плоска послідовність? Тоді попросіть її за допомогою підпрограми `flat`:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat(@a, @b);       # (1 2 3 4 5)
say flat(@a, @b).elems; # 5
```

## Штучність

Іноді вам потрібне протилежне. Ви хочете зберегти контейнер цілим, навіть усередині `flat`. Конструкція `$(...)` робить свій аргумент _штучним_. Це означає, що вона позначає результат як один-єдиний елемент. Порівняйте попередній приклад із цим:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat($(@a), @b); # ([1 2 3] 4 5)
```

Тут `$(@a)` зберігає `@a` як один елемент. Але `@b` усе одно стає плоским. Він дає свої два значення. Це знову ідея сигіла `$`. Знак `$` означає «розглядай це як одну річ».
