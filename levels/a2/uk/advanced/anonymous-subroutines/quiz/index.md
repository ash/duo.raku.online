Що виведе ця програма?

```raku
(-> $a, $b { $a * $b })(3, 4).say
```

{:.quiz}
1 | 12
0 | 7
0 | 34
0 | an error

{% include quiz.html %}

<div class="extended-explanation">

Стрілочний блок може мати кілька параметрів. `-> $a, $b` приймає два. Тут програма не тримає блок у змінній. Блок стоїть у дужках. Програма викликає його одразу з `(3, 4)`. Тож `$a` отримує `3`, а `$b` отримує `4`. Блок множить їх. Результат — `12`. Потім `.say` у кінці виводить його.

</div>
