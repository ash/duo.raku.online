Ось один спосіб розв'язати завдання.

## Код

```raku
say (1, 2, 3).map(sub ($x) { $x * $x });
```

🦋 Ви можете знайти вихідний код у файлі [anonymous-square.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/anonymous-subroutines/anonymous-square.raku).

## Вивід

```
(1 4 9)
```

## Коментарі

1. Підпрограма `sub ($x) { $x * $x }` не має імені. Програма ніколи не тримає її у змінній. Програма дає її прямо в `map` як аргумент.

1. `map` використовує її для кожного елемента `1, 2, 3`. Вона множить кожне число саме на себе. Результат — `(1 4 9)`. Найчастіше анонімну підпрограму пишуть саме для цього. Її передають прямо, як тут.
