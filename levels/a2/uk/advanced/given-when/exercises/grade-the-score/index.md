## Завдання

Використайте `given`/`when`. Вік — це число в коді. Виведіть етап життя для цього віку. Використайте такі групи:

* `child` для 0–12,
* `teenager` для 13–19,
* `adult` для 20–64,
* `senior` для 65 і старше.

Вік менше нуля не має сенсу. Тож для будь-якого числа менше нуля виведіть `invalid`. Перевірте цей випадок першим, перед діапазонами.

## Приклад

Якщо вік — `30`, програма виводить:

```
adult
```
