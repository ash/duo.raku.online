Ось один спосіб розв'язати задачу.

## Код

```raku
my $age = 30;

given $age {
    when $_ < 0 { say 'invalid' }
    when 0..12  { say 'child' }
    when 13..19 { say 'teenager' }
    when 20..64 { say 'adult' }
    default     { say 'senior' }
}
```

🦋 Вихідний код можна знайти у файлі [grade-the-score.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/given-when/grade-the-score.raku).

## Вивід

```
adult
```

## Коментарі

1. Це розв'язання має два види `when`. Перший — це *умова*, `$_ < 0`. Тут `$_` — це топік з `given`. Ця умова ловить вік, який не має сенсу. Інші блоки `when` — це *діапазони*. Вони розкладають правильний вік за етапами.

1. Порядок важливий. Перевірка на від'ємний вік іде першою. Тож вона виконується перед усіма діапазонами. Значення `30` входить у `20..64`. Тож програма виводить `adult`.

1. Блок `default` — для будь-якого віку від 65 і старше. Жоден діапазон у списку не має такого віку.

Є й інший спосіб. Нехай `default` ловить *недійсний* ввід. Перелічіть кожен відомий етап. Запишіть `senior` як умову `$_ >= 65`. Усе інше недійсне, наприклад від'ємний вік:

```raku
given $age {
    when 0..12    { say 'child' }
    when 13..19   { say 'teenager' }
    when 20..64   { say 'adult' }
    when $_ >= 65 { say 'senior' }
    default       { say 'invalid' }
}
```

Тут `default` справді означає «жодне з переліченого». Який варіант кращий? Ви можете вибрати. Недійсний випадок рідкісний? Тоді поставте перевірку першою. Ви чітко перелічуєте всі дійсні етапи? Тоді зробіть недійсний випадок блоком `default`.
