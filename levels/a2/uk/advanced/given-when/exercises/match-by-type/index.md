## Завдання

`when` може зіставлятися з *типом*, а не лише зі значенням. Змінна зберігає число `3.14`. Використайте `given`/`when`, щоб сказати, яке це значення. Виведіть `integer` для `Int`. Виведіть `rational` для `Rat`. Виведіть `string` для `Str`.

## Приклад

Програма виводить:

```
rational
```
