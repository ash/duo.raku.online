Іноді програма має вибрати з кількох варіантів. Ланцюжок перевірок `if` і `elsif` може стати довгим. Він також повторює те саме. У такому випадку `given`/`when` часто зрозуміліший. Він схожий на оператор `switch` в інших мовах.

Блок `given` бере значення. Він робить це значення _топіком_. Топік — це спеціальна змінна `$_`. Потім Raku порівнює кожен блок `when` з топіком. Виконується перший `when`, який збігається:

```raku
my $n = 2;

given $n {
    when 1 { say 'one' }
    when 2 { say 'two' }
    when 3 { say 'three' }
}
```

Ця програма виводить:

```
two
```

Деякі інші мови мають оператор `switch`. Після збігу він може перейти до наступного випадку. Raku так не робить. Коли `when` збігається, виконується його блок. Потім блок `given` закінчується. Raku не перевіряє інші блоки `when`.

## Блок `default`

Блок `default` виконується, коли жоден блок `when` не збігся. Він працює як частина `else` в операторі `if`:

```raku
my $n = 5;

given $n {
    when 1 { say 'one' }
    when 2 { say 'two' }
    default { say 'many' }
}
```

`$n` — це не `1` і не `2`. Тож програма виводить:

```
many
```
