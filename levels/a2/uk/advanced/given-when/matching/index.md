Блок `when` робить більше, ніж просто перевіряє, чи рівні два значення. Він робить _розумне зіставлення_. Він порівнює топік зі значенням, яке ви даєте. Тож можна зіставляти з діапазонами, типами та умовами. Ви не обмежені окремими значеннями.

## Діапазони

Діапазон збігається, коли топік лежить усередині нього. Тож `given`/`when` добре підходить, щоб розкладати числа на групи:

```raku
my $score = 75;

given $score {
    when 90..100 { say 'A' }
    when 80..89  { say 'B' }
    when 70..79  { say 'C' }
    default      { say 'F' }
}
```

Значення `75` лежить у діапазоні `70..79`. Тож програма виводить:

```
C
```

## Типи

Тип збігається, коли топік має цей тип. Тож ви можете вибирати дію за видом значення:

```raku
my $value = 'Raku';

given $value {
    when Int { say 'an integer' }
    when Str { say 'a string' }
}
```

`$value` містить рядок. Тож програма виводить:

```
a string
```

## Умови

Можна також написати порівняння прямо. Усередині `when` топік — це `$_`. Тож умова на зразок `$_ < 0` збігається, коли вона істинна:

```raku
my $n = -7;

given $n {
    when $_ < 0 { say 'negative' }
    when 0      { say 'zero' }
    default     { say 'positive' }
}
```

Тут збігається перший `when`. Програма виводить:

```
negative
```
