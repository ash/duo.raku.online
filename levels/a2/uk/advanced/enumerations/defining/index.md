Щоб оголосити перелічення, напишіть ключове слово `enum`. Потім напишіть ім'я та список імен для констант:

```raku
enum Colour <red green blue>;
```

Це створює новий тип `Colour`. Це також створює три константи: `red`, `green` і `blue`. Константу можна використати просто за її іменем:

```raku
say red;   # red
say green; # green
```

За кожним іменем стоїть число. Raku сам дає ці числа. Він починає з нуля й іде за порядком вашого списку. Тож `red` — це `0`, `green` — `1`, а `blue` — `2`. Значення мають порядок. Тому константи можна порівнювати:

```raku
say red < blue; # True
```

Змінна може мати перелічення як свій тип. Тоді змінна приймає лише ці константи:

```raku
my Colour $c = green;
say $c; # green
```

Константа й щось інше можуть мати однакове ім'я. Тоді напишіть перед константою ім'я перелічення та `::`. Це працює завжди:

```raku
say Colour::red; # red
```

Перелічення об'єднує пов'язані константи. Воно дає їм ім'я та тип. Код із такими константами набагато зрозуміліший, ніж код із самими числами. Наступна тема розповідає про [числа, що стоять за іменами](/uk/advanced/enumerations/values-and-keys).
