## Завдання

Перелічення пов'язує імена з числами. Можна піти й у зворотний бік. Викличте тип перелічення як функцію, з числом. Тоді ви отримаєте константу для цього числа.

Визначте перелічення `Day` з константами від `Mon` до `Fri`. Дайте їм числа від `1` до `5`. Потім знайдіть константи для чисел `5` і `1`. Виведіть їх.

## Приклад

Програма виводить:

```
Fri
Mon
```
