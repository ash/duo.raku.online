Кожна константа перелічення має ім'я та число. Метод `.value` дає число. Метод `.key` дає ім'я як рядок:

```raku
enum Colour <red green blue>;

say green.value; # 1
say green.key;   # green
```

Raku нумерує константи від нуля. Але це можна змінити. Запишіть константи як пари. Тоді ви самі обираєте значення:

```raku
enum Day (Mon => 1, Tue => 2, Wed => 3, Thu => 4, Fri => 5);

say Tue.value; # 2
say Fri.value; # 5
```

Тут робочий тиждень починається з одиниці, а не з нуля.

Тип перелічення може також показати всі свої константи. Метод `.enums` повертає відображення. Відображення схоже на хеш. У цьому відображенні кожне ім'я має своє значення:

```raku
enum Colour <red green blue>;

say Colour.enums;       # Map.new((blue => 2, green => 1, red => 0))
say Colour.enums.elems; # 3
```

З `.value`, `.key` і `.enums` ви можете вільно рухатися. Можна перейти від константи до її числа. Можна перейти від числа назад до даних. І можна пройти по всьому набору. Тому перелічення корисні, наприклад, для меню, станів і таблиць пошуку.
