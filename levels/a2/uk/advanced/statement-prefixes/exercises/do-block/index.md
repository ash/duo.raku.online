## Завдання

`do` також працює перед операторами керування потоком виконання. Він робить їх виразами зі значенням. Використайте `do if 7 > 5 { 'big' } else { 'small' }`, щоб вибрати позначку. Присвойте позначку змінній `$label` і виведіть її.

## Приклад

Програма виводить:

```
big
```
