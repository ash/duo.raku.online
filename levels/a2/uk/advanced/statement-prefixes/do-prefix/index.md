Блок сам по собі — це оператор, а не вираз. Тож зазвичай його не можна присвоїти змінній. Префікс `do` робить блок виразом. Його значення — це значення **останнього** оператора в блоці:

```raku
my $x = do {
    my $a = 3;
    $a + 4;
};

say $x; # 7
```

Усередині блоку можна створювати змінні. Можна виконати кілька операторів і обчислити результат. `do` повертає значення блоку. Це корисно, коли для значення не вистачає одного виразу.

`do` також працює перед операторами керування потоком виконання. Ці оператори вибирають або повторюють код. З `do` вони теж повертають значення:

```raku
my $sign = do given 5 {
    when * > 0 { 'positive' }
    when * < 0 { 'negative' }
    default    { 'zero' }
};

say $sign; # positive
```

Тут `do given` робить увесь `given`/`when` виразом. Його значення — `positive`. Так само працюють `do if` і `do for`. Коротко кажучи, з `do` блок може стояти там, де Raku потрібне значення. Це працює і для керівних конструкцій.
