Машинні типи мають назви з малих літер: `int`, `num` та `str`. Ви оголошуєте з ними змінну так само, як з `Int` чи `Str`:

```raku
my int $i = 42;
my num $n = 3.14e0;
say $i; # 42
say $n; # 3.14
```

Машинне значення прямо відповідає регістру або слову машини. Це маленькі місця для даних усередині комп'ютера. Звичайне значення Raku має навколо себе об'єкт-обгортку. Машинне значення не має обгортки. Тому машинні типи швидші й займають менше пам'яті. Це важливо у великих масивах. Це також важливо в коротких циклах, які багато обчислюють.

Одну річ варто знати одразу. Машинна змінна ніколи не буває невизначеною. Звичайна змінна `Int` спершу невизначена. `say` показує її як `(Int)`. А машинний `int` починає з **нуля**:

```raku
say (my Int $a); # (Int)
say (my int $b); # 0
```

Те саме стосується машинних масивів. Щоб оголосити такий масив, напишіть машинний тип перед змінною з `@`:

```raku
my int @numbers = 10, 20, 30;
say @numbers.sum; # 60
```

Такий масив зберігає свої елементи як прості машинні цілі числа. Це не повні об'єкти `Int`. Тому масив займає менше пам'яті. Ви можете запитати машинне значення про його тип. Тоді Raku автоматично кладе його у відповідний повний тип. Ми кажемо, що значення _упаковане_. Ось чому `(my int $b).WHAT` показує `(Int)`.
