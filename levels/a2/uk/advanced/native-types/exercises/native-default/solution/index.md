Ось один спосіб розв'язати задачу.

## Код

```raku
my num $n;
my str $s;

say $n;
say "[$s]";
```

🦋 Вихідний код можна знайти у файлі [native-default.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/native-default.raku).

## Вивід

```
0
[]
```

## Коментарі

1. Машинний `num` не може бути невизначеним. Тому він починає з `0`, як машинний `int`. Він не починає з `(Num)`.

1. Машинний `str` починає з порожнього рядка. Тому між дужками нічого немає. Машинний тип ніколи не містить невизначеного значення.

1. Тут типи дуже важливі. Спробуйте їх прибрати. Напишіть натомість `my $n; my $s;`. Тепер змінні — звичайні контейнери. На початку вони *невизначені*: вони містять `Any`. Тоді `say $n` виводить `(Any)`. Рядок інтерполює `$s`, але `$s` невизначена. Тому Raku показує попередження: *«Use of uninitialized value … in string context»*. Тільки машинні типи `num` і `str` дають початкові значення. Це `0` і порожній рядок.
