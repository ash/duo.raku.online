Ось один спосіб розв'язати задачу.

## Код

```raku
my uint8 @bytes = 100, 200, 255;
say @bytes.sum;
```

🦋 Вихідний код можна знайти у файлі [native-array.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/native-array.raku).

## Вивід

```
555
```

## Коментарі

1. Напишіть машинний тип фіксованого розміру `uint8` перед масивом із `@`. Тоді Raku зберігає кожен елемент в одному байті. Цей байт беззнаковий: у нього немає знака мінус. Такий масив займає мало пам'яті. Це добре для двійкових даних.

1. Кожен *елемент* має межу, `0..255`. За цією межею значення загортаються. Але ця межа не стосується суми елементів. `.sum` кладе суму у звичайний `Int`. Тож `100 + 200 + 255` дає повні `555`.
