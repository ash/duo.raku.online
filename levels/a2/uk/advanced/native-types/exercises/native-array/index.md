## Завдання

Машинні типи фіксованого розміру добре підходять для масивів байтів. Такі масиви займають мало пам'яті. Створіть масив `uint8` зі значеннями `100`, `200` та `255`. Кожне значення вміщується в один байт. Виведіть суму елементів.

Елементи лишаються в діапазоні `0..255`. Але їхня сума може бути більшою. `.sum` повертає звичайний `Int`.

## Приклад

Програма виводить:

```
555
```
