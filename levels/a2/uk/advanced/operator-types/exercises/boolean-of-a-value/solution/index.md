Ось один спосіб розв'язати задачу.

## Код

```raku
say ?0;
say ?5;
```

🦋 Вихідний код можна знайти у файлі [boolean-of-a-value.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operator-types/boolean-of-a-value.raku).

## Вивід

```
False
True
```

## Коментарі

1. `?` — це префіксний оператор. Він стоїть перед своїм операндом. Він повертає булеве значення операнда.

1. `0` — хибне, а `5` — істинне. Тож програма виводить `False` і `True`.
