## Завдання

Напишіть дві мульти-підпрограми з іменем `abs-value`. Вони приймають ціле число й повертають його абсолютне значення. Абсолютне значення — це число без знака мінус. Використайте речення `where` для від'ємних чисел. Не використовуйте `if` у підпрограмах. Вбудований `abs` теж не використовуйте.

Виведіть результат для `-7` та для `4`.

## Приклад

Програма виводить:

```
7
4
```
