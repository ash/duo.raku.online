## Завдання

Ось модуль `Greeting.rakumod`. Він експортує підпрограму `hello`:

```raku
unit module Greeting;

sub hello($name) is export {
    "Hello, $name!"
}
```

Завантажте цей модуль через `require`, а не через `use`. Тоді програма завантажує його **під час виконання**, коли вона вже працює. `require` не імпортує імена автоматично. Тож перелічіть потрібне ім'я, ось так: `require Greeting <&hello>;`. Потім викличте `hello('Sam')` і виведіть результат.

Тепер покажіть, чим корисне завантаження під час виконання. Покладіть `require` усередину `sub MAIN` із прапорцем `--quiet`. Модуль завантажується *лише* тоді, коли вам справді потрібне привітання. З `--quiet` програма зовсім не торкається модуля. Вона лише виводить `Silence.`

## Приклад

Запустіть програму з модулем на шляху пошуку. Вона виводить:

```console
$ raku -I. require-import.raku
Hello, Sam!

$ raku -I. require-import.raku --quiet
Silence.
```
