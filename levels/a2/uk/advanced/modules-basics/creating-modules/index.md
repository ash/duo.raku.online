З часом програми стають більшими. Тоді їх добре розбити на частини. Ці частини можна використовувати знову. Така частина коду — це _модуль_. Він лежить у своєму файлі. Інші програми можуть завантажити його й використати.

Файл модуля має розширення `.rakumod`. Він починається з `unit module` та імені модуля. Зазвичай підпрограми в модулі приватні. Лише сам модуль може їх використовувати. Хочете поділитися підпрограмою з іншим кодом? Позначте її трейтом `is export`.

Ось модуль у файлі `Greeting.rakumod`:

```raku
unit module Greeting;

sub hello($name) is export {
    return "Hello, $name!";
}
```

Підпрограма `hello` має `is export`. Тож її бачить кожна програма, яка використовує модуль. Підпрограма без `is export` залишається приватною. Лише сам модуль може її використовувати.

Модуль також може ділитися даними. Для цього він використовує змінні `our`. Інший код може дістатися до них через ім'я модуля. Додаймо до `Greeting` номер версії. Нам потрібен лише ще один рядок у файлі:

```raku
our $version = '1.0';
```

Тепер у `Greeting.rakumod` є цей рядок. Тож значення доступне як `$Greeting::version`. Це працює всюди, де ви завантажуєте модуль.

Наступні теми показують, [як програма завантажує такий модуль](/uk/advanced/modules-basics/using-modules). Також вони показують, що програма від нього отримує.
