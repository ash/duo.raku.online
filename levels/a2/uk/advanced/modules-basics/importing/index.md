Є кілька способів внести модуль у програму. Для цього в Raku є три оператори: `use`, `need` і `require`. Вони відрізняються двома речами. Перша — _коли_ вони завантажують модуль. Друга — _що_ вони дають програмі.

## `use`

Ви вже знаєте `use`. Він завантажує модуль під час компіляції, ще до запуску програми. Також він імпортує експортовані імена модуля. Тож їх можна викликати напряму:

```raku
use Greeting;
say hello('Anna'); # Hello, Anna!
```

## `need`

`need` теж завантажує модуль під час компіляції. Але він _не_ імпортує експортовані імена. До змінних `our` модуля ви все одно можете дістатися. Для цього використайте ім'я модуля:

```raku
need Greeting;
say $Greeting::version; # 1.0
```

Після `need Greeting` простий `hello(...)` не працює. Програма нічого не імпортувала. Доступні лише повні імена, з ім'ям модуля в них. Приклад — `$Greeting::version`.

## `require`

`require` завантажує модуль _під час виконання_, а не під час компіляції. Це корисно в деяких випадках. Іноді ви не знаєте, чи потрібен вам модуль. Ви дізнаєтеся це лише тоді, коли програма працює. Наприклад, користувач може ввести ім'я модуля.

Модуль завантажується під час виконання. Тож нічого не імпортується автоматично. Після імені модуля напишіть потрібні імена. Візьміть їх у кутові дужки. Тоді вони імпортуються. Тож їх можна викликати напряму:

```raku
require Greeting <&hello>;
say hello('Anna'); # Hello, Anna!
```

Зазвичай `use` — правильний вибір. `need` і `require` — для рідших випадків.
