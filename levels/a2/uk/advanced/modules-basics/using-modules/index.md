Щоб скористатися модулем, завантажте його оператором `use`. Після цього ви можете використовувати імена, які модуль експортує. Це так, ніби ви написали їх самі.

Візьмімо файл `Greeting.rakumod` з попередньої теми. Програма використовує його так:

```raku
use Greeting;

say hello('Anna');
```

`hello` має позначку `is export`. Тож оператор `use` робить її доступною. Програма викликає її напряму:

```
Hello, Anna!
```

Raku має знайти модуль. Тому модуль має бути на шляху пошуку модулів. Це список місць, де Raku шукає модулі. Можливо, файл модуля лежить у тому самому каталозі, що й ваша програма. Тоді скажіть Raku шукати там за допомогою опції `-I.`. Крапка означає «поточний каталог»:

```console
$ raku -I. program.raku
Hello, Anna!
```

Raku знаходить встановлені модулі автоматично. Про них ви дізнаєтеся пізніше, у темі [Встановлення модулів із мережі](/uk/advanced/installing-modules). Тож опція `-I` потрібна лише для модулів поруч із вашою програмою.
