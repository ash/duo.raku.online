## Завдання

Програма може мати більше ніж один фазер `END`. Тоді вони виконуються у **зворотному** порядку. Останній у коді виконується першим. Це називають «останнім прийшов — першим вийшов».

Напишіть два фазери `END`. Перший виводить `first END`. Другий виводить `second END`. Після них напишіть простий `say 'body'`. Який порядок виводу? Спершу вгадайте його. Потім отримайте цей вивід своєю програмою.

## Приклад

Програма виводить:

```
body
second END
first END
```
