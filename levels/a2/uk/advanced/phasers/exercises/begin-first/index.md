## Завдання

Фазер `BEGIN` — це не лише блок, який виконується рано. Це також *вираз*. Raku обчислює його значення один раз, коли компілює програму. Потім значення лишається в програмі й не змінюється.

Створіть змінну `$compiled`. Задайте її перше значення через `BEGIN { 2 + 3 }`. Потім виведіть змінну. Raku обчислює `2 + 3` під час компіляції. Але збережене значення можна використати й тоді, коли програма працює.

## Приклад

Програма виводить:

```
5
```
