## Завдання

Фазер `END` виконується після основного коду. Тож він бачить *остаточні* значення ваших змінних. Тому він чудово підходить для підсумку.

Створіть лічильник `$count` зі значенням `0`. Напишіть фазер `END`, який виводить `processed $count items`. Поставте фазер перед основним кодом. Потім в основному тілі тричі додайте 1 до лічильника. Використайте для цього цикл. Підсумок має показати останнє значення лічильника. Він не має показувати старе значення з рядка фазера.

## Приклад

Програма виводить:

```
processed 3 items
```
