Ось один спосіб розв'язати задачу.

## Структура

```
Greet-Simple/
├── META6.json
├── README.md
├── lib/
│   └── Greet/
│       └── Simple.rakumod
└── t/
    └── 01-basic.rakutest
```

## Коментарі

1. `META6.json` лежить нагорі. Вихідний код модуля лежить у `lib/`. Його шлях каталогів відповідає частинам імені. В імені `::` розділяє ці частини.

1. Тести лежать у `t/`. Використовуйте цю структуру. Тоді `zef test .` і `zef install .` працюють у верхньому каталозі.
