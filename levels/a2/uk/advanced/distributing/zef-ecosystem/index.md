`zef` встановлює модулі Raku. Ви вже використовували його, щоб встановлювати модулі за іменем. Він також працює з дистрибутивом у локальному каталозі. Зайдіть у каталог дистрибутива. Звідти ви можете одразу протестувати й встановити його:

```
zef test .
zef install .
```

`zef test .` запускає файли під `t/`. `zef install .` встановлює дистрибутив у ваш Raku. Тоді інші програми можуть завантажити його через `use`. Ви також можете встановити модуль за іменем, наприклад `zef install Cro`. Це робить те саме. Але спершу команда завантажує дистрибутив з екосистеми.

Можливо, ви захочете **опублікувати** власний дистрибутив. Тоді інші люди зможуть встановити його за іменем. Для цього ви завантажуєте його в екосистему. Зазвичай люди використовують для цього `fez`:

```
fez upload
```

Це пакує поточний дистрибутив і надсилає його в екосистему Raku. Після цього `zef install Maths::Simple` працює для будь-кого.

> Цим командам потрібні встановлені `zef`/`fez` і мережа. Щоб завантажувати, вам ще потрібен обліковий запис в екосистемі.

Отже, спільний модуль проходить три кроки. Спершу ви даєте йому стандартну структуру і `META6.json`. Далі ви тестуєте його через `zef test`. Потім ви публікуєте його через `fez upload`. Після цього це просто ще одне ім'я. Будь-хто може встановити його через `zef install`.
