Підпрограма хоче **змінити змінну викликача** через параметр. Який трейт це дозволяє?

{:.quiz}
1 | `is rw`
0 | `is copy`
0 | `is default`
0 | жоден — параметри доступні для запису за замовчуванням

{% include quiz.html %}

<div class="extended-explanation">

Зазвичай параметр доступний лише для читання. Тож звичайному параметру не можна присвоїти нове значення. `is rw` зв'язує параметр із власною змінною викликача. Тож зміну всередині підпрограми видно ззовні. `is copy` працює інакше. Він дає вам *копію*, яку можна змінювати. Змінна викликача не змінюється.

</div>
