Ви додаєте _трейт_ ключовим словом `is`, одразу після оголошення. Трейт виконується під час компіляції. Він змінює сталу властивість того, що має цей трейт. У Raku багато трейтів. Кількома з них ви вже користувалися.

Зазвичай параметри підпрограми доступні **лише для читання**. Усередині підпрограми не можна присвоїти їм нові значення. Трейт `is copy` дає вам власну копію аргументу. Цю копію можна змінювати. Зміна лишається всередині підпрограми. Змінна викликача не змінюється:

```raku
sub greet($name is copy) {
    $name = "dear $name";
    say "Hello, $name!";
}

my $who = 'Anna';
greet($who); # Hello, dear Anna!
say $who;    # Anna — власна змінна викликача недоторкана
```

Трейт `is rw` іде ще далі. Він зв'язує параметр зі змінною викликача. Ви змінюєте параметр усередині підпрограми. Тоді цю зміну видно й ззовні:

```raku
sub bump($n is rw) {
    $n++;
}

my $x = 10;
bump($x);
say $x; # 11
```

Без одного з цих трейтів `$n++` дає помилку. Це тому, що параметр доступний лише для читання.

Ще один поширений трейт задає типове значення:

```raku
my $port is default(8080);
say $port; # 8080
```

Тут `is default` дає змінній значення за замовчуванням. Змінна має це значення, коли в ній немає нічого іншого. Є багато вбудованих трейтів: `is rw`, `is copy`, `is default` та інші. Кожен із них додає до оголошення одну особливу поведінку. Це відбувається під час компіляції. Наступна тема показує, що список трейтів не закритий. [Ви можете створювати власні трейти](/uk/advanced/traits-pragmas/writing-a-trait).
