## Завдання

Зазвичай параметри підпрограми доступні лише для читання. Тож підпрограма не може змінити змінну викликача. Трейт `is rw` знімає це обмеження.

Напишіть підпрограму `double`. Вона має один параметр із трейтом `is rw`. Підпрограма подвоює сам параметр: `$n *= 2`. Викличте `double` зі змінною, у якій є `21`. Потім виведіть змінну. Тепер вона дорівнює `42`.

## Приклад

Програма виводить:

```
42
```
