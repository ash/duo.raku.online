Одна функція модуля `Test` проходить, коли умова істинна. Умова є `True` або `False`. Яка це функція?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` приймає умову. Він проходить, коли умова істинна. `is` порівнює значення, яке ви отримуєте, зі значенням, яке ви очікуєте. `plan` каже, скільки тестів очікувати. `done-testing` завершує файл і виводить план.

</div>
