## Завдання

Напишіть файл тестів. Використайте `plan`, а не `done-testing`. Через `plan` скажіть на початку, що у файлі рівно дві перевірки. Зробіть такі дві перевірки:

1. За допомогою `is-deeply` перевірте, що список `3, 1, 2` після сортування дає `[1, 2, 3]`.
1. За допомогою `is` перевірте, що `10 % 3` дорівнює `1`.

Напишіть власний короткий опис для кожної перевірки.

## Приклад

Нехай описи будуть `sorted` і `remainder`. Тоді програма виводить:

```
1..2
ok 1 - sorted
ok 2 - remainder
```
