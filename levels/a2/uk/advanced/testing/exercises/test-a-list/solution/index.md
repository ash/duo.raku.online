Ось один спосіб розв'язати задачу.

## Код

```raku
use Test;

plan 2;

my @sorted = (3, 1, 2).sort;
is-deeply @sorted, [1, 2, 3], 'sorted';

is 10 % 3, 1, 'remainder';
```

🦋 Вихідний код можна знайти у файлі [test-a-list.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/testing/test-a-list.raku).

## Вивід

```
1..2
ok 1 - sorted
ok 2 - remainder
```

## Коментарі

1. `plan 2` вказує кількість до запуску будь-якого тесту. Тож рядок `1..2` іде першим. Файл може виконати іншу кількість перевірок. Тоді весь набір тестів провалюється. `done-testing` не може так вас захистити.

1. `is-deeply` перевіряє, що два списки точно рівні, і їхні типи теж. Сортування `3, 1, 2` дає `1, 2, 3`. Це збігається.

1. `is` перевіряє, що два значення рівні. Якщо ні, він показує обидва значення. Тут `10 % 3` дорівнює `1`. Це очікуване значення. Тож другий тест теж проходить.
