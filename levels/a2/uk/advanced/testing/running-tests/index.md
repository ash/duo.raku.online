Один файл тестів — це просто програма на Raku. Тож ви можете запустити його, як будь-яку програму:

```
raku t/01-basic.rakutest
```

Він показує на екрані свій вивід у форматі TAP. Але у вас може бути більше ніж один-два файли. Тоді вам потрібен _запускач тестів_. Він запускає всі тести в каталозі. Потім він дає короткий підсумок результатів. Запускач тестів у Raku — це `prove6`:

```
prove6 t/
```

Команда запускає кожен файл тестів під `t/`. Вона показує, скільки файлів і тестів пройшло. У кінці вона дає один результат для всього: пройдено чи не пройдено. Це набагато легше читати, ніж сирий TAP із кожного файлу.

Дистрибутив може мати `META6.json`. Тоді інструмент для модулів запускає його тести за вас:

```
zef test .
```

`zef test` знаходить каталог `t/`. Він запускає всі тести й показує результат. Те саме відбувається автоматично, перш ніж хтось встановлює дистрибутив. Отже, тести мають два завдання. Ви запускаєте їх через `prove6`, коли працюєте над кодом. А екосистема запускає їх, перш ніж хтось встановить дистрибутив. Так вона перевіряє дистрибутив.

> Файли тестів мають розширення `.rakutest` або `.t`. Зазвичай їхні назви починаються з числа, наприклад `t/01-basic.rakutest`.
