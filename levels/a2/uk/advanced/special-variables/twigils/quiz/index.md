Raku знаходить **динамічну** змінну через стек викликів. Який твіґіл показує, що змінна динамічна?

{:.quiz}
1 | `*`
0 | `?`
0 | `!`
0 | `.`

{% include quiz.html %}

<div class="extended-explanation">

Твіґіл `*` показує динамічну змінну, як у `$*OUT` чи `$*greeting`. Твіґіл `?` — для компіляційних значень. `!` — для приватного атрибута. А `.` — для методу доступу до атрибута.

</div>
