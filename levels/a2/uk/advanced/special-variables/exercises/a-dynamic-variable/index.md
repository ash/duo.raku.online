## Завдання

Динамічна змінна має твіґіл `*`. Raku шукає її через стек викликів, а не за лексичною областю видимості. Тож підпрограма може бачити різні значення. Значення залежить від того, хто викликає підпрограму. Тоді блок може запускати код, який він викликає, від імені когось іншого.

1. Оголосіть динамічну змінну `$*user` зі значенням `'guest'`.
2. Напишіть підпрограму `whoami`. Вона виводить `running as `, а потім поточне значення `$*user`, наприклад `running as guest`. Вона не має параметрів. Вона має читати `$*user` напряму.
3. Викличте `whoami` один раз на верхньому рівні. Вона показує `guest`.
4. Потім створіть блок. У ньому знову оголосіть `$*user` як `'admin'`. Викличте там *ту саму* `whoami`. Тепер вона показує `admin`.

## Приклад

Програма виводить:

```
running as guest
running as admin
```
