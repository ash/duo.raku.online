## Завдання

Покажіть, як динамічна змінна проходить крізь підпрограму посередині. Ця підпрограма нічого не знає про змінну.

Напишіть підпрограму `log-it($msg)`. Вона виводить повідомлення. Перед повідомленням вона виводить динамічну змінну `$*prefix`. Напишіть другу підпрограму, `task`. Вона лише викликає `log-it('working')`. Сама вона ніколи не використовує `$*prefix`. Потім викличте `task` два рази. Щоразу викликайте її зсередини блоку. Кожен блок дає `$*prefix` інше значення: спершу `INFO`, потім `DEBUG`.

## Приклад

Програма виводить:

```
INFO: working
DEBUG: working
```
