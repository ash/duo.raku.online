## Завдання

`$_` — це *топічна* змінна. Цикл `for` записує в неї кожен елемент, один за одним. Деякі виклики методів починаються з крапки, як-от `.chars`. Перед крапкою нічого немає. Такий виклик працює з `$_`. Тож `.chars` означає `$_.chars`.

Пройдіть циклом по трьох рядках: `'apple'`, `'fig'` та `'cherry'`. Для кожного рядка виведіть такий рядок: `<слово> has <n> letters`. Для слова використайте топік `$_`. Для його довжини використайте виклик `.chars`. Він починається з крапки. Подивіться, як `$_` стає кожним рядком, один за одним.

## Приклад

Програма виводить:

```
apple has 5 letters
fig has 3 letters
cherry has 6 letters
```
