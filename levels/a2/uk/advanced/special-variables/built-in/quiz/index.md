Яка вбудована змінна зберігає аргументи командного рядка програми?

{:.quiz}
0 | `$*ARGS`
1 | `@*ARGS`
0 | `@*ARGV`
0 | `%*ENV`

{% include quiz.html %}

<div class="extended-explanation">

Аргументи командного рядка надходять як *список*. Тож змінна має сигіл `@`. Вона також динамічна, тому має твіґіл `*`. Виходить `@*ARGS`. `%*ENV` — це хеш середовища. У ньому немає аргументів. `@*ARGV` — це ім'я з Perl. Raku його не використовує.

</div>
