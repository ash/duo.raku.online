Ще два інструменти інтроспекції — це `HOW` і `WHO`. Вони завершують набір.

## `HOW`

За кожним значенням у Raku стоїть _метаоб'єкт_. Метаоб'єкт — це об'єкт. Він знає, як працює тип значення. `HOW` — це скорочення від _Higher Order Workings_. Він повертає метаоб'єкт:

```raku
my $x = 42;
say $x.HOW.^name; # Perl6::Metamodel::ClassHOW
```

Ви вже використовуєте метаоб'єкт. Можливо, ви цього не помітили. `.^` у `.^name` — це виклик методу. Цей виклик іде через `HOW`. Ці два рядки роблять те саме:

```raku
my $x = 42;
say $x.^name;        # Int
say $x.HOW.name($x); # Int
```

Тож `$x.^name` — це лише короткий запис для `$x.HOW.name($x)`. Зверніть увагу, що об'єкт знову йде як аргумент. Чому? Усі значення типу мають один *спільний* метаоб'єкт. Методи метаоб'єкта — це метаметоди. Метаметод має знати, про який об'єкт ви питаєте. Форма `.^` передає об'єкт за вас. Для `name` Raku не використовує цей аргумент. Але правильний, загальний спосіб — передавати його. Деякі метаметоди таки його використовують.

Це також стосується інших метаметодів. Один приклад — `.^methods`. Він дає список методів. Ці методи можна викликати для значення.

## `WHO`

`WHO` повертає _пакунок_ імені. Це таблиця імен, або символів, у цьому просторі імен:

```raku
say Int.WHO.^name; # Stash
```

`Stash` — це хеш для таблиці символів. Він корисний для роботи з модулями. З ним можна шукати імена модуля. Ми повернемося до нього в [розділі про модулі](/uk/advanced/module-introspection). Поки що просто запам'ятайте, що `WHO` існує. Також запам'ятайте, що він дає.
