## Завдання

Контейнер може мати типове значення. Ви задаєте його трейтом `is default`. Доки ви не присвоїте значення, змінна повертає це типове значення. `.VAR.default` теж його показує.

Оголосіть скаляр `$count`. Його типове значення має бути `0`. Нічого йому не присвоюйте. Виведіть змінну. Потім виведіть типове значення її контейнера. Обидва рядки мають показати `0`.

## Приклад

Програма виводить:

```
0
0
```
