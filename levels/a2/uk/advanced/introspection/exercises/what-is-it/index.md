## Завдання

`WHAT` робить більше, ніж описує тип. Він повертає сам об'єкт типу. Об'єкти типу можна порівнювати оператором `===`.

Оголосіть дві змінні. `$a` зберігає ціле число `42`. `$b` зберігає рядок `'x'`. Для кожної змінної подивіться на її `WHAT`. Це тип `Int`? Виведіть відповідь.

## Приклад

Програма виводить:

```
True
False
```
