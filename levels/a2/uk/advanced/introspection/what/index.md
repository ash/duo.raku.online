`WHAT` — це псевдометод. Він дає вам тип значення. Ви використовуєте його майже як `.^name`:

```raku
my $var = 42;

say $var.^name;
say $var.WHAT;
```

Обидва виводять тип, але виглядають трохи по-різному. `.^name` дає лише ім'я. `WHAT` дає сам тип як об'єкт типу. Він показує його в круглих дужках:

```
Int
(Int)
```

Візьміть змінну без обмеження типу. Спочатку її тип — `Any`. Потім ви присвоюєте значення. Тепер `^name` і `WHAT` обидва показують тип цього значення:

```raku
my $var;
say $var.^name; # Any
say $var.WHAT;  # (Any)

$var = 'Hello';
say $var.^name; # Str
say $var.WHAT;  # (Str)
```

З обмеженням типу Raku знає тип одразу. Це так навіть до того, як ви присвоїте значення:

```raku
my Str $var;
say $var.^name; # Str
say $var.WHAT;  # (Str)

$var = 'Hello';
say $var.^name; # Str
say $var.WHAT;  # (Str)
```

## Порівняння об'єктів типу

`WHAT` повертає сам об'єкт типу. Тож ви можете порівняти два об'єкти типу. Для цього використовуйте оператор `===`. Це оператор _тотожності значень_. Він перевіряє, чи обидві сторони — те саме значення. Кожен тип має лише один об'єкт типу. Тож `===` легко перевіряє, чи мають два значення той самий тип:

```raku
my $a = 42;
my $b = 100;

say $a.WHAT === $b.WHAT; # True  — обидва Int
say $a.WHAT === Int;     # True
say $a.WHAT === Str;     # False
```

`==` порівнює числа. А `===` порівнює тотожність. Тож він працює прямо з об'єктами типу. Він також працює з іншими значеннями.
