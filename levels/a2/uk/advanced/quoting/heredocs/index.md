_Heredoc_ — це форма цитування для тексту з багатьма рядками. Навколо тексту в нього немає роздільників. Натомість ви даєте слово-термінатор через `:to`. Термінатор позначає кінець. Рядок починається з наступного рядка коду. Він триває до рядка, де є лише це слово:

```raku
my $text = q:to/END/;
Hello,
World!
END

print $text;
```

Програма виводить:

```
Hello,
World!
```

Термінатор позначає кінець тексту. Тут це `END`, але можна взяти будь-яке слово. Подивіться на `print`. Текст зберігає перехід рядка перед термінатором. Тож текст уже закінчується розривом рядка. `say` додає другий. Тоді в кінці ви отримуєте порожній рядок. Цей heredoc починається з `q:to`. Тому текст не інтерполюється. Щоб інтерполювати змінні, використовуйте `qq:to`:

```raku
my $name = 'Anna';

my $greeting = qq:to/EOF/;
Dear $name,
Welcome!
EOF

print $greeting;
```

Ось корисна деталь. Подивіться на **відступ закривального термінатора**. Raku прибирає його з кожного рядка тексту. Тож heredoc можна писати з відступом, як код навколо. Відступ не потрапляє в рядок:

```raku
sub greeting {
    return q:to/END/;
        Hello,
        World!
        END
}

print greeting;
```

Це виводить ті самі `Hello,` та `World!`, що й перший приклад. Тут закривальне `END` має попереду вісім пробілів. Тому Raku прибирає вісім пробілів із кожного рядка. Функція повертає просто `Hello,\nWorld!`. На початку немає пробілів.

Закривальний термінатор визначає, скільки пробілів прибирає Raku. Тож кожен рядок тексту потребує щонайменше стільки пробілів. Можливо, у рядку менше пробілів. Тоді Raku не може прибрати їх усі. Він попереджає: *Asked to remove 8 spaces, but the shortest indent is 4 spaces*. Уникайте цього попередження. Не робіть термінатору більший відступ, ніж у будь-якого рядка тексту. Heredoc-и — природний вибір для шаблонів і повідомлень. Насправді вони добрі для будь-якого тексту з кількох рядків.
