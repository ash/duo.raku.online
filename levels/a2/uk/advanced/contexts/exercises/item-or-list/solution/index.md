Ось один спосіб розв'язати задачу.

## Код

```raku
my @a = 1, 2, 3;
my $count = 0;

my $x = $(@a);
$count++ for @($x);
say $count;
```

🦋 Вихідний код можна знайти у файлі [item-or-list.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/contexts/item-or-list.raku).

## Вивід

```
3
```

## Коментарі

1. `my $x = $(@a)` задає штучний контекст. Тож увесь масив іде в один скаляр `$x`. Масив не розпадається на свої елементи.

1. Далі `@($x)` задає списковий контекст. Тепер `$x` знову стає трьома елементами. Тож цикл `for` виконується тричі. У кінці лічильник дорівнює `3`. Ці два контекстуалізатори роблять протилежні речі. `$( )` пакує список в один елемент. `@( )` знову його розпаковує.
