Що виведе ця програма?

```raku
my @a = 1, 2, 3;
my $n = 0;
$n++ for $(@a);
say $n;
```

{:.quiz}
0 | 3
1 | 1
0 | 0
0 | 6

{% include quiz.html %}

<div class="extended-explanation">

Контекстуалізатор `$( … )` задає штучний контекст. Тож масив — це одне значення, а не список елементів. Цикл `for` бачить один елемент. Тож він виконує своє тіло лише раз. У кінці `$n` дорівнює `1`. Без `$( )` цикл виконується тричі.

</div>
