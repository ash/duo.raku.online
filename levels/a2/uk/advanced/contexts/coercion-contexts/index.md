Три контексти трапляються дуже часто. У першому значення поводиться як число. У другому воно поводиться як рядок. У третьому воно поводиться як `True` або `False`. Кожен із цих контекстів має префіксний оператор. Оператор стоїть перед значенням. Він прямо задає контекст:

* `+` — числовий контекст: значення поводиться як число
* `~` — рядковий контекст: значення поводиться як рядок
* `?` — булевий контекст: значення поводиться як `True` або `False`

Застосуйте їх до масиву. `+` дає довжину масиву. `~` дає його елементи з пробілами між ними. `?` каже, чи є в масиві елементи:

```raku
my @a = 1, 2, 3;

say +@a; # 3
say ~@a; # 1 2 3
say ?@a; # True
```

Порожній масив у числовому контексті — це `0`. У булевому контексті він — `False`:

```raku
my @empty;
say +@empty; # 0
say ?@empty; # False
```

Вам не завжди треба писати ці оператори. Часто Raku сам задає потрібний контекст за вас. Арифметика ставить значення в числовий контекст. З'єднання рядків ставить їх у рядковий контекст. А `if`, `while`, `and` та `or` ставлять свою умову в булевий контекст:

```raku
my @a = 1, 2, 3;

say 10 + @a;              # 13, тут @a це його довжина: 3
say 'items: ' ~ @a;       # items: 1 2 3
if @a { say 'not empty' } # not empty
```

Тож `if @array { … }` працює так, як ви чекаєте. Масив з елементами є істинним. Префіксними операторами ви самі просите ті самі перетворення.

Ви також можете поставити `if` після виразу. Тоді код короткий і зрозумілий:

```raku
say "{+@a} items are there" if @a; # 3 items are there
```
