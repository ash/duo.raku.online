title: Вибір правильного методу
---

{% include menu.html %}

Візьміть прості скаляри, як числа й рядки. Тут усі три форми виглядають однаково. Вони різні для значень із кількох частин. Вони також різні для невизначених значень. Ось `Pair`, показаний трьома способами:

```raku
say (foo => 1).gist; # foo => 1
say (foo => 1).Str;  # foo	1
say (foo => 1).raku; # :foo(1)
```

Ось просте правило:

* [`.gist`](../gist) — для виводу, який люди *читають* (`say`, `note`).
* [`.Str`](../str) — для виводу, який є *простим текстом* (`print`, `put`, значення всередині рядків, оператор `~`).
* [`.raku`](../raku-method) — для форми, *схожої на код*, під час налагодження (`dd`).

Ви можете писати власні класи. У класі ви можете самі визначити кожен із цих методів. Тоді ваші власні об'єкти теж гарно друкуються. Ми повернемося до цього в наступній частині. Там ми [створимо класи](/uk/oop/classes).
