---
title: Метод `.gist`
---

{% include menu.html %}

Метод `.gist` повертає **зручну для людини** форму значення. Це форма, яку ви хочете *читати*. `say` друкує саме цю форму. `note` теж її друкує. Вони викликають `.gist` для кожного аргументу.

```raku
say 42.gist;     # 42
say 'Raku'.gist; # Raku
```

Для простих значень gist — це просто саме значення. Деякі дані мають кілька частин. Для таких даних `.gist` додає трохи форматування. Тоді структуру все одно легко читати:

```raku
my @a = 'alpha', 'beta', 'gamma';
say @a.gist; # [alpha beta gamma]
```

Об'єкт типу — це значення. Воно представляє сам тип. Його gist — це назва типу в дужках. Тому його легко побачити у виводі:

```raku
say Int.gist; # (Int)
```
