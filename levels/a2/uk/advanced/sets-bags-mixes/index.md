У Raku є масиви й хеші. Також є кілька особливих контейнерів для груп значень. Найпростіший із них — `Set`. Його значення _різні_, тобто кожне значення відрізняється від інших. Значення в множині не мають порядку. Значення або є в множині, або його там немає. Якщо значення трапляється двічі, множина ігнорує друге.

Щоб створити множину, використайте підпрограму `set`. Значення, що повторюються, стають одним значенням:

```raku
my $s = set(1, 2, 3, 2, 1);
say $s.elems; # 3
```

Ми даємо множині п'ять чисел. Але вона має лише три елементи. Це тому, що `1` і `2` трапляються більше ніж один раз.

Ви зазвичай ставите множині одне головне запитання. Чи є значення в множині? Оператор `∈` відповідає на нього. Ви читаєте `∈` як «є елементом». Він повертає булеве значення, `True` або `False`:

```raku
say 2 ∈ set(1, 2, 3); # True
say 9 ∈ set(1, 2, 3); # False
```

Можливо, ви хочете використовувати лише прості символи ASCII. Тоді пишіть той самий оператор як `(elem)`:

```raku
say 2 (elem) set(1, 2, 3); # True
```

Наступні теми показують, як поєднувати множини. Вони також показують мультимножини й суміші. Мультимножини й суміші — близькі родичі множин.
