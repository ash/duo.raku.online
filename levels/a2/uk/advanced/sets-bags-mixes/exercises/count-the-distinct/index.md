## Завдання

Ось список чисел. Деякі з них повторюються:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Виведіть, скільки в ньому _різних_ значень. Різні значення всі відрізняються одне від одного. Використайте множину.

## Приклад

Програма виводить:

```
7
```
