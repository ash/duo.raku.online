## Завдання

Ось дві множини з назвами фруктів:

```raku
my $a = set(<apple banana cherry>);
my $b = set(<banana cherry date>);
```

Знайдіть їхній переріз. Переріз має значення, які є в обох множинах. Збережіть його у змінній. Потім виведіть два рядки. Перший рядок — це кількість спільних значень. Другий рядок показує, чи є `apple` одним із них. Його там не має бути.

## Приклад

Програма виводить:

```
2
False
```
