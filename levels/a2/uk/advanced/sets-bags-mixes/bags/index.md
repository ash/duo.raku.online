Множина пам'ятає лише, _чи_ є в ній значення. Іноді ви також хочете знати, _скільки разів_ воно там трапляється. Для цього є `Bag`. Він зберігає лічильник для кожного значення.

Щоб створити мультимножину, використайте підпрограму `bag`. Мультимножина не з'єднує повторені значення в одне. Вона їх рахує:

```raku
my $b = bag(<a b a c a>);
say $b<a>; # 3
say $b<b>; # 1
```

Запитайте мультимножину про значення через індекс `< >`. Ви отримаєте, скільки разів це значення потрапило в мультимножину. Метод `total` додає всі лічильники:

```raku
say bag(<a b a c a>).total; # 5
```

`Mix` схожий на мультимножину. Але в суміші лічильники називають _вагами_. Вага не мусить бути цілим числом. Вона може бути й дробом. Ви можете самі задати ваги. Поєднайте кожне значення з його вагою в пару. Потім перетворіть список на суміш через `.Mix`:

```raku
my $m = (flour => 2.5, sugar => 0.75).Mix;
say $m<flour>; # 2.5
say $m.total;  # 3.25
```

Вагу ви отримуєте через `< >`. Ваги ви додаєте через `total`. Обидва способи працюють так само, як для мультимножини. Лише числа не мусять бути цілими. Тут `total` додає ваги `2.5` і `0.75`. Результат — `3.25`. Тож `total` дає суму ваг. Він не рахує значення. Мультимножини й суміші корисні, коли треба рахувати кількості. Наприклад, мультимножина може рахувати слова в тексті. Вона каже, як часто трапляється кожне слово. Суміш може давати ваги варіантам.
