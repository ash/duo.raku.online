## Завдання

Символом оператора може бути будь-який знак. Це може бути й символ Unicode. Визначте **постфіксний** оператор `²`. Він повертає квадрат свого операнда. Тож `5²` означає `5 ** 2`. Потім виведіть `5²`.

## Приклад

Програма виводить:

```
25
```
