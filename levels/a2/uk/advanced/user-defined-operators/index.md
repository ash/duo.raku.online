У Raku оператори — це просто підпрограми з особливими іменами. Тож ви можете створювати власні оператори. Для цього ви використовуєте назви категорій зі сторінки [Типи операторів Raku](/uk/advanced/operator-types). Це `prefix`, `infix`, `postfix` і так далі.

Щоб оголосити оператор, напишіть `sub`. Його ім'я має три частини. Спершу йде категорія. Потім іде двокрапка. Потім іде символ оператора в кутових дужках. Ось новий інфіксний оператор. Його ім'я — `plus`:

```raku
sub infix:<plus>($a, $b) {
    $a + $b
}

say 3 plus 4; # 7
```

Після цього ви пишете `plus` між двома його операндами. Він працює точно як вбудований інфіксний оператор.

Постфіксний оператор іде після свого операнда. Факторіал — типовий приклад. Ось він як постфіксний оператор `!`. Він використовує [метаоператор згортки](/uk/advanced/metaoperators/reduction), який ви вже знаєте:

```raku
sub postfix:<!>(Int $n) {
    [*] 1..$n
}

say 5!; # 120
```

Можна використовувати не лише літери й розділові знаки ASCII. Символом оператора може бути будь-який знак. Цей префіксний оператор використовує знак параграфа `§`. Він подвоює число:

```raku
sub prefix:<§>($x) {
    $x * 2
}

say §5; # 10
```

Власні оператори — сильний інструмент. Тож використовуйте їх обережно. Добрий оператор робить код схожим на мову його теми. Дивний оператор лише заплутає наступного читача.
