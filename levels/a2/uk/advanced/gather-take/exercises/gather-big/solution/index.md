Ось один спосіб розв'язати задачу.

## Код

```raku
my $sum = 0;
my @result = gather for 1..100 {
    $sum += $_;
    last if $sum > 10;
    take $_;
}

say @result;
```

🦋 Вихідний код можна знайти у файлі [gather-big.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/gather-take/gather-big.raku).

## Вивід

```
[1 2 3 4]
```

## Коментарі

1. Цикл отримує діапазон зі ста чисел. Йому треба набагато менше. Але це нормально. Цикл зупиняється сам. Коли `$sum` стає більшою за `10`, `last` виходить з циклу. Програма ніколи не дивиться на інші числа.

1. Порядок у блоці важливий. Спочатку ми додаємо число до `$sum`. Потім ми перевіряємо межу. Після цього ми беремо число. Одне число робить суму більшою за `10`. Тут це число — `5`. Код його не бере. Після `4` сума дорівнює рівно `10`. Тож список — це `1, 2, 3, 4`.

1. З `for`, `gather`/`take` може зупинитися раніше. `grep` так не може. `grep` завжди дивиться на весь список. Тут ми самі вибираємо, коли зупинитися.
