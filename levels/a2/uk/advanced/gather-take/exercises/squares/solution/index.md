Ось один спосіб розв'язати задачу.

## Код

```raku
my @squares = gather for 1..6 {
    take $_ ** 2 if $_ %% 2;
};

say @squares;
```

🦋 Вихідний код можна знайти у файлі [squares.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/gather-take/squares.raku).

## Вивід

```
[4 16 36]
```

## Коментарі

1. Перевірка `if $_ %% 2` вирішує, *чи* бере код значення. `$_ ** 2` вирішує, *що* він бере. Перевірку проходять лише парні числа `2`, `4`, `6`.

1. Їхні квадрати — `4`, `16`, `36`. Лише ці значення йдуть до `take`. Тож `gather` збирає саме ці значення. Тут один `take` і вибирає, і змінює значення. Простий `map` не може сказати це так ясно.
