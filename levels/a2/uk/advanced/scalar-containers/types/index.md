Погляньмо на програму. Вона використовує ту саму змінну для різних видів даних. Ми використовуємо `dd`, щоб бачити дані на кожному кроці. Цей приклад лише показує, як усе працює. Це не добрий спосіб писати програми.

```raku
my $value;
dd $value;

$value = 42;
dd $value;

$value = 'forty-two';
dd $value;
```

Кожен виклик `dd` показує поточне значення `$value`:

```
$value = Any
$value = 42
$value = "forty-two"
```

Спочатку змінна порожня. `dd` показує її значення як `Any`. Це невизначене базове значення. З нього починає кожен нетипізований контейнер. Після присвоєнь `dd` показує ціле число. Потім `dd` показує рядок.

Зверніть увагу, що тут `dd` не виводить типу перед іменем. Нетипізований контейнер не має сталого типу. Тому `dd` показує лише значення. [Контейнер з оголошеним типом](/uk/advanced/scalar-containers/type-constraints) працює інакше. Ви побачите це в наступній темі.
