Іноді ви створюєте скалярну змінну. Але ви ще не присвоюєте їй значення. Контейнер усе одно зберігає значення. Це його типове значення. Типове значення залежить від типу змінної.

Ця програма використовує Raku не найкращим способом. Але вона показує ідею:

```raku
my $int;
say $int + 5;
```

У виводі є `5`. Можливо, ви цього чекали. Можливо, ви думали, що типове значення `$int` — це `0`. Але програма також виводить попередження:

```
Use of uninitialized value $int of type Any in numeric context
  in block <unit> at t.raku line 2
5
```

Є два способи прибрати цей сумнів. Ви можете прямо присвоїти значення:

```raku
my $int = 0;
say $int + 5; # 5
```

Або ви можете задати типове значення трейтом `is default`:

```raku
my $int is default(0);
say $int + 5; # 5
```

Типове значення не обов'язково нуль. Це може бути будь-яке значення, яке вам здається добрим. Наприклад:

```raku
my $int is default(1);
say $int + 5; # 6
```
