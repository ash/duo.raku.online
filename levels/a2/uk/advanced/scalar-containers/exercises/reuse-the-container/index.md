## Завдання

Оголосіть дві скалярні змінні поруч. Перша — `$untyped`. Вона не має типу. Друга — `$typed`. Вона має тип `Int`. Виведіть дамп обох через `dd`, поки вони ще порожні. Потім присвойте `42` кожній із них. Знову виведіть дамп обох. Уважно подивіться на вивід. `dd` описує ці два контейнери по-різному.

## Приклад

Програма виводить це у стандартний потік помилок:

```
$untyped = Any
Int $typed = Int
$untyped = 42
Int $typed = 42
```
