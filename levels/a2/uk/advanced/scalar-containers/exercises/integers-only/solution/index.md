Ось один спосіб розв'язати задачу.

## Код

```raku
my Int $cars;

$cars = 250.7.Int;
say $cars;
say $cars.WHAT;
```

🦋 Вихідний код можна знайти у файлі [integers-only.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/scalar-containers/integers-only.raku).

## Вивід

```
250
(Int)
```

## Коментарі

1. Обмеження типу `Int` у `my Int $cars` — це правило для контейнера. Контейнер не приймає значення, які не є цілими числами. Ви не можете прямо присвоїти `250.7`. Це значення — `Rat`. Raku дає помилку під час компіляції, ще до запуску програми.

1. Програма викликає `.Int` для раціонального значення `250.7`. Це перетворює його на ціле число `250`. Метод просто відкидає частину після десяткової крапки. Нове значення підходить для контейнера. Зверніть увагу, що це не те саме, що округлення.

1. Псевдометод `.WHAT` показує тип збереженого значення. Це `Int`.
