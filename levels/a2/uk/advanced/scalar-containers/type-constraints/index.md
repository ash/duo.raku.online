У [частині «Основи»](/uk/essentials/typed-variables/type-constraints/) ви навчилися давати змінній тип. Ви робили це за допомогою обмеження типу. Ось важливий момент. Це правило перевіряє _контейнер_. Він вирішує, які значення приймати.

Це оголошення створює скалярний контейнер. Він може зберігати лише цілі числа:

```raku
my Int $int;
```

Типізований контейнер приймає лише значення, які підходять до його типу. Тому всі ці присвоєння працюють:

```raku
my Int $int;

$int = 123;       # безпосередньо ціле число
say $int;

$int = 100 + 23;  # результат є цілим числом
say $int;

$int = '123'.Int; # рядок, перетворений на ціле число
say $int;
```

У цьому випадку Raku сам не змінює тип. У Raku число з десятковою крапкою — це значення `Rat`. Тому його не можна присвоїти:

```raku
my Int $int;
$int = 123.45;
```

Ви отримуєте помилку під час компіляції. Це ще до запуску програми:

```
===SORRY!=== Error while compiling t.raku
Cannot assign a literal of type Rat (123.45) to a variable ($int) of
type Int.  You can declare the variable to be of type Real, or try to
coerce the value with 123.45.Int or Int(123.45), or just write the value
as 123.
at t.raku:2
------> <BOL>⏏$int = 123.45;
```

Перетворіть значення самі. Тоді помилки немає:

```raku
my Int $int;

$int = 123.45.Int;
say $int; # 123
```

У `123.45.Int` є дві крапки. Нехай вони вас не плутають. Перша крапка — це десяткова крапка. Друга крапка викликає метод `Int`. Цей метод працює зі значенням `Rat`, тобто з раціональним числом.
