title: Вивід сигнатур функцій
---

Іноді ви викликаєте `dd` без аргументів усередині підпрограми. Тоді `dd` друкує сигнатуру підпрограми. Це її ім'я та її параметри, якщо підпрограма їх має. Подивіться на цей приклад із двома підпрограмами:

```raku
sub f1 {
    dd
}

f1();

sub f2($x) {
    dd
}

f2(42);
```

Програма друкує сигнатури. Вона не друкує жодних значень:

```console
sub f1()
sub f2($x)
```

Це дуже корисно з мультифункціями. Це кілька функцій з однаковим ім'ям. Тут `dd` каже вам, який варіант програма справді викликає:

```raku
multi sub g {
    dd
}

multi sub g($x) {
    dd
}

g();
g(42);
```

Щоразу вивід називає варіант, який підходить:

```console
sub g()
sub g($x)
```
