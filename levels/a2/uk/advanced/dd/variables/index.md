title: Вивід змінних
---

{% include menu.html %}

Щоб побачити значення змінної, викличте `dd`. Це схоже на `say`:

```raku
my $var = 42;
dd $var;
```

`dd` показує значення. Також `dd` показує ім'я змінної:

```console
$var = 42
```

Змінна може мати оголошений тип. Тоді `dd` показує й тип. Порівняйте вивід цієї програми з попередньою:

```raku
my Int $var = 42;
dd $var;
```

```console
Int $var = 42
```

Це головна відмінність від `say`. Викличте `dd` один раз для скаляра. `dd` показує вам ім'я змінної. Також `dd` показує тип даних, якщо Raku його знає. Тож ви можете додати в програму кілька викликів `dd`. Ви все одно знаєте, який вивід від якої змінної.

Ви також можете дампити більші структури даних, як масиви або хеші. Тоді `dd` друкує значення у формі, схожій на код:

```raku
my @arr = 10, 20, [1, 2, 3], 30;
dd @arr;
```

```console
[10, 20, [1, 2, 3], 30]
```

Зверніть увагу, що внутрішній масив добре видно. Але тут `dd` не друкує ім'я змінної. З хешами це працює так само. `dd` друкує ключі хешу у відсортованому порядку:

```raku
my %hash =
    gamma => 'g',
    alpha => 'a',
    beta  => 'b';
dd %hash;
```

```console
{:alpha("a"), :beta("b"), :gamma("g")}
```
