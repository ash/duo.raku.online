Ось один спосіб розв'язати задачу.

## Код

```raku
my @data = 'Raku', [1, 2, 3], (key => 'value');

dd @data;
say "Structure: { @data.raku }";
```

🦋 Вихідний код можна знайти у файлі [dump-the-structure.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/dd/dump-the-structure.raku).

## Вивід

```
["Raku", [1, 2, 3], :key("value")]
Structure: ["Raku", [1, 2, 3], :key("value")]
```

## Коментарі

1. `dd @data` виводить вміст масиву. Він виводить його у формі, схожій на код. Цей вивід іде у стандартний потік помилок.

1. Метод `.raku` повертає ту саму форму як рядок. Програма вставляє цей рядок у звичайне повідомлення. Для цього вона виконує код усередині рядка. Потім `say` виводить повідомлення у стандартний вивід.

1. Тут два рядки виглядають однаково. Але вони йдуть у різні потоки виводу. Перший рядок приходить від `dd` і йде у стандартний потік помилок. Другий рядок приходить від `say` і йде у стандартний вивід. Порівняйте ці два запуски:

```console
$ raku t.raku > /dev/null
["Raku", [1, 2, 3], :key("value")]

$ raku t.raku 2&> /dev/null
Structure: ["Raku", [1, 2, 3], :key("value")]
```
