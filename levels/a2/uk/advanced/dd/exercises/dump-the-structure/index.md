## Завдання

Ось вкладена структура даних. У ній одні дані лежать усередині інших:

```raku
my @data = 'Raku', [1, 2, 3], (key => 'value');
```

Зробіть із нею дві речі:

1. Виведіть дамп `@data` через `dd`, у формі для програмістів.
2. Виведіть ту саму форму як рядок. Поставте перед нею текст `Structure: `.

## Приклад

Програма виводить два рядки. Вони дуже схожі:

```
["Raku", [1, 2, 3], :key("value")]
Structure: ["Raku", [1, 2, 3], :key("value")]
```
