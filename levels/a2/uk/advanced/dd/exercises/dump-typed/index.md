## Завдання

Оголосіть змінну типу `Int`: `my Int $n = 42;`. Виведіть її дамп через `dd`. Подивіться на вивід. Змінна без типу дає інший вивід.

## Приклад

Програма виводить це у стандартний потік помилок:

```
Int $n = 42
```
