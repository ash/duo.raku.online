Послідовності не треба обчислювати всі свої значення одразу. Послідовності в Raku — _ліниві_. Raku створює кожне значення лише тоді, коли воно вам справді потрібне. Тож можна описати послідовність зовсім без кінця.

Для нескінченної послідовності використайте `Inf` як кінцеву точку. Raku виконує `=` раніше за `...`. Ми кажемо, що `...` зв'язується слабше за `=`. Тому візьміть послідовність у дужки:

```raku
my $naturals = (1 ... Inf);
```

Подивіться на `my $naturals = 1 ... Inf` без дужок. Тут змінна отримує лише `1`. Після цього Raku будує послідовність окремо. Ніхто не використовує цю нескінченну послідовність. Але Raku пробує її обчислити. Тож програма зависає й ніколи не закінчується.

Поки що Raku нічого не обчислює. Послідовність дає вам значення лише тоді, коли ви їх просите. Метод `head` бере кілька перших значень:

```raku
say (1 ... Inf).head(5); # (1 2 3 4 5)
```

Послідовність нескінченна. Але Raku створює лише перші п'ять чисел. Без лінивості програма пробує побудувати всю нескінченну послідовність. Така програма ніколи не закінчується.

Скінченна послідовність має кінець. Для такої послідовності метод `tail` бере значення з кінця:

```raku
say (1 ... 100).tail(3); # (98 99 100)
```

Лінивість дозволяє робити дві речі окремо. Спочатку ви даєте _опис_ послідовності. Пізніше ви вирішуєте, скільки з неї використати.
