Метаоператор zip `Z` бере два списки або більше. Він з'єднує їхні елементи за позиціями:

```raku
say (1, 2, 3) Z (4, 5, 6); # ((1 4) (2 5) (3 6))
```

Результат — це список груп. У першій групі — перший елемент кожного списку. У другій групі — другий елемент кожного списку і так далі.

Є й розумніший спосіб. Можна використати `Z` з оператором. Тоді оператор працює з кожною парою. Наприклад, `Z+` додає елементи на однакових позиціях:

```raku
say (1, 2, 3) Z+ (10, 20, 30); # (11 22 33)
```

Тут метаоператор zip працює з оператором `+`. Він обчислює `1 + 10`, `2 + 20` і `3 + 30`. Так само `Z*` перемножує елементи на однакових позиціях:

```raku
say (1, 2, 3) Z* (10, 20, 30); # (10 40 90)
```

А `Z~` з'єднує рядки на однакових позиціях:

```raku
say <a b c> Z~ <1 2 3>; # (a1 b2 c3)
```
