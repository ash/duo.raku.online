## Завдання

Напишіть програму. Вона виводить середнє значення масиву чисел. Середнє значення ще називають середнім арифметичним. Додайте значення за допомогою метаоператора згортки.

Числа стоять у самій програмі. Наприклад:

```raku
my @data = 10, 20, 30, 40;
```

## Приклад

Програма виводить середнє значення елементів `@data`:

```
25
```
