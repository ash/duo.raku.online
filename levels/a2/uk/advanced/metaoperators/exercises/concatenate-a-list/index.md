## Завдання

URL розрізали на частини. Частини лежать у масиві. Знову з'єднайте частини в один рядок. Використайте для цього метаоператор згортки. Виведіть URL. У наступному рядку виведіть його довжину в символах.

## Приклад

Ось вхідний масив:

```raku
my @parts = <http :// example .com>;
```

Програма виводить:

```
http://example.com
18
```
