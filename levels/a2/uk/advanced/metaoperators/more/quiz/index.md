Що виведе ця програма?

```raku
say (1, 2, 3) »+» 10;
```

{:.quiz}
1 | (11 12 13)
0 | (11 2 3)
0 | 16
0 | 6

{% include quiz.html %}

<div class="extended-explanation">

Гіпероператор `»+»` застосовує `+` до кожного елемента. Праворуч стоїть лише одне значення, `10`. Raku використовує це значення для всього списку. Тож кожен елемент стає більшим на `10`: `(11 12 13)`. Згортка `[+]` працює інакше. Вона перетворює список на одну суму, `6`.

</div>
