У Raku є й інші метаоператори, не лише згортка та zip. Тут ви дізнаєтеся про три з них.

## Перехресний — `X`

Перехресний метаоператор `X` бере два списки й робить пари. Тут **кожен** елемент одного списку йде в пару з **кожним** елементом іншого. Це називають декартовим добутком:

```raku
say <a b> X <1 2>; # ((a 1) (a 2) (b 1) (b 2))
```

Як і zip, `X` теж може брати оператор. Тоді оператор працює з кожною парою. `X~` з'єднує кожну пару в рядок. `X*` перемножує два числа:

```raku
say <a b> X~ <1 2>;         # (a1 a2 b1 b2)
say (1, 2, 3) X* (10, 100); # (10 100 20 200 30 300)
```

Zip іде по двох списках поруч. Перехресний оператор з'єднує їх усіма можливими способами.

## Гіпер — `»…«`

Гіпероператор використовує оператор для **кожного елемента** списку. Оператор стоїть між стрілками `»…«`. Лише з символами ASCII ви пишете `>>…<<`. З двома списками він працює елемент за елементом, як zip. Іноді з одного боку є лише одне значення. Тоді він використовує це значення з кожним елементом списку:

```raku
say (1, 2, 3) »+» (10, 20, 30); # (11 22 33)
say (1, 2, 3) »*» 2;            # (2 4 6)
```

Дві стрілки можуть дивитися в різні боки. Напрямок важливий, коли списки мають різну довжину. Якщо стрілка дивиться **на** список, Raku може повторити цей список. Тоді він стає такої ж довжини, як інший список. Ось чотири варіанти в ASCII, з `<<` і `>>`:

* `>>op<<` — Raku не повторює жодного списку. Списки мають бути однакової довжини. Якщо ні, буде помилка.
* `>>op>>` — Raku повторює **правий** список. Тоді він стає такої ж довжини, як лівий.
* `<<op<<` — Raku повторює **лівий** список. Тоді він стає такої ж довжини, як правий.
* `<<op>>` — Raku повторює **коротший** список. Тоді він стає такої ж довжини, як довший.

```raku
say (1, 2, 3, 4) <<+>> (10, 20); # (11 22 13 24)  — 10, 20 повторюється як 10, 20, 10, 20
```

Є також форма лише з одним операндом. Вона викликає метод для кожного елемента. `>>.uc` пише кожен рядок великими літерами:

```raku
say <raku perl>>>.uc; # (RAKU PERL)
```

Гіпероперація також каже Raku ще одну річ. Raku *може* виконати роботу паралельно. Тоді кілька частин роботи йдуть одночасно. Пізніше ви вивчите схожий метод `.hyper`. Він є в [розділі про конкурентне програмування](/uk/paradigms/hyper-race).

## Заперечний — `!`

Поставте `!` перед оператором порівняння. Тоді ви отримаєте протилежний результат. Ви вже знаєте `!=`, тобто «не дорівнює». Це просто цей метаоператор разом із `==`. Інші оператори теж дають `True` або `False`, як-от `eq` і `%%`. Метаоператор працює з ними так само:

```raku
say 3 != 4;      # True
say 'a' !eq 'b'; # True  — не рівні як рядки
say 5 !%% 2;     # True  — 5 не ділиться на 2
```

Тож `$a !op $b` — це просто чистіший спосіб написати `!($a op $b)`.

Raku робить це навмисно. Деякі мови навмисно малі й прості, як есперанто. Есперанто намагається мати один правильний спосіб для кожної речі. Raku інший. Він охоче дає вам кілька способів. Тому в Raku є заперечний `!eq`. Також у ньому є спеціальний оператор `ne`. Обидва означають точно те саме:

```raku
say 'a' ne 'b'; # True — та сама перевірка, що й 'a' !eq 'b'
```
