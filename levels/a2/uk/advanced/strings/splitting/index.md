Рядок можна розбити на частини кількома способами. Частини також можна знову скласти разом.

Метод `words` розбиває рядок на список слів. Слова розділяють пробільні символи, наприклад пробіл:

```raku
say 'Hello big World'.words; # (Hello big World)
```

Метод `split` розрізає рядок за роздільником. Роздільник вибираєте ви:

```raku
say 'a,b,c'.split(','); # (a b c)
```

Ось важливий особливий випадок. Можна розбивати за **порожнім рядком** `''`. Тоді ви отримуєте окремі символи рядка. Але ви також отримуєте ще два порожні рядки. Вони стоять на самому початку і в самому кінці. Тож у результаті на два елементи більше, ніж ви чекаєте:

```raku
say 'abc'.split('').elems;        # 5 — три літери плюс порожній рядок з кожного боку
say 'abc'.split('', :skip-empty); # (a b c) — наріччя :skip-empty відкидає порожні
```

Хочете розбити рядок на символи? Викличте метод `comb` без аргументів. Він робить це напряму. Зайвих порожніх рядків немає:

```raku
say 'Raku'.comb; # (R a k u)
```

Метод `join` робить навпаки. Він з'єднує список значень в один рядок. Між значеннями він ставить роздільник:

```raku
say <a b c>.join('-'); # a-b-c
```

Ще два методи працюють із частинами рядка. Метод `substr` дає вам шматок рядка. Ви даєте йому початкову позицію. Якщо хочете, можна дати йому й довжину:

```raku
say 'Hello World'.substr(0, 5); # Hello
say 'Hello World'.substr(6);    # World
```

А `trim` прибирає пробільні символи з обох кінців рядка:

```raku
say '  hi  '.trim; # hi
```
