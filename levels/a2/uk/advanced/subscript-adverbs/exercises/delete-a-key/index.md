## Завдання

Ось хеш: `a => 1, b => 2, c => 3`. Видаліть запис `b` за допомогою наріччя індексу. Потім виведіть, скільки записів залишилося в хеші. Це показує, що одного запису вже немає.

## Приклад

Програма виводить:

```
2
```
