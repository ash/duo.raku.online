Інші наріччя змінюють те, **що** повертає індекс. Зазвичай індекс повертає значення. Ці наріччя повертають більше:

* `:v` — значення; так є за замовчуванням
* `:k` — ключ або індекс
* `:kv` — ключ і значення
* `:p` — `Pair` із ключа та значення

Для масиву «ключем» є індекс:

```raku
my @a = 10, 20, 30;

say @a[1]:kv; # (1 20)
say @a[1]:p;  # 1 => 20
```

`@a[1]:kv` повертає індекс і значення разом у списку. `@a[1]:p` повертає їх як пару.

Це працює і з хешами. Це дуже зручно зі зрізом. Зріз має кілька ключів одразу:

```raku
my %h = a => 1, b => 2, c => 3;

say %h<a c>:kv; # (a 1 c 3)
```

Тут зріз має два ключі. Результат — ключ, його значення, наступний ключ, його значення. `map`, `for` та схожі інструменти часто використовують ці наріччя. З ними можна працювати з ключами й значеннями разом. Вам не потрібні окремі пошуки.
