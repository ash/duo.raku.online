Наріччя `:exists` робить з індексу запитання. Чи є значення за цим ключем або індексом? Відповідь — `True` або `False`. Наріччя не дістає значення:

```raku
my %h = apple => 1, pear => 2;

say %h<apple>:exists; # True
say %h<plum>:exists;  # False
```

Це правильний спосіб перевірити ключ. Можна також просто прочитати `%h<plum>`. Але тоді ви отримаєте невизначене значення. Або з деякими даними ви не побачите різниці. Ключ «відсутній»? Чи він «є, але невизначений»?

Наріччя `:delete` видаляє запис. Воно повертає значення цього запису:

```raku
my %h = apple => 1, pear => 2;

say %h<apple>:delete; # 1
say %h.keys;          # (pear)
say %h;               # {pear => 2}
```

Запису `apple` більше немає. Ви отримуєте назад його значення `1`. Ви можете використати це значення.

Обидва наріччя працюють і з масивами. Там ви використовуєте індекс:

```raku
my @a = 10, 20, 30;

say @a[1]:exists; # True
say @a[5]:exists; # False

say @a[1]:delete; # 20
say @a[1]:exists; # False
```

Ви видаляєте елемент із середини. Який тоді вигляд має масив? Ось відповідь:

```raku
say @a; # [10 (Any) 30]
```

Тож ви використовуєте один запис, і він завжди працює однаково. З ним можна запитати про контейнер. Також можна змінити контейнер на місці. Для цього не потрібні окремі методи.
