Ви вже знаєте фазери для всієї програми. Raku також має фазери для одного блоку або одного циклу. Вони належать до життя цього блоку або циклу.

## Вхід у блок і вихід з нього

Фазер `ENTER` запускається щоразу, коли програма входить у блок. Фазер `LEAVE` запускається щоразу, коли програма виходить з блоку. Їхнє місце в блоці не має значення:

```raku
say 'before block';
{
    LEAVE say 'leaving';
    ENTER say 'entering';
    say 'inside';
}
say 'after block';
```

Подивіться на вивід. `ENTER` запускається першим, а `LEAVE` — останнім. Тіло блоку стоїть між ними:

```
before block
entering
inside
leaving
after block
```

`LEAVE` дуже корисний. Він запускається, навіть коли блок закінчується раніше. Тож там можна спокійно звільнити ресурс, наприклад відкритий файл.

Фазер може мати цілий блок `{ }`, а не лише один оператор. Ви також можете мати кілька фазерів. Блок може мати більше одного `LEAVE`. Тоді вони запускаються у зворотному порядку. Останній запускається першим. Це працює як стек. Що прийшло останнім, те йде першим:

```raku
say 'open A';
{
    LEAVE {
        say 'close A';
    }
    say 'open B';
    LEAVE {
        say 'close B';
    }
    say 'work';
}
say 'done';
```

Програма відкриває ресурс `A` першим. Вона закриває його останнім:

```
open A
open B
work
close B
close A
done
```

Цей порядок — «останнім прийшов, першим пішов». Він якраз підходить для очищення. Що ви налаштували останнім, те ви прибираєте першим. Фазер `END` для всієї програми працює так само. Кілька блоків `END` теж запускаються у зворотному порядку.

## Фазери для циклів

Цикли мають ще три фазери. Вони позначають кроки циклу. `FIRST` запускається один раз, перед першим проходом. `LAST` запускається один раз, після останнього проходу. `NEXT` запускається в кінці кожного проходу:

```raku
for 1..3 {
    FIRST say '-- first';
    LAST  say '-- last';
    NEXT  say "-- next (was $_)";
    say "body $_";
}
```

Цикл друкує:

```
-- first
body 1
-- next (was 1)
body 2
-- next (was 2)
body 3
-- next (was 3)
-- last
```

Тут усе так само, як з іншими фазерами. Ви можете писати `FIRST`, `NEXT` і `LAST` будь-де в циклі. Кожен запускається у свій час.
