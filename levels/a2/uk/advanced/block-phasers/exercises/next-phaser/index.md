## Задача

Фазер `NEXT` запускається *в кінці* кожного проходу циклу. Це добрий час, щоб показати прогрес.

Тримайте суму, що росте, у `$sum`. Вона починається з `0`. Пройдіть циклом по `1..3`. На кожному проході спочатку додайте поточне число до `$sum`. Використайте фазер `NEXT`, щоб друкувати `sum so far: $sum` після кожного проходу.

Будьте уважні з порядком. Фазер `NEXT` запускається після тіла. Тож сума, яку він показує, *містить* поточне число.

## Приклад

Програма виводить:

```
sum so far: 1
sum so far: 3
sum so far: 6
```
