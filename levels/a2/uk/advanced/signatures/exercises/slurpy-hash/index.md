## Завдання

Напишіть підпрограму `describe`. Її перший параметр — це ім'я. Це ім'я позиційне й обов'язкове. Після нього всеїдний хеш `*%opts` збирає будь-яку кількість іменованих аргументів. Підпрограма повертає ось такий рядок: `name: key=value, key=value, ...`. Рядок перелічує кожен параметр. Ключі йдуть в алфавітному порядку.

Викличте її ось так: `describe('Anna', colour => 'red', size => 5)`. Виведіть результат.

## Приклад

Програма виводить:

```
Anna: colour=red, size=5
```
