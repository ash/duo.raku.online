Ось один спосіб розв'язати задачу.

## Код

```raku
say <a b c>.reverse.join: '-';
```

🦋 Вихідний код можна знайти у файлі [colon-join.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/colon-calls/colon-join.raku).

## Вивід

```
c-b-a
```

## Коментарі

1. `.reverse` стоїть посередині ланцюжка. Тож він зберігає звичайну форму. `join` — останній виклик. Тож він може використати двокрапку. Двокрапка передає йому `'-'`, так само як `join('-')`.

1. Після `.reverse` список стає `c, b, a`. Потім `join` ставить дефіси між словами. Результат — `c-b-a`. Форма з двокрапкою працює і зі звичайними значеннями, не лише з блоками.
