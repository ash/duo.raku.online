## Завдання

Форма з двокрапкою мусить бути *останнім* викликом у ланцюжку. Але виклики перед нею можуть бути звичайними, з дужками. Почніть зі слів `a`, `b`, `c`. Поставте їх у зворотному порядку за допомогою `.reverse`. Потім з'єднайте результат дефісом. Для з'єднання використайте форму з **двокрапкою**. Виведіть результат.

## Приклад

Програма виводить:

```
c-b-a
```
