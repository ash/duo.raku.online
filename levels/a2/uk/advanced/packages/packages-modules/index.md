Ключове слово `package` створює простір імен. Усередині нього ви можете створювати речі через `our`. Вони стають частиною простору імен. До них можна дістатися ззовні. Використайте ім'я пакунка й роздільник `::`:

```raku
package Maths {
    our $pi = 3.14;
    our sub double($x) { $x * 2 }
}

say $Maths::pi;         # 3.14
say Maths::double(5);   # 10
```

Змінну ви отримуєте як `$Maths::pi`. Спершу йде сигіл, потім ім'я пакунка, потім ім'я змінної. Підпрограму ви викликаєте як `Maths::double(...)`.

І `package`, і `module` створюють простір імен. Але вони також роблять різні речі. `module` — звичайний вибір для коду, який ви використовуєте знову. Простий `package` — це лише простір імен, і нічого більше. `class` теж створює простір імен. Про класи ви дізнаєтеся в [наступній частині](/uk/oop). Клас ще й додає інструменти для об'єктів.

```raku
module Greet {
    our sub hello { 'hi' }
}

say Greet::hello; # hi
```

Отже, `module` дає вам простір імен. Сам `package` дає такий самий простір імен. Вибирайте між ними за тим, що ви хочете зробити. Використовуйте `module` для бібліотек. Використовуйте `package`, коли потрібен лише простір імен. Пізніше, з об'єктами, використовуйте `class` для типів.
