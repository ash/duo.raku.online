Слово `our` робить щось видимим у його просторі імен. Змінна з `my` є лексичною. Вона приватна для свого блоку. Змінна з `our` — це ще й змінна пакунка. До неї можна дістатися ззовні через шлях із `::`:

```raku
module Counter {
    our $count = 0;  # змінна пакунка
    my  $secret = 42; # лексична, ззовні не видима
}

say $Counter::count; # 0
```

`$Counter::count` працює. Змінна `count` має `our`. Але `$Counter::secret` не працює. Змінна `secret` — лексична.

Простори імен можуть **вкладатися**. Це означає, що один простір імен лежить усередині іншого. Пакунок у пакунку дає довший шлях із `::`:

```raku
module Outer {
    module Inner {
        our $val = 42;
    }
}

say $Outer::Inner::val; # 42
```

Повне ім'я `$Outer::Inner::val` схоже на шлях. Воно веде із зовнішнього простору імен у внутрішній. Потім воно веде до змінної. Стандартна бібліотека має саме таку будову. Імена на кшталт `IO::Socket::INET` — це вкладені простори імен. Ваші власні модулі теж можуть так працювати. Вони тримають усі свої частини під одним іменем верхнього рівня.
