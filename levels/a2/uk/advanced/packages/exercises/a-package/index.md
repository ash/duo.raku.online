## Завдання

Створіть пакунок `Temperature`. У ньому дві речі. Перша — змінна `our` `$freezing` зі значенням `0`. Друга — підпрограма `our` `fahrenheit`. Вона переводить значення за Цельсієм у градуси Фаренгейта. Для цього помножте на 9/5 і додайте 32. Ззовні пакунка виведіть точку замерзання. Потім виведіть `100` градусів Цельсія за Фаренгейтом.

## Приклад

Програма виводить:

```
0
212
```
