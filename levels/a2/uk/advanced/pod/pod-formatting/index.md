У тексті Pod ви позначаєте слова _кодами форматування_. Кожен код — це одна літера. Після літери ви ставите кутові дужки навколо тексту:

* `B<…>` — жирний
* `I<…>` — курсив
* `C<…>` — код (усі літери мають однакову ширину)
* `L<…>` — посилання

```raku
=begin pod

This is B<important>, and C<say> is a built-in.

=end pod
```

У форматованому тексті `important` стоїть жирним. `say` стоїть шрифтом коду. Ви можете вкласти один код в інший код. Так ви їх поєднуєте. Тож `B<C<say>>` — це жирний код.

Іноді вам потрібен цілий блок коду. Короткого шматка всередині рядка мало. Тоді використайте блок коду: `=begin code … =end code`. Він має рядок на початку і рядок у кінці. Він зберігає текст точно таким, як він є:

```raku
=begin pod

Here is how to call it:

=begin code
say greet('world');
=end code

=end pod
```

Рядки в блоці коду виглядають точно так, як ви їх пишете. Raku не читає їх як Pod. Отже, Pod має коди всередині рядків і має блоки коду. З ними ви можете описати API. API — це спосіб, яким інші програми використовують ваш код. Ви пишете форматований текст і приклади. Приклади виглядають як код, який можна запустити. Усе це лежить поруч із кодом, який воно описує.
