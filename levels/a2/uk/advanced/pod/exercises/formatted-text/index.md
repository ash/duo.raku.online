## Завдання

Напишіть блок Pod. У ньому є заголовок `=head1` з текстом `Greeting` і абзац `Hello, world!`. Зробіть слово `world` жирним через `B<…>`. Потім перетворіть блок на текст через `raku --doc`.

> Запустіть файл через `raku --doc`. Тоді ви побачите форматований текст.

## Приклад

Через `raku --doc` він виводить ось що:

```
Greeting

Hello, world!
```
