Ви можете визначити підпрограму _всередині_ іншої підпрограми. Це вкладена підпрограма. Вона — звичайна підпрограма. Але ви можете бачити й використовувати її лише всередині зовнішньої підпрограми.

```raku
sub outer {
    sub inner {
        say 'I am the inner subroutine';
    }

    inner;
}

outer;
```

Програма виводить:

```
I am the inner subroutine
```

Тут ми створюємо `inner` усередині `outer`. Потім `outer` викликає її. Це працює. Ім'я `inner` відоме в усьому тілі `outer`.

Але поза `outer` імені `inner` не існує. Ця програма не компілюється:

```raku
sub outer {
    sub inner { 42 }
}

inner; # помилка: Undeclared routine: inner
```

Іноді допоміжна підпрограма потрібна лише одній підпрограмі. Тоді вкладення корисне. Покладіть помічника всередину тієї підпрограми. Це показує, що помічник приватний. А ще інший код не може випадково його викликати.
