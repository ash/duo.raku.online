## Завдання

Напишіть підпрограму `stats`. Усередині неї визначте **вкладену** допоміжну підпрограму `double`. Вона повертає свій аргумент, помножений на два. Усередині `stats` використайте помічника. Виведіть значення `double(3) + double(5)`.

Потім викличте `stats`.

## Приклад

Програма виводить:

```
16
```
