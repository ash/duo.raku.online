## Problem

Make a class `Book` with two attributes, `title` and `author`. Make a book with the title `Raku` and the author `Larry`. Then print one line about the book. Use both accessors in it. The line has this form: `<title> by <author>`.

## Example

The program prints:

```
Raku by Larry
```
