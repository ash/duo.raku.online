## Problem

Make a class `Label` with one attribute, `text`. You can change this attribute (`is rw`). Make a label with the text `draft`. Then **add** ` (revised)` to the end of its text. Do this through the accessor. Do not make the object again. Print the result.

## Example

The program prints:

```
draft (revised)
```
