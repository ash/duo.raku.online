## Problem

Make a class `Counter` with one attribute, `count`. You can change this attribute (`is rw`). Its default value is `0`.

Make a counter. First, print its `count`. This shows that it starts at the default. Then add 1 to it five times in a loop. Print the last value.

## Example

The program prints:

```
0
5
```
