## Problem

Make a class `Converter` with a class method `km-to-miles`. It takes a number of kilometres. It returns the distance in miles. To get miles, multiply by `0.621`.

Call the method on the class for `10` kilometres. Print the result.

## Example

The program prints:

```
6.21
```
