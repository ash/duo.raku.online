## Problem

A class method can have parameters, like any other method. Make a class `Geometry` with a class method `circle-area`. It takes a radius. It returns the area of a circle. Use `π` or `pi`. Round the area to a whole number. The formula belongs to the whole class. There is no single circle object here. Call the method on the class with a radius of `10`. Print the result.

## Example

The program prints:

```
314
```
