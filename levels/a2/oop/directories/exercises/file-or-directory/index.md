## Problem

Create a file with the name `a.txt`. Then ask the *same* path two questions. Is it a regular file (`.f`)? Is it a directory (`.d`)? Print both answers. You see that the two tests give opposite results for one path.

## Example

The program prints:

```
True
False
```
