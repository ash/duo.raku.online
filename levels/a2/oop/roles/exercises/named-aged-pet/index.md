## Problem

Make two roles:

* `Named` has a method `label`. The method returns `I am <name>`.
* `Aged` has a method `status`. The method returns `<age> years`.

Then make a class `Pet`. It does both roles. It has the attributes `name` and `age`. Create a pet with the name `Rex` and the age `3`. Print its `label` and its `status`.

## Example

The program prints:

```
I am Rex
3 years
```
