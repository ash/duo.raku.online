## Problem

Make a class `Robot` with a method `speak`. This method returns `beep`. Then make a role `Dancing`. It adds a method `dance`. This method returns `spinning around`.

Create two robots. Give the role `Dancing` to only one of them. Call `speak` on both robots and print the results. Then call `dance` on the robot that can dance. Print this result too.

## Example

The program prints:

```
beep
beep
spinning around
```
