## Problem

Make a base class `Vehicle` with an attribute `wheels`. Then make two classes that inherit from it. The first is `Bike`. It comes with `2` wheels. The second is `Car`. It comes with `4`.

Create a `Bike` and a `Car`. Print the number of wheels of each one.

## Example

The program prints:

```
2
4
```
