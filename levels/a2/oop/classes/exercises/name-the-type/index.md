## Problem

Make two empty classes, `Cat` and `Dog`. Then make an instance of `Cat` with the name `$felix`. Print the type of `$felix` with `WHAT`. Then print two more lines. Use the operator `===` in them. The first line shows if the type is the same as `Cat`. The second line shows if it is the same as `Dog`.

## Example

The program prints:

```
(Cat)
True
False
```
