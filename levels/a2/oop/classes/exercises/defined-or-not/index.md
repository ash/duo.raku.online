## Problem

Make two empty classes, `Cat` and `Dog`. Then write a loop over four values: `Cat`, `Dog`, `Cat.new`, and `Dog.new`. For each value, print if it is defined. Look at the result. The two type objects are undefined. The two instances are defined. The class does not matter here.

## Example

The program prints:

```
False
False
True
True
```
