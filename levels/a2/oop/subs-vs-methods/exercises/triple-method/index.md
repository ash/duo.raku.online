## Problem

Now solve the same task with a **method**. Make a class `Number`. It has an attribute `n` and a method `triple`. The method returns three times `n`. Create a `Number` with `n` equal to `7`. Call `triple` on it and print the result.

## Example

The program prints:

```
21
```
