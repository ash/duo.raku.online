## Problem

Write three words to a file with the name `words.txt`. The words are `apple`, `banana`, and `cherry`. Each word is on its own line. Then read the file line by line. Print each line with its number before it. The numbers start from `1`. Use this form: `<number>: <line>`.

## Example

The program prints:

```
1: apple
2: banana
3: cherry
```
