## Problem

Open a file with the name `out.txt` for writing. Keep the handle open. Write the numbers `1`, `2`, and `3` to it in a loop. Each number must be on its own line. Then close the handle. Read the file and print its content.

## Example

The program prints:

```
1
2
3
```
