## Problem

Make a class `Dog`. It has only an attribute `name` and no methods. Then use the MOP to add a method `speak` to it. Do this while the program runs. The new method uses the object’s own `name`. It returns `<name> says woof`. Create a dog with the name `Rex` and call the new method.

## Example

The program prints:

```
Rex says woof
```
