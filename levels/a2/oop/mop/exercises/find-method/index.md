## Problem

Make a class `Animal` with a method `speak`. Then make a class `Dog`. It inherits from `Animal`. It has no methods of its own. Use a meta-method on `Dog`. Check if `Dog` has a method `speak`. Print just `True` or `False`. This shows something about `find_method`. It looks along the whole inheritance chain. It does not look only at the methods of the class itself.

## Example

The program prints:

```
True
```
