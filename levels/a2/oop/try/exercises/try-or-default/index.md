## Problem

When a `try` block fails, its value is undefined. Use this with the defined-or operator `//`. With `//`, you can give a fallback value for this case. Run a `try` block with `die 'no'` inside. If the block fails, use the string `default` instead. Print the result.

## Example

The program prints:

```
default
```
