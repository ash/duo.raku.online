## Problem

Show both sides of `try`. A `try` block catches errors in its code. First, put a calculation into a `try` block. The calculation must work, for example `6 * 7`. Print its result. Then put code with `die 'broken'` into a second `try` block. Print if this block gave a defined result. Also print the message of the caught exception.

## Example

The program prints:

```
42
False
broken
```
