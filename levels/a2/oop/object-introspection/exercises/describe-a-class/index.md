## Problem

Make a base class `Animal`. Then make a class `Dog` that inherits from it. Print the name of the class `Dog`. Then look at the inheritance chain of `Dog`. This chain has the class and all its parents. On the next line, print the number of types in it. Use `.^mro` and count its elements. On a third line, print if this chain has a class `Cat`.

## Example

The program prints:

```
Dog
4
False
```
