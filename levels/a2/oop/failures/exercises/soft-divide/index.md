## Problem

Write a subroutine `reciprocal`. It returns `1` divided by its argument. But if the argument is `0`, it uses `fail`. The message is `no reciprocal of zero`.

Print the result of `reciprocal(4)`. Then print the result of `reciprocal(0)`. Do not check `.defined` yourself here. Use the `//` operator instead. If the call fails, `//` gives the string `undefined`.

## Example

The program prints:

```
0.25
undefined
```
