## Problem

Make a small log file. Add lines to its end several times. First, write the line `start` to a file with the name `log.txt`. Then **append** three more lines in a loop. This means that you add them to the end of the file. The lines are `entry 1`, `entry 2`, and `entry 3`. Do not delete what is already in the file. At the end, read the whole file and print it.

## Example

The program prints:

```
start
entry 1
entry 2
entry 3
```
