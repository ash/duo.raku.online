## Problem

Make a class `Word` with an attribute `text`. Give it a method `reversed`. This method returns the text of the word backwards. Hint: the method `flip` puts a string in reverse order.

Make a word with the text `Raku`. Print the text backwards.

## Example

The program prints:

```
ukaR
```
