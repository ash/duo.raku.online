## Problem

Make a class `Rectangle` with two attributes, `width` and `height`. Add a method `area`. It returns the area of the rectangle. Add a second method, `describe`. It returns the string `area is <area>`. For this, it must **call its own `area` method** through `self`.

Make a rectangle. It is `3` wide and `4` high. Print its description.

## Example

The program prints:

```
area is 12
```
