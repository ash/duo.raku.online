## Problem

Make a class `Celsius` with an attribute `degrees`. Add a method `to-fahrenheit`. It changes the temperature to Fahrenheit. Use this formula: `degrees × 9 / 5 + 32`.

Make a `Celsius` object for `100` degrees. Print its value in Fahrenheit.

## Example

The program prints:

```
212
```
