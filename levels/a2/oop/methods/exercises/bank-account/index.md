## Problem

Make a class `Robot`. It has an attribute `position` that you can change. Its default value is `0`. The class also has a method `move`. This method moves the position forward by some number of steps. The default number of steps is `1`. So `move` with no argument moves the robot one step.

Make a robot. Move it `5` steps. Then call `move` with no argument. Then move it `2` more steps. Print its last position.

## Example

The program prints:

```
8
```
