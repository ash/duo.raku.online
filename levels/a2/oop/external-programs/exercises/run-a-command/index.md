## Problem

Use `run` to start `echo`. Give it two separate arguments: `home:` and `$HOME`. Arguments are values that you give to a program. Let the output go to the screen. Note that the program prints `$HOME` as it is. It does **not** print the home directory. This is because `run` does not use a shell. Only a shell replaces variables like `$HOME` with their values.

## Example

The program prints:

```
home: $HOME
```
