## Problem

Run a command that fails on purpose. For example, use `sh -c 'exit 4'`. Keep the `Proc` that it returns. Print the exit code of the command. The exit code is a number. A command returns it when it ends. Then print `success` if the command worked. Print `failure` if it did not.

## Example

The program prints:

```
4
failure
```
