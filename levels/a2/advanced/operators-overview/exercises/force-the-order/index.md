## Problem

The operator `**` is stronger than `+`. So Raku reads `2 ** 3 + 1` as `(2 ** 3) + 1`. This is `9`. Add parentheses and change this order. The addition must happen *first*. Print the result.

## Example

The program prints:

```
16
```
