## Problem

Start from the `q` form. It does not interpolate. Turn on only the closure adverb. The variable `$x` holds `10`. Print a line with the calculation `{$x ** 2}` *and* a plain `$x`. This plain `$x` is not interpolated. So you see that the closure adverb runs code in braces. But it does not touch plain `$` variables.

## Example

The program prints:

```
$x squared is 100
```
