## Problem

Use `gather` and `take` to build a list. Each number from `1` to `4` is in the list several times. The number of times is the number itself: `1` once, `2` two times, `3` three times, and `4` four times. Print the list.

## Example

The program prints:

```
[1 2 2 3 3 3 4 4 4 4]
```
