## Problem

The star alone, `*`, means “no limit”. Use it as the end of a sequence. Write the even numbers as the sequence `2, 4 ... *`. This sequence has no end. Then take the first four numbers with `head`. This is safe only because the sequence is lazy. A lazy sequence makes its values only when you need them.

## Example

The program prints:

```
(2 4 6 8)
```
