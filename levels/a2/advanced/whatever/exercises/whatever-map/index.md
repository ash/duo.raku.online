## Problem

A `WhateverCode` is a normal function value. So you can keep it in a variable. You can also give it to `map`. Make a function with one argument. It multiplies the argument by three. Keep it in `$triple`. Use it with `map` on the list `1..4`. Print the result.

## Example

The program prints:

```
(3 6 9 12)
```
