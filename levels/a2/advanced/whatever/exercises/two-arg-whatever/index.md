## Problem

Each `*` in a Whatever expression is a separate argument. So two stars make a function with two arguments. Write such a function. It joins its two arguments with a hyphen between them: `* ~ '-' ~ *`. Keep it in a variable. Then call it with `'a'` and `'b'`. Print the result.

## Example

The program prints:

```
a-b
```
