## Problem

Take the array `1, 2, 3`. Put it into a scalar `$x` with the **item** contextualiser. A contextualiser sets the context. Now `$x` keeps the whole array as one single value. Then run a `for` loop over `$x` with the **list** contextualiser. Count how many times the loop runs. In list context, the array becomes three elements again. So the loop runs three times. Print the count.

## Example

The program prints:

```
3
```
