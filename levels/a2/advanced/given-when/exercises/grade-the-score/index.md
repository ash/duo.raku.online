## Problem

Use `given`/`when`. The age is a number in the code. Print the stage of life for this age. Use these groups:

* `child` for 0–12,
* `teenager` for 13–19,
* `adult` for 20–64,
* `senior` for 65 and older.

An age below zero makes no sense. So for any number below zero, print `invalid`. Check this case first, before the ranges.

## Example

If the age is `30`, the program prints:

```
adult
```
