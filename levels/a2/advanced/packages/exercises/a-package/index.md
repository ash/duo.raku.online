## Problem

Create a package `Temperature`. It has two things in it. The first is an `our` variable `$freezing` with the value `0`. The second is an `our` subroutine `fahrenheit`. It changes a value in Celsius to Fahrenheit. To do this, multiply by 9/5 and add 32. From outside the package, print the freezing point. Then print `100` degrees Celsius in Fahrenheit.

## Example

The program prints:

```
0
212
```
