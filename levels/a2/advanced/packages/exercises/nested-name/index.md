## Problem

Put a module `Inner` inside a module `Outer`. In `Inner`, create an `our` variable `$base` with the value `10`. Also create an `our sub doubled`. It returns `$base` times two. From outside both modules, use the full nested name of the variable. This name has both module names in it. Call the subroutine by its full nested name too. Print both results.

## Example

The program prints:

```
10
20
```
