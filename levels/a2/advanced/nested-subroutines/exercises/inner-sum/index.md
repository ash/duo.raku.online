## Problem

Write a subroutine `compute`. Inside it, define a nested helper `add`. It returns the sum of its two arguments. Inside `compute`, return `add(2, 3) + add(4, 5)`.

Call `compute` and print the result.

## Example

The program prints:

```
14
```
