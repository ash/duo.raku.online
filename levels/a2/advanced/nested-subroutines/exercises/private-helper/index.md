## Problem

Write a subroutine `stats`. Inside it, define a **nested** helper subroutine `double`. It returns its argument times two. Inside `stats`, use the helper. Print the value of `double(3) + double(5)`.

Then call `stats`.

## Example

The program prints:

```
16
```
