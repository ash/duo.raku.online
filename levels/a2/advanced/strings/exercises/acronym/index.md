## Problem

Make an acronym from a phrase. An acronym is made of the first letters of words. Take the first letter of each word. Join the letters. Print the result in upper case.

Use this phrase:

```raku
my $phrase = 'hyper text markup language';
```

## Example

The program prints:

```
HTML
```
