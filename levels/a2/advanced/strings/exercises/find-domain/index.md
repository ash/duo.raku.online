## Problem

`index` tells you *where* a character is. Then you can cut the string at that place with `substr`. Use them together.

Take the email address `user@example.com`. Find the position of the `@` sign. Then print everything after it. This is the domain part.

## Example

The program prints:

```
example.com
```
