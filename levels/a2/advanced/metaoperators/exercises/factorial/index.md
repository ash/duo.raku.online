## Problem

One `[*]` reduction gives one factorial. Your task is to print _every_ factorial from _1!_ to _6!_. Print them in order, on one line. Use only one reduction. Use the triangular form of the reduction meta-operator. It keeps the product after each step, not only the last product.

## Example

The program prints the factorials of the numbers from 1 to 6:

```
(1 2 6 24 120 720)
```
