## Problem

A URL is cut into pieces. The pieces are in an array. Join the pieces into one string again. Use a reduction meta-operator for this. Print the URL. On the next line, print its length in characters.

## Example

Here is the input array:

```raku
my @parts = <http :// example .com>;
```

The program prints:

```
http://example.com
18
```
