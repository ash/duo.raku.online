## Problem

Write a program. It prints the average of an array of numbers. The average is also called the arithmetic mean. Use a reduction meta-operator to add up the values.

The numbers are written in the program itself. For example:

```raku
my @data = 10, 20, 30, 40;
```

## Example

The program prints the average of the elements of `@data`:

```
25
```
