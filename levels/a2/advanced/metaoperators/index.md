title: Meta-operators
---

{% include menu.html %}

A _meta-operator_ is not an operator by itself. It takes a normal operator and makes a new operator from it. For example, take a list of values. A meta-operator can use one operator on all of them at once. Then you do not write the operator between every two values.

Raku has several meta-operators. This section shows the most useful groups. The first group is _reduction_. It turns a list into one value. The second group is _zip_. It joins two lists, element by element. The last page shows the _cross_, _hyper_, and _negated_ operators.
