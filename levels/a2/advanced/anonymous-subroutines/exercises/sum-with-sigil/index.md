## Problem

A pointy block can have more than one parameter. With the `&` sigil, you can call it by its name. Write a pointy block with two parameters. It adds its two arguments. Keep it in the variable `&add`. This variable has the `&` sigil. Then call it as `add(2, 3)`, without the sigil. Print the result.

## Example

The program prints:

```
5
```
