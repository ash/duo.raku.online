## Problem

An anonymous subroutine is a closure. It remembers the variables from the place where you write it. Create a variable `$factor` with the value `3`. Then write a pointy block. It multiplies its argument by `$factor`. Do not write the number `3` in the block. Keep the block in `$scale`. Call `$scale(7)` and print the result.

## Example

The program prints:

```
21
```
