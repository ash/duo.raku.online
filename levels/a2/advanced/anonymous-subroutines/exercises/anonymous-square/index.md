## Problem

You do not have to keep an anonymous subroutine in a variable first. You can give it directly to another routine. Use the `sub` form, not a pointy block. Write an anonymous “square” subroutine. It multiplies a number by itself. Give it directly to `map` over the list `1, 2, 3`. Print the result.

## Example

The program prints:

```
(1 4 9)
```
