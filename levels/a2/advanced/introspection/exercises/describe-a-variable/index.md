## Problem

Here is a variable with a type:

```raku
my Str $lang = 'Raku';
```

Print three things about it. Print each one on its own line:

1. the type of its value;
2. the type of its container;
3. its name, with the sigil.

## Example

The program prints:

```
Str
Scalar
$lang
```
