## Problem

A container can have a default value. You set it with the trait `is default`. Before you assign a value, the variable returns this default. `.VAR.default` also shows it.

Declare a scalar `$count`. Its default must be `0`. Do not assign anything to it. Print the variable. Then print the default of its container. Both lines must show `0`.

## Example

The program prints:

```
0
0
```
