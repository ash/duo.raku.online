## Problem

`WHAT` does more than describe a type. It returns the type object itself. You can compare type objects with the operator `===`.

Declare two variables. `$a` keeps the integer `42`. `$b` keeps the string `'x'`. For each variable, look at its `WHAT`. Is it the type `Int`? Print the answer.

## Example

The program prints:

```
True
False
```
