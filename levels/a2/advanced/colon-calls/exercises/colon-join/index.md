## Problem

The colon form must be the *last* call in a chain. But the calls before it can be normal calls with parentheses. Start with the words `a`, `b`, `c`. Put them in reverse order with `.reverse`. Then join the result with a dash. Use the **colon** form for the join. Print the result.

## Example

The program prints:

```
c-b-a
```
