title: Subscript adverbs

{% include menu.html %}

You can subscript an array or a hash, like `@a[2]` or `%h<key>`. Then you can add an _adverb_ to the subscript. The adverb changes what the subscript does. Usually, a subscript only gets the value. With an adverb, you can ask if a key exists. You can delete the key. Or you can get the key and the value together.

You write these adverbs after the subscript. They start with a colon. They work in the same way with arrays and with hashes. This section shows the most useful adverbs.
