## Problem

Write two multi-subroutines with the name `price`. They take one integer: the quantity of items. Use a `where` clause. An order of 10 or more items prints `bulk price`. A smaller order prints `normal price`.

Call the subroutine with the quantities `3` and `25`.

## Example

The program prints:

```
normal price
bulk price
```
