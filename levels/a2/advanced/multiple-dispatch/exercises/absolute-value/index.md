## Problem

Write two multi-subroutines with the name `abs-value`. They take an integer and return its absolute value. The absolute value is the number without its minus sign. Use a `where` clause for negative numbers. Do not use `if` in the subroutines. Do not use the built-in `abs` either.

Print the result for `-7` and for `4`.

## Example

The program prints:

```
7
4
```
