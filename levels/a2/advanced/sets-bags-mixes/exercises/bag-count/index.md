## Problem

A bag is very good for counting words. Take the sentence `the cat sat on the mat`. Split it into words. Make a bag from the words. Then print two lines. The first line shows how many times the word `the` appears. The second line shows the total number of words.

## Example

The program prints:

```
2
6
```
