## Problem

Here are two sets with names of fruit:

```raku
my $a = set(<apple banana cherry>);
my $b = set(<banana cherry date>);
```

Find their intersection. The intersection has the values that are in both sets. Save it in a variable. Then print two lines. The first line is the number of common values. The second line shows if `apple` is one of them. It should not be one of them.

## Example

The program prints:

```
2
False
```
