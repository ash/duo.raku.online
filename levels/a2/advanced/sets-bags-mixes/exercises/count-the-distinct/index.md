## Problem

Here is a list of numbers. Some of them repeat:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Print how many _distinct_ values it has. Distinct values are all different from each other. Use a set.

## Example

The program prints:

```
7
```
