Tests check that your code does the right thing. They also check it again after each change. Raku comes with a module for tests, `Test`. Raku also has standard ways to run many tests at once. Real Raku programs and modules need tests. Writing them is an important part of the work.

This section shows the main parts of the `Test` module. It also shows the different kinds of comparison in it. Last, it shows how to run tests.
