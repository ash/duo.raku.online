A function in the `Test` module passes when a condition is true. The condition is `True` or `False`. Which function is it?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` takes a condition. It passes when the condition is true. `is` compares the value that you get with the value that you expect. `plan` says how many tests to expect. `done-testing` ends the file and prints the plan.

</div>
