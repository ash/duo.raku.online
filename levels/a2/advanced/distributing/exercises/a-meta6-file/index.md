## Problem

Write a `META6.json` file. The distribution has the name `Greet::Simple` and the version `0.0.1`. It provides the module `Greet::Simple` from the file `lib/Greet/Simple.rakumod`. In the example in the theory, `depends` is empty. Here it is different. This distribution **depends on** another distribution, `JSON::Fast`. Put it in the `depends` array.

> The result of this exercise is a file. It is not the output of a program.

## Example

You can see a correct file in the solution. It has only the parts that are needed.
