title: Distributing modules
---

{% include menu.html %}

Your module may be useful on other computers too. Then you can make it into a _distribution_. You can share it in the Raku module ecosystem. The ecosystem is the collection of shared Raku modules. Then anyone can install your module with `zef`.

This section shows two things that you need for this. The first is the file `META6.json`. It describes a distribution. The second is the tools `zef` and `fez`. They install and publish distributions. These steps are about the ecosystem and the network. They are not about the language. So the examples here show files and commands. They do not show the output of programs.
