## Problem

Is a number prime? Often, you cannot see this by just looking. The `is-prime` method answers this question. Use it on two numbers, `97` and `91`. At first, both of them look prime. Print the result for each number on its own line.

Be careful with `91`. It is `7 × 13`.

## Example

The program prints:

```
True
False
```
