## Problem

You can read a number in a base. You can also write it back in that base. These two steps are opposites. Take the hexadecimal number `1A`. Hexadecimal means base 16. Save its decimal value in a variable. Decimal means base 10. Then print two lines. The first line is the decimal value. Next, turn the value back into a hexadecimal string. Print it on the second line.

## Example

The program prints:

```
26
1A
```
