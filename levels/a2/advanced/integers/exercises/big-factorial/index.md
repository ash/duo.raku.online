## Problem

Integers in Raku have no size limit. So Raku can find the exact value of `2 ** 1000`. This number is very long. You cannot easily count its digits yourself. So let the program count them. Print how many digits `2 ** 1000` has in base 10.

## Example

The program prints:

```
302
```
