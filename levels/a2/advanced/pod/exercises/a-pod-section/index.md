## Problem

With `$=pod`, a program can go inside its own documentation. Write a `=begin pod` … `=end pod` block. Put a top-level heading and a paragraph in it. Then get the first Pod block with `$=pod[0]`. Print how many parts it has inside. The heading and the paragraph are two parts.

## Example

The program prints:

```
2
```
