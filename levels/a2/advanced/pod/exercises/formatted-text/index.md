## Problem

Write a Pod block. It has a `=head1` heading `Greeting` and a paragraph `Hello, world!`. Make the word `world` bold with `B<…>`. Then turn the block into text with `raku --doc`.

> Run the file with `raku --doc`. Then you see the formatted text.

## Example

With `raku --doc`, it prints this:

```
Greeting

Hello, world!
```
