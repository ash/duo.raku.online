The `x` operator repeats a string. So `'ab' x 3` gives `'ababab'`. The `x` stands between its two operands. What is its category?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Only the position matters. The operator can be a symbol or a word. `x` stands *between* two operands. So it is an **infix** operator, just like `+` or `~`. But its name is a letter.

</div>
