## Problem

Start with `my $n = 9;`. The postfix operator `++` has a feature that is easy to miss. In an expression, it returns the old value of the variable. This is the value *before* the increment. After that, `++` adds 1 to the variable.

Use one `say` to print the result of `$n++`. On the next line, print `$n` itself. Then you can see the difference.

## Example

The program prints:

```
9
10
```
