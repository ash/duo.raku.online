## Problem

Write the powers of two as a geometric sequence. In such a sequence, you multiply by the same number each time. Make the sequence *infinite*: end it with `Inf`. Then take only the first eight values with `head`. The sequence is lazy. So Raku never computes all of this endless sequence.

## Example

The program prints:

```
(1 2 4 8 16 32 64 128)
```
