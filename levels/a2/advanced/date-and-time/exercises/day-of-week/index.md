## Problem

Take Valentine’s Day, the 14th of February 2027. Is this day on a weekend? The weekend is Saturday and Sunday. If yes, print `True`. If not, print `False`. Remember that `day-of-week` gives each day a number. Monday is `1`, and Sunday is `7`.

## Example

The program prints:

```
True
```
