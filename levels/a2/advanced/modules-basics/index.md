A _module_ is a file with code that you can use again. It can have subroutines, variables, and more. Other programs can load the module and share it. This section shows the main things in three steps. First, you **write** a module. You mark what it gives to other programs. Second, a program **loads** the module with `use`. Third, **importing** brings the names of the module into your scope.
