## Problem

Create a module with the name `Maths` in the file `Maths.rakumod`. It exports a subroutine `square`. The subroutine returns the square of its argument.

Then write a separate program. It uses the module and prints `square(6)`.

## Example

Run the program with the module on the search path. It prints:

```console
$ raku -I. maths.raku
36
```
