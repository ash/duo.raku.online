## Problem

A native variable is never undefined. This rule is true for all native types, not only for `int`. Declare a native `num` and a native `str`. Do not give them values. Print the number. Then print the string in square brackets. This way, you can see that it is empty.

## Example

The program prints:

```
0
[]
```
