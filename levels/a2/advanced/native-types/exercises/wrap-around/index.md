## Problem

A `uint8` wraps around in both directions, up and down. It happens with big steps too, not only with steps of one. Show this:

1. Take a `uint8` with the value `250`. Add `10` to it. Print the result.
1. Take another `uint8` with the value `0`. Subtract one from it, that is, decrement it. Print the result.

## Example

The program prints:

```
4
255
```
