An _enumeration_ is a type. Its short name is _enum_. An enum has a fixed list of values. Each value is a constant with a name. A constant is a value that never changes. The days of the week are an example. The colours of a traffic light are another. The suits in a deck of cards are one more. Maybe `0` means red, and `1` means amber. You do not need to remember this. You give each value a name. Raku remembers the numbers for you.

This section shows how to make an enum. It also shows how to go from names to values, and back.
