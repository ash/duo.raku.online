## Problem

An enum connects names to numbers. You can also go the other way. Call the enum type like a function, with a number. Then you get the constant for this number.

Define an enum `Day` with the constants `Mon` to `Fri`. Give them the numbers from `1` to `5`. Then find the constants for the numbers `5` and `1`. Print them.

## Example

The program prints:

```
Fri
Mon
```
