## Problem

Define an enum `Coin`. Each constant holds its value in cents. `penny` is 1, and `nickel` is 5. `dime` is 10, and `quarter` is 25. Use `.enums` for the next part. Print the number of constants in the enum. Then print the sum of all their values.

## Example

The program prints:

```
4
41
```
