## Problem

`FIRST` runs only once. An `ENTER` phaser is different. It runs *every time* the program goes into the block. A loop goes into its body again in each round.

Make a loop over `1..2`. Inside the loop, put an `ENTER` phaser. It prints `--entering`. Also put a normal statement there. It prints `body` and the current number. You can see `--entering` once in each round.

## Example

The program prints:

```
--entering
body 1
--entering
body 2
```
