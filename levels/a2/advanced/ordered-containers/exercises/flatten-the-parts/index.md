## Problem

Here are two arrays:

```raku
my @first = 1, 2;
my @second = 3, 4, 5;
```

Put them together into one _flat_ array. It must not be a nested array, with arrays inside it. Print the array. Then print the number of its elements.

## Example

The program prints:

```
[1 2 3 4 5]
5
```
