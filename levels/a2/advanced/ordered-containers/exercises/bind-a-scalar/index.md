## Problem

Start with a scalar `$source` with the value `1`. Then make two more names. Bind `$bound` to `$source` with `:=`. Give `$copy` the value of `$source` with a normal `=`. Now change `$source` to `9`. Print `$bound` and `$copy`. Then you can see the difference between binding and copying.

## Example

The program prints:

```
9
1
```
