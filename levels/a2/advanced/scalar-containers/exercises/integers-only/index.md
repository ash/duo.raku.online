## Problem

Declare a container `$cars`. It can keep only integers.

You have a value from a computer model of traffic: `250.7`. Put it into `$cars`. Convert it to an integer first. Without this, the assignment does not work. Then print the value and its type.

## Example

The program prints:

```
250
(Int)
```
