## Aufgabe

Eine native Variable ist nie undefiniert. Diese Regel gilt für alle nativen Typen, nicht nur für `int`. Deklariere eine native `num` und eine native `str`. Gib ihnen keine Werte. Gib die Zahl aus. Dann gib den String in eckigen Klammern aus. So siehst du, dass er leer ist.

## Beispiel

Das Programm gibt aus:

```
0
[]
```
