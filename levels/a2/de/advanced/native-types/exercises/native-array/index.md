## Aufgabe

Native Typen mit fester Größe sind gut für Arrays aus Bytes. Solche Arrays brauchen wenig Speicher. Erstelle ein `uint8`-Array mit den Werten `100`, `200` und `255`. Jeder Wert passt in ein Byte. Gib die Summe der Elemente aus.

Die Elemente bleiben im Bereich `0..255`. Aber ihre Summe kann größer sein. `.sum` gibt einen normalen `Int` zurück.

## Beispiel

Das Programm gibt aus:

```
555
```
