## Aufgabe

Ist eine Zahl eine Primzahl? Oft kannst du das nicht einfach so sehen. Die Methode `is-prime` beantwortet diese Frage. Verwende sie für zwei Zahlen, `97` und `91`. Zuerst sehen beide wie Primzahlen aus. Gib das Ergebnis für jede Zahl in einer eigenen Zeile aus.

Pass bei `91` auf. Diese Zahl ist `7 × 13`.

## Beispiel

Das Programm gibt aus:

```
True
False
```
