title: Verständnis von Raku-Containern
---

{% include menu.html %}

In Raku speichern Container Daten. Aber ein Container ist mehr als eine einfache Variable. Seine Rolle ist größer und tiefer. Dieser Abschnitt zeigt die verschiedenen Containertypen in Raku.

Es ist wichtig, Container zu verstehen. Ohne dieses Wissen können dich manche Programme überraschen. Manchmal erwartest du ein Array. Aber das Programm scheint einen Skalar zu verwenden. Oder es ist umgekehrt.

Verschiedene Container können verschiedene Arten von Daten speichern. Die Daten können verschieden groß sein. Auch die Anzahl der Elemente kann verschieden sein. Deshalb hat jeder Containertyp eigene Methoden. Sie arbeiten mit den Daten im Container.
