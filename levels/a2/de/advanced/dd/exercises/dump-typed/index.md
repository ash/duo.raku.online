## Aufgabe

Deklariere eine Variable vom Typ `Int`: `my Int $n = 42;`. Gib sie mit `dd` aus. Sieh dir die Ausgabe an. Bei einer Variable ohne Typ ist die Ausgabe anders.

## Beispiel

Das Programm schreibt das auf den Standardfehlerstream:

```
Int $n = 42
```
