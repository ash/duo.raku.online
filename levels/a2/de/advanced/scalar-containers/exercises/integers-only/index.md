## Aufgabe

Deklariere einen Container `$cars`. Er darf nur Ganzzahlen speichern.

Du hast einen Wert aus einem Computermodell für Verkehr: `250.7`. Speichere ihn in `$cars`. Wandle ihn vorher in eine Ganzzahl um. Sonst funktioniert die Zuweisung nicht. Gib dann den Wert und seinen Typ aus.

## Beispiel

Das Programm gibt aus:

```
250
(Int)
```
