## Aufgabe

Deklariere eine skalare Variable `$discount`. Ihr Standardwert muss `0` sein. Gib die Variable aus, bevor du ihr etwas zuweist. Das Programm muss `0` ausgeben. Es darf keine Warnung ausgeben.

Weise dann der Variable `15` zu. Gib sie noch einmal aus.

## Beispiel

Das Programm gibt zwei Zeilen aus:

```
0
15
```
