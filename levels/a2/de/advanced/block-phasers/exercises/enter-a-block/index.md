## Problem

`FIRST` läuft nur einmal. Ein `ENTER`-Phaser ist anders. Er läuft *jedes Mal*, wenn das Programm in den Block geht. Eine Schleife geht in jeder Runde neu in ihren Rumpf.

Schreibe eine Schleife über `1..2`. Setze in die Schleife einen `ENTER`-Phaser. Er gibt `--entering` aus. Setze dort auch eine normale Anweisung hin. Sie gibt `body` und die aktuelle Zahl aus. Du siehst `--entering` einmal in jeder Runde.

## Beispiel

Das Programm gibt aus:

```
--entering
body 1
--entering
body 2
```
