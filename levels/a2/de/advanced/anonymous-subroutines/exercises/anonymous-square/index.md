## Problem

Sie müssen eine anonyme Subroutine nicht zuerst in einer Variablen speichern. Sie können sie direkt an eine andere Routine übergeben. Verwenden Sie die `sub`-Form, keinen Pointy Block. Schreiben Sie eine anonyme „Quadrat“-Subroutine. Sie multipliziert eine Zahl mit sich selbst. Übergeben Sie sie direkt an `map` über die Liste `1, 2, 3`. Geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
(1 4 9)
```
