## Problem

Ein Pointy Block kann mehr als einen Parameter haben. Mit dem `&`-Sigil können Sie ihn über seinen Namen aufrufen. Schreiben Sie einen Pointy Block mit zwei Parametern. Er addiert seine zwei Argumente. Speichern Sie ihn in der Variablen `&add`. Diese Variable hat das `&`-Sigil. Rufen Sie ihn dann als `add(2, 3)` auf, ohne Sigil. Geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
5
```
