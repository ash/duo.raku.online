## Problem

Eine anonyme Subroutine ist eine Closure. Sie merkt sich die Variablen von der Stelle, wo sie im Code steht. Erstellen Sie eine Variable `$factor` mit dem Wert `3`. Schreiben Sie dann einen Pointy Block. Er multipliziert sein Argument mit `$factor`. Schreiben Sie nicht die Zahl `3` in den Block. Speichern Sie den Block in `$scale`. Rufen Sie `$scale(7)` auf und geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
21
```
