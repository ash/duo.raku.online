## Problem

Schreiben Sie eine Subroutine `power`. Sie hat einen erforderlichen Parameter `$base` und einen **optionalen** Parameter `$exp`. Wenn der Aufrufer den Exponenten angibt, rechnen Sie Basis hoch Exponent. Wenn der Exponent fehlt, quadrieren Sie die Basis. Nutzen Sie dafür den Defined-or-Operator `//`, um `2` anzugeben.

Rufen Sie sie zweimal auf. Geben Sie zuerst nur eine Basis an. Geben Sie dann eine Basis und einen Exponenten an.

## Beispiel

Das Programm gibt aus:

```
25
125
```
