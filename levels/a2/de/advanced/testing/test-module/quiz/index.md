Eine Funktion im `Test`-Modul ist erfolgreich, wenn eine Bedingung wahr ist. Die Bedingung ist `True` oder `False`. Welche Funktion ist das?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` nimmt eine Bedingung. Es ist erfolgreich, wenn die Bedingung wahr ist. `is` vergleicht den Wert, den du bekommst, mit dem Wert, den du erwartest. `plan` sagt, wie viele Tests kommen. `done-testing` beendet die Datei und gibt den Plan aus.

</div>
