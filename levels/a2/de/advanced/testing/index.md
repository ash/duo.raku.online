Tests prüfen, ob dein Code das Richtige tut. Sie prüfen das auch nach jeder Änderung wieder. Raku bringt ein Modul für Tests mit: `Test`. Raku hat auch Standardwege, um viele Tests auf einmal auszuführen. Echte Raku-Programme und -Module brauchen Tests. Sie zu schreiben ist ein wichtiger Teil der Arbeit.

Dieser Abschnitt zeigt die wichtigsten Teile des `Test`-Moduls. Er zeigt auch die verschiedenen Arten von Vergleichen darin. Zuletzt zeigt er, wie du Tests ausführst.
