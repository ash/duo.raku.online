## Aufgabe

Ein Container kann einen Standardwert haben. Du setzt ihn mit dem Trait `is default`. Bevor du einen Wert zuweist, gibt die Variable diesen Standardwert zurück. Auch `.VAR.default` zeigt ihn.

Deklariere einen Skalar `$count`. Sein Standardwert muss `0` sein. Weise ihm nichts zu. Gib die Variable aus. Gib dann den Standardwert ihres Containers aus. Beide Zeilen müssen `0` zeigen.

## Beispiel

Das Programm gibt aus:

```
0
0
```
