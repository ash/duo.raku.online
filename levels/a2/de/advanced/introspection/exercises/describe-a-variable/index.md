## Aufgabe

Hier ist eine Variable mit einem Typ:

```raku
my Str $lang = 'Raku';
```

Gib drei Dinge über sie aus. Gib jedes in einer eigenen Zeile aus:

1. den Typ ihres Wertes;
2. den Typ ihres Containers;
3. ihren Namen, mit dem Sigil.

## Beispiel

Das Programm gibt aus:

```
Str
Scalar
$lang
```
