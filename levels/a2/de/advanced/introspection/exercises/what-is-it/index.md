## Aufgabe

`WHAT` beschreibt nicht nur einen Typ. Es gibt das Typ-Objekt selbst zurück. Du kannst Typ-Objekte mit dem Operator `===` vergleichen.

Deklariere zwei Variablen. `$a` enthält die Ganzzahl `42`. `$b` enthält den String `'x'`. Schau dir für jede Variable ihr `WHAT` an. Ist das der Typ `Int`? Gib die Antwort aus.

## Beispiel

Das Programm gibt aus:

```
True
False
```
