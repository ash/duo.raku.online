## Aufgabe

Hier ist ein Hash: `a => 1, b => 2, c => 3`. Lösche den Eintrag `b` mit einem Subscript-Adverb. Gib dann aus, wie viele Einträge noch im Hash sind. Das zeigt, dass ein Eintrag weg ist.

## Beispiel

Das Programm gibt aus:

```
2
```
