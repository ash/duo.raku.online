## Aufgabe

Hier sind zwei Sets mit Namen von Obst:

```raku
my $a = set(<apple banana cherry>);
my $b = set(<banana cherry date>);
```

Finde ihren Durchschnitt. Der Durchschnitt hat die Werte, die in beiden Sets sind. Speichere ihn in einer Variablen. Gib dann zwei Zeilen aus. Die erste Zeile ist die Anzahl der gemeinsamen Werte. Die zweite Zeile zeigt, ob `apple` einer davon ist. Das sollte nicht so sein.

## Beispiel

Das Programm gibt aus:

```
2
False
```
