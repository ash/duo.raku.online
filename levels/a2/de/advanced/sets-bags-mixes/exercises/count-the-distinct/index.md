## Aufgabe

Hier ist eine Liste von Zahlen. Einige davon wiederholen sich:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Gib aus, wie viele _verschiedene_ Werte sie hat. Bei verschiedenen Werten kommt kein Wert doppelt vor. Benutze ein Set.

## Beispiel

Das Programm gibt aus:

```
7
```
