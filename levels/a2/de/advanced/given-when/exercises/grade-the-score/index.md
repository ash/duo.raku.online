## Problem

Nutze `given`/`when`. Das Alter ist eine Zahl im Code. Gib die Lebensphase für dieses Alter aus. Nutze diese Gruppen:

* `child` für 0--12,
* `teenager` für 13--19,
* `adult` für 20--64,
* `senior` für 65 und älter.

Ein Alter unter null ergibt keinen Sinn. Gib also für jede Zahl unter null `invalid` aus. Prüfe diesen Fall zuerst, vor den Bereichen.

## Beispiel

Wenn das Alter `30` ist, gibt das Programm aus:

```
adult
```
