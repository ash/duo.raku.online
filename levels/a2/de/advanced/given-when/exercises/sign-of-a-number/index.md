## Problem

Nimm eine ganze Zahl im Code. Gib mit `given`/`when` aus, ob sie `zero`, `even` oder `odd` ist. Null ist auch eine gerade Zahl. Prüfe also zuerst auf null. Gib sie getrennt aus.

## Beispiel

Wenn die Zahl `12` ist, gibt das Programm aus:

```
even
```
