## Problem

Definiere einen Infix-Operator `percent-of`. Der Ausdruck `$p percent-of $whole` soll `$p` Prozent von `$whole` zurückgeben. Zum Beispiel ist `20 percent-of 150` gleich `30`.

Verwende den Operator, um `20 percent-of 150` auszugeben.

## Beispiel

Das Programm gibt aus:

```
30
```
