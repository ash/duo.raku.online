## Problem

Das Symbol eines Operators kann jedes Zeichen sein. Es kann auch ein Unicode-Zeichen sein. Definiere einen **Postfix**-Operator `²`. Er gibt das Quadrat seines Operanden zurück. Also bedeutet `5²` dasselbe wie `5 ** 2`. Gib dann `5²` aus.

## Beispiel

Das Programm gibt aus:

```
25
```
