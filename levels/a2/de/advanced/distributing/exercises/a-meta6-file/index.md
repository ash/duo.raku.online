## Problem

Schreibe eine Datei `META6.json`. Die Distribution hat den Namen `Greet::Simple` und die Version `0.0.1`. Sie liefert das Modul `Greet::Simple` aus der Datei `lib/Greet/Simple.rakumod`. Im Beispiel in der Theorie ist `depends` leer. Hier ist das anders. Diese Distribution **hängt von** einer anderen Distribution **ab**: `JSON::Fast`. Schreibe sie in das Array `depends`.

> Das Ergebnis dieser Aufgabe ist eine Datei. Es ist keine Ausgabe eines Programms.

In der Lösung siehst du eine korrekte Datei. Sie hat nur die nötigen Teile.
