## Problem

In Raku ist das Pragma `strict` standardmäßig eingeschaltet. Also müssen Sie jede Variable mit `my` deklarieren, bevor Sie sie benutzen. Schalten Sie das Pragma mit `no strict` aus. Weisen Sie dann `$a` den Wert `10` und `$b` den Wert `20` zu. Tun Sie das *ohne* `my`. Geben Sie die Summe der zwei Variablen aus.

## Beispiel

Das Programm gibt aus:

```
30
```
