## Aufgabe

Nimm das Array `1, 2, 3`. Lege es mit dem **Element**-Kontextualisierer in einen Skalar `$x`. Ein Kontextualisierer setzt den Kontext. Jetzt speichert `$x` das ganze Array als einen einzigen Wert. Lass dann mit dem **Listen**-Kontextualisierer eine `for`-Schleife über `$x` laufen. Zähle, wie oft die Schleife läuft. Im Listenkontext wird das Array wieder zu drei Elementen. Also läuft die Schleife dreimal. Gib die Anzahl aus.

## Beispiel

Das Programm gibt aus:

```
3
```
