## Problem

Jedes `*` in einem Whatever-Ausdruck ist ein eigenes Argument. Zwei Sterne machen also eine Funktion mit zwei Argumenten. Schreibe so eine Funktion. Sie verbindet ihre zwei Argumente mit einem Bindestrich dazwischen: `* ~ '-' ~ *`. Speichere sie in einer Variablen. Rufe sie dann mit `'a'` und `'b'` auf. Gib das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
a-b
```
