Der Operator `x` wiederholt einen String. Also ergibt `'ab' x 3` den String `'ababab'`. Das `x` steht zwischen seinen zwei Operanden. Welche Kategorie hat dieser Operator?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Nur die Position zählt. Der Operator kann ein Symbol oder ein Wort sein. `x` steht *zwischen* zwei Operanden. Also ist er ein **Infix**-Operator, genau wie `+` oder `~`. Aber sein Name ist ein Buchstabe.

</div>
