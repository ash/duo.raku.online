## Problem

Beginnen Sie mit `my $n = 9;`. Der Postfix-Operator `++` hat eine Eigenschaft, die man leicht übersieht. In einem Ausdruck gibt er den alten Wert der Variablen zurück. Das ist der Wert *vor* dem Erhöhen. Danach addiert `++` 1 zur Variablen.

Geben Sie mit einem `say` das Ergebnis von `$n++` aus. Geben Sie in der nächsten Zeile `$n` selbst aus. Dann sehen Sie den Unterschied.

## Beispiel

Das Programm gibt aus:

```
9
10
```
