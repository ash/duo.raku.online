## Problem

Erstelle ein Modul mit dem Namen `Maths` in der Datei `Maths.rakumod`. Es exportiert eine Subroutine `square`. Die Subroutine gibt das Quadrat ihres Arguments zurück.

Schreibe dann ein separates Programm. Es benutzt das Modul und gibt `square(6)` aus.

## Beispiel

Führe das Programm mit dem Modul im Suchpfad aus. Es gibt Folgendes aus:

```console
$ raku -I. maths.raku
36
```
