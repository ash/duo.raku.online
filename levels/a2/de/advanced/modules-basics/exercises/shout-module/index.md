## Problem

Erstelle ein Modul mit dem Namen `Shouter` in der Datei `Shouter.rakumod`. Es exportiert eine Subroutine `shout`. Die Subroutine gibt ihr Argument in Großbuchstaben zurück, also groß geschrieben.

Schreibe dann ein separates Programm. Es benutzt das Modul und gibt `shout('hi')` aus.

## Beispiel

Führe das Programm mit dem Modul im Suchpfad aus. Es gibt Folgendes aus:

```console
$ raku -I. shout.raku
HI
```
