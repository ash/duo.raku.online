## Aufgabe

`quietly` versteckt Warnungen. Wie `do` gibt es den Wert seines Blocks zurück. Lege eine Variable für einen Namen an, aber gib ihr keinen Wert. Baue dann einen Gruß `"Hello, " ~ $name ~ "!"` in einem `quietly`-Block. So bleibt die Warnung „uninitialized value“ versteckt. Weise den Wert des Blocks `$greeting` zu und gib ihn aus.

## Beispiel

Das Programm gibt aus:

```
Hello, !
```
