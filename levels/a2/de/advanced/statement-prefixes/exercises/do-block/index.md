## Aufgabe

`do` funktioniert auch vor Kontrollfluss-Anweisungen. Es macht sie zu Ausdrücken mit einem Wert. Wähle mit `do if 7 > 5 { 'big' } else { 'small' }` ein Label. Weise das Label `$label` zu und gib es aus.

## Beispiel

Das Programm gibt aus:

```
big
```
