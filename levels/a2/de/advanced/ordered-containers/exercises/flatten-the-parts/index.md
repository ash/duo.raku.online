## Aufgabe

Hier sind zwei Arrays:

```raku
my @first = 1, 2;
my @second = 3, 4, 5;
```

Füge sie zu einem _flachen_ Array zusammen. Es darf kein verschachteltes Array mit Arrays darin sein. Gib das Array aus. Dann gib die Anzahl seiner Elemente aus.

## Beispiel

Das Programm gibt aus:

```
[1 2 3 4 5]
5
```
