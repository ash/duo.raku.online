title: Geordnete Container
---

{% include menu.html %}

Geordnete Container speichern mehrere Elemente. Sie behalten die Reihenfolge der Elemente. So kannst du jedes Element über seine Position bekommen. Manchmal speichern sie nur ein Element oder sogar gar keins. Die häufigsten geordneten Container sind _Arrays_ und _Listen_.

Das Sigil `@` zeigt: Die Variable ist für viele Elemente. Bei so einer Variable kannst du einen Index verwenden. Du schreibst den Index in eckige Klammern. Dann bekommst du ein Element. Das hast du schon im Grundlagenteil gesehen.

In diesem Abschnitt sehen wir uns Arrays und Listen genauer an. Wie unterscheiden sie sich _als Container_? Welche davon kannst du ändern? Was passiert, wenn du einen Container in einen anderen steckst? Und was ist _Binding_? Binding gibt einem Container einen Namen. Es kopiert nichts.
