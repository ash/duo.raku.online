Welche Pod-Direktive macht eine **Überschrift der obersten Ebene**?

{:.quiz}
1 | `=head1`
0 | `=title`
0 | `=h1`
0 | `=heading`

{% include quiz.html %}

<div class="extended-explanation">

`=head1` ist eine Überschrift der obersten Ebene. `=head2`, `=head3` und so weiter sind tiefere Ebenen. Die Zahl ist die Ebene der Überschrift. Andere Sprachen zum Formatieren von Text funktionieren ähnlich.

</div>
