## Problem

Die Doppelpunkt-Form muss der *letzte* Aufruf in einer Kette sein. Aber die Aufrufe davor können normale Aufrufe mit Klammern sein. Beginne mit den Wörtern `a`, `b`, `c`. Drehe ihre Reihenfolge mit `.reverse` um. Dann verbinde das Ergebnis mit einem Bindestrich. Nimm dafür die **Doppelpunkt**-Form. Gib das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
c-b-a
```
