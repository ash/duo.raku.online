## Problem

Ein Programm kann mehr als einen `END`-Phaser haben. Dann laufen sie in **umgekehrter** Reihenfolge. Der letzte im Code läuft zuerst. Man nennt das „Last in, First out“.

Schreibe zwei `END`-Phaser. Der erste gibt `first END` aus. Der zweite gibt `second END` aus. Schreibe danach ein einfaches `say 'body'`. In welcher Reihenfolge kommt die Ausgabe? Rate sie zuerst. Dann erzeuge diese Ausgabe mit deinem Programm.

## Beispiel

Das Programm gibt aus:

```
body
second END
first END
```
