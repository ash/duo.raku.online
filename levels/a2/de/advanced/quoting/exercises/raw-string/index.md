## Problem

Nimm die wörtlichste Quoting-Form. Sie lässt den ganzen Text, wie er ist. Gib damit den Text `$x and \n` genau so aus, wie er geschrieben ist. Die Variable darf nicht interpoliert werden. Die Escape-Sequenz darf nicht verarbeitet werden.

## Beispiel

Das Programm gibt aus:

```
$x and \n
```
