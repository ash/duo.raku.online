## Problem

Beginne mit der `q`-Form. Sie interpoliert nicht. Schalte nur das Closure-Adverb ein. Die Variable `$x` enthält `10`. Gib eine Zeile mit der Rechnung `{$x ** 2}` *und* einem einfachen `$x` aus. Dieses einfache `$x` wird nicht interpoliert. So siehst du, dass das Closure-Adverb Code in geschweiften Klammern ausführt. Aber einfache `$`-Variablen fasst es nicht an.

## Beispiel

Das Programm gibt aus:

```
$x squared is 100
```
