## Problem

Erstelle ein Package `Temperature`. Es enthält zwei Dinge. Das erste ist eine `our`-Variable `$freezing` mit dem Wert `0`. Das zweite ist eine `our`-Subroutine `fahrenheit`. Sie rechnet einen Wert in Celsius in Fahrenheit um. Multipliziere dafür mit 9/5 und addiere 32. Gib von außerhalb des Packages den Gefrierpunkt aus. Gib dann `100` Grad Celsius in Fahrenheit aus.

## Beispiel

Das Programm gibt aus:

```
0
212
```
