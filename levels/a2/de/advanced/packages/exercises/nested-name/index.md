## Problem

Setze ein Modul `Inner` in ein Modul `Outer`. Erstelle in `Inner` eine `our`-Variable `$base` mit dem Wert `10`. Erstelle auch eine `our sub doubled`. Sie gibt `$base` mal zwei zurück. Benutze von außerhalb beider Module den vollen verschachtelten Namen der Variable. Dieser Name enthält beide Modulnamen. Rufe auch die Subroutine mit ihrem vollen verschachtelten Namen auf. Gib beide Ergebnisse aus.

## Beispiel

Das Programm gibt aus:

```
10
20
```
