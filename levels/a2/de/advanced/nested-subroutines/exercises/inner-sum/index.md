## Problem

Schreiben Sie eine Unterroutine `compute`. Definieren Sie darin einen verschachtelten Helfer `add`. Er gibt die Summe seiner zwei Argumente zurück. Geben Sie in `compute` den Wert `add(2, 3) + add(4, 5)` zurück.

Rufen Sie `compute` auf und geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
14
```
