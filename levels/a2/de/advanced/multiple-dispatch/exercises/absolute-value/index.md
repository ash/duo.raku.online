## Problem

Schreiben Sie zwei Multi-Subroutinen mit dem Namen `abs-value`. Sie nehmen eine ganze Zahl und geben ihren Absolutwert zurück. Der Absolutwert ist die Zahl ohne ihr Minuszeichen. Verwenden Sie eine `where`-Klausel für negative Zahlen. Verwenden Sie kein `if` in den Subroutinen. Verwenden Sie auch nicht das eingebaute `abs`.

Geben Sie das Ergebnis für `-7` und für `4` aus.

## Beispiel

Das Programm gibt aus:

```
7
4
```
