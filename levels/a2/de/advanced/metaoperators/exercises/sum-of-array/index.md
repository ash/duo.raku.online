## Aufgabe

Schreiben Sie ein Programm. Es gibt den Durchschnitt eines Arrays von Zahlen aus. Der Durchschnitt heißt auch arithmetisches Mittel. Nehmen Sie einen Reduktions-Meta-Operator, um die Werte zu addieren.

Die Zahlen stehen im Programm selbst. Zum Beispiel:

```raku
my @data = 10, 20, 30, 40;
```

## Beispiel

Das Programm gibt den Durchschnitt der Elemente von `@data` aus:

```
25
```
