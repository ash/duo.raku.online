## Aufgabe

Eine URL ist in Teile zerlegt. Die Teile sind in einem Array. Fügen Sie die Teile wieder zu einer Zeichenkette zusammen. Nehmen Sie dafür einen Reduktions-Meta-Operator. Geben Sie die URL aus. Geben Sie in der nächsten Zeile ihre Länge in Zeichen aus.

## Beispiel

Hier ist das Eingabe-Array:

```raku
my @parts = <http :// example .com>;
```

Das Programm gibt aus:

```
http://example.com
18
```
