Ein _Meta-Operator_ ist kein Operator für sich allein. Er nimmt einen normalen Operator und macht daraus einen neuen Operator. Nehmen Sie zum Beispiel eine Liste von Werten. Ein Meta-Operator kann einen Operator für alle Werte auf einmal benutzen. Dann schreiben Sie den Operator nicht zwischen je zwei Werte.

Raku hat mehrere Meta-Operatoren. Dieser Abschnitt zeigt die nützlichsten Gruppen. Die erste Gruppe ist die _Reduktion_. Sie macht aus einer Liste einen einzigen Wert. Die zweite Gruppe ist _Zip_. Es verbindet zwei Listen, Element für Element. Die letzte Seite zeigt die _Kreuz-_, _Hyper-_ und _negierten_ Operatoren.
