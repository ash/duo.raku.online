## Problem

`index` sagt dir, *wo* ein Zeichen steht. Dann kannst du den String mit `substr` an dieser Stelle schneiden. Benutze beide zusammen.

Nimm die E-Mail-Adresse `user@example.com`. Finde die Position des `@`-Zeichens. Dann gib alles danach aus. Das ist der Domain-Teil.

## Beispiel

Das Programm gibt aus:

```
example.com
```
