## Problem

Nimm den Valentinstag, den 14.02.2027. Liegt dieser Tag an einem Wochenende? Das Wochenende ist Samstag und Sonntag. Wenn ja, gib `True` aus. Wenn nicht, gib `False` aus. Denk daran: `day-of-week` gibt jedem Tag eine Nummer. Montag ist `1`, und Sonntag ist `7`.

## Beispiel

Das Programm gibt aus:

```
True
```
