In [einem der früheren Abschnitte](../hello-world) haben wir ein einfaches Programm geschrieben. Aber wir haben es noch nicht ausgeführt. Es gibt viele Wege, ein Programm auszuführen. Sie können ein Befehlszeilentool auf Ihrem Computer benutzen. Sie können eine REPL-Shell benutzen. Sie können das Programm direkt aus einer [IDE](../editors-and-ides) ausführen. Sie können einen Online-Dienst benutzen, wie [glot.io](https://glot.io/new/raku). Oder Sie können einen Docker-Container benutzen.

Dieser Abschnitt hat fünf Themen. Sie können alle lesen. Oder Sie lesen nur die Themen, die Sie brauchen. Nach den Themen gibt es eine Aufgabe.
