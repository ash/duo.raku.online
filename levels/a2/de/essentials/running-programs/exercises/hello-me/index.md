## Problem

Schreibe ein Programm und führe es aus. Es gibt einen Gruß mit deinem Namen aus. Speichere das Programm in einer Datei. Führe es über die Kommandozeile aus. Wenn du möchtest, kannst du das Programm auch online oder direkt in einer IDE [ausführen](/de/essentials/running-programs).

## Beispiel

Hier siehst du, wie man das Programm ausführt. Du siehst auch seine Ausgabe:

```console
$ raku hello-me.raku
Hallo, Andrew!
```

## Lösung

Versuche, diese Aufgabe selbst zu lösen. Speichere den Code in einer Datei. Dann gib die Datei dem Kommandozeileninterpreter. Oder führe sie auf einem anderen Weg von den früheren Seiten aus. Möchtest du ein Beispiel sehen? Oder funktioniert dein Programm aus irgendeinem Grund nicht? Dann sieh dir die funktionierende Lösung an. Der Link ist unten.
