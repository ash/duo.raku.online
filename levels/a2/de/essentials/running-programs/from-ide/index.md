Dieser Abschnitt ist sehr kurz. Er zeigt, wie Sie ein Programm ausführen, ohne die IDE zu verlassen. Wir sehen uns die zwei am meisten empfohlenen [IDEs](../../editors-and-ides) an.

## Visual Studio Code Editor

Öffnen Sie ein Terminal über das Menü: `Terminal` → `New Terminal`. Ein neues Panel öffnet sich unter Ihrem Programmtext. Führen Sie das Programm dort aus, wie auf der Kommandozeile:

```console
$ raku hello.raku
```

## Comma IDE

Um ein Programm auszuführen, nutzen Sie den Punkt `Run` im Menü. Richten Sie vor dem ersten Start die IDE ein. Folgen Sie [den Anweisungen](https://commaide.com/docs/running) auf der Comma-Website.
