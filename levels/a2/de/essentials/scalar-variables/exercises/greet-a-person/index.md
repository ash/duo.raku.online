## Problem

Schreiben Sie ein Programm. Es macht zwei Dinge:

1. Es fragt den Benutzer nach seinem Namen.
2. Es gibt die Nachricht `Hallo, Name!` aus. `Name` ist der Name, den der Benutzer gerade eingegeben hat.

Verwenden Sie in diesem Programm Variablen.

## Beispiel

So funktioniert das Programm:

```console
$ raku greet-a-person.raku
Wie heißt du? John
Hallo, John!
```
