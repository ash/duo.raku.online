## Problem

Schreiben Sie ein Programm. Zuerst erstellt es zwei Variablen. Es legt in jede Variable eine ganze Zahl. Dann tauscht es die Werte. Jede Variable bekommt den Wert der anderen. Am Ende gibt das Programm die Werte aus. Versuchen Sie, das Programm so einfach wie möglich zu machen. Verwenden Sie keine temporären oder zusätzlichen Variablen.
