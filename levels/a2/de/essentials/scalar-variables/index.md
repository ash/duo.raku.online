Bis jetzt hatten unsere Programme Textzeichenfolgen direkt im Code. Jetzt bringen wir ein wenig Freiheit hinein. Die Programme können Variablen verwenden.

Raku hat einige Arten von Variablen. Eine Variable ist ein Behälter. Sie speichert Daten, wie eine Kiste. Wir beginnen mit den einfachsten Behältern. Sie speichern nur einen Wert. Wir nennen sie _Skalare_ oder skalare Variablen. Jede Variable hat einen Namen. Vor dem Namen steht ein besonderes Zeichen. Es zeigt die Art des Behälters. Dieses Zeichen ist das _Sigil_. Für skalare Behälter ist das Sigil das Dollarzeichen `$`.

Hier sind zwei skalare Variablen:

```raku
$name

$age
```
