## Problem

Dieser Hash enthält die Daten eines Mitarbeiters:

```raku
my %employee =
    full-name => 'Eliza Vents',
    department => 'Sales',
    salary => 3000;
```

Erhöhe das Gehalt um 5&thinsp;%. Gib das neue Gehalt und den Namen des Mitarbeiters aus. Nach der Änderung muss der Hash `%employee` die richtigen Werte haben.

## Beispiel

Das Programm muss das hier ausgeben:

```console
$ raku salary-raise.raku
Neues Gehalt von Eliza Vents: 3150
```
