## Problem

Ein Array enthält eine Liste von Ländercodes. Jeder Code hat zwei Buchstaben:

```raku
my @codes = < FR IT DE EE LV US CN IN BR >;
```

Schreibe das Programm zu Ende. Es muss die vollen Namen dieser Länder ausgeben. Gib jeden Namen in einer eigenen Zeile aus. Verwende die Datei [cc.raku](https://github.com/ash/raku-course/blob/master/essentials/associatives/exercises/country-codes/cc.raku). Sie enthält einen Hash. Der Hash gibt für jeden Code den Namen des Landes.

## Beispiel

Hier ist die Ausgabe des Programms. Sie zeigt nur die ersten paar Namen:

```console
$ raku country-codes.raku
France
Italy
Germany
. . .
```
