{% include menu.html %}

Raku hat einen eingebauten Typ für Boolesche Werte. Er heißt `Bool`. Eigentlich ist `Bool` eine Enumeration. Eine Enumeration ist ein Typ mit einer festen Liste von Werten. `Bool` hat nur zwei Werte: `True` und `False`.
