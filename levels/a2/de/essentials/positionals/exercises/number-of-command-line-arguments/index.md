## Aufgabe

Schreiben Sie ein Programm. Es zählt die Argumente von der Befehlszeile. Es gibt die Anzahl in einem ganzen Satz aus. Die Grammatik muss richtig sein. Für genau ein Argument verwenden Sie das Wort `argument`. In allen anderen Fällen verwenden Sie `arguments`.

## Beispiel

Das muss das Programm tun:

```console
$ raku number-of-command-line-arguments.raku make them count us now
You passed 5 arguments.

$ raku number-of-command-line-arguments.raku solo
You passed 1 argument.
```
