## Aufgabe

Schreiben Sie ein Programm. Es liest Argumente von der Befehlszeile. Es können beliebig viele sein. Das Programm gibt jedes Argument auf einer eigenen Zeile aus. Die Zeilen haben Nummern.

## Beispiel

Das Programm muss so funktionieren:

```console
$ raku count-and-print-arguments.raku wörter zum anzeigen
1. wörter
2. zum
3. anzeigen
```
