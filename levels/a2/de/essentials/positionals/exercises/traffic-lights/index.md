## Problem

Eine Ampel wechselt jede Sekunde ihre Farbe. Wenn Sie sie einschalten, beginnt sie mit Gelb. Dann wechselt die Farbe jede Sekunde. Die Reihenfolge ist Gelb — Rot — Gelb — Grün. Dann beginnt alles wieder von vorne.

Schreiben Sie ein Programm. Es gibt die Farbe der Ampeln aus. Machen Sie das für die 51<sup>ste</sup>, 102<sup>te</sup> und 305<sup>te</sup> Sekunde. In der 1<sup>sten</sup> Sekunde ist die Farbe Rot.

## Beispiel

Das Programm muss drei Farben ausgeben. Jede steht auf einer eigenen Zeile:

```console
$ raku traffic-lights.raku
...
...
...
```
