Raku-Programme sind reiner Text. Normalerweise speichern Sie sie in Textdateien. Aber es gibt einige Ausnahmen. Zum Beispiel können Sie ein Programm online ausführen. Oder Sie führen es in der Befehlszeile aus. Sie können auch Code vorbereiten und mit `EVAL` ausführen. Es gibt auch noch ein paar andere seltene Fälle.

Raku erwartet den Programmtext in UTF-8. Sie können also jeden Texteditor benutzen. Aber er darf keine Formatierung in der Datei speichern. Sie können `vim`, `nano`, `emacs` oder `mcedit` benutzen. Jeder davon ist eine gute Wahl. Aber vielleicht möchten Sie auch ein paar beliebte neue Programme ausprobieren.

## Externe Links

Hier sind Links zu einigen beliebten IDEs. Eine IDE ist ein Programm zum Schreiben und Ausführen von Code.

* [Visual Studio Code](https://code.visualstudio.com/) — für Windows, Mac OS und Linux
* [Comma](https://commaide.com) — die Raku-IDE, extra für das Programmieren in Raku gemacht. Sie läuft unter Windows, Mac OS und Linux.
