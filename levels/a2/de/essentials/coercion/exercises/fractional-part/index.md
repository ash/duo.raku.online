## Problem

Eine Zahl steht direkt im Programm. Geben Sie ihren Dezimalbruch aus. Hier ist der Anfang des Programms:

```raku
my $n = 15.8972;
# ... Ihr Code hier
```

## Beispiel

Das Programm muss den Teil nach dem Dezimalpunkt ausgeben:

```console
$ raku fractional-part.raku
0.8972
```
