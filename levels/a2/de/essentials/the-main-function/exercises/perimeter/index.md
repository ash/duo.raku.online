## Problem

Schreiben Sie ein Programm. Es berechnet den Umfang eines Rechtecks und gibt ihn aus. Übergeben Sie die Längen von zwei Seiten als Kommandozeilenargumente. Bei einem Quadrat übergeben Sie nur einen Wert. Verwenden Sie die Funktion `MAIN`.

## Beispiel

Das Programm muss die Form klar nennen: ein Quadrat oder ein Rechteck. Hier ist eine mögliche Ausgabe für die zwei Fälle:

```console
$ raku perimeter.raku 15
Der Umfang eines Quadrats beträgt 60.

$ raku perimeter.raku 15 20
Der Umfang eines Rechtecks beträgt 70.
```
