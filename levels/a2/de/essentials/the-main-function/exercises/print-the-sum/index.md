## Problem

Schreiben Sie ein Programm. Es nimmt zwei ganze Zahlen von der Kommandozeile. Dann gibt es ihre Summe aus. Verwenden Sie die Funktion `MAIN`. Die Parameter der Funktion müssen Typen haben.

## Beispiel

Hier ist ein Beispiel:

```console
$ raku print-the-sum.raku 500 700
1200
```
