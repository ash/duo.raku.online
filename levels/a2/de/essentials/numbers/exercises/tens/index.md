## Problem

Schreiben Sie ein Programm. Es fragt den Benutzer nach einer positiven ganzen Zahl. Dann gibt es die Ziffer aus, die die Anzahl der _Zehner_ darin zeigt.

## Beispiel

Zum Beispiel gibt der Benutzer 234 ein. Die Anzahl der Zehner darin ist 3. Also gibt das Programm 3 aus:

```console
$ raku tens.raku
Geben Sie eine positive ganze Zahl ein: 234
3
```
