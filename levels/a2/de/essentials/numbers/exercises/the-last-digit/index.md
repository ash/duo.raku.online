## Problem

Schreiben Sie ein Programm. Es fragt den Benutzer nach einer positiven ganzen Zahl. Dann gibt es die letzte Ziffer dieser Zahl aus.

## Beispiel

Hier ist ein Beispiel, wie das Programm funktioniert:

```console
$ raku die-letzte-ziffer.raku
Geben Sie eine Zahl ein: 123
Die letzte Ziffer von 123 ist 3.
```
