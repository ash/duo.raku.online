## Aufgabe

Schreiben Sie ein Programm. Es erstellt einige skalare Variablen. Es gibt ihnen Werte dieser Typen: `Int`, `Rat`, `Num`, `Bool` und `Str`. Das Programm gibt jeden Wert und seinen Typ aus.

## Beispiel

Ihre Ausgabe kann anders sein. Aber dieser Testlauf zeigt die Idee:

```console
$ raku types.raku
151 (Int)
4.2 (Rat)
1e10 (Num)
True (Bool)
xyz (Str)
```
