Ein Codeblock ist ein Teil Ihres Programms. Er steht zwischen zwei geschweiften Klammern: `{` und `}`. Ein Block enthält mehrere Anweisungen. Sie arbeiten zusammen, wie eine große Anweisung. Die nächsten Abschnitte zeigen viele Wege, Blöcke zu benutzen.

```raku
{
    say 'Hallo, Welt!';
}
```

Dieses Programm braucht den Codeblock eigentlich nicht. Aber Codeblöcke sind in anderen Fällen sehr nützlich. Wir sehen sie uns sehr bald an.

Aber zuerst sehen wir uns die Idee des _Scopes_ an. Der Scope zeigt, wo Sie eine Variable benutzen können.
