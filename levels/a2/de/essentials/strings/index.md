Jetzt sprechen wir über Zeichenketten. Unsere Programme hatten schon Zeichenketten. Diese Zeichenketten heißen auch Zeichenkettenliterale. Ein Zeichenkettenliteral ist ein Text in Anführungszeichen:

```raku
say 'Ich bin ein Zeichenkettenliteral';
```

Natürlich kann auch eine skalare Variable eine Zeichenkette speichern:

```raku
my $message = 'Das ist meine Nachricht';
```
