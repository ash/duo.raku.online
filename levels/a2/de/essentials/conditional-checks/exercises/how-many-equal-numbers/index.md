## Problem

Schreiben Sie ein Programm. Der Benutzer gibt drei ganze Zahlen ein. Das Programm sagt, wie viele davon gleich sind. Die Zahlen können positiv oder negativ sein. Das Programm muss mit beiden Arten funktionieren.

## Beispiel

So kann das Programm laufen:

```console
$ raku how-many-equal-numbers.raku
Zahl 1: 3
Zahl 2: -4
Zahl 3: 3
2
```

Wenn alle drei Zahlen unterschiedlich sind, gibt das Programm `0` aus.
