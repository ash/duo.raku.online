## Problem

Hier ist die bekannte [FizzBuzz-Aufgabe](https://en.wikipedia.org/wiki/Fizz_buzz). Unsere Version ist etwas einfacher.

Schreiben Sie ein Programm. Es fragt den Benutzer nach einer ganzen Zahl größer als null. Dann gibt es Folgendes aus:

* `Fizz`, wenn man die Zahl ohne Rest durch 3 teilen kann.
* `Buzz`, wenn man die Zahl ohne Rest durch 5 teilen kann.

## Beispiel

Starten Sie das Programm. Es fragt Sie nach einer Zahl. Dann gibt es das Ergebnis aus.

```console
$ raku fizz-buzz.raku
Geben Sie eine Zahl ein: 10
Buzz
```
