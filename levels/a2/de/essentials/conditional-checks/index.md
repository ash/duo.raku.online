---

{% include menu.html %}

Manchmal muss ein Programm in verschiedenen Situationen verschiedene Dinge tun. Dafür können Sie `if` und ähnliche Wörter benutzen.

Alle diese Wörter brauchen eine Bedingung. Die Bedingung kann ein [Boolean](/de/essentials/booleans)-Wert sein, `True` oder `False`. Sie kann ein Boolean-Ausdruck sein. So ein Ausdruck ergibt `True` oder `False`. Oder sie kann jeder andere Ausdruck sein. Raku muss seinen Wert in `True` oder `False` [ändern](/de/essentials/coercion) können.
