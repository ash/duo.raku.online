## Problem

Schreiben Sie ein Programm, das eine ganze Zahl durch eine andere teilt. Es muss Subtraktion verwenden. Die Zahlen stehen schon im Code:

```raku
my $a = 175;
my $b = 25;
```

Schreiben Sie das Programm fertig. Es muss den ganzzahligen Teil von `$a / $b` ausgeben. Verwenden Sie nur eine Schleife und Subtraktion.

## Beispiel

```console
$ raku division-via-subtraction.raku
7
```
