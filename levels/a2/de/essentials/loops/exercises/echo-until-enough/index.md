## Problem

Schreiben Sie ein Programm. Es fragt immer wieder nach einem Wort. Es gibt jedes Wort im Terminal aus. Wenn das Wort `genug` ist, hört das Programm auf. Bevor es aufhört, gibt es eine letzte Nachricht aus.

## Beispiel

Das Programm kann endlos laufen. Hier sehen Sie nur ein paar Runden.
```console
$ raku echo-until-enough.raku
Ihr Wort: Sprache
Sprache
Ihr Wort: Programmierung
Programmierung
Ihr Wort: genug
OK, fertig.
```
