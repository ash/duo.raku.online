## Problem

Schreiben Sie eine Funktion mit zwei Argumenten, `$x` und `$y`. Die Funktion gibt `$x` hoch `$y` zurück. Schreiben Sie dann ein Programm. Es gibt die Werte von `5³`, `2¹⁰` und `(−4)⁵` aus.

## Beispiel

Für diese Werte gibt das Programm Folgendes aus:

```
$ raku function-x-to-the-power-of-y.raku
125
1024
-1024
```
