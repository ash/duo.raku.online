## Problem

Schreiben Sie eine Funktion. Die Funktion berechnet die mathematische Konstante _e_. Das Ergebnis ist nicht genau, aber es ist nah dran. Verwenden Sie diese Formel:

<img src="e-formula.png" style="height: 4.5em; width: auto">

Die Funktion muss auf diese zwei Arten funktionieren:

1. Das Argument gibt die Anzahl der Elemente in der Formel an: `e-approx(10)`.
2. Ohne Argument hat die Summe 100 Elemente: `e-approx()`.

Geben Sie die Ergebnisse für beide Fälle aus.

## Beispiel

```console
$ raku the-value-of-e.raku
2.7182818
2.718281828459045
```
