## Problem

Schreiben Sie ein Programm. Es gibt die Werte der Funktion `f(x) = x²` aus. Nehmen Sie für `x` die Werte von −3 bis 3, auch −3 und 3 selbst. Addieren Sie jedes Mal 0,1 zu `x`.

## Beispiel

Das Programm gibt zwei Spalten aus. In der ersten Spalte steht der Wert von `x`. In der zweiten Spalte steht der Wert von `f(x)`.

```
$ raku function-table.raku
-3	9
-2.9	8.41
-2.8	7.84
. . .
```
