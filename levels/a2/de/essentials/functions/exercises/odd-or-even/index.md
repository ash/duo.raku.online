## Problem

Schreiben Sie eine Funktion. Die Funktion nimmt eine ganze Zahl als Argument. Sie gibt die Zeichenkette `'Ungerade'` oder `'Gerade'` zurück. Schreiben Sie dann ein Programm mit dieser Funktion. Geben Sie die Antwort für einige Zahlen aus. Nehmen Sie zum Beispiel `10`, `5`, `0` und `3`.

## Beispiel

Für diese Zahlen gibt das Programm Folgendes aus:

```console
$ raku odd-or-even.raku
Gerade
Ungerade
Gerade
Ungerade
```
