## Problem

Schreiben Sie ein Programm. Es fragt nach Ihrem Alter. Wenn die Zahl negativ ist, gibt das Programm eine oder zwei Warnungen aus. Die Warnung muss an `STDERR` gehen.

## Beispiel

Hier sind zwei Beispiele:

```console
$ raku print-the-warning.raku
Wie alt sind Sie? 20
Ihr Alter ist 20

$ raku print-the-warning.raku
Wie alt sind Sie? -1
Sie haben eine negative Zahl eingegeben!
```
