## Aufgabe

Erstellen Sie eine Klasse `Robot`. Sie hat ein Attribut `position`, das Sie ändern können. Sein Standardwert ist `0`. Die Klasse hat auch eine Methode `move`. Diese Methode bewegt die Position um einige Schritte nach vorn. Der Standardwert für die Anzahl der Schritte ist `1`. Also bewegt `move` ohne Argument den Roboter einen Schritt.

Erstellen Sie einen Roboter. Bewegen Sie ihn `5` Schritte. Rufen Sie dann `move` ohne Argument auf. Bewegen Sie ihn dann noch `2` Schritte. Geben Sie seine letzte Position aus.

## Beispiel

Das Programm gibt aus:

```
8
```
