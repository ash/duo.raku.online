## Aufgabe

Erstellen Sie eine Klasse `Word` mit einem Attribut `text`. Geben Sie ihr eine Methode `reversed`. Diese Methode gibt den Text des Wortes rückwärts zurück. Tipp: Die Methode `flip` dreht eine Zeichenkette um.

Erstellen Sie ein Wort mit dem Text `Raku`. Geben Sie den Text rückwärts aus.

## Beispiel

Das Programm gibt aus:

```
ukaR
```
