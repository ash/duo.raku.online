## Aufgabe

Erstellen Sie eine Klasse `Rectangle` mit zwei Attributen, `width` und `height`. Fügen Sie eine Methode `area` hinzu. Sie gibt die Fläche des Rechtecks zurück. Fügen Sie eine zweite Methode hinzu, `describe`. Sie gibt die Zeichenkette `area is <area>` zurück. Dafür muss sie über `self` **ihre eigene Methode `area` aufrufen**.

Erstellen Sie ein Rechteck. Es ist `3` breit und `4` hoch. Geben Sie seine Beschreibung aus.

## Beispiel

Das Programm gibt aus:

```
area is 12
```
