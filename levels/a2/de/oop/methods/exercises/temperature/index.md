## Aufgabe

Erstellen Sie eine Klasse `Celsius` mit einem Attribut `degrees`. Fügen Sie eine Methode `to-fahrenheit` hinzu. Sie rechnet die Temperatur in Fahrenheit um. Benutzen Sie diese Formel: `Grad × 9 / 5 + 32`.

Erstellen Sie ein `Celsius`-Objekt für `100` Grad. Geben Sie seinen Wert in Fahrenheit aus.

## Beispiel

Das Programm gibt aus:

```
212
```
