## Aufgabe

Erstellen Sie eine Basisklasse `Animal`. Erstellen Sie dann eine Klasse `Dog`, die von ihr erbt. Geben Sie den Namen der Klasse `Dog` aus. Sehen Sie sich dann die Vererbungskette von `Dog` an. Diese Kette enthält die Klasse und alle ihre Elternklassen. Geben Sie in der nächsten Zeile die Anzahl der Typen darin aus. Benutzen Sie `.^mro` und zählen Sie die Elemente. Geben Sie in einer dritten Zeile aus, ob diese Kette eine Klasse `Cat` enthält.

## Beispiel

Das Programm gibt aus:

```
Dog
4
False
```
