## Aufgabe

Wenn ein `try`-Block fehlschlägt, ist sein Wert undefiniert. Nutzen Sie das mit dem Defined-or-Operator `//`. Mit `//` können Sie für diesen Fall einen Ersatzwert angeben. Führen Sie einen `try`-Block mit `die 'no'` darin aus. Wenn der Block fehlschlägt, nehmen Sie stattdessen die Zeichenkette `default`. Geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
default
```
