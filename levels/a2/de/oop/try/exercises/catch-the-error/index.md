## Aufgabe

Zeigen Sie beide Seiten von `try`. Ein `try`-Block fängt Fehler in seinem Code. Schreiben Sie zuerst eine Berechnung in einen `try`-Block. Die Berechnung muss funktionieren, zum Beispiel `6 * 7`. Geben Sie ihr Ergebnis aus. Schreiben Sie dann Code mit `die 'broken'` in einen zweiten `try`-Block. Geben Sie aus, ob dieser Block ein definiertes Ergebnis geliefert hat. Geben Sie auch die Meldung der gefangenen Ausnahme aus.

## Beispiel

Das Programm gibt aus:

```
42
False
broken
```
