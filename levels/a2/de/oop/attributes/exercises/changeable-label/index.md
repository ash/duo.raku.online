## Aufgabe

Erstellen Sie eine Klasse `Label` mit einem Attribut, `text`. Sie können dieses Attribut ändern (`is rw`). Erstellen Sie ein Etikett mit dem Text `draft`. Dann **hängen** Sie ` (revised)` an das Ende des Textes an. Tun Sie das über den Accessor. Erstellen Sie das Objekt nicht noch einmal. Geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
draft (revised)
```
