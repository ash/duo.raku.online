## Aufgabe

Erstellen Sie eine Klasse `Counter` mit einem Attribut, `count`. Sie können dieses Attribut ändern (`is rw`). Sein Standardwert ist `0`.

Erstellen Sie einen Zähler. Geben Sie zuerst sein `count` aus. Das zeigt, dass er beim Standardwert beginnt. Erhöhen Sie ihn dann in einer Schleife fünfmal um 1. Geben Sie den letzten Wert aus.

## Beispiel

Das Programm gibt aus:

```
0
5
```
