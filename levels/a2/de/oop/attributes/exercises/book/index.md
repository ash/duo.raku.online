## Aufgabe

Erstellen Sie eine Klasse `Book` mit zwei Attributen, `title` und `author`. Erstellen Sie ein Buch mit dem Titel `Raku` und dem Autor `Larry`. Geben Sie dann eine Zeile über das Buch aus. Benutzen Sie darin beide Accessoren. Die Zeile hat diese Form: `<title> by <author>`.

## Beispiel

Das Programm gibt aus:

```
Raku by Larry
```
