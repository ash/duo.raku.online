## Aufgabe

Lösen Sie jetzt dieselbe Aufgabe mit einer **Methode**. Erstellen Sie eine Klasse `Number`. Sie hat ein Attribut `n` und eine Methode `triple`. Die Methode gibt das Dreifache von `n` zurück. Erstellen Sie ein `Number` mit `n` gleich `7`. Rufen Sie `triple` darauf auf und geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
21
```
