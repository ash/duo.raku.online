## Aufgabe

Erstellen Sie eine Klasse `Animal` mit einer Methode `speak`. Erstellen Sie dann eine Klasse `Dog`. Sie erbt von `Animal`. Sie hat keine eigenen Methoden. Benutzen Sie eine Metamethode auf `Dog`. Prüfen Sie, ob `Dog` eine Methode `speak` hat. Geben Sie nur `True` oder `False` aus. Das zeigt etwas über `find_method`. Diese Methode sucht entlang der ganzen Vererbungskette. Sie sucht nicht nur bei den Methoden der Klasse selbst.

## Beispiel

Das Programm gibt aus:

```
True
```
