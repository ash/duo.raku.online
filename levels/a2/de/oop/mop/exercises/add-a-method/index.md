## Aufgabe

Erstellen Sie eine Klasse `Dog`. Sie hat nur ein Attribut `name` und keine Methoden. Fügen Sie ihr dann mit dem MOP eine Methode `speak` hinzu. Tun Sie das, während das Programm läuft. Die neue Methode benutzt den eigenen `name` des Objekts. Sie gibt `<name> says woof` zurück. Erstellen Sie einen Hund mit dem Namen `Rex` und rufen Sie die neue Methode auf.

## Beispiel

Das Programm gibt aus:

```
Rex says woof
```
