## Aufgabe

Erstellen Sie eine Klasse `A`. Erstellen Sie dann `B` und `C`. Beide erben von `A`. Erstellen Sie zum Schluss `D`. Diese Klasse erbt von `B` und von `C`. Geben Sie die method resolution order von `D` aus. Geben Sie sie als Liste von Typnamen aus. In dieser Reihenfolge sucht Raku nach einer Methode.

## Beispiel

Das Programm gibt aus:

```
(D B C A Any Mu)
```
