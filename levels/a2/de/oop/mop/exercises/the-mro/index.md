## Aufgabe

Erstellen Sie eine Kette aus drei Klassen. Die erste ist `A`. Dann erbt `B` von `A`. Dann erbt `C` von `B`. Geben Sie die method resolution order von `C` aus. Geben Sie sie als Liste von Typnamen aus. In dieser Reihenfolge sucht Raku nach einer Methode.

## Beispiel

Das Programm gibt aus:

```
(C B A Any Mu)
```
