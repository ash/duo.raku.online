## Aufgabe

Speichern Sie eine Zahl in einer Datei und laden Sie sie wieder. Die Datei heißt `number.txt`. Schreiben Sie die Zahl `42` hinein und danach einen Zeilenumbruch. Lesen Sie dann die Datei. Machen Sie aus ihrem Inhalt einen Integer, also eine ganze Zahl. Multiplizieren Sie die Zahl mit zwei und geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
84
```
