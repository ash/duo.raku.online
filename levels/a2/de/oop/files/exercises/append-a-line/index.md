## Aufgabe

Legen Sie eine kleine Protokolldatei an. Fügen Sie mehrmals Zeilen an ihrem Ende hinzu. Schreiben Sie zuerst die Zeile `start` in eine Datei mit dem Namen `log.txt`. **Hängen** Sie dann in einer Schleife drei weitere Zeilen **an**. Das heißt, Sie fügen sie am Ende der Datei hinzu. Die Zeilen sind `entry 1`, `entry 2` und `entry 3`. Löschen Sie nicht, was schon in der Datei steht. Lesen Sie am Ende die ganze Datei und geben Sie sie aus.

## Beispiel

Das Programm gibt aus:

```
start
entry 1
entry 2
entry 3
```
