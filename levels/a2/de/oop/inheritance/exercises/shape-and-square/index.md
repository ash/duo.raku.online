## Aufgabe

Erstellen Sie eine Basisklasse `Shape` mit zwei Methoden. Die Methode `name` gibt `'shape'` zurück. Die Methode `describe` gibt die Zeichenkette `I am a <name>` zurück. Für den Namen ruft sie ihre eigene Methode `name` auf.

Erstellen Sie dann eine Klasse `Square`. Sie erbt von `Shape`. Sie überschreibt `name`. Ihre eigene Version von `name` gibt `'square'` zurück.

Geben Sie die Beschreibung eines `Square` aus.

## Beispiel

Das Programm gibt aus:

```
I am a square
```
