## Aufgabe

Erstellen Sie eine Basisklasse `Vehicle` mit einem Attribut `wheels`. Erstellen Sie dann zwei Klassen, die von ihr erben. Die erste ist `Bike`. Sie hat `2` Räder. Die zweite ist `Car`. Sie hat `4` Räder.

Erstellen Sie ein `Bike` und ein `Car`. Geben Sie für jedes die Anzahl der Räder aus.

## Beispiel

Das Programm gibt aus:

```
2
4
```
