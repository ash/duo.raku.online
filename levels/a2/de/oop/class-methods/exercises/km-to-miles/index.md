## Aufgabe

Erstellen Sie eine Klasse `Converter` mit einer Klassenmethode `km-to-miles`. Sie bekommt eine Anzahl Kilometer. Sie gibt die Strecke in Meilen zurück. Für Meilen multiplizieren Sie mit `0.621`.

Rufen Sie die Methode auf der Klasse für `10` Kilometer auf. Geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
6.21
```
