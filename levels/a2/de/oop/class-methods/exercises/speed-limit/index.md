## Aufgabe

Eine Klassenmethode kann Parameter haben, wie jede andere Methode. Erstellen Sie eine Klasse `Geometry` mit einer Klassenmethode `circle-area`. Sie bekommt einen Radius. Sie gibt die Fläche eines Kreises zurück. Benutzen Sie `π` oder `pi`. Runden Sie die Fläche auf eine ganze Zahl. Die Formel gehört zur ganzen Klasse. Hier gibt es kein einzelnes Kreisobjekt. Rufen Sie die Methode auf der Klasse mit einem Radius von `10` auf. Geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
314
```
