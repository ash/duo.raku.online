## Aufgabe

Starten Sie mit `run` das Programm `echo`. Geben Sie ihm zwei getrennte Argumente: `home:` und `$HOME`. Argumente sind Werte, die Sie einem Programm geben. Lassen Sie die Ausgabe auf den Bildschirm gehen. Beachten Sie: Das Programm gibt `$HOME` unverändert aus. Es gibt das Heimatverzeichnis **nicht** aus. Der Grund ist: `run` benutzt keine Shell. Nur eine Shell ersetzt Variablen wie `$HOME` durch ihre Werte.

## Beispiel

Das Programm gibt aus:

```
home: $HOME
```
