## Aufgabe

Verwenden Sie `run` mit `:out`. Starten Sie `echo` mit den drei Wörtern `hello world raku`. Fangen Sie seine Ausgabe in einer Variablen auf. Geben Sie die Ausgabe nicht einfach aus. Zählen Sie stattdessen die Wörter darin. Geben Sie dann diese Zahl aus.

## Beispiel

Das Programm gibt aus:

```
3
```
