## Aufgabe

Führen Sie einen Befehl aus, der absichtlich fehlschlägt. Nehmen Sie zum Beispiel `sh -c 'exit 4'`. Behalten Sie das `Proc`, das er zurückgibt. Geben Sie den Exit-Code des Befehls aus. Der Exit-Code ist eine Zahl. Ein Befehl gibt sie am Ende zurück. Geben Sie dann `success` aus, wenn der Befehl funktioniert hat. Sonst geben Sie `failure` aus.

## Beispiel

Das Programm gibt aus:

```
4
failure
```
