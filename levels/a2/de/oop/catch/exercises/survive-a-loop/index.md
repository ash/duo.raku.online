## Aufgabe

Schreiben Sie eine Schleife über die Zahlen `1`, `2` und `3`. Geben Sie für jede Zahl `ok: <n>` aus. Aber bei der Zahl `2` führen Sie `die "bad: 2"` aus. Fügen Sie einen `CATCH`-Phaser in den Rumpf der Schleife ein. Er fängt den Fehler und gibt `caught: <message>` aus. Dann hält eine schlechte Runde nicht die ganze Schleife an.

## Beispiel

Das Programm gibt aus:

```
ok: 1
caught: bad: 2
ok: 3
```
