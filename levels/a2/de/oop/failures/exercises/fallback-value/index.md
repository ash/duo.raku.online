## Aufgabe

Schreiben Sie eine Subroutine `get`. Sie gibt ihr Argument zurück. Aber wenn das Argument `0` ist, ruft sie `fail` auf. Die Meldung ist `bad`.

Geben Sie das Ergebnis von `get(5)` aus. Geben Sie dann das Ergebnis von `get(0)` aus. Nutzen Sie den Defined-or-Operator `//` mit dem Ersatzwert `default`. Der Operator `//` nimmt diesen Wert, wenn das Ergebnis undefiniert ist.

## Beispiel

Das Programm gibt aus:

```
5
default
```
