## Aufgabe

Schreiben Sie eine Subroutine `reciprocal`. Sie gibt `1` geteilt durch ihr Argument zurück. Aber wenn das Argument `0` ist, benutzt sie `fail`. Die Meldung ist `no reciprocal of zero`.

Geben Sie das Ergebnis von `reciprocal(4)` aus. Geben Sie dann das Ergebnis von `reciprocal(0)` aus. Prüfen Sie hier nicht selbst `.defined`. Nutzen Sie stattdessen den Operator `//`. Wenn der Aufruf fehlschlägt, liefert `//` die Zeichenkette `undefined`.

## Beispiel

Das Programm gibt aus:

```
0.25
undefined
```
