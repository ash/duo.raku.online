## Aufgabe

Erstellen Sie zwei Rollen:

* `Named` hat eine Methode `label`. Die Methode gibt `I am <name>` zurück.
* `Aged` hat eine Methode `status`. Die Methode gibt `<age> years` zurück.

Erstellen Sie dann eine Klasse `Pet`. Sie erfüllt beide Rollen. Sie hat die Attribute `name` und `age`. Erstellen Sie ein Haustier mit dem Namen `Rex` und dem Alter `3`. Geben Sie sein `label` und seinen `status` aus.

## Beispiel

Das Programm gibt aus:

```
I am Rex
3 years
```
