## Aufgabe

Erstellen Sie eine Klasse `Robot` mit einer Methode `speak`. Diese Methode gibt `beep` zurück. Erstellen Sie dann eine Rolle `Dancing`. Sie fügt eine Methode `dance` hinzu. Diese Methode gibt `spinning around` zurück.

Erstellen Sie zwei Roboter. Geben Sie die Rolle `Dancing` nur einem von ihnen. Rufen Sie `speak` auf beiden Robotern auf und geben Sie die Ergebnisse aus. Rufen Sie dann `dance` auf dem Roboter auf, der tanzen kann. Geben Sie auch dieses Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
beep
beep
spinning around
```
