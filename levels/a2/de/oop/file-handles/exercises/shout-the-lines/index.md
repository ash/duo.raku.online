## Aufgabe

Schreiben Sie drei Wörter in eine Datei mit dem Namen `words.txt`. Die Wörter sind `apple`, `banana` und `cherry`. Jedes Wort steht in einer eigenen Zeile. Lesen Sie die Datei dann Zeile für Zeile. Geben Sie jede Zeile mit ihrer Nummer davor aus. Die Nummern beginnen bei `1`. Verwenden Sie diese Form: `<Nummer>: <Zeile>`.

## Beispiel

Das Programm gibt aus:

```
1: apple
2: banana
3: cherry
```
