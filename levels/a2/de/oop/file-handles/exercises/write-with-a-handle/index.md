## Aufgabe

Öffnen Sie eine Datei mit dem Namen `out.txt` zum Schreiben. Lassen Sie den Handle offen. Schreiben Sie in einer Schleife die Zahlen `1`, `2` und `3` hinein. Jede Zahl muss in einer eigenen Zeile stehen. Schließen Sie dann den Handle. Lesen Sie die Datei und geben Sie ihren Inhalt aus.

## Beispiel

Das Programm gibt aus:

```
1
2
3
```
