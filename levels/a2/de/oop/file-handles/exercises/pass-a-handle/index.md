## Aufgabe

Ein Dateihandle ist ein normaler Wert. Also können Sie ihn an eine Funktion übergeben, wie jedes andere Argument. Schreiben Sie eine Subroutine `log-line`. Die Subroutine nimmt einen Handle und eine Meldung. Sie schreibt die Meldung in den Handle, in einer eigenen Zeile.

Öffnen Sie `log.txt` zum Schreiben. Rufen Sie `log-line` dreimal auf. Schreiben Sie damit `started`, `working` und `done`. Schließen Sie dann den Handle. Lesen Sie die Datei und geben Sie ihren Inhalt aus.

## Beispiel

Das Programm gibt aus:

```
started
working
done
```
