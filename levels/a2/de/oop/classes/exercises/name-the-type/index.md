## Aufgabe

Erstellen Sie zwei leere Klassen, `Cat` und `Dog`. Erstellen Sie dann eine Instanz von `Cat` mit dem Namen `$felix`. Geben Sie den Typ von `$felix` mit `WHAT` aus. Geben Sie dann zwei weitere Zeilen aus. Benutzen Sie darin den Operator `===`. Die erste Zeile zeigt, ob der Typ gleich `Cat` ist. Die zweite Zeile zeigt, ob er gleich `Dog` ist.

## Beispiel

Das Programm gibt aus:

```
(Cat)
True
False
```
