## Aufgabe

Erstellen Sie zwei leere Klassen, `Cat` und `Dog`. Schreiben Sie dann eine Schleife über vier Werte: `Cat`, `Dog`, `Cat.new` und `Dog.new`. Geben Sie für jeden Wert aus, ob er definiert ist. Sehen Sie sich das Ergebnis an. Die zwei Typobjekte sind undefiniert. Die zwei Instanzen sind definiert. Die Klasse ist hier nicht wichtig.

## Beispiel

Das Programm gibt aus:

```
False
False
True
True
```
