## Problem

Write a function. It calculates the mathematical constant _e_. The result is not exact, but it is close. Use this formula:

<img src="e-formula.png" style="height: 4.5em; width: auto">

The function must work in these two ways:

1. The argument gives the number of items in the formula: `e-approx(10)`.
2. With no argument, the sum has 100 items: `e-approx()`.

Print the results for both cases.

## Example

```console
$ raku the-value-of-e.raku
2.7182818
2.718281828459045
```
