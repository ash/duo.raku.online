## Problem

Write a function with two arguments, `$x` and `$y`. It returns `$x` to the power of `$y`. Then write a program. It prints the values of `5³`, `2¹⁰`, and `(−4)⁵`.

## Example

For these values, the program prints this:

```
$ raku function-x-to-the-power-of-y.raku
125
1024
-1024
```
