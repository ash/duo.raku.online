## Problem

Write a function. It takes a whole number as an argument. It returns the string `'Odd'` or `'Even'`. Then write a program with this function. Print the answer for a few numbers. For example, use `10`, `5`, `0`, and `3`.

## Example

For these numbers, the program prints this:

```console
$ raku odd-or-even.raku
Even
Odd
Even
Odd
```
