## Problem

Write a program. It prints the values of the function `f(x) = x²`. Take `x` from −3 to 3, with −3 and 3 too. Each time, add 0.1 to `x`.

## Example

The program prints two columns. The first column has the value of `x`. The second column has the value of `f(x)`.

```
$ raku function-table.raku
-3	9
-2.9	8.41
-2.8	7.84
. . .
```
