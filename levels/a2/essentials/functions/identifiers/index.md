The name of a function is an identifier. It follows the same rules as [variable names](/essentials/scalar-variables/identifiers). It must start with a letter or an underscore (`_`). Then it can have letters, digits and underscores. It can also have hyphens (`-`) and apostrophes (`'`). An apostrophe is a single quote.

After an apostrophe or a hyphen, there must be a letter. People do not often use apostrophes in names. But they use hyphens a lot. With hyphens, a name can say more.

Here are some examples of correct function names.

    greet

    greet-them

    hello-world

    NumberOfItems

    is-valid

    to_be-or-not_to_be
