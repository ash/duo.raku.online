A code block is a part of your program. It is inside a pair of curly braces: `{` and `}`. A block has several statements in it. They work together, like one big statement. The next sections show many ways to use blocks.

```raku
{
    say 'Hello, World!';
}
```

This program does not really need the code block. But code blocks are very useful in other cases. We look at them very soon.

But first, let's look at the idea of _scope_. Scope is about where you can use a variable.
