In [one of the earlier sections](../hello-world), we wrote a simple program. But we did not run it yet. There are many ways to run a program. You can use a command-line tool on your computer. You can use a REPL shell. You can run the program directly from an [IDE](../editors-and-ides). You can use an online service, like [glot.io](https://glot.io/new/raku). Or you can use a docker container.

This section has five topics. You can read all of them. Or you can read only the ones you need. After the topics, there is a task.
