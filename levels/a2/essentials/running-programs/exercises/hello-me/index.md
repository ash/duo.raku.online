## Problem

Write a program and run it. It prints a greeting with your name. Save the program in a file. Run it from the command line. If you like, [run the program](/essentials/running-programs) online or directly from an IDE.

## Example

Here you see how to run the program. You also see its output:

```console
$ raku hello-me.raku
Hello, Andrew!
```

## Solution

Try to solve this task yourself. Save the code in a file. Then give the file to the command-line interpreter. Or run it in another way from the earlier pages. Do you want to see an example? Or does your program not work for some reason? Then look at the working solution. The link is below.
