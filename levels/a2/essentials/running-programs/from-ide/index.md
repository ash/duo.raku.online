This section is very short. It shows how to run a program without leaving the IDE. We look at the two most recommended [IDEs](../../editors-and-ides).

## Visual Studio Code Editor

Open a terminal from the menu: `Terminal` → `New Terminal`. A new panel opens below your program text. Run the program there, like from the command line:

```console
$ raku hello.raku
```

## Comma IDE

To run a program, use the `Run` item in the menu. Before the first run, set up the IDE. Follow [the instructions](https://commaide.com/docs/running) on the Comma website.
