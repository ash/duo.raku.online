title: Conventional file extensions in Raku

{% include menu.html %}

A file extension is the last part of a file name. Here are the [recommended](https://github.com/Raku/problem-solving/blob/master/solutions/language/Path-to-Raku.md#extensions) extensions for Raku files:

* `.raku` for program files
* `.rakumod` for modules
* `.rakutest` and `.t` for tests
* `.rakudoc` for documentation in the POD6 format
