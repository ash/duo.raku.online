## Problem

OK, let's greet a person one more time. But this time, use string interpolation. Ask the person for their name. Then print a greeting. The greeting also tells the number of letters in the name. Use code interpolation, the `{ }` form. With it, you find the length right inside the string.

## Example

Run the program. It asks for your name:

```console
$ raku hello-interpolation.raku
What is your name? Raku
Hello, Raku! Your name has 4 letters.
```
