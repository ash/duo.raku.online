## Problem

Write a program. It asks the user for their first name. Then it asks for their last name. At the end, it prints the number of letters in both names together. Do not count the space between the names.

## Example

Run the program and answer both questions. Then the program prints one number. It is the length of the two names together.

```console
$ raku name-length.raku
First name: Ada
Last name: Lovelace
11
```
