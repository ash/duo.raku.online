## Problem

Write a program. It prints a price table in this form. Please keep the prices and the totals in variables.

    Item    Price   N      Total
    Chairs  $20.57  4      $82.28
    Tables  $50.18  1      $50.18

Maybe you do not like this currency. Then you can use any other one. But do not forget that `$` [has a special meaning](/essentials/strings/escaping-special-characters) in Raku strings. That is why we chose it. It helps you learn Raku better.

## Example

This program needs no input. You run it, and it prints the table above.

```console
$ raku purchase-table.raku
```
