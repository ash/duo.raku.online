## Problem

Do you remember our exercise ‘[Greet a person](/essentials/scalar-variables/exercises/greet-a-person/)’? Let's do it again, now at a new level.

Write a program. It asks the user for their name. Then it asks for the city they come from. At the end, it prints a greeting with the name and the city. Use string concatenation in the solution.

## Example

Run the program. It asks you two questions:

```console
$ raku hello-concatenation.raku
What is your name? Ella
Where are you from? Lisbon
```

Then the program prints the greeting:

    Hello, Ella from Lisbon!
