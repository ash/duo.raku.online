Now let's talk about strings. Our programs already had strings. These strings are also called string literals. A string literal is some text in quotes:

```raku
say 'I am a string literal';
```

Of course, a scalar variable can keep a string too:

```raku
my $message = 'This is my message';
```

Now let's learn some more basic things about strings.
