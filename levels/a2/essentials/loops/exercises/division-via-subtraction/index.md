## Problem

Write a program that divides one whole number by another. It must use subtraction. The numbers are already in the code:

```raku
my $a = 175;
my $b = 25;
```

Finish the program. It must print the whole part of `$a / $b`. Use only a loop and subtraction.

## Example

```console
$ raku division-via-subtraction.raku
7
```
