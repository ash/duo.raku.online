## Problem

Write a program that divides whole numbers with subtraction. The numbers are fixed in the program:

```raku
my $a = 175;
my $b = 25;
```

Finish the program. It must print the whole-number part of `$a / $b`. Use only a loop and subtraction.

## Example

```console
$ raku division-via-subtraction.raku
7
```
