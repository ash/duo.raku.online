## Problem

Write a program that prints this shape:

    1
    12
    123
    1234

The user enters the size of the stairs. The size is not bigger than 9.

## Example

Here is an example with the input value `3`:

```console
$ raku digital-stairs.raku
Enter the size: 3
1
12
123
```
