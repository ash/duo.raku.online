## Problem

Write a program that prints this:

    1
    12
    123
    1234

The user enters the size of the stairs. The size is 9 or less.

## Example

Here is an example. The user enters `3`:

```console
$ raku digital-stairs.raku
Enter the size: 3
1
12
123
```
