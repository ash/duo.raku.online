{% include menu.html %}

You can also use `loop` with only a body:

```raku
loop {
    say 'Eternity';
}
```

This loop runs forever. It stops only when you stop the program, for example, with `Ctrl+C`. In the second part of the course, you will learn better ways to control loops.
