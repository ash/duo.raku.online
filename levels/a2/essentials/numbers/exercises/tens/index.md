## Problem

Write a program. It asks the user for a positive integer. Then it prints the digit that shows the number of _tens_ in it.

## Example

For example, the user enters 234. The number of tens in it is 3. So the program prints 3:

```console
$ raku tens.raku
Enter a positive integer number: 234
3
```
