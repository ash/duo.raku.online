## Problem

There are _N_ people and _K_ apples. The people share the apples equally. Write a program that answers these questions:

* How many apples does each person get?
* How many apples stay in the basket?

Write the numbers _N_ and _K_ directly in the code. Put them into variables, for example:

```raku
my $N = 3;
my $K = 11;

# Your code here . . .
```

Each apple stays whole. You cannot cut apples into pieces.

## Example

With the numbers above, the program should print this:

```console
$ raku apple-sharing.raku
Each person gets 3 apple(s).
There are 2 apple(s) remaining.
```

For now, do not worry about the correct form of the nouns. The output may also look strange when no apples are left. That is OK for now.
