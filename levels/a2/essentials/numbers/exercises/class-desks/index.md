## Problem

A school is getting ready for the year after coronavirus. It is going to order new desks. One desk is for two students. You know the number of students in the class. How many desks must the school buy for the class? Print the smallest possible number.

Write the number of students directly in the code. Keep it in a variable.

## Example

Here is the first line of the program:

```raku
my $students = 23;
# Your code here . . .
```

Run the program. You should see this:

```console
$ raku class-desks.raku
12 desks must be bought.
```
