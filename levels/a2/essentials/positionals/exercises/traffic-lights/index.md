## Problem

A traffic light changes its colour every second. When you turn it on, it starts as yellow. Then the colour changes every second. The order is yellow — red — yellow — green. Then it starts again from the beginning.

Write a program. It prints the colour of the traffic lights. Do it for the 51<sup>st</sup>, 102<sup>nd</sup> and 305<sup>th</sup> second. On the 1<sup>st</sup> second, the colour is red.

## Example

The program must print three colours. Each one is on its own line:

```console
$ raku traffic-lights.raku
...
...
...
```
