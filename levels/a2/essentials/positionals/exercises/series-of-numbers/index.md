## Task

Write a program. It asks the user for two integers, _A_ and _B_. The number _A_ must not be bigger than _B_: _A ≤ B_. Then the program prints all integers from _A_ to _B_. The numbers _A_ and _B_ are in the output too.

## Example

The program should work like this:

```console
$ raku series-of-numbers.raku
Begin: 14
End: 17
14
15
16
17
```
