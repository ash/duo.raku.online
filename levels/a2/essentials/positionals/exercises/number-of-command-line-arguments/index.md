## Task

Write a program. It counts the arguments from the command line. It prints the number in a full sentence. The grammar must be correct. For exactly one argument, use the word `argument`. In all other cases, use `arguments`.

## Example

This is what the program must do:

```console
$ raku number-of-command-line-arguments.raku make them count us now
You passed 5 arguments.

$ raku number-of-command-line-arguments.raku solo
You passed 1 argument.
```
