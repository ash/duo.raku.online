## Problem

Here is an array of numbers:

```raku
my @data = 10, 12, 1, 5, -9, 8, 36, 18, 21;
```

Finish the program. It must print only the elements with odd indices. These are the indices 1, 3, 5, and so on. Then change the number of items in `@data`. The program must still work.

## Example

```console
$ raku odd-indices.raku
12
5
8
18
```
