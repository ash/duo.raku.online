Now it is time for more complex data types. In Raku, some data types are positional. You can index them, or _subscript_ them. So you can get an element by its number. We already know one positional data type: [ranges](/essentials/ranges).

This section shows two more positional data types: `Array` and `List`. The second part of the course tells more about them. We also look at ranges again. This time, we look at them as a positional data type.
