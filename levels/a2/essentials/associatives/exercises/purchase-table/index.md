## Problem

You did the exercise ‘[Purchase table](/essentials/strings/exercises/purchase-table)’ before. Take the same table from it:

    Item    Price   N      Total

    Tables  $50.18  1      $50.18

Choose a data structure for these values. Then write a program. It must print the data.

## Example

Run the program. It must print the table above.

