## Problem

This hash has the data of one employee:

```raku
my %employee =
    full-name => 'Eliza Vents',
    department => 'Sales',
    salary => 3000;
```

Increase the salary by 5&thinsp;%. Print the new salary and the name of the employee. After the change, the `%employee` hash must have the correct values.

## Example

The program must print this:

```console
$ raku salary-raise.raku
New salary of Eliza Vents: 3150
```
