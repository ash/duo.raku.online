## Problem

An array has a list of country codes. Each code has two letters:

```raku
my @codes = < FR IT DE EE LV US CN IN BR >;
```

Finish the program. It must print the full names of these countries. Print each name on its own line. Use the file [cc.raku](https://github.com/ash/raku-course/blob/master/essentials/associatives/exercises/country-codes/cc.raku). It has a hash. The hash gives the name of the country for each code.

## Example

Here is the output of the program. It shows only the first few names:

```console
$ raku country-codes.raku
France
Italy
Germany
. . .
```
