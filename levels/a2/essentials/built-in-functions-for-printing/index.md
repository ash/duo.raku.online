We often use the built-in routine `say`. It prints data to the console. To be more exact, it prints to the `STDOUT` stream. Raku has a few more functions that print. Most of them were in the [‘Hello, World!’ examples](/essentials/hello-world). But we only looked at them quickly. This section gives more details.
