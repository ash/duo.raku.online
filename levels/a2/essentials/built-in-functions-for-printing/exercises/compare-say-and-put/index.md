## Problem

Write a program. It shows how `say` and `put` are different. Use all the data types from the course so far. They are `Int`, `Rat`, `Num`, `Str`, `Array`, `List`, `Range`, and `Hash`. For single values, use [variables with a type](/essentials/typed-variables).

## Example

For each data type, the program prints at least one result. It uses both `say` and `put`.

```console
$ raku compare-say-and-put.raku
256
256
0.125
0.125
. . .
```
