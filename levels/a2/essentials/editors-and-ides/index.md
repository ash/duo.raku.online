Raku programs are plain text. Usually, you keep them in text files. But there are some exceptions. For example, you can run a program online. Or you can run it in the command line. You can also prepare code and run it with `EVAL`. There are a few other rare cases too.

Raku expects the program text in UTF-8. So you can use any text editor. But it must not save formatting in the file. You can use `vim`, `nano`, `emacs` or `mcedit`. Any of them is a good choice. But you may also want to try some popular new applications.

## External links

Here are links to some popular IDEs. An IDE is a program for writing and running code.

* [Visual Studio Code](https://code.visualstudio.com/) — for Windows, Mac OS and Linux
* [Comma](https://commaide.com) — the Raku IDE, made just for programming in Raku. It works on Windows, Mac OS and Linux.
