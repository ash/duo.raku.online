title: Conditional checks
---

{% include menu.html %}

Sometimes a program must do different things in different situations. For this, you can use `if` and similar words.

All of them need a condition. The condition can be a [Boolean](/essentials/booleans) value, `True` or `False`. It can be a Boolean expression. Such an expression gives `True` or `False`. Or it can be any other expression. Raku must be able to [change](/essentials/coercion) its value into `True` or `False`.
