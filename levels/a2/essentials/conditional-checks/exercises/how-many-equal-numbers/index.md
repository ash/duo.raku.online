## Problem

Write a program. The user enters three whole numbers. The program tells how many of them are equal. The numbers can be positive or negative. The program must work with both kinds.

## Example

Here is how the program can run:

```console
$ raku how-many-equal-numbers.raku
Number 1: 3
Number 2: -4
Number 3: 3
2
```

If all three numbers are different, the program prints `0`.
