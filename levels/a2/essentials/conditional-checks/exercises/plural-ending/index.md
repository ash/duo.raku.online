## Task

Write a program. It asks the user for a whole number bigger than zero. Then it prints `N files copied`. Here, `N` is the number from the user. The word `file` must be in the correct form, singular or plural.

## Example

This is what the program must do:

```console
$ raku plural-endings.raku
How many files to copy? 15
15 files copied.
```
