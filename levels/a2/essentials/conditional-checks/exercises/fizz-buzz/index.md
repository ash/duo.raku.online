## Problem

Here is the well-known [FizzBuzz task](https://en.wikipedia.org/wiki/Fizz_buzz). Our version is a bit simpler.

Write a program. It asks the user for a whole number bigger than zero. Then it prints:

* `Fizz` if the number divides by 3 with nothing left over.
* `Buzz` if the number divides by 5 with nothing left over.

## Example

Run the program. It asks you for a number. Then it prints the result.

```console
$ raku fizz-buzz.raku
Enter a number: 10
Buzz
```
