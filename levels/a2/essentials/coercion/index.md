We already know several data types in Raku. First, there are different kinds of [numbers](/essentials/numbers). They are integers, rational numbers, and floating-point numbers. Then there are [strings](/essentials/strings). And there is the [Boolean](/essentials/booleans) type. Each data type has a name in the Raku type system.

`Str` | String of characters
`Int` | Integer number
`Rat` | Rational number
`Num` | Floating-point number
`Bool` | Logical Boolean

Raku knows more data types. We see them later in the course.
