## Task

Write a program. It creates a few scalar variables. It gives them values of these types: `Int`, `Rat`, `Num`, `Bool`, and `Str`. The program prints each value and its type.

## Example

Your output can be different. But this test run shows the idea:

```console
$ raku types.raku
151 (Int)
4.2 (Rat)
1e10 (Num)
True (Bool)
xyz (Str)
```
