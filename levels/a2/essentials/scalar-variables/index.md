{% include menu.html %}

Until now, our programs had text strings written right in the code. Now we add a little freedom. The programs can use variables.

Raku has a few kinds of variables. A variable is a container. It keeps some data, like a box. We start with the simplest containers. They keep only one value. We call them _scalars_, or scalar variables. Every variable has a name. A special character comes before the name. It shows the kind of container. This character is the _sigil_. For scalar containers, the sigil is the dollar sign `$`.

Here are two scalar variables:

```raku
$name

$age
```
