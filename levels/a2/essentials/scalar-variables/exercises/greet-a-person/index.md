## Problem

Write a program. It does two things:

1. It asks the user for their name.
2. It prints the message `Hello, Name!`. `Name` is the name that the user just entered.

Use variables in this program.

## Example

This is how the program works:

```console
$ raku greet-a-person.raku
What is your name? John
Hello, John!
```
