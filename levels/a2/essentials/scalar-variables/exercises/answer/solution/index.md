Here is one way to solve the task.

## Code

```raku
my $answer = 42;
say $answer;
```

🦋 You can find the source code in the file [answer.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/scalar-variables/answer.raku).

## Output

Run the program and see what it prints:

```console
$ raku exercises/scalar-variables/answer.raku 
42
```

## Comments

One rule of this task is to use variables. `42` is just one value. So a scalar variable is a good place to keep it.
