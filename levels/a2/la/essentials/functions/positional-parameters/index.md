title: Positional parametra
---

{% include menu.html %}

Ordo parametrorum functionis magni momenti est. Exempli gratia, sume functionem. Ea differentiam inter duos numeros invenit:

```raku
sub diff($a, $b) { $a - $b }
```

Certe `diff(10, 20)` et `diff(20, 10)` diversos eventus dant.

In functione supra parametri sunt index cum commatibus. Tales parametros _positionales_ vocamus. In vocatione ordo argumentorum magni momenti est. Is sensum cuiusque parametri statuit.
