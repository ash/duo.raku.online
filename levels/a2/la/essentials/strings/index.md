Nunc de chordis loquamur. Programmata nostra iam chordas habebant. Hae chordae etiam chordae litterales vocantur. Chorda litteralis est textus in quotationibus:

```raku
say 'Ego sum chorda litteralis';
```

Scilicet, variabilis scalaris etiam chordam tenere potest:

```raku
my $nuntius = 'Hoc est meum nuntius';
```

Nunc plura elementa de chordis discamus.
