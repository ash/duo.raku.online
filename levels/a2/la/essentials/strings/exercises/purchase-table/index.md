## Problema

Scribe programma. Id tabulam pretiorum hac forma imprimit. Quaeso, pretia et summas in variabilibus tene.

    Item    Pretium  N      Summa
    Sellae  $20.57   4      $82.28
    Mensae  $50.18   1      $50.18

Fortasse haec moneta tibi non placet. Tum quamlibet aliam adhibere potes. Sed noli oblivisci: `$` [significationem specialem habet](/la/essentials/strings/escaping-special-characters) in stringis Raku. Ideo eam elegimus. Sic Raku melius discis.

## Exemplum

Hoc programma nullum input requirit. Id curris, et tabulam supra imprimit.

```console
$ raku purchase-table.raku
```
