## Problema

Programma numerum directe in codice habet. Imprime eius partem fractionalem. Hic est initium programmatis:

```raku
my $n = 15.8972;
# ... Tua codex hic
```

## Exemplum

Programma partem post punctum decimale imprimere debet:

```console
$ raku fractional-part.raku
0.8972
```
