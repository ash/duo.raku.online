Extensio fasciculi est ultima pars nominis fasciculi. Hic sunt extensiones [commendatae](https://github.com/Raku/problem-solving/blob/master/solutions/language/Path-to-Raku.md#extensions) pro fasciculis Raku:

* `.raku` pro fasciculis programmatis
* `.rakumod` pro modulorum
* `.rakutest` et `.t` pro probationibus
* `.rakudoc` pro documentis in forma POD6
