Facile est valorem π imprimere.

## Codex

```raku
say π;
```

🦋 Totum codicem invenire potes in archivo [pi.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/numbers/pi.raku).

## Exitus

Programma exsequere et vide quid imprimat:

```console
$ raku exercises/numbers/pi.raku
3.141592653589793
```

## Commentarii

Raku constantem in structura `π` habet. Itaque programma simplicissimum est. Sed idem aliis modis facere potes:

```raku
    π.say;
```

Vel:

```raku
    pi.say;
```

Vel:

```raku
    say pi;
```
