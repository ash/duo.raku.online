## Problema

Scribe programma. Duos numeros integros ex linea mandati accipit. Deinde summam eorum imprimit. Utere functione `MAIN`. Parametri eius typos habere debent.

## Exemplum

Ecce exemplum:

```console
$ raku print-the-sum.raku 500 700
1200
```
