## Problema

Haec tabula data unius operarii habet:

```raku
my %employee =
    full-name => 'Eliza Vents',
    department => 'Sales',
    salary => 3000;
```

Auge salarium per 5&thinsp;%. Imprime novum salarium et nomen operarii. Post mutationem, tabula `%employee` rectos valores habere debet.

## Exemplum

Programma hoc imprimere debet:

```console
$ raku salary-raise.raku
New salary of Eliza Vents: 3150
```
