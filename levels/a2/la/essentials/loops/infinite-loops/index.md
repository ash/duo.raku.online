Potes etiam `loop` cum solo corpore scribere:

```raku
loop {
    say 'Aeternitas';
}
```

Hic circulus numquam per se desinit. Tu programma sistere debes, exempli gratia, per `Ctrl+C`. Secunda pars cursus meliores modos ostendit ad circulos regendos.
