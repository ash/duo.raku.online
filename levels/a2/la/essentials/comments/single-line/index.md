---

{% include menu.html %}

Simplicissimus commentarius est commentarius unius lineae. Incipit a charactere `#`. Usque ad finem lineae pergit.

```raku
my $name; # Haec variabilis ad nomen usoris servandum adhibetur
$name = prompt 'Quod est nomen tuum? ';
say $name; # Nunc nomen videmus
```

Shebang est prima linea, ut `#!/usr/bin/env raku`. Pro Raku, id etiam commentarius est. Sed testudo id legere et exsequi potest.
