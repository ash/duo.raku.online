Commentarios incorporatos etiam commentarios in linea vocamus. Similes sunt commentariis multi-lineae. Una sola differentia est. Eos inter alias partes programmatis ponis. Exempli gratia:

```raku
my $name;
$name = #`[User input expected here] prompt 'Quod est nomen tuum? ';
say $name;
```

Bonus syntax highlighter codicem coloribus ostendit. Hoc multum adiuvat ad commentarios videndos.
