Claustrum codicis est pars programmatis tui. Intra par uncinorum curvorum est: `{` et `}`. Claustrum plures enuntiationes habet. Simul operantur, quasi una magna enuntiatio. Sectiones sequentes multos usus claustrorum ostendunt.

```raku
{
    say 'Salve, Munde!';
}
```

Hoc programma claustrum codicis non vere requirit. Sed claustra codicis in aliis casibus valde utilia sunt. Eos casus mox videmus.

Sed primum notionem _ambitus_ spectemus. Ambitus ostendit ubi variabilem adhibere potes.
