REPL est nomen breve pro _Read–eval–print loop_. Est modus testudinis in-aedificatus. Instructiones scribis. Post quamque, eventum in scrinio vides. Statum variabilium vides. Etiam output programmatis tui vides.

Hoc scribe ad testudinem Rakudo incipiendam:

```console
$ raku
Welcome to 𝐑𝐚𝐤𝐮𝐝𝐨™ v2020.10.
Implementing the 𝐑𝐚𝐤𝐮™ programming language v6.d.
Built on MoarVM version 2020.10.

You may want to `zef install Readline` or `zef install Linenoise` or use rlwrap for a line editor

To exit type 'exit' or '^D'
> 
```

Output ex versione compilatoris tui pendet. In output supra testudo installationem aliquorum modulorum suadet. Cum eis testudo commodior est. Ideo hunc nuntium vides.

In fine characterem promptum `>` vides. Hic programma tuum vel partes eius scribis. Testudo codicem tuum lineam per lineam compilat. Hoc facit cum Enter premis.

    > dic 'Salve, Munde';
    Salve, Munde
    >
