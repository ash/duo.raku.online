---
title: Currendo ex linea mandati
---

{% include menu.html %}

Serva programma in fasciculo textuali, exempli gratia, `hello.raku`. Deinde viam fasciculi instrumento lineae mandati `raku` da. Hic character dollari est promptus testae:

```console
$ raku hello.raku
```

Si programma errores non habet, statim currit. Si aliquid imprimit, eventum in terminali vides:

```console
$ raku hello.raku 
Hello, World!
```

In systematibus Unix-fundatis shebang addere potes. Haec est prima linea specialis. Etiam fasciculum exsecutabilem facere potes:

```raku
#!/usr/bin/env raku

say 'Hello, World!';
```

Hic sunt gradus proximi:

```console
$ chmod a+x hello.raku
$ ./hello.raku
Hello, World!
```
