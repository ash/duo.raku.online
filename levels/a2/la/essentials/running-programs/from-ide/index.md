Haec sectio brevissima est. Ostendit quomodo programma curras sine IDE relinquendo. Duo [IDEs](../../editors-and-ides) maxime commendata spectamus.

## Visual Studio Code Editor

Aperi terminalem ex menu: `Terminal` → `New Terminal`. Novum panel infra textum programmatis tui apparet. Ibi programma curre, sicut ex linea mandati:

```console
$ raku hello.raku
```

## Comma IDE

Ad programma currendum, `Run` in menu elige. Ante primum cursum IDE institue. Sequere [instructiones](https://commaide.com/docs/running) in situ Comma.
