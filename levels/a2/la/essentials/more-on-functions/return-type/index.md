title: Redonare typus
---

{% include menu.html %}

Etiam typum pro eventu functionis statuere potes. Hoc in codice paucis modis scribere potes.

```raku
sub add(Int $x, Int $y) returns Int { $x + $y }

my Int sub add(Int $x, Int $y) { $x + $y }

sub add(Int $x, Int $y) of Int { $x + $y }

sub add(Int $x, Int $y --> Int) { $x + $y }
```

Elige modum qui tibi maxime placet. Specta quartum exemplum. Ibi typus eventus intra parentheses est. Parametri functionis quoque ibi sunt.
