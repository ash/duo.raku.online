In [sectione de receptaculis](/la/advanced/containers) `.^name` adhibuisti. Cum eo valorem de genere suo interrogavisti. Eaedem metavocationes `.^` etiam cum classibus et obiectis operantur. Cum eis nomina et attributa eorum videre potes. Etiam locum eorum in arbore classium videre potes.

Metamethodus est methodus quam per `.^` vocas. Metamethodus `.^name` nomen classis reddit:

```raku
class Dog {
    has Str $.name;
    method bark { 'Woof' }
}

say Dog.^name; # Dog
```

Metamethodus `.^attributes` attributa classis enumerat. Pro quoque attributo genus eius vides. Etiam nomen eius privatum internum vides. Haec est forma `$!`. Eam apud [attributa privata](/la/oop/methods/private-attributes) vidisti:

```raku
say Dog.^attributes; # (Str $!name)
```

Introspectio hoc significat: obiectum de se ipso interrogas. Utilis est instrumentis quae cum quolibet genere obiecti operantur. Exempli gratia, instrumentum omne attributum obiecti imprimere potest. Classem obiecti prius scire non debet. Argumentum sequens de catena hereditatis classis est. Haec est linea classium parentum eius.
