## Problema

Programma cum valore laborat. Valor negativus est. Si valor infra nihil est, monitum ad errorem vulgarem mitte. Ad hoc `note` adhibe. Deinde verum effectum per `say` ad exitum vulgarem mitte. Effectus est valor absolutus numeri. Hic est numerus sine signo minus. Utere valore `-3`.

## Exemplum

Utramque lineam in screen vides:

```
Warning: the value is negative
3
```

Hic errorem vulgarem abicimus. Solus effectus manet:

```
$ raku note-a-warning.raku 2>/dev/null
3
```
