## Problema

Programma seriem numerorum `3, 5, 7` in anulo addit. In quoque gyro summam huc usque ad errorem vulgarem mitte. Haec summa est summa currens. Est nuntius de progressu. Post anulum effectum finalem ad exitum vulgarem mitte. Tractabulis fluentorum directe utere.

Cur hoc magni momenti est? Effectum servare aut ad aliud programma mittere potes. Nuntii progressus in errore vulgari manent. Ibi non obstant.

## Exemplum

Programma curre. Utrumque fluentum in screen vides. Primum veniunt summae currentes, deinde effectus finalis:

```
running total: 3
running total: 8
running total: 15
15
```

Sed nunc errorem vulgarem abicimus. Solus verus effectus manet:

```
$ raku output-and-error.raku 2>/dev/null
15
```
