## Problema

Fac classem `Robot`. Attributum `position` habet, quod mutare potes. Valor eius praedefinitus est `0`. Classis etiam methodum `move` habet. Haec methodus positionem aliquot gradibus promovet. Numerus graduum praedefinitus est `1`. Itaque `move` sine argumento robotum uno gradu movet.

Fac robotum. Move id `5` gradibus. Deinde `move` sine argumento voca. Deinde id `2` gradibus amplius move. Ultimam positionem eius imprime.

## Exemplum

Programma imprimit:

```
8
```
