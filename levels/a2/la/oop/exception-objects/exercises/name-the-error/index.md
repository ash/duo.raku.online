## Problema

Scribe subprogramma `risky`. Agit `die 'sub failed'`. Deinde voca `risky` intra clausulam cum fasi `CATCH`. Primum `CATCH` nomen generis exceptionis imprimit, per `.^name`. Deinde nuntium eius imprimit, per `.message`. Hoc unam rem aliam de `CATCH` ostendit. Etiam exceptiones tractat ex codice quem clausula *vocat*. Non necesse est `die` in ipsa clausula esse.

## Exemplum

Programma imprimit:

```
X::AdHoc
sub failed
```
