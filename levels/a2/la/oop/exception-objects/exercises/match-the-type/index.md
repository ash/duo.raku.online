## Problema

Quisque error inbuiltus suum genus exceptionis habet. Haec genera comparare potes. Scribe clausulam quae `1 / 0` computat. Deinde clausula effectu uti conatur. Hoc `X::Numeric::DivideByZero` iacit. Adde clausulae fasim `CATCH`. In ea utere `when X::Numeric::DivideByZero`. Hoc exacte huic generi convenit. Deinde imprime `cannot divide by zero`.

## Exemplum

Programma imprimit:

```
cannot divide by zero
```
