## Problema

Scribe clausulam cum `die 'timeout'` intus. Adde clausulae fasim `CATCH`. Ea exceptionem capit et nuntium eius imprimit. Pone `Error: ` ante nuntium.

## Exemplum

Programma imprimit:

```
Error: timeout
```
