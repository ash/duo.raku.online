## Problema

Fac classem exceptionis propriae `Negative`. Haec est classis pro erroribus tuis. Ab `Exception` heredat. Attributum `n` habet. Methodus eius `message` reddit `<n> is negative`.

Scribe subprogramma `check($n)`. Si argumentum eius infra nihil est, `Negative` iacit. Haec `Negative` illud `n` tenet. Aliter subprogramma argumentum reddit. Deinde `check(-5)` intra clausulam voca. Adde fasim `CATCH` cum `when Negative`. Ea nuntium exceptionis imprimit.

In fine, post clausulam, unam aliam `Negative` iace. Eius `n` est `-10`. Ibi nulla `CATCH` eam capit. Hoc ostendit quid tum fiat. Exceptio programma finit.

## Exemplum

Programma imprimit:

```
-5 is negative
-10 is negative
  in block <unit> at negative-error.raku line 24
```
