## Problema

Tractabulum archivi valor ordinarius est. Itaque id functioni tradere potes, sicut quodlibet aliud argumentum. Scribe subprogramma `log-line`. Tractabulum et nuntium accipit. Nuntium in tractabulum scribit, in sua linea.

Aperi `log.txt` ad scribendum. Voca `log-line` ter. Per id `started`, `working` et `done` scribe. Deinde tractabulum claude. Archivum lege et contentum eius imprime.

## Exemplum

Programma imprimit:

```
started
working
done
```
