## Problema

Aperi archivum nomine `out.txt` ad scribendum. Tractabulum apertum serva. Numeros `1`, `2` et `3` in id anulo scribe. Quisque numerus in sua linea esse debet. Deinde tractabulum claude. Archivum lege et contentum eius imprime.

## Exemplum

Programma imprimit:

```
1
2
3
```
