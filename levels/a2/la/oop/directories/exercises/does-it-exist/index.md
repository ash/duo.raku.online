## Problema

Noli adhuc quidquam creare. Primum imprime an archivum `test.txt` exsistat. Deinde archivum crea. Iterum imprime an nunc exsistat. Eadem semita primum `False` dare debet, et postea `True`.

## Exemplum

Programma imprimit:

```
False
True
```
