## Problema

Fac classem `Counter` cum uno attributo, `count`. Hoc attributum mutare potes (`is rw`). Valor eius praedefinitus est `0`.

Fac numeratorem. Primum eius `count` imprime. Hoc ostendit eum a valore praedefinito incipere. Deinde in anulo quinquies unum ei adde. Valorem ultimum imprime.

## Exemplum

Programma imprimit:

```
0
5
```
