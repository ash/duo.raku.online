Quae variabilis variabiles ambitus programmatis continet?

{:.quiz}
0 | `@*ARGS`
1 | `%*ENV`
0 | `$*ENV`
0 | `%ENV`

{% include quiz.html %}

<div class="extended-explanation">

`%*ENV` est mappa dynamica cum variabilibus ambitus. Variabilem per nomen eius legis, ut `%*ENV<HOME>`. `@*ARGS` alia res est. Argumenta lineae imperandi continet. Sunt valores post nomen programmatis in imperato.
