## Problema

Curre imperatum quod consulto deficit. Exempli gratia, utere `sh -c 'exit 4'`. Serva `Proc` quod reddit. Imprime codicem exeundi imperati. Codex exeundi est numerus. Imperatum eum reddit cum finit. Deinde imprime `success` si imperatum operatum est. Imprime `failure` si non operatum est.

## Exemplum

Programma imprimit:

```
4
failure
```
