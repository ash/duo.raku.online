## Problema

Utere `run` cum `:out`. Incipe `echo` cum tribus verbis `hello world raku`. Exitum eius in variabili cape. Noli exitum tantum imprimere. Potius verba in eo numera. Deinde hunc numerum imprime.

## Exemplum

Programma imprimit:

```
3
```
