## Problema

Ostende utramque partem `try`. Clausula `try` errores in codice suo capit. Primum computationem in clausulam `try` pone. Computatio bene operari debet, exempli gratia `6 * 7`. Effectum eius imprime. Deinde codicem cum `die 'broken'` in alteram clausulam `try` pone. Imprime an haec clausula effectum definitum dederit. Etiam nuntium exceptionis captae imprime.

## Exemplum

Programma imprimit:

```
42
False
broken
```
