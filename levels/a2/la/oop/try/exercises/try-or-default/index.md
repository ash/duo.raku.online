## Problema

Cum clausula `try` deficit, valor eius indefinitus est. Hoc cum operatore defined-or `//` adhibe. Per `//` valorem subsidiarium pro hoc casu dare potes. Curre clausulam `try` cum `die 'no'` intus. Si clausula deficit, chordam `default` loco eius adhibe. Effectum imprime.

## Exemplum

Programma imprimit:

```
default
```
