Hoc modo exercitationem solvere potes.

## Codex

```raku
my $r = try { die 'no' } // 'default';

say $r;
```

🦋 Inveni codicem fontem in archivo [try-or-default.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/try/try-or-default.raku).

## Exitus

```
default
```

## Commentarii

1. Clausula `try` deficit. Itaque valor eius indefinitus est.

1. Itaque operator defined-or `//` partem suam dexteram reddit. Haec est `'default'`. Hoc modo post defectum munde pergere potes. Solum unam lineam et valorem subsidiarium requiris.
