## Problema

Scribe anulum per tria elementa: `ok`, `bad` et `ok`. Pro quoque elemento clausulam curre. Clausula `processed <elementum>` imprimit. Sed pro elemento `bad` agit `die 'boom'`. Pone fasim `CATCH` intra clausulam. Ea errorem capit. Pro elemento deficiente `skipped (<elementum>): <nuntius>` imprimit. Deinde anulus ad elementum sequens pergit. Non sistit.

## Exemplum

Programma imprimit:

```
processed ok
skipped (bad): boom
processed ok
```
