## Problema

Ostende quomodo programma per `CATCH` post errorem recuperet. Programma non sistit. Cum valore praedefinito tuto pergit.

Ante clausulam variabilem `$timeout` fac. Ei valorem praedefinitum `30` da. Intra clausulam age `die 'config missing'`. In linea sequenti conare `$timeout` ad `60` ponere. Programma numquam ad hanc lineam pervenit. Adde fasim `CATCH` cum clausula `default`. Ea `warning: <nuntius>; keeping default` imprimit. Post clausulam imprime `timeout is <timeout> seconds`.

## Exemplum

Programma imprimit:

```
warning: config missing; keeping default
timeout is 30 seconds
```
