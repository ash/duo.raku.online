## Problema

Scribe subprogramma `lookup`. Si argumentum eius est `'a'`, `100` reddit. Aliter `fail` cum nuntio `no such key` vocat.

Voca `lookup('z')`. Si effectus definitus est, eum imprime. Si non, imprime `not found`. Deinde alteram lineam cum causa defectus imprime. Causam ex ipso `Failure` sume. Linea sic apparet: `reason: <nuntius>`.

## Exemplum

Programma imprimit:

```
not found
reason: no such key
```
