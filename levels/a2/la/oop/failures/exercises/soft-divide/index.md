## Problema

Scribe subprogramma `reciprocal`. Reddit `1` per argumentum suum divisum. Sed si argumentum est `0`, `fail` adhibet. Nuntius est `no reciprocal of zero`.

Imprime effectum `reciprocal(4)`. Deinde imprime effectum `reciprocal(0)`. Hic noli ipse `.defined` inspicere. Loco eius operatore `//` utere. Si vocatio deficit, `//` chordam `undefined` dat.

## Exemplum

Programma imprimit:

```
0.25
undefined
```
