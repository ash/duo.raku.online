## Problema

Scribe subprogramma `get`. Argumentum suum reddit. Sed si argumentum est `0`, `fail` vocat. Nuntius est `bad`.

Imprime effectum `get(5)`. Deinde imprime effectum `get(0)`. Utere operatore defined-or `//` cum valore subsidiario `default`. Operator `//` hunc valorem dat cum effectus indefinitus est.

## Exemplum

Programma imprimit:

```
5
default
```
