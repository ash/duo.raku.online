## Problema

Fac duas classes vacuas, `Cat` et `Dog`. Deinde fac exemplar `Cat` nomine `$felix`. Imprime genus `$felix` per `WHAT`. Deinde duas lineas amplius imprime. In eis operatore `===` utere. Prima linea ostendit an genus idem sit ac `Cat`. Secunda linea ostendit an idem sit ac `Dog`.

## Exemplum

Programma imprimit:

```
(Cat)
True
False
```
