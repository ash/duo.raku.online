## Problema

Fac duas classes vacuas, `Cat` et `Dog`. Deinde scribe anulum super quattuor valores: `Cat`, `Dog`, `Cat.new` et `Dog.new`. Pro quoque valore imprime utrum definitus sit. Specta effectum. Duo obiecta generis indefinita sunt. Duo exemplaria definita sunt. Classis hic nihil refert.

## Exemplum

Programma imprimit:

```
False
False
True
True
```
