## Problema

`do` etiam ante sententias fluxus controllandi operatur. Eas expressiones cum valore facit. Cum `do if 7 > 5 { 'big' } else { 'small' }` etiketam elige. Etiketam ad `$label` assigna et eam imprime.

## Exemplum

Programma imprimit:

```
big
```
