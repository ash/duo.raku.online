## Problema

Praefixum `eager` contrarium `lazy` facit. Raku cogit totum indicem statim producere. Tum index non iam piger est. Differentiam cum `.is-lazy` ostende.

Primum imprime num intervallum infinitum `1 .. Inf` pigrum sit. Deinde imprime num `eager 1..3` pigrum sit. Postremo imprime num `lazy 1..3` pigrum sit. Resultata debent esse `True`, `False`, `True`.

## Exemplum

Programma imprimit:

```
True
False
True
```
