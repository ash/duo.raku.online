## Problema

Ecce tabula: `a => 1, b => 2, c => 3`. Dele introitum `b` cum adverbio subscripti. Deinde imprime numerum introituum qui in tabula manent. Hoc ostendit: unus introitus abest.

## Exemplum

Programma imprimit:

```
2
```
