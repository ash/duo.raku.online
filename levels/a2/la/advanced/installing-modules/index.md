Modulos tuos ipse scribere potes. Sed communitas Raku etiam multos modulos edit. Moduli sunt pro multis rebus, a compagibus interretialibus usque ad formas datorum. Eos installare et in programmatis tuis adhibere potes.

## Installare per `zef`

Modulos per `zef` installas. `zef` est moderator modulorum normatus. Una cum Rakudo venit. Ut modulum installes, nomen moduli `zef` da:

```console
$ zef install JSON::Fast
```

`zef` modulum deponit. Etiam omnia deponit quae modulus requirit. Deinde probationes moduli exsequitur. Tum modulum installat. Postea modulus automatice in via inquisitionis est. Itaque programma eum solo `use` onerare potest. Optionem `-I` non requiris:

```raku
use JSON::Fast;
```

Etiam in oecosystemate quaerere potes. Oecosystema omnes modulos continet quos homines edunt. Et modulos renovare vel removere potes:

```console
$ zef search Test
$ zef uninstall JSON::Fast
```

## Unde moduli proveniant

Moduli editi in _oecosystemate_ Raku sunt. Id in situ interretiali [raku.land](https://raku.land) inspicere potes. Situs distributiones paratas enumerat. Distributio unum vel plures modulos continet. Situs etiam documentationem earum ostendit.

## `META6.json`

Distributio ad communicandum fasciculum cum descriptione habet. Nomen fasciculi est `META6.json`. Nomen et versionem distributionis continet. Modulos distributionis enumerat. Etiam alias distributiones enumerat quas requirit. `zef` hunc fasciculum legit. Itaque scit quid installare debeat. Etiam scit quomodo partes inter se conveniant. Fortasse modulum tuum edere vis. Tum ei rectum `META6.json` da. Hoc fasciculo omnes alii modulum tuum installare possunt.
