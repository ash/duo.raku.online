## Problema

Operator `**` fortior est quam `+`. Ergo Raku `2 ** 3 + 1` legit ut `(2 ** 3) + 1`. Hoc est `9`. Adde parentheses et hunc ordinem muta. Additio *primum* fieri debet. Eventum imprime.

## Exemplum

Programma imprimit:

```
16
```
