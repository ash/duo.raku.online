## Problema

Ecce index numerorum. Aliqui ex eis iterum apparent:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Imprime quot valores _distinctos_ habeat. Valores distincti omnes inter se differunt. Coniunctum adhibe.

## Exemplum

Programma imprimit:

```
7
```
