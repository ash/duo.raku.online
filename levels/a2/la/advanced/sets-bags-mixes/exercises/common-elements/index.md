## Problema

Ecce duo coniuncta cum nominibus fructuum:

```raku
my $a = set(<apple banana cherry>);
my $b = set(<banana cherry date>);
```

Intersectionem eorum inveni. Intersectio valores habet qui in utroque coniuncto sunt. Eam in variabili serva. Deinde duas lineas imprime. Prima linea est numerus valorum communium. Secunda linea ostendit num `apple` unus ex eis sit. Unus ex eis esse non debet.

## Exemplum

Programma imprimit:

```
2
False
```
