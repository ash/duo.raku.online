## Problema

Symbolum operatoris quilibet character esse potest. Etiam character Unicode esse potest. Defini operatorem **postfixum** `²`. Quadratum operandi sui reddit. Ergo `5²` significat `5 ** 2`. Deinde imprime `5²`.

## Exemplum

Programma imprimit:

```
25
```
