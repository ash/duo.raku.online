Functio in modulo `Test` transit cum condicio vera est. Condicio est `True` aut `False`. Quae functio est?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` condicionem accipit. Transit cum condicio vera est. `is` valorem quem accipis cum valore quem exspectas comparat. `plan` dicit numerum probationum quas exspectas. `done-testing` archivum finit et consilium imprimit.

</div>
