Unum archivum probationum solum programma Raku est. Itaque id sicut quodvis programma currere potes:

```
raku t/01-basic.rakutest
```

Exitum suum TAP in screen imprimit. Sed fortasse plura quam unum aut duo archiva habes. Tum _cursorem probationum_ requiris. Omnes probationes in directorio currit. Deinde brevem summam effectuum dat. Cursor probationum Raku est `prove6`:

```
prove6 t/
```

Hoc quodque archivum probationum sub `t/` currit. Ostendit quot archiva et probationes transierint. In fine unum effectum pro omnibus dat: transit aut deficit. Hoc multo facilius legis quam nudum TAP ex quoque archivo.

Fortasse distributio `META6.json` habet. Tum instrumentum modulorum probationes eius pro te currit:

```
zef test .
```

`zef test` directorium `t/` invenit. Omnes probationes currit et effectum ostendit. Idem sponte fit antequam aliquis distributionem installat. Itaque probationes duo munera habent. Eas per `prove6` curris dum in codice tuo laboras. Et oecosystema eas currit antequam quisquam distributionem installat. Hoc modo distributionem verificat.

> Archiva probationum extensionem `.rakutest` vel `.t` habent. Plerumque nomina eorum a numero incipiunt, exempli gratia `t/01-basic.rakutest`.
