## Problema

Crea modulum nomine `Maths` in archivo `Maths.rakumod`. Subprogramma `square` exportat. Subprogramma quadratum argumenti sui reddit.

Deinde programma separatum scribe. Modulo utitur et `square(6)` imprimit.

## Exemplum

Programma curre cum modulo in semita quaesitionis. Id imprimit:

```console
$ raku -I. maths.raku
36
```
