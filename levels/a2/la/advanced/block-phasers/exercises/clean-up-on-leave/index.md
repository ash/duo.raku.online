## Problema

Hoc optimum est in `LEAVE`. Currit *quocumque modo* programma copiam relinquit. Etiam post maturum `return` currit.

Scribe subroutinam `work`. Corpus eius cum phasere `LEAVE` incipit. Phaser `Cleanup` imprimit. Deinde, adhuc in subroutina, imprime `Working`. Postea statim `return` adhibe. Pone lineam `say 'never reached'` post `return`. Voca subroutinam. Maturus `return` ultimam lineam praeterit. Sed programma tamen `Cleanup` imprimit.

## Exemplum

Programma imprimit:

```
Working
Cleanup
```
