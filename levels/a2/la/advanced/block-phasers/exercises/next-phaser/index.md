## Problema

Phaser `NEXT` in *fine* cuiusque gyri ansae currit. Hoc bonum tempus est progressum ostendere.

Summam crescentem in `$sum` tene. Ab `0` incipit. Itera per `1..3`. In quoque gyro primum numerum currentem ad `$sum` adde. Cum phasere `NEXT` imprime `sum so far: $sum` post quemque gyrum.

Cave ordinem. Phaser `NEXT` post corpus currit. Itaque summa quam ostendit numerum currentem *includit*.

## Exemplum

Programma imprimit:

```
sum so far: 1
sum so far: 3
sum so far: 6
```
