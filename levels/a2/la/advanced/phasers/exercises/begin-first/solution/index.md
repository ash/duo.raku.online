Hoc modo munus solvere potes.

## Codex

```raku
my $compiled = BEGIN { 2 + 3 };

say $compiled;
```

🦋 Inveni codicem fontem in archivo [begin-first.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/phasers/begin-first.raku).

## Exitus

```
5
```

## Commentarii

1. `BEGIN { 2 + 3 }` tempore compilationis currit. `5` dat. Hic copia `BEGIN` expressio est. Ergo valorem suum reddit. Programma hunc valorem in `$compiled` ponit.

1. Computatio semel tantum fit, tempore compilationis. Cum programma currit, `$compiled` tantum valorem fixum `5` tenet. Ergo cum `BEGIN` valores mature computare potes. Non tantum ad mature imprimendum est.
