## Problema

Programma plus quam unum phaserem `END` habere potest. Tum ordine **inverso** currunt. Ultimus in codice primus currit. Homines hoc vocant “ultimus intrans, primus exiens”.

Scribe duos phaseres `END`. Primus `first END` imprimit. Secundus `second END` imprimit. Post eos simplicem `say 'body'` scribe. Qui est ordo output? Primum eum coniice. Deinde hoc output programmate tuo produc.

## Exemplum

Programma imprimit:

```
body
second END
first END
```
