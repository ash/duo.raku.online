`zef` modulos Raku installat. Iam eo modulos nominibus suis installavisti. Etiam cum distributione in directorio locali operatur. Intra in directorium distributionis. Inde eam directe probare et installare potes:

```
zef test .
zef install .
```

`zef test .` archiva sub `t/` exsequitur. `zef install .` distributionem in Raku tuum installat. Tum alia programmata eam per `use` adhibere possunt. Etiam nomine installare potes, exempli gratia `zef install Cro`. Hoc idem facit. Sed prius distributionem ex systemate deponit.

Fortasse distributionem tuam **publicare** vis. Tum alii eam nomine installare possunt. Ad hoc eam in systema imponis. Homines plerumque `fez` ad hoc adhibent:

```
fez upload
```

Hoc distributionem praesentem componit et in systema Raku mittit. Postea `zef install Maths::Simple` pro omnibus operatur.

> Haec mandata `zef`/`fez` installata et retia requirunt. Ad imponendum etiam rationem in systemate requiris.

Itaque modulus communicatus tres gradus habet. Primum ei dispositionem normalem et `META6.json` das. Deinde eum per `zef test` probas. Tum eum per `fez upload` publicas. Postea solum unum aliud nomen est. Quisque eum per `zef install` installare potest.
