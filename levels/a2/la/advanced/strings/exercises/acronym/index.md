## Problema

Fac acronymum ex phrasi. Acronymum ex primis litteris verborum constat. Sume primam litteram cuiusque verbi. Litteras coniunge. Eventum litteris maioribus imprime.

Hanc phrasim adhibe:

```raku
my $phrase = 'hyper text markup language';
```

## Exemplum

Hoc programma imprimit:

