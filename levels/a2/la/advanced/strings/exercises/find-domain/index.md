## Problema

`index` tibi dicit *ubi* character sit. Deinde chordam eo loco cum `substr` secare potes. Eas simul adhibe.

Sume inscriptionem electronicam `user@example.com`. Inveni positionem signi `@`. Deinde omnia post id imprime. Haec est pars dominii.

## Exemplum

Hoc programma imprimit:

```
example.com
```
