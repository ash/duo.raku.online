## Problema

Hic est ordo:

```raku
my @original = 10, 20, 30;
```

Fac secundum nomen, `@alias`, pro _eodem_ ordine. Noli ordinem copiare. Hac vice novum elementum ad `@original` cum `push` adde. Deinde `@alias` imprime. Hoc ostendit: alias plus quam novos valores videt. Etiam mutationes structurae ordinis videt.

## Exemplum

Programma imprimit:

```
[10 20 30 40]
```
