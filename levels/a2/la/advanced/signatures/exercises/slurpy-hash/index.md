## Problema

Scribe subprogramma `describe`. Primus parametrus eius est nomen. Hoc nomen positionale et necessarium est. Post id, mappa sorbens `*%opts` quotlibet argumenta nominata colligit. Subprogramma chordam talem reddit: `nomen: clavis=valor, clavis=valor, ...`. Chorda omnem optionem enumerat. Claves ordine alphabetico sunt.

Id sic voca: `describe('Anna', colour => 'red', size => 5)`. Effectum imprime.

## Exemplum

Programma imprimit:

```
Anna: colour=red, size=5
```
