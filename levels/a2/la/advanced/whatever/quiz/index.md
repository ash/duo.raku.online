Quid hoc programma imprimit?

```raku
my @a = 5, 6, 7, 8, 9;
say @a[*-2];
```

{:.quiz}
1 | 8
0 | 7
0 | 9
0 | 3

{% include quiz.html %}

<div class="extended-explanation">

In indice stella sola est numerus elementorum. Hic est `5`. Itaque `*-2` est index `3`. A zero numeramus. Elementum ad indicem `3` est `8`.

</div>
