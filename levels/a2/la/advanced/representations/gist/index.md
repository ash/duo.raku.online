{% include menu.html %}

Methodus `.gist` formam valoris **homini amicam** reddit. Haec est forma quam *legere* vis. `say` hanc ipsam formam imprimit. `note` quoque eam imprimit. Methodum `.gist` in quoque argumento vocant.

```raku
say 42.gist;     # 42
say 'Raku'.gist; # Raku
```

Pro valoribus simplicibus gist est solum valor ipse. Quaedam data plures partes habent. Pro talibus datis `.gist` paulum formationis addit. Tum structuram adhuc facile legere potes:

```raku
my @a = 'alpha', 'beta', 'gamma';
say @a.gist; # [alpha beta gamma]
```

Obiectum typi est valor. Typum ipsum significat. Gist eius est nomen typi in parenthesibus. Itaque id facile in output vides:

```raku
say Int.gist; # (Int)
```
