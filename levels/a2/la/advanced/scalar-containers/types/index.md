Nunc programma spectamus. Eandem variabilem pro diversis generibus datorum adhibet. Per `dd` data in quoque gradu videmus. Hoc exemplum solum rem ostendit. Sic programmata scribere bonum non est.

```raku
my $value;
dd $value;

$value = 42;
dd $value;

$value = 'forty-two';
dd $value;
```

Quaeque vocatio `dd` valorem praesentem `$value` ostendit:

```
$value = Any
$value = 42
$value = "forty-two"
```

Initio variabilis vacua est. `dd` valorem eius ut `Any` ostendit. Hic est valor indefinitus basalis. Quisque continens sine typo cum eo incipit. Post assignationes `dd` numerum integrum ostendit. Deinde seriem ostendit.

Nota: `dd` hic typum ante nomen non imprimit. Continens sine typo typum fixum non habet. Itaque `dd` solum valorem ostendit. [Continens cum typo declarato](/la/advanced/scalar-containers/type-constraints) aliter operatur. Hoc in themate sequenti videbis.
