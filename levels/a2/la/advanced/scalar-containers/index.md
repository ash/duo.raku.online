title: Scalaria receptacula
---

{% include menu.html %}

Continentes scalares valores singulos, vel scalares, servant. Nomen hoc tibi dicit. Tales continentes sigillum `$` habent.

Hic est usus scalaris valde simplex:

```raku
my $lang = 'Raku';
```

Variabilis `$lang` est continens scalaris.

Per defectum continens scalaris typum datorum non limitat. Itaque valorem cuiuslibet typi in eo servare potes. Hic est exemplum simplicissimum. Primum variabilis numerum integrum servat. Deinde eadem variabilis seriem servat:

```raku
my $value = 42;
$value = 'forty-two';
```

Auctor non commendat codicem sic scribere.

Intra Raku hoc unam rem significat. Per defectum novus continens valores typi `Any` servare potest. `Any` est typus basalis pro plerisque aliis typis. Exempli gratia, `Int` et `Str` ex `Any` veniunt.
