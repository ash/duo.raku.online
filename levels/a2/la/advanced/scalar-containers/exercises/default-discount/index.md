## Problema

Declara variabilem scalarem `$discount`. Valor defectus eius `0` esse debet. Imprime variabilem antequam quicquam ei assignas. Programma `0` imprimere debet. Nullum monitum imprimere debet.

Deinde `15` variabili assigna. Eam iterum imprime.

## Exemplum

Programma duas lineas imprimit:

```
0
15
```
