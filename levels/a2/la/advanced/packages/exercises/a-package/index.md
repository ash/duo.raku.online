## Problema

Crea fasciculum `Temperature`. Duas res continet. Prima est variabilis `our` nomine `$freezing` cum valore `0`. Secunda est subroutina `our` nomine `fahrenheit`. Valorem Celsius in Fahrenheit mutat. Ad hoc multiplica per 9/5 et adde 32. Extra fasciculum, punctum congelationis imprime. Deinde `100` gradus Celsius in Fahrenheit imprime.

## Exemplum

Programma imprimit:

```
0
212
```
