## Problema

Solum `our` nomen extra fasciculum suum visibile facit. `my` nomen privatum servat. Crea fasciculum `Config`. Variabilem `our` nomine `$port` cum valore `8080` habet. Habet **etiam** variabilem `my` nomine `$secret` cum valore `42`. Extra fasciculum, `$Config::port` imprime. Deinde imprime num `$Config::secret` definita sit. Definita esse non debet. Variabilis `my` non est pars spatii nominum.

## Exemplum

Programma imprimit:

```
8080
False
```
