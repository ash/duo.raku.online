## Problema

Typi nativi magnitudinis fixae boni sunt pro indicibus bytorum. Tales indices parum memoriae adhibent. Fac indicem `uint8` cum valoribus `100`, `200`, et `255`. Quisque valor in uno byte locum habet. Summam elementorum imprime.

Elementa intra ambitum `0..255` manent. Sed summa eorum maior esse potest. `.sum` reddit `Int` ordinarium.

## Exemplum

Hoc programma imprimit:

```
555
```
