## Problema

Variabilis nativa numquam indefinita est. Haec regula pro omnibus typis nativis valet, non solum pro `int`. Declara nativum `num` et nativum `str`. Eis nullos valores da. Numerum imprime. Deinde chordam intra parentheses quadratas imprime. Sic chordam vacuam vides.

## Exemplum

Hoc programma imprimit:

```
0
[]
```
