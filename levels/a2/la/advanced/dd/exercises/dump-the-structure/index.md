## Problema

Hic est structura datorum inserta. Data intra alia data habet:

```raku
my @data = 'Raku', [1, 2, 3], (key => 'value');
```

Duo cum ea fac:

1. `@data` cum `dd` exscribe, in forma pro programmatoribus.
2. Eandem formam ut seriem imprime. Textum `Structure: ` ante eam pone.

## Exemplum

Programma duas lineas imprimit. Valde similes sunt:

```
["Raku", [1, 2, 3], :key("value")]
Structure: ["Raku", [1, 2, 3], :key("value")]
```
