## Problema

URL in partes divisa est. Partes in ordine sunt. Partes iterum in unum filum coniunge. Ad hoc meta-operatore reductionis utere. URL imprime. In proxima linea longitudinem eius in characteribus imprime.

## Exemplum

Hic est ordo introitus:

```raku
my @parts = <http :// example .com>;
```

Programma imprimit:

```
http://example.com
18
```
