## Problema

Ecce modulus in archivo `Circle.rakumod`. Duas variabiles `our` habet:

```raku
unit module Circle;

our $pi = 3.14;
our $tau = 6.28;
```

Programma scribe. Id modulum adhibet. Primum numerum nominum in fasciculo moduli imprimit. Deinde nomina imprimit. Ordine alphabetico esse debent.

## Exemplum

```console
$ raku -I. list.raku
2
($pi $tau)
```
