## Problema

`WHAT` plus facit quam typum describere. Ipsum obiectum typi reddit. Obiecta typi cum operatore `===` comparare potes.

Declara duas variabiles. `$a` integrum `42` tenet. `$b` seriem `'x'` tenet. Pro utraque variabili `WHAT` eius inspice. Estne typus `Int`? Imprime responsum.

## Exemplum

Programma imprimit:

```
True
False
```
