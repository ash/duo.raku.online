## Problema

Receptaculum valorem praedefinitum habere potest. Eum tropo `is default` constituis. Antequam valorem assignas, variabilis hoc praedefinitum reddit. `.VAR.default` quoque id ostendit.

Declara scalarem `$count`. Praedefinitum eius debet esse `0`. Nihil ei assigna. Imprime variabilem. Deinde imprime praedefinitum receptaculi eius. Ambae lineae `0` ostendere debent.
