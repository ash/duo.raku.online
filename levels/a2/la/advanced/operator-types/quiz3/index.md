Operator `x` chordam repetit. Itaque `'ab' x 3` dat `'ababab'`. `x` inter duos operandos suos stat. Quae est categoria eius?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Sola positio interest. Operator symbolum vel verbum esse potest. `x` *inter* duos operandos stat. Itaque operator **infixus** est, sicut `+` vel `~`. Sed nomen eius littera est.

</div>
