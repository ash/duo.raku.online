## Codex

```raku
my %h = a => 1;
say %h<a>;
```

🦋 Inveni codicem fontem in archivo [subscript-a-hash.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operator-types/subscript-a-hash.raku).

## Exitus

```
1
```

## Commentarii

1. Subscriptum `< >` est operator postcircumfixus. Post terminum venit, hic post hash. Et circum clavem stat.

1. `%h<a>` valorem pro clave `a` reddit. Hic valor est `1`.
