Specta expressionem `@a[0]`. Quae est categoria subscripti `[0]`?

{:.quiz}
0 | postfix
1 | postcircumfix
0 | circumfix
0 | infix

{% include quiz.html %}

<div class="extended-explanation">

Subscriptum uncos circum contentum suum habet. *Etiam* post terminum venit, hic `@a`. Itaque operator postcircumfixus est. Postfixus normalis, ut `++`, nullos uncos circum aliquid habet. Circumfixus circum aliquid stat. Sed post terminum non venit. Exemplum est `[1, 2, 3]`. Ordinem facit.

</div>
