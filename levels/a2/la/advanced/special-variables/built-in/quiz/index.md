Quae variabilis inbuilta argumenta lineae imperandi programmatis tenet?

{:.quiz}
0 | `$*ARGS`
1 | `@*ARGS`
0 | `@*ARGV`
0 | `%*ENV`

{% include quiz.html %}

<div class="extended-explanation">

Argumenta lineae imperandi ut *series* adveniunt. Itaque variabilis sigillum `@` habet. Etiam dynamica est, itaque twigil `*` habet. Eventus est `@*ARGS`. `%*ENV` est mappa ambitus. Argumenta non tenet. `@*ARGV` est nomen in Perl. Raku eo non utitur.

</div>
