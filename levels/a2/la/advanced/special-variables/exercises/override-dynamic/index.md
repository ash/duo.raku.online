## Problema

Ostende quomodo variabilis dynamica per proceduram mediam eat. Haec procedura nihil de variabili scit.

Scribe subprogramma `log-it($msg)`. Nuntium imprimit. Ante nuntium variabilem dynamicam `$*prefix` imprimit. Scribe alterum subprogramma, `task`. Solum `log-it('working')` vocat. Ipsum `$*prefix` numquam adhibet. Deinde voca `task` bis. Utraque vice id ex clausula voca. Quaeque clausula variabili `$*prefix` alium valorem dat: primo `INFO`, deinde `DEBUG`.

## Exemplum

Programma imprimit:

```
INFO: working
DEBUG: working
```
