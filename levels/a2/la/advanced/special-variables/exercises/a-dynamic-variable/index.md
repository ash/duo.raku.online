## Problema

Variabilis dynamica twigil `*` habet. Raku eam per acervum vocationum quaerit, non per circumscriptionem lexicam. Itaque subprogramma diversos valores videre potest. Valor ab eo pendet qui subprogramma vocat. Sic clausula codicem quem vocat sub alia persona exsequi potest.

1. Declara variabilem dynamicam `$*user` cum valore `'guest'`.
2. Scribe subprogramma `whoami`. Imprimit `running as ` et deinde `$*user` praesentem, exempli gratia `running as guest`. Nullos parametros habet. `$*user` directe legere debet.
3. Voca `whoami` semel in gradu summo. `guest` ostendit.
4. Deinde fac clausulam. In ea `$*user` iterum ut `'admin'` declara. Ibi voca *idem* `whoami`. Nunc `admin` ostendit.

## Exemplum

Programma imprimit:

```
running as guest
running as admin
```
