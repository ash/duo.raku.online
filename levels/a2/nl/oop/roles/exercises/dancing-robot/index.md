## Opgave

Maak een klasse `Robot` met een methode `speak`. Deze methode geeft `beep` terug. Maak daarna een rol `Dancing`. Hij voegt een methode `dance` toe. Deze methode geeft `spinning around` terug.

Maak twee robots. Geef de rol `Dancing` aan maar één van de twee. Roep `speak` aan op beide robots en druk de resultaten af. Roep daarna `dance` aan op de robot die kan dansen. Druk ook dit resultaat af.

## Voorbeeld

Het programma drukt af:

```
beep
beep
spinning around
```
