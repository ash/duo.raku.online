## Opgave

Maak een klasse `Word` met een attribuut `text`. Geef haar een methode `reversed`. Deze methode geeft de tekst van het woord achterstevoren terug. Tip: de methode `flip` zet een string in omgekeerde volgorde.

Maak een woord met de tekst `Raku`. Druk de tekst achterstevoren af.

## Voorbeeld

Het programma drukt af:

```
ukaR
```
