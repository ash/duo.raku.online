## Opgave

Maak een klasse `Robot`. Ze heeft een attribuut `position` dat je kunt veranderen. Zijn standaardwaarde is `0`. De klasse heeft ook een methode `move`. Deze methode schuift de positie een aantal stappen op. Het standaardaantal stappen is `1`. Dus verplaatst `move` zonder argument de robot één stap.

Maak een robot. Verplaats hem `5` stappen. Roep dan `move` aan zonder argument. Verplaats hem daarna nog `2` stappen. Druk zijn laatste positie af.

## Voorbeeld

Het programma drukt af:

```
8
```
