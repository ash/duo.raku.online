## Opgave

Een bestandshandle is een gewone waarde. Dus kun je hem aan een functie meegeven, net als elk ander argument. Schrijf een subroutine `log-line`. Die neemt een handle en een melding aan. Ze schrijft de melding naar de handle, op een eigen regel.

Open `log.txt` om te schrijven. Roep `log-line` drie keer aan. Schrijf daarmee `started`, `working` en `done`. Sluit daarna de handle. Lees het bestand en druk de inhoud af.

## Voorbeeld

Het programma drukt af:

```
started
working
done
```
