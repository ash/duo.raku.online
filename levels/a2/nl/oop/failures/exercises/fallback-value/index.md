## Opgave

Schrijf een subroutine `get`. Ze geeft haar argument terug. Maar als het argument `0` is, roept ze `fail` aan. De melding is `bad`.

Druk het resultaat van `get(5)` af. Druk daarna het resultaat van `get(0)` af. Gebruik de defined-or-operator `//` met de terugvalwaarde `default`. De operator `//` geeft deze waarde als het resultaat ongedefinieerd is.

## Voorbeeld

Het programma drukt af:

```
5
default
```
