## Opgave

Schrijf een subroutine `reciprocal`. Ze geeft `1` gedeeld door haar argument terug. Maar als het argument `0` is, gebruikt ze `fail`. De melding is `no reciprocal of zero`.

Druk het resultaat van `reciprocal(4)` af. Druk daarna het resultaat van `reciprocal(0)` af. Controleer hier niet zelf `.defined`. Gebruik in plaats daarvan de operator `//`. Als de aanroep mislukt, geeft `//` de string `undefined`.

## Voorbeeld

Het programma drukt af:

```
0.25
undefined
```
