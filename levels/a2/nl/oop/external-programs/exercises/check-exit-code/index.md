## Opgave

Draai een commando dat met opzet mislukt. Gebruik bijvoorbeeld `sh -c 'exit 4'`. Bewaar de `Proc` die het teruggeeft. Druk de exitcode van het commando af. De exitcode is een getal. Een commando geeft dit getal terug als het klaar is. Druk daarna `success` af als het commando gewerkt heeft. Druk `failure` af als dat niet zo is.

## Voorbeeld

Het programma drukt af:

```
4
failure
```
