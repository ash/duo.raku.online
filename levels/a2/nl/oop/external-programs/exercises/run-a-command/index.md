## Opgave

Gebruik `run` om `echo` te starten. Geef het twee losse argumenten: `home:` en `$HOME`. Argumenten zijn waarden die je aan een programma geeft. Laat de uitvoer naar het scherm gaan. Let op: het programma drukt `$HOME` af zoals het er staat. Het drukt de thuismap **niet** af. Dat komt doordat `run` geen shell gebruikt. Alleen een shell vervangt variabelen als `$HOME` door hun waarden.

## Voorbeeld

Het programma drukt af:

```
home: $HOME
```
