Welke functie stuurt haar commando door de **shell** van het systeem? Met deze functie kun je pipes en omleiding gebruiken.

{:.quiz}
0 | `run`
1 | `shell`
0 | `exec`
0 | `system`

{% include quiz.html %}

<div class="extended-explanation">

`shell` geeft één string aan de shell. De shell begrijpt mogelijkheden als pipes. `run` start een programma direct. Die neemt losse argumenten en gebruikt geen shell. Dat is veiliger. Dus is `run` de betere standaardkeuze.

</div>
