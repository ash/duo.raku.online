## Opgave

Laat beide kanten van `try` zien. Een `try`-blok vangt fouten in zijn code. Zet eerst een berekening in een `try`-blok. De berekening moet lukken, bijvoorbeeld `6 * 7`. Druk het resultaat af. Zet daarna code met `die 'broken'` in een tweede `try`-blok. Druk af of dit blok een gedefinieerd resultaat gaf. Druk ook de melding van de gevangen exceptie af.

## Voorbeeld

Het programma drukt af:

```
42
False
broken
```
