## Opgave

Als een `try`-blok mislukt, is zijn waarde ongedefinieerd. Gebruik dit met de defined-or-operator `//`. Met `//` kun je voor dit geval een terugvalwaarde geven. Draai een `try`-blok met `die 'no'` erin. Als het blok mislukt, gebruik dan in plaats daarvan de string `default`. Druk het resultaat af.

## Voorbeeld

Het programma drukt af:

```
default
```
