## Opgave

Maak een klasse `Label` met één attribuut, `text`. Je kunt dit attribuut veranderen (`is rw`). Maak een label met de tekst `draft`. Zet dan ` (revised)` **achter** de tekst. Doe dit via de accessor. Maak het object niet opnieuw. Druk het resultaat af.

## Voorbeeld

Het programma drukt af:

```
draft (revised)
```
