## Opgave

Maak een klasse `Point` met twee attributen, `x` en `y`. Maak **twee** punten. Eén ligt op `(3, 4)`. Het andere ligt in de oorsprong, `(0, 0)`. Druk de afstand tussen de twee punten af.

## Voorbeeld

Het programma drukt af:

```
5
```
