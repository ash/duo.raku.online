## Opgave

Maak een keten van drie klassen. De eerste is `A`. Daarna erft `B` van `A`. Daarna erft `C` van `B`. Druk de method resolution order van `C` af. Druk die af als een lijst met typenamen. Raku zoekt in deze volgorde naar een methode.

## Voorbeeld

Het programma drukt af:

```
(C B A Any Mu)
```
