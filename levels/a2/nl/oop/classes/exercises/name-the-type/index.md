## Opgave

Maak twee lege klassen, `Cat` en `Dog`. Maak dan een instantie van `Cat` met de naam `$felix`. Druk het type van `$felix` af met `WHAT`. Druk daarna nog twee regels af. Gebruik daarin de operator `===`. De eerste regel toont of het type hetzelfde is als `Cat`. De tweede regel toont of het hetzelfde is als `Dog`.

## Voorbeeld

Het programma drukt af:

```
(Cat)
True
False
```
