## Opgave

Maak een klasse `Converter` met een klassemethode `km-to-miles`. Ze krijgt een aantal kilometers. Ze geeft de afstand in mijlen terug. Voor mijlen vermenigvuldig je met `0.621`.

Roep de methode aan op de klasse voor `10` kilometer. Druk het resultaat af.

## Voorbeeld

Het programma drukt af:

```
6.21
```
