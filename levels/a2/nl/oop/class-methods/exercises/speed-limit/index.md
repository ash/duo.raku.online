## Opgave

Een klassemethode kan parameters hebben, net als elke andere methode. Maak een klasse `Geometry` met een klassemethode `circle-area`. Ze krijgt een straal. Ze geeft de oppervlakte van een cirkel terug. Gebruik `π` of `pi`. Rond de oppervlakte af op een heel getal. De formule hoort bij de hele klasse. Er is hier geen los cirkelobject. Roep de methode aan op de klasse met een straal van `10`. Druk het resultaat af.

## Voorbeeld

Het programma drukt af:

```
314
```
