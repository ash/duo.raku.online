Tot nu toe hadden onze programma's tekststrings direct in de code. Nu voegen we een beetje vrijheid toe. De programma's kunnen variabelen gebruiken.

Raku heeft een paar soorten variabelen. Een variabele is een container. Hij bewaart wat gegevens, zoals een doos. We beginnen met de eenvoudigste containers. Ze bewaren maar één waarde. We noemen ze _scalars_, of scalaire variabelen. Elke variabele heeft een naam. Voor de naam staat een speciaal teken. Het laat zien wat voor container het is. Dit teken is de _sigil_. Voor scalaire containers is de sigil het dollarteken `$`.

Hier zijn twee scalaire variabelen:

```raku
$name

$age
```
