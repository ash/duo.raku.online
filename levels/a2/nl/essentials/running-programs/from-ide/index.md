Deze sectie is heel kort. Ze laat zien hoe je een programma uitvoert zonder de IDE te verlaten. We kijken naar de twee meest aanbevolen [IDE's](../../editors-and-ides).

## Visual Studio Code Editor

Open een terminal via het menu: `Terminal` → `New Terminal`. Er gaat een nieuw paneel open onder je programmatekst. Voer het programma daar uit, net als vanaf de opdrachtregel:

```console
$ raku hello.raku
```

## Comma IDE

Gebruik het menu-item `Run` om een programma uit te voeren. Stel de IDE in voordat je het programma de eerste keer uitvoert. Volg [de instructies](https://commaide.com/docs/running) op de website van Comma.
