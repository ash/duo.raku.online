## Taak

Schrijf een programma. Het drukt alle argumenten van de opdrachtregel af. Druk op elke regel één argument af.

## Voorbeeld

Het programma moet zo werken:

```console
$ raku print-command-line-arguments.raku woorden om weer te geven
woorden
om
weer
te
geven
```
