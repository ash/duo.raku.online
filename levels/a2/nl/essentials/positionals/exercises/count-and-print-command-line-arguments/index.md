## Taak

Schrijf een programma. Het leest argumenten van de commandoregel. Het aantal argumenten maakt niet uit. Het programma print elk argument op een eigen regel. De regels hebben nummers.

## Voorbeeld

Het programma moet zo werken:

```console
$ raku count-and-print-arguments.raku woorden om weer te geven
1. woorden
2. om
3. weer te geven
```
