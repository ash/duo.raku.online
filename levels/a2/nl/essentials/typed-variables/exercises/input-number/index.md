## Probleem

Schrijf een programma. Het vraagt de gebruiker om een geheel getal. Het bewaart het getal in een getypte variabele. Print dan het getal.

## Voorbeeld

Het programma werkt zo:

```console
$ raku input-number.raku
Voer een getal in: 42
42
```
