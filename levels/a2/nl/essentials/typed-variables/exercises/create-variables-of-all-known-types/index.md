## Taak

Schrijf een programma. Het maakt een paar scalaire variabelen. Het geeft ze waarden van deze typen: `Int`, `Rat`, `Num`, `Bool` en `Str`. Het programma drukt elke waarde en het type ervan af.

## Voorbeeld

Jouw uitvoer kan anders zijn. Maar deze testrun laat het idee zien:

```console
$ raku types.raku
151 (Int)
4.2 (Rat)
1e10 (Num)
True (Bool)
xyz (Str)
```
