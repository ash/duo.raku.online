Een bestandsextensie is het laatste deel van een bestandsnaam. Hier zijn de [aanbevolen](https://github.com/Raku/problem-solving/blob/master/solutions/language/Path-to-Raku.md#extensions) extensies voor Raku-bestanden:

* `.raku` voor programmabestanden
* `.rakumod` voor modules
* `.rakutest` en `.t` voor tests
* `.rakudoc` voor documentatie in het POD6-formaat
