---

{% include menu.html %}

Ingebedde opmerkingen heten ook inline opmerkingen. Ze zien eruit als meerregelige opmerkingen. Er is maar één verschil. Je zet ze tussen andere delen van het programma. Bijvoorbeeld:

```raku
my $name;
$name = #`[Gebruikersinvoer hier verwacht] prompt 'Wat is je naam? ';
say $name;
```

Een goede syntax-highlighter toont code in kleuren. Dat helpt veel om de opmerkingen te zien.
