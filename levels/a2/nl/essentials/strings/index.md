Laten we het nu over strings hebben. Onze programma's hadden al strings. Deze strings heten ook string literals. Een string literal is een stuk tekst tussen aanhalingstekens:

```raku
say 'I am a string literal';
```

Natuurlijk kan een scalaire variabele ook een string bewaren:

```raku
my $message = 'This is my message';
```
