Een codeblok is een deel van je programma. Het staat tussen een paar accolades: `{` en `}`. Een blok heeft meerdere instructies. Ze werken samen, als één grote instructie. In de volgende secties zie je veel manieren om blokken te gebruiken.

```raku
{
    say 'Hallo, Wereld!';
}
```

Dit programma heeft het codeblok eigenlijk niet nodig. Maar codeblokken zijn heel nuttig in andere gevallen. We bekijken ze heel binnenkort.

Maar eerst bekijken we het idee van _scope_. Scope gaat over waar je een variabele kunt gebruiken.
