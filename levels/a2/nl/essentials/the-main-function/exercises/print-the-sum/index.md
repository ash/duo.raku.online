## Probleem

Schrijf een programma. Het neemt twee gehele getallen van de commandoregel. Dan drukt het hun som af. Gebruik de `MAIN`-functie. De parameters moeten een type hebben.

## Voorbeeld

Hier is een voorbeeld:

```console
$ raku print-the-sum.raku 500 700
1200
```
