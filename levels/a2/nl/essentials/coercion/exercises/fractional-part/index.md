## Probleem

Een getal staat direct in het programma. Print het fractionele deel ervan. Hier is het begin van het programma:

```raku
my $n = 15.8972;
# ... Jouw code hier
```

## Voorbeeld

Het programma moet het deel na de decimale punt printen:

```console
$ raku fractional-part.raku
0.8972
```
