## Probleem

Schrijf een functie met twee argumenten, `$x` en `$y`. De functie geeft `$x` tot de macht `$y` terug. Schrijf daarna een programma. Het print de waarden van `5³`, `2¹⁰` en `(−4)⁵`.

## Voorbeeld

Voor deze waarden print het programma dit:

```
$ raku function-x-to-the-power-of-y.raku
125
1024
-1024
```
