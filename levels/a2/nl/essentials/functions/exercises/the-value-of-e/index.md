## Probleem

Schrijf een functie. De functie berekent de wiskundige constante _e_. Het resultaat is niet precies, maar het ligt er dichtbij. Gebruik deze formule:

<img src="e-formula.png" style="height: 4.5em; width: auto">

De functie moet op deze twee manieren werken:

1. Het argument geeft het aantal termen in de formule: `e-approx(10)`.
2. Zonder argument heeft de som 100 termen: `e-approx()`.

Print de resultaten voor beide gevallen.

## Voorbeeld

```console
$ raku the-value-of-e.raku
2.7182818
2.718281828459045
```
