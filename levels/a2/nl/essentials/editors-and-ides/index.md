Raku-programma's zijn platte tekst. Meestal bewaar je ze in tekstbestanden. Maar er zijn een paar uitzonderingen. Je kunt een programma bijvoorbeeld online uitvoeren. Of je voert het uit op de opdrachtregel. Je kunt ook code klaarzetten en die met `EVAL` uitvoeren. Er zijn ook nog een paar andere zeldzame gevallen.

Raku verwacht de programmatekst in UTF-8. Je kunt dus elke teksteditor gebruiken. Maar hij mag geen opmaak in het bestand opslaan. Je kunt `vim`, `nano`, `emacs` of `mcedit` gebruiken. Elk ervan is een goede keuze. Maar misschien wil je ook een paar populaire nieuwe programma's proberen.

## Externe links

Hier zijn links naar een paar populaire IDE's. Een IDE is een programma om code te schrijven en uit te voeren.

* [Visual Studio Code](https://code.visualstudio.com/) — voor Windows, Mac OS en Linux
* [Comma](https://commaide.com) — de Raku IDE, speciaal gemaakt voor programmeren in Raku. Hij werkt op Windows, Mac OS en Linux.
