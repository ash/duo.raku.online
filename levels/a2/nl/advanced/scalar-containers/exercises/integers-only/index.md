## Probleem

Declareer een container `$cars`. Die kan alleen gehele getallen bewaren.

Je hebt een waarde uit een computermodel van het verkeer: `250.7`. Zet deze in `$cars`. Zet hem eerst om naar een geheel getal. Zonder dat werkt de toewijzing niet. Druk daarna de waarde en het type af.

## Voorbeeld

Het programma drukt af:

```
250
(Int)
```
