Een _module_ is een bestand met code die je opnieuw kunt gebruiken. Hij kan subroutines, variabelen en meer bevatten. Andere programma's kunnen de module laden en delen. Dit gedeelte toont de belangrijkste dingen in drie stappen. Eerst **schrijf** je een module. Je geeft aan wat hij aan andere programma's geeft. Ten tweede **laadt** een programma de module met `use`. Ten derde brengt **importeren** de namen van de module in je bereik.
