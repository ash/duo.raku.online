## Probleem

Schrijf een programma. Het drukt het gemiddelde van een array met getallen af. Dit heet ook het rekenkundig gemiddelde. Gebruik een reductie-meta-operator om de waarden op te tellen.

De getallen staan in het programma zelf. Bijvoorbeeld:

```raku
my @data = 10, 20, 30, 40;
```

## Voorbeeld

Het programma drukt het gemiddelde van de elementen van `@data` af:

```
25
```
