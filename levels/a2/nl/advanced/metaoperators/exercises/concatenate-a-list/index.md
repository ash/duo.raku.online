## Probleem

Een URL is in stukken geknipt. De stukken staan in een array. Plak de stukken weer aan elkaar tot één tekenreeks. Gebruik daarvoor een reductie-meta-operator. Druk de URL af. Druk op de volgende regel de lengte in tekens af.

## Voorbeeld

Hier is de invoer-array:

```raku
my @parts = <http :// example .com>;
```

Het programma drukt dit af:

```
http://example.com
18
```
