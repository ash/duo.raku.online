## Opgave

Hier is een hash: `a => 1, b => 2, c => 3`. Verwijder het item `b` met een subscript-adverb. Druk daarna af hoeveel items er nog in de hash zitten. Dat laat zien dat er één item weg is.

## Voorbeeld

Het programma drukt af:

```
2
```
