## Probleem

Neem de array `1, 2, 3`. Zet hem in een scalar `$x` met de **item**-contextomzetter. Een contextomzetter stelt de context in. Nu bewaart `$x` de hele array als één waarde. Laat dan een `for`-lus over `$x` lopen met de **lijst**-contextomzetter. Tel hoe vaak de lus loopt. In lijstcontext wordt de array weer drie elementen. Dus loopt de lus drie keer. Druk het aantal af.

## Voorbeeld

Het programma drukt af:

```
3
```
