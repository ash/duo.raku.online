## Opgave

Native typen met een vaste grootte zijn goed voor arrays van bytes. Zulke arrays gebruiken weinig geheugen. Maak een `uint8`-array met de waarden `100`, `200` en `255`. Elke waarde past in één byte. Druk de som van de elementen af.

De elementen blijven in het bereik `0..255`. Maar hun som kan groter zijn. `.sum` geeft een gewoon `Int` terug.

## Voorbeeld

Het programma drukt af:

```
555
```
