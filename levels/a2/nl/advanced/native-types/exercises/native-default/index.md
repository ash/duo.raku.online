## Opgave

Een native variabele is nooit ongedefinieerd. Deze regel geldt voor alle native typen, niet alleen voor `int`. Declareer een native `num` en een native `str`. Geef ze geen waarden. Druk het getal af. Druk daarna de string af tussen vierkante haken. Zo kun je zien dat hij leeg is.

## Voorbeeld

Het programma drukt af:

```
0
[]
```
