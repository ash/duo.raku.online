## Opgave

Maak een hash met het paar `a => 1`. Lees dan de waarde bij de sleutel `a`. Gebruik daarvoor de postcircumfix-subscriptoperator `< >`. Druk de waarde af.

## Voorbeeld

Het programma drukt af:

```
1
```
