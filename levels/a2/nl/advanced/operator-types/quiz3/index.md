De `x`-operator herhaalt een string. `'ab' x 3` geeft dus `'ababab'`. De `x` staat tussen zijn twee operanden. Wat is zijn categorie?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Alleen de positie telt. De operator kan een symbool of een woord zijn. `x` staat *tussen* twee operanden. Dus is het een **infix**-operator, net als `+` of `~`. Maar de naam is een letter.

</div>
