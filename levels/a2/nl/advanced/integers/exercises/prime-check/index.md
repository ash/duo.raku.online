## Probleem

Is een getal een priemgetal? Vaak zie je dat niet door alleen te kijken. De methode `is-prime` beantwoordt deze vraag. Gebruik hem op twee getallen, `97` en `91`. Eerst lijken ze allebei priemgetallen. Druk het resultaat voor elk getal af op een eigen regel.

Pas op met `91`. Het is `7 × 13`.

## Voorbeeld

Het programma drukt af:

```
True
False
```
