title: Geordende containers
---

{% include menu.html %}

Geordende containers bewaren meerdere elementen. Ze bewaren de elementen in volgorde. Zo kun je elk element via zijn positie krijgen. Soms bewaren ze maar één element, of zelfs helemaal geen elementen. De meest gebruikte geordende containers zijn _arrays_ en _lists_.

De `@` sigil laat zien dat een variabele voor veel elementen is. Bij zo'n variabele kun je een index gebruiken. Je schrijft de index tussen vierkante haken. Dan krijg je één element. Dit zag je al in het deel Essentials.

In dit deel bekijken we arrays en lists van dichterbij. Hoe verschillen ze _als containers_? Welke kun je veranderen? Wat gebeurt er als je de ene container in de andere zet? En wat is _binding_? Binding geeft een naam aan een container. Het kopieert niets.
