## Probleem

Hier zijn twee arrays:

```raku
my @first = 1, 2;
my @second = 3, 4, 5;
```

Zet ze samen in één _plat_ array. Het mag geen genest array zijn, met arrays erin. Print het array. Print daarna het aantal elementen.

## Voorbeeld

Het programma print:

```
[1 2 3 4 5]
5
```
