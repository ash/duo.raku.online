## Opgave

`do` werkt ook vóór control-flow-statements. Het maakt er expressies met een waarde van. Gebruik `do if 7 > 5 { 'big' } else { 'small' }` om een label te kiezen. Wijs het label toe aan `$label` en print het.

## Voorbeeld

Het programma print:

```
big
```
