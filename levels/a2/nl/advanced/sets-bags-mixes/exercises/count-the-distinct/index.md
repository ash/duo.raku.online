## Probleem

Hier is een lijst met getallen. Sommige komen vaker voor:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Druk af hoeveel _unieke_ waarden de lijst heeft. Unieke waarden verschillen allemaal van elkaar. Gebruik een set.

## Voorbeeld

Het programma drukt af:

```
7
```
