## Probleem

Schrijf een subroutine `stats`. Definieer daarin een **geneste** hulpsubroutine `double`. Die geeft haar argument keer twee terug. Gebruik de hulpfunctie binnen `stats`. Druk de waarde van `double(3) + double(5)` af.

Roep vervolgens `stats` aan.

## Voorbeeld

Het programma drukt af:

```
16
```
