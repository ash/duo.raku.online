## Probleem

`WHAT` doet meer dan een type beschrijven. Het geeft het type object zelf terug. Je kunt type objects vergelijken met de operator `===`.

Declareer twee variabelen. `$a` bewaart het gehele getal `42`. `$b` bewaart de string `'x'`. Kijk voor elke variabele naar zijn `WHAT`. Is dat het type `Int`? Druk het antwoord af.

## Voorbeeld

Het programma drukt af:

```
True
False
```
