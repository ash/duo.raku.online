## Probleem

Een container kan een standaardwaarde hebben. Je stelt die in met de trait `is default`. Voordat je een waarde toewijst, geeft de variabele deze standaardwaarde terug. `.VAR.default` toont hem ook.

Declareer een scalar `$count`. Zijn standaardwaarde moet `0` zijn. Wijs er niets aan toe. Druk de variabele af. Druk daarna de standaardwaarde van zijn container af. Beide regels moeten `0` tonen.

## Voorbeeld

Het programma drukt af:

```
0
0
```
