## Probleem

Hier is een variabele met een type:

```raku
my Str $lang = 'Raku';
```

Druk er drie dingen over af. Druk elk ding af op een eigen regel:

1. het type van zijn waarde;
2. het type van zijn container;
3. zijn naam, met de sigil.

## Voorbeeld

Het programma drukt af:

```
Str
Scalar
$lang
```
