## Opgave

`index` vertelt je *waar* een teken staat. Dan kun je de string op die plek knippen met `substr`. Gebruik ze samen.

Neem het e-mailadres `user@example.com`. Zoek de positie van het teken `@`. Druk dan alles af wat erna komt. Dat is het domeingedeelte.

## Voorbeeld

Het programma drukt af:

```
example.com
```
