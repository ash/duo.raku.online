Hier is een manier om de taak op te lossen.

## Code

```raku
say 'raku'.flip.uc;
```

🦋 Je kunt de broncode vinden in het bestand [reverse-and-shout.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/strings/reverse-and-shout.raku).

## Uitvoer

```
UKAR
```

## Opmerkingen

1. De methoden werken van links naar rechts. Eerst maakt `flip` van `'raku'` `'ukar'`. Dan maakt `uc` er `'UKAR'` van.

1. Elke methode geeft een nieuwe string terug. Daarom kun je ze in één uitdrukking achter elkaar zetten.
