Tests controleren of je code het goede doet. Ze controleren dat ook opnieuw na elke verandering. Raku heeft een module voor tests, `Test`. Raku heeft ook vaste manieren om veel tests tegelijk uit te voeren. Echte Raku-programma's en -modules hebben tests nodig. Tests schrijven is een belangrijk deel van het werk.

Dit onderdeel toont de belangrijkste delen van de `Test`-module. Het toont ook de verschillende soorten vergelijkingen erin. Tot slot laat het zien hoe je tests uitvoert.
