## Opgave

Gebruik de `Test`-module. Schrijf één `ok`-test. Die controleert of de string `Raku` vier tekens heeft. De beschrijving is `Raku has four letters`. Roep op het eind `done-testing` aan.

## Voorbeeld

Het programma geeft de volgende uitvoer:

```
ok 1 - Raku has four letters
1..1
```
