Een functie in de `Test`-module slaagt als een voorwaarde waar is. De voorwaarde is `True` of `False`. Welke functie is het?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` neemt een voorwaarde. Deze functie slaagt als de voorwaarde waar is. `is` vergelijkt de waarde die je krijgt met de waarde die je verwacht. `plan` zegt hoeveel tests je verwacht. `done-testing` sluit het bestand af en print het plan.

</div>
