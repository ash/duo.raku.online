## Opgave

Een `when` kan matchen op een *type*, niet alleen op een waarde. Een variabele bewaart het getal `3.14`. Gebruik `given`/`when` om te zeggen wat voor waarde het is. Druk `integer` af voor een `Int`. Druk `rational` af voor een `Rat`. Druk `string` af voor een `Str`.

## Voorbeeld

Het programma drukt af:

```
rational
```
