## Opgave

Het symbool van een operator kan elk teken zijn. Het kan ook een Unicode-teken zijn. Definieer een **postfix**-operator `²`. Hij geeft het kwadraat van zijn operand terug. `5²` betekent dus `5 ** 2`. Druk dan `5²` af.

## Voorbeeld

Het programma drukt af:

```
25
```
