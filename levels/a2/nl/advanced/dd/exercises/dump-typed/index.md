## Probleem

Declareer een variabele van het type `Int`: `my Int $n = 42;`. Dump deze met `dd`. Kijk naar de uitvoer. Een variabele zonder type geeft een andere uitvoer.

## Voorbeeld

Het programma schrijft dit naar de standaardfoutstroom:

```
Int $n = 42
```
