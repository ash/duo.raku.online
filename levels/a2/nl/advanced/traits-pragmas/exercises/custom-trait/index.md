## Opgave

Je eigen trait kan meer dan alleen aanwezig zijn of niet. Hij kan ook een argument krijgen. Schrijf een trait `is role(...)`. Hij krijgt een string. Deze string is de rol van een subroutine. De trait bewaart de rol in een hash. De sleutel is de naam van de subroutine.

Voeg `is role('admin')` toe aan een subroutine `login`. Druk dan de bewaarde rol van `login` af.

## Voorbeeld

Het programma drukt af:

```
admin
```
