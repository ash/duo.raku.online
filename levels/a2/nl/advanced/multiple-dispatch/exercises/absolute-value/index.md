## Probleem

Schrijf twee multi-subroutines met de naam `abs-value`. Ze nemen een geheel getal en geven de absolute waarde terug. De absolute waarde is het getal zonder minteken. Gebruik een `where`-clausule voor negatieve getallen. Gebruik geen `if` in de subroutines. Gebruik ook de ingebouwde `abs` niet.

Print het resultaat voor `-7` en voor `4`.

## Voorbeeld

Het programma print:

```
7
4
```
