## Problemo

Skribu programon, kiu kreas kelkajn skalarajn variablojn. Donu al ili komencajn valorojn de ĉi tiuj tipoj: `Int`, `Rat`, `Num`, `Bool` kaj `Str`. La programo devus presi ĉiun valoron kaj ĝian tipon.

## Ekzemplo

La reala eligo de via programo povas malsami. Sed ĉi tiu testa rulado montras la ideon:

```console
$ raku types.raku
151 (Int)
4.2 (Rat)
1e10 (Num)
True (Bool)
xyz (Str)
```
