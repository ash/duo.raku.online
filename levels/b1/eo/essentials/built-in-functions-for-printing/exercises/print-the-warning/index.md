## Problemo

Skribu programon, kiu demandas vian aĝon. Se la valoro estas negativa, ĝi presas unu aŭ du avertojn. Certigu, ke la averto iras al `STDERR`.

## Ekzemplo

Jen du eblaj kazoj:

```console
$ raku print-the-warning.raku
Kiom estas via aĝo? 20
Via aĝo estas 20

$ raku print-the-warning.raku
Kiom estas via aĝo? -1
Vi enmetis negativan numeron!
```
