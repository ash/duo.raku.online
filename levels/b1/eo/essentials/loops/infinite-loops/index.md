title: Senfinaj bukloj

{% include menu.html %}

Vi ankaŭ povas uzi `loop` nur kun korpo:

```raku
loop {
    say 'Eterneco';
}
```

Ĉi tiu buklo ruliĝas senfine, ĝis vi haltigas la programon, ekzemple, premante `Ctrl+C`. En la dua parto de la kurso, ni vidos pli bonajn manierojn por regi buklojn.
