Programo, kiu presas la valoron de π, estas sufiĉe simpla.

## Kodo

```raku
say π;
```

🦋 Vi povas trovi la plenan kodon en la dosiero [pi.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/numbers/pi.raku).

## Eligo

Rulu la programon kaj vidu kion ĝi presas:

```console
$ raku exercises/numbers/pi.raku
3.141592653589793
```

## Komentoj

Raku donas al ni enkonstruitan konstanton nomatan `π`, do la programo estas tre simpla. Tamen, jen kelkaj aliaj manieroj fari la samon:

```raku
    π.say;
```

Aŭ:

```raku
    pi.say;
```

Aŭ:

```raku
    say pi;
```
