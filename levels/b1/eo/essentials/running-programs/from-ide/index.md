Ĉi tiu mallonga sekcio klarigas, kiel ruli programon ene de la IDE. Ĝi traktas la du plej rekomenditajn [IDE-ojn](../../editors-and-ides).

## Visual Studio Code Editor

Malfermu terminalon per la menuo `Terminal` → `New Terminal`. Ĝi aldonas panelon sub la teksto de via programo. Rulu la programon tie, same kiel de la komandlinio:

```console
$ raku hello.raku
```

## Comma IDE

Vi povas ruli programojn per la menuero `Run`. Agordu la IDE antaŭ la unua rulado de programo. Sekvu [la instrukciojn](https://commaide.com/docs/running) en la retejo de Comma.
