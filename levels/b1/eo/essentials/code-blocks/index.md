title: Kodoblokoj
---

{% include menu.html %}

Kodoblokoj estas partoj de via programo ene de paro de kurbaj krampoj: `{` kaj `}`. Bloko grupigas plurajn deklarojn, kiuj laboras kune kiel unu granda deklaro. Ni vidos multajn manierojn uzi blokojn en la sekvaj sekcioj.

```raku
{
    say 'Saluton, Mondo!';
}
```

La kodobloko en ĉi tiu programo ne vere havas sencon. Sed kodoblokoj estas tre utilaj en aliaj situacioj, kiujn ni vidos tre baldaŭ.

Sed unue, ni rigardu la ideon de _amplekso_.
