Kiu funkcio sendas sian komandon tra la sistema **ŝelo** kaj permesas duktojn kaj redirektadon?

{:.quiz}
0 | `run`
1 | `shell`
0 | `exec`
0 | `system`

{% include quiz.html %}

<div class="extended-explanation">

`shell` transdonas unu solan ĉenon al la ŝelo, kiu komprenas ecojn kiel duktojn. `run` lanĉas programon rekte, kun apartaj argumentoj kaj sen ŝelo. Tio estas pli sekura, do `run` estas la pli bona defaŭlto.
