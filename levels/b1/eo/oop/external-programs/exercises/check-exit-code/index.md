## Problemo

Rulu komandon, kiu intence malsukcesas, ekzemple `sh -c 'exit 4'`. Tenu la `Proc`, kiun ĝi redonas. Presu la elirkodon de la komando. Poste presu `success` aŭ `failure`, depende de tio, ĉu la komando sukcesis.

## Ekzemplo

La programo presas:

```
4
failure
```
