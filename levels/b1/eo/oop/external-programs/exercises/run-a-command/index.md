## Problemo

Uzu `run` por lanĉi `echo` kun du apartaj argumentoj: `home:` kaj `$HOME`. Lasu ĝian eligon iri al la ekrano. Rimarku, ke `$HOME` aperas tiel, kiel ĝi estas, kaj la hejma dosierujo **ne** estas presata. Ĉar `run` ne uzas ŝelon, la variablo ne estas anstataŭigata per sia valoro.

## Ekzemplo

La programo presas:

```
home: $HOME
```
