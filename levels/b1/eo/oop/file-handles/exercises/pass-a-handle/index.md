## Problemo

Dosiertenilo estas ordinara valoro. Do vi povas transdoni ĝin al funkcio, kiel ĉiun alian argumenton. Skribu subrutinon `log-line`, kiu prenas tenilon kaj mesaĝon. Ĝi skribu la mesaĝon al la tenilo en aparta linio.

Malfermu `log.txt` por skribado. Voku `log-line` tri fojojn por skribi `started`, `working` kaj `done`. Poste fermu la tenilon, relegu la dosieron kaj presu ĝian enhavon.

## Ekzemplo

La programo presas:

```
started
working
done
```
