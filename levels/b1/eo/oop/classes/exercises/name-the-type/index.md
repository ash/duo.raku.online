## Problemo

Difinu du malplenajn klasojn, `Cat` kaj `Dog`, kaj kreu ekzempleron de `Cat` nomatan `$felix`. Presu la tipon de `$felix` per `WHAT`. Poste uzu la operatoron `===` kaj presu du pliajn liniojn. La unua linio montras, ĉu tiu tipo estas la sama kiel `Cat`. La dua montras, ĉu ĝi estas la sama kiel `Dog`.

## Ekzemplo

La programo presas:

```
(Cat)
True
False
```
