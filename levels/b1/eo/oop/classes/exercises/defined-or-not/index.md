## Problemo

Difinu du malplenajn klasojn, `Cat` kaj `Dog`. Poste iru per buklo tra kvar valoroj: `Cat`, `Dog`, `Cat.new` kaj `Dog.new`. Por ĉiu el ili, presu, ĉu ĝi estas difinita. Rimarku, ke la du tipobjektoj estas nedifinitaj, kaj la du ekzempleroj estas difinitaj. Ne gravas, al kiu klaso ili apartenas.

## Ekzemplo

La programo presas:

```
False
False
True
True
```
