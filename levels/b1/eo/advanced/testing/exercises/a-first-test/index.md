## Problemo

Uzu la modulon `Test` por skribi unu teston `ok`. Ĝi devas kontroli, ke la ĉeno `Raku` havas kvar signojn, kun la priskribo `Raku has four letters`. Finu per `done-testing`.

## Ekzemplo

La programo presas:

```
ok 1 - Raku has four letters
1..1
```
