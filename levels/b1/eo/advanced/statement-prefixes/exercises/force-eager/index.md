## Problemo

La prefikso `eager` faras la malon de `lazy`. Ĝi igas Raku produkti la tutan liston, do la listo ne plu estas maldiligenta. Montru la diferencon per `.is-lazy`.

Presu, ĉu la senfina intervalo `1 .. Inf` estas maldiligenta. Poste presu, ĉu `eager 1..3` estas maldiligenta, kaj fine, ĉu `lazy 1..3` estas maldiligenta. La rezultoj devus esti `True`, `False`, `True`.

## Ekzemplo

La programo presas:

```
True
False
True
```
