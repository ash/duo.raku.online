title: Bazaj konoj pri moduloj

{% include menu.html %}

_Modulo_ estas dosiero de kodo, kiun vi povas uzi denove kaj denove. Ĝi enhavas subprogramojn, variablojn kaj pli, kaj aliaj programoj povas ŝargi kaj kunhavi ĝin. Ĉi tiu sekcio kovras la bazojn en tri paŝoj. Unue, vi vidos, kiel **skribi** modulon kaj marki tion, kion ĝi proponas. Poste vi vidos, kiel programo **ŝargas** ĝin per `use`. Fine, vi vidos, kiel **importado** alportas la nomojn de modulo en vian amplekson.
