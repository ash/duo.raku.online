La operatoro `x` ripetas ĉenon. Ekzemple, `'ab' x 3` donas `'ababab'`. Ĉar `x` staras inter siaj du operandoj, en kiu kategorio ĝi estas?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Gravas la pozicio, ne ĉu la operatoro estas simbolo aŭ vorto. `x` staras *inter* du operandoj, do ĝi estas **infiksa** operatoro. Ĝi estas same kiel `+` aŭ `~`, sed skribita kiel litero.

</div>
