## Problemo

Kreu pakon `Temperature`, kiu grupigas du aferojn. La unua estas `our`-variablo `$freezing` kun la valoro `0`. La dua estas `our`-subrutino `fahrenheit`, kiu konvertas valoron laŭ Celsio al Fahrenheit. Por konverti, multipliku per 9/5 kaj aldonu 32. De ekster la pako, presu la frostopunkton. Poste presu la Fahrenheit-valoron de `100` gradoj laŭ Celsio.

## Ekzemplo

La programo presas:

```
0
212
```
