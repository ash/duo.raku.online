Kion presas la jena programo?

```raku
say 'programming'.substr: 0, 3;
```

{:.quiz}
1 | pro
0 | program
0 | ing
0 | (0 3)

{% include quiz.html %}

<div class="extended-explanation">

La dupunkto prenas la *tutan* reston de la deklaro kiel la liston de argumentoj. Do `substr: 0, 3` estas la sama kiel `substr(0, 3)`, kaj ambaŭ argumentoj estas transdonataj. Ĝi komencas ĉe indekso `0` kaj prenas `3` signojn, kio donas `pro`.

</div>
