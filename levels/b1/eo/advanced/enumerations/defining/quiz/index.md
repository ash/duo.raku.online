Kion presas la jena programo?

```raku
enum Colour <red green blue>;
say green + blue;
```

{:.quiz}
1 | 3
0 | greenblue
0 | (green blue)
0 | eraron

{% include quiz.html %}

<div class="extended-explanation">

Ĉiu konstanto signifas nombron. La nombroj komenciĝas de nulo, laŭ la ordo de la listo: `red` estas `0`, `green` estas `1`, `blue` estas `2`. Kiam vi faras aritmetikon kun ili, la konstantoj agas kiel ĉi tiuj nombroj. Do `green + blue` estas `1 + 2`, kio estas `3`.

</div>
