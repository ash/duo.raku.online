## Problemo

Ujo povas havi defaŭltan valoron, kiun vi agordas per la trajto `is default`. Ĝis vi atribuas ion, la variablo redonas ĉi tiun defaŭlton. `.VAR.default` ankaŭ diras al vi, kio ĝi estas.

Deklaru skalaron `$count` kun la defaŭlta valoro `0`. Ne atribuu ion ajn al ĝi. Unue presu la variablon mem, kaj poste presu la defaŭlton de ĝia ujo. Ambaŭ linioj devus montri `0`.

## Ekzemplo

La programo presas:

```
0
0
```
