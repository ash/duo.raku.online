## Aranĝo

```
Greet-Simple/
├── META6.json
├── README.md
├── lib/
│   └── Greet/
│       └── Simple.rakumod
└── t/
    └── 01-basic.rakutest
```

## Komentoj

1. La `META6.json` estas supre. La modula fontkodo iras sub `lib/`. Ĝia dosieruja vojo kongruas kun la partoj de la nomo inter la `::`.

1. La testoj estas sub `t/`. Kun ĉi tiu aranĝo, `zef test .` kaj `zef install .` funkcias en la supra dosierujo.
