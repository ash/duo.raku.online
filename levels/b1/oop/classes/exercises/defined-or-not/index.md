## Problem

Define two empty classes, `Cat` and `Dog`. Then loop over four values: `Cat`, `Dog`, `Cat.new` and `Dog.new`. For each one, print whether it is defined. Note that the two type objects are undefined, and the two instances are defined. It does not matter which class they belong to.

## Example

The program prints:

```
False
False
True
True
```
