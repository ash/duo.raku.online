## Problem

Define two empty classes, `Cat` and `Dog`, and create a `Cat` instance called `$felix`. Print the type of `$felix` with `WHAT`. Then use the `===` operator and print two more lines. The first line shows whether that type is the same as `Cat`. The second shows whether it is the same as `Dog`.

## Example

The program prints:

```
(Cat)
True
False
```
