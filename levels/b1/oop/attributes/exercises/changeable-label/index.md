## Problem

Define a class `Label` with one attribute, `text`, that can be changed (`is rw`). Create a label with the text `draft`. Then use the accessor to **add** ` (revised)` to the end of its text. Do not create the object again. Print the result.

## Example

The program prints:

```
draft (revised)
```
