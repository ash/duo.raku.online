## Problem

Define a class `Counter` with one attribute, `count`, which can be changed (`is rw`). Its default value is `0`.

Create a counter and first print its `count`. This checks that it starts at the default. Then use a loop to add one to it five times. Print the final value.

## Example

The program prints:

```
0
5
```
