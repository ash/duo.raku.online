## Problem

Define a class `Book` with two attributes, `title` and `author`. Create a book with the title `Raku` and the author `Larry`. Then print one line that names the book and uses both accessors. The line should look like this: `<title> by <author>`.

## Example

The program prints:

```
Raku by Larry
```
