## Problem

Define a base class `Shape` with two methods. The method `name` returns `'shape'`. The method `describe` returns the string `I am a <name>`, using its own `name` method.

Then define a class `Square`, which inherits from `Shape`. It overrides `name`, so that `name` returns `'square'`.

Print the description of a `Square`.

## Example

The program prints:

```
I am a square
```
