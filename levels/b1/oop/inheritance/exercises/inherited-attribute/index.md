## Problem

Define a base class `Vehicle` with an attribute `wheels`. Then define two classes that inherit from it. A `Bike` comes with `2` wheels, and a `Car` comes with `4`.

Create a `Bike` and a `Car`, and print how many wheels each of them has.

## Example

The program prints:

```
2
4
```
