## Problem

Define two roles:

* `Named`, with a method `label`, which returns `I am <name>`;
* `Aged`, with a method `status`, which returns `<age> years`.

Then define a class `Pet` that does both roles. It has the attributes `name` and `age`. Create a pet called `Rex`, aged `3`. Then print its `label` and its `status`.

## Example

The program prints:

```
I am Rex
3 years
```
