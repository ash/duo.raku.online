## Problem

Define a class `Robot` with a method `speak` that returns `beep`. Then define a role `Dancing`, which adds a method `dance` that returns `spinning around`.

Create two robots, but give the `Dancing` role to only one of them. Print the result of `speak` for both robots. Then print the result of `dance` for the robot that can dance.

## Example

The program prints:

```
beep
beep
spinning around
```
