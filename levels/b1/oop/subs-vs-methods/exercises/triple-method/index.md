## Problem

Now solve the same task with a **method**. Define a class `Number` with an attribute `n`. Give it a method `triple` that returns three times `n`. Create a `Number` with `n` equal to `7`. Then call `triple` on it and print the result.

## Example

The program prints:

```
21
```
