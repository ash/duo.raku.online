## Problem

Like any other method, a class method can take parameters. Define a class `Geometry` with a class method `circle-area`. It takes a radius and returns the area of a circle, rounded to an integer. Use `π` or `pi`. The formula belongs to the whole class, and no single circle object is involved. Call the method on the class with a radius of `10` and print the result.

## Example

The program prints:

```
314
```
