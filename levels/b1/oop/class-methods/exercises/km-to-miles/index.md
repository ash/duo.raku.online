## Problem

Define a class `Converter` with a class method `km-to-miles`. It takes a number of kilometres and returns the distance in miles. To convert, multiply by `0.621`.

Call the method on the class with `10` kilometres, then print the result.

## Example

The program prints:

```
6.21
```
