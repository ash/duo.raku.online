## Problem

Run a command that fails on purpose, for example `sh -c 'exit 4'`. Keep the `Proc` that it returns. Print the exit code of the command. Then print `success` or `failure`, depending on whether the command succeeded.

## Example

The program prints:

```
4
failure
```
