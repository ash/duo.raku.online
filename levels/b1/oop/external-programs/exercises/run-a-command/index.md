## Problem

Use `run` to start `echo` with two separate arguments: `home:` and `$HOME`. Let its output go to the screen. Note that `$HOME` appears as it is, and the home directory is **not** printed. Because `run` does not use a shell, the variable is not replaced with its value.

## Example

The program prints:

```
home: $HOME
```
