## Problem

Define a class `Animal` with a method `speak`. Then define a class `Dog` that inherits from `Animal`. It adds no methods of its own. Use a meta-method on `Dog` and print whether `Dog` has a method called `speak`. Print a simple `True` or `False`. This shows that `find_method` looks along the inheritance chain. It does not only look at the class’s own methods.

## Example

The program prints:

```
True
```
