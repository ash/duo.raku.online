## Problem

Define a class `Dog` with only a `name` attribute and no methods. Then use the MOP to add a method `speak` to it at run time. The new method should use the object’s own `name` and return `<name> says woof`. Create a dog called `Rex` and call the new method.

## Example

The program prints:

```
Rex says woof
```
