## Problem

Build a small log file by adding to it again and again. Write the line `start` to a file called `log.txt`. Then use a loop to **append** three more lines: `entry 1`, `entry 2` and `entry 3`. Do not erase what is already in the file. Finally, read the whole file and print it.

## Example

The program prints:

```
start
entry 1
entry 2
entry 3
```
