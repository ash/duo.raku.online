## Problem

Define a class `Rectangle` with the attributes `width` and `height`. Give it a method `area` that returns the area of the rectangle. Add a second method, `describe`, which returns the string `area is <area>`. To do this, it must **call its own `area` method** through `self`.

Create a rectangle that is `3` wide and `4` high. Then print its description.

## Example

The program prints:

```
area is 12
```
