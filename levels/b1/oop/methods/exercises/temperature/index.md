## Problem

Define a class `Celsius` with an attribute `degrees`. Add a method `to-fahrenheit` that converts the temperature to Fahrenheit. Use the formula `degrees × 9 / 5 + 32`.

Create a `Celsius` object for `100` degrees and print its value in Fahrenheit.

## Example

The program prints:

```
212
```
