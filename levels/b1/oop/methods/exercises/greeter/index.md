## Problem

Define a class `Word` with a `text` attribute and a method `reversed`. The method returns the text of the word spelled backwards. You can use the `flip` method, which reverses a string.

Create a word that holds `Raku`, and print it reversed.

## Example

The program prints:

```
ukaR
```
