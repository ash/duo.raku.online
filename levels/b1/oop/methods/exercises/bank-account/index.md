## Problem

Define a class `Robot` with a `position` attribute that can be changed. Its default value is `0`. Add a method `move` that moves the position forward by a given number of steps. The number of steps should have the default `1`. Then a call to `move` with no argument moves the robot one step.

Create a robot and move it `5` steps. Then move it with no argument, and then `2` more steps. Print its final position.

## Example

The program prints:

```
8
```
