## Problem

Define a base class `Animal` and a class `Dog` that inherits from it. Print the name of the `Dog` class. On the next line, print the number of types in its inheritance chain. To do this, use `.^mro` and count its elements. Finally, on a third line, print whether a class `Cat` is anywhere in that chain.

## Example

The program prints:

```
Dog
4
False
```
