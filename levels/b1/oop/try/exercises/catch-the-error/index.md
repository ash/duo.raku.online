## Problem

Show both sides of `try`. First, use a `try` block around a calculation that works, for example `6 * 7`. Then print its result. Next, put code that does `die 'broken'` into a second `try` block. Print whether that block gave a defined result. Then print the message of the caught exception.

## Example

The program prints:

```
42
False
broken
```
