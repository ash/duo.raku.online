## Problem

Write the three words `apple`, `banana` and `cherry` to a file called `words.txt`. Put each word on its own line. Then read the file line by line. Print each line with its line number in front of it, starting from `1`. Use the form `<number>: <line>`.

## Example

The program prints:

```
1: apple
2: banana
3: cherry
```
