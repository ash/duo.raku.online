---
title: Перетворення типів для типізованих змінних
---

{% include menu.html %}

Обмеження типів досить суворі. Наприклад, ви не можете присвоїти значення `Num` змінній, оголошеній як `Int`. Це так, навіть якщо значення — ціле число:

```raku
my Int $x = 42;
# $x = 42e1; # Помилка
```

Використовуйте [один із методів](/uk/essentials/coercion/#topics-in-this-section), щоб перетворити значення на потрібний тип.

```raku
my Int $x = 42;
$x = 42e1.Int;
$x = Int(42e1);
```
