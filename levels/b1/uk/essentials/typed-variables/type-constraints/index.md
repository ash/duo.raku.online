---
title: Обмеження типу
---

{% include menu.html %}

Raku має так звану поступову систему типів. У більшості випадків вам не потрібно турбуватися про тип змінної. Але іноді ви можете захотіти обмежити змінну одним типом. Це можна зробити, якщо вказати тип, як показано нижче:

```raku
my Int $var = 42;
```

Тепер ви можете присвоїти змінній `$var` інше ціле значення. Але якщо ви спробуєте покласти в неї рядок, ви отримаєте виняток. Те саме станеться навіть з числом з плаваючою комою:

```raku
my Int $var = 42;
$var = '314E-2';
```

Ця програма видає наступну помилку:

    Type check failed in assignment to $var; expected Int but got Str ("314E-2")
      in block <unit> at t.raku line 2
