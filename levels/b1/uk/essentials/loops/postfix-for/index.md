---
title: Постфіксна форма `for`
---

{% include menu.html %}

Ви вже бачили інші модифікатори операторів: [`if` та `else`](/uk/essentials/conditional-checks/modifiers) і [`while` та `until`](/uk/essentials/loops/modifiers). Це невеликий привід для свята: дизайн Raku дуже послідовний.

Коли тіло циклу коротке, можна використати постфіксну форму `for`:

```raku
.say for 1..7;
```

Як бачите, діапазони дуже добре підходять до постфіксного `for`.

Ця програма робить те саме, що й більш звичний варіант:

```raku
for 1..7 -> $n {
    say $n;
}
```

Або, якщо ви використовуєте змінну циклу за замовчуванням, те саме, що й це:

```raku
for 1..7 {
    .say;
}
```

Тут `.say` — це скорочення для `$_.say`.
