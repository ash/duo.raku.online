---
title: Постфіксна форма `for`
---

{% include menu.html %}

Ми вже бачили інші модифікатори операторів: [`if` та `else`](/uk/essentials/conditional-checks/modifiers) і [`while` та `until`](/uk/essentials/loops/modifiers). Це привід трохи відсвяткувати, бо дизайн Raku дуже послідовний.

Коли тіло циклу коротке, ви можете записати цикл `for` у постфіксній формі:

```raku
.say for 1..7;
```

Як бачите, діапазони виглядають дуже природно з постфіксною формою `for`.

Ця програма — те саме, що й більш традиційний варіант:

```raku
for 1..7 -> $n {
    say $n;
}
```

Або, якщо ви використовуєте змінну циклу за замовчуванням, це те саме, що:

```raku
for 1..7 {
    .say;
}
```

Тут `.say` — це коротка форма для `$_.say`.
