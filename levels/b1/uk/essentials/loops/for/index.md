title: Цикли `for`

Цикл `for` — це потужний інструмент, який дає змогу перебирати кілька елементів один за одним. Наприклад, візьмімо діапазон:

```raku
for 1..5 -> $n {
    say $n;
}
```

У цій програмі змінна `$n` на кожній ітерації бере наступне значення з діапазону. Зверніть увагу, що вам не потрібно оголошувати змінну за допомогою `my`. Блок коду повторюється стільки разів, скільки елементів є в джерелі даних. Отже, програма виводить числа рядок за рядком:

```console
$ raku t.raku 
1
2
3
4
5
```

Програма проходить по всіх значеннях, які видає [діапазон](/uk/essentials/ranges) `1..5`. Це `1`, `2`, `3`, `4` і `5`.

## Взяття більше ніж одного значення

Цікава особливість Raku в тому, що ви можете брати більше ніж один елемент за одну ітерацію. Наступна програма виводить два числа щоразу, коли виконується цикл:

```raku
for 1..6 -> $n, $m {
    say "$n and $m";
}
```

Ось такий вивід цієї програми:

```console
$ raku t.raku
1 and 2
3 and 4
5 and 6
```
