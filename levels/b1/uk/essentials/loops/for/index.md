title: Цикли `for`

Цикл `for` — це потужний інструмент. Він проходить по багатьох елементах, один за одним. Наприклад, візьмімо діапазон:

```raku
for 1..5 -> $n {
    say $n;
}
```

Щоразу, коли виконується цикл, змінна `$n` бере наступне значення з діапазону. Зверніть увагу, що вам не потрібно оголошувати змінну за допомогою `my`. Блок коду виконується один раз для кожного елемента джерела даних. Тож програма виводить числа по одному в рядку:

```console
$ raku t.raku 
1
2
3
4
5
```

Програма проходить по всіх значеннях, які дає [діапазон](/uk/essentials/ranges) `1..5`. Це `1`, `2`, `3`, `4` і `5`.

## Взяття більше ніж одного значення

Ось цікава особливість Raku. Цикл може брати більше ніж один елемент за раз. Наступна програма виводить два числа щоразу, коли виконується цикл:

```raku
for 1..6 -> $n, $m {
    say "$n and $m";
}
```

Ось такий вивід цієї програми:

```console
$ raku t.raku
1 and 2
3 and 4
5 and 6
```
