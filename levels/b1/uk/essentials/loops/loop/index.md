title: Триопераційний цикл `loop`
---

Оператор `loop` у Raku має багато спільного з традиційними циклами мови програмування C та її родичів. Він приймає три вирази: ініціалізатор, тест і вираз, який змінює змінну циклу. Тіло циклу виконується знову і знову, поки тест залишається `True`.

```raku
loop (my $c = 0; $c < 5; $c++) {
    say "Поточне значення лічильника: $c.";
}
```

Тут `++` — це постфіксний оператор, який збільшує свій аргумент на 1. Більше операторів ми розглянемо в другій частині курсу.

Програма виконує тіло циклу п'ять разів.

```console
$ raku t.raku
Поточне значення лічильника: 0.
Поточне значення лічильника: 1.
Поточне значення лічильника: 2.
Поточне значення лічильника: 3.
Поточне значення лічильника: 4.
```

Деякі або навіть усі вирази в заголовку `loop` можна пропустити. Наприклад, ось та сама програма:

```raku
my $c = 0;
loop (; $c < 5;) {
    say "Поточне значення лічильника: $c.";
    $c++;
}
```

## * * *

Цикли `loop` — мабуть, найрідше вживані цикли в Raku. Їх можна знайти, наприклад, у коді, який інструмент автоматично переклав з C на Raku. Але в Raku є зручніші цикли, такі як `for`, які ми розглянемо дуже скоро.
