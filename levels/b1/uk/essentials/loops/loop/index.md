---
title: Триопераційний цикл `loop`
---

{% include menu.html %}

Оператор `loop` у Raku дуже схожий на традиційні цикли в C та подібних мовах. Він приймає три вирази. Перший задає початкове значення, а другий — це тест. Третій змінює змінну циклу. Тіло циклу виконується знову і знову, поки тест є `True`.

```raku
loop (my $c = 0; $c < 5; $c++) {
    say "Поточне значення лічильника: $c.";
}
```

Тут `++` — це постфіксний оператор, тобто він стоїть після свого аргументу. Він додає 1 до аргументу. Більше операторів є в другій частині курсу.

Програма виконує тіло циклу п'ять разів.

```console
$ raku t.raku
Поточне значення лічильника: 0.
Поточне значення лічильника: 1.
Поточне значення лічильника: 2.
Поточне значення лічильника: 3.
Поточне значення лічильника: 4.
```

Деякі вирази в заголовку `loop` або навіть усі вони — необов'язкові. Наприклад, ось та сама програма:

```raku
my $c = 0;
loop (; $c < 5;) {
    say "Поточне значення лічильника: $c.";
    $c++;
}
```

## * * *

Програмісти на Raku, мабуть, використовують `loop` рідше, ніж будь-який інший цикл. Ви можете знайти його, наприклад, у коді, який інструмент переклав з C на Raku. Але в Raku є зручніші цикли, такі як `for`. Ми розглянемо його дуже скоро.
