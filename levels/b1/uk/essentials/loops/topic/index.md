title: Топічна змінна
---

{% include menu.html %}

`$_` — це спеціальна змінна. Вона називається _topic variable_ (змінна теми).

Ось цикл по діапазону:

```raku
for 1..5 -> $n {
    say $n;
}
```

Ви можете пропустити змінну `$n`. Тоді Raku автоматично використовує замість неї змінну `$_`. Тож програма така сама, як ось ця:

```raku
for 1..5 {
    say $_;
}
```

Як ви [пам'ятаєте](/uk/essentials/hello-world/), `say` також можна викликати як метод:

```raku
for 1..5 {
    $_.say;
}
```

Щоб викликати метод на `$_`, не потрібно писати саму змінну. Тож ми можемо зробити наш цикл ще простішим:

```raku
for 1..5 {
    .say;
}
```
