`$_` — це спеціальна змінна, яка називається _topic variable_ (змінна теми).

Подивіться на цей цикл по діапазону:

```raku
for 1..5 -> $n {
    say $n;
}
```

Ви можете пропустити змінну `$n`, і тоді Raku натомість використовує автоматичну змінну `$_`. Програма така сама, як ось ця:

```raku
for 1..5 {
    say $_;
}
```

Як ви [пам'ятаєте](/uk/essentials/hello-world/), `say` також можна використовувати як метод:

```raku
for 1..5 {
    $_.say;
}
```

Коли ви викликаєте метод на `$_`, не обов'язково писати саму змінну. Отже, наш цикл можна зробити ще простішим:

```raku
for 1..5 {
    .say;
}
```
