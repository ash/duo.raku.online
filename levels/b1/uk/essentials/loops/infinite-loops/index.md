Ви також можете використовувати `loop` лише з тілом:

```raku
loop {
    say 'Вічність';
}
```

Цей цикл працює нескінченно, доки ви не зупините програму, наприклад, натиснувши `Ctrl+C`. У другій частині курсу ми побачимо кращі способи керування циклами.
