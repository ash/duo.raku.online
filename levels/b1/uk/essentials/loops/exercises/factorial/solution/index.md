Факторіал числа `N` — це добуток усіх цілих чисел від 1 до `N`. Наприклад, факторіал числа 4 дорівнює 1 * 2 * 3 * 4 = 24.

## Код

```raku
my $n = 8;

my $f = 1;
$f *= $_ for 2..$n;

say $f;
```

🦋 Знайдіть програму у файлі [factorial.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/loops/factorial.raku).

## Вивід

Запустіть програму кілька разів з різними значеннями `$n`.

```console
$ raku exercises/loops/factorial.raku
40320
```

## Коментарі

Ця програма використовує оператор `*=`, який множить і присвоює за один крок: `$x *= $y` означає те саме, що `$x = $x * $y`.

Замість постфіксної форми ви також можете використати «повний» цикл:

```raku
my $n = 8;

my $f = 1;
for 2..$n -> $x {
    $f *= $x;
}

say $f;
```
