Списки схожі на масиви, але вони незмінні. Це означає, що ви не можете змінити розмір або елементи списку. Щоб створити список, використовуйте круглі дужки:

```raku
my $odd = (1, 3, 5, 7, 9);
```

## Індексація списків

Щоб отримати окремий елемент списку, використовуйте квадратні дужки з індексом:

```raku
say $odd[3]; # 7
```

Однак ви не можете задати нове значення:

```raku
$odd[3] = 8; # Не ОК
```

Якщо ви спробуєте це зробити, ви отримаєте виняток:

    Неможливо змінити незмінний список ((1 3 5 7 9))
      в блоці <unit> на t.raku рядок 4

## Призначення списку масиву

Що відбувається, якщо зберегти список у змінній, яка має сигіл `@`?

```raku
my @data = (40, 42, 44);
```

У цьому випадку змінна `@data` зберігає масив, тому ви можете змінювати його елементи.

%%tipblock
## Змінна проти списку

Зверніть увагу, що списки незмінні. Але ви все одно можете повторно використати змінну, яка зберігає список.

```raku
my $elements = (1, 2);
say $elements[0]; # 1

$elements = (3, 4);
say $elements[0]; # 3
```

%%/tipblock
