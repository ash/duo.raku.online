Масиви — це агрегатні типи даних, тобто вони можуть зберігати більше одного значення. Цим вони відрізняються від [скалярних елементів](/uk/essentials/scalar-variables). Елементи масиву можна індексувати (або _підписувати_). Іншими словами, кожен елемент має позицію. Тому дані такого виду мають загальну назву «позиційні».

Для змінних-масивів є інший сигіл: `@`. Правила для імені змінної такі самі, як [для скалярів](/uk/essentials/scalar-variables/identifiers/).

```raku
my @cities;
```

Тепер ми створили масив з назвою `@cities`. Ви можете заповнити його кількома значеннями:

```raku
@cities = 'Paris', 'Rome', 'Berlin';
```

Ви також можете задати значення одразу, коли створюєте масив:

```raku
my @cities = 'Paris', 'Rome', 'Berlin';
```

## Індексація

Щоб отримати один елемент масиву, додайте пару дужок після його імені:

```raku
say @cities[1];
```

Зверніть увагу, що сигіл завжди залишається тим самим. Елементи рахуються з нуля, тому в нашому прикладі елемент `@cities[1]` — це `'Rome'`.

Масиви є змінними, тобто ви можете їх змінювати. Щоб змінити елемент, просто присвойте йому нове значення:

```raku
@cities[0] = 'Rome';
@cities[1] = 'Paris';
```

Тепер оператор `say @cities[1]` виводить нове значення, `'Paris'`.

## Розмір

Довжина масиву — це кількість його елементів. Щоб отримати поточну довжину, використовуйте метод `elems`:

```raku
say @cities.elems; # 3
```

Якщо масив стоїть там, де очікується число, ви отримуєте його розмір:

```raku
say +@cities; # 3
```

Тут [`+` префіксний оператор](/uk/essentials/coercion/prefixes) потребує числового значення від свого аргументу. Ось чому `+@cities` дає `3`.
