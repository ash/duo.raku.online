---
title: Виключаючи кінцеві точки
---

{% include menu.html %}

Можна виключити один кінець діапазону або обидва. Для цього додайте до оператора діапазону символ `^`. Так можна побудувати ще три оператори. Коментарі перелічують числа, які генерує кожен діапазон.

```raku
1 ..^ 5;  # 1, 2, 3, 4
1 ^.. 5;  #    2, 3, 4, 5
1 ^..^ 5; #    2, 3, 4
```

У таких простих випадках пробіли навколо оператора можна опустити:

```raku
my $r1 = 1..5;
my $r2 = 1..^5;
```

Для діапазону, який починається з 0, як-от `0..^5`, є коротка форма: `^5`.
