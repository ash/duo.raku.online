Найпростіший вид коментаря — однорядковий коментар. Він починається з символу `#`. Він триває до кінця поточного рядка.

```raku
my $name; # Ця змінна використовується для зберігання імені користувача
$name = prompt 'Як вас звати? ';
say $name; # Тепер ми бачимо ім'я
```

Подивіться на shebang, наприклад `#!/usr/bin/env raku`, у першому рядку коду. Для Raku це теж коментар. Але оболонка може його прочитати і виконати.
