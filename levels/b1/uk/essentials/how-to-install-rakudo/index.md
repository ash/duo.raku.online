Щоб запустити програму на Raku, вам потрібно встановити компілятор. У цьому курсі використовується Rakudo. Два інші, [Raku++](/uk/essentials/the-rakupp-compiler) і [mutsu](/uk/essentials/the-mutsu-interpreter), встановлюються окремо. Дивіться [Як встановити Raku++](/uk/essentials/how-to-install-rakupp) і [Як встановити mutsu](/uk/essentials/how-to-install-mutsu). Зайдіть на [сайт Rakudo](https://rakudo.org) і завантажте версію для вашої операційної системи.

## Джерела

Встановлювач для вашої системи можна завантажити на сторінці [rakudo.org/downloads](https://rakudo.org/downloads). Є версії для всіх основних операційних систем: Windows, Mac OS та Linux. Також можна взяти вихідний код і скомпілювати його самостійно.

## Docker-образи

Rakudo доступний і як docker-образ. Його можна використовувати для запуску програм. Він також добре підходить для перевірки невеликих скриптів в оболонці REPL. Усі інструкції ви знайдете на [github.com/Raku/docker](https://github.com/Raku/docker).

## Номери версій

Номер версії Rakudo має дві частини: рік і місяць випуску. Тож ви легко бачите, наскільки свіжий ваш компілятор. Виконайте цю команду, щоб побачити номер його версії:

```console
$ raku -v
Welcome to 𝐑𝐚𝐤𝐮𝐝𝐨™ v2026.06.
Implementing the 𝐑𝐚𝐤𝐮™ programming language v6.d.
Built on MoarVM version 2026.06.
```

Тут ви бачите три номери версій. Перший — це версія самого Rakudo: `v2026.06`. Далі йде версія мови Raku: `v6.d`. Поки що оновлення отримують наступну літеру як молодшу частину версії. Наприклад, наступна — `v6.e`, і так далі. Нарешті, ви бачите назву віртуальної машини в цьому компіляторі: MoarVM версії `2026.06`.
