Якщо у вас є два рядки, ви можете з'єднати їх і отримати новий, довший рядок. Це називається конкатенацією рядків. У Raku ви конкатенуєте рядки за допомогою—вгадайте чого?—оператора конкатенації. Цей оператор — тильда, `~`. Щоб конкатенувати два рядки, поставте `~` між ними:

```raku
say 'Hello, ' ~ 'World!';
```

Якщо наші рядки зберігаються у змінних, ми можемо ‘конкатенувати змінні’. Ну, точніше, ми конкатенуємо рядки, які зберігаються в цих змінних:

```raku
my $greeting = 'Hello, ';
my $who = 'World!';

say $greeting ~ $who;
```

Або ви можете створити нову змінну, яка зберігає результат конкатенації:

```raku
my $greeting = 'Hello, ';
my $who = 'World!';
my $message = $greeting ~ $who;

say $message;
```

## Конкатенація з присвоєнням

Щоб додати новий рядок у кінець змінної, використовуйте таку форму:

```raku
# Замість 
$str = $str ~ $another-str;

# використовуйте:
$str ~= $another-str;
```
