title: '`say`'
---

Ось що робить вбудована рутинна функція `say`:

1. Викликає метод `gist` на своїх аргументах.
1. Додає символ нового рядка.
1. Перетворює результат у UTF-8.
1. Відправляє його до потоку `STDOUT`.

Для користувача це виглядає просто. `say` лише виводить вміст змінної на термінал і додає новий рядок.

Перший крок потребує деяких пояснень. Кожен вбудований тип даних, наприклад цілі числа або рядки, має метод `gist`. Для таких простих типів він повертає значення, яке представляє елемент. Люди можуть легко прочитати це значення.

```raku
say 42; # 42
say 'Raku'; # Raku
```

Масиви та хеші — приклади складніших даних. Для них метод `gist` додає певне форматування.

```raku
my @data = 'alpha', 'beta', 'gamma';
say @data; # [alpha beta gamma]

my %data = alpha => 1, beta => 2, gamma => 3;
say %data; # {alpha => 1, beta => 2, gamma => 3}
```

Ви можете викликати `say` і як функцію, і як метод:

```raku
say 42;
say(42);
42.say;
```

Ви можете передати `say` кілька аргументів. Вона з'єднує частини виводу без жодних пробілів між ними.

```raku
say(100, 500); # 100500
```
