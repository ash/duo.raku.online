Процедура `put` робить ту саму роботу, що й [`print`](../print). Але за замовчуванням вона також додає в кінці новий рядок:

1. Викликає метод `Str` на своїх аргументах, щоб перетворити їх на рядок.
1. Додає символ нового рядка.
1. Відправляє рядок до потоку `STDOUT`.

Кілька прикладів:

```raku
42.put;
put 'Alpha', 'Beta';

my @array = 3, 4, 5;
put @array;

my %hash = a => 'b', c => 'd';
%hash.put;
```

Ось що виводить програма:

```console
$ raku t.raku
42
AlphaBeta
3 4 5
a	b
c	d
```

%%tipblock
## Новий рядок у `put`

`put` додає деякі символи після виводу. Ці символи вона бере з методу `nl-out` вихідного потоку. Його значення за замовчуванням — `\n`.
%%/tipblock
