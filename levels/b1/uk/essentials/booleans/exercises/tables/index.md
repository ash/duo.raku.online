## Завдання

Напишіть програму, яка виводить результати трьох булевих операцій. Вона має робити це для кожної комбінації `True` і `False`.

## Приклад

Ось приклад, який показує частину виводу.

```console
$ raku tables.raku
True && True is True
True && False is False
. . .
```
