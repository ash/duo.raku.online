З булевими значеннями можна виконувати всі стандартні операції. Це булеве І (AND), АБО (OR) та виключне АБО (його також називають XOR):

```raku
say False && True; # AND
say False || True; # OR
say False ^^ True; # XOR
```

Програма виводить такі результати:

    False
    True
    True

## Заперечення

Заперечення перетворює булеве значення на протилежне. Щоб заперечити значення, використовуйте префіксний оператор `!`:

```raku
say !False; # True
```

Булеві значення можна зберігати в скалярних змінних:

```raku
my $did = True;
my $didn't = !$did;
```
