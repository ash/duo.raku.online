У кожному розділі нижче виберіть відповідь, яка показує, що виводить програма.

## 1

Ось програма:

```raku
my $value = True && False;
say $value;
```

Що вона виводить?

{:.quiz}
0 | True
1 | False

## 2 

Що виводить друга програма?

```raku
my $value = True && False || True;
say $value;
```

{:.quiz}
1 | True
0 | False

## 3

Який результат цієї програми?

```raku
my $value = True || False && True;
say $value;
```

{:.quiz}
1 | True
0 | False

{% include quiz.html %}

## Коментарі

У другій і третій програмах є вирази з трьома булевими значеннями. Результат залежить від того, в якому порядку Raku виконує операції. Оператор `&&` має вищий пріоритет, ніж `||`, тому Raku виконує його першим.
