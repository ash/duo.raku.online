---
title: Ввід з `prompt`
---

{% include menu.html %}

Протилежністю до `say` є `prompt`. Він чекає, поки користувач щось введе і натисне Enter. Потім він передає введені дані програмі у вигляді рядка. Ви можете взяти результат `prompt` і передати його в `say`. Тоді програма повторює на екрані те, що вводить користувач. Давайте напишемо таку програму:

```raku
say prompt;
```

Якщо ви запустите цю програму, вона може вас заплутати. Програма лише чекає на якийсь ввід. Тому добре вивести для користувача повідомлення-підказку. Це робить програму зручнішою для користувача. Вам не потрібен окремий `say` для цього. Просто передайте повідомлення в `prompt`:

```raku
prompt 'Яку мову ви збираєтеся вивчати? '
```

Перш ніж закінчити цей розділ, давайте з'єднаємо всі частини. Ми створимо програму, яка питає, чого хоче користувач. Потім вона виводить фразу з текстом, який ввів користувач.

```raku
say 'Ви збираєтеся вивчати ', prompt 'Яку мову ви збираєтеся вивчати? ';
```

Якщо ви ввели `Raku`, програма виводить таку фразу:

    Ви збираєтеся вивчати Raku

Добре, тепер ми можемо спілкуватися з програмою. І можемо зробити так, щоб вона спілкувалася з нами!

Зверніть увагу, що `say` має знати рядки, перш ніж їх надрукувати. Тому Raku спочатку виконує `prompt`. Так діалог іде в правильному порядку:

```console
$ raku t.raku 
Яку мову ви збираєтеся вивчати? Raku
Ви збираєтеся вивчати Raku
```
