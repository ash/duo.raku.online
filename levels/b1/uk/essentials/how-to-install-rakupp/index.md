Raku++ доступний на своєму сайті, [raku.online](https://raku.online). Також його можна отримати з репозиторію на GitHub, [github.com/ash/rakupp](https://github.com/ash/rakupp). Після встановлення ви отримуєте один виконуваний файл під назвою `rakupp`. Більше нічого налаштовувати не треба, бо в Raku++ немає окремої віртуальної машини.

## Встановлювач

У macOS, Linux і системах BSD усе робить одна команда. Вона завантажує збірку для вашого комп'ютера і перевіряє її. Потім вона додає `rakupp` до вашого `PATH`. Права адміністратора для цього не потрібні:

```console
$ curl -fsSL https://raku.online/install.sh | sh
```

У Windows натомість використайте вікно PowerShell. Також можна скористатися майстром встановлення, `rakupp-setup-windows-x64.exe`. Він є на сторінці випусків репозиторію. У PowerShell виконайте таку команду:

```console
> irm https://raku.online/install-windows.ps1 | iex
```

Встановлювач запитає, чи потрібен вам Raku++ також під назвою `raku`. Потім відкрийте новий термінал, щоб новий `PATH` запрацював. Пізніше `rakupp upgrade` замінить його найновішим випуском.

## Інші способи встановлення

* У macOS, з Homebrew: `brew tap ash/rakupp && brew install rakupp`.
* З Docker нічого не треба встановлювати: `docker run --rm -it ghcr.io/ash/rakupp` запускає інтерактивну оболонку REPL.
* Готові архіви для кожної платформи є на сторінці випусків репозиторію.
* Raku++ написано мовою C++. Тож ви можете зібрати його й самостійно з вихідного коду. Репозиторій пояснює, які інструменти для цього потрібні.

## Номери версій

Опція `--version` показує, яка у вас версія:

```console
$ rakupp --version
Raku++ 5.4.1 (2026-10-13) arm64-darwin
```

Рядок показує випуск самого Raku++, `5.4.1`. Він також показує дату збірки і платформу для виконуваного файлу. Версія мови Raku — окрема річ. Ви можете запитати саму мову:

```console
$ rakupp -e 'say $*RAKU.version'
v6.d
```

Порівняйте це з повідомленням про версію Rakudo на [сторінці встановлення Rakudo](/uk/essentials/how-to-install-rakudo). Тоді ви побачите, як два компілятори представляють себе.
