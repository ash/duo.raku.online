Цей короткий розділ пояснює, як запустити програму всередині IDE. Він розглядає два найбільш рекомендовані [IDE](../../editors-and-ides).

## Редактор Visual Studio Code

Відкрийте термінал через меню `Terminal` → `New Terminal`. Це додає панель під текстом вашої програми. Запустіть програму там, так само як з командного рядка:

```console
$ raku hello.raku
```

## Comma IDE

Запускати програми можна з пункту меню `Run`. Налаштуйте IDE перед першим запуском програми. Дотримуйтесь [інструкцій](https://commaide.com/docs/running) на вебсайті Comma.
