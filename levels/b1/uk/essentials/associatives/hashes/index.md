_Хеш_ — це ще один асоціативний тип даних у Raku. Це агрегатний тип, який пов'язує ім'я кожного елемента з його значенням. Змінні-хеші використовують новий сигіл: `%`.

```raku
my %capitals;
```

Тепер ви можете використовувати хеш і дати йому кілька початкових значень.

```raku
%capitals = France => 'Paris', Italy => 'Rome';
```

Як і з іншими типами даних, ви можете зробити обидві дії за один крок:

```raku
my %capitals = France => 'Paris', Italy => 'Rome';
```

## Доступ до елементів

Індексація тут схожа на те, що ми бачили для [пар](../pairs). Напишіть рядок у кутових або у фігурних дужках:

```raku
say %capitals<France>;
say %capitals{'Italy'};
```

Хеші є змінними, тому ви можете змінювати наявні значення і додавати нові:

```raku
%capitals<Germany> = 'Berlin';
```

## Ключі та значення

Хеш має два вбудовані методи: `keys` і `values`. Вони повертають список його ключів і список його значень:

```raku
say %capitals.keys;
say %capitals.values;
```

Ось приклад того, що виводить ця програма:

    (Germany Italy France)
    (Berlin Rome Paris)

Зверніть увагу, що елементи хешу не мають жодного порядку. Але методи вище повертають ключі та значення в однаковому порядку.
