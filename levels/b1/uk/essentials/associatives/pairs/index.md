Пара — це структура даних, яка зберігає разом ім'я та значення. Вони утворюють один об'єкт, який ви можете зберігати в скалярній змінній. Ось як створити пару:

```raku
my $pair = name => 'Anna';
```

Тип змінної `$pair` — `Pair`:

```raku
say $pair.WHAT; # (Pair)
```

Ви можете отримати ім'я та значення окремо за допомогою методів `key` і `value`:

```raku
say $pair.key; # name
say $pair.value; # Anna
```

Важлива особливість пар у тому, що вони незмінні. Це означає, що ви не можете дати наявній парі нове значення чи нове ім'я. Але, звичайно, ви можете присвоїти зовсім нову пару тій самій змінній:

```raku
my $pair = name => 'Anna';
$pair = name => 'John';
say $pair.value; # John
```

## Індексування

Є ще один спосіб прочитати значення пари. Ви можете індексувати її іменем ключа в кутових дужках. Ось як це зробити:

```raku
say $pair<name>;
```

Зверніть увагу, що лапки навколо ключа не потрібні, якщо в ньому немає пробілів. Якщо пробіли є, правила трохи суворіші:

```raku
my $pair = 'employee name' => 'Julie Madelon';
say $pair{'employee name'};
```

Будьте уважні: цього разу ми використовуємо фігурні дужки.
