Програми Raku пишуть як звичайний текст. Зазвичай їх зберігають у текстових файлах. Винятки — це програми, які ви запускаєте онлайн або в командному рядку. Ще один виняток — код, який ви готуєте до запуску через `EVAL`. Є також кілька інших рідкісних випадків.

Вихідний код програми має бути текстом у кодуванні UTF-8. Тож підійде будь-який текстовий редактор, якщо він не зберігає форматування. Ви можете спокійно користуватися `vim`, `nano`, `emacs` або `mcedit`. Але, можливо, ви захочете спробувати кілька популярних нових програм.

## Зовнішні посилання

Ось посилання на популярні IDE.

* [Visual Studio Code](https://code.visualstudio.com/) — доступний для Windows, Mac OS та Linux
* [Comma](https://commaide.com) — IDE для Raku, створений спеціально для програмування на Raku. Він доступний для Windows, Mac OS та Linux.
