У Raku використовувати функції здебільшого легко, і проблем це не створює. Але ми маємо попередити вас про одну річ.

## Коротко

Не ставте пробіл між назвою функції та дужками з її аргументами. Але після `for` та `if` пробіл ставити треба.

## Детально

Візьмемо просту функцію:

```raku
sub f($x, $y) {
    return $x + $y;
}
```

Спершу зверніть увагу, що після назви функції немає пробілу. Відкривна дужка з параметрами йде одразу після назви. Деякі стилі коду в інших мовах можуть вимагати там пробіл. Raku це приймає, але так робити не варто:

```raku
sub f ($x, $y) {
    return $x + $y;
}
```

Коли ви викликаєте функцію, відсутність пробілу важлива. Якщо ви викликаєте функцію без дужок, після її назви має бути пробіл:

```raku
f 5, 6;
```

Але якщо ви використовуєте дужки, перед ними не може бути пробілу. Цей виклик правильний:

```raku
f(5, 6);
```

А цей виклик неправильний:

```raku
f (5, 6);
```

Такий код викликає виняток:

    Too few positionals passed; expected 2 arguments but got 1
      sub f at t.raku line 1
      in block <unit> at t.raku line 5

Raku бачить виклик із пробілом, `f (5, 6)`, інакше. Він думає, що ви хочете передати функції один аргумент, `(5, 6)`. Тип цього аргументу легко перевірити. Просто змініть функцію, щоб вона приймала лише один аргумент:

```raku
sub f($param) {
    say $param.WHAT;
}

f (5, 6); # (List)
```

Отже, коли ви викликаєте `f (5, 6)`, ви передаєте функції [список](/uk/essentials/positionals/lists). Список передається як одне ціле.

## Коли потрібен пробіл

У деяких випадках пробіл таки потрібен. Це буває, коли ви використовуєте дужки з ключовим словом, таким як `if`, `for` або `loop`. Наступний код неправильний:

```raku
if(True != False) {
    say 'OK';
}
```

Повідомлення про помилку пояснює проблему:

    ===SORRY!===
    The word 'if' is interpreted as a 'if()' function call.  Please use
    whitespace instead of parentheses.
    at /Users/ash/raku-course/t.raku:1
    ------> if⏏(True != False) {
    Unexpected block in infix position (two terms in a row)
    at /Users/ash/raku-course/t.raku:1
    ------> if(True != False)⏏ {

З `if` дужки взагалі не потрібні. Тож якщо ви їх не використовуєте, проблема не може з'явитися. Але в деяких випадках вони потрібні, наприклад, з `loop`. Тоді пробіл обов'язковий:

```raku
loop(my $c = 0; $c != 10; $c++) { say $c }
```

У цьому коді відбувається те саме: компілятор сприймає `loop(...)` як виклик функції. Додайте пробіл, щоб виправити проблему. Або, ще краще, перепишіть цю частину коду з `for`.

## Висновок

Коротко: щоб уникнути таких проблем, дотримуйтеся двох правил. Не ставте пробіл між назвою функції та дужками з її аргументами. Також намагайтеся уникати дужок в інших частинах мови, таких як керування потоком.
