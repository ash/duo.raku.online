---
title: Використання `elsif`
---

{% include menu.html %}

Досі ми вивчили `if` та `else`. Але що, якщо ви хочете зробити ланцюг тестів? У Raku є принаймні два способи це зробити. Насправді їх навіть більше.

Один зі способів — використати ланцюг блоків `if`, `elsif` та `else`. Зверніть увагу, як пишеться `elsif`. Це не `elseif` і не `else if`.

```raku
my $x = prompt 'Введіть число: ';
if $x > 100 {
    say "$x більше за 100.";
}
elsif $x > 50 {
    say "$x більше за 50.";
}
elsif $x > 25 {
    say "$x більше за 25.";
}
else {
    say "$x дорівнює 25 або менше.";
}
```

У цій програмі є три гілки і три тести, один за одним. Щойно одна з умов стає `True`, виконується відповідний блок коду. Якщо жодна з перевірок не є `True`, виконується блок `else`.

Ось кілька тестових запусків програми. Кожен блок виконується в одному з них:

```console
$ raku t.raku
Введіть число: 120
120 більше за 100.

$ raku t.raku
Введіть число: 75      
75 більше за 50.

$ raku t.raku
Введіть число: 30
30 більше за 25.

$ raku t.raku
Введіть число: 10
10 дорівнює 25 або менше.
```

Інший спосіб — використати пару [`given` та `when`](/uk/advanced/given-when), яку ми вивчимо пізніше.
