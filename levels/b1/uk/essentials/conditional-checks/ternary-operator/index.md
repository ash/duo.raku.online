title: Тернарний оператор
---

{% include menu.html %}

У Raku тернарний оператор має дві частини: `??` ... `!!`. Спочатку йде логічний тест, а за ним — два вирази. Виконується лише один з них, залежно від результату тесту.

```raku
my $shines = 'Sun';
my $day-time = $shines eq 'Sun' ?? 'day' !! 'night';
say $day-time;
```

З тим значенням, яке `$shines` має зараз, програма виводить `day`. Якщо змінити його на `Moon`, програма виведе `night`.

Тернарні вирази можна з'єднувати в ланцюжок. Тільки стежте, щоб код не став надто складним.

```raku
my $hours = 20;
my $day-time =
    $hours <= 6 ?? 'Night' !!
    $hours <= 12 ?? 'Morning' !! 
    $hours <= 18 ?? 'Afternoon' !! 'Evening';
say $day-time;
```

Тут програма виводить різну частину дня для різних значень `$hours`.
