---
title: Блоки `else`
---

{% include menu.html %}

Після блоку `if` може йти блок `else`. Raku виконує блок `else`, коли умова не справджується.

```raku
my $t = 36.6;
if 35.5 < $t < 37.5 {
    say 'У вас все добре.';
}
else {
    say 'Можливо, зверніться до лікаря?';
}
```

Ви не можете використовувати блок `else` сам по собі. Для цього є кращий варіант, який називається [`unless`](../unless). Ми розглянемо його вже за хвилину.
