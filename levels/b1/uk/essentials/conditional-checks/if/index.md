---
title: Блоки `if`
---

{% include menu.html %}

Умовна перевірка `if` дивиться на умову. Коли умова — `True`, виконується блок коду.

```raku
if 10 > 4 {
    say 'Математика працює!';
}
```

Зверніть увагу, що умову не потрібно брати в дужки. Але ви можете це зробити, якщо хочете.

Звісно, ви можете сміливо використовувати змінні в тестах:

```raku
my $flag = False;
if $flag {
    # . . . зробити щось
}
```

Якщо кілька перевірок використовують ту саму змінну, можна поставити порівняння в ланцюжок:

```raku
my $x = 42;
if 40 < $x < 45 {
    say "Правильна відповідь $x дана.";
}
```

Якщо умова не справджується, її блок коду не виконується. Потім програма продовжує роботу як звичайно.

```raku
say 'Початок';
if False {
    say 'Це ніколи не буде надруковано.';
}
say 'Кінець';
```

Ця програма просто друкує `Початок` і `Кінець`.
