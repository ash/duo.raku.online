---
title: Читання аргументів командного рядка
---

{% include menu.html %}

Функція `MAIN` чітко позначає початок програми, і це корисно. Але вона корисна ще й тому, що її аргументи отримують значення з командного рядка.

Ви можете читати аргументи командного рядка двома способами. Перший — це [масив `@*ARGS`](/uk/essentials/positionals/args-array), який ми вже використовували. Тепер давайте розглянемо другий спосіб.

Ось програма, яка додає два числа.

```raku
sub MAIN($a, $b) {
    say $a + $b;
}
```

Ось як можна запустити програму. Вона виводить суму двох своїх аргументів:

```console
$ raku t.raku 123 45
168
```

Як і будь-яка інша функція, `MAIN` може мати значення за замовчуванням для своїх аргументів. Це можливо для деяких із них або навіть для всіх. Наприклад:

```raku
sub MAIN($a, $b = 100) {
    say $a + $b;
}
```

Якщо ви не передаєте другий аргумент, програма використовує значення за замовчуванням:

```console
$ raku t.raku 15
115
```
