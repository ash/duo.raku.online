---
title: Використання `unit sub`
---

{% include menu.html %}

Конструкція `unit sub` дуже зручна. Вона робить решту файлу тілом функції! З `MAIN` вона дозволяє прибрати фігурні дужки навколо майже всього файлу. Також вам не потрібні зайві відступи.

Наступний приклад програми показує, як використовувати `unit sub`.

```raku
unit sub MAIN($a, $b);

my $sum = $a + $b;
say "Сума $a та $b дорівнює $sum.";
```

У цьому файлі `MAIN` — єдина функція. Якщо у вашій програмі так само, подумайте про використання `unit sub MAIN`, як показано вище.
