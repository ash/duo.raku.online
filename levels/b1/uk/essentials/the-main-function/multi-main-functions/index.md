---
title: Кілька функцій `MAIN`
---

{% include menu.html %}

Як і будь-яка інша функція в Raku, функція `MAIN` може мати варіанти `multi`. З ними програма може реагувати на кожен випадок по-своєму. Випадки можуть відрізнятися кількістю вхідних параметрів або їхніми типами.

```raku
multi sub MAIN($a) {
    say 2 * $a;
}

multi sub MAIN($a, $b) {
    say $a + $b;
}
```

Якщо аргумент лише один, ця програма його подвоює. Якщо є другий аргумент, програма складає обидва аргументи:

```console
$ raku t.raku 21
42

$ raku t.raku 21 33
54
```
