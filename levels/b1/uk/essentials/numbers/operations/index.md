Ви, напевно, вже знаєте деякі операції з числами в Raku. Просто зазначимо, що символ _операції_ називається _оператором_. Об'єкти, з якими працює операція, називаються _операндами_.

## Арифметика

**Оператор** | **Операція**
`+` | Додавання
`-` | Віднімання
`*` | Множення
`/` | Ділення

Оскільки Raku дуже добре [підтримує Unicode](/uk/essentials/on-unicode), деякі з цих операторів мають також не-ASCII версії:

`×` | Множення
`÷` | Ділення

Щоб змінити порядок, у якому виконуються операції, використовуйте дужки:

```raku
say 3 * 4 + 5;   # 17
say 3 * (4 + 5); # 27
```

## Модуль

Як і в багатьох інших мовах, оператор модуля — це `%`.

`%` | Модуль

Він повертає залишок від цілочисельного ділення двох чисел, тому `10 % 3` дорівнює `1`. Зверніть увагу, що `-10 % 3` дорівнює `2` через те, як визначена ця операція. Результат ділення округлюється вниз і множиться на друге число. Потім це значення віднімається від першого числа. Тож `$a % $b` означає те саме, що `$a - $b * floor($a / $b)`.

## Кратність

Raku додає ще один корисний оператор. Він перевіряє, чи ділиться одне число на інше.

`%%` | Кратність

Це інфіксний оператор: він стоїть між двома операндами, як у `10 %% 3`. Якщо перший операнд ділиться на другий, ви отримуєте булеве `True`. Інакше ви отримуєте `False`.

## Цілі операції

Деякі спеціальні операції повертають цілі числа як результат. Їхні оператори — це слова, а не символи.

`div` | Ціле ділення
`mod` | Цілий модуль

Оператор `div` округлює результат вниз. Тому `10 div 3` дорівнює `3`, а `-10 div 3` дорівнює `-4`.

І `div`, і `mod` очікують цілих операндів. Тому програма нижче не працюватиме, якщо розкоментувати рядки з позначкою `Error`:

```raku
say 10.3 % 3;     # OK
# say 10.3 mod 3; # Error

say 10.3 / 3.3;     # OK
# say 10.3 div 3.3; # Error
```

## Степінь

Піднести _x_ до степеня _y_ можна двома способами. По-перше, можна використати оператор `**`:

```raku
say 3 ** 4; # 81
```

По-друге, можна використати надрядкові цифри, тобто маленькі підняті цифри. Наприклад:

```raku
say 3⁴; # 81
```

Можна використати більше однієї надрядкової цифри, щоб отримати степінь, більший за 9. Наприклад:

```raku
say 2¹⁵; # 32768
```

Від'ємні степені теж не проблема:

```raku
say 2 ** (-2); ## 0.25
say 2⁻²; # 0.25
```

Зверніть увагу, що в останніх двох виразах результат — число типу `Rat`.

## Операції з присвоєнням

Коли потрібно оновити змінну, усі операції мають коротку форму. Покажемо це на прикладі `+`.

Повна форма

```raku
$a = $a + $b;
```

означає те саме, що:

```raku
$a += $b;
```
