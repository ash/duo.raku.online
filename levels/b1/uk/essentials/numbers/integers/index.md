title: Цілі числа

Тип даних `Int` призначений для цілих чисел, тобто чисел без дробової частини. Вони можуть бути додатними або від'ємними. Якщо хочете, можна додати знак `+`. Ось кілька очевидних прикладів:

```raku
42
-42
100
-5
0
```

Так, за замовчуванням Raku вважає звичайний `0` цілим числом.

## Групи цифр

У Raku є приємна можливість, яка допомагає писати великі числа. Цифри можна розділити на групи тисяч, щоб їх було легше читати:

```raku
1_000_000
-3_141_592
```

Можна створити число на зразок `34_56`, але краще цього не робити. Інших людей, які читають ваш код, це може заплутати. Але не можна ставити два підкреслення поруч. Також число не може починатися або закінчуватися підкресленням.

## Цілі числа будь-якої довжини

Raku без проблем працює з числами, що виходять за межі 32 або 64 біт. Наприклад, наступна програма правильна. Вона множить два великі цілі числа і виводить правильний результат.

```raku
say 1_234_456_789_012_345_678_901 * 987_654_321_098_765_432_100;
```
