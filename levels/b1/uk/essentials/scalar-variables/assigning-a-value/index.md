Щоб покласти нове значення в скалярний контейнер, використовуйте оператор `=`.

```raku
my $name;
$name = 'Анна';
```

Тепер ви можете використовувати змінну, наприклад, щоб вивести її:

```raku
say $name;
```

## Кілька змінних одразу

Ви можете присвоїти значення кільком змінним одночасно. Наприклад, ось як присвоїти значення двом скалярам в одному виразі:

```raku
my ($a, $b);
($a, $b) = 10, 20;
```

Зверніть увагу, що дужки з лівого боку пропустити не можна. Але ви можете додати їх і з правого боку, щоб обидва боки були однакові:

```raku
($a, $b) = (10, 20);
```
