title: Оператор defined-or

Так званий оператор _defined-or_ `//` допомагає, коли змінна ще не має значення. У такому разі він дає вам інше значення, яке можна використати замість нього.

```raku
my $a = 'alpha';
say $a // 'gamma';

my $b;
say $b // 'delta';
```

Ця програма виводить:

```
alpha
delta
```

Значення `$a` задано в першому рядку. Тому вираз `$a // 'gamma'` використовує поточне значення `$a`. А от змінна `$b` не отримала початкового значення. Тому `$b // 'delta'` повертає операнд з правого боку, і програма виводить `delta`.

## //=

Якщо поєднати `//` і `=`, ви отримаєте оператор `//=`. Він присвоює значення, лише якщо змінна не визначена.

```raku
my $x;
$x //= 42;
say $x; # 42
```
