Блоки коду — це частини вашої програми в парі фігурних дужок: `{` і `}`. Блок об'єднує кілька операторів, які працюють разом як один великий оператор. У наступних розділах ми побачимо багато способів використати блоки.

```raku
{
    say 'Hello, World!';
}
```

У цій програмі блок коду не має великого сенсу. Але блоки коду дуже корисні в інших ситуаціях, які ми дуже скоро побачимо.

Але спочатку давайте розглянемо ідею _області видимості_.
