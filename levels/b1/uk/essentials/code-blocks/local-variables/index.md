---
title: Локальні змінні
---

{% include menu.html %}

Давайте оголосимо змінну в глобальній області видимості. Що станеться, якщо ми також оголосимо її локально в блоці?

```raku
my $x = 1;

{
    my $x = 42;
    say $x;
}

say $x;
```

Тепер у програмі є дві окремі змінні. Обидві називаються `$x`. У глобальній області видимості `$x` завжди означає глобальну змінну. Але всередині блоку `$x` — це інша, локальна змінна. Програма виводить два різні значення:

```console
$ raku t.raku
42
1
```
