---
title: Лексична область видимості
---

{% include menu.html %}

Блок коду створює так званий лексичний обсяг. Якщо ви оголошуєте змінну в блоці, вона видима всередині блоку. Але вона не видима після того, як програма вийде з блоку. Ось приклад:

```raku
{
    my $x = 42;
    say $x;
}

say $x;
```

Змінна `$x` створюється в блоці коду. Перший `say $x` виводить її значення, тому що змінна видима всередині блоку. Другий `say $x` не спрацьовує, тому що імені `$x` поза блоком не існує. Коли блок закінчився, це ім'я вже невідоме. Програма не компілюється, і ви отримуєте помилку:

    ===SORRY!=== Error while compiling /Users/ash/raku-course/t.raku
    Variable '$x' is not declared
    at /Users/ash/raku-course/t.raku:6
    ------> say ⏏$x;
