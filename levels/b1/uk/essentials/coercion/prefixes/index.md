---
title: Перетворення типів за допомогою префіксних операторів
---

{% include menu.html %}

Ще один спосіб змінити тип об'єкта — використати префіксні оператори. Це оператори лише з одного символу. Ви ставите їх одразу перед значенням (або змінною).

`~` | Приведення до рядка
`+` | Числове приведення
`?` | Логічне приведення

Ось приклад, який створює логічне значення з цілого числа:

```raku
say ?42; # True
```

Перетворення до рядка виглядає схоже:

```raku
my $n = -30;
my $s = ~$n;
say $s.chars; # 3, оскільки "-30" має 3 символи
```

Зверніть увагу, що при перетворенні на число тип результату залежить від числа. Порівняйте такі перетворення з рядків:

```raku
say (+'100').WHAT;   # (Int)
say (+'3.14').WHAT;  # (Rat)
say (+'27E-1').WHAT; # (Num)
```

Для перетворення на логічне значення можна також використати процедуру під назвою `so`. Вона працює як префіксний оператор або як метод:

```raku
my $value = 42;
say so $value; # True
say $value.so; # True
```
