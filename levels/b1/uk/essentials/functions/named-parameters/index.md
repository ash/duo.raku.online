На відміну від [позиційних параметрів](../positional-parameters), _іменовані_ параметри розрізняють за їхніми іменами.

Ця функція має два параметри з іменами `$from` і `$to`.

```raku
sub distance(:$from, :$to) { $from - $to }
```

Щоб викликати цю функцію, ви маєте написати імена аргументів:

```raku
say distance(from => 30, to => 10); # 20
```

Якщо ви передасте аргументи так, ніби вони позиційні, ви отримаєте помилку. Наприклад, виклик `distance(30, 10)` спричиняє помилку:

    Занадто багато позиційних аргументів; очікувалося 0 аргументів, але отримано 2
        в підпрограмі distance на рядку 1 у файлі t.raku
        в блоці <unit> на рядку 2 у файлі t.raku

Добре те, що іменовані аргументи можна перелічувати в будь-якому порядку. Наступні два виклики абсолютно однакові:

```raku
say distance(from => 30, to => 10); # 20

say distance(to => 10, from => 30); # 20
```

## Передача змінних

Іноді значення, яке ви хочете передати, зберігається у змінній. Ця змінна може ще й мати те саме ім'я, що й параметр. Тоді ви можете скористатися спеціальним синтаксисом, з яким треба менше друкувати:

```raku
my $from = 30;
my $to = 10;
say distance(:$from, :$to); # 20
```

Це схоже на довший виклик:

```raku
say distance(from => $from, to => $to); # 20
```

І знову, порядок тут не має значення:

```raku
say distance(:$to, :$from); # 20
```

Якщо імена змінної і параметра різні, передайте пару. Використайте один із цих способів:

```raku
my $a = 20;
my $b = 10;

say distance(from => $a, to => $b);

# або:

say distance(:from($a), :to($b));
```
