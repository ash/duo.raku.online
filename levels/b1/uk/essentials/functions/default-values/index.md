І позиційні, і іменовані параметри можуть мати значення за замовчуванням. Якщо параметр має значення за замовчуванням, його можна пропустити у виклику функції.

## Позиційні параметри

Ось приклад значення за замовчуванням для позиційного параметра:

```raku
sub greet($name = 'World') {
    say "Hello, $name!";
}

greet('Merinda');
greet();
```

У першому виклику ім'я — єдиний аргумент, тому результат — `Hello, Merinda!`. Другий виклик використовує значення за замовчуванням і виводить `Hello, World!`.

Якщо функція має кілька параметрів, значення за замовчуванням можуть мати лише останні з них:

```raku
sub f($a, $b, $c = 42, $d = 50) { . . . } # правильно
# sub f($a = 10, $b = 20, $c, $d) { . . . } # НЕПРАВИЛЬНО
```

## Іменовані параметри

Ви задаєте значення за замовчуванням для іменованих параметрів тим самим синтаксисом:

```raku
sub greet(:$name = 'World') {
    say "Hello, $name!";
}

greet(name => 'Merinda'); # Hello, Merinda!
greet(); # Hello, World!
```

Порядок іменованих параметрів не має значення. Тому будь-який з них може мати значення за замовчуванням, навіть перший:

```raku
sub greet(:$greeting = 'Hello', :$name) {
    say "$greeting, $name!";
}

greet(name => 'Alla'); # Hello, Alla!
```
