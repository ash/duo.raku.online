---
title: Позиційні параметри
---

{% include menu.html %}

Порядок параметрів функції має значення. Наприклад, створимо функцію, яка обчислює різницю між двома числами:

```raku
sub diff($a, $b) { $a - $b }
```

Зрозуміло, що виклик `diff(10, 20)` дає інший результат, ніж `diff(20, 10)`.

Параметри у списку через кому, як у функції вище, називаються _позиційними_. Їхнє значення залежить від порядку аргументів, коли ви викликаєте функцію.
