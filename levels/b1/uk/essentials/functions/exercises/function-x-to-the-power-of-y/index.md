## Завдання

Створіть функцію з двома аргументами, яка повертає `$x` у степені `$y`. Потім напишіть програму, яка виводить значення `5³`, `2¹⁰` і `(−4)⁵`.

## Приклад

Для цих значень програма має вивести:

```
$ raku function-x-to-the-power-of-y.raku
125
1024
-1024
```
