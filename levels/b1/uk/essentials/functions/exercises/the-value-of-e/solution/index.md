## Застереження

У Raku є вбудована стала `e`. Вона одразу дає відповідь на це завдання. Рішення нижче — просто для навчання.

## Код

Формула в цьому завданні містить факторіал. У нас уже є щонайменше два способи його обчислити, і далі буде більше. Програма нижче визначає дві функції. Одна обчислює факторіал, а друга — часткову суму формули.

Функція має працювати й без аргументів. У такому разі цикл виконується наперед задану кількість разів. Тому ми можемо дати параметру [значення за замовчуванням](/uk/essentials/functions/default-values): `sub e-approx($max = 100)`.

Зверніть увагу, що в коді обидві функції накопичують результати схожим способом. Вони використовують [постфіксний цикл `for`](/uk/essentials/loops/postfix-for) по [діапазону](/uk/essentials/ranges).

Ось рішення:

```raku
sub factorial($n) {
    my $f = 1;
    $f *= $_ for 1..$n;

    return $f;
}

sub e-approx($max = 100) {
    my $e = 1;
    $e += 1 / factorial($_) for 1..$max;

    return $e;
}

say e-approx(10);
say e-approx();
```

🦋 Знайдіть програму у файлі [the-value-of-e.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/functions/the-value-of-e.raku).
