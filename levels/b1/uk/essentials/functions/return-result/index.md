Функції часто щось роблять і також повертають результат. Наприклад, у функціональному програмуванні функції не повинні мати побічних ефектів. Виведення на консоль — саме такий побічний ефект. Але Raku не забороняє вам це робити. Давайте подивимося, як функція повертає значення. Ми також побачимо, як його отримує код, що викликає функцію.

```raku
sub add($x, $y) {
    return $x + $y;
}

my $sum = add(10, 20);
say $sum; # 30
```

Тут функція `add` приймає два числа і повертає їхню суму. Вона використовує явне `return`. Код, що викликає функцію, може використовувати повернене значення як будь-яке інше. У програмі вище його присвоюють змінній.

## Останнє обчислене значення

У Raku явне `return` потрібне не завжди. Його можна пропустити, коли результат — це останнє значення, яке обчислює функція. Тож наша функція `add` може бути простішою:

```raku
sub add($x, $y) {
    $x + $y
}
```

Ви могли помітити, що в кінці рядка немає крапки з комою. Вона не потрібна, бо цей рядок завершує блок коду.

Такі маленькі й прості функції часто записують в один рядок. Так код стає компактнішим:

```raku
sub add($x, $y) { $x + $y }
```

## Відсутність даних для повернення

Іноді вам потрібно повернутися з функції до кінця її тіла. Якщо функція не повертає жодного результату, використовуйте `return` саме по собі.

```raku
sub test($x) {
    return if $x <= 10;
    say "$x перевищує ліміт";
}
```
