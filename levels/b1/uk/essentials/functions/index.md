Тепер ви в останньому розділі першої частини курсу. Після нього ви знатимете достатньо, щоб написати майже _будь-яку_ програму на Raku. Тема цього розділу — _функції_. Їх також називають _підпрограмами_ або просто _рутинами_.

Функція — це частина коду з ім'ям, яку можна використовувати багато разів. Ви можете _викликати_ функцію з різних місць програми.

## Створення функції

Щоб створити функцію, напишіть ключове слово `sub`, а потім ім'я функції. Тіло функції стоїть усередині пари фігурних дужок.

```raku
sub greet {
    say 'Hello, World!';
}
```

## Використання функції

Щоб використати функцію, просто напишіть її ім'я там, де хочете її викликати. У Raku визначення функції може стояти перед викликом або після нього.

```raku
say 'This is what the first program usually prints:';
greet;    

sub greet {
    say 'Hello, World!';
}
```

Програма виведе обидва повідомлення:

```console
$ raku t.raku
This is what the first program usually prints:
Hello, World!
```

Тепер ми розглянемо більше деталей про те, як створювати та використовувати функції.
