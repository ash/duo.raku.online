Тепер час передати функції деякі дані. Функція може приймати параметри, які ви перелічуєте в дужках одразу після її назви.

```raku
sub greet($name) {
    say "Hello, $name!";
}
```

Тепер ви можете використовувати функцію і передавати їй різні аргументи:

```raku
greet('Алла');
greet('Карл');
```

Тепер два виклики тієї самої функції дають різні результати:

```console
$ raku t.raku
Hello, Алла!
Hello, Карл!
```

%%tipblock

## Параметр чи аргумент

Люди часто вживають ці два терміни так, ніби вони означають одне й те саме. Обидва стосуються «одного й того самого», але з різних точок зору.

* Параметр — це те, що очікує функція.
* Аргумент — це те, що ви передаєте їй.

У прикладі вище `$name` — це параметр функції. Її аргументи — `'Алла'` і `'Карл'`.

%%/tipblock

## Більше параметрів

Функція може приймати більше ніж один параметр. У цьому випадку перелічіть їх усі через кому:

```raku
sub add($x, $y) {
    say $x + $y;
}

add(10, 20); # 30
```

## Без параметрів

Функція може зовсім не приймати параметрів, і це нормально. Тоді ви можете або додати порожню пару дужок, або зовсім їх пропустити. Ми пропустили їх на [початку цього розділу](../).

```raku
sub greet() {
    say 'Hello, World!';
}

greet();
```

## Підпис

Список параметрів функції називається _підписом_.
