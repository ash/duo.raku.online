Ось один із можливих розв'язків.

## Код

```raku
say 2 ** (3 + 1);
```

🦋 Вихідний код можна знайти у файлі [force-the-order.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operators-overview/force-the-order.raku).

## Вивід

```
16
```

## Коментарі

1. Без дужок `**` зв'язувався б міцніше за `+`, і ви отримали б `(2 ** 3) + 1 = 9`.

1. Дужки підвищують пріоритет додавання, тож `3 + 1` обчислюється першим. Вираз стає `2 ** 4`, тобто `16`. За допомогою дужок ви завжди можете змінити типовий пріоритет.
