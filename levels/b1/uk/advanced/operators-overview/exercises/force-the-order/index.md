## Завдання

Оператор `**` зв'язується міцніше за `+`, тож `2 ** 3 + 1` означає `(2 ** 3) + 1`, тобто `9`. Додайте дужки, щоб змінити цей порядок і щоб додавання відбулося *першим*. Потім виведіть результат.

## Приклад

Програма виводить:

```
16
```
