Ось один із можливих розв'язків.

## Код

```raku
say 0 <= 73 <= 100;
```

🦋 Вихідний код можна знайти у файлі [chained-comparison.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operators-overview/chained-comparison.raku).

## Вивід

```
True
```

## Коментарі

1. Оператори порівняння можна об'єднувати в ланцюжки. Тож `0 <= 73 <= 100` означає «0 не більше за 73, і 73 не більше за 100». Оператор `<=` дозволяє крайні значення. Тож бал рівно `0` чи `100` теж був би дійсним.

1. Обидві частини істинні, тож увесь вираз дає `True`. Зверніть увагу, що середнє значення `73` ви пишете лише раз. Проте його порівнюють з обома сусідами.

1. Без ланцюжка довелося б виписати обидва порівняння й з'єднати їх через `&&`. Тоді ви повторюєте середнє значення: `0 <= 73 && 73 <= 100`. Форма з ланцюжком каже те саме коротше.
