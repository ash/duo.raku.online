Коли вираз має кілька операторів, Raku має вирішити, в якому порядку їх застосовувати. Цим керують два правила: _пріоритет_ і _асоціативність_.

## Пріоритет

Пріоритет вирішує, який оператор сильніший, тобто який зв'язується міцніше. Множення має вищий пріоритет, ніж додавання, тож воно виконується першим:

```raku
say 2 + 3 * 4; # 14
```

Raku читає вираз як `2 + (3 * 4)`, тож результат — `14`, а не `20`. Ви завжди можете поставити дужки, щоб отримати інший порядок:

```raku
say (2 + 3) * 4; # 20
```

## Асоціативність

Асоціативність вирішує порядок, коли оператори мають _однаковий_ пріоритет. Віднімання лівоасоціативне, тобто воно групується зліва:

```raku
say 8 - 3 - 2; # 3
```

Це `(8 - 3) - 2`, що дає `3`. А от піднесення до степеня, навпаки, правоасоціативне:

```raku
say 2 ** 3 ** 2; # 512
```

Тут вираз групується як `2 ** (3 ** 2)`. Тобто це `2 ** 9`, що дає `512`.

## Ланцюжки порівнянь

Оператори порівняння можна об'єднувати в _ланцюжки_. Це читається природно й працює так, як ви чекаєте з математики:

```raku
say 1 < 2 < 3; # True
say 1 < 5 < 3; # False
```

Середнє значення порівнюється зі значеннями з обох боків від нього. Тож `1 < 2 < 3` істинне, бо істинні і `1 < 2`, і `2 < 3`.
