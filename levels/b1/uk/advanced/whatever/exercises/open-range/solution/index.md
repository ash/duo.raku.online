Ось один із можливих розв'язків.

## Код

```raku
say (2, 4 ... *).head(4);
```

🦋 Вихідний код можна знайти у файлі [open-range.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/whatever/open-range.raku).

## Вивід

```
(2 4 6 8)
```

## Коментарі

1. Початкові значення `2, 4` задають арифметичний крок: кожне нове число на два більше. Зірочка `*` сама по собі в кінці означає, що послідовність ніколи не закінчується.

1. `head(4)` бере лише перші чотири значення, `2, 4, 6, 8`. Послідовність лінива, тож нескінченний залишок ніколи не обчислюється. Тут зірочка сама по собі означає «як завгодно, без верхньої межі».
