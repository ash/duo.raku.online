Послідовності не треба обчислювати всі свої значення одразу. Послідовності Raku є _лінивими_: кожне значення створюється лише тоді, коли воно справді потрібне. Тож можна описати послідовність, яка зовсім не має кінця.

Щоб записати нескінченну послідовність, використайте `Inf` як кінцеву точку. Оператор `...` зв'язується слабше за `=`, тож Raku спершу виконав би `=`. Тому ви берете послідовність у дужки:

```raku
my $naturals = (1 ... Inf);
```

Без дужок `my $naturals = 1 ... Inf` присвоїло б змінній лише `1`. Потім воно побудувало б послідовність окремо. Обчислення нескінченної послідовності, яку ніхто не використовує, змусило б програму зависнути.

На цей момент нічого не обчислено. Послідовність видає значення лише тоді, коли ви їх просите. Метод `head` бере кілька перших із них:

```raku
say (1 ... Inf).head(5); # (1 2 3 4 5)
```

Послідовність нескінченна, але створюються лише перші п'ять чисел. Без лінивості програма спробувала б побудувати всю нескінченну послідовність. Така програма ніколи б не закінчилася.

Якщо послідовність скінченна, метод `tail` може натомість брати значення з її кінця:

```raku
say (1 ... 100).tail(3); # (98 99 100)
```

Лінивість дозволяє розділити дві речі. Перша — це _опис_ послідовності. Друга — це рішення про те, скільки з неї використати.
