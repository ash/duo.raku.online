Що виведе наведена програма?

```raku
say q{a\nb};
```

{:.quiz}
1 | a\nb
0 | a<новий рядок>b
0 | ab
0 | anb

{% include quiz.html %}

<div class="extended-explanation">

Оператор `q` працює як одинарні лапки. Він не обробляє екрановані послідовності, такі як `\n`. Рядок зберігає всі чотири символи: `a`, `\`, `n` і `b`. Лише інтерполювальна форма, як-от `qq` чи подвійні лапки, перетворює `\n` на справжній перехід рядка.

</div>
