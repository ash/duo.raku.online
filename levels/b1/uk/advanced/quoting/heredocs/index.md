_Heredoc_ — це форма цитування для тексту з кількох рядків. Він не використовує роздільників навколо тексту. Натомість ви вказуєте слово-термінатор через `:to`. Рядок починається з наступного рядка коду. Він триває до рядка, який містить лише це слово:

```raku
my $text = q:to/END/;
Hello,
World!
END

print $text;
```

Програма виводить:

```
Hello,
World!
```

Термінатор позначає, де закінчується текст. Тут це `END`, але підійде будь-яке слово. Зверніть увагу на `print`. Текст зберігає перехід рядка перед термінатором. Тож він уже закінчується розривом рядка. Із `say` ви отримали б другий розрив і порожній рядок у кінці. Heredoc починається з `q:to`, тож текст не інтерполюється. Щоб інтерполювати змінні, використовуйте `qq:to`:

```raku
my $name = 'Anna';

my $greeting = qq:to/EOF/;
Dear $name,
Welcome!
EOF

print $greeting;
```

Ось корисна деталь. **Відступ закривального термінатора** прибирається з кожного рядка тексту. Тож heredoc можна зробити з відступом, як у коді навколо. Цей відступ не потрапляє в рядок:

```raku
sub greeting {
    return q:to/END/;
        Hello,
        World!
        END
}

print greeting;
```

Це виводить ті самі `Hello,` та `World!`, що й у першому прикладі. Тут закривальне `END` має відступ у вісім пробілів. Тож із кожного рядка прибирається вісім пробілів. Повернений рядок — просто `Hello,\nWorld!`, без пробілів на початку рядків.

Закривальний термінатор задає, скільки пробілів прибирається. Тож кожен рядок тексту мусить мати щонайменше такий відступ. Якщо на початку рядка менше пробілів, Raku не може прибрати всю кількість. Тоді він попереджає: *Asked to remove 8 spaces, but the shortest indent is 4 spaces*. Щоб цього уникнути, не робіть термінатору глибший відступ, ніж у рядка з найменшим відступом. Heredoc-и — природний вибір для шаблонів, повідомлень і будь-якого тексту з кількох рядків.
