Raku має фазери для всієї програми, але має й інші. Ці фазери прив'язані до життя окремого блоку або циклу.

## Входження та вихід з блоку

Фазер `ENTER` запускається щоразу, коли програма входить у блок. Фазер `LEAVE` запускається щоразу, коли вона виходить з блоку. Не має значення, на якому рядку ви їх пишете:

```raku
say 'before block';
{
    LEAVE say 'leaving';
    ENTER say 'entering';
    say 'inside';
}
say 'after block';
```

Вивід показує, що `ENTER` запускається першим, а `LEAVE` — останнім. Тіло блоку виконується між ними:

```
before block
entering
inside
leaving
after block
```

`LEAVE` особливо корисний, бо він запускається, навіть якщо блок закінчується раніше. Тому це надійне місце, щоб звільнити ресурс.

Фазер може приймати повний блок `{ }` замість одного оператора. Ви також можете мати кілька фазерів. Коли блок має більше одного `LEAVE`, вони запускаються у зворотному порядку. Той, який налаштували останнім, запускається першим. Тож блок працює як стек, згори донизу:

```raku
say 'open A';
{
    LEAVE {
        say 'close A';
    }
    say 'open B';
    LEAVE {
        say 'close B';
    }
    say 'work';
}
say 'done';
```

Програма відкриває ресурс `A` першим і закриває його останнім:

```
open A
open B
work
close B
close A
done
```

Порядок «останнім прийшов — першим пішов» — саме те, що потрібно для очищення. Те, що ви налаштували останнім, прибирається першим. Фазер `END` усієї програми працює так само. Кілька блоків `END` теж запускаються в порядку, зворотному до того, у якому їх написано.

## Фазери циклу

Усередині циклів є ще три фазери для етапів циклу. `FIRST` запускається один раз перед першим проходом, а `LAST` — один раз після останнього. `NEXT` запускається наприкінці кожного проходу:

```raku
for 1..3 {
    FIRST say '-- first';
    LAST  say '-- last';
    NEXT  say "-- next (was $_)";
    say "body $_";
}
```

Ось вивід циклу:

```
-- first
body 1
-- next (was 1)
body 2
-- next (was 2)
body 3
-- next (was 3)
-- last
```

Як і інші фазери, `FIRST`, `NEXT` і `LAST` можуть стояти будь-де в коді. Кожен із них запускається у свій момент.
