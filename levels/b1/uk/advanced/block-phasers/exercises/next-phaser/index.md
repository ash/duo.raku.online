## Задача

Фазер `NEXT` запускається *наприкінці* кожного проходу циклу. Це вдалий момент, щоб повідомити про прогрес.

Тримайте в `$sum` суму, яка росте під час роботи циклу. Вона починається з `0`. Пройдіть циклом по `1..3` і на кожному проході спочатку додайте поточне число до `$sum`. Потім використайте фазер `NEXT`, щоб друкувати `sum so far: $sum` після кожного проходу.

Зверніть увагу на порядок. Фазер `NEXT` запускається після тіла. Тож сума, яку він показує, *включає* поточне число.

## Приклад

Програма виводить:

```
sum so far: 1
sum so far: 3
sum so far: 6
```
