У частині «Основи» ви використовували `MAIN`, [щоб отримувати аргументи командного рядка](/uk/essentials/the-main-function/reading-command-line-arguments). Але з `MAIN` Raku робить для вас більше, ніж просто передає значення.

## Повідомлення про використання

Іноді аргументи командного рядка не підходять до сигнатури `MAIN`. У такому разі Raku не виконує тіло. Натомість він виводить _повідомлення про використання_, яке Raku створює автоматично. Повідомлення пояснює, як викликати програму.

Погляньте на таку програму:

```raku
sub MAIN($name) {
    say "Hello, $name!";
}
```

Якщо викликати її правильно, вона вітає людину:

```console
$ raku hello.raku Anna
Hello, Anna!
```

Якщо викликати її без аргументу, сигнатура не збігається. Тож Raku виводить повідомлення про використання замість привітання:

```console
$ raku hello.raku
Usage:
  hello.raku <name>
```

Raku будує повідомлення з імен параметрів. Тож дайте їм зрозумілі імена, і корисний текст довідки ви отримаєте задарма.

## Іменовані аргументи

Параметри `MAIN` можуть бути не лише позиційними, а й іменованими. Іменований параметр стає опцією командного рядка, як-от `--option=value`. Якщо в нього є типове значення, опція не обов'язкова:

```raku
sub MAIN(:$name = 'World') {
    say "Hello, $name!";
}
```

```console
$ raku hello.raku
Hello, World!

$ raku hello.raku --name=Raku
Hello, Raku!
```
