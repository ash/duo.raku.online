Окрім масивів і хешів, у Raku є кілька особливих контейнерів для наборів значень. Найпростіший — `Set`. Це набір _різних_ значень без певного порядку. Кожне значення або є в множині, або ні, а повторені значення ігноруються.

Ви створюєте множину підпрограмою `set`. Якщо значення повторюється, множина зберігає лише одну його копію:

```raku
my $s = set(1, 2, 3, 2, 1);
say $s.elems; # 3
```

Ми передали п'ять чисел, але множина має лише три елементи. Це тому, що `1` і `2` траплялися більше ніж один раз.

Головне запитання, яке ви ставите множині, — чи є в ній значення. Оператор `∈`, який читають як «є елементом», повертає булеве значення:

```raku
say 2 ∈ set(1, 2, 3); # True
say 9 ∈ set(1, 2, 3); # False
```

Якщо ви хочете залишатися в межах простого ASCII, пишіть той самий оператор як `(elem)`:

```raku
say 2 (elem) set(1, 2, 3); # True
```

Далі ви побачите, як поєднувати множини. Ви також познайомитеся з мультимножинами й сумішами, які є близькими родичами множин.
