Підпрограму можна визначити _всередині_ іншої підпрограми. Така вкладена підпрограма — звичайна підпрограма. Але її видно лише всередині тієї підпрограми, яка її містить.

```raku
sub outer {
    sub inner {
        say 'I am the inner subroutine';
    }

    inner;
}

outer;
```

Програма виводить:

```
I am the inner subroutine
```

Тут `inner` оголошено всередині `outer`, і `outer` її викликає. Це працює, бо `inner` можна використовувати будь-де в тілі `outer`.

Але за межами `outer` немає імені `inner`. Тож наступна програма не компілюється:

```raku
sub outer {
    sub inner { 42 }
}

inner; # помилка: Undeclared routine: inner
```

Вкладення корисне, коли допоміжна підпрограма потрібна лише одній підпрограмі. Якщо тримати помічника всередині, видно, що це приватна деталь. Крім того, ніхто не зможе випадково викликати його звідкись іще.
