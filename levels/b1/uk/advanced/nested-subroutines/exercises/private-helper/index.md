## Завдання

Напишіть підпрограму `stats` із **вкладеною** допоміжною підпрограмою `double` усередині. Помічник повертає свій аргумент, помножений на два. Усередині `stats` скористайтеся помічником, щоб вивести значення `double(3) + double(5)`.

Потім викличте `stats`.

## Приклад

Програма виводить:

```
16
```
