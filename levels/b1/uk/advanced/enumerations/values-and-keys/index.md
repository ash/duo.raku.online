Кожна константа перелічення має і ім'я, і число. Метод `.value` повертає число, а `.key` повертає ім'я як рядок:

```raku
enum Colour <red green blue>;

say green.value; # 1
say green.key;   # green
```

Вам не обов'язково використовувати автоматичні числа від нуля. Щоб обрати значення самостійно, запишіть константи як пари:

```raku
enum Day (Mon => 1, Tue => 2, Wed => 3, Thu => 4, Fri => 5);

say Tue.value; # 2
say Fri.value; # 5
```

Тут робочий тиждень починається з одиниці замість нуля.

Тип перелічення може й сам перелічити всі свої константи. Його метод `.enums` повертає відображення, яке пов'язує кожне ім'я з його значенням:

```raku
enum Colour <red green blue>;

say Colour.enums;       # Map.new((blue => 2, green => 1, red => 0))
say Colour.enums.elems; # 3
```

Ці три методи, `.value`, `.key` і `.enums`, дозволяють вільно рухатися. Можна перейти від константи до її числа і від числа назад до даних. Також можна працювати з усім набором. Саме це робить перелічення корисними для таких речей, як меню, стани й таблиці пошуку.
