Щоб оголосити перелічення, напишіть ключове слово `enum`, ім'я та список імен констант:

```raku
enum Colour <red green blue>;
```

Тепер є новий тип `Colour` із трьома константами: `red`, `green` і `blue`. Кожну константу можна використовувати прямо за її іменем:

```raku
say red;   # red
say green; # green
```

За кожним іменем стоїть число. Raku дає ці числа автоматично, від нуля, у порядку вашого списку. Тож `red` — це `0`, `green` — `1`, а `blue` — `2`. Оскільки значення мають порядок, константи можна порівнювати:

```raku
say red < blue; # True
```

Змінній можна дати перелічення як тип. Тоді вона приймає лише ці константи:

```raku
my Colour $c = green;
say $c; # green
```

Ім'я константи може збігатися з іншим іменем у вашій програмі. Тоді до константи завжди можна звернутися через ім'я перелічення та `::`:

```raku
say Colour::red; # red
```

Перелічення дає групі пов'язаних констант ім'я та тип. Код, який їх використовує, набагато зрозуміліший за код зі звичайними числами. Наступна тема розглядає [числа, що стоять за іменами](/uk/advanced/enumerations/values-and-keys).
