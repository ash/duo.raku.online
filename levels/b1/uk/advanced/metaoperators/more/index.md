Окрім згортки та zip, у Raku є ще кілька метаоператорів. Три з них корисно знати вже зараз.

## Перехресний — `X`

Перехресний метаоператор `X` бере два списки. Він складає в пару **кожен** елемент одного списку з **кожним** елементом іншого. Це називають декартовим добутком:

```raku
say <a b> X <1 2>; # ((a 1) (a 2) (b 1) (b 2))
```

Як і zip, він може огортати оператор, який тоді працює з кожною парою. `X~` з'єднує кожну пару в рядок, а `X*` перемножує значення:

```raku
say <a b> X~ <1 2>;         # (a1 a2 b1 b2)
say (1, 2, 3) X* (10, 100); # (10 100 20 200 30 300)
```

Zip іде по двох списках поруч, а перехресний оператор поєднує їх усіма можливими способами.

## Гіпер — `»…«`

Гіпероператор застосовує оператор до **кожного елемента** списку. Оператор стоїть усередині кутових дужок `»…«` або їхньої ASCII-форми `>>…<<`. З двома списками він працює поелементно, як zip. Якщо з одного боку лише одне значення, він розтягує це значення на весь список:

```raku
say (1, 2, 3) »+» (10, 20, 30); # (11 22 33)
say (1, 2, 3) »*» 2;            # (2 4 6)
```

Дві стрілки не мусять дивитися в один бік. Їхній напрямок вирішує, що станеться, коли списки мають різну довжину. Якщо стрілка дивиться **на** список, цей список може повторюватися, щоб зрівнятися з іншим. Ось чотири варіанти, записані в ASCII з `<<` і `>>`:

* `>>op<<` — жоден список не повторюється, тож списки вже мають бути однакової довжини, інакше буде помилка;
* `>>op>>` — **правий** список повторюється, щоб зрівнятися з лівим;
* `<<op<<` — **лівий** список повторюється, щоб зрівнятися з правим;
* `<<op>>` — **коротший** список повторюється, щоб зрівнятися з довшим.

```raku
say (1, 2, 3, 4) <<+>> (10, 20); # (11 22 13 24)  — 10, 20 повторюється як 10, 20, 10, 20
```

Є й унарна форма, лише з одним операндом. Вона викликає метод для кожного елемента. `>>.uc` переводить кожен рядок у верхній регістр:

```raku
say <raku perl>>>.uc; # (RAKU PERL)
```

Гіпероперації також показують, що роботу *можна* виконати паралельно. Пізніше ви побачите схожий метод `.hyper` у [розділі про конкурентне програмування](/uk/paradigms/hyper-race).

## Заперечний — `!`

Якщо поставити `!` перед оператором порівняння, ви отримаєте протилежний результат. Знайомий вам `!=` (не дорівнює) — це саме цей метаоператор разом із `==`. Так само це працює для інших булевих операторів, як-от `eq` і `%%`:

```raku
say 3 != 4;      # True
say 'a' !eq 'b'; # True  — не рівні як рядки
say 5 !%% 2;     # True  — 5 не ділиться на 2
```

Коротко кажучи, `$a !op $b` — це просто охайніший спосіб записати `!($a op $b)`.

Так задумано. Деякі мови, як-от есперанто, навмисно малі й прості. Вони намагаються мати один правильний спосіб сказати кожну річ. Raku інший і охоче дає вам кілька способів. Тому заперечний `!eq` існує поруч зі спеціальним оператором `ne`. Обидва означають точно те саме:

```raku
say 'a' ne 'b'; # True — та сама перевірка, що й 'a' !eq 'b'
```
