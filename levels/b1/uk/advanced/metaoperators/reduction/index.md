Метаоператор згортки — це звичайний оператор у квадратних дужках, як-от `[+]` або `[*]`. Він бере список значень і ставить оператор між кожною їхньою парою. Так він згортає весь список до одного значення.

Наприклад, `[+]` додає всі елементи списку:

```raku
my @data = 3, 5, 7, 9, 11;
say [+] @data; # 35
```

Код `[+] @data` — це те саме, що виписати оператор вручну:

```raku
say 3 + 5 + 7 + 9 + 11; # 35
```

Будь-який відповідний інфіксний оператор працює так само. З `[*]` ви отримуєте добуток списку. Тож можна застосувати його до діапазону `1..$n` і легко обчислити факторіал:

```raku
my $n = 5;
say [*] 1..$n; # 120
```

Тут діапазон `1..$n` дає числа від 1 до 5, а `[*]` їх перемножує: `1 * 2 * 3 * 4 * 5`. Результат — _5!_.

Це працює і для з'єднання рядків. Згортка `[~]` з'єднує список рядків в один:

```raku
my @strings = <neun hundert fünf und zwanzig>;
say [~] @strings; # neunhundertfünfundzwanzig
```

Можна згортати навіть оператори порівняння. `[<]` повідомляє, чи кожне значення більше за попереднє:

```raku
say [<] 1, 2, 3; # True
```

## Трикутна згортка

Якщо поставити всередині дужок зворотну косу риску, ви отримаєте _трикутну_ згортку. Вона зберігає всі проміжні результати, а не лише кінцевий:

```raku
say [\+] 1..5; # (1 3 6 10 15)
```

Кожен елемент результату — це часткова сума: `1`, потім `1+2`, потім `1+2+3` і так далі. Останній із них — сума всього списку.
