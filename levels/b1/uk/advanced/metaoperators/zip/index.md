Метаоператор zip `Z` бере два або більше списків. Він складає їхні елементи в пари за позиціями:

```raku
say (1, 2, 3) Z (4, 5, 6); # ((1 4) (2 5) (3 6))
```

Результат — це список груп. Перша група містить перший елемент кожного списку. Наступна група містить другі елементи і так далі.

Ще розумніше те, що `Z` можна поєднати з оператором, який діє на кожну пару. Наприклад, `Z+` додає елементи позиція за позицією:

```raku
say (1, 2, 3) Z+ (10, 20, 30); # (11 22 33)
```

Тут метаоператор zip огортає оператор `+`. Він обчислює `1 + 10`, `2 + 20` і `3 + 30`. Так само `Z*` перемножує відповідні елементи:

```raku
say (1, 2, 3) Z* (10, 20, 30); # (10 40 90)
```

А `Z~` з'єднує відповідні рядки:

```raku
say <a b c> Z~ <1 2 3>; # (a1 b2 c3)
```
