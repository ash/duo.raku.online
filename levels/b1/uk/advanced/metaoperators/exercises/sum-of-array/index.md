## Завдання

Напишіть програму, яка виводить середнє значення масиву чисел. Середнє значення ще називають середнім арифметичним. Щоб додати значення, скористайтеся метаоператором згортки.

Вхідні дані записано прямо в програмі, наприклад:

```raku
my @data = 10, 20, 30, 40;
```

## Приклад

Програма виводить середнє значення елементів у `@data`:

```
25
```
