`zef` — це встановлювач модулів Raku. Ви вже користувалися ним, щоб встановлювати модулі за іменем. Він також працює з локальним каталогом дистрибутива. Усередині дистрибутива його можна одразу протестувати й встановити:

```
zef test .
zef install .
```

`zef test .` запускає файли під `t/`. `zef install .` встановлює дистрибутив у ваш Raku, щоб інші програми могли завантажити його через `use`. Встановлення за іменем, як-от `zef install Cro`, робить те саме. Але спершу воно завантажує дистрибутив з екосистеми.

Ви можете **опублікувати** власний дистрибутив, щоб інші могли встановити його за іменем. Для цього ви завантажуєте його в екосистему. Звичайний інструмент для цього — `fez`:

```
fez upload
```

Це пакує поточний дистрибутив і надсилає його до екосистеми Raku. Після цього `zef install Maths::Simple` спрацює в будь-кого.

> Цим командам потрібні встановлені `zef`/`fez` і з'єднання з мережею. Для завантаження також потрібен обліковий запис в екосистемі.

Отже, життя спільного модуля має три кроки. Ви даєте йому структуру з `META6.json` і тестуєте його через `zef test`. Потім ви публікуєте його через `fez upload`. Відтоді це просто ще одне ім'я, яке будь-хто може встановити через `zef install`.
