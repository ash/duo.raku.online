## Завдання

Напишіть `META6.json` для дистрибутива з назвою `Greet::Simple` і версією `0.0.1`. Він надає модуль `Greet::Simple` із файлу `lib/Greet/Simple.rakumod`. У прикладі з теорії `depends` був порожнім. Цього разу дистрибутив **залежить від** іншого дистрибутива, `JSON::Fast`. Додайте його в масив `depends`.

> Результат цієї вправи — файл, а не вивід програми.

## Приклад

Правильний файл лише з потрібними частинами виглядає так, як у розв'язанні.
