## Завдання

Контейнер може мати типове значення, яке ви задаєте трейтом `is default`. Доки ви нічого не присвоїте, змінна повертає це типове значення. `.VAR.default` теж каже, яке воно.

Оголосіть скаляр `$count` із типовим значенням `0`. Нічого йому не присвоюйте. Спершу виведіть саму змінну, а потім типове значення її контейнера. Обидва рядки мають показати `0`.

## Приклад

Програма виводить:

```
0
0
```
