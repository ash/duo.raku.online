## Завдання

Ось типізована змінна:

```raku
my Str $lang = 'Raku';
```

Виведіть про неї три факти, по одному на кожному рядку:

1. тип її значення;
2. тип її контейнера;
3. її ім'я разом із сигілом.

## Приклад

Програма виводить:

```
Str
Scalar
$lang
```
