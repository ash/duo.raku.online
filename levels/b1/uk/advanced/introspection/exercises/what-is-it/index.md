## Завдання

`WHAT` не просто описує тип. Він повертає сам об'єкт типу, і його можна порівняти оператором `===`.

Оголосіть дві змінні. Змінна `$a` містить ціле число `42`, а `$b` містить рядок `'x'`. Для кожної виведіть, чи є її `WHAT` типом `Int`.

## Приклад

Програма виводить:

```
True
False
```
