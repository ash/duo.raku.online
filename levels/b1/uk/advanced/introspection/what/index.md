`WHAT` — це псевдометод, який дозволяє отримати тип значення. Його можна використовувати майже так само, як `.^name`:

```raku
my $var = 42;

say $var.^name;
say $var.WHAT;
```

Обидва виводять тип, але виглядає це трохи по-різному. `.^name` дає лише ім'я, а `WHAT` показує об'єкт типу в дужках:

```
Int
(Int)
```

Якщо змінна не має обмеження типу, спочатку її тип — `Any`. Після того як ви присвоїте значення, і `^name`, і `WHAT` показують його тип:

```raku
my $var;
say $var.^name; # Any
say $var.WHAT;  # (Any)

$var = 'Hello';
say $var.^name; # Str
say $var.WHAT;  # (Str)
```

З обмеженням типу тип відомий одразу, ще до того, як ви щось присвоїте:

```raku
my Str $var;
say $var.^name; # Str
say $var.WHAT;  # (Str)

$var = 'Hello';
say $var.^name; # Str
say $var.WHAT;  # (Str)
```

## Порівняння об'єктів типу

`WHAT` повертає сам об'єкт типу, тож два об'єкти типу можна порівняти оператором `===`. Це оператор _тотожності значень_. Він перевіряє, чи обидві сторони є точно тим самим значенням. Кожен тип має лише один об'єкт типу. Тож це чистий спосіб перевірити, чи мають два значення той самий тип:

```raku
my $a = 42;
my $b = 100;

say $a.WHAT === $b.WHAT; # True  — обидва Int
say $a.WHAT === Int;     # True
say $a.WHAT === Str;     # False
```

`==` порівнює числа, а `===` порівнює тотожність. Тож він працює прямо з об'єктами типу, а також з іншими значеннями.
