Який твіґіл позначає **динамічну** змінну, яку Raku знаходить через стек викликів?

{:.quiz}
1 | `*`
0 | `?`
0 | `!`
0 | `.`

{% include quiz.html %}

<div class="extended-explanation">

Твіґіл `*` позначає динамічну змінну, наприклад `$*OUT` чи `$*greeting`. Твіґіл `?` — для компіляційних значень, а `!` — для приватного атрибута. Твіґіл `.` — для методу доступу до атрибута.

</div>
