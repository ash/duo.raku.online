Що виведе наведена програма?

```raku
my $*n = 1;
sub show { say $*n }

sub run {
    my $*n = 2;
    show();
}

run();
```

{:.quiz}
0 | 1
1 | 2
0 | Нічого
0 | Помилку

{% include quiz.html %}

<div class="extended-explanation">

`show` написано на верхньому рівні, просто поруч із `my $*n = 1`. Але це місце не має значення. Raku шукає динамічну змінну через *стек викликів*. Де стоїть код, неважливо. Тут `show` викликано з `run`, який знову оголосив `$*n` як `2`. Тож діє саме це значення, і програма виводить `2`.

</div>
