## Завдання

`$_` — це *топічна* змінна. Цикл `for` по черзі записує в неї кожен елемент. Виклик методу на зразок `.chars` починається з крапки й не має об'єкта перед нею. Такий виклик працює з `$_`, тож `.chars` означає `$_.chars`.

Пройдіть циклом по трьох рядках `'apple'`, `'fig'` та `'cherry'`. Для кожного з них виведіть рядок у формі `<слово> has <n> letters`. Для слова використайте топік `$_`. Для його довжини використайте виклик `.chars` із крапкою на початку. Простежте, як `$_` по черзі стає кожним рядком.

## Приклад

Програма виводить:

```
apple has 5 letters
fig has 3 letters
cherry has 6 letters
```
