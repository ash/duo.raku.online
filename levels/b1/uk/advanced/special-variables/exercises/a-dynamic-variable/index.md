## Завдання

Динамічну змінну записують із твіґілом `*`. Raku знаходить її, шукаючи назовні по стеку викликів, а не за лексичною областю видимості. Тож значення, яке бачить підпрограма, залежить від того, хто її викликав. Це дозволяє блоку виконувати код, який він викликає, від імені когось іншого.

1. Оголосіть динамічну змінну `$*user` зі значенням `'guest'`.
2. Напишіть підпрограму `whoami`, яка виводить `running as `, а потім поточне значення `$*user` (наприклад, `running as guest`). Вона не має параметрів, тож має читати `$*user` напряму.
3. Викличте `whoami` один раз на верхньому рівні. Вона показує `guest`.
4. Потім створіть блок, який знову оголошує `$*user` як `'admin'`. Усередині нього знову викличте *ту саму* `whoami`. Тепер вона показує `admin`.

## Приклад

Програма виводить:

```
running as guest
running as admin
```
