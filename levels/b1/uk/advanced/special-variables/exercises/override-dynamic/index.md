## Завдання

Покажіть, як динамічна змінна проходить крізь підпрограму посередині. Та підпрограма нічого про неї не знає.

Напишіть підпрограму `log-it($msg)`, яка виводить повідомлення, а перед ним — динамічну змінну `$*prefix`. Напишіть другу підпрограму `task`, яка лише викликає `log-it('working')`. Сама вона ніколи не згадує `$*prefix`. Потім викличте `task` двічі, щоразу зсередини блоку. Кожен блок задає `$*prefix` інше значення: спершу `INFO`, потім `DEBUG`.

## Приклад

Програма виводить:

```
INFO: working
DEBUG: working
```
