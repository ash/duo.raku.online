Ось один із можливих розв'язків.

## Код

```raku
my $factor = 3;
my $scale = -> $x { $x * $factor };

say $scale(7);
```

🦋 Ви можете знайти вихідний код у файлі [triple-it.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/anonymous-subroutines/triple-it.raku).

## Вивід

```
21
```

## Коментарі

1. Стрілочний блок має лише один параметр, `$x`. Проте він використовує `$factor` — змінну з області видимості навколо нього. Саме захоплення таких змінних робить його замиканням.

1. Коли `$factor` дорівнює `3`, виклик `$scale(7)` дає `21`. Якщо змінити `$factor`, той самий блок множитиме на нове значення:

```raku
$factor = 5;
say $scale(7); # 35
```

Замикання захоплює саму *змінну*. Воно не захоплює значення, яке було в той момент, коли блок написали. Тож пізніший виклик бачить новий `$factor` і повертає `35`.
