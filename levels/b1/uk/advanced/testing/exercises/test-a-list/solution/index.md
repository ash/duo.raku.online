Ось один із можливих розв'язків.

## Код

```raku
use Test;

plan 2;

my @sorted = (3, 1, 2).sort;
is-deeply @sorted, [1, 2, 3], 'sorted';

is 10 % 3, 1, 'remainder';
```

🦋 Вихідний код можна знайти у файлі [test-a-list.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/testing/test-a-list.raku).

## Вивід

```
1..2
ok 1 - sorted
ok 2 - remainder
```

## Коментарі

1. `plan 2` вказує кількість ще до запуску будь-якого тесту, тож рядок `1..2` іде першим. Якби файл потім виконав іншу кількість перевірок, набір тестів був би невдалим. `done-testing` не може дати вам такого захисту.

1. `is-deeply` перевіряє, що два списки точно рівні, разом з їхніми типами. Сортування `3, 1, 2` дає `1, 2, 3`, що збігається.

1. `is` перевіряє два значення на просту рівність. Якщо тест не проходить, він показує обидва значення. Тут `10 % 3` дорівнює `1`, а це й є очікуване значення. Тож другий тест теж проходить.
