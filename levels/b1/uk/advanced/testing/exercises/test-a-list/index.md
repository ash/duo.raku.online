## Завдання

Напишіть файл тестів, який використовує `plan`, а не `done-testing`. Через `plan` скажіть на початку, що файл містить рівно дві перевірки. Зробіть такі перевірки:

1. За допомогою `is-deeply` перевірте, що сортування списку `3, 1, 2` дає `[1, 2, 3]`.
1. За допомогою `is` перевірте, що `10 % 3` дорівнює `1`.

Дайте кожній перевірці короткий опис, який ви оберете самі.

## Приклад

Якщо описи — `sorted` і `remainder`, програма виводить:

```
1..2
ok 1 - sorted
ok 2 - remainder
```
