Окремий файл тестів — це просто програма на Raku. Тож його можна запустити напряму:

```
raku t/01-basic.rakutest
```

Він виводить на екран свій результат у форматі TAP. Коли у вас більше ніж один-два файли, вам потрібен _запускач тестів_. Він запускає цілий каталог тестів і підсумовує результати. Запускач для Raku — це `prove6`:

```
prove6 t/
```

Це запускає кожен файл тестів під `t/` і повідомляє, скільки файлів і тестів пройшло. У кінці є один загальний результат: пройдено чи не пройдено. Це набагато легше читати, ніж сирий TAP із кожного файлу.

Якщо дистрибутив має `META6.json`, інструмент для модулів може запустити його тести за вас:

```
zef test .
```

`zef test` знаходить каталог `t/`, запускає тести й повідомляє результат. Точно те саме відбувається автоматично перед встановленням дистрибутива. Отже, тести мають два завдання. Ви запускаєте їх через `prove6` під час розробки. Екосистема запускає їх, щоб перевірити дистрибутив, перш ніж хтось його встановить.

> Файли тестів мають розширення `.rakutest` (або `.t`). Зазвичай у їхніх назвах є номери, як-от `t/01-basic.rakutest`.
