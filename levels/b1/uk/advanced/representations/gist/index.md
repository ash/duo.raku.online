---
title: Метод `.gist`
---

{% include menu.html %}

Метод `.gist` повертає **зручне для людини** представлення значення. Це форма, яку ви хотіли б *прочитати*. `say` і `note` друкують саме її, бо вони викликають `.gist` для кожного аргументу.

```raku
say 42.gist;     # 42
say 'Raku'.gist; # Raku
```

Для простих значень gist — це просто саме значення. Для складених даних `.gist` додає трохи форматування, щоб структуру було легко читати:

```raku
my @a = 'alpha', 'beta', 'gamma';
say @a.gist; # [alpha beta gamma]
```

Об'єкт типу — це значення, яке представляє сам тип. Його gist — це його назва в дужках. Завдяки цьому його легко помітити у виводі:

```raku
say Int.gist; # (Int)
```
