---
title: Вибір правильного методу
---

{% include menu.html %}

Для звичайних скалярів, як-от чисел і рядків, усі три представлення виглядають однаково. Різниця з'являється для складених або невизначених значень. Ось `Pair`, показаний трьома способами:

```raku
say (foo => 1).gist; # foo => 1
say (foo => 1).Str;  # foo	1
say (foo => 1).raku; # :foo(1)
```

Ось приблизне загальне правило:

* [`.gist`](../gist) — для виводу, який будуть *читати* люди (`say`, `note`).
* [`.Str`](../str) — для виводу *простим текстом* (`print`, `put`, змінні всередині рядків, оператор `~`).
* [`.raku`](../raku-method) — для форми, *подібної до коду*, під час налагодження (`dd`).

Коли ви пишете клас, ви можете дати кожному з цих методів власне визначення. Тоді ваші власні об'єкти теж гарно друкуватимуться. Ми повернемося до цього, коли будемо [створювати класи](/uk/oop/classes) в наступній частині.
