Масив — це впорядкований контейнер, а його елементи — теж скалярні контейнери.

```raku
my @array = 100, 200, 300;
my @letters = 'a', 'b', 'c';
```

Сигіл `@` означає, що така змінна поводиться як об'єкт `Positional`. Це дає змогу читати окремі елементи за допомогою індексів:

```raku
say @array[1];   # 200
say @letters[2]; # c
```

Кожен елемент є скалярним контейнером, тому йому можна присвоїти нове значення. Ви робите це так само, як з окремою скалярною змінною:

```raku
my @array = 100, 200, 300;
@array[0] = 10;
say @array; # [10 200 300]
```

Можна також присвоїти значення іншого типу, наприклад:

```raku
my @array = 100, 200, 300;
@array[0] = 'ten';
say @array; # [ten 200 300]
```

Саме це робить масиви _змінюваними_, тобто такими, які можна змінювати. Кожна комірка — це контейнер, який може отримати нове значення. У наступній темі ви побачите, що [списки](/uk/advanced/ordered-containers/lists) поводяться інакше.
