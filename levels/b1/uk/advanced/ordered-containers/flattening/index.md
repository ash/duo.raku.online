Якщо ви кладете один масив в інший, Raku сам _не_ зливає їхні елементи. Подивіться на цю програму:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;
my @c = @a, @b;

say @c.elems; # 2
say @c;       # [[1 2 3] [4 5]]
```

Масив `@c` має лише два елементи — масиви `@a` та `@b`. Raku зберігає кожен контейнер як один елемент. Він не розпаковує його вміст у зовнішній масив. Те саме стається, коли ви ставите масив серед інших значень:

```raku
my @a = 1, 2, 3;
my @d = 0, @a, 99;
say @d; # [0 [1 2 3] 99]
```

Якщо вам справді потрібна одна плоска послідовність, попросіть її прямо за допомогою підпрограми `flat`:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat(@a, @b);       # (1 2 3 4 5)
say flat(@a, @b).elems; # 5
```

## Штучність

Іноді потрібне протилежне. Ви хочете захистити контейнер від сплощення, навіть усередині `flat`. Конструкція `$(...)` робить свій аргумент _штучним_. Це означає, що вона позначає результат як один елемент. Порівняйте попередній приклад із цим:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat($(@a), @b); # ([1 2 3] 4 5)
```

Тут `$(@a)` зберігає `@a` як один елемент. Але `@b` усе одно сплощується у свої два значення. Це знову ідея сигіла `$`. Знак `$` означає «розглядай це як одну річ».
