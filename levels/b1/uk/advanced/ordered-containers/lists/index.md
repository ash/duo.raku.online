Список — це теж упорядкований набір значень. Але, на відміну від масиву, він _незмінний_. Це означає, що ви не можете змінювати, додавати чи вилучати його елементи. Ви записуєте список як значення через кому, часто в дужках:

```raku
my $colours = ('red', 'green', 'blue');
```

Елементи списку можна читати за індексом, як і в масиві. Також можна спитати, скільки їх:

```raku
my $colours = ('red', 'green', 'blue');
say $colours[0];    # red
say $colours.elems; # 3
```

Різницю видно, коли ви пробуєте змінити елемент. З масивом це працює, бо кожен елемент є контейнером:

```raku
my @array = 1, 2, 3;
@array[0] = 10;
say @array; # [10 2 3]
```

Зі списком ви отримуєте помилку. Елементи списку — це просто значення, а не контейнери:

```raku
my $list = (1, 2, 3);
$list[0] = 10;
```

Друга програма зупиняється з повідомленням:

```
Cannot modify an immutable List ((1 2 3))
  in block <unit> at t.raku line 2
```

Отже, використовуйте масив із сигілом `@`, коли треба змінювати його вміст. Використовуйте список, коли треба лише зберігати сталу послідовність значень.
