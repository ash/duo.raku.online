Досі кожна змінна, яку ви створювали, отримувала новий контейнер. Присвоєння через `=` клало значення _всередину_ цього контейнера. Зв'язування, яке пишуть як `:=`, працює інакше. Воно змушує ім'я посилатися на _наявний_ контейнер, а не створює новий.

Після зв'язування два імені мають той самий контейнер. Тому зміну через одне ім'я видно через інше:

```raku
my $x = 10;
my $y := $x;

$x = 20;
say $y; # 20
```

Тут `$y := $x` не копіює значення `10`. Натомість `$y` стає ще одним іменем того самого контейнера, що й `$x`. Пізніше, коли `$x` отримує значення `20`, `$y` теж дає `20`.

Тепер порівняйте це зі звичайним присвоєнням. Воно копіює значення в окремий контейнер:

```raku
my $x = 10;
my $y = $x; # звичайна копія

$x = 20;
say $y; # 10
```

Зв'язування також працює з масивами. Цей код робить `@alias` ще одним іменем для `@data`:

```raku
my @data = 1, 2, 3;
my @alias := @data;

@alias[0] = 99;
say @data; # [99 2 3]
```

Ще одна деталь. Якщо зв'язати ім'я прямо з літеральним значенням, за ним немає контейнера. Тому ім'я стає доступним лише для читання:

```raku
my $pi := 3.14;
$pi = 3;
```
