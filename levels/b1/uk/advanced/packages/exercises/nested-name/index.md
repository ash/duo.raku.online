## Завдання

Покладіть модуль `Inner` усередину модуля `Outer`. В `Inner` оголосіть змінну `our` `$base` зі значенням `10`. Також оголосіть `our sub doubled`, яка повертає `$base`, помножене на два. Ззовні обох модулів дістаньтеся до змінної через її повне вкладене ім'я. Підпрограму теж викличте через її повне вкладене ім'я. Виведіть обидва результати.

## Приклад

Програма виводить:

```
10
20
```
