Ключове слово `package` створює простір імен. Усе, що оголошено всередині нього через `our`, стає частиною цього простору імен. Ззовні до цих імен можна дістатися через ім'я пакунка й роздільник `::`:

```raku
package Maths {
    our $pi = 3.14;
    our sub double($x) { $x * 2 }
}

say $Maths::pi;         # 3.14
say Maths::double(5);   # 10
```

До змінної ви дістаєтеся як `$Maths::pi`. Це ім'я має сигіл, потім ім'я пакунка, потім ім'я змінної. Підпрограму викликають як `Maths::double(...)`.

І `package`, і `module` створюють простір імен, але різняться тим, що ще вони роблять. `module` — звичайний вибір для коду, який використовують знову. Звичайний `package` — це просто простір імен, без нічого зайвого. `class`, з яким ви познайомитеся в [наступній частині](/uk/oop), теж створює простір імен. Крім того, він додає все, що потрібно для об'єктно-орієнтованого програмування.

```raku
module Greet {
    our sub hello { 'hi' }
}

say Greet::hello; # hi
```

Отже, `module` дає вам той самий простір імен, що й звичайний `package`. Який із них вибрати, залежить здебільшого від того, що ви хочете зробити. Використовуйте `module` для бібліотек, а `package` — для простого простору імен. Пізніше, коли дійдете до об'єктів, використовуйте `class` для типів.
