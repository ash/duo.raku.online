Саме декларатор `our` робить ім'я видимим у його просторі імен. Змінна, оголошена через `my`, є лексичною, тобто приватною для свого блоку. Змінна, оголошена через `our`, — це ще й змінна пакунка. До неї можна дістатися ззовні через шлях із `::`:

```raku
module Counter {
    our $count = 0;  # змінна пакунка
    my  $secret = 42; # лексична, ззовні не видима
}

say $Counter::count; # 0
```

`$Counter::count` працює, бо `count` оголошено через `our`. Але `$Counter::secret` не спрацював би, бо `secret` — лексична змінна.

Простори імен можуть **вкладатися**, тобто один може бути всередині іншого. Пакунок усередині пакунка дає довший шлях із `::`:

```raku
module Outer {
    module Inner {
        our $val = 42;
    }
}

say $Outer::Inner::val; # 42
```

Повне ім'я `$Outer::Inner::val` веде із зовнішнього простору імен у внутрішній. Звідти воно веде до змінної. Саме так побудована стандартна бібліотека: імена на кшталт `IO::Socket::INET` — це вкладені простори імен. Ваші власні модулі теж так збирають свої частини під одним іменем верхнього рівня.
