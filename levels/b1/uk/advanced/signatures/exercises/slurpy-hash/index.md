## Завдання

Напишіть підпрограму `describe`, яка приймає обов'язкове позиційне ім'я. Після нього підпрограма збирає будь-яку кількість іменованих аргументів у всеїдний хеш (`*%opts`). Вона має повертати рядок виду `name: key=value, key=value, ...`. Рядок перелічує кожен параметр, і ключі йдуть в алфавітному порядку.

Викличте її як `describe('Anna', colour => 'red', size => 5)` і виведіть результат.

## Приклад

Програма виводить:

```
Anna: colour=red, size=5
```
