---
title: Вивід сигнатур функцій
---

{% include menu.html %}

Ви можете викликати просто `dd`, без аргументів, усередині підпрограми. Тоді `dd` друкує сигнатуру цієї підпрограми. Це її ім'я та список параметрів, якщо підпрограма їх має. Подивіться на такий приклад із двома підпрограмами:

```raku
sub f1 {
    dd
}

f1();

sub f2($x) {
    dd
}

f2(42);
```

Програма друкує сигнатури, а не значення:

```console
sub f1()
sub f2($x)
```

Це особливо корисно з мультифункціями, бо показує, який варіант було справді викликано:

```raku
multi sub g {
    dd
}

multi sub g($x) {
    dd
}

g();
g(42);
```

Щоразу вивід показує відповідний варіант:

```console
sub g()
sub g($x)
```
