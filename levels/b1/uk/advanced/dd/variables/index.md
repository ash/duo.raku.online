title: Вивід змінних
---

{% include menu.html %}

Викличте `dd`, щоб побачити, що є всередині змінної. Ви користуєтеся `dd` так само, як `say`:

```raku
my $var = 42;
dd $var;
```

`dd` друкує і значення, і ім'я змінної:

```console
$var = 42
```

Якщо змінна має оголошений тип, `dd` показує також тип. Порівняйте вивід цієї програми з попередньою:

```raku
my Int $var = 42;
dd $var;
```

```console
Int $var = 42
```

Це головна відмінність від `say`. Один виклик `dd` для скаляра показує вам ім'я змінної. Він також показує тип даних, коли тип відомий. Тож ви можете додати в програму кілька викликів `dd`. Ви все одно побачите, який вивід належить якій змінній.

Ви також можете дампити складніші структури даних, наприклад масиви або хеші. Тоді `dd` друкує значення у формі, схожій на код:

```raku
my @arr = 10, 20, [1, 2, 3], 30;
dd @arr;
```

```console
[10, 20, [1, 2, 3], 30]
```

Зверніть увагу, що вкладений масив добре видно. Але ім'я змінної не друкується. З хешами це працює так само, і `dd` друкує їхні ключі у відсортованому порядку:

```raku
my %hash =
    gamma => 'g',
    alpha => 'a',
    beta  => 'b';
dd %hash;
```

```console
{:alpha("a"), :beta("b"), :gamma("g")}
```
