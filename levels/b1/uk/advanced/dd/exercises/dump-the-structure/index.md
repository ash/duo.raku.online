## Завдання

У вас є така вкладена структура даних:

```raku
my @data = 'Raku', [1, 2, 3], (key => 'value');
```

Зробіть із нею дві речі:

1. Виведіть за допомогою `dd` дамп `@data`, зручний для розробника.
2. Виведіть те саме подання як рядок, що починається з тексту `Structure: `.

## Приклад

Програма виводить два схожі рядки:

```
["Raku", [1, 2, 3], :key("value")]
Structure: ["Raku", [1, 2, 3], :key("value")]
```
