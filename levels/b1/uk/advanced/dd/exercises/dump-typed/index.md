## Завдання

Оголосіть змінну з типом для цілих чисел: `my Int $n = 42;`. Потім виведіть її дамп за допомогою `dd`. Зверніть увагу, чим вивід відрізняється від виводу нетипізованої змінної.

## Приклад

Програма виводить таке у стандартний потік помилок:

```
Int $n = 42
```
