## Завдання

Напишіть дві мульти-підпрограми з іменем `abs-value`, які приймають ціле число й повертають його абсолютне значення. Використайте речення `where`, щоб окремо обробити від'ємні числа. Не використовуйте жодного `if` усередині підпрограм. Вбудований `abs` теж не використовуйте.

Виведіть результат для `-7` та для `4`.

## Приклад

Програма виводить:

```
7
4
```
