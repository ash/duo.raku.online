Ось один із можливих розв'язків.

## Код

```raku
my @squares = gather for 1..6 {
    take $_ ** 2 if $_ %% 2;
};

say @squares;
```

🦋 Вихідний код можна знайти у файлі [squares.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/gather-take/squares.raku).

## Вивід

```
[4 16 36]
```

## Коментарі

1. Перевірка `if $_ %% 2` вирішує, *чи* брати значення, а `$_ ** 2` вирішує, *що* брати. Цю перевірку проходять лише парні числа `2`, `4`, `6`.

1. Їхні квадрати `4`, `16`, `36` — єдині значення, які отримує `take`. Тож `gather` збирає саме їх. Тут один `take` водночас фільтрує і змінює значення. Простий `map` не може сказати це так само ясно.
