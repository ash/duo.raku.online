Ім'я модуля створює _пакунок_. Пакунок — це простір імен, який містить імена, визначені в модулі. Раніше, у [розділі про контейнери](/uk/advanced/containers), ви познайомилися з `WHO`. Він повертає `Stash`, тобто таблицю символів пакунка. Інтроспекція модулів використовує саме це.

Приклади нижче використовують модуль `Greeting`, який ми створили в попередніх темах. Він має експортовану підпрограму та спільну змінну `our`:

```raku
unit module Greeting;

our $version = '1.0';

sub hello($name) is export {
    return "Hello, $name!";
}
```

Пакунок модуля записують із `::` у кінці. Якщо додати `.keys`, ви отримаєте список імен, які він містить:

```raku
use Greeting;

say Greeting::.keys.sort; # ($version EXPORT)
```

Модуль `Greeting` із попередніх тем визначає змінну `our` під назвою `$version`. Тож його пакунок містить це ім'я разом із сигілом. Поруч із ним стоїть `EXPORT`, і це може здивувати. Це пакунок, який Raku створює автоматично. Він зберігає все, що модуль позначає `is export`, наприклад, підпрограму `hello`. Тож експортоване ім'я _не_ з'являється в пакунку напряму. Воно живе всередині підпакунка `EXPORT`. Ключі повертаються без сталого порядку. Тому приклад їх сортує, щоб результат завжди був однаковим.

Ім'я можна також знайти в пакунку. Просто використайте ім'я як ключ. Це дає те саме значення, що й кваліфіковане ім'я `$Greeting::version`:

```raku
use Greeting;

say Greeting::{'$version'}; # 1.0
```

## Перелік того, що експортує модуль

Експортовані імена насправді живуть у пакунку `EXPORT`, який ви бачили вище. Тож їх можна перелічити, якщо заглянути на рівень глибше. Експорти без мітки потрапляють до групи `DEFAULT` (дивіться [Мітки експорту](/uk/advanced/modules-basics/export-tags)). `.keys` цієї групи — це експортовані підпрограми:

```raku
use Greeting;

say Greeting::EXPORT::DEFAULT::.keys.sort; # (&hello)
```

Кожен ключ — це експортоване ім'я з його сигілом. Тут це єдина підпрограма, `&hello`, з `&`, що позначає підпрограму. Так можна дізнатися, що модуль пропонує своїм користувачам. Вам не потрібно читати його вихідний код. Просто спитайте його пакунок `EXPORT::DEFAULT`, що той містить.

Так заглядати всередину пакунка корисно у двох випадках. Можливо, ви хочете дізнатися, що надає модуль. Або ви хочете дістатися до його імен, поки програма працює. Тоді не треба виписувати кожне з них у вихідному коді.
