Що виведе наведена програма?

```raku
my @a = 1, 2, 3;
my $n = 0;
$n++ for $(@a);
say $n;
```

{:.quiz}
0 | 3
1 | 1
0 | 0
0 | 6

{% include quiz.html %}

<div class="extended-explanation">

Контекстуалізатор `$( … )` задає штучний контекст. Тож масив є одним значенням, а не списком елементів. Тому цикл `for` бачить один елемент і виконує своє тіло лише раз. Тож у кінці `$n` дорівнює `1`. Без `$( )` цикл виконався б тричі.

</div>
