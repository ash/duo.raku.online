Три контексти трапляються дуже часто. Вони змушують значення поводитися як число, як рядок або як булеве значення. Для кожного з них є префіксний оператор, який прямо задає контекст:

* `+` — числовий контекст
* `~` — рядковий контекст
* `?` — булевий контекст

З масивом `+` дає його довжину, а `~` дає його елементи, з'єднані пробілами. `?` показує, чи є в масиві взагалі якісь елементи:

```raku
my @a = 1, 2, 3;

say +@a; # 3
say ~@a; # 1 2 3
say ?@a; # True
```

Порожній масив дає `0` у числовому контексті та `False` у булевому контексті:

```raku
my @empty;
say +@empty; # 0
say ?@empty; # False
```

Вам не завжди потрібно писати ці оператори самостійно. Raku може задати потрібний контекст за вас. Арифметика ставить свої значення в числовий контекст, а з'єднання рядків ставить їх у рядковий. `if`, `while` та `and`/`or` ставлять свою умову в булевий контекст:

```raku
my @a = 1, 2, 3;

say 10 + @a;              # 13, тут @a це його довжина: 3
say 'items: ' ~ @a;       # items: 1 2 3
if @a { say 'not empty' } # not empty
```

Тож `if @array { … }` працює саме так, як ви й очікуєте. Масив, який не порожній, є істинним. Префіксні оператори — це спосіб прямо попросити ті самі перетворення.

Разом із постфіксним `if` це дозволяє писати короткий і зрозумілий код:

```raku
say "{+@a} items are there" if @a; # 3 items are there
```
