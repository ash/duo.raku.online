## Завдання

Візьміть масив `1, 2, 3` і запакуйте його в скаляр `$x` за допомогою контекстуалізатора **штучного** контексту. Тоді `$x` містить увесь масив як одне значення. Далі за допомогою контекстуалізатора **спискового** контексту пройдіть циклом `for` по `$x`. Порахуйте, скільки разів виконується цикл. Списковий контекст розгортає запакований масив назад у його елементи. Тож цикл виконується тричі. Виведіть лічильник.

## Приклад

Програма виводить:

```
3
```
