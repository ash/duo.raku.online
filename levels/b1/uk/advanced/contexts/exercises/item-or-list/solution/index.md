Ось один із можливих розв'язків задачі.

## Код

```raku
my @a = 1, 2, 3;
my $count = 0;

my $x = $(@a);
$count++ for @($x);
say $count;
```

🦋 Вихідний код можна знайти у файлі [item-or-list.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/contexts/item-or-list.raku).

## Вивід

```
3
```

## Коментарі

1. `my $x = $(@a)` задає штучний контекст. Тож увесь масив пакується в єдиний скаляр `$x`. Він не розгортається.

1. Далі `@($x)` задає списковий контекст і розгортає `$x` назад у три елементи. Тож цикл `for` виконується тричі, і в кінці лічильник дорівнює `3`. Ці два контекстуалізатори — повні протилежності: `$( )` пакує список в один елемент, а `@( )` знову його розпаковує.
