Блок сам по собі — оператор, а не вираз. Тож зазвичай його не можна присвоїти змінній. Префікс `do` перетворює блок на вираз. Його значення — це значення **останнього** оператора блоку:

```raku
my $x = do {
    my $a = 3;
    $a + 4;
};

say $x; # 7
```

Усередині блоку можна оголошувати змінні, виконувати кілька операторів і обчислювати результат. Потім `do` повертає значення блоку. Це корисно, коли для отримання значення потрібен не один вираз.

`do` також працює перед операторами керування потоком виконання. Тоді вони теж можуть повертати значення:

```raku
my $sign = do given 5 {
    when * > 0 { 'positive' }
    when * < 0 { 'negative' }
    default    { 'zero' }
};

say $sign; # positive
```

Тут `do given` перетворює весь `given`/`when` на вираз зі значенням `positive`. Так само працюють `do if` і `do for`. Коротко кажучи, `do` дає змогу використати блок там, де очікується значення. Це працює і для керівної конструкції.
