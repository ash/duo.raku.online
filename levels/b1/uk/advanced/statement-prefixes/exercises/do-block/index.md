## Завдання

`do` також працює перед операторами керування потоком виконання. Він перетворює їх на вирази, що дають значення. Використайте `do if 7 > 5 { 'big' } else { 'small' }`, щоб вибрати позначку. Потім присвойте її змінній `$label` і виведіть.

## Приклад

Програма виводить:

```
big
```
