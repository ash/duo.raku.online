Оператори в Raku насправді є просто підпрограмами з особливими іменами. Це означає, що ви можете визначати власні оператори. Ви використовуєте назви категорій зі сторінки [Типи операторів Raku](/uk/advanced/operator-types): `prefix`, `infix`, `postfix` і так далі.

Щоб оголосити оператор, напишіть `sub` з особливим іменем. Ім'я складається з категорії, двокрапки й символу оператора в кутових дужках. Ось новий інфіксний оператор під назвою `plus`:

```raku
sub infix:<plus>($a, $b) {
    $a + $b
}

say 3 plus 4; # 7
```

Щойно його визначено, `plus` стоїть між двома своїми операндами. Це точно як у будь-якого вбудованого інфіксного оператора.

Постфіксний оператор іде після свого операнда. Класичний приклад — факторіал. Ось він як постфіксний оператор `!`. Він побудований на [метаоператорі згортки](/uk/advanced/metaoperators/reduction), який ви бачили раніше:

```raku
sub postfix:<!>(Int $n) {
    [*] 1..$n
}

say 5!; # 120
```

Ви не обмежені літерами й розділовими знаками ASCII. Символом оператора може бути будь-який знак. Цей префіксний оператор використовує знак параграфа, `§`, щоб подвоїти число:

```raku
sub prefix:<§>($x) {
    $x * 2
}

say §5; # 10
```

Визначення операторів — потужний інструмент, тож користуйтеся ним зі смаком. Вдало вибраний оператор може зробити код схожим на мову його галузі. Незрозумілий оператор лише заплутає наступну людину, яка читатиме код.
