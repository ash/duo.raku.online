Наріччя `:exists` перетворює індекс на запитання. Чи є значення за цим ключем або індексом? Наріччя повертає булеве значення, але не дістає саме значення:

```raku
my %h = apple => 1, pear => 2;

say %h<apple>:exists; # True
say %h<plum>:exists;  # False
```

Це правильний спосіб перевірити ключ. Якщо просто прочитати `%h<plum>`, ви отримаєте невизначене значення. Залежно від даних, це може приховати різницю між «відсутнє» та «є, але невизначене».

Наріччя `:delete` вилучає запис і повертає вам його значення:

```raku
my %h = apple => 1, pear => 2;

say %h<apple>:delete; # 1
say %h.keys;          # (pear)
say %h;               # {pear => 2}
```

Запису `apple` більше немає. Ви отримуєте назад видалене значення `1`, тож можете його використати.

Обидва наріччя працюють і з масивами, за індексом:

```raku
my @a = 10, 20, 30;

say @a[1]:exists; # True
say @a[5]:exists; # False

say @a[1]:delete; # 20
say @a[1]:exists; # False
```

Який вигляд має масив, коли з нього видалено елемент у середині? Ось відповідь:

```raku
say @a; # [10 (Any) 30]
```

Тож один і той самий запис дозволяє перевіряти й змінювати контейнери на місці. Для цього вам не потрібні окремі методи.
