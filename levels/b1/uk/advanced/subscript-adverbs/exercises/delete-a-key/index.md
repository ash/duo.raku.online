## Завдання

Візьміть хеш `a => 1, b => 2, c => 3`. За допомогою наріччя індексу видаліть запис `b`. Потім виведіть, скільки записів залишилося, щоб показати, що один із них видалено.

## Приклад

Програма виводить:

```
2
```
