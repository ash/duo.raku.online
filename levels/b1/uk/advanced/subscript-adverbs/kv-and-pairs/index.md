Інші наріччя змінюють те, **що** індекс повертає. Зазвичай індекс повертає лише значення, але ці наріччя повертають більше:

* `:v` — значення (за замовчуванням)
* `:k` — ключ (або індекс)
* `:kv` — і ключ, і значення
* `:p` — `Pair` із ключа та значення

Для масиву «ключем» є індекс:

```raku
my @a = 10, 20, 30;

say @a[1]:kv; # (1 20)
say @a[1]:p;  # 1 => 20
```

`@a[1]:kv` дає індекс і значення разом у списку. `@a[1]:p` дає їх як пару.

Те саме працює для хешів. Це особливо зручно зі зрізом із кількох ключів одразу:

```raku
my %h = a => 1, b => 2, c => 3;

say %h<a c>:kv; # (a 1 c 3)
```

Тут зріз із двох ключів повертає кожен ключ, а за ним його значення. `map`, `for` та схожі інструменти часто спираються на ці наріччя. Вони дозволяють обробляти ключі й значення разом, без окремих пошуків.
