## Завдання

Оголосіть поруч дві скалярні змінні: `$untyped`, яка не має типу, і `$typed`, яка має тип `Int`. Виведіть дамп обох через `dd`, поки вони ще порожні. Потім присвойте кожній `42` і знову виведіть дамп обох. Уважно подивіться, як по-різному `dd` описує ці два контейнери.

## Приклад

Програма виводить таке у стандартний потік помилок:

```
$untyped = Any
Int $typed = Int
$untyped = 42
Int $typed = 42
```
