Ось один із можливих розв'язків задачі.

## Код

```raku
my Int $cars;

$cars = 250.7.Int;
say $cars;
say $cars.WHAT;
```

🦋 Вихідний код можна знайти у файлі [integers-only.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/scalar-containers/integers-only.raku).

## Вивід

```
250
(Int)
```

## Коментарі

1. Обмеження типу `Int` у `my Int $cars` змушує контейнер відкидати всі нецілі значення. Якщо прямо присвоїти `250.7`, тобто `Rat`, буде помилка під час компіляції.

1. Виклик `.Int` для раціонального значення `250.7` перетворює його на ціле `250`. Він просто відкидає дробову частину. Нове значення підходить для контейнера. Не плутайте це з округленням.

1. Псевдометод `.WHAT` показує, що значення в контейнері має тип `Int`.
