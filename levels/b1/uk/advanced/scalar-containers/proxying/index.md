Насправді скалярний контейнер — це об'єкт типу `Scalar`. У більшості випадків ви навіть не помічаєте контейнера, коли використовуєте скаляр. Вам не треба про нього думати. Можна уявляти, що ви працюєте напряму зі значеннями в ньому.

Це працює, бо скалярний контейнер передає виклики методів своєму значенню. Наприклад, після `my $lang = 'Raku'` можна викликати метод `.chars` для змінної:

```raku
my $lang = 'Raku';
say $lang.chars; # 4
```

Програма виводить `4` — кількість символів у рядку `'Raku'`. Тепер викличте `.chars` прямо для рядкового значення, а не для змінної-контейнера. Результат точно такий самий:

```raku
say 'Raku'.chars; # 4
```

Іншими словами, контейнер тихо передає виклик `.chars` рядку, який у ньому лежить. Потім він повертає вам результат.
