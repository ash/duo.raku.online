Іноді ви створюєте нову скалярну змінну і не присвоюєте їй нічого одразу. Навіть тоді контейнер містить значення — своє типове значення. Яким саме воно буде, залежить від типу змінної.

Наступна програма — не найкращий спосіб користуватися Raku. Але вона показує ідею:

```raku
my $int;
say $int + 5;
```

Вивід містить `5`. Ви могли цього очікувати, якщо думали, що типове значення `$int` — це `0`. Але програма також виводить попередження:

```
Use of uninitialized value $int of type Any in numeric context
  in block <unit> at t.raku line 2
5
```

Щоб було ясно, яке там значення, ви можете або присвоїти його самі:

```raku
my $int = 0;
say $int + 5; # 5
```

Або ви можете встановити типове значення за допомогою трейту `is default`:

```raku
my $int is default(0);
say $int + 5; # 5
```

Типове значення не мусить бути нулем. Це може бути будь-яке значення, яке ви вважаєте добрим вибором, наприклад:

```raku
my $int is default(1);
say $int + 5; # 6
```
