Щоб скористатися модулем, завантажте його оператором `use`. Після цього імена, які модуль експортує, стають доступними. Ви можете використовувати їх так, ніби написали їх самі.

Ось як програма використовує файл `Greeting.rakumod` з попередньої теми:

```raku
use Greeting;

say hello('Anna');
```

`hello` позначено як `is export`, тож оператор `use` робить її доступною. Програма викликає її напряму:

```
Hello, Anna!
```

Raku може знайти модуль, лише якщо той є на шляху пошуку модулів. Ваш файл модуля може лежати в тому самому каталозі, що й програма. У такому разі скажіть Raku шукати там за допомогою опції `-I.`. Крапка означає «поточний каталог»:

```console
$ raku -I. program.raku
Hello, Anna!
```

Raku знаходить встановлені модулі автоматично. Про них ідеться далі, у темі [Встановлення модулів із мережі](/uk/advanced/installing-modules). Тож опція `-I` вам потрібна лише для модулів, які лежать поруч із вашою власною програмою.
