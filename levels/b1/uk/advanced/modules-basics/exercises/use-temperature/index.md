## Завдання

У вас є модуль у файлі `Temperature.rakumod`:

```raku
unit module Temperature;

sub c-to-f($c) is export {
    $c * 9/5 + 32
}
```

Напишіть окрему програму, яка використовує цей модуль. Програма отримує температуру за Цельсієм як аргумент командного рядка. Вона переводить її в градуси Фаренгейта за допомогою модуля й виводить результат.

## Приклад

```console
$ raku -I. temperature.raku 100
212
```
