Коли програми ростуть, корисно розбити їх на частини, які можна використовувати знову. Кожен _модуль_ — це одиниця коду в окремому файлі. Інші програми можуть завантажувати й використовувати його.

Файл модуля має розширення `.rakumod`. Він починається з `unit module`, що дає модулю ім'я. Підпрограми всередині за замовчуванням приватні. Щоб поділитися однією з них із кодом, який використовує модуль, позначте її трейтом `is export`.

Ось модуль у файлі під назвою `Greeting.rakumod`:

```raku
unit module Greeting;

sub hello($name) is export {
    return "Hello, $name!";
}
```

Підпрограма `hello` має `is export`, тож її бачить будь-яка програма, яка використовує модуль. Без `is export` підпрограма лишилася б приватною для модуля.

Модуль також може ділитися даними через змінні `our`. Інший код може дістатися до них через ім'я модуля. Щоб додати до `Greeting` номер версії, досить ще одного рядка у файлі:

```raku
our $version = '1.0';
```

Коли цей рядок є в `Greeting.rakumod`, значення доступне як `$Greeting::version`. Це працює всюди, де завантажено модуль.

Наступні теми показують, [як програма завантажує такий модуль](/uk/advanced/modules-basics/using-modules). Також вони пояснюють, що саме програма від нього отримує.
