Який трейт дозволяє підпрограмі **змінювати змінну викликача** через параметр?

{:.quiz}
1 | `is rw`
0 | `is copy`
0 | `is default`
0 | жоден — параметри доступні для запису за замовчуванням

{% include quiz.html %}

<div class="extended-explanation">

За замовчуванням параметр доступний лише для читання, тож звичайному параметру нічого не можна присвоїти. `is rw` зв'язує параметр із власною змінною викликача. Тож зміну всередині підпрограми видно й ззовні. `is copy` натомість дав би вам *копію*, яку можна змінювати. Змінна викликача лишилася б недоторканою.

</div>
