_Трейт_ додають ключовим словом `is` одразу після оголошення. Він виконується під час компіляції. Він змінює сталу властивість того, до чого належить. Raku має багато трейтів, і кількома ви вже користувалися.

За замовчуванням параметри підпрограми доступні **лише для читання**. Усередині підпрограми їм не можна нічого присвоїти. Трейт `is copy` дає вам приватну копію аргументу, яку можна змінювати. Ця зміна не зачіпає того, хто викликав підпрограму:

```raku
sub greet($name is copy) {
    $name = "dear $name";
    say "Hello, $name!";
}

my $who = 'Anna';
greet($who); # Hello, dear Anna!
say $who;    # Anna — власна змінна викликача недоторкана
```

Трейт `is rw` іде далі. Він зв'язує параметр зі змінною викликача. Тож зміну всередині підпрограми видно й ззовні:

```raku
sub bump($n is rw) {
    $n++;
}

my $x = 10;
bump($x);
say $x; # 11
```

Без одного з цих трейтів `$n++` спричинив би помилку. Параметр був би доступний лише для читання.

Ще один поширений трейт задає типове значення:

```raku
my $port is default(8080);
say $port; # 8080
```

Тут `is default` дає змінній значення, яке діє, коли іншого значення немає. Є багато вбудованих трейтів, як-от `is rw`, `is copy` і `is default`. Кожен із них додає до оголошення одну конкретну поведінку під час компіляції. Наступна тема показує, що набір трейтів не закритий.
