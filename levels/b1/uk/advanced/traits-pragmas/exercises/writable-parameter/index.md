## Завдання

За замовчуванням параметри підпрограми доступні лише для читання. Це означає, що підпрограма не може змінити змінну викликача. Трейт `is rw` знімає це обмеження.

Напишіть підпрограму `double` з одним параметром, позначеним `is rw`. Підпрограма подвоює параметр на місці через `$n *= 2`. Викличте її зі змінною, яка містить `21`. Потім виведіть змінну, щоб показати, що вона стала `42`.

## Приклад

Програма виводить:

```
42
```
