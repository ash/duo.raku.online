Ось один із можливих розв'язків.

## Код

```raku
say (2 ** 1000).chars;
```

🦋 Вихідний код можна знайти у файлі [big-factorial.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/integers/big-factorial.raku).

## Вивід

```
302
```

## Коментарі

1. Raku обчислює `2 ** 1000` точно. Він не округлює число й не переповнюється, бо цілі числа мають довільну точність.

1. `chars` зазвичай є методом рядків. Коли ви викликаєте його для цілого числа, він спершу перетворює число на десятковий текст. Потім він рахує символи. Тут немає ні знака мінус, ні десяткової крапки. Тож кількість символів точно дорівнює кількості цифр, `302`.
