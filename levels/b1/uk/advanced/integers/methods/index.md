Цілі числа мають багато корисних методів і підпрограм. Ось кілька з тих, що вам часто знадобляться.

Метод `is-prime` перевіряє, чи є число простим:

```raku
say 17.is-prime; # True
say 18.is-prime; # False
```

Оператор `gcd` дає найбільший спільний дільник двох чисел. Оператор `lcm` дає їхнє найменше спільне кратне:

```raku
say 12 gcd 18; # 6
say 4 lcm 6;   # 12
```

Метод `abs` повертає абсолютне значення числа. Метод `sign` повертає `-1`, `0` або `1`. Це залежить від того, чи є число від'ємним, нулем або додатним:

```raku
say (-5).abs;  # 5
say (-5).sign; # -1
say 0.sign;    # 0
```
