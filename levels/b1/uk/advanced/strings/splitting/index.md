Є кілька способів розбити рядок на частини й знову їх з'єднати.

Метод `words` розбиває рядок за пробільними символами на список слів:

```raku
say 'Hello big World'.words; # (Hello big World)
```

Метод `split` розбиває рядок за роздільником, який ви вибираєте:

```raku
say 'a,b,c'.split(','); # (a b c)
```

Важливий особливий випадок — розбиття за **порожнім рядком** `''`. Воно розбиває рядок на окремі символи. Але воно також додає порожній рядок на самому початку і в самому кінці. Тож результат має на два елементи більше, ніж ви, можливо, чекаєте:

```raku
say 'abc'.split('').elems;        # 5 — три літери плюс порожній рядок з кожного боку
say 'abc'.split('', :skip-empty); # (a b c) — наріччя :skip-empty відкидає порожні
```

Щоб розбити рядок на символи, можна викликати метод `comb` без аргументів. Він робить це напряму, і немає зайвих порожніх рядків, які треба прибирати:

```raku
say 'Raku'.comb; # (R a k u)
```

Щоб піти у зворотний бік, використовуйте метод `join`. Він склеює список значень в один рядок і ставить між ними роздільник:

```raku
say <a b c>.join('-'); # a-b-c
```

Ще два методи працюють із частинами рядка. Метод `substr` повертає шматок рядка. Ви даєте йому початкову позицію і, якщо хочете, довжину:

```raku
say 'Hello World'.substr(0, 5); # Hello
say 'Hello World'.substr(6);    # World
```

А `trim` прибирає пробільні символи на початку і в кінці рядка:

```raku
say '  hi  '.trim; # hi
```
