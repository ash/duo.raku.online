У частині «Основи» ви дізналися, [як будувати рядки](/uk/essentials/strings). Ви бачили конкатенацію, інтерполяцію та довжину рядка. Рядки також мають великий набір методів. Цей розділ збирає найкорисніші з них. Пошук за [регулярними виразами](/uk/regexes) — окрема, більша тема. Вона розглядається у власній частині далі.

Три методи змінюють регістр літер у рядку:

```raku
say 'raku'.uc; # RAKU  — верхній регістр
say 'RAKU'.lc; # raku  — нижній регістр
say 'raku'.tc; # Raku  — заголовний регістр (перша літера велика)
```

Метод `flip` змінює порядок символів у рядку на зворотний:

```raku
say 'Raku'.flip; # ukaR
```

А оператор `x` повторює рядок стільки разів, скільки ви попросите:

```raku
say 'ab' x 3; # ababab
```

Наступні теми показують, як шукати всередині рядків. Вони також показують, як розбивати рядки на частини й склеювати їх назад.
