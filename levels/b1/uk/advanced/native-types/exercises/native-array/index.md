## Завдання

Природне застосування машинного типу фіксованого розміру — масив байтів. Такий масив займає мало пам'яті. Оголосіть масив `uint8` зі значеннями `100`, `200` і `255`. Кожне з них вміщується в один байт. Потім виведіть суму його елементів.

Зверніть увагу: кожен елемент лишається в діапазоні `0..255`, але сума може бути більшою. Це тому, що `.sum` повертає звичайний `Int`.

## Приклад

Програма виводить:

```
555
```
