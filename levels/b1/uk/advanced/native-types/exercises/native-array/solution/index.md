Ось один із можливих розв'язків.

## Код

```raku
my uint8 @bytes = 100, 200, 255;
say @bytes.sum;
```

🦋 Вихідний код можна знайти у файлі [native-array.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/native-array.raku).

## Вивід

```
555
```

## Коментарі

1. Машинний тип фіксованого розміру `uint8` стоїть перед масивом із `@`. Це оголошує масив, у якому кожен елемент — один беззнаковий байт. Він займає мало пам'яті, і це добре для двійкових даних.

1. Межа загортання `0..255` діє для кожного *елемента*, але не для їхньої суми. `.sum` упаковує суму у звичайний `Int`. Тож `100 + 200 + 255` дає повні `555`.
