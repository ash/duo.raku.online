Ось один із можливих розв'язків.

## Код

```raku
my num $n;
my str $s;

say $n;
say "[$s]";
```

🦋 Вихідний код можна знайти у файлі [native-default.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/native-default.raku).

## Вивід

```
0
[]
```

## Коментарі

1. Машинний `num` не може бути невизначеним. Тож, як і машинний `int`, він починає з `0`, а не з `(Num)`.

1. Машинний `str` починає з порожнього рядка. Саме тому у виводі між дужками нічого немає. Жоден машинний тип ніколи не містить невизначеного значення.

1. Назви типів тут дуже важливі. Якщо прибрати їх і написати `my $n; my $s;`, змінні стануть звичайними контейнерами. Спочатку вони *невизначені* (`Any`). Тоді `say $n` виводить `(Any)`. Інтерполяція невизначеної `$s` теж дає попередження: *«Use of uninitialized value … in string context»*. Тільки машинні типи `num` і `str` дають типові значення `0` і порожній рядок.
