Ось один із можливих розв'язків.

## Код

```raku
say <a b c>.reverse.join: '-';
```

🦋 Вихідний код можна знайти у файлі [colon-join.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/colon-calls/colon-join.raku).

## Вивід

```
c-b-a
```

## Коментарі

1. `.reverse` стоїть посередині ланцюжка, тож зберігає свою звичайну форму. `join` іде останнім, тож може використати двокрапку. Він передає `'-'` точно так само, як `join('-')`.

1. Обернений список, `c, b, a`, потім з'єднується дефісами, що дає `c-b-a`. Форма з двокрапкою працює зі звичайними значеннями, а не лише з блоками.
