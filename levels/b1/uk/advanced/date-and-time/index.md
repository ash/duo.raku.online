У Raku є вбудовані типи для календарних дат і часу на годиннику. Календарна дата має тип `Date`. Щоб створити її, ви вказуєте рік, місяць і день:

```raku
my $d = Date.new(2026, 6, 27);
say $d; # 2026-06-27
```

Коли у вас є дата, ви можете прочитати її частини:

```raku
my $d = Date.new(2026, 6, 27);
say $d.year;  # 2026
say $d.month; # 6
say $d.day;   # 27
```

Метод `day-of-week` каже, на який день тижня припадає дата. Він дає число від `1` для понеділка до `7` для неділі:

```raku
say Date.new(2026, 6, 27).day-of-week; # 6
```

27 червня 2026 року — субота, тому результат — `6`.

Метод `is-leap-year` перевіряє, чи є рік цієї дати високосним:

```raku
say Date.new(2024, 1, 1).is-leap-year; # True
say Date.new(2026, 1, 1).is-leap-year; # False
```

Викличте `Date.today`, щоб отримати сьогоднішню дату. Її вивід тут не показано. Він залежить від того, в який день ви запускаєте програму.
