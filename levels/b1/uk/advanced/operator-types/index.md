Ви вже використовували багато операторів, наприклад `+`, `~` і `++`. Операнди — це значення, з якими працює оператор. У Raku оператори ділять на категорії за тим, _де_ вони стоять відносно своїх операндів. Знання категорій допоможе вам пізніше, коли ви створюватимете власні оператори.

## `prefix`

Префіксний оператор стоїть _перед_ своїм єдиним операндом:

```raku
my $x = 5;
say -$x; # -5
say ?$x; # True
```

Тут `-` змінює знак числа. Оператор `?` перетворює значення на його булеве значення.

## `infix`

Інфіксний оператор стоїть _між_ двома операндами. Більшість арифметичних і рядкових операторів, які ви знаєте, працюють саме так:

```raku
say 3 + 4;       # 7
say 'a' ~ 'b';   # ab
```

Інфіксний оператор не мусить бути символом. Він може бути й словом. Наприклад, оператор `gcd` із розділу про [цілі числа](/uk/advanced/integers) є інфіксним оператором. Це ім'я, яке ви пишете між двома його операндами:

```raku
say 12 gcd 18;   # 6
```

## `postfix`

Постфіксний оператор стоїть _після_ свого єдиного операнда:

```raku
my $x = 5;
$x++;
say $x; # 6
```

## `circumfix` та `postcircumfix`

Циркумфіксний оператор стоїть _навколо_ свого операнда. Квадратні дужки, які створюють масив, — це приклад:

```raku
my @a = [1, 2, 3];
```

Постциркумфіксний оператор теж стоїть навколо чогось, але йде після терма. Індекс, наприклад `[1]` після `@a`, є постциркумфіксним оператором:

```raku
my @a = 10, 20, 30;
say @a[1]; # 20
```

Ось назви категорій: `prefix`, `infix`, `postfix`, `circumfix` і `postcircumfix`. Як ви побачите пізніше, Raku використовує ці самі слова, щоб [оголосити новий оператор](/uk/advanced/user-defined-operators).
