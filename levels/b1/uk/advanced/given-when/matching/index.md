Блок `when` не лише перевіряє, чи рівні два значення. Він робить _розумне зіставлення_ між топіком і значенням, яке ви йому даєте. Тож зіставляти можна з діапазонами, типами й умовами, а не тільки з окремими значеннями.

## Діапазони

Діапазон збігається, коли топік лежить усередині нього. Тому `given`/`when` — природний вибір, щоб ділити числа на групи:

```raku
my $score = 75;

given $score {
    when 90..100 { say 'A' }
    when 80..89  { say 'B' }
    when 70..79  { say 'C' }
    default      { say 'F' }
}
```

Значення `75` лежить у діапазоні `70..79`, тож програма виводить:

```
C
```

## Типи

Тип збігається, коли топік належить до цього типу. Тож програма може вибирати гілку за тим, яке значення вона має:

```raku
my $value = 'Raku';

given $value {
    when Int { say 'an integer' }
    when Str { say 'a string' }
}
```

`$value` містить рядок, тож програма виводить:

```
a string
```

## Умови

Можна також написати порівняння прямо. Усередині `when` топік можна використовувати як `$_`. Тож умова на кшталт `$_ < 0` збігається, коли вона істинна:

```raku
my $n = -7;

given $n {
    when $_ < 0 { say 'negative' }
    when 0      { say 'zero' }
    default     { say 'positive' }
}
```

Тут збігається перший `when`, і програма виводить:

```
negative
```
