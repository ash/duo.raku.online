Іноді програмі треба вибрати з кількох варіантів. Тоді ланцюжок перевірок `if` і `elsif` може стати довгим і повним повторів. У таких випадках `given`/`when` часто зрозуміліший. Він схожий на оператор `switch` з інших мов.

Блок `given` бере значення і робить його _топіком_. Топік — це спеціальна змінна `$_`. Потім кожен блок `when` порівнюється з цим топіком. Виконується перший, що збігся:

```raku
my $n = 2;

given $n {
    when 1 { say 'one' }
    when 2 { say 'two' }
    when 3 { say 'three' }
}
```

Ця програма виводить:

```
two
```

На відміну від `switch` у деяких мовах, тут немає провалювання до наступного випадку. Щойно якийсь `when` збігся, виконується його блок, і блок `given` завершується. Інші блоки `when` не перевіряються.

## Блок `default`

Блок `default` виконується, коли не збігся жоден із блоків `when`. Він робить ту саму роботу, що й гілка `else` в операторі `if`:

```raku
my $n = 5;

given $n {
    when 1 { say 'one' }
    when 2 { say 'two' }
    default { say 'many' }
}
```

`$n` не дорівнює ні `1`, ні `2`, тож програма виводить:

```
many
```
