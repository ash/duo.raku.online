Ось один із можливих розв'язків.

## Код

```raku
my $n = 12;

given $n {
    when 0      { say 'zero' }
    when $_ %% 2 { say 'even' }
    default     { say 'odd' }
}
```

🦋 Вихідний код можна знайти у файлі [sign-of-a-number.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/given-when/sign-of-a-number.raku).

## Вивід

```
even
```

## Коментарі

1. `when 0` збігається лише зі значенням нуль. Він іде першим, бо нуль теж парний, а ми хочемо повідомити про нього окремо.

1. `when $_ %% 2` — це умова, де `$_` — топік, який задає `given`. Оператор `%%` перевіряє, чи ділиться топік на два націло. Значення `12` — не нуль, але воно ділиться на два, тож програма виводить `even`.

1. `default` охоплює все, що залишилося. Це числа, які не є ні нулем, ні парними, тобто непарні.
