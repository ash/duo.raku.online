## Завдання

`when` може зіставлятися з *типом*, а не лише зі значенням. Змінна містить число `3.14`. Використайте `given`/`when`, щоб показати, що це за значення. Виведіть `integer` для `Int`, `rational` для `Rat` і `string` для `Str`.

## Приклад

Програма виводить:

```
rational
```
