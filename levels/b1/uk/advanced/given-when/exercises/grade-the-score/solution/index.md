Ось один із можливих розв'язків.

## Код

```raku
my $age = 30;

given $age {
    when $_ < 0 { say 'invalid' }
    when 0..12  { say 'child' }
    when 13..19 { say 'teenager' }
    when 20..64 { say 'adult' }
    default     { say 'senior' }
}
```

🦋 Вихідний код можна знайти у файлі [grade-the-score.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/given-when/grade-the-score.raku).

## Вивід

```
adult
```

## Коментарі

1. Це розв'язання поєднує два види `when`. Перший — це *умова*, `$_ < 0`, де `$_` — топік, який задає `given`. Вона відсіює недійсний вік. Решта — це *діапазони*, які групують дійсний вік за етапами.

1. Порядок має значення. Перевірка на від'ємний вік іде першою. Тож вона виконується раніше, ніж програма пробує будь-який діапазон. Значення `30` входить у `20..64`, тож програма виводить `adult`.

1. Блок `default` охоплює будь-який вік від 65 і вище. Жоден із перелічених діапазонів не ловить такий вік.

Можна також зробити навпаки й дозволити `default` ловити *недійсний* ввід. Перелічіть кожен відомий етап, разом із `senior` як умовою `$_ >= 65`. Усе, що залишилося, наприклад від'ємний вік, вважайте недійсним:

```raku
given $age {
    when 0..12    { say 'child' }
    when 13..19   { say 'teenager' }
    when 20..64   { say 'adult' }
    when $_ >= 65 { say 'senior' }
    default       { say 'invalid' }
}
```

Тут `default` — справжня гілка «жодне з переліченого». Який варіант читається краще — справа смаку. Ставте перевірку першою, коли недійсний випадок — виняток. Або зробіть цей випадок блоком `default`, коли всі дійсні етапи чітко перелічено.
