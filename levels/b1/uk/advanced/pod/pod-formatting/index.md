У тексті Pod ви розмічуєте слова однолітерними _кодами форматування_. Ви пишете літеру, а потім кутові дужки навколо тексту:

* `B<…>` — жирний
* `I<…>` — курсив
* `C<…>` — код (усі літери однакової ширини)
* `L<…>` — посилання

```raku
=begin pod

This is B<important>, and C<say> is a built-in.

=end pod
```

Після відображення `important` показано жирним, а `say` — шрифтом коду. Коди можна вкладати один в одного й поєднувати, тож `B<C<say>>` — це жирний код.

Іноді вам потрібен цілий блок коду, а не лише шматок усередині рядка. Тоді використайте блок коду з чіткими рядками початку й кінця, `=begin code … =end code`. Він зберігає текст точно так, як його записано:

```raku
=begin pod

Here is how to call it:

=begin code
say greet('world');
=end code

=end pod
```

Рядки всередині блоку коду показано точно так, як їх записано. Їх не читають як Pod. Разом із кодами всередині рядків і блоками коду Pod може документувати API. Він може містити форматований текст і приклади, схожі на справжній робочий код. Усе це лежить поруч із кодом, який воно описує.
