Тепер у вас є два способи організувати поведінку: _підпрограма_ й _метод_. Вони схожі на вигляд, але ви використовуєте їх по-різному.

Підпрограма стоїть сама по собі. Ви викликаєте її за іменем і передаєте їй усе потрібне як аргументи:

```raku
sub area-of($radius) {
    π * $radius * $radius;
}

say area-of(2); # 12.566370614359172
```

Метод належить класу. Ви викликаєте його для об'єкта через крапку. Він може використовувати власні дані об'єкта через `self` та аксесори атрибутів. Тож ці дані не треба передавати:

```raku
class Circle {
    has $.radius;

    method area {
        π * $.radius * $.radius;
    }
}

say Circle.new(radius => 2).area; # 12.566370614359172
```

Обидва обчислюють те саме число. Різниця в тому, звідки беруться дані. Підпрограма отримує радіус як аргумент. Метод читає його з об'єкта, для якого його викликали.

Ось просте правило. Використовуйте підпрограму для окремої операції, яка просто перетворює свої аргументи на результат. Використовуйте метод, коли поведінка належить об'єкту й використовує його дані. Для загальних підпрограм, які належать класу загалом, використовуйте методи класу.
