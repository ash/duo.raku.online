## Завдання

Блок `try`, який не спрацьовує, дає невизначене значення. Використайте це з оператором «визначене або» `//`, щоб дати запасне значення. Виконайте блок `try` з `die 'no'` усередині. Якщо він не спрацює, використайте натомість рядок `default`. Виведіть результат.

## Приклад

Програма виводить:

```
default
```
