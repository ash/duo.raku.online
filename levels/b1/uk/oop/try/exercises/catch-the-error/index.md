## Завдання

Покажіть обидві сторони `try`. Спершу оберніть блоком `try` обчислення, яке спрацьовує, наприклад `6 * 7`. Потім виведіть його результат. Далі покладіть код, який виконує `die 'broken'`, у другий блок `try`. Виведіть, чи дав цей блок визначений результат. Потім виведіть повідомлення перехопленого винятку.

## Приклад

Програма виводить:

```
42
False
broken
```
