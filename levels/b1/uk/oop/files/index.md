У найпростішому випадку ви читаєте або записуєте весь файл за раз.

Підпрограма `spurt` записує рядок у файл. Вона створює файл або замінює його вміст, якщо файл уже існує:

```raku
spurt 'greeting.txt', "Hello, file!\n";
```

Підпрограма `slurp` читає весь файл назад у рядок:

```raku
my $text = slurp 'greeting.txt';
print $text; # Hello, file!
```

Разом `spurt` і `slurp` зберігають дані й знову завантажують їх лише двома короткими викликами. Тут ми використовуємо `print` замість `say`, бо текст уже закінчується символом нового рядка.

Ці підпрограми працюють з усім файлом за раз. Вони найкраще підходять для файлів, які досить малі, щоб легко вміститися в пам'ять. Для більших файлів використовують [дескриптор файлу](/uk/oop/file-handles). Він також потрібен, щоб працювати з файлом рядок за рядком. Ми розглянемо дескриптори файлів наприкінці цього розділу. Наступна тема показує, як додавати до файлу, а не замінювати його.
