За замовчуванням `spurt` замінює все, що було у файлі. Щоб натомість додати щось у кінець наявного файлу, передайте іменований аргумент `:append`:

```raku
spurt 'log.txt', "line1\n";
spurt 'log.txt', "line2\n", :append;

print slurp 'log.txt';
```

Другий `spurt` зберігає старий вміст і додає новий рядок після нього. Тож зрештою файл містить обидва рядки:

```
line1
line2
```

Без `:append` другий виклик перезаписав би файл. Лишився б тільки `line2`. Дописування в кінець корисне для таких речей, як файли журналу. Кожен запуск програми доповнює запис, який росте, замість того щоб починати знову.
