## Завдання

Створіть невеликий файл журналу, знову й знову додаючи до нього рядки. Запишіть рядок `start` у файл під назвою `log.txt`. Потім у циклі **допишіть** ще три рядки: `entry 1`, `entry 2` і `entry 3`. Не стирайте того, що вже є у файлі. Нарешті прочитайте весь файл і виведіть його.

## Приклад

Програма виводить:

```
start
entry 1
entry 2
entry 3
```
