_Успадкування_ дозволяє одному класу будуватися на іншому. Після імені нового класу ви пишете `is` та ім'я іншого класу. Тоді новий клас успадковує всі атрибути й методи цього класу. Цей клас називають його _батьківським_ (або _базовим_) класом.

```raku
class Animal {
    has $.name;
    method speak {
        'some sound';
    }
}

class Dog is Animal {
}
```

`Dog is Animal` означає, що `Dog` — це різновид `Animal`. Клас `Dog` не має власного коду. Але він уже має атрибут `name` і метод `speak` від `Animal`:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.name;  # Rex
say $rex.speak; # some sound
```

Об'єкт `Dog` також вважається об'єктом `Animal`:

```raku
say Dog.new ~~ Animal; # True
```

Розумне зіставлення `~~` з типом істинне, якщо об'єкт має цей тип. Воно також істинне, якщо об'єкт успадковує від цього типу. У наступній темі дочірній клас замінює успадкований метод власною версією.
