Блок `try` зручний, але він розглядає весь блок як одне ціле. Блок або спрацьовує, або ні. Фазер `CATCH` дає вам більше контролю. Він дозволяє обробити виняток _усередині_ того блоку, де той стався. Потім ви вирішуєте, що робити.

`CATCH` — це фазер, як ті, що ви бачили в [розділі про порядок виконання](/uk/advanced/phasers). Його можна поставити будь-де всередині блоку. Він виконується, лише якщо в цьому блоці кинуто виняток. Виняток ви отримуєте як змінну-топік `$_`:

```raku
{
    die 'Boom!';

    CATCH {
        default {
            say 'Caught: ' ~ .message;
        }
    }
}

say 'after';
```

Програма виводить:

```
Caught: Boom!
after
```

Блок `default` усередині `CATCH` обробляє будь-який виняток. Після того як він виконався, виняток вважається обробленим. Тож програма не зупиняється. Вона продовжує роботу після блоку, у якому стоїть `CATCH`, і тому виводиться `after`.

Без `CATCH` виклик `die` завершив би програму раніше, ніж вона дійшла б до `after`.
