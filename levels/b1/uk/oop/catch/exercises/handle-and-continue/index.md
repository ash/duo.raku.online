## Завдання

Пройдіть циклом три елементи: `ok`, `bad` та `ok`. Для кожного елемента виконайте блок, який виводить `processed <item>`. Але коли елемент дорівнює `bad`, блок має робити `die 'boom'`. Помістіть усередину блоку фазер `CATCH`. Він має повідомляти про невдалий елемент як `skipped (<item>): <message>`. Потім цикл переходить до наступного елемента, а не зупиняється.

## Приклад

Програма виводить:

```
processed ok
skipped (bad): boom
processed ok
```
