## Завдання

Напишіть підпрограму `risky`, яка робить `die 'sub failed'`. Потім викличте її зсередини блоку, що має фазер `CATCH`. `CATCH` має вивести ім'я типу винятку через `.^name`. Потім він має вивести його повідомлення через `.message`. Це показує, що `CATCH` обробляє винятки з коду, який блок *викликає*. `die` не мусить бути записаним безпосередньо в блоці.

## Приклад

Програма виводить:

```
X::AdHoc
sub failed
```
