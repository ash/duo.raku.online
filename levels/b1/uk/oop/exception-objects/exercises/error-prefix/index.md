## Завдання

Напишіть блок, який робить `die 'timeout'`. Додайте фазер `CATCH`, який виводить повідомлення перехопленого винятку. Поставте `Error: ` перед повідомленням.

## Приклад

Програма виводить:

```
Error: timeout
```
