## Завдання

Програма працює зі значенням, і це значення виявляється від'ємним. Якщо значення менше за нуль, використайте `note`, щоб надіслати попередження у стандартний потік помилок. Використайте `say`, щоб надіслати справжній результат, абсолютне значення, у стандартний вивід. Візьміть значення `-3`.

## Приклад

Обидва рядки з'являються на екрані:

```
Warning: the value is negative
3
```

Якщо відкинути стандартний потік помилок, лишається тільки результат:

```
$ raku note-a-warning.raku 2>/dev/null
3
```
