## Завдання

Програма в циклі підсумовує список чисел `3, 5, 7`. На кожному проході надсилайте поточну накопичену суму у стандартний потік помилок як повідомлення про прогрес. Після циклу надішліть остаточний результат у стандартний вивід. Використовуйте дескриптори потоків напряму.

Це розділення важливе. Результат можна зберегти або передати далі іншій програмі. Тим часом повідомлення про прогрес лишаються у стандартному потоці помилок і не заважають.

## Приклад

Коли ви запускаєте програму, на екрані з'являються обидва потоки. Спочатку йдуть накопичені суми, а потім остаточний результат:

```
running total: 3
running total: 8
running total: 15
15
```

Але якщо відкинути стандартний потік помилок, лишається тільки справжній результат:

```
$ raku output-and-error.raku 2>/dev/null
15
```
