Ось один із можливих розв'язків.

## Код

```raku
my @data = 3, 5, 7;

my $sum = 0;
for @data -> $n {
    $sum += $n;
    $*ERR.say("running total: $sum");
}

$*OUT.say($sum);
```

🦋 Вихідний код можна знайти у файлі [output-and-error.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/standard-streams/output-and-error.raku).

## Вивід

На екрані з'являються обидва потоки. Спочатку йдуть накопичені суми, а потім остаточний результат:

```
running total: 3
running total: 8
running total: 15
15
```

Якщо відкинути стандартний потік помилок, лишається тільки справжній вивід:

```
$ raku output-and-error.raku 2>/dev/null
15
```

## Коментарі

1. `$*OUT` і `$*ERR` — це дескриптори стандартного виводу й стандартного потоку помилок. Кожен із них має власний метод `say`.

1. Кожен прохід додає наступне число й пише накопичену суму в `$*ERR`. Лише остаточна сума йде в `$*OUT`. На екрані прогрес і результат виглядають однаково. Але вони йдуть різними потоками. Тож коли `2>/dev/null` прибирає стандартний потік помилок, лишається тільки остаточне `15`.
