_Роль_ — це частина поведінки, а іноді й даних, яку можуть спільно використовувати кілька класів. Успадкування каже, що клас _є_ різновидом іншого класу. А роль, навпаки, описує те, що клас _уміє робити_.

Роль визначають ключовим словом `role`, так само як клас. Щоб надати її класу, використовують трейт `does`:

```raku
role Greet {
    method hello {
        'Hello from ' ~ self.name;
    }
}

class Person does Greet {
    has $.name;
}
```

Клас `Person` тепер має метод `hello` з ролі. Він працює так, наче ви написали його в самому класі:

```raku
say Person.new(name => 'Anna').hello; # Hello from Anna
```

Якщо клас виконує роль, Raku бачить, що він має цю роль:

```raku
say Person.new(name => 'Anna') ~~ Greet; # True
```

Зверніть увагу, що метод `hello` ролі використовує `self.name`. Але сама роль не має атрибута `name`. Це нормально. Метод виконується як частина того класу, який компонує роль. А цей клас надає `name`. Наступна тема показує, що клас може мати кілька ролей одночасно.
