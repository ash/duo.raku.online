## Завдання

Визначте клас `Robot` з методом `speak`, який повертає `beep`. Потім визначте роль `Dancing`, яка додає метод `dance`, що повертає `spinning around`.

Створіть двох роботів, але надайте роль `Dancing` лише одному з них. Виведіть результат `speak` для обох роботів. Потім виведіть результат `dance` для робота, який уміє танцювати.

## Приклад

Програма виводить:

```
beep
beep
spinning around
```
