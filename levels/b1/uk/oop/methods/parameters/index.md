Як і підпрограма, метод може приймати параметри. Ви пишете їх у дужках після імені методу:

```raku
class Account {
    has $.balance is rw = 0;

    method deposit($amount) {
        $.balance += $amount;
    }
}
```

Метод `deposit` приймає один параметр, `$amount`. Він додає цю суму до балансу об'єкта:

```raku
my $a = Account.new;
$a.deposit(100);
$a.deposit(50);
say $a.balance; # 150
```

Кожен виклик працює з тим об'єктом, для якого його зробили. Тож той самий метод може окремо оновлювати різні об'єкти. Методи можуть мати позиційні та іменовані параметри й типові значення. Насправді вони можуть використовувати все, що ви вже бачили в сигнатурах підпрограм.
