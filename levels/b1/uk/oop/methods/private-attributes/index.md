У [розділі про атрибути](/uk/oop/attributes) ми оголошували кожен атрибут через `$.`. Це створює публічний аксесор. Якщо ж оголосити атрибут через `$!`, він _приватний_. Він не має аксесора, і ззовні об'єкта його не видно. Дістатися до нього можуть лише власні методи класу. Там ви пишете його як `$!name`.

```raku
class Safe {
    has $!code = 4321;

    method unlocks($attempt) {
        return $attempt == $!code;
    }
}

my $safe = Safe.new;
say $safe.unlocks(4321); # True
say $safe.unlocks(1111); # False
```

Таємний `$!code` зберігається всередині об'єкта, але ніколи не показується назовні. Аксесора `.code` немає. Тож працювати з ним можна лише через метод `unlocks`. Клас сам вирішує надати цей метод. Якщо ви спробуєте прочитати `$safe.code` чи `$safe!code`, це просто не вдасться.

Приватні атрибути корисні для внутрішніх деталей. Решта програми не повинна працювати з цими деталями напряму.
