Атрибути дають об'єкту дані, а _методи_ дають йому поведінку. Метод — це підпрограма, яка належить класу. Ви викликаєте її для об'єкта. Ви оголошуєте метод ключовим словом `method`:

```raku
class Dog {
    has $.name;

    method bark {
        return $.name ~ ' says Woof!';
    }
}
```

Щоб викликати метод для об'єкта, використайте крапку, як з аксесором:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.bark; # Rex says Woof!
```

Усередині методу `self` — це об'єкт, для якого викликали метод. До атрибутів ви дістаєтеся через їхні аксесори. Ви пишете їх як `$.name`, `$.age` тощо. Вони працюють і всередині рядків у подвійних лапках, де Raku вставляє їхні значення:

```raku
class Dog {
    has $.name;

    method greet {
        "Hello, my name is $.name";
    }
}

say Dog.new(name => 'Rex').greet; # Hello, my name is Rex
```

Наступні теми розповідають про приватні атрибути, бо тепер ми маємо методи, щоб ними користуватися. Потім вони розповідають про методи з параметрами та про методи, які викликають інші методи.
