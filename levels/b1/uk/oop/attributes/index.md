Порожній клас не дуже корисний. Щоб об'єкт міг зберігати власні дані, дайте класу _атрибути_. Ви оголошуєте атрибут усередині класу ключовим словом `has`:

```raku
class Dog {
    has $.name;
    has $.age;
}
```

Кожен об'єкт класу має власну копію цих атрибутів. Їхні значення ви задаєте, коли створюєте об'єкт. Для цього передайте їх до `new` як іменовані аргументи:

```raku
class Dog {
    has $.name;
    has $.age;
}

my $rex = Dog.new(name => 'Rex', age => 3);
```

`$.` у `has $.name` робить дві речі водночас. Він оголошує атрибут і створює метод із тим самим ім'ям. Цей метод називають _аксесором_, і він повертає значення атрибута:

```raku
say $rex.name; # Rex
say $rex.age;  # 3
```

Різні об'єкти зберігають власні значення, які не залежать одне від одного:

```raku
my $rex  = Dog.new(name => 'Rex',  age => 3);
my $fido = Dog.new(name => 'Fido', age => 5);

say $rex.name;  # Rex
say $fido.name; # Fido
```

Наступні теми показують, як дозволити змінювати атрибути. Вони також показують, як дати атрибутам типові значення. Є також спосіб оголосити _приватні_ атрибути, яких не видно ззовні. Ми повернемося до них, коли познайомимося з методами.
