Ви можете дати атрибуту _типове значення_. Його використовують, коли ви створюєте об'єкт без значення для цього атрибута. Запишіть типове значення після атрибута через `=`:

```raku
class Dog {
    has Str $.name;
    has Rat $.weight = 4.0;
}
```

Зверніть увагу, що атрибутам можна задати тип, так само як змінним.

Коли ви не передаєте `weight` до `new`, атрибут отримує своє типове значення:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.weight; # 4
```

Ви все одно можете замінити типове значення, якщо передасте своє:

```raku
my $lighty = Dog.new(name => 'Lighty', weight => 3.2);
say $lighty.weight; # 3.2
```

Атрибут без типового значення і без значення з `new` просто невизначений. Він точно такий, як нова скалярна змінна.
