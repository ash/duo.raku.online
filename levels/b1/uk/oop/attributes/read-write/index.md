За замовчуванням аксесор, який створює `has $.name`, доступний _лише для читання_. Конструктор, `new`, задає значення, коли створює об'єкт. Після цього код поза об'єктом може читати значення, але не може його змінити. Присвоєння йому — помилка:

```raku
class Dog {
    has $.name;
}

my $rex = Dog.new(name => 'Rex');
$rex.name = 'Max';
```

Програма зупиняється з таким повідомленням:

```
Cannot modify an immutable Str (Rex)
```

Ви хочете змінювати значення через аксесор? Тоді позначте атрибут трейтом `is rw`:

```raku
class Dog {
    has $.name is rw;
}

my $rex = Dog.new(name => 'Rex');
$rex.name = 'Max';
say $rex.name; # Max
```

Тепер аксесор повертає контейнер, у який можна записувати. Тож присвоєння працює, і `name` об'єкта змінюється на `Max`.
