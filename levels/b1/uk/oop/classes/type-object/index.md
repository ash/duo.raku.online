Ім'я класу, наприклад `Dog`, означає _об'єкт типу_ цього класу. Об'єкт типу представляє сам тип. Це не якийсь конкретний об'єкт цього типу. А _екземпляр_, який ви створюєте через `new`, — це справжній об'єкт.

Raku вміє бачити різницю між ними. Метод `defined` повертає `False` для об'єкта типу й `True` для екземпляра:

```raku
class Dog {
}

say Dog.defined;     # False
say Dog.new.defined; # True
```

Об'єкт типу вважається _невизначеним_, бо не містить справжніх даних. Він лише описує тип. Екземпляр _визначений_, бо це справжній об'єкт.

З `WHAT` обидва показують той самий тип. Ви вже знайомилися з `WHAT` у [розділі про контейнери](/uk/advanced/containers):

```raku
class Dog {
}

say Dog.WHAT;     # (Dog)
say Dog.new.WHAT; # (Dog)
```

Raku показує тип у дужках, як у `(Dog)`. Тож `Dog` і `Dog.new` мають той самий тип, `Dog`. Але між ними є різниця. `Dog` — це сам тип, а `Dog.new` — об'єкт цього типу.
