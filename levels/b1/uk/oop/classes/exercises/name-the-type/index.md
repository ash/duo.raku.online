## Завдання

Визначте два порожні класи, `Cat` та `Dog`, і створіть екземпляр `Cat` з ім'ям `$felix`. Виведіть тип `$felix` за допомогою `WHAT`. Потім скористайтеся оператором `===` і виведіть ще два рядки. Перший рядок показує, чи цей тип той самий, що й `Cat`. Другий показує, чи він той самий, що й `Dog`.

## Приклад

Програма виводить:

```
(Cat)
True
False
```
