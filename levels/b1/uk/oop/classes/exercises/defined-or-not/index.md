## Завдання

Визначте два порожні класи, `Cat` та `Dog`. Потім пройдіть циклом по чотирьох значеннях: `Cat`, `Dog`, `Cat.new` та `Dog.new`. Для кожного з них виведіть, чи воно визначене. Зверніть увагу, що два об'єкти типу невизначені, а два екземпляри визначені. Не важливо, до якого класу вони належать.

## Приклад

Програма виводить:

```
False
False
True
True
```
