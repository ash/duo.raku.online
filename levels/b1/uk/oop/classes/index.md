Досі всі типи даних, якими ви користувалися, були вбудовані в Raku. Це були числа, рядки, масиви тощо. З _об'єктно-орієнтованим програмуванням_ ви можете визначати власні типи, які називають _класами_. Ви також можете створювати значення цих типів, які називають _об'єктами_.

Щоб визначити клас, напишіть ключове слово `class`, а потім ім'я та блок:

```raku
class Dog {
}
```

Цей клас `Dog` ще порожній, але це вже новий тип. Об'єкт класу також називають _екземпляром_. Щоб створити екземпляр, викличте метод `new` для імені класу:

```raku
class Dog {
}

my $rex = Dog.new;
say $rex; # Dog.new
```

Тепер `$rex` містить об'єкт `Dog`. Щоразу, коли ви викликаєте `new`, ви отримуєте новий, окремий об'єкт:

```raku
my $rex = Dog.new;
my $fido = Dog.new;
```

`$rex` і `$fido` — два різні пси, хоча клас ще порожній. У наступних розділах ви дасте класу власні дані, які називають _атрибутами_. Ви також дасте йому власну поведінку, яку називають _методами_. Перша тема уважніше розглядає, чим клас відрізняється від своїх екземплярів.
