## Завдання

Запишіть три слова `apple`, `banana` і `cherry` у файл під назвою `words.txt`. Поставте кожне слово на окремий рядок. Потім прочитайте файл рядок за рядком. Виведіть кожен рядок із його номером попереду, починаючи з `1`. Використайте форму `<номер>: <рядок>`.

## Приклад

Програма виводить:

```
1: apple
2: banana
3: cherry
```
