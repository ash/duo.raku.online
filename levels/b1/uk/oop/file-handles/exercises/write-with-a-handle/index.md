## Завдання

Відкрийте файл під назвою `out.txt` для запису. Тримайте дескриптор відкритим. У циклі запишіть у нього числа `1`, `2` і `3`. Поставте кожне число на окремий рядок. Потім закрийте дескриптор, прочитайте файл назад і виведіть його вміст.

## Приклад

Програма виводить:

```
1
2
3
```
