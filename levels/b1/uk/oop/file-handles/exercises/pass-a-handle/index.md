## Завдання

Дескриптор файлу — це звичайне значення. Тож його можна передати функції, як будь-який інший аргумент. Напишіть підпрограму `log-line`, яка приймає дескриптор і повідомлення. Вона має записати повідомлення в дескриптор окремим рядком.

Відкрийте `log.txt` для запису. Викличте `log-line` тричі, щоб записати `started`, `working` і `done`. Потім закрийте дескриптор, прочитайте файл назад і виведіть його вміст.

## Приклад

Програма виводить:

```
started
working
done
```
