Ось один із можливих розв'язків.

## Код

```raku
sub log-line($fh, $message) {
    $fh.say($message);
}

my $fh = open 'log.txt', :w;
log-line($fh, 'started');
log-line($fh, 'working');
log-line($fh, 'done');
$fh.close;

print slurp 'log.txt';
```

🦋 Вихідний код можна знайти у файлі [pass-a-handle.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/file-handles/pass-a-handle.raku).

## Вивід

```
started
working
done
```

## Коментарі

1. Дескриптор, який повертає `open`, — це просто значення, що зберігається в `$fh`. Тож він може бути аргументом `log-line`, як будь-який рядок чи число. Усередині підпрограми `$fh.say` пише через той самий відкритий дескриптор.

1. Дескриптор лишається відкритим під час усіх трьох викликів. Тож кожен `log-line` додає ще один рядок у кінець того самого файлу. Потім `close` зберігає все на диску, а `slurp` читає три рядки назад.

1. Саме тому дескриптори легко поєднувати. Функція може приймати дескриптор і писати в нього або читати з нього. Їй байдуже, на який файл вказує дескриптор. Це вирішує код, який викликає функцію, коли відкриває файл.
