Читати чи записувати весь файл за раз легко. Але іноді потрібно пройти файл рядок за рядком. Або ви хочете тримати файл відкритим і писати в нього багато разів. Для цього використовують _дескриптор файлу_.

Ось найпростіший спосіб читати файл рядок за рядком. Вам навіть не треба створювати для цього дескриптор. Метод `lines` об'єкта шляху дає вам рядки по одному. Вони готові для циклу `for`:

```raku
spurt 'words.txt', "one\ntwo\nthree\n";

for 'words.txt'.IO.lines -> $line {
    say $line.uc;
}
```

Кожен `$line` — це один рядок без символу нового рядка в кінці. Програма виводить:

```
ONE
TWO
THREE
```

Щоб писати через дескриптор, відкрийте файл за допомогою `open` із прапорцем `:w` (write). Потім використовуйте методи `say` або `print` дескриптора. Коли закінчите, закрийте його через `close`:

```raku
my $fh = open 'out.txt', :w;
$fh.say('first line');
$fh.say('second line');
$fh.close;
```

Коли ви закриваєте дескриптор, усе написане справді зберігається на диску. Деякі файли завеликі, щоб завантажити їх у пам'ять цілком. Такі файли зазвичай читають рядок за рядком, як вище.
