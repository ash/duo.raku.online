## Завдання

Напишіть підпрограму `get`, яка повертає свій аргумент. Але коли аргумент дорівнює `0`, вона має викликати `fail` із повідомленням `bad`.

Виведіть результат `get(5)`, а потім `get(0)`. Використайте оператор «визначене або» `//`, щоб дати запасне значення `default`.

## Приклад

Програма виводить:

```
5
default
```
