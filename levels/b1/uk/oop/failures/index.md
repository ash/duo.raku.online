Кидання винятку через `die` одразу зупиняє все. Іноді це надто різко. Ви можете хотіти, щоб підпрограма повідомила, що не змогла дати результат. Але викликач має сам вирішити, чи це фатально. Для цього в Raku є _м'які збої_, які створюють через `fail`.

Коли підпрограма викликає `fail`, вона не кидає виняток одразу. Натомість вона повертає викликачеві особливий об'єкт `Failure`. `Failure` невизначений, тож викликач може тихо його перевірити:

```raku
sub divide($a, $b) {
    fail 'cannot divide by zero' if $b == 0;
    return $a / $b;
}

say divide(10, 2);         # 5
say divide(10, 0).defined; # False
```

Успішний виклик повертає `5`. Невдалий виклик повертає `Failure`, і `defined` дає для нього `False`. Тож викликач може перевірити результат, перш ніж ним скористатися.

Чому `Failure` називають _м'яким_? Він стає справжнім кинутим винятком лише в одному випадку. Це стається, коли ви використовуєте його як значення, спершу не перевіривши. Доки ви його обробляєте, наприклад перевіряючи `defined`, він лишається тихим. Тож підпрограма може повідомити про проблему, не зупиняючи всю програму.

## Ви це вже бачили

Такий відкладений збій буває не лише від `fail`. Раніше в цій частині ви двічі зустрічали ту саму ідею.

**Ділення на нуль** тихо створює значення. Воно кидає виняток, лише коли ви справді використовуєте це значення:

```raku
my $x = 1 / 0;   # помилки ще немає
say $x;           # кидає лише тут, коли значення використано
```

**Зовнішня програма, яка не спрацювала,** повертає `Proc`. Він кидає виняток, лише якщо ви викидаєте його, не обробивши. Якщо ви збережете його й подивитеся на нього, він лишиться тихим значенням:

```raku
run 'sh', '-c', 'exit 1';   # невдалий Proc відкинуто, тож це кидає виняток
```

У кожному випадку проблема не зупиняє програму тієї миті, коли стається. Натомість вона стає значенням, яке можна перевірити. Вона стає кинутим винятком, лише коли ви використовуєте її без перевірки або ігноруєте. Тема [Не кожна помилка негайна](/uk/oop/try/deferred-errors) показує ці два приклади поруч.
