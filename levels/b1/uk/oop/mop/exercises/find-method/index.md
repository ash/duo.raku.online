## Завдання

Визначте клас `Animal` з методом `speak`. Потім визначте клас `Dog`, який успадковує від `Animal`. Він не додає власних методів. Скористайтеся метаметодом для `Dog` і виведіть, чи має `Dog` метод на ім'я `speak`. Виведіть просте `True` або `False`. Це показує, що `find_method` шукає вздовж ланцюжка успадкування. Він шукає не лише серед власних методів класу.

## Приклад

Програма виводить:

```
True
```
