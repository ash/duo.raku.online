Підпрограма `dir` повертає записи каталогу, кожен як об'єкт шляху. Їхній порядок не фіксований. Тому результат часто сортують, і тоді вивід завжди має той самий порядок.

```raku
mkdir 'box';
spurt 'box/a.txt', '';
spurt 'box/b.txt', '';

for dir('box').sort -> $entry {
    say $entry.basename;
}
```

Програма виводить відсортовані імена файлів у каталозі `box`:

```
a.txt
b.txt
```

Кожен запис — це повний об'єкт шляху. Метод `basename` дає лише кінцеве ім'я, без частини з каталогом. Об'єкту шляху можна ставити всі ті самі запитання, що й раніше: `.f`, `.d` і `.e`. Тож ви можете, наприклад, пройти каталогом і вибрати лише файли.
