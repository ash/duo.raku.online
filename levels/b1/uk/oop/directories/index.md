Іноді потрібно працювати із самою файловою системою. Наприклад, ви можете захотіти перевірити, що існує, або створити каталоги. Для цього Raku використовує _об'єкти шляху_. Будь-який рядок можна перетворити на об'єкт шляху методом `.IO`. Потім об'єкт шляху відповідає на запитання про цей шлях.

Найчастіше ви питаєте, чи існує шлях і що це за річ:

```raku
spurt 'greeting.txt', 'hi';

say 'greeting.txt'.IO.e; # True  — чи існує?
say 'greeting.txt'.IO.f; # True  — чи це файл?
say 'greeting.txt'.IO.d; # False — чи це каталог?
```

`.e` перевіряє, чи існує шлях. `.f` перевіряє, чи це звичайний файл, а `.d` — чи це каталог.

Щоб створити новий каталог, скористайтеся `mkdir`:

```raku
mkdir 'reports';
say 'reports'.IO.d; # True
```

У наступній темі ви побачите, як перелічити вміст каталогу.
