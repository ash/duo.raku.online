Більшість методів викликають для об'єкта, який є екземпляром класу. Але метод можна викликати й для самого класу. Іншими словами, ви викликаєте його для об'єкта типу. Такий метод часто називають _методом класу_. Він корисний для значень та операцій, які належать усьому класу. Вони не належать одному конкретному об'єкту.

Метод класу визначають точно так само, як будь-який інший метод:

```raku
class Road {
    method speed-limit { 120 }
}
```

Але ви викликаєте його для імені класу, а не для екземпляра:

```raku
say Road.speed-limit; # 120
```

Насправді ви вже користувалися методом класу, хоч і не називали його так. `new` — це метод, який ви викликаєте для класу, щоб створити новий об'єкт.

Метод класу не може використовувати атрибути екземпляра, бо за ним немає конкретного об'єкта. Тож він працює лише з інформацією, спільною для всіх об'єктів класу. Якщо робота залежить від даних одного об'єкта, беріть звичайний метод. Викликайте його для екземпляра. Якщо ні, метод класу — природний вибір.

Методам класу не потрібен екземпляр. Проте коли об'єкт у вас таки є, ви можете використати його дані в них:

```raku
class Road {
    has $.name;
    method speed-limit { 120 }

    method info {
        "The maximum speed on $.name is " ~ self.speed-limit
    }
}

my $R404 = Road.new(name => 'Road 404');
say $R404.info;
```

Ця програма виводить саме той результат, якого можна чекати:

```
The maximum speed on Road 404 is 120
```

Без об'єкта класу виклик на зразок `say Road.info` дав би помилку.
