## Завдання

Визначте клас `Converter` із методом класу `km-to-miles`. Він приймає кількість кілометрів і повертає відстань у милях. Щоб перевести кілометри в милі, помножте на `0.621`.

Викличте метод для класу з `10` кілометрами, а потім виведіть результат.

## Приклад

Програма виводить:

```
6.21
```
