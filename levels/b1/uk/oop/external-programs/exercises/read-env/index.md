## Завдання

Створіть файл `notes.txt` і запишіть у нього кілька рядків. Покладіть його ім'я у змінну середовища `NOTES`. Потім використайте `shell`, щоб запустити `wc -l` і взяти ім'я файлу з `$NOTES`. Тоді дочірня програма рахує рядки й виводить число. Наостанок видаліть файл із Raku через `unlink`, а не через оболонку.

## Приклад

Програма виводить:

```
3
```

Вона також не лишає по собі `notes.txt`.
