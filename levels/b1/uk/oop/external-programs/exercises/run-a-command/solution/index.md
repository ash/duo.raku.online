Ось один із можливих розв'язків.

## Код

```raku
run 'echo', 'home:', '$HOME';
```

🦋 Вихідний код можна знайти у файлі [run-a-command.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/external-programs/run-a-command.raku).

## Вивід

```
home: $HOME
```

## Коментарі

1. `run` запускає `echo` напряму й передає кожен рядок як окремий аргумент. Без `:out` вивід програми йде просто на екран.

1. Аргумент доходить до `echo` точно таким, як його записано. `$HOME` виводиться без змін і не замінюється вашим домашнім каталогом. Це тому, що немає оболонки, яка б його замінила. Ось чому `run` — безпечний вибір за замовчуванням. Та сама команда, передана до `shell`, могла б працювати зовсім інакше.

1. Щоб справді вивести домашній каталог, дозвольте оболонці замінити змінну. `shell 'echo home: $HOME'` виводить щось на кшталт `home: /home/anna`. Залиште також одинарні лапки на боці Raku. Рядок у подвійних лапках `"$HOME"` створив би проблему. Raku сам спробував би вставити в рядок змінну з іменем `$HOME`. Це сталося б ще до того, як `echo` взагалі запуститься.
