## Завдання

Використайте `run`, щоб запустити `echo` з двома окремими аргументами: `home:` і `$HOME`. Хай його вивід іде на екран. Зверніть увагу, що `$HOME` з'являється без змін, а домашній каталог **не** виводиться. Оскільки `run` не використовує оболонку, змінна не замінюється своїм значенням.

## Приклад

Програма виводить:

```
home: $HOME
```
