## Завдання

Запустіть команду, яка навмисно не спрацьовує, наприклад `sh -c 'exit 4'`. Збережіть `Proc`, який вона повертає. Виведіть код завершення команди. Потім виведіть `success` або `failure` — залежно від того, чи команда спрацювала.

## Приклад

Програма виводить:

```
4
failure
```
