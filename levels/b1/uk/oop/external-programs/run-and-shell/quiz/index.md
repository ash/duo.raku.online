Яка функція передає свою команду через системну **оболонку** й дозволяє канали та перенаправлення?

{:.quiz}
0 | `run`
1 | `shell`
0 | `exec`
0 | `system`

{% include quiz.html %}

<div class="extended-explanation">

`shell` передає оболонці один рядок, а та розуміє такі можливості, як канали. `run` запускає програму напряму, з окремими аргументами й без оболонки. Так безпечніше, тож `run` — кращий вибір за замовчуванням.

</div>
