Є два способи запустити зовнішню програму. Функція `run` бере команду та її аргументи як **окремі** значення. Вона запускає програму напряму, без оболонки:

```raku
run 'echo', 'hello';
```

Це запускає програму `echo` з єдиним аргументом `hello`, тож вона виводить `hello`. Аргументи передаються окремо, тому оболонка не може неправильно прочитати пробіли чи особливі символи. Ось чому `run` — безпечний вибір за замовчуванням.

Функція `shell` працює інакше. Вона передає **один рядок** системній оболонці, яка читає його й виконує. Це дозволяє користуватися можливостями оболонки, такими як канали й перенаправлення:

```raku
shell 'echo hello | tr a-z A-Z';
```

Тут оболонка запускає `echo` і пропускає його вивід через `tr` за допомогою каналу. Потім вона виводить `HELLO`. Це зручно, але треба бути обережними. Оболонка сама вирішує, що означає рядок. Тож небезпечно будувати команду для `shell` із введення, якому ви не довіряєте. Використовуйте `run`, якщо вам не потрібні саме можливості оболонки.

Обидві функції повертають об'єкт `Proc`, який описує, як програма завершилася. За замовчуванням запущена програма ділить вивід із вашою програмою. Тож те, що вона виводить, з'являється на екрані. Щоб натомість перехопити цей вивід, треба про це попросити. Про це розповідає наступна тема.
