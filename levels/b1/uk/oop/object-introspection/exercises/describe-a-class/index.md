## Завдання

Визначте базовий клас `Animal` і клас `Dog`, який успадковує від нього. Виведіть ім'я класу `Dog`. Наступним рядком виведіть кількість типів у його ланцюжку успадкування. Для цього скористайтеся `.^mro` і порахуйте його елементи. Нарешті, третім рядком виведіть, чи є десь у цьому ланцюжку клас `Cat`.

## Приклад

Програма виводить:

```
Dog
4
False
```
