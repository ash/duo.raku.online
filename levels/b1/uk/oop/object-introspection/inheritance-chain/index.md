Якщо клас успадковує від іншого, можна запитати весь його ланцюжок типів. Метаметод `.^mro` повертає цей ланцюжок. Назва походить від _method resolution order_ — «порядок розв'язання методів». Це порядок, у якому Raku шукає метод.

```raku
class Animal {
}

class Dog is Animal {
}

say Dog.^mro; # ((Dog) (Animal) (Any) (Mu))
```

Читайте список зліва. `Dog` спершу є сам собою, потім `Animal` (його батьком), а потім `Any` та `Mu`. Ці два типи стоять на самій вершині, і кожен об'єкт Raku успадковує від них. Коли ви викликаєте метод для `Dog`, Raku шукає в цьому списку зліва направо. Він бере перший відповідний метод, який знаходить. Саме тому метод дитини перевизначає метод батька. Дитина стоїть у ланцюжку раніше.

Якщо клас не має батька, якого ви назвали самі, ланцюжок коротший. У ньому лише сам клас, а за ним `Any` та `Mu`.
