У [розділі про контейнери](/uk/advanced/containers) ви користувалися `.^name`, щоб запитати значення про його тип. Тими самими метавикликами `.^` можна зазирнути всередину класу та його об'єктів. Можна побачити їхні імена, атрибути та місце в ієрархії класів.

Метаметод `.^name` повертає ім'я класу:

```raku
class Dog {
    has Str $.name;
    method bark { 'Woof' }
}

say Dog.^name; # Dog
```

Метаметод `.^attributes` перелічує атрибути класу. Ви бачите кожен із його типом і внутрішнім приватним іменем. Це форма `$!`, з якою ви познайомилися в темі про [приватні атрибути](/uk/oop/methods/private-attributes):

```raku
say Dog.^attributes; # (Str $!name)
```

Інтроспекція корисна для інструментів, які працюють з будь-якими об'єктами. Наприклад, такий інструмент може вивести кожен атрибут об'єкта. Йому не треба заздалегідь знати клас. Наступна тема показує, як побачити ланцюжок успадкування класу.
