Raku має вбудовані винятки `X::`, але ви можете створювати й власні. Власний виняток — це клас, який успадковує від вбудованого класу `Exception`. Також він має метод `message`:

```raku
class TooBig is Exception {
    has $.value;

    method message {
        "Value $.value is too big";
    }
}
```

`TooBig` — звичайний клас, тож він може мати атрибути, як-от `value`. Але оскільки він `is Exception`, його можна кинути. Щоб кинути його, ви створюєте об'єкт і викликаєте для нього `.throw`:

```raku
my $value = 20 * 30;

TooBig.new(value => $value).throw if $value > 50;

CATCH {
    when TooBig {
        say .message;
    }
}
```

Програма виводить:

```
Value 600 is too big
```

Усередині `CATCH` гілка `when TooBig` збігається, бо кинутий об'єкт має цей тип. Власний виняток несе будь-які дані, які ви йому даєте, тут це `value`. Тож обробник може побудувати точне повідомлення або відреагувати особливим способом. Це набагато корисніше, ніж простий рядок, переданий до `die`.

Ця сторінка зводить разом усе з цієї частини. Власний виняток — це _клас_ з атрибутами й методом. Також він бере участь у системі винятків Raku. Тож він готовий точно повідомити, що пішло не так.
