`spurt` і `mkdir` створюють щось на диску, а дві інші підпрограми це видаляють.

Підпрограма `unlink` видаляє файл:

```raku
spurt 'temp.txt', 'scratch data';
say 'temp.txt'.IO.e; # True

unlink 'temp.txt';
say 'temp.txt'.IO.e; # False
```

`unlink` видаляє файл із вказаним ім'ям. Як і інші підпрограми файлової системи, він має також форму методу. Ви викликаєте його для об'єкта шляху: `'temp.txt'.IO.unlink`.

Видалення відбувається відразу й назавжди. Немає кошика, з якого можна повернути файл. Зверніть увагу ще на одне щодо видаленого файлу. Перевіряти його треба через `.e` (існування), а не через `.f`. Перевірки типу `.f` і `.d` дають помилку, якщо шляху немає.

Підпрограма `rmdir` вилучає каталог, але лише **порожній**:

```raku
mkdir 'reports';
rmdir 'reports';
say 'reports'.IO.e; # False
```

Якщо в каталозі ще щось є, `rmdir` нічого не видаляє. Каталог лишається на своєму місці. Тож щоб видалити каталог із файлами, спершу спорожніть його, а потім видаліть:

```raku
mkdir 'reports';
spurt 'reports/jan.txt', 'January';
spurt 'reports/feb.txt', 'February';

.unlink for 'reports'.IO.dir;   # видалити кожен запис
rmdir 'reports';                # тепер каталог порожній
say 'reports'.IO.e;             # False
```

`'reports'.IO.dir` перелічує записи каталогу, як ви бачили в попередній темі. Виклик `.unlink` для кожного запису видаляє його. Коли каталог порожній, `rmdir` може його видалити. Зверніть увагу, що цей простий цикл очікує в каталозі лише файли. Для дерева з вкладеними підкаталогами потрібна рекурсія, щоб спершу їх спорожнити.
