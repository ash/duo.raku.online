## Problem

Write and run a program that prints a greeting with your name. Save it in a file and run it from the command line. If you prefer, [run the program](/essentials/running-programs) online or directly from an IDE.

## Example

This example shows how to run the program and what it prints:

```console
$ raku hello-me.raku
Hello, Andrew!
```

## Solution

Try to solve this task yourself. Save the code in a file. Then pass it to the command-line interpreter. Or run it in another way that we covered earlier. Do you want to see the example? Or does your program not work for some reason? Then you are welcome to open the working solution below.
