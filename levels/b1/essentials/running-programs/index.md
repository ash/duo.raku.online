In [one of the previous sections](../hello-world), we created a simple program. But we did not run it yet. There are many ways to run a program. You can use an installed command-line tool or a REPL shell. You can also run it directly from an [IDE](../editors-and-ides). Another way is an online service, such as [glot.io](https://glot.io/new/raku). You can also use a docker container.

This section has five topics. Look through all of them, or study only the ones you need. After the topics, there is an assignment.
