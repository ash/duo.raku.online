This short section explains how to run a program inside the IDE. It covers the two most recommended [IDEs](../../editors-and-ides).

## Visual Studio Code Editor

Open a terminal with the menu `Terminal` → `New Terminal`. It adds a panel below the text of your program. Run the program there, just like from the command line:

```console
$ raku hello.raku
```

## Comma IDE

You can run programs from the `Run` menu item. Set up the IDE before the first run of a program. Follow [the instructions](https://commaide.com/docs/running) on the Comma website.
