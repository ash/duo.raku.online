## Problem

Write a program that calculates and prints the perimeter of a rectangle. Pass the lengths of the two sides as command-line arguments. If the shape is a square, pass only one value. Use the `MAIN` function.

## Example

The program should clearly say whether it works with a square or a rectangle. Here is a possible output for both cases:

```console
$ raku perimeter.raku 15
The perimeter of a square is 60.

$ raku perimeter.raku 15 20
The perimeter of a rectangle is 70.
```
