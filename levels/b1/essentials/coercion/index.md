So far, we have seen several data types in Raku. These were different kinds of [numbers](/essentials/numbers): integers, rational numbers, and floating-point numbers. We also saw [strings](/essentials/strings) and the [Boolean](/essentials/booleans) type. Each data type has its own name in the Raku type system.

`Str` | String of characters
`Int` | Integer number
`Rat` | Rational number
`Num` | Floating-point number
`Bool` | Logical Boolean

Raku understands more data types than these. We will see them in later sections of this course.
