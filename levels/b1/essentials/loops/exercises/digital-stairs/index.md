## Problem

Create a program that prints the following structure:

    1
    12
    123
    1234

The user must enter the size of the stairs (no more than 9).

## Example

Here is an example of using the program with the input value `3`:

```console
$ raku digital-stairs.raku
Enter the size: 3
1
12
123
```
