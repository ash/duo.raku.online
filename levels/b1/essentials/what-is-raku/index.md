Raku is a great programming language.

Raku lets you program in different styles. These include procedural, functional, object-oriented and reactive programming. It has a rich type system. You can add types to your code step by step. It also has amazing new regexes and grammars. Raku can solve many tasks with very short programs.

This course covers the most basic features of Raku. It also shows many tricks that will make your work faster and easier.
