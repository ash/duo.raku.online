## Task

Write a program that creates a few scalar variables. Give them start values of these types: `Int`, `Rat`, `Num`, `Bool`, and `Str`. The program should print each value and its type.

## Example

The real output of your program may differ. But this test run shows the idea:

```console
$ raku types.raku
151 (Int)
4.2 (Rat)
1e10 (Num)
True (Bool)
xyz (Str)
```
