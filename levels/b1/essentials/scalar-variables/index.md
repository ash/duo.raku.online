So far, the text strings in our programs were written directly in the code. Let us add a bit of freedom now and let the program use variables.

Raku has a few types of variables. A variable is a container that can keep some data. We will start with the simplest containers, which keep only one value. They are called _scalars_, or scalar variables. The name of a variable starts with a special character. It shows what kind of container the variable is. This character is called a _sigil_. For scalar containers, the sigil is the dollar sign `$`.

Here are two examples of scalar variables:

```raku
$name

$age
```
