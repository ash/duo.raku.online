## Problem

Write a program that does these two things:

1. Asks the user to enter their name.
2. Prints the message `Hello, Name!`. Instead of `Name`, it shows the name that the user has just entered.

In this program, please use variables.

## Example

Here is how the program should work:

```console
$ raku greet-a-person.raku
What is your name? John
Hello, John!
```
