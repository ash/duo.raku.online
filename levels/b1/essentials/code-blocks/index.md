Code blocks are parts of your program inside a pair of curly braces: `{` and `}`. A block groups several statements, which work together like one big statement. We will see many ways to use blocks in the next sections.

```raku
{
    say 'Hello, World!';
}
```

The code block in this program does not really make sense. But code blocks are very useful in other situations, which we will see very soon.

But first, let us look at the idea of _scope_.
