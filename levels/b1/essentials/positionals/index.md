Now it is time to talk about more complex data types. In Raku, positional data types are the ones that can be indexed (or _subscripted_). We have already met one data type of this kind: [ranges](/essentials/ranges).

In this section, we show two more positional data types: `Array` and `List`. You will find more details in the second part of the course. We also look at ranges again, now as a positional data type.
