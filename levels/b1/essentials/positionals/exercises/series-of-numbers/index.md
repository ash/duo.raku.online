## Task

Write a program that asks for two integers, _A_ and _B_, where _A ≤ B_. Then it prints all integers from _A_ to _B_, including both _A_ and _B_.

## Example

The program should work like this:

```console
$ raku series-of-numbers.raku
Begin: 14
End: 17
14
15
16
17
```
