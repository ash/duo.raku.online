## Task

Write a program that counts the arguments it got from the command line. It must report the number in a complete sentence. The grammar must be correct. Use the word `argument` when there is exactly one, and `arguments` in all other cases.

## Example

This is how the program should respond:

```console
$ raku number-of-command-line-arguments.raku make them count us now
You passed 5 arguments.

$ raku number-of-command-line-arguments.raku solo
You passed 1 argument.
```
