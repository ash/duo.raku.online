## Problem

You have an array of numbers:

```raku
my @data = 10, 12, 1, 5, -9, 8, 36, 18, 21;
```

Complete the program so that it prints only the elements with odd indices. Make sure that it still works if you change the number of items in `@data`.

## Example

```console
$ raku odd-indices.raku
12
5
8
18
```
