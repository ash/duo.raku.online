## Problem

The traffic light changes its colour every second. When it is turned on, it starts as yellow. Then the colour changes every second in this order: yellow — red — yellow — green. After that, the cycle starts again.

Write a program to print the state of the traffic lights. Print it for the 51<sup>st</sup>, 102<sup>nd</sup> and 305<sup>th</sup> second. Assume that the colour on the 1<sup>st</sup> second is red.

## Example

The program should print three colours on separate lines:

```console
$ raku traffic-lights.raku
...
...
...
```
