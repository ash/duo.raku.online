## Problem

Write a program that asks the user for three whole numbers. It should say how many of the numbers are equal. Both positive and negative numbers must work.

## Example

Here is one possible run of the program:

```console
$ raku how-many-equal-numbers.raku
Number 1: 3
Number 2: -4
Number 3: 3
2
```

If all three numbers are different, the program prints `0`.
