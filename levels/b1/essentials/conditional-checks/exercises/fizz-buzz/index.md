## Problem

This task is an easier version of the well-known [FizzBuzz problem](https://en.wikipedia.org/wiki/Fizz_buzz).

Write a program that asks for a positive whole number and prints:

* `Fizz` if the number is divisible by 3.
* `Buzz` if the number is divisible by 5.

## Example

When you start the program, it asks for a number. After that, it prints the result.

```console
$ raku fizz-buzz.raku
Enter a number: 10
Buzz
```
