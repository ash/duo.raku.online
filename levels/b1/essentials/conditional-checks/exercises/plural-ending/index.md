## Task

Write a program that asks the user for a positive whole number. Then the program prints `N files copied`, with the user’s number in place of `N`. The word `file` must have the right form, plural or singular.

## Example

This example shows what the program must do:

```console
$ raku plural-endings.raku
How many files to copy? 15
15 files copied.
```
