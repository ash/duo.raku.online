{% include menu.html %}

Sometimes you want a program to act differently in different situations. Then you can start using `if` and its family.

All of them need a condition. It can be a [Boolean](/essentials/booleans) value or a Boolean expression. It can also be any other expression that can be [converted](/essentials/coercion) to a Boolean value.
