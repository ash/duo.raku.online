Raku programs are written as plain text. Usually, they are kept in text files. The exceptions are programs that you run online or in the command line. Another exception is code that you prepare to run with `EVAL`. There are also a few other rare cases.

The program source is expected to be UTF-8 text. So any text editor is fine if it does not save formatting. You can happily use `vim`, `nano`, `emacs` or `mcedit`. But you may also want to try a couple of popular new applications.

## External links

Here are the links to the popular IDEs.

* [Visual Studio Code](https://code.visualstudio.com/) — available for Windows, Mac OS and Linux
* [Comma](https://commaide.com) — the Raku IDE, made especially for programming in Raku. It is available for Windows, Mac OS and Linux.
