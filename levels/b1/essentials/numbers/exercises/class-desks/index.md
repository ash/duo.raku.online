## Problem

A school is getting ready for the year after coronavirus. It is going to order new desks, and each desk is made for two students. You know the number of students in the class. Print the smallest possible number of desks that the school must buy for it.

Put the number of students into a variable directly in the code.

## Example

Here is the first line of the program:

```raku
my $students = 23;
# Your code here . . .
```

When you run the program, you should see the following:

```console
$ raku class-desks.raku
12 desks must be bought.
```
