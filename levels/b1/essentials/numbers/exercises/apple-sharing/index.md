## Problem

_N_ people share _K_ apples equally among them. Write a program that answers the following questions:

* How many apples does each person get?
* How many apples are left in the basket?

Write the input numbers _N_ and _K_ directly in the code. Assign them to variables, for example:

```raku
my $N = 3;
my $K = 11;

# Your code here . . .
```

Each apple is whole, so you cannot cut it into pieces.

## Example

With the numbers given above, the program should print the following:

```console
$ raku apple-sharing.raku
Each person gets 3 apple(s).
There are 2 apple(s) remaining.
```

For now, do not worry about putting the nouns in the correct form. Also, do not worry if the output looks a bit strange when no apples remain.
