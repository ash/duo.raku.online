## Problem

Write a program that asks the user to enter a positive integer. Then it prints the digit that shows how many _tens_ there are in the number.

## Example

For example, if the input number is 234, the number of tens is 3. So the program prints 3:

```console
$ raku tens.raku
Enter a positive integer number: 234
3
```
