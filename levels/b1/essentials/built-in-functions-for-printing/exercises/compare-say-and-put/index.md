## Problem

Write a program that shows the differences between `say` and `put`. Try them with all the data types we have learned so far. These are `Int`, `Rat`, `Num`, `Str`, `Array`, `List`, `Range`, and `Hash`. For scalar values, use [typed variables](/essentials/typed-variables).

## Example

For every data type, the program should print at least one result. It should use both `say` and `put`.

```console
$ raku compare-say-and-put.raku
256
256
0.125
0.125
. . .
```
