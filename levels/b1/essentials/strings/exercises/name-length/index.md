## Problem

Write a program that asks the user for their first and last names separately. Then it prints how many letters the two names have together. The space between them does not count.

## Example

Run the program and answer both prompts. Then it prints just one number, the total length of the two names.

```console
$ raku name-length.raku
First name: Ada
Last name: Lovelace
11
```
