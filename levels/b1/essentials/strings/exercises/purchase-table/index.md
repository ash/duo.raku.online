## Problem

Write a program that prints a price table in the format below. Please store the prices and the totals in variables.

    Item    Price   N      Total
    Chairs  $20.57  4      $82.28
    Tables  $50.18  1      $50.18

Note: if you do not like this currency, you can use any other one. But remember that `$` [has a special meaning](/essentials/strings/escaping-special-characters) in Raku strings. That is exactly why we chose it, to help you learn Raku better.

## Example

This program takes no input. When you run it, it just prints the table above.

```console
$ raku purchase-table.raku
```
