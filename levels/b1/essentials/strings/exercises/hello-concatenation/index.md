## Problem

Do you remember the practice program ‘[Greet a person](/essentials/scalar-variables/exercises/greet-a-person/)’? Now we will write it again at a new level.

Write a program that asks the user for their name and their home city. Then it prints a greeting that mentions both. Use string concatenation in your solution.

## Example

When you run the program, you see two prompts:

```console
$ raku hello-concatenation.raku
What is your name? Ella
Where are you from? Lisbon
```

Then the program prints the greeting:

    Hello, Ella from Lisbon!
