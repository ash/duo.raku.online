## Problem

OK, let us greet a person once again. But this time, try to use string interpolation. Ask the person to enter their name. Then print a greeting that also says how many letters the name has. Use code interpolation, the `{ }` form, to calculate the length right inside the string.

## Example

When you run the program, you see a prompt:

```console
$ raku hello-interpolation.raku
What is your name? Raku
Hello, Raku! Your name has 4 letters.
```
