Let us talk about strings now. We have already used strings in our earlier programs. All of them are also known as string literals. A string literal is some text in quotes:

```raku
say 'I am a string literal';
```

Of course, you can also keep strings in a scalar variable:

```raku
my $message = 'This is my message';
```
