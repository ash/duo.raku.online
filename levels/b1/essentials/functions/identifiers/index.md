The name of a function is an identifier. It follows the same rules as [variable names](/essentials/scalar-variables/identifiers). It must start with a letter or an underscore. After that, it can contain any letters, digits, underscores, single quotes (apostrophes) and hyphens.

An apostrophe or a hyphen must be followed by a letter. Apostrophes are rare in identifiers. Hyphens, however, are used a lot, because they make names more expressive.

Here are a few examples of valid function names.

    greet

    greet-them

    hello-world

    NumberOfItems

    is-valid

    to_be-or-not_to_be
