## Problem

Write a program that prints the values of the function `f(x) = x²`. Take `x` on the interval [−3, 3] with a step of 0.1.

## Example

The program should print two columns. The first column shows `x`, and the second column shows `f(x)`.

```
$ raku function-table.raku
-3	9
-2.9	8.41
-2.8	7.84
. . .
```
