## Problem

Create a function that calculates an approximate value of the mathematical constant _e_. Use the following formula:

<img src="e-formula.png" style="height: 4.5em; width: auto">

You should be able to call this function in either of these forms:

1. The argument sets the number of items in the formula: `e-approx(10)`.
2. If there is no argument, the sum has 100 elements: `e-approx()`.

Print the results for both cases.

## Example

```console
$ raku the-value-of-e.raku
2.7182818
2.718281828459045
```
