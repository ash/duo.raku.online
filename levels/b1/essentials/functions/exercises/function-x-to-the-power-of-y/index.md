## Problem

Create a function with two arguments that returns `$x` to the power of `$y`. Then write a program that prints the values of `5³`, `2¹⁰`, and `(−4)⁵`.

## Example

For these values, the program should print:

```
$ raku function-x-to-the-power-of-y.raku
125
1024
-1024
```
