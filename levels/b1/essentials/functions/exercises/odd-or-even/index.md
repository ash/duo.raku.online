## Problem

Create a function that takes an integer as an argument. It returns the string `'Odd'` or `'Even'`. Then use it in a program and print the answer for a few numbers. For example, take `10`, `5`, `0`, and `3`.

## Example

For these numbers, the program should print the following:

```console
$ raku odd-or-even.raku
Even
Odd
Even
Odd
```
