## Problema

Una subrutina anónima no tiene que guardarse primero. Puedes pasarla directamente a otra rutina. Usa la forma `sub`, no un bloque puntiagudo, y escribe una subrutina anónima de "cuadrado". Pásala directamente a `map` sobre la lista `1, 2, 3` e imprime el resultado.

## Ejemplo

El programa imprime:

```
(1 4 9)
```
