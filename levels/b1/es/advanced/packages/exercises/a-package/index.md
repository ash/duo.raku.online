## Problema

Crea un paquete `Temperature` que agrupe dos cosas. La primera es una variable `our` llamada `$freezing` con el valor `0`. La segunda es una subrutina `our` llamada `fahrenheit`, que convierte un valor en Celsius a Fahrenheit. Para convertir, multiplica por 9/5 y suma 32. Desde fuera del paquete, imprime el punto de congelación. Luego imprime el valor en Fahrenheit de `100` grados Celsius.

## Ejemplo

El programa imprime:

```
0
212
```
