## Problema

Empieza con `my $n = 9;`. El operador postfijo `++` tiene una característica fácil de pasar por alto. Como expresión, devuelve el valor que tenía la variable *antes* del incremento. Solo después suma uno a la variable.

Imprime el resultado de `$n++` con un solo `say`. En la línea siguiente, imprime el propio `$n`, para que puedas ver la diferencia.

## Ejemplo

El programa imprime:

```
9
10
```
