El operador `x` repite una cadena. Por ejemplo, `'ab' x 3` da `'ababab'`. Como `x` está entre sus dos operandos, ¿a qué categoría pertenece?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Lo que importa es la posición, no si el operador es un símbolo o una palabra. `x` está *entre* dos operandos, así que es un operador **infijo**. Es igual que `+` o `~`, pero se escribe con una letra.

</div>
