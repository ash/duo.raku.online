## Problema

Escribe una subrutina `power` con un parámetro obligatorio `$base` y un parámetro **opcional** `$exp`. Cuando se da el exponente, eleva la base a ese valor. Cuando falta, eleva la base al cuadrado por defecto. Usa el operador defined-or `//` para dar `2`.

Llámala dos veces. Primero llámala solo con una base, y después con una base y un exponente.

## Ejemplo

El programa imprime:

```
25
125
```
