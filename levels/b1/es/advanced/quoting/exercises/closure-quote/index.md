## Problema

Empieza desde la forma `q`, que no interpola. Activa solo el adverbio de closure. La variable `$x` guarda `10`. Imprime una línea con el cálculo `{$x ** 2}` *y* un `$x` simple que no se interpola. Esto muestra que el adverbio de closure ejecuta código entre llaves. Pero deja las variables `$` simples tal como están.

## Ejemplo

El programa imprime:

```
$x squared is 100
```
