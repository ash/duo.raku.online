## Problema

Una variable nativa nunca puede ser indefinida. Esta regla vale para todos los tipos nativos, no solo para `int`. Declara un `num` nativo y un `str` nativo sin asignarles valores. Imprime el número. Luego imprime la cadena entre corchetes, para que puedas ver que está vacía.

## Ejemplo

El programa imprime:

```
0
[]
```
