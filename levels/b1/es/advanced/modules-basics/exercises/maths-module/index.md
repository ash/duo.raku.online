## Problema

Crea un módulo llamado `Maths` en un archivo `Maths.rakumod`. Debe exportar una subrutina `square` que devuelva el cuadrado de su argumento.

Luego escribe un programa separado que use el módulo e imprima `square(6)`.

## Ejemplo

Si lo ejecutas con el módulo en la ruta de búsqueda, el programa imprime:

```console
$ raku -I. maths.raku
36
```
