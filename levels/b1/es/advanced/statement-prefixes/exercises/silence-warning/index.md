## Problema

`quietly` oculta las advertencias y, como `do`, devuelve el valor de su bloque. Declara una variable para un nombre sin valor. Después construye un saludo `"Hello, " ~ $name ~ "!"` dentro de un bloque `quietly`. Esto oculta la advertencia de «valor no inicializado». Asigna el valor del bloque a `$greeting` e imprímelo.

## Ejemplo

El programa imprime:

```
Hello, !
```
