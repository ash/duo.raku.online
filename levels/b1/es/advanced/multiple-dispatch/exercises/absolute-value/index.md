## Problema

Escribe dos multi-subrutinas llamadas `abs-value` que tomen un entero y devuelvan su valor absoluto. Usa una cláusula `where` para tratar aparte los números negativos. No uses ningún `if` dentro de las subrutinas. Tampoco uses la función incorporada `abs`.

Imprime el resultado para `-7` y para `4`.

## Ejemplo

El programa imprime:

```
7
4
```
