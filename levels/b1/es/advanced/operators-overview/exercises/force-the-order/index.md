## Problema

El operador `**` se une con más fuerza que `+`, así que `2 ** 3 + 1` significa `(2 ** 3) + 1`, que es `9`. Añade paréntesis para cambiar este orden, de modo que la suma ocurra *primero*. Después imprime el resultado.

## Ejemplo

El programa imprime:

```
16
```
