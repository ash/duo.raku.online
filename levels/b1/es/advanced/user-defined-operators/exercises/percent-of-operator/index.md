## Problema

Define un operador infijo `percent-of`. La expresión `$p percent-of $whole` debe dar el `$p` por ciento de `$whole`. Por ejemplo, `20 percent-of 150` es `30`.

Usa el operador para imprimir `20 percent-of 150`.

## Ejemplo

El programa imprime:

```
30
```
