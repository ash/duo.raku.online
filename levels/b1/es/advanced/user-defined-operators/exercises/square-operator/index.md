## Problema

El símbolo de un operador puede ser cualquier carácter, también un carácter Unicode. Define un operador **postfijo** `²` que eleve su operando al cuadrado, de modo que `5²` signifique `5 ** 2`. Después imprime `5²`.

## Ejemplo

El programa imprime:

```
25
```
