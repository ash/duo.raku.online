## Problema

Toma el array `1, 2, 3` y empaquétalo en un escalar `$x` con el contextualizador de **elemento**. Entonces `$x` guarda el array completo como un solo valor. Después, usa el contextualizador de **lista** para ejecutar un bucle `for` sobre `$x`. Cuenta cuántas veces se ejecuta el bucle. El contexto de lista vuelve a separar el array empaquetado en sus elementos. Así que el bucle se ejecuta tres veces. Imprime el conteo.

## Ejemplo

El programa imprime:

```
3
```
