## Problema

Una URL se ha dividido en partes, y las partes están en un array. Vuelve a unirlas en una sola cadena con un meta-operador de reducción. Imprime la URL y, en la línea siguiente, imprime cuántos caracteres tiene.

## Ejemplo

Toma este array de entrada:

```raku
my @parts = <http :// example .com>;
```

Con este array, el programa imprime:

```
http://example.com
18
```
