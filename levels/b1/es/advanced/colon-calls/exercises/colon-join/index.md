## Problema

La forma con dos puntos debe ser la *última* llamada de una cadena. Pero las llamadas anteriores pueden ser llamadas normales con paréntesis. Empieza con las palabras `a`, `b`, `c` e invierte su orden con `.reverse`. Después une el resultado con un guion, usando la forma con **dos puntos**. Imprímelo.

## Ejemplo

El programa imprime:

```
c-b-a
```
