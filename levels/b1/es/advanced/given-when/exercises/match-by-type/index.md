## Problema

Un `when` puede comparar con un *tipo*, no solo con un valor. Una variable contiene el número `3.14`. Usa `given`/`when` para mostrar de qué tipo es el valor. Imprime `integer` para un `Int`, `rational` para un `Rat` y `string` para un `Str`.

## Ejemplo

El programa imprime:

```
rational
```
