## Problema

La edad está fija en el código. Usa `given`/`when` para imprimir su etapa de la vida. Usa estos grupos:

* `child` para 0-12,
* `teenager` para 13-19,
* `adult` para 20-64,
* `senior` para 65 en adelante.

Una edad negativa no tiene sentido, así que imprime `invalid` para cualquier número menor que cero. Asegúrate de comprobar este caso antes de los rangos.

## Ejemplo

Para la edad `30`, el programa imprime:

```
adult
```
