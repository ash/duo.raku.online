## Problema

Normalmente es difícil ver si un número es primo solo con mirarlo. El método `is-prime` responde a esta pregunta. Úsalo con dos números que a primera vista parecen primos: `97` y `91`. Imprime el resultado de cada uno en una línea aparte.

La trampa está en `91`, porque es igual a `7 × 13`.

## Ejemplo

El programa imprime:

```
True
False
```
