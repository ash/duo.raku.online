## Problema

Como los enteros de Raku tienen precisión arbitraria, Raku puede calcular `2 ** 1000` de forma exacta. El número es demasiado largo para contarlo tú mismo, así que deja que lo haga el programa. Imprime cuántos dígitos decimales tiene el valor de `2 ** 1000`.

## Ejemplo

El programa imprime:

```
302
```
