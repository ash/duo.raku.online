## Problema

Crea un acrónimo a partir de una frase. Toma la primera letra de cada palabra y une las letras. Luego imprime el resultado en mayúsculas.

Usa esta frase:

```raku
my $phrase = 'hyper text markup language';
```

## Ejemplo

El programa imprime:

```
HTML
```
