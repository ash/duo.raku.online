## Problema

Escribe un bloque Pod con un encabezado `=head1` `Greeting` y un párrafo `Hello, world!`. En el párrafo, marca la palabra `world` en negrita con `B<…>`. Renderiza el bloque como texto con `raku --doc`.

> Ejecuta el archivo con `raku --doc` para ver el texto con formato.

## Ejemplo

Cuando lo renderizas con `raku --doc`, imprime:

```
Greeting

Hello, world!
```
