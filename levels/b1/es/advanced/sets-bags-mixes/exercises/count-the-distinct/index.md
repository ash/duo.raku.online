## Problema

Tienes una lista de números, y algunos de ellos se repiten:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Imprime cuántos valores _distintos_ hay en ella. Para esto, usa un set.

## Ejemplo

El programa imprime:

```
7
```
