## Problema

Usa `gather` y `take` para construir una lista con los números del `1` al `4`. Cada número aparece tantas veces como su propio valor: `1` una vez, `2` dos veces, `3` tres veces y `4` cuatro veces. Imprime la lista que obtienes.

## Ejemplo

El programa imprime:

```
[1 2 2 3 3 3 4 4 4 4]
```
