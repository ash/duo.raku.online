## Problema

`WHAT` no solo describe un tipo. Devuelve el objeto de tipo mismo, y puedes compararlo con el operador `===`.

Declara dos variables. La variable `$a` guarda el entero `42`, y `$b` guarda la cadena `'x'`. Para cada una, imprime si su `WHAT` es el tipo `Int`.

## Ejemplo

El programa imprime:

```
True
False
```
