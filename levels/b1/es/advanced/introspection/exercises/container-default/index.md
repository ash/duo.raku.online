## Problema

Un contenedor puede tener un valor por defecto, que pones con el trait `is default`. Hasta que asignes algo, la variable devuelve este valor por defecto. `.VAR.default` también te dice qué valor tiene.

Declara un escalar `$count` con el valor por defecto `0`. No le asignes nada. Primero imprime la variable misma, y luego imprime el valor por defecto de su contenedor. Las dos líneas deberían mostrar `0`.

## Ejemplo

El programa imprime:

```
0
0
```
