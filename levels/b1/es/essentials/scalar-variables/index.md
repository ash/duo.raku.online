Hasta ahora, las cadenas de texto de nuestros programas estaban escritas directamente en el código. Vamos a añadir ahora un poco de libertad y dejar que el programa use variables.

Raku tiene algunos tipos de variables. Una variable es un contenedor que puede guardar algunos datos. Empezaremos con los contenedores más simples, que solo guardan un valor. Se llaman _escalares_, o variables escalares. El nombre de una variable empieza con un carácter especial. Indica qué tipo de contenedor es la variable. Este carácter se llama _sigil_. Para los contenedores escalares, el sigil es el signo de dólar `$`.

Aquí hay dos ejemplos de variables escalares:

```raku
$name

$age
```
