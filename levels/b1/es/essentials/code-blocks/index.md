Los bloques de código son partes de tu programa dentro de un par de llaves: `{` y `}`. Un bloque agrupa varias declaraciones, que funcionan juntas como una gran declaración. Veremos muchas formas de usar bloques en las siguientes secciones.

```raku
{
    say '¡Hola, Mundo!';
}
```

El bloque de código en este programa no tiene mucho sentido. Pero los bloques de código son muy útiles en otras situaciones, que veremos muy pronto.

Pero primero, veamos la idea de _alcance_.
