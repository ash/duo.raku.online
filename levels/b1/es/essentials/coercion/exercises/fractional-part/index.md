## Problema

Tienes un número, que está escrito directamente en el código del programa. Imprime su parte fraccionaria. Aquí está el comienzo del programa:

```raku
my $n = 15.8972;
# ... Tu código aquí
```

## Ejemplo

El programa debe imprimir la parte del número después del punto decimal:

```console
$ raku fractional-part.raku
0.8972
```
