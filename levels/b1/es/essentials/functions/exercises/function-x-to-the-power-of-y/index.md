## Problema

Crea una función con dos argumentos que devuelva `$x` elevado a la potencia de `$y`. Después escribe un programa que imprima los valores de `5³`, `2¹⁰` y `(−4)⁵`.

## Ejemplo

Para estos valores, el programa debe imprimir:

```
$ raku function-x-to-the-power-of-y.raku
125
1024
-1024
```
