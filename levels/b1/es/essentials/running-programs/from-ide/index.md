Esta sección corta explica cómo ejecutar un programa dentro del IDE. Trata los dos [IDEs](../../editors-and-ides) más recomendados.

## Editor de Visual Studio Code

Abre una terminal con el menú `Terminal` → `New Terminal`. Esto añade un panel debajo del texto de tu programa. Ejecuta allí el programa, igual que desde la línea de comandos:

```console
$ raku hello.raku
```

## Comma IDE

Puedes ejecutar programas desde el elemento de menú `Run`. Configura el IDE antes de ejecutar un programa por primera vez. Sigue [las instrucciones](https://commaide.com/docs/running) en el sitio web de Comma.
