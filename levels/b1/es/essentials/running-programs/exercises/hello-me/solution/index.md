Aquí está la solución al problema '[¡Hola, yo!](../)'.

## Código

```raku
say '¡Hola, Andrew!';
```

🦋 Puedes encontrar el código completo en el archivo [hello-me.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/running-programs/hello-me.raku).

## Salida

Para ver la salida, ejecuta el programa, como se muestra a continuación:

```console
$ raku exercises/running-programs/hello-me.raku 
¡Hola, Andrew!
```

## Discusión

No hay duda de que lograste escribir este programa. Pero recuerda: a menudo hay más de una manera de hacerlo.
