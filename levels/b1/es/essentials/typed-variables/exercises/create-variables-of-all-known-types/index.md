## Tarea

Escribe un programa que cree algunas variables escalares. Dales valores iniciales de estos tipos: `Int`, `Rat`, `Num`, `Bool` y `Str`. El programa debe imprimir cada valor y su tipo.

## Ejemplo

La salida real de tu programa puede ser diferente. Pero esta ejecución de prueba muestra la idea:

```console
$ raku types.raku
151 (Int)
4.2 (Rat)
1e10 (Num)
True (Bool)
xyz (Str)
```
