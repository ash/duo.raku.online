## Problema

Usa la tabla del ejercicio ‘[Tabla de compras](/es/essentials/strings/exercises/purchase-table)’, que hiciste antes:

    Artículo  Precio  N      Total
    Sillas    $20.57  4      $82.28
    Mesas     $50.18  1      $50.18

Propón una estructura de datos para guardar estos valores. Después escribe un programa que la imprima.

## Ejemplo

Cuando ejecutes el programa, debe imprimir la tabla de arriba.

```console
$ raku purchase-table.raku
```
