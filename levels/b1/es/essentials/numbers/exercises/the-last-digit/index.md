## Problema

Escribe un programa que pida al usuario ingresar un entero positivo. Luego imprime el último dígito de este número.

## Ejemplo

Así puede verse el uso del programa:

```console
$ raku the-last-digit.raku
Introduce un número: 123
El último dígito de 123 es 3.
```
