También puedes usar `loop` solo con un cuerpo:

```raku
loop {
    say 'Eternidad';
}
```

Este bucle se ejecuta sin fin hasta que detengas el programa, por ejemplo, presionando `Ctrl+C`. En la segunda parte del curso, veremos mejores formas de controlar los bucles.
