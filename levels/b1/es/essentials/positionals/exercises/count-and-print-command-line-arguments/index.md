## Tarea

Escribe un programa que lea cualquier número de argumentos desde la línea de comandos. Los imprime en líneas separadas, y cada línea tiene un número.

## Ejemplo

Así es como debe comportarse el programa:

```console
$ raku count-and-print-arguments.raku palabras para mostrar
1. palabras
2. para
3. mostrar
```
