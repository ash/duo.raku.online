## Problema

El semáforo cambia de color cada segundo. Cuando se enciende, empieza en amarillo. Luego el color cambia cada segundo en este orden: amarillo — rojo — amarillo — verde. Después, el ciclo empieza de nuevo.

Escribe un programa que imprima el estado de los semáforos. Imprímelo para el 51<sup>er</sup>, 102<sup>do</sup> y 305<sup>to</sup> segundo. Supón que el color en el 1<sup>er</sup> segundo es rojo.

## Ejemplo

El programa debe imprimir tres colores en líneas separadas:

```console
$ raku traffic-lights.raku
...
...
...
```
