## Problema

Escribe un programa que tome un entero positivo desde la línea de comandos. Debe escribir el número con palabras en inglés. Resuelve el problema para números menores de 100.

## Ejemplo

```console
$ raku spell-a-number.raku 34
thirty-four
```
