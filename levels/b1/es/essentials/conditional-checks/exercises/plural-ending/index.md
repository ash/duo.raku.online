## Tarea

Escribe un programa que pida al usuario un número entero positivo. Luego el programa imprime `N archivos copiados`, con el número del usuario en lugar de `N`. La palabra `archivo` debe tener la forma correcta, plural o singular.

## Ejemplo

Este ejemplo muestra lo que el programa debe hacer:

```console
$ raku plural-endings.raku
¿Cuántos archivos copiar? 15
15 archivos copiados.
```
