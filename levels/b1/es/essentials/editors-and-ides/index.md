Los programas en Raku se escriben como texto plano. Normalmente, se guardan en archivos de texto. Las excepciones son los programas que ejecutas en línea o en la línea de comandos. Otra excepción es el código que preparas para ejecutarlo con `EVAL`. También hay algunos otros casos raros.

Se espera que el código del programa sea texto UTF-8. Así que cualquier editor de texto sirve si no guarda el formato. Puedes usar sin problema `vim`, `nano`, `emacs` o `mcedit`. Pero quizás también quieras probar un par de aplicaciones nuevas y populares.

## Enlaces externos

Aquí están los enlaces a los IDEs populares.

* [Visual Studio Code](https://code.visualstudio.com/) — disponible para Windows, Mac OS y Linux
* [Comma](https://commaide.com) — el IDE de Raku, hecho especialmente para programar en Raku. Está disponible para Windows, Mac OS y Linux.
