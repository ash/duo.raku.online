## Problema

Escribe una subrutina `get` que devuelva su argumento. Pero cuando el argumento sea `0`, debe llamar a `fail` con el mensaje `bad`.

Imprime el resultado de `get(5)` y después el de `get(0)`. Usa el operador defined-or `//` para dar el valor de reserva `default`.

## Ejemplo

El programa imprime:

```
5
default
```
