## Problema

Escribe una subrutina `reciprocal` que devuelva `1` dividido por su argumento. Pero cuando el argumento sea `0`, debe usar `fail` con el mensaje `no reciprocal of zero`.

Imprime el resultado de `reciprocal(4)`. Después imprime el resultado de `reciprocal(0)`. En lugar de comprobar tú mismo `.defined`, usa el operador `//`. Debe dar la cadena `undefined` cuando la llamada falle.

## Ejemplo

El programa imprime:

```
0.25
undefined
```
