## Problema

Define dos clases vacías, `Cat` y `Dog`. Después recorre cuatro valores: `Cat`, `Dog`, `Cat.new` y `Dog.new`. Para cada uno, imprime si está definido. Fíjate en que los dos objetos de tipo no están definidos, y las dos instancias sí lo están. No importa a qué clase pertenecen.

## Ejemplo

El programa imprime:

```
False
False
True
True
```
