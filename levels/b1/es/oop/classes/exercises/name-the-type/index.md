## Problema

Define dos clases vacías, `Cat` y `Dog`, y crea una instancia de `Cat` llamada `$felix`. Imprime el tipo de `$felix` con `WHAT`. Después usa el operador `===` e imprime dos líneas más. La primera línea muestra si ese tipo es el mismo que `Cat`. La segunda muestra si es el mismo que `Dog`.

## Ejemplo

El programa imprime:

```
(Cat)
True
False
```
