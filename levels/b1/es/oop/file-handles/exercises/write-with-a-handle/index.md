## Problema

Abre para escribir un archivo llamado `out.txt`. Mantén el manejador abierto. En un bucle, escribe en él los números `1`, `2` y `3`. Pon cada número en su propia línea. Después cierra el manejador, vuelve a leer el archivo e imprime su contenido.

## Ejemplo

El programa imprime:

```
1
2
3
```
