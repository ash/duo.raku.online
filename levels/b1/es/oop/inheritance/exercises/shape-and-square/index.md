## Problema

Define una clase base `Shape` con dos métodos. El método `name` devuelve `'shape'`. El método `describe` devuelve la cadena `I am a <nombre>`, usando su propio método `name`.

Después define una clase `Square`, que hereda de `Shape`. Sobrescribe `name`, de modo que `name` devuelve `'square'`.

Imprime la descripción de un `Square`.

## Ejemplo

El programa imprime:

```
I am a square
```
