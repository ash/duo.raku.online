## Problema

Define una clase base `Vehicle` con un atributo `wheels`. Después define dos clases que hereden de ella. Una `Bike` viene con `2` ruedas, y un `Car` viene con `4`.

Crea una `Bike` y un `Car`, e imprime cuántas ruedas tiene cada uno.

## Ejemplo

El programa imprime:

```
2
4
```
