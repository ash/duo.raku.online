## Problema

Define una clase `Robot` con un método `speak` que devuelva `beep`. Después define un rol `Dancing`, que añade un método `dance` que devuelve `spinning around`.

Crea dos robots, pero dale el rol `Dancing` solo a uno de ellos. Imprime el resultado de `speak` para los dos robots. Después imprime el resultado de `dance` para el robot que sabe bailar.

## Ejemplo

El programa imprime:

```
beep
beep
spinning around
```
