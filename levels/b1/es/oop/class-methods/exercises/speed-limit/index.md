## Problema

Como cualquier otro método, un método de clase puede recibir parámetros. Define una clase `Geometry` con un método de clase `circle-area`. Recibe un radio y devuelve el área de un círculo, redondeada a un entero. Usa `π` o `pi`. La fórmula pertenece a toda la clase, y no hay ningún objeto círculo concreto. Llama al método sobre la clase con un radio de `10` e imprime el resultado.

## Ejemplo

El programa imprime:

```
314
```
