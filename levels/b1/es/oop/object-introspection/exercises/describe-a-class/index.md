## Problema

Define una clase base `Animal` y una clase `Dog` que herede de ella. Imprime el nombre de la clase `Dog`. En la línea siguiente, imprime el número de tipos de su cadena de herencia. Para ello, usa `.^mro` y cuenta sus elementos. Por último, en una tercera línea, imprime si una clase `Cat` está en algún lugar de esa cadena.

## Ejemplo

El programa imprime:

```
Dog
4
False
```
