## Problema

Ejecuta una orden que falle a propósito, por ejemplo `sh -c 'exit 4'`. Guarda el `Proc` que devuelve. Imprime el código de salida de la orden. Después imprime `success` o `failure`, según si la orden tuvo éxito.

## Ejemplo

El programa imprime:

```
4
failure
```
