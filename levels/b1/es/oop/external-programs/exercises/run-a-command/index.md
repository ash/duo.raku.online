## Problema

Usa `run` para iniciar `echo` con dos argumentos separados: `home:` y `$HOME`. Deja que su salida vaya a la pantalla. Fíjate en que `$HOME` aparece tal cual, y la carpeta personal **no** se imprime. Como `run` no usa una shell, la variable no se cambia por su valor.

## Ejemplo

El programa imprime:

```
home: $HOME
```
