## Problema

Define una clase `Label` con un atributo, `text`, que se pueda cambiar (`is rw`). Crea una etiqueta con el texto `draft`. Después usa el accesor para **añadir** ` (revised)` al final de su texto. No crees el objeto otra vez. Imprime el resultado.

## Ejemplo

El programa imprime:

```
draft (revised)
```
