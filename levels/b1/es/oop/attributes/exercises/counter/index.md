## Problema

Define una clase `Counter` con un atributo, `count`, que se puede cambiar (`is rw`). Su valor por defecto es `0`.

Crea un contador e imprime primero su `count`. Así compruebas que empieza en el valor por defecto. Después usa un bucle para sumarle uno cinco veces. Imprime el valor final.

## Ejemplo

El programa imprime:

```
0
5
```
