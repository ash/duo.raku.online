## Problema

Construye un pequeño archivo de registro añadiéndole líneas una y otra vez. Escribe la línea `start` en un archivo llamado `log.txt`. Después usa un bucle para **añadir** tres líneas más: `entry 1`, `entry 2` y `entry 3`. No borres lo que ya hay en el archivo. Por último, lee todo el archivo e imprímelo.

## Ejemplo

El programa imprime:

```
start
entry 1
entry 2
entry 3
```
