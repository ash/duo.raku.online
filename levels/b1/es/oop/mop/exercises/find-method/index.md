## Problema

Define una clase `Animal` con un método `speak`. Después define una clase `Dog` que herede de `Animal`. No añade métodos propios. Usa un metamétodo sobre `Dog` e imprime si `Dog` tiene un método llamado `speak`. Imprime un simple `True` o `False`. Esto muestra que `find_method` busca a lo largo de la cadena de herencia. No busca solo entre los métodos propios de la clase.

## Ejemplo

El programa imprime:

```
True
```
