## Problema

Muestra las dos caras de `try`. Primero, usa un bloque `try` alrededor de un cálculo que funciona, por ejemplo `6 * 7`. Después imprime su resultado. Luego pon código que hace `die 'broken'` en un segundo bloque `try`. Imprime si ese bloque dio un resultado definido. Después imprime el mensaje de la excepción capturada.

## Ejemplo

El programa imprime:

```
42
False
broken
```
