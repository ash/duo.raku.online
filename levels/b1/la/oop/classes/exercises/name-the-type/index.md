## Problema

Define duas classes vacuas, `Cat` et `Dog`, et crea exemplar `Cat` nomine `$felix`. Imprime genus `$felix` per `WHAT`. Deinde operatore `===` utere et duas lineas amplius imprime. Prima linea ostendit utrum illud genus idem sit ac `Cat`. Secunda ostendit utrum idem sit ac `Dog`.

## Exemplum

Programma imprimit:

```
(Cat)
True
False
```
