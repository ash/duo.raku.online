## Problema

Aperi archivum nomine `out.txt` ad scribendum. Tractabulum apertum serva. In anulo numeros `1`, `2` et `3` in id scribe. Quemque numerum in sua linea pone. Deinde tractabulum claude, archivum retro lege et contentum eius imprime.

## Exemplum

Programma imprimit:

```
1
2
3
```
