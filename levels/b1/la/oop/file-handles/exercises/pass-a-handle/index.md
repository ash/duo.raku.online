## Problema

Tractabulum archivi valor ordinarius est. Itaque id functioni tradere potes, sicut quodlibet aliud argumentum. Scribe subprogramma `log-line` quod tractabulum et nuntium accipit. Nuntium in tractabulum in sua linea scribere debet.

Aperi `log.txt` ad scribendum. Voca `log-line` ter ut `started`, `working` et `done` scribas. Deinde tractabulum claude, archivum retro lege et contentum eius imprime.

## Exemplum

Programma imprimit:

```
started
working
done
```
