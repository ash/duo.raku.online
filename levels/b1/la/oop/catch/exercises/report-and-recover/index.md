## Problema

Ostende quomodo programma auxilio `CATCH` recuperare possit. Cum valore praedefinito idoneo pergit.

Ante clausulam declara variabilem `$timeout` cum valore praedefinito `30`. Intra clausulam age `die 'config missing'`. Deinde, in linea quae numquam currit, conare `$timeout` ad `60` ponere. Utere fasi `CATCH` cuius clausula `default` imprimit `warning: <nuntius>; keeping default`. Post clausulam imprime `timeout is <timeout> seconds`.

## Exemplum

Programma imprimit:

```
warning: config missing; keeping default
timeout is 30 seconds
```
