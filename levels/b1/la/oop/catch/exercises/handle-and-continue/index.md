## Problema

Percurre tria elementa `ok`, `bad` et `ok`. Pro quoque elemento curre clausulam quae `processed <elementum>` imprimit. Sed cum elementum est `bad`, clausula `die 'boom'` agere debet. Pone fasim `CATCH` intra clausulam. Elementum deficiens ut `skipped (<elementum>): <nuntius>` nuntiare debet. Deinde anulus non sistit, sed ad elementum sequens pergit.

## Exemplum

Programma imprimit:

```
processed ok
skipped (bad): boom
processed ok
```
