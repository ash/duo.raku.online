## Problema

Scribe subprogramma `risky` quod `die 'sub failed'` agit. Deinde voca illud ex clausula quae fasim `CATCH` habet. `CATCH` nomen generis exceptionis per `.^name` imprimere debet. Deinde nuntium eius per `.message` imprimere debet. Hoc ostendit `CATCH` exceptiones tractare ex codice quem clausula *vocat*. Non necesse est `die` directe in clausula scribere.

## Exemplum

Programma imprimit:

```
X::AdHoc
sub failed
```
