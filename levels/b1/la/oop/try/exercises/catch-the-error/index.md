## Problema

Ostende utramque partem `try`. Primum utere clausula `try` circa computationem quae bene operatur, exempli gratia `6 * 7`. Deinde effectum eius imprime. Tum codicem qui `die 'broken'` agit in alteram clausulam `try` pone. Imprime utrum illa clausula effectum definitum dederit. Deinde nuntium exceptionis captae imprime.

## Exemplum

Programma imprimit:

```
42
False
broken
```
