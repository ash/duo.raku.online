## Problema

Programma cum valore laborat, et valor negativus esse apparet. Si valor infra nihil est, `note` adhibe ut monitum ad errorem vulgarem mittas. `say` adhibe ut verum effectum, valorem absolutum, ad exitum vulgarem mittas. Utere valore `-3`.

## Exemplum

Utraque linea in screen apparet:

```
Warning: the value is negative
3
```

Si errorem vulgarem abicis, solus effectus manet:

```
$ raku note-a-warning.raku 2>/dev/null
3
```
