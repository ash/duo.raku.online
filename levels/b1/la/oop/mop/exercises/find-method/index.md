## Problema

Define classem `Animal` cum methodo `speak`. Deinde define classem `Dog` quae ab `Animal` heredat. Nullas proprias methodos addit. Utere metamethodo in `Dog` et imprime utrum `Dog` methodum nomine `speak` habeat. Imprime simplex `True` vel `False`. Hoc ostendit `find_method` per catenam hereditatis quaerere. Non solum in propriis classis methodis quaerit.

## Exemplum

Programma imprimit:

```
True
```
