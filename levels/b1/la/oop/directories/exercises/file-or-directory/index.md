## Problema

Crea archivum nomine `a.txt`. Deinde *eidem* semitae duas quaestiones pone. Estne archivum ordinarium (`.f`), et estne directoria (`.d`)? Utrumque responsum imprime, ut videas duas probationes pro una semita contraria responsa dare.

## Exemplum

Programma imprimit:

```
True
False
```
