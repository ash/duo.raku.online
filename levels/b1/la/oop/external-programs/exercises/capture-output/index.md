## Problema

Utere `run` cum `:out` ut `echo` cum tribus verbis `hello world raku` incipias. Exitum eius in variabili cape. Deinde eum non tantum imprime, sed numera quot verba contineat. Illum numerum imprime.

## Exemplum

Programma imprimit:

```
3
```
