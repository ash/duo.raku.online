## Problema

Define classem `Robot` cum methodo `speak` quae `beep` reddit. Deinde define partem `Dancing`, quae methodum `dance` addit quae `spinning around` reddit.

Crea duo robota, sed partem `Dancing` uni tantum ex eis da. Imprime effectum `speak` pro utroque roboto. Deinde imprime effectum `dance` pro roboto quod saltare potest.

## Exemplum

Programma imprimit:

```
beep
beep
spinning around
```
