## Problema

Scribe subprogramma `lookup`. `100` reddit cum argumentum eius est `'a'`. Aliter `fail` cum nuntio `no such key` vocat.

Voca `lookup('z')` et effectum eius imprime si definitus est. Si non est, imprime `not found`. Altera linea imprime causam defectus, ex ipso `Failure` sumptam: `reason: <nuntius>`.

## Exemplum

Programma imprimit:

```
not found
reason: no such key
```
