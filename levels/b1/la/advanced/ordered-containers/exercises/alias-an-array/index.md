## Problema

Hunc ordinem habes:

```raku
my @original = 10, 20, 30;
```

Crea secundum nomen, `@alias`, pro _eodem_ ordine, sine copia. Hac vice novum elementum in `@original` per `push` adde, et deinde `@alias` imprime. Hoc ostendit alias etiam mutationes structurae videre, non solum valorum.

## Exemplum

Programma imprimit:

```
[10 20 30 40]
```
