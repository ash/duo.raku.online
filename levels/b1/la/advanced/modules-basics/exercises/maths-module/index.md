## Problema

Crea modulum nomine `Maths` in archivo `Maths.rakumod`. Subprogramma `square` exportare debet, quod quadratum argumenti sui reddit.

Deinde scribe programma separatum quod modulo utitur et `square(6)` imprimit.

## Exemplum

Si id cum modulo in semita quaesitionis curris, programma imprimit:

```console
$ raku -I. maths.raku
36
```
