Hic est una solutio possibilis.

## Codex

```raku
say (5, 10 ... 50).tail(3);
```

🦋 Inveni codicem fontem in archivo [last-three.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/sequences/last-three.raku).

## Exitus

```
(40 45 50)
```

## Commentarii

1. Semina, id est valores initiales, `5, 10` gradum arithmeticum quinque constituunt. Series usque ad finem suum `50` it.

1. `tail(3)` tres ultimos valores seriei finitae reddit: `40, 45, 50`. Eodem modo `head` primos paucos redderet.
