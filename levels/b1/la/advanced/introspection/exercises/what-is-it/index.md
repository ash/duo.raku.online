## Problema

`WHAT` non solum typum describit. Ipsum obiectum typi reddit, et id cum operatore `===` comparare potes.

Declara duas variabiles. Variabilis `$a` integrum `42` continet, et `$b` seriem `'x'` continet. Pro utraque imprime an eius `WHAT` sit typus `Int`.

## Exemplum

Programma imprimit:

```
True
False
```
