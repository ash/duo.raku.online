## Problema

Scribe subprogramma `describe` quod nomen positionale necessarium accipit. Post id, subprogramma quotlibet argumenta nominata in mappam sorbentem (`*%opts`) colligit. Chordam formae `nomen: clavis=valor, clavis=valor, ...` reddere debet. Chorda omnem optionem enumerat, clavibus ordine alphabetico.

Voca illud ut `describe('Anna', colour => 'red', size => 5)` et effectum imprime.

## Exemplum

Programma imprimit:

```
Anna: colour=red, size=5
```
