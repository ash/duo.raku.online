Quid sequens programma imprimit?

```raku
my int $n = 42;
say $n.^name;
```

{:.quiz}
1 | Int
0 | int
0 | (Int)
0 | Num

{% include quiz.html %}

<div class="extended-explanation">

Cum valorem nativum de se ipso interrogas, Raku eum automatice *involvit*. Valor in typum plenum respondentem it. Hic `$n` ut nativus `int` declaratus est. Sed `.^name` tamen typum eius ut involutum `Int` refert.

</div>
