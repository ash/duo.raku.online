## Problema

Variabilis nativa numquam indefinita esse potest. Haec regula pro omni typo nativo valet, non solum pro `int`. Declara nativum `num` et nativum `str` sine valoribus. Numerum imprime. Deinde chordam intra parentheses quadratas imprime, ut eam vacuam esse videas.

## Exemplum

Hoc programma imprimit:

```
0
[]
```
