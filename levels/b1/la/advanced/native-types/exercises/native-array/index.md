## Problema

Usus naturalis typi nativi dimensi est index bytorum. Talis index parum memoriae adhibet. Declara indicem `uint8` cum valoribus `100`, `200` et `255`. Quisque eorum in uno byte locum habet. Deinde summam elementorum eius imprime.

Nota quod quodque elementum intra ambitum `0..255` manet, sed summa altior esse potest. Hoc fit quia `.sum` reddit `Int` ordinarium.

## Exemplum

Hoc programma imprimit:

```
555
```
