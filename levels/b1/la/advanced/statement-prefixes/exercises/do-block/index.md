## Problema

`do` etiam ante sententias fluxus controllandi operatur. Eas in expressiones convertit quae valorem dant. Utere `do if 7 > 5 { 'big' } else { 'small' }` ad etiketam eligendam. Deinde eam ad `$label` assigna et imprime.

## Exemplum

Programma imprimit:

```
big
```
