## Problema

Praefixum `eager` contrarium `lazy` facit. Raku cogit totum indicem producere, itaque index non iam piger est. Differentiam cum `.is-lazy` ostende.

Imprime num intervallum infinitum `1 .. Inf` pigrum sit. Deinde imprime num `eager 1..3` pigrum sit, et denique num `lazy 1..3` pigrum sit. Resultata debent esse `True`, `False`, `True`.

## Exemplum

Programma imprimit:

```
True
False
True
```
