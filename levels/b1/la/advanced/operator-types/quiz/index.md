Ad quam categoriam subscriptum `[0]` in expressione `@a[0]` pertinet?

{:.quiz}
0 | postfix
1 | postcircumfix
0 | circumfix
0 | infix

{% include quiz.html %}

<div class="extended-explanation">

Subscriptum uncos circum contentum suum ponit *et* post terminum venit, hic `@a`. Itaque est operator postcircumfixus. Postfixus simplex ut `++` nullos uncos circum aliquid habet. Circumfixus, ut constructor ordinis `[1, 2, 3]`, circum aliquid it. Sed post terminum non venit.

</div>
