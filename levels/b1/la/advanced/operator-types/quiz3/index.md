Operator `x` chordam repetit. Exempli gratia, `'ab' x 3` dat `'ababab'`. Quia `x` inter duos operandos suos stat, in qua categoria est?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Positio interest, non utrum operator symbolum sit an verbum. `x` *inter* duos operandos stat, itaque operator **infixus** est. Sicut `+` vel `~` est, sed ut littera scribitur.

</div>
