## Problema

Symbolum operatoris quilibet character esse potest, etiam character Unicode. Defini operatorem **postfixum** `²` qui operandum suum quadrat, ita ut `5²` significet `5 ** 2`. Deinde imprime `5²`.

## Exemplum

Programma imprimit:

```
25
```
