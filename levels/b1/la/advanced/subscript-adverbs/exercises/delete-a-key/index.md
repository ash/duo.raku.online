## Problema

Sume tabulam `a => 1, b => 2, c => 3`. Adverbio subscripti utere ut introitum `b` deleas. Deinde imprime quot introitus maneant, ut ostendas unum ex eis remotum esse.

## Exemplum

Programma imprimit:

```
2
```
