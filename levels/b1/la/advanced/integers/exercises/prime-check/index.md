## Problema

Plerumque difficile est solis oculis videre an numerus primus sit. Methodus `is-prime` huic quaestioni respondet. Eam in duobus numeris adhibe qui ambo primo primi videntur: `97` et `91`. Eventum pro unoquoque in linea separata imprime.

Numerus dolosus est `91`, quia `7 × 13` aequat.

## Exemplum

Hoc programma imprimit:

```
True
False
```
