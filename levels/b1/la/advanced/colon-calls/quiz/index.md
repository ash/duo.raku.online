Quid sequens programma imprimit?

```raku
say 'programming'.substr: 0, 3;
```

{:.quiz}
1 | pro
0 | program
0 | ing
0 | (0 3)

{% include quiz.html %}

<div class="extended-explanation">

Colon *totum* reliquum enuntiati ut indicem argumentorum capit. Itaque `substr: 0, 3` idem est ac `substr(0, 3)`, et ambo argumenta traduntur. Ab indice `0` incipit et `3` litteras capit, quod `pro` dat.

</div>
