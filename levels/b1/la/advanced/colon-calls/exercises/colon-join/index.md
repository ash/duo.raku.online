## Problema

Forma cum colono *ultima* vocatio in catena esse debet. Sed vocationes ante eam ordinariae cum parenthesibus esse possunt. Incipe a verbis `a`, `b`, `c` et ea cum `.reverse` inverte. Deinde exitum cum lineola coniunge, forma **cum colono** adhibita. Id imprime.

## Exemplum

Programma imprimit:

```
c-b-a
```
