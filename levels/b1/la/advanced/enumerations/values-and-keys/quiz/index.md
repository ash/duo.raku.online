Quid sequens programma imprimit?

```raku
enum Day (Mon => 1, Tue => 2);
say Tue.key;
```

{:.quiz}
1 | Tue
0 | 2
0 | 1
0 | Mon

{% include quiz.html %}

<div class="extended-explanation">

`.value` numerum post constantem reddit. `.key` autem *nomen* eius ut chordam reddit. Itaque `Tue.key` est `Tue`, et numerus `2` qui ei datus est non interest.

</div>
