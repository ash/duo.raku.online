## Problema

Operator `**` arctius quam `+` ligat, ergo `2 ** 3 + 1` significat `(2 ** 3) + 1`, quod est `9`. Adde parentheses ut hunc ordinem mutes, ita ut additio *primum* fiat. Deinde eventum imprime.

## Exemplum

Programma imprimit:

```
16
```
