## Problema

Crea fasciculum `Temperature` qui duas res simul colligit. Prima est variabilis `our` nomine `$freezing` cum valore `0`. Secunda est subroutina `our` nomine `fahrenheit`, quae valorem Celsius in Fahrenheit convertit. Ad convertendum, multiplica per 9/5 et adde 32. Extra fasciculum, punctum congelationis imprime. Deinde valorem Fahrenheit `100` graduum Celsius imprime.

## Exemplum

Programma imprimit:

```
0
212
```
