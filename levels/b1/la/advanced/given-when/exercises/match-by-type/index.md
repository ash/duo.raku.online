## Problema

`when` cum *typo* congruere potest, non solum cum valore. Variabilis numerum `3.14` continet. Adhibe `given`/`when` ut ostendas quale genus valoris sit. Imprime `integer` pro `Int`, `rational` pro `Rat`, et `string` pro `Str`.

## Exemplum

Programma imprimit:

```
rational
```
