## Problema

Indicem numerorum habes, et aliqui ex eis repetuntur:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Imprime quot valores _distincti_ in eo sint. Ad hoc coniunctum adhibe.

## Exemplum

Programma imprimit:

```
7
```
