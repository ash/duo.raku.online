## Problema

Trait proprium argumentum accipere potest. Non necesse est tantum praesens vel absens esse. Scribe trait `is role(...)` quod seriem characterum accipit. Munus cuiusque subroutinae in hash registrat. Clavis in hash est nomen subroutinae.

Applica `is role('admin')` subroutinae `login`. Deinde munus imprime quod pro `login` repositum est.

## Exemplum

Programma imprimit:

```
admin
```
