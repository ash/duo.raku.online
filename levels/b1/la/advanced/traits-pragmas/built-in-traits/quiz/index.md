Quis trait subroutinae permittit **variabilem vocantis mutare** per parametrum?

{:.quiz}
1 | `is rw`
0 | `is copy`
0 | `is default`
0 | nullus — parametra ex defectu scribilia sunt

{% include quiz.html %}

<div class="extended-explanation">

Parametrum ex defectu tantum-lectu est, ergo parametro simplici assignare non potes. `is rw` parametrum variabili propriae vocantis ligat. Ergo mutatio intra routinam etiam foris visibilis est. `is copy` potius tibi *copiam* daret quam mutare potes. Variabilis vocantis intacta maneret.

</div>
