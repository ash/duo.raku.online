## Problema

`index` tibi dicit *ubi* character sit. Deinde `substr` tibi permittit chordam eo loco secare. Duas methodos simul adhibe.

Sume inscriptionem electronicam `user@example.com`. Inveni positionem signi `@`. Deinde omnia post id imprime, quae sunt pars dominii.

## Exemplum

Hoc programma imprimit:

```
example.com
```
