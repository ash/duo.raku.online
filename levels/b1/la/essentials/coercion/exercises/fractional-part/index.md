## Problema

Habes numerum, qui directe in codice programmatis scriptus est. Imprime eius partem fractionalem. Hic est initium programmatis:

```raku
my $n = 15.8972;
# ... Tua codex hic
```

## Exemplum

Programma partem numeri post punctum decimalem imprimere debet:

```console
$ raku fractional-part.raku
0.8972
```
