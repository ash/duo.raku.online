title: Codicis sectiones
---

{% include menu.html %}

Claustra codicis sunt partes programmatis tui intra par uncinorum curvorum: `{` et `}`. Claustrum plures enuntiationes coniungit, quae simul operantur quasi una magna enuntiatio. In sectionibus sequentibus multos usus claustrorum videbimus.

```raku
{
    say 'Salve, Munde!';
}
```

Claustrum codicis in hoc programmate non vere sensum habet. Sed claustra codicis in aliis casibus valde utilia sunt, quos mox videbimus.

Sed primum notionem _ambitus_ spectemus.
