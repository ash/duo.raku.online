## Problema

Ecce tabula cum datis operarii:

```raku
my %employee =
    full-name => 'Eliza Vents',
    department => 'Sales',
    salary => 3000;
```

Auge salarium per 5&thinsp;% et id una cum nomine operarii imprime. Post augmentum, tabula `%employee` adhuc rectos valores continere debet.

## Exemplum

Hoc est quod programma imprimere debet:

```console
$ raku salary-raise.raku
New salary of Eliza Vents: 3150
```
