Potes etiam `loop` cum solo corpore adhibere:

```raku
loop {
    say 'Aeternitas';
}
```

Hic circulus sine fine currit, donec programma sistis, exempli gratia, `Ctrl+C` premendo. In secunda parte cursus, meliores modos videbimus ad circulos regendos.
