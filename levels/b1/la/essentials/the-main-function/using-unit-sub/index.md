---
title: 'Utendo `unit sub`'
---

{% include menu.html %}

Constructum `unit sub` valde utile est. Reliquam partem fasciculi corpus functionis facit! Cum `MAIN`, tibi licet uncos curvos circa fere totum fasciculum tollere. Nec indentationem additam requiris.

Sequens exemplum programmatis ostendit quomodo `unit sub` adhibeas.

```raku
unit sub MAIN($a, $b);

my $sum = $a + $b;
say "The sum of $a and $b is $sum.";
```

In hoc fasciculo, `MAIN` sola functio est. Si idem in programmate tuo verum est, cogita de usu `unit sub MAIN`, sicut supra ostenditur.
