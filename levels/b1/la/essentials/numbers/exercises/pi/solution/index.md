Programma quod valorem π imprimit satis simplex est.

## Codex

```raku
say π;
```

🦋 Totum codicem invenire potes in archivo [pi.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/numbers/pi.raku).

## Exitus

Programma exsequere et vide quid imprimat:

```console
$ raku exercises/numbers/pi.raku
3.141592653589793
```

## Commentarii

Raku nobis constantem in structura nomine `π` dat, itaque programma simplicissimum est. Tamen hic sunt alii modi idem faciendi:

```raku
    π.say;
```

Vel:

```raku
    pi.say;
```

Vel:

```raku
    say pi;
```
