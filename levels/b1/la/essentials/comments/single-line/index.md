Simplicissimum genus commentarii est commentarius unius lineae. Incipit a charactere `#`. Pergit usque ad finem lineae currentis.

```raku
my $name; # Haec variabilis ad nomen usoris servandum adhibetur
$name = prompt 'Quod est nomen tuum? ';
say $name; # Nunc nomen videmus
```

Specta shebang sicut `#!/usr/bin/env raku` in prima linea codicis. Pro Raku, id etiam commentarius est. Sed testudo id legere et exsequi potest.
