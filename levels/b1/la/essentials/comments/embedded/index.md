title: Inscripti commentarii
---

{% include menu.html %}

Commentarii incorporati, vel in linea, eandem formam habent ac commentarii multi-lineae. Sola differentia est quod inter alias partes programmatis ponuntur. Exempli gratia:

```raku
my $name;
$name = #`[User input expected here] prompt 'Quod est nomen tuum? ';
say $name;
```

Cum bono syntax highlighter commentarios multo facilius vides.
