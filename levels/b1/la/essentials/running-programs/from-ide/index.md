Haec brevis sectio explicat quomodo programma intra IDE curras. Duo [IDEs](../../editors-and-ides) maxime commendata tractat.

## Visual Studio Code Editor

Aperi terminalem per menu `Terminal` → `New Terminal`. Panel infra textum programmatis tui addit. Ibi programma curre, sicut ex linea mandati:

```console
$ raku hello.raku
```

## Comma IDE

Programmata per `Run` in menu currere potes. IDE ante primum cursum programmatis institue. Sequere [instructiones](https://commaide.com/docs/running) in situ Comma.
