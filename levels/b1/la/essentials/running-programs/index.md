In [una ex sectionibus praecedentibus](../hello-world) programma simplex creavimus. Sed id nondum cucurrimus. Multae viae sunt ad programma currendum. Instrumentum lineae mandati installatum aut REPL concham adhibere potes. Id etiam directe ex [IDE](../editors-and-ides) currere potes. Alia via est servitium online, ut [glot.io](https://glot.io/new/raku). Etiam continens docker adhibere potes.

Haec sectio quinque argumenta habet. Omnia perlustra, aut ea sola examina quae requiris. Post argumenta est assignatio.
