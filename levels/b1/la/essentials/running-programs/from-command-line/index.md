---
title: Currendo ex linea mandati
---

{% include menu.html %}

Serva textum programmatis in fasciculo textuali, exempli gratia, `hello.raku`. Deinde viam eius instrumento lineae mandati `raku` trade. Character dollari promptum testae ostendit:

```console
$ raku hello.raku
```

Si programma errores non habet, statim currit. Si aliquis exitus est, eum in terminali videbis:

```console
$ raku hello.raku 
Hello, World!
```

In systematibus Unix-fundatis shebang addere et fasciculum exsecutabilem facere potes:

```raku
#!/usr/bin/env raku

say 'Hello, World!';
```

Proximi gradus sunt sequentes:

```console
$ chmod a+x hello.raku
$ ./hello.raku
Hello, World!
```
