## Opgave

Definieer twee lege klassen, `Cat` en `Dog`, en maak een `Cat`-instantie met de naam `$felix`. Druk het type van `$felix` af met `WHAT`. Gebruik daarna de operator `===` en druk nog twee regels af. De eerste regel toont of dat type hetzelfde is als `Cat`. De tweede toont of het hetzelfde is als `Dog`.

## Voorbeeld

Het programma drukt af:

```
(Cat)
True
False
```
