## Opgave

Definieer een klasse `Label` met één attribuut, `text`, dat je kunt veranderen (`is rw`). Maak een label met de tekst `draft`. Gebruik daarna de accessor om ` (revised)` achter de tekst te **plakken**. Maak het object niet opnieuw. Druk het resultaat af.

## Voorbeeld

Het programma drukt af:

```
draft (revised)
```
