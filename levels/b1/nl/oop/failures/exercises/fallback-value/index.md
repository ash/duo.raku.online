## Opgave

Schrijf een subroutine `get` die haar argument teruggeeft. Maar als het argument `0` is, moet ze `fail` aanroepen met de melding `bad`.

Druk het resultaat af van `get(5)` en daarna van `get(0)`. Gebruik de defined-or-operator `//` om de terugvalwaarde `default` te geven.

## Voorbeeld

Het programma drukt af:

```
5
default
```
