## Opgave

Laat beide kanten van `try` zien. Gebruik eerst een `try`-blok om een berekening die lukt, bijvoorbeeld `6 * 7`. Druk daarna het resultaat af. Zet vervolgens code die `die 'broken'` doet in een tweede `try`-blok. Druk af of dat blok een gedefinieerd resultaat gaf. Druk daarna de melding van de gevangen exceptie af.

## Voorbeeld

Het programma drukt af:

```
42
False
broken
```
