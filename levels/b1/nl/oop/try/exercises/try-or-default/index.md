## Opgave

Een `try`-blok dat mislukt, geeft een ongedefinieerde waarde. Gebruik dat samen met de defined-or-operator `//` om een terugvalwaarde te leveren. Draai een `try`-blok met `die 'no'` erin. Als het mislukt, gebruik dan in plaats daarvan de string `default`. Druk het resultaat af.

## Voorbeeld

Het programma drukt af:

```
default
```
