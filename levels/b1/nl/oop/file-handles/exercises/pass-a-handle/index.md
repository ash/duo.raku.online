## Opgave

Een bestandshandle is een gewone waarde. Dus kun je hem aan een functie meegeven, net als elk ander argument. Schrijf een subroutine `log-line` die een handle en een melding aanneemt. Ze moet de melding op een eigen regel naar de handle schrijven.

Open `log.txt` om te schrijven. Roep `log-line` drie keer aan om `started`, `working` en `done` te schrijven. Sluit daarna de handle, lees het bestand terug en druk de inhoud af.

## Voorbeeld

Het programma drukt af:

```
started
working
done
```
