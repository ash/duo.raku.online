## Opgave

Open een bestand met de naam `out.txt` om te schrijven. Houd de handle open. Schrijf in een lus de getallen `1`, `2` en `3` ernaar. Zet elk getal op een eigen regel. Sluit daarna de handle, lees het bestand terug en druk de inhoud af.

## Voorbeeld

Het programma drukt af:

```
1
2
3
```
