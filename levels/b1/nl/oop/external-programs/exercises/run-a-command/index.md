## Opgave

Gebruik `run` om `echo` te starten met twee afzonderlijke argumenten: `home:` en `$HOME`. Laat de uitvoer naar het scherm gaan. Merk op dat `$HOME` verschijnt zoals het er staat, en dat de thuismap **niet** afgedrukt wordt. Omdat `run` geen shell gebruikt, wordt de variabele niet door haar waarde vervangen.

## Voorbeeld

Het programma drukt af:

```
home: $HOME
```
