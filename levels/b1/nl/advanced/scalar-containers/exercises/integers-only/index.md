## Probleem

Declareer een container `$cars` die alleen gehele getallen kan bewaren.

Je hebt een waarde die uit berekeningen met een verkeersmodel kwam: `250.7`. Sla deze op in `$cars`. Zet hem eerst om naar een geheel getal, zodat de toewijzing wordt geaccepteerd. Druk daarna de waarde en het type af.

## Voorbeeld

Het programma drukt af:

```
250
(Int)
```
