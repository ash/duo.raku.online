## Opgave

Een eigen trait kan een argument aannemen. Hij hoeft niet alleen aanwezig of afwezig te zijn. Schrijf een trait `is role(...)` die een string aanneemt. Hij legt de rol van elke subroutine vast in een hash. De sleutel in de hash is de naam van de subroutine.

Pas `is role('admin')` toe op een subroutine `login`. Druk daarna de rol af die voor `login` is opgeslagen.

## Voorbeeld

Het programma drukt af:

```
admin
```
