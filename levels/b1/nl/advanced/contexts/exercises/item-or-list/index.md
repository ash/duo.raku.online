## Probleem

Neem de array `1, 2, 3` en verpak hem in een scalar `$x` met de **item**-contextomzetter. Dan bevat `$x` de hele array als één waarde. Gebruik daarna de **lijst**-contextomzetter om een `for`-lus over `$x` te laten lopen. Tel hoe vaak de lus loopt. Lijstcontext spreidt de verpakte array weer uit in zijn elementen. Dus loopt de lus drie keer. Druk het aantal af.

## Voorbeeld

Het programma drukt af:

```
3
```
