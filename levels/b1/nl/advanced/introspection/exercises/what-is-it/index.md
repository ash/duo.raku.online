## Probleem

`WHAT` beschrijft niet alleen een type. Het geeft het type object zelf terug, en dat kun je vergelijken met de `===`-operator.

Declareer twee variabelen. De variabele `$a` bevat het gehele getal `42`, en `$b` bevat de string `'x'`. Druk voor elk ervan af of zijn `WHAT` het type `Int` is.

## Voorbeeld

Het programma drukt af:

```
True
False
```
