## Probleem

Een container kan een standaardwaarde hebben, die je instelt met de `is default`-trait. Totdat je iets toewijst, geeft de variabele deze standaardwaarde terug. `.VAR.default` vertelt je ook wat die is.

Declareer een scalar `$count` met de standaardwaarde `0`. Wijs er niets aan toe. Druk eerst de variabele zelf af, en druk daarna de standaardwaarde van zijn container af. Beide regels moeten `0` tonen.

## Voorbeeld

Het programma drukt af:

```
0
0
```
