## Probleem

Hier is een variabele met typebeperking:

```raku
my Str $lang = 'Raku';
```

Druk er drie feiten over af, één op elke regel:

1. het type van zijn waarde;
2. het type van zijn container;
3. zijn naam, inclusief de sigil.

## Voorbeeld

Het programma drukt af:

```
Str
Scalar
$lang
```
