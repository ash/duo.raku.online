## Opgave

Een native variabele kan nooit ongedefinieerd zijn. Deze regel geldt voor elk native type, niet alleen voor `int`. Declareer een native `num` en een native `str` zonder ze een waarde te geven. Druk het getal af. Druk daarna de string af tussen vierkante haken, zodat je kunt zien dat hij leeg is.

## Voorbeeld

Het programma drukt af:

```
0
[]
```
