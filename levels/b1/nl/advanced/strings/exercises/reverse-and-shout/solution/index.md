Hier is een mogelijke oplossing.

## Code

```raku
say 'raku'.flip.uc;
```

🦋 Je kunt de broncode vinden in het bestand [reverse-and-shout.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/strings/reverse-and-shout.raku).

## Uitvoer

```
UKAR
```

## Opmerkingen

1. De methoden werken van links naar rechts. Eerst keert `flip` `'raku'` om tot `'ukar'`, en daarna maakt `uc` er `'UKAR'` van.

1. Elke methode geeft een nieuwe string terug, dus je kunt ze in één uitdrukking aan elkaar koppelen.
