## Probleem

Declareer een variabele met het type integer: `my Int $n = 42;`. Dump deze daarna met `dd`. Let op hoe de uitvoer verschilt van die van een variabele zonder type.

## Voorbeeld

Het programma schrijft dit naar standaardfout:

```
Int $n = 42
```
