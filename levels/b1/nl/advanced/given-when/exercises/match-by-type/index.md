## Opgave

Een `when` kan matchen op een *type*, niet alleen op een waarde. Een variabele bevat het getal `3.14`. Gebruik `given`/`when` om te laten zien wat voor soort waarde het is. Druk `integer` af voor een `Int`, `rational` voor een `Rat` en `string` voor een `Str`.

## Voorbeeld

Het programma drukt af:

```
rational
```
