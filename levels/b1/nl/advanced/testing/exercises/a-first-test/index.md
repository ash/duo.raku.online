## Opgave

Gebruik de `Test`-module om één `ok`-test te schrijven. Die moet controleren of de string `Raku` vier tekens heeft, met de beschrijving `Raku has four letters`. Sluit af met `done-testing`.

## Voorbeeld

Het programma geeft de volgende uitvoer:

```
ok 1 - Raku has four letters
1..1
```
