Tests controleren of je code doet wat die moet doen. Ze controleren ook of de code blijft werken als je die verandert. Raku wordt geleverd met een testmodule, `Test`. Het heeft ook vaste manieren om hele reeksen tests tegelijk uit te voeren. Tests schrijven is een belangrijk deel van het bouwen van echte Raku-programma's en -modules.

Dit onderdeel behandelt de basisdelen van de `Test`-module. Het laat ook zien welke soorten vergelijkingen de module biedt en hoe je tests uitvoert.
