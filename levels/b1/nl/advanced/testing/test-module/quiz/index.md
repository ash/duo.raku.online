Welke functie in de `Test`-module slaagt als een Booleaanse voorwaarde waar is?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` neemt een voorwaarde en slaagt als die waar is. `is` vergelijkt een werkelijke waarde met een verwachte waarde. `plan` zegt hoeveel tests er verwacht worden. `done-testing` sluit het bestand af en print het plan.

</div>
