## Opgave

Schrijf een `META6.json` voor een distributie met de naam `Greet::Simple`, versie `0.0.1`. Ze levert de module `Greet::Simple` uit het bestand `lib/Greet/Simple.rakumod`. In het voorbeeld uit de theorie was `depends` leeg. Deze keer **hangt** de distributie **af van** een andere distributie, `JSON::Fast`. Voeg die toe aan de array `depends`.

> Het resultaat van deze oefening is een bestand, geen programma-uitvoer.

## Voorbeeld

Een correct bestand met alleen de nodige delen ziet eruit als dat in de oplossing.
