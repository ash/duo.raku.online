Een _statement prefix_ is een sleutelwoord dat je voor een statement of blok zet. Het verandert de manier waarop de code draait. Je hebt er al een gezien: `gather`, dat alles verzamelt wat een blok aan `take` geeft. Dit gedeelte laat nog een paar prefixen voor algemeen gebruik zien.

Met prefixen kun je verschillende dingen doen. Je kunt een blok veranderen in een expressie die een waarde geeft (`do`). Je kunt bepalen wanneer een lijst berekend wordt: meteen of pas als het nodig is (`eager` en `lazy`). En je kunt code alleen voor zijn neveneffecten draaien (`sink`). Of je kunt code draaien met de waarschuwingen uitgezet (`quietly`).
