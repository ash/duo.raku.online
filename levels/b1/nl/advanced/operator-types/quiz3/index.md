De `x`-operator herhaalt een string. Zo geeft `'ab' x 3` bijvoorbeeld `'ababab'`. Omdat `x` tussen zijn twee operanden staat, bij welke categorie hoort hij?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Wat telt is de positie, niet of de operator een symbool of een woord is. `x` staat *tussen* twee operanden, dus het is een **infix**-operator. Het is net als `+` of `~`, maar geschreven als een letter.

</div>
