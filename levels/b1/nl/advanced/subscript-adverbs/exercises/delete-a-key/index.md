## Opgave

Neem de hash `a => 1, b => 2, c => 3`. Gebruik een subscript-adverb om het item `b` te verwijderen. Druk daarna af hoeveel items er nog over zijn, om te laten zien dat er één is verwijderd.

## Voorbeeld

Het programma drukt af:

```
2
```
