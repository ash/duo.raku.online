## Probleem

Een URL is in stukken gesplitst, en de stukken staan in een array. Plak ze met een reductie-meta-operator weer aan elkaar tot één tekenreeks. Druk de URL af, en druk op de volgende regel af hoeveel tekens hij heeft.

## Voorbeeld

Neem deze invoer-array:

```raku
my @parts = <http :// example .com>;
```

Met deze array drukt het programma dit af:

```
http://example.com
18
```
