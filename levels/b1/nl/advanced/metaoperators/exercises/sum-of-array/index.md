## Probleem

Schrijf een programma dat het gemiddelde van een array met getallen afdrukt. Dit gemiddelde heet ook het rekenkundig gemiddelde. Gebruik een reductie-meta-operator om de waarden op te tellen.

De invoergegevens staan direct in het programma, bijvoorbeeld:

```raku
my @data = 10, 20, 30, 40;
```

## Voorbeeld

Het programma drukt de gemiddelde waarde van de elementen in `@data` af:

```
25
```
