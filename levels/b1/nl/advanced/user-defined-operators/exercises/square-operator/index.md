## Opgave

Het symbool van een operator kan elk teken zijn, ook een Unicode-teken. Definieer een **postfix**-operator `²` die zijn operand kwadrateert, zodat `5²` hetzelfde betekent als `5 ** 2`. Druk daarna `5²` af.

## Voorbeeld

Het programma drukt af:

```
25
```
