title: Geordende containers
---

{% include menu.html %}

Geordende containers bewaren meerdere elementen in volgorde. Zo kun je elk element bereiken via zijn positie. In bijzondere gevallen bewaren ze ook maar één element, of helemaal geen. De meest voorkomende geordende containers zijn _arrays_ en _lists_.

De `@` sigil vertelt je dat een variabele voor veel elementen is. Zo'n variabele ondersteunt subscripting, wat betekent dat je een element via zijn index kunt lezen. Je hebt dit al gezien in het deel Essentials.

In dit deel bekijken we van dichterbij hoe arrays en lists verschillen _als containers_. Welke kun je wijzigen? Wat gebeurt er als je de ene container in de andere zet? En hoe geeft _binding_ een naam aan een container zonder iets te kopiëren?
