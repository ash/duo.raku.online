## Opgave

Zet een module `Inner` in een module `Outer`. Declareer in `Inner` een `our`-variabele `$base` met de waarde `10`. Declareer ook een `our sub doubled` die `$base` vermenigvuldigd met twee teruggeeft. Bereik van buiten beide modules de variabele via zijn volledige geneste naam. Roep de subroutine ook aan via zijn volledige geneste naam. Druk beide resultaten af.

## Voorbeeld

Het programma drukt af:

```
10
20
```
