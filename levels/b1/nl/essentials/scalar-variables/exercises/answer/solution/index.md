Hier is een mogelijke oplossing voor de taak.

## Code

```raku
my $answer = 42;
say $answer;
```

🦋 Je kunt de broncode vinden in het bestand [answer.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/scalar-variables/answer.raku).

## Uitvoer

Voer het programma uit en zie wat het afdrukt:

```console
$ raku exercises/scalar-variables/answer.raku 
42
```

## Opmerkingen

Een van de voorwaarden van deze taak was het gebruik van variabelen. `42` is één enkele waarde, dus een scalaire variabele is daar een goede keuze voor.
