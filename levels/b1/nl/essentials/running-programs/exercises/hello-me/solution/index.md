Hier is de oplossing voor het probleem '[Hallo, ik!](../)'.

## Code

```raku

```

🦋 Je kunt de volledige code vinden in het bestand [hello-me.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/running-programs/hello-me.raku).

## Uitvoer

Om de uitvoer te zien, voer het programma uit, zoals hieronder getoond:

```console
$ raku exercises/running-programs/hello-me.raku 
Hallo, Andrew!
```
