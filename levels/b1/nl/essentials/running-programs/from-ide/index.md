Deze korte sectie legt uit hoe je een programma in de IDE uitvoert. Ze behandelt de twee meest aanbevolen [IDE's](../../editors-and-ides).

## Visual Studio Code Editor

Open een terminal met het menu `Terminal` → `New Terminal`. Dit voegt een paneel toe onder de tekst van je programma. Voer het programma daar uit, net als vanaf de opdrachtregel:

```console
$ raku hello.raku
```

## Comma IDE

Je kunt programma's uitvoeren via het menu-item `Run`. Stel de IDE in voordat je een programma de eerste keer uitvoert. Volg [de instructies](https://commaide.com/docs/running) op de website van Comma.
