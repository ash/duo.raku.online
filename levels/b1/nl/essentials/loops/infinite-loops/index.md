Je kunt `loop` ook gebruiken met alleen een body:

```raku
loop {
    say 'Eternity';
}
```

Deze lus draait eindeloos door totdat je het programma stopt, bijvoorbeeld door `Ctrl+C` in te drukken. In het tweede deel van de cursus zien we betere manieren om lussen te besturen.
