## Taak

Schrijf een programma dat een willekeurig aantal argumenten van de commandoregel leest. Het print ze op aparte regels, en elke regel heeft een nummer.

## Voorbeeld

Zo moet het programma zich gedragen:

```console
$ raku count-and-print-arguments.raku woorden om weer te geven
1. woorden
2. om
3. weer te geven
```
