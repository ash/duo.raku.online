## Probleem

Maak een functie die een benaderde waarde van de wiskundige constante _e_ berekent. Gebruik de volgende formule:

<img src="e-formula.png" style="height: 4.5em; width: auto">

Je moet deze functie op een van deze twee manieren kunnen aanroepen:

1. Het argument bepaalt het aantal termen in de formule: `e-approx(10)`.
2. Als er geen argument is, heeft de som 100 elementen: `e-approx()`.

Print de resultaten voor beide gevallen.

## Voorbeeld

```console
$ raku the-value-of-e.raku
2.7182818
2.718281828459045
```
