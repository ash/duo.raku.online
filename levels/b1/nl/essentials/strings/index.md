Laten we het nu over strings hebben. We hebben al strings gebruikt in onze eerdere programma's. Ze worden allemaal ook string literals genoemd. Een string literal is een stuk tekst tussen aanhalingstekens:

```raku
say 'I am a string literal';
```

Natuurlijk kun je strings ook in een scalaire variabele bewaren:

```raku
my $message = 'This is my message';
```
