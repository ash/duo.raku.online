## Taak

Schrijf een programma dat een paar scalaire variabelen maakt. Geef ze beginwaarden van deze typen: `Int`, `Rat`, `Num`, `Bool` en `Str`. Het programma moet elke waarde en het type ervan afdrukken.

## Voorbeeld

De echte uitvoer van je programma kan verschillen. Maar deze testrun laat het idee zien:

```console
$ raku types.raku
151 (Int)
4.2 (Rat)
1e10 (Num)
True (Bool)
xyz (Str)
```
