Codeblokken zijn delen van je programma tussen een paar accolades: `{` en `}`. Een blok zet meerdere instructies bij elkaar, die samenwerken als één grote instructie. In de volgende secties zien we veel manieren om blokken te gebruiken.

```raku
{
    say 'Hallo, Wereld!';
}
```

Het codeblok in dit programma heeft niet echt zin. Maar codeblokken zijn heel nuttig in andere situaties, die we heel binnenkort zullen zien.

Maar laten we eerst kijken naar het idee van _scope_.
