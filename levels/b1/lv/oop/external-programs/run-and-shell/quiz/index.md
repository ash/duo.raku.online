Kura funkcija sūta savu komandu caur sistēmas **čaulu** un atļauj caurules un novirzīšanu?

{:.quiz}
0 | `run`
1 | `shell`
0 | `exec`
0 | `system`

{% include quiz.html %}

<div class="extended-explanation">

`shell` padod vienu virkni čaulai, kas saprot tādas iespējas kā caurules. `run` palaiž programmu tieši, ar atsevišķiem argumentiem un bez čaulas. Tas ir drošāk, tāpēc `run` ir labākais noklusējums.

</div>
