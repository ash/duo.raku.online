## Uzdevums

Izmantojiet `run`, lai palaistu `echo` ar diviem atsevišķiem argumentiem: `home:` un `$HOME`. Ļaujiet tā izvadei iet uz ekrānu. Ievērojiet, ka `$HOME` parādās tāds, kāds tas ir, un mājas direktorija **netiek** izdrukāta. Tā kā `run` nelieto čaulu, mainīgais netiek aizstāts ar tā vērtību.

## Piemērs

Programma izdrukā:

```
home: $HOME
```
