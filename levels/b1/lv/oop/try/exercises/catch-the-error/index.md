## Uzdevums

Parādiet abas `try` puses. Vispirms izmantojiet `try` bloku ap aprēķinu, kas izdodas, piemēram, `6 * 7`. Tad izdrukājiet tā rezultātu. Pēc tam ielieciet kodu, kas dara `die 'broken'`, otrā `try` blokā. Izdrukājiet, vai šis bloks deva definētu rezultātu. Tad izdrukājiet noķertā izņēmuma paziņojumu.

## Piemērs

Programma izdrukā:

```
42
False
broken
```
