## Uzdevums

Uzrakstiet bloku, kas izpilda `die 'timeout'`. Pievienojiet fāzeri `CATCH`, kas izdrukā noķertā izņēmuma paziņojumu. Paziņojuma priekšā ielieciet `Error: `.

## Piemērs

Programma izdrukā:

```
Error: timeout
```
