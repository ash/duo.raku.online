## Uzdevums

Uzrakstiet apakšprogrammu `get`, kas atgriež savu argumentu. Bet, kad arguments ir `0`, tai jāizsauc `fail` ar paziņojumu `bad`.

Izdrukājiet `get(5)` un pēc tam `get(0)` rezultātu. Izmantojiet defined-or operatoru `//`, lai dotu rezerves vērtību `default`.

## Piemērs

Programma izdrukā:

```
5
default
```
