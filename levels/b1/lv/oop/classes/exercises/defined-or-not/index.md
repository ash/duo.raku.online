## Uzdevums

Definējiet divas tukšas klases, `Cat` un `Dog`. Pēc tam ar ciklu ejiet pāri četrām vērtībām: `Cat`, `Dog`, `Cat.new` un `Dog.new`. Katrai no tām izdrukājiet, vai tā ir definēta. Ievērojiet, ka abi tipa objekti ir nedefinēti, bet abas instances ir definētas. Nav svarīgi, kurai klasei tās pieder.

## Piemērs

```

False
True
True
```
