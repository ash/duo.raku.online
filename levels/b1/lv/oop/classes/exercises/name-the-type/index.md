## Uzdevums

Definējiet divas tukšas klases, `Cat` un `Dog`, un izveidojiet `Cat` instanci ar nosaukumu `$felix`. Izdrukājiet `$felix` tipu ar `WHAT`. Pēc tam izmantojiet operatoru `===` un izdrukājiet vēl divas rindas. Pirmā rinda parāda, vai šis tips ir tas pats, kas `Cat`. Otrā parāda, vai tas ir tas pats, kas `Dog`.

## Piemērs

Programma izdrukā:

```
(Cat)
True
False
```
