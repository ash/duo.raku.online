## Uzdevums

Atveriet failu ar nosaukumu `out.txt` rakstīšanai. Atstājiet turi atvērtu. Ciklā ierakstiet tajā skaitļus `1`, `2` un `3`. Katru skaitli ielieciet savā rindā. Pēc tam aizveriet turi, nolasiet failu atpakaļ un izdrukājiet tā saturu.

## Piemērs

Programma izdrukā:

```
1
2
3
```
