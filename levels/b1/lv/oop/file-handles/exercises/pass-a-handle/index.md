## Uzdevums

Faila turis ir parasta vērtība. Tāpēc to var padot funkcijai, tāpat kā jebkuru citu argumentu. Uzrakstiet apakšprogrammu `log-line`, kas ņem turi un paziņojumu. Tai jāieraksta paziņojums turī savā rindā.

Atveriet `log.txt` rakstīšanai. Izsauciet `log-line` trīs reizes, lai ierakstītu `started`, `working` un `done`. Pēc tam aizveriet turi, nolasiet failu atpakaļ un izdrukājiet tā saturu.

## Piemērs

Programma izdrukā:

```
started
working
done
```
