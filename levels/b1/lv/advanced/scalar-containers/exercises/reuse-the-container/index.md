## Uzdevums

Deklarējiet blakus divus skalārus mainīgos: `$untyped`, kam nav tipa, un `$typed`, kam ir tips `Int`. Izmetiet abus ar `dd`, kamēr tie vēl ir tukši. Tad piešķiriet katram `42` un izmetiet abus vēlreiz. Uzmanīgi aplūkojiet, cik dažādi `dd` apraksta abus konteinerus.

## Piemērs

Programma to izdrukā standarta kļūdu plūsmā:

```
$untyped = Any
Int $typed = Int
$untyped = 42
Int $typed = 42
```
