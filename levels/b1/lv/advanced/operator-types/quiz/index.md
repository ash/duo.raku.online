Kādai kategorijai pieder indekss `[0]` izteiksmē `@a[0]`?

{:.quiz}
0 | postfix
1 | postcircumfix
0 | circumfix
0 | infix

{% include quiz.html %}

<div class="extended-explanation">

Indekss ieliek savu saturu iekavās *un* atrodas aiz terma, šeit aiz `@a`. Tas padara to par postcirkumfiksa operatoru. Parastam postfiksam, piemēram, `++`, nav iekavu ap kaut ko. Cirkumfikss, piemēram, masīva konstruktors `[1, 2, 3]`, atrodas ap kaut ko. Bet tas neatrodas aiz terma.

</div>
