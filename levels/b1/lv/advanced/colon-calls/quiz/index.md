Ko izdrukā šī programma?

```raku
say 'programming'.substr: 0, 3;
```

{:.quiz}
1 | pro
0 | program
0 | ing
0 | (0 3)

{% include quiz.html %}

<div class="extended-explanation">

Kols par argumentu sarakstu paņem *visu* atlikušo instrukcijas daļu. Tātad `substr: 0, 3` ir tas pats, kas `substr(0, 3)`, un tiek nodoti abi argumenti. Tas sāk pie indeksa `0` un paņem `3` rakstzīmes, kas dod `pro`.

</div>
