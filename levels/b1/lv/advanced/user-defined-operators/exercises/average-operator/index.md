## Uzdevums

Izveidojiet infiksa operatoru `avg`, kas dod savu divu operandu vidējo vērtību. Pēc tam izmantojiet to, lai izdrukātu `4` un `10` vidējo vērtību.

## Piemērs

Programma izdrukā:

```
7
```
