## Uzdevums

Jums ir šāda ligzdota datu struktūra:

```raku
my @data = 'Raku', [1, 2, 3], (key => 'value');
```

Izdariet ar to divas lietas:

1. Izmantojiet `dd`, lai izdrukātu `@data` izmetumu izstrādātājiem.
2. Izdrukājiet to pašu atveidojumu kā virkni, kas sākas ar tekstu `Structure: `.

## Piemērs

Programma izdrukā divas līdzīgas rindas:

```
["Raku", [1, 2, 3], :key("value")]
Structure: ["Raku", [1, 2, 3], :key("value")]
```
