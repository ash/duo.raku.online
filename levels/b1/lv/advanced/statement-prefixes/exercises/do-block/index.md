## Uzdevums

`do` darbojas arī vadības plūsmas teikumu priekšā. Tas pārvērš tos par izteiksmēm, kas dod vērtību. Izmantojiet `do if 7 > 5 { 'big' } else { 'small' }`, lai izvēlētos apzīmējumu. Tad piešķiriet to mainīgajam `$label` un izdrukājiet.

## Piemērs

Programma izdrukā:

```
big
```
