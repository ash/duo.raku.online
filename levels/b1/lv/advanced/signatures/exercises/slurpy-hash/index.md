## Uzdevums

Uzrakstiet apakšprogrammu `describe`, kas pieņem obligātu pozicionālu nosaukumu. Pēc tā apakšprogramma savāc jebkuru skaitu nosaukto argumentu uzsūcošā hešā (`*%opts`). Tai jāatgriež virkne formā `name: key=value, key=value, ...`. Virkne uzskaita katru opciju, un atslēgas ir alfabēta secībā.

Izsauciet to ka `describe('Anna', colour => 'red', size => 5)` un izvadiet rezultatu.

## Piemers

Programma izvada:

```
Anna: colour=red, size=5
```
