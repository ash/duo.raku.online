## Uzdevums

Paņemiet jaukteni `a => 1, b => 2, c => 3`. Ar indeksa apstākļvārdu izdzēsiet ierakstu `b`. Pēc tam izdrukājiet, cik ierakstu ir palicis, lai parādītu, ka viens no tiem ir noņemts.

## Piemērs

Programma izdrukā:

```
2
```
