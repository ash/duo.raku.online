## Uzdevums

Paņemiet jaukteni `x => 10, y => 20`. Ar indeksa apstākļvārdu izdrukājiet atslēgu `x` kopā ar tās vērtību.

## Piemērs

Programma izdrukā:

```
(x 10)
```
