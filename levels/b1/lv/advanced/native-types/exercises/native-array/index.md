## Problēma

Natīvo tipu ar fiksētu izmēru visdabiskāk izmantot baitu masīvam. Šāds masīvs aizņem maz atmiņas. Deklarējiet `uint8` masīvu ar vērtībām `100`, `200` un `255`. Katra no tām ietilpst vienā baitā. Tad izdrukājiet tā elementu summu.

Ievērojiet, ka katrs elements paliek diapazonā `0..255`, bet summa var būt lielāka. Tas ir tāpēc, ka `.sum` atgriež parastu `Int`.

## Piemērs

Programma izdrukā:

```
555
```
