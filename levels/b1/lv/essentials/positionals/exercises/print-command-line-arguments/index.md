## Uzdevums

Uzrakstiet programmu, kas izdrukā visus savus argumentus no komandrindas. Izdrukājiet katru no tiem atsevišķā rindā.

## Piemērs

Šādi programmai vajadzētu darboties:

```console
$ raku print-command-line-arguments.raku words to display
words
to
display
```
