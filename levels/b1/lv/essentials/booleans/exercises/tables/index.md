## Problēma

Uzrakstiet programmu, kas izdrukā trīs Būla operāciju rezultātus. Tai tas jādara visām `True` un `False` kombinācijām.

## Piemērs

Šeit ir piemērs, kas parāda daļu no izvades.

```console
$ raku tables.raku
True && True ir True
True && False ir False
. . .
```
