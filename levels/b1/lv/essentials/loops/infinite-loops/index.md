{% include menu.html %}

Jūs varat izmantot `loop` arī tikai ar ķermeni:

```raku
loop {
    say 'Eternity';
}
```

Šī cilpa darbojas bezgalīgi, līdz jūs apturat programmu, piemēram, nospiežot `Ctrl+C`. Kursa otrajā daļā mēs redzēsim labākus veidus, kā kontrolēt cilpas.
