## Uzdevums

Uzrakstiet programmu, kas izveido dažus skalāros mainīgos. Dodiet tiem sākuma vērtības ar šādiem tipiem: `Int`, `Rat`, `Num`, `Bool` un `Str`. Programmai vajadzētu izdrukāt katru vērtību un tās tipu.

## Piemērs

Jūsu programmas īstā izvade var atšķirties. Bet šī testa palaišana parāda ideju:

```console
$ raku types.raku
151 (Int)
4.2 (Rat)
1e10 (Num)
True (Bool)
xyz (Str)
```
