title: Koda bloki
---

{% include menu.html %}

Koda bloki ir jūsu programmas daļas cirtainajās iekavās: `{` un `}`. Bloks apvieno vairākus paziņojumus, kas darbojas kopā kā viens liels paziņojums. Nākamajās sadaļās mēs redzēsim daudzus veidus, kā izmantot blokus.

```raku
{
    say 'Hello, World!';
}
```

Koda blokam šajā programmā nav īstas jēgas. Bet koda bloki ir ļoti noderīgi citās situācijās, kuras mēs redzēsim pavisam drīz.

Bet vispirms apskatīsim _apjoma_ ideju.
