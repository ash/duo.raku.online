## Problēma

Izveidojiet funkciju ar diviem argumentiem, kas atgriež `$x` pakāpē `$y`. Pēc tam uzrakstiet programmu, kas izdrukā `5³`, `2¹⁰` un `(−4)⁵` vērtības.

## Piemērs

Šīm vērtībām programmai jāizdrukā:

```
$ raku function-x-to-the-power-of-y.raku
125
1024
-1024
```
