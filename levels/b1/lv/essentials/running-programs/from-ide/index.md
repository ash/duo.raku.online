Šī īsā sadaļa paskaidro, kā palaist programmu pašā IDE. Tā aplūko divus visvairāk ieteiktos [IDE](../../editors-and-ides).

## Visual Studio Code redaktors

Atveriet termināli ar izvēlni `Terminal` → `New Terminal`. Tas pievieno paneli zem jūsu programmas teksta. Palaidiet programmu tur, tieši tāpat kā no komandrindas:

```console
$ raku hello.raku
```

## Comma IDE

Programmas var palaist no izvēlnes vienuma `Run`. Iestatiet IDE pirms pirmās programmas palaišanas. Sekojiet [instrukcijām](https://commaide.com/docs/running) Comma vietnē.
