Эта короткая глава объясняет, как запустить программу внутри IDE. Она рассказывает о двух самых рекомендуемых [средах разработки](../../editors-and-ides).

## Visual Studio Code Editor

Откройте терминал через меню `Terminal` → `New Terminal` (`Терминал` → `Новый терминал`). Он добавит панель под текстом вашей программы. Запустите там программу, так же как из командной строки:

```console
$ raku hello.raku
```

## Comma IDE

Программы можно запускать через пункт меню `Run`. Настройте IDE перед первым запуском программы. Следуйте [инструкциям](https://commaide.com/docs/running) на сайте Comma.
