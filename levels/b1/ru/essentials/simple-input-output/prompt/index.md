---
title: Ввод с использованием `prompt`
---

{% include menu.html %}

Противоположность `say` — это `prompt`. Он ждёт, пока пользователь что-нибудь введёт и нажмёт Enter. Затем он передаёт ввод в программу в виде строки. Вы можете взять результат `prompt` и передать его в `say`. Тогда программа выводит обратно то, что вводит пользователь. Давайте напишем такую программу:

```raku
say prompt;
```

Если вы запустите эту программу, она может вас запутать. Программа просто ждёт какого-то ввода. Поэтому хорошо напечатать для пользователя подсказку. Так программой удобнее пользоваться. Для этого не нужен отдельный `say`. Просто передайте сообщение в `prompt`:

```raku
prompt 'What language are you going to learn? '
```

Прежде чем закончить эту главу, давайте соберём все части вместе. Мы напишем программу, которая спрашивает, чего хочет пользователь. Затем она печатает фразу с текстом, который ввёл пользователь.

```raku
say 'You are going to learn ', prompt 'What language are you going to learn? ';
```

Если вы ввели `Raku`, программа напечатает следующую фразу:

```
You are going to learn Raku
```

Отлично, теперь мы можем говорить с программой. И можем заставить её говорить с нами!

Заметьте, что функции `say` нужно знать строки до того, как она их напечатает. Поэтому Raku сначала выполняет `prompt`. Благодаря этому диалог идёт в правильном порядке:

```console
$ raku t.raku
What language are you going to learn? Raku
You are going to learn Raku
```
