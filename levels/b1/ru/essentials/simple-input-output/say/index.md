---
title: Вывод с использованием `say`
---

{% include menu.html %}

Функция `say` печатает значения в стандартный поток вывода, `STDOUT`. Её также называют подпрограммой, или просто программой. Если вы запускаете программу из терминала, вывод появится там же. В онлайн-сервисах он попадает в особую часть веб-страницы.

Вот пример использования `say`:

```raku
say 42;
```

Эта строка может быть как частью большей программы, так и целой программой. Конечно, она выводит `42`.

Теперь давайте попробуем поработать со строками:

```raku
say 'Hello, World!';
```

Вот и готово: `Hello, World!` на экране.

`say` может принимать несколько аргументов, так что мы можем вывести больше значений за один раз:

```raku
say 42, 'Hello, World!';
```

Только заметьте, что части соединены в одну строку: `42Hello, World!`. Поэтому лучше добавить между ними пробел. Сейчас вы уже должны уметь решить эту проблему. Например, вот так:

```raku
say 42, ' ', 'Hello, World!';
```

После всех аргументов `say` добавляет в вывод символ новой строки.
