Чтобы запустить программу на Raku, вам нужно установить компилятор. В этом курсе используется Rakudo. Два других, [Raku++](/ru/essentials/the-rakupp-compiler) и [mutsu](/ru/essentials/the-mutsu-interpreter), устанавливаются отдельно. Смотрите страницы [Как установить Raku++](/ru/essentials/how-to-install-rakupp) и [Как установить mutsu](/ru/essentials/how-to-install-mutsu). Зайдите на [сайт Rakudo](https://rakudo.org) и скачайте версию для вашей операционной системы.

## Исходники

Установщик для вашей системы можно скачать на странице [rakudo.org/downloads](https://rakudo.org/downloads). Есть версии для всех основных операционных систем: Windows, Mac OS и Linux. Вы также можете взять исходный код и сами его скомпилировать.

## Docker-образы

Rakudo доступен и в виде docker-образа. Его можно использовать для запуска программ. Он также удобен, чтобы проверять небольшие скрипты в оболочке REPL. Все инструкции вы найдёте на [github.com/Raku/docker](https://github.com/Raku/docker).

## Номера версий

Номер версии Rakudo состоит из двух частей: года и месяца выпуска. Поэтому вы легко можете увидеть, насколько свежий у вас компилятор. Выполните эту команду, чтобы увидеть номер его версии:

```console
$ raku -v
Welcome to 𝐑𝐚𝐤𝐮𝐝𝐨™ v2026.06.
Implementing the 𝐑𝐚𝐤𝐮™ programming language v6.d.
Built on MoarVM version 2026.06.
```

Здесь видно три номера версий. Первый — это версия самого Rakudo: `v2026.06`. Затем идёт версия языка Raku: `v6.d`. Пока обновления получают следующую букву как младшую часть версии. Например, следующей будет `v6.e`, и так далее. Наконец, вы видите название виртуальной машины в этом компиляторе: MoarVM версии `2026.06`.
