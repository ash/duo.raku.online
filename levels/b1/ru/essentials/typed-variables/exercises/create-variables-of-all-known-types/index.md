## Задача

Напишите программу, которая создаёт несколько скалярных переменных. Дайте им начальные значения таких типов: `Int`, `Rat`, `Num`, `Bool` и `Str`. Программа должна выводить каждое значение и его тип.

## Пример

Настоящий вывод вашей программы может отличаться. Но этот тестовый запуск показывает идею:

```console
$ raku types.raku
151 (Int)
4.2 (Rat)
1e10 (Num)
True (Bool)
xyz (Str)
```
