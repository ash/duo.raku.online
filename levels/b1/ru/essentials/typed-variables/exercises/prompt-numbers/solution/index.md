## Код

Вот полная программа. Она решает задачу и выводит как введённое значение, так и его тип.

```raku
my $n = prompt 'Введите число: ';
say $n;
say $n.WHAT;
```

🦋 Исходный код можно найти в файле [prompt-numbers.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/typed-variables/prompt-numbers.raku).

## Тестовые запуски

Запустите программу несколько раз и введите числа разных типов.

### Целые числа

Сначала попробуем целые числа, как положительные, так и отрицательные.

```console
$ raku exercises/what/prompt-numbers.raku
Введите число: 10
10
(IntStr)
```

Результат имеет тип `IntStr`. У этого встроенного типа есть свойства как `Int`, так и `Str`.

### Рациональные числа

Теперь попробуем рациональное число. Помните, что в Raku запись числа с десятичной точкой даёт число типа `Rat`. Это не число с плавающей запятой.

```console
$ raku exercises/what/prompt-numbers.raku
Введите число: 3.14
3.14
(RatStr)
```

На этот раз программа сообщает, что данные в `$n` имеют тип `RatStr`. Это комбинированный тип из `Rat` и `Str`.

### Числа с плавающей запятой

Наконец, попробуйте число в научной нотации. Теперь вы, наверное, уже можете угадать вывод.

```console
$ raku exercises/what/prompt-numbers.raku
Введите число: 5e-14
5e-14
(NumStr)
```

Как и ожидалось, новое значение имеет тип `NumStr`.
