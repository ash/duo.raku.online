---
title: Ограничения типов
---

{% include menu.html %}

В Raku есть так называемая постепенная типизация. В большинстве случаев вам не нужно думать о типе переменной. Но иногда вы можете захотеть ограничить переменную одним типом. Это можно сделать, если указать тип, как показано ниже:

```raku
my Int $var = 42;
```

Теперь вы можете присвоить `$var` другое целое значение. Но если попробовать положить в неё строку, вы получите исключение. То же самое будет даже с числом с плавающей запятой:

```raku
my Int $var = 42;
$var = '314E-2';
```

Эта программа выдаёт следующую ошибку:

    Ошибка проверки типа при присвоении $var; ожидался Int, но получен Str ("314E-2")
      в блоке <unit> на строке 2 в t.raku
