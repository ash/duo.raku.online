---
title: Приведение типов для типизированных переменных
---

{% include menu.html %}

Ограничения типов довольно строгие. Например, нельзя присвоить значение типа `Num` переменной, объявленной как `Int`. Это так, даже если значение — целое число:

```raku
my Int $x = 42;
# $x = 42e1; # Ошибка
```

Используйте [один из методов](/ru/essentials/coercion/#topics-in-this-section), чтобы привести значение к нужному типу.

```raku
my Int $x = 42;
$x = 42e1.Int;
$x = Int(42e1);
```
