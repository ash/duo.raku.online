## Проблема

Напишите программу, которая просит пользователя ввести три целых числа. Она должна сказать, сколько из этих чисел равны. Программа должна работать и с положительными, и с отрицательными числами.

## Пример

Вот один возможный запуск программы:

```console
$ raku how-many-equal-numbers.raku
Number 1: 3
Number 2: -4
Number 3: 3
2
```

Если все три числа разные, программа должна вывести `0`.
