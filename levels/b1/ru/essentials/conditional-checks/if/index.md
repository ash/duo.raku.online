---
title: '`if` блоки'
---

{% include menu.html %}

Условная проверка `if` смотрит на условие. Когда условие равно `True`, выполняется блок кода.

```raku
if 10 > 4 {
    say 'Mathematics works!';
}
```

Обратите внимание, что условие не нужно брать в скобки. Но вы можете это сделать, если хотите.

Конечно, в проверках можно смело использовать переменные:

```raku
my $flag = False;
if $flag {
    # . . . do something
}
```

Если несколько проверок используют одну и ту же переменную, сравнения можно записать цепочкой:

```raku
my $x = 42;
if 40 < $x < 45 {
    say "Correct answer $x is given.";
}
```

Если условие не выполняется, его блок кода не запускается. Затем программа продолжает работу как обычно.

```raku
say 'Begin';
if False {
    say 'This is never printed.';
}
say 'End';
```

Эта программа выводит только `Begin` и `End`.
