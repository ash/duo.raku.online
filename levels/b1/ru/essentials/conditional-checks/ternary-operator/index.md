---
title: Тернарный оператор
---

{% include menu.html %}

В Raku у тернарного оператора две части: `??` ... `!!`. Сначала идёт булева проверка, а за ней следуют два выражения. Выполняется только одно из них, в зависимости от результата проверки.

```raku
my $shines = 'Sun';
my $day-time = $shines eq 'Sun' ?? 'day' !! 'night';
say $day-time;
```

С тем значением, которое сейчас есть у `$shines`, программа выводит `day`. Если поменять его на `Moon`, программа выведет `night`.

Тернарные выражения можно объединять в цепочки. Только следите, чтобы код не стал слишком сложным.

```raku
my $hours = 20;
my $day-time =
    $hours <= 6 ?? 'Night' !!
    $hours <= 12 ?? 'Morning' !! 
    $hours <= 18 ?? 'Afternoon' !! 'Evening';
say $day-time;
```

Здесь программа выводит разную часть дня для разных значений `$hours`.
