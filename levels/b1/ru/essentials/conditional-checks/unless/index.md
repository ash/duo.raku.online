---
title: Использование `unless`
---

{% include menu.html %}

С помощью [оператора `!`](/ru/essentials/booleans/operations#negation) можно легко превратить любое булево условие в противоположное. Но иногда лишний `!` делает выражение тяжёлым и трудным для чтения. В таких случаях `unless` может стать вашим другом.

Raku выполняет блок `unless`, когда его условие равно `False`.

```raku
my $broken = False;

# ...Здесь что-то может записать True в $broken...
    
unless $broken {
    say "Don’t worry!";
    say "Be happy!";
}
```

Сравните два варианта одной и той же программы:

С `if` и инверсией:

```raku
if !$broken { . . . }
```

С `unless`:

```raku
unless $broken { . . . }
```

У вас есть оба варианта, поэтому вы всегда можете выбрать то, что кажется лучше в каждой ситуации.

Обратите внимание, что после `unless` нельзя поставить блок `else` или `elsif`. Если такой блок нужен, остаётся только использовать `if`.
