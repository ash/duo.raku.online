Оператор `loop` в Raku имеет много общего с традиционными циклами языка программирования C и его родственников. Он принимает три выражения: инициализатор, проверку и выражение, которое изменяет переменную цикла. Тело цикла выполняется снова и снова, пока проверка остаётся `True`.

```raku
loop (my $c = 0; $c < 5; $c++) {
    say "Текущее значение счетчика: $c.";
}
```

Здесь `++` — это постфиксный оператор, который увеличивает свой аргумент на 1. Во второй части курса мы рассмотрим больше операторов.

Программа выполняет тело цикла пять раз.

```console
$ raku t.raku
Текущее значение счетчика: 0.
Текущее значение счетчика: 1.
Текущее значение счетчика: 2.
Текущее значение счетчика: 3.
Текущее значение счетчика: 4.
```

Некоторые или даже все выражения в заголовке `loop` можно опустить. Например, вот та же программа:

```raku
my $c = 0;
loop (; $c < 5;) {
    say "Текущее значение счетчика: $c.";
    $c++;
}
```

## * * *

Циклы `loop` — это, вероятно, самые редко используемые циклы в Raku. Их можно встретить, например, в коде, который инструмент автоматически перевёл с C на Raku. Но в Raku есть более удобные циклы, такие как `for`, который мы рассмотрим очень скоро.
