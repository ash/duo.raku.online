Оператор `loop` в Raku очень похож на традиционные циклы в C и похожих на него языках. Он принимает три выражения. Первое задаёт начальное значение, а второе — это проверка. Третье изменяет переменную цикла. Тело цикла выполняется снова и снова, пока проверка равна `True`.

```raku
loop (my $c = 0; $c < 5; $c++) {
    say "Текущее значение счетчика: $c.";
}
```

Здесь `++` — это постфиксный оператор, то есть он стоит после своего аргумента. Он прибавляет 1 к аргументу. Во второй части курса есть и другие операторы.

Программа выполняет тело цикла пять раз.

```console
$ raku t.raku
Текущее значение счетчика: 0.
Текущее значение счетчика: 1.
Текущее значение счетчика: 2.
Текущее значение счетчика: 3.
Текущее значение счетчика: 4.
```

Некоторые выражения в заголовке `loop`, или даже все они, необязательны. Например, вот та же программа:

```raku
my $c = 0;
loop (; $c < 5;) {
    say "Текущее значение счетчика: $c.";
    $c++;
}
```

## * * *

Программисты на Raku, наверное, используют `loop` реже любого другого цикла. Его можно встретить, например, в коде, который инструмент перевёл с C на Raku. Но в Raku есть более удобные циклы, такие как `for`. Мы рассмотрим его очень скоро.
