Факториал числа `N` — это произведение всех целых чисел от 1 до `N`. Например, факториал числа 4 равен 1 * 2 * 3 * 4 = 24.

## Код

```raku
my $n = 8;

my $f = 1;
$f *= $_ for 2..$n;

say $f;
```

🦋 Найдите программу в файле [factorial.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/loops/factorial.raku).

## Вывод

Запустите программу несколько раз с разными значениями переменной `$n`.

```console
$ raku exercises/loops/factorial.raku
40320
```

## Комментарии

Эта программа использует оператор `*=`, который умножает и присваивает за один шаг: `$x *= $y` значит то же самое, что `$x = $x * $y`.

Вместо постфиксной формы можно также использовать «полный» цикл:

```raku
my $n = 8;

my $f = 1;
for 2..$n -> $x {
    $f *= $x;
}

say $f;
```
