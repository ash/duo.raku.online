## Задача

Создайте программу, которая выполняет целочисленное деление с помощью вычитания. Числа записаны прямо в программе:

```raku
my $a = 175;
my $b = 25;
```

Дополните программу так, чтобы она выводила целую часть от `$a / $b`. Используйте только цикл и вычитание.

## Пример

```console
$ raku division-via-subtraction.raku
7
```
