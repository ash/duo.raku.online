`$_` — это специальная переменная, называемая _переменной topic_.

Посмотрите на этот цикл по диапазону:

```raku
for 1..5 -> $n {
    say $n;
}
```

Переменную `$n` можно опустить, и тогда Raku использует вместо неё автоматическую переменную `$_`. Программа — то же самое, что и вот эта:

```raku
for 1..5 {
    say $_;
}
```

Как вы [помните](/ru/essentials/hello-world/), `say` можно также использовать как метод:

```raku
for 1..5 {
    $_.say;
}
```

Когда вы вызываете метод на `$_`, саму переменную писать не обязательно. Поэтому наш цикл можно сделать ещё проще:

```raku
for 1..5 {
    .say;
}
```
