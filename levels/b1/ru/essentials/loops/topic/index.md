`$_` — это специальная переменная. Она называется _переменной topic_.

Вот цикл по диапазону:

```raku
for 1..5 -> $n {
    say $n;
}
```

Переменную `$n` можно не писать. Тогда Raku автоматически использует вместо неё переменную `$_`. Поэтому программа — то же самое, что и эта:

```raku
for 1..5 {
    say $_;
}
```

Как вы [помните](/ru/essentials/hello-world/), `say` можно также вызвать как метод:

```raku
for 1..5 {
    $_.say;
}
```

Чтобы вызвать метод на `$_`, саму переменную писать не нужно. Поэтому наш цикл можно сделать ещё проще:

```raku
for 1..5 {
    .say;
}
```
