Цикл `for` — это мощный инструмент. Он проходит по многим элементам, один за другим. Например, давайте возьмём диапазон:

```raku
for 1..5 -> $n {
    say $n;
}
```

Каждый раз, когда выполняется цикл, переменная `$n` получает следующее значение из диапазона. Обратите внимание, что вам не нужно объявлять переменную с помощью `my`. Блок кода выполняется один раз для каждого элемента источника данных. Поэтому программа выводит числа по одному на строке:

```console
$ raku t.raku 
1
2
3
4
5
```

Программа проходит по всем значениям, которые даёт [диапазон](/ru/essentials/ranges) `1..5`. Это `1`, `2`, `3`, `4` и `5`.

## Взятие более одного значения

Вот интересная особенность Raku. Цикл может брать больше одного элемента за раз. Следующая программа выводит два числа при каждом проходе цикла:

```raku
for 1..6 -> $n, $m {
    say "$n and $m";
}
```

Вывод программы такой:

```console
$ raku t.raku
1 and 2
3 and 4
5 and 6
```
