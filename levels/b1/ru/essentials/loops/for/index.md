Цикл `for` — это мощный инструмент, который позволяет пройти по нескольким элементам один за другим. Например, возьмём диапазон:

```raku
for 1..5 -> $n {
    say $n;
}
```

В этой программе переменная `$n` на каждой итерации принимает следующее значение из диапазона. Обратите внимание, что вам не нужно объявлять переменную с помощью `my`. Блок кода повторяется столько раз, сколько элементов в источнике данных. Таким образом, программа выводит числа построчно:

```console
$ raku t.raku 
1
2
3
4
5
```

Программа проходит по всем значениям, которые даёт [диапазон](/ru/essentials/ranges) `1..5`. Это `1`, `2`, `3`, `4` и `5`.

## Взятие более одного значения

Интересная особенность Raku в том, что можно брать больше одного элемента за одну итерацию. Следующая программа выводит два числа при каждом проходе цикла:

```raku
for 1..6 -> $n, $m {
    say "$n and $m";
}
```

Вывод программы такой:

```console
$ raku t.raku
1 and 2
3 and 4
5 and 6
```
