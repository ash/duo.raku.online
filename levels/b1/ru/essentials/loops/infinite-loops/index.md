Вы можете также использовать `loop` только с телом:

```raku
loop {
    say 'Вечность';
}
```

Этот цикл работает бесконечно, пока вы не остановите программу, например, нажав `Ctrl+C`. Во второй части курса мы увидим лучшие способы управления циклами.
