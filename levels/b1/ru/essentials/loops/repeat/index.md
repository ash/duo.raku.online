---
title: Использование `repeat`
---

{% include menu.html %}

Блоки `while` и `until` могут ни разу не выполниться, если условие с самого начала равно `False`. Блок `repeat`, наоборот, всегда выполняется хотя бы один раз. Условие проверяется после блока кода. Для проверки вы используете те же слова `while` или `until`.

Посмотрите на эту программу.

```raku
my $x = 100;
repeat {
    $x = prompt 'Введите число: ';
    say "Вы ввели $x.";
} while $x <= 10;
say "$x больше 10.";
```

В начале переменная `$x` равна `100`, а условие `while` проверяет, меньше или равно ли `$x` числу `10`. При таком значении условие уже равно `False`, но блок кода всё равно сначала выполняется один раз.

```console
$ raku t.raku
Введите число: 10
Вы ввели 10.
Введите число: 20
Вы ввели 20.
20 больше 10.
```

Давайте изменим программу, чтобы вместо этого использовать `until`.

```raku
my $x = 0;
repeat {
    $x = prompt 'Введите число: ';
    say "Вы ввели $x.";
} until $x > 10;
say "$x больше 10.";
```

Запустите её, чтобы проверить, что она работает как ожидалось:

```console
$ raku t.raku
Введите число: 5
Вы ввели 5.
Введите число: 15
Вы ввели 15.
15 больше 10.
```
