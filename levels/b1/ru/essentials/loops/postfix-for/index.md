---
title: Постфиксная форма `for`
---

{% include menu.html %}

Вы уже видели другие модификаторы операторов: [`if` и `else`](/ru/essentials/conditional-checks/modifiers) и [`while` и `until`](/ru/essentials/loops/modifiers). Это небольшой повод для радости: дизайн Raku очень последовательный.

Если тело цикла короткое, можно использовать постфиксную форму `for`:

```raku
.say for 1..7;
```

Как видите, диапазоны очень хорошо подходят к постфиксному `for`.

Эта программа делает то же, что и более привычный вариант:

```raku
for 1..7 -> $n {
    say $n;
}
```

Или, если использовать переменную цикла по умолчанию, то же, что и это:

```raku
for 1..7 {
    .say;
}
```

Здесь `.say` — это сокращение от `$_.say`.
