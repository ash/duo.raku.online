---
title: Постфиксная форма `for`
---

{% include menu.html %}

Мы уже видели другие модификаторы операторов: [`if` и `else`](/ru/essentials/conditional-checks/modifiers) и [`while` и `until`](/ru/essentials/loops/modifiers). Это повод немного порадоваться, потому что дизайн Raku очень последователен.

Когда тело цикла короткое, цикл `for` можно записать в постфиксной форме:

```raku
.say for 1..7;
```

Как видите, диапазоны выглядят очень естественно с постфиксной формой `for`.

Эта программа — то же самое, что и более традиционный вариант:

```raku
for 1..7 -> $n {
    say $n;
}
```

Или, если использовать переменную цикла по умолчанию, это то же самое, что:

```raku
for 1..7 {
    .say;
}
```

Здесь `.say` — это короткая форма для `$_.say`.
