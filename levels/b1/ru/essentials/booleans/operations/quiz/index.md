В каждом примере ниже выберите ответ, который показывает, что выводит программа.

## 1

Вот программа:

```raku
my $value = True && False;
say $value;
```

Что она выведет?

{:.quiz}
0 | True
1 | False

## 2 

Что выведет вторая программа?

```raku
my $value = True && False || True;
say $value;
```

{:.quiz}
1 | True
0 | False

## 3

Какой вывод у этой программы?

```raku
my $value = True || False && True;
say $value;
```

{:.quiz}
1 | True
0 | False

{% include quiz.html %}

## Комментарии

Во второй и третьей программах есть выражения с тремя булевыми значениями. Результат зависит от того, в каком порядке Raku выполняет операции. У оператора `&&` приоритет выше, чем у `||`, поэтому Raku выполняет его первым.
