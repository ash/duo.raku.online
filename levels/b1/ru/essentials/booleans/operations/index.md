Вы можете выполнять все стандартные операции с булевыми значениями. Это логическое И, ИЛИ и исключающее ИЛИ (его также называют XOR):

```raku
say False && True; # И
say False || True; # ИЛИ
say False ^^ True; # исключающее ИЛИ
```

Программа выводит такие результаты:

```
False
True
True
```

## Инверсия

Инверсия превращает булево значение в противоположное. Чтобы инвертировать значение, используйте префиксный оператор `!`:

```raku
say !False; # True
```

Вы можете хранить булевы значения в скалярных переменных:

```raku
my $did = True;
my $didn't = !$did;
```
