## Код

```raku
my $students = 23;

my $desks = $students div 2 + $students % 2;

say "$desks desks must be bought.";
```

🦋 Вы можете найти исходный код в файле [class-desks.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/numbers/class-desks.raku).

## Вывод

Запустите программу хотя бы два раза. Попробуйте и нечётное, и чётное количество учеников. Например, для входных чисел `23` и `24` программа выводит один и тот же результат:

```console
$ raku exercises/numbers/class-desks.raku
12 desks must be bought.
```

## Комментарии

Просто разделить число учеников на два недостаточно. Программа должна правильно работать и с нечётными, и с чётными числами. Вот один из возможных способов округлить число вверх: `$students div 2 + $students % 2`. Когда число учеников чётное, вторая часть равна нулю. Тогда результат равен половине числа учеников. Когда число нечётное, первая часть всё равно остаётся целым числом. Это потому, что мы используем `div` вместо `/`. А вторая часть выражения добавляет одну дополнительную парту.
