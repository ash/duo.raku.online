## Проблема

Напишите программу, которая просит пользователя ввести целое положительное число. Затем она выводит цифру, которая показывает, сколько в этом числе _десятков_.

## Пример

Например, если введено число 234, количество десятков равно 3. Поэтому программа выводит 3:

```console
$ raku tens.raku
Enter a positive integer number: 234
3
```
