Вот как вы можете выполнить эту задачу.

## Код

```raku
my $n = prompt 'Enter a positive integer number: ';

say ($n % 100) div 10;
```

🦋 Вы можете найти исходный код в файле [tens.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/numbers/tens.raku).

## Вывод

Запустите программу, чтобы проверить несколько разных случаев:

* Круглое трёхзначное число, такое как 120;
* Число, кратное 100, например, 400;
* Число больше 10, но меньше 100;
* Число меньше 10.

Для числа 234 вывод программы выглядит так:

```console
$ raku exercises/numbers/tens.raku
Enter a positive integer number: 234
3
```

## Комментарии

В этом решении снова сочетаются остаток от деления `%` и целочисленное деление `div`.

Обратите внимание на пробел перед открывающей скобкой. Он должен там быть, иначе вы получите синтаксическую ошибку. Мы вернёмся к [этой особенности](/ru/essentials/more-on-functions/mind-the-space) Raku в главе про функции. Пока набирайте код так, как показано выше. Или можно поставить ещё одну пару скобок вокруг аргумента функции. В этом случае пробел не нужен:

```raku
    say(($n % 100) div 10);
```
