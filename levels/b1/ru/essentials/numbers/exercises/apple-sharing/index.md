## Проблема

_N_ человек делят между собой _K_ яблок поровну. Напишите программу, которая отвечает на следующие вопросы:

* Сколько яблок получит каждый человек?
* Сколько яблок останется в корзине?

Запишите входные числа _N_ и _K_ прямо в коде. Присвойте их переменным, например:

```raku
my $N = 3;
my $K = 11;

# Ваш код …
```

Каждое яблоко целое, поэтому его нельзя разрезать на части.

## Пример

С числами, которые даны выше, программа должна вывести следующее:

```console
$ raku apple-sharing.raku
Each person gets 3 apple(s).
There are 2 apple(s) remaining.
```

Пока не беспокойтесь о том, чтобы ставить существительные в правильную форму. Также не беспокойтесь, если вывод выглядит немного странно, когда яблок не остаётся.
