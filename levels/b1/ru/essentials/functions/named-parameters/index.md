В отличие от [позиционных параметров](../positional-parameters), _именованные_ параметры указываются по их именам.

У этой функции два параметра с именами `$from` и `$to`.

```raku
sub distance(:$from, :$to) { $from - $to }
```

Чтобы вызвать эту функцию, нужно написать имена аргументов:

```raku
say distance(from => 30, to => 10); # 20
```

Если передать аргументы так, будто они позиционные, будет ошибка. Например, вызов `distance(30, 10)` приводит к ошибке:

    Слишком много позиционных аргументов; ожидалось 0 аргументов, но получено 2
        в подпрограмме distance на строке 1 в t.raku
        в блоке <unit> на строке 2 в t.raku

Хорошо то, что именованные аргументы можно перечислять в любом порядке. Следующие два вызова совершенно одинаковы:

```raku
say distance(from => 30, to => 10); # 20

say distance(to => 10, from => 30); # 20
```

## Передача переменных

Иногда значение, которое вы хотите передать, хранится в переменной. Имя этой переменной может совпадать с именем параметра. Тогда вам поможет особый синтаксис, с которым нужно писать меньше:

```raku
my $from = 30;
my $to = 10;
say distance(:$from, :$to); # 20
```

Это похоже на более длинный вызов:

```raku
say distance(from => $from, to => $to); # 20
```

И снова порядок здесь не важен:

```raku
say distance(:$to, :$from); # 20
```

Если имена переменной и параметра разные, передайте пару. Используйте один из этих способов:

```raku
my $a = 20;
my $b = 10;

say distance(from => $a, to => $b);

# или:

say distance(:from($a), :to($b));
```
