Сейчас вы в последнем разделе первой части курса. После него вы будете знать достаточно, чтобы написать почти _любую_ программу на Raku. Тема этого раздела — _функции_. Их также называют _подпрограммами_ или просто _рутинами_.

Функция — это часть кода с именем, которую можно использовать много раз. Вы можете _вызывать_ функцию из разных мест программы.

## Создание функции

Чтобы создать функцию, напишите ключевое слово `sub`, а потом имя функции. Тело функции находится внутри пары фигурных скобок.

```raku
sub greet {
    say 'Hello, World!';
}
```

## Использование функции

Чтобы использовать функцию, просто напишите её имя там, где вы хотите её вызвать. В Raku определение функции может стоять до вызова или после него.

```raku
say 'This is what the first program usually prints:';
greet;    

sub greet {
    say 'Hello, World!';
}
```

Программа выводит оба сообщения:

```console
$ raku t.raku
This is what the first program usually prints:
Hello, World!
```
