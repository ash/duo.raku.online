Теперь пора передать данные в функцию. Функция может принимать параметры, которые вы перечисляете в скобках сразу после её имени.

```raku
sub greet($name) {
    say "Hello, $name!";
}
```

Теперь вы можете использовать функцию и передавать ей разные аргументы:

```raku
greet('Алла');
greet('Карл');
```

Теперь два вызова одной и той же функции дают разные результаты:

```console
$ raku t.raku
Hello, Алла!
Hello, Карл!
```

%%tipblock

## Параметр или аргумент

Эти два термина часто используют так, будто они значат одно и то же. Оба относятся к «одному и тому же», но с разных точек зрения.

* Параметр — это то, что ожидает функция.
* Аргумент — это то, что вы передаете функции.

В примере выше `$name` — это параметр функции. Её аргументы — `'Алла'` и `'Карл'`.

%%/tipblock

## Больше параметров

Функция может принимать больше одного параметра. В этом случае перечислите их все через запятую:

```raku
sub add($x, $y) {
    say $x + $y;
}

add(10, 20); # 30
```

## Без параметров

Функция может вообще не принимать параметров, и это нормально. Тогда вы можете либо добавить пустые скобки, либо совсем их не писать. Мы их не писали в [начале этого раздела](../).

```raku
sub greet() {
    say 'Hello, World!';
}

greet();
```

## Сигнатура

Список параметров функции называется _сигнатурой_.
