## Задача

Напишите программу, которая выводит значения функции `f(x) = x²`. Возьмите `x` на интервале [−3, 3] с шагом 0.1.

## Пример

Программа должна выводить две колонки. В первой колонке — `x`, а во второй колонке — `f(x)`.

```
$ raku function-table.raku
-3	9
-2.9	8.41
-2.8	7.84
. . .
```
