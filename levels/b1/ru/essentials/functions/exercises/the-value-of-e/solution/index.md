## Отказ от ответственности

В Raku есть встроенная константа `e`. Она сразу даёт ответ на эту задачу. Решение ниже нужно просто для обучения.

## Код

Формула в этой задаче содержит факториал. У нас уже есть как минимум два способа его вычислить, и позже будут ещё. Программа ниже определяет две функции. Одна вычисляет факториал, а другая — частичную сумму формулы.

Функция должна работать и без аргументов. В этом случае цикл выполняется заданное число раз. Поэтому мы можем дать параметру [значение по умолчанию](/ru/essentials/functions/default-values): `sub e-approx($max = 100)`.

Обратите внимание, что в коде обе функции собирают свои результаты похожим образом. Они используют [постфиксный цикл `for`](/ru/essentials/loops/postfix-for) по [диапазону](/ru/essentials/ranges).

Вот решение:

```raku
sub factorial($n) {
    my $f = 1;
    $f *= $_ for 1..$n;

    return $f;
}

sub e-approx($max = 100) {
    my $e = 1;
    $e += 1 / factorial($_) for 1..$max;

    return $e;
}

say e-approx(10);
say e-approx();
```

🦋 Найдите программу в файле [the-value-of-e.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/functions/the-value-of-e.raku).

## Вывод

```console
2.7182818
2.718281828459045
```
