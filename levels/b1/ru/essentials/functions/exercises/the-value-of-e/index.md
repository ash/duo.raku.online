## Проблема

Создайте функцию, которая вычисляет примерное значение математической константы _e_. Используйте следующую формулу:

<img src="e-formula.png" style="height: 4.5em; width: auto">

Эта функция должна работать при вызове в любой из этих форм:

1. Аргумент задаёт количество элементов в формуле: `e-approx(10)`.
2. Если аргумента нет, в сумме 100 элементов: `e-approx()`.

Выведите результаты для обоих случаев.

## Пример

```console
$ raku the-value-of-e.raku
2.7182818
2.718281828459045
```
