## Задача

Создайте функцию с двумя аргументами, которая возвращает `$x` в степени `$y`. Потом напишите программу, которая выводит значения `5³`, `2¹⁰` и `(−4)⁵`.

## Пример

Для этих значений программа должна вывести:

```
$ raku function-x-to-the-power-of-y.raku
125
1024
-1024
```
