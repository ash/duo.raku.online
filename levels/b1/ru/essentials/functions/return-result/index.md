title: Возврат результата
---

Функции часто что-то делают и ещё возвращают результат. Например, в функциональном программировании у функций не должно быть побочных эффектов. Вывод на консоль — как раз такой побочный эффект. Но Raku не запрещает вам так делать. Давайте посмотрим, как функция возвращает значение. Мы также увидим, как вызывающий код его получает.

```raku
sub add($x, $y) {
    return $x + $y;
}

my $sum = add(10, 20);
say $sum; # 30
```

Здесь функция `add` принимает два числа и возвращает их сумму. Она использует явный `return`. Вызывающий код может использовать возвращённое значение как любое другое. В программе выше оно присваивается переменной.

## Последнее вычисленное значение

В Raku явный `return` нужен не всегда. Его можно не писать, когда результат — это последнее значение, которое вычисляет функция. Поэтому нашу функцию `add` можно упростить:

```raku
sub add($x, $y) {
    $x + $y
}
```

Вы, наверное, заметили, что в конце строки нет точки с запятой. Она не нужна, потому что эта строка заканчивает блок кода.

Такие маленькие и простые функции часто записывают в одну строку. Так код становится компактнее:

```raku
sub add($x, $y) { $x + $y }
```

## Отсутствие возвращаемых данных

Иногда нужно выйти из функции до конца её тела. Если функция не возвращает никакого результата, используйте просто `return`.

```raku
sub test($x) {
    return if $x <= 10;
    say "$x is above the limit";
}
```
