И позиционные, и именованные параметры могут иметь значения по умолчанию. Если у параметра есть значение по умолчанию, его можно пропустить при вызове функции.

## Позиционные параметры

Вот пример значения по умолчанию для позиционного параметра:

```raku
sub greet($name = 'World') {
    say "Hello, $name!";
}

greet('Merinda');
greet();
```

В первом вызове имя — единственный аргумент, поэтому результат — `Hello, Merinda!`. Второй вызов использует значение по умолчанию и выводит `Hello, World!`.

Если у функции несколько параметров, значения по умолчанию могут быть только у последних:

```raku
sub f($a, $b, $c = 42, $d = 50) { . . . } # правильно
# sub f($a = 10, $b = 20, $c, $d) { . . . } # НЕПРАВИЛЬНО
```

## Именованные параметры

Значения по умолчанию для именованных параметров вы задаёте тем же синтаксисом:

```raku
sub greet(:$name = 'World') {
    say "Hello, $name!";
}

greet(name => 'Merinda'); # Hello, Merinda!
greet(); # Hello, World!
```

Порядок именованных параметров не важен. Поэтому значение по умолчанию может быть у любого из них, даже у первого:

```raku
sub greet(:$greeting = 'Hello', :$name) {
    say "$greeting, $name!";
}

greet(name => 'Alla'); # Hello, Alla!
```
