---
title: Использование `unit sub`
---

{% include menu.html %}

Конструкция `unit sub` очень удобна. Она делает остальную часть файла телом функции! С `MAIN` она позволяет убрать фигурные скобки вокруг почти всего файла. Лишние отступы вам тоже не нужны.

Следующий пример программы показывает, как использовать `unit sub`.

```raku
unit sub MAIN($a, $b);

my $sum = $a + $b;
say "Сумма $a и $b равна $sum.";
```

В этом файле `MAIN` — единственная функция. Если в вашей программе так же, подумайте о том, чтобы использовать `unit sub MAIN`, как показано выше.
