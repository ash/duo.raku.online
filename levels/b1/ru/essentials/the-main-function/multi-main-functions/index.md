---
title: Несколько функций `MAIN`
---

{% include menu.html %}

Как и любая другая функция в Raku, функция `MAIN` может иметь варианты `multi`. С ними программа может реагировать на каждый случай по-своему. Случаи могут отличаться количеством входных параметров или их типами.

```raku
multi sub MAIN($a) {
    say 2 * $a;
}

multi sub MAIN($a, $b) {
    say $a + $b;
}
```

Если аргумент только один, эта программа удваивает его. Если есть второй аргумент, программа складывает оба аргумента:

```console
$ raku t.raku 21
42

$ raku t.raku 21 33
54
```
