---
title: Чтение аргументов командной строки
---

{% include menu.html %}

Функция `MAIN` ясно отмечает начало программы, и это полезно. Но она полезна и потому, что её аргументы получают значения из командной строки.

Аргументы командной строки можно читать двумя способами. Первый — это массив [`@*ARGS`](/ru/essentials/positionals/args-array), который мы уже использовали. Теперь давайте посмотрим на второй способ.

Вот программа, которая складывает два числа.

```raku
sub MAIN($a, $b) {
    say $a + $b;
}
```

Вот как можно запустить программу. Она выводит сумму двух своих аргументов:

```console
$ raku t.raku 123 45
168
```

Как и любая другая функция, `MAIN` может иметь значения по умолчанию для своих аргументов. Это возможно для некоторых из них или даже для всех. Например:

```raku
sub MAIN($a, $b = 100) {
    say $a + $b;
}
```

Если вы не передаёте второй аргумент, программа использует значение по умолчанию:

```console
$ raku t.raku 15
115
```
