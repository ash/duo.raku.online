## Задача

Напишите программу, которая считает и выводит периметр прямоугольника. Передайте длины двух сторон как аргументы командной строки. Если фигура — квадрат, передайте только одно значение. Используйте функцию `MAIN`.

## Пример

Программа должна ясно говорить, работает ли она с квадратом или с прямоугольником. Вот возможный вывод для обоих случаев:

```console
$ raku perimeter.raku 15
Периметр квадрата равен 60.

$ raku perimeter.raku 15 20
Периметр прямоугольника равен 70.
```
