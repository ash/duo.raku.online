В Raku интервалы создают списки элементов, которые идут один за другим.

В самом простом случае интервал — это список целых чисел, которые растут на единицу. Чтобы создать интервал, используйте оператор `..` и два значения. Они задают минимальное и максимальное значения интервала:

```raku
1 .. 5
```

Пробелы вокруг оператора ставить не обязательно. Поэтому тот же интервал можно записать так:

```raku
1..5
```

Интервал — это способ создавать списки, но он всё равно остаётся одним объектом. Поэтому его можно сохранить в скалярной переменной:

```raku
my $r = 1 .. 5;
```

## Не только числа

Интервалы могут использовать и другие типы данных, если Raku знает, как увеличивать их значения. Например:

```raku
my $letters = 'a' .. 'z';
```

В Raku интервалы — это объекты со своим собственным типом данных. Тип переменной `$r` — `Range`.
