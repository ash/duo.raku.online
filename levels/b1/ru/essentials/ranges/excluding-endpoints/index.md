---
title: Исключение концов интервала
---

{% include menu.html %}

Вы можете исключить один конец интервала или оба конца. Для этого добавьте символ `^` к оператору интервала. Так можно построить ещё три оператора. Комментарии перечисляют числа, которые создаёт каждый интервал.

```raku
1 ..^ 5;  # 1, 2, 3, 4
1 ^.. 5;  #    2, 3, 4, 5
1 ^..^ 5; #    2, 3, 4
```

В простых случаях, как эти, можно не ставить пробелы вокруг оператора:

```raku
my $r1 = 1..5;
my $r2 = 1..^5;
```

Для интервала, который начинается с 0, например `0..^5`, есть короткая форма: `^5`.
