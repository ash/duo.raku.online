title: Присвоение значения

{% include menu.html %}

Чтобы записать новое значение в скалярный контейнер, используйте оператор `=`.

```raku
my $name;
$name = 'Anna';
```

Теперь вы можете использовать переменную, например, чтобы напечатать её:

```raku
say $name;
```

## Несколько переменных сразу

Вы можете присвоить значения нескольким переменным одновременно. Например, вот так можно присвоить значения двум скалярам в одной инструкции:

```raku
my ($a, $b);
($a, $b) = 10, 20;
```

Заметьте, что скобки слева убрать нельзя. Но вы можете добавить их и справа, чтобы обе стороны были одинаковыми:

```raku
($a, $b) = (10, 20);
```
