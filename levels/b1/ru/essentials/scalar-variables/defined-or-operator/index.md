---
title: Оператор присвоено-или
---

{% include menu.html %}

Так называемый оператор _присвоено-или_ `//` помогает, когда у переменной ещё нет значения. В этом случае он даёт другое значение, которое можно использовать вместо него.

```raku
my $a = 'alpha';
say $a // 'gamma';

my $b;
say $b // 'delta';
```

Эта программа выведет:

```
alpha
delta
```

Значение `$a` задаётся в первой строке. Поэтому выражение `$a // 'gamma'` использует текущее значение `$a`. А переменная `$b` не получила начального значения. Поэтому `$b // 'delta'` возвращает операнд с правой стороны, и программа печатает `delta`.

## //=

Если соединить `//` и `=`, получится оператор `//=`. Он присваивает значение, только если переменная не определена.

```raku
my $x;
$x //= 42;
say $x; # 42
```
