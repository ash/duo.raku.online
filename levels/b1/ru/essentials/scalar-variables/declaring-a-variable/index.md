---
title: Объявление переменной
---

{% include menu.html %}

Прежде чем использовать переменную, её нужно объявить. В Raku для этого есть специальные слова — _объявители_. Чтобы объявить переменную, напишите `my` вот так:

```raku
my $name;
```

Этой строкой вы создали новую переменную, у которой пока нет значения. Но компилятор уже знает о ней. Когда это же имя появится дальше в программе, компилятор его узнает.

## Больше, чем одна переменная

Вы можете объявить две или больше переменных одним объявителем `my`:

```raku
my ($x, $y);
```
