Пока что текстовые строки в наших программах были записаны прямо в коде. Давайте теперь добавим немного свободы и дадим программе использовать переменные.

В Raku есть несколько типов переменных. Переменная — это контейнер, который может хранить данные. Мы начнём с самых простых контейнеров, которые хранят только одно значение. Они называются _скалярами_, или скалярными переменными. Имя переменной начинается с особого символа. Он показывает, какой это вид контейнера. Этот символ называется _сигил_. Для скалярных контейнеров сигил — это знак доллара `$`.

Вот два примера скалярных переменных:

```raku
$name

$age
```
