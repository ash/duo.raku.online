Для файлов Raku [рекомендуются](https://github.com/Raku/problem-solving/blob/master/solutions/language/Path-to-Raku.md#extensions) такие расширения:

* `.raku` для файлов с программами
* `.rakumod` для модулей
* `.rakutest` и `.t` для тестов
* `.rakudoc` для документов в формате POD6
