Если у вас есть две строки, их можно соединить и получить новую, более длинную строку. Это называется конкатенацией строк. В Raku строки соединяют — угадайте чем? — оператором конкатенации. Этот оператор — тильда, `~`. Чтобы соединить две строки, поставьте между ними `~`:

```raku
say 'Hello, ' ~ 'World!';
```

Если наши строки хранятся в переменных, мы можем «конкатенировать переменные». Ну, точнее, мы конкатенируем строки, которые хранятся в этих переменных:

```raku
my $greeting = 'Hello, ';
my $who = 'World!';

say $greeting ~ $who;
```

Или можно создать новую переменную, которая хранит результат конкатенации:

```raku
my $greeting = 'Hello, ';
my $who = 'World!';
my $message = $greeting ~ $who;

say $message;
```

## Конкатенация с присвоением

Чтобы добавить новую строку в конец переменной, используйте такую форму:

```raku
# Instead of 
$str = $str ~ $another-str;

# use:
$str ~= $another-str;
```
