Интерполяция кода — это следующий уровень интерполяции. Она позволяет вставить код прямо в строку в двойных кавычках. Код может быть простым или даже сложным!

Код для интерполяции ставится в фигурные скобки:

```raku
my $a = 10;
my $b = 20;
say "The sum of $a and $b is {$a + $b}.";
```

Программа выводит:

```console
$ raku t.raku 
The sum of 10 and 20 is 30.
```

## И снова переменные

Этот способ нужен, например, когда за переменной должен идти какой-то текст. Этот текст можно по ошибке принять за продолжение имени переменной. Чтобы этого избежать, заключите переменную в фигурные скобки:

```raku
my $how-many = 5;
my $what = 'suit';
say "There are $how-many {$what}s."; # There are 5 suits.
```

Без фигурных скобок Raku попытался бы интерполировать `$whats`, переменную, которой не существует.
