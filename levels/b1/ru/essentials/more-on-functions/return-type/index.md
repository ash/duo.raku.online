Результату функции также можно явно задать тип. Есть несколько способов записать это в коде.

```raku
sub add(Int $x, Int $y) returns Int { $x + $y }

my Int sub add(Int $x, Int $y) { $x + $y }

sub add(Int $x, Int $y) of Int { $x + $y }

sub add(Int $x, Int $y --> Int) { $x + $y }
```

Выберите тот, который вам нравится больше всего. Обратите внимание на четвёртый пример. Там тип возвращаемого значения стоит внутри скобок, вместе с параметрами функции.
