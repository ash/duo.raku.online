В Raku использовать функции в основном легко, и проблем это не вызывает. Но мы должны предупредить вас об одной вещи.

## TL;DR

Не ставьте пробел между именем функции и скобками с её аргументами. Но после `for` и `if` пробел ставить нужно.

## Длинная история

Возьмем простую функцию:

```raku
sub f($x, $y) {
    return $x + $y;
}
```

Прежде всего обратите внимание, что после имени функции нет пробела. Открывающая скобка с параметрами идёт сразу после имени. Некоторые стили кода в других языках могут требовать там пробел. Raku это принимает, но так делать не стоит:

```raku
sub f ($x, $y) {
    return $x + $y;
}
```

Когда вы вызываете функцию, отсутствие пробела важно. Если вы вызываете функцию без скобок, после её имени обязательно нужен пробел:

```raku
f 5, 6;
```

Но если вы используете скобки, перед ними не может быть пробела. Этот вызов правильный:

```raku
f(5, 6);
```

А этот вызов неправильный:

```raku
f (5, 6);
```

Такой код вызывает исключение:

    Too few positionals passed; expected 2 arguments but got 1
      sub f at t.raku line 1
      in block <unit> at t.raku line 5

Вызов с пробелом, `f (5, 6)`, Raku понимает по-другому. Он думает, что вы хотите передать функции один аргумент — `(5, 6)`. Тип этого аргумента легко проверить. Просто измените функцию, чтобы она принимала только один аргумент:

```raku
sub f($param) {
    say $param.WHAT;
}

f (5, 6); # (List)
```

Итак, когда вы вызываете `f (5, 6)`, вы передаёте функции [список](/ru/essentials/positionals/lists). Список передаётся как одно целое.

## Когда пробел необходим

В некоторых случаях пробел всё-таки нужен. Это бывает, когда вы используете скобки с ключевым словом, таким как `if`, `for` или `loop`. Следующий код неправильный:

```raku
if(True != False) {
    say 'OK';
}
```

Сообщение об ошибке объясняет проблему:

    ===SORRY!===
    The word 'if' is interpreted as a 'if()' function call.  Please use
    whitespace instead of parentheses.
    at /Users/ash/raku-course/t.raku:1
    ------> if⏏(True != False) {
    Unexpected block in infix position (two terms in a row)
    at /Users/ash/raku-course/t.raku:1
    ------> if(True != False)⏏ {

С `if` скобки вообще не нужны. Поэтому если вы их не используете, проблема не может появиться. Но в некоторых случаях они нужны, например, с `loop`. Тогда пробел обязателен:

```raku
loop(my $c = 0; $c != 10; $c++) { say $c }
```

В этом коде происходит то же самое: компилятор принимает `loop(...)` за вызов функции. Добавьте пробел, чтобы исправить проблему. Или, ещё лучше, перепишите эту часть кода с `for`.

## Заключение

Коротко говоря, чтобы избежать таких проблем, следуйте двум правилам. Не ставьте пробел между именем функции и скобками с её аргументами. Также старайтесь не использовать скобки в других частях языка, например, в управляющих конструкциях.
