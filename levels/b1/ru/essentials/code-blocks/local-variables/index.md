---
title: Локальные переменные
---

{% include menu.html %}

Давайте объявим переменную в глобальной области видимости. Что будет, если мы объявим её ещё и локально в блоке?

```raku
my $x = 1;

{
    my $x = 42;
    say $x;
}

say $x;
```

Теперь в программе две отдельные переменные. Обе называются `$x`. В глобальной области видимости `$x` всегда означает глобальную переменную. Но внутри блока `$x` — это другая, локальная переменная. Программа выводит два разных значения:

```console
$ raku t.raku
42
1
```
