---
title: Лексическая область видимости
---

{% include menu.html %}

Блок кода создаёт так называемую лексическую область видимости. Если вы объявляете переменную в блоке, она видна внутри блока. Но она не видна после того, как программа выходит из блока. Вот пример:

```raku
{
    my $x = 42;
    say $x;
}

say $x;
```

Переменная `$x` создаётся в блоке кода. Первый `say $x` выводит её значение, потому что переменная видна внутри блока. Второй `say $x` не срабатывает, потому что вне блока имени `$x` не существует. Когда блок закончился, это имя уже неизвестно. Программа не компилируется, и вы получаете ошибку:

```
===SORRY!=== Error while compiling /Users/ash/raku-course/t.raku
Variable '$x' is not declared
at /Users/ash/raku-course/t.raku:6
------> say ⏏$x;
```
