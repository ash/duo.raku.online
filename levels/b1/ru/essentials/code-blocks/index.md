Блоки кода — это части вашей программы внутри пары фигурных скобок: `{` и `}`. Блок объединяет несколько инструкций, которые работают вместе как одна большая инструкция. В следующих главах мы увидим много способов использовать блоки.

```raku
{
    say 'Hello, World!';
}
```

Блок кода в этой программе не имеет большого смысла. Но блоки кода очень полезны в других ситуациях, которые мы увидим очень скоро.

Но сначала давайте посмотрим, что такое _область видимости_.
