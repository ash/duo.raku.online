---
title: Приведение типов с помощью префиксных операторов
---

{% include menu.html %}

Ещё один способ изменить тип объекта — использовать префиксные операторы. Это операторы всего из одного символа. Вы ставите их прямо перед значением (или переменной).

`~` | Преобразование в строку
`+` | Преобразование в число
`?` | Преобразование в логическое значение

Вот пример, который создаёт логическое значение из целого числа:

```raku
say ?42; # True
```

Преобразование в строку аналогично:

```raku
my $n = -30;
my $s = ~$n;
say $s.chars; # 3, так как "-30" содержит 3 символа
```

Обратите внимание, что при преобразовании в число тип результата зависит от самого числа. Сравните следующие преобразования из строк:

```raku
say (+'100').WHAT;   # (Int)
say (+'3.14').WHAT;  # (Rat)
say (+'27E-1').WHAT; # (Num)
```

Чтобы получить логическое значение, можно также использовать процедуру `so`. Она работает как префиксный оператор или как метод:

```raku
my $value = 42;
say so $value; # True
say $value.so; # True
```
