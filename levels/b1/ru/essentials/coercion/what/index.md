---
title: Интроспекция с помощью `WHAT`
---

{% include menu.html %}

Чтобы увидеть тип данных в переменной, вызовите у неё метод `WHAT`:

```raku
my $n = 42;
my $s = '42';
say $n.WHAT; # (Int)
say $s.WHAT; # (Str)
```

Как видно в комментариях, тип выводится в скобках. Например, `(Int)` или `(Str)`.

Можно без проблем вызвать метод у самого литерала. Например:

```raku
say 42.WHAT;      # (Int)
say (-1).WHAT;    # (Int)
say 'Hello'.WHAT; # (Str)
say True.WHAT;    # (Bool)
```

Обратите внимание, что мы взяли `-1` в скобки. Без них `say -1.WHAT` попытался бы поставить минус перед результатом `1.WHAT`. Это приводит к исключению.
