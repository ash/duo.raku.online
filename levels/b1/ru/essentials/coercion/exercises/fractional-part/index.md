## Задача

У вас есть число, которое записано прямо в коде программы. Выведите его дробную часть. Вот начало программы:

```raku
my $n = 15.8972;
# ... Ваш код здесь
```

## Пример

Программа должна вывести часть числа после десятичной точки:

```console
$ raku fractional-part.raku
0.8972
```
