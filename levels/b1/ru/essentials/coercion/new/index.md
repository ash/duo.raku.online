title: Приведение типов с помощью конструкторов типов
---

{% include menu.html %}

Похожий способ — создать новый объект нужного типа. Для этого вы вызываете его конструктор, у которого такое же имя, как у типа. Например:

```raku
my $n = Int('1.23E4');
say $n;      # 12300
say $n.WHAT; # (Int)
```

Здесь строка с числом с плавающей запятой преобразуется в целое число.
