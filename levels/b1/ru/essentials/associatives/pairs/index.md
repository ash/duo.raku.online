Пара — это структура данных, которая хранит вместе имя и значение. Они составляют один объект, который можно хранить в скалярной переменной. Вот как создать пару:

```raku
my $pair = name => 'Anna';
```

Тип переменной `$pair` — `Pair`:

```raku
say $pair.WHAT; # (Pair)
```

Имя и значение можно получить по отдельности с помощью методов `key` и `value`:

```raku
say $pair.key; # name
say $pair.value; # Anna
```

Важная особенность пар — они неизменяемые. Это значит, что вы не можете дать существующей паре новое значение или новое имя. Но, конечно, вы можете присвоить совсем новую пару той же переменной:

```raku
my $pair = name => 'Anna';
$pair = name => 'John';
say $pair.value; # John
```

## Индексация

Есть другой способ прочитать значение пары. Её можно индексировать именем ключа в угловых скобках. Вот как это сделать:

```raku
say $pair<name>;
```

Обратите внимание, что кавычки вокруг ключа не нужны, если в нём нет пробелов. Если пробелы есть, правила немного строже:

```raku
my $pair = 'employee name' => 'Julie Madelon';
say $pair{'employee name'};
```

Будьте внимательны: на этот раз мы используем фигурные скобки.
