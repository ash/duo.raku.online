_Хэш_ — это ещё один ассоциативный тип данных в Raku. Это агрегированный тип, который связывает имя каждого элемента с его значением. Переменные-хэши используют новый сигил: `%`.

```raku
my %capitals;
```

Теперь вы можете использовать хэш и дать ему начальные значения.

```raku
%capitals = France => 'Paris', Italy => 'Rome';
```

Как и с другими типами данных, оба действия можно сделать за один шаг:

```raku
my %capitals = France => 'Paris', Italy => 'Rome';
```

## Доступ к элементам

Индексация работает примерно так же, как мы видели для [пар](../pairs). Напишите строку в угловых или фигурных скобках:

```raku
say %capitals<France>;
say %capitals{'Italy'};
```

Хэши изменяемы, поэтому вы можете менять существующие значения и добавлять новые:

```raku
%capitals<Germany> = 'Berlin';
```

## Ключи и значения

У хэша есть два встроенных метода, `keys` и `values`. Они возвращают список его ключей и список его значений:

```raku
say %capitals.keys;
say %capitals.values;
```

Вот пример того, что выводит эта программа:

    (Germany Italy France)
    (Berlin Rome Paris)

Обратите внимание, что у элементов хэша нет определённого порядка. Но методы выше возвращают ключи и значения в одном и том же порядке.
