Raku++ доступен на своём сайте, [raku.online](https://raku.online). Его также можно взять из репозитория на GitHub, [github.com/ash/rakupp](https://github.com/ash/rakupp). После установки у вас будет один исполняемый файл под названием `rakupp`. Больше ничего настраивать не нужно, потому что у Raku++ нет отдельной виртуальной машины.

## Установщик

В macOS, Linux и системах BSD всё делает одна команда. Она скачивает сборку для вашего компьютера и проверяет её. Затем она добавляет `rakupp` в ваш `PATH`. Права администратора для этого не нужны:

```console
$ curl -fsSL https://raku.online/install.sh | sh
```

В Windows вместо этого используйте окно PowerShell. Можно также взять мастер установки, `rakupp-setup-windows-x64.exe`. Он лежит на странице релизов репозитория. В PowerShell выполните вот это:

```console
> irm https://raku.online/install-windows.ps1 | iex
```

Установщик спрашивает, нужен ли вам Raku++ ещё и под именем `raku`. После этого откройте новый терминал, чтобы новый `PATH` начал работать. Позже `rakupp upgrade` заменит его самым новым выпуском.

## Другие способы установки

* В macOS, через Homebrew: `brew tap ash/rakupp && brew install rakupp`.
* С Docker вам не нужно ничего устанавливать: команда `docker run --rm -it ghcr.io/ash/rakupp` запускает интерактивную оболочку REPL.
* Готовые архивы для каждой платформы лежат на странице релизов репозитория.
* Raku++ написан на C++. Поэтому его можно собрать и самому из исходного кода. В репозитории объясняется, какие инструменты для этого нужны.

## Номера версий

Опция `--version` показывает, какая у вас версия:

```console
$ rakupp --version
Raku++ 5.4.1 (2026-10-13) arm64-darwin
```

Эта строка показывает выпуск самого Raku++, `5.4.1`. Ещё она показывает дату сборки и платформу исполняемого файла. Версия языка Raku — это отдельная вещь. Её можно узнать у самого языка:

```console
$ rakupp -e 'say $*RAKU.version'
v6.d
```

Сравните это с сообщением о версии Rakudo на [странице установки Rakudo](/ru/essentials/how-to-install-rakudo). Тогда вы увидите, как каждый из двух компиляторов представляется.
