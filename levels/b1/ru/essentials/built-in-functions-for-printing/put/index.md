Процедура `put` делает ту же работу, что и [`print`](../print). Но по умолчанию она ещё добавляет символ новой строки в конце:

1. Вызывает метод `Str` на своих аргументах, чтобы преобразовать их в строку.
1. Добавляет символ новой строки.
1. Отправляет строку в поток `STDOUT`.

Несколько примеров:

```raku
42.put;
put 'Alpha', 'Beta';

my @array = 3, 4, 5;
put @array;

my %hash = a => 'b', c => 'd';
%hash.put;
```

Вот что выводит программа:

```console
$ raku t.raku
42
AlphaBeta
3 4 5
a	b
c	d
```

%%tipblock
## Новая строка в `put`

`put` добавляет после вывода некоторые символы. Точные символы берутся из метода `nl-out` выходного потока. Его значение по умолчанию — `\n`.
%%/tipblock
