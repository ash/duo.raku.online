title: '`say`'

Вот что делает встроенная операция `say`:

1. Вызывает метод `gist` для своих аргументов.
1. Добавляет символ новой строки.
1. Преобразует результат в UTF-8.
1. Отправляет его в поток `STDOUT`.

Для пользователя это выглядит просто. `say` лишь выводит содержимое переменной в терминал и добавляет новую строку.

Первый шаг нужно немного объяснить. У каждого встроенного типа данных, например у целых чисел или строк, есть метод `gist`. Для таких простых типов он возвращает значение, которое представляет элемент. Люди могут легко прочитать это значение.

```raku
say 42; # 42
say 'Raku'; # Raku
```

Массивы и хэши — примеры более сложных данных. Для них метод `gist` добавляет некоторое форматирование.

```raku
my @data = 'alpha', 'beta', 'gamma';
say @data; # [alpha beta gamma]

my %data = alpha => 1, beta => 2, gamma => 3;
say %data; # {alpha => 1, beta => 2, gamma => 3}
```

Вы можете вызвать `say` и как функцию, и как метод:

```raku
say 42;
say(42);
42.say;
```

Вы можете передать в `say` несколько аргументов. Она соединяет части вывода без пробелов между ними.

```raku
say(100, 500); # 100500
```
