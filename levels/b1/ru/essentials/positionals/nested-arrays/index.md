title: Вложенные массивы
---

{% include menu.html %}

Массивы могут содержать любые другие данные, в том числе другие массивы. Чтобы отметить, где начинается и заканчивается каждый вложенный массив, используйте квадратные скобки:

```raku
my @table = 
    [1, 2, 3, 4],
    [10, 20, 30, 40],
    [100, 200, 300, 400];
```

Можно также поставить ещё одну пару скобок вокруг массива верхнего уровня. Этот пример показывает ту же структуру данных, что и предыдущий.

```raku
my @table = [
    [1, 2, 3, 4],
    [10, 20, 30, 40],
    [100, 200, 300, 400]
];
```

Чтобы получить внутренние элементы, добавьте столько индексов, сколько нужно. Каждая пара квадратных скобок ведёт вас на один уровень глубже в структуру:

```raku
say @table[0][3]; # Выводит 4
say @table[2][1]; # Выводит 200 
```
