## Задача

Напишите программу, которая читает любое количество аргументов из командной строки. Она выводит их на отдельных строках, и у каждой строки есть номер.

## Пример

Вот как программа должна себя вести:

```console
$ raku count-and-print-arguments.raku words to display
1. words
2. to
3. display
```
