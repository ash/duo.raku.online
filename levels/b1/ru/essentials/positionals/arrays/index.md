Массивы — это агрегированные типы данных, то есть они могут хранить больше одного значения. Этим они отличаются от [скалярных элементов](/ru/essentials/scalar-variables). Элементы массива можно индексировать (или _субскриптировать_). Другими словами, у каждого элемента есть позиция. Поэтому у данных такого вида общее название — позиционные.

Для переменных-массивов есть другой сигил: `@`. Правила для имени переменной такие же, как [для скаляров](/ru/essentials/scalar-variables/identifiers/).

```raku
my @cities;
```

Сейчас мы создали массив с именем `@cities`. Вы можете заполнить его несколькими значениями:

```raku
@cities = 'Paris', 'Rome', 'Berlin';
```

Значения можно задать и сразу, когда вы создаёте массив:

```raku
my @cities = 'Paris', 'Rome', 'Berlin';
```

## Индексация

Чтобы получить один элемент массива, добавьте пару скобок после его имени:

```raku
say @cities[1];
```

Обратите внимание, что сигил всегда остаётся тем же. Элементы считаются с нуля, поэтому в нашем примере элемент `@cities[1]` — это `'Rome'`.

Массивы изменяемы, то есть их можно менять. Чтобы изменить элемент, просто присвойте ему новое значение:

```raku
@cities[0] = 'Rome';
@cities[1] = 'Paris';
```

Теперь оператор `say @cities[1]` выводит новое значение, `'Paris'`.

## Размер

Длина массива — это количество его элементов. Чтобы получить текущую длину, используйте метод `elems`:

```raku
say @cities.elems; # 3
```

Если массив стоит там, где ожидается число, вы получаете его размер:

```raku
say +@cities; # 3
```

Здесь [префиксный оператор `+`](/ru/essentials/coercion/prefixes) требует от своего аргумента число. Вот почему `+@cities` даёт `3`.
