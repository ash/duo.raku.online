## Задача

В программе может быть больше одного фейзера `END`. В этом случае они выполняются в порядке, **обратном** тому, в котором записаны. Последний объявленный вами фейзер выполняется первым: последним пришёл — первым ушёл.

Напишите два фейзера `END`. Первый выводит `first END`, а второй — `second END`. После них добавьте обычный `say 'body'`. Предскажите порядок вывода, а затем получите такой же вывод своей программой.

## Пример

Программа выводит:

```
body
second END
first END
```
