## Задача

Фейзер `END` выполняется после основного кода. Поэтому он видит *финальное* состояние ваших переменных. Это делает его идеальным местом для итогового сообщения.

Объявите счётчик `$count` со значением `0`. Напишите фейзер `END`, который выводит `processed $count items`, и поместите его перед основным кодом. Затем в основном теле программы увеличьте счётчик три раза с помощью цикла. Итоговое сообщение должно показать финальное значение счётчика. Оно не должно показывать значение в том месте, где записан фейзер.

## Пример

Программа выводит:

```
processed 3 items
```
