## Задача

Фейзер `BEGIN` — это больше, чем блок, который выполняется рано. Это ещё и *выражение*. Его значение вычисляется один раз, во время компиляции. Затем оно остаётся в программе неизменным.

С помощью `BEGIN { 2 + 3 }` задайте начальное значение переменной `$compiled`, а затем выведите её. Выражение `2 + 3` вычисляется, пока программа ещё компилируется. Но сохранённое значение отлично работает и во время выполнения.

## Пример

Программа выводит:

```
5
```
