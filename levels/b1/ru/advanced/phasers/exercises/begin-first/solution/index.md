Вот одно возможное решение.

## Код

```raku
my $compiled = BEGIN { 2 + 3 };

say $compiled;
```

🦋 Найдите программу в файле [begin-first.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/phasers/begin-first.raku).

## Вывод

```
5
```

## Комментарии

1. `BEGIN { 2 + 3 }` выполняется во время компиляции и даёт `5`. Если использовать блок `BEGIN` как выражение, он возвращает своё значение. Здесь это значение присваивается переменной `$compiled`.

1. Вычисление происходит только один раз, во время компиляции. Когда программа работает, `$compiled` просто содержит константу `5`. Так `BEGIN` может вычислять значения заранее. Он нужен не только для того, чтобы выводить что-то рано.
