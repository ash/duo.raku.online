## Задача

У вас есть модуль в файле `Circle.rakumod`, в котором объявлены две переменные `our`:

```raku
unit module Circle;

our $pi = 3.14;
our $tau = 6.28;
```

Напишите программу, которая использует модуль. Сначала она выводит, сколько имён объявлено в пакете модуля. Затем она выводит сами имена в алфавитном порядке.

## Пример

```console
$ raku -I. list.raku
2
($pi $tau)
```
