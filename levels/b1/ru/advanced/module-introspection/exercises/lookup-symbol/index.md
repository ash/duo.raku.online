## Задача

Кроме перечисления имён пакета, можно обратиться и к одному имени. Для этого используйте имя как ключ в stash пакета. Тогда имя не нужно заранее задавать в коде. Вот модуль `Circle.rakumod`:

```raku
unit module Circle;

our $pi = 3.14;
```

Напишите отдельную программу, которая загружает модуль и выводит значение `$pi`. Она должна найти `$pi` в stash с помощью `Circle::{'$pi'}`. Она не должна использовать полное имя `$Circle::pi`.

## Пример

Если запустить её с модулем в пути поиска, программа выводит:

```console
$ raku -I. lookup.raku
3.14
```
