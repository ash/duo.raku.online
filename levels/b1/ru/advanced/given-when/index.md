Иногда программе нужно выбрать один из нескольких вариантов. Тогда цепочка проверок `if` и `elsif` может стать длинной и полной повторов. В таких случаях `given`/`when` часто понятнее. Эта конструкция похожа на оператор `switch` из других языков.

Блок `given` принимает значение и делает его _топиком_. Топик — это специальная переменная `$_`. Затем каждый блок `when` сравнивается с этим топиком. Выполняется первый, который совпал:

```raku
my $n = 2;

given $n {
    when 1 { say 'one' }
    when 2 { say 'two' }
    when 3 { say 'three' }
}
```

Эта программа печатает:

```
two
```

В отличие от `switch` в некоторых языках, здесь нет «проваливания» (fall-through) к следующему случаю. Как только `when` совпадает, выполняется его блок, и блок `given` заканчивается. Остальные блоки `when` не проверяются.

## Блок `default`

Блок `default` выполняется, когда ни один из блоков `when` не совпал. Он делает ту же работу, что и ветка `else` в операторе `if`:

```raku
my $n = 5;

given $n {
    when 1 { say 'one' }
    when 2 { say 'two' }
    default { say 'many' }
}
```

`$n` не равно ни `1`, ни `2`, поэтому программа печатает:

```
many
```
