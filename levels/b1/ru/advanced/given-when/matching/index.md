Блок `when` не только проверяет, равны ли два значения. Он выполняет _умное сопоставление_ (smart match) между топиком и значением, которое вы ему даёте. Поэтому можно сопоставлять с диапазонами, типами и условиями, а не только с отдельными значениями.

## Диапазоны

Диапазон совпадает, когда топик попадает в него. Поэтому `given`/`when` — естественный выбор, чтобы делить числа на группы:

```raku
my $score = 75;

given $score {
    when 90..100 { say 'A' }
    when 80..89  { say 'B' }
    when 70..79  { say 'C' }
    default      { say 'F' }
}
```

Значение `75` входит в диапазон `70..79`, поэтому программа печатает:

```
C
```

## Типы

Тип совпадает, когда топик относится к этому типу. Так программа может выбрать ветку в зависимости от вида значения, которое у неё есть:

```raku
my $value = 'Raku';

given $value {
    when Int { say 'an integer' }
    when Str { say 'a string' }
}
```

`$value` содержит строку, поэтому программа печатает:

```
a string
```

## Условия

Можно также написать сравнение напрямую. Внутри `when` топик можно использовать как `$_`. Поэтому условие вроде `$_ < 0` совпадает, когда оно истинно:

```raku
my $n = -7;

given $n {
    when $_ < 0 { say 'negative' }
    when 0      { say 'zero' }
    default     { say 'positive' }
}
```

Здесь первый `when` совпадает, и программа печатает:

```
negative
```
