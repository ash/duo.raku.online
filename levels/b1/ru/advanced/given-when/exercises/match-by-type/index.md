## Задача

`when` может сравнивать не только со значением, но и с *типом*. Переменная содержит число `3.14`. С помощью `given`/`when` покажите, какого вида это значение. Напечатайте `integer` для `Int`, `rational` для `Rat` и `string` для `Str`.

## Пример

Программа печатает:

```
rational
```
