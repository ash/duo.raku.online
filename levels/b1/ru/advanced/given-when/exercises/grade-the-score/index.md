## Задача

Возраст задан прямо в коде. С помощью `given`/`when` напечатайте его этап жизни. Используйте такие группы:

* `child` для 0–12,
* `teenager` для 13–19,
* `adult` для 20–64,
* `senior` для 65 и старше.

Отрицательный возраст не имеет смысла, поэтому для любого числа меньше нуля печатайте `invalid`. Обязательно проверьте этот случай до диапазонов.

## Пример

Для возраста `30` программа печатает:

```
adult
```
