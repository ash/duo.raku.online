Вот одно возможное решение.

## Код

```raku
my $age = 30;

given $age {
    when $_ < 0 { say 'invalid' }
    when 0..12  { say 'child' }
    when 13..19 { say 'teenager' }
    when 20..64 { say 'adult' }
    default     { say 'senior' }
}
```

🦋 Исходный код можно найти в файле [grade-the-score.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/given-when/grade-the-score.raku).

## Вывод

```
adult
```

## Комментарии

1. В этом решении смешаны два вида `when`. Первый — это *условие* `$_ < 0`, где `$_` — топик, который задаёт `given`. Оно отсеивает недопустимые возрасты. Остальные — это *диапазоны*, которые делят допустимые возрасты на этапы.

1. Порядок имеет значение. Проверка отрицательного возраста идёт первой. Поэтому она выполняется до проверки любого диапазона. Значение `30` входит в `20..64`, поэтому программа печатает `adult`.

1. Блок `default` покрывает любой возраст от 65 и выше. Ни один из перечисленных диапазонов не ловит эти возрасты.

Можно сделать и наоборот: пусть `default` ловит *недопустимый* ввод. Перечислите все известные этапы, включая `senior` в виде условия `$_ >= 65`. Всё, что осталось, например отрицательный возраст, считайте недопустимым:

```raku
given $age {
    when 0..12    { say 'child' }
    when 13..19   { say 'teenager' }
    when 20..64   { say 'adult' }
    when $_ >= 65 { say 'senior' }
    default       { say 'invalid' }
}
```

Здесь `default` — настоящая ветка «ничего из перечисленного». Какой вариант читается лучше — дело вкуса. Ставьте проверку первой, когда недопустимый случай — исключение. Или сделайте его блоком `default`, когда все допустимые этапы ясно перечислены.
