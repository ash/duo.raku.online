Вот одно возможное решение.

## Код

```raku
my $n = 12;

given $n {
    when 0      { say 'zero' }
    when $_ %% 2 { say 'even' }
    default     { say 'odd' }
}
```

🦋 Исходный код можно найти в файле [sign-of-a-number.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/given-when/sign-of-a-number.raku).

## Вывод

```
even
```

## Комментарии

1. `when 0` совпадает только со значением ноль. Он идёт первым, потому что ноль тоже чётный, а мы хотим вывести его отдельно.

1. `when $_ %% 2` — это условие, где `$_` — топик, который задаёт `given`. Оператор `%%` проверяет, делится ли топик на два нацело. Значение `12` не равно нулю, но делится на два, поэтому программа печатает `even`.

1. `default` покрывает всё, что осталось. Это числа, которые не являются ни нулём, ни чётными, то есть нечётные.
