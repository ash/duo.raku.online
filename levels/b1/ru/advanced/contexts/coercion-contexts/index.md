Три контекста встречаются очень часто. Они заставляют значение вести себя как число, строка или логическое значение. Для каждого из них есть префиксный оператор, который прямо задаёт контекст:

* `+` — числовой контекст
* `~` — строковый контекст
* `?` — логический контекст

С массивом `+` даёт его длину, а `~` даёт его элементы, соединённые через пробел. `?` показывает, есть ли в массиве хоть какие-то элементы:

```raku
my @a = 1, 2, 3;

say +@a; # 3
say ~@a; # 1 2 3
say ?@a; # True
```

Пустой массив даёт `0` в числовом контексте и `False` в логическом контексте:

```raku
my @empty;
say +@empty; # 0
say ?@empty; # False
```

Вам не всегда нужно писать эти операторы самим. Raku может сам задать нужный контекст. Арифметика помещает свои значения в числовой контекст, а соединение строк помещает их в строковый контекст. `if`, `while` и `and`/`or` помещают своё условие в логический контекст:

```raku
my @a = 1, 2, 3;

say 10 + @a;              # 13, here @a is its length: 3
say 'items: ' ~ @a;       # items: 1 2 3
if @a { say 'not empty' } # not empty
```

Поэтому `if @array { … }` работает именно так, как вы ожидаете. Массив, который не пуст, считается истинным. Префиксные операторы — это способ прямо попросить те же преобразования.

Вместе с постфиксным `if` это позволяет писать короткий и понятный код:

```raku
say "{+@a} items are there" if @a; # 3 items are there
```
