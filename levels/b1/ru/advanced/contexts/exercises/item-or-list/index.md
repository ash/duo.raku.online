## Задача

Возьмите массив `1, 2, 3` и упакуйте его в скаляр `$x` с помощью контекстуализатора **элемента**. Тогда `$x` хранит весь массив как одно значение. Затем с помощью контекстуализатора **списка** запустите цикл `for` по `$x`. Посчитайте, сколько раз выполняется цикл. Контекст списка снова раскладывает упакованный массив на элементы. Поэтому цикл выполняется три раза. Выведите счётчик.

## Пример

Программа выводит:

```
3
```
