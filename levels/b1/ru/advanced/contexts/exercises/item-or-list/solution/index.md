Вот одно возможное решение задачи.

## Код

```raku
my @a = 1, 2, 3;
my $count = 0;

my $x = $(@a);
$count++ for @($x);
say $count;
```

🦋 Исходный код можно найти в файле [item-or-list.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/contexts/item-or-list.raku).

## Вывод

```
3
```

## Комментарии

1. `my $x = $(@a)` задаёт контекст элемента. Поэтому весь массив упаковывается в один скаляр `$x`. Он не раскладывается на элементы.

1. Затем `@($x)` задаёт контекст списка и снова раскладывает `$x` на три элемента. Поэтому цикл `for` выполняется три раза, и в конце счётчик равен `3`. Два контекстуализатора — точные противоположности: `$( )` упаковывает список в один элемент, а `@( )` снова его распаковывает.
