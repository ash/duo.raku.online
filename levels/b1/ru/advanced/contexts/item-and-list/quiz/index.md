Что выведет следующая программа?

```raku
my @a = 1, 2, 3;
my $n = 0;
$n++ for $(@a);
say $n;
```

{:.quiz}
0 | 3
1 | 1
0 | 0
0 | 6

{% include quiz.html %}

<div class="extended-explanation">

Контекстуализатор `$( … )` задаёт контекст элемента. Поэтому массив — одно значение, а не список элементов. Вот почему цикл `for` видит один элемент и выполняет своё тело только один раз. Поэтому в конце `$n` равно `1`. Без `$( )` цикл выполнился бы три раза.

</div>
