Операторы в Raku — на самом деле просто подпрограммы с особыми именами. Это значит, что вы можете определять собственные операторы. Для этого используются названия категорий со страницы [Типы операторов Raku](/ru/advanced/operator-types): `prefix`, `infix`, `postfix` и так далее.

Чтобы объявить оператор, напишите `sub` с особым именем. Это имя состоит из категории, двоеточия и символа оператора в угловых скобках. Вот новый инфиксный оператор с именем `plus`:

```raku
sub infix:<plus>($a, $b) {
    $a + $b
}

say 3 plus 4; # 7
```

Когда `plus` определён, он ставится между двумя своими операндами. Это точно так же, как у любого встроенного инфиксного оператора.

Постфиксный оператор идёт после своего операнда. Факториал — классический пример. Вот он в виде постфиксного оператора `!`. Он построен на [метаоператоре редукции](/ru/advanced/metaoperators/reduction), который вы видели раньше:

```raku
sub postfix:<!>(Int $n) {
    [*] 1..$n
}

say 5!; # 120
```

Вы не ограничены буквами и знаками препинания ASCII. Символом оператора может быть любой символ. Этот префиксный оператор использует знак параграфа, `§`, чтобы удвоить число:

```raku
sub prefix:<§>($x) {
    $x * 2
}

say §5; # 10
```

Определение операторов — мощный инструмент, поэтому пользуйтесь им со вкусом. Удачно выбранный оператор может сделать код похожим на язык той области, к которой относится задача. Непонятный оператор только запутает следующего человека, который будет читать код.
