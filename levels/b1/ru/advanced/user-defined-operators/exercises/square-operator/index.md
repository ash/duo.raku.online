## Задача

Символом оператора может быть любой символ, в том числе символ Юникода. Определите **постфиксный** оператор `²`, который возводит операнд в квадрат, так что `5²` означает `5 ** 2`. Затем напечатайте `5²`.

## Пример

Программа выводит:

```
25
```
