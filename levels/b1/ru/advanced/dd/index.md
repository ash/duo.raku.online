---
title: Отладка с помощью `dd`
---

{% include menu.html %}

Есть разные способы отладки программы. Можно просто печатать значения с помощью `say`. А можно взять более сложные инструменты, которые следят за ходом программы. В этом разделе мы рассмотрим полезную процедуру `dd`. Она есть в компиляторе Rakudo, но стандарт языка Raku её не включает.

Название `dd` расшифровывается как _data dumper_ (дампер данных). Процедуры `say` и `put` нужны для обычного вывода программы. А `dd` печатает значение в виде, который удобен для разработчиков. Это та же форма, похожая на код, которую даёт метод [`.raku`](/ru/advanced/representations/raku-method). Мы видели этот метод в предыдущем разделе. `dd` печатает в поток стандартной ошибки. Поэтому её вывод не смешивается с тем, что ваша программа печатает для пользователя.
