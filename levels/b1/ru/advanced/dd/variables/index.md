---
title: Вывод переменных
---

{% include menu.html %}

Вызовите `dd`, чтобы увидеть, что лежит в переменной. Вы используете её так же, как `say`:

```raku
my $var = 42;
dd $var;
```

`dd` печатает и значение, и имя переменной:

```console
$var = 42
```

Если у переменной объявлен тип, `dd` показывает и его. Сравните вывод этой программы с выводом предыдущей:

```raku
my Int $var = 42;
dd $var;
```

```console
Int $var = 42
```

В этом главное отличие от `say`. Один вызов `dd` для скаляра сообщает вам имя переменной. Ещё он сообщает тип данных, когда тот известен. Поэтому можно добавить в программу несколько вызовов `dd`. Вы всё равно увидите, какой вывод относится к какой переменной.

Можно выводить дамп и более сложных структур данных, например массивов или хэшей. Тогда `dd` печатает значение в виде, похожем на код:

```raku
my @arr = 10, 20, [1, 2, 3], 30;
dd @arr;
```

```console
[10, 20, [1, 2, 3], 30]
```

Обратите внимание, что вложенный массив хорошо видно. Но имя переменной не печатается. С хэшами это работает так же, и `dd` печатает их ключи в отсортированном порядке:

```raku
my %hash =
    gamma => 'g',
    alpha => 'a',
    beta  => 'b';
dd %hash;
```

```console
{:alpha("a"), :beta("b"), :gamma("g")}
```
