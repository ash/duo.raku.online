## Задача

Объявите переменную с типом для целых чисел: `my Int $n = 42;`. Затем выведите её с помощью `dd`. Обратите внимание, чем вывод отличается от вывода переменной без типа.

## Пример

Программа печатает это в стандартный поток ошибок:

```
Int $n = 42
```
