## Задача

У вас есть такая вложенная структура данных:

```raku
my @data = 'Raku', [1, 2, 3], (key => 'value');
```

Сделайте с ней два действия:

1. С помощью `dd` выведите дамп `@data` для разработчиков.
2. Выведите то же представление в виде строки, которая начинается с текста `Structure: `.

## Пример

Программа печатает две похожие строки:

```
["Raku", [1, 2, 3], :key("value")]
Structure: ["Raku", [1, 2, 3], :key("value")]
```
