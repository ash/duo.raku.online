---
title: Сигнатура функции
---

Внутри подпрограммы можно вызвать просто `dd`, без аргументов. Тогда она печатает сигнатуру этой подпрограммы. Это её имя и список параметров, если они есть. Посмотрите на следующий пример с двумя подпрограммами:

```raku
sub f1 {
    dd
}

f1();

sub f2($x) {
    dd
}

f2(42);
```

Программа печатает сигнатуры, а не значения:

```console
sub f1()
sub f2($x)
```

Это особенно полезно с мультифункциями, потому что `dd` показывает, какой вариант был вызван на самом деле:

```raku
multi sub g {
    dd
}

multi sub g($x) {
    dd
}

g();
g(42);
```

Каждый раз вывод показывает подходящий вариант:

```console
sub g()
sub g($x)
```
