Имена нативных типов записываются строчными буквами: `int`, `num` и `str`. С ними объявляют переменную точно так же, как с `Int` или `Str`:

```raku
my int $i = 42;
my num $n = 3.14e0;
say $i; # 42
say $n; # 3.14
```

Нативное значение прямо соответствует машинному регистру или слову. У него нет объекта-обёртки, который всегда есть у обычного значения Raku. Поэтому нативные типы быстрее и занимают меньше памяти. Это важно в коротких циклах с большим количеством вычислений и в больших массивах.

Одну вещь стоит знать сразу: нативная переменная никогда не может быть неопределённой. Обычная переменная `Int` начинается с неопределённого значения `(Int)`. А вот нативный `int` начинается с **нуля**:

```raku
say (my Int $a); # (Int)
say (my int $b); # 0
```

То же верно для нативных массивов. Чтобы их объявить, нативный тип ставят перед переменной с `@`:

```raku
my int @numbers = 10, 20, 30;
say @numbers.sum; # 60
```

Такой массив хранит элементы как «сырые» машинные целые числа, а не как упакованные объекты `Int`. Поэтому он занимает меньше памяти. Когда вы спрашиваете нативное значение о нём самом, Raku автоматически _упаковывает_ его. Он кладёт значение в соответствующий полный тип. Вот почему `(my int $b).WHAT` показывает `(Int)`.
