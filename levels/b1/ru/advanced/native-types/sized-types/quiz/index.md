Что напечатает следующая программа?

```raku
my int8 $i = -128;
$i--;
say $i;
```

{:.quiz}
1 | 127
0 | -129
0 | -128
0 | 0

{% include quiz.html %}

<div class="extended-explanation">

`int8` хранит значения от `-128` до `127`. У нижней границы значения тоже идут по кругу. Если сделать декремент наименьшего значения, вы не получите `-129`. Поэтому значение по кругу переходит к наибольшему, `127`.

</div>
