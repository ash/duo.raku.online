## Задача

Лучше всего нативный тип фиксированного размера подходит для массива байтов. Такой массив занимает мало памяти. Объявите массив `uint8` со значениями `100`, `200` и `255`. Каждое из них помещается в один байт. Затем напечатайте сумму его элементов.

Обратите внимание: каждый элемент остаётся в диапазоне `0..255`, но сумма может быть больше. Это потому, что `.sum` возвращает обычный `Int`.

## Пример

Программа выводит:

```
555
```
