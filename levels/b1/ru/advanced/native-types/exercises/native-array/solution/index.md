Вот одно возможное решение задачи.

## Код

```raku
my uint8 @bytes = 100, 200, 255;
say @bytes.sum;
```

🦋 Исходный код можно найти в файле [native-array.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/native-array.raku).

## Вывод

```
555
```

## Комментарии

1. Нативный тип фиксированного размера `uint8` стоит перед массивом с `@`. Так объявляется массив, где каждый элемент — это один беззнаковый байт. Он занимает мало памяти, и это хорошо для двоичных данных.

1. Граница `0..255`, после которой значение идёт по кругу, действует для каждого *элемента*, но не для их суммы. `.sum` упаковывает итог в обычный `Int`. Поэтому `100 + 200 + 255` даёт полное значение `555`.
