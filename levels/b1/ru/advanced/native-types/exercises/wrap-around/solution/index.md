Вот одно возможное решение задачи.

## Код

```raku
my uint8 $u = 250;
$u += 10;
say $u;

my uint8 $v = 0;
$v--;
say $v;
```

🦋 Исходный код можно найти в файле [wrap-around.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/wrap-around.raku).

## Вывод

```
4
255
```

## Комментарии

1. `uint8` принимает значения от `0` до `255`, то есть у него 256 разных значений. На практике арифметика с ним идёт по модулю 256.

1. `250 + 10` дало бы `260`, а это не помещается. Поэтому значение идёт по кругу и оказывается на `260 - 256 = 4` выше нижней границы. Значит, переполнение — это не только шаг на единицу за верхнюю границу. Любой результат вне диапазона возвращается в него.

1. Движение в другую сторону тоже вызывает переполнение. В беззнаковом типе декремент `0` не может дать `-1`. Поэтому значение по кругу переходит к максимуму, `255`.
