Вот одно возможное решение задачи.

## Код

```raku
my num $n;
my str $s;

say $n;
say "[$s]";
```

🦋 Исходный код можно найти в файле [native-default.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/native-default.raku).

## Вывод

```
0
[]
```

## Комментарии

1. Нативный `num` не может быть неопределённым. Поэтому, как и нативный `int`, он начинается с `0`, а не с `(Num)`.

1. Нативный `str` начинается как пустая строка. Вот почему в выводе между скобками ничего нет. Ни один нативный тип никогда не хранит неопределённое значение.

1. Имена типов здесь очень важны. Если убрать их и написать `my $n; my $s;`, переменные станут обычными контейнерами. Сначала они *неопределённые* (`Any`). Тогда `say $n` печатает `(Any)`. Интерполяция неопределённой `$s` к тому же даёт предупреждение: *«Use of uninitialized value … in string context»*. Только нативные типы `num` и `str` дают значения по умолчанию `0` и пустую строку.
