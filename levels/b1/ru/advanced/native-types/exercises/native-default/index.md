## Задача

Нативная переменная никогда не может быть неопределённой. Это правило верно для любого нативного типа, а не только для `int`. Объявите нативный `num` и нативный `str`, не присваивая им значений. Напечатайте число. Затем напечатайте строку в квадратных скобках, чтобы было видно, что она пустая.

## Пример

Программа выводит:

```
0
[]
```
