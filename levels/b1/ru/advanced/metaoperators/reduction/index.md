Метаоператор свёртки — это обычный оператор в квадратных скобках, например `[+]` или `[*]`. Он берёт список значений и ставит оператор между каждой их парой. Так он сворачивает весь список в одно значение.

Например, `[+]` складывает все элементы списка:

```raku
my @data = 3, 5, 7, 9, 11;
say [+] @data; # 35
```

Код `[+] @data` — то же самое, что выписать оператор вручную:

```raku
say 3 + 5 + 7 + 9 + 11; # 35
```

Любой подходящий инфиксный оператор работает так же. С `[*]` вы получаете произведение списка. Поэтому, если применить его к диапазону `1..$n`, можно легко вычислить факториал:

```raku
my $n = 5;
say [*] 1..$n; # 120
```

Здесь диапазон `1..$n` даёт числа от 1 до 5, а `[*]` перемножает их: `1 * 2 * 3 * 4 * 5`. Результат — _5!_.

Это работает и для соединения строк. Свёртка `[~]` соединяет список строк в одну:

```raku
my @strings = <neun hundert fünf und zwanzig>;
say [~] @strings; # neunhundertfünfundzwanzig
```

Можно сворачивать даже операторы сравнения. `[<]` сообщает, больше ли каждое значение, чем предыдущее:

```raku
say [<] 1, 2, 3; # True
```

## Треугольная свёртка

Если поставить внутри скобок обратную косую черту, получится _треугольная_ свёртка. Она сохраняет все промежуточные результаты, а не только итоговый:

```raku
say [\+] 1..5; # (1 3 6 10 15)
```

Каждый элемент результата — частичная сумма: `1`, затем `1+2`, затем `1+2+3` и так далее. Последний из них — сумма всего списка.
