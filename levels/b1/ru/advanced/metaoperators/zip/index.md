Метаоператор zip `Z` берёт два или больше списков. Он объединяет их элементы по позициям:

```raku
say (1, 2, 3) Z (4, 5, 6); # ((1 4) (2 5) (3 6))
```

Результат — это список групп. Первая группа содержит первый элемент каждого списка. Следующая группа содержит вторые элементы, и так далее.

Можно поступить ещё умнее и совместить `Z` с оператором, который работает с каждой парой. Например, `Z+` складывает элементы по позициям:

```raku
say (1, 2, 3) Z+ (10, 20, 30); # (11 22 33)
```

Здесь метаоператор zip оборачивает оператор `+`. Он вычисляет `1 + 10`, `2 + 20` и `3 + 30`. Точно так же `Z*` перемножает соответствующие элементы:

```raku
say (1, 2, 3) Z* (10, 20, 30); # (10 40 90)
```

А `Z~` соединяет соответствующие строки:

```raku
say <a b c> Z~ <1 2 3>; # (a1 b2 c3)
```
