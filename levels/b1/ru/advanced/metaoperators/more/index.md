Кроме свёртки и zip, в Raku есть ещё несколько метаоператоров. Три из них полезно знать уже сейчас.

## Перекрёстный — `X`

Перекрёстный метаоператор `X` берёт два списка. Он составляет пары из **каждого** элемента одного списка и **каждого** элемента другого. Это называется декартовым произведением:

```raku
say <a b> X <1 2>; # ((a 1) (a 2) (b 1) (b 2))
```

Как и zip, он может обернуть оператор, который потом работает с каждой парой. `X~` соединяет каждую пару в строку, а `X*` перемножает значения:

```raku
say <a b> X~ <1 2>;         # (a1 a2 b1 b2)
say (1, 2, 3) X* (10, 100); # (10 100 20 200 30 300)
```

Zip проходит по двум спискам одновременно, а перекрёстный оператор сочетает их всеми возможными способами.

## Гипероператор — `»…«`

Гипероператор применяет оператор к **каждому элементу** списка. Оператор ставится внутрь угловых стрелок `»…«` или в их ASCII-форму `>>…<<`. С двумя списками он работает поэлементно, как zip. Если с одной стороны стоит одно значение, он растягивает это значение на весь список:

```raku
say (1, 2, 3) »+» (10, 20, 30); # (11 22 33)
say (1, 2, 3) »*» 2;            # (2 4 6)
```

Стрелки не обязательно смотрят в одну сторону. Их направление решает, что происходит, когда у списков разная длина. Если стрелка смотрит **на** список, этот список может повторяться, чтобы совпасть по длине с другим. Вот четыре сочетания, записанные в ASCII с `<<` и `>>`:

* `>>op<<` — ни один список не повторяется, поэтому списки уже должны быть одной длины, иначе будет ошибка;
* `>>op>>` — **правый** список повторяется, чтобы совпасть по длине с левым;
* `<<op<<` — **левый** список повторяется, чтобы совпасть по длине с правым;
* `<<op>>` — **более короткий** список повторяется, чтобы совпасть по длине с более длинным.

```raku
say (1, 2, 3, 4) <<+>> (10, 20); # (11 22 13 24)  — 10, 20 повторяется как 10, 20, 10, 20
```

Есть также унарная форма, у которой только один операнд. Она вызывает метод у каждого элемента. `>>.uc` переводит каждую строку в верхний регистр:

```raku
say <raku perl>>>.uc; # (RAKU PERL)
```

Гипероперации также показывают, что работа *может* выполняться параллельно. Позже вы встретите связанный с ними метод `.hyper` в [разделе о конкурентном программировании](/ru/paradigms/hyper-race).

## Отрицающий — `!`

Если поставить `!` перед оператором сравнения, получится обратный результат. Знакомый вам `!=` (не равно) — это ровно этот метаоператор, применённый к `==`. Точно так же это работает с другими логическими операторами, например `eq` и `%%`:

```raku
say 3 != 4;      # True
say 'a' !eq 'b'; # True  — не равны как строки
say 5 !%% 2;     # True  — 5 не делится на 2
```

Коротко говоря, `$a !op $b` — это просто более аккуратный способ записать `!($a op $b)`.

Так задумано. Некоторые языки, например эсперанто, специально сделаны маленькими и простыми. Они стараются иметь один правильный способ выразить каждую мысль. Raku не такой и охотно даёт вам несколько способов. Поэтому отрицающий `!eq` существует прямо рядом с отдельным оператором `ne`. Оба означают ровно одно и то же:

```raku
say 'a' ne 'b'; # True — та же проверка, что и 'a' !eq 'b'
```
