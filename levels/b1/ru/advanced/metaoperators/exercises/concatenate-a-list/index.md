## Задача

URL разбит на части, и эти части лежат в массиве. Соедините их обратно в одну строку с помощью метаоператора свёртки. Напечатайте URL, а на следующей строке — сколько в нём символов.

## Пример

Возьмём такой входной массив:

```raku
my @parts = <http :// example .com>;
```

С этим массивом программа печатает:

```
http://example.com
18
```
