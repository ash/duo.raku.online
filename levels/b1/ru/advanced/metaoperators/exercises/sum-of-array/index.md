## Задача

Напишите программу, которая печатает среднее значение массива чисел. Среднее значение также называют средним арифметическим. Для сложения значений используйте метаоператор свёртки.

Входные данные записаны прямо в программе, например:

```raku
my @data = 10, 20, 30, 40;
```

## Пример

Программа печатает среднее значение элементов массива `@data`:

```
25
```
