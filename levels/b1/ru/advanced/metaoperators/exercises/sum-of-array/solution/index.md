Вот одно возможное решение.

## Код

```raku
my @data = 10, 20, 30, 40;

say ([+] @data) / @data.elems;
```

🦋 Исходный код можно найти в файле [sum-of-array.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/metaoperators/sum-of-array.raku).

## Вывод

```
25
```

## Комментарии

1. Метаоператор свёртки `[+]` ставит оператор `+` между всеми элементами `@data`. Поэтому `[+] @data` — то же самое, что `10 + 20 + 30 + 40`, то есть `100`. Скобки нужны, чтобы свёртка выполнилась раньше деления.

1. `@data.elems` даёт число элементов. Если разделить сумму на это число, получится среднее, `25`. Если бы деление было не нацело, Raku не стал бы округлять результат. Вместо этого он дал бы точное значение типа `Rat`.
