Вот одно возможное решение.

## Код

```raku
say (2, 4 ... *).head(4);
```

🦋 Исходный код можно найти в файле [open-range.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/whatever/open-range.raku).

## Вывод

```
(2 4 6 8)
```

## Комментарии

1. Начальные значения `2, 4` задают арифметический шаг: каждое новое число на два больше. Одна `*` в конце означает, что последовательность никогда не заканчивается.

1. `head(4)` берёт только первые четыре значения, `2, 4, 6, 8`. Последовательность ленивая, поэтому бесконечный остаток никогда не вычисляется. Здесь звёздочка сама по себе означает «что угодно, без верхней границы».
