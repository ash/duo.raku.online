Подпрограмма не обязана иметь имя. Внешне _анонимная_ подпрограмма такая же, как обычная, только у неё нет имени. Обычно её сохраняют в переменной, чтобы потом вызвать.

```raku
my $double = sub ($x) {
    $x * 2
};

say $double(5); # 10
```

Переменная `$double` хранит подпрограмму. Затем `$double(5)` вызывает её с аргументом `5`.

## Остроконечные блоки

В Raku есть более короткая запись того же самого — _остроконечный блок_ (pointy block). Стрелка `->` стоит перед параметрами. Не нужны ни слово `sub`, ни скобки вокруг параметров:

```raku
my $double = -> $x {
    $x * 2
};

say $double(5); # 10
```

Чаще всего небольшую анонимную подпрограмму записывают именно так.

## Сигил `&`

Возможно, вы хотите вызывать подпрограмму по имени, а не через переменную с `$`. В этом случае объявите переменную с сигилом `&`. Тогда её можно вызывать без сигила, так же как обычную подпрограмму:

```raku
my &triple = -> $x {
    $x * 3
};

say triple(4); # 12
```

## Передача в другую функцию

Анонимную подпрограмму вообще не обязательно сохранять в переменной. Это просто значение. Поэтому её можно передать прямо в функцию, которой нужно такое значение. Например, это `map`, `grep` или `sort`:

```raku
say (1, 2, 3).map(-> $x { $x * 2 }); # (2 4 6)
```

Здесь остроконечный блок — это анонимная подпрограмма. `map` вызывает его один раз для каждого элемента. На самом деле вы делали это всё время. Вы передавали в `map` и `grep` много блоков `{ ... }` и `-> $x { ... }`. Каждый из них — небольшая анонимная подпрограмма. Вы пишете её прямо там, где она нужна, а не даёте ей сначала имя.
