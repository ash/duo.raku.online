## Задача

Остроконечный блок может принимать больше одного параметра. Сигил `&` позволяет вызывать его по имени. Напишите остроконечный блок с двумя параметрами, который складывает свои аргументы. Сохраните его в переменной `&add`, объявленной с сигилом `&`. Затем вызовите его как `add(2, 3)`, без сигила, и выведите результат.

## Пример

Программа выводит:

```
5
```
