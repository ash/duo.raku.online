Вот одно возможное решение.

## Код

```raku
my $factor = 3;
my $scale = -> $x { $x * $factor };

say $scale(7);
```

🦋 Исходный код можно найти в файле [triple-it.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/anonymous-subroutines/triple-it.raku).

## Вывод

```
21
```

## Комментарии

1. У остроконечного блока только один параметр, `$x`. И всё же он использует `$factor` — переменную из области видимости вокруг него. Именно захват таких переменных делает его замыканием.

1. Когда `$factor` равен `3`, вызов `$scale(7)` даёт `21`. Если изменить `$factor`, тот же блок будет умножать на новое значение:

```raku
$factor = 5;
say $scale(7); # 35
```

Замыкание захватывает саму *переменную*. Оно не захватывает значение, которое было в тот момент, когда блок написали. Поэтому более поздний вызов видит новый `$factor` и возвращает `35`.
