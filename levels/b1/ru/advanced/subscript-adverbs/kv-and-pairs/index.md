Другие наречия меняют **то, что** возвращает обращение по индексу. Обычно оно возвращает только значение, но эти наречия возвращают больше:

* `:v` — значение (по умолчанию)
* `:k` — ключ (или индекс)
* `:kv` — и ключ, и значение
* `:p` — пару (`Pair`) из ключа и значения

Для массива «ключом» является индекс:

```raku
my @a = 10, 20, 30;

say @a[1]:kv; # (1 20)
say @a[1]:p;  # 1 => 20
```

`@a[1]:kv` даёт индекс и значение вместе в виде списка. `@a[1]:p` даёт их в виде пары.

То же самое работает и для хешей. Это особенно удобно для среза сразу из нескольких ключей:

```raku
my %h = a => 1, b => 2, c => 3;

say %h<a c>:kv; # (a 1 c 3)
```

Здесь срез из двух ключей возвращает каждый ключ, а за ним его значение. `map`, `for` и похожие инструменты часто используют эти наречия. Они позволяют обрабатывать ключи и значения рядом, без отдельных обращений.
