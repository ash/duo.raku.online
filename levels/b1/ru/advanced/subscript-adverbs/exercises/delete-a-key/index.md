## Задача

Возьмите хеш `a => 1, b => 2, c => 3`. С помощью наречия для обращения по индексу удалите запись `b`. Затем напечатайте, сколько записей осталось, чтобы показать, что одна из них удалена.

## Пример

Программа выводит:

```
2
```
