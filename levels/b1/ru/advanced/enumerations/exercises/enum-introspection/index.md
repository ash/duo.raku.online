## Задача

Определите перечисление `Coin`. Его константы хранят свои значения в центах: `penny` равно 1, `nickel` равно 5, `dime` равно 10, а `quarter` равно 25. С помощью `.enums` напечатайте число констант в перечислении. Затем напечатайте сумму всех их значений.

## Пример

Программа печатает:

```
4
41
```
