У каждой константы перечисления есть и имя, и число. Метод `.value` возвращает число, а `.key` возвращает имя в виде строки:

```raku
enum Colour <red green blue>;

say green.value; # 1
say green.key;   # green
```

Вам не обязательно использовать автоматические номера от нуля. Чтобы выбрать значения самим, запишите константы в виде пар:

```raku
enum Day (Mon => 1, Tue => 2, Wed => 3, Thu => 4, Fri => 5);

say Tue.value; # 2
say Fri.value; # 5
```

Здесь рабочая неделя начинается с единицы вместо нуля.

Тип перечисления может и сам перечислить все свои константы. Его метод `.enums` возвращает отображение, которое связывает каждое имя с его значением:

```raku
enum Colour <red green blue>;

say Colour.enums;       # Map.new((blue => 2, green => 1, red => 0))
say Colour.enums.elems; # 3
```

Эти три метода, `.value`, `.key` и `.enums`, позволяют свободно двигаться. Можно перейти от константы к её числу и от числа обратно к данным. Можно также работать со всем набором. Именно поэтому перечисления полезны для таких вещей, как меню, состояния и таблицы соответствий.
