Чтобы объявить перечисление, напишите ключевое слово `enum`, имя и список имён констант:

```raku
enum Colour <red green blue>;
```

Теперь есть новый тип `Colour` с тремя константами: `red`, `green` и `blue`. Каждую константу можно использовать прямо по её имени:

```raku
say red;   # red
say green; # green
```

За каждым именем стоит число. Raku даёт эти числа автоматически, начиная с нуля, в порядке вашего списка. Поэтому `red` равно `0`, `green` равно `1`, а `blue` равно `2`. Так как у значений есть порядок, константы можно сравнивать:

```raku
say red < blue; # True
```

Переменной можно дать тип перечисления. Тогда она принимает только эти константы:

```raku
my Colour $c = green;
say $c; # green
```

Имя константы может совпасть с другим именем в вашей программе. Тогда к константе всегда можно обратиться через имя перечисления и `::`:

```raku
say Colour::red; # red
```

Перечисление даёт группе связанных констант имя и тип. Код, который их использует, гораздо понятнее, чем код с простыми числами. Следующая тема рассказывает о [числах, которые стоят за именами](/ru/advanced/enumerations/values-and-keys).
