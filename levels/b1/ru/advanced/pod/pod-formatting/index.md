Внутри текста Pod вы размечаете слова однобуквенными _кодами форматирования_. Вы пишете букву, а затем угловые скобки вокруг текста:

* `B<…>` — жирный
* `I<…>` — курсив
* `C<…>` — код (все буквы одинаковой ширины)
* `L<…>` — ссылка

```raku
=begin pod

This is B<important>, and C<say> is a built-in.

=end pod
```

После отрисовки `important` показан жирным шрифтом, а `say` — шрифтом для кода. Коды можно вкладывать друг в друга и сочетать, поэтому `B<C<say>>` — это жирный код.

Иногда нужен целый блок кода, а не просто кусочек внутри строки. Тогда используйте блок кода с понятными строками начала и конца, `=begin code … =end code`. Он сохраняет текст точно так, как он написан:

```raku
=begin pod

Here is how to call it:

=begin code
say greet('world');
=end code

=end pod
```

Строки внутри блока кода показываются точно так, как они написаны. Они не читаются как Pod. Вместе с кодами внутри строк и блоками кода Pod может описать API. В нём может быть форматированный текст и примеры, которые похожи на настоящий рабочий код. Всё это остаётся рядом с кодом, который оно описывает.
