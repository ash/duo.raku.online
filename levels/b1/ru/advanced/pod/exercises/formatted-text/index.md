## Задача

Напишите блок Pod с заголовком `=head1` `Greeting` и абзацем `Hello, world!`. В абзаце выделите слово `world` жирным с помощью `B<…>`. Отрисуйте блок как текст с помощью `raku --doc`.

> Запустите файл с `raku --doc`, чтобы увидеть форматированный текст.

## Пример

Когда вы отрисуете его с помощью `raku --doc`, получится:

```
Greeting

Hello, world!
```
