title: Скалярные контейнеры
---

{% include menu.html %}

Как говорит название, скалярные контейнеры хранят одиночные, или скалярные, значения. У этих контейнеров есть сигил `$`.

Вот очень простой и прямой способ использовать скаляр:

```raku
my $lang = 'Raku';
```

Переменная `$lang` — это скалярный контейнер.

По умолчанию скалярные контейнеры не ограничивают тип своих данных. Поэтому в них можно хранить значение любого типа. Вот самый простой способ это показать. Одну и ту же переменную можно использовать сначала для целого числа, а потом для строки:

```raku
my $value = 42;
$value = 'forty-two';
```

Автор не рекомендует вам писать программы таким образом.

Внутри это означает следующее. По умолчанию новый контейнер может хранить значения типа `Any`. `Any` — это базовый тип для большинства других типов, например `Int` или `Str`.
