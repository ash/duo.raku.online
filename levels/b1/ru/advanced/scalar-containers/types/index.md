Вот программа, которая использует одну переменную для разных видов данных. Мы используем `dd`, чтобы увидеть, что лежит в контейнере на каждом шаге. Этот пример только показывает идею. Мы не советуем так программировать.

```raku
my $value;
dd $value;

$value = 42;
dd $value;

$value = 'forty-two';
dd $value;
```

Каждый вызов `dd` показывает, что лежит в переменной `$value` в этот момент:

```
$value = Any
$value = 42
$value = "forty-two"
```

Сначала переменная пустая, и `dd` показывает её значение как `Any`. Это неопределённое базовое значение, с которого начинает любой контейнер без типа. После присваиваний `dd` показывает сначала целое число, а потом строку.

Обратите внимание, что здесь `dd` не печатает тип перед именем. Контейнер без типа не привязан ни к какому типу, поэтому показывается только значение. Следующая тема покажет, что [контейнер с объявленным типом](/ru/advanced/scalar-containers/type-constraints) ведёт себя иначе.
