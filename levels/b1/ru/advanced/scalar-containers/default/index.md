---
title: Значения по умолчанию
---

{% include menu.html %}

Иногда вы создаёте новую скалярную переменную и сразу ничего ей не присваиваете. Даже тогда контейнер содержит значение — значение по умолчанию. Какое именно это значение, зависит от типа переменной.

Следующая программа — не лучший способ использовать Raku. Но она показывает идею:

```raku
my $int;
say $int + 5;
```

В выводе есть `5`. Вы могли этого ждать, если думали, что значение по умолчанию у `$int` равно `0`. Но программа также печатает предупреждение:

```
Use of uninitialized value $int of type Any in numeric context
  in block <unit> at t.raku line 2
5
```

Чтобы было ясно, какое там значение, можно либо присвоить его самому:

```raku
my $int = 0;
say $int + 5; # 5
```

Либо можно задать значение по умолчанию трейтом `is default`:

```raku
my $int is default(0);
say $int + 5; # 5
```

Значение по умолчанию не обязано быть нулём. Это может быть любое значение, которое вы считаете удачным, например:

```raku
my $int is default(1);
say $int + 5; # 6
```
