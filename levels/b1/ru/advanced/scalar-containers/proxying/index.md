На самом деле скалярный контейнер — это объект типа `Scalar`. Чаще всего, когда вы используете скаляр, вы даже не замечаете контейнер. Вам не нужно о нём думать. Можно представить, что вы работаете прямо со значениями, которые в нём хранятся.

Это работает, потому что скалярный контейнер передаёт вызовы методов своему значению. Например, после `my $lang = 'Raku'` можно вызвать метод `.chars` для переменной:

```raku
my $lang = 'Raku';
say $lang.chars; # 4
```

Программа печатает `4` — число символов в строке `'Raku'`. Теперь вызовите `.chars` прямо для строкового значения, а не для переменной-контейнера. Результат точно такой же:

```raku
say 'Raku'.chars; # 4
```

Другими словами, контейнер незаметно передаёт вызов `.chars` строке внутри себя. Затем он возвращает вам результат.
