## Задача

Объявите рядом две скалярные переменные: `$untyped`, у которой нет типа, и `$typed`, у которой тип `Int`. Выведите обе с помощью `dd`, пока они ещё пустые. Затем присвойте каждой `42` и снова выведите обе. Внимательно посмотрите, как по-разному `dd` описывает два контейнера.

## Пример

Программа выводит это в стандартный поток ошибок:

```
$untyped = Any
Int $typed = Int
$untyped = 42
Int $typed = 42
```
