Вот одно возможное решение задачи.

## Код

```raku
my Int $cars;

$cars = 250.7.Int;
say $cars;
say $cars.WHAT;
```

🦋 Исходный код можно найти в файле [integers-only.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/scalar-containers/integers-only.raku).

## Вывод

```
250
(Int)
```

## Комментарии

1. Ограничение типа `Int` в `my Int $cars` заставляет контейнер отказываться от всех нецелых значений. Прямое присваивание `250.7`, значения типа `Rat`, дало бы ошибку компиляции.

1. Вызов `.Int` для рационального значения `250.7` превращает его в целое число `250`. Он просто отбрасывает дробную часть. Новое значение подходит для контейнера. Не путайте это с округлением.

1. Псевдометод `.WHAT` показывает, что значение в контейнере имеет тип `Int`.
