## Задача

Объявите контейнер `$cars`, который может хранить только целые числа.

У вас есть значение, которое получилось в расчётах по модели дорожного движения: `250.7`. Сохраните его в `$cars`. Сначала преобразуйте его в целое число, чтобы присваивание прошло. Затем выведите значение и его тип.

## Пример

Программа выводит:

```
250
(Int)
```
