## Задача

Объявите скалярную переменную `$discount` со значением по умолчанию `0`. Выведите переменную до того, как присвоите ей что-нибудь. Программа должна напечатать `0` и не выдать никаких предупреждений.

Затем присвойте переменной значение `15` и снова выведите её.

## Пример

Программа выводит две строки:

```
0
15
```
