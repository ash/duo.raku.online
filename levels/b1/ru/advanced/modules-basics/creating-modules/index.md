Когда программы растут, их полезно делить на части, которые можно использовать снова. Единица кода в отдельном файле называется _модулем_. Другие программы могут загружать и использовать его.

Файл модуля имеет расширение `.rakumod`. Он начинается с `unit module`, и эта строка даёт модулю имя. Подпрограммы внутри по умолчанию приватные. Чтобы поделиться одной из них с кодом, который использует модуль, пометьте её трейтом `is export`.

Вот модуль в файле под названием `Greeting.rakumod`:

```raku
unit module Greeting;

sub hello($name) is export {
    return "Hello, $name!";
}
```

У подпрограммы `hello` есть `is export`, поэтому её видит любая программа, которая использует модуль. Без `is export` подпрограмма осталась бы приватной для модуля.

Модуль также может делиться данными через переменные `our`. Другой код может обращаться к ним через имя модуля. Чтобы добавить номер версии в `Greeting`, достаточно ещё одной строки в файле:

```raku
our $version = '1.0';
```

Когда эта строка есть в `Greeting.rakumod`, значение доступно как `$Greeting::version`. Это работает везде, где загружен модуль.

Следующие темы показывают, [как программа загружает такой модуль](/ru/advanced/modules-basics/using-modules). Ещё они объясняют, что именно программа из него получает.
