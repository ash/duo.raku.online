Чтобы использовать модуль, загрузите его с помощью инструкции `use`. После этого имена, которые экспортирует модуль, становятся доступны. Их можно использовать так, как будто вы написали их сами.

Вот как программа использует файл `Greeting.rakumod` из предыдущей темы:

```raku
use Greeting;

say hello('Anna');
```

`hello` помечена как `is export`, поэтому инструкция `use` делает её доступной. Программа вызывает её напрямую:

```
Hello, Anna!
```

Raku может найти модуль, только если он есть в пути поиска модулей. Файл модуля может лежать в том же каталоге, что и ваша программа. В этом случае скажите Raku искать там с помощью опции `-I.`. Точка означает «текущий каталог»:

```console
$ raku -I. program.raku
Hello, Anna!
```

Raku находит установленные модули автоматически. О них мы расскажем позже, в разделе [Установка модулей из сети](/ru/advanced/installing-modules). Поэтому опция `-I` нужна только для модулей, которые лежат рядом с вашей программой.
