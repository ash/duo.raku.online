## Задача

У вас есть модуль в файле `Circle.rakumod`:

```raku
unit module Circle;

our $pi = 3.14;
```

Напишите программу, которая загружает этот модуль с помощью `need`, а не `use`. Она должна напечатать значение `$pi`. Помните, что `need` не импортирует имена. Поэтому до переменной нужно добираться через имя модуля.

## Пример

```console
$ raku -I. read-pi.raku
3.14
```
