## Задача

Создайте модуль с именем `Shouter` в файле `Shouter.rakumod`. Он должен экспортировать подпрограмму `shout`, которая возвращает свой аргумент в верхнем регистре.

Затем напишите отдельную программу, которая использует модуль и печатает `shout('hi')`.

## Пример

Если запустить её с модулем в пути поиска, программа печатает:

```console
$ raku -I. shout.raku
HI
```
