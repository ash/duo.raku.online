## Задача

Создайте модуль с именем `Maths` в файле `Maths.rakumod`. Он должен экспортировать подпрограмму `square`, которая возвращает квадрат своего аргумента.

Затем напишите отдельную программу, которая использует модуль и печатает `square(6)`.

## Пример

Если запустить её с модулем в пути поиска, программа печатает:

```console
$ raku -I. maths.raku
36
```
