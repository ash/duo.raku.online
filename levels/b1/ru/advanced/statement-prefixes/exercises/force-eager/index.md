## Задача

Префикс `eager` делает противоположное тому, что делает `lazy`. Он заставляет Raku создать весь список, поэтому список больше не ленивый. Покажите разницу с помощью `.is-lazy`.

Напечатайте, является ли бесконечный диапазон `1 .. Inf` ленивым. Затем напечатайте, ленивый ли `eager 1..3`, и наконец, ленивый ли `lazy 1..3`. Результаты должны быть `True`, `False`, `True`.

## Пример

Программа выводит:

```
True
False
True
```
