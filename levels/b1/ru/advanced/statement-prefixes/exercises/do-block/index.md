## Задача

`do` также работает перед управляющими конструкциями. Он превращает их в выражения, которые дают значение. Используйте `do if 7 > 5 { 'big' } else { 'small' }`, чтобы выбрать метку. Затем присвойте её переменной `$label` и напечатайте.

## Пример

Программа выводит:

```
big
```
