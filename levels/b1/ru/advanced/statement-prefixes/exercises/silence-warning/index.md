## Задача

`quietly` скрывает предупреждения и, как и `do`, возвращает значение своего блока. Объявите переменную для имени без значения. Затем соберите приветствие `"Hello, " ~ $name ~ "!"` внутри блока `quietly`. Это скрывает предупреждение «uninitialized value». Присвойте значение блока переменной `$greeting` и напечатайте его.

## Пример

Программа выводит:

```
Hello, !
```
