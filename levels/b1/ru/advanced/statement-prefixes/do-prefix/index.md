Блок сам по себе — это оператор, а не выражение. Поэтому обычно его нельзя присвоить переменной. Префикс `do` превращает блок в выражение. Значение этого выражения — значение **последнего** оператора блока:

```raku
my $x = do {
    my $a = 3;
    $a + 4;
};

say $x; # 7
```

Внутри блока можно объявлять переменные, выполнять несколько операторов и вычислять результат. Затем `do` возвращает значение блока. Это удобно, когда для получения значения нужно больше одного выражения.

`do` также работает перед управляющими конструкциями. Тогда они тоже могут возвращать значение:

```raku
my $sign = do given 5 {
    when * > 0 { 'positive' }
    when * < 0 { 'negative' }
    default    { 'zero' }
};

say $sign; # positive
```

Здесь `do given` превращает всю конструкцию `given`/`when` в выражение со значением `positive`. То же самое работает с `do if` и `do for`. Короче говоря, `do` позволяет использовать блок там, где ожидается значение. Это работает и для управляющей конструкции.
