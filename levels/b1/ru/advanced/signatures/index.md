В разделе "Основы" вы [определяли подпрограммы с позиционными и именованными параметрами](/ru/essentials/functions). Ещё вы задавали параметрам значения по умолчанию. Список параметров называется _сигнатурой_. В этом разделе показаны ещё две вещи, которые умеет сигнатура. Она может сделать параметр необязательным и может собрать любое количество дополнительных аргументов.

## Необязательные параметры

Параметр, после которого стоит знак вопроса, — _необязательный_. Это значит, что при вызове его можно не указывать. В этом случае параметр не определён. Поэтому ему можно дать запасное значение с помощью оператора defined-or `//`:

```raku
sub greet($name, $greeting?) {
    my $g = $greeting // 'Hello';
    say "$g, $name!";
}

greet('Anna');           # Hello, Anna!
greet('Anna', 'Hi');     # Hi, Anna!
```

Когда `greet` вызывается с одним аргументом, `$greeting` не определён. Поэтому `//` подставляет вместо него `'Hello'`.

## Поглощающие параметры

Параметр, помеченный символом `*`, — _поглощающий_ (slurpy). Он забирает все оставшиеся аргументы. Поглощающий массив, который пишется как `*@`, собирает любое количество позиционных аргументов в массив:

```raku
sub count-them(*@items) {
    say @items.elems;
}

count-them(1, 2, 3, 4); # 4
count-them('a', 'b');   # 2
```

Обычные параметры можно сочетать с поглощающим. Фиксированные параметры получают свои значения первыми. Всё, что осталось, попадает в поглощающий массив:

```raku
sub titles($name, *@titles) {
    say "$name has {@titles.elems} title(s)";
}

titles('Anna', 'Dr', 'Prof'); # Anna has 2 title(s)
```

Поглощающий хеш работает так же. Вы пишете его как `*%`, и он собирает все дополнительные именованные аргументы в хеш:

```raku
sub register($name, *%options) {
    say "$name: {%options.elems} option(s)";
    say "role is %options<role>";
}

register('Anna', role => 'admin', active => True);
```

Два именованных аргумента становятся ключами в `%options`, поэтому программа выводит:

```
Anna: 2 option(s)
role is admin
```
