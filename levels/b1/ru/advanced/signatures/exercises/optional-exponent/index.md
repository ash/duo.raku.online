## Задача

Напишите подпрограмму `power` с обязательным параметром `$base` и **необязательным** параметром `$exp`. Когда показатель степени передан, возведите основание в эту степень. Когда его нет, по умолчанию возведите основание в квадрат. Используйте оператор defined-or `//`, чтобы подставить `2`.

Вызовите её дважды. Сначала только с основанием, а потом с основанием и показателем степени.

## Пример

Программа выводит:

```
25
125
```
