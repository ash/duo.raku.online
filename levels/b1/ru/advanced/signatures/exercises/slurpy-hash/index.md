## Задача

Напишите подпрограмму `describe`, которая принимает обязательное позиционное имя. После него подпрограмма собирает любое количество именованных аргументов в поглощающий хеш (`*%opts`). Она должна возвращать строку вида `name: key=value, key=value, ...`. Строка перечисляет все опции, а ключи идут в алфавитном порядке.

Вызовите её как `describe('Anna', colour => 'red', size => 5)` и выведите результат.

## Пример

Программа выводит:

```
Anna: colour=red, size=5
```
