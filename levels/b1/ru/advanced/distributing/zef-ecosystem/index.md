`zef` — это установщик модулей Raku. Вы уже использовали его, чтобы устанавливать модули по имени. Он также работает с локальной директорией дистрибутива. Внутри дистрибутива его можно сразу протестировать и установить:

```
zef test .
zef install .
```

`zef test .` запускает файлы из `t/`. `zef install .` устанавливает дистрибутив в ваш Raku, чтобы другие программы могли загружать его через `use`. Установка по имени, как в `zef install Cro`, делает то же самое. Но сначала она скачивает дистрибутив из экосистемы.

Вы можете **опубликовать** свой дистрибутив, чтобы другие могли установить его по имени. Для этого его нужно загрузить в экосистему. Обычно для этого используют `fez`:

```
fez upload
```

Эта команда упаковывает текущий дистрибутив и отправляет его в экосистему Raku. После этого `zef install Maths::Simple` будет работать у всех.

> Для этих команд нужны установленные `zef`/`fez` и подключение к сети. Для загрузки также нужна учётная запись в экосистеме.

Итак, жизнь общего модуля состоит из трёх шагов. Вы готовите его структуру с `META6.json` и тестируете его с помощью `zef test`. Потом вы публикуете его через `fez upload`. С этого момента это просто ещё одно имя, которое любой может установить через `zef install`.
