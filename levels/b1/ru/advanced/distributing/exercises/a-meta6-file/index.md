## Задача

Напишите `META6.json` для дистрибутива `Greet::Simple` версии `0.0.1`. Он предоставляет модуль `Greet::Simple` из файла `lib/Greet/Simple.rakumod`. В примере из теории `depends` был пустым. На этот раз дистрибутив **зависит от** другого дистрибутива, `JSON::Fast`. Добавьте его в массив `depends`.

> Результат этого упражнения — файл, а не вывод программы.

## Пример

Правильный файл, где есть только нужные части, выглядит как файл в решении.
