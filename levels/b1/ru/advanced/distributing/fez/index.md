В предыдущей теме вы познакомились с `fez` — инструментом, который загружает дистрибутивы в экосистему Raku. Использовать `fez` не обязательно, потому что есть и другие способы публикации. Но чаще всего выбирают именно его. Кроме того, он умеет больше, чем просто загружать. Он может создать для вас новый дистрибутив и управлять вашей учётной записью автора. Установите его с помощью `zef`:

```
zef install fez
```

## Создание дистрибутива

Вы можете создать `META6.json` и каталоги `lib/` и `t/` вручную. Или можно позволить `fez` создать их за вас:

```
fez init My::Greeting
```

`fez init` создаёт новый дистрибутив, который можно развивать дальше. Это директория проекта с готовым `META6.json` и стандартной структурой. Поэтому вы можете сразу писать код в `lib/` и тесты в `t/`. Вам не нужно самим готовить файл метаданных.

## Регистрация и вход

Чтобы публиковать, нужна учётная запись в экосистеме. Вы создаёте её один раз командой `fez register`, которая спрашивает имя пользователя, email и пароль. Потом вы входите командой `fez login`. Она сохраняет ваш ключ, чтобы следующие команды знали, кто вы:

```
fez register
fez login
```

Ваше имя пользователя важно. В `META6.json` дистрибутива должно быть поле `auth` со значением `zef:<username>`. Так экосистема узнаёт, что загрузка действительно пришла от вас.

## Загрузка

Когда у вас есть учётная запись и дистрибутив готов, запустите `fez upload`. Эта команда упаковывает текущую директорию и отправляет её:

```
fez upload
```

После этого любой может установить его по имени с помощью `zef install My::Greeting`. Каждую версию можно загрузить только один раз. Поэтому не забудьте увеличить `version` в `META6.json`, прежде чем публиковать обновление.

## Другие полезные команды

Вот ещё несколько команд `fez`, которые вам понадобятся:

* `fez review` — проверить дистрибутив на возможные проблемы, прежде чем загружать его;
* `fez list` — показать дистрибутивы, которые вы уже опубликовали;
* `fez refresh` — заново собрать `META6.json` по файлам, которые сейчас есть на диске.

> Для всех этих команд нужны установленный `fez` и подключение к сети. Всем командам, кроме `init`, нужна ещё и учётная запись в экосистеме.
