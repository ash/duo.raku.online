У обычных скаляров, например чисел и строк, все три представления выглядят одинаково. Разница появляется у составных или неопределённых значений. Вот `Pair`, показанный тремя способами:

```raku
say (foo => 1).gist; # foo => 1
say (foo => 1).Str;  # foo	1
say (foo => 1).raku; # :foo(1)
```

Вот примерное общее правило:

* [`.gist`](../gist) — для вывода, который будут *читать* люди (`say`, `note`).
* [`.Str`](../str) — для вывода в виде *простого текста* (`print`, `put`, переменные внутри строк, оператор `~`).
* [`.raku`](../raku-method) — для формы, *похожей на код*, при отладке (`dd`).

Когда вы пишете класс, вы можете дать каждому из этих методов своё определение. Тогда и ваши собственные объекты будут печататься красиво. Мы вернёмся к этому, когда будем [создавать классы](/ru/oop/classes) в следующей части.
