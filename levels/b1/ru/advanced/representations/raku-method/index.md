---
title: Метод `.raku`
---

{% include menu.html %}

Третий метод представления — `.raku`. Он возвращает строку с представлением значения, **похожим на код**. В идеале эту строку можно вставить в программу и снова получить то же значение. Этот метод есть у каждого значения в Raku.

```raku
say 42.raku;        # 42
say 'Raku'.raku;    # "Raku"
say (1, 2, 3).raku; # (1, 2, 3)
```

Обратите внимание, что строка `'Raku'` возвращается с кавычками. Поэтому вы сразу видите разницу между числом и строкой. Именно такие детали нужны при отладке.

Метод работает и для составных данных, даже для вложенных структур:

```raku
my @data = 1, [2, 3], 4;
say @data.raku; # [1, [2, 3], 4]
```

Так как `.raku` возвращает обычную строку, его можно использовать везде, где ожидается строка. Например, его можно вставить в строку в двойных кавычках:

```raku
my @data = 10, 20, 30;
say "The data is { @data.raku }";
# The data is [10, 20, 30]
```

Используйте `.raku`, когда вам нужно представление, похожее на код, в виде строки. Тогда его можно соединить с вашими собственными сообщениями. Совсем скоро мы познакомим вас с `dd`. Этот инструмент Rakudo печатает такое же представление за вас за один шаг.
