---
title: Преобразование значений в текст
---

{% include menu.html %}

Когда программа показывает значение, она должна превратить его в текст. Так бывает, когда вы выводите значение через `say`, печатаете его или вставляете в строку. В Raku нет одного-единственного способа сделать это. Вместо этого у каждого значения есть несколько стандартных методов. Каждый из них делает строку для своей цели:

* `.gist` — форма, которую людям легко читать. Именно её печатает `say`.
* `.Str` — простая строковая форма для мест, где Raku нужна строка.
* `.raku` — форма, похожая на код, которая полезна при отладке.

Все три — обычные методы, которые есть у каждого значения в Raku. Поэтому они одинаково работают с числами, строками, массивами и вашими собственными объектами. Следующие страницы рассматривают каждый метод по очереди. Затем они помогут вам выбрать подходящий. [Следующий за ними раздел знакомит с `dd`](/ru/advanced/dd) — инструментом Rakudo, который построен на `.raku`.
