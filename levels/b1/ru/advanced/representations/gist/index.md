---
title: Метод `.gist`
---

{% include menu.html %}

Метод `.gist` возвращает **удобное для человека** представление значения. Это та форма, которую вам хотелось бы *прочитать*. `say` и `note` печатают именно её, потому что вызывают `.gist` для каждого аргумента.

```raku
say 42.gist;     # 42
say 'Raku'.gist; # Raku
```

Для простых значений gist — это просто само значение. Для составных данных `.gist` добавляет немного форматирования, чтобы структуру было легко читать:

```raku
my @a = 'alpha', 'beta', 'gamma';
say @a.gist; # [alpha beta gamma]
```

Типовой объект — это значение, которое обозначает сам тип. Его gist — это его имя в скобках. Благодаря этому его легко заметить в выводе:

```raku
say Int.gist; # (Int)
```
