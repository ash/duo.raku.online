## Задача

Отсортируйте слова `pear`, `fig`, `apple`, `kiwi` по их **длине**. Самое короткое должно идти первым, а самое длинное — последним. Используйте форму вызова с двоеточием. Передайте ключ сортировки как выражение Whatever, а не как блок. Выведите результат.

## Пример

Программа выводит:

```
(fig pear kiwi apple)
```
