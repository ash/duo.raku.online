Вот одно возможное решение.

## Код

```raku
say <a b c>.reverse.join: '-';
```

🦋 Исходный код можно найти в файле [colon-join.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/colon-calls/colon-join.raku).

## Вывод

```
c-b-a
```

## Комментарии

1. `.reverse` стоит в середине цепочки, поэтому остаётся в обычной форме. `join` идёт последним, поэтому может использовать двоеточие. Он передаёт `'-'` точно так же, как `join('-')`.

1. Развёрнутый список `c, b, a` затем соединяется дефисами, и получается `c-b-a`. Форма с двоеточием работает с обычными значениями, а не только с блоками.
