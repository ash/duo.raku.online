## Задача

Это выражение удваивает числа от `1` до `10`. Затем оно оставляет только те, что больше `10`:

```raku
(1..10).map(* * 2).grep(* > 10).say;
```

Перепишите код так, чтобы вызов `grep` использовал форму с двоеточием, а не скобки. Остальную часть цепочки не меняйте. Помните, что форма с двоеточием забирает весь остаток выражения. Поэтому использовать её может только последний вызов в цепочке.

## Пример

Программа выводит:

```
(12 14 16 18 20)
```
