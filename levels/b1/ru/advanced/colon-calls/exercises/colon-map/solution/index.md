Вот одно возможное решение.

## Код

```raku
say (1..10).map(* * 2).grep: * > 10;
```

🦋 Исходный код можно найти в файле [colon-map.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/colon-calls/colon-map.raku).

## Вывод

```
(12 14 16 18 20)
```

## Комментарии

1. Форма с двоеточием возможна только для `grep`, последнего вызова в цепочке. Двоеточие делает `* > 10` его аргументом, точно так же, как `grep(* > 10)`. Нам всё ещё нужно вывести результат. Поэтому теперь `say` используется как функция, а не как метод.

1. Вызов `map` должен сохранить свои скобки. Допустим, вы написали вместо этого `.map: * * 2`. Тогда двоеточие забрало бы и `.grep(* > 10)` как аргумент `map`. Поэтому цепочка сломалась бы.
