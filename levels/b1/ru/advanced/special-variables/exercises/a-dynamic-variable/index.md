## Задача

Динамическая переменная пишется с твигилом `*`. Raku находит её, когда ищет вверх по стеку вызовов, а не по лексической области видимости. Поэтому значение, которое видит подпрограмма, зависит от того, кто её вызвал. Так блок может запускать вызываемый им код от имени кого-то другого.

1. Объявите динамическую переменную `$*user` со значением `'guest'`.
2. Напишите подпрограмму `whoami`, которая выводит `running as ` и потом текущее значение `$*user` (например, `running as guest`). У неё нет параметров, поэтому она должна читать `$*user` напрямую.
3. Вызовите `whoami` один раз на верхнем уровне. Она показывает `guest`.
4. Потом создайте блок, который снова объявляет `$*user` как `'admin'`. Внутри него снова вызовите *ту же самую* `whoami`. Теперь она показывает `admin`.

## Пример

Программа выводит:

```
running as guest
running as admin
```
