## Задача

`$_` — это переменная *темы* (topic variable). Цикл `for` по очереди записывает в неё каждый элемент. Вызов метода вроде `.chars` начинается с точки, и перед ним нет объекта. Такой вызов работает с `$_`, поэтому `.chars` означает `$_.chars`.

Пройдите в цикле по трём строкам `'apple'`, `'fig'` и `'cherry'`. Для каждой из них выведите строку вида `<слово> has <n> letters`. Для слова используйте переменную темы `$_`. Для его длины используйте вызов `.chars` с точкой в начале. Посмотрите, как `$_` по очереди становится каждой строкой.

## Пример

Программа выводит:

```
apple has 5 letters
fig has 3 letters
cherry has 6 letters
```
