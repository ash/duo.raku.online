## Задача

Покажите, как динамическая переменная проходит через промежуточную подпрограмму. Эта подпрограмма ничего о ней не знает.

Напишите подпрограмму `log-it($msg)`, которая выводит сообщение, а перед ним динамическую переменную `$*prefix`. Напишите вторую подпрограмму `task`, которая только вызывает `log-it('working')`. Сама она никогда не упоминает `$*prefix`. Затем вызовите `task` дважды, каждый раз изнутри блока. Каждый блок задаёт `$*prefix` другое значение: сначала `INFO`, затем `DEBUG`.

## Пример

Программа выводит:

```
INFO: working
DEBUG: working
```
