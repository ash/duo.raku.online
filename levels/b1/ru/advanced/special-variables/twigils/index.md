title: Твигилы
---

{% include menu.html %}

_Твигил_ — это символ между сигилом и именем переменной. Он не меняет имя. Вместо этого он меняет то, как ведёт себя переменная и как Raku её находит. Вот самые распространённые из них:

* `*` — **динамическая** переменная, например `$*OUT`, которую Raku ищет по стеку вызовов
* `?` — значение **времени компиляции**, которое даёт компилятор, например `$?FILE` или `$?LINE`
* `!` — **приватный** атрибут объекта, например `$!balance`
* `.` — атрибут, к которому вы обращаетесь через его метод-аксессор, например `$.name`

Вы уже встречали несколько из них, но мы не называли их твигилами. Это динамические `$*OUT` и `$*IN`, а также `$!`/`$.` из [части об объектах](/ru/oop).

Компилятор заполняет переменные с `?`, пока компилирует вашу программу:

```raku
say $?LINE; # the line number of this statement
say $?FILE; # the path of this source file
```

Каждый твигил сразу показывает другой вид переменной. Когда вы читаете `$*foo`, вы сразу знаете, что это динамическая переменная. А `$?foo` — это константа времени компиляции. Следующая тема подробно рассматривает [динамические переменные](/ru/advanced/special-variables/dynamic-variables). Они ведут себя совсем иначе, чем лексические переменные, которые вы использовали до сих пор.
