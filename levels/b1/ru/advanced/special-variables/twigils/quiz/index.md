Какой твигил обозначает **динамическую** переменную, которую Raku находит по стеку вызовов?

{:.quiz}
1 | `*`
0 | `?`
0 | `!`
0 | `.`

{% include quiz.html %}

<div class="extended-explanation">

Твигил `*` обозначает динамическую переменную, например `$*OUT` или `$*greeting`. Твигил `?` нужен для значений времени компиляции, а `!` — для приватного атрибута. Твигил `.` нужен для аксессора атрибута.

</div>
