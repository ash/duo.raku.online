Raku определяет для вас набор переменных. Большинство из них _динамические_, с твигилом `*`. Поэтому их можно читать где угодно, как вы видели на примере [динамических переменных](/ru/advanced/special-variables/dynamic-variables). Их можно даже перекрыть для области видимости. Вот те, которые вам понадобятся чаще всего.

## Стандартные потоки

Ввод и вывод идут через три динамические переменные: `$*OUT` для стандартного вывода, `$*ERR` для стандартного потока ошибок и `$*IN` для стандартного ввода. `say` и `print` пишут в `$*OUT`. Чтобы отправить текст в стандартный поток ошибок, вызовите метод у `$*ERR`:

```raku
$*OUT.say('normal output'); # goes to standard output
$*ERR.say('a diagnostic');  # goes to standard error
```

Так как эти переменные динамические, можно перенаправить `$*OUT` в блоке. Тогда всё, что вы вызываете внутри этого блока, отправляет свой вывод в новое место. Вам не нужно менять этот код.

## Программа и её процесс

Несколько переменных дают информацию о самой запущенной программе:

```raku
say $*PROGRAM-NAME; # the path of the script being run
say $*PID;          # the process id of this program
say $*CWD;          # the current working directory
```

Их значения меняются при каждом запуске программы. Поэтому здесь нет постоянного вывода, который можно показать.

## Командная строка и окружение

Аргументы и окружение приходят в двух контейнерах, которые готовы к работе:

* `@*ARGS` — список аргументов командной строки (подпрограмма `MAIN` получает те же самые)
* `%*ENV` — переменные окружения в хэше

```raku
say @*ARGS.elems; # how many arguments were passed
say %*ENV<HOME>;  # the value of the HOME environment variable
```

Благодаря этим встроенным переменным вам не нужно самим собирать ту же информацию. Кроме того, они динамические, поэтому Raku ищет их по стеку вызовов. Поэтому любую встроенную переменную с `$*` можно перекрыть для области видимости. Это работает точно так же, как с вашей собственной переменной с `$*`.

Кроме этих динамических переменных, в Raku есть и встроенные переменные времени компиляции с твигилом `?`: `$?FILE` и `$?LINE`. Вы уже видели их на странице о [твигилах](/ru/advanced/special-variables/twigils).
