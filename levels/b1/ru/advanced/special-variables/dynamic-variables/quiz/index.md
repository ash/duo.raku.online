Что выведет следующая программа?

```raku
my $*n = 1;
sub show { say $*n }

sub run {
    my $*n = 2;
    show();
}

run();
```

{:.quiz}
0 | 1
1 | 2
0 | Nothing
0 | An error

{% include quiz.html %}

<div class="extended-explanation">

`show` написана на верхнем уровне, прямо рядом с `my $*n = 1`. Но это место не имеет значения. Raku ищет динамическую переменную по *стеку вызовов*. Где находится код, не важно. Здесь `show` вызывается из `run`, которая снова объявила `$*n` как `2`. Поэтому действует именно это значение, и программа выводит `2`.

</div>
