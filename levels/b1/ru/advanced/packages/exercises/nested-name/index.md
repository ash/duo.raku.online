## Задача

Поместите модуль `Inner` внутрь модуля `Outer`. В `Inner` объявите переменную `our` `$base` со значением `10`. Ещё объявите `our sub doubled`, которая возвращает `$base`, умноженную на два. Снаружи обоих модулей обратитесь к переменной по её полному вложенному имени. Подпрограмму тоже вызовите по её полному вложенному имени. Выведите оба результата.

## Пример

Программа выводит:

```
10
20
```
