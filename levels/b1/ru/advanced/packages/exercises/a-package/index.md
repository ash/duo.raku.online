## Задача

Создайте пакет `Temperature`, который объединяет две вещи. Первая — переменная `our` `$freezing` со значением `0`. Вторая — подпрограмма `our` `fahrenheit`, которая переводит значение по Цельсию в градусы Фаренгейта. Чтобы перевести, умножьте на 9/5 и прибавьте 32. Снаружи пакета выведите точку замерзания. Затем выведите значение `100` градусов Цельсия по Фаренгейту.

## Пример

Программа выводит:

```
0
212
```
