## Задача

Только `our` делает имя видимым за пределами пакета, а `my` оставляет его приватным. Создайте пакет `Config` с переменной `our` `$port`, равной `8080`. В тот же пакет **также** добавьте переменную `my` `$secret`, равную `42`. Снаружи выведите `$Config::port`. Затем выведите, определена ли `$Config::secret`. Она не должна быть определена, потому что переменная `my` не входит в пространство имён.

## Пример

Программа выводит:

```
8080
False
```
