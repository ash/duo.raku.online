Ключевое слово `package` создаёт пространство имён. Всё, что объявлено внутри него с `our`, становится частью этого пространства имён. Снаружи к этим именам можно обратиться через имя пакета и разделитель `::`:

```raku
package Maths {
    our $pi = 3.14;
    our sub double($x) { $x * 2 }
}

say $Maths::pi;         # 3.14
say Maths::double(5);   # 10
```

К переменной вы обращаетесь как `$Maths::pi`. Здесь идёт сигил, затем имя пакета, затем имя переменной. Подпрограмма вызывается как `Maths::double(...)`.

И `package`, и `module` создают пространство имён, но они различаются тем, что ещё они делают. `module` — обычный выбор для кода, который используют снова. Простой `package` — это только пространство имён, и ничего больше. `class`, с которым вы познакомитесь в [следующей части](/ru/oop), тоже создаёт пространство имён. Кроме того, он добавляет всё, что нужно для объектно-ориентированного программирования.

```raku
module Greet {
    our sub hello { 'hi' }
}

say Greet::hello; # hi
```

Итак, `module` даёт вам то же пространство имён, что и простой `package`. Какой из них выбрать, зависит в основном от того, что вы хотите сделать. Используйте `module` для библиотек, а `package` — для простого пространства имён. Позже, когда вы дойдёте до объектов, используйте `class` для типов.
