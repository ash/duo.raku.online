Именно декларатор `our` делает имя видимым в его пространстве имён. Переменная, объявленная с `my`, лексическая, то есть она приватная для своего блока. Переменная, объявленная с `our`, — это ещё и переменная пакета. К ней можно обратиться снаружи через путь `::`:

```raku
module Counter {
    our $count = 0;  # package variable
    my  $secret = 42; # lexical, not visible outside
}

say $Counter::count; # 0
```

`$Counter::count` работает, потому что `count` объявлена с `our`. А `$Counter::secret` вызвало бы ошибку, потому что `secret` — лексическая переменная.

Пространства имён могут быть **вложенными**, то есть одно может лежать внутри другого. Пакет внутри пакета даёт более длинный путь `::`:

```raku
module Outer {
    module Inner {
        our $val = 42;
    }
}

say $Outer::Inner::val; # 42
```

Полное имя `$Outer::Inner::val` ведёт из внешнего пространства имён во внутреннее. Оттуда оно ведёт к переменной. Именно так устроена стандартная библиотека: имена вроде `IO::Socket::INET` — это вложенные пространства имён. Ваши собственные модули тоже так собирают свои части под одним именем верхнего уровня.
