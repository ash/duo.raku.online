## Задача

`index` показывает, *где* находится символ. Затем `substr` позволяет разрезать строку в этом месте. Используйте эти два метода вместе.

Возьмите адрес электронной почты `user@example.com`. Найдите позицию знака `@`. Затем напечатайте всё, что идёт после него, — это доменная часть.

## Пример

Программа выводит:

```
example.com
```
