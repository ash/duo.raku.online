Есть несколько способов разделить строку на части и снова соединить их.

Метод `words` разделяет строку по пробельным символам на список слов:

```raku
say 'Hello big World'.words; # (Hello big World)
```

Метод `split` разделяет строку по разделителю, который вы выбираете:

```raku
say 'a,b,c'.split(','); # (a b c)
```

Важный особый случай — разделение по **пустой строке** `''`. Оно разделяет строку на отдельные символы. Но ещё оно добавляет пустую строку в самое начало и в самый конец. Поэтому в результате на два элемента больше, чем вы, может быть, ожидаете:

```raku
say 'abc'.split('').elems;        # 5 — the three letters, plus an empty string at each end
say 'abc'.split('', :skip-empty); # (a b c) — the :skip-empty adverb drops the empties
```

Чтобы разделить строку на символы, можно вызвать метод `comb` без аргументов. Он делает это напрямую, и лишних пустых строк, которые нужно убирать, нет:

```raku
say 'Raku'.comb; # (R a k u)
```

Для обратного действия используйте метод `join`. Он соединяет список значений в одну строку и ставит между ними разделитель:

```raku
say <a b c>.join('-'); # a-b-c
```

Ещё два метода работают с частями строки. Метод `substr` возвращает кусок строки. Вы передаёте ему начальную позицию и, если хотите, длину:

```raku
say 'Hello World'.substr(0, 5); # Hello
say 'Hello World'.substr(6);    # World
```

А `trim` удаляет пробельные символы в начале и в конце строки:

```raku
say '  hi  '.trim; # hi
```
