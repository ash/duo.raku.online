Вы можете использовать не только те модули, которые пишете сами. Сообщество Raku опубликовало большую коллекцию модулей. Среди них есть всё, от веб-фреймворков до форматов данных. Вы можете установить их и использовать в своих программах.

## Установщик `zef`

Модули устанавливают с помощью `zef` — стандартного менеджера модулей. Он идёт в комплекте с Rakudo. Чтобы установить модуль, передайте `zef` его имя:

```console
$ zef install JSON::Fast
```

`zef` скачивает модуль вместе со всем, от чего он зависит. Затем он запускает тесты модуля и устанавливает его. Установленный модуль автоматически попадает в путь поиска. Поэтому программа может загрузить его простым `use`. Опция `-I` не нужна:

```raku
use JSON::Fast;
```

`zef` также умеет искать в экосистеме. Ещё он может обновлять или удалять модули:

```console
$ zef search Test
$ zef uninstall JSON::Fast
```

## Откуда берутся модули

Опубликованные модули — это часть _экосистемы_ Raku. Её можно просмотреть на сайте [raku.land](https://raku.land). Там есть список доступных дистрибутивов и их документация.

## `META6.json`

В дистрибутиве для общего пользования есть файл описания под названием `META6.json`. В этом файле записаны имя и версия дистрибутива. Ещё там перечислены модули из дистрибутива и другие дистрибутивы, от которых он зависит. `zef` читает этот файл. Из него `zef` узнаёт, что устанавливать и как части связаны между собой. Если вы публикуете свой модуль, ему нужен правильный `META6.json`. Именно этот файл позволяет всем остальным установить ваш модуль.
