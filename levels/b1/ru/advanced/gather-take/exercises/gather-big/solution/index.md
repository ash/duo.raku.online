Вот одно возможное решение.

## Код

```raku
my $sum = 0;
my @result = gather for 1..100 {
    $sum += $_;
    last if $sum > 10;
    take $_;
}

say @result;
```

🦋 Исходный код можно найти в файле [gather-big.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/gather-take/gather-big.raku).

## Вывод

```
[1 2 3 4]
```

## Комментарии

1. Цикл получает диапазон из ста чисел, гораздо больше, чем он использует. Это нормально, потому что цикл останавливается сам. Как только `$sum` становится больше `10`, `last` выходит из цикла. Остальные числа так и не проверяются.

1. Порядок внутри блока важен. Сначала мы прибавляем к `$sum` и проверяем предел, а уже потом берём число. Поэтому число, из-за которого сумма становится больше `10` (здесь это `5`), не попадает в список. Сумма доходит ровно до `10` после `4`, поэтому список — `1, 2, 3, 4`.

1. С `for` пара `gather`/`take` может выйти раньше времени, а `grep` — нет. `grep` всегда проходит весь список, а здесь мы сами решаем, когда остановиться.
