Вот одно возможное решение.

## Код

```raku
my @squares = gather for 1..6 {
    take $_ ** 2 if $_ %% 2;
};

say @squares;
```

🦋 Исходный код можно найти в файле [squares.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/gather-take/squares.raku).

## Вывод

```
[4 16 36]
```

## Комментарии

1. Проверка `if $_ %% 2` решает, *брать ли* значение, а `$_ ** 2` решает, *что* брать. Эту проверку проходят только чётные числа `2`, `4`, `6`.

1. Их квадраты `4`, `16`, `36` — единственные значения, которые передаются в `take`. Поэтому `gather` собирает именно их. Здесь один `take` сразу и фильтрует, и меняет значения. Простой `map` не может выразить это так же ясно.
