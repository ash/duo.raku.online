## Задача

С помощью `gather` и `take` постройте список из чисел от `1` до `4`. Каждое число встречается в нём столько раз, сколько составляет его значение: `1` один раз, `2` два раза, `3` три раза и `4` четыре раза. Напечатайте список, который получится.

## Пример

Программа печатает:

```
[1 2 2 3 3 3 4 4 4 4]
```
