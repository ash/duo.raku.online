Вот одно возможное решение.

## Код

```raku
my @result = gather for 1..4 -> $n {
    take $n for 1..$n;
};

say @result;
```

🦋 Исходный код можно найти в файле [collect-the-evens.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/gather-take/collect-the-evens.raku).

## Вывод

```
[1 2 2 3 3 3 4 4 4 4]
```

## Комментарии

1. Нигде не сказано, что на каждом проходе должен быть только один `take`. Здесь внутренний `take $n for 1..$n` выполняет `take` разное число раз на каждом проходе. Именно эта гибкость делает `gather`/`take` мощнее простого `map`.

1. Внешний цикл специально использует именованную переменную, `-> $n`. Допустим, мы использовали бы `$_` во внутреннем цикле. Тогда внутренний `for` записал бы в `$_` свой счётчик. И мы брали бы счётчик вместо текущего числа.

1. `gather` просто собирает по порядку все взятые значения. Поэтому `@result` содержит `1`, затем два `2`, затем три `3`, затем четыре `4`.
