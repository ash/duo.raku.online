В Raku есть встроенные типы для календарных дат и времени. Календарная дата имеет тип `Date`. Чтобы создать её, вы указываете год, месяц и день:

```raku
my $d = Date.new(2026, 6, 27);
say $d; # 2026-06-27
```

Когда у вас есть дата, вы можете прочитать её части:

```raku
my $d = Date.new(2026, 6, 27);
say $d.year;  # 2026
say $d.month; # 6
say $d.day;   # 27
```

Метод `day-of-week` сообщает, на какой день недели приходится дата. Он даёт число от `1` для понедельника до `7` для воскресенья:

```raku
say Date.new(2026, 6, 27).day-of-week; # 6
```

27 июня 2026 года — суббота, поэтому результат равен `6`.

Метод `is-leap-year` проверяет, високосный ли год у этой даты:

```raku
say Date.new(2024, 1, 1).is-leap-year; # True
say Date.new(2026, 1, 1).is-leap-year; # False
```

Вызовите `Date.today`, чтобы получить сегодняшнюю дату. Её результат здесь не показан. Он зависит от того, в какой день вы запускаете программу.
