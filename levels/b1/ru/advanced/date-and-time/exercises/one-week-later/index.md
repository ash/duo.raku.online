## Задача

Возьмите дату 28 февраля 2027 года. Напечатайте дату ровно через неделю после неё. Вместо оператора `+` используйте метод `later` с нужным именованным аргументом. На следующей строке напечатайте также номер дня недели этой новой даты.

## Пример

Программа печатает:

```
2027-03-07
7
```
