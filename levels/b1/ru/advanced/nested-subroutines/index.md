Подпрограмму можно определить _внутри_ другой подпрограммы. Такая вложенная подпрограмма — обычная подпрограмма. Но она видна только внутри той подпрограммы, в которой находится.

```raku
sub outer {
    sub inner {
        say 'I am the inner subroutine';
    }

    inner;
}

outer;
```

Программа выводит:

```
I am the inner subroutine
```

Здесь `inner` объявлена внутри `outer`, и `outer` её вызывает. Это работает, потому что `inner` можно использовать в любом месте тела `outer`.

Но за пределами `outer` никакого имени `inner` нет. Поэтому следующая программа не компилируется:

```raku
sub outer {
    sub inner { 42 }
}

inner; # error: Undeclared routine: inner
```

Вложенность полезна, когда вспомогательная подпрограмма нужна только одной подпрограмме. Если держать её внутри, понятно, что это внутренняя деталь. Кроме того, никто не сможет случайно вызвать её из другого места.
