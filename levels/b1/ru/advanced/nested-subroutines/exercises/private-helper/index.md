## Задача

Напишите подпрограмму `stats`, внутри которой есть **вложенная** вспомогательная подпрограмма `double`. Она возвращает свой аргумент, умноженный на два. Внутри `stats` используйте её, чтобы вывести значение `double(3) + double(5)`.

Затем вызовите `stats`.

## Пример

Программа выводит:

```
16
```
