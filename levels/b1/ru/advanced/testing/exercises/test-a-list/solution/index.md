Вот одно возможное решение.

## Код

```raku
use Test;

plan 2;

my @sorted = (3, 1, 2).sort;
is-deeply @sorted, [1, 2, 3], 'sorted';

is 10 % 3, 1, 'remainder';
```

🦋 Исходный код можно найти в файле [test-a-list.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/testing/test-a-list.raku).

## Вывод

```
1..2
ok 1 - sorted
ok 2 - remainder
```

## Комментарии

1. `plan 2` указывает количество до запуска любого теста, поэтому строка `1..2` идёт первой. Если бы файл потом выполнил другое число проверок, набор тестов не прошёл бы. `done-testing` не может дать вам такую защиту.

1. `is-deeply` проверяет, что два списка точно равны, включая их типы. Сортировка `3, 1, 2` даёт `1, 2, 3`, и это совпадает.

1. `is` проверяет два значения на простое равенство. Если тест не проходит, он показывает оба значения. Здесь `10 % 3` равно `1`, и это ожидаемое значение. Поэтому второй тест тоже проходит.
