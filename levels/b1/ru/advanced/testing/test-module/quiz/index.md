Какая функция в модуле `Test` проходит, когда логическое условие истинно?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` принимает условие и проходит, когда оно истинно. `is` сравнивает фактическое значение с ожидаемым. `plan` говорит, сколько тестов ожидать. `done-testing` завершает файл и печатает план.

</div>
