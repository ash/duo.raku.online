В Raku есть фазеры для всей программы, но есть и другие. Эти фазеры связаны с жизнью отдельного блока или цикла.

## Вход и выход из блока

Фазер `ENTER` выполняется каждый раз, когда программа входит в блок. Фазер `LEAVE` выполняется каждый раз, когда она выходит из блока. Неважно, на какой строке вы их напишете:

```raku
say 'before block';
{
    LEAVE say 'leaving';
    ENTER say 'entering';
    say 'inside';
}
say 'after block';
```

Вывод показывает, что `ENTER` выполняется первым, а `LEAVE` — последним. Тело блока выполняется между ними:

```
before block
entering
inside
leaving
after block
```

`LEAVE` особенно полезен, потому что он выполняется, даже если блок заканчивается раньше времени. Поэтому это надёжное место, чтобы освободить ресурс.

Фазер может принимать целый блок `{ }` вместо одного выражения. Можно также задать несколько фазеров. Если в блоке больше одного `LEAVE`, они выполняются в обратном порядке. Тот, что был задан последним, выполняется первым. Так блок работает как стек, сверху вниз:

```raku
say 'open A';
{
    LEAVE {
        say 'close A';
    }
    say 'open B';
    LEAVE {
        say 'close B';
    }
    say 'work';
}
say 'done';
```

Программа открывает ресурс `A` первым и закрывает его последним:

```
open A
open B
work
close B
close A
done
```

Порядок «последним пришёл — первым ушёл» — как раз то, что нужно для очистки. То, что вы настроили последним, убирается первым. Фазер `END` всей программы работает так же. Несколько блоков `END` тоже выполняются в порядке, обратном тому, в котором они написаны.

## Фазеры цикла

Внутри циклов есть ещё три фазера для этапов цикла. `FIRST` выполняется один раз перед первым проходом, а `LAST` — один раз после последнего. `NEXT` выполняется в конце каждого прохода:

```raku
for 1..3 {
    FIRST say '-- first';
    LAST  say '-- last';
    NEXT  say "-- next (was $_)";
    say "body $_";
}
```

Вот что выводит цикл:

```
-- first
body 1
-- next (was 1)
body 2
-- next (was 2)
body 3
-- next (was 3)
-- last
```

Как и другие фазеры, `FIRST`, `NEXT` и `LAST` могут стоять в любом месте кода. Каждый из них выполняется в свой момент.
