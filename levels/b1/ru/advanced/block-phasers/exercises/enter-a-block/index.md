## Задача

`FIRST` выполняется только один раз, а фазер `ENTER` — *каждый раз*, когда программа входит в блок. А цикл входит в своё тело заново на каждом проходе.

Напишите цикл по `1..2`. Внутри цикла поставьте фазер `ENTER`, который печатает `--entering`. Добавьте также обычное выражение, которое печатает `body` и текущее число. Обратите внимание, что `--entering` появляется один раз на каждом проходе цикла.

## Пример

Программа выводит:

```
--entering
body 1
--entering
body 2
```
