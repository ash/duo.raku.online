## Задача

Фазер `NEXT` выполняется в *конце* каждого прохода цикла. Это удобный момент, чтобы сообщить о прогрессе.

Храните в `$sum` сумму, которая растёт во время работы цикла. Вначале она равна `0`. Пройдите циклом по `1..3` и на каждом проходе сначала прибавляйте текущее число к `$sum`. Затем с помощью фазера `NEXT` печатайте `sum so far: $sum` после каждого прохода.

Обратите внимание на порядок. Фазер `NEXT` выполняется после тела. Поэтому сумма, которую он показывает, *включает* текущее число.

## Пример

Программа выводит:

```
sum so far: 1
sum so far: 3
sum so far: 6
```
