## Задача

Напишите две мульти-подпрограммы `abs-value`, которые принимают целое число и возвращают его абсолютное значение. Используйте конструкцию `where`, чтобы отдельно обработать отрицательные числа. Не используйте никаких `if` внутри подпрограмм. Встроенную функцию `abs` тоже не используйте.

Напечатайте результат для `-7` и для `4`.

## Пример

Программа печатает:

```
7
4
```
