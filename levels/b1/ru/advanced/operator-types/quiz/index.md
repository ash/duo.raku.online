К какой категории относится обращение по индексу `[0]` в выражении `@a[0]`?

{:.quiz}
0 | postfix
1 | postcircumfix
0 | circumfix
0 | infix

{% include quiz.html %}

<div class="extended-explanation">

Обращение по индексу ставит скобки вокруг своего содержимого *и* идёт после терма, здесь `@a`. Поэтому это постциркумфиксный оператор. У простого постфикса вроде `++` нет никаких скобок. Циркумфикс, например конструктор массива `[1, 2, 3]`, стоит вокруг чего-то. Но он не идёт после терма.

</div>
