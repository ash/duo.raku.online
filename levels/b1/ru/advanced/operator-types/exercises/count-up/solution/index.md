Вот одно возможное решение задачи.

## Код

```raku
my $n = 9;

say $n++;
say $n;
```

🦋 Исходный код можно найти в файле [count-up.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operator-types/count-up.raku).

## Вывод

```
9
10
```

## Комментарии

1. `++` — это постфиксный оператор, то есть он стоит после своего операнда. В выражении `$n++` сначала даёт *старое* значение `9`. Именно его выводит `say`. Только потом он увеличивает переменную.

1. Вторая строка показывает, что `$n` действительно стало равно `10`. Префиксная форма `++$n` сначала прибавила бы единицу, а потом вернула бы `10`.
