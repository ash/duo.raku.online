Вы уже использовали много операторов, например `+`, `~` и `++`. Операнды — это значения, с которыми работает оператор. В Raku операторы делят на категории по тому, _где_ они стоят рядом со своими операндами. Знание категорий поможет вам позже, когда вы будете создавать свои операторы.

## `prefix`

Префиксный оператор стоит _перед_ своим единственным операндом:

```raku
my $x = 5;
say -$x; # -5
say ?$x; # True
```

Здесь `-` меняет знак числа. Оператор `?` превращает значение в булево.

## `infix`

Инфиксный оператор стоит _между_ двумя операндами. Так работает большинство знакомых вам арифметических и строковых операторов:

```raku
say 3 + 4;       # 7
say 'a' ~ 'b';   # ab
```

Инфиксный оператор не обязательно должен быть символом. Он может быть и словом. Например, оператор `gcd` из раздела о [целых числах](/ru/advanced/integers) — инфиксный оператор. Это имя, которое вы пишете между двумя его операндами:

```raku
say 12 gcd 18;   # 6
```

## `postfix`

Постфиксный оператор стоит _после_ своего единственного операнда:

```raku
my $x = 5;
$x++;
say $x; # 6
```

## `circumfix` и `postcircumfix`

Циркумфиксный оператор стоит _вокруг_ своего операнда. Пример — квадратные скобки, которые создают массив:

```raku
my @a = [1, 2, 3];
```

Постциркумфиксный оператор тоже стоит вокруг чего-то, но идёт после терма. Обращение по индексу, например `[1]` после `@a`, — это постциркумфиксный оператор:

```raku
my @a = 10, 20, 30;
say @a[1]; # 20
```

Вот названия категорий: `prefix`, `infix`, `postfix`, `circumfix` и `postcircumfix`. Как вы увидите позже, Raku использует те же слова, чтобы [объявить новый оператор](/ru/advanced/user-defined-operators).
