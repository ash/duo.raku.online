title: Массивы

Массив — это упорядоченный контейнер, и его элементы — тоже скалярные контейнеры.

```raku
my @array = 100, 200, 300;
my @letters = 'a', 'b', 'c';
```

Сигил `@` означает, что такая переменная ведёт себя как объект `Positional`. Это позволяет читать отдельные элементы по индексу:

```raku
say @array[1];   # 200
say @letters[2]; # c
```

Каждый элемент — это скалярный контейнер, поэтому ему можно присвоить новое значение. Вы делаете это так же, как с отдельной скалярной переменной:

```raku
my @array = 100, 200, 300;
@array[0] = 10;
say @array; # [10 200 300]
```

Можно также присвоить значение другого типа, например:

```raku
my @array = 100, 200, 300;
@array[0] = 'ten';
say @array; # [ten 200 300]
```

Именно это делает массивы _изменяемыми_, то есть их можно менять. Каждая ячейка — это контейнер, который может получить новое значение. В следующей теме вы увидите, что [списки](/ru/advanced/ordered-containers/lists) ведут себя иначе.
