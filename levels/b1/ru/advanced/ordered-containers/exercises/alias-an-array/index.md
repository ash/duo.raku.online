## Задача

У вас есть такой массив:

```raku
my @original = 10, 20, 30;
```

Создайте второе имя, `@alias`, для _того же самого_ массива, не копируя его. На этот раз добавьте новый элемент в `@original` с помощью `push`, а потом напечатайте `@alias`. Это покажет, что псевдоним видит изменения не только в значениях, но и в структуре.

## Пример

Программа печатает:

```
[10 20 30 40]
```
