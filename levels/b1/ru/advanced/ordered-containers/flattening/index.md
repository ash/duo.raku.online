Если вы кладёте один массив в другой, Raku сам _не_ объединяет их элементы. Посмотрите на эту программу:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;
my @c = @a, @b;

say @c.elems; # 2
say @c;       # [[1 2 3] [4 5]]
```

В массиве `@c` только два элемента — массивы `@a` и `@b`. Raku хранит каждый контейнер как один элемент. Он не распаковывает его содержимое во внешний массив. То же самое происходит, когда вы ставите массив среди других значений:

```raku
my @a = 1, 2, 3;
my @d = 0, @a, 99;
say @d; # [0 [1 2 3] 99]
```

Если вам действительно нужна одна плоская последовательность, попросите её прямо с помощью функции `flat`:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat(@a, @b);       # (1 2 3 4 5)
say flat(@a, @b).elems; # 5
```

## Упаковка в элемент (Itemisation)

Иногда нужно обратное. Вы хотите защитить контейнер от разворачивания, даже внутри `flat`. Конструкция `$(...)` _упаковывает_ свой аргумент. Это значит, что она помечает результат как один элемент. Сравните предыдущий пример с этим:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat($(@a), @b); # ([1 2 3] 4 5)
```

Здесь `$(@a)` сохраняет `@a` как один элемент. Но `@b` всё равно разворачивается в свои два значения. Это снова идея сигила `$`. Знак `$` означает «рассматривать это как одну вещь».
