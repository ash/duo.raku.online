---
title: Привязка с помощью `:=`
---

{% include menu.html %}

До сих пор каждая созданная вами переменная получала новый контейнер. Присваивание через `=` помещало значение _в_ этот контейнер. Привязка, которая пишется как `:=`, работает иначе. Она делает имя ссылкой на _уже существующий_ контейнер, а не создаёт новый.

После привязки оба имени делят один и тот же контейнер. Поэтому изменение через одно имя видно и через другое:

```raku
my $x = 10;
my $y := $x;

$x = 20;
say $y; # 20
```

Здесь `$y := $x` не копирует значение `10`. Вместо этого `$y` становится другим именем для того же самого контейнера, что и `$x`. Позже, когда `$x` получает значение `20`, `$y` тоже даёт `20`.

Теперь сравните это с обычным присваиванием. Оно копирует значение в отдельный контейнер:

```raku
my $x = 10;
my $y = $x; # обычная копия

$x = 20;
say $y; # 10
```

Привязка работает также с массивами. Этот код делает `@alias` другим именем для `@data`:

```raku
my @data = 1, 2, 3;
my @alias := @data;

@alias[0] = 99;
say @data; # [99 2 3]
```

Ещё одна деталь. Если привязать имя прямо к литеральному значению, за ним не будет контейнера. Поэтому имя становится доступным только для чтения:

```raku
my $pi := 3.14;
$pi = 3;
```
