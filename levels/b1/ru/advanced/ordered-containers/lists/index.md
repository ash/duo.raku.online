title: Списки
---

Список — это тоже упорядоченный набор значений. Но, в отличие от массива, он _неизменяем_. Это значит, что его элементы нельзя менять, добавлять или удалять. Список записывают как значения с запятыми между ними, часто в круглых скобках:

```raku
my $colours = ('red', 'green', 'blue');
```

Элементы списка можно читать по индексу, как и у массива. Также можно узнать, сколько их:

```raku
my $colours = ('red', 'green', 'blue');
say $colours[0];    # red
say $colours.elems; # 3
```

Разницу видно, когда вы пытаетесь изменить элемент. С массивом это работает, потому что каждый элемент — это контейнер:

```raku
my @array = 1, 2, 3;
@array[0] = 10;
say @array; # [10 2 3]
```

Со списком вы получите ошибку. Элементы списка — это просто значения, а не контейнеры:

```raku
my $list = (1, 2, 3);
$list[0] = 10;
```

Вторая программа завершится с сообщением:

```
Cannot modify an immutable List ((1 2 3))
  in block <unit> at t.raku line 2
```

Итак, используйте массив, с сигилом `@`, когда вам нужно менять его содержимое. Используйте список, когда нужно только хранить фиксированную последовательность значений.
