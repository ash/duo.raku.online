Какой типаж позволяет подпрограмме **изменять переменную вызывающей стороны** через параметр?

{:.quiz}
1 | `is rw`
0 | `is copy`
0 | `is default`
0 | ни один — параметры по умолчанию доступны для записи

{% include quiz.html %}

<div class="extended-explanation">

По умолчанию параметр доступен только для чтения, поэтому обычному параметру нельзя ничего присвоить. `is rw` привязывает параметр к самой переменной вызывающей стороны. Поэтому изменение внутри подпрограммы видно и снаружи. `is copy` вместо этого дал бы вам *копию*, которую можно менять. Переменная вызывающей стороны осталась бы нетронутой.

</div>
