_Типаж_ добавляется с помощью ключевого слова `is` сразу после объявления. Он выполняется во время компиляции. Он меняет фиксированное свойство того, к чему относится. В Raku есть много типажей, и некоторые вы уже использовали.

По умолчанию параметры подпрограммы доступны **только для чтения**. Внутри подпрограммы им нельзя ничего присвоить. Типаж `is copy` даёт вам личную копию аргумента, которую можно менять. Это изменение не затрагивает вызывающую сторону:

```raku
sub greet($name is copy) {
    $name = "dear $name";
    say "Hello, $name!";
}

my $who = 'Anna';
greet($who); # Hello, dear Anna!
say $who;    # Anna — the caller's own variable is untouched
```

Типаж `is rw` идёт дальше. Он привязывает параметр к переменной вызывающей стороны. Поэтому изменение внутри подпрограммы видно и снаружи:

```raku
sub bump($n is rw) {
    $n++;
}

my $x = 10;
bump($x);
say $x; # 11
```

Без одного из этих типажей `$n++` вызвало бы ошибку. Параметр был бы доступен только для чтения.

Другой распространённый типаж задаёт значение по умолчанию:

```raku
my $port is default(8080);
say $port; # 8080
```

Здесь `is default` даёт переменной значение, которое используется, когда другого значения нет. Есть много встроенных типажей, например `is rw`, `is copy` и `is default`. Каждый из них добавляет к объявлению одно определённое поведение во время компиляции. Следующая тема показывает, что набор типажей не закрыт. [Вы можете определить собственные](/ru/advanced/traits-pragmas/writing-a-trait).
