## Задача

Прагма `strict` в Raku включена по умолчанию. Это значит, что каждую переменную нужно объявить с помощью `my`, прежде чем её использовать. Отключите прагму с помощью `no strict`. Затем *без* всякого `my` присвойте `10` переменной `$a` и `20` переменной `$b`. Выведите их сумму.

## Пример

Программа выводит:

```
30
```
