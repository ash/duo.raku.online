Вот одно возможное решение.

## Код

```raku
no strict;

$a = 10;
$b = 20;
say $a + $b;
```

🦋 Исходный код можно найти в файле [no-strict.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/traits-pragmas/no-strict.raku).

## Вывод

```
30
```

## Комментарии

1. `no strict` выключает правило, по которому переменные нужно объявлять. Поэтому переменным `$a` и `$b` можно присвоить значения без `my`. С включённой по умолчанию `strict` каждая из этих строк вызвала бы ошибку компиляции.

1. После присваивания переменные ведут себя как обычно, поэтому `$a + $b` равно `30`. Это ослабленное правило лексическое. Оно действует только до конца области видимости, в которой стоит `no strict`.

1. Это только демонстрация, и мы не советуем так делать на практике. `strict` включена по умолчанию не зря. Она ловит опечатки в именах переменных во время компиляции. В настоящем коде оставляйте её включённой и объявляйте переменные с помощью `my`.
