## Задача

Пользовательский типаж может принимать аргумент. Он не обязан просто присутствовать или отсутствовать. Напишите типаж `is role(...)`, который принимает строку. Он записывает роль каждой подпрограммы в хеш. Ключ в хеше — это имя подпрограммы.

Примените `is role('admin')` к подпрограмме `login`. Затем выведите роль, которая сохранена для `login`.

## Пример

Программа выводит:

```
admin
```
