## Задача

По умолчанию параметры подпрограммы доступны только для чтения. Это значит, что подпрограмма не может изменить переменную вызывающей стороны. Типаж `is rw` снимает это ограничение.

Напишите подпрограмму `double` с одним параметром, который помечен `is rw`. Подпрограмма удваивает параметр на месте с помощью `$n *= 2`. Вызовите её с переменной, которая содержит `21`. Затем выведите переменную, чтобы показать, что она стала равна `42`.

## Пример

Программа выводит:

```
42
```
