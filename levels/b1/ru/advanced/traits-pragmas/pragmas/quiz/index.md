Прагма `strict` в Raku включена по умолчанию. Что произойдёт, если присвоить значение переменной, которую вы никогда не объявляли, как в `$x = 42`?

{:.quiz}
1 | Это ошибка времени компиляции
0 | Он молча создаёт `$x`
0 | Он выводит предупреждение, но работает
0 | Он устанавливает `$x` в `Nil`

{% include quiz.html %}

<div class="extended-explanation">

`strict` включена по умолчанию. Она требует сначала объявлять каждую переменную с помощью `my`. Поэтому `$x = 42` без `my` не компилируется. Ошибка: *Variable '$x' is not declared*. Если выключить прагму с помощью `no strict`, присваивание сработает.

</div>
