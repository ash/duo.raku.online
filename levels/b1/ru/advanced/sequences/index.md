_Последовательность_ — это ряд значений по порядку, которые создаются одно за другим. Raku строит последовательности с помощью оператора `...`. Он находит закономерность в значениях, которые вы ему даёте. Затем он создаёт остальные значения, до конечной точки.

Самая простая последовательность просто считает от одного значения до другого:

```raku
say 1 ... 5; # (1 2 3 4 5)
```

Если дать два начальных значения, Raku найдёт шаг между ними. Потом он продолжит с тем же шагом. Так создаётся арифметическая последовательность:

```raku
say 1, 3 ... 11; # (1 3 5 7 9 11)
```

Здесь начальные значения `1, 3` дают шаг, равный двум. Поэтому Raku считает через два и останавливается, когда доходит до `11`.

Значение, которое создаёт `...`, имеет тип `Seq`:

```raku
say (1 ... 5).WHAT; # (Seq)
```

Следующие темы показывают другие закономерности, которые умеет находить оператор `...`. Ещё они показывают, как последовательность может быть ленивой и даже бесконечной.
