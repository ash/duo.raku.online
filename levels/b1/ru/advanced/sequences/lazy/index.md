Последовательности не нужно вычислять все свои значения сразу. Последовательности в Raku _ленивые_: каждое значение создаётся, только когда оно действительно нужно. Поэтому можно описать последовательность, у которой вообще нет конца.

Чтобы записать бесконечную последовательность, используйте `Inf` как конечную точку. Оператор `...` связывает слабее, чем `=`, поэтому Raku сначала выполнил бы `=`. Вот почему последовательность нужно взять в скобки:

```raku
my $naturals = (1 ... Inf);
```

Без скобок `my $naturals = 1 ... Inf` присвоил бы переменной только `1`. Потом он отдельно построил бы последовательность. Если вычислять бесконечную последовательность, которую никто не использует, программа зависнет.

Пока ничего не вычислено. Последовательность выдаёт значения, только когда вы их просите. Метод `head` берёт первые несколько из них:

```raku
say (1 ... Inf).head(5); # (1 2 3 4 5)
```

Последовательность бесконечна, но создаются только первые пять чисел. Без ленивости программа пыталась бы построить всю бесконечную последовательность. Такая программа никогда бы не закончилась.

Если последовательность конечна, метод `tail` может брать значения с её конца:

```raku
say (1 ... 100).tail(3); # (98 99 100)
```

Ленивость позволяет разделить две вещи. Первая — это _описание_ последовательности. Вторая — решение о том, какую её часть использовать.
