Вот одно возможное решение задачи.

## Код

```raku
say (5, 10 ... 50).tail(3);
```

🦋 Исходный код можно найти в файле [last-three.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/sequences/last-three.raku).

## Вывод

```
(40 45 50)
```

## Комментарии

1. Начальные значения `5, 10` задают арифметический шаг пять. Последовательность идёт до своей конечной точки `50`.

1. `tail(3)` возвращает последние три значения конечной последовательности: `40, 45, 50`. Так же `head` вернул бы первые несколько значений.
