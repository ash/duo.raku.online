Когда в выражении несколько операторов, Raku должен решить, в каком порядке их применять. Это определяют два правила: _приоритет_ и _ассоциативность_.

## Приоритет

Приоритет определяет, какой оператор сильнее, то есть какой из них связывается теснее. У умножения приоритет выше, чем у сложения, поэтому оно выполняется первым:

```raku
say 2 + 3 * 4; # 14
```

Raku читает выражение как `2 + (3 * 4)`, поэтому результат — `14`, а не `20`. Чтобы получить другой порядок, всегда можно использовать скобки:

```raku
say (2 + 3) * 4; # 20
```

## Ассоциативность

Ассоциативность определяет порядок, когда у операторов _одинаковый_ приоритет. Вычитание левоассоциативно, то есть оно группируется слева:

```raku
say 8 - 3 - 2; # 3
```

Это `(8 - 3) - 2`, что даёт `3`. А вот возведение в степень правоассоциативно:

```raku
say 2 ** 3 ** 2; # 512
```

Здесь выражение группируется как `2 ** (3 ** 2)`. Это `2 ** 9`, что даёт `512`.

## Цепочки сравнений

Операторы сравнения можно _объединять в цепочки_. Это читается естественно и работает так, как вы ожидаете по математике:

```raku
say 1 < 2 < 3; # True
say 1 < 5 < 3; # False
```

Среднее значение сравнивается со значениями по обе стороны от него. Поэтому `1 < 2 < 3` истинно, ведь и `1 < 2`, и `2 < 3` истинны.
