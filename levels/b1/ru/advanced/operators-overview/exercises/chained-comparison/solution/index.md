Вот одно возможное решение.

## Код

```raku
say 0 <= 73 <= 100;
```

🦋 Исходный код можно найти в файле [chained-comparison.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operators-overview/chained-comparison.raku).

## Вывод

```
True
```

## Комментарии

1. Операторы сравнения можно объединять в цепочки. Поэтому `0 <= 73 <= 100` означает «0 не больше 73, а 73 не больше 100». Оператор `<=` допускает граничные значения. Поэтому результат ровно `0` или `100` тоже был бы допустимым.

1. Обе части истинны, поэтому всё выражение равно `True`. Обратите внимание, что среднее значение `73` вы пишете только один раз. И всё же оно сравнивается с обоими соседями.

1. Без цепочек пришлось бы записать оба сравнения и соединить их с помощью `&&`. Тогда среднее значение повторяется: `0 <= 73 && 73 <= 100`. Цепочка сравнений говорит то же самое короче.
