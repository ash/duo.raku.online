Вот одно возможное решение.

## Код

```raku
say 2 ** (3 + 1);
```

🦋 Исходный код можно найти в файле [force-the-order.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operators-overview/force-the-order.raku).

## Вывод

```
16
```

## Комментарии

1. Без скобок `**` связывался бы теснее, чем `+`, и вы получили бы `(2 ** 3) + 1 = 9`.

1. Скобки повышают приоритет сложения, поэтому сначала вычисляется `3 + 1`. Выражение становится `2 ** 4`, что равно `16`. С помощью скобок всегда можно изменить приоритет по умолчанию.
