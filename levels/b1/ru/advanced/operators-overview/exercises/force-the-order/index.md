## Задача

Оператор `**` связывается теснее, чем `+`, поэтому `2 ** 3 + 1` означает `(2 ** 3) + 1`, то есть `9`. Добавьте скобки, чтобы изменить этот порядок и чтобы сложение выполнялось *первым*. Затем выведите результат.

## Пример

Программа выводит:

```
16
```
