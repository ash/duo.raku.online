## Задача

`WHAT` не просто описывает тип. Он возвращает сам объект типа, и его можно сравнить с помощью оператора `===`.

Объявите две переменные. Переменная `$a` содержит целое число `42`, а `$b` содержит строку `'x'`. Для каждой из них напечатайте, является ли её `WHAT` типом `Int`.

## Пример

Программа печатает:

```
True
False
```
