## Задача

У контейнера может быть значение по умолчанию, которое вы задаёте трейтом `is default`. Пока вы ничего не присвоили, переменная возвращает это значение по умолчанию. `.VAR.default` тоже сообщает, какое оно.

Объявите скаляр `$count` со значением по умолчанию `0`. Ничего ему не присваивайте. Сначала напечатайте саму переменную, а потом значение по умолчанию её контейнера. Обе строки должны показать `0`.

## Пример

Программа печатает:

```
0
0
```
