`WHAT` — это псевдо-метод, который позволяет получить тип значения. Его можно использовать почти так же, как `.^name`:

```raku
my $var = 42;

say $var.^name;
say $var.WHAT;
```

Оба печатают тип, но выглядят немного по-разному. `.^name` даёт только имя, а `WHAT` показывает объект типа в скобках:

```
Int
(Int)
```

Если у переменной нет ограничения типа, сначала её тип — `Any`. После того как вы присвоите значение, `^name` и `WHAT` оба показывают его тип:

```raku
my $var;
say $var.^name; # Any
say $var.WHAT;  # (Any)

$var = 'Hello';
say $var.^name; # Str
say $var.WHAT;  # (Str)
```

С ограничением типа тип известен сразу, ещё до того, как вы что-то присвоите:

```raku
my Str $var;
say $var.^name; # Str
say $var.WHAT;  # (Str)

$var = 'Hello';
say $var.^name; # Str
say $var.WHAT;  # (Str)
```

## Сравнение объектов типов

`WHAT` возвращает сам объект типа, поэтому два объекта типов можно сравнить с помощью `===`. Это оператор _тождества значений_. Он проверяет, стоит ли с обеих сторон одно и то же значение. У каждого типа есть только один объект типа. Поэтому это простой и чистый способ проверить, одинаковый ли тип у двух значений:

```raku
my $a = 42;
my $b = 100;

say $a.WHAT === $b.WHAT; # True  — both are Int
say $a.WHAT === Int;     # True
say $a.WHAT === Str;     # False
```

`==` сравнивает числа, а `===` сравнивает тождество. Поэтому он работает прямо с объектами типов, а также с другими значениями.
