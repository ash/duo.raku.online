_Heredoc_ — это форма цитирования для текста в несколько строк. Она не использует разделители вокруг текста. Вместо этого вы указываете слово-терминатор с помощью `:to`. Текст начинается со следующей строки. Он продолжается до строки, в которой есть только это слово:

```raku
my $text = q:to/END/;
Hello,
World!
END

print $text;
```

Это выводит:

```
Hello,
World!
```

Терминатор отмечает, где заканчивается текст. Здесь это `END`, но подойдёт любое слово. Обратите внимание на `print`. Текст сохраняет перевод строки перед терминатором. Поэтому он уже заканчивается переводом строки. С `say` вы бы получили второй перевод строки и пустую строку в конце. Heredoc начинается с `q:to`, поэтому текст не интерполируется. Чтобы интерполировать переменные, используйте `qq:to`:

```raku
my $name = 'Anna';

my $greeting = qq:to/EOF/;
Dear $name,
Welcome!
EOF

print $greeting;
```

Вот полезная деталь. **Отступ закрывающего терминатора** удаляется из каждой строки текста. Поэтому heredoc можно писать с таким же отступом, как код вокруг него. Этот отступ не попадает в строку:

```raku
sub greeting {
    return q:to/END/;
        Hello,
        World!
        END
}

print greeting;
```

Это выводит те же `Hello,` и `World!`, что и в первом примере. Здесь у закрывающего `END` отступ в восемь пробелов. Поэтому из каждой строки удаляется восемь пробелов. Возвращаемая строка — просто `Hello,\nWorld!`, без пробелов в начале строк.

Закрывающий терминатор задаёт, сколько пробелов удаляется. Поэтому у каждой строки текста должен быть хотя бы такой же отступ. Если в начале строки пробелов меньше, Raku не может удалить их полностью. Тогда он предупреждает: *Asked to remove 8 spaces, but the shortest indent is 4 spaces*. Чтобы этого избежать, не делайте у терминатора отступ больше, чем у строки с самым маленьким отступом. Heredoc'и — естественный выбор для шаблонов, сообщений и любого текста в несколько строк.
