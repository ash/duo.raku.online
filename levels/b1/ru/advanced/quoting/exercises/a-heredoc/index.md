## Задача

С помощью *интерполирующего* heredoc'а составьте письмо, которое подтверждает заказ. Используйте несколько переменных: имя покупателя `$name`, товар `$item`, цену `$price` и количество `$count`. Цена дана за один товар. Heredoc должен интерполировать переменные. Он *также* должен вычислить итоговую сумму прямо в тексте с помощью встроенного блока `{ … }` (`$count * $price`).

Сделайте у тела heredoc'а такой же отступ, как у кода вокруг него. Выровняйте закрывающий терминатор по тексту. Тогда отступ не попадёт в вывод. Напечатайте результат.

## Пример

Возьмите `$name = 'Anna'`, `$item = 'Raku Book'`, `$price = 25` и `$count = 3`. Тогда программа выводит следующее, без пробелов в начале:

```
Dear Anna,
You ordered 3 copies of "Raku Book".
That comes to 75 dollars.
Thank you!
```
