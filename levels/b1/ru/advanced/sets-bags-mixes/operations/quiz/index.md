Что напечатает следующая программа?

```raku
say (set(1, 2) ∪ set(2, 3)).elems;
```

{:.quiz}
1 | 3
0 | 4
0 | 2
0 | 1

{% include quiz.html %}

<div class="extended-explanation">

Объединение собирает каждое значение из обоих множеств. Но множество хранит каждое значение только один раз. В обоих множествах есть `2`, поэтому объединение — это `{1, 2, 3}`, три различных элемента.

</div>
