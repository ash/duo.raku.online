Множества можно комбинировать с помощью обычных операций из теории множеств. У каждого оператора есть символ в Unicode и запись в ASCII. Можно использовать любой из них.

_Объединение_ `∪`, или `(|)`, собирает все значения обоих множеств:

```raku
say (set(1, 2, 3) ∪ set(3, 4, 5)).elems; # 5
```

Так как `3` есть в обоих множествах, в объединении пять различных элементов: `1, 2, 3, 4, 5`.

_Пересечение_ `∩`, или `(&)`, оставляет только те значения, которые есть у обоих множеств:

```raku
my $common = set(1, 2, 3) ∩ set(2, 3, 4);
say $common;       # Set(2 3) — обратите внимание, что множества неупорядочены
say $common.elems; # 2
say 2 ∈ $common;   # True
```

Здесь в пересечении `2` и `3` — значения, которые есть в обоих множествах. У множества нет своего порядка. Поэтому, когда вы его печатаете, два элемента могут идти в любом порядке.

Результат этих операций — тоже множество. Поэтому ему можно задавать те же вопросы. Сколько в нём элементов и есть ли в нём определённое значение?
