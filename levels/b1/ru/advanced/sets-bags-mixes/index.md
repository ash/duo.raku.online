Кроме массивов и хешей, в Raku есть несколько особых контейнеров для коллекций значений. Самый простой из них — `Set`. Это коллекция _уникальных_ значений без определённого порядка. Каждое значение либо есть в множестве, либо нет, а повторы не учитываются.

Вы создаёте множество с помощью подпрограммы `set`. Если значение повторяется, множество хранит только одну его копию:

```raku
my $s = set(1, 2, 3, 2, 1);
say $s.elems; # 3
```

Мы передали пять чисел, но в множестве только три элемента. Так получилось потому, что `1` и `2` встречались больше одного раза.

Главный вопрос к множеству — есть ли в нём значение. Оператор `∈`, который читается как «является элементом», возвращает булево значение:

```raku
say 2 ∈ set(1, 2, 3); # True
say 9 ∈ set(1, 2, 3); # False
```

Если вы хотите обойтись простым ASCII, запишите тот же оператор как `(elem)`:

```raku
say 2 (elem) set(1, 2, 3); # True
```

Дальше вы увидите, как комбинировать множества. Вы также познакомитесь с мультимножествами (bags) и смесями (mixes) — близкими родственниками множеств.
