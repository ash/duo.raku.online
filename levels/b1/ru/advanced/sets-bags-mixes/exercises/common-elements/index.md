## Задача

У вас есть два множества названий фруктов:

```raku
my $a = set(<apple banana cherry>);
my $b = set(<banana cherry date>);
```

Найдите их пересечение и сохраните его в переменной. Затем напечатайте две строки. В первой — сколько общих значений у двух множеств. Во второй — есть ли `apple` среди этих общих значений. Его там быть не должно.

## Пример

Программа печатает:

```
2
False
```
