Множество говорит вам только, _есть ли_ в нём значение. Но иногда нужно знать ещё, _сколько раз_ оно там встречается. Для этого есть `Bag`, который хранит счётчик для каждого значения.

Вы создаёте мультимножество с помощью подпрограммы `bag`. Повторяющиеся значения не превращаются в одно. Вместо этого они подсчитываются:

```raku
my $b = bag(<a b a c a>);
say $b<a>; # 3
say $b<b>; # 1
```

Можно спросить мультимножество о значении с помощью индекса `< >`. Тогда вы получите, сколько раз это значение было добавлено. Метод `total` даёт сумму всех счётчиков:

```raku
say bag(<a b a c a>).total; # 5
```

`Mix` — та же идея, что и мультимножество. Разница в том, что счётчики, которые называются _весами_, могут быть дробями, а не только целыми числами. Чтобы задать веса самим, соедините каждое значение с его весом в пару. Затем превратите список в смесь с помощью `.Mix`:

```raku
my $m = (flour => 2.5, sugar => 0.75).Mix;
say $m<flour>; # 2.5
say $m.total;  # 3.25
```

Вы находите вес с помощью `< >` и складываете веса с помощью `total`. Оба способа работают точно так же, как для мультимножества. Единственная разница в том, что числа не обязаны быть целыми. Здесь `total` складывает веса `2.5` и `0.75`, и получается `3.25`. Это сумма весов, а не количество значений. Мультимножества и смеси полезны всегда, когда нужно следить за количествами. Например, можно посчитать, как часто каждое слово встречается в тексте. Или можно задать веса вариантам.
