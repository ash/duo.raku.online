В разделе «Основы» вы использовали `MAIN`, [чтобы получать аргументы командной строки](/ru/essentials/the-main-function/reading-command-line-arguments). Но вокруг `MAIN` Raku делает для вас больше, чем просто передаёт значения.

## Сообщение об использовании

Иногда аргументы командной строки не подходят к сигнатуре `MAIN`. В этом случае Raku не выполняет тело. Вместо этого он выводит _сообщение об использовании_ (usage message), которое Raku создаёт автоматически. Сообщение объясняет, как вызывать программу.

Взгляните на эту программу:

```raku
sub MAIN($name) {
    say "Hello, $name!";
}
```

Если вызвать её правильно, она приветствует человека:

```console
$ raku hello.raku Anna
Hello, Anna!
```

Если вызвать её без аргумента, сигнатура не совпадает. Поэтому Raku выводит сообщение об использовании вместо приветствия:

```console
$ raku hello.raku
Usage:
  hello.raku <name>
```

Raku строит сообщение из имён параметров. Поэтому давайте им понятные имена, и вы бесплатно получите полезный текст справки.

## Именованные аргументы

Параметры `MAIN` могут быть не только позиционными, но и именованными. Именованный параметр становится опцией командной строки вида `--option=value`. Если у него есть значение по умолчанию, опция не обязательна:

```raku
sub MAIN(:$name = 'World') {
    say "Hello, $name!";
}
```

```console
$ raku hello.raku
Hello, World!

$ raku hello.raku --name=Raku
Hello, Raku!
```
