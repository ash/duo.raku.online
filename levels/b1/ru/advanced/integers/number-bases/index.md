В коде не обязательно записывать целые числа в десятичной системе. Raku сразу понимает три самые распространённые другие системы счисления. У каждой из них свой префикс:

```raku
say 0xFF;   # 255  — hexadecimal (base 16)
say 0b1010; # 10   — binary (base 2)
say 0o17;   # 15   — octal (base 8)
```

Какую бы систему счисления вы ни использовали в коде, значение — то же самое целое число. Отличается только то, как вы его записываете.

Для всех других систем счисления есть форма с основанием `:основание<число>`:

```raku
say :16<FF>;   # 255
say :2<1010>;  # 10
```

Чтобы сделать обратное, вызовите метод `base`. Он записывает число в другой системе счисления и возвращает строку цифр:

```raku
say 255.base(16); # FF
say 10.base(2);   # 1010
```
