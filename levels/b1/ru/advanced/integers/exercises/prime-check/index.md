## Задача

Обычно трудно увидеть на глаз, простое ли число. Метод `is-prime` отвечает на этот вопрос. Используйте его для двух чисел, которые на первый взгляд оба кажутся простыми: `97` и `91`. Напечатайте результат для каждого на отдельной строке.

Подвох здесь в числе `91`, потому что оно равно `7 × 13`.

## Пример

Программа печатает:

```
True
False
```
