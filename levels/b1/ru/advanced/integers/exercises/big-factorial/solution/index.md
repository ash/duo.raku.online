Вот одно возможное решение задачи.

## Код

```raku
say (2 ** 1000).chars;
```

🦋 Исходный код можно найти в файле [big-factorial.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/integers/big-factorial.raku).

## Вывод

```
302
```

## Комментарии

1. Raku вычисляет `2 ** 1000` точно. Он не округляет число, и переполнения не бывает, потому что целые числа имеют произвольную точность.

1. `chars` — обычно метод для строк. Когда вы вызываете его на целом числе, он сначала превращает число в десятичный текст. Потом он считает символы. Здесь нет ни знака минус, ни десятичной точки. Поэтому количество символов точно равно количеству цифр, `302`.
