У целых чисел много полезных методов и функций. Вот несколько из них, которые вам часто понадобятся.

Метод `is-prime` проверяет, является ли число простым:

```raku
say 17.is-prime; # True
say 18.is-prime; # False
```

Оператор `gcd` даёт наибольший общий делитель двух чисел. Оператор `lcm` даёт их наименьшее общее кратное:

```raku
say 12 gcd 18; # 6
say 4 lcm 6;   # 12
```

Метод `abs` возвращает абсолютное значение числа. Метод `sign` возвращает `-1`, `0` или `1`. Это зависит от того, какое число: отрицательное, ноль или положительное:

```raku
say (-5).abs;  # 5
say (-5).sign; # -1
say 0.sign;    # 0
```
