Вы используете целые числа с самого начала курса. В этом разделе мы рассмотрим некоторые их особенности, которые легко не заметить.

Самая важная из них — то, что целые числа в Raku имеют _произвольную точность_. У них нет фиксированного количества байтов. Они никогда незаметно не переполняются и не дают неправильный результат. Если хватает памяти, целое число может расти до любого нужного размера:

```raku
say 2 ** 100;
# 1267650600228229401496703205376
```

Это точное значение, а не округлённое. То же самое верно, когда вы умножаете большие числа. Например, Raku вычисляет факториал числа 50 точно:

```raku
my $factorial = 1;
$factorial = $factorial * $_ for 1..50;
say $factorial;
# 30414093201713378043612608166064768844377641568960512000000000000
```

Цифры длинных чисел можно разделять на группы с помощью подчёркиваний. Так их легче читать в коде. Компилятор не обращает внимания на подчёркивания:

```raku
say 1_000_000; # 1000000
```
