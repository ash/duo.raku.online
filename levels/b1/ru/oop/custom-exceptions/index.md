В Raku есть встроенные исключения `X::`, но вы можете создавать и свои. Собственное исключение — это класс, который наследует от встроенного класса `Exception`. Ещё у него есть метод `message`:

```raku
class TooBig is Exception {
    has $.value;

    method message {
        "Value $.value is too big";
    }
}
```

`TooBig` — обычный класс, поэтому у него могут быть атрибуты, например `value`. Но так как он `is Exception`, его можно бросить. Чтобы бросить его, вы создаёте объект и вызываете у него `.throw`:

```raku
my $value = 20 * 30;

TooBig.new(value => $value).throw if $value > 50;

CATCH {
    when TooBig {
        say .message;
    }
}
```

Программа печатает:

```
Value 600 is too big
```

Внутри `CATCH` срабатывает `when TooBig`, потому что брошенный объект имеет этот тип. Собственное исключение несёт любые данные, которые вы ему даёте, здесь это `value`. Поэтому обработчик может составить точное сообщение или отреагировать особым образом. Это гораздо полезнее, чем простая строка, переданная в `die`.

Эта страница собирает вместе всё из этой части. Собственное исключение — это _класс_ с атрибутами и методом. Ещё оно участвует в системе исключений Raku. Поэтому оно готово точно сообщить, что пошло не так.
