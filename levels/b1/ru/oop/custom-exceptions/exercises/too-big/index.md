## Задача

Определите собственный класс исключения `TooBig`. Он наследует от `Exception` и имеет два атрибута: `value` и `limit`. Его метод `message` должен возвращать `Value <value> exceeds the limit of <limit>`.

Затем пройдите циклом по значениям `30`, `99` и `60` при пределе `50`. Для каждого значения бросайте `TooBig`, только если значение больше предела. Возьмите фазер `CATCH` с ветвью `when TooBig`, который печатает сообщение **и** вторую строку. Для этой строки он напрямую читает атрибут `limit` исключения. Он печатает `Try a value up to <limit>.`. Для значения в пределах нормы программа должна просто сообщить, что всё в порядке.

Это показывает, что исключение вызывают только числа, которые не проходят проверку. Остальные числа проходят насквозь, а цикл в обоих случаях продолжается.

## Пример

Программа печатает:

```
Value 30 is within the limit
Value 99 exceeds the limit of 50
Try a value up to 50.
Value 60 exceeds the limit of 50
Try a value up to 50.
```
