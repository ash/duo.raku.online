## Задача

Определите два собственных класса исключений: `TooSmall` и `TooBig`. Каждый из них наследует от `Exception`. Их методы `message` возвращают `too small` и `too big`, в этом порядке.

Пройдите циклом по двум типам. Для каждого из них бросьте исключение этого типа внутри отдельного блока. Возьмите фазер `CATCH` с ветвью `when` для каждого типа. Он печатает `small` для `TooSmall` и `big` для `TooBig`. Так вы увидите, что используются обе ветви.

## Пример

Программа печатает:

```
small
big
```
