Вот одно возможное решение.

## Код

```raku
class Negative is Exception {
    has $.n;

    method message {
        "$.n is negative";
    }
}

sub check($n) {
    Negative.new(n => $n).throw if $n < 0;
    return $n;
}

{
    say check(-5);

    CATCH {
        when Negative {
            say .message;
        }
    }
}

Negative.new(n => -10).throw;
```

🦋 Исходный код можно найти в файле [negative-error.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/custom-exceptions/negative-error.raku).

## Вывод

```
-5 is negative
-10 is negative
  in block <unit> at negative-error.raku line 24
```

## Комментарии

1. `Negative is Exception` даёт возможность бросать этот класс. Его метод `message` строит текст из атрибута `n`.

1. `check` проверяет свои входные данные и для отрицательного числа бросает собственное исключение. Исключение выходит из `check` и идёт к `CATCH` в вызывающем блоке. Там `when Negative` сопоставляет его по типу и печатает сообщение. Это очень частое, реальное применение собственных исключений. Код проверяет свои входные данные и сообщает о плохих значениях исключением своего типа.

1. Зачем вокруг вызова стоит `{ … }`? Фазер `CATCH` обрабатывает только исключения, брошенные в **том блоке, где он стоит**. Блок объединяет рискованный `check(-5)` и `CATCH`, который его охраняет. Поэтому исключение перехватывается прямо здесь, и программа продолжает работу сразу после блока. Без блока `CATCH` охранял бы вместо этого всю программу. Он перехватил бы исключение, но потом программа просто закончилась бы. Не было бы естественного места, чтобы продолжить работу.

1. Последний `Negative.new(n => -10).throw` показывает обратную сторону. Он стоит **вне** блока, поэтому его никто не перехватывает. Исключение поднимается до самого верха, и программа умирает. Она печатает сообщение и трассировку в стандартный поток ошибок. Затем она завершается с ненулевым кодом возврата. Так происходит с любым исключением, которое вы не перехватили. И именно поэтому первому броску был нужен `CATCH`, чтобы программа выжила.
