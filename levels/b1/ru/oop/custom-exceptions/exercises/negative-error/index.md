## Задача

Определите собственный класс исключения с именем `Negative`. Он наследует от `Exception` и имеет атрибут `n`. Его метод `message` возвращает `<n> is negative`.

Напишите подпрограмму `check($n)`. Когда её аргумент меньше нуля, она бросает `Negative`, который несёт это `n`. В остальных случаях она возвращает аргумент. Затем вызовите в блоке `check(-5)`. С помощью фазера `CATCH` с ветвью `when Negative` напечатайте сообщение исключения.

Наконец, после блока бросьте ещё один `Negative`, у которого `n` равно `-10`. Это место не охраняет никакой `CATCH`. Это показывает, что такое исключение завершает программу.

## Пример

Программа печатает:

```
-5 is negative
-10 is negative
  in block <unit> at negative-error.raku line 24
```
