## Задача

Определите класс `Label` с одним атрибутом, `text`, который можно менять (`is rw`). Создайте метку с текстом `draft`. Затем через аксессор **добавьте** ` (revised)` в конец её текста. Не создавайте объект заново. Напечатайте результат.

## Пример

Программа печатает:

```
draft (revised)
```
