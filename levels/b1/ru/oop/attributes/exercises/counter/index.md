## Задача

Определите класс `Counter` с одним атрибутом, `count`, который можно менять (`is rw`). Его значение по умолчанию — `0`.

Создайте счётчик и сначала напечатайте его `count`. Так вы проверите, что он начинается со значения по умолчанию. Затем с помощью цикла пять раз прибавьте к нему единицу. Напечатайте итоговое значение.

## Пример

Программа печатает:

```
0
5
```
