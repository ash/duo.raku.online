Пустой класс не очень полезен. Чтобы объект мог хранить свои данные, дайте классу _атрибуты_. Атрибут объявляют внутри класса ключевым словом `has`:

```raku
class Dog {
    has $.name;
    has $.age;
}
```

У каждого объекта класса есть своя копия этих атрибутов. Вы задаёте их значения, когда создаёте объект. Для этого передайте их в `new` как именованные аргументы:

```raku
class Dog {
    has $.name;
    has $.age;
}

my $rex = Dog.new(name => 'Rex', age => 3);
```

Запись `$.` в `has $.name` делает сразу две вещи. Она объявляет атрибут и создаёт метод с тем же именем. Этот метод называется _аксессором_, и он возвращает значение атрибута:

```raku
say $rex.name; # Rex
say $rex.age;  # 3
```

Разные объекты хранят свои значения, и эти значения не зависят друг от друга:

```raku
my $rex  = Dog.new(name => 'Rex',  age => 3);
my $fido = Dog.new(name => 'Fido', age => 5);

say $rex.name;  # Rex
say $fido.name; # Fido
```

Следующие темы показывают, как сделать атрибуты изменяемыми. Ещё они показывают, как задать атрибутам значения по умолчанию. Есть также способ объявить _приватные_ атрибуты, которые не видны снаружи. Мы вернёмся к ним, когда познакомимся с методами.
