По умолчанию аксессор, который создаёт `has $.name`, работает _только на чтение_. Конструктор `new` задаёт значение, когда создаёт объект. После этого код снаружи объекта может читать значение, но не может его изменить. Присваивание ему приводит к ошибке:

```raku
class Dog {
    has $.name;
}

my $rex = Dog.new(name => 'Rex');
$rex.name = 'Max';
```

Программа останавливается с таким сообщением:

```
Cannot modify an immutable Str (Rex)
```

Хотите изменять значение через аксессор? Тогда пометьте атрибут трейтом `is rw`:

```raku
class Dog {
    has $.name is rw;
}

my $rex = Dog.new(name => 'Rex');
$rex.name = 'Max';
say $rex.name; # Max
```

Теперь аксессор возвращает изменяемый контейнер. Поэтому присваивание работает, и `name` объекта меняется на `Max`.
