Атрибуту можно задать _значение по умолчанию_. Оно используется, когда вы создаёте объект без значения для этого атрибута. Напишите значение по умолчанию после атрибута, через `=`:

```raku
class Dog {
    has Str $.name;
    has Rat $.weight = 4.0;
}
```

Обратите внимание, что атрибутам можно задать тип, так же как переменным.

Если вы не передаёте `weight` в `new`, атрибут получает своё значение по умолчанию:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.weight; # 4
```

Значение по умолчанию всё равно можно заменить, если передать своё значение:

```raku
my $lighty = Dog.new(name => 'Lighty', weight => 3.2);
say $lighty.weight; # 3.2
```

Атрибут без значения по умолчанию и без значения из `new` просто не определён. Он ведёт себя точно как новая скалярная переменная.
