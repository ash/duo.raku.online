Атрибуты дают объекту данные, а _методы_ дают ему поведение. Метод — это подпрограмма, которая принадлежит классу. Вы вызываете его у объекта. Объявляют метод ключевым словом `method`:

```raku
class Dog {
    has $.name;

    method bark {
        return $.name ~ ' says Woof!';
    }
}
```

Чтобы вызвать метод у объекта, используйте точку, как и с аксессором:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.bark; # Rex says Woof!
```

Внутри метода `self` — это объект, у которого вызвали метод. К атрибутам обращаются через их аксессоры. Их записывают как `$.name`, `$.age` и так далее. Они работают и внутри строк в двойных кавычках, куда Raku вставляет их значения:

```raku
class Dog {
    has $.name;

    method greet {
        "Hello, my name is $.name";
    }
}

say Dog.new(name => 'Rex').greet; # Hello, my name is Rex
```
