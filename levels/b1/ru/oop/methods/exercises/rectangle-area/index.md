## Задача

Определите класс `Rectangle` с атрибутами `width` и `height`. Дайте ему метод `area`, который возвращает площадь прямоугольника. Добавьте второй метод, `describe`, который возвращает строку `area is <площадь>`. Для этого он должен **вызвать собственный метод `area`** через `self`.

Создайте прямоугольник шириной `3` и высотой `4`. Затем напечатайте его описание.

## Пример

Программа печатает:

```
area is 12
```
