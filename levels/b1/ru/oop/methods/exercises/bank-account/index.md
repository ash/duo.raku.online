## Задача

Определите класс `Robot` с атрибутом `position`, который можно менять. Его значение по умолчанию — `0`. Добавьте метод `move`, который сдвигает позицию вперёд на заданное число шагов. Пусть число шагов по умолчанию будет равно `1`. Тогда вызов `move` без аргумента сдвигает робота на один шаг.

Создайте робота и сдвиньте его на `5` шагов. Затем сдвиньте его без аргумента, а потом ещё на `2` шага. Напечатайте его итоговую позицию.

## Пример

Программа печатает:

```
8
```
