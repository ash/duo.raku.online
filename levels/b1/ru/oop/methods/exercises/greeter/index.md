## Задача

Определите класс `Word` с атрибутом `text` и методом `reversed`. Этот метод возвращает текст слова, записанный задом наперёд. Можно использовать метод `flip`, который переворачивает строку.

Создайте слово, в котором хранится `Raku`, и напечатайте его задом наперёд.

## Пример

Программа печатает:

```
ukaR
```
