В [разделе об атрибутах](/ru/oop/attributes) мы объявляли каждый атрибут через `$.`. Так создаётся публичный аксессор. Если же объявить атрибут через `$!`, он будет _приватным_. У него нет аксессора, и снаружи объекта его не видно. Обратиться к нему могут только методы самого класса. Там его пишут как `$!name`.

```raku
class Safe {
    has $!code = 4321;

    method unlocks($attempt) {
        return $attempt == $!code;
    }
}

my $safe = Safe.new;
say $safe.unlocks(4321); # True
say $safe.unlocks(1111); # False
```

Секретный `$!code` хранится внутри объекта, но никогда не показывается снаружи. Аксессора `.code` нет. Поэтому работать с ним можно только через метод `unlocks`. Класс сам решил дать этот метод. Если попробовать прочитать `$safe.code` или `$safe!code`, ничего не выйдет.

Приватные атрибуты полезны для внутренних деталей. Остальной программе не следует работать с этими деталями напрямую.
