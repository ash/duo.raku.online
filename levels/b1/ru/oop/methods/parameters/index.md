Как и подпрограмма, метод может принимать параметры. Их пишут в круглых скобках после имени метода:

```raku
class Account {
    has $.balance is rw = 0;

    method deposit($amount) {
        $.balance += $amount;
    }
}
```

Метод `deposit` принимает один параметр, `$amount`. Он прибавляет эту сумму к балансу объекта:

```raku
my $a = Account.new;
$a.deposit(100);
$a.deposit(50);
say $a.balance; # 150
```

Каждый вызов работает с тем объектом, у которого его сделали. Поэтому один и тот же метод может менять разные объекты по отдельности. У методов могут быть позиционные и именованные параметры и значения по умолчанию. На самом деле они могут использовать всё, что вы уже видели в сигнатурах подпрограмм.
