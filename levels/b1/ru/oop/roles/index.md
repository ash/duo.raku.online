_Роль_ — это часть поведения, а иногда и данных, которую могут разделять несколько классов. Наследование говорит, что класс _является_ разновидностью другого класса. А роль описывает то, что класс _умеет делать_.

Вы определяете роль ключевым словом `role`, так же как класс. Чтобы передать её классу, используйте трейт `does`:

```raku
role Greet {
    method hello {
        'Hello from ' ~ self.name;
    }
}

class Person does Greet {
    has $.name;
}
```

Теперь у класса `Person` есть метод `hello` из роли. Он работает так, как если бы вы написали его в самом классе:

```raku
say Person.new(name => 'Anna').hello; # Hello from Anna
```

Если класс выполняет роль, Raku видит, что у него есть эта роль:

```raku
say Person.new(name => 'Anna') ~~ Greet; # True
```

Обратите внимание, что метод роли `hello` использует `self.name`. Но у самой роли нет атрибута `name`. Это нормально. Метод выполняется как часть того класса, который включает эту роль. А `name` даёт уже этот класс. Следующая тема показывает, что у класса может быть сразу несколько ролей.
