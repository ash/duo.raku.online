## Задача

Определите роль `Sized` с методом `describe`. Он возвращает строку `size is <размер>` и использует для этого `self.size`.

Затем определите класс `Box`, который выполняет роль `Sized` и имеет атрибут `size`. Создайте коробку с размером `10`. Напечатайте результат вызова у неё `describe`. На второй строке напечатайте, верно ли для коробки `~~ Sized`. Другими словами, напечатайте, видит ли Raku, что она выполняет роль.

## Пример

Программа печатает:

```
size is 10
True
```
