## Задача

Определите две роли:

* `Named` с методом `label`, который возвращает `I am <имя>`;
* `Aged` с методом `status`, который возвращает `<возраст> years`.

Затем определите класс `Pet`, который выполняет обе роли. У него есть атрибуты `name` и `age`. Создайте питомца по имени `Rex` в возрасте `3` лет. Затем напечатайте его `label` и его `status`.

## Пример

Программа печатает:

```
I am Rex
3 years
```
