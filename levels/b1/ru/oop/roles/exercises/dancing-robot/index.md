## Задача

Определите класс `Robot` с методом `speak`, который возвращает `beep`. Затем определите роль `Dancing`, которая добавляет метод `dance`; этот метод возвращает `spinning around`.

Создайте двух роботов, но дайте роль `Dancing` только одному из них. Напечатайте результат `speak` для обоих роботов. Затем напечатайте результат `dance` для робота, который умеет танцевать.

## Пример

Программа печатает:

```
beep
beep
spinning around
```
