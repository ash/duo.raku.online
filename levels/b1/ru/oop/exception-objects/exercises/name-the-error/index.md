## Задача

Напишите подпрограмму `risky`, которая делает `die 'sub failed'`. Затем вызовите её изнутри блока, в котором есть фазер `CATCH`. `CATCH` должен напечатать имя типа исключения через `.^name`. Затем он должен напечатать его сообщение через `.message`. Это показывает, что `CATCH` обрабатывает исключения из кода, который блок *вызывает*. `die` не обязательно писать прямо в блоке.

## Пример

Программа печатает:

```
X::AdHoc
sub failed
```
