## Задача

У встроенных ошибок есть свои типы исключений, и их можно сопоставлять. Напишите блок, который вычисляет `1 / 0` и пытается использовать результат. Из-за этого бросается `X::Numeric::DivideByZero`. В фазере `CATCH` этого блока используйте `when X::Numeric::DivideByZero`, чтобы сопоставить именно этот тип. Затем напечатайте `cannot divide by zero`.

## Пример

Программа печатает:

```
cannot divide by zero
```
