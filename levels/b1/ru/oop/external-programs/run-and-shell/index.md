Есть два способа запустить внешнюю программу. Функция `run` принимает команду и её аргументы как **отдельные** значения. Она запускает программу напрямую, без оболочки:

```raku
run 'echo', 'hello';
```

Этот код запускает программу `echo` с единственным аргументом `hello`, поэтому она печатает `hello`. Аргументы передаются по отдельности, поэтому оболочка не может неверно понять пробелы или специальные символы. Вот почему `run` — безопасный выбор по умолчанию.

Функция `shell` работает иначе. Она передаёт **одну строку** системной оболочке, которая читает и выполняет её. Так можно пользоваться возможностями оболочки, например конвейерами и перенаправлением:

```raku
shell 'echo hello | tr a-z A-Z';
```

Здесь оболочка запускает `echo` и передаёт его вывод по конвейеру в `tr`. Потом она печатает `HELLO`. Это удобно, но нужно быть осторожным. Оболочка сама решает, что значит строка. Поэтому опасно собирать команду для `shell` из ввода, которому вы не доверяете. Используйте `run`, если вам на самом деле не нужны возможности оболочки.

Обе функции возвращают объект `Proc`, который описывает, как завершилась программа. По умолчанию запущенная программа делит вывод с вашей программой. Поэтому то, что она печатает, появляется на экране. Чтобы вместо этого перехватить вывод, его нужно запросить. Об этом — следующая тема.
