## Задача

С помощью `run` с `:out` запустите `echo` с тремя словами `hello world raku`. Перехватите его вывод в переменную. Затем, вместо того чтобы просто напечатать его, посчитайте, сколько в нём слов. Напечатайте это число.

## Пример

Программа печатает:

```
3
```
