## Задача

Создайте файл `notes.txt` и запишите в него несколько строк. Поместите его имя в переменную окружения `NOTES`. Затем с помощью `shell` запустите `wc -l` и возьмите имя файла из `$NOTES`. Дочерняя программа тогда посчитает строки и напечатает их число. Наконец, удалите файл в самом Raku через `unlink`, а не через оболочку.

## Пример

Программа печатает:

```
3
```

Ещё она не оставляет после себя `notes.txt`.
