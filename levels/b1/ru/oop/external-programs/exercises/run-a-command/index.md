## Задача

С помощью `run` запустите `echo` с двумя отдельными аргументами: `home:` и `$HOME`. Пусть его вывод идёт на экран. Заметьте, что `$HOME` появляется как есть, а домашний каталог **не** печатается. Так как `run` не использует оболочку, переменная не заменяется своим значением.

## Пример

Программа печатает:

```
home: $HOME
```
