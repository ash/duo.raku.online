Вот одно возможное решение.

## Код

```raku
run 'echo', 'home:', '$HOME';
```

🦋 Исходный код можно найти в файле [run-a-command.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/external-programs/run-a-command.raku).

## Вывод

```
home: $HOME
```

## Комментарии

1. `run` запускает `echo` напрямую и передаёт каждую строку отдельным аргументом. Без `:out` вывод программы идёт прямо на экран.

1. Аргумент доходит до `echo` ровно в том виде, в каком он написан. `$HOME` печатается как есть и не заменяется вашим домашним каталогом. Так происходит потому, что нет оболочки, которая бы его заменила. Вот почему `run` — безопасный выбор по умолчанию. Та же команда, переданная `shell`, могла бы вести себя совсем иначе.

1. Чтобы всё-таки напечатать домашний каталог, пусть переменную заменит оболочка. `shell 'echo home: $HOME'` напечатает что-нибудь вроде `home: /home/anna`. Оставьте одинарные кавычки и на стороне Raku. С `"$HOME"` в двойных кавычках была бы проблема. Сам Raku попытался бы вставить в строку переменную с именем `$HOME`. Это случилось бы ещё до того, как запустится `echo`.
