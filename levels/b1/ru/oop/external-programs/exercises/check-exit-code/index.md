## Задача

Запустите команду, которая специально завершается неудачей, например `sh -c 'exit 4'`. Сохраните `Proc`, который она возвращает. Напечатайте код возврата команды. Затем напечатайте `success` или `failure` — в зависимости от того, удалась ли команда.

## Пример

Программа печатает:

```
4
failure
```
