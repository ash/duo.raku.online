## Задача

Определите класс `Animal` с методом `speak`. Затем определите класс `Dog`, который наследует от `Animal`. Своих методов он не добавляет. Используйте метаметод у `Dog` и напечатайте, есть ли у `Dog` метод с именем `speak`. Напечатайте просто `True` или `False`. Это показывает, что `find_method` смотрит вдоль цепочки наследования. Он смотрит не только на собственные методы класса.

## Пример

Программа печатает:

```
True
```
