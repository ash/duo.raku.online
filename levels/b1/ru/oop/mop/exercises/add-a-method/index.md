## Задача

Определите класс `Dog`, у которого есть только атрибут `name` и нет методов. Затем с помощью MOP добавьте ему метод `speak` во время работы программы. Новый метод должен использовать `name` самого объекта и возвращать `<имя> says woof`. Создайте собаку по имени `Rex` и вызовите новый метод.

## Пример

Программа печатает:

```
Rex says woof
```
