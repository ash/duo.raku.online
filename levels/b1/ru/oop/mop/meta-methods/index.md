_Метаметод_ вызывается через `.^`, а не через `.`. Обычный `.method` выполняет метод объекта. А `.^method` вызывает метод у **метаобъекта** этого объекта. Поэтому он спрашивает о типе, а не действует как тип.

Вы уже видели `.^name`, который возвращает имя типа:

```raku
say 42.^name; # Int
```

Другие метаметоды изучают устройство типа. `.^attributes` перечисляет его атрибуты, а `.^find_method` сообщает, есть ли такой метод:

```raku
class Animal {
    has $.name;
    method speak { 'generic' }
}

say Animal.^attributes.elems;          # 1
say so Animal.^find_method('speak');   # True
say so Animal.^find_method('fly');     # False
```

`.^mro` возвращает _порядок разрешения методов_. Это цепочка типов, которые Raku по очереди просматривает, чтобы найти метод. Это линия наследования класса:

```raku
class A {}
class B is A {}

say B.^mro.map(*.^name); # (B A Any Mu)
```

`B` наследует от `A`, а в конце концов каждый тип наследует от `Any` и `Mu`. Поэтому Raku ищет метод объекта `B` ровно по этому пути. Эти метаметоды превращают устройство ваших типов в данные. Об этих данных можно спрашивать во время работы программы.
