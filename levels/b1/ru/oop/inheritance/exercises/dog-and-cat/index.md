## Задача

Определите базовый класс `Employee` с атрибутом `name` и двумя методами. Метод `role` возвращает `'staff'`. Метод `badge` возвращает строку `<имя> - <роль>` и использует для этого свой метод `role`.

Затем определите два дочерних класса, `Manager` и `Intern`, которые наследуют от `Employee`. Они переопределяют `role`: в `Manager` он возвращает `'manager'`, а в `Intern` — `'intern'`.

Напечатайте бейджи менеджера по имени `Anna` и стажёра по имени `Bob`.

## Пример

Программа печатает:

```
Anna - manager
Bob - intern
```
