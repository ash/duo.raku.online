## Задача

Определите базовый класс `Shape` с двумя методами. Метод `name` возвращает `'shape'`. Метод `describe` возвращает строку `I am a <имя>` и использует для этого свой метод `name`.

Затем определите класс `Square`, который наследует от `Shape`. Он переопределяет `name`, чтобы `name` возвращал `'square'`.

Напечатайте описание объекта `Square`.

## Пример

Программа печатает:

```
I am a square
```
