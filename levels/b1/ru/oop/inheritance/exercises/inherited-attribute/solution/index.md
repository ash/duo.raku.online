Вот одно возможное решение.

## Код

```raku
class Vehicle {
    has $.wheels;
}

class Bike is Vehicle {
    has $.wheels = 2;
}

class Car is Vehicle {
    has $.wheels = 4;
}

say Bike.new.wheels;
say Car.new.wheels;
```

🦋 Исходный код можно найти в файле [inherited-attribute.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/inheritance/inherited-attribute.raku).

## Вывод

```
2
4
```

## Комментарии

1. И `Bike`, и `Car` наследуют от `Vehicle` атрибут `wheels` вместе с его аксессором. Ни один из них не объявляет этот атрибут заново. Они только дают унаследованному атрибуту значение по умолчанию: `2` для `Bike` и `4` для `Car`.

1. Значение по умолчанию встроено в каждый класс. Поэтому объекты можно создать простым `Bike.new` и `Car.new`. Затем унаследованный аксессор возвращает нужное число колёс.

1. Вы всё ещё можете передать значение сами, например `Car.new(wheels => 3)`. Такой аргумент переопределяет значение по умолчанию. Но у велосипеда или машины, скорее всего, уже есть привычное число колёс. Поэтому значения по умолчанию делают обычный случай простым. Но место для редкого исключения всё равно остаётся.
