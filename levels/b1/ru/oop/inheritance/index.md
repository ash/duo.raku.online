_Наследование_ позволяет одному классу строиться на основе другого. После имени нового класса вы пишете `is` и имя другого класса. Тогда новый класс наследует все атрибуты и методы этого класса. Этот класс называется его _родительским_ (или _базовым_) классом.

```raku
class Animal {
    has $.name;
    method speak {
        'some sound';
    }
}

class Dog is Animal {
}
```

`Dog is Animal` означает, что `Dog` — это разновидность `Animal`. У класса `Dog` нет своего кода. Но у него уже есть атрибут `name` и метод `speak` из `Animal`:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.name;  # Rex
say $rex.speak; # some sound
```

Объект `Dog` тоже считается объектом `Animal`:

```raku
say Dog.new ~~ Animal; # True
```

Умное сопоставление `~~` с типом истинно, если объект имеет этот тип. Оно истинно и тогда, когда объект наследует от этого типа. В следующей теме дочерний класс заменит унаследованный метод своей версией.
