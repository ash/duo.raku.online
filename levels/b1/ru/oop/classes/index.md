До сих пор все типы данных, которыми вы пользовались, были встроены в Raku. Это были числа, строки, массивы и так далее. В _объектно-ориентированном программировании_ вы можете определять свои типы, которые называются _классами_. Вы также можете создавать значения этих типов, которые называются _объектами_.

Чтобы определить класс, напишите ключевое слово `class`, а за ним имя и блок:

```raku
class Dog {
}
```

Этот класс `Dog` пока пустой, но это уже новый тип. Объект класса также называют _экземпляром_. Чтобы создать экземпляр, вызовите метод `new` у имени класса:

```raku
class Dog {
}

my $rex = Dog.new;
say $rex; # Dog.new
```

Теперь `$rex` содержит объект `Dog`. Каждый раз, когда вы вызываете `new`, вы получаете новый, отдельный объект:

```raku
my $rex = Dog.new;
my $fido = Dog.new;
```

`$rex` и `$fido` — две разные собаки, хотя класс ещё пустой. В следующих разделах вы дадите классу его собственные данные, которые называются _атрибутами_. Вы также дадите ему собственное поведение — _методы_. Первая тема подробнее рассматривает, чем класс отличается от своих экземпляров.
