## Задача

Определите два пустых класса, `Cat` и `Dog`. Затем пройдите циклом по четырём значениям: `Cat`, `Dog`, `Cat.new` и `Dog.new`. Для каждого из них напечатайте, определено ли оно. Обратите внимание, что оба объекта типа не определены, а оба экземпляра определены. Неважно, к какому классу они относятся.

## Пример

Программа печатает:

```
False
False
True
True
```
