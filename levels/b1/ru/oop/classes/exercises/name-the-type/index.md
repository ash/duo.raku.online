## Задача

Определите два пустых класса, `Cat` и `Dog`, и создайте экземпляр `Cat` по имени `$felix`. Напечатайте тип `$felix` с помощью `WHAT`. Затем с помощью оператора `===` напечатайте ещё две строки. Первая строка показывает, совпадает ли этот тип с `Cat`. Вторая показывает, совпадает ли он с `Dog`.

## Пример

Программа печатает:

```
(Cat)
True
False
```
