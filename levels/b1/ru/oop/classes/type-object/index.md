Имя класса, например `Dog`, означает _объект типа_ этого класса. Объект типа обозначает сам тип. Это не какой-то конкретный объект этого типа. А _экземпляр_, который вы создаёте с помощью `new`, — это настоящий объект.

Raku может отличить одно от другого. Метод `defined` возвращает `False` для объекта типа и `True` для экземпляра:

```raku
class Dog {
}

say Dog.defined;     # False
say Dog.new.defined; # True
```

Объект типа считается _неопределённым_, потому что в нём нет настоящих данных. Он только описывает тип. Экземпляр _определён_, потому что это настоящий объект.

С `WHAT` оба показывают один и тот же тип. Вы уже встречали `WHAT` в [разделе о контейнерах](/ru/advanced/containers):

```raku
class Dog {
}

say Dog.WHAT;     # (Dog)
say Dog.new.WHAT; # (Dog)
```

Raku показывает тип в круглых скобках, как в `(Dog)`. Значит, у `Dog` и `Dog.new` один и тот же тип — `Dog`. Но между ними есть разница. `Dog` — это сам тип, а `Dog.new` — объект этого типа.
