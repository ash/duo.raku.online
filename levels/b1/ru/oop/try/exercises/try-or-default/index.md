## Задача

Блок `try`, который дал сбой, возвращает неопределённое значение. Используйте это вместе с оператором «определённое или» `//`, чтобы подставить запасное значение. Выполните блок `try` с `die 'no'` внутри. Если он даст сбой, возьмите вместо этого строку `default`. Напечатайте результат.

## Пример

Программа печатает:

```
default
```
