## Задача

Покажите обе стороны `try`. Сначала оберните в блок `try` вычисление, которое работает, например `6 * 7`. Затем напечатайте его результат. Потом поместите код, который выполняет `die 'broken'`, во второй блок `try`. Напечатайте, дал ли этот блок определённый результат. Затем напечатайте сообщение перехваченного исключения.

## Пример

Программа печатает:

```
42
False
broken
```
