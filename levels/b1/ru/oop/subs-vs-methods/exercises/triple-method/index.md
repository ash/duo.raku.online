## Задача

Теперь решите ту же задачу с помощью **метода**. Определите класс `Number` с атрибутом `n`. Дайте ему метод `triple`, который возвращает `n`, умноженное на три. Создайте `Number`, у которого `n` равно `7`. Затем вызовите у него `triple` и напечатайте результат.

## Пример

Программа печатает:

```
21
```
