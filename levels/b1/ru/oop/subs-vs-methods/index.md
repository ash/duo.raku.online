Теперь у вас есть два способа оформить какое-то поведение: _подпрограмма_ и _метод_. Выглядят они похоже, но используете вы их по-разному.

Подпрограмма существует сама по себе. Вы вызываете её по имени и передаёте ей всё нужное в виде аргументов:

```raku
sub area-of($radius) {
    π * $radius * $radius;
}

say area-of(2); # 12.566370614359172
```

Метод принадлежит классу. Вы вызываете его у объекта через точку. Он может пользоваться данными самого объекта через `self` и аксессоры атрибутов. Поэтому передавать ему эти данные не нужно:

```raku
class Circle {
    has $.radius;

    method area {
        π * $.radius * $.radius;
    }
}

say Circle.new(radius => 2).area; # 12.566370614359172
```

Оба варианта вычисляют одно и то же число. Разница в том, откуда берутся данные. Подпрограмма получает радиус как аргумент. Метод читает его из объекта, у которого его вызвали.

Вот простое правило. Используйте подпрограмму для отдельной операции, которая просто превращает свои аргументы в результат. Используйте метод, когда поведение принадлежит объекту и использует его данные. Для общих действий, которые относятся ко всему классу, используйте методы класса.
