Блок `try` удобен, но для него весь блок — одно целое. Блок либо работает, либо нет. Фазер `CATCH` даёт вам больше контроля. Он позволяет обработать исключение _внутри_ того блока, где оно произошло. Затем вы решаете, что делать.

`CATCH` — это фазер, как те, что вы видели в [разделе о порядке выполнения](/ru/advanced/phasers). Его можно поставить где угодно внутри блока. Он срабатывает, только если в этом блоке бросается исключение. Исключение доступно как переменная темы `$_`:

```raku
{
    die 'Boom!';

    CATCH {
        default {
            say 'Caught: ' ~ .message;
        }
    }
}

say 'after';
```

Программа печатает:

```
Caught: Boom!
after
```

Блок `default` внутри `CATCH` обрабатывает любое исключение. Когда он отработал, исключение считается обработанным. Поэтому программа не останавливается. Она продолжает работу после блока, где стоит `CATCH`, — вот почему печатается `after`.

Без `CATCH` вызов `die` завершил бы программу до того, как она дошла до `after`.
