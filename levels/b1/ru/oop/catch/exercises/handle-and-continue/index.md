## Задача

Пройдите циклом по трём элементам `ok`, `bad` и `ok`. Для каждого элемента выполните блок, который печатает `processed <элемент>`. Но когда элемент равен `bad`, блок должен делать `die 'boom'`. Поставьте внутрь блока фазер `CATCH`. Он должен сообщать об элементе с ошибкой так: `skipped (<элемент>): <сообщение>`. Затем цикл переходит к следующему элементу, а не останавливается.

## Пример

Программа печатает:

```
processed ok
skipped (bad): boom
processed ok
```
