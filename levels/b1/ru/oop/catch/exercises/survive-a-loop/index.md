## Задача

Пройдите циклом по числам `1`, `2` и `3`. Для каждого числа печатайте `ok: <n>`. Но когда число равно `2`, вместо этого выполните `die "bad: 2"`. Добавьте внутрь тела цикла фазер `CATCH`, который печатает `caught: <сообщение>`. Так один плохой проход не остановит весь цикл.

## Пример

Программа печатает:

```
ok: 1
caught: bad: 2
ok: 3
```
