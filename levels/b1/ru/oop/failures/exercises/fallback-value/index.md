## Задача

Напишите подпрограмму `get`, которая возвращает свой аргумент. Но когда аргумент равен `0`, она должна вызывать `fail` с сообщением `bad`.

Напечатайте результат `get(5)`, а затем `get(0)`. Используйте оператор «определённое или» `//`, чтобы подставить запасное значение `default`.

## Пример

Программа печатает:

```
5
default
```
