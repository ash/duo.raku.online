## Задача

Напишите подпрограмму `reciprocal`, которая возвращает `1`, делённую на свой аргумент. Но когда аргумент равен `0`, она должна использовать `fail` с сообщением `no reciprocal of zero`.

Напечатайте результат `reciprocal(4)`. Затем напечатайте результат `reciprocal(0)`. Вместо того чтобы самим проверять `.defined`, используйте оператор `//`. Он должен давать строку `undefined`, когда вызов даёт сбой.

## Пример

Программа печатает:

```
0.25
undefined
```
