## Задача

Напишите подпрограмму `lookup`. Она возвращает `100`, когда её аргумент равен `'a'`. В остальных случаях она вызывает `fail` с сообщением `no such key`.

Вызовите `lookup('z')` и напечатайте результат, если он определён. Если нет, напечатайте `not found`. Второй строкой напечатайте причину сбоя, взятую из самого `Failure`: `reason: <сообщение>`.

## Пример

Программа печатает:

```
not found
reason: no such key
```
