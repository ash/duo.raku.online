Читать или записывать весь файл сразу легко. Но иногда нужно пройти по файлу строка за строкой. Или вы хотите держать файл открытым и много раз писать в него. Для этого используют _файловый дескриптор_.

Вот самый простой способ читать файл построчно. Для этого даже не нужно создавать дескриптор. Метод `lines` у объекта пути выдаёт строки по одной. Они сразу готовы для цикла `for`:

```raku
spurt 'words.txt', "one\ntwo\nthree\n";

for 'words.txt'.IO.lines -> $line {
    say $line.uc;
}
```

Каждая `$line` — это одна строка без перевода строки в конце. Программа печатает:

```
ONE
TWO
THREE
```

Чтобы писать через дескриптор, откройте файл с помощью `open` и флага `:w` (запись). Потом используйте методы `say` или `print` у дескриптора. Когда закончите, закройте его через `close`:

```raku
my $fh = open 'out.txt', :w;
$fh.say('first line');
$fh.say('second line');
$fh.close;
```

Если закрыть дескриптор, всё, что вы записали, точно сохранится на диске. Некоторые файлы слишком большие, чтобы загрузить их в память целиком. Их обычно читают построчно, как выше.
