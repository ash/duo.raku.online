## Задача

Откройте файл `out.txt` на запись. Держите дескриптор открытым. В цикле запишите в него числа `1`, `2` и `3`. Каждое число поставьте на отдельную строку. Затем закройте дескриптор, прочитайте файл обратно и напечатайте его содержимое.

## Пример

Программа печатает:

```
1
2
3
```
