## Задача

Запишите три слова `apple`, `banana` и `cherry` в файл `words.txt`. Каждое слово поставьте на отдельную строку. Затем прочитайте файл построчно. Напечатайте каждую строку с её номером впереди, начиная с `1`. Используйте форму `<номер>: <строка>`.

## Пример

Программа печатает:

```
1: apple
2: banana
3: cherry
```
