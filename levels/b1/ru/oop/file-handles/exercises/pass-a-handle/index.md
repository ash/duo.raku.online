## Задача

Файловый дескриптор — это обычное значение. Поэтому его можно передать в функцию, как любой другой аргумент. Напишите подпрограмму `log-line`, которая принимает дескриптор и сообщение. Она должна записывать сообщение в дескриптор на отдельной строке.

Откройте `log.txt` на запись. Вызовите `log-line` три раза, чтобы записать `started`, `working` и `done`. Затем закройте дескриптор, прочитайте файл обратно и напечатайте его содержимое.

## Пример

Программа печатает:

```
started
working
done
```
