Большинство методов вызывают у объекта, который является экземпляром класса. Но метод можно вызвать и у самого класса. Другими словами, его вызывают у объекта типа. Такой метод часто называют _методом класса_. Он полезен для значений и операций, которые принадлежат всему классу. Они не принадлежат какому-то одному объекту.

Метод класса определяют точно так же, как любой другой метод:

```raku
class Road {
    method speed-limit { 120 }
}
```

Но вызывают его у имени класса, а не у экземпляра:

```raku
say Road.speed-limit; # 120
```

На самом деле вы уже пользовались методом класса, хотя и не называли его так. `new` — это метод, который вы вызываете у класса, чтобы создать новый объект.

Метод класса не может использовать атрибуты экземпляра, потому что за ним не стоит конкретный объект. Поэтому он работает только с информацией, которая общая для всех объектов класса. Если работа зависит от данных одного объекта, используйте обычный метод. Вызывайте его у экземпляра. Если не зависит, метод класса — самый естественный выбор.

Методам класса экземпляр не нужен. Но если объект у вас всё же есть, вы можете использовать в них его данные:

```raku
class Road {
    has $.name;
    method speed-limit { 120 }

    method info {
        "The maximum speed on $.name is " ~ self.speed-limit
    }
}

my $R404 = Road.new(name => 'Road 404');
say $R404.info;
```

Эта программа печатает результат, которого вы и ожидаете:

```
The maximum speed on Road 404 is 120
```

Без объекта класса вызов вроде `say Road.info` привёл бы к ошибке.
