Иногда нужно работать с самой файловой системой. Например, вы хотите проверить, что существует, или создать каталоги. Для этого Raku использует _объекты пути_. Любую строку можно превратить в объект пути методом `.IO`. Затем объект пути отвечает на вопросы об этом пути.

Чаще всего вы спрашиваете, существует ли путь и что это такое:

```raku
spurt 'greeting.txt', 'hi';

say 'greeting.txt'.IO.e; # True  — существует ли?
say 'greeting.txt'.IO.f; # True  — это файл?
say 'greeting.txt'.IO.d; # False — это каталог?
```

`.e` проверяет, существует ли путь. `.f` проверяет, обычный ли это файл, а `.d` — каталог ли это.

Чтобы создать новый каталог, используйте `mkdir`:

```raku
mkdir 'reports';
say 'reports'.IO.d; # True
```

В следующей теме вы увидите, как получить список содержимого каталога.
