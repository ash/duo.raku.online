Процедура `dir` возвращает записи каталога, каждую в виде объекта пути. Их порядок может меняться. Поэтому результат часто сортируют, и тогда вывод всегда идёт в одном и том же порядке.

```raku
mkdir 'box';
spurt 'box/a.txt', '';
spurt 'box/b.txt', '';

for dir('box').sort -> $entry {
    say $entry.basename;
}
```

Программа печатает отсортированные имена файлов в каталоге `box`:

```
a.txt
b.txt
```

Каждая запись — это полноценный объект пути. Метод `basename` даёт только последнее имя, без части с каталогом. Объекту пути можно задать все те же вопросы, что и раньше: `.f`, `.d` и `.e`. Поэтому можно, например, пройти по каталогу и выбрать только файлы.
