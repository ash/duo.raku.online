## Задача

Сохраните число в файл и снова загрузите его. Запишите число `42` и перевод строки в файл `number.txt`. Затем прочитайте файл обратно и превратите его содержимое в целое число. Напечатайте это число, умноженное на два.

## Пример

Программа печатает:

```
84
```
