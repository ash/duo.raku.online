## Задача

Сделайте небольшой файл журнала, добавляя в него снова и снова. Запишите строку `start` в файл `log.txt`. Затем в цикле **допишите** ещё три строки: `entry 1`, `entry 2` и `entry 3`. Не стирайте то, что уже есть в файле. Наконец, прочитайте весь файл и напечатайте его.

## Пример

Программа печатает:

```
start
entry 1
entry 2
entry 3
```
