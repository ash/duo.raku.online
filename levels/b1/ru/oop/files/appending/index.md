По умолчанию `spurt` заменяет всё, что было в файле. Чтобы вместо этого дописать в конец существующего файла, передайте именованный аргумент `:append`:

```raku
spurt 'log.txt', "line1\n";
spurt 'log.txt', "line2\n", :append;

print slurp 'log.txt';
```

Второй `spurt` сохраняет старое содержимое и добавляет новую строку после него. Поэтому в итоге в файле оказываются обе строки:

```
line1
line2
```

Без `:append` второй вызов перезаписал бы файл. Осталась бы только `line2`. Дописывание полезно, например, для файлов журнала. Каждый запуск программы добавляет что-то к растущей истории, а не начинает её заново.
