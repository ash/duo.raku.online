## Задача

Используйте дескриптор стандартного вывода `$*OUT`. Напечатайте буквы `a` и `b` с помощью `print`, который не добавляет перевод строки. Затем напечатайте букву `c` с помощью `say`. Все три буквы должны оказаться на одной строке.

## Пример

Программа печатает:

```
abc
```
