## Задача

Программа работает со значением, и оно оказывается отрицательным. Если значение меньше нуля, используйте `note`, чтобы отправить предупреждение в стандартный поток ошибок. Используйте `say`, чтобы отправить настоящий результат, абсолютное значение, в стандартный вывод. Возьмите значение `-3`.

## Пример

На экране появляются обе строки:

```
Warning: the value is negative
3
```

Если вы отбросите стандартный поток ошибок, останется только результат:

```
$ raku note-a-warning.raku 2>/dev/null
3
```
