## Задача

Программа в цикле складывает список чисел `3, 5, 7`. На каждом проходе отправляйте текущую накопленную сумму в стандартный поток ошибок как сообщение о ходе работы. После цикла отправьте итоговый результат в стандартный вывод. Используйте дескрипторы потоков напрямую.

Такое разделение важно. Результат можно сохранить или передать дальше в другую программу. А сообщения о ходе работы при этом остаются в стандартном потоке ошибок и не мешают.

## Пример

Когда вы запускаете программу, на экране появляются оба потока. Сначала идут накопленные суммы, а потом итоговый результат:

```
running total: 3
running total: 8
running total: 15
15
```

Но если вы отбросите стандартный поток ошибок, останется только настоящий результат:

```
$ raku output-and-error.raku 2>/dev/null
15
```
