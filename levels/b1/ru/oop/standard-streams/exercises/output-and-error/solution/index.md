Вот одно возможное решение.

## Код

```raku
my @data = 3, 5, 7;

my $sum = 0;
for @data -> $n {
    $sum += $n;
    $*ERR.say("running total: $sum");
}

$*OUT.say($sum);
```

🦋 Исходный код можно найти в файле [output-and-error.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/standard-streams/output-and-error.raku).

## Вывод

На экране появляются оба потока. Сначала идут накопленные суммы, а потом итоговый результат:

```
running total: 3
running total: 8
running total: 15
15
```

Если вы отбросите стандартный поток ошибок, останется только настоящий вывод:

```
$ raku output-and-error.raku 2>/dev/null
15
```

## Комментарии

1. `$*OUT` и `$*ERR` — это дескрипторы стандартного вывода и стандартного потока ошибок. У каждого из них есть свой метод `say`.

1. Каждый проход прибавляет следующее число и пишет накопленную сумму в `$*ERR`. В `$*OUT` уходит только итоговая сумма. На экране ход работы и результат выглядят одинаково. Но они идут по разным потокам. Поэтому, когда `2>/dev/null` убирает стандартный поток ошибок, остаётся только итоговое `15`.
