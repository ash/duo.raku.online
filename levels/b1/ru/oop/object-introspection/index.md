В [разделе о контейнерах](/ru/advanced/containers) вы использовали `.^name`, чтобы спросить у значения его тип. С теми же метавызовами `.^` можно заглянуть внутрь класса и его объектов. Можно увидеть их имена, их атрибуты и их место в иерархии классов.

Метаметод `.^name` возвращает имя класса:

```raku
class Dog {
    has Str $.name;
    method bark { 'Woof' }
}

say Dog.^name; # Dog
```

Метаметод `.^attributes` перечисляет атрибуты класса. Вы видите каждый из них с его типом и внутренним приватным именем. Это та форма `$!`, которую вы встречали в [приватных атрибутах](/ru/oop/methods/private-attributes):

```raku
say Dog.^attributes; # (Str $!name)
```

Интроспекция полезна для инструментов, которые работают с любыми объектами. Например, такой инструмент может напечатать каждый атрибут объекта. Ему не нужно заранее знать класс. Следующая тема показывает, как увидеть цепочку наследования класса.
