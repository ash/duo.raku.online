Если класс наследует от другого, можно запросить всю его цепочку типов. Метаметод `.^mro` возвращает эту цепочку. Название расшифровывается как _method resolution order_, порядок разрешения методов. Это порядок, в котором Raku ищет метод.

```raku
class Animal {
}

class Dog is Animal {
}

say Dog.^mro; # ((Dog) (Animal) (Any) (Mu))
```

Читайте список слева. `Dog` — это сначала он сам, затем `Animal` (его родитель), а затем `Any` и `Mu`. Эти два типа стоят на самом верху, и от них наследует каждый объект Raku. При вызове метода у `Dog` Raku просматривает этот список слева направо. Он берёт первый подходящий метод, который находит. Именно поэтому метод потомка переопределяет метод родителя. Потомок стоит в цепочке раньше.

Если у класса нет родителя, которого вы указали сами, цепочка короче. В ней только сам класс, а за ним `Any` и `Mu`.
