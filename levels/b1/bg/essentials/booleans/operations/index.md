С булеви стойности можете да използвате всички стандартни операции. Това са булево И, ИЛИ и изключващо ИЛИ (наричано също XOR):

```raku
say False && True; # И
say False || True; # ИЛИ
say False ^^ True; # XOR
```

Програмата отпечатва тези резултати:

    False
    True
    True

## Отрицание

Отрицанието превръща булевата стойност в обратната. За да отречете стойност, използвайте префиксния оператор `!`:

```raku
say !False; # True
```

Можете да съхранявате булеви стойности в скаларни променливи:

```raku
my $did = True;
my $didn't = !$did;
```
