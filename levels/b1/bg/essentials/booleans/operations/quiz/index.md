Във всяка секция по-долу изберете отговора, който показва какво отпечатва програмата.

## 1

Ето програмата:

```raku
my $value = True && False;
say $value;
```

Какво отпечатва?

{:.quiz}
0 | True
1 | False

## 2 

Какво отпечатва втората програма?

```raku
my $value = True && False || True;
say $value;
```

{:.quiz}
1 | True
0 | False

## 3

Какъв е изходът на тази програма?

```raku
my $value = True || False && True;
say $value;
```

{:.quiz}
1 | True
0 | False

{% include quiz.html %}

## Коментари

Втората и третата програма имат изрази с три булеви стойности. Резултатът зависи от реда, в който Raku изпълнява операциите. Операторът `&&` има по-висок приоритет от `||`, така че Raku го изпълнява първо.
