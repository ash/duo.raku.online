За да решим втората част на упражнението, нека разширим програмата. Можем да използваме същата променлива отново:

## Код

```raku
my $value = False;
say !!$value;

$value = True;
say !!$value;
```

🦋 Можете да намерите пълния код във файла [double-negation.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/booleans/double-negation.raku).

## Коментари

Преди да стартирате програмата, нека помислим какво ще отпечата тя. Преди променливата има два оператора за отрицание. Те работят като две отделни отрицания. В първия случай стойността се променя от `False` на `True`. След това веднага се връща обратно от `True` на `False`. Вторият случай работи по същия начин. След две отрицания получаваме първоначалната булева стойност.

## Изход

Програмата отпечатва следния изход, който показва, че сме били прави:

```console
$ raku exercises/booleans/double-negation.raku
False
True
```
