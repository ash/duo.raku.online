---
title: Ограничения на типове
---

{% include menu.html %}

Raku има така наречената постепенна типова система. В повечето случаи не е нужно да се притеснявате за типа на променливата. Но понякога може да искате да ограничите променлива до един тип. Можете да го направите, като зададете типа, както е показано по-долу:

```raku
my Int $var = 42;
```

Сега можете да присвоите друга целочислена стойност на `$var`. Но ако опитате да сложите низ в нея, получавате изключение. Същото става дори с число с плаваща запетая:

```raku
my Int $var = 42;
$var = '314E-2';
```

Тази програма дава следната грешка:

    Type check failed in assignment to $var; expected Int but got Str ("314E-2")
      in block <unit> at t.raku line 2
