---
title: Четене на аргументите на командния ред
---

{% include menu.html %}

Функцията `MAIN` ясно отбелязва началото на програмата, което е полезно. Но тя е полезна и защото нейните аргументи получават стойностите от командния ред.

Можете да четете аргументи от командния ред по два начина. Първият е масивът [`@*ARGS`](/bg/essentials/positionals/args-array), който вече използвахме. Сега нека разгледаме втория начин.

Ето програма, която събира две числа.

```raku
sub MAIN($a, $b) {
    say $a + $b;
}
```

Ето как можете да стартирате програмата. Тя отпечатва сумата на двата си аргумента:

```console
$ raku t.raku 123 45
168
```

Като всяка друга функция, `MAIN` може да има стойности по подразбиране за аргументите си. Това е възможно за някои от тях или дори за всички. Например:

```raku
sub MAIN($a, $b = 100) {
    say $a + $b;
}
```

Ако не подадете втория аргумент, програмата използва стойността по подразбиране:

```console
$ raku t.raku 15
115
```
