---
title: Множество функции `MAIN`
---

{% include menu.html %}

Като всяка друга функция в Raku, функцията `MAIN` може да има `multi` варианти. С тях програмата може да реагира на всеки случай по свой начин. Случаите могат да се различават по броя на входните параметри или по техните типове.

```raku
multi sub MAIN($a) {
    say 2 * $a;
}

multi sub MAIN($a, $b) {
    say $a + $b;
}
```

Ако има само един аргумент, тази програма го удвоява. Ако има и втори аргумент, програмата събира двата аргумента:

```console
$ raku t.raku 21
42

$ raku t.raku 21 33
54
```
