Двойката е структура от данни, която пази заедно име и стойност. Те образуват един обект, който можете да съхраните в скаларна променлива. Ето как създавате двойка:

```raku
my $pair = name => 'Anna';
```

Типът на променливата `$pair` е `Pair`:

```raku
say $pair.WHAT; # (Pair)
```

Можете да вземете името и стойността поотделно с методите `key` и `value`:

```raku
say $pair.key; # name
say $pair.value; # Anna
```

Важна черта на двойките е, че те са неизменяеми. Това означава, че не можете да дадете нова стойност или ново име на съществуваща двойка. Но, разбира се, можете да присвоите съвсем нова двойка на същата променлива:

```raku
my $pair = name => 'Anna';
$pair = name => 'John';
say $pair.value; # John
```

## Индексиране

Има и друг начин да прочетете стойността на двойка. Можете да я индексирате с името на нейния ключ в ъглови скоби. Ето как:

```raku
say $pair<name>;
```

Забележете, че не ви трябват кавички около ключа, ако в него няма интервали. Ако има интервали, правилата са малко по-строги:

```raku
my $pair = 'employee name' => 'Julie Madelon';
say $pair{'employee name'};
```

Обърнете внимание: този път използваме къдрави скоби.
