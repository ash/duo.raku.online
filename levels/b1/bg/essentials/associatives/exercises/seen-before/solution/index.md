Тази задача е класически пример за използване на хеш, за да следите елементите. Преди цикъла програмата създава хеша `%seen`. Вътре в цикъла въведената дума `$word` служи за ключ на хеша.

## Код

Ето решението:

```raku
my %seen;
loop {
    my $word = prompt 'Дума: ';
    if %seen{$word} {
        say %seen{$word} == 1 ?? 'Виждано!' !! say "Виждано %seen{$word} пъти!";
    }
    %seen{$word}++;
}
```

🦋 Намерете програмата във файла [seen-before.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/associatives/seen-before.raku).

## Коментар

Конструкцията `%seen{$word}++` не само добавя 1 към стойността. Тя също създава стойността, ако преди я е нямало. Създаването на стойност по този начин се нарича _автовивификация_. Забележете, че само _четенето_ на стойността, както в условието `if %seen{$word}`, не я създава.
