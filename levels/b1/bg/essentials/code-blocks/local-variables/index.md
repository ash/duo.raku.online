---
title: Локални променливи
---

{% include menu.html %}

Нека декларираме променлива в глобалния обхват. Какво става, ако я декларираме и локално в блока?

```raku
my $x = 1;

{
    my $x = 42;
    say $x;
}

say $x;
```

Сега в програмата има две отделни променливи. И двете се казват `$x`. В глобалния обхват `$x` винаги означава глобалната променлива. Но вътре в блока `$x` е друга, локална променлива. Програмата отпечатва две различни стойности:

```console
$ raku t.raku
42
1
```
