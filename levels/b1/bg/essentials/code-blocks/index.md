title: Кодови блокове
---

{% include menu.html %}

Кодовите блокове са части от вашата програма, които стоят в чифт къдрави скоби: `{` и `}`. Блокът групира няколко израза, които работят заедно като един голям израз. В следващите раздели ще видим много начини да използваме блоковете.

```raku
{
    say 'Hello, World!';
}
```

Кодовият блок в тази програма всъщност няма голям смисъл. Но кодовите блокове са много полезни в други ситуации, които ще видим много скоро.

Но първо, нека разгледаме идеята за _обхват_.
