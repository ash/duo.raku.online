---
title: Блокове `if`
---

{% include menu.html %}

Условната проверка `if` гледа едно условие. Когато условието е `True`, се изпълнява блок от код.

```raku
if 10 > 4 {
    say 'Математиката работи!';
}
```

Забележете, че не е нужно да поставяте условието в скоби. Но можете, ако искате.

Разбира се, спокойно можете да използвате променливи в тестовете:

```raku
my $flag = False;
if $flag {
    # . . . направете нещо
}
```

Ако няколко проверки използват една и съща променлива, можете да свържете сравненията във верига:

```raku
my $x = 42;
if 40 < $x < 45 {
    say "Даден е правилният отговор $x.";
}
```

Ако условието не е изпълнено, неговият блок от код не се изпълнява. След това програмата продължава както обикновено.

```raku
say 'Начало';
if False {
    say 'Това никога не се отпечатва.';
}
say 'Край';
```

Тази програма просто отпечатва `Начало` и `Край`.
