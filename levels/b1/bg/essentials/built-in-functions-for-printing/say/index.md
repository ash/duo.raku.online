Ето какво прави вградената рутина `say`:

1. Извиква метода `gist` върху своите аргументи.
1. Добавя нов ред.
1. Преобразува резултата в UTF-8.
1. Изпраща го към потока `STDOUT`.

За потребителя това изглежда просто. `say` само отпечатва съдържанието на променлива в терминала и добавя нов ред.

Първата стъпка изисква малко обяснение. Всеки вграден тип данни, като цели числа или низове, има метод `gist`. За такива прости типове той връща стойност, която представя елемента. Хората могат лесно да четат тази стойност.

```raku
say 42; # 42
say 'Raku'; # Raku
```

Масивите и хешовете са примери за по-сложни данни. За тях методът `gist` добавя малко форматиране.

```raku
my @data = 'alpha', 'beta', 'gamma';
say @data; # [alpha beta gamma]

my %data = alpha => 1, beta => 2, gamma => 3;
say %data; # {alpha => 1, beta => 2, gamma => 3}
```

Можете да извикате `say` както като функция, така и като метод:

```raku
say 42;
say(42);
42.say;
```

Можете да подадете няколко аргумента на `say`. Тя съединява частите на изхода без никакви интервали между тях.

```raku
say(100, 500); # 100500
```
