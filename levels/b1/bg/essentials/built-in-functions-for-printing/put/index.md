Рутината `put` върши същата работа като [`print`](../print). Но по подразбиране тя добавя и нов ред накрая:

1. Извиква метода `Str` върху аргументите си, за да ги преобразува в низ.
1. Добавя символ за нов ред.
1. Изпраща низа към потока `STDOUT`.

Няколко примера:

```raku
42.put;
put 'Alpha', 'Beta';

my @array = 3, 4, 5;
put @array;

my %hash = a => 'b', c => 'd';
%hash.put;
```

Ето какво отпечатва програмата:

```console
$ raku t.raku
42
AlphaBeta
3 4 5
a	b
c	d
```

%%tipblock
## Нов ред на `put`

`put` добавя някои символи след изхода. Точните символи идват от метода `nl-out` на изходния поток. Неговата стойност по подразбиране е `\n`.
%%/tipblock
