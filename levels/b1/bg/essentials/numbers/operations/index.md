Със сигурност вече знаете някои от операциите с числа в Raku. Нека само споменем, че символът на _операцията_ се нарича _оператор_. Обектите, с които работи една операция, се наричат _операнди_.

## Арифметика

**Оператор** | **Операция**
`+` | Събиране
`-` | Изваждане
`*` | Умножение
`/` | Деление

Тъй като Raku [поддържа Unicode](/bg/essentials/on-unicode) много добре, някои от тези оператори имат и не-ASCII версии:

`×` | Умножение
`÷` | Деление

За да промените реда, в който се изпълняват операциите, използвайте скоби:

```raku
say 3 * 4 + 5;   # 17
say 3 * (4 + 5); # 27
```

## Модуло

Както в много други езици, операторът за модуло е `%`.

`%` | Модуло

Той връща остатъка от целочисленото деление на две числа, така че `10 % 3` е `1`. Забележете, че `-10 % 3` е `2` заради начина, по който е определена операцията. Резултатът от делението се закръгля надолу и се умножава по второто число. След това тази стойност се изважда от първото число. Така `$a % $b` означава същото като `$a - $b * floor($a / $b)`.

## Делимост

Raku добавя още един полезен оператор. Той проверява дали едно число се дели на друго.

`%%` | Делимост

Това е инфиксен оператор: той стои между двата си операнда, както в `10 %% 3`. Ако първият операнд се дели на втория, получавате булево `True`. Иначе получавате `False`.

## Целочислени операции

Някои специални операции връщат цели числа като резултат. Техните оператори са думи вместо символи.

`div` | Целочислено деление
`mod` | Целочислено модуло

Операторът `div` закръгля резултата надолу. Така `10 div 3` е `3`, а `-10 div 3` е `-4`.

И `div`, и `mod` очакват целочислени операнди. Затова програмата по-долу няма да работи, ако разкоментирате редовете, маркирани с `Error`:

```raku
say 10.3 % 3;     # OK
# say 10.3 mod 3; # Error

say 10.3 / 3.3;     # OK
# say 10.3 div 3.3; # Error
```

## Степенуване

Можете да получите _x_ на степен _y_ по два начина. Първо, можете да използвате оператора `**`:

```raku
say 3 ** 4; # 81
```

Второ, можете да използвате надписани цифри, тоест малки повдигнати цифри. Например:

```raku
say 3⁴; # 81
```

Можете да използвате повече от една надписана цифра, за да получите степен, по-голяма от 9. Например:

```raku
say 2¹⁵; # 32768
```

Отрицателните степени също не са проблем:

```raku
say 2 ** (-2); ## 0.25
say 2⁻²; # 0.25
```

Забележете, че в последните два израза резултатът е число от тип `Rat`.

## Операции с присвояване

Когато трябва да обновите променлива, всички операции имат кратка форма. Нека я покажем с примера на `+`.

Пълната форма

```raku
$a = $a + $b;
```

означава същото като:

```raku
$a += $b;
```
