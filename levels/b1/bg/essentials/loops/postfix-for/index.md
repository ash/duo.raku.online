---
title: Постфиксна форма на `for`
---

{% include menu.html %}

Вече видяхте други модификатори на изрази: [`if` и `else`](/bg/essentials/conditional-checks/modifiers) и [`while` и `until`](/bg/essentials/loops/modifiers). Това е малък повод за празнуване: дизайнът на Raku е много последователен.

При кратко тяло на цикъла можете да използвате постфиксната форма на `for`:

```raku
.say for 1..7;
```

Както виждате, диапазоните се съчетават много добре с постфиксния `for`.

Тази програма прави същото като един по-обичаен вариант:

```raku
for 1..7 -> $n {
    say $n;
}
```

Или, ако използвате стандартната променлива на цикъла, същото като това:

```raku
for 1..7 {
    .say;
}
```

Тук `.say` е кратка форма на `$_.say`.
