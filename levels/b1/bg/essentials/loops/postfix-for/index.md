---
title: Постфиксна форма на `for`
---

{% include menu.html %}

Вече видяхме други модификатори на изрази: [`if` и `else`](/bg/essentials/conditional-checks/modifiers) и [`while` и `until`](/bg/essentials/loops/modifiers). Това е повод за малко празнуване, защото дизайнът на Raku е много последователен.

Когато тялото на цикъла е кратко, можете да напишете цикъла `for` в постфиксна форма:

```raku
.say for 1..7;
```

Както виждате, диапазоните изглеждат много естествено с постфиксната форма на `for`.

Тази програма е същата като по-традиционния вариант:

```raku
for 1..7 -> $n {
    say $n;
}
```

Или, ако използвате стандартната променлива на цикъла, е същата като:

```raku
for 1..7 {
    .say;
}
```

Тук `.say` е кратката форма на `$_.say`.
