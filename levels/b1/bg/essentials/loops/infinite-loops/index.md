Можете да използвате `loop` и само с тяло:

```raku
loop {
    say 'Вечност';
}
```

Този цикъл работи безкрайно, докато не спрете програмата, например като натиснете `Ctrl+C`. Във втората част на курса ще видим по-добри начини за контрол на циклите.
