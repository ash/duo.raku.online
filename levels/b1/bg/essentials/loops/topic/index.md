---
title: Тематична променлива
---

{% include menu.html %}

`$_` е специална променлива, наречена _променлива за тема_.

Разгледайте този цикъл върху диапазон:

```raku
for 1..5 -> $n {
    say $n;
}
```

Можете да пропуснете променливата `$n` и тогава Raku използва вместо нея автоматична променлива, `$_`. Програмата е същата като тази:

```raku
for 1..5 {
    say $_;
}
```

Както [помните](/bg/essentials/hello-world/), можете да използвате `say` и като метод:

```raku
for 1..5 {
    $_.say;
}
```

Когато извиквате метод върху `$_`, не е нужно да пишете самата променлива. Така нашият цикъл може да стане още по-прост:

```raku
for 1..5 {
    .say;
}
```
