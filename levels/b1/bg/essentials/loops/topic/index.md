title: Тематична променлива
---

{% include menu.html %}

`$_` е специална променлива. Тя се нарича _променлива за тема_.

Ето цикъл върху диапазон:

```raku
for 1..5 -> $n {
    say $n;
}
```

Можете да пропуснете променливата `$n`. Тогава Raku автоматично използва вместо нея променливата `$_`. Така програмата е същата като тази:

```raku
for 1..5 {
    say $_;
}
```

Както [помните](/bg/essentials/hello-world/), можете да извиквате `say` и като метод:

```raku
for 1..5 {
    $_.say;
}
```

За да извикате метод върху `$_`, не е нужно да пишете самата променлива. Така можем да направим нашия цикъл още по-прост:

```raku
for 1..5 {
    .say;
}
```
