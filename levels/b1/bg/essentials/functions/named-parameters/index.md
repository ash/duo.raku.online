За разлика от [позиционните параметри](../positional-parameters), _именуваните_ параметри се разпознават по техните имена.

Тази функция има два параметъра, наречени `$from` и `$to`.

```raku
sub distance(:$from, :$to) { $from - $to }
```

За да извикате тази функция, трябва да напишете имената на аргументите:

```raku
say distance(from => 30, to => 10); # 20
```

Ако предадете аргументите, сякаш са позиционни, получавате грешка. Например извикването `distance(30, 10)` предизвиква грешка:

    Прекалено много позиционни аргументи; очаквани 0 аргумента, но получени 2
        в sub distance на ред 1 в t.raku
        в блок <unit> на ред 2 в t.raku

Хубавото е, че можете да изброявате именуваните аргументи в произволен ред. Следните две извиквания са напълно еднакви:

```raku
say distance(from => 30, to => 10); # 20

say distance(to => 10, from => 30); # 20
```

## Предаване на променливи

Понякога стойността, която искате да предадете, се пази в променлива. Тази променлива може да има и същото име като параметъра. Тогава можете да се възползвате от специален синтаксис, който спестява писане:

```raku
my $from = 30;
my $to = 10;
say distance(:$from, :$to); # 20
```

Това е подобно на по-дълго извикване:

```raku
say distance(from => $from, to => $to); # 20
```

Отново, тук редът няма значение:

```raku
say distance(:$to, :$from); # 20
```

Ако имената на променливата и параметъра са различни, предайте двойка. Използвайте един от тези начини:

```raku
my $a = 20;
my $b = 10;

say distance(from => $a, to => $b);

# или:

say distance(:from($a), :to($b));
```
