Сега е време да предадем някакви данни на функция. Функцията може да приема параметри, които изброявате в скоби веднага след нейното име.

```raku
sub greet($name) {
    say "Здравей, $name!";
}
```

Сега можете да използвате функцията и да ѝ предавате различни аргументи:

```raku
greet('Алла');
greet('Карл');
```

Сега двете извиквания на една и съща функция дават различни резултати:

```console
$ raku t.raku
Здравей, Алла!
Здравей, Карл!
```

%%tipblock

## Параметър или аргумент

Хората често използват тези два термина, сякаш означават едно и също. И двата се отнасят до ‘едно и също нещо’, но от различни гледни точки.

* Параметър е това, което функцията очаква.
* Аргумент е това, което предавате на нея.

В горния пример `$name` е параметърът на функцията. Нейните аргументи са `'Алла'` и `'Карл'`.

%%/tipblock

## Повече параметри

Функцията може да приема повече от един параметър. В този случай ги изброете всичките, със запетаи между тях:

```raku
sub add($x, $y) {
    say $x + $y;
}

add(10, 20); # 30
```

## Без параметри

Нормално е функцията да не приема никакви параметри. Тогава можете или да добавите празни скоби, или да ги пропуснете напълно. Ние ги пропуснахме в [началото на тази секция](../).

```raku
sub greet() {
    say 'Здравей, свят!';
}

greet();
```
