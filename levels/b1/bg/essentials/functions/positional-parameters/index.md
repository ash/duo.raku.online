---
title: Позиционни параметри
---

{% include menu.html %}

Редът на параметрите на функцията има значение. Например, нека създадем функция, която изчислява разликата между две числа:

```raku
sub diff($a, $b) { $a - $b }
```

Ясно е, че извикването `diff(10, 20)` дава различен резултат от `diff(20, 10)`.

Параметрите в списък със запетаи, както във функцията по-горе, се наричат _позиционни_. Тяхното значение зависи от реда на аргументите, когато извиквате функцията.
