И позиционните, и именуваните параметри могат да имат стойности по подразбиране. Ако даден параметър има стойност по подразбиране, можете да го пропуснете при извикване на функцията.

## Позиционни параметри

Ето пример за стойност по подразбиране на позиционен параметър:

```raku
sub greet($name = 'World') {
    say "Hello, $name!";
}

greet('Merinda');
greet();
```

В първото извикване името е единственият аргумент, затова резултатът е `Hello, Merinda!`. Второто извикване използва стойността по подразбиране и отпечатва `Hello, World!`.

Ако функцията има няколко параметъра, само последните от тях могат да имат стойности по подразбиране:

```raku
sub f($a, $b, $c = 42, $d = 50) { . . . } # правилно
# sub f($a = 10, $b = 20, $c, $d) { . . . } # ГРЕШНО
```

## Именувани параметри

Стойностите по подразбиране за именувани параметри задавате със същия синтаксис:

```raku
sub greet(:$name = 'World') {
    say "Hello, $name!";
}

greet(name => 'Merinda'); # Hello, Merinda!
greet(); # Hello, World!
```

Редът на именуваните параметри няма значение. Затова всеки от тях може да има стойност по подразбиране, дори първият:

```raku
sub greet(:$greeting = 'Hello', :$name) {
    say "$greeting, $name!";
}

greet(name => 'Alla'); # Hello, Alla!
```
