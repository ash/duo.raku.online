Функциите често правят нещо и също така връщат резултат. Например във функционалното програмиране функциите не трябва да имат странични ефекти. Печатането на конзолата е такъв страничен ефект. Но Raku не ви спира да го правите. Нека видим как функцията връща стойност. Ще видим също как извикващият код я получава.

```raku
sub add($x, $y) {
    return $x + $y;
}

my $sum = add(10, 20);
say $sum; # 30
```

Тук функцията `add` приема две числа и връща тяхната сума. Тя използва явен `return`. Извикващият код може да използва върнатата стойност като всяка друга стойност. В програмата по-горе тя се присвоява на променлива.

## Последната изчислена стойност

В Raku явен `return` не винаги е необходим. Можете да го пропуснете, когато резултатът е последната стойност, която функцията изчислява. Затова нашата функция `add` може да бъде по-проста:

```raku
sub add($x, $y) {
    $x + $y
}
```

Може би сте забелязали, че редът няма точка и запетая в края. Тя не е нужна, защото този ред завършва блока код.

Малки и прости функции като тази често се пишат на един-единствен ред. Това прави кода по-компактен:

```raku
sub add($x, $y) { $x + $y }
```

## Няма данни за връщане

Понякога трябва да излезете от функцията преди края на нейното тяло. Ако функцията не връща никакъв резултат, използвайте само `return`.

```raku
sub test($x) {
    return if $x <= 10;
    say "$x е над лимита";
}
```
