Raku има _многократно разпределение_ според подписа на функцията. То ви позволява да създавате функции с едно и също име, но с различни типове входни данни. Използвайте декларатора `multi` за всеки вариант на функцията.

```raku
multi sub add(Int $x, Int $y) { $x + $y }
multi sub add(Str $x, Str $y) { $x ~ $y }
```

Не е проблем да пропуснете `sub` след `multi`.

Когато има два варианта на една и съща функция, компилаторът извършва многократно разпределение. Неговият избор зависи от това какви аргументи вижда в извикването на функцията. Сравнете тези две извиквания:

```raku
say add(10, 20); # 30
say add('10', '20'); # 1020
```

Първото извикване изпълнява варианта с целочислени параметри. Второто извикване изпълнява другия вариант, който очаква два низа.

## Литерални параметри

Интересно използване на мулти-функциите са варианти с литерални стойности като параметри. Разгледайте следните два варианта:

```raku
multi sub f(42) {say 'Това е отговорът'}
multi sub f($x) {say "$x не е отговорът"}
```

Първият вариант се изпълнява само когато извикате функцията с точно 42. Във всички други случаи Raku използва втория вариант. Няма значение в какъв ред са дефинирани тези функции.

```raku
f(10); # 10 не е отговорът
f(42); # Това е отговорът
```
