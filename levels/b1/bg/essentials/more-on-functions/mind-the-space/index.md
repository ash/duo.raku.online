В Raku използването на функции е предимно лесно и не създава проблеми. Но трябва да ви предупредим за едно нещо.

## TL;DR

Не слагайте интервал между името на функцията и скобите с нейните аргументи. Но след `for` и `if` използвайте интервал.

## Дълга история

Нека вземем една проста функция:

```raku
sub f($x, $y) {
    return $x + $y;
}
```

Първо, обърнете внимание, че след името на функцията няма интервал. Отварящата скоба с параметрите идва веднага след името. Някои стилове на кодиране в други езици може да изискват интервал там. Raku го приема, но това не е добра практика, която да следвате:

```raku
sub f ($x, $y) {
    return $x + $y;
}
```

Когато извиквате функцията, липсата на интервал е важна. Ако извиквате функцията без скоби, след нейното име трябва да има интервал:

```raku
f 5, 6;
```

Но ако използвате скоби, преди тях не може да има интервал. Това извикване е правилно:

```raku
f(5, 6);
```

А това извикване е грешно:

```raku
f (5, 6);
```

Такъв код предизвиква изключение:

    Too few positionals passed; expected 2 arguments but got 1
      sub f at t.raku line 1
      in block <unit> at t.raku line 5

Raku вижда извикването с интервал, `f (5, 6)`, по различен начин. Raku смята, че искате да предадете един-единствен аргумент, `(5, 6)`, на функцията. Лесно е да проверите типа на този аргумент. Просто променете функцията така, че да приема само един аргумент:

```raku
sub f($param) {
    say $param.WHAT;
}

f (5, 6); # (List)
```

Така че, когато извиквате `f (5, 6)`, предавате [списък](/bg/essentials/positionals/lists) на функцията. Списъкът се предава като един елемент.

## Кога е нужен интервал

В някои случаи интервалът наистина е нужен. Това се случва, когато използвате скоби с ключова дума като `if`, `for` или `loop`. Следният код е грешен:

```raku
if(True != False) {
    say 'OK';
}
```

Съобщението за грешка обяснява проблема:

    ===SORRY!===
    The word 'if' is interpreted as a 'if()' function call.  Please use
    whitespace instead of parentheses.
    at /Users/ash/raku-course/t.raku:1
    ------> if⏏(True != False) {
    Unexpected block in infix position (two terms in a row)
    at /Users/ash/raku-course/t.raku:1
    ------> if(True != False)⏏ {

С `if` изобщо не са ви нужни скоби. Така че, ако не ги използвате, проблемът не може да се появи. Но в някои случаи те са нужни, например с `loop`. Тогава интервалът е задължителен:

```raku
loop(my $c = 0; $c != 10; $c++) { say $c }
```

В този код се случва същото: компилаторът приема `loop(...)` за извикване на функция. Добавете интервал, за да решите проблема. Или, още по-добре, пренапишете тази част от кода с `for`.

## Заключение

Накратко, за да избегнете такива проблеми, спазвайте две правила. Не слагайте интервал между името на функцията и скобите с нейните аргументи. Също така, опитайте да избягвате скобите в други части на езика, например в контролния поток.
