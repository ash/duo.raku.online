Тази кратка секция обяснява как да стартирате програма в самото IDE. Тя разглежда двете най-препоръчвани [IDE-та](../../editors-and-ides).

## Visual Studio Code Editor

Отворете терминал с менюто `Terminal` → `New Terminal`. Това добавя панел под текста на вашата програма. Стартирайте програмата там, точно както от командния ред:

```console
$ raku hello.raku
```

## Comma IDE

Можете да стартирате програми от менюто `Run`. Настройте IDE преди първото стартиране на програма. Следвайте [инструкциите](https://commaide.com/docs/running) на уебсайта на Comma.
