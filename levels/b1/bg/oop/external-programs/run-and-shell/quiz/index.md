Коя функция изпраща командата си през системната **обвивка** и позволява канали и пренасочване?

{:.quiz}
0 | `run`
1 | `shell`
0 | `exec`
0 | `system`

{% include quiz.html %}

<div class="extended-explanation">

`shell` подава един-единствен низ на обвивката, която разбира възможности като каналите. `run` стартира програма направо, с отделни аргументи и без обвивка. Това е по-безопасно, затова `run` е по-добрият избор по подразбиране.

</div>
