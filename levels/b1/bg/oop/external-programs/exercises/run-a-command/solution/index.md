Ето едно възможно решение.

## Код

```raku
run 'echo', 'home:', '$HOME';
```

🦋 Намерете програмата във файла [run-a-command.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/external-programs/run-a-command.raku).

## Изход

```
home: $HOME
```

## Коментари

1. `run` стартира `echo` направо и подава всеки низ като отделен аргумент. Без `:out` изходът на програмата отива право на екрана.

1. Аргументът стига до `echo` точно както е написан. `$HOME` се отпечатва така, както е, а не се заменя с домашната ви директория. Това е така, защото няма обвивка, която да го замени. Затова `run` е безопасният избор по подразбиране. Същата команда, подадена на `shell`, би могла да се държи съвсем различно.

1. За да отпечатате наистина домашната директория, оставете обвивката да замени променливата. `shell 'echo home: $HOME'` отпечатва нещо като `home: /home/anna`. Запазете единичните кавички и от страна на Raku. Низ в двойни кавички `"$HOME"` би създал проблем. Самият Raku би се опитал да вмъкне в низа променлива на име `$HOME`. Това би станало, преди `echo` изобщо да е започнала работа.
