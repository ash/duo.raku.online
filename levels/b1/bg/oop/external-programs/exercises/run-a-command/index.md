## Задача

Използвайте `run`, за да стартирате `echo` с два отделни аргумента: `home:` и `$HOME`. Оставете изхода ѝ да отиде на екрана. Забележете, че `$HOME` се появява така, както е, а домашната директория **не** се отпечатва. Понеже `run` не използва обвивка, променливата не се заменя със стойността си.

## Пример

Програмата отпечатва:

```
home: $HOME
```
