## Задача

Изпълнете команда, която се проваля нарочно, например `sh -c 'exit 4'`. Запазете `Proc`, който тя връща. Отпечатайте кода на изход на командата. После отпечатайте `success` или `failure` в зависимост от това дали командата е успяла.

## Пример

Програмата отпечатва:

```
4
failure
```
