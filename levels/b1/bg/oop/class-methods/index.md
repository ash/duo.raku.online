Повечето методи се извикват върху обект, който е екземпляр на клас. Но можете да извикате метод и върху самия клас. С други думи, извиквате го върху обекта на типа. Често наричат такъв метод _метод на класа_. Той е полезен за стойности и операции, които принадлежат на целия клас. Те не принадлежат на един конкретен обект.

Дефинирате метод на класа точно по същия начин като всеки друг метод:

```raku
class Road {
    method speed-limit { 120 }
}
```

Но го извиквате върху името на класа, а не върху екземпляр:

```raku
say Road.speed-limit; # 120
```

Всъщност вече сте използвали метод на класа, без да го наричате така. `new` е метод, който извиквате върху класа, за да създадете нов обект.

Методът на класа не може да използва атрибутите на екземпляра, защото зад него няма конкретен обект. Затова той работи само с информация, която е обща за всички обекти от класа. Ако работата зависи от данните на един обект, използвайте обикновен метод. Извикайте го върху екземпляр. Ако не зависи, методът на класа е естественият избор.

Методите на класа нямат нужда от екземпляр. Все пак, когато имате обект, можете да използвате данните му в тях:

```raku
class Road {
    has $.name;
    method speed-limit { 120 }

    method info {
        "The maximum speed on $.name is " ~ self.speed-limit
    }
}

my $R404 = Road.new(name => 'Road 404');
say $R404.info;
```

Тази програма отпечатва резултата, който бихте очаквали:

```
The maximum speed on Road 404 is 120
```

Без обект от класа извикване като `say Road.info` би довело до грешка.
