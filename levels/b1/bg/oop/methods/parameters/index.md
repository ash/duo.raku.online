Също като подпрограмата, методът може да приема параметри. Слагате ги в скоби след името на метода:

```raku
class Account {
    has $.balance is rw = 0;

    method deposit($amount) {
        $.balance += $amount;
    }
}
```

Методът `deposit` приема един параметър, `$amount`. Той добавя тази сума към баланса на обекта:

```raku
my $a = Account.new;
$a.deposit(100);
$a.deposit(50);
say $a.balance; # 150
```

Всяко извикване работи върху обекта, върху който е извикано. Затова един и същ метод може да обновява различни обекти поотделно. Методите могат да имат позиционни и именувани параметри и стойности по подразбиране. Всъщност те могат да използват всичко, което вече видяхте в сигнатурите на подпрограмите.
