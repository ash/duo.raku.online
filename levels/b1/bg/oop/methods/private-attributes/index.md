В [раздела за атрибутите](/bg/oop/attributes) декларирахме всеки атрибут с `$.`. Това създава публичен аксесор. Ако вместо това декларирате атрибут с `$!`, той е _частен_. Той няма аксесор и не можете да го видите извън обекта. Само собствените методи на класа могат да стигнат до него. Там го пишете като `$!name`.

```raku
class Safe {
    has $!code = 4321;

    method unlocks($attempt) {
        return $attempt == $!code;
    }
}

my $safe = Safe.new;
say $safe.unlocks(4321); # True
say $safe.unlocks(1111); # False
```

Тайният `$!code` се пази вътре в обекта, но никога не се показва навън. Няма аксесор `.code`. Затова можете да работите с него само през метода `unlocks`. Класът сам избира да даде този метод. Ако се опитате да прочетете `$safe.code` или `$safe!code`, това просто не успява.

Частните атрибути са полезни за вътрешни подробности. Останалата част от програмата не бива да работи направо с тях.
