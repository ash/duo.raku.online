## Задача

Дефинирайте клас `Robot` с атрибут `position`, който може да се променя. Стойността му по подразбиране е `0`. Добавете метод `move`, който мести позицията напред с даден брой стъпки. Броят на стъпките трябва да е `1` по подразбиране. Тогава извикване на `move` без аргумент мести робота с една стъпка.

Създайте робот и го преместете с `5` стъпки. После го преместете без аргумент, а след това с още `2` стъпки. Отпечатайте крайната му позиция.

## Пример

Програмата отпечатва:

```
8
```
