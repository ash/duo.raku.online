Атрибутите дават на обекта неговите данни, а _методите_ му дават поведение. Методът е подпрограма, която принадлежи на клас. Извиквате го върху обект. Декларирате метод с ключовата дума `method`:

```raku
class Dog {
    has $.name;

    method bark {
        return $.name ~ ' says Woof!';
    }
}
```

За да извикате метод върху обект, използвайте точка, както при аксесор:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.bark; # Rex says Woof!
```

Вътре в метода `self` е обектът, върху който е извикан методът. Стигате до атрибутите през техните аксесори. Пишете ги като `$.name`, `$.age` и така нататък. Те работят и в низове с двойни кавички, където Raku вмъква стойностите им:

```raku
class Dog {
    has $.name;

    method greet {
        "Hello, my name is $.name";
    }
}

say Dog.new(name => 'Rex').greet; # Hello, my name is Rex
```

Следващите теми разглеждат частните атрибути, защото вече имаме методи, с които да ги използваме. След това те разглеждат методите, които приемат параметри, и методите, които извикват други методи.
