## Задача

Манипулаторът на файл е обикновена стойност. Затова можете да го подадете на функция като всеки друг аргумент. Напишете подпрограма `log-line`, която приема манипулатор и съобщение. Тя трябва да записва съобщението в манипулатора на отделен ред.

Отворете `log.txt` за писане. Извикайте `log-line` три пъти, за да запишете `started`, `working` и `done`. След това затворете манипулатора, прочетете файла обратно и отпечатайте съдържанието му.

## Пример

Програмата отпечатва:

```
started
working
done
```
