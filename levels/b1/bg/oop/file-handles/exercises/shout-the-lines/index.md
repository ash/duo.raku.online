## Задача

Запишете трите думи `apple`, `banana` и `cherry` във файл на име `words.txt`. Сложете всяка дума на отделен ред. След това прочетете файла ред по ред. Отпечатайте всеки ред с номера му отпред, като започнете от `1`. Използвайте вида `<номер>: <ред>`.

## Пример

Програмата отпечатва:

```
1: apple
2: banana
3: cherry
```
