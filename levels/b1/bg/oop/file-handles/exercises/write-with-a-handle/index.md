## Задача

Отворете файл на име `out.txt` за писане. Дръжте манипулатора отворен. С цикъл запишете в него числата `1`, `2` и `3`. Сложете всяко число на отделен ред. След това затворете манипулатора, прочетете файла обратно и отпечатайте съдържанието му.

## Пример

Програмата отпечатва:

```
1
2
3
```
