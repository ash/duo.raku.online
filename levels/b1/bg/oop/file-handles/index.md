Четенето или записването на цял файл наведнъж е лесно. Но понякога искате да минете през файла ред по ред. Или може да искате да държите файла отворен и да пишете в него много пъти. За това използвате _манипулатор на файл_.

Ето най-простия начин да четете файл ред по ред. За него дори не е нужно да създавате манипулатор. Методът `lines` на обекта-път ви дава редовете един по един. Те са готови за цикъл `for`:

```raku
spurt 'words.txt', "one\ntwo\nthree\n";

for 'words.txt'.IO.lines -> $line {
    say $line.uc;
}
```

Всеки `$line` е един ред без новия ред в края. Програмата отпечатва:

```
ONE
TWO
THREE
```

За да пишете чрез манипулатор, отворете файла с `open` и флага `:w` (write). След това използвайте методите `say` или `print` на манипулатора. Когато приключите, го затворете с `close`:

```raku
my $fh = open 'out.txt', :w;
$fh.say('first line');
$fh.say('second line');
$fh.close;
```

Когато затворите манипулатора, всичко, което сте записали, наистина се запазва на диска. Някои файлове са твърде големи, за да се заредят в паметта наведнъж. Тях обикновено ги четете ред по ред, както по-горе.
