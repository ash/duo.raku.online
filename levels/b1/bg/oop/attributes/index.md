Празният клас не е много полезен. За да може обектът да пази свои данни, дайте на класа _атрибути_. Декларирате атрибут вътре в класа с ключовата дума `has`:

```raku
class Dog {
    has $.name;
    has $.age;
}
```

Всеки обект от класа има свое собствено копие на тези атрибути. Задавате стойностите им, когато създавате обекта. За целта ги подайте на `new` като именувани аргументи:

```raku
class Dog {
    has $.name;
    has $.age;
}

my $rex = Dog.new(name => 'Rex', age => 3);
```

`$.` в `has $.name` върши две неща наведнъж. Декларира атрибут и създава метод със същото име. Този метод се нарича _аксесор_ и връща стойността на атрибута:

```raku
say $rex.name; # Rex
say $rex.age;  # 3
```

Различните обекти пазят свои собствени стойности, които не зависят една от друга:

```raku
my $rex  = Dog.new(name => 'Rex',  age => 3);
my $fido = Dog.new(name => 'Fido', age => 5);

say $rex.name;  # Rex
say $fido.name; # Fido
```

Следващите теми показват как да направите атрибутите променяеми. Те показват и как да дадете на атрибутите стойности по подразбиране. Има и начин да декларирате _частни_ атрибути, които са скрити отвън. Ще се върнем към тях, след като въведем методите.
