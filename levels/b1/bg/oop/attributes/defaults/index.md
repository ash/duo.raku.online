Можете да дадете на атрибута _стойност по подразбиране_. Тя се използва, когато създавате обект без стойност за този атрибут. Запишете стойността по подразбиране след атрибута, с `=`:

```raku
class Dog {
    has Str $.name;
    has Rat $.weight = 4.0;
}
```

Забележете, че можете да дадете тип на атрибутите, точно както при променливите.

Когато не подадете `weight` на `new`, атрибутът получава стойността си по подразбиране:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.weight; # 4
```

Пак можете да замените стойността по подразбиране, ако подадете стойност:

```raku
my $lighty = Dog.new(name => 'Lighty', weight => 3.2);
say $lighty.weight; # 3.2
```

Атрибут без стойност по подразбиране и без стойност от `new` просто е недефиниран. Той е точно като нова скаларна променлива.
