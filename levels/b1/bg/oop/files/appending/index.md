По подразбиране `spurt` заменя всичко, което е имало във файла. За да добавите вместо това в края на съществуващ файл, подайте именувания аргумент `:append`:

```raku
spurt 'log.txt', "line1\n";
spurt 'log.txt', "line2\n", :append;

print slurp 'log.txt';
```

Второто `spurt` запазва старото съдържание и добавя новия ред след него. Така накрая файлът съдържа и двата реда:

```
line1
line2
```

Без `:append` второто извикване би презаписало файла. Тогава би останал само `line2`. Добавянето е полезно за неща като журналните файлове. Всяко изпълнение на програмата добавя към растящ запис, вместо да започва отначало.
