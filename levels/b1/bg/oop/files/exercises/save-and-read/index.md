## Задача

Запазете число във файл и го заредете отново. Запишете числото `42` и нов ред във файл на име `number.txt`. След това прочетете файла обратно и превърнете съдържанието му в цяло число. Отпечатайте това число, умножено по две.

## Пример

Програмата отпечатва:

```
84
```
