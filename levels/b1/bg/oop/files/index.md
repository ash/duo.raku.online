В най-простия случай прочитате или записвате цял файл наведнъж.

Процедурата `spurt` записва низ във файл. Тя създава файла или заменя съдържанието му, ако файлът вече съществува:

```raku
spurt 'greeting.txt', "Hello, file!\n";
```

Процедурата `slurp` прочита целия файл обратно в низ:

```raku
my $text = slurp 'greeting.txt';
print $text; # Hello, file!
```

Заедно `spurt` и `slurp` запазват данни и ги зареждат отново само с две кратки извиквания. Тук използваме `print` вместо `say`, защото текстът вече завършва с нов ред.

Тези процедури работят с целия файл наведнъж. Те са най-добри за файлове, които са достатъчно малки, за да се поберат лесно в паметта. За по-големи файлове използвате [манипулатор на файл](/bg/oop/file-handles). Той ви трябва и за да работите с файл ред по ред. Ще разгледаме манипулаторите на файлове в края на този раздел. Следващата тема показва как да добавяте към файл, вместо да го заменяте.
