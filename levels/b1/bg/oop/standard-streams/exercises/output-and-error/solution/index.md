Ето едно възможно решение.

## Код

```raku
my @data = 3, 5, 7;

my $sum = 0;
for @data -> $n {
    $sum += $n;
    $*ERR.say("running total: $sum");
}

$*OUT.say($sum);
```

🦋 Намерете програмата във файла [output-and-error.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/standard-streams/output-and-error.raku).

## Изход

И двата потока се появяват на екрана. Първо идват междинните суми, а после крайният резултат:

```
running total: 3
running total: 8
running total: 15
15
```

Ако изхвърлите стандартната грешка, остава само истинският изход:

```
$ raku output-and-error.raku 2>/dev/null
15
```

## Коментари

1. `$*OUT` и `$*ERR` са манипулаторите за стандартния изход и стандартната грешка. Всеки от тях има свой собствен метод `say`.

1. Всяка обиколка добавя следващото число и записва междинната сума в `$*ERR`. Само крайната сума отива в `$*OUT`. На екрана напредъкът и резултатът изглеждат еднакво. Но те минават през различни потоци. Затова, когато `2>/dev/null` изпрати стандартната грешка настрани, остава само крайното `15`.
