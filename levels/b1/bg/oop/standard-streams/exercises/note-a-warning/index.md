## Задача

Една програма работи със стойност и стойността се оказва отрицателна. Ако стойността е под нулата, използвайте `note`, за да изпратите предупреждение в стандартната грешка. Използвайте `say`, за да изпратите истинския резултат, абсолютната стойност, в стандартния изход. Използвайте стойността `-3`.

## Пример

И двата реда се появяват на екрана:

```
Warning: the value is negative
3
```

Ако изхвърлите стандартната грешка, остава само резултатът:

```
$ raku note-a-warning.raku 2>/dev/null
3
```
