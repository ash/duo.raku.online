## Задача

Покажете как програмата може да се възстанови с помощта на `CATCH`. Тя продължава с разумна стойност по подразбиране.

Преди блок декларирайте променлива `$timeout` със стойност по подразбиране `30`. Вътре в блока направете `die 'config missing'`. После, на ред, който никога не се изпълнява, опитайте да зададете на `$timeout` стойност `60`. Използвайте фазер `CATCH`, чийто блок `default` отпечатва `warning: <съобщение>; keeping default`. След блока отпечатайте `timeout is <timeout> seconds`.

## Пример

Програмата отпечатва:

```
warning: config missing; keeping default
timeout is 30 seconds
```
