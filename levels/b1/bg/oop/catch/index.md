Блокът `try` е удобен, но третира целия блок като едно цяло. Блокът или работи, или не. Фазерът `CATCH` ви дава повече контрол. Той ви позволява да обработите изключение _вътре_ в блока, където то се е случило. После решавате какво да правите.

`CATCH` е фазер, като онези, които видяхте в [раздела за управлението на потока](/bg/advanced/phasers). Можете да го сложите където и да е вътре в блок. Той се изпълнява само ако в този блок бъде хвърлено изключение. Получавате изключението като тематичната променлива `$_`:

```raku
{
    die 'Boom!';

    CATCH {
        default {
            say 'Caught: ' ~ .message;
        }
    }
}

say 'after';
```

Програмата отпечатва:

```
Caught: Boom!
after
```

Блокът `default` вътре в `CATCH` обработва всяко изключение. След като той се изпълни, изключението се смята за обработено. Затова програмата не спира. Тя продължава след блока, който съдържа `CATCH`, и затова се отпечатва `after`.

Без `CATCH` `die` би спрял програмата, преди тя да стигне до `after`.
