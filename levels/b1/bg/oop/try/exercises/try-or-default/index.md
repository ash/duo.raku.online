## Задача

Блок `try`, който се проваля, дава недефинирана стойност. Използвайте това с оператора „определено или“ `//`, за да дадете резервна стойност. Изпълнете блок `try` с `die 'no'` вътре. Ако той се провали, използвайте вместо това низа `default`. Отпечатайте резултата.

## Пример

Програмата отпечатва:

```
default
```
