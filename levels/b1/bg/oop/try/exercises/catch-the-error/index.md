## Задача

Покажете двете страни на `try`. Първо използвайте блок `try` около изчисление, което успява, например `6 * 7`. После отпечатайте резултата му. След това сложете код, който прави `die 'broken'`, във втори блок `try`. Отпечатайте дали този блок е дал дефиниран резултат. После отпечатайте съобщението на прихванатото изключение.

## Пример

Програмата отпечатва:

```
42
False
broken
```
