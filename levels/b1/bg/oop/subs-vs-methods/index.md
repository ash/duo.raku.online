Вече имате два начина да организирате някакво поведение: _подпрограма_ и _метод_. Изглеждат подобни, но ги използвате по различен начин.

Подпрограмата стои сама за себе си. Извиквате я по име и ѝ подавате всичко необходимо като аргументи:

```raku
sub area-of($radius) {
    π * $radius * $radius;
}

say area-of(2); # 12.566370614359172
```

Методът принадлежи на клас. Извиквате го върху обект с точка. Той може да използва собствените данни на обекта чрез `self` и аксесорите на атрибутите. Затова не е нужно да му подавате тези данни:

```raku
class Circle {
    has $.radius;

    method area {
        π * $.radius * $.radius;
    }
}

say Circle.new(radius => 2).area; # 12.566370614359172
```

И двете изчисляват едно и също число. Разликата е откъде идват данните. Подпрограмата получава радиуса като аргумент. Методът го чете от обекта, върху който е извикан.

Ето едно просто правило. Използвайте подпрограма за отделна операция, която просто превръща аргументите си в резултат. Използвайте метод, когато поведението принадлежи на обект и използва неговите данни. За общи процедури, които принадлежат на класа като цяло, използвайте методи на класа.
