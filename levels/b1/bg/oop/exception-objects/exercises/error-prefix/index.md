## Задача

Напишете блок, който прави `die 'timeout'`. Добавете фазер `CATCH`, който отпечатва съобщението на прихванатото изключение. Сложете `Error: ` пред съобщението.

## Пример

Програмата отпечатва:

```
Error: timeout
```
