Raku има вградени изключения `X::`, но можете да създавате и свои собствени. Собственото изключение е клас, който наследява вградения клас `Exception`. Той има и метод `message`:

```raku
class TooBig is Exception {
    has $.value;

    method message {
        "Value $.value is too big";
    }
}
```

`TooBig` е нормален клас, така че може да има атрибути като `value`. Но понеже е `is Exception`, можете да го хвърлите. За да го хвърлите, създавате обект и извиквате `.throw` върху него:

```raku
my $value = 20 * 30;

TooBig.new(value => $value).throw if $value > 50;

CATCH {
    when TooBig {
        say .message;
    }
}
```

Програмата отпечатва:

```
Value 600 is too big
```

Вътре в `CATCH` клонът `when TooBig` съвпада, защото хвърленият обект е от този тип. Собственото изключение носи всякакви данни, които му дадете, тук `value`. Така обработчикът може да състави точно съобщение или да реагира по особен начин. Това е много по-полезно от обикновен низ, подаден на `die`.

Тази страница събира всичко от тази част. Собственото изключение е _клас_ с атрибути и метод. То участва и в системата за изключения на Raku. Така то е готово да съобщи точно какво се е объркало.
