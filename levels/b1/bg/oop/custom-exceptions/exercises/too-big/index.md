## Задача

Дефинирайте собствен клас изключение `TooBig`. Той наследява `Exception` и има два атрибута, `value` и `limit`. Методът му `message` трябва да връща `Value <value> exceeds the limit of <limit>`.

После обходете в цикъл стойностите `30`, `99` и `60` при граница `50`. За всяка стойност хвърляйте `TooBig` само ако стойността е над границата. Използвайте фазер `CATCH` с `when TooBig`, който отпечатва съобщението **и** втори ред. На този ред той чете направо атрибута `limit` на изключението. Той отпечатва `Try a value up to <limit>.`. Стойност в рамките на границата трябва просто да съобщи, че е наред.

Това показва, че само провалените числа водят до изключение. Другите числа минават направо, а цикълът продължава и в двата случая.

## Пример

Програмата отпечатва:

```
Value 30 is within the limit
Value 99 exceeds the limit of 50
Try a value up to 50.
Value 60 exceeds the limit of 50
Try a value up to 50.
```
