## Задача

Дефинирайте два празни класа, `Cat` и `Dog`, и създайте екземпляр на `Cat` на име `$felix`. Отпечатайте типа на `$felix` с `WHAT`. След това използвайте оператора `===` и отпечатайте още два реда. Първият ред показва дали този тип съвпада с `Cat`. Вторият показва дали съвпада с `Dog`.

## Пример

Програмата отпечатва:

```
(Cat)
True
False
```
