Име на клас, например `Dog`, означава _обекта на типа_ на класа. Обектът на типа представя самия тип. Той не е някакъв конкретен обект от този тип. А _екземплярът_, който създавате с `new`, е истински обект.

Raku може да види разликата между двете. Методът `defined` връща `False` за обект на типа и `True` за екземпляр:

```raku
class Dog {
}

say Dog.defined;     # False
say Dog.new.defined; # True
```

Обектът на типа се смята за _недефиниран_, защото не съдържа истински данни. Той само описва тип. Екземплярът е _дефиниран_, защото е истински обект.

С `WHAT` и двете показват един и същ тип. Вече се запознахте с `WHAT` в [раздела за контейнерите](/bg/advanced/containers):

```raku
class Dog {
}

say Dog.WHAT;     # (Dog)
say Dog.new.WHAT; # (Dog)
```

Raku показва типа в скоби, както в `(Dog)`. Значи `Dog` и `Dog.new` имат един и същ тип, `Dog`. Но има разлика. `Dog` е самият тип, а `Dog.new` е обект от този тип.
