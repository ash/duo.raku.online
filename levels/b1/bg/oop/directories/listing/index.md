Процедурата `dir` връща елементите на директория, всеки като обект-път. Редът им не е фиксиран. Затова хората често сортират резултата и тогава изходът винаги е в същия ред.

```raku
mkdir 'box';
spurt 'box/a.txt', '';
spurt 'box/b.txt', '';

for dir('box').sort -> $entry {
    say $entry.basename;
}
```

Програмата отпечатва сортираните имена на файловете в директорията `box`:

```
a.txt
b.txt
```

Всеки елемент е пълен обект-път. Методът `basename` дава само крайното име, без частта с директорията. Можете да зададете на обекта-път всички същите въпроси както преди: `.f`, `.d` и `.e`. Така можете например да обходите директория и да изберете само файловете.
