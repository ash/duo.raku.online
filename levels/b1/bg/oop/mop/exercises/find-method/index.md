## Задача

Дефинирайте клас `Animal` с метод `speak`. След това дефинирайте клас `Dog`, който наследява `Animal`. Той не добавя свои собствени методи. Използвайте метаметод върху `Dog` и отпечатайте дали `Dog` има метод на име `speak`. Отпечатайте просто `True` или `False`. Това показва, че `find_method` търси по веригата на наследяване. Той не гледа само собствените методи на класа.

## Пример

Програмата отпечатва:

```
True
```
