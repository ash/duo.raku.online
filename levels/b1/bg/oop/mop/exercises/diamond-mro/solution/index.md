Ето едно възможно решение.

## Код

```raku
class A {
}

class B is A {
}

class C is A {
}

class D is B is C {
}

say D.^mro.map(*.^name);
```

🦋 Намерете програмата във файла [diamond-mro.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/mop/diamond-mro.raku).

## Изход

```
(D B C A Any Mu)
```

## Коментари

1. `D` наследява от двама родители наведнъж: `class D is B is C` изброява всеки от тях със свое `is`. Това е множествено наследяване. Заедно `A`, `B`, `C` и `D` образуват *ромб*. Има два пътя от `D` нагоре до общия прародител `A`.

1. `.^mro` превръща ромба в един прав ред на търсене. `D` е първи, после родителите му `B` и `C` в реда, в който сте ги написали. После идва общият `A` и накрая `Any` и `Mu`.

1. И `B`, и `C` водят до `A`. Все пак типът `A` се появява само **веднъж** и едва след двата. Точно в това е смисълът на реда на разрешаване на методите. Всеки тип се посещава точно веднъж. И родителят никога не идва преди дъщерен клас, който го наследява. Затова Raku винаги намира метод в `B` преди онзи в `A`, който той предефинира.
