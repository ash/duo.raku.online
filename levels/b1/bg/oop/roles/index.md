_Ролята_ е парче поведение, а понякога и данни, което няколко класа могат да споделят. Наследяването казва, че един клас _е_ вид друг клас. Ролята, от друга страна, описва нещо, което класът _може да прави_.

Дефинирате роля с ключовата дума `role`, по същия начин като клас. За да я дадете на клас, използвате трейта `does`:

```raku
role Greet {
    method hello {
        'Hello from ' ~ self.name;
    }
}

class Person does Greet {
    has $.name;
}
```

Класът `Person` вече има метода `hello` от ролята. Той работи така, все едно сте го написали в самия клас:

```raku
say Person.new(name => 'Anna').hello; # Hello from Anna
```

Ако класът изпълнява роля, Raku вижда, че той има тази роля:

```raku
say Person.new(name => 'Anna') ~~ Greet; # True
```

Забележете, че методът `hello` на ролята използва `self.name`. Но самата роля няма атрибут `name`. Това е наред. Методът се изпълнява като част от онзи клас, който компонира ролята. А този клас предоставя `name`. Следващата тема показва, че класът може да има няколко роли наведнъж.
