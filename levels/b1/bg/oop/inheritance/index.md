_Наследяването_ позволява един клас да се изгради върху друг. След името на новия клас пишете `is` и името на друг клас. Тогава новият клас наследява всички атрибути и методи на този клас. Този клас се нарича негов _родителски_ (или _базов_) клас.

```raku
class Animal {
    has $.name;
    method speak {
        'some sound';
    }
}

class Dog is Animal {
}
```

`Dog is Animal` означава, че `Dog` е вид `Animal`. Класът `Dog` няма свой собствен код. Но той вече има атрибута `name` и метода `speak` от `Animal`:

```raku
my $rex = Dog.new(name => 'Rex');
say $rex.name;  # Rex
say $rex.speak; # some sound
```

Обектът `Dog` се смята и за `Animal`:

```raku
say Dog.new ~~ Animal; # True
```

Интелигентното съпоставяне `~~` с тип е истина, ако обектът има този тип. То е истина и ако обектът наследява този тип. В следващата тема дъщерен клас заменя наследен метод със своя собствена версия.
