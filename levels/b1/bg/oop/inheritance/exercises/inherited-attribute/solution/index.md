Ето едно възможно решение.

## Код

```raku
class Vehicle {
    has $.wheels;
}

class Bike is Vehicle {
    has $.wheels = 2;
}

class Car is Vehicle {
    has $.wheels = 4;
}

say Bike.new.wheels;
say Car.new.wheels;
```

🦋 Намерете програмата във файла [inherited-attribute.raku](https://github.com/ash/raku-course/blob/master/exercises/oop/inheritance/inherited-attribute.raku).

## Изход

```
2
4
```

## Коментари

1. И `Bike`, и `Car` наследяват атрибута `wheels`, както и неговия аксесор, от `Vehicle`. Никой от тях не декларира атрибута отново от самото начало. Те само дават на наследения атрибут стойност по подразбиране: `2` за `Bike` и `4` за `Car`.

1. Стойността по подразбиране е вградена във всеки клас. Затова можете да създадете обектите с обикновени `Bike.new` и `Car.new`. После наследеният аксесор връща правилния брой колела.

1. Пак можете сами да подадете стойността, например `Car.new(wheels => 3)`. Такъв аргумент надделява над стойността по подразбиране. Но велосипедът или колата най-вероятно вече имат обичайния си брой колела. Затова стойностите по подразбиране държат обичайния случай прост. Но пак остава място за рядкото изключение.
