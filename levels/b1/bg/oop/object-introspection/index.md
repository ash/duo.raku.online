В [раздела за контейнерите](/bg/advanced/containers) използвахте `.^name`, за да попитате стойността за нейния тип. Със същите метаизвиквания с `.^` можете да погледнете вътре в клас и неговите обекти. Можете да видите имената им, атрибутите им и мястото им в йерархията на класовете.

Методът `.^name` връща името на класа:

```raku
class Dog {
    has Str $.name;
    method bark { 'Woof' }
}

say Dog.^name; # Dog
```

Метаметодът `.^attributes` изброява атрибутите на класа. Виждате всеки от тях с типа му и с вътрешното му частно име. Това е формата `$!`, с която се запознахте при [частните атрибути](/bg/oop/methods/private-attributes):

```raku
say Dog.^attributes; # (Str $!name)
```

Интроспекцията е полезна за инструменти, които работят с всякакви обекти. Например такъв инструмент може да отпечата всеки атрибут на обекта. Не е нужно той първо да знае класа. Следващата тема показва как да видите веригата на наследяване на класа.
