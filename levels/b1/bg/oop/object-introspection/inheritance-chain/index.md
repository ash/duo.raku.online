Ако един клас наследява друг, можете да поискате цялата му верига от типове. Метаметодът `.^mro` връща тази верига. Името идва от _method resolution order_. Това е редът, в който Raku търси метод.

```raku
class Animal {
}

class Dog is Animal {
}

say Dog.^mro; # ((Dog) (Animal) (Any) (Mu))
```

Четете списъка отляво. `Dog` е първо сам себе си, после `Animal` (неговият родител), а после `Any` и `Mu`. Тези два типа са най-отгоре и всеки обект в Raku ги наследява. При извикване на метод върху `Dog` Raku претърсва този списък отляво надясно. Той използва първия подходящ метод, който намери. Точно затова методът на дъщерния клас предефинира метода на родителя. Дъщерният клас идва по-рано във веригата.

Ако класът няма родител, който сте посочили сами, веригата е по-къса. В нея е само самият клас, следван от `Any` и `Mu`.
