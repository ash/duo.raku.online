## Задача

Дефинирайте базов клас `Animal` и клас `Dog`, който го наследява. Отпечатайте името на класа `Dog`. На следващия ред отпечатайте броя на типовете в неговата верига на наследяване. За целта използвайте `.^mro` и пребройте нейните елементи. Накрая, на трети ред, отпечатайте дали клас `Cat` се появява някъде в тази верига.

## Пример

Програмата отпечатва:

```
Dog
4
False
```
