Подпрограма може да бъде дефинирана _вътре_ в друга подпрограма. Такава вложена подпрограма е обикновена подпрограма. Но тя е видима само в подпрограмата, която я съдържа.

```raku
sub outer {
    sub inner {
        say 'I am the inner subroutine';
    }

    inner;
}

outer;
```

Програмата отпечатва:

```
I am the inner subroutine
```

Тук `inner` е декларирана вътре в `outer`, а `outer` я извиква. Това работи, защото можете да използвате `inner` навсякъде в тялото на `outer`.

Но извън `outer` няма име `inner`. Затова следващата програма не се компилира:

```raku
sub outer {
    sub inner { 42 }
}

inner; # error: Undeclared routine: inner
```

Влагането е полезно, когато само една подпрограма има нужда от помощна подпрограма. Ако държите помощника вътре, е ясно, че той е частен детайл. Освен това никой не може да го извика по грешка от друго място.
