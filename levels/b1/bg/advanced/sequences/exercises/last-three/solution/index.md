Ето едно възможно решение.

## Код

```raku
say (5, 10 ... 50).tail(3);
```

🦋 Можете да намерите пълния код във файла [last-three.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/sequences/last-three.raku).

## Резултат

```
(40 45 50)
```

## Коментари

1. Началните стойности `5, 10` задават аритметична стъпка пет. Последователността стига до крайната си точка `50`.

1. `tail(3)` връща последните три стойности на крайната последователност: `40, 45, 50`. По същия начин `head` би върнал първите няколко.
