Ето едно възможно решение.

## Код

```raku
say 0 <= 73 <= 100;
```

🦋 Можете да намерите пълния код във файла [chained-comparison.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/operators-overview/chained-comparison.raku).

## Резултат

```
True
```

## Коментари

1. Операторите за сравнение могат да бъдат верижни. Така `0 <= 73 <= 100` означава „0 е най-много 73, и 73 е най-много 100“. Операторът `<=` позволява крайните стойности. Така резултат от точно `0` или `100` също би бил валиден.

1. И двете части са верни, затова целият израз е `True`. Забележете, че пишете средната стойност `73` само веднъж. Въпреки това тя се сравнява и с двата си съседа.

1. Без верижното сравнение би трябвало да напишете двете сравнения и да ги свържете с `&&`. Тогава повтаряте средната стойност: `0 <= 73 && 73 <= 100`. Верижната форма казва същото по по-кратък начин.
