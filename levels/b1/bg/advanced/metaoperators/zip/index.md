title: Zip метаоператори
---

{% include menu.html %}

Метаоператорът zip `Z` взима два или повече списъка. Той сдвоява елементите им по позиция:

```raku
say (1, 2, 3) Z (4, 5, 6); # ((1 4) (2 5) (3 6))
```

Резултатът е списък от групи. Първата група съдържа първия елемент от всеки списък. Следващата група съдържа вторите елементи и така нататък.

Още по-умно е, че можете да комбинирате `Z` с оператор, който работи върху всяка двойка. Например `Z+` събира елементите позиция по позиция:

```raku
say (1, 2, 3) Z+ (10, 20, 30); # (11 22 33)
```

Тук метаоператорът zip обвива оператора `+`. Той пресмята `1 + 10`, `2 + 20` и `3 + 30`. По същия начин `Z*` умножава съответните елементи:

```raku
say (1, 2, 3) Z* (10, 20, 30); # (10 40 90)
```

А `Z~` съединява съответните низове:

```raku
say <a b c> Z~ <1 2 3>; # (a1 b2 c3)
```
