---
title: Дефиниране на enum
---

{% include menu.html %}

За да декларирате изброим тип, напишете ключовата дума `enum`, име и списък от имена на константи:

```raku
enum Colour <red green blue>;
```

Сега има нов тип, `Colour`, с три константи: `red`, `green` и `blue`. Можете да използвате всяка константа директно по нейното име:

```raku
say red;   # red
say green; # green
```

Зад всяко име стои число. Raku дава тези числа автоматично, като започва от нула, в реда на вашия списък. Така `red` е `0`, `green` е `1`, а `blue` е `2`. Тъй като стойностите имат ред, можете да сравнявате константите:

```raku
say red < blue; # True
```

Можете да дадете на променлива изброимия тип като неин тип. Тогава тя приема само тези константи:

```raku
my Colour $c = green;
say $c; # green
```

Името на константа може да съвпада с друго име във вашата програма. Тогава винаги можете да стигнете до константата чрез името на изброимия тип и `::`:

```raku
say Colour::red; # red
```

Изброимият тип дава на група свързани константи име и тип. Кодът, който ги използва, е много по-ясен от код с обикновени числа. Следващата тема разглежда [числата зад имената](/bg/advanced/enumerations/values-and-keys).
