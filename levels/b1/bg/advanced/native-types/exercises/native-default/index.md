## Задача

Нативната променлива никога не може да бъде недефинирана. Това правило важи за всеки нативен тип, не само за `int`. Декларирайте нативен `num` и нативен `str`, без да им присвоявате стойности. Отпечатайте числото. След това отпечатайте низа в квадратни скоби, за да видите, че е празен.

## Пример

Програмата отпечатва:

```
0
[]
```
