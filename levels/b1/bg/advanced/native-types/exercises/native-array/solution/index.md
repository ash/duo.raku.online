Ето едно възможно решение.

## Код

```raku
my uint8 @bytes = 100, 200, 255;
say @bytes.sum;
```

🦋 Можете да намерите изходния код във файла [native-array.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/native-types/native-array.raku).

## Резултат

```
555
```

## Коментари

1. Нативният тип с размер `uint8` се поставя преди масива с `@`. Така се декларира масив, в който всеки елемент е един беззнаков байт. Той заема малко памет, което е добре за двоични данни.

1. Ограничението за обръщане `0..255` важи за всеки *елемент*, но не и за тяхната сума. `.sum` обвива общата сума в обикновен `Int`. Затова `100 + 200 + 255` дава пълните `555`.
