Имената на нативните типове са с малки букви: `int`, `num` и `str`. Използвате ги, за да декларирате променлива, точно както `Int` или `Str`:

```raku
my int $i = 42;
my num $n = 3.14e0;
say $i; # 42
say $n; # 3.14
```

Нативната стойност съответства директно на машинен регистър или дума. Тя няма обвиващ обект, който обикновената Raku стойност винаги има. Това прави нативните типове по-бързи и по-малки в паметта. Това е важно в кратки цикли с много изчисления и в големи масиви.

Едно нещо трябва да знаете веднага: нативната променлива никога не може да бъде недефинирана. Обикновената `Int` променлива започва като недефинираното `(Int)`. Нативният `int` обаче започва от **нула**:

```raku
say (my Int $a); # (Int)
say (my int $b); # 0
```

Същото важи и за нативните масиви. Декларирате ги, като поставите нативния тип преди променливата с `@`:

```raku
my int @numbers = 10, 20, 30;
say @numbers.sum; # 60
```

Такъв масив съхранява елементите си като сурови машинни цели числа, а не като обвити `Int` обекти. Затова заема по-малко памет. Когато попитате нативна стойност за самата нея, Raku автоматично я _обвива_. Raku поставя стойността в съответния пълен тип. Ето защо `(my int $b).WHAT` показва `(Int)`.
