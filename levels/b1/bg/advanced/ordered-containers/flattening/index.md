Ако сложите един масив в друг, Raku _не_ обединява сам елементите им. Разгледайте тази програма:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;
my @c = @a, @b;

say @c.elems; # 2
say @c;       # [[1 2 3] [4 5]]
```

Масивът `@c` има само два елемента, масивите `@a` и `@b`. Raku запазва всеки контейнер като един елемент. Той не разопакова съдържанието му във външния масив. Същото се случва, когато сложите масив сред други стойности:

```raku
my @a = 1, 2, 3;
my @d = 0, @a, 99;
say @d; # [0 [1 2 3] 99]
```

Ако наистина искате една плоска последователност, поискайте я директно с рутината `flat`:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat(@a, @b);       # (1 2 3 4 5)
say flat(@a, @b).elems; # 5
```

## Айтемизация (Itemization)

Понякога искате обратното. Искате да защитите контейнер от изравняване, дори вътре във `flat`. Конструкцията `$(...)` _айтемизира_ аргумента си. Това означава, че тя маркира резултата като единичен елемент. Сравнете предишния пример с този:

```raku
my @a = 1, 2, 3;
my @b = 4, 5;

say flat($(@a), @b); # ([1 2 3] 4 5)
```

Тук `$(@a)` запазва `@a` като един елемент. Но `@b` все пак се изравнява до двете си стойности. Това отново е идеята на сигила `$`. Знакът `$` означава „третирай това като едно нещо“.
