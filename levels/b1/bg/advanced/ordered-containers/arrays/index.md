Масивът е подреден контейнер, а неговите елементи също са скаларни контейнери.

```raku
my @array = 100, 200, 300;
my @letters = 'a', 'b', 'c';
```

Сигилът `@` означава, че такава променлива се държи като обект от тип `Positional`. Така можете да използвате индекси, за да четете отделни елементи:

```raku
say @array[1];   # 200
say @letters[2]; # c
```

Всеки елемент е скаларен контейнер, затова можете да му присвоите нова стойност. Правите го по същия начин, както с отделна скаларна променлива:

```raku
my @array = 100, 200, 300;
@array[0] = 10;
say @array; # [10 200 300]
```

Можете също да присвоите стойност от друг тип, например:

```raku
my @array = 100, 200, 300;
@array[0] = 'ten';
say @array; # [ten 200 300]
```

Именно това прави масивите _изменяеми_, тоест такива, които могат да се променят. Всяка позиция е контейнер, който може да получи нова стойност. В следващата тема ще видите, че [списъците](/bg/advanced/ordered-containers/lists) се държат по различен начин.
