---
title: Извеждане на сигнатури на функции
---

{% include menu.html %}

Можете да извикате само `dd`, без аргументи, вътре в подпрограма. Тогава тя отпечатва сигнатурата на тази подпрограма. Това са нейното име и списъкът с параметри, ако има такива. Разгледайте следния пример с две подпрограми:

```raku
sub f1 {
    dd
}

f1();

sub f2($x) {
    dd
}

f2(42);
```

Програмата отпечатва сигнатурите, а не стойности:

```console
sub f1()
sub f2($x)
```

Това е особено полезно при мулти-функции, защото показва кой вариант е бил извикан наистина:

```raku
multi sub g {
    dd
}

multi sub g($x) {
    dd
}

g();
g(42);
```

Всеки път изходът показва съответния вариант:

```console
sub g()
sub g($x)
```
