## Проблем

Имате следната вложена структура от данни:

```raku
my @data = 'Raku', [1, 2, 3], (key => 'value');
```

Направете две неща с нея:

1. Използвайте `dd`, за да отпечатате дъмп на `@data` за разработчици.
2. Отпечатайте същото представяне като низ, който започва с текста `Structure: `.

## Пример

Програмата отпечатва два подобни реда:

```
["Raku", [1, 2, 3], :key("value")]
Structure: ["Raku", [1, 2, 3], :key("value")]
```
