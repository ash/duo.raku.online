Три контекста са много чести. Те карат стойността да се държи като число, низ или булева стойност. За всеки от тях има префиксен оператор, който задава контекста направо:

* `+` — числов контекст
* `~` — низов контекст
* `?` — булев контекст

При масив `+` дава дължината му, а `~` дава елементите му, съединени с интервали. `?` показва дали масивът изобщо има елементи:

```raku
my @a = 1, 2, 3;

say +@a; # 3
say ~@a; # 1 2 3
say ?@a; # True
```

Празен масив дава `0` в числов контекст и `False` в булев контекст:

```raku
my @empty;
say +@empty; # 0
say ?@empty; # False
```

Не е нужно винаги сами да пишете тези оператори. Raku може да зададе правилния контекст вместо вас. Аритметиката поставя стойностите си в числов контекст, а съединяването на низове ги поставя в низов контекст. `if`, `while` и `and`/`or` поставят условието си в булев контекст:

```raku
my @a = 1, 2, 3;

say 10 + @a;              # 13, here @a is its length: 3
say 'items: ' ~ @a;       # items: 1 2 3
if @a { say 'not empty' } # not empty
```

Така `if @array { … }` работи точно както бихте очаквали. Масив, който не е празен, е истина. Префиксните оператори са начин да поискате същите преобразувания направо.

Заедно с постфиксен `if` това ви позволява да пишете кратък и ясен код:

```raku
say "{+@a} items are there" if @a; # 3 items are there
```
