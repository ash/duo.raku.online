Raku има фазери за цялата програма, но има и други. Тези фазери са свързани с живота на един блок или цикъл.

## Влизане и излизане от блок

Фазерът `ENTER` се изпълнява всеки път, когато програмата влиза в блок. Фазерът `LEAVE` се изпълнява всеки път, когато тя излиза от блока. Няма значение на кой ред ги пишете:

```raku
say 'before block';
{
    LEAVE say 'leaving';
    ENTER say 'entering';
    say 'inside';
}
say 'after block';
```

Изходът показва, че `ENTER` се изпълнява първи, а `LEAVE` — последен. Тялото на блока се изпълнява между тях:

```
before block
entering
inside
leaving
after block
```

`LEAVE` е особено полезен, защото се изпълнява дори ако блокът свърши по-рано. Това го прави надеждно място за освобождаване на ресурс.

Фазерът може да приеме цял блок `{ }` вместо един оператор. Можете да имате и няколко фазера. Когато блокът има повече от един `LEAVE`, те се изпълняват в обратен ред. Последният зададен се изпълнява първи. Така блокът работи като стек, отгоре надолу:

```raku
say 'open A';
{
    LEAVE {
        say 'close A';
    }
    say 'open B';
    LEAVE {
        say 'close B';
    }
    say 'work';
}
say 'done';
```

Програмата първо отваря ресурс `A` и го затваря най-накрая:

```
open A
open B
work
close B
close A
done
```

Редът „последен влязъл, първи излязъл“ е точно това, което ви трябва за почистване. Нещото, което сте настроили последно, се премахва първо. Фазерът `END` на цялата програма работи по същия начин. Няколко блока `END` също се изпълняват в обратен ред спрямо реда, в който са написани.

## Цикъл фазери

В циклите има още три фазера за етапите на цикъла. `FIRST` се изпълнява веднъж преди първото преминаване, а `LAST` — веднъж след последното. `NEXT` се изпълнява в края на всяко преминаване:

```raku
for 1..3 {
    FIRST say '-- first';
    LAST  say '-- last';
    NEXT  say "-- next (was $_)";
    say "body $_";
}
```

Това е изходът на цикъла:

```
-- first
body 1
-- next (was 1)
body 2
-- next (was 2)
body 3
-- next (was 3)
-- last
```

Както другите фазери, `FIRST`, `NEXT` и `LAST` могат да стоят навсякъде в кода. Всеки от тях се изпълнява в своя момент.
