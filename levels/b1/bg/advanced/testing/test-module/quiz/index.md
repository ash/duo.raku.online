Коя функция в модула `Test` минава, когато булево условие е вярно?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` приема условие и минава, когато то е вярно. `is` сравнява действителна стойност с очаквана. `plan` казва колко теста да се очакват. `done-testing` завършва файла и извежда плана.

</div>
