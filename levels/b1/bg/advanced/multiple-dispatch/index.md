В частта „Основи“ се запознахте с [_мулти-функциите_](/bg/essentials/more-on-functions/multi-functions). Това са няколко подпрограми с едно и също име. Raku избира правилната, като гледа типовете на аргументите. Това се нарича _множествено диспечиране_ (multiple dispatch).

Досега Raku избираше по _типа_ на аргументите. Клаузата `where` ви позволява да отидете по-далеч и да избирате и по _стойността_. Пишете я след параметъра и тя съдържа условие. Аргументът трябва да изпълни това условие, иначе този кандидат не се избира:

```raku
multi sub info(Int $n where $n < 0)  { say "$n is negative" }
multi sub info(Int $n where $n == 0) { say "$n is zero" }
multi sub info(Int $n where $n > 0)  { say "$n is positive" }

info(-5);
info(0);
info(7);
```

Всяко извикване изпълнява кандидата с условие, което е вярно за дадената стойност:

```
-5 is negative
0 is zero
7 is positive
```

Ако гледате само типовете, и трите кандидата имат една и съща сигнатура: един `Int`. Затова без клаузите `where` те биха се сблъскали. Условията ги правят различни един от друг.

## Базов случай за рекурсия

`where` често се използва за точката на спиране на рекурсията. Тази точка получава свой собствен кандидат. Ето отново факториелът, този път като две мулти-подпрограми:

```raku
multi sub fact(Int $n where $n <= 1) { 1 }
multi sub fact(Int $n)               { $n * fact($n - 1) }

say fact(5); # 120
```

Първият кандидат обработва базовия случай, когато `$n` е `1` или по-малко. Той просто връща `1`. Всяка друга стойност отива към втория кандидат. Той извиква `fact` отново с по-малко число. Вътре във функцията няма `if`. Диспечерът избира между базовия случай и рекурсивната стъпка.
