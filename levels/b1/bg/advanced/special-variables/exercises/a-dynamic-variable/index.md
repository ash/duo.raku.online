## Проблем

Динамичната променлива се пише с туигила `*`. Raku я намира, като търси навън през стека на извикванията, а не по лексикален обхват. Така стойността, която подпрограмата вижда, зависи от това кой я е извикал. Това позволява на един блок да изпълни кода, който извиква, с различна идентичност.

1. Декларирайте динамична променлива `$*user` със стойност `'guest'`.
2. Напишете подпрограма `whoami`, която отпечатва `running as ` и след това текущата `$*user` (например `running as guest`). Тя няма параметри, затова трябва да чете `$*user` директно.
3. Извикайте `whoami` веднъж на най-горното ниво. Тя показва `guest`.
4. След това направете блок, който декларира `$*user` отново като `'admin'`. В него извикайте *същата* `whoami` отново. Сега тя показва `admin`.

## Пример

Програмата отпечатва:

```
running as guest
running as admin
```
