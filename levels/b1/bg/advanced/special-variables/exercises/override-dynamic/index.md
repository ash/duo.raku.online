## Проблем

Покажете как динамична променлива преминава през подпрограма по средата. Тази подпрограма не знае нищо за нея.

Напишете подпрограма `log-it($msg)`, която отпечатва съобщението с динамичната променлива `$*prefix` пред него. Напишете втора подпрограма `task`, която само извиква `log-it('working')`. Тя никога не споменава сама `$*prefix`. След това извикайте `task` два пъти, всеки път отвътре на блок. Всеки блок задава на `$*prefix` различна стойност: първо `INFO`, после `DEBUG`.

## Пример

Програмата отпечатва:

```
INFO: working
DEBUG: working
```
