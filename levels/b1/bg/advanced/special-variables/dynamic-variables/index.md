---
title: Динамични променливи
---

{% include menu.html %}

_Динамичната_ променлива има туигила `*`. Лексикалната променлива се вижда само в блока, където я декларирате. Динамичната променлива е различна: Raku я намира, като търси **навън през стека на извикванията**. Той търси в кода, който е извикал текущия код. Няма значение къде е дефиниран този код.

```raku
my $*greeting = 'Hello';

sub greet {
    say $*greeting;
}

greet(); # Hello
```

Подпрограмата `greet` не декларира `$*greeting` и не я получава като аргумент. Но все пак може да я види. Това е така, защото променливата е динамична. Освен това `greet` е извикана от място, където променливата е в обхват.

Този пример би работил и с обикновена глобална скаларна променлива `$greeting`. Но следващият пример показва какво прави динамичните променливи специални.

Търсенето следва стека на извикванията. Затова по-близка декларация **заменя** по-далечната, докато работи нейният блок:

```raku
my $*level = 'outer';

sub show {
    say $*level;
}

show(); # outer

{
    my $*level = 'inner';
    show(); # inner
}
```

Същата `show` отпечатва `outer` първия път. Тя отпечатва `inner`, когато е извикана отвътре на блока, който декларира `$*level` отново. Това е _динамично обхващане_. Вградените в Raku `$*OUT`, `$*IN` и `$*ERR` работят по същия начин. Можете временно да пренасочите изхода, ако декларирате `$*OUT` отново в блок. Тогава всяка подпрограма, която извиквате в блока, вижда новата стойност. Динамичните променливи са чудесни за предаване на контекст към извикания код без изричен аргумент.
