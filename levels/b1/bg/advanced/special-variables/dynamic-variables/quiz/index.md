Какво отпечатва следната програма?

```raku
my $*n = 1;
sub show { say $*n }

sub run {
    my $*n = 2;
    show();
}

run();
```

{:.quiz}
0 | 1
1 | 2
0 | Nothing
0 | An error

{% include quiz.html %}

<div class="extended-explanation">

`show` е написана на най-горното ниво, точно до `my $*n = 1`. Но това място няма значение. Raku търси динамичната променлива през *стека на извикванията*. Къде стои кодът, не е важно. Тук `show` е извикана от `run`, която декларира `$*n` отново като `2`. Така това е стойността в сила и програмата отпечатва `2`.

</div>
