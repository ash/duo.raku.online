Raku дефинира набор от променливи за вас. Повечето от тях са _динамични_, с туигила `*`. Затова можете да ги четете навсякъде, както видяхте при [динамичните променливи](/bg/advanced/special-variables/dynamic-variables). Можете дори да ги замените за даден обхват. Ето тези, които ще ви трябват най-често.

## Стандартни потоци

Входът и изходът минават през три динамични променливи: `$*OUT` за стандартния изход, `$*ERR` за стандартната грешка и `$*IN` за стандартния вход. `say` и `print` пишат в `$*OUT`. За да изпратите текст към стандартната грешка вместо това, извикайте метода върху `$*ERR`:

```raku
$*OUT.say('normal output'); # goes to standard output
$*ERR.say('a diagnostic');  # goes to standard error
```

Понеже тези променливи са динамични, можете да пренасочите `$*OUT` в блок. Тогава всичко, което извиквате в този блок, изпраща изхода си на новото място. Не е нужно да променяте нищо от този код.

## Програмата и нейният процес

Няколко променливи дават информация за самата работеща програма:

```raku
say $*PROGRAM-NAME; # the path of the script being run
say $*PID;          # the process id of this program
say $*CWD;          # the current working directory
```

Стойностите им се променят всеки път, когато изпълнявате програмата. Затова тук няма фиксиран изход за показване.

## Команден ред и среда

Аргументите и средата идват в два контейнера, които са готови за използване:

* `@*ARGS` — списъкът с аргументи от командния ред (подпрограмата `MAIN` получава същите)
* `%*ENV` — променливите на средата, в хеш

```raku
say @*ARGS.elems; # how many arguments were passed
say %*ENV<HOME>;  # the value of the HOME environment variable
```

Тези вградени променливи ви спестяват да събирате сами същата информация. Те са и динамични, затова Raku ги търси през стека на извикванията. Така можете да замените всяка вградена `$*` променлива за даден обхват. Това работи точно както с ваша собствена `$*` променлива.

Освен тези динамични променливи, Raku има и вградени `?` променливи, които се задават по време на компилация: `$?FILE` и `$?LINE`. Вече ги видяхте на страницата за [туигилите](/bg/advanced/special-variables/twigils).
