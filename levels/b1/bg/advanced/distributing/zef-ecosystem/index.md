`zef` е инсталаторът на модули на Raku. Вече сте го използвали, за да инсталирате модули по име. Той работи и с локална директория на дистрибуция. Вътре в дистрибуцията можете директно да я тествате и инсталирате:

```
zef test .
zef install .
```

`zef test .` изпълнява файловете под `t/`. `zef install .` инсталира дистрибуцията във вашия Raku, така че други програми да могат да я заредят с `use`. Инсталирането по име, както в `zef install Cro`, прави същото. Но първо изтегля дистрибуцията от екосистемата.

Можете да **публикувате** своя дистрибуция, така че други да могат да я инсталират по име. За целта я качвате в екосистемата. Обичайният инструмент за това е `fez`:

```
fez upload
```

Това пакетира текущата дистрибуция и я изпраща в екосистемата на Raku. След това `zef install Maths::Simple` ще работи за всеки.

> Тези команди изискват инсталирани `zef`/`fez` и връзка с мрежата. Качването изисква и акаунт в екосистемата.

Така животът на споделения модул има три стъпки. Оформяте го с `META6.json` и го тествате със `zef test`. След това го публикувате с `fez upload`. Оттам нататък той е просто още едно име, което всеки може да инсталира със `zef install`.
