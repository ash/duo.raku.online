Прагмата `strict` в Raku е включена по подразбиране. Какво се случва, ако присвоите стойност на променлива, която никога не сте декларирали, например `$x = 42`?

{:.quiz}
1 | Грешка по време на компилация
0 | Мълчаливо създава `$x`
0 | Извежда предупреждение, но се изпълнява
0 | Задава `$x` на `Nil`

{% include quiz.html %}

<div class="extended-explanation">

`strict` е включена по подразбиране. Тя изисква първо да декларирате всяка променлива с `my`. Затова `$x = 42` без `my` не се компилира. Грешката е *Variable '$x' is not declared*. Ако изключите прагмата с `no strict`, присвояването работи.

</div>
