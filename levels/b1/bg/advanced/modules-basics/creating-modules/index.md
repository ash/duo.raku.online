Когато програмите станат по-големи, е полезно да ги разделите на части за повторна употреба. Всеки _модул_ е единица код в собствен файл. Други програми могат да го заредят и използват.

Файлът на модула има разширение `.rakumod`. Той започва с `unit module`, което дава името на модула. Подпрограмите вътре са частни по подразбиране. За да споделите някоя от тях с кода, който използва модула, маркирайте я с характеристиката `is export`.

Ето модул във файл с име `Greeting.rakumod`:

```raku
unit module Greeting;

sub hello($name) is export {
    return "Hello, $name!";
}
```

Подпрограмата `hello` има `is export`, така че всяка програма, която използва модула, може да я вижда. Без `is export` една подпрограма би останала частна за модула.

Модулът може да споделя и данни чрез `our` променливи. Друг код може да достигне до тях чрез името на модула. За да добавите номер на версия към `Greeting`, стига още един ред във файла:

```raku
our $version = '1.0';
```

Щом този ред е в `Greeting.rakumod`, стойността е достъпна като `$Greeting::version`. Това работи навсякъде, където модулът е зареден.

Следващите теми показват [как програмата зарежда такъв модул](/bg/advanced/modules-basics/using-modules). Те обясняват и какво точно получава програмата от него.
