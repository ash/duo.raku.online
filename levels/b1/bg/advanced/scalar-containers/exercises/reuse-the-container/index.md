## Задача

Декларирайте две скаларни променливи една до друга: `$untyped`, която няма тип, и `$typed`, която има тип `Int`. Изведете и двете с `dd`, докато са още празни. След това присвоете `42` на всяка от тях и отново изведете и двете. Вижте внимателно колко различно `dd` описва двата контейнера.

## Пример

Програмата отпечатва това към стандартната грешка:

```
$untyped = Any
Int $typed = Int
$untyped = 42
Int $typed = 42
```
