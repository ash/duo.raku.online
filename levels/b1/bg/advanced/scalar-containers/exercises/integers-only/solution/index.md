Ето едно възможно решение на задачата.

## Код

```raku
my Int $cars;

$cars = 250.7.Int;
say $cars;
say $cars.WHAT;
```

🦋 Можете да намерите изходния код във файла [integers-only.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/scalar-containers/integers-only.raku).

## Изход

```
250
(Int)
```

## Коментари

1. Ограничението на типа `Int` в `my Int $cars` кара контейнера да отказва всички стойности, които не са цели числа. Директното присвояване на `250.7`, стойност от тип `Rat`, би дало грешка по време на компилация.

1. Извикването на `.Int` върху рационалната стойност `250.7` я превръща в цялото число `250`. То просто маха дробната част. Новата стойност е подходяща за контейнера. Не бъркайте това със закръгляне.

1. Псевдо-методът `.WHAT` показва, че стойността в контейнера е от тип `Int`.
