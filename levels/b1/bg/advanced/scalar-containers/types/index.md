Ето програма, която използва една променлива за различни видове данни. Използваме `dd`, за да видим какво има в контейнера на всяка стъпка. Този пример само показва идеята. Не препоръчваме този стил на програмиране.

```raku
my $value;
dd $value;

$value = 42;
dd $value;

$value = 'forty-two';
dd $value;
```

Всяко извикване на `dd` показва какво има в променливата `$value` в този момент:

```
$value = Any
$value = 42
$value = "forty-two"
```

В началото променливата е празна и `dd` показва стойността й като `Any`. Това е неопределената базова стойност, с която започва всеки нетипизиран контейнер. След присвояванията `dd` показва цялото число, а след това низа.

Забележете, че тук `dd` не отпечатва тип преди името. Нетипизираният контейнер не е свързан с никакъв тип, затова се показва само стойността. Следващата тема показва, че [контейнер с деклариран тип](/bg/advanced/scalar-containers/type-constraints) се държи различно.
