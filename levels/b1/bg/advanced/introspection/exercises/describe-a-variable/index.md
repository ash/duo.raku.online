## Задача

Ето една типизирана променлива:

```raku
my Str $lang = 'Raku';
```

Отпечатайте три факта за нея, по един на всеки ред:

1. типа на нейната стойност;
2. типа на нейния контейнер;
3. нейното име, включително сигила.

## Пример

Програмата отпечатва:

```
Str
Scalar
$lang
```
