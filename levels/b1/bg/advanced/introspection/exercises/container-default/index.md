## Задача

Контейнерът може да има стойност по подразбиране, която задавате с характеристиката `is default`. Докато не присвоите нещо, променливата връща тази стойност. `.VAR.default` също ви казва каква е тя.

Декларирайте скалар `$count` със стойност по подразбиране `0`. Не му присвоявайте нищо. Първо отпечатайте самата променлива, а след това стойността по подразбиране на нейния контейнер. И двата реда трябва да покажат `0`.

## Пример

Програмата отпечатва:

```
0
0
```
