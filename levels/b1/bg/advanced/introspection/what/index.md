`WHAT` е псевдо-метод, който ви позволява да получите типа на стойност. Можете да го използвате почти по същия начин като `.^name`:

```raku
my $var = 42;

say $var.^name;
say $var.WHAT;
```

И двата отпечатват типа, но изглеждат малко различно. `.^name` дава само името, а `WHAT` показва типовия обект в скоби:

```
Int
(Int)
```

Ако променливата няма ограничение на типа, отначало типът ѝ е `Any`. След като присвоите стойност, и `^name`, и `WHAT` показват нейния тип:

```raku
my $var;
say $var.^name; # Any
say $var.WHAT;  # (Any)

$var = 'Hello';
say $var.^name; # Str
say $var.WHAT;  # (Str)
```

С ограничение на типа типът е известен веднага, дори преди да присвоите нещо:

```raku
my Str $var;
say $var.^name; # Str
say $var.WHAT;  # (Str)

$var = 'Hello';
say $var.^name; # Str
say $var.WHAT;  # (Str)
```

## Сравняване на типови обекти

`WHAT` връща самия типов обект, така че можете да сравните два типови обекта с `===`. Това е операторът за _идентичност на стойности_. Той проверява дали двете страни са точно една и съща стойност. Всеки тип има само един типов обект. Така това е чист начин да проверите дали две стойности имат един и същ тип:

```raku
my $a = 42;
my $b = 100;

say $a.WHAT === $b.WHAT; # True  — both are Int
say $a.WHAT === Int;     # True
say $a.WHAT === Str;     # False
```

`==` сравнява числа, а `===` сравнява идентичност. Затова той работи направо с типови обекти, а също и с други стойности.
