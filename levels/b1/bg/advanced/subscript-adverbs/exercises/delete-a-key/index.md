## Задача

Вземете хеша `a => 1, b => 2, c => 3`. Използвайте наречие за индексиране, за да изтриете записа `b`. След това отпечатайте колко записа са останали, за да покажете, че един от тях е премахнат.

## Пример

Програмата отпечатва:

```
2
```
