Понякога програмата трябва да избира между няколко възможности. Тогава верига от проверки `if` и `elsif` може да стане дълга и пълна с повторения. В такива случаи конструкцията `given`/`when` често е по-ясна. Тя е подобна на оператора `switch` в други езици.

Блокът `given` приема стойност и я прави _тема_. Темата е специалната променлива `$_`. След това всеки блок `when` се сравнява с тази тема. Първият, който съвпадне, се изпълнява:

```raku
my $n = 2;

given $n {
    when 1 { say 'one' }
    when 2 { say 'two' }
    when 3 { say 'three' }
}
```

Тази програма отпечатва:

```
two
```

За разлика от `switch` в някои езици, тук няма преминаване надолу към следващия случай. Щом един `when` съвпадне, неговият блок се изпълнява и блокът `given` приключва. Другите блокове `when` не се проверяват.

## Блокът `default`

Блокът `default` се изпълнява, когато нито един от блоковете `when` не е съвпаднал. Той върши същата работа като клона `else` на оператора `if`:

```raku
my $n = 5;

given $n {
    when 1 { say 'one' }
    when 2 { say 'two' }
    default { say 'many' }
}
```

`$n` не е нито `1`, нито `2`, затова програмата отпечатва:

```
many
```
