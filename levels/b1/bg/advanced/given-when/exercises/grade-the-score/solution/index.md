Ето едно възможно решение.

## Код

```raku
my $age = 30;

given $age {
    when $_ < 0 { say 'invalid' }
    when 0..12  { say 'child' }
    when 13..19 { say 'teenager' }
    when 20..64 { say 'adult' }
    default     { say 'senior' }
}
```

🦋 Можете да намерите изходния код във файла [grade-the-score.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/given-when/grade-the-score.raku).

## Изход

```
adult
```

## Коментари

1. Това решение смесва два вида `when`. Първият е *условие*, `$_ < 0`, където `$_` е темата, зададена от `given`. То отсява невалидните възрасти. Останалите са *диапазони*, които групират валидните възрасти в етапи.

1. Редът има значение. Проверката за отрицателна възраст е първа. Затова тя се изпълнява, преди да се опита който и да е диапазон. Стойността `30` е в `20..64`, затова програмата отпечатва `adult`.

1. Блокът `default` покрива всяка възраст от 65 и нагоре. Нито един от изброените диапазони не хваща тези възрасти.

Можете и да обърнете нещата и да оставите `default` да хваща *невалидния* вход. Изброете всеки познат етап, включително `senior` като условието `$_ >= 65`. Смятайте за невалидно всичко, което остава, например отрицателна възраст:

```raku
given $age {
    when 0..12    { say 'child' }
    when 13..19   { say 'teenager' }
    when 20..64   { say 'adult' }
    when $_ >= 65 { say 'senior' }
    default       { say 'invalid' }
}
```

Тук `default` е истински клон „нищо от горното“. Кой вариант се чете по-добре е въпрос на вкус. Сложете проверката първа, когато невалидният случай е изключение. Или го направете `default`, когато всички валидни етапи са ясно изброени.
