Ето едно възможно решение.

## Код

```raku
my $n = 12;

given $n {
    when 0      { say 'zero' }
    when $_ %% 2 { say 'even' }
    default     { say 'odd' }
}
```

🦋 Можете да намерите изходния код във файла [sign-of-a-number.raku](https://github.com/ash/raku-course/blob/master/exercises/advanced/given-when/sign-of-a-number.raku).

## Изход

```
even
```

## Коментари

1. `when 0` съвпада само със стойността нула. Той е първи, защото нулата също е четна, а ние искаме да я отчетем отделно.

1. `when $_ %% 2` е условие, където `$_` е темата, зададена от `given`. Операторът `%%` проверява дали темата се дели на две без остатък. Стойността `12` не е нула, но се дели на две, затова програмата отпечатва `even`.

1. `default` покрива всичко, което остава. Това са числата, които не са нито нула, нито четни, тоест нечетните.
