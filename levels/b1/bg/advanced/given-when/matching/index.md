Блокът `when` не проверява само дали две стойности са равни. Той прави _умно съвпадение_ между темата и стойността, която му давате. Затова можете да проверявате за съвпадение с диапазони, типове и условия, а не само с единични стойности.

## Диапазони

Диапазонът съвпада, когато темата е в него. Това прави `given`/`when` естествен избор за разделяне на числата на групи:

```raku
my $score = 75;

given $score {
    when 90..100 { say 'A' }
    when 80..89  { say 'B' }
    when 70..79  { say 'C' }
    default      { say 'F' }
}
```

Стойността `75` е в диапазона `70..79`, затова програмата отпечатва:

```
C
```

## Типове

Типът съвпада, когато темата е от този тип. Така програмата може да избере клон според вида на стойността, която има:

```raku
my $value = 'Raku';

given $value {
    when Int { say 'an integer' }
    when Str { say 'a string' }
}
```

`$value` съдържа низ, затова програмата отпечатва:

```
a string
```

## Условия

Можете също да напишете сравнение директно. Вътре в `when` можете да използвате темата като `$_`. Затова условие като `$_ < 0` съвпада, когато е вярно:

```raku
my $n = -7;

given $n {
    when $_ < 0 { say 'negative' }
    when 0      { say 'zero' }
    default     { say 'positive' }
}
```

Тук първият `when` съвпада и програмата отпечатва:

```
negative
```
