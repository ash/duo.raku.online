Има няколко начина да разделите низ на части и да ги съедините отново.

Методът `words` разделя низ по интервалите на списък от думи:

```raku
say 'Hello big World'.words; # (Hello big World)
```

Методът `split` разделя низ по разделител, който вие изберете:

```raku
say 'a,b,c'.split(','); # (a b c)
```

Важен специален случай е разделянето по **празен низ** `''`. То разделя низа на отделните му символи. Но добавя и празен низ в самото начало и в самия край. Затова резултатът има два елемента повече, отколкото бихте очаквали:

```raku
say 'abc'.split('').elems;        # 5 — the three letters, plus an empty string at each end
say 'abc'.split('', :skip-empty); # (a b c) — the :skip-empty adverb drops the empties
```

За да разделите низ на символи, можете да извикате метода `comb` без аргументи. Той го прави директно и няма излишни празни низове за премахване:

```raku
say 'Raku'.comb; # (R a k u)
```

За обратната посока използвайте метода `join`. Той съединява списък от стойности в един низ и слага разделител между тях:

```raku
say <a b c>.join('-'); # a-b-c
```

Още два метода работят с части от низ. Методът `substr` връща част от низ. Давате му начална позиция и, ако искате, дължина:

```raku
say 'Hello World'.substr(0, 5); # Hello
say 'Hello World'.substr(6);    # World
```

А `trim` премахва интервалите в началото и в края на низ:

```raku
say '  hi  '.trim; # hi
```
