## Задача

Създайте пакет `Temperature`, който събира заедно две неща. Първото е `our` променлива `$freezing` със стойност `0`. Второто е `our` подпрограма `fahrenheit`, която преобразува стойност по Целзий във Фаренхайт. За преобразуването умножете по 9/5 и добавете 32. Извън пакета отпечатайте точката на замръзване. След това отпечатайте стойността по Фаренхайт на `100` градуса по Целзий.

## Пример

Програмата отпечатва:

```
0
212
```
