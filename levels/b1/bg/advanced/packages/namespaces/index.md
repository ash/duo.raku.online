Декларацията `our` е това, което прави едно име видимо в неговото пространство от имена. Променлива, декларирана с `my`, е лексикална, което значи, че е частна за своя блок. Променлива, декларирана с `our`, е също и пакетна променлива. Можете да достигнете до нея отвън чрез пътя с `::`:

```raku
module Counter {
    our $count = 0;  # package variable
    my  $secret = 42; # lexical, not visible outside
}

say $Counter::count; # 0
```

`$Counter::count` работи, защото `count` е декларирана с `our`. Но `$Counter::secret` не би сработила, защото `secret` е лексикална.

Пространствата от имена могат да бъдат **вложени**, тоест едно може да е вътре в друго. Пакет вътре в пакет дава по-дълъг път с `::`:

```raku
module Outer {
    module Inner {
        our $val = 42;
    }
}

say $Outer::Inner::val; # 42
```

Пълното име `$Outer::Inner::val` води от външното пространство от имена към вътрешното. Оттам то води до променливата. Точно така е организирана стандартната библиотека: имена като `IO::Socket::INET` са вложени пространства от имена. Вашите собствени модули също групират частите си под едно име от най-високо ниво по този начин.
