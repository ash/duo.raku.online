## Задача

Префиксът `eager` прави обратното на `lazy`. Той кара Raku да създаде целия списък, така че списъкът вече не е мързелив. Покажете разликата с `.is-lazy`.

Отпечатайте дали безкрайният диапазон `1 .. Inf` е мързелив. После отпечатайте дали `eager 1..3` е мързелив и накрая дали `lazy 1..3` е мързелив. Резултатите трябва да са `True`, `False`, `True`.

## Пример

Програмата отпечатва:

```
True
False
True
```
