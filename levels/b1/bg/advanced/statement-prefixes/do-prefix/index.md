Самостоятелният блок е оператор, а не израз. Затова обикновено не можете да го присвоите на променлива. Префиксът `do` превръща блок в израз. Стойността на този израз е стойността на **последния** оператор на блока:

```raku
my $x = do {
    my $a = 3;
    $a + 4;
};

say $x; # 7
```

Вътре в блока можете да декларирате променливи, да изпълнявате няколко оператора и да изчислите резултат. След това `do` връща стойността на блока. Това е полезно, когато ви трябва повече от един израз, за да получите стойност.

`do` работи и пред операторите за управление на потока. Тогава и те могат да връщат стойност:

```raku
my $sign = do given 5 {
    when * > 0 { 'positive' }
    when * < 0 { 'negative' }
    default    { 'zero' }
};

say $sign; # positive
```

Тук `do given` превръща цялата конструкция `given`/`when` в израз със стойност `positive`. Същото работи с `do if` и `do for`. Накратко, `do` ви позволява да използвате блок там, където се очаква стойност. Това работи и за управляваща конструкция.
