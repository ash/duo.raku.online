## Проблем

Символът на оператора може да бъде всеки знак, включително Unicode знак. Дефинирайте **постфиксен** оператор `²`, който повдига операнда си на квадрат, така че `5²` да означава `5 ** 2`. След това отпечатайте `5²`.

## Пример

Програмата отпечатва:

```
25
```
