title: Потребителски оператори
---

Операторите в Raku всъщност са просто подпрограми със специални имена. Това означава, че можете да дефинирате свои оператори. Използвате имената на категориите от страницата [Видове оператори в Raku](/bg/advanced/operator-types): `prefix`, `infix`, `postfix` и така нататък.

За да декларирате оператор, напишете `sub` със специално име. Името се състои от категорията, двоеточие и символа на оператора в ъглови скоби. Ето един нов инфиксен оператор, наречен `plus`:

```raku
sub infix:<plus>($a, $b) {
    $a + $b
}

say 3 plus 4; # 7
```

Щом е дефиниран, `plus` стои между двата си операнда. Това е точно като при всеки вграден инфиксен оператор.

Постфиксният оператор идва след своя операнд. Факториелът е класически пример. Ето го като постфиксен оператор `!`. Той е изграден върху [метаоператора за редукция](/bg/advanced/metaoperators/reduction), който видяхте по-рано:

```raku
sub postfix:<!>(Int $n) {
    [*] 1..$n
}

say 5!; # 120
```

Не сте ограничени до букви и ASCII пунктуация. Символът на оператора може да бъде всеки знак. Този префиксен оператор използва знака за параграф, `§`, за да удвои число:

```raku
sub prefix:<§>($x) {
    $x * 2
}

say §5; # 10
```

Дефинирането на оператори е мощен инструмент, затова го използвайте с добър вкус. Добре избраният оператор може да направи така, че кодът да се чете като езика на своята област. Неясният оператор само обърква следващия човек, който чете кода.
