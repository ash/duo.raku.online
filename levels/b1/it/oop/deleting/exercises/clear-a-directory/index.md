## Problema

Crea una directory `cache` con `mkdir` e mettici dentro due file. Poi cancella tutto. Rimuovi i due file, poi rimuovi la directory, che ora è vuota. Infine stampa se la directory esiste ancora.

## Esempio

Il programma stampa:

```
False
```
