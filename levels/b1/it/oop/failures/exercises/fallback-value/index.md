## Problema

Scrivi una subroutine `get` che restituisce il suo argomento. Ma quando l'argomento è `0`, deve chiamare `fail` con il messaggio `bad`.

Stampa il risultato di `get(5)` e poi quello di `get(0)`. Usa l'operatore defined-or `//` per dare un valore di ripiego pari a `default`.

## Esempio

Il programma stampa:

```
5
default
```
