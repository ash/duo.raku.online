## Problema

Definisci una classe `Label` con un attributo, `text`, che si può cambiare (`is rw`). Crea un'etichetta con il testo `draft`. Poi usa l'accessore per **aggiungere** ` (revised)` alla fine del suo testo. Non creare di nuovo l'oggetto. Stampa il risultato.

## Esempio

Il programma stampa:

```
draft (revised)
```
