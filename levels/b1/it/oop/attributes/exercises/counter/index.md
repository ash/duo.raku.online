## Problema

Definisci una classe `Counter` con un attributo, `count`, che si può cambiare (`is rw`). Il suo valore predefinito è `0`.

Crea un contatore e stampa prima il suo `count`. Questo controlla che parta dal valore predefinito. Poi usa un ciclo per aggiungergli uno cinque volte. Stampa il valore finale.

## Esempio

Il programma stampa:

```
0
5
```
