## Problema

Scrivi le tre parole `apple`, `banana` e `cherry` in un file chiamato `words.txt`. Metti ogni parola su una riga a parte. Poi leggi il file riga per riga. Stampa ogni riga con il suo numero di riga davanti, a partire da `1`. Usa la forma `<numero>: <riga>`.

## Esempio

Il programma stampa:

```
1: apple
2: banana
3: cherry
```
