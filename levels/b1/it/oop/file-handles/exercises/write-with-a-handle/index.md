## Problema

Apri per la scrittura un file chiamato `out.txt`. Tieni aperto l'handle. In un ciclo, scrivici i numeri `1`, `2` e `3`. Metti ogni numero su una riga a parte. Poi chiudi l'handle, rileggi il file e stampa il suo contenuto.

## Esempio

Il programma stampa:

```
1
2
3
```
