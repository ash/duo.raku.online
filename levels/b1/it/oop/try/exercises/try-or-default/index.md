## Problema

Un blocco `try` che fallisce dà un valore non definito. Usa questo fatto con l'operatore defined-or `//` per fornire un valore di ripiego. Esegui un blocco `try` che contiene `die 'no'`. Se fallisce, usa al suo posto la stringa `default`. Stampa il risultato.

## Esempio

Il programma stampa:

```
default
```
