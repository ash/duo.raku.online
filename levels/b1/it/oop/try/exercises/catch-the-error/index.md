## Problema

Mostra entrambe le facce di `try`. Prima usa un blocco `try` attorno a un calcolo che funziona, per esempio `6 * 7`. Poi stampa il suo risultato. Dopo metti del codice che fa `die 'broken'` in un secondo blocco `try`. Stampa se quel blocco ha dato un risultato definito. Poi stampa il messaggio dell'eccezione intercettata.

## Esempio

Il programma stampa:

```
42
False
broken
```
