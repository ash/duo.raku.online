## Problema

Gli errori incorporati hanno tipi di eccezione propri, e puoi confrontarli. Scrivi un blocco che calcola `1 / 0` e prova a usare il risultato. Questo solleva una `X::Numeric::DivideByZero`. Nel phaser `CATCH` del blocco, usa `when X::Numeric::DivideByZero` per riconoscere proprio questo tipo. Poi stampa `cannot divide by zero`.

## Esempio

Il programma stampa:

```
cannot divide by zero
```
