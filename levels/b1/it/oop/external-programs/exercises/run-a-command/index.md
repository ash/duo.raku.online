## Problema

Usa `run` per avviare `echo` con due argomenti separati: `home:` e `$HOME`. Lascia che il suo output vada sullo schermo. Nota che `$HOME` compare così com'è, e la directory home **non** viene stampata. Poiché `run` non usa una shell, la variabile non viene sostituita con il suo valore.

## Esempio

Il programma stampa:

```
home: $HOME
```
