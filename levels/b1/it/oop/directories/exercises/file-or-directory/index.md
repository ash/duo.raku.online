## Problema

Crea un file chiamato `a.txt`. Poi fai due domande allo *stesso* percorso. È un file regolare (`.f`), ed è una directory (`.d`)? Stampa tutte e due le risposte per vedere che i due test danno risultati opposti per un solo percorso.

## Esempio

Il programma stampa:

```
True
False
```
