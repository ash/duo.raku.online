## Problema

Definisci due classi vuote, `Cat` e `Dog`, e crea un'istanza di `Cat` chiamata `$felix`. Stampa il tipo di `$felix` con `WHAT`. Poi usa l'operatore `===` e stampa altre due righe. La prima riga mostra se quel tipo è lo stesso di `Cat`. La seconda mostra se è lo stesso di `Dog`.

## Esempio

Il programma stampa:

```
(Cat)
True
False
```
