## Problema

Definisci una classe base `Animal` e una classe `Dog` che eredita da essa. Stampa il nome della classe `Dog`. Sulla riga successiva, stampa il numero di tipi nella sua catena di ereditarietà. Per farlo, usa `.^mro` e conta i suoi elementi. Infine, su una terza riga, stampa se una classe `Cat` compare da qualche parte in quella catena.

## Esempio

Il programma stampa:

```
Dog
4
False
```
