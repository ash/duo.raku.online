## Problema

Definisci una classe `Converter` con un metodo di classe `km-to-miles`. Prende un numero di chilometri e restituisce la distanza in miglia. Per la conversione, moltiplica per `0.621`.

Chiama il metodo sulla classe con `10` chilometri, poi stampa il risultato.

## Esempio

Il programma stampa:

```
6.21
```
