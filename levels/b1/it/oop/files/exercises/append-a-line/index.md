## Problema

Costruisci un piccolo file di log aggiungendo qualcosa più volte. Scrivi la riga `start` in un file chiamato `log.txt`. Poi usa un ciclo per **aggiungere in coda** altre tre righe: `entry 1`, `entry 2` ed `entry 3`. Non cancellare quello che c'è già nel file. Infine leggi tutto il file e stampalo.

## Esempio

Il programma stampa:

```
start
entry 1
entry 2
entry 3
```
