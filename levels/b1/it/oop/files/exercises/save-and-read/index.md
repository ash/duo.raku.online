## Problema

Salva un numero in un file e caricalo di nuovo. Scrivi il numero `42` e un ritorno a capo in un file chiamato `number.txt`. Poi rileggi il file e trasforma il suo contenuto in un intero. Stampa questo intero moltiplicato per due.

## Esempio

Il programma stampa:

```
84
```
