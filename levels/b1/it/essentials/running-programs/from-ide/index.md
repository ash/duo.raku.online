Questa breve sezione spiega come eseguire un programma dentro l'IDE. Parla dei due [IDE](../../editors-and-ides) più raccomandati.

## Visual Studio Code Editor

Apri un terminale con il menu `Terminal` → `New Terminal`. Aggiunge un pannello sotto il testo del tuo programma. Esegui lì il programma, proprio come dalla riga di comando:

```console
$ raku hello.raku
```

## Comma IDE

Puoi eseguire i programmi dalla voce di menu `Run`. Configura l'IDE prima di eseguire un programma per la prima volta. Segui [le istruzioni](https://commaide.com/docs/running) sul sito web di Comma.
