## Problema

Scrivi un programma che stampi i risultati delle tre operazioni booleane. Deve farlo per ogni combinazione di `True` e `False`.

## Esempio

Ecco un esempio che mostra una parte dell'output.

```console
$ raku tables.raku
True && True is True
True && False is False
. . .
```
