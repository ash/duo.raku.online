Parliamo ora di stringhe. Abbiamo già usato delle stringhe nei programmi precedenti. Tutte si chiamano anche stringhe letterali. Una stringa letterale è del testo tra virgolette:

```raku
say 'Io sono una stringa letterale';
```

Ovviamente, puoi anche conservare le stringhe in una variabile scalare:

```raku
my $messaggio = 'Questo è il mio messaggio';
```

Ora vediamo alcune altre caratteristiche di base delle stringhe.
