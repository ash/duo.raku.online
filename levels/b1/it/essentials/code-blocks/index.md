I blocchi di codice sono parti del tuo programma dentro una coppia di parentesi graffe: `{` e `}`. Un blocco raggruppa diverse istruzioni, che lavorano insieme come una grande istruzione. Nelle prossime sezioni vedremo molti modi di usare i blocchi.

```raku
{
    say 'Hello, World!';
}
```

Il blocco di codice in questo programma non ha molto senso. Ma i blocchi di codice sono molto utili in altre situazioni, che vedremo molto presto.

Ma prima, vediamo l'idea di _ambito_.
