## Compito

Scrivi un programma che chiede all'utente un numero intero positivo. Poi il programma stampa `N file copiati`, con il numero dell'utente al posto di `N`. La parola `file` deve avere la forma giusta, plurale o singolare.

## Esempio

Questo esempio mostra che cosa deve fare il programma:

```console
$ raku plural-endings.raku
Quanti file copiare? 15
15 file copiati.
```
