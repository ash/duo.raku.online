title: Cicli infiniti
---

{% include menu.html %}

Puoi usare `loop` anche solo con un corpo:

```raku
loop {
    say 'Eternità';
}
```

Questo ciclo viene eseguito all'infinito finché non fermi il programma, per esempio premendo `Ctrl+C`. Nella seconda parte del corso vedremo modi migliori per controllare i cicli.
