## Problema

Scrivi un programma che chiede all'utente di inserire un intero positivo. Poi stampa la cifra che mostra quante _decine_ ci sono nel numero.

## Esempio

Per esempio, se il numero di input è 234, il numero di decine è 3. Quindi il programma stampa 3:

```console
$ raku tens.raku
Inserisci un numero intero positivo: 234
3
```
