## Problema

Scrivi una subroutine `stats` con dentro una subroutine helper **annidata** `double`. L'helper restituisce il suo argomento moltiplicato per due. Dentro `stats`, usa l'helper per stampare il valore di `double(3) + double(5)`.

Poi chiama `stats`.

## Esempio

Il programma stampa:

```
16
```
