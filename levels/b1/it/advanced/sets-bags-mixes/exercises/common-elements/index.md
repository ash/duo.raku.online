## Problema

Hai due set di nomi di frutta:

```raku
my $a = set(<apple banana cherry>);
my $b = set(<banana cherry date>);
```

Trova la loro intersezione e salvala in una variabile. Poi stampa due righe. La prima dice quanti valori hanno in comune i due set. La seconda dice se `apple` è uno di questi valori comuni. Non dovrebbe esserlo.

## Esempio

Il programma stampa:

```
2
False
```
