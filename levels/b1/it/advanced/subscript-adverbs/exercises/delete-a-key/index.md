## Problema

Prendi l'hash `a => 1, b => 2, c => 3`. Usa un avverbio di accesso tramite indice per eliminare l'elemento `b`. Poi stampa quanti elementi restano, per mostrare che uno è stato rimosso.

## Esempio

Il programma stampa:

```
2
```
