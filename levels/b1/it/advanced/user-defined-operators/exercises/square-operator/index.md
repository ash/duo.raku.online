## Problema

Il simbolo di un operatore può essere qualsiasi carattere, anche un carattere Unicode. Definisci un operatore **postfisso** `²` che eleva al quadrato il suo operando, in modo che `5²` significhi `5 ** 2`. Poi stampa `5²`.

## Esempio

Il programma stampa:

```
25
```
