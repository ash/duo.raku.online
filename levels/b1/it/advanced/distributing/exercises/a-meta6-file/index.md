## Problema

Scrivi un `META6.json` per una distribuzione chiamata `Greet::Simple`, versione `0.0.1`. Fornisce il modulo `Greet::Simple` dal file `lib/Greet/Simple.rakumod`. Nell'esempio della teoria, `depends` era vuoto. Questa volta la distribuzione **dipende da** un'altra distribuzione, `JSON::Fast`. Aggiungila all'array `depends`.

> Il risultato di questo esercizio è un file, non l'output di un programma.

## Esempio

Un file corretto, con solo le parti necessarie, è simile a quello della soluzione.
