## Problema

`WHAT` non descrive soltanto un tipo. Restituisce l'oggetto tipo stesso, e puoi confrontarlo con l'operatore `===`.

Dichiara due variabili. La variabile `$a` contiene l'intero `42`, e `$b` contiene la stringa `'x'`. Per ognuna, stampa se il suo `WHAT` è il tipo `Int`.

## Esempio

Il programma stampa:

```
True
False
```
