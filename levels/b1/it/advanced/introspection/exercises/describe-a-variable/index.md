## Problema

Ecco una variabile tipizzata:

```raku
my Str $lang = 'Raku';
```

Stampa tre informazioni su di essa, una per riga:

1. il tipo del suo valore;
2. il tipo del suo contenitore;
3. il suo nome, incluso il sigillo.

## Esempio

Il programma stampa:

```
Str
Scalar
$lang
```
