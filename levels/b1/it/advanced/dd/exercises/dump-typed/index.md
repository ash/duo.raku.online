## Problema

Dichiara una variabile con un tipo intero: `my Int $n = 42;`. Poi fai il dump con `dd`. Nota come l'output è diverso da quello di una variabile senza tipo.

## Esempio

Il programma stampa questo sullo standard error:

```
Int $n = 42
```
