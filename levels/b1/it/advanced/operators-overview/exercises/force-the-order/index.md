## Problema

L'operatore `**` lega più strettamente di `+`, quindi `2 ** 3 + 1` significa `(2 ** 3) + 1`, che fa `9`. Aggiungi le parentesi per cambiare questo ordine, in modo che l'addizione avvenga *per prima*. Poi stampa il risultato.

## Esempio

Il programma stampa:

```
16
```
