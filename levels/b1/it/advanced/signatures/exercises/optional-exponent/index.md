## Problema

Scrivi una subroutine `power` con un parametro obbligatorio `$base` e un parametro **opzionale** `$exp`. Quando l'esponente c'è, eleva la base all'esponente. Quando manca, eleva la base al quadrato come scelta predefinita. Usa l'operatore defined-or `//` per dare `2`.

Chiamala due volte. Prima chiamala solo con una base, poi con una base e un esponente.

## Esempio

Il programma stampa:

```
25
125
```
