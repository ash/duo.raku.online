## Problema

Crea un acronimo da una frase. Prendi la prima lettera di ogni parola e unisci le lettere. Poi stampa il risultato in maiuscolo.

Usa questa frase:

```raku
my $phrase = 'hyper text markup language';
```

## Esempio

Il programma stampa:

```
HTML
```
