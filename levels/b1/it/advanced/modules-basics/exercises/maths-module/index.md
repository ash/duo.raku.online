## Problema

Crea un modulo chiamato `Maths` in un file `Maths.rakumod`. Deve esportare una subroutine `square` che restituisce il quadrato del suo argomento.

Poi scrivi un programma separato che usa il modulo e stampa `square(6)`.

## Esempio

Se lo esegui con il modulo nel percorso di ricerca, il programma stampa:

```console
$ raku -I. maths.raku
36
```
