## Problema

Crea un modulo chiamato `Shouter` in un file `Shouter.rakumod`. Deve esportare una subroutine `shout` che restituisce il suo argomento in maiuscolo.

Poi scrivi un programma separato che usa il modulo e stampa `shout('hi')`.

## Esempio

Se lo esegui con il modulo nel percorso di ricerca, il programma stampa:

```console
$ raku -I. shout.raku
HI
```
