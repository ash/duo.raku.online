## Problema

Un URL è stato diviso in pezzi, e i pezzi sono in un array. Riuniscili in una sola stringa con un meta-operatore di riduzione. Stampa l'URL e, sulla riga successiva, stampa quanti caratteri ha.

## Esempio

Prendi questo array di input:

```raku
my @parts = <http :// example .com>;
```

Con questo array, il programma stampa:

```
http://example.com
18
```
