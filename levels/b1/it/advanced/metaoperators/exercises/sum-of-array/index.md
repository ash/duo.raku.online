## Problema

Scrivi un programma che stampa la media di un array di numeri. La media si chiama anche media aritmetica. Usa un meta-operatore di riduzione per sommare i valori.

I dati di input sono scritti direttamente nel programma, per esempio:

```raku
my @data = 10, 20, 30, 40;
```

## Esempio

Il programma stampa il valore medio degli elementi di `@data`:

```
25
```
