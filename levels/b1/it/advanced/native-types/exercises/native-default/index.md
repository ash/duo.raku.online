## Problema

Una variabile nativa non può mai essere indefinita. Questa regola vale per ogni tipo nativo, non solo per `int`. Dichiara un `num` nativo e una `str` nativa senza assegnare loro dei valori. Stampa il numero. Poi stampa la stringa tra parentesi quadre, così puoi vedere che è vuota.

## Esempio

Il programma stampa:

```
0
[]
```
