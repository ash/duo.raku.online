L'operatore `x` ripete una stringa. Per esempio, `'ab' x 3` dà `'ababab'`. Dato che `x` sta tra i suoi due operandi, in quale categoria si trova?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Conta la posizione, non se l'operatore è un simbolo o una parola. `x` sta *tra* due operandi, quindi è un operatore **infisso**. È proprio come `+` o `~`, ma scritto come una lettera.

</div>
