## Problema

Dichiarate una variabile scalare `$discount` con un valore predefinito di `0`. Stampate la variabile prima di assegnarle qualcosa. Il programma deve stampare `0` senza dare avvertimenti.

Poi assegnate `15` alla variabile e stampatela di nuovo.

## Esempio

Il programma stampa due righe:

```
0
15
```
