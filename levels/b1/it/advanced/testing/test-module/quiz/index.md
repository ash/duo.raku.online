Quale funzione del modulo `Test` ha successo quando una condizione booleana è vera?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` riceve una condizione e ha successo quando è vera. `is` confronta un valore effettivo con uno atteso. `plan` dice quanti test aspettarsi. `done-testing` termina il file e stampa il piano.
