## Problema

Crea un package `Temperature` che raggruppa due cose. La prima è una variabile `our` `$freezing` con il valore `0`. La seconda è una subroutine `our` `fahrenheit`, che converte un valore Celsius in Fahrenheit. Per convertire, moltiplica per 9/5 e aggiungi 32. Dall'esterno del package, stampa il punto di congelamento. Poi stampa il valore in Fahrenheit di `100` gradi Celsius.

## Esempio

Il programma stampa:

```
0
212
```
