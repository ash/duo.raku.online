## Problema

Metti un modulo `Inner` dentro un modulo `Outer`. In `Inner`, dichiara una variabile `our` `$base` con il valore `10`. Dichiara anche una `our sub doubled` che restituisce `$base` moltiplicato per due. Dall'esterno di entrambi i moduli, raggiungi la variabile con il suo nome completo annidato. Chiama anche la subroutine con il suo nome completo annidato. Stampa entrambi i risultati.

## Esempio

Il programma stampa:

```
10
20
```
