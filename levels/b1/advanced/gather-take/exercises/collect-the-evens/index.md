## Problem

Use `gather` and `take` to build a list of the numbers from `1` to `4`. Each number appears as many times as its own value: `1` once, `2` twice, `3` three times, and `4` four times. Print the list that you get.

## Example

The program prints:

```
[1 2 2 3 3 3 4 4 4 4]
```
