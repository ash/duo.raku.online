## Problem

An enum links names to numbers. But you can also go the other way. Call the enum type like a function with a number. You get the matching constant back.

Define an enum `Day`. Its constants `Mon` to `Fri` have the numbers `1` to `5`. Then look up the constants for the numbers `5` and `1`, and print them.

## Example

The program prints:

```
Fri
Mon
```
