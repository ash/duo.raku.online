## Problem

Define an enum `Coin`. Its constants hold their values in cents: `penny` is 1, `nickel` is 5, `dime` is 10, and `quarter` is 25. Use `.enums` to print the number of constants in the enum. Then print the sum of all their values.

## Example

The program prints:

```
4
41
```
