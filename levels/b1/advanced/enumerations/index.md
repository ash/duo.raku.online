An _enumeration_, or _enum_, is a type with a fixed set of values. Each value is a named constant. Think of the days of the week or the colours of a traffic light. The suits in a deck of cards are another example. You do not have to remember that `0` means red and `1` means amber. Instead, you give each value a name, and Raku keeps track of the numbers.

In this section, you will learn how to define an enum. You will also see how to go between its names and the values behind them.
