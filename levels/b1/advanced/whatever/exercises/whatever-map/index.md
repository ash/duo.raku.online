## Problem

A `WhateverCode` is an ordinary function value. So you can store it and pass it to `map`. Write a function with one argument that multiplies it by three. Store it in `$triple`, and use it to map the list `1..4`. Print the result.

## Example

The program prints:

```
(3 6 9 12)
```
