## Problem

On its own, `*` means “no limit”. Use it as the end of a sequence. Write the even numbers as the open sequence `2, 4 ... *`. Then take the first four of them with `head`. The sequence has no end, so only laziness makes this safe.

## Example

The program prints:

```
(2 4 6 8)
```
