## Problem

Each `*` in a Whatever expression is a separate argument. So an expression with two stars builds a function with two arguments. Write one that joins its two arguments with a hyphen between them: `* ~ '-' ~ *`. Store it in a variable. Then call it with `'a'` and `'b'`, and print the result.

## Example

The program prints:

```
a-b
```
