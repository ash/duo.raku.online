## Problem

`index` tells you *where* a character is. Then `substr` lets you cut the string at that point. Use the two methods together.

Take the email address `user@example.com`. Find the position of the `@` sign. Then print everything after it, which is the domain part.

## Example

The program prints:

```
example.com
```
