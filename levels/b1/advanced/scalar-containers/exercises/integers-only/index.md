## Problem

Declare a container `$cars` that can only keep integers.

You have a value that came from calculations with a traffic model: `250.7`. Store it in `$cars`. Convert it to an integer first, so that the assignment is accepted. Then print the value and its type.

## Example

The program prints:

```
250
(Int)
```
