## Problem

A custom trait can take an argument. It does not have to be just present or absent. Write a trait `is role(...)` that takes a string. It records the role of each subroutine in a hash. The key in the hash is the name of the subroutine.

Apply `is role('admin')` to a subroutine `login`. Then print the role that is stored for `login`.

## Example

The program prints:

```
admin
```
