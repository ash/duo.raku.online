## Problem

Raku’s `strict` pragma is on by default. This means that you must declare every variable with `my` before you use it. Turn it off with `no strict`. Then, *without* any `my`, assign `10` to `$a` and `20` to `$b`. Print their sum.

## Example

The program prints:

```
30
```
