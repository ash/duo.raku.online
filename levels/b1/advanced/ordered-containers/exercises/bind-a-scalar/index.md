## Problem

Start with a scalar `$source` that holds `1`. Then make two more names from it. Bind `$bound` to `$source` with `:=`. Give `$copy` the value of `$source` with a normal `=`. Now change `$source` to `9` and print both `$bound` and `$copy`. This shows the difference between binding and copying.

## Example

The program prints:

```
9
1
```
