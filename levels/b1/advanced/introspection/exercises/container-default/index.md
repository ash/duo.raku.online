## Problem

A container can have a default value, which you set with the `is default` trait. Until you assign something, the variable returns this default. `.VAR.default` also tells you what it is.

Declare a scalar `$count` with the default value `0`. Do not assign anything to it. First print the variable itself, and then print the default of its container. Both lines should show `0`.

## Example

The program prints:

```
0
0
```
