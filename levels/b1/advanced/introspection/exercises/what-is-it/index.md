## Problem

`WHAT` does not just describe a type. It returns the type object itself, and you can compare it with the `===` operator.

Declare two variables. The variable `$a` holds the integer `42`, and `$b` holds the string `'x'`. For each one, print if its `WHAT` is the type `Int`.

## Example

The program prints:

```
True
False
```
