Tests check that your code does what it should. They also check that it keeps working when you change it. Raku comes with a testing module, `Test`. It also has standard ways to run whole sets of tests at once. Writing tests is a key part of building real Raku programs and modules.

This section covers the basic parts of the `Test` module. It also shows the kinds of comparison that it offers and how tests are run.
