Which function in the `Test` module passes when a Boolean condition is true?

{:.quiz}
1 | `ok`
0 | `is`
0 | `plan`
0 | `done-testing`

{% include quiz.html %}

<div class="extended-explanation">

`ok` takes a condition and passes when it is true. `is` compares an actual value with an expected one. `plan` says how many tests to expect. `done-testing` ends the file and prints the plan.

</div>
