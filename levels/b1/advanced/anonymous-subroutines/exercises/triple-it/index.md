## Problem

An anonymous subroutine is a closure. It remembers the variables that were in scope where you wrote it. Declare a variable `$factor` with the value `3`. Then store a pointy block in `$scale` that multiplies its argument by `$factor`. Do not write a fixed `3` in the block. Call `$scale(7)` and print the result.

## Example

The program prints:

```
21
```
