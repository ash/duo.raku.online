## Problem

A pointy block can take more than one parameter. The `&` sigil lets you call it by name. Write a pointy block with two parameters that adds its arguments. Store it in a variable `&add`, declared with the `&` sigil. Then call it as `add(2, 3)`, without the sigil, and print the result.

## Example

The program prints:

```
5
```
