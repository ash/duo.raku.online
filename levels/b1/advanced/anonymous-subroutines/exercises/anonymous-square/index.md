## Problem

An anonymous subroutine does not have to be stored first. You can pass it directly to another routine. Use the `sub` form, not a pointy block, and write an anonymous “square” subroutine. Pass it directly to `map` over the list `1, 2, 3` and print the result.

## Example

The program prints:

```
(1 4 9)
```
