## Problem

It is usually hard to see if a number is prime just by looking. The `is-prime` method answers this question. Use it on two numbers which both look prime at first: `97` and `91`. Print the result for each one on a separate line.

The tricky one is `91`, because it equals `7 × 13`.

## Example

The program prints:

```
True
False
```
