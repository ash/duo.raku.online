## Problem

Reading a number in a base and writing it back are opposite operations. Take the hexadecimal number `1A` and store its decimal value in a variable. Then print two lines. The first is the decimal value. The second is the same value, turned back into a hexadecimal string.

## Example

The program prints:

```
26
1A
```
