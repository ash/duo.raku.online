## Problem

Because Raku integers have arbitrary precision, Raku can calculate `2 ** 1000` exactly. The number is much too long to count yourself, so let the program do it. Print how many decimal digits the value of `2 ** 1000` has.

## Example

The program prints:

```
302
```
