## Problem

A URL has been split into pieces, and the pieces are in an array. Join them back into one string with a reduction meta-operator. Print the URL, and on the next line, print how many characters it has.

## Example

Take this input array:

```raku
my @parts = <http :// example .com>;
```

With this array, the program prints:

```
http://example.com
18
```
