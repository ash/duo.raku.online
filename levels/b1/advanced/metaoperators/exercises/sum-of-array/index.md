## Problem

Write a program that prints the average of an array of numbers. The average is also called the arithmetic mean. Use a reduction meta-operator to add up the values.

The input data are written directly in the program, for example:

```raku
my @data = 10, 20, 30, 40;
```

## Example

The program prints the average value of the elements in `@data`:

```
25
```
