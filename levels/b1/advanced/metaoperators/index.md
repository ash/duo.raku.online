title: Meta-operators
---

{% include menu.html %}

A _meta-operator_ is not an operator by itself. It goes around an ordinary operator and turns it into a new one. For example, it can apply one operator to a whole list of values at once. Then you do not have to write the operator between every pair of values.

Raku has several meta-operators. This section covers the most useful groups of them. A _reduction_ turns a list into a single value. A _zip_ combines two lists element by element. The last page covers the _cross_, _hyper_, and _negated_ operators.
