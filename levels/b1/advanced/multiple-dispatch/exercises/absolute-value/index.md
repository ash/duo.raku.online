## Problem

Write two multi-subroutines called `abs-value` that take an integer and return its absolute value. Use a `where` clause to handle negative numbers separately. Do not use any `if` inside the subroutines. Do not use the built-in `abs` either.

Print the result for `-7` and for `4`.

## Example

The program prints:

```
7
4
```
