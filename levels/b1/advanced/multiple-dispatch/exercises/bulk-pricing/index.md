## Problem

Write two multi-subroutines called `price` that take an integer quantity. Use a `where` clause so that an order of 10 or more items prints `bulk price`. A smaller order should print `normal price`.

Call the subroutine for the quantities `3` and `25`.

## Example

The program prints:

```
normal price
bulk price
```
