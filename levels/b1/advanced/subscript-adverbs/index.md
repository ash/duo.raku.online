title: Subscript adverbs
---

{% include menu.html %}

Subscripts like `@a[2]` or `%h<key>` get values from an array or a hash. You can add an _adverb_ to such a subscript. The adverb changes what the subscript does. Instead of just getting the value, you can ask whether a key exists. You can also delete the key, or get the key and the value together.

You write these adverbs after the subscript, with a colon. They work in the same way with arrays and with hashes. This section covers the most useful ones.
