## Problem

Start from the `q` form, which does not interpolate. Turn on only the closure adverb. The variable `$x` holds `10`. Print a line with the calculation `{$x ** 2}` *and* a plain `$x` that is not interpolated. This shows that the closure adverb runs code in braces. But it leaves plain `$` variables as they are.

## Example

The program prints:

```
$x squared is 100
```
