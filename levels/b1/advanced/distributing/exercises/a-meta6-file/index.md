## Problem

Write a `META6.json` for a distribution called `Greet::Simple`, version `0.0.1`. It provides the module `Greet::Simple` from the file `lib/Greet/Simple.rakumod`. In the example from the theory, `depends` was empty. This time, the distribution **depends on** another distribution, `JSON::Fast`. Add it to the `depends` array.

> The result of this exercise is a file, not program output.
