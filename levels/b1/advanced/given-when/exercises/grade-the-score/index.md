## Problem

The age is fixed in the code. Use `given`/`when` to print its stage of life. Use these groups:

* `child` for 0–12,
* `teenager` for 13–19,
* `adult` for 20–64,
* `senior` for 65 and above.

A negative age makes no sense, so print `invalid` for any number below zero. Make sure that you check this case before the ranges.

## Example

For the age `30`, the program prints:

```
adult
```
