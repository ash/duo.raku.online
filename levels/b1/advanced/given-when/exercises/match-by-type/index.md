## Problem

A `when` can match against a *type*, not only a value. A variable holds the number `3.14`. Use `given`/`when` to show what kind of value it is. Print `integer` for an `Int`, `rational` for a `Rat`, and `string` for a `Str`.

## Example

The program prints:

```
rational
```
