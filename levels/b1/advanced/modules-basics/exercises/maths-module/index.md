## Problem

Create a module called `Maths` in a file `Maths.rakumod`. It should export a subroutine `square` that returns the square of its argument.

Then write a separate program that uses the module and prints `square(6)`.

## Example

If you run it with the module on the search path, the program prints:

```console
$ raku -I. maths.raku
36
```
