A _module_ is a file of code that you can use again and again. It holds subroutines, variables and more, and other programs can load and share it. This section covers the basics in three steps. First, you will see how to **write** a module and mark what it offers. Then you will see how a program **loads** it with `use`. Finally, you will see how **importing** brings the names of a module into your scope.
