## Problem

Write a Pod block with a `=head1` heading `Greeting` and a paragraph `Hello, world!`. In the paragraph, mark the word `world` as bold with `B<…>`. Render the block as text with `raku --doc`.

> Run the file with `raku --doc` to see the formatted text.

## Example

When you render it with `raku --doc`, it prints:

```
Greeting

Hello, world!
```
