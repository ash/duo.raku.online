## Problem

Put a module `Inner` inside a module `Outer`. In `Inner`, declare an `our` variable `$base` with the value `10`. Also declare an `our sub doubled` that returns `$base` multiplied by two. From outside both modules, reach the variable through its full nested name. Call the subroutine through its full nested name too. Print both results.

## Example

The program prints:

```
10
20
```
