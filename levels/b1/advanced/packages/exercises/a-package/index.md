## Problem

Create a package `Temperature` that groups two things together. The first is an `our` variable `$freezing` with the value `0`. The second is an `our` subroutine `fahrenheit`, which converts a Celsius value to Fahrenheit. To convert, multiply by 9/5 and add 32. From outside the package, print the freezing point. Then print the Fahrenheit value of `100` degrees Celsius.

## Example

The program prints:

```
0
212
```
