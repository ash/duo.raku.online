## Problem

The `**` operator binds more tightly than `+`, so `2 ** 3 + 1` means `(2 ** 3) + 1`, which is `9`. Add parentheses to change this order, so that the addition happens *first*. Then print the result.

## Example

The program prints:

```
16
```
