## Problem

The colon form must be the *last* call in a chain. But the calls before it can be ordinary calls with parentheses. Start with the words `a`, `b`, `c` and reverse them with `.reverse`. Then join the result with a dash, using the **colon** form. Print it.

## Example

The program prints:

```
c-b-a
```
