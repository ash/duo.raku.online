## Problem

Sort the words `pear`, `fig`, `apple`, `kiwi` by their **length**. Put the shortest first and the longest last. Use the colon form of the call. Give the sort key as a Whatever expression, not as a block. Print the result.

## Example

The program prints:

```
(fig pear kiwi apple)
```
