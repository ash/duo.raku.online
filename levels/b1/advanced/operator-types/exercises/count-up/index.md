## Problem

Start with `my $n = 9;`. The postfix `++` operator has a feature that is easy to miss. As an expression, it returns the value that the variable had *before* the increment. Only then does it add one to the variable.

Print the result of `$n++` with a single `say`. On the next line, print `$n` itself, so that you can see the difference.

## Example

The program prints:

```
9
10
```
