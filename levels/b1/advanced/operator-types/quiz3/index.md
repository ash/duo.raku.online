The `x` operator repeats a string. For example, `'ab' x 3` gives `'ababab'`. Since `x` stands between its two operands, which category is it in?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Position is what matters, not whether the operator is a symbol or a word. `x` stands *between* two operands, so it is an **infix** operator. It is just like `+` or `~`, but written as a letter.

</div>
