## Problem

Take the array `1, 2, 3` and pack it into a scalar `$x` with the **item** contextualiser. Then `$x` holds the whole array as a single value. Next, use the **list** contextualiser to run a `for` loop over `$x`. Count how many times the loop runs. List context spreads the packed array back into its elements. So the loop runs three times. Print the count.

## Example

The program prints:

```
3
```
