## Problem

You have a list of numbers, and some of them repeat:

```raku
my @data = 3, 1, 4, 1, 5, 9, 2, 6, 5, 3;
```

Print how many _distinct_ values are in it. Use a set for this.

## Example

The program prints:

```
7
```
