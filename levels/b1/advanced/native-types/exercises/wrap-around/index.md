## Problem

A `uint8` wraps around in both directions. This also happens when you go past the edge by more than one. Show this:

1. Take a `uint8` with the value `250`, add `10` to it, and print the result.
1. Take another `uint8` with the value `0`. Subtract one from it (decrement it) and print the result.

## Example

The program prints:

```
4
255
```
