## Problem

A native variable can never be undefined. This rule is true for every native type, not only for `int`. Declare a native `num` and a native `str` without assigning values to them. Print the number. Then print the string inside square brackets, so that you can see it is empty.

## Example

The program prints:

```
0
[]
```
