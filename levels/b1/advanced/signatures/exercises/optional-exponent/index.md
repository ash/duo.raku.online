## Problem

Write a subroutine `power` with a required parameter `$base` and an **optional** parameter `$exp`. When the exponent is given, raise the base to it. When it is left out, square the base by default. Use the defined-or operator `//` to give `2`.

Call it twice. First call it with only a base, then with a base and an exponent.

## Example

The program prints:

```
25
125
```
