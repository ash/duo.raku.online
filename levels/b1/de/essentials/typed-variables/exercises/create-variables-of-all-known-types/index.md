## Aufgabe

Schreiben Sie ein Programm, das einige skalare Variablen erstellt. Geben Sie ihnen Startwerte dieser Typen: `Int`, `Rat`, `Num`, `Bool` und `Str`. Das Programm soll jeden Wert und seinen Typ ausgeben.

## Beispiel

Die echte Ausgabe Ihres Programms kann anders aussehen. Aber dieser Testlauf zeigt die Idee:

```console
$ raku types.raku
151 (Int)
4.2 (Rat)
1e10 (Num)
True (Bool)
xyz (Str)
```
