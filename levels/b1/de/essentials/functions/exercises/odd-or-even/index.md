## Problem

Erstellen Sie eine Funktion, die eine ganze Zahl als Argument nimmt. Die Funktion gibt die Zeichenkette `'Ungerade'` oder `'Gerade'` zurück. Verwenden Sie sie dann in einem Programm und geben Sie die Antwort für einige Zahlen aus. Nehmen Sie zum Beispiel `10`, `5`, `0` und `3`.

## Beispiel

Für diese Zahlen soll das Programm Folgendes ausgeben:

```console
$ raku odd-or-even.raku
Gerade
Ungerade
Gerade
Ungerade
```
