## Problem

Schreiben Sie ein Programm, das die Werte der Funktion `f(x) = x²` ausgibt. Nehmen Sie `x` im Intervall [−3, 3] mit einer Schrittweite von 0,1.

## Beispiel

Das Programm soll zwei Spalten ausgeben. Die erste Spalte zeigt `x`, und die zweite Spalte zeigt `f(x)`.

```
$ raku function-table.raku
-3	9
-2.9	8.41
-2.8	7.84
. . .
```
