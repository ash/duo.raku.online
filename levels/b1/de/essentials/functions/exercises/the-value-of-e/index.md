## Problem

Erstellen Sie eine Funktion, die einen ungefähren Wert der mathematischen Konstante _e_ berechnet. Verwenden Sie die folgende Formel:

<img src="e-formula.png" style="height: 4.5em; width: auto">

Sie sollten diese Funktion in jeder dieser beiden Formen aufrufen können:

1. Das Argument legt die Anzahl der Elemente in der Formel fest: `e-approx(10)`.
2. Wenn es kein Argument gibt, hat die Summe 100 Elemente: `e-approx()`.

Geben Sie die Ergebnisse für beide Fälle aus.

## Beispiel

```console
$ raku the-value-of-e.raku
2.7182818
2.718281828459045
```
