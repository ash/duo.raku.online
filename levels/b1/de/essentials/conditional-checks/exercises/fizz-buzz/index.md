## Problem

Diese Aufgabe ist eine einfachere Version des bekannten [FizzBuzz-Problems](https://en.wikipedia.org/wiki/Fizz_buzz).

Schreiben Sie ein Programm, das nach einer positiven ganzen Zahl fragt und Folgendes ausgibt:

* `Fizz`, wenn die Zahl durch 3 teilbar ist.
* `Buzz`, wenn die Zahl durch 5 teilbar ist.

## Beispiel

Wenn Sie das Programm starten, fragt es nach einer Zahl. Danach gibt es das Ergebnis aus.

```console
$ raku fizz-buzz.raku
Geben Sie eine Zahl ein: 10
Buzz
```
