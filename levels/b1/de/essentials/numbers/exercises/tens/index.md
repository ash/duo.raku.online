## Problem

Schreiben Sie ein Programm, das den Benutzer bittet, eine positive ganze Zahl einzugeben. Dann gibt es die Ziffer aus, die zeigt, wie viele _Zehner_ die Zahl hat.

## Beispiel

Wenn die Eingabezahl zum Beispiel 234 ist, ist die Anzahl der Zehner 3. Also gibt das Programm 3 aus:

```console
$ raku tens.raku
Geben Sie eine positive ganze Zahl ein: 234
3
```
