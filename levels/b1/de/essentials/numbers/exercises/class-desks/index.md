## Problem

Eine Schule bereitet sich auf das Jahr nach dem Coronavirus vor. Sie will neue Schreibtische bestellen, und jeder Schreibtisch ist für zwei Schüler gemacht. Du kennst die Anzahl der Schüler in der Klasse. Gib die kleinste mögliche Anzahl von Schreibtischen aus, die die Schule für die Klasse kaufen muss.

Speichere die Anzahl der Schüler direkt im Code in einer Variablen.

## Beispiel

Hier ist die erste Zeile des Programms:

```raku
my $students = 23;
# Dein Code hier . . .
```

Wenn du das Programm ausführst, solltest du Folgendes sehen:

```console
$ raku class-desks.raku
12 Schreibtische müssen gekauft werden.
```
