## Problem

Schreiben Sie ein Programm, das den Benutzer bittet, drei Zahlen nacheinander einzugeben. Dann gibt es ihre Summe aus.

## Beispiel

Hier ist ein Beispiel dafür, wie das Programm funktionieren soll:

```console
$ raku sum-of-numbers.raku
Geben Sie Zahl A ein: 10
Geben Sie Zahl B ein: 20
Geben Sie Zahl C ein: 30
Die Summe der Zahlen ist 60.
```
