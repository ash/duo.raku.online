## Problem

Schreiben Sie ein Programm, das den Benutzer bittet, eine positive ganze Zahl einzugeben. Dann gibt es die letzte Ziffer dieser Zahl aus.

## Beispiel

So kann die Arbeit mit dem Programm aussehen:

```console
$ raku die-letzte-ziffer.raku
Geben Sie eine Zahl ein: 123
Die letzte Ziffer von 123 ist 3.
```
