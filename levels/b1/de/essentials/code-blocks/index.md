Codeblöcke sind Teile Ihres Programms zwischen zwei geschweiften Klammern: `{` und `}`. Ein Block fasst mehrere Anweisungen zusammen, die wie eine große Anweisung zusammenarbeiten. In den nächsten Abschnitten sehen wir viele Wege, Blöcke zu benutzen.

```raku
{
    say 'Hallo, Welt!';
}
```

Der Codeblock in diesem Programm ergibt eigentlich keinen Sinn. Aber Codeblöcke sind in anderen Situationen sehr nützlich, die wir sehr bald sehen werden.
