## Problem

Schreiben Sie ein Programm, das nach Ihrem Alter fragt. Wenn der Wert negativ ist, gibt es eine oder zwei Warnungen aus. Achten Sie darauf, dass die Warnung an `STDERR` geht.

## Beispiel

Hier sind zwei mögliche Fälle:

```console
$ raku print-the-warning.raku
Wie alt sind Sie? 20
Ihr Alter ist 20

$ raku print-the-warning.raku
Wie alt sind Sie? -1
Sie haben eine negative Zahl eingegeben!
```
