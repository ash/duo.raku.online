Hier ist eine mögliche Lösung für die Aufgabe.

## Code

```raku
my $answer = 42;
say $answer;
```

🦋 Du findest den Quellcode in der Datei [answer.raku](https://github.com/ash/raku-course/blob/master/exercises/essentials/scalar-variables/answer.raku).

## Ausgabe

Führe das Programm aus und sieh, was es ausgibt:

```console
$ raku exercises/scalar-variables/answer.raku 
42
```

## Kommentare

Eine der Bedingungen dieser Aufgabe war, Variablen zu verwenden. `42` ist ein einzelner Wert, also ist eine skalare Variable eine gute Wahl dafür.
