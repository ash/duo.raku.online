## Problem

Schreiben Sie ein Programm, das diese zwei Dinge macht:

1. Bittet den Benutzer, seinen Namen einzugeben.
2. Gibt die Nachricht `Hallo, Name!` aus. Statt `Name` zeigt es den Namen, den der Benutzer gerade eingegeben hat.

Verwenden Sie in diesem Programm bitte Variablen.

## Beispiel

So soll das Programm funktionieren:

```console
$ raku greet-a-person.raku
Wie heißt du? John
Hallo, John!
```
