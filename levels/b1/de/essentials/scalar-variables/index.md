Bisher standen die Textzeichenfolgen in unseren Programmen direkt im Code. Lassen Sie uns jetzt etwas Freiheit einführen und das Programm Variablen verwenden lassen.

Raku hat einige Arten von Variablen. Eine Variable ist ein Behälter, der Daten speichern kann. Wir beginnen mit den einfachsten Behältern, die nur einen Wert speichern. Man nennt sie _Skalare_ oder skalare Variablen. Der Name einer Variablen beginnt mit einem besonderen Zeichen. Es zeigt, welche Art von Behälter die Variable ist. Dieses Zeichen heißt _Sigil_. Für skalare Behälter ist das Sigil das Dollarzeichen `$`.

Hier sind zwei Beispiele für skalare Variablen:

```raku
$name

$age
```
