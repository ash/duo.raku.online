## Aufgabe

Schreiben Sie ein Programm, das die Argumente zählt, die es von der Befehlszeile bekommen hat. Es soll die Anzahl in einem vollständigen Satz melden. Die Grammatik muss richtig sein. Verwenden Sie das Wort `argument`, wenn es genau eines ist, und `arguments` in allen anderen Fällen.

## Beispiel

So soll das Programm antworten:

```console
$ raku number-of-command-line-arguments.raku make them count us now
You passed 5 arguments.

$ raku number-of-command-line-arguments.raku solo
You passed 1 argument.
```
