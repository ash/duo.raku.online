## Problem

Die Ampel wechselt jede Sekunde ihre Farbe. Wenn sie eingeschaltet wird, beginnt sie mit Gelb. Dann wechselt die Farbe jede Sekunde in dieser Reihenfolge: Gelb — Rot — Gelb — Grün. Danach beginnt der Zyklus von vorne.

Schreiben Sie ein Programm, das den Zustand der Ampeln ausgibt. Geben Sie ihn für die 51<sup>ste</sup>, 102<sup>te</sup> und 305<sup>te</sup> Sekunde aus. Nehmen Sie an, dass die Farbe in der 1<sup>sten</sup> Sekunde Rot ist.

## Beispiel

Das Programm soll drei Farben auf separaten Zeilen ausgeben:

```console
$ raku traffic-lights.raku
...
...
...
```
