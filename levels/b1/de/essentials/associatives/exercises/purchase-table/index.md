## Problem

Verwenden Sie die Tabelle aus der Übung ‘[Einkaufstabelle](/de/essentials/strings/exercises/purchase-table)’, die Sie schon früher gemacht haben:

    Artikel  Preis   Anzahl  Gesamt
    Stühle   $20.57  4       $82.28
    Tische   $50.18  1       $50.18

Schlagen Sie eine Datenstruktur für diese Werte vor. Schreiben Sie dann ein Programm, das sie ausgibt.

## Beispiel

Wenn Sie das Programm ausführen, sollte es die Tabelle von oben ausgeben.

```console
$ raku purchase-table.raku
```
