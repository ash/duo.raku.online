{% include menu.html %}

Sie können `loop` auch nur mit einem Körper verwenden:

```raku
loop {
    say 'Ewigkeit';
}
```

Diese Schleife läuft endlos, bis Sie das Programm beenden, zum Beispiel durch Drücken von `Strg+C`. Im zweiten Teil des Kurses sehen wir bessere Möglichkeiten, Schleifen zu steuern.
