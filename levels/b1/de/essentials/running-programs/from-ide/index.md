Dieser kurze Abschnitt erklärt, wie Sie ein Programm in der IDE ausführen. Er behandelt die beiden am meisten empfohlenen [IDEs](../../editors-and-ides).

## Visual Studio Code Editor

Öffnen Sie ein Terminal über das Menü `Terminal` → `New Terminal`. Es fügt ein Panel unter dem Text Ihres Programms hinzu. Führen Sie das Programm dort aus, genau wie auf der Kommandozeile:

```console
$ raku hello.raku
```

## Comma IDE

Sie können Programme über den Menüpunkt `Run` ausführen. Richten Sie die IDE vor dem ersten Start eines Programms ein. Folgen Sie [den Anweisungen](https://commaide.com/docs/running) auf der Comma-Website.
