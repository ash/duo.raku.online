In [einem der vorherigen Abschnitte](../hello-world) haben wir ein einfaches Programm erstellt. Aber wir haben es noch nicht ausgeführt. Es gibt viele Möglichkeiten, ein Programm auszuführen. Sie können ein installiertes Befehlszeilentool oder eine REPL-Shell benutzen. Sie können es auch direkt aus einer [IDE](../editors-and-ides) ausführen. Ein anderer Weg ist ein Online-Dienst wie [glot.io](https://glot.io/new/raku). Sie können auch einen Docker-Container verwenden.

Dieser Abschnitt hat fünf Themen. Sehen Sie sich alle an, oder lesen Sie nur die, die Sie brauchen. Nach den Themen gibt es eine Aufgabe.
