## Problem

Schreiben Sie ein Programm, das eine Preistabelle im folgenden Format ausgibt. Bitte speichern Sie die Preise und die Gesamtsummen in Variablen.

    Artikel  Preis   N      Gesamt
    Stühle   $20.57  4      $82.28
    Tische   $50.18  1      $50.18

Hinweis: Wenn Sie diese Währung nicht mögen, können Sie jede andere verwenden. Aber denken Sie daran, dass `$` in Raku-Strings [eine besondere Bedeutung hat](/de/essentials/strings/escaping-special-characters). Genau deshalb haben wir den Dollar gewählt, damit Sie Raku besser lernen.

## Beispiel

Dieses Programm bekommt keine Eingabe. Wenn Sie es ausführen, gibt es einfach die Tabelle oben aus.

```console
$ raku purchase-table.raku
```
