Diese Dateierweiterungen sind für Raku-Dateien [empfohlen](https://github.com/Raku/problem-solving/blob/master/solutions/language/Path-to-Raku.md#extensions):

* `.raku` für Programmdateien
* `.rakumod` für Module
* `.rakutest` und `.t` für Tests
* `.rakudoc` für Dokumentation im POD6-Format
