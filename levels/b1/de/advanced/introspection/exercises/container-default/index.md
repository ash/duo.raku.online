## Aufgabe

Ein Container kann einen Standardwert haben, den du mit dem Trait `is default` setzt. Solange du nichts zuweist, gibt die Variable diesen Standardwert zurück. `.VAR.default` sagt dir auch, welcher Wert das ist.

Deklariere einen Skalar `$count` mit dem Standardwert `0`. Weise ihm nichts zu. Gib zuerst die Variable selbst aus und dann den Standardwert ihres Containers. Beide Zeilen sollten `0` zeigen.

## Beispiel

Das Programm gibt aus:

```
0
0
```
