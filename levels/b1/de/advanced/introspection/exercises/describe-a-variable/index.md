## Aufgabe

Hier ist eine typisierte Variable:

```raku
my Str $lang = 'Raku';
```

Gib drei Fakten über sie aus, einen in jeder Zeile:

1. den Typ ihres Wertes;
2. den Typ ihres Containers;
3. ihren Namen, einschließlich des Sigils.

## Beispiel

Das Programm gibt aus:

```
Str
Scalar
$lang
```
