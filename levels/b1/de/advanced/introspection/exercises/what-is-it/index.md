## Aufgabe

`WHAT` beschreibt nicht bloß einen Typ. Es gibt das Typ-Objekt selbst zurück, und du kannst es mit dem Operator `===` vergleichen.

Deklariere zwei Variablen. Die Variable `$a` enthält die Ganzzahl `42`, und `$b` enthält den String `'x'`. Gib für jede aus, ob ihr `WHAT` der Typ `Int` ist.

## Beispiel

Das Programm gibt aus:

```
True
False
```
