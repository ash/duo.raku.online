## Problem

Ein `when` kann auf einen *Typ* passen, nicht nur auf einen Wert. Eine Variable enthält die Zahl `3.14`. Zeige mit `given`/`when`, welche Art von Wert das ist. Gib `integer` für einen `Int`, `rational` für einen `Rat` und `string` für einen `Str` aus.

## Beispiel

Das Programm gibt aus:

```
rational
```
