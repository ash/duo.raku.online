## Problem

Eine ganze Zahl steht fest im Code. Gib mit `given`/`when` aus, ob sie `zero`, `even` oder `odd` ist. Beachte, dass null genau genommen gerade ist. Prüfe also zuerst darauf und gib sie getrennt aus.

## Beispiel

Für die Zahl `12` gibt das Programm aus:

```
even
```
