## Problem

Beginne mit der `q`-Form, die nicht interpoliert. Schalte nur das Closure-Adverb ein. Die Variable `$x` enthält `10`. Gib eine Zeile mit der Rechnung `{$x ** 2}` *und* einem einfachen `$x` aus, das nicht interpoliert wird. Das zeigt, dass das Closure-Adverb Code in geschweiften Klammern ausführt. Aber einfache `$`-Variablen lässt es so, wie sie sind.

## Beispiel

Das Programm gibt aus:

```
$x squared is 100
```
