## Problem

Schreibe eine `META6.json` für eine Distribution namens `Greet::Simple`, Version `0.0.1`. Sie stellt das Modul `Greet::Simple` aus der Datei `lib/Greet/Simple.rakumod` bereit. Im Beispiel aus der Theorie war `depends` leer. Diesmal **hängt** die Distribution von einer anderen Distribution **ab**, von `JSON::Fast`. Füge sie zum Array `depends` hinzu.

> Das Ergebnis dieser Aufgabe ist eine Datei, keine Programmausgabe.

## Beispiel

Eine korrekte Datei mit nur den nötigen Teilen sieht so aus wie die in der Lösung.
