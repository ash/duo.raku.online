Geordnete Container speichern mehrere Elemente in einer festen Reihenfolge. So kannst du jedes Element über seine Position erreichen. In Sonderfällen können sie auch nur ein Element enthalten oder gar keines. Die häufigsten geordneten Container sind _Arrays_ und _Listen_.

Das Sigil `@` sagt dir, dass eine Variable für viele Elemente da ist. So eine Variable unterstützt Indizierung, das heißt, du kannst ein Element über seinen Index lesen. Das hast du schon im Grundlagenteil gesehen.

In diesem Abschnitt sehen wir uns genauer an, wie sich Arrays und Listen _als Container_ unterscheiden. Welche davon kannst du ändern? Was passiert, wenn du einen Container in einen anderen steckst? Und wie gibt _Binding_ einem Container einen Namen, ohne etwas zu kopieren?
