## Aufgabe

Du hast zwei Arrays:

```raku
my @first = 1, 2;
my @second = 3, 4, 5;
```

Verbinde sie zu einem _flachen_ Array, nicht zu einem verschachtelten. Gib das Array aus und dann die Anzahl seiner Elemente.

## Beispiel

Das Programm gibt aus:

```
[1 2 3 4 5]
5
```
