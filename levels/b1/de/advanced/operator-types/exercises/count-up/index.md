## Problem

Beginnen Sie mit `my $n = 9;`. Der Postfix-Operator `++` hat eine Eigenschaft, die man leicht übersieht. Als Ausdruck gibt er den Wert zurück, den die Variable *vor* dem Erhöhen hatte. Erst danach addiert er eins zur Variablen.

Geben Sie das Ergebnis von `$n++` mit einem einzigen `say` aus. Geben Sie in der nächsten Zeile `$n` selbst aus, damit Sie den Unterschied sehen.

## Beispiel

Das Programm gibt aus:

```
9
10
```
