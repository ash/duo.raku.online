Der Operator `x` wiederholt einen String. Zum Beispiel ergibt `'ab' x 3` den String `'ababab'`. Da `x` zwischen seinen zwei Operanden steht: Zu welcher Kategorie gehört dieser Operator?

{:.quiz}
1 | infix
0 | prefix
0 | postfix
0 | circumfix

{% include quiz.html %}

<div class="extended-explanation">

Wichtig ist die Position, nicht ob der Operator ein Symbol oder ein Wort ist. `x` steht *zwischen* zwei Operanden, also ist er ein **Infix**-Operator. Er ist genau wie `+` oder `~`, nur als Buchstabe geschrieben.

</div>
