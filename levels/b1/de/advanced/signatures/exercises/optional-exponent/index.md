## Problem

Schreiben Sie eine Subroutine `power` mit einem erforderlichen Parameter `$base` und einem **optionalen** Parameter `$exp`. Wenn der Exponent angegeben ist, rechnen Sie Basis hoch Exponent. Wenn er fehlt, quadrieren Sie die Basis als Standard. Nutzen Sie den Defined-or-Operator `//`, um `2` anzugeben.

Rufen Sie sie zweimal auf. Rufen Sie sie zuerst nur mit einer Basis auf, dann mit einer Basis und einem Exponenten.

## Beispiel

Das Programm gibt aus:

```
25
125
```
