## Aufgabe

Nimm den Hash `a => 1, b => 2, c => 3`. Verwende ein Subscript-Adverb, um den Eintrag `b` zu löschen. Gib dann aus, wie viele Einträge übrig sind, um zu zeigen, dass einer davon entfernt wurde.

## Beispiel

Das Programm gibt aus:

```
2
```
