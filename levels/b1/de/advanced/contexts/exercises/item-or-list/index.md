## Aufgabe

Nimm das Array `1, 2, 3` und packe es mit dem **Element**-Kontextualisierer in einen Skalar `$x`. Dann enthält `$x` das ganze Array als einzelnen Wert. Verwende danach den **Listen**-Kontextualisierer, um eine `for`-Schleife über `$x` laufen zu lassen. Zähle, wie oft die Schleife läuft. Der Listenkontext breitet das gepackte Array wieder in seine Elemente aus. Also läuft die Schleife dreimal. Gib die Anzahl aus.

## Beispiel

Das Programm gibt aus:

```
3
```
