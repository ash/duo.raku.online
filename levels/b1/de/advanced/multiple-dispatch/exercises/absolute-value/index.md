## Problem

Schreiben Sie zwei Multi-Subroutinen namens `abs-value`, die eine ganze Zahl nehmen und ihren Absolutwert zurückgeben. Behandeln Sie negative Zahlen getrennt mit einer `where`-Klausel. Verwenden Sie kein `if` innerhalb der Subroutinen. Verwenden Sie auch nicht das eingebaute `abs`.

Geben Sie das Ergebnis für `-7` und für `4` aus.

## Beispiel

Das Programm gibt aus:

```
7
4
```
