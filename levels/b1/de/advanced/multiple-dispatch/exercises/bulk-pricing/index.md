## Problem

Schreiben Sie zwei Multi-Subroutinen namens `price`, die eine ganzzahlige Menge nehmen. Verwenden Sie eine `where`-Klausel, damit eine Bestellung mit 10 oder mehr Artikeln `bulk price` ausgibt. Eine kleinere Bestellung soll `normal price` ausgeben.

Rufen Sie die Subroutine für die Mengen `3` und `25` auf.

## Beispiel

Das Programm gibt aus:

```
normal price
bulk price
```
