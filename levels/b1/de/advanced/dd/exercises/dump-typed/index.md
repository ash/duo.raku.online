## Aufgabe

Deklariere eine Ganzzahl-Variable mit Typ: `my Int $n = 42;`. Gib sie dann mit `dd` aus. Achte darauf, wie sich die Ausgabe von der einer untypisierten Variable unterscheidet.

## Beispiel

Das Programm gibt das auf die Standardfehlerausgabe aus:

```
Int $n = 42
```
