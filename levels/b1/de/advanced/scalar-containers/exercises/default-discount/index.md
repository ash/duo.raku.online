## Aufgabe

Deklariere eine skalare Variable `$discount` mit dem Standardwert `0`. Gib die Variable aus, bevor du ihr etwas zuweist. Das Programm muss `0` ausgeben und darf keine Warnung zeigen.

Weise dann `15` der Variable zu und gib sie erneut aus.

## Beispiel

Das Programm gibt zwei Zeilen aus:

```
0
15
```
