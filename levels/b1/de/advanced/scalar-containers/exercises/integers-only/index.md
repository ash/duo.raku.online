## Aufgabe

Deklariere einen Container `$cars`, der nur Ganzzahlen speichern kann.

Du hast einen Wert, der aus Berechnungen mit einem Verkehrsmodell kommt: `250.7`. Speichere ihn in `$cars`. Wandle ihn vorher in eine Ganzzahl um, damit die Zuweisung akzeptiert wird. Gib dann den Wert und seinen Typ aus.

## Beispiel

Das Programm gibt aus:

```
250
(Int)
```
