## Problem

Das `strict`-Pragma von Raku ist standardmäßig eingeschaltet. Das bedeutet, dass Sie jede Variable mit `my` deklarieren müssen, bevor Sie sie benutzen. Schalten Sie es mit `no strict` aus. Weisen Sie dann, *ohne* ein `my`, der Variablen `$a` den Wert `10` und `$b` den Wert `20` zu. Geben Sie ihre Summe aus.

## Beispiel

Das Programm gibt aus:

```
30
```
