Mit zwei Funktionen können Sie ändern, wie Code **kompiliert** wird, noch bevor er läuft. Ein _Trait_ ist ein Modifikator für eine Deklaration, zum Beispiel für eine Variable oder eine Routine. Sie schreiben es mit `is`. Ein _Pragma_ ist eine besondere Anweisung, die wie ein Modul aussieht. Sie schalten es mit `use` ein oder mit `no` aus. Es ändert eine Regel für den Rest des lexikalischen Gültigkeitsbereichs.

Sie haben schon ein Trait wie `is default` benutzt, ohne viel darauf zu achten. Dieser Abschnitt betrachtet Traits als eigene Funktion. Er zeigt, wie Sie eigene Traits schreiben, und stellt Pragmas vor.
