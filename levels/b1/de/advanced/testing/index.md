Tests prüfen, ob dein Code das tut, was er soll. Sie prüfen auch, ob er weiter funktioniert, wenn du ihn änderst. Raku bringt ein Testmodul mit, `Test`. Raku hat auch Standardwege, um ganze Gruppen von Tests auf einmal auszuführen. Tests zu schreiben ist ein wichtiger Teil der Arbeit an echten Raku-Programmen und -Modulen.

Dieser Abschnitt behandelt die grundlegenden Teile des `Test`-Moduls. Er zeigt auch, welche Arten von Vergleichen es bietet und wie man Tests ausführt.
