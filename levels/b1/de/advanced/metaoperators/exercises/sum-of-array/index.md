## Aufgabe

Schreiben Sie ein Programm, das den Durchschnitt eines Arrays von Zahlen ausgibt. Der Durchschnitt heißt auch arithmetisches Mittel. Verwenden Sie einen Reduktions-Meta-Operator, um die Werte zu addieren.

Die Eingabedaten stehen direkt im Programm, zum Beispiel:

```raku
my @data = 10, 20, 30, 40;
```

## Beispiel

Das Programm gibt den Durchschnittswert der Elemente in `@data` aus:

```
25
```
