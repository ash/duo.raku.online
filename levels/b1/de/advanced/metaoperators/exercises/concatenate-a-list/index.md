## Aufgabe

Eine URL wurde in Teile zerlegt, und die Teile liegen in einem Array. Fügen Sie sie mit einem Reduktions-Meta-Operator wieder zu einer Zeichenkette zusammen. Geben Sie die URL aus und in der nächsten Zeile, wie viele Zeichen sie hat.

## Beispiel

Nehmen Sie dieses Eingabe-Array:

```raku
my @parts = <http :// example .com>;
```

Mit diesem Array gibt das Programm aus:

```
http://example.com
18
```
