Ein _Meta-Operator_ ist kein Operator für sich allein. Er legt sich um einen gewöhnlichen Operator und macht daraus einen neuen. Zum Beispiel kann er einen Operator auf eine ganze Liste von Werten auf einmal anwenden. Dann müssen Sie den Operator nicht zwischen jedes Paar von Werten schreiben.

Raku hat mehrere Meta-Operatoren. Dieser Abschnitt behandelt die nützlichsten Gruppen davon. Eine _Reduktion_ macht aus einer Liste einen einzigen Wert. Ein _Zip_ verbindet zwei Listen Element für Element. Die letzte Seite behandelt die _Kreuz-_, _Hyper-_ und _negierten_ Operatoren.
