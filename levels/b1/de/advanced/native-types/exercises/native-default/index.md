## Aufgabe

Eine native Variable kann nie undefiniert sein. Diese Regel gilt für jeden nativen Typ, nicht nur für `int`. Deklariere eine native `num` und eine native `str`, ohne ihnen Werte zuzuweisen. Gib die Zahl aus. Dann gib den String in eckigen Klammern aus, damit du siehst, dass er leer ist.

## Beispiel

Das Programm gibt aus:

```
0
[]
```
