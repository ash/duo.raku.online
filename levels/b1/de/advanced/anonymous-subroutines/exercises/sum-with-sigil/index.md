## Problem

Ein Pointy Block kann mehr als einen Parameter annehmen. Mit dem `&`-Sigil können Sie ihn über einen Namen aufrufen. Schreiben Sie einen Pointy Block mit zwei Parametern, der seine Argumente addiert. Speichern Sie ihn in einer Variablen `&add`, die mit dem `&`-Sigil deklariert ist. Rufen Sie ihn dann als `add(2, 3)` auf, ohne Sigil, und geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
5
```
