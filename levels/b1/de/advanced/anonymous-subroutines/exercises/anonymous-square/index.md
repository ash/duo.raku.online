## Problem

Eine anonyme Subroutine muss nicht zuerst gespeichert werden. Sie können sie direkt an eine andere Routine übergeben. Verwenden Sie die `sub`-Form, keinen Pointy Block, und schreiben Sie eine anonyme „Quadrat“-Subroutine. Übergeben Sie sie direkt an `map` über die Liste `1, 2, 3` und geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
(1 4 9)
```
