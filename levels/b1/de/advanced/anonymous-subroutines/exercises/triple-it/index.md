## Problem

Eine anonyme Subroutine ist eine Closure. Sie merkt sich die Variablen, die dort sichtbar waren, wo Sie sie geschrieben haben. Deklarieren Sie eine Variable `$factor` mit dem Wert `3`. Speichern Sie dann in `$scale` einen Pointy Block, der sein Argument mit `$factor` multipliziert. Schreiben Sie keine feste `3` in den Block. Rufen Sie `$scale(7)` auf und geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
21
```
