## Aufgabe

Du hast zwei Sets mit Obstnamen:

```raku
my $a = set(<apple banana cherry>);
my $b = set(<banana cherry date>);
```

Finde ihren Durchschnitt und speichere ihn in einer Variablen. Gib dann zwei Zeilen aus. Die erste ist, wie viele Werte die beiden Sets gemeinsam haben. Die zweite ist, ob `apple` einer dieser gemeinsamen Werte ist. Das sollte nicht so sein.

## Beispiel

Das Programm gibt aus:

```
2
False
```
