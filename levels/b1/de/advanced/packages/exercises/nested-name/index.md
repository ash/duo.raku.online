## Problem

Setze ein Modul `Inner` in ein Modul `Outer`. Deklariere in `Inner` eine `our`-Variable `$base` mit dem Wert `10`. Deklariere auch eine `our sub doubled`, die `$base` mal zwei zurückgibt. Greife von außerhalb beider Module über ihren vollen verschachtelten Namen auf die Variable zu. Rufe auch die Subroutine über ihren vollen verschachtelten Namen auf. Gib beide Ergebnisse aus.

## Beispiel

Das Programm gibt aus:

```
10
20
```
