## Problem

Erstelle ein Package `Temperature`, das zwei Dinge zusammenfasst. Das erste ist eine `our`-Variable `$freezing` mit dem Wert `0`. Das zweite ist eine `our`-Subroutine `fahrenheit`, die einen Celsius-Wert in Fahrenheit umrechnet. Zum Umrechnen multipliziere mit 9/5 und addiere 32. Gib von außerhalb des Packages den Gefrierpunkt aus. Gib dann den Fahrenheit-Wert von `100` Grad Celsius aus.

## Beispiel

Das Programm gibt aus:

```
0
212
```
