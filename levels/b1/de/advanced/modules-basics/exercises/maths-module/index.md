## Problem

Erstelle ein Modul namens `Maths` in einer Datei `Maths.rakumod`. Es soll eine Subroutine `square` exportieren, die das Quadrat ihres Arguments zurückgibt.

Schreibe dann ein separates Programm, das das Modul benutzt und `square(6)` ausgibt.

## Beispiel

Wenn du das Programm mit dem Modul im Suchpfad ausführst, gibt es Folgendes aus:

```console
$ raku -I. maths.raku
36
```
