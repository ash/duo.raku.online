## Problem

Erstelle ein Modul namens `Shouter` in einer Datei `Shouter.rakumod`. Es soll eine Subroutine `shout` exportieren, die ihr Argument in Großbuchstaben zurückgibt.

Schreibe dann ein separates Programm, das das Modul benutzt und `shout('hi')` ausgibt.

## Beispiel

Wenn du das Programm mit dem Modul im Suchpfad ausführst, gibt es Folgendes aus:

```console
$ raku -I. shout.raku
HI
```
