## Aufgabe

Definieren Sie zwei leere Klassen, `Cat` und `Dog`, und erzeugen Sie eine `Cat`-Instanz namens `$felix`. Geben Sie den Typ von `$felix` mit `WHAT` aus. Benutzen Sie dann den Operator `===` und geben Sie zwei weitere Zeilen aus. Die erste Zeile zeigt, ob dieser Typ derselbe wie `Cat` ist. Die zweite zeigt, ob er derselbe wie `Dog` ist.

## Beispiel

Das Programm gibt aus:

```
(Cat)
True
False
```
