## Aufgabe

Definieren Sie zwei leere Klassen, `Cat` und `Dog`. Gehen Sie dann mit einer Schleife über vier Werte: `Cat`, `Dog`, `Cat.new` und `Dog.new`. Geben Sie für jeden aus, ob er definiert ist. Beachten Sie, dass die zwei Typobjekte undefiniert sind und die zwei Instanzen definiert. Es spielt keine Rolle, zu welcher Klasse sie gehören.

## Beispiel

Das Programm gibt aus:

```
False
False
True
True
```
