## Aufgabe

Definieren Sie eine Basisklasse `Vehicle` mit einem Attribut `wheels`. Definieren Sie dann zwei Klassen, die von ihr erben. Ein `Bike` hat von Anfang an `2` Räder, und ein `Car` hat `4`.

Erzeugen Sie ein `Bike` und ein `Car`, und geben Sie aus, wie viele Räder jedes davon hat.

## Beispiel

Das Programm gibt aus:

```
2
4
```
