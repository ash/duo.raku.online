## Aufgabe

Definieren Sie eine Klasse `Dog` mit nur einem Attribut `name` und ohne Methoden. Fügen Sie ihr dann mit dem MOP zur Laufzeit eine Methode `speak` hinzu. Die neue Methode soll den eigenen `name` des Objekts benutzen und `<name> says woof` zurückgeben. Erzeugen Sie einen Hund namens `Rex` und rufen Sie die neue Methode auf.

## Beispiel

Das Programm gibt aus:

```
Rex says woof
```
