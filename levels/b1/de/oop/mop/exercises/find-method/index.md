## Aufgabe

Definieren Sie eine Klasse `Animal` mit einer Methode `speak`. Definieren Sie dann eine Klasse `Dog`, die von `Animal` erbt. Sie fügt keine eigenen Methoden hinzu. Benutzen Sie eine Metamethode auf `Dog` und geben Sie aus, ob `Dog` eine Methode namens `speak` hat. Geben Sie ein einfaches `True` oder `False` aus. Das zeigt, dass `find_method` entlang der Vererbungskette sucht. Die Methode sucht nicht nur bei den eigenen Methoden der Klasse.

## Beispiel

Das Programm gibt aus:

```
True
```
