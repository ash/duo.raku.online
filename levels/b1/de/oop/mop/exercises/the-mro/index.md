## Aufgabe

Definieren Sie eine Kette aus drei Klassen. Zuerst kommt `A`. Dann erbt `B` von `A`, und `C` erbt von `B`. Geben Sie die method resolution order von `C` als Liste von Typnamen aus.

## Beispiel

Das Programm gibt aus:

```
(C B A Any Mu)
```
