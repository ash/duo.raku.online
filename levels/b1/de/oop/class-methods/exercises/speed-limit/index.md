## Aufgabe

Wie jede andere Methode kann eine Klassenmethode Parameter nehmen. Definieren Sie eine Klasse `Geometry` mit einer Klassenmethode `circle-area`. Sie nimmt einen Radius und gibt die Fläche eines Kreises zurück, gerundet auf eine ganze Zahl. Benutzen Sie `π` oder `pi`. Die Formel gehört zur ganzen Klasse, und kein einzelnes Kreisobjekt spielt dabei eine Rolle. Rufen Sie die Methode auf der Klasse mit einem Radius von `10` auf und geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
314
```
