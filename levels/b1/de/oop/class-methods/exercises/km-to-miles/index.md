## Aufgabe

Definieren Sie eine Klasse `Converter` mit einer Klassenmethode `km-to-miles`. Sie nimmt eine Anzahl Kilometer und gibt die Strecke in Meilen zurück. Zum Umrechnen multiplizieren Sie mit `0.621`.

Rufen Sie die Methode auf der Klasse mit `10` Kilometern auf und geben Sie dann das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
6.21
```
