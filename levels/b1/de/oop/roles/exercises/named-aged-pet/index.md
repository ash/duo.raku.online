## Aufgabe

Definieren Sie zwei Rollen:

* `Named`, mit einer Methode `label`, die `I am <name>` zurückgibt;
* `Aged`, mit einer Methode `status`, die `<age> years` zurückgibt.

Definieren Sie dann eine Klasse `Pet`, die beide Rollen erfüllt. Sie hat die Attribute `name` und `age`. Erzeugen Sie ein Haustier namens `Rex` im Alter von `3`. Geben Sie dann sein `label` und seinen `status` aus.

## Beispiel

Das Programm gibt aus:

```
I am Rex
3 years
```
