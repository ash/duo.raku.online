## Aufgabe

Definieren Sie eine Klasse `Robot` mit einer Methode `speak`, die `beep` zurückgibt. Definieren Sie dann eine Rolle `Dancing`, die eine Methode `dance` hinzufügt, die `spinning around` zurückgibt.

Erzeugen Sie zwei Roboter, aber geben Sie die Rolle `Dancing` nur einem von beiden. Geben Sie das Ergebnis von `speak` für beide Roboter aus. Geben Sie dann das Ergebnis von `dance` für den Roboter aus, der tanzen kann.

## Beispiel

Das Programm gibt aus:

```
beep
beep
spinning around
```
