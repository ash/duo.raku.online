## Aufgabe

Ein `try`-Block, der fehlschlägt, ergibt einen undefinierten Wert. Nutzen Sie das mit dem Defined-or-Operator `//`, um einen Ersatzwert anzugeben. Führen Sie einen `try`-Block mit `die 'no'` darin aus. Wenn er fehlschlägt, verwenden Sie stattdessen die Zeichenkette `default`. Geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
default
```
