## Aufgabe

Zeigen Sie beide Seiten von `try`. Verwenden Sie zuerst einen `try`-Block um eine Berechnung, die funktioniert, zum Beispiel `6 * 7`. Geben Sie dann ihr Ergebnis aus. Schreiben Sie danach Code, der `die 'broken'` ausführt, in einen zweiten `try`-Block. Geben Sie aus, ob dieser Block ein definiertes Ergebnis geliefert hat. Geben Sie dann die Meldung der gefangenen Ausnahme aus.

## Beispiel

Das Programm gibt aus:

```
42
False
broken
```
