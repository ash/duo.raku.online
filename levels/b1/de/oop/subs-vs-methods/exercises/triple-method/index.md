## Aufgabe

Lösen Sie jetzt dieselbe Aufgabe mit einer **Methode**. Definieren Sie eine Klasse `Number` mit einem Attribut `n`. Geben Sie ihr eine Methode `triple`, die das Dreifache von `n` zurückgibt. Erzeugen Sie ein `Number` mit `n` gleich `7`. Rufen Sie dann `triple` darauf auf und geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
21
```
