## Aufgabe

Schreiben Sie eine Schleife über die Zahlen `1`, `2` und `3`. Geben Sie für jede Zahl `ok: <n>` aus. Aber wenn die Zahl `2` ist, sollen Sie stattdessen `die "bad: 2"` ausführen. Fügen Sie im Schleifenrumpf einen `CATCH`-Phaser hinzu, der `caught: <message>` ausgibt. So hält eine schlechte Runde nicht die ganze Schleife an.

## Beispiel

Das Programm gibt aus:

```
ok: 1
caught: bad: 2
ok: 3
```
