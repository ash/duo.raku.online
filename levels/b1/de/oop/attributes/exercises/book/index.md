## Aufgabe

Definieren Sie eine Klasse `Book` mit zwei Attributen, `title` und `author`. Erzeugen Sie ein Buch mit dem Titel `Raku` und dem Autor `Larry`. Geben Sie dann eine Zeile aus, die das Buch nennt und beide Accessoren benutzt. Die Zeile soll so aussehen: `<title> by <author>`.

## Beispiel

Das Programm gibt aus:

```
Raku by Larry
```
