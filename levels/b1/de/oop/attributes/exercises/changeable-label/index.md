## Aufgabe

Definieren Sie eine Klasse `Label` mit einem Attribut, `text`, das man ändern kann (`is rw`). Erzeugen Sie ein Etikett mit dem Text `draft`. Benutzen Sie dann den Accessor, um ` (revised)` an das Ende des Textes **anzuhängen**. Erzeugen Sie das Objekt nicht noch einmal. Geben Sie das Ergebnis aus.

## Beispiel

Das Programm gibt aus:

```
draft (revised)
```
