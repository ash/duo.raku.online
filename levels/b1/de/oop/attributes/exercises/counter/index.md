## Aufgabe

Definieren Sie eine Klasse `Counter` mit einem Attribut, `count`, das man ändern kann (`is rw`). Sein Standardwert ist `0`.

Erzeugen Sie einen Zähler und geben Sie zuerst sein `count` aus. Das prüft, ob er beim Standardwert beginnt. Erhöhen Sie ihn dann mit einer Schleife fünfmal um eins. Geben Sie den Endwert aus.

## Beispiel

Das Programm gibt aus:

```
0
5
```
