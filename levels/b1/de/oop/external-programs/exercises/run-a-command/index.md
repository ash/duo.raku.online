## Aufgabe

Starten Sie mit `run` das Programm `echo` mit zwei getrennten Argumenten: `home:` und `$HOME`. Lassen Sie seine Ausgabe auf den Bildschirm gehen. Beachten Sie, dass `$HOME` unverändert erscheint und das Heimatverzeichnis **nicht** ausgegeben wird. Weil `run` keine Shell benutzt, wird die Variable nicht durch ihren Wert ersetzt.

## Beispiel

Das Programm gibt aus:

```
home: $HOME
```
