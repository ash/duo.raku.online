## Aufgabe

Führen Sie einen Befehl aus, der absichtlich fehlschlägt, zum Beispiel `sh -c 'exit 4'`. Behalten Sie das `Proc`, das er zurückgibt. Geben Sie den Exit-Code des Befehls aus. Geben Sie dann `success` oder `failure` aus, je nachdem, ob der Befehl gelungen ist.

## Beispiel

Das Programm gibt aus:

```
4
failure
```
