## Aufgabe

Definieren Sie eine Basisklasse `Animal` und eine Klasse `Dog`, die von ihr erbt. Geben Sie den Namen der Klasse `Dog` aus. Geben Sie in der nächsten Zeile die Anzahl der Typen in ihrer Vererbungskette aus. Benutzen Sie dafür `.^mro` und zählen Sie die Elemente. Geben Sie schließlich in einer dritten Zeile aus, ob irgendwo in dieser Kette eine Klasse `Cat` vorkommt.

## Beispiel

Das Programm gibt aus:

```
Dog
4
False
```
