## Aufgabe

Schreiben Sie die drei Wörter `apple`, `banana` und `cherry` in eine Datei namens `words.txt`. Schreiben Sie jedes Wort in eine eigene Zeile. Lesen Sie die Datei dann Zeile für Zeile. Geben Sie jede Zeile mit ihrer Zeilennummer davor aus, beginnend bei `1`. Verwenden Sie die Form `<Nummer>: <Zeile>`.

## Beispiel

Das Programm gibt aus:

```
1: apple
2: banana
3: cherry
```
