## Aufgabe

Öffnen Sie eine Datei namens `out.txt` zum Schreiben. Lassen Sie den Handle offen. Schreiben Sie in einer Schleife die Zahlen `1`, `2` und `3` hinein. Schreiben Sie jede Zahl in eine eigene Zeile. Schließen Sie dann den Handle, lesen Sie die Datei zurück und geben Sie ihren Inhalt aus.

## Beispiel

Das Programm gibt aus:

```
1
2
3
```
