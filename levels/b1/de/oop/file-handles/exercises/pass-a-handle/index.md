## Aufgabe

Ein Dateihandle ist ein gewöhnlicher Wert. Also können Sie ihn wie jedes andere Argument an eine Funktion übergeben. Schreiben Sie eine Subroutine `log-line`, die einen Handle und eine Meldung nimmt. Sie soll die Meldung in einer eigenen Zeile in den Handle schreiben.

Öffnen Sie `log.txt` zum Schreiben. Rufen Sie `log-line` dreimal auf, um `started`, `working` und `done` zu schreiben. Schließen Sie dann den Handle, lesen Sie die Datei zurück und geben Sie ihren Inhalt aus.

## Beispiel

Das Programm gibt aus:

```
started
working
done
```
