## Aufgabe

Schreiben Sie eine Subroutine `lookup`. Sie gibt `100` zurück, wenn ihr Argument `'a'` ist. Andernfalls ruft sie `fail` mit der Meldung `no such key` auf.

Rufen Sie `lookup('z')` auf und geben Sie das Ergebnis aus, wenn es definiert ist. Wenn nicht, geben Sie `not found` aus. Geben Sie in einer zweiten Zeile den Grund für den Fehlschlag aus, den Sie aus dem `Failure` selbst nehmen: `reason: <message>`.

## Beispiel

Das Programm gibt aus:

```
not found
reason: no such key
```
