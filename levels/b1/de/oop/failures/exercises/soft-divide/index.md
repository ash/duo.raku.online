## Aufgabe

Schreiben Sie eine Subroutine `reciprocal`, die `1` geteilt durch ihr Argument zurückgibt. Aber wenn das Argument `0` ist, soll sie `fail` mit der Meldung `no reciprocal of zero` verwenden.

Geben Sie das Ergebnis von `reciprocal(4)` aus. Geben Sie dann das Ergebnis von `reciprocal(0)` aus. Statt selbst `.defined` zu prüfen, verwenden Sie den Operator `//`. Er soll die Zeichenkette `undefined` liefern, wenn der Aufruf fehlschlägt.

## Beispiel

Das Programm gibt aus:

```
0.25
undefined
```
