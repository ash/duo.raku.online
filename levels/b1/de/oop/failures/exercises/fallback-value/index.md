## Aufgabe

Schreiben Sie eine Subroutine `get`, die ihr Argument zurückgibt. Aber wenn das Argument `0` ist, soll sie `fail` mit der Meldung `bad` aufrufen.

Geben Sie das Ergebnis von `get(5)` und dann von `get(0)` aus. Nutzen Sie den Defined-or-Operator `//`, um den Ersatzwert `default` anzugeben.

## Beispiel

Das Programm gibt aus:

```
5
default
```
