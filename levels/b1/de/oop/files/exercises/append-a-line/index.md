## Aufgabe

Bauen Sie eine kleine Protokolldatei auf, indem Sie immer wieder etwas hinzufügen. Schreiben Sie die Zeile `start` in eine Datei namens `log.txt`. **Hängen** Sie dann in einer Schleife drei weitere Zeilen **an**: `entry 1`, `entry 2` und `entry 3`. Löschen Sie nicht, was schon in der Datei steht. Lesen Sie zum Schluss die ganze Datei und geben Sie sie aus.

## Beispiel

Das Programm gibt aus:

```
start
entry 1
entry 2
entry 3
```
