## Aufgabe

Speichern Sie eine Zahl in einer Datei und laden Sie sie wieder. Schreiben Sie die Zahl `42` und einen Zeilenumbruch in eine Datei namens `number.txt`. Lesen Sie die Datei dann zurück und machen Sie aus ihrem Inhalt eine ganze Zahl. Geben Sie diese Zahl mal zwei aus.

## Beispiel

Das Programm gibt aus:

```
84
```
