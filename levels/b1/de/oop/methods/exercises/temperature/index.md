## Aufgabe

Definieren Sie eine Klasse `Celsius` mit einem Attribut `degrees`. Fügen Sie eine Methode `to-fahrenheit` hinzu, die die Temperatur in Fahrenheit umrechnet. Benutzen Sie die Formel `Grad × 9 / 5 + 32`.

Erzeugen Sie ein `Celsius`-Objekt für `100` Grad und geben Sie seinen Wert in Fahrenheit aus.

## Beispiel

Das Programm gibt aus:

```
212
```
