## Aufgabe

Definieren Sie eine Klasse `Rectangle` mit den Attributen `width` und `height`. Geben Sie ihr eine Methode `area`, die die Fläche des Rechtecks zurückgibt. Fügen Sie eine zweite Methode hinzu, `describe`, die die Zeichenkette `area is <area>` zurückgibt. Dazu muss sie über `self` **ihre eigene Methode `area` aufrufen**.

Erzeugen Sie ein Rechteck, das `3` breit und `4` hoch ist. Geben Sie dann seine Beschreibung aus.

## Beispiel

Das Programm gibt aus:

```
area is 12
```
