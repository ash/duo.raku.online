## Aufgabe

Definieren Sie eine Klasse `Robot` mit einem Attribut `position`, das man ändern kann. Sein Standardwert ist `0`. Fügen Sie eine Methode `move` hinzu, die die Position um eine gegebene Anzahl von Schritten nach vorn bewegt. Die Anzahl der Schritte soll den Standardwert `1` haben. Dann bewegt ein Aufruf von `move` ohne Argument den Roboter einen Schritt.

Erzeugen Sie einen Roboter und bewegen Sie ihn `5` Schritte. Bewegen Sie ihn dann ohne Argument und danach noch `2` Schritte. Geben Sie seine Endposition aus.

## Beispiel

Das Programm gibt aus:

```
8
```
