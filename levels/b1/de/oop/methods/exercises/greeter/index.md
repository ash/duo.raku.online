## Aufgabe

Definieren Sie eine Klasse `Word` mit einem Attribut `text` und einer Methode `reversed`. Die Methode gibt den Text des Wortes rückwärts geschrieben zurück. Sie können die Methode `flip` benutzen, die eine Zeichenkette umdreht.

Erzeugen Sie ein Wort mit dem Inhalt `Raku` und geben Sie es umgedreht aus.

## Beispiel

Das Programm gibt aus:

```
ukaR
```
